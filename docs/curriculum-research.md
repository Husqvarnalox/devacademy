Чужие курсы использовались **только как ориентир методики**: порядок тем, размер шага, форма упражнений и проверки.
Тексты, примеры, задания, решения и тесты DevAcademy написаны заново. Технические факты сверяются с официальной
документацией (go.dev, pkg.go.dev, docs.python.org и т. д.). Бесплатный доступ к курсу не даёт права его переиздавать.

## 2. Сравнение подходов

Оценка экспертная (по структуре курсов), не измерение эффективности.

| Ресурс | Последовательность | Новых понятий на шаг | Упражнения | Самостоятельность | Проверка усвоения | Продвинутая часть |
|---|---|---|---|---|---|---|
| Helsinki Python MOOC | вывод → ввод → переменные → условия → циклы → функции → списки → словари → файлы → ООП | 1-2 | очень много мелких задач, растущих по сложности | постепенно, от правки примера к задачам с нуля | автотесты TMC на каждую задачу | вторая часть: ООП, продвинутые темы |
| CS50P | по неделям: функции → условия → циклы → исключения → библиотеки → тесты → файлы → regex → ООП | 3-5 за неделю | наборы задач + финальный проект | высокая, задачи сформулированы как спецификации | check50, финальный проект | нет отдельной |
| Python Tutorial | справочный порядок: интерпретатор → типы → управление → структуры данных → модули → ввод-вывод → ошибки → классы | много | нет | - | нет | stdlib-тур |
| A Tour of Go | плотный тур для программистов: основы → методы и интерфейсы → обобщения → конкурентность | 1 на слайд, но предполагает опыт | правка кода в песочнице, несколько упражнений | средняя | нет | конкурентность в конце |
| Go by Example | справочник примеров по темам | 1 на страницу | нет | - | нет | широкий охват stdlib |
| Learn Go with Tests | каждая глава: тест → реализация → рефакторинг | 1-2 | сам код главы | высокая | тесты как спецификация | конкурентность, контекст, HTTP |

| MDN Learn / Odin / Full Stack Open | проектный путь веб-разработчика | разное | проекты, курс FSO - сабмиты | высокая | проекты, ревью | фреймворки, бэкенд |

| Rust Book | концепт-главы + проектные главы | 2-3 | проекты внутри глав | средняя | нет | unsafe, async, макросы |

## 3. Что взято в методику DevAcademy

1. **Одно понятие за шаг и много мелких задач** (Helsinki, Exercism, learncpp) - урок вводит одно понятие; курс уровня 0
   разбит на 29 уроков вместо 3.
2. **От правки примера к задаче с нуля** (Helsinki) - уровни упражнений A-D в стандарте.
3. **Автопроверка каждой задачи с понятной причиной неудачи** (TMC, check50) - открытые и скрытые тесты с подсказкой,
   что проверяется; для функций - `go test` / harness, чтобы ошибка указывала на случай.
4. **Тест как спецификация** (Learn Go with Tests) - в профессиональном курсе ученик пишет и тесты; в курсе с нуля тесты
   только проверяют.
5. **Отдельный плотный путь для программистов** (A Tour of Go) - курс «Go для программистов», уроки которого зачитывают
   базовые.
6. **Дерево концептов** (Exercism) - метаданные `concepts` с проверкой валидатором «понятие введено до использования».
7. **Проекты для закрепления** (CS50P, Odin, FSO) - мини-проекты в конце курса с нуля.
8. **Внутреннее устройство - отдельно** (Python Tutorial и Go docs дают его как справку) - раздел `deep-dive` и
   профессиональные курсы, а не первый урок.

Отличия от источников: адаптивность по уровню подготовки и диагностика компетенций (ни один из перечисленных курсов не
пропускает материал по результатам проверки), русский язык, встроенная проверка без внешних инструментов.
