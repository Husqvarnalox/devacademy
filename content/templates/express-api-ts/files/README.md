# {{name}}

REST API на Express 5 и TypeScript. Нужен Node 22.15 или новее.

## Что внутри

- `src/app.ts` — `createApp()` собирает Express-приложение (маршруты `/health`, `/todos`) и ничего не слушает.
- `src/server.ts` — запускает `createApp()` на порту `PORT` (по умолчанию 3000).
- `src/app.test.ts` — API-тесты на встроенном `node:test`: сервер поднимается на свободном порту, запросы делает `fetch`.
- `tsconfig.json` — строгий режим, `noEmit`, `erasableSyntaxOnly`.

## Как запускается TypeScript

Node сам вырезает типы (`--experimental-strip-types`), поэтому нет ни `tsx`, ни шага сборки, а зависимостей минимум.
Ограничения: в импортах указывайте расширение `.ts`; нельзя `enum`, `namespace` и параметры-свойства конструктора
(`erasableSyntaxOnly` подсветит это ошибкой). Node выводит предупреждение ExperimentalWarning — это нормально.
Проверку типов делает `tsc`.

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm install` | ставит зависимости (нужна сеть) |
| `npm run dev` | сервер с перезапуском при изменениях, http://localhost:3000 |
| `npm start` | сервер без наблюдения |
| `npm test` | тесты `node:test` |
| `npm run build` | проверка типов (`tsc --noEmit`); сборки в JavaScript нет |

## Заметки об архитектуре

- Отделяйте создание приложения (`createApp`) от `listen`: тесты не занимают фиксированный порт.
- Хранилище задач в памяти — заглушка; замените его слоем доступа к данным за интерфейсом.
- Ошибки валидации возвращайте как `400` с телом `{ "error": "..." }`.
