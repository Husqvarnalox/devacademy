## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Такой текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется **JavaScript**. Он нужен, чтобы описывать действия компьютера, и на нём написана огромная часть современных сайтов и серверов.

Текст на JavaScript сам по себе ничего не делает - его должна кто-то прочитать и выполнить. В этом курсе выполняет его программа **Node.js**. Она открывает файл с исходным кодом, читает команды по порядку и исполняет их на вашем компьютере. Файл с программой называется `main.js`, а запускают его командой `node main.js`.

В приложении вам не нужно вводить эту команду вручную: вы пишете текст в редакторе, нажимаете «Запустить», и приложение само вызывает `node main.js`. Запоминать команду пока не нужно.

## Одна новая идея: команда `console.log` печатает текст

Чтобы увидеть результат работы программы, её нужно заставить что-то показать. Для этого есть команда `console.log(...)`. Она печатает то, что указано в скобках, и переходит на следующую строку. Текст в программе записывают в кавычках: `"Касса открыта"`.

<!-- section: examples -->
## Пример 1. Печать одной строки

```javascript run
console.log("Касса открыта");
```
```output
Касса открыта
```

Разбор по строкам:

* `console.log` - название команды. Слово `console` (консоль) означает «место, куда программа выводит текст», слово `log` - «записать в журнал»; вместе: «напечатать в консоль».
* `(` и `)` - скобки, внутри которых стоит то, что нужно напечатать. Это значение команде передают.
* `"Касса открыта"` - **строковый литерал**: текст, записанный прямо в программе, в двойных кавычках. Кавычки на экран не попадают.
* `;` - точка с запятой в конце команды. Она отмечает, что команда закончилась.

## Пример 2. Несколько команд подряд

```javascript run
console.log("Первая строка");
console.log("Вторая строка");
console.log("Третья строка");
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет.

## Пример 3. Несколько значений в одной команде

```javascript run
console.log("Итого:", 450, "рублей");
```
```output
Итого: 450 рублей
```

Внутри скобок значения можно разделять запятыми. `console.log` напечатает их в одной строке, поставив между ними по пробелу. Число `450` написано без кавычек: это не текст, а число, о них будет следующий урок.

**Попробуйте.** Поменяйте местами две строки в примере 2 и предскажите вывод до запуска. Затем уберите одну кавычку вокруг текста и посмотрите, что сообщит Node.js (подробнее - в разделе об ошибках и в следующем уроке).

## Точные правила

* Программа - это команды в файле. Node.js выполняет их сверху вниз, по одной.
* **Строковый литерал** записывают в двойных `"..."` или одинарных `'...'` кавычках. В этом курсе используются двойные. Внутри допустимы русские буквы, пробелы, цифры и знаки.
* Текст в кавычках печатается как есть. Если убрать кавычки, Node.js решит, что это не текст, а имя, и будет искать его.
* Регистр важен: `console.log` работает, `console.Log` и `Console.log` - нет.
* Между `console` и `log` стоит точка. Пробелов внутри имени нет.
* Команду принято заканчивать точкой с запятой. Node.js в большинстве случаев справится и без неё, но в курсе она ставится всегда: так видно, где команда кончается.
* Несколько значений в скобках разделяют запятыми; при печати между ними ставится пробел.
* Пустые строки между командами допустимы и улучшают чтение. Пустая команда `console.log();` печатает пустую строку.
* Строка, начинающаяся с `//`, - **комментарий**: Node.js её пропускает. Комментарии пишут для людей.

## Типичные ошибки

**1. Не закрыли кавычки.**

```javascript
console.log("Привет);
```

Node.js: `SyntaxError: Invalid or unexpected token`. Первая строка вывода показывает файл и номер строки (`main.js:1`), затем саму строку и значки `^^^` под проблемным местом. Строка началась с кавычки и не закончилась. Проверьте, что у каждой открывающей кавычки есть закрывающая. Редактор обычно подсвечивает текст в кавычках одним цветом: если цвет «убегает» до конца строки, кавычка пропущена.

**2. Опечатка в названии команды.**

```javascript
consol.log("Привет");
```

Node.js: `ReferenceError: consol is not defined`. Переводится: «имя `consol` не определено». Node.js не знает такого слова. Исправьте опечатку.

**3. Заглавная буква.**

```javascript
console.Log("Привет");
```

Node.js: `TypeError: console.Log is not a function`: «`console.Log` - это не функция». Слово `console` Node.js знает, а `Log` у него нет, поэтому вызвать его нельзя. Регистр букв входит в имя.

**4. Забыли кавычки у текста.**

```javascript
console.log(Привет);
```

Node.js: `ReferenceError: Привет is not defined`. Без кавычек `Привет` - не текст, а имя, а такого имени нет. Если вы хотите напечатать слово, оно должно стоять в кавычках.

Общее правило чтения: сначала найдите номер строки, затем последнюю строку сообщения - в ней название и причина ошибки. Откройте указанную строку и посмотрите на неё и на предыдущую. Подробно - в следующем уроке.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; JavaScript - язык, Node.js - программа, которая выполняет этот текст.
* `console.log("текст")` печатает значение и переходит на следующую строку; кавычки на экран не попадают.
* Команды выполняются сверху вниз; несколько значений через запятую печатаются через пробел.
* Регистр букв и кавычки важны: от них зависит, поймёт ли Node.js вашу команду.

Любая следующая программа курса устроена так же: набор команд в `main.js`. В следующем уроке вы научитесь читать сообщения об ошибках и исправлять их: [Как читать сообщения об ошибках](lesson:javascript.from-zero.reading-errors).

## Для тех, кто уже программирует

* Точки входа нет: Node.js выполняет файл сверху вниз. Ни `main`, ни класса-обёртки не нужно.
* `console.log` - аналог `print` в Python, `System.out.println` в Java, `Console.WriteLine` в C#, `fmt.Println` в Go. Несколько аргументов печатаются через пробел, как у `print` в Python.
* Точка с запятой формально необязательна из-за автоматической вставки, но в курсе она ставится всегда.
* Строки можно писать в одинарных, двойных или обратных кавычках; в курсе - двойные.
* JavaScript интерпретируется во время запуска: ошибки синтаксиса сообщаются сразу при старте, ошибки имён (`ReferenceError`) - в момент выполнения строки.
* `console` - глобальный объект Node.js, импорт не нужен.

## Что происходит при `node main.js`

Это необязательный раздел: для заданий он не нужен.

Node.js - это среда выполнения, построенная вокруг того же движка JavaScript, что и в браузере Chrome. Получив имя файла, она читает его целиком и разбирает текст по правилам языка. Если текст не соответствует правилам (например, не закрыта кавычка), выполнение не начинается совсем и вы сразу видите `SyntaxError`: ни одна команда файла не выполнена.

Если разбор прошёл, команды выполняются по порядку. Команда `console.log` не рисует текст сама. Она передаёт его в так называемый стандартный вывод - поток текста, который операционная система присоединяет к терминалу или, как в этом приложении, к окну результата. Поэтому одна и та же программа может печатать и на экран, и в файл: Node.js не знает, куда уходит поток.

Когда команды закончились, Node.js завершает работу и возвращает операционной системе код 0, «всё прошло хорошо». Необработанная ошибка завершает программу с ненулевым кодом, и именно по нему системы автоматической проверки отличают успех от сбоя.
