## Зачем это нужно

Почти каждая программа работает с текстом: приветствие по имени, чек, сообщение об ошибке, письмо. Почти всегда текст собирают из готовых частей и значений переменных. В этом уроке два способа это делать и один способ узнать длину текста.

## Одна новая идея: строки можно собирать из частей

**Склейка** (конкатенация) - соединение двух строк в одну. Выполняет её оператор `+`: `"Ча" + "й"` даёт `"Чай"`. Один и тот же знак `+` складывает числа и склеивает строки; что именно произойдёт, зависит от типов значений по обе стороны.

**Шаблонная строка** - текст в обратных кавычках `` ` ``, внутри которого можно писать `${выражение}`. Выражение вычисляется, и его значение подставляется в текст на это место: `` `Привет, ${name}!` ``. Так записывать сборку удобнее, чем цепочку из `+`.

**Длина строки** - число символов в ней. Её даёт запись `строка.length` (через точку, без скобок).

<!-- section: examples -->
## Пример 1. Склейка

```javascript run
const first = "Иван";
const last = "Петров";
console.log(first + last);
console.log(first + " " + last);
console.log("Привет, " + first + "!");
```
```output
ИванПетров
Иван Петров
Привет, Иван!
```

Разбор: первая склейка не добавляет пробел сама, поэтому имена слиплись. Во второй пробел вставлен как отдельная строка `" "`. В третьей текст собран из трёх частей: `"Привет, "`, значения `first` и `"!"`.

## Пример 2. Шаблонная строка

```javascript run
const first = "Иван";
const price = 45;
const count = 3;
console.log(`Привет, ${first}!`);
console.log(`${count} шт. по ${price} руб. = ${price * count} руб.`);
```
```output
Привет, Иван!
3 шт. по 45 руб. = 135 руб.
```

Разбор: строка начинается и заканчивается обратной кавычкой, а не двойной. Внутри `${first}` подставляет значение переменной. Во второй команде внутри `${}` стоит целое выражение `price * count`: оно вычисляется, и в текст попадает результат `135`.

## Пример 3. Длина строки

```javascript run
const word = "привет";
console.log(word.length);
console.log("привет мир".length);
console.log("".length);
```
```output
6
10
0
```

Пробел - такой же символ, как буква, поэтому в `"привет мир"` их десять. Пустая строка `""` имеет длину 0.

## Пример 4. Число рядом со строкой

```javascript run
console.log("Итого: " + 450);
console.log(2 + 3);
console.log("2" + "3");
console.log("2" + 3);
```
```output
Итого: 450
5
23
23
```

Если хотя бы один операнд `+` - строка, число превращается в текст и происходит склейка. Поэтому `"2" + 3` - это `"23"`, а не `5`. Если обе части числа, они складываются.

**Попробуйте.** Соберите свою фразу «Меня зовут ... , мне ... лет» двумя способами - через `+` и через шаблонную строку - и сравните вывод. Затем выведите длину своего имени.

<!-- section: precise -->
## Точные правила

* Оператор `+` складывает, если оба операнда числа, и склеивает, если хотя бы один операнд - строка (число при этом превращается в текст).
* Склейка не добавляет пробелов: `"a" + "b"` равно `"ab"`.
* Шаблонная строка записывается в **обратных кавычках** `` `...` ``. Внутри `${...}` может стоять любое выражение: имя переменной, арифметика, вызов команды.
* Одинарные и двойные кавычки не вычисляют `${}`: в `"Привет, ${name}"` это обычный текст.
* `строка.length` - число символов (точнее, кодовых единиц UTF-16: для русских букв, цифр и пробелов - по одной на символ). Скобок после `length` нет.
* Кавычку внутри строки той же кавычки записывают с обратной косой чертой: `"Он сказал: \"да\""`. Знак `\n` внутри кавычек означает перенос строки, `\t` - табуляцию. Строки в обратных кавычках могут занимать несколько строк.
* Строка неизменяема: склейка создаёт новую строку, старая не меняется.
* Знак `+=` работает и со строками: `text += "!"` добавляет в конец.

## Типичные ошибки

**1. Не поставили пробел.**

```javascript
console.log("Привет," + name);
```

Если `name` равно `"Иван"`, напечатается `Привет,Иван`. Пробел - символ, его нужно записать: `"Привет, " + name`.

**2. Кавычки вместо обратных кавычек в шаблоне.**

```javascript
console.log("Привет, ${name}!");
```

Печатается дословно `Привет, ${name}!`: подстановка работает только в обратных кавычках. Замените кавычки на `` ` ``.

**3. Сложение вместо склейки (и наоборот).**

```javascript
console.log("Итого: " + 2 + 3);
```

Печатается `Итого: 23`, а не `Итого: 5`: `+` вычисляется слева направо, и после первой склейки всё остальное тоже склеивается. Если нужна сумма, возьмите её в скобки: `"Итого: " + (2 + 3)`.

**4. Скобки после `length`.**

```javascript
console.log("мир".length());
```

Node.js: `TypeError: "мир".length is not a function`. `length` - значение (число 3), а не команда, скобки не нужны.

**5. Забыли закрыть `${`.**

```javascript
console.log(`Привет, ${name!`);
```

Node.js: `SyntaxError: Missing } in template expression` («пропущена } в подстановке»). Каждому `${` нужна своя `}`.

**6. Забыли кавычку у разделителя.**

```javascript
console.log(first + , + last);
```

Node.js: `SyntaxError: Unexpected token ','`. Текстовый разделитель должен быть в кавычках: `first + ", " + last`.

<!-- section: summary -->
## Итоги

* `+` между числами складывает, а если есть хотя бы одна строка - склеивает. Пробелы при склейке нужно писать самому.
* Шаблонная строка в обратных кавычках подставляет значение выражения из `${}` в текст.
* `строка.length` возвращает число символов, пробелы входят.

Мы умеем хранить значения, считать и собирать текст. Чтобы программа могла принимать решения, нужны сравнения: [Сравнения и логика](lesson:javascript.from-zero.comparison-and-logic).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `+` перегружен: если есть строка, число приводится к тексту (`"2" + 3` даёт `"23"`). В Python это `TypeError`, в Java/C# - тоже склейка.
* Шаблонные строки в обратных кавычках - аналог f-строк Python (`f"{x}"`), интерполяции C# (`$"{x}"`), `fmt.Sprintf` в Go; внутри `${}` любое выражение, строки могут быть многострочными.
* Строки неизменяемы; `length` - свойство, а не метод (в отличие от `len()` в Python и `.Length()`/`.length()` в других языках); считает кодовые единицы UTF-16, поэтому `"😀".length === 2`.
* Отдельного типа `char` нет.
* Одинарные и двойные кавычки взаимозаменяемы.
* Много склеек в цикле работают нормально: движок оптимизирует их внутри, `StringBuilder` обычно не нужен.

<!-- section: deep-dive -->
## Что значит «неизменяемая» и почему length считает 2 для смайлика

Это необязательный раздел: для заданий он не нужен.

Строка в JavaScript хранится как последовательность 16-битных кодовых единиц (формат UTF-16). Русские буквы, латиница, цифры и пробелы занимают одну единицу. Редкие символы вроде эмодзи не помещаются в 16 бит и занимают две, поэтому `"😀".length` равно `2`, хотя на экране это один значок. Для задач этого курса длина русского и английского текста считается ожидаемо.

Строка неизменяема: операция `a + b` не дописывает `b` в `a`, а создаёт новую строку. Поэтому присваивание `text += "!"` на самом деле означает «создать склейку и записать её в переменную `text`». Старое значение остаётся в памяти, пока на него есть ссылки, и затем уничтожается автоматически.
