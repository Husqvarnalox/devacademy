## Зачем это нужно

В цикле `while` три части живут в разных местах: начальное значение счётчика - до цикла, условие - в заголовке, изменение счётчика - в конце тела. Забыть любую из них легко. Когда число повторений известно заранее («сделать 10 раз», «пройти от 1 до n»), эти части удобнее собрать в одной строке. Для этого есть цикл **`for`** (англ. «для»).

## Одна новая идея: заголовок for собирает счётчик в одну строку

```javascript
for (let i = 0; i < 5; i++) {
  // тело
}
```

В круглых скобках три части через точку с запятой:

1. `let i = 0` - **начало**: выполняется один раз перед циклом, создаёт счётчик.
2. `i < 5` - **условие**: проверяется перед каждым шагом; пока оно истинно, тело выполняется.
3. `i++` - **изменение**: выполняется после каждого шага, увеличивает счётчик на 1.

Этот цикл выполнится 5 раз: `i` будет 0, 1, 2, 3, 4. Цикл `for` и `while` - равносильные способы записи: `for` удобнее, когда есть счётчик, `while` - когда повторение определяется условием («пока не накопится сумма»).

<!-- section: examples -->
## Пример 1. Счётчик от 0

```javascript run
for (let i = 0; i < 5; i++) {
  console.log("i =", i);
}
console.log("Готово");
```
```output
i = 0
i = 1
i = 2
i = 3
i = 4
Готово
```

Разбор: `i` начинается с 0 и растёт на 1 после каждого шага. Пока `i < 5` истинно, тело выполняется. Когда `i` стало 5, условие ложно, и цикл заканчивается. Значения 0-4 - это пять шагов. Нумерация с нуля принята в программировании почти везде; позже вы встретите её в массивах.

## Пример 2. Счётчик от 1 и сумма

```javascript run
let sum = 0;
for (let i = 1; i <= 5; i++) {
  sum = sum + i;
}
console.log(sum);
```
```output
15
```

Начало 1, условие `i <= 5` включает пятёрку. Переменная `sum` объявлена **до** цикла: так её видно и после него. Эту же задачу вы решали циклом `while`; запись стала короче, а счётчик нельзя забыть изменить.

## Пример 3. Другой шаг и обратный отсчёт

```javascript run
let evens = "";
for (let i = 0; i <= 10; i += 2) {
  evens = evens + i + " ";
}
console.log(evens + "стоп");

let back = "";
for (let i = 3; i > 0; i--) {
  back = back + i + " ";
}
console.log(back + "старт");
```
```output
0 2 4 6 8 10 стоп
3 2 1 старт
```

Изменение может быть любым: `i += 2` шагает через два, `i--` уменьшает на 1. При обратном отсчёте условие меняется на `i > 0`.

## Пример 4. for и if вместе

```javascript run
function countEven(limit) {
  let count = 0;
  for (let i = 1; i <= limit; i++) {
    if (i % 2 === 0) {
      count++;
    }
  }
  return count;
}

console.log(countEven(10));
console.log(countEven(0));
```
```output
5
0
```

Цикл перебирает числа, а `if` внутри отбирает нужные. Для `limit` равного 0 условие `1 <= 0` ложно сразу, тело не выполняется, и функция возвращает исходное значение счётчика 0.

**Попробуйте.** Напишите цикл, который печатает таблицу умножения на 7 в виде `7 * 1 = 7`. Подсказка: используйте шаблонную строку с `${i}` и `${7 * i}`. Затем измените цикл так, чтобы он шёл от 10 до 1.

## Точные правила

* Форма: `for (начало; условие; изменение) { тело }`. Части разделяются точкой с запятой, не запятой.
* Порядок выполнения: начало (один раз) → условие → тело → изменение → условие → тело → ... Когда условие ложно, цикл заканчивается.
* Счётчик, объявленный в заголовке (`let i`), существует **только внутри цикла**. После него он недоступен.
* Типичные формы: `i = 0; i < n; i++` - ровно `n` шагов со значениями от 0 до `n - 1`; `i = 1; i <= n; i++` - значения от 1 до `n` включительно; `i = n; i > 0; i--` - в обратную сторону.
* `i++` увеличивает на 1, `i--` уменьшает на 1, `i += k` увеличивает на `k`.
* Если условие ложно сразу, тело не выполняется ни разу; результат определяют начальные значения переменных до цикла.
* Менять счётчик внутри тела допустимо, но не нужно: это делает цикл трудно читаемым.
* Накопитель объявляют до цикла: `0` для суммы и счётчика, `1` для произведения, `""` для текста.
* Любой `for` можно заменить `while`, и наоборот. Выбирают тот вариант, который читается проще.

## Типичные ошибки

**1. Запятые вместо точек с запятой.**

```javascript
for (let i = 0, i < 3, i++) {
  console.log(i);
}
```

Node.js: `SyntaxError: Identifier 'i' has already been declared`. После запятой Node.js решает, что вы объявляете ещё одну переменную `i`. Части заголовка разделяются `;`.

**2. Ошибка на единицу.**

```javascript
for (let i = 0; i <= 3; i++) {
  console.log("шаг");
}
```

Печатает «шаг» четыре раза, а не три. Для `n` повторений при счётчике с нуля нужно `i < n`. Для значений от 1 до `n` включительно - `i <= n`.

**3. Использование счётчика после цикла.**

```javascript
for (let i = 0; i < 3; i++) {
}
console.log(i);
```

Node.js: `ReferenceError: i is not defined`. `i` живёт только внутри цикла. Если значение нужно после цикла, сохраните его в переменную, объявленную раньше.

**4. Точка с запятой после заголовка.**

```javascript
for (let i = 0; i < 3; i++);
{
  console.log("x");
}
```

Печатается «x» один раз, а не три: `;` сделала тело цикла пустым, а блок ниже выполняется отдельно. Как и в `if`, `;` после `)` не нужна.

**5. Не закрыли фигурную скобку.**

```javascript
for (let i = 0; i < 3; i++) {
  console.log(i);
```

Node.js: `SyntaxError: Unexpected end of input` («неожиданный конец ввода»). Файл закончился, а блок не закрыт. Проверьте, что на каждую `{` есть `}`.

**6. Накопитель внутри цикла.**

```javascript
for (let i = 1; i <= 3; i++) {
  let sum = 0;
  sum = sum + i;
}
```

Накопитель сбрасывается на каждом шаге, и итог всегда равен последнему слагаемому; снаружи цикла `sum` вообще не виден. Объявляйте накопитель до цикла.

**7. Начальное значение не подходит накопителю.**

Для произведения накопитель `0` даёт всегда `0`; для текста `0` превратит результат в строку вида `"0ab"`. Начинайте с нейтрального значения: `1` для умножения, `""` для текста.

## Итоги

* `for (начало; условие; изменение) { тело }` собирает счётчик в одну строку и подходит, когда число шагов известно.
* Выполняется: начало один раз, затем условие, тело, изменение - по кругу, пока условие истинно.
* `i < n` даёт значения от 0 до `n - 1`, `i <= n` включает `n`; счётчик виден только внутри цикла.
* Накопители объявляются до цикла и начинаются с нейтрального значения.

Остался последний шаг в изучении циклов: как остановить цикл раньше и как вкладывать циклы друг в друга: [Управление циклом](lesson:javascript.from-zero.loop-control).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Классический `for` как в C/Java/C#; в Go это единственная форма цикла, в Python аналог - `for i in range(n)`.
* `let i` в заголовке создаёт **новую привязку на каждой итерации**: замыкания, захватившие `i`, видят своё значение (с `var` было бы иначе).
* `for...of` и `for...in` (перебор значений коллекций) - в следующих уроках; здесь только счётный цикл.
* Любая из трёх частей заголовка может быть пустой: `for (;;)` - бесконечный цикл.
* Модификация `i` внутри тела разрешена и меняет ход цикла.
* `i++` как выражение возвращает старое значение; в курсе используется только как отдельная команда.

## Как for превращается в while

Это необязательный раздел: для заданий он не нужен.

Цикл `for (A; B; C) { тело }` почти буквально равен записи:

```text
A;
while (B) {
  тело
  C;
}
```

Разница одна: для `let`-счётчика в заголовке язык создаёт отдельную копию переменной на каждый шаг. Это почти незаметно в простых циклах, но важно, когда внутри тела создают функции, запоминающие счётчик. Поэтому в современном JavaScript пишут `for (let i ...)`, а не `var`.

Выбор между `for` и `while` - вопрос читаемости. Если вы пишете `let i = 0; while (i < n) { ...; i++; }`, то это `for` в разобранном виде. А если число шагов заранее неизвестно, как при накоплении суммы до цели, то `while` честнее: он показывает, что цикл управляется условием, а не счётчиком.
