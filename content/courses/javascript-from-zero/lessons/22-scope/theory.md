## Зачем это нужно

Вы уже объявляли переменные внутри функций и циклов. Но где именно переменная «живёт»? Если написать `let` внутри `if`, увидит ли её код после `if`? А если в функции уже есть переменная с таким именем? Ответы на такие вопросы определяют, правильно ли считает программа. Ошибки здесь коварные: код запускается, ничего не падает, а результат тихо неверный (сумма равна нулю, максимум - первое число).

## Одна новая идея: переменная живёт в своём блоке

**Блок** - это код между фигурными скобками `{ ... }`: тело функции, цикла, ветки `if`. Переменная, объявленная через `let` или `const`, существует **только внутри блока, где объявлена** (и внутри блоков, вложенных в него), и исчезает на закрывающей скобке. Область, где имя можно использовать, называется **областью видимости** (по-английски scope).

Из этого вытекают два правила, которые нужно держать в голове:

1. Нужно значение **после** блока - объявляйте переменную **до** блока (перед циклом, перед `if`).
2. Внутри блока, чтобы **изменить** внешнюю переменную, пишите просто `имя = значение;`, без `let` и `const`. Слово `let` создаёт **новую** переменную, которая **скрывает** внешнюю с тем же именем: это называется **затенением**.

<!-- section: examples -->
## Пример 1. Блок скрывает переменную

```javascript run
const x = 1;
{
  const x = 2;
  console.log("внутри: " + x);
}
console.log("снаружи: " + x);
```
```output
внутри: 2
снаружи: 1
```

Это две разные переменные с одним именем. Внутри блока видна ближайшая, снаружи - внешняя. Внешняя не изменилась.

## Пример 2. let внутри блока не меняет внешнюю

```javascript run
let total = 10;
if (total > 5) {
  let total = 100;
  console.log("в if: " + total);
}
console.log("после if: " + total);

if (total > 5) {
  total = 100;
}
console.log("без let: " + total);
```
```output
в if: 100
после if: 10
без let: 100
```

Первый `if` создаёт новую переменную и ничего не меняет снаружи. Второй `if` просто присваивает значение внешней переменной: она изменилась.

## Пример 3. Переменная вышла из блока

```javascript run
function describe(n) {
  if (n >= 0) {
    const kind = "неотрицательное";
  }
  return kind;
}

try {
  describe(5);
} catch (e) {
  console.log(e.name + ": " + e.message);
}
```
```output
ReferenceError: kind is not defined
```

`kind` существует только между скобками `if`. На строке `return kind;` такого имени уже нет. Исправление - объявить её раньше:

```javascript run
function describe(n) {
  let kind = "отрицательное";
  if (n >= 0) {
    kind = "неотрицательное";
  }
  return kind;
}

console.log(describe(5));
console.log(describe(-5));
```
```output
неотрицательное
отрицательное
```

## Пример 4. Счётчик цикла принадлежит циклу

```javascript run
function firstEven(numbers) {
  let found = -1;
  for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] % 2 === 0) {
      found = i;
      break;
    }
  }
  return found;
}

console.log(firstEven([3, 5, 8, 10]));
console.log(firstEven([1, 3]));
```
```output
2
-1
```

Номер `i` нужен только внутри цикла. Результат поиска нужен после него, поэтому живёт в `found`, объявленной перед циклом. Если бы мы вернули `i` после цикла, получили бы `ReferenceError`.

## Пример 5. Параметр - тоже переменная функции

```javascript run
function addTax(price) {
  const price2 = price * 1.2;
  return price2;
}

function wrong(price) {
  {
    const price = 0;
  }
  return price;
}

console.log(addTax(100));
console.log(wrong(100));
```
```output
120
100
```

Параметр `price` виден во всей функции. Блок `{ }` с собственной `const price` создаёт отдельную переменную и параметр не трогает.

**Попробуйте.** Возьмите пример 2 и уберите `let` в первом `if`. Что изменится в выводе? Сделайте предположение раньше, чем запускать.

## Точные правила

* Блок - всё между `{` и `}`: тело функции, цикла, `if`/`else`, отдельная пара скобок.
* `let` и `const` имеют **блочную** область видимости: имя доступно от объявления до закрывающей скобки блока, включая вложенные блоки.
* Параметры функции и переменные в её теле видны во всей функции.
* Переменная в заголовке цикла (`let i` в `for (let i = ...)`, `const item` в `for (const item of ...)`) принадлежит циклу и после него не существует.
* Вложенный блок может объявить имя, которое уже есть снаружи: внутри блока видна внутренняя переменная (**затенение**). Это допустимо, ошибки не будет, и именно поэтому такие баги незаметны.
* В **одном** блоке объявить одно имя через `let`/`const` дважды нельзя: `SyntaxError: Identifier 'x' has already been declared` (файл не запустится вообще).
* Чтобы изменить внешнюю переменную, нужна команда присваивания без `let`/`const`: `total = total + 1;`. Для этого переменная должна быть объявлена через `let`, а не `const`.
* Обращение к имени, которого нет в доступных областях, даёт `ReferenceError: имя is not defined` во время выполнения.
* Имя нельзя использовать до объявления в том же блоке: `ReferenceError: Cannot access 'v' before initialization`.
* Практическое правило: переменные, которые накапливают результат или запоминают найденное, объявляются **перед** циклом или условием; переменные для одного шага цикла - внутри него.

## Типичные ошибки

**1. Второе `let` внутри цикла.**

```javascript
let count = 0;
for (const n of [2, 4, 5]) {
  let count = 0;
  if (n % 2 === 0) {
    count++;
  }
}
console.log(count);
```

Напечатается `0`, ошибки нет. Внутренняя `count` создаётся заново на каждом круге и исчезает, внешняя не меняется. Уберите `let` у внутренней: `count++` будет менять внешнюю.

**2. Результат объявлен внутри `if`.**

```javascript
function f() {
  if (true) {
    const label = "x";
  }
  return label;
}
f();
```

Node.js: `ReferenceError: label is not defined`. Объявите `let label` перед `if`, а в ветках присваивайте.

**3. Счётчик цикла после цикла.**

```javascript
for (let i = 0; i < 3; i++) {}
console.log(i);
```

Node.js: `ReferenceError: i is not defined`. Нужное после цикла значение сохраните в переменной, объявленной до цикла.

**4. Повторное объявление в одном блоке.**

```javascript
let x = 1;
let x = 2;
```

Node.js: `SyntaxError: Identifier 'x' has already been declared`. Это то же имя в той же области. Если нужно новое значение, пишите `x = 2;`.

**5. Присваивание константе.**

```javascript
const k = 1;
k = 2;
```

Node.js: `TypeError: Assignment to constant variable.` Если значение нужно менять (счётчик, сумма), объявляйте через `let`.

**6. Использование до объявления.**

```javascript
console.log(v);
let v = 1;
```

Node.js: `ReferenceError: Cannot access 'v' before initialization`. Сначала объявите, потом используйте.

**7. Переименовали и забыли об этом.**
Если внутри блока вы пишете `let best = n;` «для понятности», внешний `best` остаётся старым. Вывод программы выглядит правдоподобно (результат - первое значение), и найти такую ошибку трудно. Привычка: в баге с «теряющимся» результатом сначала ищите лишнее `let` или `const` в теле цикла.

<!-- section: summary -->
## Итоги

* Блок `{ }` ограничивает видимость `let` и `const`: после закрывающей скобки имя исчезает.
* Внутреннее объявление с тем же именем **затеняет** внешнюю переменную и не меняет её.
* Чтобы изменить внешнюю переменную из блока, пишите присваивание без `let` и `const`.
* Результат, нужный после цикла или `if`, объявляйте до них.
* `ReferenceError: x is not defined` - имя не видно в этом месте; тихо неверный результат - частый признак затенения.

## Для тех, кто уже программирует

* `let` и `const` блочные, как в C#/Java/Go. В отличие от них, затенение локальной переменной внутри вложенного блока в JavaScript разрешено без предупреждения (в C# это ошибка компиляции), поэтому линтеры включают правило `no-shadow`.
* Старое `var` имеет функциональную область и «поднимается»: `var` в блоке виден во всей функции. В учебных программах используйте только `let` и `const`.
* Имена `let`/`const` «подняты», но недоступны до объявления (временная мёртвая зона): отсюда `Cannot access 'v' before initialization`, а не `is not defined`.
* Замыкание - это функция, запоминающая переменные внешней области видимости. Каждый круг `for (let i ...)` получает собственную `i`, поэтому функции, созданные в цикле, видят разные значения. Подробно - в курсе для программистов.
* `const` запрещает перепривязку имени, а не изменение содержимого: в `const a = []` можно вызвать `a.push(1)`.

## Как движок ищет имя

Это необязательный раздел.

Для каждого блока движок создаёт список объявленных в нём имён. Когда программа обращается к имени, движок ищет его в текущем блоке; если не находит, поднимается к охватывающему блоку, затем к функции, затем к файлу. Первое найденное имя побеждает: так работает затенение (внутреннее найдено раньше внешнего). Если имя не найдено нигде, получается `ReferenceError`.

Отсюда простой приём отладки: для подозрительного имени пройдите от места использования вверх по вложенным скобкам и отметьте каждое объявление. Если их два - вы нашли затенение. Если ни одного в охватывающих скобках - имя вышло из области видимости.
