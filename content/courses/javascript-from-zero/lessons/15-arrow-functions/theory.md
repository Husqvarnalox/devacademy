## Зачем это нужно

Иногда нужно написать функцию, которая выполняет разное действие в зависимости от ситуации: «пройти по всем товарам и что-то с каждым сделать», «посчитать, сколько элементов подходят», «отсортировать по правилу». Что именно делать с каждым товаром, функция не знает заранее. Тогда это действие передают в неё снаружи - в виде другой функции. Чтобы такие небольшие функции записывать коротко, в JavaScript есть стрелочная запись.

## Одна новая идея: функцию можно передать как значение

Функция в JavaScript - такое же значение, как число или строка. Её можно положить в переменную, передать в другую функцию аргументом и вернуть из функции. Ключевое различие:

* `double` - сама функция (как рецепт на бумаге);
* `double(4)` - вызов: функция выполнена с аргументом 4, получился результат (как приготовленное блюдо).

Функция, которую передают другой функции, чтобы та вызвала её сама, называется **колбэком** (от английского callback, «перезвони»: «вот что делать, вызови, когда понадобится»).

**Стрелочная функция** - короткая запись: параметры в скобках, затем стрелка `=>`, затем результат.

```javascript
const double = (n) => n * 2;
```

Если после стрелки идёт одно выражение, его значение возвращается само, без слова `return`. Если нужно несколько команд, после стрелки ставят фигурные скобки, и тогда `return` обязателен.

<!-- section: examples -->
## Пример 1. Стрелка в переменной

```javascript run
const double = (n) => n * 2;
const add = (a, b) => a + b;
console.log(double(4));
console.log(add(2, 3));
console.log(typeof double);
```
```output
8
5
function
```

Разбор:

* `(n) => n * 2` - функция с одним параметром `n`, которая возвращает `n * 2`. Присвоив её переменной `double`, мы получили функцию с именем, которую вызываем как обычно: `double(4)`.
* `(a, b) => a + b` - два параметра, в скобках через запятую.
* `typeof double` даёт `"function"`: функция - особое значение, у которого есть свой тип.

## Пример 2. Стрелка с телом

```javascript run
const describe = (age) => {
  if (age >= 18) {
    return "взрослый";
  }
  return "ребёнок";
};
console.log(describe(20));
console.log(describe(10));
```
```output
взрослый
ребёнок
```

Когда нужны условия и несколько команд, после стрелки открывают фигурные скобки и пишут тело как у обычной функции, с `return`. Точка с запятой после закрывающей скобки нужна, потому что это конец команды `const describe = ...;`.

## Пример 3. Функция как аргумент

```javascript run
function applyTwice(fn, x) {
  return fn(fn(x));
}

const addTen = (n) => n + 10;
console.log(applyTwice(addTen, 1));
console.log(applyTwice((n) => n * 3, 2));
```
```output
21
18
```

Функция `applyTwice` получает в параметре `fn` другую функцию и вызывает её дважды. В первом вызове передана переменная `addTen` (без скобок!): `1 -> 11 -> 21`. Во втором стрелка записана прямо в скобках вызова, без имени: `2 -> 6 -> 18`. Такая безымянная функция удобна, когда она нужна один раз.

## Пример 4. Колбэк, который вызывается на каждом элементе

```javascript run
function forEachItem(items, show) {
  for (const item of items) {
    show(item);
  }
}

forEachItem(["чай", "кофе"], (name) => {
  console.log("В меню: " + name);
});
```
```output
В меню: чай
В меню: кофе
```

`forEachItem` не знает, что делать с элементами: это решает тот, кто её вызывает. Функцию `show` она вызывает один раз на каждый элемент. Это именно то, как работают методы массивов в следующем уроке.

**Попробуйте.** В примере 3 замените вторую стрелку на `(n) => n - 1` и предскажите результат. Затем в примере 4 передайте стрелку, которая печатает название вместе с его длиной: `name + ": " + name.length`.

## Точные правила

* Форма записи: `(параметры) => выражение` или `(параметры) => { команды }`.
* Один параметр можно писать без скобок (`n => n * 2`), но в курсе скобки сохраняются для единообразия. Без параметров скобки обязательны: `() => 42`.
* С выражением после стрелки значение возвращается автоматически. С фигурными скобками нужен `return`; без него результат `undefined`.
* Стрелочная функция - значение; в `const` её кладут, чтобы дать имя, или записывают на месте, как аргумент.
* `имя` без скобок - сама функция, `имя(аргументы)` - вызов. Скобки решают, получите вы функцию или результат её работы.
* Параметр-функция вызывается обычным способом: если параметр называется `fn`, то `fn(значение)`. Это значит, что на месте `fn` могут оказаться разные функции.
* Колбэк не обязан принимать все данные, которые ему передают, и не обязан возвращать значение; что от него ожидается, определяет функция, которая его вызывает.
* Стрелочные функции записывают через `const`, а не `let`: имя функции не должно меняться.
* Стрелку нельзя вызвать раньше, чем выполнена строка с её объявлением: объявления `function` доступны до своей строки, а `const f = () => ...` - нет.

## Типичные ошибки

**1. Скобки при передаче функции.**

```javascript
function applyTwice(fn, x) {
  return fn(fn(x));
}
const double = (n) => n * 2;
console.log(applyTwice(double(), 3));
```

Node.js: `TypeError: fn is not a function`. `double()` вызвала функцию без аргумента и вернула `NaN`; именно `NaN` оказался в `fn`, а его вызвать нельзя. Передавайте функцию без скобок: `applyTwice(double, 3)`.

**2. Фигурные скобки без `return`.**

```javascript
const triple = (n) => {
  n * 3;
};
console.log(triple(2));
```

Напечатается `undefined`. Фигурные скобки открывают тело функции, и значение нужно вернуть явно: `return n * 3;`. Либо уберите скобки: `(n) => n * 3`.

**3. Вызов стрелки до её объявления.**

```javascript
console.log(square(3));
const square = (n) => n * n;
```

Node.js: `ReferenceError: Cannot access 'square' before initialization`. Строка с `const` ещё не выполнена, когда на неё ссылаются. Поставьте объявление выше вызова.

**4. Ждут результат, а получили функцию.**

```javascript
const double = (n) => n * 2;
console.log(double);
```

Напечатается `[Function: double]`, а не число. Забыли вызвать: `double(4)`.

**5. Присваивание вместо стрелки.**
Запись `(n) = n * 2` или `n -> n * 2` из других языков в JavaScript не работает: нужны именно `=>`, без пробела между знаками.

## Итоги

* Функция - значение: её можно сохранить в переменную, передать аргументом и вызвать позже.
* `имя` - сама функция, `имя(аргументы)` - её вызов.
* Стрелочная функция: `(параметры) => выражение` возвращает значение выражения; `(параметры) => { ...; return значение; }` требует `return`.
* Колбэк - функция, которую передают другой функции, чтобы та вызвала её сама.

С колбэками вы готовы к методам массивов, которые делают за вас типовые обходы: [Методы массивов](lesson:javascript.from-zero.array-methods).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Стрелки - лямбды JavaScript. Вне классов и объектов они ведут себя как обычные функции; главное отличие: у стрелки нет собственного `this`, она берёт его из окружения (подробнее - в `javascript-fundamentals`).
* Функции - значения первого класса: можно хранить, передавать, возвращать. `function` и `const f = () => ...` различаются hoisting-ом: объявление `function` поднимается, `const` - нет (временная мёртвая зона).
* Выражение-тело возвращается неявно; чтобы вернуть литерал объекта, его оборачивают в круглые скобки: `() => ({ a: 1 })`. Объекты появятся в одном из следующих уроков.
* Число аргументов не проверяется: колбэку можно передать лишние аргументы, он их проигнорирует (поэтому в `map(parseInt)` бывают сюрпризы).
* Замыкания (стрелка видит переменные окружающего кода) в курсе подробно не разбираются.

<!-- section: deep-dive -->
## Почему функция может быть значением

Это необязательный раздел: для заданий он не нужен.

Когда программа доходит до объявления функции, движок создаёт в памяти объект-функцию: в нём хранится код тела и ссылка на окружение, где функцию создали. Имя `double` - просто переменная, которая указывает на этот объект. Поэтому `const f = double;` не копирует код, а даёт второе имя тому же объекту, а `double(4)` означает «возьми объект, на который указывает `double`, и выполни его код с аргументом 4».

Отсюда два следствия. Во-первых, передать функцию аргументом так же естественно, как передать число: в параметре окажется ссылка на тот же объект. Во-вторых, ссылка на окружение позволяет функции помнить переменные, которые были видны в месте её создания, даже когда окружающий код давно закончился. Это свойство называют замыканием; оно лежит в основе многих приёмов JavaScript и разбирается в следующем курсе.
