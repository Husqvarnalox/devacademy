## Зачем это нужно

Массив нужен, чтобы что-то делать со всеми его элементами сразу: сложить цены в чеке, найти лучшую оценку, посчитать подходящие слова. Перебирать элементы вручную (`prices[0]`, `prices[1]`, ...) можно только при трёх значениях; для десяти или для списка неизвестной длины нужен цикл. Он у вас уже есть, но запись через счётчик громоздка. Для массивов существует более короткая форма.

## Одна новая идея: for...of берёт элементы по очереди

Цикл **`for...of`** («для каждого из») на каждом шаге кладёт в переменную очередной элемент массива и выполняет тело. Запись: `for (const item of items) { ... }`. Читается как «для каждого `item` из `items`». Счётчик заводить не нужно, выход за границу невозможен, а пустой массив просто не вызовет ни одного шага.

Если нужен ещё и **номер** элемента, используют знакомый цикл со счётчиком: `for (let i = 0; i < items.length; i++)`. Тогда элемент - `items[i]`. Выбор простой: нужны только значения - `for...of`; нужны позиции - счётчик.

Три типичные задачи обхода решаются одним приёмом - **накопителем**. Это переменная до цикла, в которую цикл на каждом шаге что-то добавляет: сумма, количество или лучшее значение.

<!-- section: examples -->
## Пример 1. Сумма

```javascript run
const prices = [120, 80, 45];
let total = 0;
for (const price of prices) {
  total = total + price;
}
console.log(total);
```
```output
245
```

Разбор:

* `let total = 0;` - накопитель. Он объявлен через `let`, потому что значение меняется, и начинается с 0: ноль не влияет на сумму.
* `for (const price of prices)` - на первом шаге `price` равно 120, на втором 80, на третьем 45. Слово `const` здесь допустимо: на каждом шаге создаётся новая переменная.
* `total = total + price;` - прибавляем очередную цену. После цикла в `total` лежит 245.

## Пример 2. Подсчёт подходящих элементов

```javascript run
const words = ["кот", "собака", "ёж", "лиса"];
let count = 0;
for (const word of words) {
  if (word.length > 3) {
    count++;
  }
}
console.log(count);
```
```output
2
```

Здесь накопитель считает не сумму, а количество: растёт на единицу только тогда, когда слово подходит. Условие `word.length > 3` использует свойство `length`, знакомое по строкам.

## Пример 3. Наибольшее значение

```javascript run
const temperatures = [-4, -1, -7];
let warmest = temperatures[0];
for (const t of temperatures) {
  if (t > warmest) {
    warmest = t;
  }
}
console.log(warmest);
```
```output
-1
```

Накопитель начинается с первого элемента, а не с нуля. Если бы мы начали с `0`, ни одно из отрицательных чисел не оказалось бы больше, и программа выдала бы 0, которого в массиве нет. Правило: «лучшее на данный момент» нужно инициализировать реальным элементом массива.

## Пример 4. Цикл с индексом: где стоит элемент

```javascript run
const names = ["Анна", "Борис", "Вера"];
for (let i = 0; i < names.length; i++) {
  console.log(i + 1 + ". " + names[i]);
}
```
```output
1. Анна
2. Борис
3. Вера
```

Номер строки нужен только здесь, поэтому цикл идёт по индексам от 0 до `names.length - 1`. Условие `i < names.length` (строго меньше) останавливает цикл до выхода за границу. Выражение `i + 1 + ". "` складывает числа слева направо: сначала `i + 1` как числа, затем склейка с текстом.

**Попробуйте.** В примере 3 замените `let warmest = temperatures[0];` на `let warmest = 0;` и объясните, почему результат изменился. Затем в примере 2 поменяйте условие на `word.length >= 3`.

## Точные правила

* `for (const item of array) { тело }` выполняет тело по одному разу на каждый элемент в порядке индексов. Для пустого массива тело не выполняется.
* Переменная цикла живёт только внутри тела. В `for...of` её удобно объявлять через `const`: на каждом шаге это новая переменная. Присвоить ей что-то внутри тела нельзя.
* `for...of` не изменяет массив и не сообщает индекс. Чтобы заменить элементы (`items[i] = ...`), нужен цикл со счётчиком.
* В цикле со счётчиком условие `i < items.length` проходит все индексы с 0 до `length - 1`. Условие `i <= items.length` выходит за границу: `items[items.length]` равно `undefined`.
* `break` и `continue` работают в `for...of` так же, как в других циклах; `return` внутри функции завершает и цикл.
* Накопитель объявляют **до** цикла: объявленная внутри тела переменная создаётся заново на каждом шаге.
* Начальное значение накопителя зависит от задачи: сумма - 0, количество - 0, максимум или минимум - первый элемент массива (после проверки, что массив не пуст).
* `for...of` работает не только с массивами, но и со строками: `for (const letter of "кот")` обходит буквы по одной.

## Типичные ошибки

**1. Выход за границу в цикле со счётчиком.**

```javascript
const numbers = [1, 2];
let total = 0;
for (let i = 0; i <= numbers.length; i++) {
  total = total + numbers[i];
}
console.log(total);
```

Напечатается `NaN`: на последнем шаге `numbers[2]` равно `undefined`, а `3 + undefined` не число. Условие должно быть `i < numbers.length`.

**2. Присваивание переменной цикла.**

```javascript
const prices = [10, 20];
for (const price of prices) {
  price = price * 2;
}
```

Node.js: `TypeError: Assignment to constant variable.` К тому же это не изменило бы массив: переменная цикла - копия значения. Для замены элементов используйте `prices[i] = prices[i] * 2` в цикле со счётчиком.

**3. `for...of` по числу.**

```javascript
for (const digit of 12345) {
  console.log(digit);
}
```

Node.js: `TypeError: 12345 is not iterable`. Цикл `for...of` перебирает то, что состоит из частей: массив, строку. Число - одно значение.

**4. Накопитель внутри цикла.**

```javascript
for (const price of prices) {
  let total = 0;
  total = total + price;
}
console.log(total);
```

Переменная `total` создаётся заново на каждом шаге и не видна после цикла. Результат: `ReferenceError: total is not defined`. Объявите накопитель перед циклом.

**5. Максимум с нулевым началом.**
`let best = 0;` не годится для массива отрицательных чисел: результат останется 0. Начинайте с `numbers[0]`.

**6. Не обработали пустой массив.**
`numbers[0]` для `[]` даёт `undefined`, и функция «максимум» вернёт его без предупреждения. Решите заранее, что возвращать для пустого массива, и проверьте `numbers.length === 0`.

## Итоги

* `for (const item of items) { ... }` перебирает элементы по очереди; для пустого массива тело не выполняется.
* Когда нужен номер, используют `for (let i = 0; i < items.length; i++)` и обращаются к `items[i]`.
* Сумму, количество и максимум считают накопителем, который объявлен перед циклом. Максимум начинают с первого элемента.
* Краевые случаи - пустой массив и отрицательные числа - нужно продумывать заранее.

Функции, которые мы пишем, пока всегда имеют имя и слово `function`. В следующем уроке функции станут значениями, которые можно передать в другую функцию: [Стрелочные функции и колбэки](lesson:javascript.from-zero.arrow-functions).

## Для тех, кто уже программирует

* `for (const x of arr)` - аналог `for x in arr` из Python и `foreach` из C#/Java. Не путайте с `for...in`: он перебирает имена свойств (для массива - строки `"0"`, `"1"`), и в курсе не используется.
* `for...of` работает с любым итерируемым объектом: массивами, строками, `Map`, `Set`, генераторами. Для обычного объекта (`{}`) не работает: он не итерируемый.
* `const` в заголовке допустим: на каждой итерации создаётся новая привязка. Изменение элемента массива через переменную цикла возможно только для объектов (по ссылке), для чисел и строк переменная цикла - копия.
* Индекса в `for...of` нет; для пары (индекс, значение) в языке есть `entries()`, в курсе его нет - используйте обычный `for`.
* Изменение длины массива в ходе обхода (`push` внутри цикла) допустимо, но делает цикл трудно предсказуемым.

## Что скрывается за for...of

Это необязательный раздел: для заданий он не нужен.

Цикл `for...of` работает не с самим массивом, а с «итератором» - вспомогательным объектом, который умеет отвечать на вопрос «какой элемент следующий и закончились ли они». Цикл по очереди задаёт этот вопрос и выполняет тело, пока ответ «не закончились». Любой объект, умеющий создавать такой итератор, можно обойти циклом `for...of`, поэтому с одинаковой записью работают массивы, строки и другие коллекции.

Поэтому в `for...of` нет индекса: итератор отдаёт только значения. Когда индекс нужен, проще вернуться к счётчику, чем строить пары значений и номеров. А для чтения сложной структуры, например списка заказов, где в каждом заказе свой список товаров, внутри `for...of` можно ставить ещё один `for...of`, как вы делали с вложенными циклами.
