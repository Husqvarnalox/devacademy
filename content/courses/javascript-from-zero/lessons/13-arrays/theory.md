## Зачем это нужно

До сих пор в переменной лежало одно значение: одна цена, одно имя. Но в жизни данные приходят списками: цены всех товаров в чеке, оценки за четверть, названия задач на день. Заводить переменную `price1`, `price2`, `price3` для каждого значения неудобно: неизвестно заранее, сколько их будет, и по ним нельзя пройтись циклом. Для списков в JavaScript есть **массив**.

## Одна новая идея: массив - пронумерованный список значений

**Массив** - это одно значение, внутри которого лежит упорядоченный набор других значений. Каждое значение в массиве называется **элементом**. Массив записывают в квадратных скобках, элементы разделяют запятыми: `[120, 80, 45]`. Такая запись называется **литералом массива**, как `"текст"` - литерал строки.

Каждый элемент имеет номер - **индекс**. Нумерация начинается с **нуля**: первый элемент имеет индекс 0, второй - 1, третий - 2. Чтобы взять элемент, после имени массива пишут индекс в квадратных скобках: `prices[0]`. Число элементов хранится в свойстве `length` (длина), как у строки.

Чтобы добавить элемент в конец, используют команду `push`: `prices.push(60)`. Это ещё не функция из прошлых уроков, а **метод** - команда, которая «принадлежит» значению и записывается через точку после него. Другие методы вы встретите в следующих уроках.

<!-- section: examples -->
## Пример 1. Литерал, индекс и длина

```javascript run
const prices = [120, 80, 45];
console.log(prices);
console.log(prices[0]);
console.log(prices[2]);
console.log(prices.length);
```
```output
[ 120, 80, 45 ]
120
45
3
```

Разбор по строкам:

* `const prices = [120, 80, 45];` - создан массив из трёх чисел, и имя `prices` указывает на него.
* `console.log(prices)` печатает весь массив целиком: в квадратных скобках, через запятую, с пробелами по краям. Так `console.log` показывает массивы всегда.
* `prices[0]` - первый элемент (120), `prices[2]` - третий и последний (45). Индекс последнего на единицу меньше длины.
* `prices.length` - сколько всего элементов.

## Пример 2. Добавить в конец и заменить

```javascript run
const cart = ["хлеб", "молоко"];
cart.push("сыр");
cart[0] = "батон";
console.log(cart);
console.log(cart.length);
```
```output
[ 'батон', 'молоко', 'сыр' ]
3
```

`cart.push("сыр")` добавляет новый элемент в конец, и длина растёт с 2 до 3. Присваивание `cart[0] = "батон"` кладёт новое значение на место элемента с индексом 0. Обратите внимание: массив объявлен через `const`, и всё равно меняется. `const` запрещает только присвоить имени **другой** массив (`cart = []` дало бы ошибку); содержимое самого массива менять можно. Строки в массиве `console.log` печатает в одинарных кавычках: так он отличает текст от чисел.

## Пример 3. Последний элемент и выход за границу

```javascript run
const colors = ["красный", "зелёный"];
console.log(colors[colors.length - 1]);
console.log(colors[2]);
const empty = [];
console.log(empty.length);
console.log(empty[0]);
```
```output
зелёный
undefined
0
undefined
```

Последний элемент всегда имеет индекс `length - 1`: так не нужно знать длину заранее. Элемента с индексом 2 в массиве из двух элементов нет, и вместо ошибки получается `undefined` - уже знакомое «значения нет». Пустой массив `[]` допустим: его длина 0, а любой индекс даёт `undefined`.

## Пример 4. Заполнение массива циклом

```javascript run
const squares = [];
for (let i = 1; i <= 5; i++) {
  squares.push(i * i);
}
console.log(squares);
```
```output
[ 1, 4, 9, 16, 25 ]
```

Массив начинается пустым, а цикл на каждом шаге добавляет в конец очередной квадрат. Это самый частый способ собрать результат неизвестной заранее длины.

**Попробуйте.** В примере 1 напечатайте `prices[3]` и `prices[-1]` и предскажите вывод до запуска. Затем в примере 4 замените `i * i` на `i * 10`.

## Точные правила

* Литерал: `[элемент, элемент, ...]`. Элементы могут быть любых типов, в том числе разных в одном массиве; на практике в одном массиве держат значения одного смысла.
* Индекс - целое число от 0 до `length - 1`. `array[index]` читает элемент, `array[index] = value` заменяет его.
* Обращение к индексу, которого нет (больше `length - 1`, отрицательному, дробному), не вызывает ошибку и даёт `undefined`.
* `length` - количество элементов. У пустого массива `[]` оно равно 0. `length` не требует скобок: это не команда, а значение.
* `array.push(value)` добавляет элемент в конец и увеличивает `length` на единицу. Команда меняет сам массив, а не создаёт новый.
* Присваивание `array[array.length] = value` тоже добавляет в конец, но `push` читается яснее.
* `const` закрепляет за именем один и тот же массив; менять его содержимое можно. Присвоить имени другой массив нельзя.
* Печать: `console.log(array)` показывает весь массив в виде `[ 1, 2, 3 ]`. Строки в нём показаны в одинарных кавычках.
* Числа индексов тоже считаются: `array[i + 1]` - следующий элемент, `array[i - 1]` - предыдущий; на краях это может дать `undefined`.

## Типичные ошибки

**1. Считают с единицы.**

```javascript
const days = ["пн", "вт", "ср"];
console.log(days[3]);
```

Напечатается `undefined`: элементы имеют индексы 0, 1 и 2. Если ждали «ср», нужен `days[2]`. Правило проверки: последний индекс равен `days.length - 1`.

**2. Обращение к `length` с ошибкой в названии.**

```javascript
const items = [1, 2, 3];
console.log(items.lenght);
```

Ошибки нет, печатается `undefined`: у массива просто нет свойства `lenght`. Если вместо числа вы видите `undefined`, проверьте написание имени.

**3. Присваивание нового массива в `const`.**

```javascript
const list = [1, 2];
list = [3, 4];
```

Node.js: `TypeError: Assignment to constant variable.` Либо объявите `let`, либо измените существующий массив: `list.push(3)`.

**4. `push` у значения, которое не массив.**

```javascript
let log;
log.push("запись");
```

Node.js: `TypeError: Cannot read properties of undefined (reading 'push')`. В переменной `log` лежит `undefined`, потому что её не заполнили. Объявите её как пустой массив: `let log = [];`.

**5. Скобки вместо точки и скобок.**

```javascript
const items = [];
items(0);
```

Node.js: `TypeError: items is not a function`. Круглые скобки означают вызов функции. Для индекса нужны квадратные: `items[0]`.

**6. Ждут, что `-1` даст последний элемент.**
В некоторых языках отрицательный индекс считается с конца. В JavaScript `items[-1]` - это `undefined`. Используйте `items[items.length - 1]`.

## Итоги

* Массив - упорядоченный список значений: `[1, 2, 3]`. Индексы начинаются с нуля, последний равен `length - 1`.
* `array[i]` читает и заменяет элемент, `array.length` - длина, `array.push(x)` добавляет в конец.
* Индекс за границей даёт `undefined`, а не ошибку. Пустой массив `[]` - обычное значение.
* Массив в `const` можно менять, но нельзя заменить целиком.

Вручную обращаться к каждому индексу неудобно, когда элементов много. Как пройти по всему массиву, показывает следующий урок: [Обход массива](lesson:javascript.from-zero.iterating-arrays).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Массив JavaScript - динамический список с произвольными типами элементов (аналог `list` в Python, `ArrayList` в Java, `List<object>` в C#). Размер не фиксирован: `push` увеличивает его сам.
* Выход за границу не бросает исключение, а возвращает `undefined`; запись за границей (`a[10] = 1`) создаёт «дыры» в массиве. Отрицательные индексы не считаются с конца, в отличие от Python; для этого есть `at(-1)` (метод `at` в курсе не используется).
* `const` защищает привязку, а не содержимое, как `final` в Java.
* Массив - объект: сравнение `===` сравнивает ссылки, а не содержимое; `[1] === [1]` даёт `false`.
* `console.log` форматирует массивы в стиле `util.inspect`: строки в одинарных кавычках, длинные массивы переносятся на несколько строк.

## Что такое массив внутри

Это необязательный раздел: для заданий он не нужен.

Движок JavaScript хранит массивы с числовыми элементами в сплошных областях памяти, как в языках с массивами фиксированного размера: так чтение `prices[2]` выполняется за один шаг, без поиска. Когда `push` не помещается в выделенную область, движок выделяет область побольше и переносит элементы туда. Для программиста это незаметно, но объясняет, почему добавление в конец дёшево.

С точки зрения языка массив - особый вид объекта, а индексы - его свойства с именами `"0"`, `"1"`, `"2"`. Поэтому запись `items[10] = 5` в массиве из трёх элементов допустима: `length` станет 11, а в промежутке окажутся пустые места. Такое использование считается плохой практикой, и в курсе мы всегда добавляем элементы командой `push`.
