## Зачем это нужно

Много задач сводится к повторению: пересчитать каждую покупку, вывести числа от 1 до 100, делить сумму, пока она не станет достаточно маленькой. Писать одну и ту же команду сто раз нельзя, поэтому для повторения есть **циклы**. Первый из них - `while` (англ. «пока»).

## Одна новая идея: пока условие истинно, тело повторяется

```javascript
while (условие) {
  // тело цикла
}
```

Порядок работы такой:

1. Проверяется условие.
2. Если оно истинно, выполняется **тело** цикла (команды в `{ }`), затем снова шаг 1.
3. Если ложно, цикл заканчивается, и выполнение идёт к команде после него.

Одно выполнение тела называется **итерацией** (шагом). Важно: условие проверяется **до** каждой итерации, поэтому при ложном условии с самого начала тело не выполнится ни разу.

Чтобы цикл когда-нибудь закончился, что-то внутри тела должно менять переменную из условия. Обычно это **счётчик** - переменная, которая считает шаги: `let i = 1;` до цикла и `i = i + 1;` внутри.

<!-- section: examples -->
## Пример 1. Считаем до трёх

```javascript run
let i = 1;
while (i <= 3) {
  console.log("Шаг", i);
  i = i + 1;
}
console.log("Готово");
```
```output
Шаг 1
Шаг 2
Шаг 3
Готово
```

Разбор:

* `let i = 1;` - счётчик создан до цикла и равен 1.
* `i <= 3` - условие. Пока оно истинно, тело повторяется.
* `console.log("Шаг", i)` печатает текущее значение.
* `i = i + 1;` - увеличение счётчика. Без этой строки `i` всегда был бы 1, и цикл не закончился бы.
* Когда `i` стало 4, условие ложно, цикл закончился, выполнилась команда «Готово».

## Пример 2. Накопление суммы

```javascript run
let sum = 0;
let i = 1;
while (i <= 5) {
  sum = sum + i;
  i = i + 1;
}
console.log(sum);
```
```output
15
```

Переменная `sum` называется **накопителем**: она начинает с нуля и на каждом шаге получает новое слагаемое. Значения по шагам: 0, 1, 3, 6, 10, 15. Перед циклом накопитель нужно обнулить, иначе результат будет неверным.

## Пример 3. Число шагов неизвестно заранее

```javascript run
let balance = 1000;
let years = 0;
while (balance < 2000) {
  balance = balance * 1.5;
  years = years + 1;
}
console.log(years, balance);
```
```output
2 2250
```

Здесь мы не знаем заранее, сколько шагов понадобится: вклад растёт на 50% в год, пока не достигнет 2000. Цикл `while` подходит как раз для таких задач: условие задаёт цель, а счётчик `years` считает сколько шагов нужно. Через год баланс 1500, через два - 2250.

## Пример 4. Цикл внутри функции

```javascript run
function countdown(from) {
  let result = "";
  let n = from;
  while (n > 0) {
    result = result + n + " ";
    n = n - 1;
  }
  return result + "старт";
}

console.log(countdown(3));
console.log(countdown(0));
```
```output
3 2 1 старт
старт
```

Цикл можно использовать внутри функции и вернуть накопленный результат. Для `countdown(0)` условие `0 > 0` ложно сразу, тело не выполняется ни разу, и функция возвращает только «старт». Это важный край: ноль повторений - допустимое число повторений.

**Попробуйте.** В примере 1 замените условие на `i < 3` и предскажите вывод. Затем верните `<=` и запишите, чем отличаются «до 3 не включая» и «до 3 включая».

## Точные правила

* Форма: `while (условие) { тело }`. Условие даёт `true` или `false`, как у `if`.
* Условие вычисляется перед каждым выполнением тела. Тело может не выполниться ни разу.
* Цикл заканчивается, когда условие становится ложным. Если оно никогда не становится ложным, цикл **бесконечный**: программа не завершается сама, и приложение остановит её по тайм-ауту.
* Типичная схема: подготовка переменных → `while` с условием → внутри действие и изменение счётчика → после цикла `return` или вывод результата.
* Переменные, которые меняются внутри цикла, объявляют через `let`, а не `const`.
* Переменные, объявленные внутри тела цикла, видны только в нём; результат цикла записывают в переменную, объявленную до цикла.
* Сокращения из урока про переменные: `i = i + 1` можно писать `i++` или `i += 1`; `sum = sum + i` - как `sum += i`.
* Знак условия определяет, входит ли граница: `i <= n` включает `n`, `i < n` - нет. Ошибка на единицу (off-by-one) - самая частая в циклах.
* Результат цикла по числу шагов зависит от начального значения счётчика: проверьте, с чего он начинается (0 или 1).

## Типичные ошибки

**1. Забыли изменить счётчик: бесконечный цикл.**

```javascript
let n = 5;
while (n > 0) {
  console.log(n);
}
```

Печатает `5` бесконечно: `n` не меняется. Нужно добавить `n = n - 1;` в тело. Если программа «зависла» и печатает без остановки, сначала посмотрите на условие и на то, что меняется внутри.

**2. Ошибка на единицу.**

```javascript
let i = 1;
let sum = 0;
while (i < 5) {
  sum = sum + i;
  i = i + 1;
}
```

Сумма чисел 1-5 должна быть 15, а получилась 10: условие `i < 5` не включает 5. Для чисел «от 1 до n включительно» нужно `i <= n`.

**3. Не обнулили накопитель.**

Если `let sum;` без значения или `let sum = 1;` вместо `0`, результат окажется неверным: в первом случае `NaN` (`undefined + число`), во втором - на единицу больше. Начальное значение накопителя для суммы - 0.

**4. Точка с запятой после условия.**

```javascript
let i = 0;
while (i < 3);
{
  i = i + 1;
}
```

Пустая команда `;` стала телом цикла, а блок ниже выполняется отдельно. Цикл бесконечный. Не ставьте `;` сразу после `)` условия.

**5. Счётчик через `const`.**

```javascript
const i = 0;
while (i < 3) {
  i++;
}
```

Node.js: `TypeError: Assignment to constant variable.` Меняющуюся переменную объявляют через `let`.

**6. Результат цикла вне цикла.**

```javascript
let i = 0;
while (i < 3) {
  let step = i * 2;
  i++;
}
console.log(step);
```

Node.js: `ReferenceError: step is not defined`. Переменная `step` существует только внутри тела. Объявите её до цикла и обновляйте внутри.

**7. Условие никогда не станет ложным из-за направления.**

`while (n > 0)` с `n = n + 1` внутри - счётчик растёт, а условие требует, чтобы он стал не больше нуля. Проверьте, что изменение приближает условие к ложному.

## Итоги

* `while (условие) { тело }` повторяет тело, пока условие истинно; условие проверяется перед каждой итерацией.
* Внутри тела нужно менять переменную из условия, иначе цикл бесконечный.
* Схема: подготовить переменные, повторять в цикле, вернуть результат; накопитель начинается с нейтрального значения (0 для суммы).
* Границы проверяйте отдельно: `<` и `<=` дают разное число шагов; ноль повторений допустим.

Когда число повторений известно заранее, запись счётчика удобнее собрать в одну строку: [Цикл for](lesson:javascript.from-zero.for-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Синтаксис `while (cond) { ... }` как в C/Java/C#; в Go аналог - `for cond { ... }`, в Python - `while cond:`. Скобки вокруг условия обязательны.
* Условие приводится к `boolean` по правилам truthy/falsy (`while (n)` работает), но в курсе пишутся явные сравнения.
* `do...while` в курсе не рассматривается; `break` и `continue` разбираются в уроке про управление циклом.
* Переменные `let` в теле цикла блочные; на каждой итерации создаются заново.
* Бесконечный цикл блокирует единственный поток Node.js целиком, включая таймеры и ввод-вывод.

## Почему бесконечный цикл «вешает» программу

Это необязательный раздел: для заданий он не нужен.

Node.js выполняет JavaScript в одном потоке: пока одна команда не закончилась, следующая не начнётся. Цикл `while`, условие которого всегда истинно, не отдаёт управление никому, пока вы его не остановите. На компьютере это выглядит как процесс, который занимает процессор на 100% и ничего не делает полезного. Поэтому система запуска упражнений ставит ограничение по времени и принудительно завершает такую программу.

Для процессора цикл - это условный переход назад: проверить условие, выполнить тело, вернуться к проверке. Если условие не меняется, переход выполняется миллиарды раз в секунду. Это не «сложная» ситуация, а прямое следствие определения: цикл повторяется, пока условие истинно, и компьютер не умеет понимать, что условие уже никогда не изменится. Эту ответственность языки оставляют программисту.
