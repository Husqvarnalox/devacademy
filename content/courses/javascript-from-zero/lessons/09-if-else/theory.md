## Зачем это нужно

До сих пор программа выполняла все команды подряд, всегда одинаково. Реальные задачи требуют выбора: если на счёте хватает денег - списать, иначе - показать отказ; если сумма большая - применить скидку; если пользователь младше 7 лет - билет бесплатный. Для выбора служит **условный оператор** `if` (англ. «если»).

## Одна новая идея: блок выполняется, только если условие истинно

```javascript
if (условие) {
  // выполняется, если условие истинно
} else {
  // выполняется, если условие ложно
}
```

**Условие** - выражение, которое даёт `true` или `false` (обычно сравнение, возможно составное). Если оно истинно, выполняется блок после `if`. Если ложно - блок после `else` («иначе»). Ветка `else` необязательна.

Когда вариантов больше двух, между ними ставят `else if` - следующее условие, которое проверяется, только если предыдущие оказались ложными. **Блок** - команды между фигурными скобками `{ }`.

<!-- section: examples -->
## Пример 1. if без else

```javascript run
const temperature = -5;
if (temperature < 0) {
  console.log("Мороз");
}
console.log("Конец");
```
```output
Мороз
Конец
```

Условие `-5 < 0` истинно, блок выполняется. Команда после закрывающей скобки выполняется в любом случае. При `temperature = 5` вывод был бы только «Конец».

## Пример 2. if и else

```javascript run
function parity(n) {
  if (n % 2 === 0) {
    return "чётное";
  } else {
    return "нечётное";
  }
}

console.log(parity(7));
console.log(parity(10));
```
```output
нечётное
чётное
```

Выполняется ровно одна из двух веток. Условие `n % 2 === 0` читается так: «остаток от деления на 2 равен нулю».

## Пример 3. Цепочка else if

```javascript run
function discount(total) {
  if (total >= 5000) {
    return 10;
  } else if (total >= 1000) {
    return 5;
  } else {
    return 0;
  }
}

console.log(discount(7000));
console.log(discount(1500));
console.log(discount(300));
```
```output
10
5
0
```

Условия проверяются **сверху вниз**, выполняется первая ветка с истинным условием, остальные пропускаются. Для суммы 7000 истинны оба первых условия, но срабатывает только первое. Именно поэтому порядок веток важен: более «узкое» условие (`>= 5000`) ставят выше более «широкого» (`>= 1000`).

## Пример 4. Составное условие

```javascript run
function canEnter(age, hasTicket) {
  if (age >= 18 && hasTicket) {
    return "проходите";
  }
  return "нельзя";
}

console.log(canEnter(20, true));
console.log(canEnter(20, false));
console.log(canEnter(17, true));
```
```output
проходите
нельзя
нельзя
```

Условие можно составить из сравнений операторами `&&`, `||`, `!` (прошлый урок). Здесь у `if` нет `else`: если условие ложно, выполнение просто идёт дальше, к `return "нельзя"`. Такой приём называют **ранним возвратом**: частный случай обрабатывают сразу, а общий оставляют ниже.

**Попробуйте.** Поменяйте местами первые две ветки в примере 3 и предскажите результат `discount(7000)`. Запустите и проверьте.

## Точные правила

* Условие записывают в круглых скобках после `if`. Тело - в фигурных скобках `{ }`.
* `else` стоит после закрывающей скобки блока `if`: `} else {`. `else if (условие) { ... }` - это `else`, внутри которого новый `if`.
* Проверка идёт сверху вниз и останавливается на первой истинной ветке. Если истинных нет и есть `else`, выполняется он; если нет `else`, ничего.
* Ветки в цепочке исключают друг друга: выполнится максимум одна. Два отдельных `if` подряд - независимые проверки, выполниться могут оба.
* В функции `return` внутри ветки завершает функцию сразу, поэтому `else` после `return` по смыслу не нужен: `if (a) { return 1; } return 2;` делает то же, что и вариант с `else`. В курсе используются оба стиля.
* Условие должно давать `true` или `false`. В JavaScript в условии допустимы и другие значения (число 0 и пустая строка считаются «ложными»), но на этом этапе используйте только сравнения и логические операторы.
* Граница включается или нет зависит от знака: `>=` включает, `>` не включает. Для диапазонов проверяйте именно граничные числа.
* Фигурные скобки у блока из одной команды можно опустить, но в курсе они пишутся всегда.

## Типичные ошибки

**1. Нет скобок вокруг условия.**

```javascript
if x > 5 {
  console.log("много");
}
```

Node.js: `SyntaxError: Unexpected identifier 'x'`. После `if` обязательны круглые скобки: `if (x > 5) {`.

**2. Присваивание вместо сравнения.**

```javascript
const x = 3;
if (x = 5) {
  console.log("пять");
}
```

Node.js: `TypeError: Assignment to constant variable.` Один знак `=` присваивает. Если бы `x` была `let`, ошибки не было бы, условие всегда оказалось бы истинным, а значение `x` изменилось бы. Для сравнения нужно `x === 5`.

**3. Неверный порядок веток.**

```javascript
if (score >= 50) {
  return "удовлетворительно";
} else if (score >= 90) {
  return "отлично";
}
```

Для 95 вернётся «удовлетворительно»: первое условие истинно, до второго дело не дойдёт. Ставьте более строгое условие выше.

**4. Лишняя точка с запятой после условия.**

```javascript
const x = 3;
if (x > 5);
{
  console.log("всегда");
}
```

Печатается «всегда», хотя `3 > 5` ложно: `;` сделала пустым тело `if`, а блок ниже стал обычным блоком. Не ставьте `;` после закрывающей скобки условия.

**5. `else` без `if` или пустое `else if`.**

```javascript
else {
  console.log("иначе");
}
```

Node.js: `SyntaxError: Unexpected token 'else'`. `else` всегда относится к предыдущему блоку `if`. У `else if` обязательно должно быть условие в скобках.

**6. Забыли `return` в одной из веток.**

Если в какой-то ветке нет `return`, функция вернёт `undefined`. Проверьте, что каждая ветка либо возвращает значение, либо за блоком есть общий `return`.

**7. Ошибка на границе.**

`age < 18` и `age <= 18` отличаются ровно на человеке, которому 18. Выписывайте границы и проверяйте обе стороны каждой: 17 и 18, 49 и 50.

<!-- section: summary -->
## Итоги

* `if (условие) { ... }` выполняет блок, только если условие истинно; `else` - в противном случае; `else if` добавляет ещё одну проверку.
* Проверка идёт сверху вниз, срабатывает первая истинная ветка, поэтому порядок веток важен.
* Условие составляют из сравнений и `&&`, `||`, `!`; границы диапазонов нужно проверять отдельно.
* Внутри функции `return` в ветке сразу завершает функцию.

Условие позволяет выбрать путь; повторять действие много раз позволяет цикл: [Цикл while](lesson:javascript.from-zero.while-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Синтаксис как в C/Java/C#: скобки вокруг условия обязательны, `else if` - две отдельные лексемы (не `elif`, не `elseif`). Фигурные скобки необязательны для одной команды, но в курсе пишутся всегда.
* В условии допустимо любое значение: оно приводится к `boolean` по правилам «truthy/falsy» (`0`, `""`, `null`, `undefined`, `NaN` - ложные). Курс на этом этапе использует только настоящие логические значения; подробности - в `javascript-fundamentals`.
* `if (x = 5)` синтаксически допустимо (присваивание как выражение); линтеры его запрещают.
* `switch` и тернарный оператор `?:` в этом уроке не рассматриваются.
* Область видимости блочная: переменные `let`/`const`, объявленные внутри `{ }`, снаружи не видны.
* Пустая инструкция `;` после условия - ловушка, как в C.

## Как выполняется цепочка условий

Это необязательный раздел: для заданий он не нужен.

Для Node.js конструкция `if (A) { X } else if (B) { Y } else { Z }` - это вложенная запись: `if (A) { X } else { if (B) { Y } else { Z } }`. Слово `else` просто принимает следующий `if` как свою единственную команду, поэтому отдельного ключевого слова «elif» языку не нужно. Из этого следует всё поведение, о котором говорилось: условие `B` вычисляется только если `A` ложно, а ветка `Z` выбирается, только когда ложны и `A`, и `B`.

Процессор при этом выполняет «условный переход»: проверяет результат сравнения и либо продолжает выполнение подряд, либо перескакивает на другое место программы. Любая конструкция выбора в любом языке - в конечном счёте такой переход. Именно поэтому порядок проверок влияет на результат, а граничные значения - любимое место ошибок: переход срабатывает по строгому правилу, а не «примерно».
