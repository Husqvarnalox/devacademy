## Зачем это нужно

В прошлом уроке значения записывались прямо в команды. Но программе часто нужно запомнить значение и использовать его позже: цену товара, имя пользователя, число попыток. Для этого значению дают имя, и оно становится **переменной**.

## Одна новая идея: переменная - это имя, под которым хранится значение

**Переменная** - именованное место в памяти, в котором лежит значение. Чтобы создать её, используют слово `let` или `const` - это называется **объявлением**:

```javascript
let age = 25;
const name = "Анна";
```

Знак `=` здесь - **присваивание**: «положить значение справа в переменную слева». Это не равенство из математики. Читать запись нужно так: «в `age` положить 25».

Слова `let` и `const` отличаются одним:

* `let` (англ. «пусть») - значение потом можно **заменить**.
* `const` (от constant, «константа») - значение задано один раз и **не меняется**.

Правило выбора простое: по умолчанию пишите `const`, а `let` берите, когда значение действительно должно меняться (счётчик, баланс).

<!-- section: examples -->
## Пример 1. Объявление и использование

```javascript run
const shop = "Булочная";
const price = 45;
console.log(shop);
console.log(price);
console.log(shop, price);
```
```output
Булочная
45
Булочная 45
```

Разбор:

* `const shop = "Булочная";` - создана переменная `shop` со значением-строкой.
* `const price = 45;` - переменная `price` со значением-числом.
* `console.log(shop)` - имя без кавычек: печатается значение, лежащее в переменной.
* `console.log(shop, price)` - несколько переменных через запятую, как и значения в первом уроке.

## Пример 2. Замена значения у let

```javascript run
let balance = 1000;
console.log("Было:", balance);
balance = 700;
console.log("Стало:", balance);
```
```output
Было: 1000
Стало: 700
```

Слово `let` пишется один раз - при объявлении. Дальше значение меняют присваиванием `balance = 700;` без `let`. Старое значение 1000 пропало: в переменной всегда ровно одно значение.

## Пример 3. Новое значение на основе старого

```javascript run
let count = 1;
count = count + 1;
count = count + 1;
console.log(count);
```
```output
3
```

Как выполняется `count = count + 1;`: сначала вычисляется правая часть - берётся текущее значение `count` (1) и прибавляется 1 (знак `+` между числами складывает их, подробности в следующем уроке). Потом результат 2 записывается обратно в `count`. После второй такой команды в `count` лежит 3.

Для таких случаев есть сокращения: `count += 1;` делает то же, что `count = count + 1;`, а `count++;` увеличивает на 1.

```javascript run
let steps = 10;
steps += 5;
steps++;
console.log(steps);
```
```output
16
```

**Попробуйте.** Замените `let` на `const` в примере 2 и запустите. Прочитайте сообщение (оно разобрано в разделе об ошибках), затем верните `let`.

## Точные правила

* Объявление: `let имя = значение;` или `const имя = значение;`. Значение можно не задавать у `let` (`let x;`), тогда в переменной лежит особое значение `undefined`, «значения нет». Для `const` значение обязательно.
* **Имя** может содержать буквы, цифры, знак подчёркивания `_` и знак доллара `$`. Начинаться оно не может с цифры. Пробелов внутри нет.
* Регистр важен: `count` и `Count` - разные переменные.
* Имя нельзя взять из зарезервированных слов языка: `let`, `const`, `if`, `for` и т. п.
* Принято писать имена на английском в стиле **camelCase**: первое слово строчными, следующие с заглавной - `totalPrice`, `userName`. Имя должно говорить, что хранится.
* Переменную объявляют один раз. Повторное `let count` с тем же именем в той же части программы - `SyntaxError`.
* Переменную нужно объявить **до** первого использования. Иначе - `ReferenceError`.
* `const` запрещает **присвоить** новое значение. Попытка сделать это - `TypeError`.
* Присваивание выполняется справа налево: сначала вычисляется правая часть, потом результат записывается в левую.
* Сокращения: `x += n` равно `x = x + n`; `x++` равно `x = x + 1`.

## Типичные ошибки

**1. Попытка изменить `const`.**

```javascript
const rate = 90;
rate = 95;
```

Node.js: `TypeError: Assignment to constant variable.` Строка с `^` указывает на присваивание. Если значение должно меняться, объявите переменную через `let`.

**2. Объявить дважды.**

```javascript
let total = 1;
let total = 2;
```

Node.js: `SyntaxError: Identifier 'total' has already been declared` («имя total уже объявлено»). Второй раз слово `let` не нужно: напишите `total = 2;`.

**3. Использовать до объявления.**

```javascript
console.log(total);
let total = 5;
```

Node.js: `ReferenceError: Cannot access 'total' before initialization` («нет доступа к total до инициализации»). Переменная появляется в программе там, где её объявили, и не раньше.

**4. Взять в кавычки имя переменной.**

```javascript
const city = "Казань";
console.log("city");
```

Печатается слово `city`, а не `Казань`. Текст в кавычках не заменяется значением переменной. Уберите кавычки.

**5. Имя, начинающееся с цифры.**

```javascript
let 2x = 1;
```

Node.js: `SyntaxError: Invalid or unexpected token`. Имя не может начинаться с цифры. Назовите переменную, например, `x2`.

**6. Опечатка в имени.**

```javascript
let count = 1;
console.log(cout);
```

Node.js: `ReferenceError: cout is not defined`. Имена `count` и `cout` для Node.js - разные слова. Сверьте написание с объявлением.

<!-- section: summary -->
## Итоги

* Переменная - имя, под которым хранится значение. Создаётся словом `let` или `const`.
* `const` - значение не меняется; `let` - можно заменить присваиванием `имя = новое значение;`.
* Присваивание сначала вычисляет правую часть, потом записывает результат; поэтому `count = count + 1` увеличивает `count`.
* Имя состоит из букв, цифр, `_` и `$`, не начинается с цифры, различает регистр.

Теперь, когда значения можно хранить, можно с ними считать: [Арифметика](lesson:javascript.from-zero.arithmetic).

## Для тех, кто уже программирует

* `let` и `const` имеют блочную область видимости, как переменные в C#/Java; `var` в курсе не используется (его особенности - в `javascript-fundamentals`).
* `const` запрещает **переприсваивание** имени, но не делает значение неизменяемым: у объектов и массивов содержимое можно менять (позже в курсе).
* Тип у переменной не объявляется: `let x = 1; x = "a";` допустимо. В отличие от Go/Java/C#, объявление не содержит типа.
* Повторное объявление в той же области - синтаксическая ошибка; обращение к `let`/`const` до объявления - `ReferenceError` (временная мёртвая зона).
* `let x;` даёт `undefined`, а не ноль или пустую строку.
* Присваивание `=` - выражение, `++` и `+=` работают как в C-подобных языках.

<!-- section: deep-dive -->
## Что такое «временная мёртвая зона»

Это необязательный раздел: для заданий он не нужен.

Когда Node.js разбирает файл, он уже знает, какие имена объявлены. Поэтому сообщение в ошибке 3 звучит не «total не определено», а «нет доступа к total до инициализации»: имя зарезервировано, но значения у него ещё нет. Отрезок от начала области до строки с объявлением называют временной мёртвой зоной - обращаться к переменной в нём нельзя.

Это сделано намеренно. В старом JavaScript было слово `var`, которое позволяло использовать переменную до объявления и тихо получать `undefined`. Это порождало трудноуловимые ошибки, поэтому `let` и `const` ведут себя строже: ошибка видна сразу и указывает на конкретное место.
