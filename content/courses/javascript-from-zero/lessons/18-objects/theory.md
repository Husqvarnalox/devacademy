## Зачем это нужно

Массив хранит список однородных значений: цены, имена, оценки. Но многие вещи описываются несколькими признаками разного вида. Товар - это название, цена и наличие. Пользователь - имя, возраст и город. Хранить их в отдельных переменных (`productName`, `productPrice`, `productInStock`) неудобно: их приходится таскать по программе по одной, а для второго товара заводить ещё три. Для таких случаев есть **объект**: одно значение, в котором лежат другие значения с именами.

## Одна новая идея: объект - набор пар «имя: значение»

**Объект** записывают в фигурных скобках, пары разделяют запятыми, имя от значения - двоеточием:

```javascript
const product = { name: "Чай", price: 120, inStock: true };
```

Каждая пара называется **свойством**. Слева стоит имя свойства (ключ), справа - его значение, значением может быть число, строка, булево, массив и даже другой объект. В отличие от массива, в объекте элементы находят не по номеру, а по имени.

Прочитать свойство можно двумя способами:

* через точку: `product.name` - имя записано в коде буквально;
* через квадратные скобки: `product["name"]` - внутри скобок выражение, значение которого и есть имя. Это нужно, когда имя лежит в переменной.

Свойство можно изменить или добавить присваиванием: `product.price = 99;`. Проверить, что свойство есть, можно оператором `in`: `"price" in product`. Список всех имён даёт `Object.keys(product)`.

<!-- section: examples -->
## Пример 1. Создать и прочитать

```javascript run
const product = { name: "Чай", price: 120, inStock: true };
console.log(product);
console.log(product.name);
console.log(product["price"]);
console.log(product.weight);
```
```output
{ name: 'Чай', price: 120, inStock: true }
Чай
120
undefined
```

Разбор:

* `console.log(product)` показывает объект целиком в фигурных скобках; строки в нём печатаются в одинарных кавычках.
* `product.name` и `product["price"]` - два способа прочитать свойство. Имя в скобках пишется строкой, в кавычках.
* Свойства `weight` у объекта нет, и результат - `undefined`, как с индексом за границей массива. Ошибки нет.

## Пример 2. Изменить и добавить

```javascript run
const product = { name: "Чай", price: 120 };
product.price = 99;
product.weight = 250;
console.log(product);
console.log(Object.keys(product));
```
```output
{ name: 'Чай', price: 99, weight: 250 }
[ 'name', 'price', 'weight' ]
```

Присваивание существующему свойству заменяет значение, несуществующему - создаёт его. `const` запрещает только заменить `product` другим объектом, а содержимое менять можно, как и у массива. `Object.keys` возвращает **массив** имён, поэтому к нему применимы `length`, цикл `for...of` и методы массивов.

## Пример 3. Имя в переменной

```javascript run
const user = { name: "Анна", age: 30 };
const field = "age";
console.log(user[field]);
console.log(user.field);
console.log("name" in user, "city" in user);
```
```output
30
undefined
true false
```

В `user[field]` внутри скобок вычисляется переменная `field`, получается `"age"`, и читается свойство `age`. Запись `user.field` ищет свойство буквально с именем `field`, которого нет. Оператор `in` слева принимает имя строкой и сообщает `true` или `false`.

## Пример 4. Функция, которая создаёт объект

```javascript run
function makeUser(name, age) {
  return { name: name, age: age };
}

const first = makeUser("Борис", 25);
const second = makeUser("Вера", 41);
console.log(first.name + " - " + first.age);
console.log(second.name + " - " + second.age);
```
```output
Борис - 25
Вера - 41
```

Функция принимает значения и возвращает готовый объект. Каждый вызов создаёт новый объект, и они не зависят друг от друга. Запись `name: name` означает «свойство `name` со значением из параметра `name`».

**Попробуйте.** В примере 2 добавьте свойство `color` со значением `"зелёный"` и напечатайте `Object.keys(product).length`. Затем в примере 3 замените `"age"` в переменной `field` на `"name"` и предскажите вывод.

## Точные правила

* Литерал объекта: `{ имя: значение, имя: значение }`. Имена, похожие на идентификаторы, пишут без кавычек; имя с пробелом или дефисом нужно в кавычках: `{ "first name": "Анна" }`.
* Чтение: `obj.name` (имя буквально) или `obj["name"]` / `obj[переменная]` (имя вычисляется). Нужной формы нет - не будет и ошибки, получится `undefined`.
* Запись: `obj.name = value` меняет существующее свойство или создаёт новое.
* Удалить свойство можно командой `delete obj.name`; в курсе она не используется.
* `"name" in obj` - есть ли свойство с таким именем. Свойство, значение которого `undefined`, **есть**: `"a" in { a: undefined }` даёт `true`. Поэтому `obj.a !== undefined` и `"a" in obj` - не одно и то же.
* `Object.keys(obj)` - массив имён собственных свойств в порядке добавления (имена, похожие на целые числа, идут первыми по возрастанию). `Object.values(obj)` - массив значений.
* Значение свойства может быть массивом или другим объектом: `user.address.city`, `user.tags[0]`. Если по пути встретится `undefined`, дальнейшее чтение вызывает `TypeError`.
* `const obj = {}` не мешает менять свойства, но не позволяет присвоить `obj` другой объект.
* Два разных объекта с одинаковыми свойствами не равны: `{ a: 1 } === { a: 1 }` даёт `false`, так как сравниваются сами объекты, а не их содержимое.
* Вызов `console.log(obj)` показывает объект в фигурных скобках; длинные объекты печатаются на нескольких строках.

## Типичные ошибки

**1. Опечатка в имени свойства.**

```javascript
const user = { name: "Анна" };
console.log(user.nme);
```

Напечатается `undefined`, ошибки нет. Если вместо значения видите `undefined`, сверьте имя с тем, что записано в объекте, включая регистр: `userName` и `username` - разные свойства.

**2. Точка вместо скобок при имени в переменной.**

```javascript
const user = { age: 30 };
const key = "age";
console.log(user.key);
```

Напечатается `undefined`: ищется свойство с именем `key`. Нужно `user[key]`.

**3. Чтение свойства у `undefined`.**

```javascript
const user = { name: "Анна" };
console.log(user.address.city);
```

Node.js: `TypeError: Cannot read properties of undefined (reading 'city')`. Свойства `address` нет, поэтому `user.address` равно `undefined`, а у него нельзя читать свойства. Сообщение называет имя, которое не удалось прочитать (`city`); искать нужно то, что стоит слева от точки.

**4. Забыли кавычки в скобках.**

```javascript
const user = { name: "Анна" };
console.log(user[name]);
```

Здесь `name` без кавычек - это обращение к переменной, а не имени. Переменной `name` нет, поэтому Node.js сообщит `ReferenceError: name is not defined`. Для буквального имени пишите `user["name"]` или `user.name`.

**5. Сравнение объектов через `===`.**

```javascript
console.log({ a: 1 } === { a: 1 });
```

Напечатается `false`: это два разных объекта. Чтобы сравнить содержимое, сравнивайте нужные свойства по отдельности.

**6. Забыта запятая между свойствами.**

```javascript
const p = { name: "Чай" price: 120 };
```

Node.js: `SyntaxError: Unexpected identifier 'price'`. Пары разделяются запятой.

<!-- section: summary -->
## Итоги

* Объект - набор свойств «имя: значение» в фигурных скобках: `{ name: "Чай", price: 120 }`.
* `obj.name` и `obj["name"]` читают свойство; в скобках можно использовать переменную. Отсутствующее свойство даёт `undefined`.
* Присваивание `obj.name = value` меняет или добавляет свойство. `"name" in obj` проверяет наличие, `Object.keys(obj)` возвращает массив имён.
* Объект в `const` можно изменять, но нельзя заменить целиком.

Реальные данные - это обычно много объектов сразу, то есть массив объектов: [Массивы объектов](lesson:javascript.from-zero.arrays-of-objects).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Объект-литерал - это одновременно и запись/структура, и словарь: произвольные строковые ключи (и `Symbol`), изменяемый набор свойств. Для настоящих словарей есть `Map`, в курсе не используется.
* Чтение несуществующего свойства возвращает `undefined`, а не `KeyError`/`NullPointerException`; ошибкой становится только чтение свойства *у* `undefined` или `null`.
* `in` проверяет и унаследованные свойства: `"toString" in {}` даёт `true`. Для собственных свойств есть `Object.hasOwn(obj, key)`, но в курсе достаточно `in` на простых объектах.
* Порядок ключей: сначала целочисленные по возрастанию, затем строки в порядке добавления.
* `{ name, age }` - сокращённая запись для `{ name: name, age: age }`; в курсе пишется полностью, чтобы не скрывать, что происходит.
* `===` сравнивает объекты по ссылке. Глубокого сравнения в языке нет.
* `Object.keys/values/entries` возвращают массивы, так что дальше работают методы массивов.

## Что хранит переменная с объектом

Это необязательный раздел: для заданий он не нужен.

Числа, строки и булевы значения при присваивании копируются: после `let b = a;` у `b` собственное значение. Объекты (и массивы) устроены иначе. Переменная хранит не сам объект, а **ссылку** на него: «адрес», по которому в памяти лежит набор свойств. Присваивание `const second = first;` копирует ссылку, и теперь обе переменные указывают на один и тот же объект. Изменение через `second.price = 1` видно и через `first.price`.

Это объясняет сразу несколько фактов из урока: почему `const` не мешает менять объект (неизменной остаётся ссылка, а не то, на что она указывает), почему `{ a: 1 } === { a: 1 }` ложно (две разные ссылки) и почему функция из упражнения может изменить переданный ей объект и вернуть его же. Вызов `makeUser` создаёт новый объект при каждом вызове, поэтому `first` и `second` в примере 4 не влияют друг на друга.
