## Зачем это нужно

Текст редко бывает в нужном виде. Пользователь вводит имя с пробелом в конце, пишет всё заглавными, в адресе страницы нужны строчные буквы и дефисы вместо пробелов, а строка «красный,зелёный,синий» на самом деле список. У строк, как и у массивов, есть методы - готовые команды, которые решают такие задачи.

## Одна новая идея: метод строки возвращает новую строку

Метод вызывают через точку после значения: `"текст".метод(...)`. Строки в JavaScript **неизменяемы**: ни один метод не меняет саму строку. Он возвращает **новую** строку (или другой результат), а старая остаётся прежней. Поэтому результат нужно куда-то деть: напечатать, вернуть из функции или сохранить в переменную.

Основные методы:

* **`trim()`** - убрать пробелы и переносы строк в начале и в конце.
* **`toUpperCase()`**, **`toLowerCase()`** - заглавные и строчные буквы (кириллица тоже).
* **`slice(начало, конец)`** - часть строки с индекса `начало` до индекса `конец`, не включая его. Если `конец` не указан, берётся всё до конца строки.
* **`includes(фрагмент)`** - `true`, если фрагмент встречается в строке.
* **`replaceAll(что, чем)`** - заменить все вхождения.
* **`split(разделитель)`** - разбить строку на массив частей. Обратная операция к `join`.

<!-- section: examples -->
## Пример 1. Пробелы и регистр

```javascript run
const raw = "  Привет, Мир  ";
console.log("[" + raw.trim() + "]");
console.log("[" + raw.toUpperCase() + "]");
console.log("[" + raw.toLowerCase() + "]");
console.log(raw.length, raw.trim().length);
```
```output
[Привет, Мир]
[  ПРИВЕТ, МИР  ]
[  привет, мир  ]
15 11
```

Квадратные скобки добавлены только для того, чтобы были видны пробелы. `trim` убрал пробелы по краям, а `toUpperCase` и `toLowerCase` их не тронули. Длина исходной строки не изменилась (15): она по-прежнему лежит в `raw`, а `trim` создал отдельную строку длиной 11.

## Пример 2. slice

```javascript run
const word = "программа";
console.log(word.slice(0, 4));
console.log(word.slice(4));
console.log(word.slice(-2));
console.log(word.slice(0, 1).toUpperCase() + word.slice(1));
```
```output
прог
рамма
ма
Программа
```

* `slice(0, 4)` - символы с индексами 0, 1, 2, 3.
* `slice(4)` - всё, начиная с индекса 4.
* `slice(-2)` - отрицательное число отсчитывается от конца: последние два символа.
* Последняя строка делает первую букву заглавной: берём её отдельно, поднимаем регистр и приклеиваем остаток.

## Пример 3. includes и replaceAll

```javascript run
const phrase = "кот и кот";
console.log(phrase.includes("кот"));
console.log(phrase.includes("Кот"));
console.log(phrase.replaceAll("кот", "пёс"));
console.log(phrase);
```
```output
true
false
пёс и пёс
кот и кот
```

`includes` различает регистр: «Кот» не найден. `replaceAll` заменил оба вхождения, а в последней строке видно, что исходная `phrase` не изменилась.

## Пример 4. split и join

```javascript run
const line = "красный,зелёный,синий";
const colors = line.split(",");
console.log(colors);
console.log(colors.length);
console.log(colors.join(" / "));
console.log("раз два три".split(" ").length);
```
```output
[ 'красный', 'зелёный', 'синий' ]
3
красный / зелёный / синий
3
```

`split(",")` режет строку по запятым и возвращает массив строк, с которым можно делать всё, что вы умеете с массивами: считать, фильтровать, склеивать обратно. Так делят строку на слова (разделитель `" "`) и на строки текста (разделитель `"\n"`).

**Попробуйте.** Напишите `"  Анна Ивановна ".trim().split(" ")` и предскажите результат. Затем измените разделитель в примере 4 на `"и"` и посмотрите, как разделилась строка.

## Точные правила

* Строки неизменяемы. `s.trim();` без сохранения результата ничего не меняет: исходное значение остаётся в `s`.
* `trim()` убирает пробелы, табуляции и переносы строк (`"\n"`, `"\r"`) только по краям.
* `toUpperCase()` и `toLowerCase()` работают с кириллицей и другими алфавитами.
* `slice(a, b)`: индексы считаются от 0, `b` не включается; отрицательный индекс считается от конца. Если индексы выходят за границы, ошибки нет: получится пустая строка или вся строка. `slice` пустой строки - пустая строка.
* `includes(x)` различает регистр; чтобы искать без учёта регистра, приведите обе строки к одному регистру.
* `replaceAll(a, b)` заменяет все вхождения строки `a`. Метод `replace` заменяет только первое; в курсе используется `replaceAll`.
* `split(разделитель)` возвращает массив. `"".split(",")` даёт `[""]` - массив из одной пустой строки, а не пустой массив. `"абв".split("")` режет на отдельные символы.
* Без аргумента `split()` не режет строку: результат - массив с одним элементом, всей строкой.
* Цепочка вызовов читается слева направо: `s.trim().toLowerCase()` - сначала `trim`, к его результату `toLowerCase`.
* Индексы в строке считаются, как в массиве: `"кот"[0]` - `"к"`. Присвоить символ нельзя: `s[0] = "К"` не работает.

## Типичные ошибки

**1. Результат метода потерян.**

```javascript
let name = "  Анна ";
name.trim();
console.log("[" + name + "]");
```

Напечатается `[  Анна ]`: `trim` вернул новую строку, которую никто не сохранил. Напишите `name = name.trim();`.

**2. Забыли скобки.**

```javascript
console.log("abc".toUpperCase);
```

Напечатается `[Function: toUpperCase]`: это сама функция, а не результат. Нужно `"abc".toUpperCase()`. Тот же случай, что `double` и `double(4)` из урока про колбэки.

**3. Метод строки у числа.**

```javascript
const count = 5;
console.log(count.trim());
```

Node.js: `TypeError: count.trim is not a function`. У чисел нет метода `trim`. Если в переменной не строка, а число, сначала превратите его в строку или проверьте, откуда оно взялось.

**4. Пустая строка и `split`.**

```javascript
console.log("".split(" ").length);
```

Напечатается `1`, а не `0`: у пустой строки одна «часть» - она сама. При подсчёте слов пустую строку проверяют отдельно.

**5. `split` без разделителя.**

```javascript
console.log("раз два".split());
```

Напечатается `[ 'раз два' ]`: массив из одной целой строки. Укажите, по чему резать: `split(" ")`.

**6. Попытка заменить букву по индексу.**

```javascript
const word = "кот";
word[0] = "Л";
console.log(word);
```

В файле `.js` ничего не произойдёт, напечатается `кот`; в файле `.mjs` (как в упражнениях) будет `TypeError: Cannot assign to read only property '0' of string 'кот'`. Соберите новую строку: `"Л" + word.slice(1)`.

**7. `includes` не нашёл слово из-за регистра.**
`"Купить Молоко".includes("молоко")` вернёт `false`. Приводите обе стороны к одному регистру: `text.toLowerCase().includes(word.toLowerCase())`.

## Итоги

* Строки неизменяемы: методы возвращают новую строку, результат нужно сохранить или вернуть.
* `trim` убирает краевые пробелы, `toUpperCase`/`toLowerCase` меняют регистр, `slice` вырезает часть, `includes` проверяет наличие, `replaceAll` заменяет все вхождения, `split` превращает строку в массив.
* Вызовы можно соединять в цепочку: `title.trim().toLowerCase()`.
* Пустая строка требует отдельного внимания: `"".split(" ")` даёт массив из одного элемента.

Пока мы хранили данные в массивах и строках. Чтобы описать одну вещь с несколькими признаками (название, цена, остаток), в языке есть объекты: [Объекты](lesson:javascript.from-zero.objects).

## Для тех, кто уже программирует

* Строки неизменяемы и хранятся как UTF-16. `length` и `slice` считают кодовые единицы UTF-16, а не символы Unicode: эмодзи занимает два «символа». Для кириллицы проблемы нет.
* `trim`, `toUpperCase`, `slice`, `includes`, `split` - аналоги методов Python/Java/C#. `replaceAll` существует с ES2021; старый `replace` заменяет только первое вхождение (если искать строку, а не регулярное выражение).
* `slice` допускает отрицательные индексы; есть также устаревший `substr` и `substring` (последний не принимает отрицательные значения) - в курсе не используются.
* `toUpperCase` не учитывает локаль (для этого есть `toLocaleUpperCase`); особые случаи вроде турецкой «i» в курсе не рассматриваются.
* `"".split(",")` даёт `[""]`, как и в Java, и в отличие от Python-разделения без аргумента.
* Сравнение строк `===` побайтово, без учёта регистра и нормализации Unicode.

## Почему строки нельзя менять на месте

Это необязательный раздел: для заданий он не нужен.

Если бы строку можно было менять, любая функция, получившая строку, могла бы изменить её для всех остальных частей программы, которые на ту же строку ссылаются. Чтобы такие неожиданности не возникали, строки в JavaScript сделаны неизменяемыми, как и числа: значение `5` тоже нельзя «переписать», можно лишь получить другое число. Поэтому методы строк всегда возвращают новое значение, а присваивание `word[0] = "Л"` не имеет эффекта.

Это экономит и память, и отладку: одна и та же строка спокойно может использоваться сразу в нескольких местах. Цена - необходимость самому сохранять результаты, как в `name = name.trim()`. Для многих операций движок хранит срезы без копирования символов, так что `slice` обычно дешевле, чем кажется.
