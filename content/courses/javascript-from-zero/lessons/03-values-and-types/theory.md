## Зачем это нужно

Программа работает со значениями: именами, ценами, количеством, ответами «да» и «нет». Компьютеру важно знать, с каким видом значения он имеет дело: числа складывают, а слова - нет. Вид значения называется **типом**. Если не различать типы, получаются странные ошибки: например, цена, записанная как текст, не посчитается как сумма.

## Одна новая идея: у каждого значения есть тип

В JavaScript три базовых типа, с которых начинается любое программирование:

* **number (число)** - целые и дробные числа: `42`, `-5`, `3.5`. Записываются без кавычек. Дробная часть отделяется точкой, а не запятой.
* **string (строка)** - текст в кавычках: `"привет"`, `"42"`, `""` (пустая строка). Всё, что в кавычках, - строка, даже если внутри цифры.
* **boolean (логическое значение)** - бывает только `true` («истина») и `false` («ложь»). Без кавычек и с маленькой буквы.

Узнать тип значения можно командой **`typeof`**: она ставится перед значением и возвращает название типа в виде строки.

<!-- section: examples -->
## Пример 1. Три типа

```javascript run
console.log(typeof 42);
console.log(typeof "привет");
console.log(typeof true);
```
```output
number
string
boolean
```

Разбор:

* `typeof 42` - значение `42` без кавычек: тип `number`.
* `typeof "привет"` - значение в кавычках: тип `string`.
* `typeof true` - значение `true`: тип `boolean`. Это слово языка, поэтому кавычек нет.
* Результат `typeof` - тоже значение (строка с названием типа). `console.log` печатает её без кавычек.

## Пример 2. Число и текст с цифрами

```javascript run
console.log(42);
console.log("42");
console.log(typeof 42);
console.log(typeof "42");
```
```output
42
42
number
string
```

На экране первые две строки выглядят одинаково, но для программы это разные значения: `42` - число, а `"42"` - два символа «4» и «2». Различие видно только через `typeof`. Позже оно станет важным: числа можно вычитать и умножать, а строки - нет.

## Пример 3. Дробные числа, отрицательные числа, пустая строка

```javascript run
console.log(typeof 3.5);
console.log(typeof -12);
console.log(typeof "");
console.log(typeof false);
```
```output
number
number
string
boolean
```

Целые, дробные и отрицательные числа относятся к одному типу `number`. Пустая строка `""` - тоже строка, просто без символов. `false` - второе логическое значение.

**Попробуйте.** Предскажите результат `console.log(typeof "true");` и `console.log(typeof "3.5");`, затем запустите. Кавычки решают, что перед вами.

<!-- section: precise -->
## Точные правила

* Значение в кавычках - всегда `string`, независимо от содержимого. Значение без кавычек - число, если это цифры, или `true`/`false`.
* Дробные числа записывают с точкой: `3.5`. Запись `3,5` не число (запятая разделяет значения в скобках).
* `true` и `false` пишутся строчными буквами. `True` и `"true"` - не логические значения: первое - неизвестное имя, второе - строка.
* Отдельных типов для целых и дробных чисел нет: оба имеют тип `number`.
* `typeof` возвращает строку: `"number"`, `"string"`, `"boolean"`. Другие названия (`"undefined"`, `"object"`, `"function"`) появятся в следующих уроках вместе с понятиями, к которым они относятся.
* Кавычки двойные и одинарные равноправны: `"привет"` и `'привет'` - одна и та же строка. В курсе используются двойные.
* `typeof` можно писать со скобками или без: `typeof 42` и `typeof(42)` дают одно и то же. В курсе - без скобок.

<!-- section: mistakes -->
## Типичные ошибки

**1. Считать число в кавычках числом.**

```javascript
console.log(typeof "5");
```

Выводит `string`. Если значение пришло в кавычках, оно текст, даже если выглядит как число. Если вам нужно число, пишите его без кавычек.

**2. Заглавная буква в `true`.**

```javascript
console.log(True);
```

Node.js: `ReferenceError: True is not defined`. JavaScript различает регистр, поэтому `True` - неизвестное имя. Логические значения пишутся `true` и `false`.

**3. Запятая в дробном числе.**

```javascript
console.log(typeof 3,5);
```

Печатает `number 5`: Node.js видит два значения, разделённых запятой, - `typeof 3` и `5`. Дробную часть отделяют точкой: `3.5`.

**4. Забыли кавычки у слова.**

```javascript
console.log(привет);
```

Node.js: `ReferenceError: привет is not defined`. Слово без кавычек - не текст, а имя, которого нет. Если нужен текст, поставьте кавычки.

**5. Ожидать, что `typeof` вернёт значение.**

`typeof true` - не `true`, а `"boolean"`: команда возвращает название типа. Сами значения она не меняет.

Как проверить самому: выведите `typeof значение` и сравните с ожиданием. Эта команда нужна как раз для таких проверок.

<!-- section: summary -->
## Итоги

* У каждого значения есть тип. Три базовых: `number` (число), `string` (строка), `boolean` (логическое значение).
* Кавычки превращают всё в строку: `42` - число, `"42"` - текст.
* `typeof значение` возвращает название типа строкой.
* Дробная часть отделяется точкой; `true` и `false` пишутся с маленькой буквы без кавычек.

Значения пока приходится писать каждый раз заново. В следующем уроке вы научитесь давать им имена и хранить: [Переменные](lesson:javascript.from-zero.variables).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Один числовой тип `number` - 64-битное число с плавающей точкой (IEEE 754). Отдельных `int`/`float` нет; для больших целых позже встретится `BigInt`.
* Строки - неизменяемые последовательности символов UTF-16; отдельного типа символа нет, символ - строка длиной 1.
* Типизация динамическая: тип у значения, а не у переменной.
* `typeof` - оператор, а не функция. Его неожиданности (`typeof null === "object"`, `typeof NaN === "number"`) разбираются в `javascript-fundamentals`.
* Типы `undefined`, `null`, `symbol`, `bigint`, `object` в этом уроке не рассматриваются.
* В отличие от Python, `true`/`false` пишутся со строчной буквы, как в Java и C#.

## Почему 42 и "42" - разные вещи

Это необязательный раздел: для заданий он не нужен.

В памяти компьютера любое значение - набор нулей и единиц. Число 42 хранится как двоичное число. Строка `"42"` хранится как последовательность кодов двух символов - «4» и «2» (в таблице Unicode это числа 52 и 50). Поэтому «42 как число» и «42 как текст» - разные последовательности бит, и компьютеру нужен тип, чтобы знать, как их читать.

Все числа JavaScript хранятся в одном формате - 64-битном числе с плавающей точкой. Целые числа в нём точны только до `9007199254740991`; дальше начинаются погрешности. Для обычных программ этого более чем достаточно, а границы мы разберём, когда дойдём до арифметики.
