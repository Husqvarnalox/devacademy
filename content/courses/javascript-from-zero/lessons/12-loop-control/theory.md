## Зачем это нужно

Цикл не всегда нужно проходить до конца. Если вы ищете первый подходящий товар, после находки продолжать незачем. Если некоторые значения нужно обойти (например, чётные числа), хочется пропустить шаг, а не оборачивать всё тело в `if`. А когда нужны пары значений (строки и столбцы таблицы), цикл помещают внутрь другого цикла. Об этих трёх приёмах и пойдёт речь.

## Одна новая идея: break останавливает цикл, continue пропускает шаг

* **`break`** («прервать») немедленно завершает цикл. Выполнение продолжается с команды после цикла.
* **`continue`** («продолжить») пропускает остаток тела на текущем шаге и переходит к следующему: в `for` - к изменению счётчика и проверке условия.
* **Вложенные циклы** - цикл внутри тела другого цикла. Внутренний выполняется целиком на каждый шаг внешнего, поэтому если внешний делает 3 шага, а внутренний 4, то тело внутреннего выполнится 3 * 4 = 12 раз.

<!-- section: examples -->
## Пример 1. break: найти и остановиться

```javascript run
let first = 0;
for (let i = 1; i <= 100; i++) {
  if (i % 7 === 0 && i % 5 === 0) {
    first = i;
    break;
  }
}
console.log(first);
```
```output
35
```

Ищем первое число, которое делится и на 7, и на 5. При `i` равном 35 условие истинно, значение сохранено, `break` завершает цикл. Без `break` цикл дошёл бы до 100 и перезаписал бы результат на 70. Результат вне цикла, поэтому переменную `first` объявляют до него.

## Пример 2. continue: пропустить шаг

```javascript run
let sum = 0;
for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) {
    continue;
  }
  sum = sum + i;
}
console.log(sum);
```
```output
37
```

Числа, кратные 3 (3, 6, 9), пропускаются: `continue` сразу переходит к следующему `i`. Остальные суммируются: 55 - (3 + 6 + 9) = 37.

## Пример 3. Вложенные циклы

```javascript run
for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 4; col++) {
    line = line + "*";
  }
  console.log(line);
}
```
```output
****
****
****
```

Внешний цикл отвечает за строки: три шага. На каждом шаге создаётся пустая строка `line`, внутренний цикл добавляет в неё четыре звёздочки, и строка печатается. Переменная `line` объявлена внутри внешнего цикла, поэтому на каждой строке начинается заново.

## Пример 4. Вложенные циклы с использованием счётчиков

```javascript run
for (let i = 1; i <= 3; i++) {
  let line = "";
  for (let j = 1; j <= 3; j++) {
    line = line + i * j + " ";
  }
  console.log(line + "|");
}
```
```output
1 2 3 |
2 4 6 |
3 6 9 |
```

Значение клетки зависит от обоих счётчиков: `i * j`. Это таблица умножения. Комбинация внешнего и внутреннего счётчиков дает все пары (1,1), (1,2), (1,3), (2,1) и так далее.

## Пример 5. break во вложенном цикле

```javascript run
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    if (j > i) {
      break;
    }
    console.log(i, j);
  }
}
```
```output
1 1
2 1
2 2
3 1
3 2
3 3
```

`break` завершает только внутренний цикл, в котором он стоит. Внешний продолжает работу. Для i = 1 внутренний цикл печатает одну пару и обрывается на j = 2, для i = 3 - три пары.

**Попробуйте.** В примере 2 замените `continue` на `break` и предскажите результат. Затем верните `continue` и пропустите числа, кратные 2, вместо 3.

## Точные правила

* `break;` допустим только внутри цикла. Вне цикла это `SyntaxError: Illegal break statement`. `continue;` вне цикла - `SyntaxError: Illegal continue statement: no surrounding iteration statement`.
* `break` завершает **ближайший** окружающий цикл, а не все циклы сразу.
* `continue` в `for` выполняет изменение счётчика (`i++`) и проверку условия. В `while` изменение счётчика обычно стоит в теле, поэтому `continue` может его пропустить и сделать цикл бесконечным: счётчик нужно менять **до** `continue`.
* В функции `return` внутри цикла завершает и цикл, и функцию сразу. Это часто короче, чем `break` с флагом: `if (n % i === 0) { return false; }`.
* В вложенных циклах у внутреннего цикла собственный счётчик с другим именем (`i` и `j`, `row` и `col`). Одинаковые имена путают читателя.
* Общее число шагов внутреннего тела - произведение числа шагов обоих циклов (если нет `break`).
* Переменная-накопитель строки таблицы объявляется внутри внешнего цикла (чтобы строка начиналась заново), общий результат - до внешнего цикла.
* Сигнал «пропустить» часто проще записать через `continue`, чем увеличивать вложенность `if`.
* Лишние пробелы и переносы в конце строки - частая причина провала проверки: в формате таблицы разделители ставят **между** элементами, а не после каждого. Приём: перед каждым элементом, кроме первого, добавляют разделитель.

## Типичные ошибки

**1. `break` вне цикла.**

```javascript
const x = 1;
if (x > 0) {
  break;
}
```

Node.js: `SyntaxError: Illegal break statement`. `break` работает только внутри `for` и `while`.

**2. `continue` пропускает увеличение счётчика в `while`.**

```javascript
let i = 0;
while (i < 5) {
  if (i === 2) {
    continue;
  }
  i = i + 1;
}
```

Цикл зависает: при `i` равном 2 `continue` возвращает к условию, не доходя до `i = i + 1`, и `i` навсегда остаётся 2. Увеличьте счётчик до `continue` или используйте `for`.

**3. `break` во вложенном цикле останавливает не тот цикл.**
`break` завершает только внутренний цикл. Если нужно выйти из функции целиком, используйте `return`.

**4. Забыли сбросить строку таблицы.**
Если `let line = "";` написать до внешнего цикла, строки будут накапливаться: вторая будет содержать первую. Объявляйте `line` внутри внешнего цикла.

**5. Лишний разделитель в конце.**

```javascript
line = line + i * j + " ";
```

После последнего числа остаётся пробел: строка `"1 2 3 "` не равна `"1 2 3"`. Проверка сравнивает строки точно. Добавляйте пробел перед каждым числом, кроме первого: `if (j > 1) { line = line + " "; }`.

**6. Ошибка границы в проверке простого числа.**
Для 1 и 0 цикл поиска делителя не находит делитель и вернёт `true`, хотя они не простые. Числа меньше 2 нужно отсечь до цикла.

**7. Одинаковое имя счётчика.**
`for (let i...)` внутри другого `for (let i...)` допустимо, но внутри внутреннего цикла будет видно только его `i`, и читателю легко запутаться. Берите разные имена.

## Итоги

* `break` завершает ближайший цикл; `continue` пропускает остаток текущего шага.
* Во вложенных циклах внутренний выполняется полностью на каждый шаг внешнего; `break` действует только на свой цикл.
* Таблицы собирают двумя циклами, разделители ставят между элементами, а не после каждого.
* В цикле `while` изменяйте счётчик до `continue`.

Вы изучили основу программирования: значения, переменные, условия, функции и циклы. Дальше - данные: списки значений, с которыми циклы работают естественнее всего. Начните с урока [Массивы](lesson:javascript.from-zero.arrays).

## Для тех, кто уже программирует

* `break` и `continue` как в C/Java/C#/Python. Метки (`outer: for ...` и `break outer`) в JavaScript есть, в курсе не используются.
* В Python у цикла есть `else`; в JavaScript его нет.
* `continue` в `for` выполняет третью часть заголовка; в `while` - нет.
* `return` из цикла внутри функции - обычный способ раннего выхода, часто вместо флага.
* Вложенные `let`-счётчики с одинаковым именем допустимы (затенение), но линтеры предупреждают.
* Строки в JavaScript неизменяемы, а накопление `+=` в цикле нормально: движок оптимизирует; позже будет `join` для массивов.

## Почему вложенные циклы быстро становятся дорогими

Это необязательный раздел: для заданий он не нужен.

Если внешний цикл делает `n` шагов, а внутренний тоже `n`, то тело внутреннего выполнится `n * n` раз. Для `n = 10` это 100 шагов, для `n = 1000` уже миллион, а для `n = 100000` - десять миллиардов, и программа будет считать минуты. Такой рост называют квадратичным, и по нему программисты оценивают, насколько решение масштабируется.

Поэтому даже в простой задаче проверки на простоту полезно не обходить все числа до `n - 1`: достаточно проверить делители до квадратного корня из `n`, а при первом найденном остановиться. `break` и `return` внутри цикла - не просто удобство записи, а способ не делать лишней работы. Для учебных чисел разница незаметна, для больших она решающая.
