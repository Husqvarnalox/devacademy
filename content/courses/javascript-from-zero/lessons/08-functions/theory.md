## Зачем это нужно

Часто один и тот же расчёт нужен в разных местах программы: посчитать скидку, собрать приветствие, найти площадь. Переписывать его каждый раз неудобно, и при изменении легко забыть одно из мест. Решение - дать расчёту имя и вызывать его по имени. Именованный кусок кода, который можно запускать много раз, называется **функцией**.

## Одна новая идея: функция принимает значения и возвращает результат

Функция устроена как маленькая машина: на вход получает значения, внутри что-то с ними делает, на выходе отдаёт результат.

```javascript
function double(n) {
  return n * 2;
}
```

* `function` - слово, которое объявляет функцию.
* `double` - имя функции.
* `n` в скобках - **параметр**: имя для значения, которое функция получит при вызове. Параметров может быть несколько, через запятую, или ни одного.
* `{ ... }` - **тело** функции: команды, которые выполняются при вызове.
* `return n * 2;` - **возврат**: функция завершает работу и отдаёт значение тому, кто её вызвал.

Само объявление ничего не выполняет. Чтобы функция сработала, её нужно **вызвать**: написать имя и в скобках значения, которые называют **аргументами**: `double(4)`. Результат вызова - значение, которое вернул `return`; его можно напечатать, записать в переменную или использовать в вычислении.

<!-- section: examples -->
## Пример 1. Объявление и вызов

```javascript run
function double(n) {
  return n * 2;
}

console.log(double(4));
console.log(double(10));
const result = double(7) + 1;
console.log(result);
```
```output
8
20
15
```

Разбор:

* Строки 1-3 объявляют функцию. На этом этапе она не выполняется.
* `double(4)` - вызов. Параметр `n` получает значение `4`, выполняется `return n * 2`, функция возвращает `8`. Это значение попадает в `console.log`.
* `double(10)` - тот же код с другим аргументом. Функция написана один раз, а используется много.
* `double(7) + 1` - вызов можно использовать как любое значение: сначала `14`, затем плюс 1.

## Пример 2. Несколько параметров и строки

```javascript run
function greet(name, greeting) {
  return greeting + ", " + name + "!";
}

console.log(greet("Анна", "Привет"));
console.log(greet("Олег", "Добрый день"));
```
```output
Привет, Анна!
Добрый день, Олег!
```

Аргументы подставляются в параметры **по порядку**: первое значение - в первый параметр, второе - во второй. Функция возвращает собранную строку, а печатает её уже вызывающий код.

## Пример 3. return и console.log - не одно и то же

```javascript run
function priceWithTax(price) {
  return price * 1.2;
}

function showPrice(price) {
  console.log("Цена:", price);
}

const full = priceWithTax(100);
console.log(full);
showPrice(full);
console.log(showPrice(50));
```
```output
120
Цена: 120
Цена: 50
undefined
```

`priceWithTax` **возвращает** значение: его можно сохранить в `full`. `showPrice` только **печатает**: значение возвращено не было. Функция без `return` возвращает `undefined` («значения нет»), поэтому последняя строка печатает сначала `Цена: 50` (внутри `showPrice`), а потом `undefined` (то, что она вернула).

Практическое правило: функции, которые что-то вычисляют, должны возвращать результат. Печатают потом в вызывающем коде.

## Слово `export` в упражнениях

В упражнениях начиная с этого урока вы пишете функции в файле с расширением `.mjs`, например `functions_task.mjs`. Перед `function` там стоит слово `export`:

```text
export function greet(name) {
  return "Привет, " + name + "!";
}
```

`export` («экспортировать») делает функцию видимой для проверки: отдельная программа проверки загружает ваш файл, берёт из него функции и вызывает их с набором значений. Слово `export` оставляйте как есть. Подробно модули и экспорт разбираются позже, в курсе `javascript-fundamentals`.

**Попробуйте.** Напишите функцию `square(n)`, которая возвращает `n * n`, и вызовите её для 3, 0 и -4. Предскажите результаты, потом запустите. Затем уберите `return` и посмотрите, что напечатается.

## Точные правила

* Объявление: `function имя(параметры) { тело }`. Имена функций и параметров подчиняются тем же правилам, что и имена переменных; принят стиль camelCase и глагол или существительное, которое говорит, что функция делает или возвращает.
* Вызов: `имя(аргументы)`. Скобки обязательны, даже если аргументов нет: `hello()`. Без скобок вы получаете саму функцию, а не вызов.
* Аргументы сопоставляются с параметрами по порядку. Лишние аргументы игнорируются. Недостающие параметры получают значение `undefined`: `double()` вернёт `NaN`, потому что `undefined * 2` не число.
* `return значение;` завершает функцию и отдаёт значение. Команды после `return` не выполняются. Без `return` функция возвращает `undefined`.
* Параметры и переменные, объявленные внутри функции, существуют **только внутри неё**. Снаружи обратиться к ним нельзя - это `ReferenceError`.
* Функцию можно вызвать до её объявления в файле: Node.js учитывает объявления `function` заранее. В курсе функции пишут выше мест вызова.
* Функция может вызывать другие функции и использоваться в выражениях.
* `export` в начале объявления (`export function ...`) делает функцию доступной проверке; работает в файлах `.mjs`.

## Типичные ошибки

**1. Забыли `return`.**

```javascript
function add(a, b) {
  a + b;
}
console.log(add(2, 3));
```

Печатается `undefined`. Сумма вычислена и никуда не отдана. Напишите `return a + b;`.

**2. Печатают вместо возврата.**

```javascript
function add(a, b) {
  console.log(a + b);
}
const total = add(2, 3) + 10;
```

Сумма печатается, но `total` будет `NaN`: функция вернула `undefined`, а `undefined + 10` не число. Проверка упражнения тоже увидит `undefined`. Если результат нужно использовать дальше, функция должна его вернуть.

**3. Забыли скобки при вызове.**

```javascript
function hello() {
  return "Привет";
}
console.log(hello);
```

Печатается `[Function: hello]`: это сама функция как значение. Чтобы выполнить её, нужны скобки: `hello()`.

**4. Перепутали порядок аргументов.**

```javascript
function divide(a, b) {
  return a / b;
}
console.log(divide(2, 10));
```

Печатается `0.2`, а не `5`. Первый аргумент попадает в `a`, второй - в `b`. Порядок аргументов должен совпадать с порядком параметров.

**5. Использовали параметр снаружи функции.**

```javascript
function double(n) {
  return n * 2;
}
console.log(n);
```

Node.js: `ReferenceError: n is not defined`. Параметр `n` существует только в теле функции.

**6. Код после `return`.**

Команды после `return` не выполняются: `return a; console.log("готово");` не напечатает «готово». Размещайте всё нужное до `return`.

**7. Вызвали несуществующую функцию.**

```javascript
console.log(triple(3));
```

Node.js: `ReferenceError: triple is not defined`. Проверьте имя и регистр букв.

## Итоги

* Функция - именованный блок кода: `function имя(параметры) { ... }`. Объявление не выполняет её, выполняет вызов `имя(аргументы)`.
* Параметры принимают значения по порядку; `return` отдаёт результат и завершает функцию; без `return` получится `undefined`.
* Вычисляющие функции возвращают значение, печать - дело вызывающего кода.
* В упражнениях перед `function` стоит `export`: так проверка получает вашу функцию.

Теперь, когда у вас есть функции и сравнения, можно заставить функцию выбирать: [Условия if и else](lesson:javascript.from-zero.if-else).

## Для тех, кто уже программирует

* Функции - значения первого класса (можно передавать и хранить); в курсе это раскроется на уроках про колбэки. Объявление `function f() {}` «поднимается» (hoisting): вызвать можно до объявления.
* Типов параметров и возврата нет. Проверки числа аргументов нет: лишние отбрасываются, недостающие - `undefined`. Перегрузки нет.
* Без `return` возвращается `undefined`. Вернуть несколько значений можно массивом или объектом (позже).
* Областью видимости служит функция/блок; переменные внутри не видны снаружи, замыкания (вложенные функции) разберутся позже.
* `export function` - синтаксис ES-модулей (файлы `.mjs`); проверка импортирует модуль через `import()`. В отличие от файла `main.js` (CommonJS), здесь действуют правила модулей.
* Аналог `def` в Python, методов-функций верхнего уровня в Go (`func`); в Java/C# отдельных функций вне класса нет.

## Что происходит при вызове функции

Это необязательный раздел: для заданий он не нужен.

При вызове `double(4)` Node.js создаёт для функции новую небольшую «рабочую область»: в ней заводится переменная `n` со значением `4`. Тело выполняется в этой области. Как только встречен `return`, область уничтожается, а значение отдаётся в то место программы, откуда была вызвана функция, и подставляется вместо выражения `double(4)`. Поэтому `double(4) + 1` вычисляется как `8 + 1`.

Каждый вызов получает собственную область, поэтому вызовы не мешают друг другу: `n` в первом вызове и `n` во втором - разные переменные. Эта же идея объясняет, почему переменные тела функции недоступны снаружи: после возврата области попросту больше нет.
