## Зачем этот урок

Синтаксис C++ знаком каждому, кто писал на Java, C#, Go или JavaScript: фигурные скобки, статические типы, `if`, `for`, `while`, `switch`. Отличия лежат под синтаксисом: у C++ нет проверок «на всякий случай». Целое молча переполняется, обычная переменная без начального значения содержит мусор, `size()` возвращает беззнаковое число, а строка считает байты. Значительная часть таких ошибок - **неопределённое поведение** (UB): стандарт не обещает ничего, и программа может напечатать что угодно, упасть или «работать» до смены компилятора. Успешное прохождение (упражнение и квиз) засчитывает уроки 01-16 курса «C++ с нуля».

## Главная мысль

C++ доверяет программисту: компилятор проверяет типы, но не проверяет значения. Всё, что зависит от диапазона, начального значения и границ, нужно обеспечить самому: инициализировать каждую переменную, считать суммы в `long long`, проверять границы до обращения. Тогда код остаётся в области определённого поведения, и результат одинаков на любом компиляторе.

## Пример 1. Целые числа: диапазон, деление, остаток

Каждая программа ниже - полный файл `main.cpp`; `#include` подключает нужную часть стандартной библиотеки, а имена из неё пишутся с префиксом `std::` (директиву `using namespace std;` в курсе не используют: чужие имена не смешиваются с вашими).

```cpp run
#include <iostream>
#include <limits>

int main() {
    int big = std::numeric_limits<int>::max();
    std::cout << big << "\n";
    std::cout << static_cast<long long>(big) + 1 << "\n";

    unsigned int u = 0;
    u = u - 1;
    std::cout << u << "\n";
    std::cout << static_cast<unsigned int>(-1) << "\n";

    std::cout << 7 / 2 << "\n";
    std::cout << -7 / 2 << "\n";
    std::cout << -7 % 3 << "\n";
    std::cout << 7 / 2.0 << "\n";
    double ratio = 10 / 4;
    std::cout << ratio << "\n";
    std::cout << static_cast<int>(3.99) << " " << static_cast<int>(-3.99) << "\n";

    int a = 2000000000;
    int b = 2000000000;
    if (a > big - b) {
        std::cout << "сумма не поместится в int\n";
    }
    std::cout << (static_cast<long long>(a) + b) / 2 << "\n";
    std::cout << a + (b - a) / 2 << "\n";

    std::cout << 5.0 / 0 << " " << -5.0 / 0 << " " << 0.0 / 0 << "\n";
}
```
```output
2147483647
2147483648
4294967295
4294967295
3
-3
-1
3.5
2
3 -3
сумма не поместится в int
2000000000
2000000000
inf -inf nan
```

Разбор. Тип `int` обычно занимает 32 бита, его наибольшее значение `2147483647`. Прибавить единицу к нему нельзя: **переполнение знакового числа - UB**, поэтому программа выше считает в `long long` (64 бита) и сравнивает заранее (`a > big - b`), не вычисляя «опасную» сумму. Беззнаковые типы ведут себя иначе: переполнение `unsigned` определено и оборачивается по модулю, поэтому `0u - 1` равно `4294967295`. Деление двух целых целочисленное и отбрасывает дробную часть к нулю (`-7 / 2` равно `-3`), остаток получает знак делимого (`-7 % 3` равно `-1`). В `double ratio = 10 / 4` сначала выполняется целочисленное деление (`2`), и только потом результат становится `double`. Деление `double` на ноль не падает и даёт `inf` или `nan`, а деление **целых** на ноль - UB.

**Попробуйте.** Вычислите среднее `a` и `b` формулой `(a + b) / 2` для значений меньше миллиарда, а потом для `2000000000` в `long long`. Проверьте, что `a + (b - a) / 2` не переполняется при `a <= b`.

## Пример 2. double, вывод и char

```cpp run
#include <cmath>
#include <iomanip>
#include <iostream>

int main() {
    std::cout << 0.1 + 0.2 << "\n";
    std::cout << std::setprecision(17) << 0.1 + 0.2 << "\n";
    std::cout << std::setprecision(6);
    std::cout << std::boolalpha << (0.1 + 0.2 == 0.3) << " " << (std::fabs(0.1 + 0.2 - 0.3) < 1e-9) << "\n";

    std::cout << 1.0 / 3 << " " << 1000000.0 << " " << 1234567.0 << "\n";
    std::cout << std::fixed << std::setprecision(2) << 1.0 / 3 << " " << 1000000.0 << "\n";
    std::cout << std::defaultfloat << std::setprecision(6);

    std::cout << std::round(2.5) << " " << std::round(-2.5) << " " << std::round(3.5) << "\n";
    std::cout << true << " ";
    std::cout << std::noboolalpha << true << "\n";

    char c = 'a';
    std::cout << c << " " << c + 1 << " " << static_cast<char>(c + 1) << "\n";
    std::cout << 'a' + 'b' << "\n";
    std::cout << sizeof(int) << " " << sizeof(long long) << "\n";
}
```
```output
0.3
0.30000000000000004
false true
0.333333 1e+06 1.23457e+06
0.33 1000000.00
3 -3 4
true 1
a 98 b
195
4 8
```

Разбор. `double` - двоичная дробь, поэтому `0.1 + 0.2` не равно `0.3`, а при печати 17 значащих цифр это видно. По умолчанию `std::cout` печатает шесть значащих цифр и переходит к научной записи: `1000000.0` превращается в `1e+06`. Формат фиксированных знаков после запятой даёт `std::fixed << std::setprecision(2)` из `<iomanip>`; оба манипулятора **остаются включёнными** для всех последующих выводов, пока их не отменить (`std::defaultfloat`). Выражение `true` печатается как `1`, пока не включён `std::boolalpha`. `std::round` округляет половину **от нуля**: `2.5` даёт `3`, `-2.5` даёт `-3`. Тип `char` - это малое целое: `'a' + 1` имеет тип `int` и печатается как `98`; чтобы получить символ `b`, нужно `static_cast<char>`.

## Пример 3. Строки, `switch` и цикл

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string s = "привет";
    std::cout << s.size() << "\n";
    std::string empty;
    std::cout << empty.size() - 1 << "\n";
    std::cout << (0 < empty.size() - 1) << "\n";
    std::cout << (static_cast<long long>(empty.size()) - 1) << "\n";

    std::string a = "caf";
    a += "e";
    std::string b = "cafe";
    std::cout << (a == b) << " " << (std::string("a") == "A") << " " << (std::string("Z") < "a") << "\n";
    std::cout << "x" + std::string("1") + std::to_string(2) << "\n";
    std::cout << std::to_string(1.5) << " " << std::to_string(10) << "\n";

    int score = 75;
    switch (score / 25) {
    case 3:
        std::cout << "три четверти\n";
    case 4:
        std::cout << "почти всё\n";
        break;
    default:
        std::cout << "меньше\n";
    }
    for (int i = 0, j = 10; i < j; i += 4, j -= 1) {
        std::cout << i << "," << j << "\n";
    }
}
```
```output
12
18446744073709551615
1
-1
1 0 1
x12
1.500000 10
три четверти
почти всё
0,10
4,9
```

Разбор. `std::string::size()` возвращает **количество байт**, а не букв: русское слово из шести букв в UTF-8 занимает `12` байт. Результат `size()` имеет тип `std::size_t` (беззнаковый), поэтому у пустой строки `size() - 1` равно `18446744073709551615`, а сравнение `0 < size() - 1` истинно. Для безопасной арифметики преобразуйте размер в знаковый тип заранее. Оператор `==` сравнивает строки по содержимому (в отличие от `==` для строк в Java), `<` сравнивает по кодам байт, поэтому `"Z" < "a"`. Склейка `"x" + std::string("1")` работает, а `"x" + "1"` (два литерала) - ошибка компиляции, потому что литералы не строки. `std::to_string(1.5)` даёт `1.500000`: формат нельзя настроить, для красивого вывода используйте `std::fixed`. В `switch` при отсутствии `break` выполнение **проваливается** в следующую метку: `case 3` напечатал обе строки.

## Точные правила

* Переполнение знакового целого (`int`, `long long`) - UB; переполнение беззнакового определено и выполняется по модулю `2^N`. `INT_MAX` доступен как `std::numeric_limits<int>::max()` из `<limits>`.
* Деление целых усекает к нулю, а `a == (a / b) * b + a % b`; деление и остаток при `b == 0` - UB. Результат `INT_MIN / -1` тоже не помещается в `int` - UB. Для неотрицательного остатка: `((a % b) + b) % b` при `b > 0`.
* Обычная локальная переменная (`int x;`) **не инициализируется**: её чтение - UB. Запись `int x{};` и `int x = 0;` даёт нуль, `std::string` и `std::vector` инициализируются сами (пустые значения).
* Неявные преобразования между числами разрешены в обе стороны, в том числе с потерей: `int n = 3.7;` компилируется (`n == 3`). Инициализация в фигурных скобках (`int n{3.7};`) запрещает **сужающее** преобразование. Явное преобразование - `static_cast<T>(x)`.
* При сравнении знакового со беззнаковым знаковое сначала приводится к беззнаковому: `-1 < 1u` ложно. Компилятор предупреждает: `-Wsign-compare`.
* `size()` строк и контейнеров - `std::size_t` (беззнаковый). Конструкция `i < v.size() - 1` для пустого вектора - бесконечное «вперёд»; `for (std::size_t i = n - 1; i >= 0; i--)` не заканчивается никогда, потому что `i >= 0` всегда истинно для беззнакового.
* `double` - IEEE 754: `nan != nan`, равенство дробей через `==` ненадёжно, сравнивают с допуском. Вывод по умолчанию - шесть значащих цифр; `std::fixed` и `std::setprecision` залипают.
* `char` - целый тип, может быть знаковым или беззнаковым в зависимости от платформы; арифметика с ним даёт `int`. `bool` в `cout` печатается как `1` или `0`.
* `std::string` хранит байты (кодировка не проверяется): `size()` и `s[i]` работают с байтами, поэтому индексация подходит только для ASCII.
* `switch` работает по целым и `char`, без `break` проваливается дальше; `if (x = 5)` присваивает и проверяет результат.

## Типичные ошибки

Сообщения ниже получены компилятором Apple clang 21 с ключами `-O2 -Wall -Wextra` (g++ формулирует иначе, но указывает то же место).

**1. Неинициализированная переменная.** Программа компилируется, а прочитанное значение непредсказуемо:

```cpp
int count;
std::cout << count << "\n";
```

```
main.cpp:5:18: warning: variable 'count' is uninitialized when used here [-Wuninitialized]
    5 |     std::cout << count << "\n";
      |                  ^~~~~
main.cpp:4:14: note: initialize the variable 'count' to silence this warning
```

Предупреждение не обязательно: компилятор видит не все пути. Привычка `int count = 0;` избавляет от вопроса.

**2. Константное переполнение.** `int big = 2147483647 + 1;` компилируется с предупреждением, а для значений из переменных предупреждения нет вовсе:

```
main.cpp:6:26: warning: overflow in expression; result is -2'147'483'648 with type 'int' [-Winteger-overflow]
```

Не полагайтесь на «получилось отрицательное»: в оптимизированной сборке компилятор вправе считать, что переполнения не бывает, и выбросить проверку, которая на него рассчитана.

**3. Сужение в фигурных скобках.**

```
main.cpp:8:11: error: type 'double' cannot be narrowed to 'int' in initializer list [-Wc++11-narrowing]
```

Запись `int n = 3.7;` такой ошибки не даёт, а молча усекает. Если усечение нужно, пишите `static_cast<int>(3.7)`.

**4. Присваивание вместо сравнения.**

```
main.cpp:10:11: warning: using the result of an assignment as a condition without parentheses [-Wparentheses]
```

`if (y = 5)` всегда истинно. Это предупреждение, а не ошибка, поэтому не отключайте `-Wall`.

**5. `(a + b) / 2` для больших `int`.** Сумма переполняется до деления - UB. Считайте в `long long`.

**6. Счётчик `std::size_t` с условием `>= 0`.** Цикл «от конца» с беззнаковой переменной бесконечен. Пишите `for (std::size_t i = n; i > 0; i--)` и обращайтесь к `v[i - 1]`.

**7. Деньги в `double`.** Накопленная погрешность видна уже на сотнях операций. Храните копейки в `long long`, как в упражнении.

**8. `std::endl` в цикле.** Он не просто переводит строку, а сбрасывает буфер, что медленно при большом выводе; используйте `"\n"`.

## Главное для тех, кто уже программирует

* Синтаксис ближе всего к Java и C#, но семантика ближе к C: нет проверок диапазона, нет значений по умолчанию у локальных переменных, нет исключения на целочисленное деление на ноль (в Java это `ArithmeticException`, в Python `ZeroDivisionError`; в C++ - UB).
* Переполнение `int` в Java, C# и Go молча оборачивается и **определено**; в C++ переполнение знакового - UB. Определённо оборачиваются только беззнаковые типы. В Python `int` неограничен, в Rust в отладочной сборке паника.
* Деление к нулю и знак остатка - как в Java, C# и Go; в Python `//` и `%` округляют вниз, поэтому `-7 // 2 == -4`.
* Размеры типов зависят от платформы: `int` обычно 32 бита, `long` - 32 или 64 (Windows и Linux различаются), `long long` - не меньше 64. В Java и C# размеры фиксированы; для точного размера есть `std::int32_t` и `std::int64_t` из `<cstdint>`.
* `std::string` изменяема и копируется как значение; `size()` - байты в UTF-8, как `len(s)` в Go и `len(s.encode())` в Python, но не `length` в JavaScript или Java (UTF-16).
* `std::format` (C++20) и `std::print` (C++23) есть не в каждой стандартной библиотеке, поэтому курс форматирует вывод манипуляторами `std::fixed` и `std::setprecision`.
* `std::cout << x` печатает `double` с шестью цифрами, как `%g` в C; в Python и JavaScript выводится кратчайшее представление. `std::endl` сбрасывает буфер.
* `switch` проваливается без `break`, как в C и Java до выражений `switch`; в Go и Rust этого нет.
