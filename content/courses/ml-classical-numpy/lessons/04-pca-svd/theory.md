## Сжатие данных с минимальными потерями

Допустим, у каждого объекта 50 признаков, но многие из них сильно связаны друг с другом: рост и размер обуви, площадь и число комнат. Тогда данные на самом деле «живут» в пространстве меньшей размерности: вместо 50 осей хватит нескольких. **Метод главных компонент (PCA)** находит эти оси автоматически. Он ищет направление, вдоль которого данные разбросаны сильнее всего (первая компонента), затем следующее направление, перпендикулярное первому, с наибольшим из оставшихся разбросов, и так далее.

Дальше можно оставить только первые `k` компонент и описывать каждый объект `k` числами вместо `d`. Потеря информации при этом измеряется ошибкой восстановления: насколько точка после сжатия и обратного разворачивания отличается от исходной. PCA даёт наименьшую возможную такую ошибку среди всех линейных сжатий до `k` измерений.

Считать PCA удобнее всего через **сингулярное разложение (SVD)**: оно напрямую выдаёт нужные направления и их «силу» и устойчивее, чем явное построение матрицы ковариации. Единственная подготовка — **центрирование**: из каждого признака надо вычесть его среднее.

## PCA как SVD центрированных данных

Пусть `X` — матрица `n × d`, `μ` — вектор средних по столбцам, `Xc = X - μ`. Сингулярное разложение: `Xc = U Σ Vᵀ`, где `U` и `V` имеют ортонормированные столбцы, `Σ = diag(s_1 ≥ s_2 ≥ ... ≥ 0)`. Тогда:

* **Главные компоненты** — строки `Vᵀ` (столбцы `V`); берём первые `k` и записываем как матрицу `W` формы `k × d`.
* **Дисперсии вдоль компонент** (с `ddof=1`): `λ_j = s_j² / (n - 1)`. Это собственные числа выборочной ковариации `Xcᵀ Xc / (n - 1)`, а столбцы `V` — её собственные векторы. Поэтому SVD даёт то же, что и `np.linalg.eigh(np.cov(X.T))`, но без явного возведения данных в квадрат.
* **Доля объяснённой дисперсии**: `λ_j / Σ_i λ_i`, где сумма идёт по **всем** `d` компонентам, а не только по выбранным `k`.
* **Проекция**: `Z = (X - μ) Wᵀ`, форма `n × k`. **Восстановление**: `X̂ = Z W + μ`.
* **Ошибка восстановления**: `mean_i ‖x_i - x̂_i‖² = (n - 1)/n · Σ_{j>k} λ_j` — сумма отброшенных дисперсий (с поправкой `(n-1)/n` из-за `ddof`). По теореме Эккарта — Янга — Мирского это минимум среди всех приближений матрицы данных рангом `k`.

**Неоднозначность знака.** Если `v` — сингулярный вектор, то и `-v` тоже (со сменой знака у соответствующего столбца `U`). Разные реализации и версии библиотек выбирают знак по-разному, поэтому сравнивать компоненты надо с точностью до знака: например, `|cos|` между векторами должен быть равен 1. Проекции и ошибка восстановления от знака не зависят.

**Центрирование обязательно.** Без вычитания среднего первая «компонента» в основном указывает на направление от начала координат к центру облака, а не на направление наибольшего разброса.

**Сложность.** Тонкий SVD матрицы `n × d` стоит `O(n d min(n, d))`.

## Примеры

**Пример 1. PCA через SVD и сверка с собственными числами ковариации.**

```python run
import numpy as np

rng = np.random.default_rng(0)
A = np.array([[3.0, 0.0, 0.0], [1.0, 1.5, 0.0], [0.5, 0.2, 0.3]])
X = rng.normal(size=(200, 3)) @ A + np.array([5.0, -3.0, 2.0])
n = len(X)

mean = X.mean(axis=0)
U, s, Vt = np.linalg.svd(X - mean, full_matrices=False)
var = s ** 2 / (n - 1)

vals = np.linalg.eigvalsh(np.cov(X.T))[::-1]          # по убыванию
print("формы:", U.shape, s.shape, Vt.shape)
print("дисперсии совпали с собственными числами ковариации:", bool(np.allclose(var, vals, rtol=1e-8)))
print("доли дисперсии:", (var / var.sum()).round(3).tolist())
print("строки Vt ортонормированы:", bool(np.allclose(Vt @ Vt.T, np.eye(3), atol=1e-10)))
```
```output
формы: (200, 3) (3,) (3, 3)
дисперсии совпали с собственными числами ковариации: True
доли дисперсии: [0.832, 0.161, 0.007]
строки Vt ортонормированы: True
```

**Пример 2. Знак компоненты не определён.**

```python run
import numpy as np

rng = np.random.default_rng(1)
X = rng.normal(size=(100, 2)) @ np.array([[2.0, 1.0], [0.0, 0.5]])
Xc = X - X.mean(axis=0)
_, _, Vt = np.linalg.svd(Xc, full_matrices=False)

w = Vt[:1]                       # первая компонента, форма (1, 2)
Z = Xc @ w.T
R_plus = Z @ w
R_minus = (Xc @ (-w).T) @ (-w)   # с обратным знаком
print("реконструкция не зависит от знака:", bool(np.allclose(R_plus, R_minus)))
print("координаты меняют знак:", bool(np.allclose(Xc @ (-w).T, -Z)))
print("сравнивать нужно |cos| = 1:", bool(np.isclose(abs(float(w[0] @ (-w[0]))), 1.0)))
```
```output
реконструкция не зависит от знака: True
координаты меняют знак: True
сравнивать нужно |cos| = 1: True
```

**Пример 3. Ошибка восстановления и отброшенная дисперсия.**

```python run
import numpy as np

rng = np.random.default_rng(2)
A = np.array([[3.0, 0.0, 0.0], [1.0, 1.5, 0.0], [0.5, 0.2, 0.3]])
X = rng.normal(size=(300, 3)) @ A
n = len(X)
mean = X.mean(axis=0)
_, s, Vt = np.linalg.svd(X - mean, full_matrices=False)
var = s ** 2 / (n - 1)

errors = []
for k in (1, 2, 3):
    W = Vt[:k]
    R = (X - mean) @ W.T @ W + mean
    errors.append(float(np.mean(np.sum((X - R) ** 2, axis=1))))

print("ошибка убывает с k:", errors[0] > errors[1] > errors[2])
print("k = d даёт почти нуль:", errors[2] < 1e-20)
print("ошибка = отброшенная дисперсия * (n - 1) / n:",
      bool(np.isclose(errors[0], var[1:].sum() * (n - 1) / n, rtol=1e-8)),
      bool(np.isclose(errors[1], var[2] * (n - 1) / n, rtol=1e-8)))
```
```output
ошибка убывает с k: True
k = d даёт почти нуль: True
ошибка = отброшенная дисперсия * (n - 1) / n: True True
```

**Пример 4. Что будет без центрирования.**

```python run
import numpy as np

rng = np.random.default_rng(3)
X = rng.normal(size=(200, 2)) * np.array([2.0, 0.5]) + np.array([30.0, 30.0])   # разброс вдоль оси x, центр далеко

_, _, Vt_raw = np.linalg.svd(X, full_matrices=False)
_, _, Vt_c = np.linalg.svd(X - X.mean(axis=0), full_matrices=False)

diag = np.array([1.0, 1.0]) / np.sqrt(2.0)
print("без центрирования компонента почти вдоль диагонали:", bool(abs(Vt_raw[0] @ diag) > 0.99))
print("с центрированием вдоль оси x:", bool(abs(Vt_c[0, 0]) > 0.99))
```
```output
без центрирования компонента почти вдоль диагонали: True
с центрированием вдоль оси x: True
```

## Типичные ошибки

* **Забыли центрировать.** Первая компонента указывает на центр облака, а дисперсии получаются неверными (пример 4).
* **Путаница `Vt` и `V`.** `np.linalg.svd` возвращает `Vt`: компоненты — **строки**. Для проекции нужен `Xc @ Vt[:k].T`.
* **Доли дисперсии от выбранных `k`.** Делить надо на сумму по всем компонентам, иначе доли всегда дают 1.
* **`ddof`.** `s² / n` и `s² / (n - 1)` различаются; для сравнения с `np.cov` берите `n - 1`.
* **Сравнивать компоненты по равенству.** Знак произвольный; тесты и отчёты должны быть устойчивы к нему.
* **Явная ковариационная матрица при плохой обусловленности.** Возведение в квадрат теряет малые дисперсии; SVD от `Xc` устойчивее.
* **Не стандартизовать признаки в разных единицах.** PCA максимизирует дисперсию, и признак с большим масштабом доминирует; приводите признаки к единому масштабу, если это уместно.
* **Центрирование по тестовой выборке.** Среднее и компоненты вычисляют на обучающих данных и применяют к новым.

## Итоги

* PCA = SVD центрированных данных: компоненты — строки `Vt`, дисперсии `s² / (n - 1)`.
* Доля объяснённой дисперсии считается от суммы по всем компонентам.
* Проекция `(X - μ) Wᵀ`, восстановление `Z W + μ`, ошибка равна отброшенной дисперсии с множителем `(n - 1)/n`.
* Знак компонент произволен: сравнивайте с точностью до знака.
* Центрирование обязательно; параметры считают по обучающим данным.

Это последняя лекция курса. Следующий шаг — этап B курса: библиотечные реализации тех же алгоритмов (запланирован).

## Как это делается в библиотеке

Этап B курса — реализация в scikit-learn — **запланирован**: библиотека в окружении курса не установлена, поэтому исполняемого кода с ней здесь нет, а ниже только описание.

В scikit-learn метод реализован классом `PCA` из `sklearn.decomposition`. По документации, он центрирует данные (но не масштабирует их) и применяет сингулярное разложение; при больших данных и малом `n_components` выбирается рандомизированный вариант SVD, который быстрее и даёт приближённый результат. Атрибуты `components_`, `explained_variance_` и `explained_variance_ratio_` соответствуют нашим `components`, `explained_variance` и доле дисперсии; в документации также указано, что знак компонент детерминируется библиотекой по определённому правилу, но на него не стоит опираться. Для данных, которые не помещаются в память, есть `IncrementalPCA`, а для разреженных — `TruncatedSVD`, который не центрирует данные.

Сравнение с нашей реализацией:

* **Корректность.** При полном SVD результат совпадает с нашим с точностью до знака компонент и ошибок округления; именно так устроены наши тесты.
* **Численная устойчивость.** Оба варианта используют SVD центрированных данных, а не явную ковариационную матрицу, поэтому малые дисперсии теряются меньше; рандомизированный вариант вносит небольшую контролируемую погрешность.
* **Сложность.** Полный SVD стоит `O(n d min(n, d))`; рандомизированный для малого `k` — порядка `O(n d k)`.
* **Удобство.** Библиотека добавляет `fit`/`transform`, выбор числа компонент по порогу доли дисперсии, обработку больших данных по частям и интеграцию в конвейеры.
