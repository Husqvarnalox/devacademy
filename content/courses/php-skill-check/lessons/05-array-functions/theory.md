## Что проверяет эта проверка

`array_map`, `array_filter`, `array_reduce`, `usort` и оператор `<=>`, `array_column`, `array_merge` и `+`, замыкания с `use` и стрелочные функции, деструктуризация и оператор `...`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Массивы как упорядоченные хеш-таблицы, функции высшего порядка и деструктуризация](lesson:php.fundamentals.arrays-and-functions).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```php run
<?php
declare(strict_types=1);

$scores = [5, 8, 3, 8, 1];
$even = array_filter($scores, fn(int $n): bool => $n % 2 === 0);
echo json_encode($even), " ", json_encode(array_values($even)), "\n";
echo json_encode(array_map(fn(int $n): int => $n * 10, $scores)), "\n";
echo array_reduce($scores, fn(int $sum, int $n): int => $sum + $n, 0), "\n";

$people = [["Анна", 31], ["Иван", 25], ["Ольга", 31]];
usort($people, fn(array $a, array $b): int => [$b[1], $a[0]] <=> [$a[1], $b[0]]);
echo implode(", ", array_column($people, 0)), "\n";

$factor = 3;
$scale = function (int $n) use ($factor): int {
    return $n * $factor;
};
[$first, , $third] = $scores;
echo $scale(2), " ", $first, " ", $third, " ", max(...$scores), "\n";
```
```output
{"1":8,"3":8} [8,8]
[50,80,30,80,10]
25
Анна, Ольга, Иван
6 5 3 8
```

`array_filter` сохраняет ключи, поэтому `json_encode` печатает объект, а `array_values` возвращает список. Стрелочная функция `fn` захватывает внешние переменные автоматически, а обычному замыканию они передаются через `use`. `usort` с оператором `<=>` над массивами сравнивает по очереди элементы, что даёт сортировку по убыванию возраста и затем по имени. Деструктуризация пропускает ненужные элементы, а оператор `...` разворачивает массив в аргументы.

<!-- section: precise -->
## Что нужно уметь

* применять `array_map`, `array_filter`, `array_reduce` и понимать, какие ключи они сохраняют (`array_filter` сохраняет, `array_map` по одному массиву тоже);
* сортировать с компаратором через `usort`, помня, что она переиндексирует массив и в PHP 8 стабильна;
* писать компараторы через `<=>` для нескольких полей, включая обратный порядок;
* использовать `array_column`, `array_keys`, `array_values`, `array_sum`, `array_merge` и оператор `+`;
* различать замыкание с `use` и стрелочную функцию `fn`, захватывающую значение в момент создания;
* деструктурировать массивы (`[$a, $b] = ...`, `['k' => $v] = ...`) и разворачивать их через `...`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* `array_filter` оставляет исходные ключи: без `array_values` список «с дырками» превращается в JSON-объект.
* `usort` принимает массив по ссылке и возвращает `true`, поэтому результат `$sorted = usort(...)` не массив.
* Компаратор `fn($a, $b) => $a - $b` ломается на float: разницу приводят к `int`, лучше использовать `<=>`.
* Стрелочная функция захватывает переменную по значению: её последующее изменение стрелочная функция уже не видит.
* `array_merge` перенумеровывает числовые ключи, а оператор `+` оставляет первое значение для общего ключа.
