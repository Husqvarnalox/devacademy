## Что проверяет эта проверка

Списки и ассоциативные массивы, `foreach`, `count`, `in_array`, `sort`, `ksort`, `arsort`, `implode`, `explode`, `isset` и `??`, функции строк и работа с UTF-8 через `mb_`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Массивы: список значений](lesson:php.from-zero.arrays), [Готовые функции для массивов](lesson:php.from-zero.array-functions), [Ассоциативные массивы](lesson:php.from-zero.associative-arrays), [Строковые функции](lesson:php.from-zero.string-functions).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```php run
<?php
declare(strict_types=1);

$scores = ["Анна" => 85, "Иван" => 92];
$scores["Ольга"] = 77;
arsort($scores);
foreach ($scores as $name => $score) {
    echo "{$name}: {$score}\n";
}
$numbers = [4, 1, 3];
sort($numbers);
echo implode(",", $numbers), " ", max($numbers), " ", in_array(3, $numbers, true) ? "есть" : "нет", "\n";
$words = explode(" ", "кот и пёс");
echo count($words), " ", mb_strlen($words[2]), " ", $scores["Пётр"] ?? 0, "\n";
```
```output
Иван: 92
Анна: 85
Ольга: 77
1,3,4 4 есть
3 3 0
```

Ассоциативный массив хранит пары «ключ => значение»; `arsort` упорядочивает его по значениям, сохраняя ключи, а `sort` перенумеровывает обычный список. Функции `explode` и `implode` переводят строку в массив и обратно, `mb_strlen` считает символы, а `??` подставляет запасное значение для отсутствующего ключа без предупреждения.

## Что нужно уметь

* создавать списки и ассоциативные массивы, читать, добавлять и менять элементы, обходить их через `foreach`;
* пользоваться `count`, `in_array`, `array_sum`, `min`, `max`, `sort`, `ksort`, `arsort`, `implode`, `array_slice`;
* различать `isset`, `array_key_exists` и `??`;
* делить и склеивать строки через `explode` и `implode`;
* работать с текстом в UTF-8 через `mb_strlen`, `mb_substr`, `mb_strtoupper`, `mb_strtolower`;
* считать частоты и искать максимум по массиву.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Чтение несуществующего ключа даёт `Warning: Undefined array key`; используйте `??` или `isset`.
* `sort` меняет сам массив и возвращает `true`, а не отсортированный массив: `$sorted = sort($a)` сохранит `true`.
* `strlen`, `substr` и `strtoupper` работают с байтами: кириллицу считают неверно, для текста нужны `mb_`-функции.
* `isset($a["k"])` ложно и для ключа со значением `null`; `array_key_exists` проверяет только наличие ключа.
* `explode(" ", "")` возвращает массив из одной пустой строки, а не пустой массив.
