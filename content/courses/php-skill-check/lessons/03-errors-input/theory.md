## Что проверяет эта проверка

Чтение строк через `fgets` и `trim`, пустые и плохие строки, `filter_var`, `throw`, `try / catch / finally`, `InvalidArgumentException` и форматирование итогов.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Чтение всего ввода](lesson:php.from-zero.reading-all-input), [Исключения](lesson:php.from-zero.exceptions).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```php run
<?php
declare(strict_types=1);

function parseScore(string $text): int
{
    $score = filter_var($text, FILTER_VALIDATE_INT);
    if ($score === false) {
        throw new InvalidArgumentException("неверная оценка: {$text}");
    }
    return $score;
}

foreach (["85", "0", "abc", "4.5"] as $text) {
    try {
        echo parseScore($text), "\n";
    } catch (InvalidArgumentException $e) {
        echo "Ошибка: ", $e->getMessage(), "\n";
    } finally {
        echo "-\n";
    }
}
```
```output
85
-
0
-
Ошибка: неверная оценка: abc
-
Ошибка: неверная оценка: 4.5
-
```

`filter_var` возвращает число или `false`; значение `0` корректно, поэтому сравнивать надо строго. Исключение бросается в месте обнаружения ошибки, а ловится там, где решают, что делать дальше. Блок `finally` выполняется после каждой попытки. В программе, которая читает ввод, такой `try` стоит внутри цикла `while (($line = fgets(STDIN)) !== false)`.

<!-- section: precise -->
## Что нужно уметь

* читать ввод до конца: `while (($line = fgets(STDIN)) !== false)`, обрезать строку через `trim`, пропускать пустые;
* разбирать числа строго: `filter_var($text, FILTER_VALIDATE_INT)` и сравнение с `false`; помнить, что `0` - корректное число;
* бросать `InvalidArgumentException` с понятным сообщением и ловить её, считая ошибки и продолжая работу;
* предсказывать порядок `try`, `catch` и `finally` и знать, что `TypeError` - это `Error`, а не `Exception`;
* форматировать итоги через `number_format` и `printf`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* `while ($line = fgets(STDIN))` останавливается на последней строке `0` без перевода строки: нужно `!== false`.
* Проверка `if (!$n)` после `filter_var` принимает корректный `0` за ошибку.
* `(int) "abc"` даёт `0` и ничего не проверяет: для проверки нужен `filter_var` или `is_numeric`.
* Забыли `trim`: строка из `fgets` заканчивается на `\n`, а в Windows - на `\r\n`.
* Пустой `catch` скрывает ошибки; ловите конкретный тип и сообщайте о проблеме.
