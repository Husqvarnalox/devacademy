## Функция - это значение, как число или строка

В [основах](lesson:python.fundamentals.functions) мы определяли функции через `def` и вызывали их. Важная идея продвинутого Python: **функция - обычный объект**. Её можно положить в переменную, в список или словарь, передать в другую функцию и вернуть из функции. Круглые скобки `f()` - это не часть имени, а операция «вызвать»; без скобок `f` - просто ссылка на объект.

Это даёт мощный приём: вместо «что сделать» передавать «как это сделать». Например, `sorted(words, key=len)` сортирует слова по длине: функция `len` передана как значение.

Если функция короткая и нужна один раз, её пишут через `lambda`: `lambda w: w[-1]` - безымянная функция с единственным выражением. Для типовых случаев в стандартной библиотеке есть готовые кирпичики: `functools.partial` фиксирует часть аргументов, а `operator.itemgetter` достаёт поле из записи.

Вторая половина темы - **замыкания**. Функция, объявленная внутри другой функции, «помнит» переменные внешней, даже когда внешняя уже завершилась. Так делают счётчики, настраиваемые обработчики и (в следующем уроке) декораторы. Но у замыканий есть знаменитая ловушка: переменные запоминаются, а не их значения.

## Как это устроено

**Функция первого класса.** `def f(): ...` создаёт объект типа `function` и привязывает к нему имя `f`. У него есть атрибуты: `__name__`, `__doc__`, `__defaults__`, `__code__`, `__closure__`. Присваивание `g = f` создаёт второе имя того же объекта. Функция высшего порядка - та, что принимает функции как аргументы и/или возвращает функцию (`sorted`, `map`, `filter`, `max` с `key=`).

**lambda** - выражение, создающее функцию. Её тело - ровно одно выражение (без инструкций и без `return`), результатом является значение этого выражения. Если нужна инструкция, ветвление на несколько строк или документирование - используйте `def`. Присваивать lambda имени (`f = lambda x: x`) смысла нет: PEP 8 рекомендует `def`, так как у функции будет осмысленное имя в трассировке ошибок.

**functools.partial(func, *args, **kwargs)** возвращает вызываемый объект: при вызове он добавляет зафиксированные аргументы к новым и вызывает `func`. Исходные данные доступны как `.func`, `.args`, `.keywords`.

**Модуль operator** содержит функции-версии операторов: `operator.add`, `operator.mul`, а также `itemgetter(k)` (даёт `obj[k]`), `itemgetter(k1, k2)` (даёт кортеж `(obj[k1], obj[k2])`) и `attrgetter("name")` (даёт `obj.name`). Они работают быстрее и читаются лучше, чем эквивалентные lambda, и подходят как `key=`.

**Замыкание.** Если вложенная функция использует имя из объемлющей функции, это имя становится *свободной переменной*. Компилятор создаёт для неё *ячейку* (cell), общую для внешней и внутренней функций. Объект внутренней функции хранит кортеж ячеек в `__closure__`, а имена свободных переменных - в `__code__.co_freevars`. Ключевое: в ячейке лежит **переменная**, а не снимок значения. Что в ней в момент вызова - то функция и увидит.

**nonlocal.** Присваивание внутри функции делает имя локальным (правило LEGB из [основ](lesson:python.fundamentals.functions)). Чтобы изменить переменную объемлющей функции, а не создать локальную, объявите её `nonlocal имя`. `global` относится к модулю, `nonlocal` - к ближайшей объемлющей функции. Чтение свободной переменной объявления не требует; изменение изменяемого объекта (`items.append(x)`) - тоже: это не присваивание имени.

**Позднее связывание (late binding).** Тело функции выполняется при вызове, и поиск имени тоже происходит при вызове. В `[lambda: i for i in range(3)]` у всех трёх lambda одна и та же свободная переменная `i` (в генераторе списка - одна на всю область цикла). К моменту вызова цикл закончен и `i == 2`. Способы фиксации значения: параметр по умолчанию (`lambda i=i: i` - значение по умолчанию вычисляется в момент создания функции), `functools.partial`, либо фабрика-функция, внутри которой для каждого вызова своя переменная.

## Примеры

**Пример 1. Функция - значение.**

```python run
def shout(text):
    return text.upper() + "!"

def whisper(text):
    return text.lower() + "..."

styles = {"loud": shout, "quiet": whisper}
for name, fn in styles.items():
    print(name, fn("Hello"))

print(type(shout).__name__, shout.__name__)
words = ["pear", "fig", "banana"]
print(sorted(words, key=len))
print(sorted(words, key=lambda w: w[-1]))
```
```output
loud HELLO!
quiet hello...
function shout
['fig', 'pear', 'banana']
['banana', 'fig', 'pear']
```

**Пример 2. partial и operator.**

```python run
from functools import partial, reduce
from operator import itemgetter, mul

from_binary = partial(int, base=2)
print(from_binary("1011"))
print(from_binary.func.__name__, from_binary.keywords)

people = [{"name": "Ира", "age": 31}, {"name": "Олег", "age": 25}, {"name": "Аня", "age": 31}]
by_age_name = sorted(people, key=itemgetter("age", "name"))
print([p["name"] for p in by_age_name])
print(itemgetter("name", "age")(people[0]))
print(reduce(mul, [1, 2, 3, 4]))
```
```output
11
int {'base': 2}
['Олег', 'Аня', 'Ира']
('Ира', 31)
24
```

**Пример 3. Замыкание, ячейки и nonlocal.**

```python run
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

a = make_counter()
b = make_counter()
print(a(), a(), a(), b())
print(a.__code__.co_freevars)
print(a.__closure__[0].cell_contents)
```
```output
1 2 3 1
('count',)
3
```

**Пример 4. Ловушка позднего связывания и три исправления.**

```python run
from functools import partial

bad = [lambda: i for i in range(3)]
print([f() for f in bad])

with_default = [lambda i=i: i for i in range(3)]
print([f() for f in with_default])

def ident(x):
    return x
with_partial = [partial(ident, i) for i in range(3)]
print([f() for f in with_partial])

def make(i):
    return lambda: i
with_factory = [make(i) for i in range(3)]
print([f() for f in with_factory])
```
```output
[2, 2, 2]
[0, 1, 2]
[0, 1, 2]
[0, 1, 2]
```

## Типичные ошибки

* **lambda в цикле без фиксации значения.** Все функции видят последнее значение переменной цикла. Исправляйте параметром по умолчанию, `partial` или фабрикой.
* **Забыли `nonlocal`.** `count += 1` во вложенной функции даёт `UnboundLocalError`: имя стало локальным, а значения у него ещё нет. И наоборот, `global` вместо `nonlocal` изменит переменную модуля, а не внешней функции.
* **Вызвали вместо передачи.** `sorted(words, key=len())` вызовет `len()` без аргументов и упадёт; нужно `key=len`. Скобки означают вызов.
* **Слишком сложная lambda.** Если выражение не помещается в одну понятную строку, дайте функции имя через `def`.
* **Побочный эффект параметра по умолчанию.** Фиксация через `i=i` добавляет необязательный параметр: функцию можно случайно вызвать как `f(5)` и подменить `i`. Если это важно, используйте `partial` или фабрику.
* **Путаница `itemgetter("a", "b")` с двумя вызовами.** С несколькими аргументами он возвращает кортеж, а не два значения по отдельности.

<!-- section: summary -->
## Итог

* Функция - объект: её можно хранить, передавать и возвращать; `f` - ссылка, `f()` - вызов.
* `lambda` - функция из одного выражения; `partial` фиксирует аргументы; `itemgetter`/`attrgetter` заменяют типовые lambda для `key=`.
* Замыкание хранит ячейки с переменными внешней функции (`__closure__`), а не значения.
* `nonlocal` разрешает присваивание переменной ближайшей объемлющей функции.
* Late binding: имя ищется в момент вызова. Значение фиксируют через `i=i`, `partial` или фабрику.
* Следующий шаг: [декораторы](lesson:python.advanced.decorators) - функции, которые принимают и возвращают функции.
