## Программа выбирает, что делать

До сих пор программа выполняла все строки по порядку. В жизни мы часто выбираем: «если на улице дождь, берём зонт». Программам тоже нужен выбор,
иначе они не смогут реагировать на разные данные: бесплатный билет детям, ошибка при неверном вводе.

Выбор строится на **условии** - вопросе, на который есть ответ «да» или «нет». В Python эти ответы - значения `True` («истина») и `False` («ложь»).
Значения такого вида называются **булевыми** (тип `bool`). Чаще всего их получают **сравнением**:

```python
age = 20
print(age >= 18)
```

Результат - `True`. Операторы сравнения: `==` (равно), `!=` (не равно), `<`, `<=`, `>`, `>=`. Обратите внимание: сравнение пишется **двумя** знаками `==`,
потому что один знак `=` уже занят - он означает присваивание.

Ветвление записывается командой `if` («если»):

```python
if age >= 18:
    print("Взрослый")
else:
    print("Ребёнок")
```

После условия ставится двоеточие. Строки, которые относятся к ветке, пишутся с **отступом** - четыре пробела от левого края. Отступ показывает Python, какие команды входят в ветку.

## Примеры

**Пример 1. Сравнения дают True или False.**

```python run
print(5 > 3)
print(5 == 3)
print(5 != 3)
print("кот" == "кот")
print("кот" == "Кот")
```
```output
True
False
True
True
False
```

Разбор: `==` проверяет равенство и возвращает `bool`. Текст сравнивается символ в символ, поэтому большая и маленькая буквы различаются.

**Пример 2. if / elif / else.**

```python run
temperature = 12
if temperature < 0:
    print("Мороз")
elif temperature < 15:
    print("Прохладно")
elif temperature < 25:
    print("Тепло")
else:
    print("Жарко")
print("Проверка закончена")
```
```output
Прохладно
Проверка закончена
```

Разбор: условия проверяются сверху вниз до первого верного. `12 < 0` неверно, `12 < 15` верно - печатается «Прохладно», остальные ветки пропускаются. `elif` значит «иначе, если»,
`else` - «во всех остальных случаях». Последняя строка не имеет отступа, поэтому выполняется всегда.

**Пример 3. and, or, not.**

```python run
age = 20
has_ticket = True
print(age >= 18 and has_ticket)
print(age < 12 or age > 65)
print(not has_ticket)
if age >= 18 and not has_ticket:
    print("Нужно купить билет")
else:
    print("Проходите")
```
```output
True
False
False
Проходите
```

Разбор: `and` даёт `True`, если верны обе части. `or` - если верна хотя бы одна. `not` меняет значение на противоположное. Здесь `age >= 18` верно, а `not has_ticket` ложно, значит `and` в `if` ложно и выполняется `else`.

**Пример 4. Условие по вводу.** Запускать эту программу не будем: она читает ввод.

```python
password = input()
if password == "секрет":
    print("Доступ открыт")
else:
    print("Неверный пароль")
```

Ввод `секрет` приведёт к «Доступ открыт», любой другой - к «Неверный пароль».

**Попробуйте.** В примере 2 поставьте `temperature = 25` и `temperature = 15`. Какая ветка выполнится? Обратите внимание на границы.

## Подробнее

**Блок и отступ.** Все строки с одинаковым отступом после строки с двоеточием образуют **блок**. Блок выполняется целиком или пропускается целиком.
Принято 4 пробела; в одном блоке нельзя смешивать разные отступы.

**Порядок веток.** Выбирается первая ветка с верным условием, остальные не проверяются. Поэтому `elif age <= 5` после `if age < 0` не нужно писать как `age >= 0 and age <= 5`:
отрицательные значения уже обработаны выше. Сначала проверяйте самые узкие или самые опасные случаи.

**`if` подряд и `elif`.** Несколько отдельных `if` проверяются независимо, и может сработать несколько. Цепочка `if / elif` выполнит не больше одной ветки.
`else` необязателен.

**Вложенные условия.** Блок может содержать новый `if` с ещё большим отступом. Это нормально, но глубокую вложенность читать трудно; часто её заменяют `and` или `elif`.

**Операторы `and`, `or`, `not`.** `not` связывает сильнее `and`, а `and` сильнее `or`. Для ясности ставьте скобки: `(a or b) and c`.

**Сравнение разных типов.** `5 == 5.0` истинно. Строку с числом на равенство сравнить можно (результат `False`), а на порядок (`<`, `>`) - нет: возникнет `TypeError`.

**Сравнение цепочкой.** Можно писать `18 <= age < 65`, и это то же, что `18 <= age and age < 65`.

**Границы.** Ошибки на границах (`<` вместо `<=`) - самые частые. Проверяйте значения прямо на границе: 5 и 6, 17 и 18.

## Типичные ошибки

**1. Один знак `=` вместо двух.**

```python
n = 5
if n = 5:
    print("пять")
```

```
  File "main.py", line 2
    if n = 5:
       ^^^^^
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

Python сам подсказывает, что в условии нужно сравнение `==`. Исправление: `if n == 5:`.

**2. Пропущено двоеточие.**

```
  File "main.py", line 2
    if n > 1
            ^
SyntaxError: expected ':'
```

Двоеточие нужно после `if`, `elif` и `else`. Стрелка стоит там, где его не хватает.

**3. Нет отступа у ветки.**

```
  File "main.py", line 3
    print("x")
    ^^^^^
IndentationError: expected an indented block after 'if' statement on line 2
```

После двоеточия Python ждёт блок с отступом. Добавьте четыре пробела.

**4. Сравнение текста и числа по порядку.** Ввод всегда строка:

```
TypeError: '>' not supported between instances of 'str' and 'int'
```

Исправление: сначала `age = int(input())`. Ещё коварнее сравнение двух строк с цифрами: `"10" > "9"` даёт `False`, потому что строки сравниваются по символам, а `1` меньше `9`. Числа сравнивайте только как числа.

**5. Неверный порядок веток.** Если `elif age < 18` написать выше `if age < 5`, ветка для малышей никогда не выполнится. Проверьте на значениях из каждой группы.

**6. Условие, которое всегда истинно.** `if x == 1 or 2:` не означает «x равен 1 или 2»: `2` само считается истинным. Пишите полностью: `x == 1 or x == 2`.

## Итоги

* Сравнения (`==`, `!=`, `<`, `<=`, `>`, `>=`) дают `True` или `False`.
* `if`, `elif`, `else` выбирают ветку; блок оформляется отступом после двоеточия.
* `and`, `or`, `not` объединяют условия.
* Проверяйте границы и порядок веток.

Теперь программа может принимать решения. Дальше: [цикл while](lesson:python.fundamentals.while-loops) - как повторять действия, пока условие верно.

<!-- section: programmer -->
## Для тех, кто уже программировал

* Блоки задаются отступом и двоеточием, фигурных скобок и скобок вокруг условия нет. `elif`, а не `else if`.
* Логические операторы - слова `and`, `or`, `not`; они вычисляются лениво и возвращают один из операндов, а не обязательно `bool`.
* Цепочки сравнений `a < b < c` работают как в математике.
* `==` сравнивает значения, `is` - тождество объектов; для чисел и строк используйте `==`.
* Нет тернарного `?:`, есть `x if cond else y`; `switch` в виде `match` появился в 3.10 и в курсе не рассматривается.
* Истинность определяется по значению: `0`, `""`, пустые коллекции и `None` считаются ложными. Для начала пишите явные сравнения.
* Присваивание в условии `=` - синтаксическая ошибка, а не опечатка, которая компилируется.

## Что происходит внутри (необязательно)

`bool` в Python - подтип `int`: `True` ведёт себя как `1`, а `False` как `0`, поэтому `True + True` равно `2`. Выражения с `and` и `or` вычисляются слева направо
и останавливаются, как только результат ясен: в `a and b` значение `b` вообще не вычисляется, если `a` ложно. Эта «ленивость» используется для защиты:
`x != 0 and 10 / x > 1` не упадёт при нуле. Каждая ветка `if` компилируется в условный переход в байткоде, а отступы нужны только на этапе разбора.
