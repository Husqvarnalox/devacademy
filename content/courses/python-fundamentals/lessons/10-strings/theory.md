## Строка - это последовательность символов

Текст в программе встречается везде: имена, адреса, сообщения. Вы уже умеете создавать строки и склеивать их. Теперь научимся брать из строки нужные части и преобразовывать текст.

**Строка** - упорядоченная последовательность символов. У каждого символа есть номер, который называется **индексом**. Счёт идёт с нуля:

```
 П  р  и  в  е  т
 0  1  2  3  4  5
```

Запись `word[0]` берёт первый символ, `word[2]` - третий. Отрицательные индексы считают с конца: `word[-1]` - последний символ.

**Срез** `word[a:b]` берёт часть строки от индекса `a` до `b - 1`. Правая граница в срез не входит. Если `a` или `b` не указать, берётся начало или конец: `word[:3]`, `word[3:]`.

**Метод** - это функция, которая принадлежит значению и вызывается через точку: `word.upper()`. У строк много готовых методов: преобразование регистра, поиск, замена, обрезка пробелов.

Важное свойство: строки **неизменяемы**. Метод никогда не меняет исходную строку, а возвращает новую. Чтобы сохранить результат, его присваивают переменной.

Зачем это нужно: почти любая обработка текста (проверка ввода, разбор имён, форматирование номеров) - это комбинация индексов, срезов и методов.

## Примеры

**Пример 1. Индексы и срезы.**

```python run
word = "Привет"
print(word[0])
print(word[-1])
print(word[1:4])
print(word[:2])
print(word[3:])
print(word[::-1])
print(len(word))
```
```output
П
т
рив
Пр
вет
тевирП
6
```

Разбор: `word[1:4]` - символы с индексами 1, 2, 3. `word[:2]` - первые два. `word[3:]` - всё от индекса 3 до конца. Срез с шагом `[::-1]` читает строку с конца и разворачивает её.

**Пример 2. Методы возвращают новую строку.**

```python run
name = "  анна иванова  "
print(name.strip())
print(f"[{name.upper()}]")
print(name.strip().title())
clean = name.strip()
print(clean.replace("а", "А"))
print(clean)
```
```output
анна иванова
[  АННА ИВАНОВА  ]
Анна Иванова
АннА ивАновА
анна иванова
```

Разбор: `strip()` убирает пробелы по краям, `upper()` делает все буквы заглавными, `title()` делает заглавной первую букву каждого слова (вызовы можно соединять: `name.strip().title()` сначала убирает пробелы, потом меняет регистр), `replace(что, чем)` заменяет все вхождения. Исходная `clean` после `replace` не изменилась.

**Пример 3. Поиск и проверки.**

```python run
text = "корова и коза"
print(text.find("ко"))
print(text.find("ку"))
print(text.count("ко"))
print(text.startswith("кор"))
print(text.endswith("за"))
print("коза" in text)
print("слон" in text)
```
```output
0
-1
2
True
True
True
False
```

Разбор: `find` возвращает индекс первого вхождения или `-1`, если подстроки нет. `count` считает вхождения. `startswith` и `endswith` проверяют начало и конец. Оператор `in` отвечает, встречается ли подстрока в строке.

**Пример 4. Обход строки и повторение.**

```python run
text = "банан"
count = 0
for ch in text:
    if ch == "а":
        count = count + 1
print(count)
print("-" * 5)
print("*" * 3 + text[-2:])
```
```output
2
-----
***ан
```

Разбор: цикл `for ch in text` даёт символы по одному. `"-" * 5` повторяет строку пять раз.

**Попробуйте.** Предскажите `"банан"[1:]`, `"банан"[:-1]` и `"банан"[1:-1]`.

## Подробнее

**Индексы.** В строке длины `n` допустимы индексы от `0` до `n - 1` и от `-1` до `-n`. Любой другой индекс вызывает `IndexError`. Первый символ - `s[0]`, последний - `s[-1]`.

**Срезы прощают.** В отличие от индекса, срез с выходом за границы ошибки не даёт: `"abc"[1:100]` равно `"bc"`, а `"abc"[5:]` - пустая строка. Срез `s[a:b]` содержит `b - a` символов, если границы в пределах строки.

**Шаг среза.** Третье число - шаг: `s[::2]` берёт каждый второй символ, `s[::-1]` идёт назад.

**Неизменяемость.** `s[0] = "X"` вызывает `TypeError`. Чтобы получить изменённую строку, соберите новую: `"X" + s[1:]`.

**Методы, которые вам пригодятся.**

| Метод | Что возвращает |
|---|---|
| `upper()`, `lower()` | строку в верхнем или нижнем регистре |
| `strip()` | строку без пробелов и переводов строк по краям |
| `replace(a, b)` | строку, где все `a` заменены на `b` |
| `find(x)` | индекс первого вхождения или `-1` |
| `count(x)` | число непересекающихся вхождений |
| `startswith(x)`, `endswith(x)` | `True` или `False` |
| `isdigit()` | `True`, если строка непуста и состоит только из цифр |

**Регистр.** Сравнивая тексты без учёта регистра, приводите обе части к одному регистру: `a.lower() == b.lower()`.

**Оператор `in`.** Работает для подстрок любой длины: `"ко" in "корова"`. Пустая строка входит в любую.

**Длина символа.** Каждый индекс - один символ Unicode, поэтому русские буквы занимают по одному индексу.

## Типичные ошибки

**1. Индекс за пределами строки.**

```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(s[3])
          ~^^^
IndexError: string index out of range
```

Индекс 3 не существует в строке из трёх символов. Типичная причина - счёт с единицы или пустая строка (`""[0]`). Как заметить: сравните индекс с `len(s) - 1`.

**2. Попытка изменить символ.**

```
TypeError: 'str' object does not support item assignment
```

Строки неизменяемы. Соберите новую: `s = "x" + s[1:]`.

**3. Результат метода не сохранён.** `name.strip()` на отдельной строке ничего не меняет в `name`. Нужно `name = name.strip()`.

**4. Опечатка в имени метода.**

```
AttributeError: 'str' object has no attribute 'uper'. Did you mean: 'upper'?
```

**5. Ошибка на единицу в срезе.** `s[1:3]` даёт два символа, а не три. Правая граница не входит.

**6. Забытые скобки у метода.** `name.upper` без скобок - не вызов, `print` покажет что-то вроде `<built-in method upper of str object ...>`.

**7. Сравнение без учёта регистра.** `"Да" == "да"` ложно. Приведите ввод к одному регистру через `lower()`.

## Итоги

* Индексы идут с нуля; отрицательные считают с конца; выход за границы - `IndexError`.
* Срез `s[a:b]` не включает `b`; `[::-1]` разворачивает строку.
* Строки неизменяемы; методы возвращают новые строки, результат надо присваивать.
* `upper`, `lower`, `strip`, `replace`, `find`, `count`, `startswith`, `endswith`, `in` покрывают большую часть задач.

## Для тех, кто уже программировал

* `str` - неизменяемая последовательность символов Unicode (кодовых точек), отдельного типа `char` нет: символ - строка длины 1.
* Индексирование с конца отрицательными числами, срезы `[start:stop:step]` с полуоткрытым интервалом, выход за границы в срезах не бросает исключений.
* Методы возвращают новые строки; многократная склейка в цикле через `+=` создаёт много временных объектов, обычно используют `join` (его вы встретите позже).
* `in` для строк - проверка подстроки; `find` возвращает `-1`, а `index` - бросает `ValueError`.
* Сравнение строк лексикографическое по кодовым точкам; регистр и локаль не учитываются.
* Строки одинарной и двойной кавычки идентичны; `'''...'''` допускает несколько строк.

<!-- section: deep-dive -->
## Что происходит внутри (необязательно)

Строка Python хранит кодовые точки Unicode; для хранения интерпретатор выбирает по одному, два или четыре байта на символ в зависимости от самой «широкой» буквы в строке,
поэтому индексирование остаётся быстрым. Неизменяемость позволяет безопасно использовать строки как ключи словарей (об этом в следующих уроках) и делиться одной строкой
в нескольких местах. Срез создаёт новую строку (копию части), а не окно в исходную.
