## Модуль - это набор готовых инструментов

Некоторые задачи повторяются у всех: посчитать корень, округлить вверх, выбрать случайное число. Чтобы не писать это каждый раз, такие функции собрали в **модули**.
Модуль - это файл с кодом на Python. Чтобы воспользоваться им, его подключают командой `import`:

```python run
import math

print(math.sqrt(25))
```
```output
5.0
```

После `import math` в программе появляется имя `math`. Через точку можно обратиться к тому, что внутри: `math.sqrt` - функция корня, `math.pi` - число пи.

Вместе с Python поставляется **стандартная библиотека** - сотни модулей: для математики, случайных чисел, дат, файлов. Вам не нужно их устанавливать, достаточно написать `import`.

Свой файл с функциями тоже можно подключить как модуль. Если рядом с программой лежит `prices.py`, то в другом файле той же папки достаточно написать `import prices`.

## Примеры

**Пример 1. math.**

```python run
import math

print(math.pi)
print(math.ceil(7 / 2))
print(math.floor(7 / 2))
print(math.sqrt(2))
```
```output
3.141592653589793
4
3
1.4142135623730951
```

Разбор: `pi` - число; `ceil` округляет вверх, `floor` - вниз, `sqrt` вычисляет квадратный корень. Задача «сколько машин нужно на 7 человек, если в каждой помещается 2» решается как `math.ceil(7 / 2)`.

**Пример 2. from ... import.**

```python run
from math import sqrt, pi

print(sqrt(81))
print(round(pi, 2))
```
```output
9.0
3.14
```

Разбор: форма `from модуль import имя` приносит в программу только перечисленные имена, и перед ними не нужен префикс. Имя `math` при этом не появляется.

**Пример 3. random с seed.**

```python run
import random

random.seed(10)
first = random.randint(1, 6)
random.seed(10)
second = random.randint(1, 6)
print(first == second)
print(1 <= first <= 6)
```
```output
True
True
```

Разбор: `random.randint(a, b)` возвращает случайное целое от `a` до `b` включительно. После одинакового `random.seed(...)` последовательность одна и та же, поэтому два броска совпали. Без `seed` результат при каждом запуске разный.

**Пример 4. Свой модуль.** Допустим, в файле `greeting.py` написано:

```python
def hello(name):
    return f"Здравствуйте, {name}!"
```

А в файле `main.py`, лежащем рядом:

```python
import greeting

print(greeting.hello("Анна"))
```

Запуск `main.py` выведет `Здравствуйте, Анна!`. Разбор: `import greeting` находит файл `greeting.py` рядом с программой и выполняет его; функция становится доступной как `greeting.hello`.

**Пример 5. Неверное имя модуля.**

```python
import maths
```

```
ModuleNotFoundError: No module named 'maths'
```

Разбор: такого модуля нет - проверьте написание.

**Попробуйте.** В примере 1 замените `math.ceil(7 / 2)` на `math.ceil(8 / 2)` и предскажите результат. Затем выведите `random.randint(1, 6)` несколько раз с `seed` и без него.

## Подробнее

**Две формы подключения.**

| Запись | Что даёт | Как вызывать |
|---|---|---|
| `import math` | имя `math` | `math.sqrt(9)` |
| `from math import sqrt` | имя `sqrt` | `sqrt(9)` |
| `from math import sqrt, pi` | оба имени | `sqrt(9)`, `pi` |

Первая форма делает понятным, откуда взялась функция; вторая короче. Для коротких программ подойдут обе, главное - не смешивать: после `from math import sqrt` имени `math` нет.

**Где писать import.** В самом начале файла, до использования. Так сразу видно, от чего зависит программа.

**Полезное в math.**

| Имя | Смысл |
|---|---|
| `math.pi` | число пи |
| `math.sqrt(x)` | квадратный корень |
| `math.ceil(x)` | округление вверх до целого |
| `math.floor(x)` | округление вниз до целого |

Корень из отрицательного числа вызывает `ValueError: math domain error`.

**Полезное в random.**

| Имя | Смысл |
|---|---|
| `random.randint(a, b)` | целое от `a` до `b`, обе границы включены |
| `random.random()` | дробное от 0 до 1 |
| `random.seed(n)` | фиксирует последовательность |

**Свой модуль.** Файл `name.py` подключается как `import name`. Имя файла должно быть допустимым именем переменной: латиница, цифры, подчёркивание, без дефисов. Подключаемый файл должен лежать рядом с программой.

**Не называйте свой файл как стандартный модуль.** Если создать файл `random.py`, то `import random` подключит ваш файл вместо стандартного, и программа начнёт вести себя странно.

## Типичные ошибки

**1. Забыли import.**

```
NameError: name 'math' is not defined
```

Добавьте `import math` в начало файла.

**2. Опечатка в имени модуля.**

```
ModuleNotFoundError: No module named 'maths'
```

**3. Имя, которого нет в модуле.**

```
ImportError: cannot import name 'sqroot' from 'math' (unknown location)
```

Сообщение называет и имя, и модуль. Проверьте написание.

**4. Префикс после from.** После `from math import sqrt` запись `math.sqrt(9)` даёт `NameError`, потому что имя `math` не подключено.

**5. Забыли префикс после import.** После `import math` запись `sqrt(9)` даёт `NameError: name 'sqrt' is not defined`. Нужно `math.sqrt(9)`.

**6. Файл назван как стандартный модуль.** Файл `random.py` подменяет стандартный. Переименуйте его.

**7. Ожидают разных результатов с seed.** После `random.seed(5)` вызовы дают одинаковые значения при каждом запуске - так и задумано.

**8. Ceil и floor путают с round.** `round(3.5)` даёт 4, а `round(2.5)` даёт 2; `math.ceil(2.1)` всегда даёт 3. Для «сколько коробок нужно» подходит именно `ceil`.

## Итоги

* Модуль - файл с кодом; `import имя` подключает его, обращаться нужно через точку.
* `from модуль import имя` приносит в программу только это имя, без префикса.
* `math`: `pi`, `sqrt`, `ceil`, `floor`. `random`: `randint`, `random`, `seed`.
* Свой файл `name.py` подключается как `import name`.

## Для тех, кто уже программировал

* `import x` связывает имя модуля в текущем пространстве имён; `from x import y` связывает `y` напрямую. Звёздочный импорт (`from x import *`) не рекомендуется.
* Модули выполняются один раз при первом импорте и кэшируются в `sys.modules`.
* Поиск идёт по `sys.path`: сначала папка запускаемого скрипта, затем стандартная библиотека.
* Тень стандартного модуля собственным файлом - частая ловушка.
* Генератор `random` - детерминированный (Mersenne Twister), не пригоден для криптографии; для этого есть `secrets`.
* Пакеты, виртуальные окружения и `pip` в этот курс не входят.

## Что происходит внутри (необязательно)

При `import math` интерпретатор сначала смотрит в словарь уже загруженных модулей. Если модуля там нет, он ищет файл по списку путей, выполняет его сверху вниз и сохраняет полученное пространство имён как объект модуля.
Повторный `import` просто возвращает сохранённый объект, поэтому код модуля не запускается второй раз.
Часть стандартных модулей, например `math`, написана на C и подключается как встроенное расширение, но для вас она выглядит так же, как обычный модуль.
