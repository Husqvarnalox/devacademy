## Функция - именованный кусок программы

Когда один и тот же расчёт нужен в нескольких местах, его оформляют как **функцию**: даём куску кода имя и вызываем по имени. Функция принимает **параметры** (исходные данные)
и возвращает **результат**.

```python
def area(width, height):
    return width * height

print(area(3, 4))
```

Две вещи, которые путают с самого начала:

* `print` **показывает** значение, а `return` **отдаёт** его вызвавшему коду. Функция, которая только печатает, не может быть использована в расчётах: `area(3, 4) + 1` не получится,
  если `area` ничего не вернула. Функция без `return` отдаёт специальное значение `None` («ничего»).
* Имена внутри функции живут только внутри. Переменная, созданная в теле, исчезает после возврата; зато внутри можно читать «внешние» имена.

Параметры бывают разных видов: обычные (позиционные), именованные (`area(height=4, width=3)`), с умолчанием (`def hello(name="мир")`) и такие, которые можно передать только по имени.

Особая опасность - значения по умолчанию, которые можно изменять (список, словарь). Этому посвящена отдельная ловушка ниже: она ломает программы даже у опытных разработчиков.

## Что происходит при определении и вызове

**def - это исполняемая инструкция.** Когда интерпретатор выполняет `def f(...)`, он создаёт *объект функции* (с кодом тела, списком параметров и значениями по умолчанию) и привязывает его к имени `f`.
Тело не выполняется, пока функцию не вызовут. Значения по умолчанию вычисляются **один раз, в момент выполнения def**, и сохраняются в объекте функции (атрибут `f.__defaults__`).

**Вызов.** При вызове создаётся новое локальное пространство имён: параметры привязываются к переданным объектам (так же, как при присваивании `x = аргумент`, без копирования).
Поэтому изменение изменяемого объекта через параметр видно снаружи, а перепривязка параметра (`x = ...`) - нет.

**Результат.** `return значение` завершает функцию и отдаёт значение; `return` без значения и выход из конца функции отдают `None`. Можно вернуть несколько значений - на самом деле это кортеж: `return a, b`.

**Виды параметров.** В заголовке `def f(a, b=1, *args, c, d=2, **kwargs)`:
позиционные (`a`), с умолчанием (`b`), собирающие лишние позиционные (`*args`), только именованные (`c`, `d` - всё, что стоит после `*` или `*args`) и собирающие лишние именованные (`**kwargs`).
Параметры с умолчанием должны идти после параметров без умолчания (среди позиционных). Именованные аргументы при вызове пишут как `имя=значение`.

**Ловушка изменяемого умолчания.** Выражение `[]` в `def add(item, bucket=[])` выполняется один раз. Поэтому каждый вызов без `bucket` получает *один и тот же* список, и он накапливает элементы между вызовами.
Принятый приём: `bucket=None` и внутри `if bucket is None: bucket = []`.

**Области видимости (правило LEGB).** Имя ищется по цепочке: **L**ocal (локальное пространство функции) -> **E**nclosing (охватывающие функции) -> **G**lobal (модуль) -> **B**uilt-in (встроенные).
Присваивание внутри функции создаёт *локальное* имя для всей функции (это определяется при компиляции). Чтение внешнего имени допустимо; присваивание ему без объявления делает новое локальное и может привести к `UnboundLocalError`.
`global x` разрешает присваивать глобальному имени, `nonlocal x` - имени охватывающей функции. Использование `global` - признак того, что данные лучше передавать параметрами и возвращать результатом.

**Докстринг.** Строка-литерал сразу после заголовка становится документацией функции (`f.__doc__`), её показывает `help(f)`. Первая строка - краткое описание, что делает функция, а не как.

## Примеры

**Пример 1. print и return, значение None.**

```python run
def show(x):
    print("показываю", x)

def square(x):
    return x * x

result = show(3)
print(result)
print(square(4) + 1)
```
```output
показываю 3
None
17
```

**Пример 2. Виды параметров.**

```python run
def greet(name, greeting="Привет", *, loud=False):
    """Возвращает приветствие."""
    text = f"{greeting}, {name}!"
    return text.upper() if loud else text

print(greet("Анна"))
print(greet("Анна", "Здравствуйте"))
print(greet(name="Ян", greeting="Hi"))
print(greet("Анна", loud=True))
try:
    greet("Анна", "Привет", True)
except TypeError:
    print("loud нельзя передать позиционно")
print(greet.__doc__)
```
```output
Привет, Анна!
Здравствуйте, Анна!
Hi, Ян!
ПРИВЕТ, АННА!
loud нельзя передать позиционно
Возвращает приветствие.
```

**Пример 3. Ловушка изменяемого умолчания и её исправление.**

```python run
def bad(item, bucket=[]):
    bucket.append(item)
    return bucket

print(bad(1))
print(bad(2))
print(bad.__defaults__)

def good(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

print(good(1))
print(good(2))
```
```output
[1]
[1, 2]
([1, 2],)
[1]
[2]
```

Список в `bad.__defaults__` уже содержит и 1, и 2: он создан один раз и живёт в объекте функции.

**Пример 4. Изменение и перепривязка параметров.**

```python run
def change(items, n):
    items.append(0)
    n = n + 1

data = [1]
count = 5
change(data, count)
print(data, count)
```
```output
[1, 0] 5
```

**Пример 5. LEGB, global и nonlocal.**

```python run
x = "global"

def outer():
    x = "enclosing"
    def inner():
        return x          # ищется: Local -> Enclosing
    return inner()

print(outer())
print(x)

counter = 0
def make_counter():
    count = 0
    def step():
        nonlocal count
        count += 1
        return count
    return step

step = make_counter()
step()
print(step())
```
```output
enclosing
global
2
```

## Типичные ошибки

* **Печатать вместо возврата.** Функция с `print` внутри и без `return` не может участвовать в вычислениях: вызывающий код получает `None`. Если нужен результат - возвращайте его, а печатайте снаружи.
* **Изменяемое значение по умолчанию.** `def f(x, items=[])` создаёт список один раз; вызовы накапливают данные. Используйте `None` и создавайте объект внутри функции.
* **Забыть `return` в одной из веток.** Если `if` возвращает значение, а остальные ветки нет, функция вернёт `None` в «забытом» случае, и ошибка проявится далеко от места причины.
* **Присваивание глобальному имени без `global`.** `total += 1` в функции вызывает `UnboundLocalError`: имя стало локальным. Лучше передать значение параметром и вернуть новое.
* **Ожидать, что параметр - копия.** `def f(items): items.append(0)` меняет список вызывающего. Нужна копия - сделайте её явно: `items = list(items)`.
* **Одна и та же функция делает всё сразу (ввод, расчёт, вывод).** Такую функцию нельзя проверить автоматически. Выносите расчёт в функцию, возвращающую результат, а ввод-вывод оставляйте снаружи - именно поэтому тесты упражнения вызывают функции напрямую.
* **Перепутать порядок аргументов.** При нескольких параметрах одного типа (`clamp(5, 0, 10)`) именованные аргументы (`clamp(5, low=0, high=10)`) делают вызов читаемым и защищают от перестановки.

<!-- section: summary -->
## Итоги

* `def` создаёт объект функции во время выполнения; `return` отдаёт значение, без него функция возвращает `None`.
* Аргументы привязываются к параметрам без копирования: изменяемый объект меняется на месте, присваивание имени параметра снаружи не видно.
* Значения по умолчанию вычисляются один раз; для изменяемых используйте `None` и создавайте объект внутри.
* Имена ищутся по LEGB: Local, Enclosing, Global, Built-in; присваивание делает имя локальным, `global` и `nonlocal` меняют это.
* Параметры после `*` - только именованные; докстринг описывает назначение функции.
