## Повторение без копирования

Допустим, нужно напечатать числа от 1 до 100. Писать сто `print` нелепо. Для повторения существуют циклы - два вида, и они отвечают на разные вопросы.

**`while`** отвечает на вопрос «повторять, *пока* что-то истинно»:

```python
n = 10
while n > 0:
    n -= 3
```

Мы не знаем заранее, сколько будет повторений, - ровно столько, сколько понадобится, чтобы условие стало ложным.

**`for`** отвечает на вопрос «выполнить для *каждого* элемента»:

```python
for letter in "кот":
    print(letter)
```

Здесь число повторений определяется самим набором данных. Для счётных циклов есть `range`: `range(5)` даёт числа 0, 1, 2, 3, 4.

Внутри цикла можно досрочно выйти (`break`) или перейти к следующему шагу (`continue`). А у цикла может быть ветка `else`, которая выполнится, только если выхода по `break` не было, -
удобно для сценариев «искали и не нашли».

Главная опасность - цикл `while`, который никогда не завершается. Чтобы этого избежать, перед запуском задайте себе вопрос: «Что в теле цикла приближает условие к ложности?»

<!-- section: precise -->
## Как работают циклы

**while.** Проверяется условие; если оно истинно, выполняется тело, затем условие проверяется снова. Если условие ложно с самого начала, тело не выполнится ни разу.
Цикл завершится, только если тело меняет что-то, от чего зависит условие (или выполняет `break`). Типичная схема надёжного цикла: есть величина, которая на каждом шаге строго приближается к границе -
счётчик растёт, число уменьшается, список сокращается.

**for и протокол итерации.** Цикл `for x in obj` делает следующее: вызывает `iter(obj)` и получает *итератор*; затем снова и снова вызывает `next(итератор)`, привязывая результат к имени `x`, пока не возникнет
исключение `StopIteration` - это сигнал «элементы кончились», цикл завершается. Объект, у которого можно получить итератор, называется *итерируемым*: строки, списки, словари, множества, `range`, файлы.
Благодаря этому `for` одинаково работает со всем перечисленным, и вы не управляете индексами вручную.

**range.** `range(stop)`, `range(start, stop)`, `range(start, stop, step)` - последовательность целых чисел от `start` включительно до `stop` *не включая*. Это не список: объект хранит три числа и
вычисляет элементы по требованию, поэтому `range(10**12)` не занимает гигабайты. Отсюда же быстро работает `len(range(...))` и проверка `x in range(...)`.

**break / continue / else.** `break` немедленно завершает самый внутренний цикл. `continue` пропускает остаток тела и переходит к следующей итерации (для `while` - к проверке условия).
Ветка `else` у цикла выполняется, если цикл закончился «сам» (итератор исчерпан или условие `while` ложно) и **не** была прервана `break`. Если `break` сработал, `else` пропускается.

**Накопитель.** Типичный шаблон: до цикла создаём переменную (`total = 0`, `best = None`, `count = 0`), в цикле обновляем её, после цикла используем. Начальное значение должно быть нейтральным для операции: 0 для суммы,
1 для произведения, пустой список для сбора. Для максимума начальное значение - первый элемент или значение, заведомо меньшее любого (но корректнее брать первый элемент).

**Изменение коллекции во время обхода** - источник трудноуловимых ошибок: итератор списка помнит позицию, а не копию элементов, поэтому удаление элементов во время обхода пропускает соседние. Обходите копию или стройте новый список.

## Примеры

**Пример 1. range и накопитель.**

```python run
print(list(range(5)))
print(list(range(2, 10, 3)))
print(list(range(5, 0, -2)))
total = 0
for i in range(1, 5):
    total += i
print(total)
print(len(range(10**12)))
```
```output
[0, 1, 2, 3, 4]
[2, 5, 8]
[5, 3, 1]
10
1000000000000
```

**Пример 2. continue и break.**

```python run
for n in range(1, 10):
    if n % 2 == 0:
        continue
    if n > 7:
        break
    print(n)
```
```output
1
3
5
7
```

**Пример 3. else у цикла: поиск простого числа.** `else` выполняется, только когда делитель не найден и `break` не вызывался.

```python run
for n in [7, 8, 9, 11]:
    for d in range(2, n):
        if n % d == 0:
            print(n, "составное, делитель", d)
            break
    else:
        print(n, "простое")
```
```output
7 простое
8 составное, делитель 2
9 составное, делитель 3
11 простое
```

**Пример 4. Условие завершения в while.** Цикл гарантированно завершается, потому что `n` строго уменьшается.

```python run
n = 100
steps = 0
while n > 1:
    n //= 2
    steps += 1
print(steps)
```
```output
6
```

**Пример 5. Бесконечный цикл с явным выходом.** Конструкция `while True` допустима, если внутри есть `break`, который гарантированно сработает.

```python run
attempts = 0
while True:
    attempts += 1
    if attempts * attempts > 50:
        break
print(attempts)
```
```output
8
```

## Типичные ошибки

* **Бесконечный `while`.** Тело не меняет переменную из условия (`i` не увеличивается) или меняет в неверную сторону. Перед запуском проверьте: что строго приближает условие к ложности?
* **Ошибка на единицу (off-by-one).** `range(1, 5)` даёт 1..4, а не 1..5. Правая граница не включается; чтобы получить 1..N, пишите `range(1, N + 1)`.
* **Не обновили накопитель на последнем шаге.** Типичная версия: лучший результат обновляется только при смене символа, и серия в конце строки теряется. Обновляйте результат на каждом шаге либо после цикла.
* **Неверный начальный накопитель.** Для максимума отрицательных чисел `best = 0` даёт неверный ответ - 0 больше любого элемента. Стартуйте с первого элемента.
* **Путаница с `else`.** `else` у цикла не означает «иначе, если условие ложно» - он означает «цикл не был прерван break». Если `break` нет совсем, `else` выполнится всегда.
* **Изменение списка во время обхода.** `for x in items: items.remove(x)` пропускает элементы. Стройте новый список или обходите копию: `for x in items[:]`.
* **Вложенный цикл там, где достаточно одного.** Серии символов, суммы и счётчики решаются одним проходом с накопителем; вложенность превращает O(n) в O(n²).

## Итоги

* `while` - когда число повторений заранее неизвестно; `for` - когда нужно обойти элементы итерируемого объекта.
* `for` вызывает `iter()` и `next()` до `StopIteration`; `range` хранит только `start`, `stop`, `step` и не включает правую границу.
* `break` завершает цикл, `continue` пропускает остаток итерации, `else` выполняется только если `break` не было.
* Надёжный `while` всегда имеет шаг, приближающий условие к ложности; накопитель инициализируют нейтральным значением.
