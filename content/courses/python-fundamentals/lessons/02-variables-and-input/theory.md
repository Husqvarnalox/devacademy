## Переменная - имя для значения

Программе мало выводить фиксированный текст: ей нужно работать с данными, которые меняются. Чтобы использовать значение
несколько раз и не писать его заново, ему дают имя. Такое имя вместе со значением называется **переменной**.

Переменная создаётся **присваиванием**:

```python
city = "Казань"
```

Читать эту строку нужно справа налево: значение `"Казань"` записывается под именем `city`. Знак `=` здесь не равенство из
математики, а команда «запомни». После этого везде, где нужно значение, можно писать `city`.

Второй источник данных - человек. Команда `input()` приостанавливает программу, ждёт, пока человек введёт строку и нажмёт Enter,
и **возвращает** введённый текст. «Возвращает» значит: сама команда превращается в это значение. Обычно его сразу кладут в переменную:

```python
name = input()
```

Зачем это нужно: так одна и та же программа работает с разными данными. Один раз описали, что делать с `name`, а имя подставит человек.

<!-- section: examples -->
## Примеры

**Пример 1. Создание и использование переменной.**

```python run
product = "Молоко"
shop = "Магнит"
print(product, "продаётся в магазине", shop)
```
```output
Молоко продаётся в магазине Магнит
```

Разбор: первые две строки создают переменные `product` и `shop`. В третьей `print` получает три значения: имя `product`
(без кавычек, поэтому берётся значение), текст в кавычках и имя `shop`.

**Пример 2. Переменная меняется, пока программа идёт сверху вниз.**

```python run
status = "собираем заказ"
print(status)
status = "заказ отправлен"
print(status)
copy = status
status = "заказ доставлен"
print(copy)
print(status)
```
```output
собираем заказ
заказ отправлен
заказ отправлен
заказ доставлен
```

Разбор: повторное присваивание заменяет значение под тем же именем. Строка `copy = status` записывает в `copy` то значение,
которое в `status` лежит в этот момент. Позднее изменение `status` на `copy` не влияет.

**Пример 3. Ввод. Эту программу запускать не будем: она ждёт, пока вы что-то введёте.**

```python
name = input()
print("Здравствуйте,", name)
```

Если человек введёт `Анна`, на экране появится `Здравствуйте, Анна`. Первая строка останавливает программу до ввода, вторая использует
введённое значение. Если указать текст в скобках, `input("Ваше имя: ")` сначала выведет его как приглашение, и только потом начнёт ждать.
В упражнениях этого курса приглашения не используют, потому что проверка сравнивает весь вывод программы.

**Попробуйте.** В примере 2 поменяйте местами строки `copy = status` и `status = "заказ доставлен"` и предскажите, что выведет программа.

## Подробнее

**Порядок выполнения.** Присваивание выполняется так: сначала вычисляется значение справа от `=`, затем оно записывается под имя слева.
Поэтому переменную нельзя использовать раньше, чем ей присвоили значение: строка выше должна выполниться первой.

**Правила имён.** Имя состоит из латинских букв, цифр и знака подчёркивания, не начинается с цифры и не может совпадать со
служебными словами языка (например, `if`, `for`). Регистр важен: `city` и `City` - разные имена. Python допускает и кириллицу в именах,
но принято писать латиницей. Для нескольких слов используют подчёркивания: `user_name`, `total_price`.

**Выбирайте имена по смыслу.** `price` понятнее, чем `p`. Код читают чаще, чем пишут, и хорошее имя избавляет от комментария.

**Что возвращает input.** Всегда строку - даже если человек ввёл цифры. Строка `"7"` - это текст из одного символа, а не число.
Как работать с числами, разбирается в следующем уроке.

**Сколько строк читает input.** Один вызов - одна строка, то есть всё до нажатия Enter. Символ перевода строки в значение не входит.
Чтобы прочитать две строки, нужны два вызова.

## Типичные ошибки

**1. Опечатка в имени переменной.**

```python
name = "Анна"
print(nme)
```

```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(nme)
          ^^^
NameError: name 'nme' is not defined. Did you mean: 'name'?
```

Что произошло: имени `nme` в программе нет. Как исправить: проверьте написание, Python сам подсказывает близкое имя. Как заметить: смотрите на строку 2 в сообщении и сравните слово после `name` с тем, что вы создавали.

**2. Использование имени до присваивания.** Если `print(city)` стоит выше, чем `city = "Казань"`, возникнет тот же `NameError`: на момент выполнения строки имени ещё нет.

**3. Перепутали имя и текст.** `print("name")` выведет слово name, а не значение переменной. Для значения кавычки не нужны.

**4. Ввод закончился раньше, чем программа его ждала.**

```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    name = input()
EOFError: EOF when reading a line
```

`EOFError` означает, что данных для `input()` больше нет. В проверках это случается, когда в программе `input()` вызывается чаще, чем во вводе строк. Сверьте число вызовов с условием задачи.

**5. Приглашение в input в упражнениях.** `input("Имя: ")` выводит слово «Имя: » в общий вывод, и тест, ожидающий только значения, не сойдётся.

## Итоги

* Переменная - имя, под которым хранится значение. `имя = значение` создаёт или заменяет его.
* Программа идёт сверху вниз, поэтому переменная должна быть создана раньше, чем использована.
* `input()` читает одну строку, введённую человеком, и возвращает её как текст.
* Имена выбирают по смыслу, регистр различается.

## Для тех, кто уже программировал

* Объявлений нет: переменная появляется при первом присваивании, тип у неё не фиксируется, а определяется значением. Позже под тем же именем можно записать значение другого типа.
* Строго говоря, имя связывается со значением (объектом), а не «содержит» его; подробности важны, когда появятся списки.
* `input()` всегда возвращает `str` без символа перевода строки; при конце ввода бросает `EOFError`.
* Нет констант на уровне языка: имена ЗАГЛАВНЫМИ принято считать константами лишь по соглашению.
* Область видимости переменной определяется функциями, а не блоками; об этом в уроке про функции.
* Стиль PEP 8: `snake_case` для переменных.

## Что происходит внутри (необязательно)

Присваивание в Python не копирует значение в «ящик» с именем. Имя - это ссылка на объект, который хранится в памяти интерпретатора;
`copy = status` делает так, что два имени указывают на один и тот же объект. Для строк это незаметно, потому что строки нельзя менять
на месте. Разница проявится, когда вы познакомитесь со списками. Именно поэтому в примере 2 перезапись `status` не изменила `copy`:
имя `status` просто стало указывать на другую строку.
