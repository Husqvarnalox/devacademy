## Имя - это ярлык на объекте

Во многих языках говорят «переменная - это коробка, в которой лежит значение». Для Python эта картинка вводит в заблуждение.
Точнее так: **значения - это объекты**, а **имя - это ярлык**, который вы приклеили к объекту.

```python
age = 30
```

Эта строка не кладёт 30 в ящик по имени `age`. Она создаёт (или находит) объект «число 30» и привязывает к нему ярлык `age`.
Один и тот же объект может иметь несколько ярлыков:

```python
a = [1, 2]
b = a
```

Здесь не два списка, а один список с двумя ярлыками. Если изменить список через `b`, через `a` вы увидите то же самое изменение:
вы же смотрите на один и тот же объект.

Данные в программу можно получить от пользователя функцией `input()`. Она останавливает программу, ждёт строку и возвращает её.
Важно: возвращается всегда **строка**, даже если пользователь набрал цифры. Чтобы работать с ней как с числом, её нужно явно преобразовать: `int("42")`.

<!-- section: precise -->
## Что на самом деле происходит

**Присваивание** `name = expression` выполняется так: сначала вычисляется правая часть и получается объект; затем в текущем пространстве имён
(для кода на верхнем уровне - это словарь глобальных имён модуля) имя `name` связывается с этим объектом. Если имя уже существовало, старая связь теряется.
Объект при этом не копируется и не меняется.

**Идентичность и равенство.** У каждого объекта есть идентичность (функция `id()`), тип и значение.
Оператор `==` сравнивает *значения* (вызывает специальный метод равенства), оператор `is` сравнивает *идентичность*: «это один и тот же объект?».
Два списка с одинаковым содержимым равны (`==`), но не идентичны (`is`), если созданы отдельно. `is` стоит применять почти исключительно для `None`: `if x is None`.
Результат `is` для небольших чисел и строк зависит от оптимизаций реализации (повторного использования объектов), поэтому на него полагаться нельзя.

**Изменяемые и неизменяемые объекты.** Числа, строки, кортежи неизменяемы (immutable): любая «модификация» создаёт новый объект.
Списки, словари, множества изменяемы (mutable): их можно поменять на месте, и все имена, ссылающиеся на объект, это увидят.
Поэтому `y = y + 1` для числа не влияет на другое имя, а `lst.append(3)` влияет на все имена того же списка.

**Составное присваивание** `x += 1` для неизменяемых типов равносильно `x = x + 1` (новый объект). Для списков `lst += [4]` изменяет список на месте.

**input().** Функция читает строку из stdin до перевода строки и возвращает её *без* символа перевода строки. Если ввод закончился, возникает `EOFError`.
Преобразование: `int(s)` принимает строку с необязательными пробелами и знаком; `int("3.5")` или `int("abc")` дают `ValueError`.

**Имена.** Имя состоит из букв, цифр и `_`, не начинается с цифры, не совпадает с ключевым словом (`if`, `for`, `class`...). Регистр различается.
По соглашению PEP 8 имена переменных пишут в `snake_case`. Не затеняйте встроенные имена: после `list = [1]` вызвать `list("abc")` уже нельзя.

## Примеры

**Пример 1. Два имени - один объект.**

```python run
a = [1, 2]
b = a
b.append(3)
print(a)
print(a is b)
print(a == b)
```
```output
[1, 2, 3]
True
True
```

**Пример 2. Числа неизменяемы.** `y = y + 1` создаёт новый объект и перепривязывает `y`, а `x` остаётся на старом.

```python run
x = 10
y = x
y = y + 1
print(x, y)
```
```output
10 11
```

**Пример 3. Равны, но не идентичны.**

```python run
p = [1, 2]
q = [1, 2]
print(p == q)
print(p is q)
r = p
print(p is r)
```
```output
True
False
True
```

**Пример 4. Строка из ввода - это не число.** Пользовательский ввод заменён обычной строкой, чтобы пример работал без клавиатуры.

```python run
s = "21"
print(s + s)
print(int(s) + int(s))
print(type(s).__name__, type(int(s)).__name__)
```
```output
2121
42
str int
```

Так выглядит чтение в настоящей программе (этот фрагмент не запускается автоматически, он ждёт ввод):

```python
name = input()
year = int(input())
print("Привет,", name)
```

## Типичные ошибки

* **Считать `b = a` копированием.** Для списков и словарей это тот же объект, и изменение через одно имя видно через другое.
  Копию создают явно: `b = a.copy()` или `b = a[:]` (подробнее - в уроке про списки).
* **Складывать числа из `input()` без преобразования.** `input() + input()` склеит строки: из `"2"` и `"3"` получится `"23"`. Приводите тип сразу: `int(input())`.
* **Сравнивать значения через `is`.** `if x is 5` работает случайно, потому что зависит от оптимизации. Для сравнения значений - `==`; `is` - для `None`.
* **Перезаписать встроенное имя.** Назвав переменную `list`, `str` или `sum`, вы лишаетесь встроенной функции в этой области видимости. Выбирайте осмысленные имена: `items`, `text`, `total`.
* **Ожидать, что `int()` понимает дробный текст.** `int("3.5")` вызывает `ValueError`: сначала `float("3.5")`, затем при необходимости `int(...)` (с отбрасыванием дробной части).
* **Делать `split()` для имени из нескольких слов.** `input()` уже вернул всю строку; разрезание превращает её в список слов, а это другой тип.

<!-- section: summary -->
## Итоги

* Присваивание привязывает имя к объекту; объект не копируется.
* Изменяемые объекты (списки, словари) видны через все имена; неизменяемые (числа, строки) «меняются» только созданием нового объекта.
* `==` сравнивает значения, `is` - идентичность; `is` обычно используют только с `None`.
* `input()` всегда возвращает `str`; преобразование в число делается явно через `int()` или `float()`.
