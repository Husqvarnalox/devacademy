## Словарь - данные, найденные по ключу

В списке элементы находят по номеру. Но номер не всегда удобен: цену молока лучше искать по слову «молоко», а не по позиции. Для такого поиска есть **словарь** (`dict`).
Он хранит **пары**: **ключ** (по чему ищем) и **значение** (что нашли). Пары записываются в фигурных скобках через двоеточие:

```python
prices = {"хлеб": 45, "молоко": 80}
print(prices["молоко"])
```

В квадратных скобках пишут не номер, а ключ. Ключ в словаре не повторяется, а значением может быть что угодно. Если ключа нет, `prices["сыр"]` вызовет ошибку `KeyError`;
безопасная альтернатива - `prices.get("сыр", 0)`: она вернёт 0, если ключа нет.

Второй инструмент - **множество** (`set`). Это набор значений, в котором каждое значение встречается один раз и порядка нет. Множество удобно, когда важно
только «есть или нет»: убрать повторы, найти общие элементы двух наборов.

```python
colors = {"красный", "синий", "красный"}
print(len(colors))
```

Здесь выведется 2: повторы исчезли.

Зачем это нужно: подсчёт слов, учёт товаров по названию, проверка «встречался ли уже» - в этих задачах словарь и множество проще и быстрее списка.

## Примеры

**Пример 1. Создание, чтение, изменение.**

```python run
prices = {"хлеб": 45, "молоко": 80}
print(prices["хлеб"])
prices["сыр"] = 300
prices["хлеб"] = 50
print(prices)
print(len(prices))
print("сыр" in prices, "яхта" in prices)
print(prices.get("яхта"))
print(prices.get("яхта", 0))
```
```output
45
{'хлеб': 50, 'молоко': 80, 'сыр': 300}
3
True False
None
0
```

Разбор: присваивание по новому ключу добавляет пару, по существующему - заменяет значение. Оператор `in` проверяет ключи. `get` без второго аргумента возвращает `None`, если ключа нет.

**Пример 2. Обход словаря.**

```python run
stock = {"яблоки": 12, "груши": 5}
for name in stock:
    print(name)
for name, qty in stock.items():
    print(f"{name}: {qty} шт.")
print(sum(stock.values()))
```
```output
яблоки
груши
яблоки: 12 шт.
груши: 5 шт.
17
```

Разбор: цикл `for name in stock` обходит ключи. Метод `items()` выдаёт пары, и две переменные `name, qty` получают по одной части пары. `values()` - значения.

**Пример 3. Подсчёт вхождений.**

```python run
words = ["да", "нет", "да", "да"]
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts)
```
```output
{'да': 3, 'нет': 1}
```

Разбор: для нового слова `get` вернёт 0, и в словарь записывается 1. Для известного слова берётся накопленное число и увеличивается на единицу.

**Пример 4. Множества.**

```python run
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(sorted(a & b))
print(sorted(a | b))
print(sorted(a - b))
unique = set([5, 1, 5, 2, 1])
unique.add(9)
print(sorted(unique), len(unique))
print(3 in a)
```
```output
[3, 4]
[1, 2, 3, 4, 5]
[1, 2]
[1, 2, 5, 9] 4
True
```

Разбор: `&` - пересечение (есть в обоих), `|` - объединение, `-` - разность (есть в первом, но нет во втором). `set(список)` убирает повторы. Порядок элементов в множестве не определён, поэтому для вывода их сортируют.

**Попробуйте.** В примере 3 добавьте в `words` слово `"нет"` и предскажите, как изменится словарь.

## Подробнее

**Ключи.** Ключом может быть строка, число или другое значение, которое нельзя изменить. Список ключом быть не может: `{[1]: 2}` вызовет `TypeError`. Значением может быть что угодно, в том числе список или другой словарь.

**Порядок.** Словарь помнит порядок добавления пар, и цикл обходит их в этом порядке. Множество порядка не гарантирует.

**Основные операции со словарём.**

| Запись | Что делает |
|---|---|
| `d[key]` | значение; нет ключа - `KeyError` |
| `d[key] = v` | добавить или заменить |
| `d.get(key, default)` | значение или `default` (по умолчанию `None`) |
| `key in d` | есть ли такой ключ |
| `d.pop(key)` | удалить пару и вернуть значение |
| `del d[key]` | удалить пару |
| `d.keys()`, `d.values()`, `d.items()` | ключи, значения, пары |

**Пустые структуры.** Пустой словарь - `{}`. Пустое множество - только `set()`, потому что `{}` уже занято словарём.

**Множества.** `add(x)` добавляет, `remove(x)` удаляет (ошибка, если нет), `x in s` проверяет. Операции `&`, `|`, `-` создают новые множества. Элементами множества, как и ключами, могут быть только неизменяемые значения.

**Что выбрать.** Нужен порядок и повторы - список. Нужно искать значение по имени - словарь. Нужно только «есть или нет», уникальность, общие элементы - множество. Проверка `x in s` для множества и словаря быстрая, а для списка медленнее: Python просматривает его целиком.

**Вложенные структуры.** `{"Анна": [4, 5], "Борис": [3]}` - словарь со списками. `grades["Анна"].append(5)` меняет список внутри.

## Типичные ошибки

**1. Отсутствующий ключ.**

```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(d["b"])
          ~^^^^^
KeyError: 'b'
```

Ключа `'b'` нет. Проверьте `if "b" in d:` или используйте `d.get("b", значение)`. Для подсчёта вхождений нельзя писать `counts[w] = counts[w] + 1` для нового слова: ключа ещё нет.

**2. Список как ключ.**

```
TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
```

Ключи должны быть неизменяемыми: используйте строку, число, а вместо списка - строку, склеенную из значений.

**3. `{}` как пустое множество.** `s = {}` создаёт словарь, и `s.add(1)` упадёт с `AttributeError`. Для множества: `s = set()`.

**4. Ожидание порядка у множества.** Вывод `print({3, 1, 2})` не гарантирует порядка. Если порядок нужен, используйте `sorted(...)`.

**5. Перепутаны ключ и значение.** `prices["80"]` ищет ключ 80, а не цену. Спрашивайте: «по чему ищу?»

**6. Изменение словаря во время обхода.** Добавление или удаление пар в `for key in d:` приводит к ошибке `RuntimeError`. Сначала соберите список ключей (`list(d)`).

**7. `add` у списка.** `AttributeError: 'list' object has no attribute 'add'` - `add` есть у множества, у списка метод называется `append`.

## Итоги

* Словарь - пары «ключ -> значение»; `d[key]`, `d[key] = v`, `get`, `in`, `items()`.
* Для подсчёта: `counts[x] = counts.get(x, 0) + 1`.
* Множество хранит уникальные значения без порядка; `&`, `|`, `-` дают общие, все и разницу.
* `{}` - пустой словарь, `set()` - пустое множество.

## Для тех, кто уже программировал

* `dict` - хеш-таблица; сохраняет порядок вставки (гарантировано с 3.7). Ключи должны быть хешируемыми: неизменяемые `str`, `int`, `tuple` из них.
* Нет автоматического значения для отсутствующего ключа: `d[k]` бросает `KeyError`, `get` возвращает `None` или значение по умолчанию. В стандартной библиотеке есть `collections.defaultdict` и `Counter` для подсчётов.
* `set` - неупорядоченное множество хешируемых элементов, операции `&`, `|`, `-`, `^` соответствуют математическим. Пустое множество - `set()`.
* Итерация по `dict` даёт ключи; `items()` возвращает пары, которые распаковываются в `for k, v in ...`.
* Сложность `in` для `dict` и `set` в среднем O(1), для `list` - O(n).
* Изменение словаря во время итерации по нему запрещено (`RuntimeError`).

<!-- section: deep-dive -->
## Что происходит внутри (необязательно)

Словарь и множество построены на **хеш-таблице**. Для каждого ключа вычисляется число (хеш), по которому интерпретатор сразу находит нужную ячейку массива,
не просматривая все пары. Поэтому поиск почти не замедляется с ростом данных. Хеш можно вычислить только у неизменяемых значений: если бы ключ-список изменился после вставки,
его хеш поменялся бы, и пара «потерялась» бы. Именно поэтому списки и сами словари ключами быть не могут.
