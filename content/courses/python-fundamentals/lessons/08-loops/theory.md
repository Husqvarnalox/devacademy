## Повторить известное число раз

Цикл `while` подходит, когда неизвестно, сколько повторений понадобится. Но часто число повторений известно: обойти 7 дней недели, вывести 10 строк таблицы.
Для таких случаев есть цикл `for` («для»). Он сам заводит переменную цикла и сам её меняет, поэтому забыть увеличить счётчик невозможно.

Вместе с `for` обычно используют встроенную функцию `range` («диапазон»). Она выдаёт последовательность целых чисел:

```python
for i in range(3):
    print(i)
```

Здесь `i` по очереди получает значения `0`, `1`, `2`. Запомните: счёт начинается с нуля, а верхняя граница в диапазон **не входит**.

Цикл можно разместить внутри другого цикла. Такая конструкция называется **вложенными циклами**: внешний цикл задаёт, например, строки таблицы, а внутренний - столбцы в строке. Для каждой итерации внешнего цикла внутренний выполняется целиком.

Зачем это нужно: таблицы, расписания, перебор всех пар значений - всё это записывается парой коротких циклов вместо десятков одинаковых строк.

<!-- section: examples -->
## Примеры

**Пример 1. range с одним числом.**

```python run
for i in range(4):
    print("Повторение", i)
```
```output
Повторение 0
Повторение 1
Повторение 2
Повторение 3
```

Разбор: `range(4)` - числа 0, 1, 2, 3. Тело выполнилось четыре раза, переменная `i` менялась автоматически.

**Пример 2. Начало, конец и шаг.**

```python run
for day in range(1, 4):
    print("День", day)
for n in range(10, 0, -3):
    print(n)
for even in range(0, 7, 2):
    print(even)
```
```output
День 1
День 2
День 3
10
7
4
1
0
2
4
6
```

Разбор: `range(1, 4)` - от 1 до 3 включительно, четвёрка не входит. `range(10, 0, -3)` - начинаем с 10, шаг минус три, останавливаемся, не дойдя до 0. `range(0, 7, 2)` - от 0 с шагом 2: 0, 2, 4, 6.

**Пример 3. Накопитель в for.**

```python run
total = 0
for price in range(100, 401, 100):
    total = total + price
print(total)
```
```output
1000
```

Разбор: значения 100, 200, 300, 400 складываются в `total`. Верхняя граница 401, а не 400, чтобы 400 вошло в диапазон.

**Пример 4. Вложенные циклы.**

```python run
for row in range(1, 4):
    for col in range(1, 4):
        print(f"[{row * col}]", end="")
    print()
```
```output
[1][2][3]
[2][4][6]
[3][6][9]
```

Разбор: для каждого `row` внутренний цикл выводит три числа в скобках в одну строку (`end=""` убирает перевод строки, поэтому числа идут подряд). Пустой `print()` после внутреннего цикла завершает строку. Всего `print(row * col ...)` вызван 3 × 3 = 9 раз.

**Попробуйте.** В примере 4 замените `range(1, 4)` во внутреннем цикле на `range(1, 6)`. Сколько чисел будет в каждой строке?

## Подробнее

**Три формы range.** `range(stop)` - от 0 до `stop - 1`. `range(start, stop)` - от `start` до `stop - 1`. `range(start, stop, step)` - с шагом `step` (может быть отрицательным). Количество значений в `range(start, stop)` равно `stop - start`, если оно положительно.
Пустой диапазон (например, `range(5, 1)` или `range(0)`) допустим: цикл просто не выполнится.

**Аргументы `range` - целые числа.** Дробные не принимаются. Если число пришло из `input()`, его сначала переводят через `int(...)`.

**Переменная цикла остаётся после цикла.** После `for i in range(3)` переменная `i` равна 2 и доступна. Но полагаться на это не стоит.

**Не меняйте переменную цикла внутри тела.** Присваивание `i = 10` в теле влияет только на текущий шаг: на следующем шаге `for` снова подставит значение из диапазона.

**for или while.** `for` - когда число повторений известно заранее или значения идут по порядку. `while` - когда нужно повторять до события (ввод стоп-слова, достижение результата).

**Вложенные циклы.** Общее число выполнений внутреннего тела равно произведению чисел повторений. Для 100 × 100 это уже 10 000 повторений; цикл в цикле быстро становится дорогим.

**Имена переменных.** Для счётчиков принято `i`, `j`. Если у значения есть смысл, называйте по смыслу: `row`, `day`.

**Вывод в одну строку.** `print(..., end="")` не переводит строку. В конце ряда нужен пустой `print()`.

## Типичные ошибки

**1. Ошибка на единицу.** Нужны числа от 1 до `n` включительно, а написано `range(1, n)`: последнее значение потеряно. Верно: `range(1, n + 1)`.

**2. Дробное число в range.**

```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    for i in range(3.5):
               ~~~~~^^^^^
TypeError: 'float' object cannot be interpreted as an integer
```

То же случится, если передать строку: `range("3")`. Исправление: `range(int(text))`.

**3. Нет двоеточия или отступа.** Работает так же, как для `if` и `while`: `SyntaxError: expected ':'` или `IndentationError`.

**4. Внутренний `print()` не на своём уровне.** Если пустой `print()` стоит с тем же отступом, что и вложенный `for`, а не внутри внешнего цикла, перевод строки выполнится один раз в конце, а не после каждой строки таблицы. Сравните отступы строк: кто в каком цикле.

**5. Неверный шаг.** `range(10, 0)` без отрицательного шага пуст. Для отсчёта вниз нужен третий параметр.

**6. Накопитель внутри внешнего цикла.** Если `total = 0` стоит внутри внешнего цикла, сумма обнуляется на каждой итерации. Создавайте накопитель до циклов.

<!-- section: summary -->
## Итоги

* `for i in range(n)` - `n` повторений со значениями `0 ... n-1`.
* `range(a, b)` - от `a` до `b - 1`; `range(a, b, шаг)` - с шагом, возможно отрицательным.
* Вложенные циклы строят таблицы: внешний - строки, внутренний - столбцы; тело выполняется произведение раз.
* `for` выбирают для известного числа повторений, `while` - для повторения до события.

## Для тех, кто уже программировал

* `for` в Python - это обход, а не трёхчастный `for(;;)`. `range` - ленивая последовательность: не создаёт все числа сразу.
* Диапазон полуоткрытый: `[start, stop)`. Длина равна `stop - start` при шаге 1.
* Счётчика `i++` нет; переменную цикла Python назначает сам на каждой итерации.
* Переменная цикла живёт в окружающей области видимости и остаётся после цикла.
* `for` умеет обходить и другие последовательности (строки, списки); в этом уроке только `range`.
* Метки для `break` из вложенных циклов нет.

## Что происходит внутри (необязательно)

`range` не хранит числа: он запоминает `start`, `stop`, `step` и вычисляет очередное значение по требованию, поэтому `range(1_000_000_000)` занимает мало памяти.
Цикл `for` работает с любым объектом, который умеет выдавать значения по одному (**итератор**): на каждой итерации `for` просит у такого объекта следующее значение
и останавливается, когда они закончились. Эту идею вы увидите ещё раз, когда будете обходить строки, списки и словари.
