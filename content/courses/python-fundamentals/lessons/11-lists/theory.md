## Список - несколько значений под одним именем

Переменная, которую вы уже знаете, хранит одно значение. Но данных обычно много: цены в корзине, оценки класса, имена гостей. Для набора значений есть **список** (`list`).
Он записывается в квадратных скобках, значения разделяются запятыми:

```python
prices = [120, 45, 300]
```

Каждое значение в списке называется **элементом**. Элементы нумеруются с нуля, как символы в строке, и доступ к ним тот же: `prices[0]`, `prices[-1]`, срез `prices[1:]`.
Длину списка даёт `len(prices)`.

Главное отличие от строки: список **изменяемый**. В него можно добавить элемент, удалить, заменить - сам список при этом остаётся тем же объектом:

```python
prices.append(80)
prices[0] = 100
```

Список удобно обходить циклом `for`: он по очереди даёт элементы, и счётчик заводить не нужно. А для частых задач есть готовые функции: `sum` (сумма), `min`, `max`, `sorted` (отсортированная копия).

Зачем это нужно: с одним списком работает одна и та же программа для трёх значений и для трёх тысяч.

<!-- section: examples -->
## Примеры

**Пример 1. Создание, индексы, изменение.**

```python run
prices = [120, 45, 300]
print(prices)
print(prices[0], prices[-1], len(prices))
prices.append(80)
prices[1] = 50
print(prices)
print(prices[1:3])
print(300 in prices, 5 in prices)
```
```output
[120, 45, 300]
120 300 3
[120, 50, 300, 80]
[50, 300]
True False
```

Разбор: `append` добавляет в конец. `prices[1] = 50` заменяет элемент по индексу. Срез `prices[1:3]` - новый список из элементов 1 и 2. Оператор `in` проверяет наличие значения.

**Пример 2. Обход, сумма, минимум, максимум.**

```python run
marks = [4, 5, 3, 5, 4]
total = 0
for mark in marks:
    total = total + mark
print(total, sum(marks))
print(min(marks), max(marks))
print(sum(marks) / len(marks))
```
```output
21 21
3 5
4.2
```

Разбор: `for mark in marks` даёт элементы по порядку. Цикл и `sum` дают один результат. Среднее равно сумме, делённой на количество.

**Пример 3. Удаление и вставка.**

```python run
guests = ["Анна", "Борис", "Вера", "Глеб"]
guests.remove("Вера")
last = guests.pop()
print(last)
guests.insert(0, "Дарья")
print(guests)
print(guests.index("Борис"))
```
```output
Глеб
['Дарья', 'Анна', 'Борис']
2
```

Разбор: `remove` удаляет первое найденное значение. `pop()` убирает последний элемент и возвращает его. `insert(0, x)` вставляет на позицию 0. `index` находит позицию значения.

**Пример 4. Сортировка и ссылки.**

```python run
nums = [3, 1, 2]
ordered = sorted(nums)
print(nums, ordered)
nums.sort()
print(nums)
print(sorted(nums, reverse=True))
a = [1, 2]
b = a
c = a[:]
b.append(3)
print(a, b, c)
```
```output
[3, 1, 2] [1, 2, 3]
[1, 2, 3]
[3, 2, 1]
[1, 2, 3] [1, 2, 3] [1, 2]
```

Разбор: `sorted` возвращает новый список, `nums.sort()` сортирует сам список. Присваивание `b = a` копирует не список, а **ссылку**: оба имени указывают на один список, поэтому `append` через `b` виден в `a`. Срез `a[:]` создаёт настоящую копию, она не изменилась.

**Пример 5. Список из строки.** Метод `split()` разрезает строку по пробелам на список слов. Запускать пример нельзя, он читает ввод.

```python
numbers = []
for word in input().split():
    numbers.append(int(word))
print(sum(numbers))
```

Для ввода `4 5 6` программа выведет `15`.

**Попробуйте.** В примере 4 замените `c = a[:]` на `c = a` и предскажите вывод последней строки.

## Подробнее

**Основные операции.**

| Запись | Что делает |
|---|---|
| `len(x)` | число элементов |
| `x.append(v)` | добавить в конец |
| `x.insert(i, v)` | вставить перед индексом `i` |
| `x.remove(v)` | удалить первое значение `v`; нет такого - `ValueError` |
| `x.pop()` / `x.pop(i)` | убрать и вернуть последний (или `i`-й) элемент |
| `x.index(v)` | индекс первого `v`; нет такого - `ValueError` |
| `x.count(v)` | сколько раз встречается `v` |
| `v in x`, `v not in x` | проверка наличия |
| `sorted(x)`, `x.sort()` | отсортированная копия / сортировка на месте |
| `x.reverse()`, `x[::-1]` | разворот на месте / новый развёрнутый список |

**Методы, меняющие список, возвращают `None`.** Поэтому `x = x.append(5)` оставит в `x` значение `None`. Эти методы изменяют список и ничего не возвращают.

**Индексы и срезы** работают как у строк: индекс вне границ - `IndexError`, срез вне границ ошибки не вызывает. Но присваивание по индексу (`x[0] = 5`) для списков разрешено.

**Ссылки.** Имя списка указывает на объект. Присваивание `b = a` создаёт второе имя того же списка. Если нужна независимая копия, пишите `b = a[:]` или `b = list(a)`.
Это же касается передачи списка в функцию: функция получает тот же список и может его изменить. Если функция не должна менять исходный список, она сначала создаёт копию или использует `sorted`.

**Списки внутри списков.** Элементом может быть любое значение, в том числе другой список: `[[1, 2], [3, 4]]`. Элемент таблицы берётся двумя индексами: `table[1][0]`.

**Обход.** `for x in items:` - самый простой способ пройти по всем элементам. Не изменяйте длину списка, пока по нему идёте циклом.

**Пустой список.** `[]` допустим. `sum([])` равно 0, а `min([])` и `max([])` вызывают `ValueError`, поэтому пустой список проверяют заранее.

**Склеивание.** `[1, 2] + [3]` даёт `[1, 2, 3]`, `[0] * 3` даёт `[0, 0, 0]`.

## Типичные ошибки

**1. Индекс за пределами списка.**

```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(a[3])
          ~^^^
IndexError: list index out of range
```

В списке из трёх элементов последний индекс - 2. Для последнего элемента надёжнее `a[-1]`.

**2. Несуществующий метод.**

```
AttributeError: 'list' object has no attribute 'add'
```

Для добавления в список используется `append`. Метод `add` есть у множеств, о них в следующем уроке.

**3. Сохранение результата метода, который возвращает `None`.**

```python
x = [3, 1, 2]
x = x.sort()
print(x)
```

Выведет `None`: `sort` сортирует на месте и ничего не возвращает. Верно: `x.sort()` отдельной строкой или `x = sorted(x)`.

**4. Минимум или максимум пустого списка.**

```
ValueError: max() iterable argument is empty
```

Проверьте длину перед вызовом: `if len(items) > 0:`.

**5. Копия, которая не копия.** `b = a` и затем `b.append(1)` меняет и `a`. Для копии: `a[:]`.

**6. Сумма нечисловых значений.**

```
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Это сообщение появится, например, при `sum(["a", "b"])`: `sum` предназначена для чисел.

**7. Строки из `split()` - это строки.** `"5 6".split()` даёт `["5", "6"]`. Для сложения превратите элементы в числа через `int`.

## Итоги

* Список - изменяемая последовательность элементов в `[]`; индексы и срезы такие же, как у строк.
* `append`, `insert`, `remove`, `pop` меняют список; `sorted` и срезы создают новый.
* `len`, `sum`, `min`, `max`, `in` и цикл `for` покрывают большую часть задач.
* Имя указывает на список, а не содержит его: `b = a` не копирует; копия - `a[:]`.

<!-- section: programmer -->
## Для тех, кто уже программировал

* `list` - динамический массив ссылок на объекты; элементы могут быть разных типов. Не путать с массивами фиксированного типа.
* Присваивание и передача в функцию копируют ссылку, а не содержимое: `b = a` даёт алиас. Поверхностная копия - `a[:]`, `list(a)`, `a.copy()`; вложенные списки остаются общими.
* Методы-мутаторы (`append`, `sort`, `reverse`) возвращают `None` - отдельно от «чистых» `sorted`, `reversed`.
* `sort` и `sorted` устойчивы; параметры `key=` и `reverse=` (в курсе используется только `reverse`).
* `append` - O(1) амортизированно, `insert(0, x)` и `x in lst` - O(n).
* Изменение списка во время итерации по нему допускается синтаксически, но ведёт к пропускам элементов.
* Списковые включения (`[x*2 for x in a]`) существуют, но в этом курсе не используются.

## Что происходит внутри (необязательно)

Список хранит не сами значения, а ссылки на них, в одном массиве, и при нехватке места выделяет новый, больше прежнего, запас. Поэтому `append` обычно мгновенный,
хотя иногда требует копирования всех ссылок. Именно из-за ссылок `b = a` дёшево: копируется одна ссылка, а не весь массив. Срез и `list(a)` создают новый массив ссылок на те же элементы.
Для чисел и строк это незаметно (они неизменяемы), а вот для вложенных списков копия остаётся «мелкой» - внутренние списки общие.
