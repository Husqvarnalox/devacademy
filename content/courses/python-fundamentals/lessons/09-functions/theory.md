## Функция - именованный кусок программы

Когда одна и та же последовательность действий нужна в нескольких местах, её не переписывают, а оформляют как **функцию**: даём блоку кода имя
и затем вызываем по имени. Вы уже пользовались готовыми функциями: `print`, `input`, `int`, `len`. Теперь вы создадите собственные.

Функция описывается ключевым словом `def` (от define, «определить»):

```python
def square(n):
    return n * n
```

Разберём запись:

* `square` - имя функции;
* `n` в скобках - **параметр**: имя, под которым функция получит данные. Значение, которое передаёт вызывающий код, называется **аргументом**;
* тело функции пишется с отступом;
* `return` («вернуть») завершает функцию и отдаёт результат туда, откуда её вызвали.

Вызов `square(5)` подставляет 5 в параметр `n`, выполняет тело и превращается в значение `25`. Это значение можно сохранить в переменную или передать в `print`.

Важно различать `print` и `return`. `print` показывает текст человеку и ничего не отдаёт программе. `return` передаёт результат дальше в программу, чтобы с ним работал другой код.
Функция, в которой нет `return`, возвращает специальное значение `None` - «ничего».

Зачем это нужно: функции делят программу на понятные части, убирают повторения, и их можно проверять по отдельности.

## Примеры

**Пример 1. Определение и вызов.**

```python run
def square(n):
    return n * n

print(square(5))
result = square(3) + square(4)
print(result)
```
```output
25
25
```

Разбор: строка `def` только описывает функцию, ничего не выполняя. Первый `print` вызывает `square(5)`; результат 25 выводится. Во второй строке сначала вычисляются 9 и 16, потом их сумма.

**Пример 2. `print` и `return`.**

```python run
def show_total(price, count):
    print("Итого:", price * count)

def get_total(price, count):
    return price * count

show_total(50, 3)
value = get_total(50, 3)
print(value + 10)
print(show_total(1, 1))
```
```output
Итого: 150
160
Итого: 1
None
```

Разбор: `show_total` печатает, но ничего не возвращает. `get_total` отдаёт число, и к нему можно прибавить 10. Последняя строка показывает, что вызов функции без `return` даёт `None`: сначала вывелось `Итого: 1`, затем `print` напечатал `None`.

**Пример 3. Несколько параметров и значение по умолчанию.**

```python run
def price_with_tax(price, tax=20):
    return price + price * tax / 100

print(price_with_tax(100))
print(price_with_tax(100, 10))
print(price_with_tax(tax=5, price=200))
```
```output
120.0
110.0
210.0
```

Разбор: если второй аргумент не передан, `tax` равно 20. В третьем вызове аргументы переданы по именам, поэтому порядок не важен.

**Пример 4. Область видимости.**

```python run
def make_label(name):
    label = "Клиент: " + name
    return label

text = make_label("Анна")
print(text)
```
```output
Клиент: Анна
```

Разбор: `name` и `label` существуют только внутри функции и пока она работает. Это **локальные** переменные. Снаружи они недоступны, поэтому результат пришлось вернуть через `return`.
Попытка написать `print(label)` в конце привела бы к `NameError`.

**Попробуйте.** В примере 3 вызовите `price_with_tax(50, 0)` и предскажите результат.

## Подробнее

**Определение и вызов - разные события.** `def` создаёт функцию, но не выполняет тело. Тело выполняется при каждом вызове. Функцию нужно определить раньше, чем вызвать: Python выполняет программу сверху вниз.

**Параметры и аргументы.** Параметр - имя в `def`, аргумент - значение при вызове. Аргументы можно передавать по порядку или по имени (`price=200`). Параметры со значением по умолчанию (`tax=20`) пишут после обычных.
Передавать меньше аргументов, чем нужно, или больше, нельзя.

**`return`.** Завершает функцию сразу: код после `return` не выполняется. В функции может быть несколько `return` в разных ветках `if`. Если выполнение дошло до конца без `return`, функция вернёт `None`.
Один `return` может вернуть только одно значение (позже вы узнаете, как отдать несколько).

**Локальные и внешние переменные.** Переменные, созданные внутри функции (в том числе параметры), локальны: каждый вызов получает свои, а после возврата они исчезают.
Функция может **прочитать** переменную, созданную вне неё до вызова, но присваивание внутри функции создаёт новую локальную переменную, не меняя внешнюю.
Надёжнее передавать данные параметрами и получать результат через `return`.

**Имена функций.** Правила те же, что у переменных: по смыслу, в `snake_case`, обычно глагол или результат (`get_total`, `square`). Не называйте функцию так же, как встроенную (`print`, `len`, `sum`).

**Документирующая строка.** Первая строка тела, записанная в тройных кавычках или обычных, описывает назначение функции. Она ни на что не влияет, но помогает читателю.

**Проверка функции.** Чем меньше функция, тем легче её проверить: вызовите её с несколькими значениями, включая граничные, и сверьте результат с ожидаемым.

## Типичные ошибки

**1. Забыт `return`.**

```python
def double(x):
    x * 2

print(double(4))
```

Выведет `None`. Ошибки нет: выражение `x * 2` вычислено и сразу выброшено. Исправление: `return x * 2`. Как заметить: вместо числа в выводе `None`.

**2. Печать вместо возврата.** Если функция печатает результат, а вызывающий код хочет использовать его дальше (`total = show_total(...)`), в переменной окажется `None`. Печатайте снаружи.

**3. Неверное число аргументов.**

```
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    f(1)
    ~^^^
TypeError: f() missing 1 required positional argument: 'b'
```

Функции нужен ещё один аргумент `b`. Лишний аргумент даёт сообщение `f() takes 2 positional arguments but 3 were given`.

**4. Локальная переменная снаружи.**

```
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(x)
          ^
NameError: name 'x' is not defined
```

Если `x` создана внутри функции, снаружи её нет. Решение: вернуть значение через `return`.

**5. Изменение внешней переменной.**

```python
total = 0
def add_one():
    total += 1
add_one()
```

```
UnboundLocalError: cannot access local variable 'total' where it is not associated with a value
```

Присваивание внутри функции делает `total` локальной, а локальной значения ещё нет. Верно: передавать значение параметром и возвращать новое: `total = add_one(total)`.

**6. Вызов без скобок.** `square` без `(5)` - не вызов, а сам объект функции. `print(square)` не напечатает результат.

**7. `return` внутри цикла раньше времени.** Если `return` стоит внутри цикла на уровне тела, функция вернётся на первой же итерации. Проверьте отступ у `return`.

<!-- section: summary -->
## Итоги

* `def имя(параметры):` описывает функцию; вызов `имя(аргументы)` выполняет тело.
* `return` отдаёт результат и завершает функцию; без `return` получится `None`.
* `print` показывает значение человеку, `return` передаёт программе.
* Параметры и переменные внутри функции локальны.
* Значение по умолчанию позволяет не передавать аргумент.

## Для тех, кто уже программировал

* Функции - объекты первого класса, определяются инструкцией `def` во время выполнения. Типы параметров и результата не объявляются.
* Аргументы можно передавать позиционно и по имени; значения по умолчанию вычисляются один раз при выполнении `def`. Для изменяемых значений по умолчанию (списки, словари) это известная ловушка: все вызовы разделяют один объект.
* Область видимости - функция, а не блок: переменные из `if` и `for` живут до конца функции. Поиск имён: локальные, объемлющие функции, глобальные, встроенные.
* Присваивание внутри функции без `global` создаёт локальную переменную; чтение внешней работает.
* Без `return` или с пустым `return` результат - `None`. Несколько возвращаемых значений возвращаются кортежем.
* Перегрузки по типам нет: одно имя - одна функция.

## Что происходит внутри (необязательно)

Инструкция `def` во время выполнения создаёт объект-функцию и связывает с ним имя. Поэтому вызвать функцию до строки `def` нельзя: имени ещё нет.
При вызове интерпретатор создаёт **кадр** - маленькую таблицу локальных имён - и кладёт его на стек вызовов. Параметры становятся первыми локальными именами.
Когда функция возвращается, кадр удаляется и вместе с ним исчезают локальные переменные. Этот же стек вы видите в traceback: каждая строка `File ... in имя_функции` - один кадр.
