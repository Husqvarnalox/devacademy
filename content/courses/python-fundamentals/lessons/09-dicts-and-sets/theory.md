## Справочник вместо списка

Список отвечает на вопрос «что лежит на позиции 3?». Но часто нужно другое: «какой телефон у Ани?», «встречалось ли это слово раньше?». Искать ответ перебором всех элементов долго.
Для таких вопросов у Python есть две структуры, устроенные как **хеш-таблицы**.

**Словарь** (`dict`) связывает **ключ** со **значением**: `{"аня": "555-01", "боря": "555-02"}`. Спрашиваете по ключу - получаете значение почти мгновенно, независимо от размера словаря.

**Множество** (`set`) - это набор уникальных элементов без номеров: `{1, 2, 3}`. Оно отвечает на вопрос «есть ли такой элемент?» тоже почти мгновенно, автоматически отбрасывает повторы
и умеет операции, знакомые из школьной математики: объединение, пересечение, разность.

Идея хеш-таблицы: по ключу вычисляется число (хеш), по этому числу сразу понятно, в какой «ячейке» искать. Не нужно смотреть все ячейки подряд - как в библиотеке, где книгу ищут по шифру, а не пролистывая все полки.

У такого устройства есть цена. Во-первых, ключом может быть только то, что **не меняется** (число, строка, кортеж), иначе хеш «разойдётся» с положением. Во-вторых, у множества нет порядка,
поэтому, если вы хотите красивый повторяемый вывод, его надо упорядочить явно. Словарь же помнит порядок добавления ключей.

## Что происходит внутри

**Хеш-таблица.** Это массив ячеек. Чтобы положить пару `(ключ, значение)`, вычисляют `hash(ключ)`, превращают его в номер ячейки и сохраняют пару там. Если ячейка занята другим ключом (*коллизия*),
CPython ищет другую свободную по определённому правилу (открытая адресация). При поиске происходит то же самое: по хешу находят ячейку и сравнивают ключи через `==`.
Когда таблица заполняется больше определённой доли, она расширяется, а все ключи размещаются заново. В среднем поиск, вставка и удаление делают константное число шагов: **O(1)**. В худшем случае (много коллизий) - O(n), но хеш-функции встроенных типов этого избегают.

**Хешируемость.** Объект хешируем, если у него есть значение `hash()`, которое не меняется за время жизни объекта, и равные объекты имеют равные хеши (`a == b` влечёт `hash(a) == hash(b)`).
Хешируемы `int`, `float`, `bool`, `str`, `bytes`, `None`, а также `tuple` и `frozenset`, если все их элементы хешируемы. **Не хешируемы** `list`, `dict`, `set` - они изменяемы. Попытка использовать их как ключ
вызывает `TypeError: unhashable type`. Поскольку `1 == 1.0 == True`, а хеши этих значений равны, в словаре это **один и тот же ключ**.

**Хеш строк случайно «солится».** Для `str` и `bytes` значение `hash()` зависит от случайной соли, выбираемой при старте интерпретатора. Значит, порядок перебора `set` строк может меняться от запуска к запуску.

**Порядок.** Словарь сохраняет порядок вставки ключей (гарантия языка с версии 3.7). Перезапись значения существующего ключа порядок не меняет; удаление и повторная вставка отправляют ключ в конец.
Множество порядка не гарантирует вообще. Если нужен стабильный вывод - `sorted(...)`.

**Основные операции dict.** `d[key]` (бросает `KeyError`, если ключа нет), `d.get(key, default)` (без исключения), `key in d`, `d[key] = value`, `del d[key]`, `d.pop(key, default)`,
`d.setdefault(key, default)` (вернуть значение, вставив default, если ключа нет), `d.items()`, `d.keys()`, `d.values()` (представления, а не копии), `len(d)`.
Итерация `for k in d` идёт по ключам. Изменять размер словаря во время обхода нельзя (`RuntimeError`).

**Операции set.** `a | b` (объединение), `a & b` (пересечение), `a - b` (разность), `a ^ b` (симметрическая разность), `x in a`, `a <= b` (подмножество), `a.add(x)`, `a.discard(x)`.
Пустое множество создаётся `set()`: литерал `{}` - это пустой **словарь**.

**Идиомы.** Подсчёт частот: `counts[w] = counts.get(w, 0) + 1`. Устранение повторов с сохранением порядка: `list(dict.fromkeys(items))`. Сортировка словаря по значению:
`sorted(d.items(), key=lambda pair: (-pair[1], pair[0]))` - сначала по убыванию значения, при равенстве по ключу.

## Примеры

**Пример 1. Базовые операции и порядок.**

```python run
d = {"a": 1, "b": 2}
del d["a"]
d["a"] = 3
print(d, list(d))
print(d.get("z"), d.get("z", 0))
print(d.setdefault("q", []), d)
print("b" in d, len(d))
```
```output
{'b': 2, 'a': 3} ['b', 'a']
None 0
[] {'b': 2, 'a': 3, 'q': []}
True 3
```

Ключ `a` после удаления и повторной вставки оказался в конце.

**Пример 2. Что может быть ключом.**

```python run
print({1: "a", 1.0: "b", True: "c"})
print(hash((1, 2)) == hash((1, 2)))
try:
    {[1]: 2}
except TypeError:
    print("список не может быть ключом")
try:
    hash((1, [2]))
except TypeError:
    print("кортеж со списком внутри тоже не хешируется")
```
```output
{1: 'c'}
True
список не может быть ключом
кортеж со списком внутри тоже не хешируется
```

**Пример 3. Множества и повторяемый вывод.**

```python run
s1 = {1, 2, 3, 4}
s2 = {3, 4, 5}
print(sorted(s1 | s2))
print(sorted(s1 & s2))
print(sorted(s1 - s2))
print(sorted(s1 ^ s2))
print(3 in s1, s1 <= {1, 2, 3, 4, 5})
print(list(dict.fromkeys([3, 1, 3, 2, 1])))
```
```output
[1, 2, 3, 4, 5]
[3, 4]
[1, 2]
[1, 2, 5]
True True
[3, 1, 2]
```

Мы оборачиваем результат в `sorted`, потому что порядок перебора множества не определён. `dict.fromkeys` убрал повторы, сохранив порядок появления.

**Пример 4. Подсчёт частот с детерминированным выводом.**

```python run
text = "b a b c a b"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
for word, n in sorted(counts.items(), key=lambda pair: (-pair[1], pair[0])):
    print(word, n)
```
```output
b 3
a 2
c 1
```

**Пример 5. Словарные и множественные включения.**

```python run
print({k: v for k, v in zip("abc", range(3))})
print(sorted({len(w) for w in ["a", "bb", "cc", "ddd"]}))
```
```output
{'a': 0, 'b': 1, 'c': 2}
[1, 2, 3]
```

## Типичные ошибки

* **Изменяемый объект в роли ключа.** `d[[1, 2]] = x` - `TypeError: unhashable type`. Используйте кортеж `(1, 2)` или строку.
* **`d[key]` для отсутствующего ключа.** Вызывает `KeyError`. Если ключа может не быть, пишите `d.get(key, значение)` или проверяйте `key in d`.
* **`{}` как пустое множество.** Это пустой словарь. Для пустого множества - `set()`.
* **Полагаться на порядок `set`.** Вывод `for w in words_set` может меняться между запусками, особенно для строк. Если нужен повторяемый результат, сортируйте.
* **Менять словарь во время обхода.** Добавление или удаление ключей внутри `for k in d` приводит к `RuntimeError`. Обходите копию: `for k in list(d)`.
* **Считать `1`, `1.0` и `True` разными ключами.** Они равны и имеют одинаковый хеш, поэтому занимают одну запись.
* **Проверять вхождение в список вместо множества.** `if x in big_list` внутри цикла делает вложенный перебор (O(n²)); один раз превратите список в `set` и проверяйте по нему.
* **Сортировка «по убыванию» отрицанием строки.** `-word` невозможно; чтобы смешать убывание числа и возрастание слова, ставьте минус только перед числом: `(-count, word)`.

## Итоги

* `dict` и `set` - хеш-таблицы: поиск, вставка и удаление в среднем O(1) при условии хешируемых ключей.
* Хешируемы неизменяемые типы (`int`, `str`, `tuple` из хешируемых элементов); `list`, `dict`, `set` - нет.
* `dict` сохраняет порядок вставки (с Python 3.7), `set` порядка не гарантирует: для стабильного вывода используйте `sorted`.
* Частоты считаются через `counts.get(word, 0) + 1`; множества дают объединение, пересечение, разность и мгновенную проверку вхождения.
