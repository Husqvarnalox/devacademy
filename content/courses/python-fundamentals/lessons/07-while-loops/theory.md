## Повторять, пока условие верно

Многие задачи состоят из повторений: пересчитать товары в корзине, спрашивать пароль, пока он не верный, суммировать числа. Писать одну и ту же команду
десять раз нельзя: неизвестно, сколько раз нужно повторить. Для этого есть **цикл** - команда, которая повторяет блок кода.

Цикл `while` («пока») выглядит как `if`: условие, двоеточие и блок с отступом. Разница в том, что после выполнения блока Python **возвращается и проверяет условие снова**:

```python
n = 1
while n <= 3:
    print(n)
    n = n + 1
```

Один проход тела цикла называется **итерацией**. Порядок такой: проверить условие; если оно верно - выполнить блок и вернуться к проверке; если ложно - выйти из цикла и идти дальше.

Две привычные роли переменных в цикле: **счётчик** (`n` выше, меняется на 1 при каждом шаге) и **накопитель** (например, `total`, куда прибавляют значение на каждом шаге).
Если внутри цикла ничего не меняет условие, цикл никогда не завершится - это **бесконечный цикл**.

<!-- section: examples -->
## Примеры

**Пример 1. Счётчик.**

```python run
n = 1
while n <= 3:
    print("Шаг", n)
    n = n + 1
print("Готово, n =", n)
```
```output
Шаг 1
Шаг 2
Шаг 3
Готово, n = 4
```

Разбор: перед первым шагом `n` равно 1, `1 <= 3` верно - тело выполняется. Строка `n = n + 1` приближает конец цикла. Когда `n` стало 4, условие `4 <= 3` ложно, цикл завершился, и после него выполнилась последняя строка.

**Пример 2. Накопитель.**

```python run
total = 0
number = 1
while number <= 5:
    total = total + number
    number = number + 1
print(total)
```
```output
15
```

Таблица значений (так удобно проверять цикл вручную):

| Шаг | number до шага | total после шага |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |
| 5 | 5 | 15 |

**Пример 3. `break` и `continue`.**

```python run
n = 0
while n < 10:
    n = n + 1
    if n == 3:
        continue
    if n == 6:
        break
    print(n)
print("Конец, n =", n)
```
```output
1
2
4
5
Конец, n = 6
```

Разбор: `continue` («продолжай») пропускает остаток тела и сразу возвращается к проверке условия, поэтому тройка не напечатана. `break` («прервать») немедленно выходит из цикла, шестёрка тоже не напечатана.

**Пример 4. Ввод до стоп-слова.** Запускать нельзя: программа ждёт ввод.

```python
total = 0
while True:
    line = input()
    if line == "стоп":
        break
    total = total + int(line)
print(total)
```

`while True` - условие, которое всегда верно, поэтому выход делает только `break`. Для ввода `5`, `7`, `стоп` программа выведет `12`.

**Попробуйте.** В примере 1 замените условие на `n < 3` и предскажите, что выведется и чему будет равно `n` в конце.

## Подробнее

**Проверка стоит в начале.** Условие проверяется до каждой итерации, включая первую. Если оно ложно сразу, тело не выполнится ни разу.

**Бесконечный цикл.** Типичные причины: забыли изменить переменную в условии; изменение стоит в ветке, которая не выполняется; условие никогда не становится ложным (`n != 10` при шаге 3 от 0 проскочит 10). Если программа «зависла», нажмите кнопку остановки
и добавьте `print` с переменной условия, чтобы увидеть, как она меняется.

**`break` и `continue` относятся только к ближайшему циклу.** Они не нужны в большинстве простых циклов; применяйте их, когда выход или пропуск понятнее всего выражается именно так.

**`while True` и `break`.** Подходит, когда решение «продолжать ли» можно принять только после чтения данных. Альтернатива без `break` требует прочитать значение дважды: до цикла и в конце тела.

**`else` у цикла** существует, но в курсе не используется.

**Накопители.** `total = total + x` можно записывать короче: `total += x`. Результат тот же.

**Порядок строк в теле.** Если счётчик увеличивается до `print`, будут напечатаны уже увеличенные значения. Проверяйте порядок на таблице значений.

## Типичные ошибки

**1. Бесконечный цикл.**

```python
n = 1
while n < 4:
    print(n)
```

Программа будет без конца выводить `1`. Сообщения об ошибке нет: с точки зрения Python всё в порядке. Как заметить: вывод не прекращается, а переменная условия в теле не меняется. Исправление: добавить `n = n + 1`.

**2. Ошибка на единицу.** `while n <= 3` и `while n < 3` дают разное число шагов. Проверьте на таблице значений, сколько раз выполнится тело.

**3. Накопитель сброшен внутри цикла.**

```python
while number <= 5:
    total = 0
    total = total + number
```

В конце `total` равно последнему числу, а не сумме. Накопитель нужно создавать до цикла.

**4. Забыли преобразовать ввод в число.** `total = total + line` при `line = "5"`:

```
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Исправление: `int(line)`.

**5. Нет двоеточия или отступа.**

```
  File "main.py", line 1
    while True
              ^
SyntaxError: expected ':'
```

**6. `continue` до изменения счётчика.** Если `continue` стоит выше строки `n = n + 1`, цикл может застрять на одном значении. В примерах выше счётчик меняется до `continue`.

<!-- section: summary -->
## Итоги

* `while условие:` повторяет блок, пока условие верно; проверка делается перед каждой итерацией.
* Счётчик и накопитель заводят до цикла, меняют внутри.
* `break` выходит из цикла, `continue` переходит к следующей проверке.
* Если условие не может стать ложным, цикл бесконечен.

Дальше: [цикл for и range](lesson:python.fundamentals.loops) - более удобная запись для повторения известное число раз.

<!-- section: programmer -->
## Для тех, кто уже программировал

* Нет `do ... while` и нет `++`; счётчик увеличивают `n += 1`.
* Условие без скобок, блок через отступ; `while True` + `break` - обычный способ написать цикл с проверкой в середине.
* У `while` и `for` есть необязательная ветка `else`, выполняемая, если цикл не прервали `break`.
* Python не ограничивает целые числа, поэтому переполнение счётчика не бывает; зато зависание из-за неизменяемого условия бывает.
* Для чтения «до конца ввода» обычно пользуются обходом `sys.stdin` или перехватом `EOFError`; в курсе используем стоп-слова.

## Что происходит внутри (необязательно)

В байткоде цикл `while` - это условный переход назад: проверка условия, если верно - тело и безусловный переход к проверке, иначе - переход за конец цикла.
`break` и `continue` - это такие же переходы: на выход и на начало. Поэтому они мгновенны и не создают «особого» состояния. Бесконечный цикл не расходует память
сам по себе, но занимает процессор целиком, поэтому проверяющая система ограничивает время выполнения программы.
