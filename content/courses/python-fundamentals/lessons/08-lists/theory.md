## Список - ряд ячеек со ссылками

Список (`list`) - упорядоченная изменяемая коллекция: `[10, "текст", 3.5]`. Его можно представить как ряд пронумерованных ячеек, но в каждой ячейке лежит не само значение, а **ссылка** на объект - ярлык, как мы
видели в уроке про имена. Поэтому в одном списке могут жить объекты разных типов, а два списка могут ссылаться на одни и те же объекты.

Главные операции: доступ по индексу (`xs[0]`), добавление в конец (`xs.append(5)`), удаление (`xs.pop()`), срезы (`xs[1:3]`), сортировка, проверка вхождения (`3 in xs`).

Три важные вещи, которые стоит запомнить с самого начала:

1. **Добавлять в конец дёшево, а в начало - дорого.** Если нужно вставить элемент в начало, придётся «подвинуть» всех остальных.
2. **`b = a` не копирует список.** Это второй ярлык на тот же список. Изменили через `b` - увидели в `a`.
3. **Срез копирует, но «неглубоко».** `a[:]` создаёт новый список, но элементы в нём - те же самые объекты. Если внутри вложены списки, они остаются общими.

Для сортировки есть два инструмента: `xs.sort()` меняет список на месте, а `sorted(xs)` возвращает новый отсортированный список, не трогая исходный.

## Как устроен list

**Структура.** В CPython `list` - это динамический массив указателей на объекты. Объект списка хранит указатель на непрерывный блок памяти, текущую длину и **ёмкость** (сколько ссылок помещается без перевыделения).
Элемент `xs[i]` находится арифметикой над адресом - это O(1).

**Амортизированное O(1) для append.** Когда ёмкость исчерпана, CPython выделяет новый блок больше нужного (с запасом, примерно пропорционально размеру) и копирует ссылки. Редкие дорогие копирования «размазываются» по многим дешёвым append,
поэтому среднее время одной операции постоянно - это и называют *амортизированной* стоимостью. Размер списка в памяти растёт не на каждое добавление, а ступенями.

**Стоимость операций (n - длина списка):**

| Операция | Стоимость |
|---|---|
| `xs[i]`, `len(xs)`, присваивание `xs[i] = v` | O(1) |
| `xs.append(v)`, `xs.pop()` | O(1) амортизированно |
| `xs.insert(0, v)`, `xs.pop(0)`, `del xs[0]` | O(n): сдвиг всех элементов |
| `v in xs`, `xs.index(v)`, `xs.count(v)` | O(n): линейный поиск |
| срез `xs[a:b]` | O(b - a): создаётся новый список |
| `sorted(xs)`, `xs.sort()` | O(n log n) |

Если нужна очередь с быстрым удалением из начала, используют `collections.deque`; если нужны быстрые проверки вхождения - множество (следующий урок).

**Псевдонимы и копии.** Присваивание `b = a` связывает второе имя с тем же объектом. Копия создаётся явно: `a.copy()`, `list(a)`, `a[:]` - все делают *поверхностную* копию: новый внешний список с теми же ссылками на элементы.
Для неизменяемых элементов (числа, строки) разницы не видно; для изменяемых (вложенные списки) изменение вложенного объекта видно через обе копии. Полностью независимая копия - `copy.deepcopy(a)`.
Выражение `[[0] * 3] * 2` создаёт список из двух ссылок на один и тот же внутренний список; верно строить так: `[[0] * 3 for _ in range(2)]`.

**Сортировка.** `xs.sort()` сортирует на месте и возвращает `None`; `sorted(iterable)` строит новый список. Оба принимают `key` (функция, которая из элемента получает значение для сравнения) и `reverse`.
Сортировка устойчива: элементы с равным ключом сохраняют исходный порядок. Сравнивать можно только сравнимые элементы: `[3, "a"]` не отсортируется (`TypeError`). Ключ-кортеж `(len(w), w)` сортирует сначала по длине, затем по самому слову.

**Comprehension (списковое включение).** `[выражение for x in iterable if условие]` строит новый список. Оно эквивалентно циклу с `append`, но короче и обычно быстрее. Если логика не помещается в одну строку - используйте обычный цикл.

## Примеры

**Пример 1. Псевдоним и копия.**

```python run
a = [1, 2, 3]
alias = a
copy = a[:]
alias.append(4)
copy[0] = 99
print(a, alias is a)
print(copy, copy is a)
```
```output
[1, 2, 3, 4] True
[99, 2, 3] False
```

**Пример 2. Поверхностная копия и вложенные списки.**

```python run
import copy

outer = [[1, 2], [3]]
shallow = outer.copy()
shallow[0].append(9)
print(outer, shallow[0] is outer[0])

deep = copy.deepcopy(outer)
deep[0].append(7)
print(outer)
print(deep)
```
```output
[[1, 2, 9], [3]] True
[[1, 2, 9], [3]]
[[1, 2, 9, 7], [3]]
```

**Пример 3. Ловушка с таблицей.**

```python run
bad = [[0] * 2] * 2
bad[0][0] = 1
print(bad)

good = [[0] * 2 for _ in range(2)]
good[0][0] = 1
print(good)
```
```output
[[1, 0], [1, 0]]
[[1, 0], [0, 0]]
```

**Пример 4. sort и sorted, параметр key.**

```python run
words = ["pear", "fig", "banana", "kiwi"]
print(sorted(words))
print(sorted(words, key=len))
print(sorted(words, key=len, reverse=True))
print(words)
result = words.sort()
print(result, words)
```
```output
['banana', 'fig', 'kiwi', 'pear']
['fig', 'pear', 'kiwi', 'banana']
['banana', 'pear', 'kiwi', 'fig']
['pear', 'fig', 'banana', 'kiwi']
None ['banana', 'fig', 'kiwi', 'pear']
```

Сортировка по длине устойчива: `pear` и `kiwi` имеют длину 4 и остались в исходном порядке (в `words` `pear` стоит раньше).

**Пример 5. Comprehension и ступенчатая ёмкость.**

```python run
import sys

print([n * n for n in range(6) if n % 2 == 0])
print([x + y for x in "ab" for y in "12"])

sizes = []
lst = []
for i in range(30):
    lst.append(i)
    sizes.append(sys.getsizeof(lst))
print("размер растёт реже, чем добавляются элементы:", len(set(sizes)) < 30)
```
```output
[0, 4, 16]
['a1', 'a2', 'b1', 'b2']
размер растёт реже, чем добавляются элементы: True
```

## Типичные ошибки

* **`b = a` вместо копии.** Изменение через `b` меняет `a`. Нужна копия - создайте её явно (`a.copy()`, `a[:]`).
* **Копия «неглубокая».** Для списка списков `a[:]` не защищает вложенные списки; используйте `copy.deepcopy` или копируйте вложенные структуры вручную.
* **`[[0] * n] * m`.** Все строки - один и тот же список. Используйте генератор: `[[0] * n for _ in range(m)]`.
* **`nums = nums.sort()`.** `sort` возвращает `None`, и список потерян. Либо `nums.sort()` без присваивания, либо `nums = sorted(nums)`.
* **Удаление из списка во время обхода.** `for x in xs: if bad(x): xs.remove(x)` пропускает элементы, потому что индексы сдвигаются. Стройте новый список: `xs = [x for x in xs if not bad(x)]`.
* **`pop(0)` и `insert(0, ...)` в цикле.** Каждая операция сдвигает весь список; на десятках тысяч элементов программа становится заметно медленной. Используйте `collections.deque` либо переверните порядок обработки.
* **Проверка `x in list` в цикле по большим данным.** Это линейный поиск, и вложенный цикл даёт O(n²). Для частых проверок вхождения используйте множество.
* **Изменение входного списка в функции.** Если функция должна вернуть результат, не меняйте аргумент: работайте с копией или создавайте новый список.

<!-- section: summary -->
## Итоги

* `list` - динамический массив ссылок: индексация O(1), `append` амортизированно O(1), `insert(0, x)` и `pop(0)` O(n), `x in lst` O(n).
* `b = a` создаёт псевдоним; `a[:]`, `a.copy()` и `list(a)` - поверхностные копии; для вложенных структур нужен `deepcopy`.
* `sort()` меняет список на месте и возвращает `None`, `sorted()` возвращает новый список; обе сортировки устойчивы и принимают `key`.
* Comprehension строит новый список выражением; для сложной логики цикл читаемее.
