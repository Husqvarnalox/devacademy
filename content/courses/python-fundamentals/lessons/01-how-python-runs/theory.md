## Программа - это записанная последовательность команд

Чтобы компьютер что-то сделал, ему нужны точные указания. Набор таких указаний, записанный в файле, называется
**программой**. Каждое указание - **команда**, и компьютер выполняет команды по порядку, сверху вниз. **Запустить** программу
значит поручить специальной программе, **интерпретатору Python**, прочитать файл и выполнить команды.

Самая нужная первая команда - показать результат. Для этого в Python есть `print` (по-английски «напечатать»):

```python
print("Привет!")
```

Слово `print` - имя команды. В скобках записано то, что нужно показать. Текст в кавычках называется
**строковым литералом**: «строка» - это последовательность символов, «литерал» - значение, записанное прямо в программе.
Кавычки нужны, чтобы Python отличил ваш текст от своих слов и от имён. Сами кавычки на экран не попадают.

Зачем это нужно: любая программа, от калькулятора до сайта, должна что-то сообщить человеку. `print` - самый простой способ,
и с него удобно проверять, что происходит в программе.

<!-- section: examples -->
## Примеры

**Пример 1. Одна команда.**

```python run
print("Привет, мир!")
```
```output
Привет, мир!
```

Разбор: `print` - команда, круглые скобки обрамляют то, что ей передают, `"Привет, мир!"` - текст. Результат появляется в окне вывода.

**Пример 2. Несколько команд идут по порядку.**

```python run
print("Первая строка")
print("Вторая строка")
print("Третья строка")
```
```output
Первая строка
Вторая строка
Третья строка
```

Каждый `print` по умолчанию заканчивает вывод переходом на новую строку, поэтому три команды дали три строки.

**Пример 3. Несколько значений в одной команде.**

```python run
print("Хлеб", 45)
print("Хлеб", "Молоко", "Сыр")
print("Хлеб", "Молоко", "Сыр", sep=", ")
print("Загрузка", end="...")
print("готово")
```
```output
Хлеб 45
Хлеб Молоко Сыр
Хлеб, Молоко, Сыр
Загрузка...готово
```

Разбор по строкам:

1. Значения в `print` разделяются запятой. Между ними `print` сам ставит пробел. Число пишется без кавычек.
2. Три текста - три значения, разделённые пробелами.
3. `sep=", "` (от separator, «разделитель») заменяет пробел между значениями на запятую с пробелом.
4. `end="..."` заменяет переход на новую строку на три точки, поэтому следующий вывод продолжает ту же строку.

**Попробуйте.** Что выведет `print("a", "b", "c", sep="")`? Предположите, затем запустите.

<!-- section: precise -->
## Подробнее о тексте и print

**Кавычки.** Строку можно записать в двойных кавычках `"..."` или в апострофах `'...'`: это одно и то же. Если внутри текста
есть кавычки одного вида, заключайте текст в кавычки другого вида: `'Магазин "Яблоко"'` или `"It's ready"`.

**Перенос строки.** Внутри текста сочетание `\n` означает «перейти на новую строку». Обратная косая черта с буквой - способ
записать символ, который неудобно набрать. Команда `print("а\nб")` выведет две строки.

**Правила print.** Команда принимает любое число значений через запятую, выводит их через `sep` (по умолчанию пробел) и в конце
добавляет `end` (по умолчанию `\n`). Пустой `print()` выводит просто пустую строку.

**Регистр и пробелы.** Python различает `print` и `Print`. Пробелы внутри кавычек - часть текста и попадут в вывод, а пробелы
вне кавычек между словами команды на вывод не влияют.

**Ошибка до запуска.** Если запись нарушает правила языка (например, не закрыта кавычка), Python сообщает об этом сразу и не
выполняет даже предыдущие строки. Такая ошибка называется синтаксической.

<!-- section: mistakes -->
## Типичные ошибки

**1. Не закрыта кавычка.**

```python
print("Привет)
```

Сообщение:

```
  File "main.py", line 1
    print("Привет)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Что произошло: Python дошёл до конца строки, а закрывающей кавычки не нашёл. Исправление: допишите `"` перед скобкой.
Как заметить: стрелка `^` указывает на место, где начинается незавершённый текст; смотрите на номер строки в сообщении.

**2. Текст без кавычек.**

```python
print(Привет)
```

```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(Привет)
          ^^^^^^
NameError: name 'Привет' is not defined
```

Без кавычек слово считается именем. Такого имени в программе нет, поэтому `NameError` («имя не определено»). Исправление: добавить кавычки.

**3. Неверный регистр в имени команды.**

```python
Print("a")
```

```
NameError: name 'Print' is not defined. Did you mean: 'print'?
```

Python различает большие и маленькие буквы. Он сам подсказал нужное имя после слов `Did you mean`.

**4. Лишний пробел или пустая строка в выводе.** Автоматическая проверка сравнивает вывод с образцом по символам. Если
тест не проходит, а программа «выглядит правильно», сравните свой вывод с образцом по строкам и пробелам.

## Итоги

* Программа - это команды в файле; Python выполняет их по порядку сверху вниз.
* `print(...)` показывает значения; между значениями ставит `sep`, в конце добавляет `end`.
* Текст пишут в кавычках; без кавычек слово воспринимается как имя.
* Ошибка записи находится до запуска, поэтому не выполняется ни одной строки.

Теперь вы можете выводить любой фиксированный текст. Дальше: [переменные и ввод](lesson:python.fundamentals.variables-and-input) -
программа научится запоминать значения и получать их от человека.

<!-- section: programmer -->
## Для тех, кто уже программировал

* Точки входа нет: файл выполняется сверху вниз, как скрипт. Функции `main` не требуется.
* Блоков с фигурными скобками нет, структуру задают отступы (подробнее в уроке про чтение ошибок и в уроке про условия).
* Точка с запятой в конце команды не нужна, но допустима.
* Строки одинаково записываются в `"` и в `'`; `print` - обычная функция, `end` и `sep` - именованные аргументы.
* Python динамически типизирован; объявлений типов нет.
* Запуск: `python main.py`; в интерактивном режиме `python` построчно выполняет введённое.
* Синтаксис проверяется до выполнения, остальные ошибки возникают во время работы.

<!-- section: deep-dive -->
## Что происходит внутри (необязательно)

Для понимания курса этот раздел не нужен.

Самая распространённая реализация Python называется CPython и написана на C. Запуск файла проходит в два этапа.
Сначала исходный текст разбирается, проверяется и превращается в **байткод** - список простых внутренних инструкций.
Затем **виртуальная машина** CPython выполняет эти инструкции по одной. Поэтому синтаксическая ошибка в последней строке
останавливает всё до первой: на первом этапе файл целиком ещё не разобран.

Для подключаемых модулей байткод сохраняется в папке `__pycache__`, чтобы не разбирать модуль заново. Главный файл
так не сохраняется.

У процесса есть три стандартных потока: `stdin` (ввод), `stdout` (обычный вывод) и `stderr` (сообщения об ошибках).
`print` пишет в `stdout`, а сообщения об ошибках интерпретатор выводит в `stderr`. Поэтому вывод программы можно
сохранить в файл, а сообщения об ошибках по-прежнему увидеть на экране.
