## Строка - это ряд букв, который нельзя править «на месте»

Строка (`str`) - это текст: последовательность символов. Её можно рассматривать как пронумерованный ряд ячеек: у каждого символа есть номер (индекс), и считать номера начинают с нуля.

```python
word = "python"
word[0]      # 'p'
word[-1]     # 'n' - минус значит "с конца"
word[1:4]    # 'yth' - срез: от индекса 1 до 4, не включая 4
```

Главное свойство строки в Python: она **неизменяема**. Нельзя «заменить букву на месте» - `word[0] = "P"` вызовет ошибку. Все методы вроде `upper()` или `replace()`
не меняют исходную строку, а **создают и возвращают новую**. Поэтому, если результат нужен, его сохраняют: `word = word.upper()`.

Строки умеют многое: разрезать (`split`), склеивать (`join`), обрезать пробелы (`strip`), искать (`find`, `in`), заменять (`replace`). А для красивого вывода значений в текст существуют **f-строки**:

```python
price = 45.5
print(f"Цена: {price:.2f} руб.")
```

Наконец, символ - не всегда один байт. В современных программах текст хранится в Unicode, и русская буква, эмодзи или иероглиф - по-прежнему «один символ» для Python,
хотя в файле и в сети они занимают разное число байтов.

## Строка внутри

**Модель.** `str` - неизменяемая последовательность *кодовых точек* Unicode (code points). `len(s)` возвращает число кодовых точек, `s[i]` - строка из одной кодовой точки (отдельного типа «символ» в Python нет),
`ord(ch)` даёт номер кодовой точки, `chr(n)` - обратное преобразование.
Внутри CPython выбирает компактную раскладку (1, 2 или 4 байта на кодовую точку) по самому «широкому» символу строки (PEP 393), поэтому индексирование - O(1), а строка из одних латинских букв занимает мало памяти.

**Байты и кодировки.** Кодировка превращает строку в байты: `"привет".encode("utf-8")` - 12 байтов (кириллица в UTF-8 - два байта на букву, латиница - один, эмодзи - четыре). Обратно: `bytes.decode("utf-8")`.
Строка и байты - разные типы; смешивать их нельзя. При чтении и записи файлов кодировку нужно указывать явно (см. урок про файлы).

**Одна «буква» - не всегда одна кодовая точка.** «é» может быть одной точкой (`"é"`, длина 1) или двумя (`"é"` - «e» с комбинирующим акцентом, длина 2), а на экране выглядят одинаково и не равны по `==`.
Для сравнения «как выглядит» используют нормализацию (`unicodedata.normalize`), но в рамках этого курса важно просто знать: `len` считает кодовые точки.

**Индексы и срезы.** Индексы идут от `0` до `len(s) - 1`; отрицательные считаются с конца (`-1` - последний). Выход за границу при индексировании `s[i]` вызывает `IndexError`,
а при срезе - нет: `s[2:100]` просто вернёт до конца. Срез `s[start:stop:step]` берёт элементы с индексами `start, start+step, ...` строго до `stop`; пропущенные границы подставляются автоматически,
`s[::-1]` - обращение. Срез создаёт **новую строку**, он не «окно» в старую.

**Методы.** Часто используемые: `split(sep=None)` (без аргумента делит по любым последовательностям пробельных символов и не создаёт пустых элементов; `split(" ")` создаёт пустые между двумя пробелами),
`sep.join(iterable)` (склеивает строки итерируемого объекта; вызывается *у разделителя*), `strip/lstrip/rstrip` (убирают пробельные символы по краям), `replace(old, new)`, `find` (индекс или `-1`; `index` вместо `-1` бросает `ValueError`),
`count`, `startswith/endswith`, `lower/upper`, `isalnum/isdigit/isalpha`. Проверка вхождения: `"tex" in "text"`.

**f-строки.** `f"{выражение:спецификатор}"` вычисляет выражение и форматирует результат. Спецификатор: выравнивание `<` `>` `^`, ширина, разделитель тысяч `,`, точность `.2f`, процент `.1%`, дополнение нулями `03d`. Ширина - минимум; длинное значение не обрезается.
`{x!r}` показывает `repr`, `{x=}` печатает выражение и его значение (полезно при отладке).

**Стоимость сборки.** `s += part` создаёт новую строку и копирует в неё уже накопленный текст, поэтому цикл из n шагов в общем случае делает работу порядка n² (CPython в некоторых случаях оптимизирует это, но язык такого не гарантирует).
Сборка через список частей и `"".join(parts)` копирует каждую часть один раз - O(n).

## Примеры

**Пример 1. Неизменяемость, индексы и срезы.**

```python run
s = "python"
try:
    s[0] = "P"
except TypeError:
    print("строки нельзя менять на месте")
print(s[0], s[-1], s[1:4], s[:2], s[::-1], s[::2])
print(s.upper(), s.replace("th", "TH"), s)
```
```output
строки нельзя менять на месте
p n yth py nohtyp pto
PYTHON pyTHon python
```

В последней строке `s` осталась прежней - каждый метод вернул новую строку.

**Пример 2. Методы разбора.**

```python run
print("  hello  ".strip() + "|")
print("a,b,,c".split(","))
print("a b  c".split())
print("-".join(["x", "y", "z"]))
print("hello".find("l"), "hello".find("z"), "hello".count("l"), "hello".startswith("he"))
```
```output
hello|
['a', 'b', '', 'c']
['a', 'b', 'c']
x-y-z
2 -1 2 True
```

Обратите внимание на пустой элемент в `split(",")`: два разделителя подряд дают пустую строку между ними.

**Пример 3. f-строки.**

```python run
name, price = "Хлеб", 45.5
print(f"{name:<8}|{price:>8.2f}|{7:03d}|{1234567:,}|{0.256:.1%}")
print(f"{name!r} {2 + 3=}")
```
```output
Хлеб    |   45.50|007|1,234,567|25.6%
'Хлеб' 2 + 3=5
```

**Пример 4. Кодовые точки и байты.**

```python run
w = "привет"
print(len(w), len(w.encode("utf-8")))
print(len("é"), len("é"), "é" == "é")
print(ord("a"), chr(1087), len("😀"), len("😀".encode("utf-8")))
```
```output
6 12
1 2 False
97 п 1 4
```

**Пример 5. Сборка строки.**

```python run
parts = [str(i) for i in range(5)]
print("".join(parts))
slow = ""
for p in parts:
    slow += p
print(slow == "".join(parts))
```
```output
01234
True
```

Результат одинаков; разница в том, сколько раз копируется накопленный текст при тысячах частей.

## Типичные ошибки

* **Ждать, что метод изменит строку.** `s.strip()` без присваивания ничего не делает с `s`. Пишите `s = s.strip()`.
* **Пытаться присвоить символ.** `s[0] = "P"` - `TypeError`. Соберите новую строку: `"P" + s[1:]`.
* **Путать границы среза.** `s[1:3]` - два символа, а не три: правая граница не входит. Для «последние три символа» пишите `s[-3:]`, а не `s[-3:-1]`.
* **`split(" ")` вместо `split()`.** При нескольких пробелах подряд получаются пустые строки в списке; `split()` без аргументов их не создаёт и учитывает табуляцию и переносы.
* **Вызывать `join` у списка.** `["a", "b"].join("-")` - ошибка: `join` - метод разделителя, `"-".join(["a", "b"])`. Элементы должны быть строками: числа нужно преобразовать (`map(str, numbers)`).
* **Склейка строки с числом.** `"Итого: " + 5` - `TypeError`. Используйте f-строку: `f"Итого: {5}"`.
* **Считать, что len равен числу байтов или видимых букв.** `len` считает кодовые точки; для размера в байтах нужен `len(s.encode("utf-8"))`.
* **Склейка в цикле для больших объёмов.** `result += line` для тысяч строк даёт квадратичный рост работы; собирайте список и вызывайте `join` один раз.

## Итоги

* `str` - неизменяемая последовательность кодовых точек Unicode; методы возвращают новые строки.
* Индексы с нуля, отрицательные - с конца; срез `[start:stop:step]` не включает `stop` и не вызывает `IndexError` за границами.
* `split()` без аргументов делит по любым пробелам, `sep.join(...)` собирает строку, f-строки со спецификаторами управляют шириной, выравниванием и точностью.
* `len` считает кодовые точки, а не байты: `"привет"` - 6 точек и 12 байтов UTF-8.
* Для сборки длинного текста используйте `join`, а не `+=` в цикле.
