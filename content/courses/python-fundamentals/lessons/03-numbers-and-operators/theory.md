## Два вида чисел

В Python две основные разновидности чисел: целые (`int`) и числа с плавающей точкой (`float`).
Целые - это 1, -7, 2026. Они точные: Python может хранить целое число любого размера, ограниченного только памятью, поэтому `2 ** 100` просто работает.

`float` - это приближённые числа с дробной частью: 3.14, 0.5, 1e-9. Приближённые - потому что компьютер хранит их в двоичной системе, а многие десятичные дроби в ней
бесконечны (так же, как 1/3 в десятичной записи это 0.3333...). Отсюда знаменитое `0.1 + 0.2`, которое даёт `0.30000000000000004`. Это не баг Python: так устроены числа
в любом языке, использующем стандартный формат double.

Деление в Python устроено интереснее, чем на калькуляторе. Есть три операции:

* `/` - обычное деление, всегда даёт `float`: `7 / 2` это `3.5`, а `6 / 3` это `2.0`;
* `//` - деление с округлением *вниз*: `7 // 2` это `3`;
* `%` - остаток: `7 % 2` это `1`.

Для положительных чисел вы получите ожидаемое. Подвох возникает с отрицательными: `-7 // 2` это `-4`, потому что «вниз» значит в сторону меньшего числа (-4 меньше -3.5).

## Как это работает

**int.** Целое число в CPython - объект, хранящий последовательность «цифр» по основанию 2^30. Размер растёт вместе со значением, поэтому переполнения нет;
но вычисления с огромными числами медленнее, чем с машинными целыми.

**float.** Это 64-битное число IEEE 754 (binary64): 1 бит знака, 11 бит порядка и 52 бита дробной части (плюс неявная единица, итого 53 значащих бита).
Значение равно `±(1.m) × 2^e`. Следствия:

* точность около 15-17 значащих десятичных цифр;
* большинство десятичных дробей приблизительны (0.1 хранится как ближайшее двоичное число);
* при больших значениях шаг между соседними числами растёт: `1e16 + 1 == 1e16`;
* сравнивать float через `==` ненадёжно. Сравнивайте с допуском: `math.isclose(a, b)`, либо работайте с целыми копейками или модулем `decimal`.

**Деление с округлением вниз.** Оператор `//` определён как округление вниз до целого, а `%` - как остаток, согласованный с ним тождеством
`(a // b) * b + a % b == a`. Отсюда знак остатка равен знаку *делителя*: `-7 % 2` равно `1`, `7 % -2` равно `-1`. Функция `divmod(a, b)` возвращает пару `(a // b, a % b)`.
Остаток по модулю положительного n всегда лежит в диапазоне от 0 до n - 1, что удобно для «циклических» вычислений (часы, индексы по кругу).

**Возведение в степень** `**` с неотрицательной целой степенью даёт `int`, с отрицательной или дробной - `float`: `2 ** -1` это `0.5`.

**Округление.** `round(x)` возвращает `int` и при равноудалённых значениях выбирает чётное: `round(2.5)` это `2`, `round(3.5)` это `4`. `round(x, n)` округляет до `n` знаков,
но результат ограничен двоичным представлением: `round(2.675, 2)` равно `2.67`, поскольку число 2.675 хранится чуть меньше точного значения. `int(x)` же не округляет, а *отбрасывает*
дробную часть (усечение к нулю): `int(-3.9)` это `-3`.

**Преобразования типов.** `int("12")` и `float("1.5")` разбирают строки; `int(3.9)` отбрасывает дробную часть; `str(12)` строит текст. Выражения со смешанными типами
приводятся к более «широкому»: `int + float` даёт `float`. Преобразование `float -> int` теряет информацию, а `int -> float` теряет точность для очень больших чисел.

## Примеры

**Пример 1. Двоичные дроби.**

```python run
import math
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
print(1e16 + 1 == 1e16)
print(10**16 + 1 == 10**16)
```
```output
0.30000000000000004
False
True
True
False
```

Последние две строки сравнивают одно и то же число: у float «не хватает разрядов», а у int - хватает.

**Пример 2. // и % с отрицательными числами.**

```python run
print(7 // 2, 7 % 2)
print(-7 // 2, -7 % 2)
print(7 // -2, 7 % -2)
print(divmod(-7, 2))
a, b = -7, 2
print((a // b) * b + a % b == a)
```
```output
3 1
-4 1
-4 -1
(-4, 1)
True
```

**Пример 3. Целые произвольной точности.**

```python run
n = 2 ** 100
print(n)
print(len(str(n)))
```
```output
1267650600228229401496703205376
31
```

**Пример 4. round против int.**

```python run
print(round(0.5), round(1.5), round(2.5), round(3.5))
print(round(2.675, 2))
print(int(3.9), int(-3.9))
print(7 / 2, 6 / 3, type(6 / 3).__name__, 6 // 3)
```
```output
0 2 2 4
2.67
3 -3
3.5 2.0 float 2
```

## Типичные ошибки

* **Сравнивать float через `==`.** `0.1 + 0.2 == 0.3` ложно из-за двоичных приближений. Используйте `math.isclose` или считайте в целых единицах (копейки вместо рублей).
* **Считать `//` усечением.** Для отрицательных чисел `-7 // 2` равно `-4`; усечение даёт `int(-7 / 2)`, то есть `-3`. Выберите нужное поведение осознанно.
* **Использовать `int(x + 0.5)` для округления.** Эта формула ведёт себя иначе, чем `round`, на отрицательных и «половинных» значениях. Если нужно правило «половина вверх», его надо реализовать явно.
* **Ожидать, что `round(x, 2)` напечатает два знака.** `round(2.0, 2)` выведется как `2.0`, а `round(2.50, 2)` как `2.5`. Для вывода фиксированного числа знаков используйте форматирование: `f"{x:.2f}"`.
* **Деление на ноль.** `1 / 0`, `1 // 0` и `1 % 0` вызывают `ZeroDivisionError`. Проверяйте делитель до операции.
* **Складывать строку и число.** `"5" + 3` даёт `TypeError`: Python не угадывает, что вы хотели - склеить или сложить. Преобразуйте явно.

## Итоги

* `int` точен и не переполняется; `float` - 64-битное двоичное приближение с конечной точностью.
* `/` всегда возвращает `float`; `//` округляет вниз; знак `%` совпадает со знаком делителя; `(a // b) * b + a % b == a`.
* `round` округляет к чётному и возвращает `int` без второго аргумента; `int(x)` отбрасывает дробную часть.
* Float не сравнивают через `==`; для денег используйте целые или `decimal`.
