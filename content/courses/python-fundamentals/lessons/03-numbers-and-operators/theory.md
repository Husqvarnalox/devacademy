## Числа бывают целые и дробные

Программы постоянно что-то считают: цены, количество, температуру. В Python для этого есть два основных вида чисел.
**Целое число** (`int`, от integer) не имеет дробной части: `5`, `-12`, `0`. **Дробное число** (`float`, «число с плавающей точкой»)
записывается с точкой: `3.5`, `0.25`, `-1.0`. Запятая в дробях не используется, только точка.

Для вычислений есть **арифметические операторы**: знаки действий, которые Python применяет к двум значениям.

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | обычное деление | `7 / 2` | `3.5` |
| `//` | целая часть от деления | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `2 ** 3` | `8` |

Одна важная деталь. `input()` возвращает **текст**, а не число. Чтобы считать, текст сначала превращают в число
функцией `int(...)` (для целых) или `float(...)` (для дробных). Такое превращение называется **преобразованием типа**.

Зачем это нужно: без него программа не отличит число 5 от символа «5» и не сможет правильно сложить введённые значения.

<!-- section: examples -->
## Примеры

**Пример 1. Операторы.**

```python run
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2)
print(7 // 2, 7 % 2)
print(2 ** 10)
print(8 / 2)
```
```output
9 5 14
3.5
3 1
1024
4.0
```

Разбор: `7 / 2` даёт `3.5`, а `7 // 2` - только целую часть `3`, остаток `1` получает `%`. Обратите внимание на последнюю строку:
`/` всегда возвращает дробное число, поэтому `8 / 2` равно `4.0`, а не `4`.

**Пример 2. Порядок действий.**

```python run
print(2 + 3 * 4)
print((2 + 3) * 4)
total = 100
total = total - 30
print(total)
```
```output
14
20
70
```

Умножение и деление выполняются раньше сложения и вычитания, а скобки меняют порядок. Строка `total = total - 30` читается так:
сначала справа вычисляется `100 - 30`, затем результат записывается обратно в `total`.

**Пример 3. Преобразование типов.**

```python run
text = "12"
print(text + "1")
print(int(text) + 1)
print(float("2.5") * 2)
print(int(3.9))
```
```output
121
13
5.0
3
```

Разбор: `"12" + "1"` - сложение текстов, получается `"121"`. `int(text)` создаёт число 12, к которому прибавляется 1. `float("2.5")` даёт `2.5`.
`int(3.9)` отбрасывает дробную часть (без округления) и даёт `3`.

**Пример 4. Ввод чисел.** Запустить эту программу в примере нельзя, она ждёт ввода.

```python
a = int(input())
b = int(input())
print("Сумма:", a + b)
```

Если ввести `4` и `5`, программа выведет `Сумма: 9`. Запись `int(input())` вложенная: сначала выполняется `input()` и возвращает текст, затем `int` превращает его в число.

**Попробуйте.** Предположите, что выведет `print(-7 // 2, -7 % 2)`, затем запустите. Результат с отрицательными числами часто удивляет.

## Подробнее

**`/` и `//`.** Оператор `/` всегда возвращает `float`. Оператор `//` называется **целочисленным делением**: он округляет результат вниз,
к меньшему числу. Поэтому `-7 // 2` равно `-4`, а не `-3`. Остаток `%` согласован с этим правилом: всегда выполняется
`(a // b) * b + a % b == a`. Для положительных чисел `%` равен привычному остатку.

**Деление на ноль.** `/`, `//` и `%` с нулевым делителем вызывают ошибку `ZeroDivisionError`.

**Точность дробей.** Дробные числа хранятся в двоичной форме и многие десятичные дроби представляют приближённо. Поэтому
`0.1 + 0.2` равно `0.30000000000000004`. Это свойство всех языков, а не ошибка Python. Для денег удобнее считать целыми числами
в копейках или рублях.

**Что допустимо в int.** `int("12")` работает, `int(" 12 ")` тоже (пробелы по краям игнорируются), а `int("12a")`, `int("3.5")` и `int("")` - нет.
Для строки с точкой используйте `float("3.5")`.

**Размер целых.** Целые числа в Python не переполняются: `2 ** 100` просто очень большое число.

**Целые и дробные вместе.** В выражении `3 + 0.5` результат дробный, потому что одно из чисел дробное.

## Типичные ошибки

**1. Сложение текстов вместо чисел.**

```python
a = input()
b = input()
print(a + b)
```

Для ввода `2` и `3` программа выведет `23`, а не `5`. Ошибки нет, поэтому Python не предупредит. Исправление: `int(a) + int(b)`.
Как заметить: проверьте на простом примере и спросите себя, что вернул `input`.

**2. Нечисловая строка в int.**

```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    x = int("12a")
ValueError: invalid literal for int() with base 10: '12a'
```

`ValueError` означает «значение неподходящее». Дробная запись `"3.5"` тоже не годится для `int`:

```
ValueError: invalid literal for int() with base 10: '3.5'
```

Исправление: `int(float("3.5"))` или правильный ввод. Если ввод принимает вашу же программа, проверьте, что именно приходит.

**3. Деление на ноль.**

```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(10 / 0)
          ~~~^~~
ZeroDivisionError: division by zero
```

Исправление: убедиться, что делитель не нуль, в тот момент, когда он может стать нулём (как это сделать, разберём в уроке про условия).

**4. Ожидание целого от `/`.** `10 / 2` равно `5.0`, и вывод `5.0` не совпадёт с ожидаемым `5`. Если нужен целый результат, используйте `//`.

**5. Запятая вместо точки.** `float("2,5")` вызовет `ValueError`. В Python дробная часть отделяется точкой.

## Итоги

* `int` - целые числа, `float` - дробные (с точкой).
* Операторы `+ - * / // % **`; умножение и деление выполняются раньше сложения, скобки меняют порядок.
* `/` всегда даёт `float`, `//` - целую часть (округляет вниз), `%` - остаток.
* `input()` возвращает текст; для вычислений его превращают через `int(...)` или `float(...)`.

<!-- section: programmer -->
## Для тех, кто уже программировал

* Два деления: `/` всегда `float`, `//` - floor division (округление к минус бесконечности), `%` берёт знак делителя, как в математике.
* `int` не переполняется: неограниченная точность. `float` - обычный IEEE 754 double.
* `**` - возведение в степень, а не XOR (XOR - `^`). `++` и `--` отсутствуют: пишут `x += 1`.
* Неявного приведения строки к числу нет: `"5" + 1` - `TypeError`. Приведение явное через `int()`, `float()`.
* `int(3.9)` усекает к нулю: `int(-3.9)` равно `-3`.
* `round` и форматирование чисел появятся позже; здесь `print` выводит число в его обычной записи.

## Что происходит внутри (необязательно)

Целое число в Python - это объект переменного размера: интерпретатор хранит столько «цифр», сколько нужно, поэтому `2 ** 1000` вычисляется без переполнения.
Дробное число занимает фиксированные 64 бита по стандарту IEEE 754: часть бит хранит порядок, часть - мантиссу. Многие десятичные
дроби, например `0.1`, в двоичной системе бесконечны и записываются с округлением. Отсюда `0.1 + 0.2 != 0.3`. Для точного
десятичного счёта в стандартной библиотеке есть модуль `decimal`, но для начала достаточно помнить о приближённости.
