## Собираем текст из частей

Сообщения программы обычно состоят из постоянного текста и значений: «Итого: 250 руб.», «Привет, Анна!». Можно выводить части
через запятую в `print`, но так нельзя управлять пробелами и форматом числа. Нужен способ собрать **одну строку** из кусочков.

Для этого в Python есть **f-строка** (от formatted, «форматированная»). Перед открывающей кавычкой ставится буква `f`, а значения
вставляются в **фигурные скобки**:

```python
name = "Анна"
print(f"Привет, {name}!")
```

Python вычислит всё, что стоит в скобках, превратит результат в текст и подставит на это место. Получится `Привет, Анна!`.
Внутри скобок можно писать и выражения: `{price * 2}`.

Ещё две полезные вещи. Функция `len` (от length, «длина») возвращает число символов в строке. А запись `:.2f` после значения в скобках
выводит дробное число ровно с двумя знаками после точки, что нужно для денег.

Зачем это нужно: так программа выдаёт аккуратные сообщения с точным форматом, и форматом можно управлять, а не надеяться на то, как `print` покажет число.

<!-- section: examples -->
## Примеры

**Пример 1. Подстановка значений.**

```python run
name = "Анна"
age = 31
print(f"{name} - {age} лет")
print(f"Через год будет {age + 1}")
```
```output
Анна - 31 лет
Через год будет 32
```

Разбор: в первой строке вывода `name` и `age` заменены значениями. Число не пришлось превращать в текст вручную: f-строка делает это сама. Во второй строке в скобках вычисляется `age + 1`.

**Пример 2. Формат числа.**

```python run
price = 45.5
print(price)
print(f"{price:.2f}")
print(f"{2:.2f}")
print(f"{3.14159:.2f}")
print(f"{2 / 3:.2f}")
```
```output
45.5
45.50
2.00
3.14
0.67
```

Разбор: после значения идёт двоеточие и формат. `.2f` значит «два знака после точки». Число округляется, а не обрезается: `2 / 3` превратилось в `0.67`.

**Пример 3. Склейка и длина.**

```python run
first = "Мото"
second = "цикл"
word = first + second
print(word)
print(len(word))
print(len("кот и пёс"))
print("-" + word + "-")
```
```output
Мотоцикл
8
9
-Мотоцикл-
```

Разбор: `+` между строками склеивает их без пробелов. `len(word)` считает символы, пробелы тоже символы.

**Пример 4. Что нельзя.** Строку и число складывать нельзя:

```python
count = 3
print("Товаров: " + count)
```

Python остановит программу с `TypeError`. Исправить можно так: `print(f"Товаров: {count}")` или `print("Товаров: " + str(count))`.
Вариант с f-строкой короче и читается лучше.

**Попробуйте.** Измените формат в примере 2 на `.1f` и на `.0f` и предскажите вывод.

## Подробнее

**Фигурные скобки.** Внутри f-строки `{...}` - это выражение, а не просто имя. Всё, что Python умеет вычислять (число, действие, вызов `len(...)`),
можно поставить в скобки. Чтобы вывести саму фигурную скобку, её удваивают: `f"{{{x}}}"`.

**Формат числа.** `:.2f` относится к числам: для целых и дробных даёт запись с фиксированным числом знаков, для текста - ошибку. Число можно задать любое:
`:.0f` выводит без дробной части. Ещё можно задать ширину: `{x:8.2f}` займёт минимум 8 символов, выровняв число по правому краю.

**Склейка.** `+` между строками создаёт новую строку, а `*` с числом повторяет: `"ab" * 3` даёт `"ababab"`. Для смеси текста и значений
f-строки удобнее, чем цепочки `+`.

**Кавычки внутри.** Если в f-строке в скобках используются кавычки, они должны отличаться от внешних. В старых версиях Python это обязательное правило, поэтому надёжнее использовать другой вид кавычек.

**Длина.** `len("")` равно 0. Для строки `len` считает символы, а не байты: русские буквы - по одному символу.

**Округление при печати.** Формат `.2f` только меняет вид вывода, само число в переменной остаётся прежним.

<!-- section: mistakes -->
## Типичные ошибки

**1. Забыли букву `f`.** Без неё скобки остаются обычным текстом:

```python
name = "Анна"
print("Привет, {name}!")
```

Выведет `Привет, {name}!`. Ошибки нет, поэтому её видно только в результате. Как заметить: в выводе остались фигурные скобки.

**2. Склейка текста и числа.**

```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print("Товаров: " + count)
          ~~~~~~~~~~~~^~~~~~~
TypeError: can only concatenate str (not "int") to str
```

Сообщение дословно: можно присоединять только строку, а получено `int`. Исправление: f-строка или `str(count)`.

**3. Имя в скобках не определено.**

```
NameError: name 'total' is not defined
```

Так бывает, если переменную назвали иначе или создали ниже. Проверьте имя в скобках.

**4. Длина числа.**

```
TypeError: object of type 'int' has no len()
```

`len` работает с текстом, а у числа длины нет. Если нужна длина записи числа, сначала превратите его в текст: `len(str(12345))`.

**5. Формат не для того типа.** `f"{name:.2f}"` с текстом даёт `ValueError`: формат дробного числа неприменим к строке.

## Итоги

* f-строка `f"... {значение} ..."` подставляет значения и вычисленные выражения в текст.
* `{x:.2f}` печатает число с двумя знаками после точки.
* `len(text)` возвращает число символов, включая пробелы.
* `+` склеивает только строки; число с текстом смешивать нельзя - используйте f-строку или `str()`.

<!-- section: programmer -->
## Для тех, кто уже программировал

* f-строки - основной способ форматирования (аналог шаблонных строк JS и интерполяции в C#/Kotlin). Мини-язык формата после `:` общий для `format()` и `str.format`.
* `+` для `str` и `int` не делает неявного преобразования, в отличие от JS: `"a" + 1` - `TypeError`.
* Строки в Python неизменяемы и состоят из символов Unicode; `len` возвращает число кодовых точек, а не байт.
* `:.2f` округляет по точному двоичному значению числа, поэтому `f"{2.675:.2f}"` даёт `2.67`, а не `2.68`.
* Для кошельков и денег `float` не подходит; обычно используют целые копейки или `decimal`.

<!-- section: deep-dive -->
## Что происходит внутри (необязательно)

f-строка не является отдельным типом: после выполнения получается обычная `str`. Интерпретатор вычисляет каждое выражение в скобках,
вызывает для результата метод форматирования (с учётом части после `:`) и склеивает кусочки в одну строку. Поэтому такая запись
обычно быстрее цепочки `+`: промежуточные строки не создаются. Спецификация формата (`.2f`, ширина, выравнивание) описана в документации
языка как «Format Specification Mini-Language» и одинакова для `format()`.
