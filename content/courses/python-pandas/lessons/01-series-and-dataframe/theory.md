## Таблица с подписями

Массив NumPy знает только позиции: «третий элемент». Таблица из реальной жизни устроена иначе: у строки есть смысл («заказ 1007», «датчик S03»), у столбца тоже («цена», «дата»). **pandas** добавляет к массивам NumPy эти подписи:

* **Series** — одномерный столбец значений с **индексом** (`index`): подписями строк;
* **DataFrame** — таблица: набор Series с общим индексом строк и подписями столбцов (`columns`).

Подписи — не украшение. Главное правило pandas: **операции выравнивают данные по подписям, а не по позициям**. Если сложить две Series, значения складываются «подпись к подписи», и там, где пары нет, появляется пропуск `NaN`. Для новичка это самый частый сюрприз: код не падает, а таблица внезапно заполняется пропусками.

У каждого столбца свой **dtype** (тип), как у массива NumPy, и этим pandas отличается от списка списков: столбец `qty` хранится как компактный массив целых, а столбец с названиями — как строковый тип `str`.

## Индекс, dtype и связь с NumPy

**Series** состоит из значений, индекса и dtype. Значения — это массив (чаще всего `ndarray`), к ним можно обратиться через `s.to_numpy()`. Индекс — отдельный объект `pd.Index`; его метки не обязаны быть уникальными или числовыми. Если индекс не задан, создаётся `RangeIndex` `0..n-1`.

**DataFrame** — упорядоченный набор столбцов; каждый столбец — Series с общим индексом и своим dtype. `df.dtypes` показывает типы по столбцам, `df.shape` — `(строк, столбцов)`, `df.index` и `df.columns` — подписи. В установленной версии pandas 3.0 строки по умолчанию получают специальный dtype `str` (раньше это был `object` из Python-объектов); пропуск в строковом столбце — это `NaN`.

**Два способа выбрать данные.**

* `loc` — по **меткам**. Срез `s.loc["a":"c"]` включает обе границы.
* `iloc` — по **позициям**, как в списках Python: `s.iloc[0:2]` — первые две строки, правая граница не включается.

Эти способы совпадают только пока метки индекса равны `0..n-1`. После фильтрации или сортировки метки «ломаются», и `s.loc[0]` и `s.iloc[0]` — разные вещи.

**Выравнивание (alignment).** Бинарная операция над Series и DataFrame сначала строит объединение индексов (для DataFrame — ещё и столбцов), а затем применяет операцию к парам с одинаковой меткой. Метка, которой нет с одной стороны, даёт `NaN`; из-за `NaN` целочисленный результат становится `float64`. Чтобы заполнить отсутствующие пары, используйте методы `s.add(other, fill_value=0)`. Чтобы складывать **по позиции**, а не по меткам, возьмите массивы: `a.to_numpy() + b.to_numpy()`.

**Связь с NumPy.** Числовой столбец поверх своего массива NumPy: работают привычные ufunc (`np.sqrt(s)`), векторные операции и dtype `int64`/`float64`. Но данные Series в pandas 3 не разделяют память с ndarray, из которого их создали (см. пример), а `to_numpy()` возвращает массив, который не стоит изменять.

## Примеры

**Пример 1. Series: значения, индекс, dtype.**

```python run
import pandas as pd

stock = pd.Series([12, 0, 7], index=["pen", "lamp", "desk"], name="stock")
print(stock)
print(stock.index.tolist(), stock.dtype, stock.shape)
print(stock.to_numpy())
print(stock["lamp"], stock.loc["lamp"], stock.iloc[1])
```
```output
pen     12
lamp     0
desk     7
Name: stock, dtype: int64
['pen', 'lamp', 'desk'] int64 (3,)
[12  0  7]
0 0 0
```

Метка `"lamp"` и позиция `1` указывают на один и тот же элемент.

**Пример 2. DataFrame и dtypes.**

```python run
import pandas as pd

pd.set_option("display.width", 80)
df = pd.DataFrame(
    {"product": ["pen", "lamp", "desk"], "qty": [12, 0, 7], "price": [1.5, 24.0, 199.0]},
    index=[101, 102, 103],
)
print(df)
print(df.dtypes)
print(df.shape, df.index.tolist(), df.columns.tolist())
```
```output
    product  qty  price
101     pen   12    1.5
102    lamp    0   24.0
103    desk    7  199.0
product        str
qty          int64
price      float64
dtype: object
(3, 3) [101, 102, 103] ['product', 'qty', 'price']
```

**Пример 3. loc и iloc расходятся после фильтрации.**

```python run
import pandas as pd

s = pd.Series([5, 6, 7, 8], index=[10, 20, 30, 40])
big = s[s > 5]
print(big)
print("iloc[0] ->", big.iloc[0], "| loc[20] ->", big.loc[20])
print("loc 20:30 включает правый конец:", big.loc[20:30].tolist())
print("iloc 0:2 не включает правый конец:", big.iloc[0:2].tolist())
```
```output
20    6
30    7
40    8
dtype: int64
iloc[0] -> 6 | loc[20] -> 6
loc 20:30 включает правый конец: [6, 7]
iloc 0:2 не включает правый конец: [6, 7]
```

**Пример 4. Выравнивание по индексу.**

```python run
import pandas as pd

a = pd.Series([1, 2, 3], index=["x", "y", "z"])
b = pd.Series([10, 20, 30], index=["y", "z", "w"])
print(a + b)
print((a + b).dtype)
print(a.add(b, fill_value=0))
print("по позиции:", (a.to_numpy() + b.to_numpy()).tolist())
```
```output
w     NaN
x     NaN
y    12.0
z    23.0
dtype: float64
float64
w    30.0
x     1.0
y    12.0
z    23.0
dtype: float64
по позиции: [11, 22, 33]
```

Сумма не похожа на `[11, 22, 33]`, которую ожидает новичок: `y` и `z` сложились с парами, а у `x` и `w` пары нет, поэтому там `NaN`, а целые числа превратились в `float64`.

**Пример 5. Связь с NumPy.**

```python run
import numpy as np
import pandas as pd

arr = np.array([1.0, 4.0, 9.0])
s = pd.Series(arr, index=list("abc"))
print(np.sqrt(s).to_dict())
s.iloc[0] = 100.0
print("исходный массив не изменился:", arr.tolist(), "| общая память:", np.shares_memory(arr, s.to_numpy()))
print("writeable у to_numpy():", s.to_numpy().flags.writeable)
```
```output
{'a': 1.0, 'b': 2.0, 'c': 3.0}
исходный массив не изменился: [1.0, 4.0, 9.0] | общая память: False
writeable у to_numpy(): False
```

## Типичные ошибки

* **Считать, что `+` складывает по позициям.** Складывается по меткам; несовпавшие метки дают `NaN`. Проверяйте `a.index.equals(b.index)` или явно выберите правило: `fill_value`, `reindex` или позиционное сложение через `to_numpy()`.
* **Путать `loc` и `iloc` на числовом индексе.** После фильтрации `s.loc[0]` может бросить `KeyError`, а `s.iloc[0]` вернёт первую строку. Пишите явно `loc` или `iloc`, а не `s[0]`.
* **Ждать, что срез `loc` исключает правую границу.** Срез по меткам включает её.
* **Не смотреть на dtypes.** Столбец из чисел, прочитанных как строки, не суммируется; `NaN` превращает `int64` в `float64`.
* **Считать, что Series — это «обёртка» над исходным массивом NumPy.** В установленной версии (pandas 3.0) конструктор копирует данные из ndarray, поэтому изменение Series не меняет массив.
* **Использовать неуникальный индекс, не замечая этого.** `loc` по повторяющейся метке вернёт несколько строк, а не одно значение.

## Итоги

* Series — значения плюс индекс; DataFrame — набор Series с общим индексом и своими dtype у каждого столбца.
* `loc` работает по меткам и включает правую границу среза, `iloc` — по позициям и её не включает.
* Арифметика выравнивает по меткам: несовпавшие метки дают `NaN`, а целые превращаются в `float64`; `fill_value` или `to_numpy()` задают другое правило.
* Всегда смотрите на `dtypes`, `shape` и `index`, прежде чем доверять результату.
