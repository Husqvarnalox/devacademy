## PHP-файл - это шаблон с кодом внутри

Файл `main.php` выполняет программа `php`. В отличие от большинства языков, PHP-файл по умолчанию считается **текстом**, а код внутри него
выделяют тегами `<?php ... ?>`. Всё, что лежит вне тегов, интерпретатор выводит как есть. Так PHP появился: он вставлялся в HTML-страницы.

```php
<?php
echo "Привет!\n";
```

Первая строка `<?php` открывает режим кода. В файлах, состоящих только из кода, закрывающий тег `?>` не пишут: так в вывод случайно не попадёт пробел или перевод строки после него.

Вывод делает `echo` (это языковая конструкция, а не функция) или `printf`. Всё попадает в **стандартный вывод** (stdout). Ввод читается из **стандартного ввода**, который в консольном режиме доступен как константа `STDIN`:

```php
$text = stream_get_contents(STDIN);
```

## Как Zend Engine выполняет скрипт

Выполнением PHP занимается **Zend Engine**. Путь файла от текста до результата такой:

1. **Лексер и парсер** разбирают исходный текст в абстрактное синтаксическое дерево (AST). Синтаксическая ошибка находится здесь, до выполнения любой строки.
2. **Компиляция в опкоды.** Из дерева строится список низкоуровневых инструкций - **опкодов** (opcodes). Это байткод PHP.
3. **Выполнение.** Виртуальная машина Zend читает опкоды и выполняет их по одному.

Обычно такой цикл повторяется при каждом запуске скрипта. Расширение **OPcache** хранит готовые опкоды в общей памяти, чтобы не разбирать один и тот же файл заново при каждом запросе.
В консольном режиме (`php main.php`) OPcache по умолчанию выключен (`opcache.enable_cli=0`), потому что скрипт запускается один раз. Начиная с PHP 8.0 в OPcache доступен и **JIT**:
он превращает часть опкодов в машинный код, но по умолчанию выключен и ощутимо помогает в основном при вычислениях, а не при типичной веб-нагрузке.

**Время жизни.** Классическая модель PHP - «ничего не разделяется»: каждый запрос (или запуск скрипта из консоли) начинается с чистого состояния, выполняется и умирает вместе со всеми переменными.
Состояние между запросами сохраняют во внешних хранилищах: базе данных, файлах, кэше. Для нашего консольного скрипта это означает, что программа читает ввод, считает и завершается.

**Ввод и вывод в CLI.** Константы `STDIN`, `STDOUT`, `STDERR` - открытые потоки. `fgets(STDIN)` читает строку вместе с символом `\n` (и возвращает `false` в конце ввода),
`stream_get_contents(STDIN)` читает всё до конца. `echo` и `print` пишут в stdout; `fwrite(STDERR, ...)` - в stderr. `PHP_EOL` - перевод строки текущей платформы.

**Типы чисел.** В PHP есть `int` (64-битное знаковое на 64-битных платформах) и `float` (IEEE 754 двойной точности). Выход `int` за границы **не оборачивается**:
`PHP_INT_MAX + 1` превращается в `float` (`9.2233720368548E+18`). Оператор `/` возвращает `int`, если деление нацело (`6 / 2` - `3`), иначе `float` (`7 / 2` - `3.5`); целочисленное деление - `intdiv(7, 2)`.

**Вывод `float`.** `echo 0.1 + 0.2` печатает `0.3`: `echo` округляет до `precision` (по умолчанию 14) значащих цифр, а `var_dump` показывает точное представление: `float(0.30000000000000004)`.
Для денег и отчётов форматируют явно: `sprintf("%.2F", $x)`. Заглавная `F` не зависит от локали, а `f` - зависит.

**Преобразование из строк.** `(int) "42abc"` - `42`: число читается с начала строки. `intval("  7 ")` - `7`. `(int) "abc"` - `0` без ошибки. Для проверки `is_numeric($s)`.

**Разбор текста.** `preg_split('/\s+/', trim($text))` режет по любым пробельным символам; `explode(" ", $s)` - только по одному пробелу и для нескольких пробелов даёт пустые элементы.

## Примеры

**Пример 1. Текст вне тегов - это вывод.**

```php run
Заголовок до кода
<?php
echo "из кода\n";
?>
Текст после кода
```
```output
Заголовок до кода
из кода
Текст после кода
```

Строки вне `<?php ... ?>` PHP вывел дословно. Перевод строки сразу после закрывающего `?>` PHP отбрасывает, поэтому строки склеились без пустой.

**Пример 2. `echo` и `var_dump` по-разному показывают числа.**

```php run
<?php
echo 0.1 + 0.2, "\n";
var_dump(0.1 + 0.2);
var_dump(6 / 2, 7 / 2, intdiv(7, 2));
echo PHP_INT_MAX + 1, "\n";
```
```output
0.3
float(0.30000000000000004)
int(3)
float(3.5)
int(3)
9.2233720368548E+18
```

`var_dump` печатает тип и точное значение, это основной инструмент отладки. Переполнение `int` даёт `float`.

**Пример 3. Преобразование строк.**

```php run
<?php
var_dump((int) "42abc", (int) "abc", intval("  7 "), is_numeric("1e3"), (float) "2.50");
printf("%.2F|%5d|%s\n", 2.5, 42, "ok");
```
```output
int(42)
int(0)
int(7)
bool(true)
float(2.5)
2.50|   42|ok
```

Приведение не бросает ошибок: плохую строку оно превращает в `0`. Поэтому ввод нужно проверять самим, если он не гарантирован.

**Пример 4. Весь ввод.**

```php
<?php
$text = stream_get_contents(STDIN);
$tokens = preg_split('/\s+/', trim($text));
$n = (int) $tokens[0];
echo $n, PHP_EOL;
```

## Типичные ошибки

* **Пробел или пустая строка после `?>`.** Всё вне тегов уходит в вывод. В чисто программных файлах `?>` не пишут вовсе.
* **`echo` без `PHP_EOL` или `"\n"`.** Строки склеятся. Обратите внимание: перевод строки внутри одинарных кавычек - два символа, внутри двойных `"\n"` - один.
* **Одинарные и двойные кавычки.** В `'a $x \n'` переменные и `\n` не подставляются, в `"a $x \n"` - подставляются.
* **Деление `/` и целые числа.** `7 / 2` - `3.5`, а не `3`. Для целой части - `intdiv`. Деление на ноль бросает `DivisionByZeroError`.
* **`explode(" ", $line)` для ввода с несколькими пробелами.** Появляются пустые элементы, а `(int) ""` равно `0`. Используйте `preg_split('/\s+/', trim($line))`.
* **`fgets` и конец строки.** Результат содержит `\n`: сравнение `"yes" === "yes\n"` ложно. Используйте `trim(fgets(STDIN))`.
* **Печать `float` через `echo` для отчётов.** Для двух знаков после точки нужен `sprintf("%.2F", ...)`; `echo` округляет до 14 значащих цифр и может выдать экспоненциальную запись.
* **Ожидать, что `(int)` проверит ввод.** `(int) "abc"` молча даёт `0`.

<!-- section: summary -->
## Итоги

* `php` разбирает файл Zend Engine, компилирует в опкоды (байткод) и выполняет их в виртуальной машине; OPcache хранит опкоды, JIT (с PHP 8.0) - необязательный слой.
* Всё вне `<?php ... ?>` - это вывод. В файлах без разметки закрывающий тег не пишут.
* Ввод: `STDIN`, `fgets`, `stream_get_contents`; вывод: `echo`, `printf`, `STDERR` для диагностики.
* `int` при переполнении становится `float`; `/` может вернуть и `int`, и `float`; для формата используйте `sprintf("%.2F")`.
