## Что проверяет эта проверка

Ввод и ошибки: чтение через `std::cin`, состояние потока при неудачном чтении, преобразование строк в числа (`std::stoi`, `std::stod`), приведение `static_cast`, исключения `std::invalid_argument` и `std::out_of_range`, `try` и `catch`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Ввод данных: std::cin](lesson:cpp.from-zero.reading-input), [Преобразование типов](lesson:cpp.from-zero.type-conversion), [Исключения: try, catch и throw](lesson:cpp.from-zero.exceptions).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

## Пример того, что понадобится

```cpp run
#include <iostream>
#include <stdexcept>
#include <string>

bool parseWhole(const std::string& text, int& out) {
    try {
        std::size_t used = 0;
        int value = std::stoi(text, &used);
        if (used != text.size()) {
            return false;
        }
        out = value;
        return true;
    } catch (const std::invalid_argument&) {
        return false;
    } catch (const std::out_of_range&) {
        return false;
    }
}

int main() {
    for (const std::string text : {"42", "4x", "x4", "99999999999", "-7"}) {
        int value = 0;
        if (parseWhole(text, value)) {
            std::cout << text << " -> " << value << "\n";
        } else {
            std::cout << text << " -> ошибка\n";
        }
    }
    std::cout << static_cast<int>(2.9) << " " << static_cast<int>(-2.9) << " " << std::stod("2.5kg") << "\n";
}
```
```output
42 -> 42
4x -> ошибка
x4 -> ошибка
99999999999 -> ошибка
-7 -> -7
2 -2 2.5
```

Функция `parseWhole` вызывает `std::stoi` с вторым аргументом: `used` получает число разобранных символов. Строка `4x` разобрана не целиком (`used` равно 1, а длина 2), `x4` не содержит числа в начале (исключение `std::invalid_argument`), `99999999999` не помещается в `int` (`std::out_of_range`). Обе ошибки перехвачены по `const&`. Преобразование `static_cast<int>` отбрасывает дробную часть к нулю, а `std::stod("2.5kg")` разбирает только начало строки.

## Что нужно уметь

* читать числа и слова через `std::cin >> x` и понимать, что при неудаче поток переходит в состояние ошибки;
* использовать результат чтения как условие: `while (std::cin >> x)`, `if (!(std::cin >> x))`;
* переводить строки в числа и обратно (`std::stoi`, `std::stod`, `std::to_string`) и знать, что разбирается только начало строки;
* проверять, что разобрана вся строка, через второй параметр `std::size_t*`;
* различать `std::invalid_argument` (нет числа) и `std::out_of_range` (не помещается в тип);
* перехватывать исключения по `const&` и ставить частные типы выше общих;
* считать и пропускать некорректные строки вместо аварийного завершения.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Считать, что `std::stoi("12abc")` бросит исключение: функция вернёт `12`.
* Забыть `try`: исключение из `stoi` без обработчика завершает программу.
* Перехватывать только одно из двух исключений разбора.
* Принимать `nan` и `inf`: `std::stod` разбирает эти слова, а проверка `value > 0` их отвергает.
* Продолжать использовать переменную после неудачного чтения: она содержит `0` или старое значение.
* Приведение `static_cast<double>(a / b)` вместо `static_cast<double>(a) / b`: деление уже выполнено над целыми.
* Использовать исключение для обычного отказа внутри цикла по большому вводу, когда достаточно вернуть `false`.
