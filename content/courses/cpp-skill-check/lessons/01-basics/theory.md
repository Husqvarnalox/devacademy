## Что проверяет эта проверка

Основы C++: переменные и типы, арифметика (целочисленное деление, остаток, `long long`), вывод с `std::fixed` и `std::setprecision`, чтение через `std::cin`, условия и логические операторы, `switch`, циклы `while` и `for`, `break` и `continue`.

## Что даёт прохождение

Проверка состоит из короткой программы с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки 01-16 курса «C++ с нуля», начиная с [Первая программа](lesson:cpp.from-zero.first-program) и заканчивая [break, continue и вложенные циклы](lesson:cpp.from-zero.loop-control).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

## Пример того, что понадобится

```cpp run
#include <iomanip>
#include <iostream>

int main() {
    int a = 7;
    int b = 2;
    std::cout << a / b << " " << a % b << " " << static_cast<double>(a) / b << "\n";

    long long big = 3000000000LL;
    std::cout << big * 2 << "\n";

    double price = 19.5;
    std::cout << std::fixed << std::setprecision(2) << price * 3 << "\n";

    int count = 0;
    int i = 10;
    while (i > 0) {
        i -= 3;
        count++;
    }
    std::cout << count << " " << i << "\n";

    for (int n = 1; n <= 8; n++) {
        if (n % 2 == 0) {
            continue;
        }
        if (n > 5) {
            break;
        }
        std::cout << n << (n < 5 ? "," : "\n");
    }

    int grade = 3;
    switch (grade) {
    case 3:
        std::cout << "три ";
    case 2:
        std::cout << "два";
        break;
    default:
        std::cout << "другое";
    }
    std::cout << "\n";
}
```
```output
3 1 3.5
6000000000
58.50
4 -2
1,3,5
три два
```

Деление двух `int` целочисленное (`7 / 2` равно `3`), остаток даёт `%`; чтобы получить `3.5`, одно из чисел приводят к `double`. Суммы, которые могут превысить два миллиарда, считают в `long long`. Манипуляторы `std::fixed` и `std::setprecision(2)` задают два знака после запятой. Цикл `while` выполняется, пока условие истинно; `continue` пропускает остаток тела, `break` выходит из цикла. В `switch` без `break` выполнение «проваливается» в следующую метку.

## Что нужно уметь

* объявлять и инициализировать переменные `int`, `long long`, `double`, `bool`, `char`, `std::string`;
* предсказывать результат целочисленного деления и `%` для положительных и отрицательных чисел;
* считать суммы и произведения в `long long` и понимать, что переполнение знакового `int` - неопределённое поведение;
* читать числа через `std::cin >> x` и обрабатывать ввод «до конца данных» циклом `while (std::cin >> x)`;
* печатать числа с фиксированным числом знаков после запятой;
* писать условия с `&&`, `||`, `!`, знать про короткое вычисление;
* выбирать между `if`, `switch`, `while`, `for` и применять `break` и `continue`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Деление `int / int` там, где ждут дробный результат.
* Неинициализированная переменная: чтение её значения - неопределённое поведение.
* Сумма в `int`, которая переполняется на больших данных.
* Среднее по пустому набору: деление на ноль в `double` даёт `nan` или `inf`, а в `int` - UB.
* `=` вместо `==` в условии.
* Забытый `break` в `switch`.
* Цикл, который не заканчивается: счётчик не меняется или условие всегда истинно.
* Залипающие манипуляторы: `std::fixed` остаётся включённым для всех следующих выводов.
