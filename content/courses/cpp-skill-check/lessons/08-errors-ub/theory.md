## Что проверяет эта проверка

Обработку ошибок и безопасную работу с числами: `std::optional` для «нет значения», строгий разбор числа через `std::from_chars`, проверку переполнения знаковых целых до операции, исключения (какой тип бросать, ловить по `const&`, порядок `catch`), `noexcept`. А также неопределённое поведение: выход за границы массива и `vector` (`[]` против `.at()`), переполнение `int`, оборачивание беззнаковых чисел.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Обработка ошибок: исключения, noexcept, optional и expected](lesson:cpp.fundamentals.error-handling), [Неопределённое поведение и санитайзеры](lesson:cpp.fundamentals.undefined-behaviour).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

## Пример того, что понадобится

```cpp run
#include <charconv>
#include <climits>
#include <iostream>
#include <optional>
#include <stdexcept>
#include <string>
#include <system_error>
#include <vector>

std::optional<int> parse(const std::string& s) {
    int value = 0;
    const char* last = s.data() + s.size();
    auto result = std::from_chars(s.data(), last, value);
    if (result.ec != std::errc() || result.ptr != last) {
        return std::nullopt;
    }
    return value;
}

std::optional<int> addChecked(int a, int b) {
    if (b > 0 && a > INT_MAX - b) {
        return std::nullopt;
    }
    if (b < 0 && a < INT_MIN - b) {
        return std::nullopt;
    }
    return a + b;
}

int main() {
    for (std::string s : {"42", "-7", "12x", "99999999999", ""}) {
        std::optional<int> v = parse(s);
        std::cout << (v ? std::to_string(*v) : "none") << "\n";
    }

    std::cout << addChecked(INT_MAX, 1).has_value() << " " << addChecked(INT_MAX, -1).value_or(0) << "\n";

    std::vector<int> v{1, 2, 3};
    try {
        std::cout << v.at(10) << "\n";
    } catch (const std::out_of_range&) {
        std::cout << "out of range\n";
    }

    std::size_t n = 2;
    std::size_t m = 3;
    std::cout << (n - m > 0) << " " << (n < m ? 0 : n - m) << "\n";
}
```
```output
42
-7
none
none
none
0 2147483646
out of range
1 0
```

`from_chars` разбирает число с начала строки и сообщает, где остановился, поэтому `12x` нужно отвергать самостоятельно (`ptr != last`). Переполнение `int` нельзя проверять после сложения: само сложение уже неопределённое поведение, проверка делается до него. Для беззнаковых чисел `2 - 3` не отрицательное число, а огромное: проверять нужно до вычитания. Метод `at` бросает исключение, а оператор `[]` границ не проверяет.

<!-- section: precise -->
## Что нужно уметь

* возвращать `std::optional<T>`, когда результата может не быть, и проверять его перед `*opt`;
* разбирать число целиком: `std::from_chars` плюс проверки `ec` и `ptr == last`;
* проверять переполнение знакового сложения, вычитания и деления (`INT_MIN / -1`) до операции;
* ловить исключения по `const&`, ставить более специфичные `catch` раньше общих и знать иерархию (`out_of_range` - это `logic_error`, а не `runtime_error`);
* знать, что исключение, вышедшее из `noexcept`-функции, вызывает `std::terminate`;
* отличать `v[i]` (нет проверки, выход за границы - неопределённое поведение) от `v.at(i)` (исключение `std::out_of_range`);
* помнить, что беззнаковые числа переполняются по модулю (`0u - 1u` - большое число), а знаковое переполнение - неопределённое поведение.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Проверка `if (a + b < a)` для `int` после сложения: сложение уже могло быть неопределённым поведением.
* Принятие строки `12x` как числа `12` из-за непроверенного `ptr`.
* Ловля исключения по значению (`catch (std::exception e)`): срезка и лишнее копирование.
* Неправильный порядок `catch`: общий обработчик `std::exception` раньше специфичного перекрывает его.
* Ожидание, что `v[i]` бросит исключение при выходе за границы.
* Вычитание беззнаковых `a - b` при `a < b` или цикл `for (std::size_t i = n - 1; i >= 0; --i)`: условие всегда истинно.
* Деление `INT_MIN / -1`: переполнение, как и сложение.
