## Что проверяет эта проверка

Владение и заимствование: перемещение `String` при присваивании и передаче в функцию, копирование простых типов, `&` и `&mut`, правило «одна изменяемая ссылка или любое число читающих», `clone`, функция, возвращающая ссылку, и аннотация времени жизни `<'a>`.

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Владение: значение принадлежит одной переменной](lesson:rust.from-zero.ownership-basics), [Владение, перемещение и заимствование](lesson:rust.first-steps.ownership-moves-and-borrowing), [Владение и перемещения подробно](lesson:rust.fundamentals.ownership-and-moves-in-depth), [Заимствование и времена жизни](lesson:rust.fundamentals.borrowing-and-lifetimes).

## Пример того, что понадобится

```rust run
fn longer<'a>(a: &'a str, b: &'a str) -> &'a str {
    if b.len() > a.len() { b } else { a }
}

fn add_mark(names: &mut Vec<String>) {
    for name in names.iter_mut() {
        name.push('!');
    }
}

fn consume(text: String) -> usize {
    text.len()
}

fn main() {
    let first = String::from("alpha");
    let second = String::from("be");
    println!("{}", longer(&first, &second));

    let mut names = vec![String::from("ann"), String::from("bob")];
    add_mark(&mut names);
    println!("{:?}", names);

    let copy = first.clone();
    println!("{}", consume(first));
    println!("{}", copy);

    let n = 7;
    let m = n;
    println!("{n} {m}");
}
```

```output
alpha
["ann!", "bob!"]
5
alpha
7 7
```

Строка `first` передаётся в `consume` по значению, то есть **перемещается**: после этого вызова использовать её нельзя, поэтому до него сделана копия `copy` через `clone()`. Число `n` относится к простым типам с копированием, и после `let m = n` обе переменные остаются доступными. В `longer` и `add_mark` значения не отдаются, а одалживаются: `&` читает, `&mut` меняет. Аннотация `<'a>` в `longer` говорит компилятору, что результат живёт не дольше обоих аргументов.

## Что нужно уметь

* сказать по коду, какие переменные ещё доступны после присваивания или вызова функции, и объяснить почему;
* различать типы, которые копируются (`i32`, `bool`, `char`, `f64`), и типы, которые перемещаются (`String`, `Vec`);
* выбирать между передачей по значению, по `&` и по `&mut` исходя из того, что функция делает со значением;
* помнить правило: в один момент либо одна изменяемая ссылка, либо любое число читающих, и они не живут одновременно с конфликтом;
* писать функцию, возвращающую ссылку на один из аргументов, с явным временем жизни;
* пользоваться `clone()` осознанно: как явную цену за второй экземпляр, а не как способ заглушить ошибку.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Использовать переменную после передачи её в функцию по значению (`E0382`).
* Брать ссылку на элемент вектора, а потом вызывать `push`: изменение может перенести буфер и испортить ссылку (`E0502`).
* Объявить переменную без `mut` и передать `&mut` (`E0596`).
* Вернуть ссылку на локальную переменную функции (`E0515`) или забыть аннотацию времени жизни при двух ссылочных аргументах (`E0106`).
* Обойти любую ошибку владения вызовом `clone()`, не поняв, что именно перемещается.
* Ждать, что присваивание `let t = s;` для `String` копирует строку: оно перемещает владение.
