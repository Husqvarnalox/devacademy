## Что проверяет эта проверка

Трейты и обобщения: объявление `trait` с обязательными методами и методами по умолчанию, `impl Trait for Type`, обобщённые функции `fn f<T: Trait>(x: &T)`, ограничения `T: A + B`, объекты трейтов `&dyn Trait` и `Box<dyn Trait>`, и когда выбирать обобщения, а когда объекты трейтов.

## Пример того, что понадобится

```rust run
trait Animal {
    fn name(&self) -> String;
    fn sound(&self) -> String;
    fn speak(&self) -> String {
        format!("{} says {}", self.name(), self.sound())
    }
}

struct Dog;
struct Cat { lives: u32 }

impl Animal for Dog {
    fn name(&self) -> String { "dog".to_string() }
    fn sound(&self) -> String { "woof".to_string() }
}

impl Animal for Cat {
    fn name(&self) -> String { format!("cat({})", self.lives) }
    fn sound(&self) -> String { "meow".to_string() }
    fn speak(&self) -> String { "...".to_string() }
}

fn describe<T: Animal>(animal: &T) -> String {
    animal.speak()
}

fn largest<T: PartialOrd + Copy>(items: &[T]) -> T {
    let mut best = items[0];
    for &item in items {
        if item > best {
            best = item;
        }
    }
    best
}

fn main() {
    println!("{}", describe(&Dog));
    println!("{}", describe(&Cat { lives: 9 }));
    let zoo: Vec<Box<dyn Animal>> = vec![Box::new(Dog), Box::new(Cat { lives: 7 })];
    for a in &zoo {
        println!("{}", a.name());
    }
    println!("{} {}", largest(&[3, 9, 4]), largest(&['a', 'z', 'c']));
}
```

```output
dog says woof
...
dog
cat(7)
9 z
```

Трейт `Animal` описывает поведение: два метода обязательны, а `speak` имеет реализацию по умолчанию, которую `Cat` переопределяет. Функция `describe<T: Animal>` принимает любой тип с этим трейтом, и компилятор создаёт для каждого использованного типа отдельную копию (статическая диспетчеризация). `Vec<Box<dyn Animal>>` хранит значения разных типов вместе, а нужный метод выбирается во время работы программы. Ограничение `T: PartialOrd + Copy` в `largest` обещает, что значения можно сравнивать и копировать.

## Что нужно уметь

* объявить трейт с обязательными методами и методом по умолчанию и реализовать его для нескольких типов;
* написать обобщённую функцию с ограничением `T: Trait` и вызвать её с разными типами;
* объяснить, почему в функции без ограничений нельзя печатать или сравнивать значение типа `T`;
* использовать `&dyn Trait` или `Box<dyn Trait>` для хранения разных типов в одной коллекции;
* выбирать между обобщением (быстро, типы известны при компиляции) и объектом трейта (гибко, диспетчеризация во время работы);
* помнить, что `impl Trait for Type` должен содержать все обязательные методы (`E0046`).

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Вызвать `println!("{}", x)` для `x: T` без ограничения `T: Display` (`E0277`).
* Реализовать трейт не полностью: забыть обязательный метод (`E0046`).
* Сравнивать значения `T` оператором `>` без `T: PartialOrd`.
* Положить в `Vec<dyn Trait>` без `Box`: размер значения должен быть известен.
* Использовать объект трейта там, где достаточно обобщения, и платить за динамическую диспетчеризацию без нужды.
* Забыть `Copy` или `Clone` и пытаться вернуть значение из среза: без них элемент нельзя взять из `&[T]`.
