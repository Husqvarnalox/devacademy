## Зачем программе выбор

До сих пор программа выполняла все команды подряд, сверху вниз, и одинаково при любых данных. Реальным программам этого мало: нужно проверить возраст и решить, пустить ли человека; сравнить температуру с нулём и посоветовать шапку; увидеть неверный ввод и сообщить об этом. Во всех таких случаях программа **выбирает**, какой кусок кода выполнить.

Выбор делает **условный оператор** `if` («если»). Вы уже умеете составлять условия: это выражения, которые дают `true` или `false` (прошлый урок). Теперь эти условия начнут управлять программой.

## Одна новая идея: `if` выбирает, выполнять ли блок

```rust
if условие {
    // эти команды выполняются, если условие истинно
} else {
    // эти команды выполняются, если условие ложно
}
```

Фигурные скобки `{ ... }` ограничивают **блок**: группу команд, которая выполняется целиком или не выполняется совсем. Ветка `else` («иначе») необязательна. Круглые скобки вокруг условия не нужны, а фигурные обязательны всегда, даже если в блоке одна команда.

Условие должно быть именно `bool`. Число или строка не считается «истинным» или «ложным», поэтому вместо `if n` пишут `if n != 0`.

<!-- section: examples -->
## Пример 1. `if` и `else`

```rust run
fn main() {
    let age = 20;
    if age >= 18 {
        println!("Вход разрешён");
    } else {
        println!("Вход закрыт");
    }
    println!("Проверка закончена");
}
```
```output
Вход разрешён
Проверка закончена
```

* Условие `age >= 18` истинно, поэтому выполняется первый блок. Блок `else` пропускается.
* Строка «Проверка закончена» стоит после `if` и выполняется в любом случае: блоки управляют только своими командами.

**Попробуйте.** Поставьте `age = 15` и убедитесь, что выводится «Вход закрыт», а последняя строка по-прежнему печатается. Затем поменяйте `>=` на `>` и подберите возраст, при котором результат изменится.

## Пример 2. Цепочка `else if`

```rust run
fn main() {
    let score = 72;
    if score >= 90 {
        println!("Оценка: отлично");
    } else if score >= 75 {
        println!("Оценка: хорошо");
    } else if score >= 60 {
        println!("Оценка: удовлетворительно");
    } else {
        println!("Оценка: неудовлетворительно");
    }

    let n = 15;
    if n % 3 == 0 {
        println!("делится на 3");
    } else if n % 5 == 0 {
        println!("делится на 5");
    }
}
```
```output
Оценка: удовлетворительно
делится на 3
```

* Проверки идут **сверху вниз**. Как только какое-то условие оказалось истинным, выполняется его блок, а остальные проверки не делаются вовсе.
* Для `score = 72` первое условие (`>= 90`) ложно, второе (`>= 75`) ложно, третье (`>= 60`) истинно: печатается «удовлетворительно». Условия четвёртой ветки проверять не нужно: `else` срабатывает, когда все условия выше ложны.
* Во втором фрагменте `n = 15` делится и на 3, и на 5, но напечатана только первая подходящая ветка. Если нужны оба сообщения, пишут два отдельных `if` подряд.
* В этом фрагменте нет `else`: если не подошло ни одно условие, ничего не печатается.

## Пример 3. `if` как выражение

```rust run
fn main() {
    let n = 7;
    let parity = if n % 2 == 0 { "чётное" } else { "нечётное" };
    println!("{n} - {parity} число");

    let x = -12;
    let distance = if x < 0 { -x } else { x };
    println!("Расстояние от нуля: {distance}");

    let hour = 14;
    let greeting = if hour < 12 {
        "Доброе утро"
    } else if hour < 18 {
        "Добрый день"
    } else {
        "Добрый вечер"
    };
    println!("{greeting}!");
}
```
```output
7 - нечётное число
Расстояние от нуля: 12
Добрый день!
```

В Rust `if` не только выбирает команды, но и **даёт значение**: значением становится последнее выражение выбранной ветки (без точки с запятой). Поэтому его можно записать справа от `let`.

* `let parity = if n % 2 == 0 { "чётное" } else { "нечётное" };` - переменная получает одно из двух слов.
* `if x < 0 { -x } else { x }` - абсолютное значение числа: для отрицательного меняем знак.
* Цепочка `else if` тоже работает как выражение, но в ней обязательно должен быть заключительный `else`: иначе непонятно, какое значение взять, когда ни одно условие не подошло.
* Точка с запятой стоит один раз в конце всего `let ...;`, а внутри веток после значений её нет.

## Пример 4. Условие из нескольких частей и ввод

Программа читает ввод, поэтому её нельзя запустить в окне примеров. Приведены ввод и вывод.

```rust
fn main() {
    let text = std::io::read_to_string(std::io::stdin()).unwrap();
    let mut lines = text.lines();
    let temp: i32 = lines.next().unwrap().trim().parse().unwrap();
    let rain = lines.next().unwrap().trim() == "да";

    if temp < 0 && rain {
        println!("Скользко: наденьте нескользящую обувь");
    } else if temp < 0 {
        println!("Мороз: наденьте шапку");
    } else if rain {
        println!("Возьмите зонт");
    } else {
        println!("Погода хорошая");
    }
}
```

Ввод:

```text
-5
да
```

Вывод:

```text
Скользко: наденьте нескользящую обувь
```

Ветки проверяются по порядку. Сначала идёт самое **узкое** условие (`temp < 0 && rain`), потому что более широкое `temp < 0` тоже истинно при дожде и перехватило бы выбор. Правило: сначала частные случаи, потом общие.

## Точные правила

* Форма: `if условие { ... }`, при необходимости `else if условие { ... }` (сколько угодно раз) и `else { ... }` в конце.
* **Условие обязано иметь тип `bool`.** Rust не превращает числа, строки и «пустоту» в истину или ложь.
* **Фигурные скобки обязательны.** Круглые скобки вокруг условия не нужны; компилятор предупредит, что они лишние.
* Выполняется **не больше одной** ветки цепочки: первая, чьё условие истинно, иначе `else`.
* `if` - выражение. Его значение - значение последнего выражения выбранного блока. Блок, который кончается точкой с запятой, имеет «пустое» значение `()`.
* Если `if` используется как значение, нужна ветка `else`, и значения всех веток должны быть **одного типа**. Если значение не нужно, `else` можно опустить.
* Переменные, объявленные внутри блока, видны только внутри него. Подробнее об области видимости - в уроке про функции.
* Порядок проверок важен: ставьте условия от частных к общим. При проверке диапазонов подумайте, что случится на границах (`>=` или `>`).

## Типичные ошибки

**1. Условие не `bool`.**

```rust
fn main() {
    let n = 5;
    if n {
        println!("не ноль");
    }
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:8
  |
3 |     if n {
  |        ^ expected `bool`, found integer
```

«Ожидался `bool`, найдено целое число». Чтобы проверить число, сравните его с чем-нибудь: `n != 0`.

**2. Присваивание вместо сравнения.**

```rust
fn main() {
    let n = 5;
    if n = 5 {
        println!("пять");
    }
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:8
  |
3 |     if n = 5 {
  |        ^^^^^ expected `bool`, found `()`
  |
help: you might have meant to compare for equality
  |
3 |     if n == 5 {
  |           +
```

Одиночный `=` - присваивание, а не вопрос. Компилятор угадал опечатку и предлагает `==`.

**3. Нет фигурных скобок.**

```rust
fn main() {
    let n = 5;
    if n > 3 println!("больше трёх");
}
```

```text
error: expected `{`, found `println`
 --> main.rs:3:14
  |
3 |     if n > 3 println!("больше трёх");
  |              ^^^^^^^ expected `{`
  |
note: the `if` expression is missing a block after this condition
 --> main.rs:3:8
  |
3 |     if n > 3 println!("больше трёх");
  |        ^^^^^
help: you might have meant to write this as part of a block
  |
3 |     if n > 3 { println!("больше трёх") };
  |              +                         +
```

В Rust, в отличие от C и Java, скобки блока нельзя опускать, даже когда в блоке одна команда.

**4. `if` как значение без `else`.**

```rust
fn main() {
    let n = 5;
    let label = if n > 3 { "много" };
    println!("{label}");
}
```

```text
error[E0317]: `if` may be missing an `else` clause
 --> main.rs:3:17
  |
3 |     let label = if n > 3 { "много" };
  |                 ^^^^^^^^^^^-------^^
  |                 |          |
  |                 |          found here
  |                 expected `&str`, found `()`
  |
  = note: `if` expressions without `else` evaluate to `()`
  = help: consider adding an `else` block that evaluates to the expected type
```

Если условие ложно, переменной `label` нечего присвоить. Поэтому у `if`-выражения должен быть `else`.

**5. Ветки разных типов.**

```rust
fn main() {
    let n = 5;
    let label = if n > 3 { "много" } else { 0 };
    println!("{label}");
}
```

```text
error[E0308]: `if` and `else` have incompatible types
 --> main.rs:3:45
  |
3 |     let label = if n > 3 { "много" } else { 0 };
  |                            -------          ^ expected `&str`, found integer
  |                            |
  |                            expected because of this
```

Одна ветка даёт текст, другая число. Переменная `label` не может иметь два типа сразу, поэтому ветки должны совпадать по типу.

**6. Слово `elif` вместо `else if`.**

```rust
fn main() {
    let n = 5;
    if n > 10 {
        println!("много");
    } elif n > 3 {
        println!("средне");
    }
}
```

```text
error: expected one of `!`, `.`, `::`, `;`, `?`, `{`, `}`, or an operator, found `n`
 --> main.rs:5:12
  |
5 |     } elif n > 3 {
  |            ^ expected one of 8 possible tokens
```

Rust пишет `else if` двумя словами. Слова `elif` из Python в языке нет.

**7. Неверный порядок проверок.** Это ошибка в логике, а не в синтаксисе, поэтому компилятор молчит:

```rust run
fn main() {
    let score = 95;
    if score >= 60 {
        println!("удовлетворительно");
    } else if score >= 75 {
        println!("хорошо");
    } else if score >= 90 {
        println!("отлично");
    }
}
```
```output
удовлетворительно
```

95 баллов - это «отлично», но первое же условие `score >= 60` истинно, и остальные ветки недостижимы. Расставляйте проверки от самого строгого условия к самому мягкому или добавляйте верхнюю границу (`score >= 60 && score < 75`).

**8. Лишние круглые скобки вокруг условия.**

```rust
fn main() {
    let n = 5;
    if (n > 3) {
        println!("больше трёх");
    }
}
```

```text
warning: unnecessary parentheses around `if` condition
 --> main.rs:3:8
  |
3 |     if (n > 3) {
  |        ^     ^
  |
  = note: `#[warn(unused_parens)]` (part of `#[warn(unused)]`) on by default
help: remove these parentheses
  |
3 -     if (n > 3) {
3 +     if n > 3 {
  |
```

Программа с такими скобками компилируется (предупреждение не останавливает сборку), но принято писать без них.

## Итоги

* `if условие { ... } else { ... }` выбирает, какой блок выполнить. Фигурные скобки обязательны, круглые вокруг условия не нужны.
* Условие должно быть `bool`. Число нужно сравнить: `n != 0`, а не `if n`.
* В цепочке `else if` выполняется первая подходящая ветка; порядок проверок важен.
* `if` - выражение: `let x = if ... { a } else { b };`. Обе ветки одного типа, `else` обязателен.
* Один знак `=` в условии - ошибка: нужно `==`.

Следующий урок: [match](lesson:rust.from-zero.match) - более удобная запись выбора, когда вариантов много.

<!-- section: programmer -->
## Для тех, кто уже программирует

* Синтаксис близок к Go: условие без круглых скобок, фигурные скобки обязательны. Нет тернарного оператора `?:` - его заменяет `if` как выражение: `let y = if c { a } else { b };`.
* Условие строго `bool`: никакой «истинности» чисел, строк и пустых коллекций, как в Python или JavaScript.
* Ветки выражения должны иметь один тип; последняя строка блока без `;` - значение блока. Лишняя `;` превращает значение в `()` и даёт ошибку типов.
* `if` без `else` имеет тип `()`; поэтому `let x = if c { 1 };` не компилируется.
* Присваивание - выражение типа `()`, поэтому `if x = 3` не скомпилируется (в C это тихая ошибка).
* Для выбора из многих значений обычно берут `match` (следующий урок); `if let` - урок про `Option`.

## Выражения и инструкции

Это необязательный раздел: для заданий он не нужен.

В Rust почти всё - выражение, то есть что-то, что имеет значение. `if`, блок `{ ... }`, `match` дают значение, а `let` и точка с запятой образуют инструкцию, которая значения не даёт. Поэтому в языке нет отдельного тернарного оператора: он не нужен, когда `if` и так возвращает значение.

Отсюда же правило о типах. Компилятор должен заранее знать тип переменной `label` в `let label = if ... { ... } else { ... };`. Чтобы не гадать, он требует, чтобы обе ветки давали один и тот же тип. Если веток может не быть вообще (нет `else`), значением станет `()`, которое с текстом несовместимо - поэтому `else` обязателен.

Обязательные фигурные скобки тоже решение компилятора: так невозможна ошибка, когда в `if (x) a; b;` вторая команда выглядит частью `if`, а на деле выполняется всегда.
