## Зачем нужны переменные

Программа почти всегда работает со значениями: ценой, количеством, именем покупателя. Если записать значение прямо в команду, как `println!("{}", 45)`, использовать его второй раз придётся тем же числом, набранным заново, а изменить - во всех местах сразу. Удобнее один раз сохранить значение под именем и дальше обращаться к нему по имени.

**Переменная** - именованное место в памяти программы, где хранится значение. Имя нужно человеку: по нему вы обращаетесь к значению. Значение нужно программе: именно оно используется в вычислениях и выводе.

## Одна новая идея: `let` создаёт переменную

Переменную объявляют командой `let`:

```rust
let price = 45;
```

Читается так: «пусть `price` будет равно 45». Слово `let` вводит новое имя, дальше идёт имя, знак `=` и значение. Теперь везде, где нужна цена, можно писать `price`.

Rust устроен необычно в одном: переменная, объявленная просто через `let`, **не может быть изменена**. Если вы захотите потом записать в `price` другое число, компилятор остановит сборку. Это не ограничение ради ограничения, а защита: значение, которое нигде не должно меняться, нельзя испортить случайно, и читатель кода знает это сразу. Если изменение действительно нужно, об этом пишут явно: `let mut price = 45;`. Слово `mut` (от *mutable*, «изменяемый») разрешает присваивать новые значения.

Правило для себя: начинайте с `let`; добавляйте `mut` только тогда, когда компилятор сообщил, что значение меняется, или вы точно знаете, что будете его менять.

## Пример 1. Объявление и вывод

```rust run
fn main() {
    let shop = "Булочная";
    let price = 45;
    println!("Магазин: {shop}");
    println!("Цена хлеба: {price} руб.");
    println!("Цена хлеба: {} руб., магазин: {}", price, shop);
}
```
```output
Магазин: Булочная
Цена хлеба: 45 руб.
Цена хлеба: 45 руб., магазин: Булочная
```

Разбор по строкам:

* `let shop = "Булочная";` - переменная `shop` (магазин) хранит текст. Текст в кавычках вы уже знаете как строковый литерал; тип такой переменной разберём в уроке про строки.
* `let price = 45;` - переменная `price` (цена) хранит целое число.
* `println!("Магазин: {shop}")` - если внутри `{}` написать имя переменной, Rust подставит её значение. Так удобно: видно, что именно печатается.
* Последняя команда делает то же через `{}` и значения после запятой, как в прошлом уроке. Оба способа допустимы; запись `{имя}` читать проще, когда подстановок много.

## Пример 2. `let mut` и присваивание

```rust run
fn main() {
    let mut balance = 500;
    println!("Было: {balance}");
    balance = 320;
    println!("Стало: {balance}");
    balance = 100;
    println!("Потом: {balance}");
}
```
```output
Было: 500
Стало: 320
Потом: 100
```

* `let mut balance = 500;` создаёт переменную `balance` (баланс) и разрешает её менять.
* `balance = 320;` - **присваивание**: значение переменной заменяется новым. Здесь нет слова `let`: переменная уже существует, мы только меняем в ней значение. Старое значение (500) теряется.
* Команды выполняются сверху вниз, поэтому после каждого присваивания `println!` видит уже новое значение.

## Пример 3. Копия значения

```rust run
fn main() {
    let a = 7;
    let mut b = a;
    b = 10;
    println!("a = {a}, b = {b}");
}
```
```output
a = 7, b = 10
```

`let mut b = a;` берёт значение из `a` и создаёт новую переменную `b` с таким же значением: это копия числа, а не вторая ссылка на то же место. Поэтому присваивание `b = 10;` не затрагивает `a`.

**Попробуйте.** В примере 2 уберите слово `mut` и посмотрите на сообщение (оно разобрано ниже). Затем в примере 1 добавьте переменную `count` со значением 3 и напечатайте её.

## Тип значения выводится сам

Вы заметили, что в `let price = 45;` нигде не написано, что `price` - число? Компилятор определяет **тип** значения сам по тому, что записано: `45` - целое число, и по умолчанию оно получает тип `i32`. Это называется **выводом типа**. `i32` - «целое число из 32 бит»; оно вмещает значения примерно от -2 миллиардов до +2 миллиардов. Другие типы (дробные числа, логические значения, символы) - в следующем уроке.

Тип у переменной всегда есть и **не меняется**. Если `price` стала числом, записать в неё текст нельзя: компилятор не даст.

## Точные правила

* **Объявление**: `let имя = значение;`. Переменной сразу даётся начальное значение.
* **Изменяемость**: `let` создаёт неизменяемую переменную, `let mut` - изменяемую. Присваивание `имя = новое_значение;` допустимо только для `mut`-переменной.
* **Присваивание** не содержит `let`. Если написать `let` ещё раз с тем же именем, это будет не присваивание, а новая переменная (затенение, урок 9).
* **Имя** состоит из латинских букв, цифр и знака `_`, не начинается с цифры, не содержит пробелов и дефисов. Регистр важен: `price` и `Price` - разные имена. По традиции Rust имена переменных пишут строчными буквами, слова разделяют `_`: `total_price`. Это называется *snake_case* («змеиный регистр»).
* **Слова языка** (`let`, `mut`, `fn`, `if` и другие) занимать как имя нельзя.
* **Тип** выводится по значению и после объявления не меняется. Целое число без дополнительных указаний - `i32`.
* **Подстановка по имени**: `{имя}` внутри строки формата. Внутри скобок допустимо только имя переменной, а не выражение: `{a + b}` не работает (вычисления - урок 6).
* **Область видимости**: переменная существует от места объявления до закрывающей `}` блока, в котором она объявлена. Пока у вас один блок `main`, это просто «до конца программы».
* Переменную нужно **использовать**. Если значение нигде не читается, компилятор выдаст предупреждение (не ошибку). Если `mut` не нужен, предупредит и об этом.
* Нельзя использовать переменную раньше, чем она объявлена: строки выполняются сверху вниз.

## Типичные ошибки

**1. Присваивание неизменяемой переменной.**

```rust
fn main() {
    let x = 5;
    x = 6;
    println!("{x}");
}
```

```text
error[E0384]: cannot assign twice to immutable variable `x`
 --> main.rs:3:5
  |
2 |     let x = 5;
  |         - first assignment to `x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut x = 5;
  |         +++
```

«Нельзя присвоить значение неизменяемой переменной второй раз». В сообщении две метки: где значение уже присвоено (`first assignment`) и где вы пытаетесь присвоить ещё раз. В `help` компилятор советует `let mut x = 5;`. Если значение должно меняться, примите совет; если нет, возможно, ошибка в логике, и нужна другая переменная.

**2. Присваивание без объявления.**

```rust
fn main() {
    price = 45;
    println!("{price}");
}
```

```text
error[E0425]: cannot find value `price` in this scope
 --> main.rs:2:5
  |
2 |     price = 45;
  |     ^^^^^
  |
help: you might have meant to introduce a new binding
  |
2 |     let price = 45;
  |     +++
```

«Значение `price` не найдено в этой области». Имя нужно сначала ввести через `let`. Компилятор угадал, что вы хотели «ввести новую привязку» (так в Rust называется связь имени со значением).

**3. Опечатка в имени.**

```rust
fn main() {
    let name = "Анна";
    println!("Привет, {nam}!");
}
```

```text
error[E0425]: cannot find value `nam` in this scope
 --> main.rs:3:24
  |
3 |     println!("Привет, {nam}!");
  |                        ^^^
  |
help: a local variable with a similar name exists
  |
3 |     println!("Привет, {name}!");
  |                           +
```

Заглавная буква, пропущенная буква, `_` вместо дефиса - частые источники ошибки. Компилятор предлагает похожее имя.

**4. Запись нового значения другого вида.**

```rust
fn main() {
    let mut x = 5;
    x = "десять";
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:9
  |
2 |     let mut x = 5;
  |                 - expected due to this value
3 |     x = "десять";
  |         ^^^^^^^^ expected integer, found `&str`
```

«Несовпадающие типы: ожидалось целое число, найден текст (`&str`)». Тип переменной определился числом 5 и больше не меняется. Читать эту ошибку удобно так: левая метка показывает, откуда компилятор узнал тип, правая - что вы записали.

**5. Предупреждение о неиспользуемой переменной.**

```rust
fn main() {
    let price = 45;
    let count = 3;
    println!("Цена: {price}");
}
```

```text
warning: unused variable: `count`
 --> main.rs:3:9
  |
3 |     let count = 3;
  |         ^^^^^ help: if this is intentional, prefix it with an underscore: `_count`
```

Это предупреждение (`warning`): программа соберётся и напечатает «Цена: 45». Переменная `count` нигде не используется, и компилятор спрашивает, не забыли ли вы. Либо используйте её, либо удалите, либо поставьте `_` в начале имени, если она нужна для порядка.

**6. `mut` там, где он не нужен.** `let mut count = 3;` без последующих присваиваний даёт предупреждение `variable does not need to be mutable` («изменяемость не нужна») с советом убрать `mut`.

## Итоги

* Переменная хранит значение под именем: `let price = 45;`.
* По умолчанию переменная не меняется; `let mut` разрешает присваивание `price = 50;`, которое записывается без `let`.
* Компилятор сам определяет тип: целое число по умолчанию - `i32`. Тип переменной не меняется.
* Значение переменной подставляют в текст: `{price}` или `{}` со значением после запятой.
* Имена - латиница, цифры и `_`, snake_case; регистр важен.

Мы пока видели только целые числа и текст. Какие ещё бывают значения и как указать тип явно - в следующем уроке: [Основные типы: i64, f64, bool, char](lesson:rust.from-zero.basic-types).

## Для тех, кто уже программирует

* По умолчанию переменные **неизменяемы**: `let` аналогичен `const` в JavaScript или `final` в Java, а `let mut` - `let`/`var` в других языках. Отличие от JavaScript `const`: Rust запрещает не только переприсваивание, но и вызов изменяющих методов у неизменяемой переменной (урок 7).
* Типы статические, выводятся компилятором (как `var` в Java и C#, `auto` в C++), но не меняются: `x = "десять"` после `let mut x = 5;` - ошибка компиляции.
* Целое по умолчанию - `i32`, а не «машинное слово» и не неограниченное, как в Python.
* Переменную нельзя использовать без значения: объявления без инициализации (`let x;`) возможны, но чтение до присваивания компилятор отвергает.
* Область видимости блочная: переменная живёт до закрывающей `}`. Повторный `let` с тем же именем создаёт новую переменную (затенение, урок 9).
* Имена принято писать в `snake_case`; компилятор предупреждает о `camelCase` (`non_snake_case`).
* Неиспользуемые переменные дают предупреждение; префикс `_` его отключает.

## Что такое «привязка»

Это необязательный раздел: для заданий он не нужен.

В документации Rust вместо «переменная» часто говорят **привязка** (*binding*): `let price = 45;` связывает имя `price` со значением. Неизменяемая привязка означает, что через это имя значение нельзя заменить. Это правило проверяет компилятор, и во время работы оно ничего не стоит.

Целые числа хранятся прямо в памяти программы на стеке (небольшая область быстрой памяти, привязанная к функции). `i32` занимает 4 байта, и присваивание `let mut b = a;` копирует эти 4 байта. Для значений, которые копировать дорого или нельзя (например, длинный текст, о нём в уроке про строки), Rust поступает иначе: значение **перемещается**, и прежнее имя перестаёт им владеть. Правила владения и перемещения - тема [курса первых шагов](lesson:rust.first-steps.ownership-moves-and-borrowing); а в этом курсе вы научитесь писать программы, не вникая в них глубже, чем нужно.

Неизменяемость по умолчанию облегчает чтение и проверку программы: если переменная объявлена без `mut`, любой читатель знает, что в дальнейшем её значение то же самое. Компилятор, в свою очередь, получает больше свободы в оптимизации.
