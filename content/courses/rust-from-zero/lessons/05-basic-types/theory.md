## Зачем нужны типы

Компьютер хранит всё числами, но числа бывают разные: количество штук, цена с копейками, ответ «да» или «нет», одна буква. Для каждого вида значений нужен свой способ хранения и свои допустимые действия: буквы нельзя умножать, а у количества штук не бывает дробной части. **Тип** - это вид значения, который говорит компьютеру (и читателю), что это за значение и что с ним можно делать.

В прошлом уроке компилятор сам определил, что `45` - число. Здесь вы узнаете основные типы и научитесь называть тип явно.

## Одна новая идея: у каждого значения есть тип, и его можно записать после двоеточия

Четыре типа, которых достаточно для начала:

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `i32` | целое число, примерно от -2,1 млрд до +2,1 млрд | `0`, `45`, `-17` |
| `i64` | целое число в диапазоне побольше, примерно ±9·10¹⁸ | `3000000000` |
| `f64` | число с дробной частью | `0.75`, `3.14`, `-2.5` |
| `bool` | логическое значение: «да» или «нет» | `true`, `false` |
| `char` | один символ (буква, цифра, знак) | `'A'`, `'я'`, `'7'` |

Тип можно записать явно: после имени переменной ставят двоеточие и тип.

```rust
let price: f64 = 49.9;
```

Читается: «переменная `price` типа `f64` равна 49,9». Чаще компилятор определяет тип сам, как в прошлом уроке, и писать его не нужно. Явный тип нужен в двух случаях: когда вы хотите не тип по умолчанию (например, `i64` вместо `i32`) и когда хотите подчеркнуть для читателя, какой тип имеете в виду.

Названия типов расшифровываются просто: `i` - *integer* (целое со знаком), `f` - *float* («плавающая точка» - так называют дробные числа в компьютере), число - сколько бит занимает значение. Чем больше бит, тем больше значений помещается.

## Пример 1. Все типы вместе

```rust run
fn main() {
    let count: i32 = 12;
    let population: i64 = 3_000_000_000;
    let price: f64 = 49.9;
    let is_open: bool = true;
    let grade: char = 'A';
    println!("Штук: {count}");
    println!("Людей: {population}");
    println!("Цена: {price}");
    println!("Открыто: {is_open}");
    println!("Оценка: {grade}");
}
```
```output
Штук: 12
Людей: 3000000000
Цена: 49.9
Открыто: true
Оценка: A
```

Разбор:

* `12` - целое, `i32`. Записывать тип необязательно, но здесь он показан для наглядности.
* `3_000_000_000` - число 3 миллиарда. Знаки `_` внутри числа нужны только человеку, как пробелы в «3 000 000 000»; в значение они не входят. Это число больше предела `i32`, поэтому тип `i64` указан явно.
* `49.9` - число с точкой, `f64`. Десятичный разделитель в программе - **всегда точка**, не запятая.
* `true` и `false` - единственные значения `bool`. Их пишут без кавычек. Текст `"true"` в кавычках - уже не логическое значение, а просто слово.
* `'A'` - символ в **одинарных** кавычках. Один символ означает один: `'ab'` не соберётся.

## Пример 2. Целое и дробное - разные типы

```rust run
fn main() {
    let a = 5;
    let b = 5.0;
    let height: f64 = 2.0;
    println!("{a} {b}");
    println!("Рост: {height}");
}
```
```output
5 5
Рост: 2
```

Литерал `5` - целое число (`i32`), а `5.0` - дробное (`f64`): точка делает его другим типом, даже если дробная часть равна нулю. Значения разных типов нельзя смешивать, это пригодится в следующих уроках.

Обратите внимание на вывод: `println!` печатает дробное число `5.0` как `5`, без `.0`. Это просто способ записи при печати; значение остаётся дробным. Как управлять количеством знаков после запятой - в уроке про форматированный вывод.

## Пример 3. Символ и текст

```rust run
fn main() {
    let letter = 'я';
    let word = "я";
    println!("Символ: {letter}");
    println!("Текст: {word}");
    let grade: char = '5';
    println!("Оценка: {grade}");
}
```
```output
Символ: я
Текст: я
Оценка: 5
```

Выводятся одинаково, но это разные вещи: `'я'` - один символ типа `char`, а `"я"` - текст (любой длины, в том числе одна буква). Для одного символа используйте `char`, для слов и предложений - текст.

Цифра `'5'` в одинарных кавычках - это символ «пять», а не число пять: складывать его как число нельзя.

**Попробуйте.** Замените в примере 1 `12` на `12.0`, оставив тип `i32`, и посмотрите на сообщение. Затем замените `i64` на `i32`, чтобы увидеть, как компилятор отвергает слишком большое число.

## Другие размеры целых

Кроме `i32` и `i64` есть ещё целые: `i8`, `i16`, `i128` и **беззнаковые** `u8`, `u16`, `u32`, `u64`, `u128`. Буква `u` (*unsigned*) означает «без знака»: такой тип хранит только числа от нуля (`u8` - от 0 до 255). Есть и `usize`: беззнаковое целое, размер которого зависит от компьютера; его используют для длин и номеров элементов (урок 7). Для знакомства с языком достаточно `i32`, `i64` и `f64`; остальные пригодятся, когда вы столкнётесь с их использованием.

## Точные правила

* **Целые литералы**: `42`, `-7`, `1_000_000`. Без указаний тип - `i32`. Если число не помещается в тип, компилятор отвергает программу.
* **Диапазоны**: `i32` - от -2 147 483 648 до 2 147 483 647; `i64` - от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807.
* **Дробные литералы** записывают с точкой: `3.14`, `0.5`, `2.0`. Тип по умолчанию - `f64`. Литерал `5` для `f64` не подходит: нужно `5.0`.
* **Дробные числа неточны**: `0.1 + 0.2` в `f64` даёт не ровно `0.3`, а `0.30000000000000004`. Так устроено хранение дробей в памяти компьютера, и во всех языках одинаково. Для денег в серьёзных программах поэтому хранят целое число копеек.
* **`bool`**: только `true` и `false`, строчными буквами и без кавычек. Другие значения (в частности, `1` и `0`) `bool` не заменяют.
* **`char`**: ровно один символ в одинарных кавычках; допустимы русские буквы, эмодзи и знаки. Пустого `''` не бывает.
* **Текст** в двойных кавычках - не `char`, и наоборот: `let c: char = "a";` - ошибка.
* **Явный тип**: `let имя: Тип = значение;`. Значение должно подходить к типу. Если тип не указан, он определяется по значению.
* **Тип не меняется**: после `let price: f64 = 49.9;` в `price` можно записать только `f64`.
* **Выбор типа**. Целое количество - `i32` (или `i64`, если число может быть больше 2 миллиардов); деньги с копейками и измерения - `f64`; да/нет - `bool`; одна буква - `char`.

## Типичные ошибки

**1. Целое число там, где нужно дробное.**

```rust
fn main() {
    let weight: f64 = 5;
    println!("{weight}");
}
```

```text
error[E0308]: mismatched types
 --> main.rs:2:23
  |
2 |     let weight: f64 = 5;
  |                 ---   ^ expected `f64`, found integer
  |                 |
  |                 expected due to this
  |
help: use a float literal
  |
2 |     let weight: f64 = 5.0;
  |                        ++
```

«Несовпадающие типы: ожидалось `f64`, найдено целое». Метка `expected due to this` показывает, откуда компилятор взял ожидание: из явного типа. В `help` предложено `5.0`.

**2. Число слишком велико для типа.**

```rust
fn main() {
    let y: i32 = 3000000000;
    println!("{y}");
}
```

```text
error: literal out of range for `i32`
 --> main.rs:2:18
  |
2 |     let y: i32 = 3000000000;
  |                  ^^^^^^^^^^
  |
  = note: the literal `3000000000` does not fit into the type `i32` whose range is `-2147483648..=2147483647`
  = help: consider using the type `u32` instead
  = note: `#[deny(overflowing_literals)]` on by default
```

«Литерал вне диапазона для `i32`». В `note` указан допустимый диапазон. Совет `u32` формально верен (число положительное и помещается в `u32`), но для общего случая надёжнее `i64`: он хранит и отрицательные значения.

**3. Двойные кавычки вместо одинарных у `char`.**

```rust
fn main() {
    let d: char = "a";
}
```

```text
error[E0308]: mismatched types
 --> main.rs:2:19
  |
2 |     let d: char = "a";
  |            ----   ^^^ expected `char`, found `&str`
  |            |
  |            expected due to this
  |
help: if you meant to write a `char` literal, use single quotes
```

«Ожидался `char`, найдено `&str`» (так компилятор называет текст в кавычках; подробнее в уроке про строки). Решение названо в `help`: для одного символа - одинарные кавычки.

**4. Запятая вместо точки в дробном числе.** `let price = 49,9;` не соберётся: запятая в Rust разделяет значения, а не часть числа. Дробную часть отделяют точкой.

**5. Кавычки вокруг `true`.** `let ok = "true";` - это текст, а не `bool`: условие с ним (урок про `if`) не заработает. Логические значения пишут без кавычек.

**6. Значение другого типа в переменную.** Если переменная объявлена как число, текст в неё не запишешь (`mismatched types`, пример в уроке про переменные). Тип задаётся при объявлении и не меняется.

## Итоги

* У каждого значения есть тип. Основные: `i32` и `i64` (целые), `f64` (дробные), `bool` (`true`/`false`), `char` (один символ в одинарных кавычках).
* Тип можно записать явно: `let price: f64 = 49.9;`. Без записи компилятор выбирает по значению: `5` - `i32`, `5.0` - `f64`.
* Дробные числа пишут с точкой; `5` и `5.0` - значения разных типов.
* Число должно помещаться в тип; для больших значений подойдёт `i64`.
* Есть и другие целые типы; `u` в названии означает «без знака».

Значения разных типов нельзя смешивать, поэтому в следующем уроке мы научимся считать, оставаясь в пределах одного типа: [Арифметика](lesson:rust.from-zero.arithmetic).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Размеры чисел указаны явно: `i8`...`i128`, `u8`...`u128`, `isize`/`usize` (размер указателя), `f32`/`f64`. Нет `int`, `long` и `double` с зависящей от платформы шириной (кроме `usize`).
* Целое по умолчанию - `i32`, дробное - `f64`. Литерал `5` не превращается в `f64` автоматически, как в Python или JavaScript: нужно `5.0` или `5 as f64` (урок 9).
* Литерал вне диапазона типа - ошибка компиляции (lint `overflowing_literals`), а не молчаливое обрезание, как в C.
* `bool` не принимает числа и строки: условие всегда должно быть `bool` (урок 12), нет «истинности» нуля и пустой строки.
* `char` - 32-битное значение Unicode (скаляр), а не байт и не 16-битная единица UTF-16: в нём помещается `'я'` и `'😀'`.
* Текст в двойных кавычках - `&str` (урок 7), строка формата в `println!` - тоже литерал.
* Числовые литералы допускают разделители `_`, суффиксы типа (`3_000_i64`, `2.5_f64`) и системы счисления (`0xFF`, `0b1010`).

## Как числа хранятся в памяти

Это необязательный раздел: для заданий он не нужен.

`i32` занимает 32 бита: 4 байта. Из 2³² возможных комбинаций половина отдана отрицательным числам и половина неотрицательным, откуда диапазон от -2³¹ до 2³¹-1. Беззнаковый `u32` использует те же 32 бита только для неотрицательных чисел, поэтому вмещает вдвое большее положительное число: до 2³²-1 (около 4,29 млрд). Поэтому компилятор в сообщении выше советует `u32` для числа 3000000000.

`f64` хранит число по стандарту IEEE 754: знак, порядок и мантиссу, всего 64 бита. Двоичная запись не умеет точно хранить такие десятичные дроби, как 0,1, так же, как десятичная не умеет точно записать 1/3. Поэтому `0.1 + 0.2` отличается от `0.3` на очень малую величину. Для денег поэтому часто хранят целое число копеек (`i64`).

Если арифметика выводит число за пределы типа, говорят о **переполнении**. В Rust оно не случайное: поведение зависит от режима сборки, и вы узнаете об этом подробно в [курсе первых шагов](lesson:rust.first-steps.how-rust-runs).
