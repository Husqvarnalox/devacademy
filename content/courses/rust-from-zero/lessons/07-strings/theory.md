## Зачем нужны строки

Имена, адреса, названия товаров, сообщения - почти любая программа работает с текстом. Текст в программисских терминах называется **строкой**: это последовательность символов. До сих пор вы записывали текст в кавычках прямо в команде или в переменной. Теперь пора узнать, как с ним обращаться: узнать длину, сделать заглавные буквы, дописать что-нибудь в конец.

## Одна новая идея: в Rust два вида строк

В Rust есть два основных способа хранить текст, и различие важно с самого начала.

1. **`&str`** (читается «эм-эс-ти-ар» или «срез строки»). Так устроен любой текст в кавычках: `"Хлеб"`. Этот текст записан в самой программе, и переменная только *смотрит* на него: прочитать можно, дописать или изменить - нет. Знак `&` перед `str` означает «ссылка на», то есть «вид на чужие данные».
2. **`String`**. Это текст, который переменная *хранит у себя*: ей принадлежат его буквы, и поэтому его можно менять и увеличивать. Создаётся так: `String::from("Хлеб")`.

Аналогия. `&str` - страница в чужой книге: можно прочитать, но нельзя вписать свой текст. `String` - ваш блокнот: можно дописывать, зачёркивать, пополнять.

Откуда эти правила и что значат «ссылка» и «владение» точнее, вы узнаете в [уроке про владение](lesson:rust.first-steps.ownership-moves-and-borrowing) курса первых шагов. Сейчас достаточно практического правила:

* текст, который только читают и печатают, - литерал `"..."`, тип `&str`;
* текст, который нужно собирать, дописывать, менять, - `String`.

И третья мелочь. Рядом со значением можно вызвать **метод**: команду, которая относится к этому значению. Запись такая: значение, точка, имя метода, скобки: `name.len()`. Читается: «у значения `name` вызвать метод `len`». С методами вы будете постоянно встречаться дальше.

<!-- section: examples -->
## Пример 1. Методы текста-литерала

```rust run
fn main() {
    let name = "Анна";
    println!("Имя: {name}");
    println!("Заглавными: {}", name.to_uppercase());
    println!("Строчными: {}", name.to_lowercase());
    println!("Пустое ли имя: {}", name.is_empty());
}
```
```output
Имя: Анна
Заглавными: АННА
Строчными: анна
Пустое ли имя: false
```

* `name.to_uppercase()` - «в верхний регистр»: возвращает **новую** строку, где все буквы заглавные. `name` при этом не меняется.
* `name.to_lowercase()` - то же для строчных.
* `name.is_empty()` - «пустая ли строка». Результат - `true` или `false` (тип `bool` из прошлых уроков).
* Результат метода можно подставить прямо в `println!`, как значение после запятой.

## Пример 2. Длина: буквы и байты

```rust run
fn main() {
    let latin = "cat";
    let word = "привет";
    println!("{} {}", latin.len(), latin.chars().count());
    println!("{} {}", word.len(), word.chars().count());
}
```
```output
3 3
12 6
```

У строки две «длины», и они не всегда совпадают.

* `len()` - длина в **байтах**: сколько места занимает текст в памяти. Для латиницы одна буква - один байт, поэтому `cat` даёт 3. Русская буква в кодировке UTF-8 занимает **два** байта, поэтому «привет» из шести букв даёт 12.
* `chars().count()` - число **символов**, то есть букв, как их считает человек. Запись состоит из двух вызовов подряд: `chars()` «разбирает текст на символы», `count()` их считает. Для «привет» это 6.

Если вам нужно число букв, берите `chars().count()`. `len()` пригодится, когда важен именно размер в байтах.

Результат `len()` и `count()` имеет тип `usize` - целое число без знака (не бывает отрицательным), которое Rust использует для длин и номеров. Печатать его можно, как любое число; смешивать с `i32` без преобразования нельзя (урок 9).

## Пример 3. `String`: создание и дописывание

```rust run
fn main() {
    let mut order = String::from("Хлеб");
    println!("{order}");
    order.push_str(", молоко");
    println!("{order}");
    order.push_str(" и сыр");
    println!("{order}");
    println!("Букв: {}", order.chars().count());
}
```
```output
Хлеб
Хлеб, молоко
Хлеб, молоко и сыр
Букв: 18
```

* `String::from("Хлеб")` создаёт `String` из литерала: текст копируется в собственное хранилище строки.
* `push_str(...)` - «втолкнуть строку» в конец. Меняется сама переменная, поэтому она объявлена `let mut`: без `mut` компилятор не разрешит изменение.
* Между кусками текста пробелы нужны: `push_str` ничего не добавляет сама. В тексте ` и сыр` пробел перед `и` часть самого текста.

Строки `String` и `&str` одинаково работают с методами `len()`, `to_uppercase()` и прочими: для чтения различия нет, оно только в том, можно ли менять.

**Попробуйте.** Дополните пример 3 ещё одним `push_str` и предскажите, сколько букв будет в результате. Затем в примере 2 замените слово на «Ёлка» и сравните `len()` и `chars().count()`.

## Точные правила

* Текст в двойных кавычках имеет тип `&str`. Его нельзя изменить. Чтобы получить изменяемый текст, создают `String`: `String::from("...")` (или `"...".to_string()`, урок 9).
* `String` меняют только через `let mut`. Без `mut` вызов `push_str` - ошибка компиляции.
* Метод вызывают через точку: `значение.метод(аргументы)`. Скобки нужны всегда, даже если аргументов нет: `s.len()`, а не `s.len`.
* `len()` возвращает длину в **байтах**, `chars().count()` - число символов. Для латиницы они совпадают, для русских букв `len()` вдвое больше.
* `to_uppercase()` и `to_lowercase()` создают новую `String`; исходное значение не меняется. Они работают и для кириллицы.
* `is_empty()` возвращает `true`, если в строке нет ни одного символа.
* `push_str(текст)` дописывает текст в конец `String`. Для одного символа есть `push('!')` (с одинарными кавычками).
* **Индексы.** Взять i-й символ записью `s[0]` в Rust нельзя: байтов и букв разное число, и «i-й» непонятно, в чём считать. Для просмотра по буквам используют `chars()` (урок про циклы и урок про методы строк).
* Результат `len()` и `count()` - `usize`. Это беззнаковое целое: оно никогда не бывает отрицательным.
* Склеивать строки знаком `+` пока не нужно: для сборки текста подставляют значения в `println!`, а для накопления используют `push_str`. Подстановки в строку (`format!`) - в уроке про форматированный вывод.
* Литерал `&str` и `String` с одинаковым текстом можно печатать одинаково, но это разные типы: значение типа `&str` нельзя присвоить переменной типа `String` без `String::from` (или `.to_string()`).

## Типичные ошибки

**1. Изменение `String` без `mut`.**

```rust
fn main() {
    let t = String::from("abc");
    t.push_str("d");
    println!("{t}");
}
```

```text
error[E0596]: cannot borrow `t` as mutable, as it is not declared as mutable
 --> main.rs:3:5
  |
3 |     t.push_str("d");
  |     ^ cannot borrow as mutable
  |
help: consider changing this to be mutable
  |
2 |     let mut t = String::from("abc");
  |         +++
```

«Нельзя взять `t` для изменения, потому что она объявлена без `mut`». Слова «borrow as mutable» (взять взаймы для изменения) обозначают, что метод хочет изменить строку; подробности - в курсе первых шагов. Решение - в `help`: `let mut t`.

**2. Попытка дописать в текст-литерал.**

```rust
fn main() {
    let s = "abc";
    s.push_str("d");
}
```

```text
error[E0599]: no method named `push_str` found for reference `&str` in the current scope
 --> main.rs:3:7
  |
3 |     s.push_str("d");
  |       ^^^^^^^^ method not found in `&str`
```

«У `&str` нет метода `push_str`». Литерал изменять нельзя, `mut` здесь не поможет. Создайте `String`: `let mut s = String::from("abc");`.

**3. Литерал вместо `String`.**

```rust
fn main() {
    let word: String = "abc";
}
```

```text
error[E0308]: mismatched types
 --> main.rs:2:24
  |
2 |     let word: String = "abc";
  |               ------   ^^^^^ expected `String`, found `&str`
  |               |
  |               expected due to this
  |
help: try using a conversion method
  |
2 |     let word: String = "abc".to_string();
  |                             ++++++++++++
```

«Ожидался `String`, найден `&str`». Это два разных типа. Если нужна `String`, создавайте её явно: `String::from("abc")`.

**4. Индекс у строки.**

```rust
fn main() {
    let s = String::from("привет");
    println!("{}", s[0]);
}
```

```text
error[E0277]: the type `str` cannot be indexed by `{integer}`
 --> main.rs:3:22
  |
3 |     println!("{}", s[0]);
  |                      ^ string indices are ranges of `usize`
  |
  = help: the trait `SliceIndex<str>` is not implemented for `{integer}`
  = note: you can use `.chars().nth()` or `.bytes().nth()`
```

«Тип `str` нельзя индексировать целым числом». Rust не знает, что значит «нулевой» элемент, когда русская буква занимает два байта. Компилятор в примечании сам называет путь: работать через `chars()`. Как это делать, вы узнаете в уроках про циклы и методы строк.

**5. Путают `len()` с числом букв.** `"привет".len()` равно 12, а не 6. Нужно число букв - пишите `chars().count()`.

**6. Забыли скобки у метода.** `name.len` без `()` - ошибка («attempted to take value of method»): метод нужно вызвать.

**7. Ждут, что `to_uppercase()` меняет исходную строку.** Метод возвращает новую строку. Результат нужно либо напечатать, либо сохранить: `let big = name.to_uppercase();`.

## Итоги

* В Rust два вида текста: `&str` (текст-литерал в кавычках, только для чтения) и `String` (собственный изменяемый текст).
* `String::from("...")` создаёт `String`, `push_str(...)` дописывает текст в конец; для изменения нужен `let mut`.
* Метод вызывают через точку со скобками: `name.len()`, `name.to_uppercase()`.
* `len()` считает байты, `chars().count()` - буквы; русская буква занимает два байта. Результат - `usize`.
* Взять букву по номеру `s[0]` нельзя; для перебора по буквам используют `chars()`.

Пока ваши программы работали с данными, записанными прямо в тексте. Настало время получать данные снаружи, из ввода: [Ввод данных: read_to_string](lesson:rust.from-zero.reading-input).

## Для тех, кто уже программирует

* `&str` - неизменяемая ссылка на UTF-8 байты (указатель и длина), `String` - владеющий растущий буфер (как `std::string` в C++ или `StringBuilder`, но с владением). Литерал - `&'static str`.
* `String` - только UTF-8: `len()` - байты (как `strlen`), символов `chars().count()` - O(n). Индексирование `s[i]` запрещено; срез `&s[a..b]` по границам байтов и паникует, если граница внутри символа.
* Строки нельзя менять без `mut`, и изменение - метод `push_str`/`push`/`insert` и т. д., а не оператор. `+` определён только как `String + &str` (перемещает левую строку); `&str + &str` не существует.
* `to_uppercase()` корректно обрабатывает Unicode (например, `ß` в `SS`), поэтому длина результата может измениться.
* Нет автоматического преобразования `&str` -> `String`: нужно `String::from`, `.to_string()` или `.into()`.
* Строки в Rust не терминированы нулём и не содержат нулевого символа в конце; в них можно хранить `\0`, как любой другой символ.
* Подробности владения - в `rust-first-steps` (урок 02): вы уже видите их на практике, когда `push_str` требует `mut`.

## Что хранится внутри

Это необязательный раздел: для заданий он не нужен.

`&str` состоит из двух чисел: адреса первого байта текста и его длины в байтах. Сам текст лежит в памяти программы: литералы в кавычках компилятор записывает прямо в исполняемый файл. Копировать при передаче нечего: передаётся пара «адрес + длина».

`String` - это три числа: адрес буфера в **куче** (большая область памяти, из которой программа берёт место на время работы), длина текста и ёмкость буфера. Когда `push_str` не умещает текст, программа выделяет буфер побольше, копирует туда старый текст и освобождает старый буфер. Освобождение происходит автоматически, когда переменная выходит из области видимости: никакого сборщика мусора нет.

UTF-8 хранит каждый символ в одном, двух, трёх или четырёх байтах: латиница - один, кириллица - два, часть иероглифов - три, эмодзи - четыре. Поэтому номер символа не равен номеру байта, и `s[i]` невозможно сделать и быстрым, и корректным одновременно. Rust выбрал честность: для побайтового доступа есть `bytes()`, для посимвольного - `chars()`. Операция `chars().count()` просматривает текст целиком, поэтому её стоит вызывать один раз и хранить результат.
