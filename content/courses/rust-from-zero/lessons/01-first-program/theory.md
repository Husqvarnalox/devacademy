## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Такой текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется **Rust**. Он нужен, чтобы описывать действия компьютера точно и безопасно: на Rust пишут программы, которым важны скорость и надёжность.

Но процессор компьютера не понимает текст на Rust. Он понимает только **машинный код** - длинные последовательности чисел. Перевод с языка, удобного человеку, на язык процессора делает особая программа - **компилятор**. Компилятор Rust называется `rustc`. Он читает исходный код, проверяет его и создаёт **исполняемый файл**: готовую программу, которую компьютер может запустить.

Поэтому у любой программы на Rust две стадии:

1. **Компиляция** - `rustc` переводит файл `main.rs` в исполняемый файл. Если в тексте есть ошибка, `rustc` объясняет, какая именно, и исполняемый файл не создаётся.
2. **Запуск** - компьютер выполняет исполняемый файл, и вы видите результат.

В приложении вам не нужно запускать эти стадии вручную: вы пишете текст в редакторе и нажимаете «Запустить», а приложение само вызывает компилятор и затем запускает результат. Запоминать команды пока не нужно.

Строгость компилятора - это помощь. Он проверяет программу ещё до запуска и пишет понятные сообщения с указанием строки и часто с готовой подсказкой, как исправить. Ошибка, найденная на этой стадии, не успевает испортить ничьи данные.

## Одна новая идея: команда `println!` печатает текст

Чтобы увидеть результат работы программы, её нужно заставить что-то показать. Для этого есть команда `println!("...")`. Она печатает текст в скобках и переходит на следующую строку. Текст в программе записывают в двойных кавычках: `"Касса открыта"`.

Восклицательный знак в `println!` - часть имени: он означает, что это не обычная функция, а **макрос**, то есть заготовка, которую компилятор разворачивает в готовый код печати. Что такое макрос подробнее, вам пока знать не нужно: просто всегда пишите `println!` с восклицательным знаком.

<!-- section: examples -->
## Пример 1. Печать одной строки

```rust run
fn main() {
    println!("Касса открыта");
}
```
```output
Касса открыта
```

Разбор по строкам:

* `fn main() {` - начало программы. `fn` - сокращение от *function*, «функция»: именованный блок команд. Функция с именем `main` особая: именно с неё программа начинается. Что такое функции, подробно - в уроке 16; сейчас достаточно знать, что программа без `fn main` не соберётся. Пустые круглые скобки `()` после имени тоже пока нужно просто писать.
* `{` и `}` - фигурные скобки. Всё, что между ними, - команды функции `main`. Команда внутри обычно сдвигается на четыре пробела: на работу это не влияет, но так легче читать.
* `println!("Касса открыта");` - команда печати. `println!` - макрос, в скобках - то, что нужно напечатать.
* `"Касса открыта"` - **строковый литерал**: текст, записанный прямо в программе, в двойных кавычках. Кавычки на экран не попадают.
* `;` - точка с запятой в конце команды. Она отмечает, что команда закончилась.

## Пример 2. Несколько команд подряд

```rust run
fn main() {
    println!("Первая строка");
    println!("Вторая строка");
    println!("Третья строка");
}
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет.

## Пример 3. Пустая строка и русский текст

```rust run
fn main() {
    println!("Магазин «Булочная»");
    println!();
    println!("Свежий хлеб каждый день");
}
```
```output
Магазин «Булочная»

Свежий хлеб каждый день
```

`println!()` без текста печатает только переход на новую строку, то есть пустую строку. Текст может быть русским, с кавычками-ёлочками и любыми знаками: Rust хранит строки в кодировке UTF-8, которая поддерживает все языки.

**Попробуйте.** Поменяйте местами две строки в примере 2 и предскажите вывод до запуска. Затем уберите одну кавычку и посмотрите, что сообщит `rustc` (подробно об этом - в разделе об ошибках и в следующем уроке).

## Точные правила

* Программа - это команды в файле `main.rs`. Выполнение начинается с функции `main` и идёт сверху вниз, по одной команде.
* Функция `main` должна быть в программе ровно одна. Если её нет, компилятор сообщает об ошибке.
* **Строковый литерал** записывают в двойных кавычках `"..."`. Внутри допустимы русские буквы, пробелы, цифры и знаки. Одинарные кавычки `'...'` в Rust означают другое (один символ) и для текста не годятся.
* Текст в кавычках печатается как есть.
* Регистр важен: `println!` работает, `Println!` и `PRINTLN!` - нет.
* Восклицательный знак в `println!` обязателен, и он стоит сразу после имени, без пробела.
* Каждую команду внутри `main` заканчивают точкой с запятой.
* Пробелы в начале строки и пустые строки между командами на работу не влияют; их используют, чтобы код легче читался.
* Сначала компилятор проверяет **всю** программу, и только если ошибок нет, программа запускается. Поэтому ошибка в последней строке мешает запуску даже тех команд, которые выше написаны правильно.
* Программа, которая дошла до конца `main`, завершается сама.

## Типичные ошибки

Сообщения ниже получены настоящим запуском `rustc`. Они начинаются с `error` (ошибка) и показывают место: `--> main.rs:2:14` означает «файл `main.rs`, строка 2, столбец 14».

**1. Не закрыли кавычки.**

```rust
fn main() {
    println!("Привет);
}
```

```text
error[E0765]: unterminated double quote string
 --> main.rs:2:14
  |
2 |       println!("Привет);
  |  ______________^
3 | | }
  | |__^
```

«Незавершённая строка в двойных кавычках»: текст начался с кавычки и не закончился, поэтому компилятор считает строкой всё до конца файла. Проверьте, что у каждой открывающей кавычки есть закрывающая.

**2. Забыли восклицательный знак.**

```rust
fn main() {
    println("Привет");
}
```

```text
error[E0423]: cannot find function `println` in this scope
 --> main.rs:2:5
  |
2 |     println("Привет");
  |     ^^^^^^^ not found in this scope
  |
  = note: a macro named `println` exists in another namespace
help: use `!` to invoke the macro
  |
2 |     println!("Привет");
  |            +
```

«Не найдена функция `println`». В примечании компилятор сам догадывается, что вы имели в виду макрос, и в строке `help` показывает исправленный вариант: знак `+` под кодом отмечает, что именно нужно добавить.

**3. Забыли точку с запятой.**

```rust
fn main() {
    println!("Привет")
    println!("Мир");
}
```

```text
error: expected `;`, found `println`
 --> main.rs:2:23
  |
2 |     println!("Привет")
  |                       ^ help: add `;` here
3 |     println!("Мир");
  |     ------- unexpected token
```

«Ожидалась `;`, но найдено `println`». Компилятор указывает на конец первой команды и сразу пишет, что добавить.

**4. Опечатка в имени макроса.**

```rust
fn main() {
    printn!("Привет");
}
```

```text
error: cannot find macro `printn` in this scope
 --> main.rs:2:5
  |
2 |     printn!("Привет");
  |     ^^^^^^
  ...
help: a macro with a similar name exists
```

«Макрос `printn` не найден». Дальше компилятор предлагает похожее имя из того, что ему известно.

**5. Одинарные кавычки вместо двойных.**

```rust
fn main() {
    println!('Привет');
}
```

```text
error: character literal may only contain one codepoint
 --> main.rs:2:14
  |
2 |     println!('Привет');
  |              ^^^^^^^^
  |
help: if you meant to write a string literal, use double quotes
```

«В символьном литерале может быть только один символ». Одинарные кавычки задают один символ, а для текста нужны двойные. Компилятор снова называет решение в строке `help`.

Общее правило чтения: найдите адрес `main.rs:строка:столбец`, посмотрите на подчёркнутое `^^^`, прочитайте строку после `error` и строку `help`. Подробно - в следующем уроке.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; Rust - язык, `rustc` - компилятор, который переводит исходный код в исполняемый файл и проверяет его.
* Программа на Rust начинается с `fn main() { ... }`, а команды внутри заканчиваются точкой с запятой.
* `println!("текст")` печатает текст и переходит на следующую строку; кавычки на экран не попадают. Восклицательный знак обязателен: `println!` - макрос.
* Регистр букв, кавычки, скобки и `;` важны: от них зависит, соберёт ли компилятор вашу программу.

В следующем уроке вы научитесь читать сообщения компилятора подробно и исправлять несколько ошибок в одной программе: [Как читать сообщения об ошибках](lesson:rust.from-zero.compiler-errors).

## Для тех, кто уже программирует

* Rust компилируется заранее в машинный код, как C, C++ и Go: нет виртуальной машины, интерпретатора и сборщика мусора. Результат компиляции - самостоятельный исполняемый файл.
* Точка входа - `fn main()`, как `main` в C и Go. Класса-обёртки, `static` и `args` нет; аргументы командной строки берут отдельно, из `std::env`.
* `println!` - макрос, а не функция. Формат-строка разбирается и проверяется при компиляции: неверное число аргументов или несуществующая переменная - ошибка сборки, а не падение во время работы (в отличие от `printf` в C и `String.format` в Java).
* Точка с запятой в Rust значима: она превращает выражение в команду. Последнее выражение функции без `;` становится её результатом (урок 16).
* Строки - всегда корректный UTF-8; `"Привет"` занимает 12 байт (урок 7).
* Ошибки типов, неинициализированные переменные, неизменяемость и гонки данных ловятся на этапе компиляции; это главная идея языка.

## Что делает `rustc`

Это необязательный раздел: для заданий он не нужен.

Приложение собирает программу командой `rustc --edition 2021 -O -o prog main.rs` и запускает получившийся файл `prog`. Флаг `--edition 2021` выбирает редакцию языка: набор правил, по которому читается текст (новые редакции выходят раз в несколько лет, и старый код продолжает собираться). Флаг `-O` включает оптимизацию: компилятор переписывает программу так, чтобы она работала быстрее, не меняя результата.

Внутри `rustc` проходит несколько стадий. Сначала он разбирает текст на слова и конструкции языка и ловит синтаксические ошибки (пропущенная `;`, незакрытая кавычка). Затем проверяет имена и типы: существует ли `println`, подходит ли число к месту, где ждут текст. Потом проверяет правила владения и заимствования - ту часть, которой Rust отличается от большинства языков и которую вы узнаете в [курсе первых шагов](lesson:rust.first-steps.how-rust-runs). После этого программа переводится в машинный код с помощью компонента LLVM и склеивается с библиотекой в исполняемый файл.

Макрос `println!` раскрывается на стадии разбора в обычный вызов функций, которые записывают байты в **стандартный вывод** - поток, подключённый к окну результата. Поэтому одна и та же программа может печатать и на экран, и в файл: она не знает, куда ведёт поток.

Когда `main` заканчивается, программа возвращает операционной системе код 0, что означает «всё прошло успешно». Паника (аварийная остановка из-за ошибки во время работы) завершает программу ненулевым кодом, по которому системы автоматической проверки отличают успех от сбоя.
