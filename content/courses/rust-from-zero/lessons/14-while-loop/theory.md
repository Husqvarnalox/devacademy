## Зачем повторять

Вывести числа от 1 до 100, сложить цены тридцати товаров, ждать, пока пользователь введёт верный пароль: во всех этих задачах одно и то же действие выполняется много раз. Писать команду сто раз неудобно, а число повторений часто заранее неизвестно. Для этого существуют **циклы**: конструкции, которые повторяют блок команд.

## Одна новая идея: `while` повторяет, пока условие истинно

```rust
while условие {
    // тело цикла
}
```

Цикл работает так: проверяет условие; если оно истинно, выполняет тело и **снова** проверяет условие; если ложно, пропускает тело и идёт дальше. Одно выполнение тела называется **итерацией** (повторением).

Чтобы цикл когда-нибудь остановился, тело должно менять что-то, от чего зависит условие. Обычно это **счётчик**: переменная, которую увеличивают или уменьшают на каждом шаге. Поскольку значение меняется, счётчик объявляют `let mut`.

Условие, как и в `if`, должно быть `bool`, а фигурные скобки обязательны.

<!-- section: examples -->
## Пример 1. Обратный отсчёт

```rust run
fn main() {
    let mut n = 3;
    while n > 0 {
        println!("{n}");
        n -= 1;
    }
    println!("Старт!");
}
```
```output
3
2
1
Старт!
```

* Перед циклом объявлена `let mut n = 3;`. Тело меняет её: `n -= 1`.
* Проверки: `3 > 0` (печатаем 3), `2 > 0` (2), `1 > 0` (1), `0 > 0` ложно - цикл закончен. Тело выполнилось три раза.
* Если бы вначале было `n = 0`, тело не выполнилось бы ни разу: условие проверяется **до** первого шага.

**Попробуйте.** Поставьте `n = 0`, затем `n = 5`. Потом замените `n > 0` на `n >= 0` и посмотрите, что изменилось.

## Пример 2. Накопление итога

```rust run
fn main() {
    let mut total = 0;
    let mut i = 1;
    while i <= 5 {
        total += i;
        println!("i = {i}, сумма = {total}");
        i += 1;
    }
    println!("Итого: {total}");

    let mut product = 1;
    let mut k = 1;
    while k <= 5 {
        product *= k;
        k += 1;
    }
    println!("Произведение 1..5: {product}");
}
```
```output
i = 1, сумма = 1
i = 2, сумма = 3
i = 3, сумма = 6
i = 4, сумма = 10
i = 5, сумма = 15
Итого: 15
Произведение 1..5: 120
```

Эта схема встречается постоянно, и в ней три части:

1. Перед циклом - итог и счётчик с начальными значениями (`0` для суммы, `1` для произведения: единица не меняет результат умножения).
2. В теле - прибавить (или умножить) текущее значение и сдвинуть счётчик.
3. После цикла - использовать итог.

Переменные `total` и `product` объявлены **вне** цикла, поэтому после него они доступны. Если объявить их внутри тела, на каждом шаге они создавались бы заново.

## Пример 3. Число повторений заранее неизвестно

```rust run
fn main() {
    let mut money = 1000;
    let mut years = 0;
    while money < 1500 {
        money += money / 10;
        years += 1;
        println!("Год {years}: {money} руб.");
    }
    println!("Нужно лет: {years}");
}
```
```output
Год 1: 1100 руб.
Год 2: 1210 руб.
Год 3: 1331 руб.
Год 4: 1464 руб.
Год 5: 1610 руб.
Нужно лет: 5
```

Здесь неизвестно, сколько лет понадобится: цикл идёт, пока вклад не достигнет 1500 руб. Условие описывает **цель**, а не количество шагов. Деление целое (урок про арифметику), поэтому проценты округляются вниз.

## Пример 4. `loop`, `break` и `continue`

```rust run
fn main() {
    let mut n = 0;
    loop {
        n += 3;
        if n > 10 {
            break;
        }
        println!("n = {n}");
    }
    println!("Вышли из цикла при n = {n}");

    let mut i = 0;
    while i < 8 {
        i += 1;
        if i % 2 == 0 {
            continue;
        }
        println!("нечётное: {i}");
    }
}
```
```output
n = 3
n = 6
n = 9
Вышли из цикла при n = 12
нечётное: 1
нечётное: 3
нечётное: 5
нечётное: 7
```

* `loop` - цикл без условия: повторяет тело «навсегда». Выйти из него можно командой `break` («прервать»), которую обычно ставят внутри `if`. Подходит, когда решение «продолжать или нет» удобнее принимать в середине тела.
* `break` работает и в `while`.
* `continue` («продолжить») завершает **текущий** шаг и переходит к следующей проверке. Здесь он пропускает чётные числа.
* Обратите внимание: в цикле с `continue` команда `i += 1` стоит **раньше** `continue`. Иначе `i` не изменился бы, и цикл застрял (см. ошибки).

## Пример 5. Цикл по цифрам числа

Программа читает ввод, поэтому приведены ввод и вывод.

```rust
fn main() {
    let text = std::io::read_to_string(std::io::stdin()).unwrap();
    let mut number: i32 = text.trim().parse().unwrap();

    let mut digits_sum = 0;
    while number > 0 {
        digits_sum += number % 10;
        number /= 10;
    }
    println!("Сумма цифр: {digits_sum}");
}
```

Ввод:

```text
4072
```

Вывод:

```text
Сумма цифр: 13
```

`number % 10` - последняя цифра числа, `number /= 10` отбрасывает её. Шаги: 4072 -> цифра 2, остаётся 407 -> цифра 7, остаётся 40 -> цифра 0, остаётся 4 -> цифра 4, остаётся 0 -> цикл заканчивается. Сумма 2 + 7 + 0 + 4 = 13.

## Точные правила

* `while условие { тело }`: условие проверяется перед каждым шагом, включая первый. Тело может не выполниться ни разу.
* Условие обязано быть `bool`.
* Счётчик и итоги, которые меняются в цикле, объявляют до цикла и с `mut`.
* `loop { ... }` повторяется бесконечно, пока не встретится `break` (или пока программа не остановится ошибкой).
* `break` немедленно выходит из ближайшего цикла; `continue` переходит к следующей итерации ближайшего цикла (для `while` - к проверке условия).
* `break` и `continue` допустимы только внутри цикла.
* Циклы можно вкладывать один в другой; `break` и `continue` относятся к самому внутреннему.
* Цикл должен приближаться к завершению: после каждого шага условие должно «приближаться» к ложному. Проверяйте: что изменяется? в какую сторону? дойдёт ли до границы?
* Типичный способ проверить цикл - три случая: тело не выполняется совсем, выполняется один раз, выполняется несколько раз.

## Типичные ошибки

**1. Забыли изменить счётчик: бесконечный цикл.**

```rust
fn main() {
    let mut i = 0;
    while i < 5 {
        println!("{i}");
    }
}
```

Программа компилируется, но `i` навсегда остаётся равным 0, условие `i < 5` всегда истинно, и бесконечно печатается 0. Остановить такую программу можно только принудительно. Перед запуском спросите себя: «что в теле цикла приближает условие к ложному?»

**2. `continue` до изменения счётчика.**

```rust
fn main() {
    let mut i = 0;
    while i < 10 {
        if i % 2 == 0 {
            continue;
        }
        println!("{i}");
        i += 1;
    }
}
```

При `i = 0` число чётное, срабатывает `continue`, команда `i += 1` пропускается, и на следующем шаге всё повторяется: цикл застрял на нуле. Меняйте счётчик до `continue` или пишите цикл так, чтобы `continue` не обходил обновление.

**3. Счётчик без `mut`.**

```rust
fn main() {
    let i = 0;
    while i < 3 {
        println!("{i}");
        i += 1;
    }
}
```

```text
error[E0384]: cannot assign twice to immutable variable `i`
 --> main.rs:5:9
  |
2 |     let i = 0;
  |         - first assignment to `i`
...
5 |         i += 1;
  |         ^^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut i = 0;
  |         +++
```

Компилятор предлагает написать `let mut i`. Если переменная меняется, её нужно объявить изменяемой.

**4. Условие не `bool`.**

```rust
fn main() {
    let mut n = 3;
    while n {
        n -= 1;
    }
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:11
  |
3 |     while n {
  |           ^ expected `bool`, found integer
```

Как и в `if`, число нельзя использовать в качестве условия. Напишите `while n > 0` или `while n != 0`.

**5. `i++` из других языков.**

```rust
fn main() {
    let mut i = 0;
    while i < 3 {
        i++;
    }
}
```

```text
error: Rust has no postfix increment operator
 --> main.rs:4:10
  |
4 |         i++;
  |          ^^ not a valid postfix operator
  |
help: use `+= 1` instead
  |
4 -         i++;
4 +         i += 1;
  |
```

В Rust нет `++` и `--`. Пишите `i += 1` и `i -= 1`.

**6. `break` вне цикла.**

```rust
fn main() {
    let n = 5;
    if n > 3 {
        break;
    }
}
```

```text
error[E0268]: `break` outside of a loop or labeled block
 --> main.rs:4:9
  |
4 |         break;
  |         ^^^^^ cannot `break` outside of a loop or labeled block
```

`break` и `continue` имеют смысл только внутри `while`, `loop` или `for`.

**7. Ошибка «на единицу».** Программа нормально компилируется и работает, но печатает не то, что нужно:

```rust run
fn main() {
    let mut i = 1;
    while i < 5 {
        println!("{i}");
        i += 1;
    }
}
```
```output
1
2
3
4
```

Хотели вывести числа от 1 до 5, а получили до 4: условие `i < 5` не допускает пятёрку. Для включения границы нужно `i <= 5`. Проверяйте границы вслух: «а при последнем значении? а на шаг дальше?»

<!-- section: summary -->
## Итоги

* `while условие { ... }` повторяет тело, пока условие истинно; условие проверяется перед каждым шагом.
* Счётчик и итоги объявляют до цикла с `let mut`, а в теле меняют: `i += 1`, `total += x`.
* `loop` повторяется бесконечно до `break`; `continue` пропускает остаток текущего шага.
* Цикл должен приближаться к концу: если в теле ничего не меняет условие, цикл бесконечный.
* Нет `++` и `--`: пишите `+= 1` и `-= 1`.
* Ошибки «на единицу» ищите на границах (`<` и `<=`).

Следующий урок: [цикл for](lesson:rust.from-zero.for-loop), который записывает самые частые счётные циклы короче.

<!-- section: programmer -->
## Для тех, кто уже программирует

* `while` и `loop` как в других языках; `loop { ... }` - идиоматичная замена `while true`, потому что компилятор знает, что цикл не завершается сам, и это учитывается при анализе типов и потока управления.
* Нет `++`/`--`, `do ... while` и C-подобного `for(;;)`. Для счётчиков обычно берут `for i in 0..n` (следующий урок).
* `loop` - выражение: `break значение;` возвращает значение из цикла, например `let x = loop { ... break 42; };`. Метки (`'outer: loop`) позволяют выйти из внешнего цикла.
* Условие строго `bool`. Нет значения по умолчанию у `mut`: забытый `mut` - ошибка компиляции, а не тихое поведение.
* Целочисленное переполнение в цикле-накопителе зависит от режима сборки: в отладочной - паника, в релизной (`-O`, как в приложении) - заворачивание по модулю. Подробнее - в `rust-first-steps`.
* Деление и остаток для отрицательных чисел округляют к нулю; цикл по цифрам `while n > 0` предполагает неотрицательное число.

## `loop` с результатом и метки

Это необязательный раздел: для заданий он не нужен.

Так как в Rust почти всё - выражения, цикл `loop` может вернуть значение. Команда `break` принимает результат:

```rust
let mut attempts = 0;
let first_big = loop {
    attempts += 1;
    if attempts * attempts > 50 {
        break attempts;
    }
};
```

Тогда `first_big` равно 8. Для `while` так нельзя: условие может оказаться ложным с самого начала, и тогда цикл вообще не имел бы значения.

Для вложенных циклов у `break` и `continue` есть метки: цикл помечают `'outer: while ... { ... }`, а выход пишут `break 'outer;`. Новичку метки нужны редко, но полезно знать, что без них в двойном цикле нет способа выйти сразу из обоих.
