## Зачем разрезать строки

Почти любые входные данные приходят текстом: строка `Анна;90`, строка `хлеб молоко сыр`, строка `2024-05-17`. Чтобы с ними работать, текст нужно разрезать на части: отделить имя от числа, слова друг от друга. Для этого у строк есть **методы** - готовые операции, которые вызываются через точку, как `trim()` в уроке про ввод.

Строки в Rust хранят текст в кодировке UTF-8: буква кириллицы занимает несколько байт. Поэтому почти все операции в Rust работают с текстом целиком или с **символами** (`char`), но не с «байтом номер 3». Это защищает от поломки букв посередине.

## Одна новая идея: методы возвращают части, а не меняют строку

Все методы этого урока **не изменяют** исходную строку: они возвращают новый результат или кусочки исходной (`&str`). Результат нужно куда-то поместить: в переменную, в цикл, в `println!`. Если его просто выбросить, строка останется прежней (см. ошибки ниже).

## Пример 1. Поиск, замена, длина

```rust run
fn main() {
    let title = "  Купить хлеб и молоко  ";
    let clean = title.trim();
    println!("[{clean}]");
    println!("{}", clean.contains("хлеб"));
    println!("{}", clean.starts_with("Купить"));
    println!("{}", clean.ends_with("сыр"));
    println!("{}", clean.replace(" и ", " & "));
    println!("{}", clean.len());
    println!("{}", clean.chars().count());
}
```
```output
[Купить хлеб и молоко]
true
true
false
Купить хлеб & молоко
37
20
```

* `contains("хлеб")` - есть ли такой кусок в тексте; `starts_with` и `ends_with` проверяют начало и конец. Все три возвращают `bool`.
* `replace(" и ", " & ")` возвращает **новую** строку, где каждое вхождение первого куска заменено вторым.
* `len()` вернул 37, а `chars().count()` - 20 для того же текста: `len()` считает **байты** (русская буква - 2 байта), `chars().count()` - символы. Для подсчёта «букв в слове» используйте `chars().count()`.

**Попробуйте.** Сколько байтов и сколько символов в слове `"привет"`? Сначала предположите, затем проверьте программой.

## Пример 2. `split_whitespace`, `split` и `join`

```rust run
fn main() {
    let sentence = "  один   два три  ";
    let mut count = 0;
    for word in sentence.split_whitespace() {
        println!("слово: {word}");
        count += 1;
    }
    println!("слов: {count}");

    let csv = "хлеб,молоко,,сыр";
    let mut items: Vec<&str> = Vec::new();
    for part in csv.split(',') {
        items.push(part);
    }
    println!("{:?}", items);
    println!("{}", items.join(" | "));
}
```
```output
слово: один
слово: два
слово: три
слов: 3
["хлеб", "молоко", "", "сыр"]
хлеб | молоко |  | сыр
```

* `split_whitespace()` делит по любым пробельным символам, **пропуская пустые** части: лишние пробелы между словами и по краям игнорируются.
* `split(',')` делит по одному символу-разделителю. Пустые части **остаются**: между двумя запятыми получилась пустая строка `""`. Разделитель в одинарных кавычках - это `char`, а не строка.
* Результат `split` - не вектор, а последовательность, которую перебирают циклом. Если части нужны потом, их складывают в `Vec<&str>` через `push`.
* `items.join(" | ")` склеивает части вектора в одну строку через разделитель.

## Пример 3. `split_once`: разрезать один раз

```rust run
fn show(line: &str) {
    match line.split_once(';') {
        Some((name, score)) => println!("имя=[{}] балл=[{}]", name.trim(), score.trim()),
        None => println!("нет разделителя: {line}"),
    }
}

fn main() {
    show("Анна; 90");
    show("Борис;75;лишнее");
    show("без разделителя");
}
```
```output
имя=[Анна] балл=[90]
имя=[Борис] балл=[75;лишнее]
нет разделителя: без разделителя
```

`line.split_once(';')` ищет **первый** разделитель и возвращает `Option`: `Some((до, после))`, если он найден, и `None`, если нет. В образце `Some((name, score))` вложенные скобки разбирают пару на две переменные, как цикл `for (k, v)` в уроке про словари.

Во втором вызове в строке два разделителя, но резка идёт только по первому: `score` содержит остаток `75;лишнее`. Пробелы вокруг частей убирают `trim()`.

## Пример 4. `chars()`: перебор символов

Программа читает ввод, поэтому приведены ввод и вывод.

```rust
fn main() {
    let text = std::io::read_to_string(std::io::stdin()).unwrap();
    let mut letters = 0;
    let mut digits = 0;
    let mut vowels = 0;
    for c in text.chars() {
        if c.is_alphabetic() {
            letters += 1;
            if "аеёиоуыэюяАЕЁИОУЫЭЮЯ".contains(c) {
                vowels += 1;
            }
        } else if c.is_ascii_digit() {
            digits += 1;
        }
    }
    println!("букв: {letters}, гласных: {vowels}, цифр: {digits}");
}
```

Ввод:

```text
Привет, мир 2024!
Где 7 яблок?
```

Вывод:

```text
букв: 17, гласных: 6, цифр: 5
```

* `text.chars()` перебирает символы по одному; `c` имеет тип `char`.
* `c.is_alphabetic()` - буква ли это (учитывает кириллицу), `c.is_ascii_digit()` - цифра `0`-`9`.
* `"аеёиоуыэюя...".contains(c)` ищет символ в строке гласных. `contains` принимает и строку, и один символ.
* Символы переноса строки, пробелов и знаков препинания не попали ни в одну категорию.

## Точные правила

* Строки (`String`, `&str`) хранятся в UTF-8. `s.len()` - число **байтов**; `s.chars().count()` - число **символов**.
* Индексировать строку по номеру (`s[0]`) нельзя: символ может занимать несколько байтов. Берите `chars()`.
* `s.chars().next()` возвращает `Option<char>` - первый символ, или `None` для пустой строки.
* `s.trim()` убирает пробельные символы по краям; `s.contains(x)`, `s.starts_with(x)`, `s.ends_with(x)` возвращают `bool`.
* `s.replace(что, чем)` возвращает новую `String`; исходная строка не меняется.
* `s.split_whitespace()` - слова, разделённые любыми пробелами (пустых слов не бывает). `s.split(разделитель)` - части по разделителю (пустые части сохраняются). Разделитель - `char` (`','`) или строка (`", "`).
* `s.split_once(разделитель)` - `Option<(&str, &str)>`: часть до первого разделителя и после него.
* `v.join(разделитель)` для `Vec<&str>` склеивает части в `String`.
* `char`: `is_alphabetic()`, `is_ascii_digit()` и другие проверки; литерал символа - в одинарных кавычках: `'а'`.
* Все эти методы не меняют строку на месте; результат нужно использовать.

## Типичные ошибки

**1. Индексация строки по номеру.**

```rust
fn main() {
    let word = String::from("привет");
    println!("{}", word[0]);
}
```

```text
error[E0277]: the type `str` cannot be indexed by `{integer}`
   --> main.rs:3:25
    |
  3 |     println!("{}", word[0]);
    |                         ^ string indices are ranges of `usize`
    |
    = help: the trait `SliceIndex<str>` is not implemented for `{integer}`
    = note: you can use `.chars().nth()` or `.bytes().nth()`
            for more information, see chapter 8 in The Book: <https://doc.rust-lang.org/book/ch08-02-strings.html#indexing-into-strings>
help: `usize` implements trait `SliceIndex<T>`
   --> ...:179:1
    |
179 | const unsafe impl<T> SliceIndex<[T]> for usize {
    | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ `SliceIndex<[T]>`
    |
   ::: ...:197:1
    |
197 | unsafe impl SliceIndex<ByteStr> for usize {
    | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ `SliceIndex<ByteStr>`
    = note: required for `String` to implement `Index<{integer}>`
```

Если нужен первый символ, возьмите `word.chars().next()`.

**2. `split_once` как пара без `Option`.**

```rust
fn main() {
    let line = "Анна;90";
    let (name, score) = line.split_once(';');
    println!("{name} {score}");
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:9
  |
3 |     let (name, score) = line.split_once(';');
  |         ^^^^^^^^^^^^^   -------------------- this expression has type `Option<(&str, &str)>`
  |         |
  |         expected `Option<(&str, &str)>`, found `(_, _)`
  |
  = note: expected enum `Option<(&str, &str)>`
            found tuple `(_, _)`
help: try wrapping the pattern in `Some`
  |
3 |     let Some((name, score)) = line.split_once(';');
  |         +++++             +
```

Результат - `Option` от пары, поэтому образец должен быть `Some((name, score))`, а ветку `None` нужно обработать (`match` или `if let`).

**3. Символ сравнивается со строкой.**

```rust
fn main() {
    let text = "мама";
    let mut count = 0;
    for c in text.chars() {
        if c == "м" {
            count += 1;
        }
    }
    println!("{count}");
}
```

```text
error[E0308]: mismatched types
 --> main.rs:5:17
  |
5 |         if c == "м" {
  |            -    ^^^ expected `char`, found `&str`
  |            |
  |            expected because this is `char`
  |
help: if you meant to write a `char` literal, use single quotes
  |
5 -         if c == "м" {
5 +         if c == 'м' {
  |
```

`c` - это `char`, а `"м"` - строка. Символ пишется в одинарных кавычках: `'м'`.

**4. Результат `replace` выброшен.**

```rust
fn main() {
    let s = String::from("abc");
    s.replace("a", "x");
    println!("{s}");
}
```

```text
warning: unused return value of `str::<impl str>::replace` that must be used
 --> main.rs:3:5
  |
3 |     s.replace("a", "x");
  |     ^^^^^^^^^^^^^^^^^^^
  |
  = note: this returns the replaced string as a new allocation, without modifying the original
  = note: `#[warn(unused_must_use)]` (part of `#[warn(unused)]`) on by default
help: use `let _ = ...` to ignore the resulting value
  |
3 |     let _ = s.replace("a", "x");
  |     +++++++
```

Программа компилируется, но `s` остаётся прежней: напечатается `abc`. Метод вернул новую строку, и компилятор предупреждает, что её никто не использует. Напишите `let s = s.replace("a", "x");` или используйте результат сразу.

**5. `len()` считают символами.** `len()` не ошибка, но для кириллицы он вернёт вдвое больше, чем число букв:

```rust run
fn main() {
    let word = "привет";
    println!("{} {}", word.len(), word.chars().count());
}
```
```output
12 6
```

Для числа букв используйте `chars().count()`.

## Итоги

* Методы строк возвращают результат и не меняют исходную строку: результат нужно использовать.
* `split_whitespace()` делит на слова, `split(разделитель)` - по разделителю (пустые части сохраняются), `split_once` - один раз, как `Option` пары.
* `contains`, `starts_with`, `ends_with` отвечают `bool`; `replace` возвращает новую строку; `join` склеивает части вектора.
* `chars()` перебирает символы; `len()` считает байты, `chars().count()` - символы; индексировать строку числом нельзя.

## Для тех, кто уже программирует

* Строки Rust - всегда валидный UTF-8. `s[i]` не существует, потому что оно либо дало бы байт, либо потребовало бы линейного поиска символа. Срез `&s[a..b]` по **байтовым** границам существует, но паникует, если граница попадает внутрь символа.
* `char` - один скаляр Unicode (4 байта), а не «графема»: составной символ вроде «й» в разложенной форме или эмодзи с модификаторами - несколько `char`.
* `split_whitespace()` аналог `str.split()` в Python без аргумента; `split(',')` сохраняет пустые части, как `str.split(',')`.
* `split_once` - аналог `partition`/`str.split(sep, 1)` с явным `Option`, без пустой строки в случае отсутствия разделителя.
* Методы возвращают `&str` - **срезы исходной строки без копирования**. Поэтому исходная строка должна жить, пока используются части (почему это гарантировано - в `rust-first-steps`, раздел про времена жизни).
* Итераторы ленивы: `split` ничего не делает, пока его не переберут. Способы собрать результат одной строкой (`collect`, `map`) отложены до `rust-fundamentals`.
* `to_uppercase` / `to_lowercase` учитывают Unicode (`"ß".to_uppercase()` даёт `"SS"`), а не только ASCII.

## Что такое UTF-8 и почему `len()` в байтах

Это необязательный раздел: для заданий он не нужен.

Компьютер хранит числа. Чтобы хранить текст, каждому символу назначен номер (Unicode), а UTF-8 - способ записать номер в байтах. Латинские буквы и цифры занимают 1 байт, буквы кириллицы - 2, многие иероглифы - 3, эмодзи - 4. Поэтому в `"привет"` шесть символов, но двенадцать байт.

Rust выбрал UTF-8 по умолчанию, чтобы тексты на любом языке вели себя одинаково. Цена - символ нельзя достать по номеру за постоянное время: для этого пришлось бы просматривать строку с начала, подсчитывая символы. Поэтому в стандартной библиотеке нет `s[i]`, а есть явные операции: `chars()` для символов, `len()` для байтов, `split*` для частей. Так нельзя случайно разрезать букву посередине.
