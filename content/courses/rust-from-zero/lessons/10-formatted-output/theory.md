## Зачем управлять видом чисел и текста

Сумма в чеке должна выглядеть как `136.50`, а не `136.5` и не `136.50000000000003`. Колонки таблицы должны стоять ровно друг под другом. Номер заказа должен быть `007`, а не `7`. Всё это решается не вычислениями, а **форматом вывода**: тем, как значение превращается в текст.

До сих пор вы писали в строке `println!` пустые скобки `{}`: «подставь значение как обычно». Внутрь скобок можно добавить **правила**, и тогда подстановка будет выглядеть так, как вам нужно.

## Одна новая идея: после двоеточия идут правила

Между фигурными скобками ставят двоеточие, а после него - правила:

```rust
println!("{:.2}", 3.14159);
```

Это печатает `3.14`. Запись `{:.2}` читается «число с двумя знаками после запятой». Общая схема такая: `{:` заполнитель выравнивание ширина `.` точность `}`. Каждая часть необязательна, нужные вы пишете, остальные пропускаете.

Основные правила, которые вам понадобятся:

* `.2` - **точность**: сколько знаков после запятой у дробного числа;
* `8` - **ширина**: минимальная длина поля в знаках; если значение короче, оно дополняется до этой длины;
* `<`, `>`, `^` - **выравнивание**: влево, вправо, по центру;
* символ перед выравниванием - **заполнитель** (по умолчанию пробел): `{:*>8}`;
* `0` перед шириной - дополнить число нулями слева: `{:05}`.

Отдельный маленький факт: запись дробных чисел в Rust не зависит от настроек компьютера (локали). Десятичный разделитель всегда точка, `{:.2}` напечатает `3.14`, а не `3,14`, на любом компьютере. Если вам понадобится запятая, её придётся подставить самим, это отдельная работа с текстом.

## Пример 1. Точность `{:.N}`

```rust run
fn main() {
    let pi = 3.14159265;
    println!("{}", pi);
    println!("{:.2}", pi);
    println!("{:.0}", pi);
    println!("{:.3}", 2.0);
    println!("{}", 3.0);
    println!("{:.1}", 3.0);
}
```
```output
3.14159265
3.14
3
2.000
3
3.0
```

* `{}` печатает число «как есть», со всеми знаками. Если дробная часть нулевая, `.0` не пишется: `3.0` печатается как `3`.
* `{:.2}` оставляет два знака и **округляет**, а не обрезает. `{:.0}` убирает дробную часть совсем.
* `{:.3}` дополняет нулями: `2.000`. Именно поэтому `{:.2}` годится для денег: `19` превратится в `19.00`.
* `{:.1}` для `3.0` даёт `3.0`: если число знаков задано, они печатаются всегда.

## Пример 2. Как именно округляется

```rust run
fn main() {
    println!("{:.2}", 2.675);
    println!("{:.2}", 0.125);
    println!("{:.1} {:.1}", 0.25, 0.35);
    let total = 0.1 + 0.2;
    println!("{}", total);
    println!("{:.2}", total);
}
```
```output
2.67
0.12
0.2 0.3
0.30000000000000004
0.30
```

Результаты могут удивить, и у каждого есть причина.

* Дробные числа хранятся в двоичном виде, и многие десятичные дроби в нём записать точно нельзя. `2.675` на самом деле чуть меньше, чем 2.675, поэтому округляется вниз до `2.67`. А `0.35` оказывается чуть меньше 0.35, и получается `0.3`.
* Если число точно посередине (как `0.125` или `0.25`), Rust округляет к ближайшему **чётному** знаку: `0.12` и `0.2`.
* `0.1 + 0.2` в двоичной арифметике равно `0.30000000000000004`, а не `0.3`. Это не ошибка Rust: так устроены дробные числа во всех языках. `{:.2}` скрывает этот хвост и печатает `0.30`.

Вывод: для печати результата ставьте `{:.2}` (или нужное число знаков), а не полагайтесь на «как есть».

## Пример 3. Ширина, выравнивание и заполнитель

```rust run
fn main() {
    println!("[{:8}]", 45);
    println!("[{:8}]", "чай");
    println!("[{:<8}]", 45);
    println!("[{:>8}]", "чай");
    println!("[{:^8}]", "чай");
    println!("[{:*>8}]", 45);
    println!("[{:-^11}]", " меню ");
}
```
```output
[      45]
[чай     ]
[45      ]
[     чай]
[  чай   ]
[******45]
[-- меню ---]
```

* `{:8}` - поле шириной 8 знаков. По умолчанию **число прижимается вправо, а текст влево**. Первые две строки это показывают.
* `<` прижимает влево, `>` вправо, `^` центрирует. Если места для центрирования нечётное число, лишний знак добавляется справа.
* Перед выравниванием можно поставить заполнитель: `{:*>8}` заполняет свободное место звёздочками. `{:-^11}` центрирует текст и заполняет остальное дефисами: так делают заголовки и рамки.
* Ширина считается в **знаках** (буквах), а не в байтах: русское «чай» занимает 3 места, хотя в памяти 6 байтов. Выравнивание кириллицы работает так же, как латиницы.
* Если значение длиннее поля, оно не обрезается: поле просто расширяется.

## Пример 4. Нули слева, знак и сочетание

```rust run
fn main() {
    println!("{:05}", 42);
    println!("{:+}", 42);
    println!("{:+.1}", 2.5);
    println!("[{:8.2}]", 3.14159);
    println!("[{:<8.2}]", 3.14159);
    println!("[{:08.3}]", 3.14159);
    println!("{:03}", -5);
}
```
```output
00042
+42
+2.5
[    3.14]
[3.14    ]
[0003.142]
-05
```

* `{:05}` - ширина 5, свободное место заполняется нулями: так записывают номера (`007`).
* `{:+}` всегда показывает знак. Обычно знак пишется только у отрицательных чисел.
* Ширину и точность можно сочетать: `{:8.2}` - поле шириной 8 и два знака после запятой. Порядок такой: сначала ширина, затем точка и точность.
* Нули слева учитывают знак: `-5` в поле шириной 3 превращается в `-05`.

## Пример 5. Ровная таблица

```rust run
fn main() {
    let name = "Чай";
    let price = 45.5;
    let name2 = "Круассан";
    let price2 = 120.0;
    println!("{:<10}{:>8}", "Товар", "Цена");
    println!("{name:<10}{price:>8.2}");
    println!("{name2:<10}{price2:>8.2}");
}
```
```output
Товар         Цена
Чай          45.50
Круассан    120.00
```

Колонки получились ровными без ручного подсчёта пробелов: название прижато влево в поле из 10 знаков, цена вправо в поле из 8. Правила можно писать и при подстановке по имени: `{name:<10}`, `{price:>8.2}`. Значение стоит перед двоеточием, правила - после.

## Пример 6. `format!` собирает строку, но не печатает

```rust run
fn main() {
    let id = format!("ID-{:03}", 7);
    let label = format!("{}: {:.1} кг", "Мука", 2.0);
    println!("{id}");
    println!("{label}");
    println!("{}", label.chars().count());
}
```
```output
ID-007
Мука: 2.0 кг
12
```

`format!` принимает ту же строку формата, что и `println!`, но вместо печати **возвращает** готовый текст типа `String`. Его можно сохранить в переменной, измерить, напечатать позже. Это самый удобный способ собирать строки из частей (знак `+` для этого, как вы помните, не годится).

**Попробуйте.** Напечатайте цену `7.5` как `7.50` и как `007.50` (подсказка: ширина 6 и нули). Затем выведите слово «Итог» по центру поля из 20 знаков, заполнитель `=`.

## Точные правила

* Общий вид подстановки: `{[имя]:[заполнитель][выравнивание][знак][0][ширина][.точность]}`. После двоеточия все части необязательны, но идут именно в таком порядке.
* **Точность** `.N`: для дробных чисел - число знаков после запятой, с округлением (при точной середине - к ближайшему чётному). Для целых чисел не используется. Для строки `.N` обрезает строку до N знаков.
* **Ширина** `N`: минимальная длина поля в знаках. Короткое значение дополняется, длинное остаётся как есть.
* **Выравнивание**: `<` влево, `>` вправо, `^` по центру. Без явного выравнивания числа прижимаются вправо, строки - влево.
* **Заполнитель** - любой один символ перед знаком выравнивания: `{:*>8}`, `{:->8}`. Выравнивание без заполнителя заполняет пробелами.
* `0` перед шириной дополняет число нулями слева: `{:05}`, `{:08.3}`. 
* `+` перед шириной всегда показывает знак числа.
* Правила действуют для подстановок по порядку (`{:.2}`) и по имени (`{price:.2}`).
* Ширина считается в символах (`char`), а не в байтах и не в «видимых» графемах. Для кириллицы совпадает.
* Число подстановок и аргументов должно совпадать (как в уроке про вывод). Лишнее значение без места в строке формата - ошибка компиляции.
* **Локаль не используется**: десятичный разделитель всегда точка, разделителей тысяч нет. `{:.2}` напечатает `3.14` на любом компьютере.
* `format!("...", ...)` возвращает `String`; `println!` печатает; `print!` печатает без перехода на новую строку.
* Спецификаторы из C (`%d`, `%.2f`) не поддерживаются, а `{:d}` и `{:.2f}` - ошибка: после двоеточия нет буквы типа (кроме `x`, `b`, `o`, `e` и `?`, которые нужны редко).
* Дробное число с нулевой дробной частью печатается через `{}` без `.0` (`3.0` -> `3`). Если нужна запись `3.0`, ставьте `{:.1}`.

## Типичные ошибки

**1. Буква типа после точности (привычка из C).**

```rust
fn main() {
    let x = 2.5;
    println!("{:.2f}", x);
}
```

```text
error: unknown format trait `f`
 --> main.rs:3:19
  |
3 |     println!("{:.2f}", x);
  |                   ^
  |
  = note: the only appropriate formatting traits are:
          - ``, which uses the `Display` trait
          - `?`, which uses the `Debug` trait
          ...
```

«Неизвестный формат `f`». В Rust тип не указывают: запись `{:.2}` подходит и для `f32`, и для `f64`. Уберите `f`. (Список подходящих букв сокращён: `?`, `e`, `x`, `b` и другие нужны редко.)

**2. Точка перед двоеточием.**

```rust
fn main() {
    let x = 2.5;
    println!("{.2}", x);
}
```

```text
error: invalid format string: expected `}`, found `.`
 --> main.rs:3:16
  |
3 |     println!("{.2}", x);
  |               -^ expected `}` in format string
  |               |
  |               because of this opening brace
```

«Ожидалась закрывающая скобка, найдена точка». Правила пишут только после двоеточия: `{:.2}`.

**3. Лишнее значение без места.**

```rust
fn main() {
    println!("{:5.2}", 1.0, 2.0);
}
```

```text
error: argument never used
 --> main.rs:2:29
  |
2 |     println!("{:5.2}", 1.0, 2.0);
  |              --------       ^^^ argument never used
  |              |
  |              formatting specifier missing
```

Каждое значение нужно показать в своей подстановке. Здесь вторая подстановка забыта.

**4. Ширина путается с точностью.** `{:2.8}` - это ширина 2 и 8 знаков после запятой, а не наоборот. Сначала ширина, потом точка и точность.

**5. Ожидают запятую как разделитель.** `{:.2}` всегда печатает точку. Если ответ нужен именно с запятой, это отдельная задача (замена знака в тексте), и условие упражнения скажет о ней прямо.

**6. Нули слева у текста.** `{:05}` работает для чисел. Чтобы дополнить текст знаком, используйте заполнитель и выравнивание: `{:0>5}` для строки `"42"` даст `00042`.

**7. Забыли, что `{}` не округляет.** `println!("{}", 0.1 + 0.2)` печатает `0.30000000000000004`. Для вывода пользователю выбирайте число знаков явно.

## Итоги

* После двоеточия в `{}` пишутся правила: `{:.2}` - два знака после запятой, `{:8}` - поле шириной 8, `{:<8}` `{:>8}` `{:^8}` - выравнивание, `{:*>8}` - заполнитель, `{:05}` - нули слева, `{:+}` - показать знак.
* Ширину и точность можно сочетать: `{:>10.2}`.
* `{:.2}` округляет и дополняет нулями; `0.30000000000000004` превращается в `0.30`.
* По умолчанию числа прижимаются вправо, текст влево; ширина считается в знаках, а не в байтах.
* Формат не зависит от локали: разделитель - всегда точка.
* `format!` принимает тот же формат, но возвращает `String`, а не печатает.

Мы научились вводить, считать и красиво выводить. Теперь программе нужно **принимать решения**, а для этого - сравнивать значения: [Сравнения и логика](lesson:rust.from-zero.comparison-and-logic).

## Для тех, кто уже программирует

* Синтаксис формата - из `std::fmt`: `{[arg]:[[fill]align][sign]['#']['0'][width]['.' precision][type]}`. Проверяется на этапе компиляции; несовпадение числа аргументов - ошибка компиляции, а не неопределённое поведение, как в `printf`.
* Тип в конце: пусто = `Display`, `?` = `Debug`, `x`/`X` = шестнадцатеричное, `b` = двоичное, `o` = восьмеричное, `e` = экспоненциальное. Буквы `d`, `f`, `s` не существуют.
* Ширину и точность можно передавать аргументом: `{:>1$}`, `{:>width$}`, `{:.*}`. В этом курсе достаточно литеральных значений.
* Округление `{:.N}` использует точное десятичное представление `f64` и округляет к ближайшему, при точной ничьей - к чётному (`{:.0}` для `0.5, 1.5, 2.5` даёт `0 2 2`).
* Локаль не участвует: `Display` для чисел всегда использует `.` и не вставляет разделителей. Для локализованных чисел нужны внешние крейты.
* Ширина измеряется в `char` (кодовых точках Unicode), а не в байтах и не в графемах; для CJK и эмодзи колонки могут не выровняться визуально.
* `format!` выделяет `String`; для записи в существующий буфер есть `write!` (требует `use std::fmt::Write`) - здесь не нужен.
* `{:?}` печатает отладочное представление (`"q"` с кавычками), `{:#?}` - с отступами; пригодится для структур (урок 19).

## Откуда берутся «лишние» знаки

Это необязательный раздел: для заданий он не нужен.

Число типа `f64` хранится в 64 битах: знак, порядок и 52 бита значащей части. Все такие числа - дроби вида `m / 2^k`. Дробь 1/10 так записать нельзя, как нельзя записать 1/3 конечной десятичной дробью: в двоичной системе у 0.1 бесконечная периодическая запись, и в `f64` попадает ближайшее подходящее число, чуть большее 0.1. При сложении 0.1 и 0.2 ошибки накапливаются, поэтому в результате появляется «хвост» `...04`.

При печати через `{}` Rust выбирает **самую короткую** десятичную запись, которая однозначно возвращает то же число `f64`. Поэтому `0.1` печатается как `0.1`, а `0.1 + 0.2` - как `0.30000000000000004`: более короткая запись уже означала бы другое число. А `{:.2}` берёт точное значение и округляет его до двух знаков, поэтому хвост пропадает.

Отсюда практическое правило для денег: хранить копейки целым числом (`4550` вместо `45.50`) надёжнее, а `f64` с `{:.2}` годится для учебных расчётов и отображения.

Правила формата хранятся не в `println!`, а в компилируемой строке: макрос разбирает её на этапе сборки и превращает в вызовы функций вывода, у каждой из которых есть параметры «ширина», «точность», «заполнитель». Благодаря этому ошибки вроде `{:.2f}` ловятся компилятором.
