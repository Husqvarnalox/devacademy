## Зачем этот урок

Вы уже пишете на Python, Java, JavaScript или C#, поэтому циклы и условия объяснять не нужно. Урок собирает то, что в Go устроено иначе и чаще всего ломает первые программы: компилятор запрещает неиспользуемые переменные и импорты, нет неявных преобразований чисел, деление целых отбрасывает дробную часть, а цикл в языке один - `for`. Прохождение урока вместе с упражнением и квизом засчитывает уроки 1-16 курса «Go с нуля».

## Главная мысль

Go - компилируемый язык со строгой статической типизацией и минимальным набором конструкций. Многое, что другие языки разрешают и ловят линтером, Go считает ошибкой компиляции. Это не придирка: компилятор заставляет держать код чистым, а отсутствие «умных» неявных правил делает поведение предсказуемым.

Каждая программа - это пакет `main` с функцией `main`. Переменные объявляются через `var` или короткую форму `:=` (только внутри функций). У каждой переменной есть тип, и если значение не задано, она получает **нулевое значение** своего типа: `0`, `""`, `false`, `nil`. Неинициализированных переменных в Go не бывает.

<!-- section: examples -->
## Пример 1. Короткое объявление и затенение

```go run
package main

import "fmt"

func main() {
	x := 10
	if x > 5 {
		x := x * 2 // новая переменная во внутреннем блоке
		fmt.Println("внутри:", x)
	}
	fmt.Println("снаружи:", x)
}
```
```output
внутри: 20
снаружи: 10
```

Оператор `:=` во внутреннем блоке создал **новую** переменную `x`, а не изменил внешнюю. В Python такого различия нет, в Java и C# повторное объявление в таком блоке запрещено. В Go это законно и служит источником тонких ошибок: чтобы изменить внешнюю переменную, нужно писать `x = x * 2`.

## Пример 2. Числа без сюрпризов и без неявных преобразований

```go run
package main

import "fmt"

func main() {
	a, b := 7, 2
	fmt.Println(a/b, a%b, -a/b, -a%b)
	fmt.Println(float64(a) / float64(b))

	var f float64 = 3.9
	fmt.Println(int(f))

	var small int8 = 127
	small++
	fmt.Println(small)

	var s string
	var p *int
	var ok bool
	fmt.Printf("%q %v %v %d\n", s, p, ok, len(s))
}
```
```output
3 1 -3 -1
3.5
3
-128
"" <nil> false 0
```

* Деление двух `int` целочисленное и округляется к нулю (`-7/2` равно `-3`); остаток имеет знак делимого.
* `float64(a) / float64(b)` - явное преобразование; выражение `a / 2.0` с переменной `a` типа `int` не скомпилируется, а `a * f` для `int` и `float64` тоже.
* `int(f)` отбрасывает дробную часть, а не округляет.
* Переполнение целых типов фиксированного размера не вызывает ошибки: `int8` после `127` даёт `-128`.
* Последняя строка показывает нулевые значения: пустая строка, `nil`-указатель, `false`.

## Пример 3. for и switch

```go run
package main

import "fmt"

func main() {
	for i := 0; i < 3; i++ {
		fmt.Print(i, ",")
	}
	fmt.Println()

	n := 1
	for n < 100 { // аналог while
		n *= 3
	}
	fmt.Println(n)

	for i := range 3 { // число после range: счёт от 0
		fmt.Print(i, ";")
	}
	fmt.Println()

	switch d := n % 4; d {
	case 0, 1:
		fmt.Println("0 или 1")
	case 3:
		fmt.Println("три")
		fallthrough
	default:
		fmt.Println("по умолчанию")
	}
}
```
```output
0,1,2,
243
0;1;2;
три
по умолчанию
```

Ключевое слово `while` в Go отсутствует: цикл с одним условием - тот же `for`, а бесконечный цикл - `for { ... }`. Ветки `switch` не проваливаются дальше, поэтому `break` в конце не нужен; чтобы выполнить следующую ветку, нужно явное `fallthrough`. В `case` можно перечислять несколько значений. Перед условием `if` и `switch` допускается короткая инструкция (`switch d := n % 4; d`), переменная которой видна только внутри.

**Попробуйте:** замените `n < 100` на `n < 10` и предскажите, какая ветка `switch` сработает.

<!-- section: precise -->
* Пакет `main` и функция `main()` - точка входа. Файл начинается с `package`, затем `import`.
* Неиспользуемая локальная переменная и неиспользуемый импорт - **ошибки компиляции**. Заглушка - пустой идентификатор `_`.
* `:=` объявляет и инициализирует; хотя бы одна переменная слева должна быть новой. Вне функций доступен только `var`.
* Нулевое значение: `0` для чисел, `""` для строки, `false` для `bool`, `nil` для указателей, срезов, карт, функций, каналов и интерфейсов.
* Числовые типы не смешиваются: `int` и `int64`, `int` и `float64` - разные типы, преобразование всегда явное: `float64(n)`. Нетипизированные константы (`2`, `2.5`) подстраиваются под тип контекста.
* `/` над целыми отбрасывает дробь к нулю, `%` - остаток со знаком делимого. Деление целого на нулевое значение приводит к панике во время выполнения, константное деление на ноль не компилируется.
* `if`, `for`, `switch` не требуют круглых скобок вокруг условия, но фигурные обязательны; условие должно иметь тип `bool` (никакого «истинного» числа или строки).
* `for` - единственный цикл: три части, одно условие, бесконечный, `for range`. `break` и `continue` работают с ближайшим циклом, метки позволяют выйти из внешнего.
* `switch` не проваливается; без выражения (`switch {`) он заменяет цепочку `if / else if`.
* Ввод и вывод: `fmt.Println`, `fmt.Printf`, `fmt.Scan` (читает слова, разделённые пробелами и переводами строк), результат `Scan` - число прочитанных значений и ошибка.

<!-- section: mistakes -->
**1. Неиспользуемая переменная или импорт.**

```go
import (
	"fmt"
	"os"
)

func main() {
	y := 2
	fmt.Println("привет")
}
```
Компилятор сообщает: `"os" imported and not used` и `declared and not used: y`. Почему: так Go исключает мёртвый код и ускоряет сборку. Исправление: удалить лишнее или использовать значение; на время отладки допустимо `_ = y`. Узнать самому: сообщение содержит имя и номер строки, код не запустится вообще.

**2. Смешение `int` и `float64`.**

```go
func scale(a int, b float64) float64 {
	return a * b
}
```
Ошибка: `invalid operation: a * b (mismatched types int and float64)`. Исправление: `float64(a) * b`. Неявных расширений нет даже между `int` и `int64`.

**3. Затенение через `:=`.**
Если внутри блока написать `x := ...`, внешняя `x` не меняется (см. пример 1). Компилятор не предупредит. Признак: после блока значение «не обновилось»; инструмент `go vet -vettool` с анализатором shadow находит такие места, а проще всего проверять, нужен ли вам `=` вместо `:=`.

**4. Ожидание «проваливания» в switch и неявного приведения условия.**
`if n {` для числа `n` или `if s {` для строки не компилируется: условие обязано быть `bool`. А в `switch` ветка сама завершается; забытое `break` не нужно, а ожидаемое по привычке из C поведение требует `fallthrough`.

**5. Целочисленное деление там, где ждали дробь.**
`avg := sum / count` для `int` теряет дробную часть, и ошибки при этом нет. Преобразуйте операнды: `float64(sum) / float64(count)`.

## Главное для тех, кто уже программирует

* Компиляция: `go run main.go` собирает и запускает, `go build` создаёт один исполняемый файл без виртуальной машины и зависимостей. Типы проверяются при компиляции; динамической типизации, как в Python и JavaScript, нет.
* Неиспользуемые переменные и импорты - ошибки (в Java и C# это предупреждения). Точка с запятой ставится автоматически, фигурная скобка обязана стоять на одной строке с `if`, `for` или `func`. Форматирование делает `gofmt`, споров о стиле нет.
* `:=` - вывод типа; `var x int` - нулевое значение. Переменная в блоке может затенять внешнюю (в отличие от Java и C#).
* Числа: `int` зависит от платформы (на 64-битных - 64 бита), явные `int8`...`int64`, `uint*`, `float32/64`. Нет неявных преобразований, нет оператора `**`, нет тернарного `?:`. Строки - неизменяемые последовательности байтов UTF-8.
* Нет `while` и `do-while`: всё это `for`. Нет скобок вокруг условий. Нет исключений: ошибки возвращаются значениями (следующий урок).
* `switch` без `break` и без проваливания; в `case` допустимы любые выражения, а не только константы; есть `switch` без выражения.
* `fmt.Println` ставит пробелы между операндами и перевод строки; `Printf` использует глагольные форматы (`%d`, `%s`, `%q`, `%v`, `%T`).
* Целочисленное переполнение молча заворачивается, деление на ноль для `int` - паника, для `float64` даёт `+Inf` или `NaN`.
