## Что проверяет эта проверка

Аннотации параметров и результата, встроенные обобщения (`list[int]`, `dict[str, int]`), объединения `X | None`, `Callable`, обобщённые функции с параметром типа `[T]`, чтение аннотаций (`__annotations__`, `typing.get_type_hints`), сужение типов через `isinstance`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Аннотации типов](lesson:python.advanced.typing-fundamentals).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```python run
import typing

def pairs[T](items: list[T]) -> list[tuple[T, T]]:
    return list(zip(items, items[1:]))

print(pairs([1, 2, 3]))
print(typing.get_type_hints(pairs)["return"])
```
```output
[(1, 2), (2, 3)]
list[tuple[T, T]]
```

`[T]` объявляет параметр типа: статический анализатор свяжет тип элементов входа и выхода. Интерпретатор аннотации не проверяет, но хранит и даёт их прочитать через `get_type_hints`.

<!-- section: precise -->
## Что нужно уметь

* читать и писать аннотации `list[int]`, `dict[str, list[int]]`, `X | None`, `Callable[[A], B]`;
* объявлять и использовать параметры типа (`def f[T](...)` или `TypeVar`);
* объяснять, что аннотации не влияют на выполнение;
* получать аннотации во время выполнения (`__annotations__`, `get_type_hints`);
* сужать `X | None` и объединения проверкой `is None` и `isinstance`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Ожидание, что Python откажется выполнять код с неверной аннотацией.
* `Optional[X]` означает `X | None`, а не «необязательный параметр».
* Один параметр типа на несколько независимых позиций делает сигнатуру точнее, чем `Any`, но разные связи требуют разных параметров (`T` и `K`).
* `list[int]` - обычное выражение, и его можно вычислить во время выполнения.
