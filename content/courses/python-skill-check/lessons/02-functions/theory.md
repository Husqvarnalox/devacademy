## Что проверяет эта проверка

Определение функций, параметры, значения по умолчанию и `return`, область видимости, индексы и срезы строк, методы `split`, `join`, `strip`, `upper`, проверки `isalnum`, форматирование f-строками.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Функции: def, параметры и return](lesson:python.fundamentals.functions), [Строки: индексы, срезы и методы](lesson:python.fundamentals.strings).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```python run
def shout(text, times=2, sep="-"):
    return sep.join([text.upper()] * times)

print(shout("hi"), shout("go", 3, "!"), "python"[1:4])
```
```output
HI-HI GO!GO!GO yth
```

Функция использует значения по умолчанию для `times` и `sep`; строка повторяется в списке и склеивается методом `join`; срез `[1:4]` берёт символы с индексами 1-3.

<!-- section: precise -->
## Что нужно уметь

* вызывать функции с позиционными и именованными аргументами и предсказывать значения по умолчанию;
* помнить, что значение по умолчанию создаётся один раз;
* отличать локальные переменные от глобальных;
* пользоваться индексами, срезами (в том числе с шагом и отрицательным), `split`/`join`, `strip`, `isalnum`;
* применять форматные спецификации `:>7`, `:.2f`, `!r`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Изменяемое значение (`[]`) в качестве умолчания делится между вызовами.
* Строки неизменяемы: методы возвращают новую строку.
* Правая граница среза не включается.
* `split(",")` сохраняет пустые элементы, а `split()` без аргумента их отбрасывает.
