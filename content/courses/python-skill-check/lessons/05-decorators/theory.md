## Что проверяет эта проверка

Функции как объекты, замыкания и `nonlocal`, декораторы без параметров и с параметрами, порядок применения нескольких декораторов, `functools.wraps`, передача `*args` и `**kwargs`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Функции как объекты и замыкания](lesson:python.advanced.functions-as-objects), [Декораторы](lesson:python.advanced.decorators).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```python run
import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("вызов", func.__name__, args)
        return func(*args, **kwargs)
    return wrapper

@logged
def add(a, b):
    """Сложить два числа."""
    return a + b

print(add(2, 3), add.__name__, add.__doc__)
```
```output
вызов add (2, 3)
5 add Сложить два числа.
```

`@logged` заменяет `add` функцией `wrapper`; `functools.wraps` копирует имя и документацию, поэтому они остаются прежними.

## Что нужно уметь

* объяснять, что функция - объект, и хранить её в переменных и структурах;
* предсказывать значения переменных в замыканиях, включая позднее связывание;
* писать декоратор с `*args, **kwargs` и `functools.wraps`;
* писать декоратор с параметрами (три уровня функций);
* предсказывать порядок применения нескольких декораторов.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Забытый `functools.wraps` меняет `__name__` и `__doc__`.
* Декоратор с параметрами без скобок (`@retry` вместо `@retry(3)`) передаёт функцию как параметр.
* Замыкания в цикле захватывают переменную цикла, а не её значение.
* Изменяемый кэш на уровне модуля общий для всех функций.
