## Что проверяет эта проверка

Итерируемые объекты и итераторы, протокол `iter` / `next`, функции-генераторы с `yield`, генераторные выражения, одноразовость итераторов, ленивость и `itertools`, метод `send`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Итераторы и генераторы](lesson:python.advanced.iterators-and-generators).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```python run
def evens(numbers):
    for n in numbers:
        if n % 2 == 0:
            yield n

pipeline = (n * n for n in evens(range(10)))
print(next(pipeline), next(pipeline), list(pipeline))
```
```output
0 4 [16, 36, 64]
```

Генератор `evens` и генераторное выражение вычисляют значения по одному, по требованию. Два вызова `next` забирают 0 и 4, остальные значения (16, 36, 64) достаются `list`.

<!-- section: precise -->
## Что нужно уметь

* различать итерируемый объект и итератор;
* предсказывать порядок выполнения кода генератора (тело стартует при первом `next`);
* помнить, что итератор одноразовый;
* писать генераторы с состоянием и вкладывать их в конвейер;
* использовать `itertools.islice`, `count` для работы с бесконечными потоками.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Повторный проход по исчерпанному итератору даёт пустой результат.
* `list(...)` внутри генератора разрушает ленивость.
* Функция с `yield` не выполняет тело при вызове.
* Генераторное выражение в скобках `(...)`, а не `[...]`: в квадратных строится список.
