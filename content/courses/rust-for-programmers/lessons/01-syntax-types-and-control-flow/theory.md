## Зачем этот урок

Если вы уже писали на Java, C#, Go, Python или JavaScript, синтаксис Rust покажется знакомым: `if`, `while`, `for`, функции, строки, числа. Отличия спрятаны в мелочах, и именно они дают новичку первые ошибки компиляции. Переменная по умолчанию **неизменяема**. Числа разных типов не смешиваются без явного приведения, и приведение `as` молча обрезает значение. `if` и `match` - выражения, которые возвращают значение, а `match` обязан перечислить все случаи. Строка знает длину в байтах и не даёт обратиться к символу по номеру. Успешное прохождение этого урока (упражнение и квиз) засчитывает уроки 01-15 курса «Rust с нуля».

## Главная мысль

Компилятор Rust требует, чтобы вы сказали явно то, что другие языки угадывают за вас: «это значение будет меняться» (`mut`), «здесь нужно обрезать число» (`as`), «а на остальные случаи - вот это» (`_` в `match`). Взамен вся категория тихих ошибок превращается в сообщение компилятора. Исключение одно, и о нём важно знать заранее: переполнение целого в программах этого курса **не** останавливает программу, а заворачивает число по кругу.

## Пример 1. Переменные, типы и приведение

Каждая программа ниже - полный файл `main.rs`. Строка `println!("{x}")` подставляет значение переменной `x` на место `{x}`; `!` в имени означает, что `println!` - макрос, но для чтения примеров это не важно.

```rust run
fn main() {
    let x = 5;
    let x = x * 2;
    let x = format!("<{x}>");
    println!("{x}");

    let mut count = 0;
    count += 3;
    count -= 1;
    println!("{count}");

    println!("{} {}", 7 / 2, -7 / 2);
    println!("{} {}", 7 % 3, -7 % 3);
    println!("{}", (-7_i32).rem_euclid(3));

    println!("{} {} {}", 300_i32 as u8, -1_i32 as u8, 3.99_f64 as i32);
    println!("{} {}", -1.5_f64 as u32, 1e10_f64 as i32);

    let big: i32 = "2147483647".parse().unwrap();
    println!("{}", big + 1);
    println!("{:?}", big.checked_add(1));
    println!("{}", big.wrapping_add(1));
    println!("{}", big.saturating_add(1));

    println!("{:.2} {} {}", 2.5_f64, 3.0_f64, 0.1 + 0.2);
}
```

```output
<10>
2
3 -3
1 -1
2
44 255 3
0 2147483647
-2147483648
None
-2147483648
2147483647
2.50 3 0.30000000000000004
```

Разбор. Три строки `let x` - это **затенение**: каждый `let` создаёт новую переменную с тем же именем, и она может иметь другой тип (число, затем строка). Это не изменение. Чтобы изменять, нужно `let mut`, как у `count`. Деление целых отбрасывает дробную часть **к нулю**, поэтому `-7 / 2` равно `-3`, а остаток `-7 % 3` отрицателен (`-1`); неотрицательный остаток даёт `rem_euclid`. Приведение `as` не проверяет значение: `300 as u8` оставляет младший байт (`44`), `-1 as u8` даёт `255`, дробное число обрезается к нулю, а при приведении `f64` к целому значение вне диапазона **прижимается** к границе типа (`-1.5` к `u32` даёт `0`, `1e10` к `i32` - наибольшее `i32`). Строка `big + 1` показывает главную ловушку: эта программа собрана с `-O`, как и в приложении, а в такой сборке переполнение не вызывает панику, и `2147483647 + 1` превращается в `-2147483648`. В сборке без оптимизации (`rustc main.rs`, `cargo run`) та же строка остановила бы программу сообщением `attempt to add with overflow`. Поэтому там, где переполнение возможно, выбирают метод явно: `checked_add` возвращает `Option`, `wrapping_add` заворачивает, `saturating_add` прижимает. Формат `{:.2}` всегда печатает точку, независимо от языка системы; `3.0` печатается как `3`, а `0.1 + 0.2` показывает обычную погрешность чисел с плавающей точкой.

**Попробуйте.** Замените `big + 1` на `2147483647 + 1` и соберите программу. Компилятор отвергнет её с ошибкой `this arithmetic operation will overflow`: заведомое переполнение констант он замечает сам, а `big` получено при работе программы и потому не проверяется.

## Пример 2. Условия, `match` и циклы

```rust run
fn main() {
    let n = 15;
    let kind = if n % 15 == 0 {
        "fizzbuzz"
    } else if n % 3 == 0 {
        "fizz"
    } else {
        "число"
    };
    println!("{kind}");

    for score in [95, 82, 67, 40, 101] {
        let grade = match score {
            90..=100 => 'A',
            80..=89 => 'B',
            60..=79 => 'C',
            0..=59 => 'F',
            _ => '?',
        };
        print!("{grade} ");
    }
    println!();

    let mut sum = 0;
    for i in 1..=4 {
        sum += i;
    }
    println!("{sum}");
    for i in (0..10).step_by(4) {
        print!("{i} ");
    }
    println!();

    let mut total = 0;
    let mut steps = 0;
    while total < 20 {
        total += 7;
        steps += 1;
        if steps == 2 {
            continue;
        }
        if total > 15 {
            break;
        }
    }
    println!("{total} {steps}");

    let label = 'outer: loop {
        for j in 0.. {
            if j == 3 {
                break 'outer j * 10;
            }
        }
    };
    println!("{label}");
}
```

```output
fizzbuzz
A B C F ? 
10
0 4 8 
21 3
30
```

Разбор. Условие `if` не нужно брать в скобки, но оно обязано быть типа `bool`: `if n {` для числа не скомпилируется. `if ... else ...` - выражение, его значение можно присвоить (`let kind = ...`), поэтому обе ветки должны давать значение одного типа. `match` проверяет значение по образцам сверху вниз: `90..=100` - диапазон с обоими концами, `|` объединяет варианты, `_` ловит всё остальное. Без `_` ветка для `101` отсутствовала бы, и программа не скомпилировалась бы (см. ниже «Типичные ошибки»). Диапазон `1..=4` включает четвёрку, а `0..10` её исключает; `(0..10).step_by(4)` даёт `0 4 8`. В `while` и `loop` работают `break` и `continue` как в других языках; `loop` - бесконечный цикл, который сам может вернуть значение через `break значение`, а метка `'outer` позволяет выйти из внешнего цикла.

## Пример 3. Строки и ввод

```rust run
fn main() {
    let word = "привет";
    println!("{} {}", word.len(), word.chars().count());
    println!("{}", word.to_uppercase());

    let mut text = String::from("рубль");
    text.push_str("!");
    println!("{text} {}", text.len());

    let tail: String = word.chars().skip(3).collect();
    println!("{tail}");
    println!("{:?}", word.chars().nth(0));
    println!("{}", &word[0..2]);
    println!("{:>6}|{:<6}|{:^6}|{:06.1}", "ab", "cd", "ef", 3.14159);
}
```

```output
12 6
ПРИВЕТ
рубль! 11
вет
Some('п')
п
    ab|cd    |  ef  |0003.1
```

Программа, которая читает ввод, не запускается без данных, поэтому она показана отдельно:

```rust
fn main() {
    let text = std::io::read_to_string(std::io::stdin()).unwrap();
    let mut lines = text.lines();
    let n: i32 = lines.next().unwrap().trim().parse().unwrap();
    let words: Vec<&str> = lines.next().unwrap().split_whitespace().collect();
    println!("{} {}", n * 2, words.len());
}
```

Разбор. `len()` возвращает число **байт**: каждая русская буква в UTF-8 занимает два байта, поэтому у «привет» длина `12`, а букв `6` (`chars().count()`). Срез `&word[0..2]` берёт байты с нулевого по второй (не включая) и случайно оказался ровно одной буквой; срез `&word[0..1]` остановил бы программу паникой, потому что граница попала бы внутрь буквы. Индексировать строку `word[0]` нельзя вообще, для символов используют `chars()`. `String` - изменяемый собственный текст, литерал `"..."` имеет тип `&str`. Чтение ввода: `read_to_string` возвращает весь stdin одной `String`, `lines()` разбивает её на строки, `trim()` убирает пробелы и перевод строки по краям, а `parse()` превращает текст в число; тип результата указывается слева (`let n: i32`) или в записи `parse::<i32>()`. `unwrap()` забирает результат или останавливает программу, если разбор не удался; обработка ошибок - в третьем уроке этого курса. Спецификаторы `{:>6}`, `{:<6}`, `{:^6}` выравнивают по правому краю, левому и по центру, `{:06.1}` задаёт ширину 6, дополнение нулями и один знак после точки.

## Точные правила

* `let` создаёт неизменяемую привязку; `let mut` разрешает присваивание нового значения **того же типа**. Повторный `let` с тем же именем - затенение: новая переменная, тип может быть другим.
* Целые типы: `i8`, `i16`, `i32`, `i64`, `i128`, `isize` и беззнаковые `u8`, `u16`, `u32`, `u64`, `u128`, `usize`. Тип по умолчанию для литерала - `i32`, для дробного - `f64`. Длины и индексы имеют тип `usize`.
* Неявных преобразований между числовыми типами нет: `i32 + i64`, `5 == 5.0`, передача `i32` в параметр `i64` - ошибки компиляции. Явное приведение: `x as i64`. Преобразование без потерь - `i64::from(x)`; с проверкой - `u8::try_from(x)`.
* `as` между целыми обрезает до младших битов; из `f64` в целое - отбрасывает дробную часть и прижимает к границам типа, `NaN` даёт `0`; из `i32` в `f64` может потерять точность только для больших `i64`.
* Переполнение: в отладочной сборке паника `attempt to add with overflow`, в сборке с `-O` (так приложение запускает ваш код) значение молча заворачивается по модулю `2^N`. Константное выражение, которое переполняется заведомо, компилятор отвергает сам. Явные варианты: `checked_*`, `wrapping_*`, `saturating_*`, `overflowing_*`.
* `/` для целых отбрасывает дробную часть к нулю, `%` берёт знак делимого. Целое деление на ноль - паника `attempt to divide by zero` в любой сборке; деление `f64` на ноль даёт `inf` или `NaN`.
* `if` требует `bool`; в 0, пустую строку и `None` условие автоматически не превращается. `if`, `match` и блок `{ }` - выражения: значение последней строки без `;` - результат блока.
* `match` обязан быть исчерпывающим. Образцы: значение, диапазон `a..=b`, варианты `a | b`, `_`, охранное условие `x if x > 0`.
* Диапазон `a..b` не включает `b`, `a..=b` включает. Цикл `for` обходит любой итератор: диапазон, массив, `s.chars()`, `text.lines()`.
* `len()` строки - байты UTF-8, `s.chars().count()` - символы; `s[i]` не компилируется; срез `&s[a..b]` по границе внутри символа - паника.
* Форматирование не зависит от локали: `{:.2}` печатает точку. `{}` для `f64` с целым значением печатает `3`, а `{:?}` - `3.0`.

## Типичные ошибки

Сообщения ниже получены настоящим `rustc` 1.99; пути к стандартной библиотеке в длинных сообщениях заменены многоточием.

**1. Изменение неизменяемой переменной.**

```rust
fn main() {
    let total = 0;
    for i in 1..=3 {
        total += i;
    }
    println!("{total}");
}
```

```text
error[E0384]: cannot assign twice to immutable variable `total`
 --> main.rs:4:9
  |
2 |     let total = 0;
  |         ----- first assignment to `total`
3 |     for i in 1..=3 {
4 |         total += i;
  |         ^^^^^^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut total = 0;
  |         +++
```

Компилятор сам предлагает исправление: `let mut total`. Любую переменную, которая должна меняться, объявляйте с `mut`; остальные пусть остаются защищёнными.

**2. Смешение числовых типов.**

```rust
fn main() {
    let items: i32 = 3;
    let price: i64 = 250;
    println!("{}", items * price);
}
```

```text
error[E0308]: mismatched types
 --> main.rs:4:28
  |
4 |     println!("{}", items * price);
  |                            ^^^^^ expected `i32`, found `i64`
```

В отличие от Java, C# и JavaScript Rust не расширяет `i32` до `i64` сам. Приведите один из операндов: `i64::from(items) * price` (без потерь) или `items as i64 * price`.

**3. Условие не типа `bool`.**

```rust
fn main() {
    let count = 2;
    if count {
        println!("есть");
    }
}
```

```text
error[E0308]: mismatched types
 --> main.rs:3:8
  |
3 |     if count {
  |        ^^^^^ expected `bool`, found integer
```

Пишите явное сравнение: `if count > 0`.

**4. Неполный `match`.**

```rust
fn main() {
    let n: i32 = 7;
    let word = match n {
        0 => "ноль",
        1..=9 => "цифра",
    };
    println!("{word}");
}
```

```text
error[E0004]: non-exhaustive patterns: `i32::MIN..=-1_i32` and `10_i32..=i32::MAX` not covered
 --> main.rs:3:22
  |
3 |     let word = match n {
  |                      ^ patterns `i32::MIN..=-1_i32` and `10_i32..=i32::MAX` not covered
  |
  = note: the matched value is of type `i32`
help: ensure that all possible cases are being handled by adding a match arm with a wildcard pattern, a match arm with multiple or-patterns as shown, or multiple match arms
  |
5 ~         1..=9 => "цифра",
6 ~         i32::MIN..=-1_i32 | 10_i32..=i32::MAX => todo!(),
  |
```

Компилятор перечисляет непокрытые значения и предлагает добавить ветку. Добавьте `_ => ...`, если остальные случаи действительно одинаковы.

**5. Индексация строки.**

```rust
fn main() {
    let s = String::from("hello");
    let first = s[0];
    println!("{first}");
}
```

```text
error[E0277]: the type `str` cannot be indexed by `{integer}`
   --> main.rs:3:19
    |
  3 |     let first = s[0];
    |                   ^ string indices are ranges of `usize`
    |
    = help: the trait `SliceIndex<str>` is not implemented for `{integer}`
    = note: you can use `.chars().nth()` or `.bytes().nth()`
            for more information, see chapter 8 in The Book: <https://doc.rust-lang.org/book/ch08-02-strings.html#indexing-into-strings>
```

Номер байта не равен номеру буквы, поэтому Rust запрещает `s[i]`. Первую букву берут через `s.chars().next()`.

**6. Целое деление на ноль во время работы.**

```rust
fn main() {
    let divisor: i32 = "0".parse().unwrap();
    println!("{}", 10 / divisor);
}
```

```text
thread 'main' panicked at main.rs:3:20:
attempt to divide by zero
```

Это паника: программа завершается с кодом, отличным от нуля. Проверяйте делитель заранее или используйте `checked_div`, который возвращает `Option`.

**7. Переполнение, которое никто не заметил.** Сумма двух `i32` в сборке с `-O` молча стала отрицательной (пример 1). Для сумм и произведений, которые могут вырасти, берите `i64` или используйте `checked_*`.

**8. Точка с запятой после результата ветки.** `if c { 1; } else { 2; }` даёт значение `()`, а не число: выражение превращается в инструкцию. В ветках-выражениях `;` в конце не ставят.

## Главное для тех, кто уже программирует

* `let` - не `var`: по умолчанию значение не меняется (как `final` в Java или `const` в JavaScript, но для всех переменных). `let mut` - обычная переменная. Затенение (`let x = x * 2`) не имеет аналога в Java и C#, зато привычно в функциональных языках.
* Нет неявных числовых преобразований, в том числе «безопасных» `int` в `long`. `as` - явное приведение в стиле C, но с определённым поведением: обрезание битов для целых, прижимание для `f64`. Для безопасных преобразований есть `From` и `TryFrom`.
* Переполнение целого - поведение сборки: паника в отладочной, заворачивание в релизной (в Java оно всегда заворачивается, в Python целые не переполняются, в C++ для знаковых - UB). Приложение запускает код с `-O`.
* `if` и `match` - выражения, тернарного оператора нет; `match` похож на `switch`, но без «проваливания» и с обязательной исчерпываемостью. Ближайший аналог - `when` в Kotlin.
* Нет `i++`: пишут `i += 1`. Нет `for (int i = 0; i < n; i++)`: цикл идёт по диапазону `0..n`.
* Тип `char` - символ Unicode (4 байта), а не 16-битная единица, как в Java и C#. Строка - UTF-8, как в Go, но `s[i]` запрещён, а не возвращает байт.
* Целое деление и остаток ведут себя как в Java и C++ (к нулю), а не как в Python (вниз).
* Форматирование через `{}` и `{:.2}` не зависит от локали: десятичная точка всегда точка.
