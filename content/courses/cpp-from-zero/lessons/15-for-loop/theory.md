## Зачем это нужно

В прошлом уроке цикл `while` собирался из трёх частей, разбросанных по трём местам: начальное значение до цикла, условие в скобках, изменение в конце тела. Когда число оборотов известно («повтори десять раз», «пройди по всем буквам слова»), забыть одну из частей особенно досадно. Цикл `for` собирает все три части в одну строку заголовка, поэтому они всегда видны вместе.

## Одна новая идея: счётчик в заголовке цикла

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << "\n";
}
```

В скобках три части через точку с запятой:

1. `int i = 1` - **начало**: выполняется один раз перед циклом, создаёт счётчик;
2. `i <= 5` - **условие**: проверяется перед каждым оборотом (как у `while`);
3. `i++` - **шаг**: выполняется после каждого оборота.

Переменная `i` называется **переменной цикла**. Она существует только внутри цикла: после него её нет. По традиции счётчики называют `i`, `j`, `k`.

Цикл `for` особенно удобен для обхода строки по номерам букв: символы пронумерованы с нуля (урок 7), поэтому счётчик идёт от `0` до `s.size() - 1`, то есть пока `i < s.size()`.

<!-- section: examples -->
## Пример 1. Простой счёт

```cpp run
#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << i << " в квадрате: " << i * i << "\n";
    }
}
```
```output
1 в квадрате: 1
2 в квадрате: 4
3 в квадрате: 9
4 в квадрате: 16
5 в квадрате: 25
```

Разбор:

* Счётчик пробегает значения 1, 2, 3, 4, 5, и на каждом обороте печатается строка с его квадратом.
* Заголовок читается слева направо: «начни с 1, пока не больше 5, после каждого оборота прибавляй 1».

## Пример 2. Другой шаг и обратный отсчёт

```cpp run
#include <iostream>

int main() {
    for (int i = 0; i <= 20; i += 5) {
        std::cout << "[" << i << "]";
    }
    std::cout << "\n";
    for (int i = 3; i >= 1; i--) {
        std::cout << i << "...";
    }
    std::cout << "старт\n";
}
```
```output
[0][5][10][15][20]
3...2...1...старт
```

Шагом может быть любое выражение: `i += 5` увеличивает счётчик на пять, `i--` уменьшает на единицу. Для обратного отсчёта в условии меняют знак сравнения. Здесь счётчик `int`, поэтому условие `i >= 1` безопасно; с беззнаковым счётчиком всё иначе (см. ниже).

## Пример 3. Обход строки

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string word = "banana";
    int count = 0;
    for (std::size_t i = 0; i < word.size(); i++) {
        if (word[i] == 'a') {
            count++;
        }
    }
    std::cout << "Букв a: " << count << "\n";
}
```
```output
Букв a: 3
```

Разбор:

* `std::size_t` - тип, в котором `size()` возвращает длину. Он **беззнаковый**: не бывает отрицательным. Если объявить счётчик как `int`, то сравнение `i < word.size()` смешивает знаковое с беззнаковым, и компилятор предупредит `-Wsign-compare` (урок 11).
* `word[i]` берёт букву с номером `i`; сравнение `== 'a'` выясняет, та ли это буква.

## Пример 4. Обратный порядок

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string word = "abc";
    std::string reversed = "";
    for (std::size_t i = word.size(); i > 0; i--) {
        reversed += word[i - 1];
    }
    std::cout << reversed << "\n";
}
```
```output
cba
```

Разбор:

* Счётчик идёт от `3` до `1`, а буква берётся как `word[i - 1]`: это `word[2]`, `word[1]`, `word[0]`.
* Почему не `i = word.size() - 1; i >= 0`? Потому что `size_t` не бывает меньше нуля: после значения `0` команда `i--` даст огромное число, условие `i >= 0` опять станет истинным, и цикл пойдёт дальше вглубь памяти. Приём «счёт от длины и `i - 1`» этой ловушки избегает.
* `+=` для строки дописывает символ в конец (урок 7).

**Попробуйте.** Напечатайте таблицу умножения на 7 от `7 * 1` до `7 * 10`. Посчитайте сумму цифр числа, записанного в строке `"90210"`: для цифры-символа `c` число равно `c - '0'`. Напишите цикл, который печатает каждую вторую букву слова.

## Точные правила

* Форма: `for (начало; условие; шаг) { тело }`. Любую из трёх частей можно опустить, но точки с запятой остаются: `for (;;)` - бесконечный цикл.
* Порядок: начало (один раз) -> проверка условия -> тело -> шаг -> проверка условия -> тело -> шаг ... Если условие сразу ложно, тело не выполняется.
* Переменная, объявленная в начале, видна только в цикле. Если её значение нужно после цикла, объявите её раньше и в заголовке оставьте только присваивание.
* Цикл `for` и цикл `while` равнозначны: `for (A; B; C) { T }` - то же, что `A; while (B) { T C; }`. Выбор по смыслу: известное число оборотов или обход по номерам - `for`; ожидание события или чтение данных - `while`.
* **Типы счётчика.** `std::size_t` (из `<cstddef>`, подключается и через `<string>`) - беззнаковый целый тип, в котором хранятся размеры. Для обхода по номерам строки и вектора используйте его, а для обычного счёта (до десяти, до тысячи) подойдёт `int`.
* **Ловушка беззнакового счётчика:** `i >= 0` всегда истинно для `size_t`, а `s.size() - 1` для пустой строки равно огромному числу (урок 7). Обратный цикл пишут как `for (std::size_t i = s.size(); i > 0; i--)` с доступом `s[i - 1]`.
* Изменять счётчик в теле цикла допустимо, но запутывает читателя. Если нужен нестандартный шаг, поместите его в заголовок.
* Границы обхода строки: допустимые номера - от `0` до `size() - 1`. Обращение `s[i]` с `i >= size()` читает чужую память (неопределённое поведение), если только это не `i == size()`, где `s[i]` возвращает завершающий нулевой символ. Проверка `.at(i)` вместо `[i]` бросает исключение (урок 22).

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Знаковый счётчик и `size()`.**

```cpp
for (int i = 0; i < s.size(); i++) {
```

```text
main.cpp:5:21: warning: comparison of integers of different signs: 'int' and 'size_type' (aka 'unsigned long') [-Wsign-compare]
    5 |     for (int i = 0; i < s.size(); i++) {
      |                     ~ ^ ~~~~~~~~
```

Программа работает, но предупреждение показывает риск (урок 11). Объявите счётчик как `std::size_t`.

**2. Бесконечный обратный цикл.**

```cpp
for (std::size_t i = s.size() - 1; i >= 0; i--) {
```

```text
main.cpp:6:42: warning: result of comparison of unsigned expression >= 0 is always true [-Wtautological-unsigned-zero-compare]
    6 |     for (std::size_t i = s.size() - 1; i >= 0; i--) {
      |                                        ~ ^  ~
```

Для беззнакового `i` условие `i >= 0` истинно всегда. Цикл не заканчивается, а когда `i` «проскакивает» ноль, `s[i]` читает память далеко за строкой. Для пустой строки уже `s.size() - 1` даёт число `18446744073709551615`. Используйте форму `i > 0` и `s[i - 1]`. Без ключей `-Wall -Wextra` предупреждения не будет: этот приём стоит запомнить без помощи компилятора.

**3. Точка с запятой после заголовка.**

```cpp
for (int i = 0; i < 3; i++);
{
    std::cout << "x";
}
```

```text
main.cpp:12:32: warning: for loop has empty body [-Wempty-body]
   12 |     for (int i = 0; i < 3; i++);
      |                                ^
main.cpp:12:32: note: put the semicolon on a separate line to silence this warning
```

Цикл крутится три раза с пустым телом, а блок после него выполняется один раз.

**4. Переменная цикла вне цикла.**

```text
main.cpp:19:18: error: use of undeclared identifier 'i'
   19 |     std::cout << i;
      |                  ^
```

Счётчик, объявленный в заголовке, исчезает вместе с циклом. Нужен после цикла - объявите до него.

**5. Ошибка на единицу.** Условие `i <= word.size()` делает на один оборот больше и читает `word[word.size()]`. Для чтения это нулевой символ, а при записи (`word[i] = ...`) уже неопределённое поведение. Условие обхода строки - всегда `i < word.size()`.

**6. Запятая вместо точки с запятой в заголовке и забытые части.** `for (int i = 0, i < 5, i++)` не компилируется: части разделяются именно `;`.

## Итоги

* `for (начало; условие; шаг)` собирает три части цикла в одну строку; счётчик существует только внутри цикла.
* Шаг может быть любым: `i++`, `i += 5`, `i--`. Для обратного отсчёта меняют начало, условие и шаг.
* Для обхода строки по номерам используйте `std::size_t` и условие `i < s.size()`.
* Обратный обход беззнаковым счётчиком: `for (std::size_t i = s.size(); i > 0; i--)` и `s[i - 1]`. Условие `i >= 0` для `size_t` всегда истинно.
* `for` выбирают, когда число оборотов известно; `while` - когда оно зависит от данных.

Иногда цикл нужно прервать раньше срока или пропустить отдельный оборот, а один цикл поместить внутрь другого. Для этого служат команды из урока [break, continue и вложенные циклы](lesson:cpp.from-zero.loop-control).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Заголовок `for` - как в C, Java, C#, JavaScript. Любая из трёх частей может быть пустой; счётчик видим только в цикле.
* Циклов вида `for i in range(n)` или `for i := range n` нет, но в C++ есть range-for `for (auto x : container)` для обхода коллекций (урок 19). Для строки можно написать `for (char c : s)`, если номер буквы не нужен.
* `size()` возвращает `std::size_t` (беззнаковое). Поэтому `for (int i = 0; i < v.size(); i++)` даёт предупреждение (в Java и C# длина знаковая). В C++20 есть `std::ssize(v)`, возвращающая знаковое значение, и обратный цикл с ним безопасен.
* Ловушка `for (size_t i = n - 1; i >= 0; i--)` классическая: цикл бесконечен.
* Запятая в заголовке - оператор: `for (int i = 0, j = 10; i < j; i++, j--)` работает, как в C.
* Объявление в начале цикла видно только в нём (область видимости цикла), как в Java и C#, но в отличие от Python.
* Компилятор нередко разворачивает короткие циклы или превращает их в векторные команды процессора; на корректность это не влияет.

## Почему size_t беззнаковый

Это необязательный раздел: для заданий он не нужен.

Тип `std::size_t` задуман как «достаточно большое число, чтобы выразить размер любого объекта в памяти». На 64-битной системе это 8 байт без знака. Знак здесь исторически не нужен: размеров меньше нуля не бывает, а выигрыш в диапазоне важен для 32-битных систем. Цена этого решения - ловушки вида `size() - 1` и `i >= 0`, о которых много спорят даже члены комитета по стандартизации. Поэтому в C++20 появилась `std::ssize()`, а в современном коде предпочитают range-for, где индекса нет совсем.

Предупреждение `-Wsign-compare` не случайно входит в набор `-Wall -Wextra`: смесь знаковых и беззнаковых чисел - один из самых частых источников тихих ошибок. Правило практики: храните размеры в `std::size_t`, обычный счёт - в `int`, и не смешивайте их без явного `static_cast`.
