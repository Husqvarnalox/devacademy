## Зачем это нужно

До сих пор мы читали ввод через `std::cin >> x`: оператор берёт одно слово или число и останавливается на пробеле. Реальные данные устроены иначе: строка `Иван Петров;85` - это имя с пробелом, точка с запятой и балл. Чтобы с такой строкой работать, нужны два умения: **прочитать строку целиком** и **разрезать её на части**.

## Одна новая идея: строка ввода - это значение, а резать её можно по разделителю

Функция `std::getline(std::cin, line)` читает всё до конца строки (сам символ перевода строки отбрасывается) и кладёт прочитанное в переменную `line` вместе с пробелами. Её ставят в условие цикла: она, как и `std::cin >> x`, сообщает «получилось» или «данные кончились».

```cpp
std::string line = "";
while (std::getline(std::cin, line)) {
    std::cout << "Строка: " << line << "\n";
}
```

Дальше строку режут. Для этого у `std::string` есть два метода:

* `line.find(';')` возвращает **позицию** первой точки с запятой (счёт с нуля) или специальное значение `std::string::npos`, если символа нет;
* `line.substr(start, length)` возвращает **вырезанную** часть строки: `length` символов, начиная с позиции `start`. Без второго аргумента вырезается всё до конца.

Если в строке `Ivanov;85` точка с запятой стоит на позиции 6, то `substr(0, 6)` даёт `Ivanov`, а `substr(7)` - `85`.

<!-- section: examples -->
## Пример 1. Поиск и вырезание

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string line = "Ivanov;85";
    std::size_t pos = line.find(';');
    std::string name = line.substr(0, pos);
    std::string score = line.substr(pos + 1);

    std::cout << "Позиция: " << pos << "\n";
    std::cout << "Имя: " << name << "\n";
    std::cout << "Балл: " << score << "\n";
    std::cout << "Балл + 5 = " << std::stoi(score) + 5 << "\n";
}
```
```output
Позиция: 6
Имя: Ivanov
Балл: 85
Балл + 5 = 90
```

Разбор:

* `pos` - позиция разделителя. Тип `std::size_t` - беззнаковое целое: позиции в строках не бывают отрицательными.
* `substr(0, pos)` - `pos` символов с начала, то есть всё, что стоит **до** разделителя.
* `substr(pos + 1)` - всё, что идёт **после** разделителя: начинаем на один символ правее него.
* `std::stoi` из урока 9 превращает текст `85` в число.

## Пример 2. Что возвращает find, если символа нет

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string line = "no separator";
    std::size_t pos = line.find(';');

    if (pos == std::string::npos) {
        std::cout << "разделитель не найден\n";
    } else {
        std::cout << "разделитель на позиции " << pos << "\n";
    }

    std::cout << line.find('o') << " " << line.find('o', 2) << " " << line.find("sep") << "\n";
}
```
```output
разделитель не найден
1 10 3
```

Разбор:

* `find` вернул `std::string::npos`, и сравнение с ним - правильная проверка «не нашлось».
* `find('o')` нашёл первую `o` на позиции 1. Второй аргумент `find('o', 2)` говорит «начни искать с позиции 2» и находит следующую `o` на позиции 10.
* `find("sep")` ищет не символ, а целую подстроку и возвращает позицию её первого символа.

## Пример 3. Сравнение строк

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string a = "Anna";
    std::string b = "anna";
    std::string c = "Boris";

    std::cout << (a == b) << " " << (a == "Anna") << "\n";
    std::cout << (a < c) << " " << (c < b) << " " << (a < b) << "\n";
}
```
```output
0 1
1 1 1
```

Разбор:

* `==` сравнивает строки по содержимому, и **регистр различается**: `Anna` и `anna` - разные строки.
* `<` сравнивает посимвольно по кодам. Код заглавной `A` меньше кода любой строчной буквы, поэтому и `Anna < anna`, и `Boris < anna` истинны: все заглавные латинские буквы стоят в таблице раньше строчных.

## Пример 4. Ловушка: `>>`, а потом `getline`

Программа читает число, а затем строку. Показан не запускаемый пример: он зависит от ввода.

```cpp
int age = 0;
std::string name = "";
std::cin >> age;
std::getline(std::cin, name);
std::cout << "[" << name << "] " << age << "\n";
```

Если ввод состоит из двух строк

```text
30
Иван Петров
```

то вывод будет таким:

```text
[] 30
```

Оператор `>>` прочитал `30` и остановился **перед** символом перевода строки: он остался в потоке. Первый `getline` увидел конец строки сразу и вернул пустую строку. Имя при этом осталось непрочитанным.

Лечение - прочитать и выбросить остаток строки отдельным вызовом `std::getline(std::cin, rest);` с запасной переменной `rest`, либо читать числа тоже через `getline` и превращать их в числа через `std::stoi`. В упражнениях этого урока всё читается только через `getline`, поэтому ловушка не встретится.

**Попробуйте.** Прочитайте строки вида `Москва;12` и найдите вторую точку с запятой через `find(';', pos + 1)`. Разделите строку `2026-10-22` по дефисам на три части. Выведите в обратном порядке две части строки `имя;фамилия`.

## Точные правила

* `std::getline(std::cin, line)` читает до символа конца строки, **не включая** его, и заменяет прежнее содержимое `line`. Пустая строка ввода даёт пустую `line`. Когда данные кончились, `getline` возвращает «неудачу», и цикл `while (std::getline(...))` завершается. Последняя строка без перевода строки на конце тоже читается.
* `>>` пропускает пробельные символы перед значением и **оставляет** перевод строки после него. `getline` ничего не пропускает. Поэтому смешивать их в одном вводе нужно осторожно.
* `line.empty()` - проверка на пустую строку (то же, что `line.size() == 0`).
* `find(x)` ищет символ или подстроку слева направо и возвращает позицию первого совпадения или `std::string::npos`. `find(x, from)` начинает поиск с позиции `from`.
* `std::string::npos` - наибольшее значение типа `std::size_t` (на 64-битной системе 18446744073709551615). Не сравнивайте результат `find` с `-1`: сравнение знакового и беззнакового чисел вызывает предупреждение `-Wsign-compare`.
* `substr(start, length)` возвращает копию части строки. Если `start` больше длины строки, бросается исключение `std::out_of_range`. Если `start` равен длине, результат - пустая строка. Если `length` слишком велик, берётся всё до конца. `substr(start)` - всё от `start` до конца.
* Сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` работают для строк посимвольно по кодам. Регистр различается. Для текста на кириллице сравнивается кодировка UTF-8, а не алфавитный порядок словаря.
* **Позиции и длины в `std::string` - в байтах, а не в буквах.** Латинская буква занимает один байт, русская в UTF-8 - два. Строка `Иванов;85` состоит из 15 байт, и `find(';')` возвращает 12. Для разбора по `;` это не мешает: `substr` режет по тем же байтам, и результат остаётся корректным текстом. Проблемы начинаются, когда вы считаете «буквы» через `size()` или режете строку посередине буквы.
* `find` и `substr` не меняют исходную строку.

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Смешивание `>>` и `getline`.** Пример 4: имя оказывается пустым. Читайте всё через `getline`, а числа получайте через `std::stoi`.

**2. Разделителя нет, а `substr(pos + 1)` вызывается.** Для строки без `;` значение `pos` равно `std::string::npos`, и `pos + 1` при переполнении даёт `0`. Результат - не ошибка, а тихий неверный ответ:

```cpp
std::string line = "no separator";
std::size_t pos = line.find(';');
std::cout << line.substr(0, pos) << "|" << line.substr(pos + 1) << "|\n";
```

```text
no separator|no separator|
```

Обе части оказались равны всей строке. Всегда проверяйте `pos == std::string::npos` до вырезания (в мини-проекте урока 24 это нужно для подсчёта плохих строк).

**3. `substr` с позицией за концом строки.** Следующий фрагмент не запускается в примерах.

```cpp
std::string s = "abc";
std::cout << s.substr(4) << "\n";
```

```text
libc++abi: terminating due to uncaught exception of type std::out_of_range: basic_string
```

Программа аварийно завершилась (код 134). В g++ сообщение подробнее: `basic_string::substr: __pos (which is 4) > this->size() (which is 3)`, но исключение то же. Ловить его вы научитесь в уроке 22.

**4. Сравнение результата `find` с `-1`.**

```cpp
std::size_t p = s.find(';');
if (p == -1) { ... }
```

```text
main.cpp:6:11: warning: comparison of integers of different signs: 'std::size_t' (aka 'unsigned long') and 'int' [-Wsign-compare]
```

Это предупреждение из урока 11. Пишите `p == std::string::npos`.

**5. Присваивание вместо сравнения.**

```cpp
if (line = "") { }
```

```text
main.cpp:8:9: error: no viable conversion from 'string' to 'bool'
```

Один знак `=` присваивает значение, а не сравнивает. Для строк компилятор даже не может превратить результат в условие. В clang перед этой ошибкой стоит предупреждение `-Wparentheses` с подсказкой использовать `==`.

**6. Ожидание «алфавитного» порядка для регистра.** `"Zebra" < "apple"` истинно: заглавные буквы идут раньше строчных. Для сравнения без учёта регистра нужно сначала привести обе строки к одному регистру (это отдельная тема).

**7. Счёт букв через `size()` для кириллицы.** `std::string("Иванов").size()` равно 12, а не 6. Для упражнений урока это не нужно, но запомните, чтобы не удивляться.

## Итоги

* `std::getline(std::cin, line)` читает строку целиком, с пробелами; цикл `while (std::getline(...))` читает ввод до конца.
* `>>` оставляет перевод строки в потоке, поэтому после него `getline` возвращает пустую строку.
* `find` возвращает позицию (счёт с нуля) или `std::string::npos`; результат проверяют до использования.
* `substr(start, length)` вырезает часть; `substr(pos + 1)` - всё после разделителя; позиция за концом строки бросает `std::out_of_range`.
* Строки сравниваются через `==` и `<` посимвольно, регистр различается.
* Позиции и размеры измеряются в байтах.

Строка `Иван;abc` или `Анна;` разрежется без проблем, но `std::stoi("abc")` не получит числа. Что происходит в таких случаях и как программа может на это отреагировать, разбирает урок про [исключения](lesson:cpp.from-zero.exceptions).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `std::getline` - аналог `input()` в Python, `BufferedReader.readLine` в Java, `scanner.Scan()` в Go, но принимает поток и строку-приёмник явно и возвращает состояние потока (ложное при конце данных), а не `null`.
* Смешивание `>>` и `getline` - известная C++-ловушка, аналога в Python и JS нет. Стандартная идиома: `std::getline` на всё, `std::stoi` для чисел; или `std::cin >> std::ws` / `std::cin.ignore()`, которые разбираются позже.
* `find` возвращает `std::size_t` и `npos` вместо `-1` (как `indexOf` в Java и JS, `str.find` в Python). Сравнение с `-1` - классическая ошибка с беззнаковыми числами.
* `substr(pos, len)` - второй аргумент это **длина**, а не конечная позиция, как в `slice(a, b)` в JS и `s[a:b]` в Python. Копирует: срез не является представлением (для представления есть `std::string_view`, C++17, разбирается в курсах дальше).
* `substr` с `pos > size()` бросает `std::out_of_range`, в отличие от срезов Python и Go, которые молча усекаются.
* `std::string` хранит байты. Индексы и `size()` - в байтах, не в кодовых точках и не в символах Unicode. Для разбора по ASCII-разделителю (`;`, `,`) это безопасно в UTF-8.
* Сравнение строк `<` лексикографическое по байтам, без учёта локали (как `strcmp`, а не `Collator`).
* В примерах не используется `std::istringstream`, который разбирает строку по пробелам или разделителям; он нужен, когда формат строки сложнее одного разделителя.

## Что хранится внутри `std::string`

Это необязательный раздел: для заданий он не нужен.

`std::string` - это последовательность байтов (тип элемента `char`) плюс размер. Для коротких строк реализация обычно хранит байты прямо внутри объекта (в стандартной библиотеке clang - до 22 символов), а для длинных запрашивает память отдельно. Вам это не видно: `find`, `substr` и `size` работают одинаково.

Метод `find` для подстроки в простых реализациях сравнивает с каждой позиции - порядка `n × m` шагов в худшем случае, хотя обычно намного быстрее. Для поиска в больших текстах существуют специальные алгоритмы, но вам понадобятся они не в начале пути.

Важное следствие устройства: `std::string` не знает ничего про буквы алфавитов. Строка `"Иванов"` для неё - 12 байт, и только вывод в терминал, понимающий UTF-8, показывает шесть букв. Поэтому «сделать первую букву заглавной» или «посчитать буквы» для кириллицы стандартными средствами не получается: нужны библиотеки работы с Unicode. Для курса этого достаточно: все разделители в разбираемых строках - ASCII-символы, а они в UTF-8 однозначны.
