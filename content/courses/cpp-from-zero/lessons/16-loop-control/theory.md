## Зачем это нужно

Цикл из прошлых уроков заканчивается только тогда, когда его условие стало ложным. Но реальные задачи сложнее: «искать, пока не найдём, а после находки остановиться», «пропустить пустые строки и обработать остальные», «обойти таблицу по строкам и столбцам». Для этого у цикла есть две команды управления и возможность вложения.

## Одна новая идея: вмешаться в ход цикла изнутри

* **`break`** - «прекрати цикл прямо сейчас»: выполнение продолжится с первой команды после цикла.
* **`continue`** - «пропусти остаток этого оборота»: выполнение переходит к проверке условия (в `for` - сначала к шагу) и начинает следующий оборот.
* **Вложенный цикл** - цикл, стоящий внутри тела другого цикла. На каждый оборот внешнего цикла внутренний проходит весь свой путь заново. Так обходят таблицы: внешний цикл идёт по строкам, внутренний - по столбцам.

Обе команды чаще всего стоят внутри `if`: «если найдено - `break`», «если пропускаем - `continue`».

<!-- section: examples -->
## Пример 1. break: найти и остановиться

```cpp run
#include <iostream>

int main() {
    int found = -1;
    for (int i = 1; i <= 100; i++) {
        if (i * i > 200) {
            found = i;
            break;
        }
    }
    std::cout << "Первое число с квадратом больше 200: " << found << "\n";
}
```
```output
Первое число с квадратом больше 200: 15
```

Разбор:

* Цикл мог бы идти до 100, но на `i = 15` (`225 > 200`) выполняется `break`, и остальные 85 оборотов не делаются.
* Значение `-1` в `found` - заведомо невозможный ответ. Если бы условие не выполнилось ни разу, это бы показало «не найдено».

## Пример 2. continue: пропустить лишнее

```cpp run
#include <iostream>

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;
        }
        sum += i;
    }
    std::cout << "Сумма нечётных: " << sum << "\n";
}
```
```output
Сумма нечётных: 25
```

На чётных числах `continue` пропускает строку `sum += i`, поэтому в сумму попадают только 1, 3, 5, 7, 9. Тот же результат даёт `if (i % 2 != 0) { sum += i; }`; `continue` удобнее, когда пропуск стоит в начале длинного тела цикла и не хочется вкладывать всё остальное в блок.

## Пример 3. Вложенные циклы: таблица

```cpp run
#include <iostream>

int main() {
    for (int row = 1; row <= 3; row++) {
        for (int col = 1; col <= 4; col++) {
            std::cout << "[" << row * col << "]";
        }
        std::cout << "\n";
    }
}
```
```output
[1][2][3][4]
[2][4][6][8]
[3][6][9][12]
```

Разбор:

* Внешний цикл выбирает строку (`row`), внутренний пробегает по четырём столбцам. Тело внутреннего цикла выполнилось 3 * 4 = 12 раз.
* Перевод строки печатается после внутреннего цикла: когда строка закончилась. Квадратные скобки нужны только для наглядности границ чисел.

## Пример 4. break во вложенном цикле

```cpp run
#include <iostream>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (j > i) {
                break;
            }
            std::cout << "*";
        }
        std::cout << "\n";
    }
}
```
```output
*
**
***
```

`break` прерывает только внутренний цикл: как только `j` превышает `i`, строка заканчивается, а внешний цикл переходит к следующему `i`. Получается треугольник из звёздочек: в строке номер `i` их ровно `i`.

**Попробуйте.** Найдите наименьшее число больше 1000, которое делится на 7 (цикл и `break`). Напечатайте числа от 1 до 20, кроме кратных трём (`continue`). Нарисуйте прямоугольник 3 на 5 из символов `#` двумя вложенными циклами.

## Точные правила

* `break` завершает ближайший объемлющий цикл (`for`, `while`) **или** `switch`. Выполнение продолжается со следующей команды после него.
* `continue` относится только к циклам. В `for` после него выполняется шаг, затем проверка условия. В `while` выполнение сразу переходит к проверке условия, поэтому изменение счётчика, стоящее ниже `continue`, **пропускается**.
* В `switch`, стоящем внутри цикла, `break` закрывает `switch`, а не цикл. Чтобы выйти из цикла, нужен флаг или другая проверка. `continue` внутри такого `switch` относится к циклу.
* В цикле внутри цикла `break` выходит только из внутреннего. Чтобы остановить оба, заведите переменную-флаг (`bool found = false;`), установите её и проверьте во внешнем цикле. Позже вы научитесь выходить из обоих циклов командой `return` из функции.
* Число оборотов вложенных циклов перемножается. Два цикла по 1000 дают миллион оборотов; три - миллиард. Это определяет скорость программы.
* Обе команды можно заменить условиями, но тогда вложенность растёт. Практическое правило: если `break` или `continue` делает цикл короче и понятнее, используйте его; если вы теряете след, как завершается цикл, перепишите условие.
* Вне цикла и `switch` `break` недопустим: компилятор отклоняет программу. `continue` вне цикла тоже.
* Переменные внешнего цикла видны во внутреннем, а переменные внутреннего - нет. Имена счётчиков во вложенных циклах должны различаться (`i` и `j`, `row` и `col`).

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. `break` вне цикла.**

```cpp
if (x > 1) {
    break;
}
```

```text
main.cpp:5:9: error: 'break' statement not in loop or switch statement
    5 |         break;
      |         ^
```

`break` нужен внутри цикла или `switch`. Здесь `if` - не цикл, поэтому выходить из него нельзя.

**2. `continue` в `while` до изменения счётчика.**

```cpp
int k = 0;
while (k < 5) {
    if (k == 2) {
        continue;
    }
    k++;
}
```

Компилятор молчит, а программа зависает: на `k == 2` команда `continue` перескакивает через `k++`, и `k` остаётся двойкой навсегда. Решения: изменить счётчик **до** `continue` (`k++` в начале тела) или использовать `for`, где шаг выполняется всегда.

**3. Ожидание, что `break` выйдет из обоих циклов.** В примере 4 `break` останавливает только внутренний цикл. Если нужно закончить поиск во всей таблице, используйте флаг:

```cpp
bool found = false;
for (int i = 0; i < 10 && !found; i++) {
    for (int j = 0; j < 10; j++) {
        if (i * j == 42) {
            found = true;
            break;
        }
    }
}
```

**4. `break` внутри `switch` внутри цикла.** Если в цикле стоит `switch` с `case 'q': break;`, этот `break` закрывает `switch`, а не цикл, поэтому «команда выхода» ничего не прерывает. Устанавливайте флаг в ветке и проверяйте его в условии цикла.

**5. Перепутаны счётчики вложенных циклов.** Если во внутреннем цикле написано `i++` вместо `j++`, внешний счётчик меняется не там, где ожидается, и цикл пропускает или зацикливается. Именуйте счётчики осмысленно (`row`, `col`), когда циклов больше одного.

**6. Лишние обороты.** Вложенные циклы по большим диапазонам медленные: два цикла по 100 000 дают десять миллиардов оборотов. Прервите бесполезную работу через `break` или выберите другой подход.

<!-- section: summary -->
## Итоги

* `break` завершает ближайший цикл или `switch`; `continue` пропускает остаток текущего оборота.
* В `while` перед `continue` счётчик должен быть уже изменён, иначе цикл зависнет; в `for` шаг выполняется и после `continue`.
* Вложенный цикл выполняется заново на каждый оборот внешнего; число оборотов перемножается.
* `break` внутреннего цикла не затрагивает внешний; для выхода из обоих служит флаг.
* Используйте `break` и `continue`, когда они упрощают чтение, и не злоупотребляйте ими.

Циклы и условия позволяют программе делать много, но код растёт. Чтобы не повторять один и тот же фрагмент и давать кускам кода имена, в следующем уроке мы введём [функции](lesson:cpp.from-zero.functions).

## Для тех, кто уже программирует

* `break` и `continue` работают как в C, Java, JavaScript, Python. **Меток для выхода из нескольких циклов нет**: в Java это `break label`, в C++ приходится использовать флаг, `return` из функции или `goto` (который существует, но в курсе не используется).
* `break` в `switch` внутри цикла закрывает `switch`, как в Java и C#. В Go и Kotlin ветки не проваливаются и поведение иное.
* Вложенные циклы с большим числом оборотов - обычная причина «зависания»; сложность перемножается как в любом языке.
* Условие `i * i > 200` для больших `i` может переполнить `int` (неопределённое поведение). В этом примере значения малы, но в общем случае используйте `long long`.
* У `for` в C++ нет `else` (как у Python) и нет `foreach` по индексам (есть range-for, урок 19).
* Компилятор C++ вправе реорганизовать циклы (развернуть, векторизовать) до тех пор, пока наблюдаемое поведение сохраняется; `break` и `continue` этому не мешают.

## Выход из нескольких циклов и `goto`

Это необязательный раздел: для заданий он не нужен.

Когда из глубоко вложенных циклов нужно выйти одним движением, в C++ есть три средства. Первое - **флаг**: он добавляет переменную и проверку, зато понятен всем. Второе - вынести циклы в отдельную функцию и выйти через `return` (урок 17): это обычно самый чистый путь. Третье - команда `goto метка;`, которая прыгает в указанное место функции. Она корректно работает и иногда оправдана именно для выхода из вложенных циклов, но злоупотребление ею превращает программу в запутанный клубок, поэтому в учебных программах и в большинстве кодовых стандартов её избегают.

В C++ нет `finally`, но есть деструкторы: когда `break`, `continue` или `return` выходят из блока, все локальные объекты блока корректно уничтожаются. Эта гарантия (RAII) - основа безопасной работы с ресурсами, она разбирается в курсе «C++: первые шаги».
