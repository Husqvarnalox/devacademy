## Зачем это нужно

Почти любая программа сообщает результат человеку: цену, имя, итог расчёта. В реальных сообщениях встречаются и текст, и числа, и кавычки, и пути к файлам. Чтобы вывод получался нужным, надо понимать, как C++ собирает строку из частей и как записать символы, которые нельзя просто вставить в кавычки.

## Одна новая идея: вывод - это цепочка, в которой каждая часть отправляется по очереди

Вы уже знаете команду `std::cout << "текст\n";`. Знак `<<` можно повторять: каждый `<<` отправляет в вывод ещё одну часть, слева направо.

```cpp
std::cout << "Цена: " << 45 << " руб.\n";
```

Здесь три части: текст `"Цена: "`, число `45` и текст `" руб.\n"`. На экране они появляются подряд без пробелов между ними: пробел нужно записать самим, внутри кавычек. Получится `Цена: 45 руб.`.

Три связанные детали делают вывод точным:

* **Перевод строки.** Компьютер сам не переходит на новую строку. Это делает символ `\n`, который пишут внутри кавычек. Без него следующий вывод продолжится в той же строке.
* **Спецсимволы в тексте.** Кавычка закрывает текст, поэтому кавычку внутри текста записывают как `\"`. Сама обратная косая черта `\` начинает такие сочетания, поэтому её саму записывают как `\\`. Такие сочетания из `\` и символа называются **управляющими последовательностями** (escape-последовательностями).
* **Комментарии.** Строка, которая начинается с `//`, - заметка для человека. Компилятор её игнорирует.

<!-- section: examples -->
## Пример 1. Цепочка из нескольких частей

```cpp run
#include <iostream>

int main() {
    std::cout << "Хлеб: " << 45 << " руб.\n";
    std::cout << "Молоко: " << 80 << " руб.\n";
}
```
```output
Хлеб: 45 руб.
Молоко: 80 руб.
```

Разбор по строкам:

* В каждой команде три части, соединённые знаком `<<`. Последняя часть заканчивается `\n`, поэтому вторая команда начинает новую строку.
* Число `45` в кавычки брать не нужно: числа печатаются как есть. Если написать `"45"`, на экране будет то же самое, но это уже текст, а не число. Разница важна, когда с числами считают.
* Пробел после двоеточия стоит внутри кавычек: `"Хлеб: "`. Без него получилось бы `Хлеб:45`.

## Пример 2. Без `\n` строка не заканчивается

```cpp run
#include <iostream>

int main() {
    std::cout << "Раз, ";
    std::cout << "два, ";
    std::cout << "три\n";
    std::cout << "Старт!\n";
}
```
```output
Раз, два, три
Старт!
```

Три первые команды печатают части одной строки, потому что в них нет `\n`. Перевод строки в конце третьей команды и в конце четвёртой завершает строки.

## Пример 3. Кавычки, обратная косая черта и табуляция

```cpp run
#include <iostream>

int main() {
    std::cout << "Он сказал: \"Привет!\"\n";
    std::cout << "Папка: C:\\Users\\student\n";
    std::cout << "Имя\tВозраст\n";
}
```
```output
Он сказал: "Привет!"
Папка: C:\Users\student
Имя	Возраст
```

Разбор:

* `\"` печатает одну двойную кавычку, а не закрывает текст.
* `\\` печатает одну обратную косую черту; поэтому в пути стоит по два символа `\` на каждый разделитель.
* `\t` вставляет табуляцию - широкий пробел, по которому удобно выравнивать столбцы.

## Пример 4. Комментарии

```cpp run
#include <iostream>

int main() {
    // Эта строка - заметка, она ничего не печатает.
    std::cout << "Видно\n";
    // std::cout << "Не видно\n";
    /* Комментарий можно
       растянуть на несколько строк */
    std::cout << "Тоже видно\n";
}
```
```output
Видно
Тоже видно
```

Закомментированную команду компилятор пропускает, будто её нет. Это удобно, чтобы временно отключить строку и посмотреть, что изменится.

**Попробуйте.** Напечатайте одной командой строку `Итого: 125 руб.`, составив её из трёх частей. Потом добавьте в текст слово в кавычках: `Скидка "Осень" действует`. Проверьте, что программа печатает кавычки.

## Точные правила

* Выражение `std::cout << a << b << c` выполняется слева направо; каждая часть попадает в вывод целиком и без разделителей.
* Управляющие последовательности:

| Запись | Что печатается |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\"` | двойная кавычка |
| `\\` | обратная косая черта |

* Другие сочетания вроде `\q` - не управляющие последовательности; компилятор предупредит о них (`unknown escape sequence`).
* Вместо `"\n"` иногда пишут `std::endl`. Он тоже переводит строку, но ещё и принудительно сбрасывает накопленный вывод на экран, что медленнее. В курсе используется `"\n"`.
* Текст в кавычках не может содержать необработанный перевод строки: строка литерала должна закончиться на той же строке исходного кода.
* Однострочный комментарий начинается с `//` и идёт до конца строки; многострочный заключён в `/* ... */` и не может вкладываться сам в себя.
* Комментарии объясняют **почему** код устроен так, а не повторяют, **что** он делает: `// Скидка 10% для постоянных клиентов` полезнее, чем `// печатаем`.
* Вывод числа и вывод текста не отличаются по записи: `std::cout << 45;` и `std::cout << "45";` печатают одно и то же, но в первом случае это число.

## Типичные ошибки

**1. Нет пробела между частями.** `std::cout << "Цена:" << 45;` печатает `Цена:45`. Пробел нужно включить в текст: `"Цена: "`.

**2. Нет `\n`.** Следующий вывод оказывается в той же строке: `Привет` и `мир` вместо двух строк. Поставьте `\n` в конец текста.

**3. Кавычка внутри текста.**

```cpp
std::cout << "Он сказал "Привет"\n";
```

```text
main.cpp:4:38: error: no matching literal operator for call to 'operator""Привет' with arguments of types 'const char *' and 'unsigned long', and no matching literal operator template
    4 |     std::cout << "Он сказал "Привет"\n";
      |                              ^
1 error generated.
```

Вторая кавычка закрыла текст, и компилятор увидел слово `Привет`, приклеенное к литералу, как будто это его «суффикс». Формулировка странная и непонятная новичку, но место названо верно: столбец указывает на кавычки вокруг слова. Если сообщение непонятно, смотрите на место, а не на слова, и проверьте кавычки в этой строке. Запишите внутренние кавычки как `\"`.

**4. Одна обратная косая черта в пути.**

```cpp
std::cout << "C:\temp\n";
```

Сочетание `\t` в `\temp` станет табуляцией, и вместо `C:\temp` на экране появится `C:` и табуляция с `emp`. Каждую обратную косую черту в пути нужно записать дважды: `"C:\\temp\n"`.

**5. Две стрелки в неверную сторону.** `std::cout >> "текст"` - ошибка: стрелки вывода всегда `<<`, направленные от данных к `cout`. Компилятор выдаст длинное сообщение `invalid operands to binary expression`; читайте только первую строку.

**6. Вложенные многострочные комментарии.** `/* /* */ */` не работает: комментарий закончится на первом `*/`, а второй `*/` станет ошибкой.

<!-- section: summary -->
## Итоги

* `<<` можно повторять: цепочка отправляет части в вывод по очереди, слева направо; числа не нужно брать в кавычки.
* Новую строку делает `\n`; без него следующий вывод продолжается в той же строке.
* Внутри текста кавычка записывается как `\"`, обратная косая черта - как `\\`, табуляция - `\t`.
* `// ...` и `/* ... */` - комментарии: компилятор их пропускает, а читатель получает объяснение.

В следующем уроке ([Переменные](lesson:cpp.from-zero.variables)) вы научитесь хранить значения под именами, чтобы использовать их в выводе несколько раз и менять в одном месте.

## Для тех, кто уже программирует

* `std::cout << a << b` - не вызов функции с аргументами, как `print(a, b)` в Python или `console.log(a, b)` в JavaScript. Это цепочка вызовов оператора `<<`, каждый из которых возвращает тот же поток; пробелов между частями нет.
* Для вывода типа определено своё поведение: `bool` печатается как `1`/`0` (если не включить `std::boolalpha`), `char` как символ, а `double` по умолчанию с шестью значащими цифрами. Подробно - в уроках 5 и 10.
* `"\n"` или `'\n'` быстрее `std::endl`, потому что `endl` ещё и вызывает сброс буфера (`flush`). Для интерактивных программ сброс иногда нужен; для обычного вывода - нет.
* Литерал `"text"` в C++ имеет тип «массив `const char`» (так называемая C-строка), а не `std::string`; в уроке 4 появится настоящая строка. Склеивать два литерала через `+` нельзя: `"a" + "b"` - ошибка.
* Сырые строковые литералы `R"(C:\temp)"` позволяют писать обратные косые черты без удвоения; в курсе не используются.

## Что делает `<<` на самом деле

Это необязательный раздел: для заданий он не нужен.

В C++ оператор `<<` для чисел означает битовый сдвиг: `1 << 3` равно `8`. Для потоков вывода стандартная библиотека определила собственную версию этого оператора: «записать значение в поток и вернуть тот же поток». Благодаря возвращённому потоку следующий `<<` продолжает цепочку. Такое переопределение называется **перегрузкой оператора**; свои перегрузки можно писать для собственных типов, но это тема курсов «C++: первые шаги» и «Язык и стандартная библиотека».

Вывод в `std::cout` буферизуется: символы сначала копятся в памяти и отправляются на экран порциями. Поэтому, если программа аварийно завершится, последние строки иногда не появятся. `std::endl` и `std::flush` принудительно отправляют накопленное.
