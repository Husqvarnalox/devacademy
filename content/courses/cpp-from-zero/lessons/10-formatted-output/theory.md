## Зачем это нужно

Цена `19.9` в чеке должна выглядеть как `19.90`. Столбцы таблицы - ровно один под другим. По умолчанию `std::cout` печатает дробные числа так, как ему удобно (шесть значащих цифр, иногда научная запись), и для денег и таблиц этого мало. Вывод можно настроить.

## Одна новая идея: настройки вывода вставляют в цепочку `<<`, как обычные части

Настройки называются **манипуляторами**. Большинство из них находятся в заголовке `<iomanip>` (от «input/output manipulators»), поэтому в начало файла добавляют `#include <iomanip>`. Вы уже встречали один манипулятор: `std::boolalpha` из урока 5.

Два главных манипулятора для чисел:

* `std::fixed` - писать дробные числа обычной записью, без `e+06`;
* `std::setprecision(n)` - сколько знаков.

**Вместе** они означают «ровно `n` знаков после точки»:

```cpp
std::cout << std::fixed << std::setprecision(2);
std::cout << 19.9;   // 19.90
```

Без `std::fixed` число `n` в `setprecision` означало бы «значащих цифр всего» - это совсем другое, поэтому для денег всегда пишите обе настройки.

Третий манипулятор - `std::setw(n)` (от «set width»): он задаёт **ширину поля** - сколько символов занять следующему значению. Если значение короче, остальное заполняется пробелами. Так выравнивают столбцы:

```cpp
std::cout << std::setw(8) << 42;   // "      42"
```

По умолчанию значение прижимается вправо. Манипуляторы `std::left` и `std::right` меняют сторону.

Важное различие, из-за которого новички путаются:

* `std::fixed`, `std::setprecision`, `std::left`, `std::right` **остаются в силе**, пока вы не измените их снова;
* `std::setw` действует **только на одно** следующее значение.

## Пример 1. Знаки после точки

```cpp run
#include <iomanip>
#include <iostream>

int main() {
    double price = 1234.5;
    double third = 1.0 / 3;
    std::cout << price << " " << third << "\n";
    std::cout << std::fixed << std::setprecision(2);
    std::cout << price << " " << third << " " << 2.0 << "\n";
    std::cout << std::setprecision(0) << 2.4 << " " << 7.6 << "\n";
}
```
```output
1234.5 0.333333
1234.50 0.33 2.00
2 8
```

Разбор:

* Первая строка напечатана по умолчанию: шесть значащих цифр, лишние нули не добавляются.
* После `std::fixed << std::setprecision(2)` все дробные числа получают ровно две цифры после точки: `1234.50`, `0.33` и даже целое `2.0` превращается в `2.00`. Число округляется (до ближайшего), а не отбрасывается.
* `std::setprecision(0)` убирает дробную часть совсем, но тоже округляет: `7.6` стало `8`. Это не то же самое, что преобразование в `int` из прошлого урока, где дробная часть отбрасывается.

## Пример 2. Таблица

```cpp run
#include <iomanip>
#include <iostream>

int main() {
    std::cout << std::fixed << std::setprecision(2);
    std::cout << std::left << std::setw(8) << "bread" << std::right << std::setw(7) << 45.5 << "\n";
    std::cout << std::left << std::setw(8) << "milk" << std::right << std::setw(7) << 80.0 << "\n";
    std::cout << std::left << std::setw(8) << "cheese" << std::right << std::setw(7) << 312.456 << "\n";
}
```
```output
bread     45.50
milk      80.00
cheese   312.46
```

Разбор:

* Название товара занимает поле из 8 символов и прижато влево (`std::left`), цена - поле из 7 символов и прижата вправо (`std::right`). Поэтому цены стоят строго друг под другом, а точки совпадают.
* `std::setw` нужно писать **перед каждым** значением: он «расходуется» после первого вывода. А вот `std::left`, `std::right`, `std::fixed` и `std::setprecision` пишутся один раз (или переключаются по необходимости).
* Число `312.456` округлилось до `312.46`.

## Пример 3. Что делает `setw` и чего не делает

```cpp run
#include <iomanip>
#include <iostream>

int main() {
    std::cout << "[" << std::setw(6) << 42 << "]\n";
    std::cout << "[" << std::left << std::setw(6) << 42 << "]\n";
    std::cout << "[" << std::setw(6) << std::right << "ab" << "]\n";
    std::cout << "[" << std::setw(3) << 12345 << "]\n";
    std::cout << "[" << std::setw(4) << 1 << 2 << "]\n";
    std::cout << "[" << std::setfill('.') << std::setw(6) << 42 << "]\n";
}
```
```output
[    42]
[42    ]
[    ab]
[12345]
[   12]
[....42]
```

Разбор по строкам:

1. Поле шириной 6, число прижато вправо: четыре пробела и `42`.
2. После `std::left` число прижато влево: `42` и четыре пробела.
3. После `std::right` строка `"ab"` снова справа.
4. Поле шириной 3 меньше числа из пяти цифр. `setw` **никогда не обрезает**: число печатается целиком.
5. `setw(4)` относится только к `1`: получилось `   1`, а следом `2` без поля.
6. `std::setfill('.')` заменяет заполнитель пробела на точку. Заполнитель остаётся в силе.

**Попробуйте.** Напечатайте число `3.14159265` с одним, двумя и пятью знаками после точки. Затем создайте таблицу из трёх строк с названием слева и целой ценой справа. Наконец, уберите `std::fixed` и оставьте `std::setprecision(2)`: посмотрите, что произойдёт с числом `1234.5`.

## Точные правила

* **`#include <iomanip>`** нужен для `std::setprecision`, `std::setw`, `std::setfill`. Манипуляторы `std::fixed`, `std::left`, `std::right`, `std::boolalpha` находятся в `<ios>`, который уже подключён через `<iostream>`; но для единообразия подключайте `<iomanip>` всякий раз, когда форматируете вывод.
* **`std::fixed << std::setprecision(n)`**: каждое дробное число печатается ровно с `n` знаками после точки, с округлением до ближайшего. Целые числа (`int`) не меняются: настройки затрагивают только дробные.
* **Только `std::setprecision(n)`**, без `std::fixed`: `n` - общее число значащих цифр, дальше вывод переходит к научной записи (`1.2e+03` для `1234.5` при `n = 2`).
* **Возврат к умолчанию** для дробных: `std::defaultfloat` и `std::setprecision(6)`.
* **Округление.** Дробные числа хранятся приближённо, поэтому «половинки» округляются не всегда так, как в школе: например, `2.675` при двух знаках может дать `2.67`, потому что в памяти оно чуть меньше `2.675`. Это нормально.
* **`std::setw(n)`** действует на следующее значение и сбрасывается. Если значение длиннее `n`, оно печатается целиком.
* **`std::left` / `std::right`** задают выравнивание внутри поля `setw`; без `setw` они ничего не меняют. По умолчанию выравнивание правое.
* **`std::setfill(c)`** задаёт символ-заполнитель, пока его не поменяют.
* **Ширина считается в байтах.** Для русских слов (два байта на букву) выравнивание через `std::setw` не работает как ожидается: поле `setw(10)` для слова «хлеб» (8 байтов) добавит только два пробела вместо шести. В таблицах курса используйте латинские названия.
* Манипуляторы можно писать и отдельной командой, не обязательно в цепочке: `std::cout << std::fixed;` затем `std::cout << std::setprecision(2);` - то же самое.

## Типичные ошибки

**1. `setprecision` без `fixed`.**

```cpp
std::cout << std::setprecision(2) << 1234.5 << " " << 3.14159 << "\n";
```

```text
1.2e+03 3.1
```

Число `2` здесь означает две **значащие** цифры, поэтому `1234.5` превратилось в `1.2e+03`, а `3.14159` - в `3.1`. Для денег добавьте `std::fixed`.

**2. Забыли `#include <iomanip>`.**

```text
main.cpp:3:23: error: no member named 'setprecision' in namespace 'std'
    3 |     std::cout << std::setprecision(2) << 1.5;
      |                       ^~~~~~~~~~~~
```

Компилятор сообщает, что в пространстве `std` нет такого имени. Это значит, что подключён не тот заголовок: добавьте `#include <iomanip>`. (Иногда программа собирается и без него, потому что другой заголовок подключает его сам, но на другой системе перестанет собираться.)

**3. Ожидание, что `setw` действует постоянно.**

```cpp
std::cout << std::setw(8) << "milk" << 80.0;
```

Ширина 8 касается только слова `milk`; число `80.0` выведется без поля, и столбец сломается. Пишите `setw` перед каждым значением.

**4. Выравнивание русского текста.**

```cpp
std::cout << std::left << std::setw(10) << "bread" << "|\n";
std::cout << std::left << std::setw(10) << "хлеб" << "|\n";
```

```text
bread     |
хлеб  |
```

Слово «хлеб» занимает 8 байтов, поэтому `setw(10)` добавил только два пробела, и колонка «поехала». Для выравнивания используйте латиницу.

**5. Числа вместо денег.** Форматирование не меняет значение: `std::fixed << std::setprecision(2)` лишь округляет **при выводе**. В переменной по-прежнему лежит, например, `2.675`, а печатается `2.67`. Сумму для вычислений не округляют через вывод.

**6. Манипуляторы в неверном порядке.** `std::cout << 19.9 << std::fixed << std::setprecision(2);` напечатает `19.9` раньше, чем настройки вступят в силу. Настройки нужно писать **до** значений.

**7. Путаница `setprecision(0)` и `static_cast<int>`.** Первый округляет при выводе (`7.6` даёт `8`), второй отбрасывает дробную часть и даёт `7`.

## Итоги

* `std::fixed << std::setprecision(n)` - ровно `n` знаков после точки (с округлением); это настройка остаётся, пока её не изменят.
* `std::setprecision(n)` без `std::fixed` задаёт общее число значащих цифр и может дать научную запись.
* `std::setw(n)` задаёт ширину поля для **одного** следующего значения; `std::left` и `std::right` выбирают сторону выравнивания.
* Все эти манипуляторы подключаются через `#include <iomanip>`.
* Ширина считается в байтах, поэтому русские слова в таблицах выравнивать нельзя.

В следующем уроке ([Сравнения и логика](lesson:cpp.from-zero.comparison-and-logic)) вы научитесь сравнивать значения и объединять сравнения в одно утверждение: это основа любых решений в программе.

## Для тех, кто уже программирует

* Манипуляторы потоков - это функции или объекты, применяемые через `<<`. Они меняют **состояние потока** (флаги формата), поэтому часть настроек «липкая». Исключение - `std::setw`, которая сбрасывается после следующего вывода. Это отличает C++ от `printf("%8.2f")`, где формат задаётся в каждом вызове.
* Состояние потока `std::cout` глобально: функция, которая изменила `std::fixed`, влияет на весь последующий вывод в программе. Если это неудобно, сохраняют и восстанавливают флаги (`std::ios_base::fmtflags`) или форматируют в `std::ostringstream`.
* В C++20 есть `std::format("{:.2f}", x)`, похожая на `str.format` в Python и `String.format` в Java. Курс не использует её, потому что она есть не во всех установленных стандартных библиотеках.
* Для денег `double` не подходит для бухгалтерских вычислений: используют целые копейки или специальные библиотеки. Форматированный вывод только маскирует погрешность.
* `std::setprecision` без `fixed` ведёт себя как `%g` в `printf`, а с `fixed` - как `%f`.

<!-- section: deep-dive -->
## Как поток хранит настройки

Это необязательный раздел: для заданий он не нужен.

Каждый поток вывода хранит набор флагов формата (`fixed`, `left`, `boolalpha`...), текущую точность, ширину поля и символ-заполнитель. Манипулятор - это просто способ изменить одно из этих значений через цепочку `<<`. Когда выводится число, поток читает эти настройки и формирует текст.

Ширина поля - единственная «одноразовая» настройка: после каждого вывода поток обнуляет её. Остальные остаются, и именно поэтому библиотечные функции, которые меняют формат вывода, должны возвращать его обратно: иначе они испортят вывод другим частям программы. Современная функция `std::format` решает эту проблему, задавая формат прямо в строке каждого вызова, а `std::print` из C++23 делает вывод ещё короче; пока они поддерживаются не везде, поэтому в курсе мы пользуемся манипуляторами.
