## Зачем это нужно

Одна переменная хранит одно значение. Но данные почти всегда приходят наборами: оценки класса, цены в чеке, строки файла. Заводить переменные `price1`, `price2`, `price3` невозможно, если заранее неизвестно, сколько их будет. Нужна **коллекция** - переменная, внутри которой лежит много значений одного типа. Самая частая коллекция в C++ - **вектор**, `std::vector`.

## Одна новая идея: вектор - нумерованный список, который растёт

Вектор хранит значения подряд, как нумерованный список. Вы указываете тип элементов в угловых скобках: `std::vector<int>` читается как «вектор целых», `std::vector<std::string>` - «вектор строк».

```cpp
std::vector<int> prices;     // пустой вектор целых
prices.push_back(120);       // добавить в конец
prices.push_back(45);
std::cout << prices.size();  // сколько элементов: 2
std::cout << prices[0];      // элемент с номером 0: 120
```

Как и в строках, элементы нумеруются **с нуля**: у вектора из трёх элементов номера 0, 1, 2. Метод `size()` возвращает количество, `push_back` добавляет в конец, а `empty()` отвечает, пуст ли вектор.

Чтобы обработать все элементы, нужен цикл. Для вектора есть особенно удобная форма **range-for** («для каждого»), в которой номер не нужен:

```cpp
for (int price : prices) {
    std::cout << price << "\n";
}
```

Читается так: «для каждого `price` из `prices` выполни блок».

<!-- section: examples -->
## Пример 1. Создание и чтение элементов

```cpp run
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores;
    scores.push_back(80);
    scores.push_back(95);
    scores.push_back(70);

    std::cout << "Элементов: " << scores.size() << "\n";
    std::cout << "Первый: " << scores[0] << "\n";
    std::cout << "Последний: " << scores[scores.size() - 1] << "\n";
    std::cout << "Пуст? " << scores.empty() << "\n";
}
```
```output
Элементов: 3
Первый: 80
Последний: 70
Пуст? 0
```

Разбор:

* Последний элемент вектора из трёх имеет номер `size() - 1`, то есть `2`. Это безопасно только если вектор не пуст (см. ошибки).
* `empty()` вернул `false` и напечатался как `0`.
* Вместо `scores[scores.size() - 1]` короче писать `scores.back()`, но оба варианта требуют непустого вектора.

## Пример 2. Начальные значения и обход

```cpp run
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> names = {"Анна", "Борис", "Вера"};
    for (const std::string& name : names) {
        std::cout << "Привет, " << name << "!\n";
    }

    std::vector<int> v = {4, 8, 15, 16};
    int sum = 0;
    for (int x : v) {
        sum += x;
    }
    std::cout << "Сумма: " << sum << "\n";
}
```
```output
Привет, Анна!
Привет, Борис!
Привет, Вера!
Сумма: 43
```

Разбор:

* Значения можно задать сразу списком в фигурных скобках.
* В цикле по строкам переменная записана как `const std::string&`: так строки не копируются (урок 18). Для чисел достаточно обычного `int x`.
* Тип в range-for должен подходить к элементам: для вектора целых это `int`, для вектора строк - `std::string`.

## Пример 3. Изменение элементов и вектор в функции

```cpp run
#include <iostream>
#include <vector>

void doubleAll(std::vector<int>& v) {
    for (int& x : v) {
        x = x * 2;
    }
}

int total(const std::vector<int>& v) {
    int sum = 0;
    for (int x : v) {
        sum += x;
    }
    return sum;
}

int main() {
    std::vector<int> v = {1, 2, 3};
    doubleAll(v);
    for (std::size_t i = 0; i < v.size(); i++) {
        std::cout << v[i] << " ";
    }
    std::cout << "| " << total(v) << "\n";
}
```
```output
2 4 6 | 12
```

Разбор:

* `for (int& x : v)` - ссылка на каждый элемент: изменение `x` меняет сам вектор. Без `&` изменялась бы копия.
* Вектор передают в функцию по ссылке: `std::vector<int>&`, если функция его меняет, и `const std::vector<int>&`, если только читает. Передача по значению скопировала бы все элементы.
* Обход по индексам нужен, если номер элемента важен; счётчик имеет тип `std::size_t` (урок 15).

## Пример 4. Чтение чисел до конца ввода

Программы с чтением ввода показаны обычными блоками, без запуска.

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int x = 0;
    while (std::cin >> x) {
        numbers.push_back(x);
    }
    std::cout << "Прочитано: " << numbers.size() << "\n";
}
```

Для ввода `5 10 15` программа напечатает `Прочитано: 3`. Вектор растёт сам, пока есть данные: заранее знать количество чисел не нужно.

## Пример 5. Выход за границы

Эти два фрагмента **не запускаются** в примерах. Оба обращаются к элементу номер 5 вектора из трёх чисел.

```cpp
std::vector<int> v = {10, 20, 30};
std::cout << v.at(5) << "\n";
```

```text
libc++abi: terminating due to uncaught exception of type std::out_of_range: vector
```

Метод `at` проверил номер и остановил программу с понятным сообщением (в g++ текст другой, но тоже называет `std::out_of_range`). Теперь тот же индекс в квадратных скобках:

```cpp
std::cout << v[5] << "\n";
```

В проверке автора (clang с `-O2`) программа напечатала число `1843359128`, не обнаружив никакой ошибки. Это мусор из чужой памяти, при другой сборке или другом запуске результат будет иным или программа упадёт. Оператор `[]` границ не проверяет, а обращение за границы - неопределённое поведение (урок 4).

**Попробуйте.** Прочитайте числа до конца ввода и напечатайте их в обратном порядке. Найдите в векторе число, равное заданному, и напечатайте его номер или `-1`. Замените `v[5]` на `v.at(5)` и сравните поведение. Заполните вектор квадратами чисел от 1 до 10 и напечатайте его.

## Точные правила

* Подключается заголовок `<vector>`. Тип элементов в угловых скобках обязателен: `std::vector<int>`, `std::vector<double>`, `std::vector<std::string>`.
* Создание: `std::vector<int> v;` - пустой; `std::vector<int> v = {1, 2, 3};` - с значениями; `std::vector<int> v(5);` - пять нулей; `std::vector<int> v(5, 7);` - пять семёрок.
* Основные операции: `v.push_back(x)` - добавить в конец; `v.size()` - количество (тип `std::size_t`, беззнаковый); `v.empty()` - пуст ли; `v.back()` и `v.front()` - последний и первый; `v.pop_back()` - убрать последний; `v.clear()` - очистить.
* **Индексы** от `0` до `size() - 1`. `v[i]` не проверяет границы, `v.at(i)` проверяет и бросает `std::out_of_range`.
* Запись в элемент по несуществующему индексу не создаёт его: `v[3] = 5;` для вектора из трёх элементов - неопределённое поведение. Элементы добавляют только через `push_back` (или задают размер заранее).
* **Range-for:** `for (T x : v)` - копия каждого элемента; `for (T& x : v)` - сам элемент (можно менять); `for (const T& x : v)` - сам элемент без права менять и без копии. Для чисел копию допускают, для строк и крупных объектов используют `const T&`.
* **Нельзя менять размер вектора (`push_back`, `clear`) внутри range-for по нему же:** вектор может перенести элементы в другую область памяти, и текущая ссылка станет недействительной (неопределённое поведение).
* Вектор в функцию передают по ссылке: `const std::vector<int>&` для чтения, `std::vector<int>&` для изменения.
* Сравнение `int` с `size()` вызывает `-Wsign-compare` (урок 11); обход по индексу пишут со счётчиком `std::size_t`.
* Вектор копируется целиком при присваивании `a = b` и при передаче по значению; копирование стоит дорого для больших данных.
* Среднее значение считают в `double`: `static_cast<double>(sum) / v.size()`.

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Чтение за границей с `[]`.** Пример 5: программа не ломается сразу, а читает мусор. Такие ошибки опасны именно тихой работой. Проверяйте индекс (`i < v.size()`) или используйте `at()`.

**2. Последний элемент пустого вектора.**

```cpp
std::vector<int> v;
std::cout << "start\n";
std::cout << v[v.size() - 1] << "\n";
```

В проверке автора программа завершилась сигналом (`Segmentation fault`, код 139), причём строка `start` не появилась на экране: вывод из буфера не успел дойти до терминала. Причина - `size() - 1` у пустого вектора равно `18446744073709551615`. Всегда сначала проверяйте `if (!v.empty())`. (Это тот же приём, что в уроке 15.)

**3. Неподходящее значение.**

```cpp
std::vector<int> y;
y.push_back("a");
```

```text
main.cpp:7:7: error: no matching member function for call to 'push_back'
    7 |     y.push_back("a");
      |     ~~^~~~~~~~~
…/c++/v1/__vector/vector.h:464:60: note: candidate function not viable: no known conversion from 'const char[2]' to 'const value_type' (aka 'const int') for 1st argument
```

В вектор целых нельзя добавить строку. Сообщение называет тип `value_type`: так в стандартной библиотеке называется тип элемента. Путь к заголовку сокращён; в полном сообщении есть ещё одна похожая заметка. Главное - слова `no known conversion`.

**4. Дробное число в списке целых.**

```cpp
std::vector<int> x = {1, 2.5};
```

```text
main.cpp:5:30: error: type 'double' cannot be narrowed to 'value_type' (aka 'int') in initializer list [-Wc++11-narrowing]
    5 |     std::vector<int> x = {1, 2.5};
      |                              ^~~
main.cpp:5:30: note: insert an explicit cast to silence this issue
```

Фигурные скобки запрещают «сужающие» преобразования, которые теряют информацию (урок 9). Если нужен вектор дробных чисел, объявите `std::vector<double>`.

**5. Знаковый счётчик и размер.** `for (int i = 0; i < v.size(); i++)` даёт предупреждение `comparison of integers of different signs`. Используйте `std::size_t` или range-for.

**6. Ожидание, что `v[3] = 5` добавит элемент.** Запись по несуществующему индексу не расширяет вектор. Добавляйте через `push_back`.

**7. Копия вместо ссылки в range-for.** `for (int x : v) { x = 0; }` ничего не меняет в векторе, потому что `x` - копия. Нужно `int& x`.

**8. Изменение вектора во время обхода.** `for (int x : v) { v.push_back(x); }` ломает обход (неопределённое поведение). Соберите новые значения в другой вектор.

## Итоги

* `std::vector<T>` хранит много значений типа `T`, растёт через `push_back`; `size()` даёт количество, `empty()` проверяет пустоту.
* Нумерация с нуля; `v[i]` не проверяет границы (неопределённое поведение за границами), `v.at(i)` проверяет и бросает исключение.
* Range-for `for (T x : v)` обходит все элементы; `T&` позволяет их менять, `const T&` избегает копий.
* Перед `v[0]`, `v.back()` и `v[v.size() - 1]` проверяйте, что вектор не пуст.
* В функцию вектор передают по ссылке: `const std::vector<T>&` или `std::vector<T>&`.

Вектор находит элементы по номеру. Но во многих задачах нужно искать по имени: количество каждого слова, баллы по фамилии. Для этого есть другая коллекция - [словарь `std::map`](lesson:cpp.from-zero.map).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `std::vector<T>` - динамический массив, как `ArrayList<T>` в Java, `List<T>` в C#, `list` в Python или слайс в Go. Элементы лежат в памяти подряд (быстрый обход), при росте вектор может переместить их в новую область.
* Хранит **значения**, а не ссылки на объекты: `std::vector<std::string>` содержит строки внутри себя, и `auto b = a;` копирует вектор целиком. В Java и Python копируется ссылка.
* `v[i]` без проверки границ - по замыслу (как в C). `at(i)` с исключением - опция. Это главное отличие от `IndexOutOfRangeException` и `IndexError`.
* `size()` беззнаковый: типичные ошибки `size() - 1` и `i >= 0`. В C++20 есть `std::ssize(v)` со знаковым результатом.
* `push_back` в среднем быстр (амортизированно O(1)); при перераспределении все ссылки и итераторы на элементы становятся недействительными. Не держите ссылку на элемент, когда добавляете в вектор.
* Range-for `for (auto& x : v)` напоминает `for-each` из Java и C#. Тип `auto` вводится в следующем уроке, пока пишите тип явно.
* Алгоритмы (`std::sort`, `std::find`, `std::accumulate`) в `<algorithm>` и `<numeric>`; в этом курсе их нет.
* `std::vector<bool>` - особый, «упакованный» вектор, и ведёт себя необычно; в обычных задачах лучше не использовать.
* Пустой вектор `empty()` проверяется всегда перед `front()`, `back()`, `v[0]`; иначе неопределённое поведение.

## Как вектор растёт

Это необязательный раздел: для заданий он не нужен.

Внутри вектор хранит три значения: начало блока памяти, количество элементов (`size`) и ёмкость (`capacity`, сколько элементов поместилось бы без нового выделения). Когда `push_back` не находит места, вектор выделяет новый блок побольше (обычно в 1,5-2 раза), переносит туда все элементы и освобождает старый. Благодаря росту «с запасом» среднее время добавления остаётся малым, хотя отдельные добавления дорогие.

Из этого вытекает правило про недействительные ссылки: если вы взяли ссылку на `v[0]`, а затем сделали `push_back` и вектор переехал, ссылка указывает на освобождённую память. Если количество элементов известно заранее, вызов `v.reserve(n)` выделит память один раз и избавит от переездов. Подробнее о контейнерах, итераторах и алгоритмах - в курсе «Язык и стандартная библиотека».
