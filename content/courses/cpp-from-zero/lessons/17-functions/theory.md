## Зачем это нужно

Программа растёт, и в ней появляются одинаковые куски: посчитать скидку, проверить високосный год, напечатать рамку из звёздочек. Копировать такой кусок по всему файлу плохо: найдёте ошибку в одной копии и забудете про остальные. Решение - дать куску кода **имя** и вызывать его по имени. Именованный кусок кода называется **функцией**.

Вы уже пользуетесь функциями: `main` - функция, а `s.size()` и `std::stoi(...)` - тоже функции, только чужие. Теперь вы научитесь писать свои.

## Одна новая идея: функция принимает значения и возвращает результат

```cpp
int square(int n) {
    return n * n;
}
```

Заголовок читается слева направо:

* `int` - тип **результата**: функция вернёт целое число;
* `square` - имя функции;
* `(int n)` - **параметры**: функция ждёт одно целое число и называет его `n` внутри себя;
* `return n * n;` - «верни это значение и завершись».

Вызов выглядит так: `square(4)`. Число `4` - **аргумент**, оно копируется в параметр `n`, а вызов `square(4)` целиком превращается в результат (`16`) и может стоять там, где ждут число: `std::cout << square(4);` или `int a = square(3) + 1;`.

Бывают функции, которые ничего не возвращают, а только делают: например, печатают. У них вместо типа результата стоит слово `void` («пусто»), а `return` не нужен.

Теперь можно объяснить `int main()`: `main` - тоже функция, и её результат (`int`) получает операционная система как код завершения программы. Если до конца `main` дошло без `return`, компилятор подставляет `return 0;` сам; ноль означает «успех». Только для `main` такое исключение есть.

## Пример 1. Функция с результатом

```cpp run
#include <iostream>

int square(int n) {
    return n * n;
}

int add(int a, int b) {
    return a + b;
}

int main() {
    std::cout << square(4) << "\n";
    std::cout << add(2, 3) << "\n";
    std::cout << add(square(2), square(3)) << "\n";
}
```
```output
16
5
13
```

Разбор:

* Функция может иметь несколько параметров, они разделяются запятыми, а у каждого есть свой тип.
* Аргументы могут быть вызовами других функций: `add(square(2), square(3))` сначала считает `4` и `9`, затем складывает.
* Функции стоят **выше** `main`. Почему так - в примере 4.

## Пример 2. Функция void и функция bool

```cpp run
#include <iostream>
#include <string>

void greet(std::string name) {
    std::cout << "Здравствуйте, " << name << "!\n";
}

bool isEven(int n) {
    return n % 2 == 0;
}

int main() {
    greet("Анна");
    greet("Борис");
    std::cout << std::boolalpha << isEven(10) << " " << isEven(7) << "\n";
}
```
```output
Здравствуйте, Анна!
Здравствуйте, Борис!
true false
```

Разбор:

* `greet` ничего не возвращает: вызов стоит отдельной командой.
* Строка `name` копируется в параметр, как и число. Для длинных строк копирование расточительно; как его избежать, показывает следующий урок.
* `isEven` возвращает `bool`: вызов можно использовать как условие, `if (isEven(n)) { ... }`. Имена функций-вопросов обычно начинаются с `is` или `has`.

## Пример 3. Несколько return и локальные переменные

```cpp run
#include <iostream>

int sign(int n) {
    if (n > 0) {
        return 1;
    } else if (n < 0) {
        return -1;
    }
    return 0;
}

int sumTo(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        total += i;
    }
    return total;
}

int main() {
    std::cout << sign(-8) << " " << sign(0) << " " << sign(5) << "\n";
    int total = 100;
    std::cout << sumTo(10) << " " << total << "\n";
}
```
```output
-1 0 1
55 100
```

Разбор:

* Выполнение функции заканчивается на первом сработавшем `return`. Последний `return 0;` обслуживает случай, когда оба условия ложны. Без него путь `n == 0` дошёл бы до конца функции без значения (см. ошибки).
* `total` внутри `sumTo` и `total` в `main` - **две разные переменные** с одним именем. Переменная, объявленная внутри функции, видна только в ней и исчезает при выходе. Поэтому `main` печатает свою `100`, а не `55`.

## Пример 4. Порядок объявления

```cpp run
#include <iostream>

int triple(int n);

int main() {
    std::cout << triple(5) << "\n";
}

int triple(int n) {
    return n * 3;
}
```
```output
15
```

Компилятор читает файл сверху вниз и должен знать функцию до её вызова. Есть два способа:

* поставить функцию (определение) выше `main`, как в примерах 1-3: так принято в небольших программах;
* оставить определение ниже и сверху дать **объявление** - заголовок с точкой с запятой вместо тела: `int triple(int n);`. Оно сообщает «такая функция есть, её тело будет позже».

**Попробуйте.** Напишите функцию `cube(int n)`, возвращающую куб числа, и функцию `printLine(int n)`, печатающую линию из `n` минусов. Напишите функцию `average(double a, double b)` и напечатайте её результат с двумя знаками после точки. Перенесите определение `square` ниже `main` и прочитайте сообщение компилятора.

## Точные правила

* **Определение:** `тип_результата имя(тип параметр, ...) { тело }`. Тело - блок команд.
* **Вызов:** `имя(аргументы)`. Число и типы аргументов должны подходить к параметрам. Аргумент копируется в параметр; изменение параметра внутри функции **не меняет** переменную вызывающего (передача по значению, подробнее в следующем уроке).
* **`return значение;`** немедленно завершает функцию и возвращает значение. Тип значения должен соответствовать типу результата (при необходимости неявно преобразуется, например `double` в `int` с потерей дробной части).
* **`void`:** функция не возвращает значения; `return;` без значения допустим и завершает её досрочно. Результат `void`-функции нельзя присвоить переменной.
* **Если функция с типом результата, отличным от `void`, дошла до конца без `return`, это неопределённое поведение.** Исключение - `main`: для него `return 0;` подразумевается. Предупреждение компилятора `-Wreturn-type` нужно читать как ошибку.
* **Область видимости.** Параметры и переменные, объявленные в функции, видны только внутри неё (и только после своего объявления). Два разных места могут использовать одно имя, не мешая друг другу. Переменная, объявленная внутри блока `{ }`, видна до конца этого блока.
* **Порядок.** Имя должно быть объявлено выше места использования. Объявление (прототип) заканчивается `;` и не содержит тела; определение должно быть одно.
* **Имена.** Имя функции описывает действие (`printReport`) или вопрос (`isEven`). Одна функция - одна задача: если вам приходится объяснять её словом «и», разделите её на две.
* Рекурсия (функция вызывает сама себя) допустима, но в этом курсе не используется.
* `main` вызывается системой; вызывать его самостоятельно из программы нельзя.

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Вызов до определения.**

```cpp
int main() {
    std::cout << square(4) << "\n";
}

int square(int n) {
    return n * n;
}
```

```text
main.cpp:4:18: error: use of undeclared identifier 'square'
    4 |     std::cout << square(4) << "\n";
      |                  ^~~~~~
```

Компилятор на этой строке ещё не знает `square`. Поставьте определение выше `main` или добавьте объявление `int square(int n);` сверху.

**2. Нет `return` на одном из путей.**

```cpp
int sign(int n) {
    if (n > 0) {
        return 1;
    } else if (n < 0) {
        return -1;
    }
}
```

```text
main.cpp:8:1: warning: non-void function does not return a value in all control paths [-Wreturn-type]
    8 | }
      | ^
```

Это не просто стилистика. Для `sign(0)` программа читает несуществующий результат, и итог зависит от настроек компилятора: в проверке автора сборка без оптимизации (`-O0`) напечатала `1`, а с `-O2` - `-1`. Оба ответа неверны, оба «допустимы» для неопределённого поведения. Добавьте `return 0;` в конце.

**3. Неверное число аргументов.**

```text
main.cpp:21:18: error: no matching function for call to 'add'
   21 |     std::cout << add(1) << "\n";
      |                  ^~~
main.cpp:11:5: note: candidate function not viable: requires 2 arguments, but 1 was provided
   11 | int add(int a, int b) {
      |     ^   ~~~~~~~~~~~~
```

Функции `add` нужны два числа, а передано одно. Компилятор указывает подходящую функцию и объясняет, чего не хватает.

**4. Использование результата `void`-функции.**

```cpp
int r = hello();
```

```text
main.cpp:22:9: error: cannot initialize a variable of type 'int' with an rvalue of type 'void'
   22 |     int r = hello();
      |         ^   ~~~~~~~~
```

Функция `hello` ничего не возвращает, поэтому присвоить её результат нельзя.

**5. Дробные аргументы в целые параметры.**

```cpp
std::cout << add(2.7, 1.9) << "\n";
```

```text
main.cpp:23:22: warning: implicit conversion from 'double' to 'int' changes value from 2.7 to 2 [-Wliteral-conversion]
   23 |     std::cout << add(2.7, 1.9) << "\n";
      |                  ~~~ ^~~
```

Параметры типа `int` получают усечённые значения: напечатается `3`, а не `4.6`. Если функция работает с дробями, объявите параметры как `double` (урок 9).

**6. Ожидание, что функция изменит переменную.** Если функция `void bump(int n)` делает `n = n + 1;`, то после `bump(x)` переменная `x` остаётся прежней: функция меняла свою копию. Чтобы передать результат наружу, верните его: `x = bump(x);`.

**7. Вызов без скобок.** Запись `greet;` без `()` не вызывает функцию. Скобки нужны всегда, даже если параметров нет.

## Итоги

* Функция - именованный кусок кода: `тип_результата имя(параметры) { тело }`. Результат отдаёт `return`, функция без результата объявляется как `void`.
* Аргументы копируются в параметры; изменение параметра не меняет переменную вызывающего.
* Переменные внутри функции локальны: снаружи их не видно.
* Определение функции должно стоять выше вызова, либо сверху даётся объявление с точкой с запятой.
* Дойти до конца функции с результатом без `return` нельзя: это неопределённое поведение. `main` - исключение.

Осталось выяснить, как передавать в функцию большие значения (строки) без копирования и как позволить функции менять переменную вызывающего. Этому посвящён урок о [ссылках](lesson:cpp.from-zero.references).

## Для тех, кто уже программирует

* Функции в C++ - свободные (не привязаны к классу), как в Python и Go. В Java и C# они всегда методы. Типы параметров и результата обязательны.
* Порядок имеет значение: имя должно быть объявлено выше использования. Отсюда прототипы и заголовочные файлы (`.h`), которые разбираются в «C++: первые шаги».
* Нет значений параметров «по имени», но есть значения по умолчанию: `void f(int x, int y = 0);` (в конце списка).
* Перегрузка функций (одно имя, разные списки параметров) допустима, как в Java и C#; выбор по типам аргументов выполняется при компиляции.
* Возвращаемое значение «забытого» `return` - неопределённое поведение, а не `None`/`null`/ноль. В Rust такую функцию компилятор не пропустит, в Go тоже; C++ ограничивается предупреждением.
* Параметры передаются по значению (копия); для крупных объектов используют ссылки (следующий урок). Это отличает C++ от Java и Python, где переменные объектов уже ссылки.
* `main` - единственная функция, которой разрешено не возвращать значение; результат `int` отдаётся системе как код завершения.
* Возвращать несколько значений можно через структуру (урок 23), `std::pair` и `std::tuple`, а также через ссылки-параметры; в курсе используются первые варианты.
* Лямбды и указатели на функции есть, но в этом курсе не используются.

## Что происходит при вызове функции

Это необязательный раздел: для заданий он не нужен.

Когда вызывается функция, процессор отводит для неё участок памяти в **стеке вызовов**: там лежат копии аргументов, локальные переменные и адрес возврата, то есть место, куда нужно вернуться после `return`. После выхода из функции участок освобождается, поэтому локальные переменные «исчезают»: их память может быть сразу же использована под другую функцию. Отсюда вытекает опасность вернуть из функции ссылку на локальную переменную: ссылка укажет на освобождённую память.

Компилятор часто **встраивает** (inline) небольшие функции: копирует их тело в место вызова и убирает затраты на вызов. Поэтому разбивать код на маленькие функции почти ничего не стоит по скорости, а читаемость повышает. Решение о встраивании принимает компилятор по своим правилам; слово `inline` в современном C++ на него почти не влияет и связано скорее с правилами об одном определении при компоновке нескольких файлов.
