## Зачем это нужно

Любое решение в программе начинается с вопроса: «возраст не меньше 18?», «пароль совпал?», «число лежит в допустимом диапазоне?». Ответ на такой вопрос - **логическое значение**: `true` (истина) или `false` (ложь). В этом уроке вы научитесь задавать такие вопросы и соединять несколько вопросов в один. Сами решения («если да, то делай то-то») появятся в следующих уроках курса; а сейчас мы просто печатаем ответы.

## Одна новая идея: сравнение - это выражение, значение которого имеет тип `bool`

Вы уже знаете тип `bool` (урок 5). Теперь вы увидите, откуда он берётся. **Операции сравнения** принимают два значения и возвращают `bool`:

| Запись | Значение |
|---|---|
| `a == b` | равно |
| `a != b` | не равно |
| `a < b`, `a > b` | меньше, больше |
| `a <= b`, `a >= b` | не больше, не меньше |

Обратите внимание: сравнение на равенство пишется **двумя** знаками `==`. Один знак `=` - это присваивание (урок 4), и путать их нельзя.

Простые вопросы соединяют **логическими операциями**:

* `x && y` («и») - истина, только если истинны оба;
* `x || y` («или») - истина, если истинно хотя бы одно;
* `!x` («не») - меняет истину на ложь и наоборот.

Условие «возраст от 18 до 64 включительно» записывается как два сравнения, связанные `&&`: `age >= 18 && age < 65`.

Порядок вычисления такой: сначала арифметика, потом сравнения, потом `!`, затем `&&`, затем `||`. Скобки меняют порядок; при сомнении ставьте скобки.

Ещё одна особенность: `&&` и `||` вычисляют правую часть **только если она нужна**. Если левая часть `&&` ложна, результат уже ясен, правая часть пропускается. Благодаря этому `d != 0 && 10 / d > 1` безопасно: деление на ноль не случится.

<!-- section: examples -->
## Пример 1. Сравнения

```cpp run
#include <iostream>

int main() {
    std::cout << std::boolalpha;
    int a = 5;
    int b = 8;
    std::cout << (a == b) << " " << (a != b) << " " << (a < b) << " "
              << (a > b) << " " << (a <= 5) << " " << (b >= 9) << "\n";
}
```
```output
false true true false true false
```

Разбор:

* `std::boolalpha` включает слова `true` и `false` вместо `1` и `0`.
* Выражение с операцией сравнения при выводе нужно ставить в **скобки**: без них `<<` и `<` перепутались бы (подробнее в ошибках ниже).
* `a <= 5` истинно: `5` меньше или равно `5`. `b >= 9` ложно: `8` не достигает `9`.

## Пример 2. Логические операции

```cpp run
#include <iostream>

int main() {
    std::cout << std::boolalpha;
    int age = 25;
    std::cout << (age >= 18 && age < 65) << " " << (age < 18 || age >= 65) << "\n";
    std::cout << !(age < 18) << " " << (3 + 4 > 6 && 2 * 3 == 6) << "\n";
    std::cout << ((true || false) && false) << "\n";
}
```
```output
true false
true true
false
```

Разбор:

* Возраст 25: условие «от 18 до 64» истинно, условие «моложе 18 или от 65» ложно.
* `!(age < 18)` меняет `false` на `true`.
* В `(3 + 4 > 6 && 2 * 3 == 6)` сначала считается арифметика (`7` и `6`), затем сравнения (`7 > 6` и `6 == 6`) и в конце `&&`.
* В последней строке скобки заставили сначала вычислить `true || false`, и результат стал другим, чем без них.

## Пример 3. Дробные числа и строки

```cpp run
#include <cmath>
#include <iostream>
#include <string>

int main() {
    std::cout << std::boolalpha;
    std::cout << (0.1 + 0.2 == 0.3) << " " << (std::abs(0.1 + 0.2 - 0.3) < 1e-9) << "\n";

    std::string x = "apple";
    std::string y = "banana";
    std::cout << (x == "apple") << " " << (x < y) << " " << (x == y) << "\n";
}
```
```output
false true
true true false
```

Разбор:

* `0.1 + 0.2 == 0.3` ложно: дробные числа хранятся приближённо (урок 5), и сумма чуть-чуть отличается от `0.3`. Поэтому дробные числа сравнивают так: разность по модулю (`std::abs` из `<cmath>`) меньше малого допуска, например `1e-9`.
* Строки сравниваются по содержимому: `x == "apple"` истинно. Операция `<` сравнивает по алфавиту (точнее, по кодам символов): `"apple"` стоит раньше `"banana"`.

## Пример 4. Вычисление «до первого ответа»

```cpp run
#include <iostream>

int main() {
    std::cout << std::boolalpha;
    int d = 0;
    std::cout << (d != 0 && 10 / d > 1) << "\n";
}
```
```output
false
```

Левая часть `d != 0` ложна, значит, весь `&&` ложен, и правая часть `10 / d > 1` не вычисляется: деления на ноль нет. Если поменять части местами, `10 / d > 1 && d != 0`, программа попробует разделить на ноль и получит неопределённое поведение.

**Попробуйте.** Выясните, попадает ли число 100 в диапазон от 1 до 100 включительно, и в диапазон от 1 до 100 не включая верхнюю границу. Затем напишите выражение «число делится на 4, но не делится на 100» (подсказка: остаток `%`). Наконец, замените `==` на `=` в одном сравнении и посмотрите, что произойдёт.

## Точные правила

* Результат сравнения и логических операций - значение типа `bool`. При печати без `std::boolalpha` это `1` и `0`.
* **Приоритет** (от высокого к низкому): `!`, затем арифметика (`* / %`, `+ -`), затем сравнения `< <= > >=`, затем `== !=`, затем `&&`, затем `||`. Операции одного приоритета выполняются слева направо.
* **Скобки** меняют порядок и показывают читателю ваше намерение. Смесь `&&` и `||` без скобок вызывает предупреждение компилятора `'&&' within '||'`.
* **Вычисление «до первого ответа»** (short-circuit): для `a && b` значение `b` вычисляется, только если `a` истинно; для `a || b` - только если `a` ложно. Это можно использовать, чтобы защититься от ошибок: проверка стоит слева, опасная операция справа.
* **Цепочка сравнений** `1 < x < 10` не проверяет диапазон. Сначала считается `1 < x` (`bool`), и потом он сравнивается с `10`. Компилятор clang сообщает об этом как об ошибке `chained comparison 'X < Y < Z' does not behave the same as a mathematical expression`, g++ - предупреждением. Пишите `1 < x && x < 10`.
* **Дробные числа.** Сравнивать `double` через `==` нельзя из-за погрешности; сравнивают разность с допуском: `std::abs(a - b) < 1e-9`.
* **Строки** `std::string` сравниваются операторами `==`, `!=`, `<`, `>` по содержимому: `==` проверяет, что все символы совпали, `<` задаёт порядок по кодам символов (для латиницы - по алфавиту, заглавные буквы раньше строчных).
* **Знаковые и беззнаковые числа.** `size()` возвращает беззнаковое число, а `int` знаковое. При сравнении `int` с `size()` значение `-1` превращается в огромное беззнаковое число, и сравнение даёт неожиданный результат (`-1 < s.size()` ложно). Компилятор предупреждает: `comparison of integers of different signs`. Преобразуйте явно: `static_cast<int>(s.size())`.
* **Присваивание в выражении.** `x = 5` - это присваивание, оно возвращает присвоенное значение (`5`). Выражение `(x = 5)` не сравнивает, а меняет `x`.

## Типичные ошибки

**1. Цепочка сравнений вместо двух.**

```cpp
std::cout << (1 < t < 3) << "\n";
```

```text
main.cpp:4:25: error: chained comparison 'X < Y < Z' does not behave the same as a mathematical expression [-Wparentheses]
    4 |     std::cout << (1 < t < 3) << "\n";
      |                         ^
```

Компилятор сразу объясняет, что запись не имеет математического смысла. Для `t = 5` выражение `1 < t` даёт `true` (то есть `1`), и затем сравнивается `1 < 3`: результат тоже `true`, хотя пять не лежит в диапазоне от 1 до 3. Правильно: `1 < t && t < 3`.

**2. `<<` и `>` без скобок.**

```cpp
std::cout << a > 2;
```

```text
main.cpp:4:20: warning: overloaded operator << has higher precedence than comparison operator [-Woverloaded-shift-op-parentheses]
    4 |     std::cout << a > 2;
      |     ~~~~~~~~~~~~~~ ^ ~
main.cpp:4:20: error: invalid operands to binary expression ('ostream' and 'int')
```

Сначала выполняется `std::cout << a`, и результатом (поток) пытаются сравнить с числом `2`. Предупреждение прямо говорит про приоритет и просит скобки. Пишите `std::cout << (a > 2);`.

**3. Знак `=` вместо `==`.** Запись `(x = 5)` не спрашивает «x равно пяти?», а кладёт `5` в `x` и возвращает `5`, то есть «истину». Из-за этого значение переменной тихо портится. Для вопроса «равно ли» используйте `==`.

**4. Смесь `&&` и `||` без скобок.**

```text
main.cpp:22:33: warning: '&&' within '||' [-Wlogical-op-parentheses]
   22 |     std::cout << (true || false && false) << " " << ((true || false) && false) << "\n";
      |                        ~~ ~~~~~~^~~~~~~~
```

Программа верна по правилам приоритета (`&&` сильнее), но читателю трудно понять намерение. Компилятор предлагает поставить скобки: сделайте это.

**5. Сравнение `int` с `size()`.**

```cpp
int i = -1;
std::string s = "abc";
std::cout << (i < s.size()) << "\n";
```

```text
main.cpp:6:21: warning: comparison of integers of different signs: 'int' and 'size_type' (aka 'unsigned long') [-Wsign-compare]
    6 |     std::cout << (i < s.size()) << "\n";
      |                   ~ ^ ~~~~~~~~
```

Программа напечатает `0`, хотя `-1 < 3`: отрицательное число превратилось в беззнаковое и стало огромным. Предупреждение здесь не пустяк. Приведите `size()` к `int`: `i < static_cast<int>(s.size())`.

**6. Дробные числа через `==`.** `0.1 + 0.2 == 0.3` ложно. Сравнивайте через допуск.

**7. Опасная проверка слева.** В `10 / d > 1 && d != 0` деление выполняется раньше проверки. Ставьте защиту **слева**: `d != 0 && 10 / d > 1`.

## Итоги

* Сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают `bool`; результат сравнения при выводе нужно брать в скобки.
* Логические операции: `&&` («и»), `||` («или»), `!` («не»). Приоритет: `!`, потом `&&`, потом `||`; скобки решают всё.
* Диапазон записывается двумя сравнениями: `x >= a && x < b`, а не `a <= x < b`.
* `&&` и `||` вычисляют правую часть только при необходимости: проверку ставьте слева от опасной операции.
* Дробные числа сравнивают через допуск, `int` с `size()` - после явного преобразования.
* `==` сравнивает, `=` присваивает.

Вы получили логические значения. Использовать их для выбора между действиями программа научится в [следующем уроке про `if` и `else`](lesson:cpp.from-zero.if-else), где значения `bool` будут решать, какой код выполнять.

## Для тех, кто уже программирует

* Результат сравнения в C++ - настоящий `bool`, но он тесно связан с `int`: `true` равно `1`, `false` равно `0`, и `bool` участвует в арифметике. Отсюда ловушка `1 < x < 10`, которая в Python работает «по-математически», а в C++ - нет.
* Операторы `&&` и `||` вычисляются слева направо с коротким замыканием, как в Java, C# и JavaScript. Результат всегда `bool`, а не одно из операндов (в отличие от Python и JavaScript).
* Операторы `and`, `or`, `not` - допустимые синонимы `&&`, `||`, `!` в C++, но в обычном коде используют символы.
* Сравнение знакового и беззнакового целого превращает знаковое в беззнаковое: `-1 < 1u` ложно. Это источник многих ошибок; предупреждение `-Wsign-compare` включается ключами `-Wall -Wextra`. В C++20 есть безопасные функции `std::cmp_less` и подобные из `<utility>`.
* Присваивание в выражении возвращает значение: `if (x = 5)` компилируется (с предупреждением `-Wparentheses`). Раньше от этой опечатки защищались записью `5 == x`; современные компиляторы предупреждают сами.
* Сравнение `double` через `==` допустимо, если значения точно получены одинаково (например, константы); в остальных случаях используют допуск или относительную погрешность.
* `std::string` сравнивается лексикографически по байтам; для регистронезависимого или локализованного сравнения нужны отдельные средства.

## Приоритет и «таблица истинности»

Это необязательный раздел: для заданий он не нужен.

Операции `&&` и `||` называют булевыми, и их поведение описывает таблица истинности: `&&` истинно только при двух истинных операндах, `||` ложно только при двух ложных. На практике важнее законы де Моргана: `!(a && b)` равно `!a || !b`, а `!(a || b)` равно `!a && !b`. Их удобно применять, когда условие «не подходит ничего из списка» нужно переписать в понятную форму: вместо `!(x < 0 || x > 100)` можно написать `x >= 0 && x <= 100`.

Вычисление «до первого ответа» - не оптимизация, а гарантия языка: код вроде `p != nullptr && p->value > 0` в больших программах опирается на то, что правая часть не будет выполнена при ложной левой. В отличие от него, побитовые операторы `&` и `|` всегда вычисляют обе части, и путать их с `&&` и `||` опасно. Побитовые операции, а также указатели и нулевые значения разбираются в курсах «C++: первые шаги» и «Язык и стандартная библиотека».
