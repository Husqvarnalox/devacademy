## Зачем это нужно

Текст встречается в программах постоянно: имена, адреса, названия товаров. Часто нужно узнать, сколько в нём символов, взять первую букву для инициалов или приписать к слову окончание. Все эти действия строятся на трёх простых вещах: длина строки, номер символа и склейка.

## Одна новая идея: строка - это последовательность символов с номерами, которые начинаются с нуля

`std::string` хранит символы подряд, один за другим. У каждого символа есть **индекс** - его номер в строке. Нумерация начинается с **нуля**, а не с единицы: у слова `kiwi` символы имеют индексы 0, 1, 2, 3.

```
k  i  w  i
0  1  2  3
```

Три базовых действия:

* `word.size()` - длина строки: число символов. У `kiwi` это `4`. Точка здесь значит «у этой строки вызвать действие»: `size` - действие, скобки обязательны.
* `word[i]` - символ с индексом `i`. Результат имеет тип `char`. Для `kiwi` значение `word[0]` - это `'k'`.
* `a + b` - **склейка** (конкатенация) двух строк: получается новая строка, где за символами `a` идут символы `b`. Прибавить к существующей строке можно через `+=`.

Последний символ имеет индекс `size() - 1`: если в строке четыре символа, то последний - с номером 3.

Теперь о самом важном. Если запросить символ с индексом, которого нет (например, `word[10]` в строке из четырёх символов), оператор `[]` не проверит границы и вернёт то, что лежит в памяти рядом. Это **неопределённое поведение** (UB): программа может напечатать мусор, а может упасть. Для проверки границ у строки есть метод `at(i)`: он делает то же самое, что `[]`, но при неверном индексе останавливает программу с понятным сообщением вместо тихой порчи данных.

## Пример 1. Длина, символы и `at`

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string word = "banana";
    std::cout << word.size() << "\n";
    std::cout << word[0] << " " << word[5] << "\n";
    std::cout << word.at(2) << "\n";
}
```
```output
6
b a
n
```

Разбор:

* `word.size()` возвращает `6`: в слове `banana` шесть символов.
* `word[0]` - первая буква `b`, `word[5]` - последняя `a`. Между ними в `std::cout` стоит пробел `" "`.
* `word.at(2)` - символ с индексом 2, это `n`. Результат тот же, что у `word[2]`, но с проверкой границ.

## Пример 2. Склейка

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string first = "Анна";
    std::string last = "Иванова";
    std::string full = first + " " + last;
    std::cout << full << "\n";

    full += "!";
    std::cout << full << "\n";

    std::string empty;
    std::cout << empty.empty() << " " << full.empty() << "\n";
}
```
```output
Анна Иванова
Анна Иванова!
1 0
```

Разбор:

* `first + " " + last` склеивает три части: имя, пробел и фамилию. Пробел - тоже строка, и его нужно добавить самому.
* `full += "!"` дописывает восклицательный знак в конец `full`.
* Объявление `std::string empty;` без значения создаёт пустую строку (так для `std::string` можно, в отличие от `int`). Метод `empty()` возвращает `true` (напечатается `1`), если символов нет.

## Пример 3. Ошибки, которые полезно увидеть

Этот код соберётся, но завершится аварийно. Метод `at` проверил границу и остановил программу:

```cpp
std::string word = "banana";
std::cout << word.at(10) << "\n";
```

```text
libc++abi: terminating due to uncaught exception of type std::out_of_range: basic_string
```

Сообщение называет тип исключения `std::out_of_range` («выход за границы»). Если у вас стоит `g++`, текст другой (`terminate called after throwing an instance of 'std::out_of_range'`), но смысл тот же. Исключения мы разберём в уроке 22; пока достаточно знать, что такое завершение - защита, а не «поломка».

Тот же индекс с оператором `[]` не проверяется:

```cpp
std::cout << word[10] << "\n";
```

Здесь результат не определён: программа может напечатать любой символ или завершиться. Именно поэтому в примерах, где индекс вычисляется или приходит из ввода, мы будем пользоваться `.at()`.

**Попробуйте.** Для строки `"orange"` напечатайте длину и последнюю букву. Затем замените `word[0]` на `word.at(6)` и прочитайте сообщение при запуске. Наконец, соберите строку `"orange" + std::string("!")` и сравните с `"orange" + "!"`: что из этого собирается?

## Точные правила

* **Индексы** идут от `0` до `size() - 1`. Индекс `size()` указывает на служебный нуль-символ, а любой больший индекс (как и отрицательный) выходит за границы строки: для `[]` это неопределённое поведение, для `at()` - исключение.
* **`size()` возвращает беззнаковое число** (тип `std::size_t`). Выражение `s.size() - 1` для **пустой** строки даёт не `-1`, а огромное число (`18446744073709551615` на 64-битных системах), и `s[s.size() - 1]` читает память далеко за строкой. Прежде чем брать последний символ, проверьте `!s.empty()` (условия - в уроке 12).
* **`empty()`** возвращает `true`, если в строке нет символов.
* **`[]`** границы не проверяет: выход за них - неопределённое поведение. **`at(i)`** проверяет и при ошибке бросает `std::out_of_range`.
* Символ в строке можно заменить: `word[0] = 'B';` меняет первую букву.
* **Склейка**: `std::string + std::string`, `std::string + "текст"`, `"текст" + std::string` и `std::string + char` допустимы. Два литерала в кавычках склеить через `+` нельзя: `"Привет" + ", мир"` - ошибка (хотя два литерала можно написать рядом без знака, и компилятор склеит их сам: `"Привет" ", мир"`).
* **Размер в байтах.** `std::string` хранит байты. Латинская буква и цифра занимают один байт, русская буква в UTF-8 - два. Поэтому `std::string s = "привет"; s.size()` равно `12`, а `s[0]` - не буква `п`, а лишь первая половина её кода. Для упражнений курса индексы и длина используются с латиницей и цифрами; русский текст мы печатаем и читаем целиком.
* **`length()`** - синоним `size()`; в курсе мы используем `size()`.
* Строка в C++ **изменяема**, а присваивание копирует содержимое: `std::string b = a;` даёт независимую копию.

## Типичные ошибки

**1. Индекс на единицу больше.** В слове из шести символов последний индекс - 5, а не 6. `word[word.size()]` - это уже не буква: там лежит служебный нуль-символ, и на экране появится «пустота». Метод `word.at(word.size())` в таком случае остановил бы программу. Правильно: `word[word.size() - 1]`.

**2. Нумерация с единицы.** `word[1]` - это **вторая** буква. Первая буква - `word[0]`.

**3. Склейка двух литералов.**

```cpp
std::string a = "Привет" + ", мир";
```

```text
main.cpp:5:36: error: invalid operands to binary expression ('const char[13]' and 'const char[9]')
    5 |     std::string a = "Привет" + ", мир";
      |                     ~~~~~~~~ ^ ~~~~~~~
```

Компилятор перечисляет типы операндов: оба `const char[...]` - обычные тексты в кавычках, а не `std::string`; сложить их нельзя. Напишите `std::string("Привет") + ", мир"` или поместите одну из частей в переменную `std::string`.

**4. Последний символ пустой строки.** Для `std::string s;` выражение `s[s.size() - 1]` обращается к индексу `18446744073709551615`. Всегда проверяйте `s.empty()` или пользуйтесь `.at()`: исключение лучше мусора.

**5. Индексы в русском тексте.** `std::string name = "Анна"; name[0]` не вернёт `А`: это один из двух байтов буквы. Размер `name.size()` равен 8, а не 4. Для упражнений с индексами берите латинские слова.

**6. Путаница `size` и `size()`.** Скобки обязательны: `word.size`, без скобок, не вызывает действие и не компилируется.

**7. Склейка со строкой и числом.** `"Итого: " + 5` не работает как склейка: число не превращается в текст. Для вывода используйте цепочку `std::cout << "Итого: " << 5;`, а превращение чисел в строки - в уроке 9.

## Итоги

* `s.size()` - длина строки в байтах, `s.empty()` - проверка на пустоту.
* `s[i]` - символ с индексом `i`; индексы начинаются с 0, последний - `s.size() - 1`.
* `[]` не проверяет границы (неопределённое поведение), `at(i)` проверяет и аварийно останавливает программу при ошибке.
* `a + b` склеивает строки, `+=` дописывает; два литерала в кавычках складывать нельзя.
* Индексы и `size()` надёжны для латиницы; русский текст в этом курсе мы только печатаем и читаем целиком.

В следующем уроке ([Ввод данных](lesson:cpp.from-zero.reading-input)) программа научится получать данные из ввода: имя, число или цену, и результат будет зависеть не от текста в коде, а от пользователя.

## Для тех, кто уже программирует

* `std::string` - изменяемая строка-значение: присваивание и передача по значению копируют данные. Нет интернирования и пула строк; сравнение `==` сравнивает содержимое.
* `s[i]` и `s.at(i)`: первый не проверяет границы (UB), второй бросает `std::out_of_range`. Отрицательных индексов, как в Python, нет; `s.back()` и `s.front()` дают последний и первый символы (для пустой строки - UB).
* `size()` возвращает `std::size_t` - беззнаковый тип. `s.size() - 1` у пустой строки заворачивается в огромное число, а сравнение `int i < s.size()` вызывает предупреждение `-Wsign-compare`. Это одна из самых частых ловушек.
* Строка - последовательность **байтов**, без знания о кодировке. `size()` у `"привет"` - 12 в UTF-8; для работы с кодовыми точками нужны сторонние библиотеки или `std::u32string`. В стандартной библиотеке нет `toUpper` для Unicode.
* Литерал `"text"` - не `std::string`, а `const char[N]`: `"a" + "b"` не компилируется. Суффикс `"text"s` (после `using namespace std::literals;`) даёт `std::string`.
* Склейка в цикле `s = s + x` создаёт временные строки; `s += x` дописывает на месте. Для сборки больших строк это важно.

## Как устроена строка внутри

Это необязательный раздел: для заданий он не нужен.

Типичный `std::string` содержит три значения: указатель на блок памяти с символами, текущую длину и ёмкость (сколько символов блок вмещает). Когда вы дописываете символы и ёмкости не хватает, строка выделяет блок побольше, копирует туда символы и освобождает старый: поэтому дописывание обычно быстрое, а изредка медленное. Короткие строки (примерно до 15-22 символов в зависимости от реализации) хранятся прямо внутри самого объекта без выделения памяти - это называется оптимизацией коротких строк (SSO).

В конце блока всегда лежит нулевой символ `'\0'`, чтобы строку можно было передать функциям языка C; он не входит в `size()`. Поэтому чтение `s[s.size()]` стандарт разрешает (оно даёт `'\0'`), но для вашей программы оно не имеет смысла. О том, почему `at()` медленнее `[]`, и о многобайтных кодировках подробно рассказывают курсы «C++: первые шаги» и «C++: язык и стандартная библиотека».
