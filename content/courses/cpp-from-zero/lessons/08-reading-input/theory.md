## Зачем это нужно

До сих пор все значения были записаны прямо в тексте программы. Полезная программа отвечает на то, что ей сообщил человек: имя, цену, количество. Для этого программа **читает ввод**: данные, которые приходят снаружи, с клавиатуры или из файла.

## Одна новая идея: `std::cin >> переменная` берёт следующее значение из ввода и кладёт его в переменную

`std::cin` - парный к `std::cout` объект: `cout` отправляет данные **наружу**, `cin` получает их **изнутри** ввода. Стрелки направлены в разные стороны: `std::cout << значение` («значение уходит в cout»), `std::cin >> переменная` («из cin значение приходит в переменную»). Он живёт в том же заголовке `<iostream>`.

```cpp
int age = 0;
std::cin >> age;
```

Тип переменной определяет, как читать текст: в `int` читается целое число, в `double` - дробное, в `std::string` - слово.

Правила чтения простые:

* Ввод - это поток текста. Значения в нём **разделяются пробелами, табуляциями и переводами строк**. Для `std::cin >>` нет разницы, написаны значения в одной строке или в нескольких.
* Читать можно сразу несколько значений цепочкой: `std::cin >> name >> age >> height;`. Значения берутся из ввода по порядку.
* В `std::string` читается **одно слово**: до первого пробела или перевода строки. Фраза «Анна Иванова» целиком в одну строку этим оператором не читается: в `name` попадёт «Анна», а «Иванова» останется в вводе для следующего чтения.

Переменную перед чтением объявляют **со значением**: `int age = 0;`. Прочитанное значение просто заменит `0`. А если чтение не удастся (например, вместо числа придёт слово), у переменной окажется известное значение, а не мусор из памяти (помните неопределённое поведение из урока 4).

## Как подать ввод своей программе

1. Под редактором откройте вкладку **«Вывод»**.
2. Нажмите на строку **«Ввод программы (stdin)»**: под ней раскроется поле.
3. Впишите в поле весь ввод заранее, например `Anna 30 1.75`. Значения можно разделять пробелами или переводами строк: для `std::cin >>` разницы нет.
4. Нажмите **«Запустить»**.

Программа не останавливается и не ждёт, пока вы что-то напечатаете: всё, что записано в поле, она получает сразу при запуске. Введённый текст в вывод не попадает: если программа печатает приглашение, после него в выводе будет только то, что напечатала сама программа. Если поле пустое, ввод пустой. Пока урок открыт, текст в поле остаётся, так что для следующего запуска достаточно поменять данные.

Кнопка **«Проверить решение»** это поле не использует: она запускает программу на вводе каждого теста по очереди.

## Пример 1. Слово, целое и дробное число

В примерах этого урока вы видите блок «Ввод» (что пользователь ввёл) и блок «Вывод» (что напечатала программа). Эти программы зависят от ввода, поэтому в тексте урока они показаны без запуска: запускайте их у себя и подавайте разные данные.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "?";
    int age = -1;
    double height = -1.0;
    std::cout << "Как вас зовут? ";
    std::cin >> name;
    std::cout << "Возраст и рост? ";
    std::cin >> age >> height;
    std::cout << name << ", " << age << ", " << height << "\n";
}
```

Ввод:

```text
Anna 30 1.75
```

Вывод:

```text
Как вас зовут? Возраст и рост? Anna, 30, 1.75
```

Разбор:

* Три чтения берут из ввода `Anna`, `30` и `1.75` по порядку. Первое чтение положило слово в `name`; второе (цепочка из двух `>>`) - число в `age` и дробь в `height`.
* Приглашения «Как вас зовут?» печатаются до чтения. На экране у пользователя они были бы разделены его вводом, но когда ввод идёт из файла или поданной строки, текст подряд, как здесь.
* Начальные значения `"?"`, `-1`, `-1.0` служат «заглушками». Мы сразу видим, не изменилась ли переменная, если чтение не сработало.

## Пример 2. Пробелы и переводы строк не важны

Для той же программы подойдёт и такой ввод:

```text
Anna
30
1.75
```

Результат тот же: `Anna, 30, 1.75`. Оператор `>>` пропускает все пробелы, табуляции и переводы строк перед следующим значением.

## Пример 3. Слово, не число

Если вместо числа пришёл текст, чтение не удаётся. Ввод:

```text
Anna Ivanova 30
```

Та же программа выведет:

```text
Как вас зовут? Возраст и рост? Anna, 0, -1
```

Объяснение шаг за шагом:

1. `std::cin >> name` читает слово `Anna`.
2. `std::cin >> age` пытается прочитать число, а видит слово `Ivanova`. Чтение не удаётся: `age` становится `0`, а `std::cin` переходит в **состояние ошибки**.
3. В состоянии ошибки все следующие чтения молча ничего не делают, поэтому `height` остался равным `-1`.

Программа не упала и не выдала сообщения: она просто продолжила с неверными данными. Как проверять успех чтения, мы разберём в уроке 12 (условия) и дальше. Пока важно знать, что такое бывает, и поэтому начальные значения переменных нужны.

## Пример 4. Читаем и считаем

```cpp
#include <iostream>

int main() {
    int price = 0;
    int count = 0;
    std::cin >> price >> count;
    std::cout << "Итого: " << price * count << " руб.\n";
}
```

Ввод `45 3`, вывод `Итого: 135 руб.`. Прочитанные значения - обычные переменные: с ними можно делать всё, что вы умеете с числами.

**Попробуйте.** Напишите программу, которая читает два целых числа и печатает их сумму, разность и произведение. Затем подайте на вход `7 xyz` и посмотрите, что станет со вторым числом и с результатами. Наконец, прочитайте в `std::string` фразу из двух слов и убедитесь, что вторая половина не попала в строку.

## Точные правила

* `std::cin >> x` читает значение, подходящее по типу `x`:
  * `int` - целое число с необязательным знаком (`-7`, `+3`, `42`);
  * `double` - число с точкой (`1.75`, `-0.5`) или без неё (`3`);
  * `std::string` - последовательность символов без пробелов;
  * `char` - один непробельный символ.
* Перед значением оператор пропускает пробельные символы (пробелы, табуляции, переводы строк). Читаемое значение заканчивается на первом символе, который не может быть его частью.
* В `int` текст `12abc` читается как `12`; `abc` остаётся для следующего чтения. Текст `1.75` читается в `int` как `1`, а `.75` остаётся во вводе.
* Если значение прочитать нельзя, переменной присваивается `0` (для `int` и `double`), а поток переходит в состояние ошибки. Все следующие чтения ничего не делают, пока состояние ошибки не будет сброшено.
* Если ввод закончился до начала чтения (конец данных), переменная не меняется, а поток переходит в состояние ошибки. Поэтому начальные значения важны: в этом случае они остаются в переменных.
* Выражение `std::cin >> x` возвращает сам `std::cin`, поэтому читать можно цепочкой.
* Переменная, в которую читают, должна быть **изменяемой**: читать в `const` нельзя.
* Дробное число вводится с **точкой**, а не с запятой: `1.75`, а не `1,75`. Запятая прервёт число (прочитается `1`, а `,75` останется).
* Вывод `std::cout` и ввод `std::cin` независимы: `cin` не печатает приглашений, их печатает программа.

## Типичные ошибки

**1. Стрелки в обратную сторону.**

```cpp
std::cin << count;
```

```text
main.cpp:5:14: error: invalid operands to binary expression ('istream' (aka 'basic_istream<char>') and 'int')
    5 |     std::cin << count;
      |     ~~~~~~~~ ^  ~~~~~
```

Компилятор сообщает, что для сочетания «`istream` и `int`» оператора `<<` нет. Затем он перечисляет длинный список подходящих кандидатов; их читать не нужно: смотрите на первую строку. Ввод пишется как `std::cin >> count;`.

**2. Литерал вместо переменной.**

```cpp
std::cin >> "count";
```

```text
main.cpp:5:14: error: invalid operands to binary expression ('istream' (aka 'basic_istream<char>') and 'const char[6]')
```

Читать можно только в переменную, а не в текст в кавычках: значение некуда записывать. Уберите кавычки: `std::cin >> count;`.

**3. Чтение без начального значения.** `int count;` и `std::cin >> count;` работает, пока ввод хороший. Но если чтение не удалось (пустой ввод), в `count` останется мусор, а использование его значения - неопределённое поведение. Пишите `int count = 0;`.

**4. Ожидание, что `cin >>` читает строку целиком.** После `std::string name = ""; std::cin >> name;` и ввода `Анна Иванова` в `name` будет только `Анна`. Вторая половина остаётся во вводе и «выстрелит» при следующем чтении: в число она не превратится, и поток перейдёт в состояние ошибки.

**5. Запятая в дробном числе.** Ввод `1,75` читается в `double` как `1`; `,75` остаётся. Вводите числа с точкой.

**6. Использование значения до чтения.** Если вычисление `price * count` стоит выше, чем `std::cin >> price >> count`, оно посчитает начальные нули. Программа выполняется сверху вниз.

**7. Не тот порядок значений.** Цепочка `std::cin >> price >> count` читает сначала цену, потом количество. Если пользователь вводит их в другом порядке, значения «перепутаются» молча.

## Итоги

* `std::cin >> x` читает следующее значение из ввода в переменную `x` подходящего типа; цепочка `>>` читает несколько значений подряд.
* Значения разделяются пробелами и переводами строк - между ними нет разницы.
* В `std::string` читается одно слово; целую строку с пробелами оператор `>>` не прочитает.
* Если чтение не удалось, число становится `0`, а поток переходит в состояние ошибки: следующие чтения ничего не делают.
* Переменную перед чтением объявляйте со значением, чтобы в неудачном случае не остался мусор.

В следующем уроке ([Преобразование типов](lesson:cpp.from-zero.type-conversion)) вы научитесь превращать числа в дробные и обратно, а также числа в строки и строки в числа. Тогда деление прочитанных целых чисел наконец даст честный дробный результат.

## Для тех, кто уже программирует

* `std::cin >> x` - форматированный ввод: он пропускает пробельные символы, разбирает значение по типу `x` и возвращает поток. Это не `readLine()`: ввод идёт по токенам, а не по строкам. Для строк с пробелами есть `std::getline(std::cin, s)`.
* Ошибка разбора не бросает исключение. Поток получает флаг `failbit`, а числовая переменная - значение `0` (с C++11). Все следующие чтения пропускаются до `std::cin.clear()`. Проверка успеха - `if (std::cin >> x)` или `std::cin.fail()`.
* На конце данных (EOF) переменная не меняется, и поток получает `eofbit` и `failbit`.
* `std::cin` по умолчанию синхронизирован с C-вводом (`stdin`), из-за чего он медленнее на больших объёмах данных. Конкурсные программы вызывают `std::ios::sync_with_stdio(false)` и `std::cin.tie(nullptr)`; в учебных программах этого делать не нужно.
* В отличие от Python `input()` или Java `Scanner.nextLine()`, `cin >>` не требует конца строки и не выбрасывает исключений. Типичная ловушка: после `std::cin >> n` в вводе остаётся перевод строки, и следующий `std::getline` прочитает пустую строку. Это разбирается в уроке 21.
* Бинарные и многобайтные кодировки читаются как есть: `std::string` получает байты.

## Поток ввода изнутри

Это необязательный раздел: для заданий он не нужен.

`std::cin` - объект типа `std::istream`. Он хранит буфер прочитанных, но ещё не разобранных символов и набор флагов состояния: `eofbit` (данные кончились), `failbit` (логическая ошибка разбора) и `badbit` (серьёзный сбой). Оператор `>>` для `int` вызывает разбор: он пропускает пробельные символы, читает подходящие цифры и преобразует их в число. Если подходящих символов нет, устанавливается `failbit`, а значение переменной становится нулём.

Проверку `if (std::cin >> x)` допускает то, что поток умеет преобразовываться в `bool`: он «истинный», если ни `failbit`, ни `badbit` не установлены. Цикл `while (std::cin >> x)` читает данные, пока они есть, и это самая распространённая идиома чтения неизвестного количества значений. Сброс состояния делает `std::cin.clear()`, а пропуск остатка строки - `std::cin.ignore(...)`; эти детали рассматривает курс «C++: первые шаги».
