## Что такое программа

Каждое приложение на телефоне и каждая игра работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Этот текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется C++. На нём написаны браузеры, игровые движки, базы данных и многие программы, которым важна скорость; он строгий и даёт много власти, поэтому мы будем идти медленно и объяснять, откуда берутся ошибки.

Процессор компьютера не понимает текст на C++. Он понимает только свои собственные команды в виде чисел - **машинный код**. Поэтому нужен ещё один инструмент - **компилятор**: он читает исходный код, проверяет его и переводит в машинный код, который записывает в файл. Этот файл можно запускать как обычное приложение. Путь получается такой: исходный код → компилятор → исполняемый файл → запуск.

В приложении вам не нужно вызывать компилятор вручную. Вы пишете текст в редакторе, нажимаете «Запустить», и приложение само компилирует и запускает программу. Как именно устроена сборка внутри, показывает раздел «Углубление» в конце урока и курс «C++: первые шаги».

## Одна новая идея: у программы на C++ есть каркас, а команды лежат внутри

Самая маленькая программа, которая что-то печатает, выглядит так:

```cpp
#include <iostream>

int main() {
    std::cout << "Привет\n";
}
```

В ней три части, и каждую пока достаточно понимать в одну строку:

1. `#include <iostream>` - «подключить готовую часть, которая умеет вводить и выводить текст». Без этой строки компилятор не знает, что такое `std::cout`. Как это работает, расскажет курс «C++: первые шаги»; сейчас достаточно помнить, что строка нужна.
2. `int main() { ... }` - «отсюда начинается программа». Слово `main` значит «главная». Всё, что стоит между фигурными скобками `{ }`, выполняется сверху вниз. Что означает слово `int` перед `main`, мы узнаем в уроке 17 о функциях; сейчас это просто часть каркаса.
3. `std::cout << "Привет\n";` - сама команда: «вывести текст на экран». `cout` (читается «си-аут») - это окно, куда программа печатает; `<<` - стрелка, которая «отправляет» текст в это окно; `"Привет\n"` - сам текст, а `\n` - символ перевода строки; `std::` показывает, что имя `cout` взято из стандартной библиотеки, готового набора средств, который поставляется вместе с C++.

Свои команды вы пишете только между фигурными скобками `main`. Остальные строки пока не трогаем.

<!-- section: examples -->
## Пример 1. Печать одной строки

```cpp run
#include <iostream>

int main() {
    std::cout << "Касса открыта\n";
}
```
```output
Касса открыта
```

Разбор по строкам:

* `#include <iostream>` - подключает ввод-вывод. Угловые скобки означают «готовая часть библиотеки», а не ваш файл.
* Пустая строка ничего не делает: она нужна только для читаемости.
* `int main() {` - начало главной части. Фигурная скобка открывает блок, а закрывающая скобка на последней строке его заканчивает.
* `std::cout << "Касса открыта\n";` - команда: напечатать текст. Точка с запятой в конце заканчивает команду. Без `\n` следующий вывод продолжился бы на той же строке.
* `}` закрывает `main`. Когда команды закончились, программа завершается.

## Пример 2. Несколько команд подряд

```cpp run
#include <iostream>

int main() {
    std::cout << "Первая строка\n";
    std::cout << "Вторая строка\n";
    std::cout << "Третья строка\n";
}
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет. Каждая команда занимает свою строку и заканчивается точкой с запятой.

**Попробуйте.** Поменяйте местами две строки с `std::cout` и предскажите вывод до запуска. Затем уберите `\n` из первой команды и посмотрите, как изменится результат. Потом удалите точку с запятой в конце одной команды и прочитайте, что ответит компилятор (разбор таких сообщений - в разделе об ошибках и в следующем уроке).

## Точные правила

* Выполнение начинается с `main`. Если функции `main` нет или она записана иначе (например, `Main`), программа не соберётся.
* Каждая команда заканчивается точкой с запятой `;`. Исключение - строки, которые только открывают или закрывают блок (`{` и `}`) и строки с `#include`.
* Фигурные скобки идут парами: у каждой открывающей `{` должна быть закрывающая `}`.
* **Строковый литерал** - текст, записанный прямо в программе, в двойных кавычках: `"Касса открыта\n"`. Он печатается как есть, без кавычек. Внутри допустимы русские буквы, пробелы, цифры и знаки.
* Регистр важен: `std`, `cout`, `main` пишутся со строчной буквы. `Std::Cout` или `Main` не заработают.
* Двойное двоеточие `::` в `std::cout` читается как «из»: `cout` из `std`. Слово `std` - название пространства имён, то есть области, в которой лежат все имена стандартной библиотеки.
* Мы всегда пишем `std::` и не используем строку `using namespace std;`, которая встречается в старых учебниках. Она позволяет писать `cout` без префикса, но в больших программах имена из разных библиотек совпадают и ссылаются не на то, что вы имели в виду; префикс показывает, откуда имя пришло. Лишние четыре символа - небольшая цена за ясность.
* Отступы (четыре пробела внутри блока) компилятору не нужны, но читателю очень помогают. Редактор расставляет их автоматически.
* Пустые строки между командами допустимы и улучшают чтение.

## Типичные ошибки

Сообщение компилятора всегда начинается с имени файла, номера строки и номера столбца: `main.cpp:5:28: error: ...`. Под сообщением компилятор печатает строку кода и знак `^`, который указывает место, где он понял, что что-то не так. Ниже сообщения приведены в том виде, в каком их печатает компилятор clang. Если в вашей системе стоит `g++`, слова будут другими, но номер строки и смысл те же.

**1. Пропущена точка с запятой.**

```cpp
std::cout << "Привет";
std::cout << "мир\n"
}
```

```text
main.cpp:5:28: error: expected ';' after expression
    5 |     std::cout << "мир\n"
      |                         ^
      |                         ;
1 error generated.
```

Команда не закончена: компилятор ждёт `;` и показывает место сразу после закрывающей кавычки. Номер строки указывает на предыдущую команду, а не на скобку, которая шла следом: компилятор замечает проблему, только дочитав до следующей строки. Добавьте `;`.

**2. Забыт префикс `std::`.**

```cpp
cout << "Привет\n";
```

```text
main.cpp:4:5: error: use of undeclared identifier 'cout'; did you mean 'std::cout'?
    4 |     cout << "Привет\n";
      |     ^~~~
      |     std::cout
```

`use of undeclared identifier` значит «это имя не объявлено», то есть компилятор такого не знает. Он сам предлагает исправление: `did you mean 'std::cout'`. Поставьте `std::` перед `cout`.

**3. Забыт `#include <iostream>`.**

```cpp
int main() {
    std::cout << "Привет\n";
}
```

```text
main.cpp:2:5: error: use of undeclared identifier 'std'
    2 |     std::cout << "Привет\n";
      |     ^
```

Без `#include` компилятор не знает даже слова `std`. Первая строка файла должна подключать `<iostream>`.

**4. Не закрыта фигурная скобка.**

```text
main.cpp:4:35: error: expected '}'
    4 |     std::cout << "Привет\n";
      |                             ^
main.cpp:3:12: note: to match this '{'
    3 | int main() {
      |            ^
```

Компилятор дочитал файл до конца и не нашёл парную `}`. Вторая строка (`note`) показывает, какая именно скобка осталась без пары. Посчитайте скобки: сколько открыто, столько должно быть закрыто.

**5. `main` записан с заглавной буквы.**

```text
Undefined symbols for architecture arm64:
  "_main", referenced from:
      <initial-undefines>
ld: symbol(s) not found for architecture arm64
```

Здесь нет номера строки: ошибка возникла не в тексте, а на последнем этапе сборки, когда программа не нашла, с чего начинать (в Linux сообщение звучит как `undefined reference to 'main'`). Если сообщение не называет файл и строку, проверьте, что функция называется `main` в точности.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; компилятор проверяет его и переводит в машинный код.
* Минимальная программа на C++: подключение `#include <iostream>` и функция `int main()`, внутри которой лежат команды. Они выполняются сверху вниз.
* `std::cout << "текст\n";` печатает строку и переходит на следующую; кавычки на экран не попадают.
* Каждая команда заканчивается точкой с запятой, регистр букв важен, а имена стандартной библиотеки пишутся с префиксом `std::`.

Это основа: любая следующая программа в курсе устроена так же, меняется только содержимое `main`. В следующем уроке ([Как читать сообщения об ошибках](lesson:cpp.from-zero.compiler-errors)) вы научитесь читать сообщения компилятора и исправлять ошибки по одной.

## Для тех, кто уже программирует

* Точка входа - `int main()` (можно `int main(int argc, char* argv[])`); `return 0;` в конце `main` писать не нужно: компилятор вставит его сам, это единственная функция с таким правилом. Коды возврата ненулевого значения сообщают об ошибке операционной системе.
* `std::cout << a << b` - цепочка операторов вывода, а не функция с аргументами, как `print` в Python. `<<` возвращает тот же поток, поэтому цепочка работает слева направо.
* `\n` против `std::endl`: `std::endl` ещё и сбрасывает буфер вывода, что медленнее; в курсе используется `\n`.
* Точка с запятой обязательна, блоки выделяются фигурными скобками, отступы не значимы.
* Компиляция даёт нативный исполняемый файл: ни интерпретатора, ни виртуальной машины, ни сборщика мусора. Ошибки типов, опечатки в именах и нехватка `;` ловятся до запуска.
* Стандартные имена лежат в `std::`; `using namespace std;` в курсе не используется.
* Заголовки (`#include`) - текстовая подстановка препроцессора, а не система модулей (модули C++20 в курсе не рассматриваются).

## Что происходит при нажатии «Запустить»

Это необязательный раздел: для заданий он не нужен.

Приложение вызывает компилятор примерно такой командой:

```text
clang++ -std=c++23 -pthread -O2 -Wall -Wextra main.cpp -o prog
```

Затем запускает `prog`. Ключ `-std=c++23` выбирает версию языка, `-O2` просит компилятор оптимизировать машинный код, а `-Wall -Wextra` включают предупреждения о подозрительных местах: они приходят в следующем уроке. Если на компьютере нет clang, используется `g++`; результат тот же.

Внутри команда делает три шага: **препроцессор** подставляет вместо `#include <iostream>` текст заголовка, **компилятор** превращает код в машинные команды (объектный файл), а **компоновщик** (linker) собирает объектный файл и библиотеку в один исполняемый файл. Ошибки вроде `expected ';'` относятся ко второму шагу и появляются **до** запуска: сборка останавливается, программа не стартует, и частично выполненного результата нет. Ошибка из пятого примера выше (нет `main`) относится к третьему шагу. Подробно эти этапы разбирает курс «C++: первые шаги».
