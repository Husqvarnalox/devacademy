## Зачем это нужно

Студент - это имя **и** балл. Товар - название **и** цена. Пока такие данные лежат в отдельных переменных (`names[i]`, `scores[i]`), связь между ними держится только в вашей голове, и её легко разорвать: отсортировать одно и забыть другое. Нужен способ объявить: «вот новый тип, в нём есть имя и балл», и дальше работать с ним как с одним значением. В C++ для этого служит **структура** (`struct`).

## Одна новая идея: struct - это новый тип из нескольких именованных частей

```cpp
struct Student {
    std::string name;
    int score = 0;
};
```

Это объявление **типа**: оно описывает, какие части есть у любого студента, но самого студента не создаёт. Части называются **полями**. После закрывающей скобки обязательно стоит точка с запятой.

Создание **объекта** (конкретного студента) и обращение к полям через точку:

```cpp
Student s = {"Анна", 92};
std::cout << s.name << " " << s.score << "\n";
s.score = 95;
```

Объект - значение типа `Student`, как `int` - значение типа `int`. Списком в фигурных скобках поля заполняются по порядку: сначала `name`, затем `score`.

К структуре можно добавить **функцию-член**: функцию, которая объявлена внутри и работает с полями того объекта, у которого её вызвали:

```cpp
struct Student {
    std::string name;
    int score = 0;

    bool passed() const {
        return score >= 60;
    }
};

// ...
if (s.passed()) { ... }
```

Внутри функции-члена поле называют просто по имени: `score`. Слово `const` после скобок означает «эта функция только читает объект и не меняет его».

## Пример 1. Структура и объекты

```cpp run
#include <iostream>
#include <string>

struct Student {
    std::string name;
    int score = 0;
};

int main() {
    Student a = {"Анна", 92};
    Student b = a;
    b.name = "Борис";
    b.score = 71;

    std::cout << a.name << ": " << a.score << "\n";
    std::cout << b.name << ": " << b.score << "\n";
}
```
```output
Анна: 92
Борис: 71
```

Разбор:

* `Student a = {"Анна", 92};` - объект с начальными значениями полей.
* `Student b = a;` копирует **весь** объект: у `b` появляются собственные `name` и `score`.
* Изменение `b` не меняет `a`: это два независимых значения. Так же вели себя `int` и `std::string`.

## Пример 2. Функции-члены

```cpp run
#include <iostream>
#include <string>

struct Account {
    std::string owner;
    int balance = 0;

    void deposit(int amount) {
        balance += amount;
    }

    std::string summary() const {
        return owner + ": " + std::to_string(balance);
    }
};

int main() {
    Account acc = {"Мария", 100};
    acc.deposit(50);
    acc.deposit(25);
    std::cout << acc.summary() << "\n";

    Account empty;
    std::cout << "[" << empty.owner << "] " << empty.balance << "\n";
}
```
```output
Мария: 175
[] 0
```

Разбор:

* `deposit` **меняет** поле `balance` объекта `acc`, поэтому без `const`.
* `summary` только читает поля, поэтому помечена `const`.
* Объект `empty` создан без списка значений. Его `owner` - пустая строка (так ведёт себя `std::string`), а `balance` - `0`, потому что в объявлении поля стоит `= 0`.

## Пример 3. Структуры в векторе и в функциях

```cpp run
#include <iostream>
#include <string>
#include <vector>

struct Item {
    std::string name;
    int price = 0;
};

int totalPrice(const std::vector<Item>& items) {
    int sum = 0;
    for (const Item& it : items) {
        sum += it.price;
    }
    return sum;
}

int main() {
    std::vector<Item> basket;
    basket.push_back({"Хлеб", 40});
    basket.push_back({"Сыр", 300});
    basket.push_back({"Чай", 120});

    for (const Item& it : basket) {
        std::cout << it.name << " - " << it.price << "\n";
    }
    std::cout << "Итого: " << totalPrice(basket) << "\n";
}
```
```output
Хлеб - 40
Сыр - 300
Чай - 120
Итого: 460
```

Разбор:

* `std::vector<Item>` хранит объекты, а не числа: элемент вектора может быть значением любого типа.
* `const Item& it` в range-for - та же ссылка, что в уроке 18: объект не копируется и не меняется.
* Внутрь `totalPrice` вектор передан по константной ссылке, как в уроке 18.

## Пример 4. Поле без значения

Следующий фрагмент показан без запуска: его результат меняется от запуска к запуску.

```cpp
struct Student {
    std::string name;
    int score;
};

Student s;
s.name = "A";
std::cout << s.name << " " << s.score << "\n";
```

```text
A 1863100328
A 1794795448
```

Поле `score` не получило значения, и программа прочитала то, что оказалось в памяти. Это неопределённое поведение из урока 4: два запуска дают разные числа, а иногда выглядит, будто «всё работает». Компилятор здесь не предупредил. Лекарство - задать начальное значение прямо в объявлении поля: `int score = 0;`.

**Попробуйте.** Опишите структуру `Rectangle` с полями `width` и `height` и функцией-членом `area() const`. Создайте вектор прямоугольников и найдите самый большой по площади. Добавьте в `Student` функцию-член `void addBonus(int points)`, которая не позволяет баллу превысить 100.

## Точные правила

* **Объявление:** `struct Имя { поля и функции };` - с обязательной `;` после `}`. Имена типов принято писать с большой буквы.
* **Поле** объявляется как переменная внутри структуры: `тип имя;` или `тип имя = значение;`. Значение в объявлении - значение по умолчанию для новых объектов.
* **Объект** создаётся как переменная типа структуры: `Student s;` (значения по умолчанию) или `Student s = {"Анна", 92};` (значения по порядку полей). Значений не может быть больше, чем полей. Пропущенные последние поля получают значения по умолчанию из их объявления (или нули, если значения нет).
* **Начальные значения.** Поле типа `int`, `double`, `bool`, `char` без `= значение` и без списка при создании объекта содержит мусор; чтение такого поля - неопределённое поведение. `std::string` и `std::vector` сами становятся пустыми.
* **Обращение к полю:** `объект.поле`. Для функции-члена: `объект.функция(аргументы)`.
* **Функция-член** объявляется внутри структуры. Внутри неё поля объекта доступны по имени без точки. Поля читаются и меняются от имени того объекта, у которого вызвана функция.
* **`const` после списка параметров** означает, что функция не меняет объект. Только такие функции можно вызывать у константного объекта и через `const Student&`. Правило: если функция-член не меняет поля, пишите `const`.
* **Копирование:** `Student b = a;` создаёт независимую копию со всеми полями. Передача в функцию по значению тоже копирует; чтобы не копировать, передают `const Student&` (читать) или `Student&` (менять).
* Структуры можно складывать в `std::vector<Student>` и `std::map<std::string, Student>` и обходить их через range-for, как числа и строки.
* Структуры сравнивают по полям вручную (`a.score == b.score`): оператор `==` для всей структуры сам не появляется.
* Эта структура - начало темы: конструкторы, закрытые поля (`class`, `private`) и наследование разбираются в курсе «C++: первые шаги».

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Нет точки с запятой после структуры.**

```cpp
struct Student {
    std::string name;
    int score;
}
int main() { ... }
```

```text
main.cpp:6:2: error: expected ';' after struct
```

Это самая частая ошибка новичков со `struct`. Компилятор указывает на `}` - точку с запятой нужно поставить сразу после неё.

**2. Вызов не-const функции через const-ссылку.**

```cpp
struct Student {
    std::string name;
    int score;
    bool passed() { return score >= 60; }
};
void show(const Student& s) {
    std::cout << s.passed() << "\n";
}
```

```text
main.cpp:9:18: error: 'this' argument to member function 'passed' has type 'const Student', but function is not marked const
```

Сообщение означает: объект константный, а функция `passed` не обещает его не менять. Допишите `const`: `bool passed() const`.

**3. Опечатка в имени поля, лишние и перепутанные значения.**

```cpp
Student s = {"A", 5};
std::cout << s.mark << "\n";
Student t = {"B", 6, 7};
Student u = {5, "x"};
```

```text
main.cpp:9:20: error: no member named 'mark' in 'Student'
main.cpp:10:26: error: excess elements in struct initializer
main.cpp:11:18: error: no viable conversion from 'int' to 'std::string' (aka 'basic_string<char>')
main.cpp:11:21: error: cannot initialize a member subobject of type 'int' with an lvalue of type 'const char[2]'
```

Список значений заполняет поля **по порядку**: сначала строка, затем число. Если поменять местами, компилятор укажет на несовместимость типов.

**4. Поле без начального значения.** Пример 4: мусор в `score`. Пишите `int score = 0;`.

**5. Забыли, что копия независима.** После `Student b = a;` изменения `b` не влияют на `a`. Если нужно менять оригинал внутри функции, принимайте `Student&`.

**6. Путаница типа и объекта.** `Student.score = 5;` - ошибка: у типа нет баллов, они есть у объекта. Нужно сначала создать объект: `Student s; s.score = 5;`.

**7. Забытый `const` в функциях, которые только читают.** Это не ошибка, пока объект не передаётся по константной ссылке, но потом приводит к сообщению из пункта 2. Привычка писать `const` с самого начала экономит время.

## Итоги

* `struct` объявляет новый тип из именованных полей; после `}` ставится `;`.
* Объект создаётся как переменная этого типа, поля читаются и меняются через точку.
* Поле числового типа без значения содержит мусор: задавайте значения по умолчанию в объявлении (`int score = 0;`).
* Функция-член объявляется внутри структуры и видит поля своего объекта; если она не меняет поля, помечайте её `const`.
* Присваивание копирует объект целиком; структуры можно хранить в векторах и словарях и передавать по `const`-ссылке.

Теперь у вас есть все основные инструменты: ввод, условия, циклы, функции, коллекции, обработка ошибок и собственные типы. Их можно собрать в законченную программу - [мини-проект](lesson:cpp.from-zero.mini-project) обрабатывает ведомость из строк, часть которых содержит ошибки. После него следующий курс начнёт разбирать, как программа превращается в исполняемый файл.

## Для тех, кто уже программирует

* В C++ `struct` и `class` - один и тот же механизм; различие только в доступе по умолчанию: в `struct` всё открыто (`public`), в `class` закрыто (`private`). `struct` традиционно используют для простых наборов данных.
* Структуры в C++ - **значения**, а не ссылки: `Student b = a;` копирует поля (в Java, C#-классах и Python - копируется ссылка на один объект; ближе всего к C# `struct` и Go `struct`).
* `Student s;` в Go даёт нулевые значения всех полей, а в C++ - нет: поля встроенных типов остаются неинициализированными. Поэтому принято задавать значения по умолчанию в объявлениях полей или использовать конструкторы.
* `const` после списка параметров - признак константной функции-члена, аналога которого в Java, Python и JS нет. Он входит в сигнатуру и проверяется компилятором.
* Списочная инициализация `{...}` - агрегатная инициализация по порядку полей (в Python аналог - позиционные поля `dataclass`). Названные поля (`.name = ...`) появились в C++20 и требуют соблюдения порядка.
* Структуры без `operator==` нельзя сравнить `==`; с C++20 можно попросить компилятор сгенерировать его (`bool operator==(const Student&) const = default;`), но это за пределами курса.
* Данные и функции-члены лежат в одном месте, а память под объект - единым блоком; размер структуры может превышать сумму размеров полей из-за выравнивания.

## Как структура лежит в памяти

Это необязательный раздел: для заданий он не нужен.

Объект структуры занимает в памяти непрерывный участок: поля идут в порядке объявления, между ними иногда вставляется «выравнивание» - пустые байты, чтобы каждое поле начиналось по адресу, удобному процессору. Поэтому `struct { char c; int n; }` обычно занимает 8 байт, а не 5.

Функции-члены в объекте места **не занимают**: код функции хранится один раз для всего типа, а при вызове `s.passed()` компилятор передаёт ей объект `s` как скрытый параметр. Именно поэтому в сообщении об ошибке из пункта 2 упоминается `'this' argument`: `this` - этот скрытый параметр, а `const` после скобок означает, что он константный.

Следующий курс, «C++: первые шаги», продолжает с того места, где здесь остановились: как исходный код попадает в исполняемый файл (препроцессор, компилятор, компоновщик), как собирать несколько файлов и почему структура со своими функциями - основа классов и RAII.
