## Зачем это нужно

Считать - основная работа программы: сумма чека, сдача, процент скидки, число полных ящиков. В C++ арифметика выглядит знакомо, но у неё есть две особенности, которые удивляют новичков: деление целых чисел отбрасывает дробную часть, а у числа типа `int` есть предел. Обе нужно понимать с самого начала.

## Одна новая идея: результат операции зависит от типов операндов

Знаки арифметики: `+` сложение, `-` вычитание, `*` умножение, `/` деление, `%` остаток от деления. Скобки меняют порядок действий, как в математике: умножение, деление и остаток выполняются раньше сложения и вычитания.

Главное правило: **тип результата определяют типы чисел, участвующих в операции.**

* Если оба числа целые (`int`), то и результат целый. Деление `17 / 5` даёт `3`: дробная часть просто отбрасывается. Остаток `17 % 5` равен `2`, потому что `17 = 5 * 3 + 2`.
* Если хотя бы одно число дробное (`double`), результат дробный. `17.0 / 5` даёт `3.4`.

Для изменения переменной есть сокращённые записи: `total += 20;` означает `total = total + 20;`. Аналогично `-=`, `*=`, `/=`, `%=`. Для прибавления и вычитания единицы пишут `k++;` и `k--;`.

Кроме того, у `int` есть предел: он хранит числа примерно от -2,1 млрд до +2,1 млрд (точнее, от -2147483648 до 2147483647). Если результат выходит за этот диапазон, случается **переполнение**. Для знаковых целых это неопределённое поведение: результат не гарантирован. Для больших значений существует тип `long long`: он хранит числа примерно до девяти квинтиллионов (9 · 10^18).

<!-- section: examples -->
## Пример 1. Пять операций над целыми

```cpp run
#include <iostream>

int main() {
    int a = 17;
    int b = 5;
    std::cout << a + b << " " << a - b << " " << a * b << " " << a / b << " " << a % b << "\n";
    std::cout << 2 + 3 * 4 << " " << (2 + 3) * 4 << "\n";
}
```
```output
22 12 85 3 2
14 20
```

Разбор:

* Пять результатов в первой строке: `17 + 5`, `17 - 5`, `17 * 5`, `17 / 5` (целая часть частного) и `17 % 5` (остаток).
* Во второй строке умножение выполняется раньше сложения: `2 + 3 * 4` равно `14`. Скобки меняют порядок: `(2 + 3) * 4` равно `20`.

## Пример 2. Деление целых и дробных

```cpp run
#include <iostream>

int main() {
    std::cout << 1 / 2 << "\n";
    std::cout << 1.0 / 2 << "\n";
    std::cout << 17.0 / 5 << " " << 17 / 5.0 << "\n";
    std::cout << -17 / 5 << " " << -17 % 5 << "\n";
}
```
```output
0
0.5
3.4 3.4
-3 -2
```

Разбор:

* `1 / 2` - деление целых, результат `0`. Это самая частая ловушка: хотите половину, а получаете ноль.
* Достаточно записать одно из чисел как `1.0`, и деление становится дробным: `0.5`.
* Для отрицательных чисел C++ отбрасывает дробную часть в сторону нуля: `-17 / 5` равно `-3`, а остаток `-17 % 5` равен `-2` (знак остатка совпадает со знаком делимого). Равенство `a == (a / b) * b + a % b` выполняется всегда.

## Пример 3. Сокращённые операции

```cpp run
#include <iostream>

int main() {
    int total = 100;
    total += 20;
    total -= 5;
    total *= 2;
    std::cout << total << "\n";

    int k = 5;
    k++;
    k--;
    k++;
    std::cout << k << "\n";
}
```
```output
230
6
```

Разбор: `total` последовательно становится `120`, `115`, `230`. Переменная `k` растёт на единицу, уменьшается и снова растёт: `6`.

## Пример 4. Большие числа и `long long`

```cpp run
#include <iostream>

int main() {
    long long big = 2000000000;
    big = big * 3;
    std::cout << big << "\n";
}
```
```output
6000000000
```

Шесть миллиардов не поместились бы в `int`, но `long long` справляется. Заметьте: если бы обе переменные были `int`, то `big * 3` переполнило бы `int` ещё до присваивания, и тип слева ничего бы не исправил. Тип результата определяют операнды.

**Попробуйте.** Посчитайте сдачу: переменная `paid = 1000`, переменная `cost = 635`; напечатайте `paid - cost`. Затем разделите `cost` на 100 дважды: одним делением целых и вторым с `100.0`, и сравните результаты. Наконец, выясните остаток от деления 1000 на 7.

## Точные правила

* Операции `*`, `/`, `%` выполняются раньше `+` и `-`; операции одного приоритета - слева направо: `10 - 4 - 3` равно `3`. При сомнении ставьте скобки.
* **Деление целых** отбрасывает дробную часть в сторону нуля: `7 / 2` равно `3`, `-7 / 2` равно `-3`.
* **Остаток `%`** определён только для целых чисел. Для `a % b` выполняется `a == (a / b) * b + a % b`.
* **Деление на ноль.** Целое деление на `0` - неопределённое поведение: программа может упасть, а может напечатать мусор. Если делитель - константа `0`, компилятор предупредит (`division by zero is undefined`); если он лежит в переменной, предупреждения не будет. Деление дробных чисел на ноль в курсе не рассматривается.
* **Диапазон `int`** - от -2147483648 до 2147483647 (на всех современных платформах, где `int` 32-битный). Выход за диапазон при вычислении - переполнение знакового целого, **неопределённое поведение**. Оптимизатор компилятора вправе исходить из того, что переполнений не бывает, и результат на практике может отличаться от ожидаемого.
* **`long long`** - не менее 64 бит, диапазон примерно ±9,22 · 10^18. Выбирайте его для сумм и произведений, которые могут превысить два миллиарда. Литерал больше `2147483647` (например, `3000000000`) компилятор сам считает числом большего типа.
* **Тип выражения.** `int * int` - `int`, `long long * int` - `long long`, `double * int` - `double`. Присваивание к переменной шире типа не спасёт, если переполнение случилось раньше, при вычислении.
* **`++` и `--`** прибавляют и вычитают единицу. В курсе мы используем их как отдельную команду (`k++;`), а не внутри другого выражения.
* Дробные числа вычисляются с погрешностью (урок 5), поэтому сравнивать результаты вычислений с `double` на равенство нельзя.

## Типичные ошибки

**1. Деление целых там, где нужно дробное.**

```cpp
int sum = 7;
int count = 2;
double avg = sum / count;
```

В `avg` попадёт `3`, а не `3.5`: деление `sum / count` выполняется над двумя `int` до присваивания. Решение придёт в уроке 9 (преобразование типов); пока достаточно записать хотя бы один операнд как `double`: `7.0 / 2`.

**2. Переполнение `int`.**

```cpp
int x = 2147483647 + 1;
```

```text
main.cpp:5:24: warning: overflow in expression; result is -2'147'483'648 with type 'int' [-Winteger-overflow]
    5 |     int x = 2147483647 + 1;
      |             ~~~~~~~~~~~^~~
```

Компилятор заметил переполнение в константном выражении и предупредил. Если значения лежат в переменных, предупреждения нет, а результат не определён: у вас может получиться `-2147483648`, а может - что-то другое. Для таких вычислений объявляйте переменные `long long`.

**3. Число больше `int` в `int`.**

```cpp
int y = 3000000000;
```

```text
main.cpp:8:13: warning: implicit conversion from 'long' to 'int' changes value from 3000000000 to -1294967296 [-Wconstant-conversion]
    8 |     int y = 3000000000;
      |         ~   ^~~~~~~~~~
```

Число не поместилось, и значение изменилось. Предупреждение называет старое и новое значение: если оно вас удивило, пора менять тип на `long long`.

**4. Деление на ноль.**

```text
main.cpp:4:20: warning: division by zero is undefined [-Wdivision-by-zero]
    4 |     std::cout << 5 / 0 << "\n";
      |                    ^ ~
```

Когда делитель берётся из переменной или из ввода, компилятор его не видит. Проверяйте значение перед делением; как делать проверки, вы узнаете в уроке 12.

**5. Остаток для дробных чисел.** Оператор `%` для `double` не работает: `5.5 % 2` - ошибка компиляции. Остаток в курсе вычисляется только для целых.

**6. Путаница `=` и `+=`.** `total = 5;` заменяет значение, `total += 5;` увеличивает его на 5. Если после операции значение «сбросилось», проверьте, не стоит ли просто `=`.

<!-- section: summary -->
## Итоги

* Операции: `+ - * / %`, скобки меняют порядок; `*`, `/`, `%` приоритетнее `+` и `-`.
* Деление целых отбрасывает дробную часть: `17 / 5` равно `3`; остаток даёт `%`: `17 % 5` равно `2`. Если один из операндов `double`, деление дробное.
* `+=`, `-=`, `*=`, `/=`, `%=`, `++`, `--` изменяют переменную на месте.
* `int` хранит числа до 2147483647; переполнение - неопределённое поведение; для больших значений используйте `long long`.
* Деление целого на ноль - тоже неопределённое поведение.

В следующем уроке ([Строки](lesson:cpp.from-zero.strings)) вы научитесь узнавать длину строки, брать из неё отдельные символы и склеивать строки, а заодно встретите ещё один способ получить неопределённое поведение: индекс за пределами строки.

## Для тех, кто уже программирует

* `int / int` - целочисленное деление с усечением к нулю (как в Java, C#, Go; в отличие от Python 3 и JavaScript). `%` следует знаку делимого, как в Java и JavaScript, а не как в Python.
* Переполнение знакового `int` - **неопределённое поведение**, а не заворачивание, как в Java, C# (без `checked`) или Go. Беззнаковые типы заворачиваются по модулю 2^N. Это не теоретическая оговорка: оптимизатор может удалить проверку `x + 1 > x`.
* Деление целого на ноль - тоже UB (на x86 обычно аппаратное исключение, ловить которое `try/catch` не может).
* Размеры типов определены платформой: `int` обычно 32 бита, `long` - 32 (Windows) или 64 (Linux, macOS), `long long` - не менее 64. Для фиксированной ширины есть `std::int32_t`, `std::int64_t` из `<cstdint>`.
* Нет оператора возведения в степень: используют `std::pow` из `<cmath>` (дробный результат) или умножение. Нет и «этажного» деления вроде `//` в Python.
* В выражениях `int` с `unsigned` превращаются в `unsigned`: `-1 < 1u` ложно. Эту ловушку курс обходит, используя `int` и `long long`; предупреждение `-Wsign-compare` указывает на неё (урок 11).

## Почему переполнение - неопределённое поведение, а не «заворачивание»

Это необязательный раздел: для заданий он не нужен.

Исторически C и C++ работали на машинах с разным представлением отрицательных чисел, и стандарт не стал фиксировать результат переполнения знаковых типов. Сегодня почти все процессоры используют дополнительный код, и сложение просто заворачивается. Но компиляторы пользуются правом считать, что переполнения не бывает: для них выражение `x + 1 > x` всегда истинно, и ветку «иначе» можно удалить. Поэтому код, который «работал при -O0», может вести себя иначе при `-O2`.

Если нужна арифметика по модулю, используйте беззнаковые типы; если нужна проверка переполнения - сравнение с границами до вычисления или встроенные средства компилятора (например, `__builtin_add_overflow` в clang и GCC). Санитайзеры (`-fsanitize=undefined`) умеют ловить такие ошибки во время тестов; они разбираются в курсе «C++: язык и стандартная библиотека».
