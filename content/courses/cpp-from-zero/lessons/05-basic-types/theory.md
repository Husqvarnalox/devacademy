## Зачем нужны разные типы

Цена `49.90`, ответ «да/нет», буква оценки `B` и количество штук `3` - это значения разной природы. Если хранить всё в `int` или в строках, программа либо потеряет данные, либо будет путаться. В C++ у каждого значения есть **тип**, и компилятор проверяет, что значения используют по назначению. Правильный выбор типа - первый шаг к программе без неожиданностей.

## Одна новая идея: тип подбирают по смыслу значения

Уже знакомые типы: `int` (целое число) и `std::string` (текст). Три новых:

| Тип | Что хранит | Литералы |
|---|---|---|
| `double` | число с дробной частью | `21.5`, `0.05`, `-3.0` |
| `bool` | логическое значение: истина или ложь | `true`, `false` |
| `char` | один символ | `'B'`, `'7'`, `'?'` |

**Литерал** - значение, записанное прямо в тексте программы. Обратите внимание на кавычки: одиночные кавычки обозначают один символ (`'B'`), двойные - текст (`"B"`). Это разные вещи: `'B'` имеет тип `char`, а `"B"` - текст из одного символа.

Ещё одно слово - `const` (от constant, «постоянная»). Оно ставится перед типом и делает значение неизменяемым:

```cpp
const int DAYS = 7;
```

Попытка записать в `DAYS` новое значение вызовет ошибку компиляции. `const` защищает от случайной порчи значений, которые не должны меняться, а по имени читатель видит, что это постоянная. Имена констант принято писать заглавными буквами.

## Пример 1. Дробные числа

```cpp run
#include <iostream>

int main() {
    double temperature = 21.5;
    double pi = 3.14159265358979;
    double third = 1.0 / 3;
    double big = 1234567.0;
    double whole = 2.0;
    std::cout << temperature << "\n";
    std::cout << pi << "\n";
    std::cout << third << "\n";
    std::cout << big << "\n";
    std::cout << whole << "\n";
}
```
```output
21.5
3.14159
0.333333
1.23457e+06
2
```

Разбор:

* Дробная часть отделяется **точкой**, а не запятой: `21.5`.
* `std::cout` по умолчанию печатает дробное число с шестью значащими цифрами. Поэтому `3.14159265358979` превращается в `3.14159`, а `1.0 / 3` - в `0.333333`.
* Число `1234567.0` не помещается в шесть цифр, и вывод переходит к научной записи: `1.23457e+06` означает 1,23457 · 10⁶. Это не ошибка: так выглядит вывод по умолчанию. Как печатать дробные числа привычно (с двумя знаками после точки), мы разберём в уроке 10.
* `2.0` печатается как `2`: нулевую дробную часть вывод по умолчанию отбрасывает.

## Пример 2. Логические значения

```cpp run
#include <iostream>

int main() {
    bool rain = true;
    bool dry = false;
    std::cout << rain << " " << dry << "\n";
    std::cout << std::boolalpha << rain << " " << dry << "\n";
}
```
```output
1 0
true false
```

Без дополнительных средств `bool` печатается числами: `true` - это `1`, `false` - это `0`. Манипулятор `std::boolalpha` (от «буквенный bool») включает слова. Он действует на весь вывод **после** себя, поэтому второй строкой напечатаны `true false`.

## Пример 3. Символ и константа

```cpp run
#include <iostream>

int main() {
    char grade = 'B';
    const int DAYS = 7;
    std::cout << "Оценка: " << grade << "\n";
    std::cout << "Дней в неделе: " << DAYS << "\n";
    std::cout << "Следующий код: " << grade + 1 << "\n";
}
```
```output
Оценка: B
Дней в неделе: 7
Следующий код: 67
```

Разбор:

* `char grade = 'B';` хранит один символ. Он печатается как буква.
* `DAYS` объявлена с `const`: менять её нельзя.
* Выражение `grade + 1` не даёт `'C'`: символ внутри компьютера - это число (код символа; у `'B'` это `66`), и сложение превращает результат в число `67`. Будьте внимательны: символ и число в C++ тесно связаны.

**Попробуйте.** Объявите `double price = 49.9;` и `char size = 'M';` и напечатайте обе переменные одной цепочкой. Затем замените `49.9` на `49` и посмотрите, как изменился вывод. Наконец, допишите строку `DAYS = 8;` и прочитайте сообщение компилятора.

## Точные правила

* **`double`** хранит дробные числа приближённо: число делится на двоичные разряды, и многие десятичные дроби (например, `0.1`) точно записать нельзя. Поэтому `0.1 + 0.2` в памяти не равно в точности `0.3`; выводом по умолчанию это скрыто. Сравнение дробных чисел на равенство - ловушка; подробнее в уроке 11.
* **`int` и `double`**: запись `int x = 3.7;` разрешена, но дробная часть отбрасывается (получится `3`, не `4`), и компилятор предупреждает об этом (`implicit conversion ... changes value`). Запись `double d = 5;` безопасна: целое просто становится `5.0`.
* **`bool`** принимает только `true` и `false`. Числа тоже превращаются в `bool` (`0` - ложь, всё остальное - истина), но в этом курсе мы пользуемся только `true` и `false`.
* **`char`** занимает один байт и подходит для латинских букв, цифр и знаков. Русская буква в UTF-8 занимает два байта и в один `char` не помещается; для кириллицы мы используем строки, а не символы.
* **Кавычки.** `'B'` - один символ, `"B"` - текст. Присвоить текст символу нельзя: `char c = "B";` - ошибка. В `std::string` напротив, можно хранить и один символ как текст.
* **Арифметика с `char`**: символ в выражении ведёт себя как число (код). Результат `grade + 1` - `int`, а не `char`.
* **`const`**: значение задаётся при объявлении и далее не меняется. Объявление `const int DAYS;` без значения - ошибка.
* Другие встроенные типы (`float`, `short`, `unsigned`, `long long`) существуют; в курсе мы вводим только то, что нужно для задач. `long long` появится в уроке 6.

## Типичные ошибки

**1. Дробное число в `int`.** Строка `int x = 3.7;` собирается, но хранит `3`:

```text
main.cpp:4:13: warning: implicit conversion from 'double' to 'int' changes value from 3.7 to 3 [-Wliteral-conversion]
    4 |     int x = 3.7;
      |         ~   ^~~
```

Предупреждение сообщает именно о потере дробной части. Для цен, температур и средних значений выбирайте `double`.

**2. Запятая вместо точки.** Запись `double price = 49,9;` не даёт `49.9`: запятая в C++ разделяет части объявления, и компилятор останавливается на ней.

```text
main.cpp:4:23: error: expected unqualified-id
    4 |     double price = 49,9;
      |                       ^
```

Сообщение непонятное (после запятой компилятор ждал имя новой переменной, а увидел `9`), но указывает на нужное место: сразу за запятой. Дробная часть отделяется точкой.

**3. Строка вместо символа и наоборот.**

```cpp
char c = "A";
```

```text
main.cpp:6:10: error: cannot initialize a variable of type 'char' with an lvalue of type 'const char[2]'
    6 |     char c = "A";
      |          ^   ~~~
```

Двойные кавычки дают текст (`const char[2]`: символ `A` и завершающий нуль), а переменной типа `char` нужен один символ в одиночных кавычках: `'A'`.

**4. Изменение константы.**

```text
main.cpp:5:10: error: cannot assign to variable 'DAYS' with const-qualified type 'const int'
    5 |     DAYS = 8;
      |     ~~~~ ^
main.cpp:4:15: note: variable 'DAYS' declared const here
    4 |     const int DAYS = 7;
      |     ~~~~~~~~~~^~~~~~~~
```

Компилятор объясняет, что `DAYS` объявлена как `const` (примечание показывает где). Если значение действительно должно меняться, уберите `const`.

**5. Ждать `'C'` от `'B' + 1`.** Результат сложения символа и числа - число `67`, а не символ. Чтобы получить символ, нужно присвоить результат переменной типа `char` (`char next = grade + 1;`), но в этом курсе такие вычисления нам не понадобятся.

**6. Ждать `true` от `bool` без `boolalpha`.** `std::cout << rain` печатает `1`. Это не ошибка вывода, а поведение по умолчанию.

<!-- section: summary -->
## Итоги

* Тип выбирают по смыслу: `int` - целое, `double` - дробное, `bool` - да/нет, `char` - один символ, `std::string` - текст.
* Дробная часть записывается через точку; `std::cout` печатает `double` по умолчанию с шестью значащими цифрами.
* `bool` без `std::boolalpha` печатается как `1` и `0`.
* `'B'` - символ, `"B"` - текст; смешивать их нельзя.
* `const` делает значение неизменяемым: попытка его изменить - ошибка компиляции.

В следующем уроке ([Арифметика](lesson:cpp.from-zero.arithmetic)) вы научитесь считать: складывать, умножать, делить и получать остаток, а также узнаете, почему `7 / 2` в C++ равно `3` и что бывает, когда `int` не хватает места.

## Для тех, кто уже программирует

* Размеры встроенных типов зависят от платформы: `int` обычно 32 бита, `double` - 64 бита IEEE 754, `char` - 8 бит. Точные значения не гарантированы стандартом, кроме минимумов; для фиксированных размеров есть `<cstdint>` (`std::int32_t`, `std::int64_t`).
* `bool` в `std::cout` без `std::boolalpha` печатается как `1`/`0`. `char` печатается как символ, а `char + int` даёт `int`.
* `char` может быть знаковым или беззнаковым в зависимости от платформы; для байтов используют `unsigned char` или `std::byte`.
* Неявные преобразования между числовыми типами разрешены (и теряют данные): `int x = 3.7;` собирается с предупреждением. Запись с фигурными скобками `int x{3.7};` - уже ошибка (сужающее преобразование).
* `const` в C++ - не просто «нельзя присвоить повторно», как `final` в Java: оно относится к типу значения и проверяется компилятором, а оптимизатор использует его для вычислений на этапе компиляции. Для констант времени компиляции есть `constexpr` (позже).
* Знаковое целое: переполнение `int` - неопределённое поведение; `unsigned` заворачивается по модулю 2^N. Подробно - в уроке 6.

## Почему `0.1 + 0.2` не равно `0.3`

Это необязательный раздел: для заданий он не нужен.

`double` хранит число как двоичную дробь: мантиссу (около 15-17 десятичных цифр) и порядок. Число `0.1` в двоичной системе - бесконечная периодическая дробь (как `1/3` в десятичной), поэтому оно хранится с крошечной погрешностью. При сложении погрешности складываются, и `0.1 + 0.2` оказывается чуть больше `0.3`: на экране с шестью значащими цифрами вы увидите `0.3`, но проверка `==` скажет `false`. Для денег поэтому часто используют целые копейки, а для дробных вычислений - допуски вроде «разность меньше 1e-9».

Стандарт не требует, чтобы `char` был 8-битным и знаковым, но все современные платформы так делают. Символы Unicode хранятся в `char16_t`, `char32_t` или в многобайтной кодировке UTF-8 внутри `std::string`; детали - в курсе «C++: язык и стандартная библиотека».
