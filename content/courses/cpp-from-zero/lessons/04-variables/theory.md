## Зачем нужны переменные

До сих пор программа печатала только готовый текст. Реальные программы работают со значениями, которые меняются: цена, имя покупателя, количество. Чтобы использовать значение несколько раз, не повторяя его в каждой строке, и менять в одном месте, его кладут в **переменную**.

**Переменная** - это место в памяти компьютера с именем, в котором лежит значение. Похоже на подписанную коробку: по имени вы находите коробку, а внутри - содержимое. У переменной в C++ есть ещё **тип**: он определяет, что можно положить в коробку и сколько места она занимает. Число и текст - разные типы, и одно в другое автоматически не превращается.

## Одна новая идея: переменная объявляется с типом и сразу получает значение

В этом уроке два типа:

* `int` - целое число (положительное, отрицательное или ноль): `3`, `-17`, `0`;
* `std::string` - строка, то есть текст: `"Хлеб"`, `"Анна"`. Для неё в начало файла нужна строка `#include <string>`: она подключает готовую часть библиотеки со строками. Как и `std::cout`, строка лежит в `std`, поэтому пишем `std::string`.

**Объявление** переменной состоит из типа, имени и начального значения:

```cpp
int count = 3;
std::string name = "Анна";
```

Знак `=` здесь не равенство из математики, а команда «положить значение справа в переменную слева». Первая строка читается так: «заведи переменную `count` типа `int` и положи в неё `3`».

Если значение нужно изменить позже, пишут **присваивание** - то же самое, но без типа:

```cpp
count = 5;
```

Тип пишут только один раз, при объявлении. После этого имя уже известно, и достаточно `count = 5;`.

## Важное правило: у переменной всегда должно быть значение

Можно объявить переменную без значения: `int count;`. Но тогда внутри лежит то, что случайно осталось в этом месте памяти. Прочитать такое значение - значит получить **неопределённое поведение** (по-английски undefined behavior, сокращённо UB): стандарт языка не говорит, что при этом произойдёт. Программа может напечатать любое число, может работать правильно сегодня и неправильно завтра. Поэтому в этом курсе каждая переменная получает значение в момент объявления.

## Пример 1. Объявление и вывод

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string city = "Казань";
    int year = 2005;
    std::cout << city << " " << year << "\n";
}
```
```output
Казань 2005
```

Разбор по строкам:

* `#include <string>` подключает тип `std::string`.
* `std::string city = "Казань";` - объявление строковой переменной `city` со значением `Казань`.
* `int year = 2005;` - целая переменная `year`.
* В `std::cout` мы пишем имена переменных **без кавычек**: так программа печатает значение, которое в них лежит. Слово в кавычках, например `"city"`, напечаталось бы как есть. Пробел между значениями - отдельная часть цепочки: `" "`.

## Пример 2. Присваивание и копирование

```cpp run
#include <iostream>
#include <string>

int main() {
    std::string city = "Казань";
    int year = 2005;
    std::cout << city << " " << year << "\n";

    city = "Самара";
    year = 1586;
    std::cout << city << " " << year << "\n";

    int copy = year;
    year = 1;
    std::cout << copy << " " << year << "\n";
}
```
```output
Казань 2005
Самара 1586
1586 1
```

Разбор:

* Две строки с `=` после первого вывода меняют значения. У `city` и `year` нет типа слева: переменные уже объявлены.
* `int copy = year;` берёт текущее значение `year` (`1586`) и кладёт его в новую переменную `copy`. После этого переменные независимы: `year = 1;` не меняет `copy`.
* Программа идёт сверху вниз, поэтому после `year = 1586;` старое значение `2005` потеряно: его никто не сохранил.

## Пример 3. Опасное объявление без значения

Так писать не надо - пример показывает, что говорит компилятор:

```cpp
int count;
std::cout << "Количество: " << count << "\n";
```

```text
main.cpp:5:46: warning: variable 'count' is uninitialized when used here [-Wuninitialized]
    5 |     std::cout << "Количество: " << count << "\n";
      |                                    ^~~~~
main.cpp:4:14: note: initialize the variable 'count' to silence this warning
    4 |     int count;
      |              ^
      |               = 0
1 warning generated.
```

Компилятор предупреждает и сам предлагает исправление: `int count = 0;`. Программа при этом собирается и печатает какое-то число, непредсказуемое: при каждом запуске оно может быть другим. Это и есть неопределённое поведение.

**Попробуйте.** Объявите переменную `int age = 30;`, напечатайте её, присвойте `age = 31;` и напечатайте снова. Затем добавьте вторую переменную `int next = age;` и убедитесь, что последующее изменение `age` не затрагивает `next`.

## Точные правила

* **Объявление**: `тип имя = значение;` Например, `int count = 3;`. Допустима и запись с фигурными скобками `int count{3};` - она делает то же самое; в курсе мы используем знак `=`.
* **Присваивание**: `имя = значение;` Тип не пишется. Значение справа должно подходить по типу.
* **Имя** состоит из латинских букв, цифр и знака подчёркивания `_`, не начинается с цифры и не совпадает со словами языка (`int`, `return`, ...). Регистр важен: `count` и `Count` - разные переменные. Имя должно говорить о смысле: `price` лучше, чем `p`.
* Переменная должна быть **объявлена раньше, чем используется**: компилятор читает файл сверху вниз.
* Имя можно объявить с типом только один раз в одном блоке (между `{` и `}`). Второе объявление `int price = 50;` с тем же именем - ошибка `redefinition`.
* `int` хранит целые числа примерно от -2 миллиардов до +2 миллиардов (точные границы - в уроке 6). Дробные числа и логические значения - тема урока 5.
* `std::string` хранит текст любой длины; строки можно присваивать друг другу и печатать через `std::cout`.
* Нельзя положить число в строку или текст в `int`: `int count = "три";` и `std::string name = 5;` не компилируются.
* Если объявить локальную переменную без значения, её содержимое случайно, а чтение - неопределённое поведение. У `std::string` есть исключение: пустая строка `std::string s;` корректна и означает `""`. Для `int` такого нет.
* Строка `#include <string>` нужна для `std::string`. В некоторых системах программа соберётся и без неё, потому что другая библиотека подключает строки сама, но рассчитывать на это нельзя: в другой системе она перестанет собираться.

## Типичные ошибки

**1. Переменная без начального значения.** Показана в примере 3. Исправление: всегда пишите `= значение` при объявлении, даже если оно временное, например `int total = 0;`.

**2. Не тот тип значения.**

```cpp
int count = "три";
```

```text
main.cpp:5:9: error: cannot initialize a variable of type 'int' with an lvalue of type 'const char[7]'
    5 |     int count = "три";
      |         ^       ~~~~~
```

Компилятор называет тип переменной (`int`) и тип значения (`const char[7]` - массив символов, то есть текст в кавычках). Число 7 здесь - число байтов в тексте «три» (русские буквы занимают по два байта, плюс завершающий нуль). Если типы не совпадают, исправьте либо тип, либо значение.

**3. Повторное объявление и опечатка в имени.**

```cpp
int price = 45;
int price = 50;
std::cout << prise << "\n";
```

```text
main.cpp:5:9: error: redefinition of 'price'
    5 |     int price = 50;
      |         ^
main.cpp:4:9: note: previous definition is here
    4 |     int price = 45;
      |         ^
main.cpp:6:18: error: use of undeclared identifier 'prise'; did you mean 'price'?
    6 |     std::cout << prise << "\n";
      |                  ^~~~~
      |                  price
```

Первая ошибка: `price` объявлена дважды; `note` показывает первое объявление. Чтобы изменить значение, напишите `price = 50;` без `int`. Вторая ошибка: в имени опечатка, и компилятор сам предлагает `price`.

**4. Кавычки вокруг имени.** `std::cout << "city";` печатает слово `city`, а не значение переменной. Кавычки нужны только для текста.

**5. Использование до объявления.** Если сначала написать `std::cout << year;`, а ниже `int year = 2005;`, компилятор сообщит `use of undeclared identifier 'year'`: он читает файл сверху вниз и в этот момент имени ещё не знает.

**6. Знак `=` читают как «равно».** Строка `year = year + 1;` в математике невозможна, а в программе означает «вычисли `year + 1` и положи результат в `year`». Справа сначала считается значение, потом оно записывается в левую часть.

## Итоги

* Переменная - именованное место в памяти для значения определённого типа.
* `int` хранит целые числа, `std::string` - текст (нужен `#include <string>`).
* Объявление: `int count = 3;`. Изменение значения - присваивание без типа: `count = 5;`.
* Переменная должна иметь значение с момента объявления: чтение неинициализированной переменной - неопределённое поведение.
* В `std::cout` имя переменной пишут без кавычек, и на экран попадает её значение.

В следующем уроке ([Основные типы данных](lesson:cpp.from-zero.basic-types)) вы познакомитесь с дробными числами `double`, логическим типом `bool` и символами `char`, а также научитесь делать значение неизменяемым с помощью `const`.

## Для тех, кто уже программирует

* Типы статические и явные: тип пишется при объявлении (`auto` позволяет компилятору вывести его, в курсе он появится позже). Переменная меняет значение, но не тип.
* Локальные переменные встроенных типов **не обнуляются**: `int x;` содержит мусор, и его чтение - неопределённое поведение (в Java, C# и Go локальные переменные либо обязаны получить значение, либо обнуляются). Сообщение компилятора `-Wuninitialized` ловит только часть случаев.
* `std::string` - значение, а не ссылка: `std::string b = a;` создаёт независимую копию (в отличие от Java и C#, где строка неизменяема, и в отличие от ссылочной семантики в Python и JavaScript). Строка изменяема.
* Три формы инициализации: `int a = 3;`, `int a(3);`, `int a{3};`. Фигурные скобки запрещают сужающие преобразования (`int a{3.5};` - ошибка); подробно в уроке о преобразованиях.
* Область видимости переменной - блок `{ }`, в котором она объявлена. Переменная нижнего блока может заслонить (shadow) одноимённую переменную внешнего блока; предупреждение `-Wshadow` в курсе не включено.

<!-- section: deep-dive -->
## Что такое «память» и откуда берётся мусор

Это необязательный раздел: для заданий он не нужен.

Локальные переменные программа хранит на **стеке** - области памяти, которая выделяется автоматически при входе в функцию и освобождается при выходе. Когда `main` объявляет `int count;`, компилятор резервирует четыре байта в стеке, но не записывает в них ничего: до вас там могли лежать данные предыдущих вызовов. Поэтому и появляется «произвольное» число.

Компилятор имеет право использовать то, что чтение неинициализированной переменной запрещено, и при оптимизации (ключ `-O2`) делать неожиданные вещи: удалить проверку, которая зависит от такого значения, или заменить его любым числом. Именно поэтому нельзя полагаться на «в прошлый раз напечаталось 0». Подробно неопределённое поведение разбирается в курсе «C++: первые шаги».
