## Зачем это нужно

В уроке 6 вы увидели: `7 / 2` в C++ равно `3`. А как получить `3.5`, если оба числа лежат в переменных типа `int`, например после чтения из ввода? А как превратить число в часть текста, а введённый текст `"42"` - в настоящее число? Все эти задачи называются **преобразованием типов**.

## Одна новая идея: тип значения меняют явно, а там, где это опасно, пишут преобразование сами

Значение одного типа можно превратить в другой. C++ делает некоторые преобразования сам (неявные), а для остальных ждёт от вас явной записи.

**Явное преобразование чисел** записывается так:

```cpp
static_cast<double>(x)   // значение x как double
static_cast<int>(y)      // значение y как int
```

Слово `static_cast` читается как «преобразуй этим способом»; в угловых скобках указан нужный тип, в круглых - значение.

Главное применение - деление. Выражение `sum / count` над двумя `int` целочисленное. Если превратить один из операндов в `double` **до** деления, то деление станет дробным:

```cpp
static_cast<double>(sum) / count
```

Обратите внимание на место скобок: преобразуется только `sum`, а затем делится `double` на `int`. Результат - `double`.

Правило обратного направления: при превращении `double` в `int` дробная часть **отбрасывается** (не округляется). `static_cast<int>(2.99)` равно `2`, а `static_cast<int>(-2.99)` равно `-2`.

**Преобразование между числами и строками** выполняют готовые функции из `<string>`:

* `std::stoi("42")` превращает строку в `int` (от «string to int»), `std::stod("3.14")` - в `double`;
* `std::to_string(7)` превращает число в `std::string`: `"7"`.

<!-- section: examples -->
## Пример 1. Целое и дробное деление

```cpp run
#include <iostream>

int main() {
    int sum = 7;
    int count = 2;
    double wrong = sum / count;
    double right = static_cast<double>(sum) / count;
    std::cout << wrong << " " << right << "\n";
}
```
```output
3 3.5
```

Разбор:

* В `wrong` тип слева - `double`, но деление `sum / count` происходит над двумя `int` **раньше** присваивания. Результат `3` лишь потом превращается в `3.0`.
* В `right` число `sum` сначала превращено в `double`, поэтому делится `7.0` на `2`. Получается `3.5`.

## Пример 2. Дробное в целое

```cpp run
#include <iostream>

int main() {
    double price = 19.99;
    int whole = static_cast<int>(price);
    int neg = static_cast<int>(-3.99);
    std::cout << whole << " " << neg << "\n";
    std::cout << 1 + 2.5 << " " << 3 * 1.5 << "\n";
}
```
```output
19 -3
3.5 4.5
```

Разбор:

* `static_cast<int>(19.99)` равно `19`: дробная часть отброшена, округления нет. Для `-3.99` результат `-3`: отбрасывание идёт в сторону нуля.
* Во второй строке показано правило неявного преобразования: если в выражении есть `int` и `double`, то `int` сам превращается в `double`. `1 + 2.5` и `3 * 1.5` дают дробные результаты, и записывать `static_cast` не нужно.

## Пример 3. Символы как числа

```cpp run
#include <iostream>

int main() {
    std::cout << 'a' << " " << 'a' + 1 << " " << static_cast<char>('a' + 1) << "\n";
}
```
```output
a 98 b
```

Символ `'a'` имеет код `97`. Сложение `'a' + 1` даёт число `98`, а `static_cast<char>` превращает его обратно в символ `b`. Так записывают переход к следующей букве алфавита.

## Пример 4. Числа и строки

```cpp run
#include <iostream>
#include <string>

int main() {
    int n = std::stoi("42");
    double x = std::stod("3.14");
    std::cout << n + 1 << " " << x * 2 << "\n";

    std::string s = "Итого: " + std::to_string(5) + " шт.";
    std::cout << s << "\n";
    std::cout << std::to_string(2.5) << " " << std::to_string(-7) << "\n";
    std::cout << std::stoi("12abc") << "\n";
}
```
```output
43 6.28
Итого: 5 шт.
2.500000 -7
12
```

Разбор:

* `std::stoi("42")` даёт число `42`, и с ним можно считать: `n + 1` равно `43`. `std::stod("3.14")` даёт `3.14`.
* `std::to_string(5)` даёт строку `"5"`. Строки склеиваются через `+`, поэтому получилось `Итого: 5 шт.`.
* `std::to_string(2.5)` для дробных чисел печатает шесть знаков после точки: `2.500000`. Если нужен другой вид, используйте форматированный вывод из следующего урока.
* `std::stoi("12abc")` читает число из начала строки и останавливается на первом неподходящем символе. Результат - `12`.

**Попробуйте.** Прочитайте из ввода два целых числа и напечатайте их среднее как дробное число. Затем напишите `static_cast<int>(7.9)` и сравните с ожиданием «округлить до 8». Наконец, соберите строку из слова, числа и ещё одного слова с помощью `std::to_string`.

## Точные правила

* **Неявные преобразования** между числовыми типами делаются автоматически. В выражении `int` и `double` приводятся к `double`; присваивание `double d = 5;` безопасно. Присваивание `int x = 3.7;` тоже компилируется, но теряет дробную часть, и компилятор предупреждает (`implicit conversion from 'double' to 'int' changes value`).
* **`static_cast<T>(x)`** превращает `x` в тип `T` явно. Он нужен там, где вы хотите это показать читателю и компилятору: «да, я знаю, что тут преобразование».
* **Из `double` в `int`** дробная часть отбрасывается в сторону нуля. Если число не помещается в `int` (например, `1e10`), результат не определён: это неопределённое поведение, как и переполнение.
* **Фигурные скобки** запрещают такие потери: запись `int y{3.5};` - ошибка компиляции (сужающее преобразование). Запись `int y = 3.5;` разрешена с предупреждением. В курсе мы используем знак `=`.
* **Из `int` в `double`** целое точно представляется до примерно 9 · 10^15; для очень больших `long long` возможна потеря точности.
* **Тип результата деления** определяют операнды: `int / int` - `int`, всё остальное - `double`. Преобразование результата после деления уже не поможет: `static_cast<double>(sum / count)` делит целые, а потом превращает `3` в `3.0`.
* **`std::stoi`, `std::stod`** принимают `std::string` (или текст в кавычках). Они пропускают пробелы в начале, читают число и останавливаются на первом неподходящем символе. Если число прочитать нельзя, они бросают исключение `std::invalid_argument`, и программа без перехвата аварийно завершается. Если число слишком велико для типа, бросается `std::out_of_range`.
* **`std::to_string(x)`** превращает числа в `std::string`. Для `double` всегда выдаёт шесть знаков после точки.
* Строку нельзя превратить в число через `static_cast`: `static_cast<int>("7")` - ошибка компиляции.

## Типичные ошибки

**1. Преобразование после деления.**

```cpp
double avg = static_cast<double>(sum / count);
```

Целочисленное деление `sum / count` выполняется первым и даёт `3`, потом `3` превращается в `3.0`. Дробной части уже нет. Преобразуйте один из операндов: `static_cast<double>(sum) / count`.

**2. Ожидание округления.** `static_cast<int>(7.9)` равно `7`, а не `8`. Если нужно округлить, существует функция `std::round` из `<cmath>`, но в курсе мы её не используем.

**3. Сужающее преобразование в фигурных скобках.**

```cpp
int y{3.5};
```

```text
main.cpp:3:11: error: type 'double' cannot be narrowed to 'int' in initializer list [-Wc++11-narrowing]
    3 |     int y{3.5};
      |           ^~~
main.cpp:3:11: note: insert an explicit cast to silence this issue
```

Компилятор называет оба типа и подсказывает исправление: вставить явное преобразование `static_cast<int>(3.5)`. Фигурные скобки здесь служат защитой от случайной потери данных.

**4. Строка плюс число.**

```cpp
std::string s = "Итого: " + 5;
```

```text
main.cpp:4:36: warning: adding 'int' to a string does not append to the string [-Wstring-plus-int]
    4 |     std::string s = "Итого: " + 5;
      |                     ~~~~~~~~~~^~~
```

Это компилируется, но **не** склеивает текст с числом: пятёрка сдвигает указатель внутри текста в кавычках, и в строке окажется обрубок или мусор (в нашем запуске - обрубок слова). Предупреждение называет проблему прямо: «добавление int к строке не дописывает в строку». Правильно: `"Итого: " + std::to_string(5)`.

**5. `static_cast` из строки в число.**

```text
main.cpp:5:13: error: static_cast from 'const char *' to 'int' is not allowed
    5 |     int b = static_cast<int>("7");
      |             ^~~~~~~~~~~~~~~~~~~~~
```

Текст превращается в число функцией `std::stoi`, а не преобразованием типа.

**6. `std::stoi` на нечисловой строке.**

```cpp
std::cout << std::stoi("abc") << "\n";
```

```text
libc++abi: terminating due to uncaught exception of type std::invalid_argument: stoi: no conversion
```

В отличие от `std::cin >>`, который молча записывает `0`, `std::stoi` останавливает программу. Это защищает от скрытых ошибок. Как обработать такую ситуацию и не упасть, вы узнаете в уроке 22 (исключения).

**7. Деление на ноль после преобразования.** `static_cast<double>(a) / 0` для дробных чисел не останавливает программу, но результат не годится для вывода. Проверяйте делитель до деления (условия - урок 12).

## Итоги

* `static_cast<T>(x)` явно превращает значение в тип `T`.
* Для дробного деления преобразуйте хотя бы один операнд в `double` **до** деления: `static_cast<double>(a) / b`.
* Из `double` в `int` дробная часть отбрасывается (не округляется).
* `std::stoi`, `std::stod` превращают строки в числа, `std::to_string` - числа в строки; на нечисловом тексте `std::stoi` бросает исключение.
* `"текст" + число` не склеивает: используйте `std::to_string`.

В следующем уроке ([Форматированный вывод](lesson:cpp.from-zero.formatted-output)) вы научитесь печатать дробные числа с нужным количеством знаков и выравнивать столбцы.

## Для тех, кто уже программирует

* В C++ несколько видов явных преобразований: `static_cast` (безопасные по типу преобразования, проверяемые при компиляции), `const_cast`, `reinterpret_cast`, `dynamic_cast`. Запись в стиле C `(double)x` работает, но её трудно искать и она смешивает все виды; в современном коде `static_cast` предпочтительнее.
* Неявные арифметические преобразования: `int` + `double` даёт `double`; узкие типы повышаются до `int`; смешение знакового и беззнакового (`int` и `unsigned`) превращает знаковое в беззнаковое. Это источник тонких ошибок, на которые указывает `-Wsign-compare` и `-Wconversion` (последний в курсе не включён).
* Сужающие преобразования запрещены только при инициализации фигурными скобками. Привычное `int x = 3.7;` компилируется с предупреждением (в Java это ошибка без явного приведения).
* `double` в `int` за пределами диапазона - UB (в Java насыщение, в C# зависит от контекста).
* `std::stoi/stol/stod` бросают `std::invalid_argument` и `std::out_of_range`. Они допускают «мусор» в конце строки: `stoi("12abc") == 12`. Если нужна строгая проверка, используют второй параметр (индекс первого необработанного символа) или `std::from_chars` из `<charconv>`, который не бросает исключений.
* `std::to_string(double)` не настраивается и печатает шесть знаков. Для контроля форматирования используют потоки (`std::ostringstream`) или `std::format` (C++20, поддерживается не всеми реализациями).

## Зачем нужна именно такая запись

Это необязательный раздел: для заданий он не нужен.

Почему не просто `(double)x`, как в языке C? Потому что у скобочной записи слишком много значений: она может означать безопасное преобразование числа, отбрасывание `const` или перетолкование памяти, и по виду не отличить. Четыре именованных преобразования C++ делают намерение видимым: `static_cast` - обычное преобразование, проверяемое компилятором, остальные - потенциально опасные и поэтому заметные при чтении кода и поиске.

Правила неявных преобразований называются **обычными арифметическими преобразованиями**: операнды приводятся к общему типу, и результат имеет этот тип. Поэтому `7 / 2` - `int`, а `7 / 2.0` - `double`. Знать это важнее, чем помнить исключения. Остальное - кругозор: стандарт подробно описывает порядок, в котором типы «повышаются» (`short` до `int`, `int` до `long` и так далее), а курс «C++: язык и стандартная библиотека» разбирает их влияние на сравнения и битовые операции.
