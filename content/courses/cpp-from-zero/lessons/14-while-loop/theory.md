## Зачем это нужно

Программы постоянно что-то повторяют: просуммировать цены в чеке, пересчитать строки файла, спрашивать пароль, пока он не подойдёт. Писать одну и ту же команду десять раз неудобно, а если количество повторов заранее неизвестно, невозможно. Для этого существуют **циклы**: команда, которая повторяет блок, пока выполняется условие.

## Одна новая идея: пока условие истинно - повторяй

Цикл `while` («пока») выглядит как `if`, но после выполнения блока возвращается к проверке условия:

```cpp
while (условие) {
    // тело цикла
}
```

Порядок такой: проверить условие; если истинно - выполнить тело и вернуться к проверке; если ложно - выйти из цикла и идти дальше. Один проход по телу называют **оборотом** (итерацией).

Чтобы цикл когда-нибудь закончился, нужны три вещи:

1. **Начальное значение**: переменная, от которой зависит условие, получает значение до цикла.
2. **Условие**: выражение типа `bool`, проверяемое перед каждым оборотом.
3. **Изменение**: внутри тела что-то приближает условие к ложному значению.

Если забыть третье, цикл не закончится: условие всегда останется истинным.

Отдельный важный случай - цикл, который читает данные, пока они есть. Для него в C++ есть короткая запись `while (std::cin >> x)`: чтение числа само является условием. Пока число прочиталось, цикл идёт; когда ввод закончился или в нём встретился не числовой текст, условие становится ложным.

## Пример 1. Обратный отсчёт

```cpp run
#include <iostream>

int main() {
    int i = 3;
    while (i > 0) {
        std::cout << i << "\n";
        i--;
    }
    std::cout << "Старт\n";
}
```
```output
3
2
1
Старт
```

Разбор:

* Начальное значение: `i = 3`. Условие: `i > 0`. Изменение: `i--` (уменьшить на единицу, урок 6).
* После оборота с `i = 1` переменная становится `0`, условие ложно, и выполнение идёт к строке «Старт».
* Если бы строки `i--` не было, программа печатала бы `3` бесконечно.

## Пример 2. Накопление суммы

```cpp run
#include <iostream>

int main() {
    int i = 1;
    int sum = 0;
    while (i <= 100) {
        sum += i;
        i++;
    }
    std::cout << "Сумма от 1 до 100: " << sum << "\n";
}
```
```output
Сумма от 1 до 100: 5050
```

Переменная `sum` - **накопитель**: она начинается с нуля (нейтральное значение для сложения) и растёт на каждом обороте. Если начать её без значения, в ней окажется мусор, и результат будет непредсказуем (урок 4).

## Пример 3. Число оборотов неизвестно заранее

```cpp run
#include <iostream>

int main() {
    int money = 100;
    int years = 0;
    while (money < 1000) {
        money *= 2;
        years++;
    }
    std::cout << years << " лет, " << money << " рублей\n";

    int n = 12345;
    int digits = 0;
    while (n > 0) {
        n /= 10;
        digits++;
    }
    std::cout << "Цифр: " << digits << "\n";
}
```
```output
4 лет, 1600 рублей
Цифр: 5
```

Разбор:

* Сумма удваивается, пока не достигнет тысячи: 100, 200, 400, 800, 1600. Четыре оборота. Заранее сказать это число было бы сложнее, чем дать компьютеру посчитать.
* Деление `n /= 10` целочисленное: оно отбрасывает последнюю цифру. Пока число не дойдёт до нуля, оно теряет по цифре, и счётчик `digits` считает обороты.

## Пример 4. Чтение до конца ввода

Программы, которые читают ввод, показаны здесь обычным блоком без запуска: при проверке примеров у них нет входных данных.

```cpp
#include <iostream>

int main() {
    int x = 0;
    int count = 0;
    int sum = 0;
    while (std::cin >> x) {
        count++;
        sum += x;
    }
    std::cout << "Чисел: " << count << ", сумма: " << sum << "\n";
}
```

Для ввода `4 8 15` (или те же числа в трёх строках) программа напечатает:

```text
Чисел: 3, сумма: 27
```

Разбор:

* `std::cin >> x` читает одно число и возвращает сам поток `std::cin`. В условии поток превращается в `bool`: истина, если чтение удалось.
* После `15` числа кончились, чтение не удалось, условие ложно, и цикл завершается. Для пустого ввода тело не выполнится ни разу: будет `Чисел: 0, сумма: 0`.
* Цикл не зависит от количества чисел: те же три строки кода обработают и три числа, и три тысячи.

**Попробуйте.** Измените пример 2 так, чтобы он суммировал только чётные числа от 1 до 100 (подсказка: шаг `i += 2` или проверка `i % 2 == 0`). Напишите цикл, который считает, сколько раз число 1000 можно разделить на 2 нацело, пока оно не станет меньше 1. И намеренно уберите `i--` из примера 1: программа не остановится сама, прервите запуск вручную.

## Точные правила

* Форма: `while (условие) { тело }`. Условие проверяется **перед** каждым оборотом, поэтому тело может не выполниться ни разу.
* Цикл завершается, когда условие стало ложным. Команда внутри тела не может остановить его сама, кроме `break` (урок 16).
* Условие должно зависеть от чего-то, что тело изменяет. Если условие всегда истинно и в теле нет выхода, цикл бесконечен. Бесконечный цикл с командами ввода-вывода просто не заканчивается, пока его не остановят. Ловушка в том, что стандарт разрешает компилятору удалять бесконечные циклы, которые ничего не делают наружу (без ввода-вывода и без обращения к общим данным), поэтому поведение такого пустого цикла нельзя считать предсказуемым.
* **Накопитель** начинают с нейтрального значения: `0` для суммы, `1` для произведения. **Наибольшее** значение начинают с первого прочитанного числа или с известного заведомо малого числа, но не с произвольного нуля.
* `while (std::cin >> x)` читает значения по одному, пропуская пробелы и переводы строк (урок 8). Цикл останавливается на конце ввода и на тексте, не похожем на число. Для обычной подачи данных этого достаточно, но не пытайтесь после неудачи читать дальше: поток находится в состоянии ошибки.
* Проверка `while (!std::cin.eof())` - плохая замена: признак конца ввода устанавливается только после неудачной попытки чтения, и такой цикл делает лишний оборот.
* Переменная, объявленная внутри тела цикла, создаётся заново на каждом обороте и не видна после цикла. Накопители объявляют **до** цикла.
* Суммы и произведения легко выходят за границы `int` (урок 6). Если в чеке могут встретиться большие числа, накопитель делают `long long`.

## Типичные ошибки

Тексты сообщений получены от Apple clang 21 с ключами курса.

**1. Условие не меняется.**

```cpp
int i = 0;
while (i < 3) {
    std::cout << i << "\n";
}
```

Компилятор не находит ошибки (программа синтаксически верна), поэтому собранная программа печатает `0` без остановки. Прервите запуск вручную. Перед запуском цикла спросите себя: «что в теле приближает условие к ложному значению?»

**2. Точка с запятой после условия.**

```cpp
int i = 0;
while (i < 5);
{
    i++;
}
```

```text
main.cpp:4:18: warning: while loop has empty body [-Wempty-body]
    4 |     while (i < 5);
      |                  ^
main.cpp:4:18: note: put the semicolon on a separate line to silence this warning
```

Тело цикла пустое: `i` не меняется, и программа зависает на этой строке. Блок `{ i++; }` после неё к циклу не относится.

**3. Накопитель без начального значения.** Переменная `int sum;` без `= 0` содержит мусор, и `sum += x` складывает числа с мусором (неопределённое поведение, урок 4). Компилятор предупреждает: `variable 'sum' is uninitialized when used here`.

**4. Ошибка на единицу.** Условие `i < 10` вместо `i <= 10` теряет последний оборот. Проверяйте граничные значения на листе бумаги: что будет при первом обороте, что при последнем, что при нулевом числе оборотов.

**5. Чтение по `eof()`.**

```cpp
int x = 0, count = 0;
while (!std::cin.eof()) {
    std::cin >> x;
    count++;
}
```

Для ввода `1 2 3` и завершающего перевода строки программа насчитает `4` оборота, а не `3`: после третьего числа в потоке остался перевод строки, конца ввода ещё нет, четвёртое чтение неудачно, но счётчик уже увеличен. Правильная форма: `while (std::cin >> x) { count++; }`.

**6. Начало наибольшего с нуля.** Если `best = 0` и все числа отрицательные, программа напечатает `0`, которого во вводе не было. Начинайте с первого числа.

**7. Переполнение накопителя.** Сумма нескольких чисел около двух миллиардов не помещается в `int` (неопределённое поведение, урок 6). Используйте `long long`.

## Итоги

* `while (условие) { ... }` повторяет тело, пока условие истинно; условие проверяется перед каждым оборотом.
* Корректный цикл имеет начальное значение, условие и изменение, приближающее конец. Без изменения цикл бесконечен.
* Накопитель сумм начинают с нуля, наибольшее значение - с первого числа.
* `while (std::cin >> x)` читает данные неизвестной длины до конца ввода; `eof()` для этого не годится.
* Пустое тело (`;` после условия) и забытое изменение - самые частые причины зависания.

Цикл `while` удобен, когда число оборотов заранее неизвестно. Когда оно известно, три части цикла удобнее собрать в одну строку: так устроен цикл [for](lesson:cpp.from-zero.for-loop).

## Для тех, кто уже программирует

* Синтаксис тот же, что в Java, C#, JavaScript: условие в скобках, тело в блоке. Цикла `while ... else` (как в Python) нет, но есть `do { ... } while (условие);`, который проверяет условие после тела; в курсе он не нужен.
* Идиома `while (std::cin >> x)` заменяет Python `for line in sys.stdin` и Java `while (scanner.hasNextInt())`. Выражение `std::cin >> x` возвращает поток, который приводится к `bool` через `explicit operator bool`.
* По правилам C++ до версии 26 бесконечный цикл без наблюдаемых действий (ввода-вывода, обращений к `volatile` и атомарным переменным) - неопределённое поведение: компилятор вправе считать, что он завершится. C++26 исключает из этого правила «тривиальные» бесконечные циклы вроде `while (true) {}`. Цикл, который печатает что-то на каждом обороте, этим правилам не подчиняется. В Java и Python пустой бесконечный цикл просто зависает.
* Целочисленное деление и переполнение знакового `int` в цикле работают так же, как вне цикла: `n /= 10` отбрасывает дробь, переполнение даёт неопределённое поведение, а не заворачивание.
* Бесконечный цикл по умолчанию пишут `while (true)` или `for (;;)`; выйти из него можно `break`.
* Проверка `eof()` в условии цикла - классическая ошибка, она есть в большом количестве старых учебников.

## Как поток превращается в условие

Это необязательный раздел: для заданий он не нужен.

У `std::cin` есть четыре внутренних признака состояния. Главные из них: `eofbit` (достигнут конец ввода) и `failbit` (чтение не удалось). Оператор `std::cin >> x` пытается прочитать число. Если не получилось, он устанавливает `failbit` (и `eofbit`, когда причина в конце ввода), а затем возвращает ссылку на сам поток. Приведение потока к `bool` возвращает `!fail()`.

Поэтому `while (std::cin >> x)` читается как «пока последняя попытка чтения удалась». Ключевой нюанс: проверка идёт **после** попытки, а не до неё. Именно поэтому цикл `while (!std::cin.eof())` ошибается: он проверяет состояние до попытки и не знает, что следующее чтение провалится. После `failbit` все последующие чтения молча ничего не делают, пока состояние не будет сброшено командой `std::cin.clear()`. Эти приёмы нужны, когда программа должна пережить плохие данные и продолжить; для них есть отдельный разговор в курсе «C++: первые шаги».
