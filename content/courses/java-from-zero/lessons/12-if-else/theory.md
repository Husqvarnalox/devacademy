## Зачем нужно условие

До сих пор программа выполняла все команды подряд, сверху вниз, и поведение не зависело от данных. Но реальные задачи требуют выбора: если в корзине больше 3000 рублей, доставка бесплатна, иначе она стоит 300; если возраст меньше 6, билет бесплатный. Для выбора нужна команда, которая выполняет блок кода только когда условие верно.

## Одна новая идея: команда if

Условие вы уже умеете записывать: это выражение типа `boolean` из прошлого урока. **Команда `if`** («если») проверяет условие и выполняет следующий за ним блок кода, только когда условие равно `true`:

```java
if (temperature < 0) {
    System.out.println("Мороз");
}
```

Части команды:

* `if` - ключевое слово. Условие записывают **в круглых скобках**, это обязательно.
* `{ ... }` - **блок**: группа команд, ограниченная фигурными скобками. Блок выполняется целиком или не выполняется вовсе. Фигурные скобки вы уже видели у `main`: это тоже блок.
* `else` («иначе») добавляет второй блок, который выполняется, когда условие равно `false`.
* `else if` («иначе, если») задаёт следующее условие, которое проверяется только если все предыдущие оказались ложными.

```java
if (score >= 90) {
    System.out.println("Отлично");
} else if (score >= 70) {
    System.out.println("Хорошо");
} else {
    System.out.println("Нужно подтянуть");
}
```

Условия проверяются **по порядку сверху вниз**. Как только одно из них истинно, выполняется его блок, а остальные ветки пропускаются, даже если их условия тоже верны. Поэтому в цепочке условия располагают от более узких к более широким.

<!-- section: examples -->
## Пример 1. Если и иначе

```java run
public class Main {
    public static void main(String[] args) {
        int cart = 3500;
        if (cart >= 3000) {
            System.out.println("Доставка бесплатная");
        } else {
            System.out.println("Доставка: 300 руб.");
        }
        System.out.println("Спасибо за заказ");
    }
}
```
```output
Доставка бесплатная
Спасибо за заказ
```

Разбор:

* Условие `cart >= 3000` равно `true`, поэтому выполняется первый блок. Блок после `else` пропускается.
* Последняя строка стоит после всей команды `if`, поэтому выполняется всегда. Измените `cart` на `2000`: изменится вторая строка вывода, но не третья.

## Пример 2. Цепочка else if

```java run
public class Main {
    public static void main(String[] args) {
        int score = 75;
        String mark;
        if (score >= 90) {
            mark = "отлично";
        } else if (score >= 70) {
            mark = "хорошо";
        } else if (score >= 50) {
            mark = "удовлетворительно";
        } else {
            mark = "неудовлетворительно";
        }
        System.out.println("Баллы: " + score + ", оценка: " + mark);
    }
}
```
```output
Баллы: 75, оценка: хорошо
```

Разбор:

* Первое условие `score >= 90` ложно, переходим ко второму. `75 >= 70` истинно, переменной `mark` присваивается «хорошо», остальные ветки не проверяются.
* Переменная `mark` объявлена **до** команды `if` без значения, а значение ей дают в ветках. Компилятор следит, чтобы к моменту печати значение было задано в каждой ветке; поэтому последняя ветка `else` здесь нужна.
* Условия не пришлось писать как `score >= 70 && score < 90`: до второй проверки мы доходим, только если первая была ложной, то есть `score < 90` уже известно.

## Пример 3. Условие из нескольких частей

```java run
public class Main {
    public static void main(String[] args) {
        int hour = 14;
        boolean weekend = false;
        if (weekend || hour < 9 || hour >= 18) {
            System.out.println("Магазин закрыт");
        } else {
            System.out.println("Магазин открыт");
        }

        int n = -4;
        if (n > 0) {
            System.out.println("Положительное");
        } else if (n < 0) {
            System.out.println("Отрицательное");
        } else {
            System.out.println("Ноль");
        }
    }
}
```
```output
Магазин открыт
Отрицательное
```

Разбор:

* В условии работают логические операторы из прошлого урока. Магазин закрыт, если выходной, либо рано, либо поздно.
* Три ветки второй команды покрывают все числа: больше нуля, меньше нуля и всё остальное, то есть ноль. Последнюю ветку `else` удобно читать как «во всех остальных случаях».

## Пример 4. Команды в блоке

```java run
public class Main {
    public static void main(String[] args) {
        int balance = 500;
        int price = 800;
        if (price > balance) {
            int missing = price - balance;
            System.out.println("Не хватает: " + missing);
            System.out.println("Пополните счёт");
        }
        System.out.println("Баланс: " + balance);
    }
}
```
```output
Не хватает: 300
Пополните счёт
Баланс: 500
```

Разбор:

* В блок можно поместить любое число команд, в том числе объявление переменной. Блок выполнился целиком: обе строки о нехватке напечатаны.
* Переменная `missing` существует только внутри блока, где она объявлена. После закрывающей скобки `}` обратиться к ней нельзя: это ошибка «cannot find symbol» (подробнее об области видимости - в уроке о методах).

**Попробуйте.** В примере 2 замените `score` на `90`, затем на `49`, затем на `50`. Предскажите оценку до запуска, затем проверьте. Какие значения лежат на границах веток и почему важно, что в условиях стоят `>=`, а не `>`?

## Точные правила

* Условие в скобках обязано иметь тип `boolean`. Число, строка и другие типы как условие не принимаются.
* Блок `{ ... }` выполняется, если условие истинно. Ветка `else` не обязательна. После `else` стоит либо блок, либо новая команда `if` (так получается `else if`).
* В цепочке `if / else if / else` выполняется **не более одной** ветки: первая, условие которой истинно; если ни одно не истинно, выполняется `else` (при его наличии).
* Условия проверяются слева направо и сверху вниз; проверка прекращается на первом истинном. Расположение веток влияет на результат: широкое условие, поставленное первым, «съедает» узкие.
* Переменная, объявленная внутри блока, видна только в этом блоке и во вложенных в него. После `}` она исчезает.
* Если внутри `if` или `else` ровно одна команда, фигурные скобки можно опустить, но тогда к ветке относится только следующая за условием команда. В этом курсе скобки пишут всегда: дописать вторую команду в ветку без скобок - частая причина ошибок.
* Команды внутри блока записывают с отступом в четыре пробела: отступ не влияет на выполнение, но помогает читать, к какому блоку относится строка.
* Блоки можно вкладывать друг в друга: внутри ветки допускается новая команда `if`. Если вложенность становится глубокой, условие обычно можно упростить логическими операторами.

## Типичные ошибки

**1. Присваивание вместо сравнения.**

```java
int x = 5;
if (x = 5) {
    System.out.println("Пять");
}
```

```text
Main.java:4: error: incompatible types: int cannot be converted to boolean
        if (x = 5) {
              ^
1 error
```

`x = 5` - присваивание, значение которого `5` типа `int`, а не `boolean`. Для вопроса «равно ли пяти» пишут `x == 5`.

**2. Число вместо условия.**

```java
int x = 5;
if (x) {
    System.out.println("Не ноль");
}
```

```text
Main.java:4: error: incompatible types: int cannot be converted to boolean
        if (x) {
            ^
1 error
```

В отличие от некоторых языков, в Java число не считается условием. Запишите сравнение явно: `x != 0`.

**3. Условие без скобок.**

```java
int x = 5;
if x > 3 {
    System.out.println("Больше трёх");
}
```

```text
Main.java:4: error: '(' expected
        if x > 3 {
          ^
Main.java:4: error: ')' expected
        if x > 3 {
                ^
2 errors
```

Сообщений несколько, но причина одна: после `if` нужна открывающая скобка. Исправляйте ошибки по порядку, начиная с первой.

**4. `else` без `if`.**

```java
int x = 5;
if (x > 3) {
    System.out.println("Больше");
};
else {
    System.out.println("Не больше");
}
```

```text
Main.java:7: error: 'else' without 'if'
        else {
        ^
1 error
```

Точка с запятой после закрывающей `}` завершила команду `if`, и `else` оказался «осиротевшим». Удалите `;` между `}` и `else`.

**5. Точка с запятой сразу после условия.** Эта ошибка компилятором не замечается:

```java run
public class Main {
    public static void main(String[] args) {
        int x = 1;
        if (x > 3);
        {
            System.out.println("Больше трёх");
        }
    }
}
```
```output
Больше трёх
```

Символ `;` после `if (x > 3)` образует пустую команду - «ветку» без действий. Блок ниже уже не относится к `if` и выполняется всегда, хотя условие ложно. Если ветка «срабатывает всегда», проверьте, нет ли лишней `;` после скобок условия.

**6. Вторая команда в ветке без фигурных скобок.**

```java run
public class Main {
    public static void main(String[] args) {
        int x = 1;
        if (x > 3)
            System.out.println("Больше трёх");
            System.out.println("Спасибо");
    }
}
```
```output
Спасибо
```

Отступ создаёт ложное впечатление, что обе строки относятся к `if`, но компилятору отступы безразличны: к ветке относится только первая команда. Вторая выполняется всегда. Ставьте фигурные скобки даже для одной команды.

**7. Неверный порядок условий.**

```java run
public class Main {
    public static void main(String[] args) {
        int score = 95;
        if (score >= 50) {
            System.out.println("зачёт");
        } else if (score >= 90) {
            System.out.println("отлично");
        }
    }
}
```
```output
зачёт
```

Баллы 95 удовлетворяют первому условию, поэтому вторая ветка недостижима: «отлично» не будет напечатано ни для каких баллов. Располагайте условия от узких к широким.

## Итоги

* `if (условие) { ... }` выполняет блок, только если условие равно `true`; `else` - блок для случая `false`; `else if` добавляет ещё одну проверку.
* В цепочке выполняется не более одной ветки - первая с истинным условием. Порядок условий важен: от узких к широким.
* Условие должно быть типа `boolean` и стоять в круглых скобках; фигурные скобки блока пишем всегда.
* Переменная из блока видна только внутри него.

Теперь программа умеет выбирать между двумя и более вариантами. Если вариантов много и все они определяются значением одной переменной, цепочка `else if` становится громоздкой; для таких случаев в Java есть более удобная команда - см. следующий урок: [Выбор из многих вариантов: switch](lesson:java.from-zero.switch).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Синтаксис как в C и JavaScript: условие в скобках, `else if` записывается двумя словами (не `elif` и не `elsif`).
* Условие обязано быть `boolean`: `if (x)` для числа или ссылки не компилируется, как и `if (x = 5)` для `int`. Исключение - `if (flag = true)` для `boolean`, которое компилируется и присваивает.
* Блок образует область видимости: переменная из блока недоступна снаружи. Объявлять во вложенном блоке переменную с именем, уже занятым локальной переменной внешнего блока, нельзя (в отличие от C и JavaScript, затенения локальных переменных нет).
* Фигурные скобки для одной команды необязательны, поэтому «висячий else» относится к ближайшему `if`; ошибку `goto fail` в стиле C предотвращает только дисциплина.
* Тернарный оператор `условие ? a : b` есть; в курсе он не вводится.
* Для выбора по значению есть `switch` (следующий урок); сопоставления с образцом в `if` (`obj instanceof Type t`) появятся в `java-fundamentals`.

## Как if превращается в переходы

Это необязательный раздел: для заданий он не нужен.

Компилятор не сохраняет слово `if` в байткоде. Условие превращается в команду сравнения и условного перехода: «если условие ложно, перейти к метке после блока». Цепочка `else if` - несколько таких переходов подряд, а после выполненной ветки стоит безусловный переход в конец всей команды. Можно увидеть это самому: команда `javap -c Main` печатает байткод скомпилированного класса, и в нём видны инструкции вида `if_icmpge` и `goto`.

Из этого следует, что порядок условий в цепочке - это порядок переходов: машина выполняет проверки строго последовательно и останавливается на первой истинной. Поэтому широкое условие, поставленное раньше узкого, делает узкую ветку недостижимой.
