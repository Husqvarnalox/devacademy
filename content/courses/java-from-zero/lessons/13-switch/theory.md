## Зачем нужен switch

Цепочка `else if` хорошо подходит для диапазонов («от 18 до 64»). Но часто нужно выбрать действие по **точному значению** одной переменной: номер дня недели, код операции, номер месяца. Запись из десяти веток `if (day == 1) ... else if (day == 2) ...` повторяет `day ==` в каждой строке и скрывает главное: мы выбираем по одному значению. Для таких случаев в Java есть команда `switch`.

## Одна новая идея: выбор по значению

**Команда `switch`** («переключатель») берёт одно значение и сравнивает его с перечисленными вариантами. Выполняется ветка, чей вариант совпал:

```java
switch (day) {
    case 1 -> System.out.println("Понедельник");
    case 2 -> System.out.println("Вторник");
    default -> System.out.println("Другой день");
}
```

* В скобках после `switch` - проверяемое значение (`day`).
* `case 1` («в случае 1») - вариант; после стрелки `->` стоит действие, которое выполняется при совпадении. Если действий несколько, их берут в блок `{ ... }`.
* `default` («по умолчанию») - ветка для всех остальных значений. Она необязательна, но почти всегда нужна: без неё при несовпадении ничего не произойдёт.
* Если нужно одно действие для нескольких значений, их перечисляют через запятую: `case 6, 7 -> ...`.

Выполняется только та ветка, которая совпала; остальные пропускаются. В записи со стрелкой не нужно слово `break`, и ветки не «проваливаются» одна в другую.

Так проверяют значения типов `int`, `char` и `String` (а также ещё нескольких типов, о которых позже). Дробные числа и `boolean` в `switch` не используются.

<!-- section: examples -->
## Пример 1. Номер дня недели

```java run
public class Main {
    public static void main(String[] args) {
        int day = 3;
        switch (day) {
            case 1 -> System.out.println("Понедельник");
            case 2 -> System.out.println("Вторник");
            case 3 -> System.out.println("Среда");
            default -> System.out.println("Другой день");
        }
        System.out.println("Готово");
    }
}
```
```output
Среда
Готово
```

Разбор:

* Значение `day` равно 3, поэтому выполняется только строка с `case 3`. Остальные пропущены.
* Строка «Готово» стоит после закрывающей скобки `switch`, поэтому выполняется всегда.
* Замените `day` на `7`: совпадений нет, выполняется ветка `default`.

## Пример 2. Несколько значений и блок

```java run
public class Main {
    public static void main(String[] args) {
        int day = 6;
        switch (day) {
            case 1, 2, 3, 4, 5 -> System.out.println("Рабочий день");
            case 6, 7 -> {
                System.out.println("Выходной");
                System.out.println("Можно отдыхать");
            }
            default -> System.out.println("Такого дня нет");
        }
    }
}
```
```output
Выходной
Можно отдыхать
```

Разбор:

* `case 1, 2, 3, 4, 5` объединяет пять значений в одну ветку: это короче, чем пять отдельных строк.
* Для значения 6 действий два, поэтому они взяты в блок `{ }`, как в `if`.
* Ветка `default` сработает для 0, для 8 и для любых других чисел: диапазоны перечислять не нужно.

## Пример 3. Выбор по символу: калькулятор

```java run
public class Main {
    public static void main(String[] args) {
        int a = 12;
        int b = 4;
        char op = '/';
        switch (op) {
            case '+' -> System.out.println(a + b);
            case '-' -> System.out.println(a - b);
            case '*' -> System.out.println(a * b);
            case '/' -> System.out.println(a / b);
            default -> System.out.println("Неизвестная операция: " + op);
        }
    }
}
```
```output
3
```

Разбор:

* Символы в вариантах записываются в одинарных кавычках, как значения типа `char`.
* `op` равно `'/'`, поэтому выполняется деление `12 / 4`. Для другого символа, например `'%'`, сработал бы `default`.

## Пример 4. switch, который возвращает значение

```java run
public class Main {
    public static void main(String[] args) {
        int month = 4;
        int days = switch (month) {
            case 2 -> 28;
            case 4, 6, 9, 11 -> 30;
            default -> 31;
        };
        System.out.println("Дней в месяце: " + days);
    }
}
```
```output
Дней в месяце: 30
```

Разбор:

* `switch` можно записать справа от `=`: тогда он вычисляет значение, и выбранная ветка задаёт его. После закрывающей скобки ставится `;`, как после обычной команды присваивания.
* У такой формы ветка `default` обязательна: переменной `days` нужно присвоить значение в любом случае.
* Это тот же выбор, только результат записывается в переменную, и не нужно повторять `days =` в каждой ветке.

**Попробуйте.** В примере 4 добавьте ветку `case 1, 3, 5, 7, 8, 10, 12 -> 31;` и измените `default` так, чтобы для номеров вне 1-12 переменная получала значение `0`. Проверьте месяцы 2, 7, 13.

## Точные правила

* Проверяемое значение имеет тип `int`, `char` или `String` (плюс ещё `byte`, `short` и перечисления; о них позже). Для `double`, `long` и `boolean` команда `switch` не работает.
* Варианты `case` - **константы**: литералы (`1`, `'a'`, `"да"`) или переменные с `final`, значение которых известно при компиляции. Переменная и выражение (`n + 1`, `x > 5`) вариантом быть не могут.
* Вариантом нельзя повторять одно и то же значение: компилятор сообщит `duplicate case label`.
* В одном `switch` нельзя смешивать запись со стрелкой (`case 1 ->`) и старую запись с двоеточием (`case 1:`).
* В форме с командой (пример 1) ветка `default` не обязательна. В форме, которая вычисляет значение (пример 4), она обязательна, если варианты не покрывают все возможные значения.
* Ветка со стрелкой содержит одно выражение, блок `{ }` или `throw`. Блок для `switch`-выражения должен завершаться значением (слово `yield`, о нём в курсе не говорится).
* Выполняется ровно одна ветка. Порядок вариантов не влияет на результат, кроме `default`: он срабатывает только когда совпадений нет, где бы ни стоял.
* Для строк `switch` сравнивает содержимое (так же, как метод `equals`, который разбирается в уроке о методах строк), а не ссылки.

## Типичные ошибки

**1. Переменная в варианте.**

```java
int day = 2;
int limit = 3;
switch (day) {
    case limit -> System.out.println("Лимит");
    default -> System.out.println("Другое");
}
```

```text
Main.java:6: error: constant expression required
            case limit -> System.out.println("Лимит");
                 ^
1 error
```

Вариант должен быть константой, известной при компиляции. Условие с переменной выражают командой `if`.

**2. Сравнение вместо значения.**

```java
int n = 7;
switch (n) {
    case n > 5 -> System.out.println("Много");
    default -> System.out.println("Мало");
}
```

```text
Main.java:5: error: incompatible types: boolean cannot be converted to int
            case n > 5 -> System.out.println("Много");
                   ^
1 error
```

`switch` проверяет равенство значения с вариантами; диапазоны и сравнения он не умеет. Для диапазонов используют `if / else if`.

**3. Повторяющийся вариант.**

```java
int day = 2;
switch (day) {
    case 1 -> System.out.println("Понедельник");
    case 1 -> System.out.println("Ещё раз понедельник");
    default -> System.out.println("Другой");
}
```

```text
Main.java:6: error: duplicate case label
            case 1 -> System.out.println("Ещё раз понедельник");
            ^
1 error
```

Одно и то же значение нельзя перечислять дважды: компилятор не знает, какая из веток нужна.

**4. Дробное число в switch.**

```java
double price = 2.5;
switch (price) {
    case 2.5 -> System.out.println("Два с половиной");
    default -> System.out.println("Другая цена");
}
```

```text
Main.java:4: error: selector type double is not allowed
        switch (price) {
               ^
1 error
```

Дробные числа приближённые, поэтому точное совпадение с вариантом ненадёжно; язык просто запрещает такой `switch`. Используйте `if` с допуском.

**5. Смесь стрелок и двоеточий.**

```java
int day = 2;
switch (day) {
    case 1 -> System.out.println("Понедельник");
    case 2: System.out.println("Вторник");
}
```

```text
Main.java:6: error: different case kinds used in the switch
            case 2: System.out.println("Вторник");
            ^
1 error
```

В одном `switch` выберите один вид записи: в этом курсе - со стрелкой.

**6. Нет `default` в `switch`, который вычисляет значение.**

```java
int day = 2;
String name = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
};
```

```text
Main.java:4: error: the switch expression does not cover all possible input values
        String name = switch (day) {
                      ^
1 error
```

Если день окажется равным 3, значения для `name` нет. Компилятор требует добавить `default`.

**7. Забытый `default` в форме с командой.** Ошибки компилятора нет, но при значении, которого нет среди вариантов, программа молча ничего не сделает. Например, `switch` по месяцу без `default` не выведет сообщение для месяца 13.

<!-- section: summary -->
## Итоги

* `switch` выбирает ветку по точному значению `int`, `char` или `String`; `default` обрабатывает все остальные значения.
* Запись `case значение -> действие` не требует `break`; для нескольких значений: `case 6, 7 -> ...`.
* `switch` можно записать справа от `=`: он вычисляет значение, и `default` обязателен.
* Диапазоны и сравнения остаются за `if / else if`.

Теперь программа умеет выбирать один из нескольких вариантов. Следующий большой шаг - повторять действия: [Цикл while: повторение, пока условие верно](lesson:java.from-zero.while-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Здесь используется стрелочная форма (Java 14+): без `break` и без «проваливания». Классическая форма `case 1: ... break;` по-прежнему допустима и в старом коде встречается чаще; в ней забытый `break` приводит к выполнению следующей ветки (как в C). Смешивать формы в одном `switch` нельзя.
* `switch` - это и выражение: `int d = switch (m) { case 2 -> 28; default -> 30; };`. Исчерпывающесть проверяет компилятор: для `enum` и закрытых иерархий `default` можно опустить.
* Допустимые типы: `byte`, `short`, `char`, `int`, их обёртки, `String`, `enum`. Типы `long`, `float`, `double`, `boolean` не поддерживаются; сопоставление с образцом (`case Circle c ->`) и условия `when` вышли в стабильную версию в Java 21.
* `case` принимает только константы времени компиляции. `String` сравнивается по содержимому (через `equals` и хеш), а не по ссылке, в отличие от `==`.
* Для `null` в селекторе `switch` бросает `NullPointerException`, если нет явного `case null` (Java 21+).
* Есть `yield` для блоков внутри `switch`-выражения; в курсе не используется.

## Во что превращается switch

Это необязательный раздел: для заданий он не нужен.

Для `int` компилятор строит одну из двух инструкций байткода: `tableswitch` (когда варианты идут почти подряд, это таблица переходов, индексируемая значением) или `lookupswitch` (отсортированный список пар «значение - адрес»). Поэтому `switch` по плотным числам выбирает ветку за одно обращение к таблице, а длинная цепочка `else if` проверяет условия по очереди.

Для `String` компилятор сначала вычисляет `hashCode` строки и выбирает по нему, а затем проверяет `equals`, чтобы отличить строки с одинаковым хешем. Для вас важно следствие: `switch` по строке сравнивает содержимое, а не ссылки. Все это видно командой `javap -c Main` после компиляции.
