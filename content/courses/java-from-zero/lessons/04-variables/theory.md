## Зачем нужны переменные

Программа работает со значениями: имя покупателя, число товаров, цена. Если записывать их прямо в команды вывода, то при каждом изменении придётся править много мест, и легко ошибиться. Переменная решает эту задачу: значение записывают один раз, дают ему имя и дальше пользуются именем.

**Переменная** - именованное место в памяти компьютера, в котором хранится значение. Представьте подписанную коробку: на коробке имя, внутри значение. Значение можно заменить, имя остаётся.

## Одна новая идея: объявление переменной

В Java переменную сначала **объявляют**: указывают, какого вида значения в ней будут лежать, и называют:

```java
int items = 3;
String name = "Анна";
```

Запись читается слева направо:

1. `int` - **тип**: слово, которое говорит, какие значения можно хранить. `int` (от integer) - целые числа: 3, 0, -15.
2. `items` - **имя** переменной. Его придумываете вы.
3. `=` - знак **присваивания**: «положить значение справа в переменную слева».
4. `3` - значение. Точка с запятой завершает команду.

Второй тип в уроке - `String`: текст в двойных кавычках. Заглавная буква в `String` обязательна. Остальные типы появятся в следующем уроке.

Знак `=` здесь не математическое равенство, а действие: «положить». Поэтому `items = 7;` читается как «записать в items число 7», и старое значение исчезает.

## Пример 1. Переменные в выводе

```java run
public class Main {
    public static void main(String[] args) {
        String name = "Анна";
        int items = 3;
        System.out.println("Покупатель: " + name);
        System.out.println("Товаров в корзине: " + items);
    }
}
```
```output
Покупатель: Анна
Товаров в корзине: 3
```

Разбор:

* `String name = "Анна";` создаёт переменную `name` типа `String` и кладёт в неё текст `Анна`.
* `int items = 3;` создаёт переменную `items` типа `int` и кладёт в неё число 3.
* В командах вывода имя переменной стоит **без кавычек**: компилятор берёт значение из переменной. С кавычками было бы напечатано само слово.
* Склейка `"Покупатель: " + name` работает так же, как с литералом в прошлом уроке: вместо числа или текста подставляется значение переменной.

## Пример 2. Изменение значения и копирование

```java run
public class Main {
    public static void main(String[] args) {
        int balance = 100;
        System.out.println("Было: " + balance);
        balance = 250;
        System.out.println("Стало: " + balance);

        int saved = balance;
        balance = 10;
        System.out.println("Сохранено: " + saved);
        System.out.println("Сейчас: " + balance);
    }
}
```
```output
Было: 100
Стало: 250
Сохранено: 250
Сейчас: 10
```

Разбор:

* `balance = 250;` - присваивание **без типа**: переменная уже существует, мы только меняем значение. Слово `int` второй раз не пишут.
* `int saved = balance;` - новая переменная получает **копию** текущего значения (250).
* `balance = 10;` меняет только `balance`; `saved` остаётся 250. Переменные после копирования не связаны.

## Пример 3. Объявление и присваивание отдельно

```java run
public class Main {
    public static void main(String[] args) {
        int count;
        count = 5;
        System.out.println("Значение: " + count);
    }
}
```
```output
Значение: 5
```

Объявить можно без значения, но прочитать переменную можно только после того, как ей что-то присвоено.

**Попробуйте.** Объявите `String city = "Казань";` и напечатайте `"Город: " + city`. Потом замените значение присваиванием `city = "Самара";` и предскажите вывод ещё одной такой же команды.

## Точные правила

* Объявление: `Тип имя = значение;`. Можно объявить без значения: `Тип имя;`, а присвоить позже: `имя = значение;`.
* Значение должно подходить по типу: в `int` кладут целое число, в `String` - текст в двойных кавычках. Несоответствие - ошибка компиляции (подробно - в следующем уроке).
* Присваивание **справа налево**: сначала вычисляется то, что справа, затем результат кладётся в переменную слева. Так, `int saved = balance;` копирует значение.
* **Имя** состоит из букв, цифр и знаков `_` и `$`; цифрой начинаться не может. Регистр важен: `items` и `Items` - разные переменные. Зарезервированные слова (`class`, `int`, `public`, `static` и другие) именами быть не могут.
* Принято писать имена на английском в стиле **camelCase**: первое слово строчными, следующие с заглавной - `itemCount`, `totalPrice`. Имя должно говорить о смысле: `items` понятнее, чем `x`. Имена типов начинаются с заглавной (`String`), имена переменных - со строчной.
* Переменную нужно объявить **раньше**, чем использовать: компилятор читает сверху вниз.
* В одном методе дважды объявить одно имя нельзя. Изменить уже существующую переменную можно только присваиванием без типа.
* Прочитать локальную переменную, которой ещё ничего не присвоили, нельзя: компилятор сообщит `might not have been initialized`.
* Кавычки меняют смысл: `name` - переменная, `"name"` - текст из четырёх букв.

## Типичные ошибки

**1. Использование до объявления.**

```java
System.out.println(price);
int price = 100;
```

```text
Main.java:3: error: cannot find symbol
        System.out.println(price);
                           ^
  symbol:   variable price
  location: class Main
```

На третьей строке компилятор ещё не знает имени `price`. Поставьте объявление выше использования.

**2. Второе объявление с тем же именем.**

```java
int price = 100;
int price = 200;
```

```text
Main.java:4: error: variable price is already defined in method main(String[])
        int price = 200;
            ^
```

Второй `int` пытается создать ещё одну переменную с тем же именем. Для изменения значения пишут `price = 200;` без типа.

**3. Чтение переменной без значения.**

```java
int price;
System.out.println(price);
```

```text
Main.java:4: error: variable price might not have been initialized
        System.out.println(price);
                           ^
```

Переменная объявлена, но ничего в неё не положено. Присвойте значение раньше или объявите сразу со значением.

**4. Значение другого типа.**

```java
int count = "три";
```

```text
Main.java:3: error: incompatible types: String cannot be converted to int
        int count = "три";
                    ^
```

В `int` нельзя положить текст. Сообщение называет оба типа: что пытались положить (`String`) и во что (`int`).

**5. Присваивание без объявления.**

```java
count = 3;
```

```text
Main.java:3: error: cannot find symbol
        count = 3;
        ^
  symbol:   variable count
  location: class Main
```

Первое присваивание должно быть объявлением: `int count = 3;`.

**6. Текст без кавычек или имя в кавычках.** `String name = Анна;` даёт `cannot find symbol` (Java ищет переменную с именем `Анна`). Обратное тоже ошибка по смыслу: `System.out.println("name")` напечатает слово `name`, а не значение переменной.

## Итоги

* Переменная - именованное место для значения; объявление состоит из типа, имени и (обычно) начального значения.
* `=` - присваивание: справа налево, значение копируется, старое значение заменяется.
* `int` хранит целые числа, `String` - текст; имена пишут в camelCase, объявляют один раз и до использования.
* Имя без кавычек даёт значение переменной, имя в кавычках - просто текст.

Какие ещё бывают типы, почему тип нельзя поменять и что делать с дробными числами, расскажет следующий урок ([Типы данных: int, double, boolean, char, String](lesson:java.from-zero.basic-types)).

## Для тех, кто уже программирует

* Java статически типизирована: тип указывают при объявлении, и он не меняется. Присвоить `String` переменной типа `int` нельзя (ошибка компиляции), в отличие от Python и JavaScript.
* Локальная переменная не имеет значения по умолчанию: чтение до присваивания - ошибка компиляции (`might not have been initialized`). Значения по умолчанию есть только у полей и элементов массивов.
* Повторное объявление имени в той же области видимости запрещено; затенение локальной переменной другой локальной внутри вложенного блока - тоже ошибка (в отличие от JavaScript и Go).
* Вывод типа: `var items = 3;` с Java 10 для локальных переменных; в курсе тип пишется явно, чтобы он был виден.
* `String` - ссылочный тип (объект), `int` - примитив; различие важно для сравнения и `null`, подробно - в курсе «Java: первые шаги».
* Соглашения: `camelCase` для переменных и методов, `PascalCase` для классов, `UPPER_SNAKE_CASE` для констант.

## Что такое «место в памяти»

Это необязательный раздел: для заданий он не нужен.

Когда метод `main` начинает работу, виртуальная машина выделяет ему небольшую область памяти - **кадр вызова**, где лежат локальные переменные. Для `int` отводится 4 байта, и в них записывается число. В переменной типа `String` лежит не сам текст, а **ссылка** на объект с текстом в другой области памяти (куче). Поэтому `int saved = balance;` копирует число, а `String copy = name;` копирует ссылку: оба имени указывают на один и тот же текст. Текст в Java неизменяем, поэтому разницы вы не заметите; она станет важной, когда появятся изменяемые объекты.

Когда метод завершается, его кадр освобождается, и переменные перестают существовать. Именно поэтому нельзя использовать переменную за пределами метода, где она объявлена; к этому мы вернёмся в уроке о методах.
