## Зачем нужны типы

Значения бывают разными: количество товаров - целое число, цена - число с копейками, «есть в наличии» - да или нет, оценка - одна буква, название - текст. Компьютер хранит их по-разному и выполняет над ними разные действия: числа складывают, текст склеивают, у ответа «да/нет» нет сложения вовсе. Чтобы не перепутать, Java требует указывать **тип** каждой переменной.

Тип отвечает на три вопроса: какие значения допустимы, сколько памяти нужно и какие действия разрешены. Проверка типов происходит при компиляции: ошибка находится до запуска, а не посреди работы программы.

## Одна новая идея: пять основных типов

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `int` | целое число | `42`, `0`, `-15` |
| `double` | число с дробной частью | `59.9`, `0.5`, `-3.0` |
| `boolean` | логическое значение «да/нет» | `true`, `false` |
| `char` | один символ | `'A'`, `'я'`, `'7'` |
| `String` | текст (последовательность символов) | `"Тетрадь"`, `""` |

Значение, записанное прямо в программе, называется **литералом**: `42` - литерал типа `int`, `59.9` - `double`, `'A'` - `char`, `"Тетрадь"` - `String`. Вид литерала определяет его тип: десятичная точка превращает число в `double`, одинарные кавычки - в `char`, двойные - в `String`.

Если значение не должно меняться (например, ставка налога), переменную объявляют с ключевым словом `final`: присвоить значение можно только один раз.

<!-- section: examples -->
## Пример 1. Пять типов в одной программе

```java run
public class Main {
    public static void main(String[] args) {
        int quantity = 3;
        double price = 59.9;
        boolean inStock = true;
        char grade = 'A';
        String title = "Тетрадь";
        System.out.println(title);
        System.out.println(quantity);
        System.out.println(price);
        System.out.println(inStock);
        System.out.println(grade);
    }
}
```
```output
Тетрадь
3
59.9
true
A
```

Разбор:

* Для каждой переменной выбран тип, который подходит значению: целое количество - `int`, цена - `double`, наличие - `boolean`, одна буква - `char`, название - `String`.
* `println` умеет печатать значение любого из этих типов. Логические значения печатаются словами `true` и `false`.

## Пример 2. int и double, char и String

```java run
public class Main {
    public static void main(String[] args) {
        double a = 3;
        double b = 3.0;
        System.out.println(a);
        System.out.println(b);

        char letter = 'A';
        String word = "A";
        System.out.println(letter);
        System.out.println(word);

        long population = 3000000000L;
        System.out.println(population);
    }
}
```
```output
3.0
3.0
A
A
3000000000
```

Разбор:

* В `double` можно положить целое число: `3` превратится в `3.0`. Обратное запрещено: `int x = 3.5;` не скомпилируется.
* `'A'` и `"A"` печатаются одинаково, но это разные типы. `char` - один символ, а `String` - текст, пусть даже из одной буквы. Позже у них будут разные возможности.
* Для очень больших целых чисел есть тип `long` (его диапазон намного шире, чем у `int`). Литерал для `long` пишут с буквой `L` на конце. Пока достаточно знать, что такой тип существует.

## Пример 3. Неизменяемое значение

```java run
public class Main {
    public static void main(String[] args) {
        final double VAT_RATE = 0.2;
        System.out.println("Ставка налога: " + VAT_RATE);
    }
}
```
```output
Ставка налога: 0.2
```

Слово `final` («окончательный») запрещает менять значение. Имена таких переменных принято писать заглавными буквами с подчёркиванием: `VAT_RATE`. Попытка сделать `VAT_RATE = 0.3;` вызовет ошибку компиляции, и значение не изменится случайно.

**Попробуйте.** Объявите `int age = 25;` и `double height = 1.8;`, напечатайте обе переменные. Затем замените `1.8` на `2` и предскажите, что напечатается.

## Точные правила

* **`int`** - 32-битное целое: от -2 147 483 648 до 2 147 483 647. Литерал за пределами диапазона (`3000000000`) - ошибка компиляции `integer number too large`; такое число пишут как `long` с буквой `L`: `3000000000L`. Для читаемости допустимы подчёркивания: `1_000_000`.
* **`long`** - 64-битное целое, литерал с `L`. В курсе используется редко; детали переполнения - в курсе «Java: первые шаги».
* **`double`** - число с дробной частью (64 бита, около 15-16 значащих цифр). Литерал содержит точку: `59.9`. Разделитель - **точка**, а не запятая. Результаты вычислений с `double` приближённые (следующие уроки).
* Печать `double`: целое значение выводится с `.0` (`3.0`), очень большие и очень малые числа - в научной записи (`1.2345678E7`, `1.2E-4`). Для аккуратного вывода есть форматирование (отдельный урок).
* **`boolean`** - только `true` или `false`, строчными буквами. Числа и текст в `boolean` не превращаются.
* **`char`** - один символ в одинарных кавычках. Внутри `char` хранится числовой код символа, но для вывода это неважно.
* **`String`** - текст в двойных кавычках; может быть пустым (`""`). Имя типа пишется с заглавной буквы.
* Строгая типизация: переменная всегда имеет один тип. Целое можно положить в `double`, но `double` в `int` - нет, потому что дробная часть потерялась бы. Любое другое несоответствие - ошибка компиляции `incompatible types`.
* **`final`** перед типом запрещает повторное присваивание. Имена констант принято писать как `MAX_COUNT`.

## Типичные ошибки

**1. Дробное число в `int`.**

```java
int x = 3.5;
```

```text
Main.java:3: error: incompatible types: possible lossy conversion from double to int
        int x = 3.5;
                ^
```

«Lossy conversion» - преобразование с потерей: дробная часть пропала бы. Либо поменяйте тип на `double`, либо позже научитесь явно преобразовывать значение.

**2. Слишком большое целое число.**

```java
int big = 3000000000;
```

```text
Main.java:3: error: integer number too large
        int big = 3000000000;
                  ^
```

Число не помещается в `int`. Если оно действительно нужно, используйте `long` и букву `L`: `long big = 3000000000L;`.

**3. Текст в `char`.**

```java
char c = "a";
```

```text
Main.java:3: error: incompatible types: String cannot be converted to char
        char c = "a";
                 ^
```

Двойные кавычки всегда означают `String`. Для `char` нужны одинарные: `'a'`.

**4. Число в `boolean` (и наоборот).**

```java
boolean b = 1;
```

```text
Main.java:3: error: incompatible types: int cannot be converted to boolean
        boolean b = 1;
                    ^
```

В Java ноль и единица не заменяют `false` и `true`. Пишите `true` или `false`.

**5. Изменение `final`.**

```java
final int limit = 10;
limit = 20;
```

```text
Main.java:4: error: cannot assign a value to final variable limit
        limit = 20;
        ^
```

Это защита от случайного изменения: если значение должно меняться, уберите `final`.

**6. Одинарные кавычки вокруг слова.** `String s = 'abc';` даёт три ошибки подряд (`unclosed character literal`, `not a statement`): компилятор считает, что `'a` - начало `char`. Текст из нескольких букв всегда в двойных кавычках.

## Итоги

* Тип определяет, какие значения хранит переменная: `int` - целые, `double` - дробные, `boolean` - `true`/`false`, `char` - один символ, `String` - текст.
* Вид литерала подсказывает тип: точка - `double`, одинарные кавычки - `char`, двойные - `String`.
* Целое число можно положить в `double`, дробное в `int` - нет; несоответствие типов находится при компиляции.
* `final` защищает значение от изменения.

В следующем уроке ([Арифметика](lesson:java.from-zero.arithmetic)) с этими значениями начнут выполнять действия: складывать, вычитать, делить и узнавать остаток.

## Для тех, кто уже программирует

* Примитивы (`int`, `long`, `double`, `boolean`, `char` и ещё `byte`, `short`, `float`) не объекты и не могут быть `null`; `String` - ссылочный тип с особым синтаксисом литералов.
* `int` всегда 32 бита, независимо от платформы. Целые типы знаковые, беззнаковых нет. Переполнение молча «заворачивается»: `Integer.MAX_VALUE + 1` даёт `Integer.MIN_VALUE`.
* `char` - 16-битная единица UTF-16, а не «символ Unicode»: символы вне базовой плоскости (например, эмодзи) занимают два `char`.
* Неявное расширение (`int` → `long` → `double`) разрешено, сужение требует явного приведения. Из-за этого `int x = 3.5;` не компилируется, в отличие от C/C++ с предупреждением.
* `boolean` не приводится к числу и не используется в условиях как «истина/ложь» для чисел и строк (как в C, Python, JS).
* `final` для локальных переменных - аналог `const` в JavaScript (но не глубокая неизменяемость) и Go; константы класса пишут `static final`.

## Как double хранит числа

Это необязательный раздел: для заданий он не нужен.

`double` хранится в 64 битах по стандарту IEEE 754: один бит знака, 11 бит порядка и 52 бита мантиссы. Число представляется как мантисса, умноженная на степень двойки. Поэтому дроби, которые в десятичной системе выглядят «круглыми», в двоичной часто бесконечны: `0.1` нельзя записать точно, так же как 1/3 нельзя точно записать десятичной дробью. В `double` лежит ближайшее представимое число. Эта неточность видна в вычислениях: в уроке об арифметике мы увидим результат `0.1 + 0.2`.

`int` устроен проще: 32 бита в дополнительном коде, значения от -2^31 до 2^31 - 1. У `boolean` всего два значения, но виртуальная машина обычно хранит его в целой ячейке: экономить память на одном бите для отдельной переменной не имеет смысла.
