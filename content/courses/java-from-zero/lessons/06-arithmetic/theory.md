## Зачем нужна арифметика

Почти любая программа что-то считает: сумму чека, время в часах и минутах, скидку, среднюю оценку. Для этого в Java есть операторы - знаки, которые выполняют действия над значениями. Если неправильно понять, как они работают с целыми числами, программа выдаст неожиданный результат без всякого сообщения об ошибке. Поэтому этот урок учит не только считать, но и предсказывать результат.

## Одна новая идея: результат зависит от типов операндов

Операторы арифметики:

| Оператор | Действие | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `17 + 5` | `22` |
| `-` | вычитание | `17 - 5` | `12` |
| `*` | умножение | `17 * 5` | `85` |
| `/` | деление | `17 / 5` | `3` |
| `%` | остаток от деления | `17 % 5` | `2` |

Главная особенность - деление. Если **оба** числа целые, результат тоже целый, а дробная часть отбрасывается: `17 / 5` равно `3`, а не `3.4`. Это называется **целочисленным делением**. Остаток от него получают оператором `%`: `17 = 3 * 5 + 2`. Если хотя бы одно из чисел `double`, деление обычное: `17 / 5.0` равно `3.4`.

Целочисленное деление не ошибка и не округление, а определённое правило: «сколько раз целиком поместилось». Оно полезно именно для таких задач, как перевод минут в часы или раздача поровну.

<!-- section: examples -->
## Пример 1. Пять операторов

```java run
public class Main {
    public static void main(String[] args) {
        int a = 17;
        int b = 5;
        System.out.println(a + b);
        System.out.println(a - b);
        System.out.println(a * b);
        System.out.println(a / b);
        System.out.println(a % b);
        System.out.println(17 / 5.0);
    }
}
```
```output
22
12
85
3
2
3.4
```

Разбор: четыре первые строки - обычная арифметика, пятая - остаток. В последней строке одно из чисел `double` (`5.0`), поэтому деление дробное. Остаток удобно использовать, чтобы проверить чётность (`n % 2`), узнать последнюю цифру (`n % 10`) или получить минуты после вычитания целых часов.

## Пример 2. Порядок действий и скобки

```java run
public class Main {
    public static void main(String[] args) {
        int price = 40;
        int count = 3;
        System.out.println("Сумма: " + price * count);
        System.out.println("Сумма: " + price + count);
        System.out.println("Сумма: " + (price + count));
        System.out.println(2 + 3 * 4);
        System.out.println((2 + 3) * 4);
    }
}
```
```output
Сумма: 120
Сумма: 403
Сумма: 43
14
20
```

Разбор:

* Умножение, деление и остаток выполняются раньше сложения и вычитания, как в школьной математике. Поэтому `2 + 3 * 4` равно 14. Скобки меняют порядок: `(2 + 3) * 4` равно 20.
* В первой строке `price * count` вычисляется раньше склейки (`*` сильнее `+`), и к тексту приклеивается число 120.
* Во второй строке умножения нет, и выражение читается слева направо: `"Сумма: " + price` даёт текст `Сумма: 40`, затем к нему приклеивается 3. Получилось `403`, а не 43.
* В третьей строке скобки заставляют сначала сложить числа.

## Пример 3. Целое, дробное и неточность

```java run
public class Main {
    public static void main(String[] args) {
        System.out.println(7 / 2);
        System.out.println(7 % 2);
        System.out.println(-7 / 2);
        System.out.println(-7 % 2);
        System.out.println(7 / 2.0);
        System.out.println(0.1 + 0.2);
    }
}
```
```output
3
1
-3
-1
3.5
0.30000000000000004
```

Разбор:

* `-7 / 2` равно `-3`: дробная часть отбрасывается к нулю, а не вниз. Остаток `-7 % 2` равен `-1`: знак остатка совпадает со знаком делимого.
* Сумма `0.1 + 0.2` в `double` не равна `0.3` точно. Дело в том, что `double` хранит числа в двоичной системе, а десятичная дробь 0.1 в ней бесконечная. Поэтому для денег в учебных задачах используют целые числа (рубли или копейки), а результаты дробных вычислений не сравнивают на точное равенство.

## Пример 4. Изменение переменной

```java run
public class Main {
    public static void main(String[] args) {
        int score = 10;
        score += 5;
        System.out.println(score);
        score -= 3;
        System.out.println(score);
        score *= 2;
        System.out.println(score);
        score++;
        System.out.println(score);
        score--;
        System.out.println(score);
    }
}
```
```output
15
12
24
25
24
```

`score += 5;` - сокращённая запись `score = score + 5;`: «прибавить 5 к текущему значению». То же с `-=`, `*=`, `/=`, `%=`. `score++` увеличивает значение на 1, `score--` уменьшает на 1. Эти записи нужны в циклах, до которых мы скоро дойдём.

**Попробуйте.** Предскажите, что напечатает `System.out.println(10 - 4 - 3);` и `System.out.println(100 / 10 / 5);`. Операторы одного приоритета выполняются слева направо.

## Точные правила

* Приоритет: сначала `*`, `/`, `%` (слева направо), затем `+`, `-` (слева направо). Скобки `( )` всегда выполняются первыми.
* Если оба операнда `int`, результат `int`. Если хотя бы один `double` - результат `double`: целое число автоматически превращается в `double`.
* Целочисленное деление отбрасывает дробную часть **к нулю**: `7 / 2` = 3, `-7 / 2` = -3. Остаток: `a % b` равен `a - (a / b) * b`; знак остатка совпадает со знаком `a`.
* Тип результата определяется операндами, а не переменной слева от `=`. В `double half = 1 / 2;` сначала вычисляется `1 / 2` = 0, и только потом 0 становится 0.0.
* Деление целого на ноль (`n / 0`, `n % 0`) - ошибка времени выполнения `ArithmeticException: / by zero`. Деление `double` на ноль ошибки не вызывает: результат `Infinity`, `-Infinity` или `NaN` («не число»).
* Результат вычисления с `double` бывает неточным (`0.1 + 0.2` = `0.30000000000000004`). Это свойство двоичного представления, а не ошибка языка.
* Составное присваивание `x op= y` равно `x = x op y`. `x++` и `x--` увеличивают и уменьшают переменную на 1; отдельной командой их пишут как `x++;`.
* Чтобы сложить число с текстом **после** текста, нужны скобки: `"Сумма: " + (a + b)`.
* Умножение всегда пишется знаком `*`: `2(3 + 4)` не работает.

## Типичные ошибки

**1. Ожидают дробь от деления целых.**

```java
double half = 1 / 2;
System.out.println(half);
```

Печатает `0.0`. Оба операнда целые, поэтому `1 / 2` равно 0, и 0 затем кладётся в `double`. Сделайте один из операндов дробным: `1 / 2.0` или `1.0 / 2`.

**2. Склейка вместо сложения.**

```java
int a = 17;
int b = 5;
System.out.println("a + b = " + a + b);
```

Печатает `a + b = 175`: вычисление идёт слева направо, и каждое число приклеивается к тексту. Нужно `"a + b = " + (a + b)`.

**3. Деление на ноль.**

```java
System.out.println(10 / 0);
```

```text
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at Main.main(Main.java:3)
```

Программа собралась, но остановилась при выполнении. Всё, что она успела напечатать до этой команды, остаётся на экране. Проверка делителя перед делением - в уроках про условия.

**4. Результат `double` в `int`.**

```java
double avg = 10 / 3.0;
int r = avg;
```

```text
Main.java:4: error: incompatible types: possible lossy conversion from double to int
        int r = avg;
                ^
```

Результат деления с дробным операндом нельзя молча положить в `int`. Либо храните его в `double`, либо явно преобразуйте (отдельный урок).

**5. Пропущенный знак умножения.**

```java
System.out.println(2(3 + 4));
```

```text
Main.java:3: error: ')' or ',' expected
        System.out.println(2(3 + 4));
                            ^
```

В Java умножение пишут всегда: `2 * (3 + 4)`.

**6. Сравнение дробных результатов «на глаз».** Если `0.1 + 0.2` напечатал `0.30000000000000004`, это не сломанный компьютер. Не рассчитывайте, что дробные вычисления дают «красивое» число, и не сравнивайте их на точное равенство.

<!-- section: summary -->
## Итоги

* Есть пять операторов: `+`, `-`, `*`, `/`, `%`; умножение, деление и остаток выполняются раньше сложения и вычитания, скобки меняют порядок.
* Деление двух `int` даёт целое с отбрасыванием дробной части, остаток даёт `%`. Достаточно одного `double`, чтобы деление стало дробным.
* Выражение вычисляется слева направо: после текста `+` склеивает, а не складывает. Сумму берут в скобки.
* `+=`, `-=`, `*=`, `/=`, `++` и `--` меняют переменную на месте.
* Деление целого на ноль останавливает программу ошибкой выполнения; результаты `double` бывают приближёнными.

В следующем уроке ([Строки: длина, буквы и регистр](lesson:java.from-zero.strings)) мы подробнее познакомимся со `String`: узнаем длину текста, выберем отдельные буквы и изменим регистр.

## Для тех, кто уже программирует

* `/` для двух целых - целочисленное деление, как в C, Go, Rust и Kotlin (в Python и JavaScript есть отдельные `//` и `Math.floor`). Деление округляет **к нулю**, а `%` имеет знак делимого: `-7 / 2 == -3`, `-7 % 2 == -1`. Для неотрицательного остатка есть `Math.floorMod`.
* Переполнение `int` и `long` молча «заворачивается»; `Math.addExact` и аналоги бросают `ArithmeticException`.
* Деление целого на ноль - `ArithmeticException`, деление `double` на ноль - `Infinity`/`NaN`; `NaN != NaN`.
* Оператора возведения в степень нет: используют `Math.pow` (возвращает `double`) или умножение.
* Приоритет и ассоциативность как в C. Составные присваивания (`+=` и другие) делают неявное приведение к типу левой части: `byte b = 1; b += 1;` допустимо.
* `++`/`--` есть в префиксной и постфиксной форме; в курсе они используются только как отдельные команды.
* Склейка строк использует тот же `+`; `"a" + 1 + 2` - `"a12"`, `1 + 2 + "a"` - `"3a"`.

<!-- section: deep-dive -->
## Почему остаток и деление связаны

Это необязательный раздел: для заданий он не нужен.

Для целых чисел Java гарантирует тождество `(a / b) * b + a % b == a` при `b != 0`. Из него вытекают оба правила: раз деление отбрасывает дробь к нулю, остаток обязан иметь знак делимого, иначе равенство не сойдётся. Для `-7` и `2`: `-7 / 2 = -3`, `(-3) * 2 = -6`, значит `-7 % 2 = -1`.

Процессоры выполняют целочисленное деление отдельной командой, которая возвращает и частное, и остаток. Поэтому запись `a / b` и `a % b` рядом не доставляет лишних расходов.
