## Зачем управлять циклом

Обычный цикл выполняется, пока верно его условие. Но часто нужно вмешаться изнутри: прекратить поиск, как только найден нужный товар; пропустить ошибочную запись и продолжить со следующей; закончить чтение по специальному знаку «конец». В этом уроке две команды для таких случаев и ещё один приём - цикл внутри цикла.

## Одна новая идея: break и continue

**Команда `break`** («прервать») немедленно завершает цикл, в котором она написана. Выполнение продолжается с первой команды после цикла:

```java
for (int i = 1; i <= 10; i++) {
    if (i == 4) {
        break;
    }
    System.out.println(i);
}
```

Этот цикл печатает 1, 2, 3 и на четвёртой итерации выходит.

**Команда `continue`** («продолжить») завершает только текущую итерацию и переходит к следующей: остаток тела пропускается, а шаг и проверка условия выполняются как обычно:

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}
```

Этот цикл печатает 1, 2, 4, 5: итерация для 3 пропущена.

**Вложенный цикл** - цикл, записанный внутри тела другого цикла. За одну итерацию внешнего цикла внутренний выполняется целиком. Если внешний выполняется 3 раза, а внутренний - 4, то тело внутреннего выполнится 12 раз.

Обе команды работают только внутри цикла, и обе обычно стоят внутри `if`: безусловный `break` в начале тела просто остановил бы цикл на первой итерации.

## Пример 1. break: прекратить поиск

```java run
public class Main {
    public static void main(String[] args) {
        for (int n = 51; n <= 100; n++) {
            if (n % 7 == 0) {
                System.out.println("Первое число, кратное 7, после 50: " + n);
                break;
            }
        }
        System.out.println("Поиск закончен");
    }
}
```
```output
Первое число, кратное 7, после 50: 56
Поиск закончен
```

Разбор:

* Перебор идёт с 51, и уже на 56 условие `n % 7 == 0` истинно. Строка печатается, `break` выходит из цикла, оставшиеся числа до 100 не проверяются.
* Строка «Поиск закончен» стоит после цикла и выполняется после `break` один раз.

## Пример 2. continue: пропустить итерацию

```java run
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("5 -2 8 -1 4");
        int sum = 0;
        int skipped = 0;
        while (in.hasNextInt()) {
            int x = in.nextInt();
            if (x < 0) {
                skipped++;
                continue;
            }
            sum += x;
        }
        System.out.println("Сумма: " + sum);
        System.out.println("Пропущено: " + skipped);
    }
}
```
```output
Сумма: 17
Пропущено: 2
```

Разбор:

* Ввод задан в программе, чтобы пример можно было запустить. Для отрицательного числа `continue` пропускает `sum += x` и возвращается к проверке `hasNextInt()`.
* Число прочитано до `continue`, поэтому ввод продолжается со следующего: цикл не застревает. Если бы чтение стояло после `continue`, цикл читал бы одно и то же число бесконечно (это ошибка №3 ниже).
* Результат: 5 + 8 + 4 = 17, два отрицательных пропущены.

## Пример 3. Выход по специальному значению

```java run
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("12 30 0 99 7");
        int total = 0;
        while (in.hasNextInt()) {
            int x = in.nextInt();
            if (x == 0) {
                break;
            }
            total += x;
        }
        System.out.println("До нуля набрано: " + total);
        System.out.println("Следующее число во вводе: " + in.nextInt());
    }
}
```
```output
До нуля набрано: 42
Следующее число во вводе: 99
```

Разбор:

* Число `0` служит знаком «конец списка»: данные после него не должны попасть в сумму. Такое значение называют **сторожевым**.
* После `break` ввод остаётся непрочитанным с числа 99, поэтому `in.nextInt()` вернёт 99.

## Пример 4. Вложенные циклы

```java run
public class Main {
    public static void main(String[] args) {
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= 4; col++) {
                System.out.print(row * col + " ");
            }
            System.out.println();
        }
    }
}
```
```output
1 2 3 4 
2 4 6 8 
3 6 9 12 
```

Разбор:

* Внешний цикл отвечает за строки, внутренний - за числа в строке. На каждой строке внутренний цикл проходит значения `col` от 1 до 4.
* `print` печатает без перевода строки, поэтому числа одной строки идут подряд. `println()` без аргументов после внутреннего цикла переводит строку.
* Тело внутреннего цикла выполнилось 3 · 4 = 12 раз.

## Пример 5. break во вложенном цикле

```java run
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == 2) {
                    break;
                }
                System.out.println("i=" + i + ", j=" + j);
            }
        }
    }
}
```
```output
i=1, j=1
i=2, j=1
i=3, j=1
```

Разбор:

* `break` завершает только тот цикл, в котором записан, то есть внутренний. Для каждого `i` внутренний цикл успевает выполнить одну итерацию (`j = 1`) и выходит на `j = 2`; внешний цикл продолжается.
* Выйти сразу из обоих циклов одной командой `break` нельзя: для этого обычно выносят цикл в метод и используют `return` (урок о методах).

**Попробуйте.** В примере 4 замените строки на звёздочки: печатайте `"*"` вместо произведения, а внутренний цикл ограничьте условием `col <= row`. Предскажите форму рисунка до запуска.

## Точные правила

* `break` завершает самый внутренний цикл (или `switch`), в котором он написан. После него выполняется команда, следующая за этим циклом.
* `continue` завершает текущую итерацию. В `for` после него выполняется шаг (`i++`) и проверка условия; в `while` - сразу проверка условия. Поэтому в `while` изменение счётчика должно стоять **до** `continue`.
* `break` и `continue` допустимы только внутри цикла (`break` - ещё и внутри `switch`). Вне цикла компилятор сообщит об ошибке.
* Команда сразу после `break` или `continue` в том же блоке недостижима, компилятор считает это ошибкой (`unreachable statement`).
* У вложенных циклов должны быть разные имена переменных цикла; внутренний цикл выполняется заново для каждой итерации внешнего.
* Число выполнений тела внутреннего цикла равно произведению числа итераций внешнего и внутреннего, если границы внутреннего не зависят от внешнего.
* `break` и `continue` не заменяют правильное условие цикла. Если выход нужен «по условию», нередко его можно записать в самом условии `while`; но для сторожевого значения и ранней остановки поиска `break` читается лучше.

## Типичные ошибки

**1. `break` вне цикла.**

```java
int x = 5;
if (x > 3) {
    break;
}
```

```text
Main.java:5: error: break outside switch or loop
            break;
            ^
1 error
```

`break` относится к циклу или `switch`. В `if` без цикла выйти «из блока» нельзя.

**2. Команда после `break`.**

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
    break;
    System.out.println("после break");
}
```

```text
Main.java:6: error: unreachable statement
            System.out.println("после break");
            ^
1 error
```

После `break` управление сразу покидает цикл, поэтому следующая команда никогда не выполнится. Компилятор запрещает такой код.

**3. `continue` в `while` до изменения счётчика.**

```java
int i = 0;
while (i < 5) {
    if (i == 2) {
        continue;
    }
    System.out.println(i);
    i++;
}
```

Компилятор не возражает, но программа печатает 0, 1 и зависает: при `i == 2` `continue` возвращает к проверке условия, а `i++` пропущен, поэтому `i` навсегда остаётся равным 2. В `for` такой ошибки нет, потому что шаг стоит в заголовке. В `while` меняйте счётчик до `continue` или используйте `for`.

**4. `break` не там, где ожидали.** Во вложенных циклах `break` выходит только из внутреннего (пример 5). Если после него внешний цикл продолжает работать, а вы хотели остановить всё, ищите команду `break` во внешнем цикле или вынесите цикл в метод.

**5. Одинаковое имя счётчика во вложенных циклах.**

```java
for (int i = 0; i < 2; i++) {
    for (int i = 0; i < 2; i++) {
        System.out.println(i);
    }
}
```

```text
Main.java:4: error: variable i is already defined in method main(String[])
            for (int i = 0; i < 2; i++) {
                     ^
1 error
```

Внутри внешнего цикла имя `i` уже занято, и объявить внутренний счётчик с тем же именем нельзя. Обычно берут `i` и `j` или осмысленные `row` и `col`.

**6. Сторожевое значение попадает в данные.** Если проверку `x == 0` поставить после `total += x`, ноль будет прибавлен (на сумму это не влияет, но на счётчик или максимум повлияет). Проверяйте знак конца сразу после чтения.

## Итоги

* `break` завершает самый внутренний цикл, `continue` пропускает остаток текущей итерации; обе команды обычно стоят внутри `if`.
* В `while` изменяйте счётчик до `continue`, иначе цикл станет бесконечным.
* Вложенный цикл выполняется целиком на каждой итерации внешнего; тело внутреннего выполнится столько раз, сколько получится при умножении числа итераций внешнего цикла на число итераций внутреннего.
* Сторожевое значение (например, 0) сообщает «данные закончились», и цикл прерывается через `break`.

Циклы закончились; теперь код, который повторяется или нужен в нескольких местах, можно выносить в именованные блоки - методы: [Методы: static, параметры и return](lesson:java.from-zero.methods).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `break` и `continue` работают как в C и JavaScript и действуют на самый внутренний цикл (или `switch`).
* В Java есть **метки**: `outer: for (...) { for (...) { break outer; } }` выходит сразу из двух циклов, а `continue outer;` переходит к следующей итерации внешнего цикла. В курсе метки не используются; это замена `goto`, которого в языке нет.
* Фрагмент `switch` в старой записи тоже использует `break`; в записи со стрелкой он не нужен.
* Python-конструкции `for ... else` и `while ... else` в Java отсутствуют: для «не найдено» заводят флаг или выносят цикл в метод и возвращают значение через `return`.
* Для вложенных циклов по двумерным данным принят вложенный `for`; индексы обычно называют `i`, `j` или `row`, `col`.
* Выход из цикла через `return` внутри метода часто понятнее двойного `break`; это тема следующего урока.

## break и continue в байткоде

Это необязательный раздел: для заданий он не нужен.

Для виртуальной машины `break` и `continue` - просто безусловные переходы (`goto`) на нужную метку: `break` ведёт к первой команде после цикла, `continue` - к шагу (в `for`) или к проверке условия (в `while`). Именно поэтому команды после них недостижимы: компилятор строит граф переходов и отказывается компилировать блок, в который управление не может попасть. Проверка недостижимости - часть спецификации языка, а не оптимизация.

Метка `outer:` тоже превращается в переход. Поэтому цена `break outer` такая же, как у простого `break`: никаких исключений или скрытых проверок нет.
