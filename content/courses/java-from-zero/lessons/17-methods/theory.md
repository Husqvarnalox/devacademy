## Зачем нужны методы

В программе часто одно и то же вычисление требуется в нескольких местах: цена со скидкой для каждого товара, проверка «взрослый ли покупатель», рамка вокруг заголовка. Копировать код нельзя - при исправлении придётся менять все копии. Решение - дать куску кода имя и вызывать его, когда нужно. Именованный кусок кода называется **методом** (в других языках - функцией).

## Одна новая идея: метод принимает данные и возвращает результат

Метод вы уже видели: `main` - тоже метод. Теперь научимся писать свои:

```java
static int square(int x) {
    return x * x;
}
```

Разберём заголовок слева направо:

* `static` - метод принадлежит самой программе (классу `Main`) и вызывается без создания объекта. Пока все наши методы пишутся со словом `static`; что бывает без него, объяснит урок о первом классе.
* `int` - **тип результата**: метод вернёт целое число.
* `square` - имя метода (с маленькой буквы, глаголом или описанием результата).
* `(int x)` - **параметры**: данные, которые метод получает. `x` - переменная, которая существует только внутри метода.
* `return x * x;` - команда, которая **возвращает** результат вызывающему и завершает метод.

Вызывают метод по имени, передавая **аргументы** - конкретные значения параметров:

```java
int result = square(5);
```

Значение `5` попадает в параметр `x`, метод вычисляет `25`, и `square(5)` в выражении заменяется на `25`.

Если метод ничего не возвращает, а только выполняет действие (например, печатает), в качестве типа результата пишут `void` («пусто»), а `return` не нужен:

```java
static void greet(String name) {
    System.out.println("Здравствуйте, " + name + "!");
}
```

Методы пишут внутри `class Main`, рядом с `main`, но не внутри него.

**Область видимости.** Параметры и переменные, объявленные внутри метода, видны только в нём. Метод не видит переменные `main`, а `main` - переменные метода. Данные передаются только через параметры и `return`.

С этого урока в упражнениях `main` уже написан за вас: он читает ввод и вызывает ваши методы. Ваша задача - написать тела методов.

## Пример 1. Метод с результатом

```java run
public class Main {
    static int square(int x) {
        return x * x;
    }

    public static void main(String[] args) {
        int a = square(5);
        System.out.println(a);
        System.out.println(square(3) + square(4));
        System.out.println("Квадрат 10: " + square(10));
    }
}
```
```output
25
25
Квадрат 10: 100
```

Разбор:

* Метод `square` описан один раз и вызван три раза с разными аргументами. Каждый вызов в выражении заменяется на возвращённое значение: `square(3) + square(4)` - это `9 + 16`.
* Порядок методов в файле неважен: `main` может вызывать методы, записанные выше или ниже него.
* Метод `main` теперь читается как рассказ: имена методов объясняют, что происходит.

## Пример 2. Метод без результата (void)

```java run
public class Main {
    static void banner(String title) {
        System.out.println("=====");
        System.out.println(title);
        System.out.println("=====");
    }

    public static void main(String[] args) {
        banner("Меню");
        System.out.println("1. Начать");
        banner("Конец");
    }
}
```
```output
=====
Меню
=====
1. Начать
=====
Конец
=====
```

Разбор:

* `void`-метод вызывается как отдельная команда: `banner("Меню");`. Значения он не возвращает, поэтому использовать `banner(...)` в выражении нельзя.
* Три строки с рамкой написаны один раз и использованы дважды.

## Пример 3. Несколько параметров и логический результат

```java run
public class Main {
    static int max(int a, int b) {
        if (a > b) {
            return a;
        }
        return b;
    }

    static boolean isAdult(int age) {
        return age >= 18;
    }

    public static void main(String[] args) {
        System.out.println(max(7, 12));
        System.out.println(max(-3, -8));
        int age = 17;
        if (isAdult(age)) {
            System.out.println("Доступ разрешён");
        } else {
            System.out.println("Доступ закрыт");
        }
    }
}
```
```output
12
-3
Доступ закрыт
```

Разбор:

* Параметры перечисляют через запятую, у каждого свой тип: `(int a, int b)`. Аргументы при вызове подставляются **по порядку**.
* `return` завершает метод сразу. В `max`, если `a > b`, выполняется `return a` и метод заканчивается; до последней строки дело не доходит.
* Метод, возвращающий `boolean`, можно записать прямо в условии `if`: `isAdult(age)` - это значение `true` или `false`.

## Пример 4. Видимость и копии параметров

```java run
public class Main {
    static int addBonus(int points) {
        points = points + 10;
        return points;
    }

    public static void main(String[] args) {
        int score = 50;
        int result = addBonus(score);
        System.out.println("score = " + score);
        System.out.println("result = " + result);
    }
}
```
```output
score = 50
result = 60
```

Разбор:

* В метод передаётся **копия** значения. Изменение `points` внутри метода не затрагивает `score` в `main`.
* Чтобы получить новое значение, метод его возвращает, а вызывающий записывает результат в переменную: `int result = addBonus(score);`.

## Пример 5. Метод вызывает метод

```java run
public class Main {
    static int priceWithDiscount(int price, int percent) {
        return price - price * percent / 100;
    }

    static boolean freeDelivery(int amount) {
        return amount >= 3000;
    }

    static String delivery(int price, int percent) {
        int total = priceWithDiscount(price, percent);
        if (freeDelivery(total)) {
            return "бесплатно";
        }
        return "300 руб.";
    }

    public static void main(String[] args) {
        System.out.println("Товар 4000, скидка 10%: доставка " + delivery(4000, 10));
        System.out.println("Товар 2500, скидка 10%: доставка " + delivery(2500, 10));
    }
}
```
```output
Товар 4000, скидка 10%: доставка бесплатно
Товар 2500, скидка 10%: доставка 300 руб.
```

Разбор:

* Метод может вызывать другие методы. Каждый занимается одним делом: посчитать цену, проверить порог доставки, подобрать текст.
* Метод `delivery` возвращает `String`, поэтому его результат можно приклеить к тексту.
* Переменная `total` существует только в `delivery`; в `main` её нет.

**Попробуйте.** Напишите метод `cube(int x)`, возвращающий куб числа, и вызовите его для 3 и для -2. Затем добавьте метод `static void printSquare(int x)`, который сам печатает квадрат, и сравните его с `square` из примера 1: чем отличается вызов?

## Точные правила

* Заголовок метода: `static <тип результата> имя(<тип> параметр, ...)`. Тип результата - любой тип (`int`, `double`, `boolean`, `String`) или `void`.
* Метод с типом результата, отличным от `void`, обязан вернуть значение **на каждом пути** выполнения. Иначе компилятор сообщит `missing return statement`.
* `return значение;` завершает метод и передаёт значение вызвавшему. В `void`-методе допустим `return;` без значения (досрочный выход).
* Тип возвращаемого значения должен подходить к типу результата. Нельзя вернуть `String` из `int`-метода; дробное число из `int`-метода без явного приведения тоже нельзя.
* Число и типы аргументов при вызове должны совпадать с параметрами: сколько параметров, столько и аргументов, в том же порядке. Целое число можно передать вместо `double` (оно расширяется до дробного), а наоборот - нет.
* Параметры - копии аргументов. Присваивание параметру внутри метода не меняет переменную вызывающего.
* Параметры и переменные метода видны только внутри него (**область видимости**). Два разных метода могут иметь переменные с одинаковым именем: они не связаны.
* Метод вызывают по имени со скобками, даже если параметров нет: `printMenu()`.
* `static` метод вызывают из `main` без объекта. Метод без `static` из `static`-метода вызвать нельзя: компилятор сообщит об ошибке (см. ниже). Что такое метод без `static`, объяснит урок о первом классе.
* Имя метода по соглашению пишут в `camelCase`; хорошее имя описывает действие или результат: `isAdult`, `priceWithDiscount`.
* Результат вызова можно не использовать (`square(5);`), но для метода без побочных эффектов это бессмысленно: значение пропадёт.

## Типичные ошибки

**1. Нет `return`.**

```java
public class Main {
    static int abs(int x) {
        if (x < 0) {
            return -x;
        }
    }

    public static void main(String[] args) {
        System.out.println(abs(-5));
    }
}
```

```text
Main.java:6: error: missing return statement
    }
    ^
1 error
```

Если `x` не отрицательный, метод доходит до конца и ничего не возвращает. Нужно вернуть значение и в этом случае: `return x;` после `if`.

**2. Неверный тип результата.**

```java
public class Main {
    static int half(int x) {
        return x / 2.0;
    }

    public static void main(String[] args) {
        System.out.println(half(5));
    }
}
```

```text
Main.java:3: error: incompatible types: possible lossy conversion from double to int
        return x / 2.0;
                 ^
1 error
```

Деление на `2.0` даёт `double`, а метод обещал `int`. Либо измените тип результата на `double`, либо используйте целое деление `x / 2`.

**3. Неверное число аргументов.**

```java
public class Main {
    static int square(int x) {
        return x * x;
    }

    public static void main(String[] args) {
        System.out.println(square(2, 3));
    }
}
```

```text
Main.java:7: error: method square in class Main cannot be applied to given types;
        System.out.println(square(2, 3));
                           ^
  required: int
  found:    int,int
  reason: actual and formal argument lists differ in length
1 error
```

Сообщение называет метод, показывает, что он ожидает (`required`), что получил (`found`) и почему это не подходит (`reason`). Читайте его как строку сравнения: сколько параметров объявлено и сколько аргументов передано.

**4. Забытое слово `static`.**

```java
public class Main {
    int square(int x) {
        return x * x;
    }

    public static void main(String[] args) {
        System.out.println(square(4));
    }
}
```

```text
Main.java:7: error: non-static method square(int) cannot be referenced from a static context
        System.out.println(square(4));
                           ^
1 error
```

`main` - `static`-метод, и вызывать из него можно только такие же `static`-методы. Добавьте `static` в заголовок `square`.

**5. Чужая переменная.**

```java
public class Main {
    static void count() {
        int total = 10;
    }

    public static void main(String[] args) {
        count();
        System.out.println(total);
    }
}
```

```text
Main.java:8: error: cannot find symbol
        System.out.println(total);
                           ^
  symbol:   variable total
  location: class Main
1 error
```

Переменная `total` существует только внутри `count`. Чтобы передать значение наружу, метод должен вернуть его через `return`.

**6. `void`-метод в выражении.**

```java
public class Main {
    static void greet() {
        System.out.println("Привет");
    }

    public static void main(String[] args) {
        String s = greet();
    }
}
```

```text
Main.java:7: error: incompatible types: void cannot be converted to String
        String s = greet();
                        ^
1 error
```

`void` означает «результата нет», поэтому присвоить его переменной нельзя.

**7. Результат вызова потерян.**

```java run
public class Main {
    static int addBonus(int points) {
        return points + 10;
    }

    public static void main(String[] args) {
        int score = 50;
        addBonus(score);
        System.out.println(score);
    }
}
```
```output
50
```

Программа компилируется, но вызов `addBonus(score);` ничего не меняет в `score`: метод вернул 60, а значение выброшено. Запишите результат: `score = addBonus(score);`.

<!-- section: summary -->
## Итоги

* Метод - именованный блок кода: `static тип имя(параметры) { ... return значение; }`.
* Аргументы вызова подставляются в параметры по порядку; параметры - копии.
* `void` - метод без результата; для остальных `return` обязателен на каждом пути.
* Переменные и параметры метода видны только в нём; данные передаются через параметры и `return`.
* Теперь заготовки упражнений содержат готовый `main`, а ваша работа - тела методов.

Мы умеем обрабатывать одно значение за раз. Чтобы хранить много значений под одним именем, нужны массивы: [Массивы](lesson:java.from-zero.arrays).

## Для тех, кто уже программирует

* Методы в Java всегда принадлежат классу; свободных функций нет. `static` значит «принадлежит классу, а не экземпляру»; обёртка `public static void main(String[] args)` теперь читается полностью, кроме `public` и `class` (урок о первом классе) и `String[] args` (массивы).
* Аргументы передаются **по значению**: для `int` копируется число, для объекта и массива копируется ссылка. Метод не может переприсвоить переменную вызывающего, но может изменить объект, на который указывает ссылка (в следующих уроках: массивы, списки).
* Перегрузка допустима: методы с одним именем и разными списками параметров (`max(int, int)`, `max(double, double)`). Значений параметров по умолчанию и именованных аргументов нет.
* Возврат нескольких значений делают через массив, список или собственный класс (урок о первом классе); кортежей, как в Go и Python, нет.
* Компилятор проверяет, что метод возвращает значение на каждом пути (`missing return statement`) и что код после `return` достижим.
* Порядок методов в файле безразличен; предварительных объявлений, как в C, не нужно.
* Рекурсия поддерживается, но JVM не оптимизирует хвостовые вызовы; глубокая рекурсия приводит к `StackOverflowError`.

<!-- section: deep-dive -->
## Что происходит при вызове метода

Это необязательный раздел: для заданий он не нужен.

Каждый вызов метода получает собственный **кадр** на стеке потока: область памяти для параметров и локальных переменных. Аргументы копируются в параметры кадра, метод выполняется, `return` кладёт результат на стек вызывающего и кадр освобождается. Поэтому локальные переменные метода «исчезают» после его завершения, а параметры - копии: внутри кадра нет доступа к переменным кадра `main`.

Глубина стека ограничена: обычно это от нескольких тысяч до нескольких десятков тысяч вложенных вызовов. Бесконечная рекурсия исчерпывает её и приводит к `StackOverflowError`. Для `static`-методов компилятор записывает в байткод инструкцию `invokestatic`: целевой метод известен уже при компиляции, и виртуальной машине не нужно выбирать реализацию по типу объекта. Небольшие методы JIT-компилятор вставляет прямо в место вызова (**встраивание**), поэтому разбиение кода на короткие методы почти ничего не стоит.
