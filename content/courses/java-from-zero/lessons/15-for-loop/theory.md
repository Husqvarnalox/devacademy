## Зачем нужен for

В прошлом уроке цикл с счётчиком состоял из трёх разбросанных частей: `int i = 1;` до цикла, `i <= 5` в скобках `while` и `i++` в конце тела. Когда число повторений известно (напечатать строку таблицы десять раз, пройти по всем буквам слова, отсчитать от 5 до 1), удобнее собрать эти три части в одну строку. Это делает цикл `for`: по заголовку сразу видно, откуда он начинается, где останавливается и как шагает.

## Одна новая идея: счётчик в заголовке

**Цикл `for`** записывается так:

```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Шаг " + i);
}
```

В скобках три части, разделённые точками с запятой:

1. `int i = 1` - **начало**: выполняется один раз перед циклом и создаёт переменную цикла.
2. `i <= 5` - **условие**: проверяется перед каждой итерацией, как у `while`; пока оно `true`, тело выполняется.
3. `i++` - **шаг**: выполняется после каждой итерации тела и меняет счётчик. Запись `i++` означает «увеличить `i` на 1».

Порядок выполнения: начало, затем повторяется «условие - тело - шаг», пока условие верно. Цикл выше - это в точности `while`, который вы уже знаете, записанный компактнее.

Переменная цикла (`i`) существует только внутри `for`: после закрывающей скобки её нет. Шаг не обязан быть единицей: `i += 2` идёт через один, а `i--` уменьшает счётчик, и цикл считает в обратную сторону.

<!-- section: examples -->
## Пример 1. От начала до конца

```java run
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Шаг " + i);
        }
        System.out.println("Готово");
    }
}
```
```output
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5
Готово
```

Разбор:

* Цикл выполняется для `i` = 1, 2, 3, 4, 5. После пятой итерации `i++` делает `i` равным 6, условие ложно, цикл заканчивается.
* Строка «Готово» выполняется один раз после цикла.
* Число итераций для `i = a; i <= b; i++` равно `b - a + 1`.

## Пример 2. Другой шаг и обратный отсчёт

```java run
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i <= 10; i += 5) {
            System.out.println("i = " + i);
        }
        for (int t = 3; t >= 1; t--) {
            System.out.println(t + "...");
        }
        System.out.println("Пуск!");
    }
}
```
```output
i = 0
i = 5
i = 10
3...
2...
1...
Пуск!
```

Разбор:

* В первом цикле шаг `i += 5` даёт значения 0, 5, 10: после 10 счётчик станет 15 и условие `i <= 10` перестанет выполняться.
* Во втором цикле счётчик уменьшается: начинаем с 3, пока `t >= 1`, шаг `t--`. Условие поэтому записано со знаком `>=`: цикл идёт вниз.
* Во втором цикле счётчик назван `t`, но имя `i` тоже подошло бы: переменная первого цикла исчезла вместе с ним.

## Пример 3. Таблица умножения

```java run
public class Main {
    public static void main(String[] args) {
        int n = 7;
        for (int k = 1; k <= 4; k++) {
            System.out.println(n + " x " + k + " = " + n * k);
        }
    }
}
```
```output
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
```

Разбор:

* Переменная цикла `k` участвует в вычислениях в теле: на каждой итерации она равна своему значению.
* В склейке `n * k` скобки не нужны: умножение выполняется раньше склейки. Скобки понадобились бы для сложения: `" = " + (n + k)`.

## Пример 4. Накопление и проверка внутри цикла

```java run
public class Main {
    public static void main(String[] args) {
        int evens = 0;
        int sum = 0;
        for (int i = 1; i <= 10; i++) {
            sum += i;
            if (i % 2 == 0) {
                evens++;
            }
        }
        System.out.println("Сумма 1..10: " + sum);
        System.out.println("Чётных: " + evens);
    }
}
```
```output
Сумма 1..10: 55
Чётных: 5
```

Разбор:

* Накопитель `sum` и счётчик `evens` объявлены до цикла (как в уроке о `while`).
* Условие `i % 2 == 0` внутри цикла отбирает чётные числа 2, 4, 6, 8, 10: их пять.

## Пример 5. Перебор букв строки

```java run
public class Main {
    public static void main(String[] args) {
        String word = "банан";
        int count = 0;
        for (int i = 0; i < word.length(); i++) {
            if (word.charAt(i) == 'а') {
                count++;
            }
        }
        System.out.println("Букв «а» в слове " + word + ": " + count);
    }
}
```
```output
Букв «а» в слове банан: 2
```

Разбор:

* Индексы букв начинаются с нуля (урок о строках), поэтому счётчик идёт от `0` и пока `i < word.length()`: у слова из 5 букв это индексы 0-4.
* `word.charAt(i) == 'а'` сравнивает символ с символом. Шаблон «от 0 до `length()` не включая» - основной способ обойти текст или (в следующих уроках) массив.

**Попробуйте.** Измените в примере 2 первый цикл, чтобы он печатал 0, 3, 6, 9. Затем напишите цикл, который печатает числа от 10 до 1 по убыванию через одно (10, 8, 6, 4, 2).

## Точные правила

* Заголовок `for (начало; условие; шаг)`: начало выполняется один раз, условие проверяется перед каждой итерацией, шаг выполняется после каждой.
* Любая из трёх частей может быть пустой (`for (;;)` - бесконечный цикл), но точки с запятой остаются. В курсе пустых частей нет.
* Переменная, объявленная в начале, видна только внутри цикла (в заголовке и теле). Два цикла подряд могут использовать одно и то же имя.
* Для прохода «n раз» принят шаблон `for (int i = 0; i < n; i++)`: границы «включая начало, не включая конец» делают число итераций равным `n` и совпадают с индексами строк и массивов.
* Для отсчёта вниз: `for (int i = n; i >= 1; i--)`. Если направление и условие противоречат друг другу (`i--` при условии `i < 10`), цикл будет бесконечным.
* Счётчик можно менять и в теле, но делать это не стоит: шаг цикла должен быть виден в заголовке.
* Между `while` и `for` нет разницы в возможностях: `for` удобнее, когда есть счётчик, а `while` - когда заранее известно только условие остановки (например, чтение до конца ввода).
* Типы: счётчик обычно `int`; шаг может быть любым выражением, но `double` как счётчик нежелателен из-за приближённой арифметики.

## Типичные ошибки

**1. Запятые вместо точек с запятой.**

```java
for (int i = 0, i < 3, i++) {
    System.out.println(i);
}
```

```text
Main.java:3: error: ';' expected
        for (int i = 0, i < 3, i++) {
                         ^
Main.java:3: error: illegal start of type
        for (int i = 0, i < 3, i++) {
                            ^
2 errors
```

В заголовке три части разделяются `;`, а не запятыми. Сообщения от компилятора идут цепочкой: исправляйте по порядку, начиная с первого.

**2. Переменная цикла после цикла.**

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
System.out.println("Последний i = " + i);
```

```text
Main.java:6: error: cannot find symbol
        System.out.println("Последний i = " + i);
                                              ^
  symbol:   variable i
  location: class Main
1 error
```

Переменная `i` создана в заголовке и живёт только внутри цикла. Если нужное значение требуется после цикла, запоминайте его в отдельной переменной, объявленной до цикла.

**3. Повторное объявление переменной.**

```java
int i = 100;
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

```text
Main.java:4: error: variable i is already defined in method main(String[])
        for (int i = 0; i < 3; i++) {
                 ^
1 error
```

Внутри `main` нельзя объявить вторую переменную с именем, которое уже занято. Выберите другое имя для счётчика.

**4. Выход за пределы строки.**

```java
String word = "кот";
for (int i = 0; i <= word.length(); i++) {
    System.out.println(word.charAt(i));
}
```

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Index 3 out of bounds for length 3
	...
	at Main.main(Main.java:5)
```

У слова из трёх букв индексы 0, 1, 2, а условие `i <= word.length()` допускает ещё индекс 3. Для обхода текста условие должно быть `i < word.length()`.

**5. Точка с запятой после заголовка.**

```java run
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++);
        {
            System.out.println("Привет");
        }
    }
}
```
```output
Привет
```

Символ `;` после скобок образует пустое тело: цикл трижды ничего не делает, а блок ниже выполняется один раз, уже вне цикла. Ожидаемые три строки «Привет» не получаются, а сообщения об ошибке нет.

**6. Цикл в неверную сторону.** `for (int i = 10; i > 0; i++)` не заканчивается: счётчик растёт, а условие требует, чтобы он был больше нуля. Направление шага должно приближать счётчик к границе.

**7. Ошибка на единицу.** `i < 5` даёт пять итераций от 0, а `i <= 5` - шесть. Если нужно ровно `n` раз, пишите `for (int i = 0; i < n; i++)`.

## Итоги

* `for (начало; условие; шаг) { ... }` собирает счётчик цикла в одну строку: начало один раз, условие перед каждой итерацией, шаг после каждой.
* Для «n раз» пишут `for (int i = 0; i < n; i++)`; для отсчёта вниз - `i--` и условие `i >= ...`.
* Переменная цикла видна только внутри цикла; накопители объявляют до него.
* Этим же шаблоном обходят буквы строки: `i` от 0 до `length() - 1`.

Иногда нужно досрочно выйти из цикла или пропустить одну итерацию: этому посвящён урок [break, continue и вложенные циклы](lesson:java.from-zero.loop-control).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Классический трёхчастный `for` как в C и JavaScript. Условие должно быть `boolean`; в начале можно объявить несколько переменных одного типа (`int i = 0, j = 10`), а в шаге перечислить несколько выражений через запятую.
* Переменная, объявленная в заголовке, видна только в цикле. Затенять локальную переменную внешней области нельзя, в отличие от JavaScript и Go.
* В Java нет `range()` и срезов; для обхода по индексу используют шаблон `i < n`. Для коллекций есть `for (T x : collection)` (урок о массивах).
* Счётчик типа `double` приводит к накоплению ошибки округления: `for (double x = 0; x != 1; x += 0.1)` никогда не завершится. Используйте целый счётчик и вычисляйте дробное значение внутри.
* `int` переполняется молча: `for (int i = 1; i > 0; i++)` в итоге заканчивается, когда `i` проходит `Integer.MAX_VALUE` и становится отрицательным.
* Цикл в Java выполняется на JVM: короткие горячие циклы JIT-компилятор разворачивает и оптимизирует; микробенчмарки нужно писать с учётом прогрева (например, через JMH).

## Что значит i++ на самом деле

Это необязательный раздел: для заданий он не нужен.

Выражение `i++` вычисляет значение и одновременно увеличивает переменную. Есть две формы: `i++` (сначала вернуть старое значение, потом увеличить) и `++i` (сначала увеличить, потом вернуть новое). Когда выражение стоит отдельной командой, как шаг в `for`, различия нет, поэтому в заголовках цикла пишут `i++`. В выражениях вида `a = i++ + ++i` результат зависит от порядка вычислений, и такие записи читать трудно. В байткоде это одна инструкция `iinc`, которая увеличивает локальную переменную прямо в её ячейке кадра.

Условие цикла `for` проверяется перед каждой итерацией, поэтому каждый вызов `word.length()` в условии выполняется заново. Для строки это дешёвая операция (длина хранится в объекте), а для сложных вызовов результат стоит записать в переменную до цикла.
