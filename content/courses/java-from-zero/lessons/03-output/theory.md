## Зачем управлять выводом

Результат работы программы нужно показать человеку: чек, список, сообщение с числом. Для этого мало печатать одну строку целиком. Нужно уметь выводить часть строки без перехода дальше, переносить строки внутри текста, печатать кавычки и добавлять к тексту числа. Всё это - вывод, и он устроен всего из нескольких приёмов.

## Одна новая идея: вывод собирается из кусков

До сих пор мы использовали `System.out.println(...)`. У неё есть «сестра» `System.out.print(...)`. Разница одна:

* `println` печатает текст и **переводит строку**: следующий вывод начнётся с новой строки;
* `print` печатает текст и **остаётся в той же строке**: следующий вывод продолжит её.

Из этих двух команд и соединения кусков оператором `+` собирается любая строка вывода. Знак `+` между текстом и числом **склеивает** их в один текст. Такая склейка называется **конкатенацией**.

<!-- section: examples -->
## Пример 1. print и println

```java run
public class Main {
    public static void main(String[] args) {
        System.out.print("Хлеб ");
        System.out.print("и молоко");
        System.out.println();
        System.out.println("Всего два товара");
    }
}
```
```output
Хлеб и молоко
Всего два товара
```

Разбор по строкам:

* Две команды `print` пишут `Хлеб ` и `и молоко` подряд, в одной строке. Пробел после слова «Хлеб» находится внутри кавычек, поэтому он попадает в вывод.
* `System.out.println();` - `println` без текста в скобках просто переводит строку. Так завершают строку, начатую через `print`.
* Последняя команда печатает текст и тоже переводит строку.

## Пример 2. Кавычки, перенос и обратная косая черта

```java run
public class Main {
    public static void main(String[] args) {
        System.out.println("Строка 1\nСтрока 2");
        System.out.println("Она сказала: \"Привет\"");
        System.out.println("Папка: C:\\temp");
    }
}
```
```output
Строка 1
Строка 2
Она сказала: "Привет"
Папка: C:\temp
```

Внутри текста обратная косая черта `\` начинает **экранированную последовательность**: два знака, которые вместе означают один особый символ. `\n` - перевод строки, `\"` - обычная кавычка внутри текста (иначе компилятор решил бы, что текст закончился), `\\` - сама обратная косая черта. На экран попадает один символ, а не два.

## Пример 3. Соединение текста с числами и комментарии

```java run
public class Main {
    public static void main(String[] args) {
        // Цена одного товара
        System.out.println("Хлеб: " + 45 + " руб.");
        System.out.println("Позиций в чеке: " + 3);
        System.out.println("Привет, " + "мир" + "!");
        System.out.println(7);
    }
}
```
```output
Хлеб: 45 руб.
Позиций в чеке: 3
Привет, мир!
7
```

Разбор:

* Строка, начинающаяся с `//`, - **комментарий**. Компилятор её пропускает, а читатель получает пояснение. Комментарий пишут о том, чего не видно из кода: зачем сделано, а не что делает команда.
* `"Хлеб: " + 45 + " руб."` склеивает три куска. Пробелы между кусками сами не появляются: они записаны внутри кавычек (`"Хлеб: "` и `" руб."`).
* Число можно напечатать без кавычек: `System.out.println(7)`. Кавычки нужны только для текста.

**Попробуйте.** Уберите пробел из `"Хлеб: "` и предскажите, что напечатается. Затем замените `println` на `print` в первой команде и посмотрите, как строки сольются.

<!-- section: precise -->
## Точные правила

* `System.out.println(x)` печатает значение `x`, затем символ перевода строки. `System.out.println()` без аргумента печатает только перевод строки.
* `System.out.print(x)` печатает значение `x` и не переводит строку.
* В `print` и `println` передают **одно** значение. Несколько кусков соединяют знаком `+`; перечислять через запятую, как в Python, нельзя.
* Если хотя бы один из двух операндов `+` - текст, результат - текст: число превращается в его запись и приклеивается. Пробелов и разделителей Java не добавляет.
* Основные экранированные последовательности:

  | Запись | Что означает |
  |---|---|
  | `\n` | перевод строки |
  | `\t` | табуляция (переход к следующему «столбцу» из пробелов) |
  | `\"` | двойная кавычка |
  | `\\` | обратная косая черта |

  Любая другая последовательность после `\` - ошибка компиляции `illegal escape character`.
* Строковый литерал должен помещаться в одной строке программы: нажимать Enter внутри кавычек нельзя, для переноса используют `\n`.
* **Комментарий** `// ...` продолжается до конца строки. Комментарий из нескольких строк пишут между `/*` и `*/`.
* Разные типы значений печатаются одной и той же командой: `println(7)`, `println(3.5)`, `println(true)`. Что это за типы, разберём в уроках про переменные и типы.

## Типичные ошибки

**1. Несколько значений через запятую.**

```java
System.out.println("Хлеб", "Молоко");
```

```text
Main.java:3: error: no suitable method found for println(String,String)
        System.out.println("Хлеб", "Молоко");
                  ^
    method PrintStream.println() is not applicable
      (actual and formal argument lists differ in length)
    ...
```

Сообщение длинное, но суть в первой строке: «нет подходящей println для двух текстовых аргументов». `println` принимает одно значение: соедините куски через `+`.

**2. Пропущен знак `+`.**

```java
System.out.println("Цена: " 45);
```

```text
Main.java:3: error: ')' or ',' expected
        System.out.println("Цена: " 45);
                                   ^
```

Компилятор не видит, как связаны текст и число, и показывает место сразу после текста. Поставьте `+` между ними.

**3. Кавычки внутри текста без `\`.**

```java
System.out.println("Он сказал "привет"");
```

```text
Main.java:3: error: ')' or ',' expected
        System.out.println("Он сказал "привет"");
                                       ^
Main.java:3: error: ';' expected
        System.out.println("Он сказал "привет"");
                                             ^
```

Вторая кавычка закрыла текст, а слово `привет` для компилятора - уже не текст. Пишите `\"` внутри текста. Обратите внимание на вторую ошибку: она вызвана первой.

**4. Одинарная обратная косая черта.**

```java
System.out.println("Привет\Мир");
```

```text
Main.java:3: error: illegal escape character
        System.out.println("Привет\Мир");
                                   ^
```

После `\` допустимы только определённые знаки. Если нужна сама косая черта (путь Windows), пишут `\\`.

**5. Нет пробела при склейке.** `"Итого:" + 100` даёт `Итого:100`. Ошибки нет, но вид не тот. Пробел пишите внутри кавычек: `"Итого: " + 100`.

**6. Забыли `ln`.** `print("a"); print("b");` напечатает `ab` в одной строке. Если строки слиплись, проверьте, не стоит ли где-то `print` вместо `println`.

<!-- section: summary -->
## Итоги

* `println` печатает и переводит строку, `print` остаётся в той же строке.
* `\n`, `\"` и `\\` позволяют записать в тексте перевод строки, кавычку и обратную косую черту.
* Знак `+` склеивает текст и число; пробелы сами не появляются, их пишут внутри кавычек.
* Комментарий `//` объясняет код читателю и не влияет на работу программы.

Теперь вы можете оформить любой вывод из фиксированных частей. В следующем уроке ([Переменные](lesson:java.from-zero.variables)) данные будут храниться в переменных, чтобы не писать их по нескольку раз.

<!-- section: programmer -->
## Для тех, кто уже программирует

* В `print`/`println` одно значение. Нет вариативных аргументов с разделителем (`print(a, b, sep=" ")` в Python). Несколько значений собирают через `+` или через `printf` (отдельный урок).
* `+` между текстом и числом - конкатенация, как в JavaScript. Приоритеты важны: `1 + 2 + "a"` даёт `"3a"`, а `"a" + 1 + 2` - `"a12"`. Будьте внимательны с выражениями; их разбирает урок про арифметику.
* `System.out.println()` без аргументов печатает только перевод строки, то есть заканчивает строку, начатую через `print`.
* Окончание строки у `println` зависит от платформы (`\n` или `\r\n`); для переноса, независимого от платформы, используют `%n` в `printf`.
* Комментарии `//` и `/* */`, как в C, Go и JavaScript; документационные комментарии `/** */` для `javadoc` здесь не нужны.
* Для вывода в поток ошибок есть `System.err`; приложение проверяет только стандартный вывод.

## Что такое System.out

Это необязательный раздел: для заданий он не нужен.

`System` - класс из стандартной библиотеки, `out` - его поле: объект типа `PrintStream`, который связан со стандартным выводом процесса. Методы `print`, `println` и `printf` принадлежат этому объекту. Операционная система предоставляет каждой программе три потока: стандартный ввод, стандартный вывод и стандартный вывод ошибок. Приложение подключает ваш вывод к окну результата, поэтому `System.out.println` попадает туда.

Склейку `"a" + 45` компилятор переписывает в вызов специального служебного механизма, который строит новую строку из частей; оператор `+` для текста в этом смысле - сокращённая запись. Строки в Java неизменяемы: каждая склейка создаёт новую строку, а старая остаётся нетронутой.
