## Зачем нужен ввод

До сих пор все данные были записаны в программе. Программа, которая всегда обрабатывает одни и те же значения, мало полезна: настоящая программа получает данные снаружи - от пользователя, из файла, от другой программы. Всё, что программа получает из внешнего мира, называется **вводом**. Ввод приходит текстом: даже число сначала записано цифрами, и программе нужно его прочитать.

Текст попадает на **стандартный ввод** (stdin) вашей программы - канал, по которому данные поступают в программу. В приложении вы вписываете его в специальное поле перед запуском (подробно - в подразделе «Как подать ввод своей программе» ниже), а при проверке решения его подаёт тест. Прочитать его в Java помогает готовое средство - класс `Scanner`.

## Одна новая идея: Scanner читает ввод по частям

Чтобы прочитать ввод, нужны три строки:

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        // дальше читаем: in.next(), in.nextInt(), in.nextLine()
    }
}
```

Разберём незнакомое:

* `import java.util.Scanner;` - строка перед `public class`. `Scanner` лежит в библиотеке Java, в «пакете» `java.util`. `import` сообщает компилятору, где его искать. Без `import` имя `Scanner` неизвестно.
* `Scanner in` - переменная `in` типа `Scanner`.
* `new Scanner(System.in)` - слово `new` («новый») создаёт **объект-читатель**: готовое средство, настроенное на чтение из `System.in` (стандартного ввода). Что такое объект, мы разберём в уроке о первом классе; сейчас достаточно правила «пишите эту строку один раз в начале `main`».

Читают данные методами `in`:

| Метод | Что делает |
|---|---|
| `in.next()` | прочитать одно слово (до пробела или перевода строки) как `String` |
| `in.nextInt()` | прочитать целое число как `int` |
| `in.nextLine()` | прочитать остаток текущей строки целиком (с пробелами) |

Между словами и числами `Scanner` сам пропускает пробелы и переводы строк, поэтому неважно, стоят ли они в одной строке или в разных.

## Как подать ввод своей программе

1. Под редактором откройте вкладку **«Вывод»**.
2. Нажмите на строку **«Ввод программы (stdin)»**: под ней раскроется поле.
3. Впишите в поле весь ввод заранее, например `Анна 25` (как в примере 1). Слово и число можно разделить пробелом или переводом строки: `Scanner` пропускает и то и другое.
4. Нажмите **«Запустить»**.

Программа не останавливается и не ждёт, пока вы что-то напечатаете: всё, что записано в поле, она получает сразу при запуске. Если поле пустое, ввод пустой. Пока урок открыт, текст в поле остаётся, так что для следующего запуска достаточно поменять данные.

Кнопка **«Проверить решение»** это поле не использует: она запускает программу на вводе каждого теста по очереди.

## Пример 1. Прочитать слово и число

Эту программу нельзя запустить в окне примеров, потому что там нет ввода, поэтому приведены ввод и вывод.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.next();
        int age = in.nextInt();
        System.out.println("Привет, " + name + "! Через год вам будет " + (age + 1) + ".");
    }
}
```

Ввод:

```text
Анна 25
```

Вывод:

```text
Привет, Анна! Через год вам будет 26.
```

Разбор: `next()` взяло слово `Анна`, `nextInt()` - число `25`. Результат `age + 1` в скобках, иначе число приклеилось бы к тексту (урок об арифметике). Тот же результат получится, если ввести слово и число на разных строках.

## Пример 2. Остаток строки после числа

Чтобы пример можно было запустить, текст для чтения задан прямо в программе: `Scanner` умеет читать не только из `System.in`, но и из строки.

```java run
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("25\nАнна Смирнова\n");
        int age = in.nextInt();
        String rest = in.nextLine();
        String fullName = in.nextLine();
        System.out.println("age=" + age);
        System.out.println("rest=[" + rest + "]");
        System.out.println("name=[" + fullName + "]");
    }
}
```
```output
age=25
rest=[]
name=[Анна Смирнова]
```

Разбор:

* Во вводе две строки: `25` и `Анна Смирнова`.
* `nextInt()` прочитало `25` и остановилось **перед** переводом строки: символ конца строки остался непрочитанным.
* Первая `nextLine()` прочитала остаток этой строки - пустой текст `[]`. Именно поэтому в упражнении «город» читают второй `nextLine()`.
* Вторая `nextLine()` прочитала следующую строку целиком, вместе с пробелом между словами. `next()` вернуло бы только `Анна`.

## Пример 3. Чтение в любой раскладке

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int price = in.nextInt();
        int count = in.nextInt();
        System.out.println("К оплате: " + price * count);
    }
}
```

Ввод `40 3` и ввод из двух строк `40` и `3` дают одинаковый результат: `К оплате: 120`. Умножение выполняется раньше склейки, поэтому скобки здесь не нужны.

**Попробуйте.** Измените пример 2: поставьте на место `nextLine()` для `rest` вызов `next()` и посмотрите, что окажется в `fullName` и `rest`.

## Точные правила

* `import java.util.Scanner;` пишут в начале файла, **до** `public class Main`. Строк `import` может быть несколько.
* `new Scanner(System.in)` создают один раз в начале `main`. Несколько `Scanner` на один `System.in` создавать не нужно: первый может «забрать» больше данных, чем прочитал.
* `next()` читает слово: пропускает пробельные символы (пробелы, табуляции, переводы строк) и возвращает символы до следующего пробельного. `nextInt()` делает то же и превращает слово в `int`.
* `nextLine()` читает всё до конца текущей строки и сам символ конца строки пропускает. Если часть строки уже прочитана, читается остаток (возможно, пустой).
* Правило безопасного чтения: если после `next()`/`nextInt()` нужно читать строку целиком, сначала вызовите `nextLine()` и отбросьте остаток.
* `in.hasNext()` возвращает `true`, если во вводе есть ещё слово; `in.hasNextLine()` - если есть ещё строка. Они понадобятся в циклах чтения «до конца ввода».
* Если следующее слово не число, `nextInt()` бросает `InputMismatchException`. Если ввод закончился - `NoSuchElementException`. Обе ошибки возникают при выполнении.
* Чтение дробных чисел через `nextDouble()` зависит от локали компьютера (где-то дробный разделитель - запятая). Надёжный способ появится в следующем уроке.
* Имя переменной-читателя произвольное: `in`, `sc`, `scanner`. В курсе используется `in`.

## Типичные ошибки

**1. Забыли `import`.**

```java
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int age = in.nextInt();
        System.out.println(age);
    }
}
```

```text
Main.java:3: error: cannot find symbol
        Scanner in = new Scanner(System.in);
        ^
  symbol:   class Scanner
  location: class Main
Main.java:3: error: cannot find symbol
        Scanner in = new Scanner(System.in);
                         ^
  symbol:   class Scanner
  location: class Main
2 errors
```

Ошибка одна, а сообщений два: имя `Scanner` встречается в строке дважды (тип переменной и после `new`). Добавьте `import java.util.Scanner;` в начало файла.

**2. На вход подано не число.** Программа читает `in.nextInt()`, а во вводе `abc`:

```text
Exception in thread "main" java.lang.InputMismatchException
	at java.base/java.util.Scanner.throwFor(Scanner.java:964)
	...
	at Main.main(Main.java:6)
```

Сообщение не называет слово, но называет строку программы: `Main.java:6`. Весь `at java.base/...` - путь внутри библиотеки; ищите строку с вашим файлом. Устойчивое чтение числа из неподходящего текста - тема урока об исключениях.

**3. Ввода не хватает.**

```text
Exception in thread "main" java.util.NoSuchElementException
	at java.base/java.util.Scanner.throwFor(Scanner.java:962)
	...
	at Main.main(Main.java:6)
```

Программа просит данные, а ввод закончился. При запуске в окне примеров ввода нет вовсе, поэтому программы с `Scanner` там и не выполняются.

**4. `nextLine()` сразу после `nextInt()`.** Вместо строки вы получаете пустой текст (пример 2). Лечится одним лишним вызовом `in.nextLine();` перед чтением строки.

**5. Неверный тип переменной.**

```java
String age = in.nextInt();
```

```text
Main.java:6: error: incompatible types: int cannot be converted to String
        String age = in.nextInt();
                               ^
```

`nextInt()` возвращает `int`; тип переменной должен быть `int`.

**6. `next()` для строки с пробелами.** `next()` вернёт только первое слово: из `Нижний Новгород` получится `Нижний`. Для названия из нескольких слов нужен `nextLine()`.

## Итоги

* `Scanner in = new Scanner(System.in);` вместе с `import java.util.Scanner;` создаёт читатель стандартного ввода.
* `next()` читает слово, `nextInt()` - целое число, `nextLine()` - остаток строки.
* Пробелы и переводы строк между словами и числами `Scanner` пропускает сам; после числа остаётся конец строки, и перед `nextLine()` его читают отдельно.
* Если ввод неверный или закончился, программа остановится с `InputMismatchException` или `NoSuchElementException`.

Теперь программы получают разные данные. В следующем уроке ([Преобразование типов](lesson:java.from-zero.type-conversion)) мы научимся превращать значения из одного типа в другой: слова в числа и дробные числа в целые.

## Для тех, кто уже программирует

* `Scanner` - самый простой способ читать `System.in`: токены по разделителю-пробелу, регулярные выражения, разбор чисел. Для больших объёмов быстрее `BufferedReader`; в начальных задачах разницы нет.
* `import` подключает класс по полному имени; пакет `java.lang` (в нём `String`, `System`, `Math`) импортируется автоматически.
* `new` создаёт объект; в Java нет функций верхнего уровня, всё работает через классы и их экземпляры.
* `nextInt()` не потребляет конец строки - классическая ловушка с последующим `nextLine()` (как в C++ с `cin >> n; getline(...)`).
* `nextInt()`/`nextDouble()` разбирают число с учётом локали по умолчанию. `scanner.useLocale(Locale.ROOT)` или `Double.parseDouble(in.next())` исключают сюрпризы.
* Python: `input()`, Go: `fmt.Scan`/`bufio.Scanner`, JavaScript (Node): `readFileSync(0)`; в Java чтение всегда идёт через объект-читатель.
* Исключения `InputMismatchException` и `NoSuchElementException` непроверяемые: объявлять их в сигнатуре не нужно.

## Что такое поток ввода

Это необязательный раздел: для заданий он не нужен.

`System.in` - объект типа `InputStream`: поток **байтов**, который операционная система подключает к вашему процессу. Читать байты вручную неудобно, поэтому `Scanner` оборачивает поток: переводит байты в символы с учётом кодировки и находит границы слов по разделителям. Перед чтением он набирает данные в буфер, а не по одному символу, поэтому два разных `Scanner` на один `System.in` могут «разделить» ввод неожиданным образом.

Для строки (`new Scanner("25\n...")`) тот же `Scanner` просто читает из текста в памяти: так проверяют разбор ввода, не запуская программу с клавиатурой.

Слово `new` выделяет память под новый объект в куче и вызывает **конструктор** - специальный метод, подготавливающий объект к работе. Подробнее конструкторы мы разберём, когда будем писать собственные классы.
