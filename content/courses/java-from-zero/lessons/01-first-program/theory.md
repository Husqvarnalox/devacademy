## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Этот текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется Java. На нём пишут серверы, приложения для Android и инструменты разработчиков; он строгий, и эта строгость помогает находить ошибки до запуска.

Компьютер не умеет выполнять текст на Java напрямую. Поэтому есть ещё один инструмент - **компилятор**: он читает исходный код, проверяет его и переводит в форму, которую можно выполнить. В Java это два шага: компилятор `javac` создаёт файл с промежуточным кодом, а затем программа `java` его выполняет. Что такое промежуточный код, рассказывает раздел «Подробнее» в конце урока и курс «Java: первые шаги».

В приложении вам не нужно вызывать эти программы вручную. Вы пишете текст в редакторе, нажимаете «Запустить», и приложение само компилирует и выполняет программу.

## Одна новая идея: программа на Java - это обёртка с командами внутри

Самая маленькая программа на Java выглядит так:

```java
public class Main {
    public static void main(String[] args) {
        // здесь пишут команды
    }
}
```

Это обёртка, которую требует Java: без неё программа не запустится. Что значит каждое слово в ней (`public`, `class`, `static`, `void`, `String[] args`), мы разберём позже - в уроке о методах и в уроке о первом классе. Пока достаточно трёх правил:

1. Файл называется `Main.java`, а внутри него написано `public class Main`. Эти имена должны совпадать.
2. Выполнение начинается с `main`. Всё, что стоит между внутренними фигурными скобками `{ }` после `main(...)`, выполняется сверху вниз.
3. Свои команды вы пишете только внутри этих скобок. Остальные строки не меняйте.

Первая команда, которую нужно знать, - `System.out.println("...")`: она печатает текст и переводит курсор на новую строку.

<!-- section: examples -->
## Пример 1. Печать одной строки

```java run
public class Main {
    public static void main(String[] args) {
        System.out.println("Касса открыта");
    }
}
```
```output
Касса открыта
```

Разбор по строкам:

* `public class Main {` - начало обёртки: «здесь описана программа по имени Main». Открывающая фигурная скобка начинает блок, закрывающая на последней строке его заканчивает.
* `public static void main(String[] args) {` - место, с которого программа начинает работу. Слово `main` («главный») - его имя, а остальные слова пока считаем частью обёртки.
* `System.out.println("Касса открыта");` - сама команда. `System.out` - это «стандартный вывод», то есть окно, куда программа печатает. `println` (от print line, «напечатать строку») - действие. В круглых скобках - то, что печатать: текст в двойных кавычках. Точка с запятой в конце заканчивает команду.
* Две последние строки `}` закрывают метод `main` и класс `Main`. Когда команды в `main` закончились, программа завершается.

## Пример 2. Несколько команд подряд

```java run
public class Main {
    public static void main(String[] args) {
        System.out.println("Первая строка");
        System.out.println("Вторая строка");
        System.out.println("Третья строка");
    }
}
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет. Каждая команда занимает свою строку и заканчивается точкой с запятой.

**Попробуйте.** Поменяйте местами две строки с `println` и предскажите вывод до запуска. Затем удалите точку с запятой в конце одной команды и прочитайте, что ответит компилятор (разбор таких сообщений - в разделе об ошибках и в следующем уроке).

## Точные правила

* Файл с программой называется `Main.java`; внутри него объявлен `public class Main`. Регистр букв важен: `main.java` или `class main` не подойдут.
* Выполнение начинается с метода `main`. Если его нет или он записан иначе, программа не запустится.
* Каждая команда заканчивается точкой с запятой `;`. Исключение - строки, которые только открывают или закрывают блок: `{` и `}`.
* Фигурные скобки идут парами: у каждой открывающей `{` должна быть закрывающая `}`.
* **Строковый литерал** - текст, записанный прямо в программе, в двойных кавычках: `"Касса открыта"`. Он печатается как есть, без кавычек. Внутри допустимы русские буквы, пробелы, цифры и знаки.
* Регистр важен и в именах: `System` пишется с заглавной буквы, `out` и `println` - со строчной. `system.out.Println` не заработает.
* Точка в `System.out.println` отделяет часть от целого: у `System` есть `out`, а у `out` есть действие `println`.
* Отступы (четыре пробела внутри блока) компилятору не нужны, но читателю очень помогают. Редактор расставляет их автоматически.
* Пустые строки между командами допустимы и улучшают чтение.

## Типичные ошибки

Сообщение компилятора всегда начинается с имени файла и номера строки: `Main.java:3: error: ...`. Ниже программа записана в стандартной обёртке, а ошибка - в строке 3. Под сообщением компилятор печатает строку кода и значок `^`, который указывает место, где он понял, что что-то не так.

**1. Пропущена точка с запятой.**

```java
System.out.println("Привет")
```

```text
Main.java:3: error: ';' expected
        System.out.println("Привет")
                                    ^
```

Команда не закончена: компилятор ждёт `;` и показывает место сразу после закрывающей скобки. Добавьте `;`. Если после этого появляются новые сообщения, исправляйте их по одному: так устроен следующий урок.

**2. Имя с неправильным регистром.**

```java
system.out.println("Привет");
```

```text
Main.java:3: error: package system does not exist
        system.out.println("Привет");
              ^
```

Слово `system` с маленькой буквы Java считает именем пакета (группы готовых средств), которого нет. Правильное имя - `System`. Узнать это самому можно по сообщению: «does not exist» говорит, что компилятор не знает такого имени.

**3. Опечатка в имени команды.**

```java
System.out.printn("Привет");
```

```text
Main.java:3: error: cannot find symbol
        System.out.printn("Привет");
                  ^
  symbol:   method printn(String)
  location: variable out of type PrintStream
```

`cannot find symbol` означает «не нахожу такое имя». В строках `symbol` и `location` компилятор подробно говорит, чего именно нет (метод `printn`) и где его искали (у `out`). Сравните имя с правильным `println`.

**4. Не закрыты кавычки.**

```java
System.out.println("Привет);
```

```text
Main.java:3: error: unclosed string literal
        System.out.println("Привет);
                           ^
```

Строка началась кавычкой и не закончилась до конца строки программы. Проверьте, что у каждой открывающей кавычки есть закрывающая.

**5. Не хватает закрывающей фигурной скобки.**

```text
Main.java:4: error: reached end of file while parsing
    }
     ^
```

Компилятор дочитал файл до конца и не нашёл парной `}`. Посчитайте скобки: сколько открыто, столько должно быть закрыто.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; компилятор проверяет его и переводит в форму, которую можно выполнить.
* Минимальная программа на Java - обёртка `public class Main` с методом `main`; команды пишут внутри `main`, они выполняются сверху вниз.
* `System.out.println("текст")` печатает строку и переходит на следующую; кавычки на экран не попадают.
* Каждая команда заканчивается точкой с запятой, а регистр букв в именах важен.

Это основа: любая следующая программа в курсе устроена так же, меняется только содержимое `main`. В следующем уроке ([Как читать сообщения об ошибках](lesson:java.from-zero.compiler-errors)) вы научитесь читать сообщения компилятора и исправлять ошибки по одной.

## Для тех, кто уже программирует

* Точка входа - `public static void main(String[] args)` внутри класса; отдельных функций и инструкций верхнего уровня в Java 22 нет. В Java 25 появились компактные файлы без обёртки, но в этом курсе (JDK 22) обёртка обязательна и сохраняется во всех заготовках.
* Публичный класс обязан лежать в файле с тем же именем: `public class Main` - в `Main.java`.
* `System.out.println` - аналог `print` в Python и `console.log` в JavaScript; `println` добавляет перевод строки, `print` - нет.
* Точка с запятой обязательна, блоки выделяются фигурными скобками, отступы не значимы (в отличие от Python).
* Имена регистрозависимы: `System`, `String` и названия классов пишут с заглавной буквы, методы и переменные - со строчной.
* Компиляция даёт `Main.class` с байткодом для виртуальной машины (JVM); нативного исполняемого файла, как в Go или Rust, нет.

<!-- section: deep-dive -->
## Что происходит при нажатии «Запустить»

Это необязательный раздел: для заданий он не нужен.

Приложение выполняет две команды. Сначала `javac -d out Main.java`: компилятор разбирает текст по правилам языка, проверяет, что все имена известны и все типы сочетаются, и записывает результат в папку `out` как файл `Main.class`. В нём не машинный код процессора, а **байткод** - команды для воображаемого процессора. Затем `java -cp out Main` запускает **виртуальную машину Java (JVM)**: она загружает `Main.class` и выполняет его, начиная с `main`.

Благодаря такому устройству один и тот же `Main.class` можно запустить на любой системе, где есть подходящая JVM. Подробнее про байткод, JVM и компиляцию во время работы - в курсе «Java: первые шаги».

Ошибки вроде `';' expected` вы видите **до** запуска: сборка останавливается, программа не стартует, и частично выполненного результата нет.
