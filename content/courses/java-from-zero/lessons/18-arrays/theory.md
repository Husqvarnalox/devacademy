## Зачем нужны массивы

Пока каждое значение хранилось в отдельной переменной. Для трёх оценок можно завести `grade1`, `grade2`, `grade3`, но для температур за месяц или цен в чеке неизвестной длины этот способ не годится: переменных пришлось бы создавать десятки, а обработать их циклом нельзя. Нужен способ хранить много однотипных значений под одним именем и обращаться к ним по номеру.

## Одна новая идея: массив - нумерованный ряд значений одного типа

**Массив** - это набор значений одного типа, расположенных подряд. Каждое значение - **элемент** - имеет номер, который называют **индексом**. Нумерация идёт **с нуля**: у массива из пяти элементов индексы 0, 1, 2, 3, 4 (так же нумеруются буквы строки).

```java
int[] temps = {18, 21, 19, 25, 22};
System.out.println(temps[0]);       // 18, первый элемент
System.out.println(temps[3]);       // 25
temps[1] = 20;                      // заменить элемент с индексом 1
System.out.println(temps.length);   // 5, число элементов
```

* `int[]` - тип «массив целых». Для текстов `String[]`, для дробных `double[]`.
* `{18, 21, 19, 25, 22}` - список значений; размер массива определяется их числом.
* `temps[3]` - обращение к элементу по индексу в квадратных скобках; его можно прочитать и записать.
* `temps.length` - число элементов. Это **поле**, у него нет скобок (в отличие от `word.length()` у строки).

Размер массива задаётся при создании и **не меняется**. Пустой массив создают словом `new`: `int[] a = new int[5];` - пять элементов, сначала все равны 0 (у `double` - 0.0, у `boolean` - `false`, у `String` - особое значение `null`, «ничего»).

Обойти все элементы можно циклом `for` по индексу (`i` от 0 до `length - 1`) или циклом **for-each**, где индекс не нужен:

```java
int sum = 0;
for (int t : temps) {
    sum += t;
}
```

Читается так: «для каждого `t` из `temps`». Переменная `t` по очереди получает значения элементов.

## Пример 1. Создание, чтение, изменение

```java run
public class Main {
    public static void main(String[] args) {
        int[] temps = {18, 21, 19, 25, 22};
        System.out.println("Первый: " + temps[0]);
        System.out.println("Последний: " + temps[temps.length - 1]);
        temps[1] = 20;
        System.out.println("Изменённый: " + temps[1]);
        System.out.println("Элементов: " + temps.length);
    }
}
```
```output
Первый: 18
Последний: 22
Изменённый: 20
Элементов: 5
```

Разбор:

* Последний элемент имеет индекс `length - 1`, потому что нумерация начинается с нуля: для пяти элементов это индекс 4.
* Присваивание `temps[1] = 20;` заменяет значение прямо в массиве.
* Попытка прочитать `temps[5]` приведёт к ошибке во время работы (см. ниже).

## Пример 2. Обход циклом: по индексу и for-each

```java run
public class Main {
    public static void main(String[] args) {
        int[] prices = {120, 80, 300, 45};

        int sum = 0;
        for (int i = 0; i < prices.length; i++) {
            sum += prices[i];
        }
        System.out.println("Сумма: " + sum);

        int max = prices[0];
        for (int p : prices) {
            if (p > max) {
                max = p;
            }
        }
        System.out.println("Максимум: " + max);
    }
}
```
```output
Сумма: 545
Максимум: 300
```

Разбор:

* Первый цикл идёт по индексам: условие `i < prices.length` не включает `length`, чтобы не выйти за границу.
* Второй цикл - for-each: он короче, когда нужны только значения.
* Максимум ищут, начиная с **первого элемента**, а не с нуля: для массива из отрицательных чисел начальный ноль дал бы неверный ответ.

## Пример 3. Новый массив и значения по умолчанию

```java run
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] squares = new int[5];
        System.out.println(Arrays.toString(squares));
        for (int i = 0; i < squares.length; i++) {
            squares[i] = i * i;
        }
        System.out.println(Arrays.toString(squares));
    }
}
```
```output
[0, 0, 0, 0, 0]
[0, 1, 4, 9, 16]
```

Разбор:

* `new int[5]` создаёт пять элементов, равных 0.
* `Arrays.toString(массив)` превращает массив в читаемый текст в квадратных скобках; для этого нужна строка `import java.util.Arrays;` в начале файла (как `import` для `Scanner`). Прямой вывод `System.out.println(squares)` напечатал бы служебный код вроде `[I@1b6d3586`, а не значения.
* В цикле по индексу элементы заполняются: `squares[i] = i * i`.

## Пример 4. Массив и метод

```java run
public class Main {
    static int countAbove(int[] a, int limit) {
        int count = 0;
        for (int x : a) {
            if (x > limit) {
                count++;
            }
        }
        return count;
    }

    static void doubleAll(int[] a) {
        for (int i = 0; i < a.length; i++) {
            a[i] = a[i] * 2;
        }
    }

    public static void main(String[] args) {
        int[] data = {5, 12, 8, 20};
        System.out.println("Больше 7: " + countAbove(data, 7));
        doubleAll(data);
        System.out.println("После удвоения: " + data[0] + " " + data[1] + " " + data[2] + " " + data[3]);
    }
}
```
```output
Больше 7: 3
После удвоения: 10 24 16 40
```

Разбор:

* Массив передают в метод как обычное значение, а тип параметра записывают `int[] a`. Метод `countAbove` только читает массив.
* Метод `doubleAll` **изменяет** элементы, и изменения видны в `main`. В прошлом уроке мы выяснили, что параметры - копии; для массива копируется «адрес» (ссылка) на один и тот же набор значений, поэтому и вызывающий, и метод работают с одними и теми же элементами.

## Пример 5. Чтение массива из ввода

Пример читает n чисел в массив. Ввод задан в программе, чтобы её можно было запустить:

```java run
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("4\n10 20 30 40\n");
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }
        System.out.println("Прочитано: " + a.length);
        System.out.println("Первый и последний: " + a[0] + " " + a[n - 1]);
    }
}
```
```output
Прочитано: 4
Первый и последний: 10 40
```

Разбор:

* Размер массива можно взять из переменной: сначала прочитали `n`, потом создали `new int[n]`.
* Типичный формат ввода: сначала количество элементов, потом сами элементы.

**Попробуйте.** В примере 2 добавьте цикл, который находит минимальную цену. Затем проверьте программу на массиве `{-5, -1, -9}`: что получится, если начальное значение максимума взять равным 0?

## Точные правила

* Тип массива: `Тип[]`. Создание: `new Тип[размер]` (элементы получают значения по умолчанию) или список значений `{a, b, c}`.
* Индексы идут от `0` до `length - 1`. Обращение с другим индексом во время работы бросает `ArrayIndexOutOfBoundsException`.
* `a.length` - число элементов, без скобок. У строки наоборот: `s.length()`.
* Размер массива после создания не меняется. Если число элементов заранее не известно, используют списки (следующий урок).
* Значения по умолчанию: `0` для `int`, `0.0` для `double`, `false` для `boolean`, `'\u0000'` для `char`, `null` для `String` и других ссылочных типов.
* Все элементы массива имеют один тип. В `int[]` нельзя положить дробное число или строку.
* Переменная массива хранит **ссылку** на массив. Присваивание `int[] b = a;` не копирует элементы: обе переменные указывают на один и тот же массив, и изменение через `b` видно через `a`. Копию делает `Arrays.copyOf(a, a.length)`.
* Оператор `==` для массивов сравнивает ссылки, а не содержимое. Для сравнения содержимого есть `Arrays.equals`.
* Цикл for-each (`for (T x : a)`) даёт копию элемента: присваивание `x = ...` не меняет массив. Менять элементы нужно по индексу.
* Массив, переданный в метод, можно изменять изнутри; изменения видны вызывающему. Присвоение параметру нового массива (`a = new int[3];`) вызывающего не затрагивает.

## Типичные ошибки

**1. Индекс за границей.**

```java
int[] a = {10, 20, 30};
System.out.println(a[3]);
```

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3
	at Main.main(Main.java:4)
```

Сообщение называет индекс и длину. Элементов три, индексы 0, 1, 2; нужного элемента с номером 3 нет. Также ищите в сообщении номер строки вашей программы (`Main.java:N`).

**2. Индекс -1.**

```java
int[] a = {10, 20, 30};
int i = a.length;
System.out.println(a[i - 4]);
```

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index -1 out of bounds for length 3
	at Main.main(Main.java:5)
```

Отрицательный индекс, в отличие от Python, не отсчитывает с конца, а считается ошибкой.

**3. Скобки у `length`.**

```java
int[] a = {1, 2, 3};
System.out.println(a.length());
```

```text
Main.java:4: error: cannot find symbol
        System.out.println(a.length());
                            ^
  symbol:   method length()
  location: variable a of type int[]
1 error
```

У массива `length` - поле, а не метод, поэтому скобки не нужны. Для строки наоборот: `word.length()`.

**4. Дробное значение в целочисленном массиве.**

```java
int[] a = {1, 2.5, 3};
```

```text
Main.java:3: error: incompatible types: possible lossy conversion from double to int
        int[] a = {1, 2.5, 3};
                      ^
1 error
```

Все элементы массива должны быть того типа, которым массив объявлен. Для дробных значений заведите `double[]`.

**5. Не указан размер.**

```java
int[] a = new int[];
```

```text
Main.java:3: error: array dimension missing
        int[] a = new int[];
                           ^
1 error
```

После `new int` в квадратных скобках нужен размер: `new int[5]`.

**6. Присваивание массива не копирует его.**

```java run
public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;
        b[0] = 99;
        System.out.println("a[0] = " + a[0]);
    }
}
```
```output
a[0] = 99
```

`b` - не копия, а второе имя того же массива. Чтобы получить независимую копию, вызовите `Arrays.copyOf(a, a.length)`.

**7. Максимум с начальным нулём.** Для массива `{-5, -1, -9}` начальное значение `max = 0` даст ответ 0, которого в массиве нет. Начинайте с `a[0]`.

**8. Печать массива напрямую.** `System.out.println(a)` печатает не элементы, а служебный текст вроде `[I@1b6d3586`. Используйте `Arrays.toString(a)` или цикл.

## Итоги

* Массив хранит несколько значений одного типа под одним именем; элементы нумеруются с нуля, число элементов - `a.length`.
* Обход: `for (int i = 0; i < a.length; i++)` по индексу или `for (int x : a)` для чтения значений.
* Размер массива не меняется. Выход за границы - `ArrayIndexOutOfBoundsException`.
* Массив передаётся в метод по ссылке: метод может изменить его элементы.

Когда число элементов не известно заранее или должно меняться, используется список: [ArrayList](lesson:java.from-zero.arraylist).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Массивы Java - объекты фиксированного размера с полем `length`; тип элементов проверяется компилятором. Многомерных массивов как отдельного типа нет: `int[][]` - массив массивов (можно «рваный»).
* Индексация проверяется во время работы (`ArrayIndexOutOfBoundsException`), как в Python, но без отрицательных индексов и срезов. Копирование части - `Arrays.copyOfRange`.
* `==` сравнивает ссылки, `equals` у массивов тоже ссылочный; содержимое сравнивают через `Arrays.equals` и `Arrays.deepEquals` (для вложенных).
* Массивы ковариантны: `Object[] o = new String[1]; o[0] = 1;` компилируется и падает с `ArrayStoreException` во время работы. Для коллекций с обобщениями это не так.
* Элементы инициализируются значением по умолчанию, неинициализированных данных, как в C, нет.
* Для сортировки и поиска есть `Arrays.sort`, `Arrays.binarySearch`, `Arrays.fill`, `Arrays.asList`.
* В объявлении допустима и запись `int a[]` в стиле C; в Java принято `int[] a`.
* Динамический массив - `ArrayList` (следующий урок). Для примитивов он хранит упакованные объекты `Integer`, что дороже `int[]`.

## Как массив лежит в памяти

Это необязательный раздел: для заданий он не нужен.

Массив - объект в куче: служебный заголовок, длина и затем подряд значения элементов. Для `int[]` каждый элемент занимает 4 байта, поэтому адрес элемента с индексом `i` вычисляется как «начало + заголовок + 4·i». Это делает доступ по индексу очень быстрым, а проверка `0 <= i < length` вставляется виртуальной машиной автоматически; JIT-компилятор убирает её там, где может доказать, что индекс корректен (например, в цикле `for (int i = 0; i < a.length; i++)`).

Переменная массива в `main` хранит не сами значения, а ссылку на этот объект. Поэтому `int[] b = a;` копирует только ссылку, а метод, получивший массив, видит те же элементы. Массив из `String` хранит ссылки на строки, а не символы; массив `int[][]` - массив ссылок на другие массивы, и строки такой «таблицы» могут иметь разную длину.
