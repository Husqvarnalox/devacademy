## Зачем нужен цикл

Многие задачи состоят из повторения: просуммировать все цены в чеке, пока они не закончатся; считать вклад по годам, пока сумма не достигнет цели; прочитать столько чисел, сколько подано. Заранее неизвестно, сколько раз придётся повторить действие. Писать одну и ту же строку десять или тысячу раз нельзя, поэтому повторение поручают **циклу**.

## Одна новая идея: while - повторять, пока условие верно

**Цикл `while`** («пока») проверяет условие. Если оно `true`, выполняется тело цикла - блок в фигурных скобках, - после чего условие проверяется снова. Когда условие становится `false`, цикл заканчивается, и выполнение идёт дальше:

```java
int i = 1;
while (i <= 3) {
    System.out.println("Шаг " + i);
    i = i + 1;
}
```

Три составные части цикла с **счётчиком**:

1. **Начальное значение** счётчика задаётся до цикла: `int i = 1;`.
2. **Условие** в скобках после `while`: пока оно верно, цикл продолжается.
3. **Изменение** счётчика внутри тела: `i = i + 1`. Без него условие никогда не станет ложным, и цикл не закончится.

Одно выполнение тела называют **итерацией**. Условие проверяется перед каждой итерацией, поэтому если оно ложно с самого начала, тело не выполнится ни разу.

Второе применение - чтение данных, пока они есть. Метод `hasNextInt()` объекта `Scanner` отвечает на вопрос «осталось ли во вводе ещё целое число?» (`true` или `false`). Цикл `while (in.hasNextInt())` читает числа, пока они не закончились, и работает при любой длине ввода:

```java
while (in.hasNextInt()) {
    int x = in.nextInt();
    // обработать x
}
```

Для слов то же делает пара `hasNext()` и `next()`, для строк - `hasNextLine()` и `nextLine()`.

<!-- section: examples -->
## Пример 1. Счётчик

```java run
public class Main {
    public static void main(String[] args) {
        int i = 1;
        while (i <= 5) {
            System.out.println("Шаг " + i);
            i++;
        }
        System.out.println("Цикл закончен, i = " + i);
    }
}
```
```output
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5
Цикл закончен, i = 6
```

Разбор:

* До цикла `i` равно 1. Условие `i <= 5` верно, тело выполняется, `i++` (то же, что `i = i + 1`) увеличивает счётчик.
* После пятой итерации `i` становится 6, условие ложно, и цикл заканчивается. Строка после цикла показывает: счётчик остаётся равным 6, а не 5.
* Условие проверяется до тела. Если начать с `i = 10`, тело не выполнится ни разу.

## Пример 2. Накопление суммы

```java run
public class Main {
    public static void main(String[] args) {
        int n = 5;
        int sum = 0;
        int i = 1;
        while (i <= n) {
            sum = sum + i;
            i++;
        }
        System.out.println("Сумма чисел от 1 до " + n + ": " + sum);
    }
}
```
```output
Сумма чисел от 1 до 5: 15
```

Разбор:

* Переменная `sum` - **накопитель**: она начинается с нуля и на каждой итерации увеличивается на очередное число. Начальное значение нужно задать до цикла, и для суммы оно равно 0.
* Итерации прибавляют 1, 2, 3, 4, 5 и дают 15.
* Накопитель объявлен до цикла, чтобы после цикла его значение можно было напечатать. Переменная, объявленная внутри тела, снаружи недоступна.

## Пример 3. Цикл по условию, а не по счётчику

```java run
public class Main {
    public static void main(String[] args) {
        int money = 1000;
        int years = 0;
        while (money < 1500) {
            money = money * 11 / 10;
            years++;
        }
        System.out.println("Лет до 1500 рублей: " + years);
        System.out.println("Накоплено: " + money);
    }
}
```
```output
Лет до 1500 рублей: 5
Накоплено: 1610
```

Разбор:

* Здесь не известно заранее, сколько будет итераций: цикл идёт, пока цель не достигнута. Каждая итерация - один год с процентом 10%, записанным как `* 11 / 10` в целых числах.
* Условие `money < 1500` стало ложным после пятого года, когда накоплено больше 1500.

## Пример 4. Чтение всех чисел из ввода

Программа читает ввод и в окне примеров не запускается, поэтому приведены ввод и вывод.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int count = 0;
        int sum = 0;
        while (in.hasNextInt()) {
            int x = in.nextInt();
            count++;
            sum += x;
        }
        System.out.println("Чисел: " + count);
        System.out.println("Сумма: " + sum);
    }
}
```

Ввод:

```text
10 20
30
5
```

Вывод:

```text
Чисел: 4
Сумма: 65
```

Разбор:

* `hasNextInt()` возвращает `true`, пока во вводе есть число, поэтому цикл прочитал все четыре числа, независимо от того, как они разбиты по строкам.
* Если ввод пуст, `hasNextInt()` сразу даёт `false`, тело не выполняется, и программа напечатает «Чисел: 0» и «Сумма: 0».
* `count++` и `sum += x` - сокращённые записи `count = count + 1` и `sum = sum + x` (урок об арифметике).

Чтобы цикл с `Scanner` можно было запустить, в следующей программе текст для чтения задан прямо в ней, как в уроке про чтение ввода:

```java run
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("3 8 12");
        int max = 0;
        while (in.hasNextInt()) {
            int x = in.nextInt();
            if (x > max) {
                max = x;
            }
        }
        System.out.println("Максимум: " + max);
    }
}
```
```output
Максимум: 12
```

Здесь `max` начинается с 0, и на каждой итерации заменяется большим числом. Такой приём работает для неотрицательных данных; для произвольных чисел начальное значение берут из первого элемента.

**Попробуйте.** В примере 1 замените `i <= 5` на `i < 5`, затем на `i <= 0`. Предскажите вывод до запуска. Затем уберите строку `i++` и остановите программу самостоятельно (в окне запуска есть кнопка остановки): так выглядит бесконечный цикл.

## Точные правила

* `while (условие) { тело }`: условие типа `boolean` проверяется **перед** каждой итерацией. Если оно ложно, цикл заканчивается; тело может не выполниться ни разу.
* Чтобы цикл закончился, тело должно изменять то, от чего зависит условие (счётчик, накопленную сумму, позицию во вводе). Если условие всегда истинно, получится **бесконечный цикл**; программу остановят вручную.
* Переменная, объявленная внутри тела, создаётся заново на каждой итерации и исчезает после `}`. Счётчики и накопители объявляют до цикла.
* `i++` увеличивает `i` на 1, `i--` уменьшает на 1, `i += 5` увеличивает на 5.
* `hasNextInt()` проверяет, что следующее слово ввода записано как целое число. Если следующее слово - не число (например `abc`), метод вернёт `false`, и цикл закончится, хотя ввод ещё не прочитан до конца. Чтение «любых слов» делает `hasNext()`.
* `hasNextInt()`, `hasNext()` и `hasNextLine()` ничего не читают: они только заглядывают вперёд. Читает следующий вызов `nextInt()`, `next()` или `nextLine()`.
* Выбор между `<` и `<=` определяет число итераций: `i = 1; while (i <= 5)` выполняет 5 итераций, а `while (i < 5)` - 4.
* Любой цикл `while` можно прочитать по схеме: «пока <условие>, делать <тело>».

## Типичные ошибки

**1. Счётчик не изменяется - бесконечный цикл.**

```java
int i = 1;
while (i <= 3) {
    System.out.println("Шаг " + i);
}
```

Компилятор не жалуется: код корректен, но условие `i <= 3` всегда верно, и программа печатает «Шаг 1» бесконечно. Если программа «зависла» или заполнила экран одинаковыми строками, ищите цикл, в котором ничего не меняется. Добавьте `i++` в тело.

**2. Точка с запятой после условия.**

```java
int i = 1;
while (i <= 3);
{
    i++;
}
```

Символ `;` после скобок образует пустое тело цикла: условие проверяется снова и снова, а `i++` стоит уже вне цикла и недостижимо. Программа зависает без единого сообщения.

**3. Переменная из тела цикла после него.**

```java
int i = 1;
while (i <= 3) {
    int square = i * i;
    i++;
}
System.out.println(square);
```

```text
Main.java:8: error: cannot find symbol
        System.out.println(square);
                           ^
  symbol:   variable square
  location: class Main
1 error
```

Переменная `square` существует только внутри фигурных скобок цикла. Чтобы использовать результат после цикла, объявите переменную до цикла.

**4. Два чтения за одну проверку.**

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner("1 2 3");
        while (in.hasNextInt()) {
            int a = in.nextInt();
            int b = in.nextInt();
            System.out.println(a + b);
        }
    }
}
```

```text
Exception in thread "main" java.util.NoSuchElementException
	...
	at Main.main(Main.java:8)
```

Проверка `hasNextInt()` подтвердила только одно число, а тело прочитало два. На нечётном количестве чисел второе чтение падает с `NoSuchElementException`. Сколько раз проверили, столько раз и читайте.

**5. Неверная граница.** Для пяти шагов нужно `i <= 5` или `i < 6`; запись `i < 5` даёт четыре шага. Ошибки «на единицу» не вызывают сообщений, поэтому после написания цикла проверьте первую и последнюю итерации вручную.

**6. Накопитель не обнулён.** Если написать `int sum;` и сразу прибавлять `sum += x`, компилятор сообщит `variable sum might not have been initialized`. Задайте `int sum = 0;` до цикла.

## Итоги

* `while (условие) { ... }` повторяет тело, пока условие верно; условие проверяется перед каждой итерацией.
* Счётчик задают до цикла, а в теле изменяют; иначе цикл бесконечен.
* Накопитель (сумма, количество, максимум) объявляют до цикла и обновляют в теле.
* `while (in.hasNextInt())` читает числа, пока они есть во вводе, при любой его длине.

Для повторений с известным числом шагов в Java есть более компактная форма, в которой счётчик, условие и изменение собраны в одной строке: [Цикл for](lesson:java.from-zero.for-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `while` такой же, как в C, JavaScript и Python (без `else`-ветки). Условие обязано быть `boolean`: `while (n)` для числа не компилируется.
* Есть `do { ... } while (условие);`, который выполняет тело минимум один раз; в курсе он не используется.
* Идиома чтения «до конца ввода» в Java - `while (in.hasNextInt())` или `while (in.hasNextLine())`; в отличие от Python `for line in sys.stdin` и Go `scanner.Scan()`, проверка и чтение здесь разделены, поэтому два `next...` за одну проверку - частая ошибка.
* `Scanner` удобен для коротких программ, но для больших объёмов ввода медленный; в соревновательном программировании используют `BufferedReader`.
* Деление целых в `money * 11 / 10` отбрасывает дробную часть на каждом шаге, поэтому результат отличается от точного процентного роста; для денег в реальных системах используют `BigDecimal` или копейки в `long`.
* Переменные цикла объявляются в теле заново на каждой итерации; закрытия (замыкания), захватывающего общую переменную, как в JavaScript с `var`, здесь не возникает.

## Что делает цикл на уровне байткода

Это необязательный раздел: для заданий он не нужен.

В байткоде нет слова `while`. Цикл превращается в метку в начале, условный переход в конец (если условие ложно) и безусловный переход назад, к метке. Поэтому «бесконечный цикл» - это просто переход назад, который никогда не пропускается условием. Виртуальная машина считает, сколько раз выполнялся такой переход назад; когда счётчик достигает порога, JIT-компилятор компилирует тело цикла в машинный код, и горячий цикл становится в десятки раз быстрее.

Из этого следует практический вывод: время работы цикла зависит от числа итераций и от стоимости тела, а не от того, `while` это или `for`: оба превращаются в один и тот же байткод.
