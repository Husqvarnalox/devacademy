## Зачем сравнивать значения

До сих пор программа выполняла команды одну за другой и не принимала решений. Чтобы программа могла выбирать («если возраст не меньше 18, пустить»), ей нужно уметь задавать вопросы о значениях: больше ли одно число другого, равны ли они, верны ли сразу два условия. Ответом на такой вопрос всегда служит значение типа `boolean`: `true` («да») или `false` («нет»).

В этом уроке мы учимся только составлять такие вопросы и вычислять ответы. Сами решения (команда `if`) появятся в следующем уроке.

## Одна новая идея: выражение, которое даёт true или false

**Сравнение** берёт два значения и возвращает `boolean`:

| Оператор | Смысл | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | `true` |
| `!=` | не равно | `5 != 5` | `false` |
| `<` | меньше | `3 < 5` | `true` |
| `>` | больше | `3 > 5` | `false` |
| `<=` | меньше или равно | `5 <= 5` | `true` |
| `>=` | больше или равно | `3 >= 5` | `false` |

Знак `==` - сравнение, а `=` - присваивание. Это разные действия: `x = 5` кладёт число в переменную, `x == 5` спрашивает «равно ли пяти».

Несколько условий соединяют **логическими операторами**:

| Оператор | Читается | Результат `true`, когда |
|---|---|---|
| `&&` | «и» | обе части `true` |
| `\|\|` | «или» | хотя бы одна часть `true` |
| `!` | «не» | часть была `false` (меняет значение на противоположное) |

Например, «возраст от 18 до 64 включительно» записывают двумя сравнениями: `age >= 18 && age <= 64`.

<!-- section: examples -->
## Пример 1. Сравнения и вывод результата

```java run
public class Main {
    public static void main(String[] args) {
        int age = 20;
        System.out.println(age >= 18);
        System.out.println(age == 20);
        System.out.println(age != 20);
        boolean adult = age >= 18;
        System.out.println("Совершеннолетний: " + adult);
    }
}
```
```output
true
true
false
Совершеннолетний: true
```

Разбор:

* Сравнение - обычное выражение: его значение можно напечатать или сохранить в переменную типа `boolean` (`adult`).
* `age == 20` и `age != 20` всегда дают противоположные ответы.
* В последней строке `adult` попадает в склейку так же, как число: `true` превращается в текст «true».

## Пример 2. Соединение условий

```java run
public class Main {
    public static void main(String[] args) {
        int age = 20;
        System.out.println(age > 18 && age < 65);
        System.out.println(age < 18 || age > 65);
        System.out.println(!(age > 18));

        System.out.println(true || false && false);
        System.out.println((true || false) && false);
    }
}
```
```output
true
false
false
true
false
```

Разбор:

* `age > 18 && age < 65`: обе части верны, поэтому `true`.
* `age < 18 || age > 65`: ни одна часть не верна, поэтому `false`.
* `!(age > 18)` меняет `true` на `false`. Скобки нужны, иначе `!` относится только к `age`.
* В четвёртой строке `&&` выполняется раньше `||`, как умножение раньше сложения: `true || (false && false)` даёт `true`. Скобки в пятой строке меняют порядок, и результат `false`.

## Пример 3. Чётность, остаток и склейка

```java run
public class Main {
    public static void main(String[] args) {
        int n = 7;
        System.out.println("Чётное: " + (n % 2 == 0));
        System.out.println("Нечётное: " + (n % 2 != 0));
        System.out.println("Однозначное: " + (n >= 0 && n <= 9));
        System.out.println(2 + 3 > 4);
    }
}
```
```output
Чётное: false
Нечётное: true
Однозначное: true
true
```

Разбор:

* `n % 2 == 0` - стандартная проверка чётности: остаток от деления на 2 равен нулю (урок об арифметике).
* Выражение со сравнением после текста нужно брать в скобки. Без них `"Чётное: " + n % 2 == 0` читается как `("Чётное: " + n % 2) == 0`: сравнивается строка с числом, и компилятор сообщит об ошибке.
* `2 + 3 > 4`: арифметика выполняется раньше сравнения, поэтому сравнивается `5 > 4` - `true`.

## Пример 4. Правая часть может не вычисляться

```java run
public class Main {
    public static void main(String[] args) {
        int n = 0;
        System.out.println(n != 0 && 10 / n > 1);
        System.out.println(n == 0 || 10 / n > 1);
        System.out.println(0.1 + 0.2 == 0.3);
        System.out.println(Math.abs(0.1 + 0.2 - 0.3) < 0.000001);
    }
}
```
```output
false
true
false
true
```

Разбор:

* Если левая часть `&&` уже `false`, результат известен, и правая часть **не вычисляется**. Поэтому деления `10 / n` на ноль не происходит. Оператор `||` ведёт себя так же, когда левая часть `true`. Это называется **коротким вычислением**.
* `0.1 + 0.2 == 0.3` даёт `false`: дробные результаты приближённые (урок об арифметике). Дробные числа сравнивают с допуском: расстояние между ними меньше малого числа.

**Попробуйте.** Предскажите значения `5 > 3 == true`, `!(1 < 2) || 4 >= 4` и `10 % 3 == 1 && 10 / 3 == 3`. Проверьте их, напечатав.

## Точные правила

* Сравнения `<`, `>`, `<=`, `>=` работают с числами (`int`, `double`, `char`). `==` и `!=` работают и с `boolean`. Результат любого сравнения - `boolean`.
* Операторы выполняются в таком порядке (от сильного к слабому): `!`, арифметика (`*`, `/`, `%`, затем `+`, `-`), сравнения (`<`, `>`, `<=`, `>=`), равенство (`==`, `!=`), `&&`, `||`. Скобки меняют порядок.
* `a && b` равно `true`, только если обе части `true`; `a || b` равно `false`, только если обе части `false`; `!a` меняет значение.
* `&&` и `||` вычисляют правую часть только при необходимости (короткое вычисление). На этом основана защита вида `n != 0 && 10 / n > 1`.
* Цепочка `1 < x < 10` недопустима: она читается слева направо, `1 < x` - `boolean`, а `boolean < 10` смысла не имеет. Пишите `1 < x && x < 10`.
* Нельзя сравнивать числа с текстом (`"a" == 5`) и применять `&&`, `||`, `!` к не-`boolean` значениям.
* `=` - присваивание, `==` - сравнение. Запись `x = 5` сама является выражением со значением `5`.
* У отрицательных чисел остаток от деления отрицателен: `-3 % 2` равно `-1`. Нечётность поэтому проверяют как `n % 2 != 0`, а не `n % 2 == 1`.
* Дробные числа на точное равенство (`==`) не сравнивают: результаты вычислений приближённые. Сравнивают расстояние между ними с малой величиной.
* Строки `==` не сравнивают: для текста нужен отдельный метод, о нём будет один из следующих уроков. Здесь `==` применяют к числам и символам.

## Типичные ошибки

**1. Цепочка сравнений.**

```java
int x = 5;
System.out.println(1 < x < 10);
```

```text
Main.java:4: error: bad operand types for binary operator '<'
        System.out.println(1 < x < 10);
                                 ^
  first type:  boolean
  second type: int
```

Сообщение называет типы: слева получился `boolean` (результат `1 < x`), справа `int`. Запишите два сравнения: `1 < x && x < 10`.

**2. Присваивание вместо сравнения.**

```java
int x = 5;
boolean b = x = 5;
```

```text
Main.java:4: error: incompatible types: int cannot be converted to boolean
        boolean b = x = 5;
                        ^
```

Второй `=` - присваивание, его значение `5` типа `int`. Для вопроса «равно ли пяти» пишут `x == 5`.

**3. Сравнение после текста без скобок.**

```java
System.out.println("Сумма: " + 1 + 2 > 3);
```

```text
Main.java:3: error: bad operand types for binary operator '>'
        System.out.println("Сумма: " + 1 + 2 > 3);
                                              ^
  first type:  String
  second type: int
```

Сначала выполняется склейка (`+` сильнее `>`), и слева получается `String`. Сравнение нужно брать в скобки: `"Результат: " + (a > b)`.

**4. Слова вместо операторов.**

```java
System.out.println(x > 3 and x < 10);
```

```text
Main.java:3: error: ')' or ',' expected
        System.out.println(x > 3 and x < 10);
                                   ^
Main.java:3: error: ';' expected
        System.out.println(x > 3 and x < 10);
                                         ^
Main.java:3: error: illegal start of type
        System.out.println(x > 3 and x < 10);
                                            ^
3 errors
```

В Java нет слов `and`, `or`, `not`: используйте `&&`, `||`, `!`. Три сообщения вызваны одной ошибкой; исправляйте по порядку, начиная с первого.

**5. Оператор `=>` вместо `>=`.**

```java
System.out.println(x => 3);
```

```text
Main.java:3: error: illegal start of expression
        System.out.println(x => 3);
                             ^
```

В сравнении знак `=` пишут вторым: `>=` и `<=`.

**6. Нечётность через `== 1`.** `n % 2 == 1` для `-3` даёт `false`, потому что `-3 % 2` равно `-1`. Используйте `n % 2 != 0`.

**7. Точное сравнение дробных.** `0.1 + 0.2 == 0.3` даёт `false`. Сравнивайте расстояние: `Math.abs(a - b) < 0.000001`.

**8. Скобки забыты у `!`.** `!age > 18` не компилируется: `!` применяется к `age`, а это число. Пишите `!(age > 18)` или `age <= 18`.

## Итоги

* Сравнение (`==`, `!=`, `<`, `>`, `<=`, `>=`) даёт значение типа `boolean`: `true` или `false`.
* Условия соединяют `&&` («и»), `||` («или») и `!` («не»). Приоритет: `!`, затем сравнения, затем `&&`, затем `||`; скобки меняют порядок.
* «x между a и b» пишут двумя сравнениями: `x >= a && x <= b`. Цепочка `a < x < b` не работает.
* Правая часть `&&` и `||` вычисляется только если нужна.
* `=` присваивает, `==` сравнивает. После текста выражение со сравнением берут в скобки.

Теперь программа умеет задавать вопросы о значениях. В следующем уроке ([Условие: if, else if и else](lesson:java.from-zero.if-else)) ответы начнут влиять на то, какие команды выполняются: появится условная команда `if`.

<!-- section: programmer -->
## Для тех, кто уже программирует

* `boolean` - отдельный тип, не число: `if (x)` для числа не компилируется, а `boolean b = 1` - ошибка. Это закрывает целый класс ошибок C: присваивание в условии `if (x = 5)` для `int` не скомпилируется.
* `&&` и `||` - короткие, как в C, Go, Python (`and`, `or`) и JavaScript. Есть и некороткие `&` и `|` для `boolean`: оба операнда вычисляются всегда.
* Цепочки сравнений Python (`1 < x < 10`) недоступны. Нет и строгого равенства `===`: тип проверяет компилятор.
* `==` на ссылочных типах сравнивает **ссылки**, а не содержимое: для строк используют `equals`. Для примитивов (`int`, `char`, `boolean`) `==` сравнивает значения.
* Для `double` есть `NaN`: `Double.NaN == Double.NaN` равно `false`; для проверки нужен `Double.isNaN(x)`. Для сравнения дробных с допуском используют `Math.abs(a - b) < eps`.
* `-0.0 == 0.0` равно `true`, хотя `Double.compare(-0.0, 0.0)` их различает.
* Остаток `%` имеет знак делимого, как в C; для неотрицательного остатка есть `Math.floorMod`.
* Оператор `==` на объектах-обёртках (`Integer`) тоже сравнивает ссылки, поэтому результат зависит от кеша значений от -128 до 127; в курсе обёртки не используются.

## Как вычисляется короткое замыкание

Это необязательный раздел: для заданий он не нужен.

Компилятор превращает `a && b` в последовательность переходов: вычислить `a`; если `false`, перейти сразу к результату `false`; иначе вычислить `b`. Именно поэтому правая часть может содержать действие, которое было бы опасным при ложной левой (деление на ноль, обращение к элементу за границей).

Такое поведение называется *коротким замыканием* (short-circuit evaluation). Оно закреплено в спецификации языка, поэтому на него можно полагаться: `n != 0 && 10 / n > 1` безопасно всегда. Для логических операторов `&` и `|` порядок иной: оба операнда вычисляются всегда, и `n != 0 & 10 / n > 1` при `n == 0` бросит исключение. Поэтому в условиях используют `&&` и `||`.

О типе `boolean`: виртуальная машина Java хранит его как целое число (0 или 1), но язык не позволяет смешивать их, поэтому ошибки вроде «число как условие» отлавливаются при компиляции.
