## Зачем нужны разные типы

Значения бывают разной природы: число штук, вес с дробной частью, ответ «да/нет», одна буква. Компьютеру нужно знать, что именно лежит в переменной, чтобы правильно хранить значение и понимать, что с ним можно делать. Вид значения называется **типом**.

Тип защищает от случайных ошибок: если вы попытаетесь положить в переменную для чисел обычный текст, компилятор остановит программу до запуска. Вы уже знаете два типа: `Int` (целое число) и `String` (текст). Здесь добавим ещё четыре.

## Одна новая идея: тип определяется записью значения

| Тип | Что хранит | Как записывают |
|---|---|---|
| `Int` | целое число до примерно 2 миллиардов | `42`, `-7`, `1_000_000` |
| `Long` | целое число с большим диапазоном (до примерно 9 квинтиллионов) | `4600000000017`, `5L` |
| `Double` | число с дробной частью | `1.5`, `0.25`, `3.0` |
| `Boolean` | да или нет | `true`, `false` |
| `Char` | один символ | `'A'`, `'я'`, `'7'` |
| `String` | текст | `"Привет"` |

Kotlin определяет тип по записи: `1.5` с точкой - `Double`; `true` - `Boolean`; символ в **одинарных** кавычках - `Char`; текст в **двойных** - `String`. Тип можно написать и явно, после имени через двоеточие:

```kotlin
val weight: Double = 1.5
```

Явный тип полезен, когда вы хотите зафиксировать намерение или значение без точки должно быть дробным: `val ratio: Double = 3.0`.

<!-- section: examples -->
## Пример 1. Все типы вместе

```kotlin run
fun main() {
    val weight = 1.5
    val inStock = true
    val category = 'M'
    val barcode = 4600000000017
    val title = "Молоко"
    println(title)
    println(weight)
    println(inStock)
    println(category)
    println(barcode)
}
```
```output
Молоко
1.5
true
M
4600000000017
```

Разбор по строкам:

* `1.5` - дробное число, тип `Double`. Целую и дробную части разделяет **точка**, не запятая.
* `true` - логическое значение `Boolean`. Пишется строчными буквами и без кавычек.
* `'M'` - один символ `Char`. Печатается без кавычек.
* `4600000000017` не помещается в `Int` (максимум около 2,1 млрд), поэтому Kotlin сам выбирает `Long`.
* `"Молоко"` - текст `String`, он нам уже знаком.

## Пример 2. Явные типы

```kotlin run
fun main() {
    val price: Double = 49.9
    val count: Int = 3
    val ratio: Double = 3.0
    val letter: Char = 'Я'
    val ready: Boolean = false
    val big: Long = 5L
    println("price=$price, count=$count, ratio=$ratio")
    println("letter=$letter, ready=$ready, big=$big")
}
```
```output
price=49.9, count=3, ratio=3.0
letter=Я, ready=false, big=5
```

Разбор: после двоеточия записан тип. `ratio` явно объявлена как `Double`, поэтому значение `3.0` выводится с дробной частью, а `count` как `Int` - без. Суффикс `L` в `5L` делает литерал числом типа `Long`; в обычных программах он нужен редко.

**Попробуйте.** В примере 2 замените `49.9` на `50.0`, а затем на `50` и сравните: во втором случае компилятор откажется, потому что `50` - это `Int`. Прочитайте сообщение.

## Точные правила

* `Int` хранит целые от -2 147 483 648 до 2 147 483 647. Если целый литерал не помещается в `Int`, Kotlin сделает его `Long`. Для читаемости большие числа можно записывать с подчёркиваниями: `1_000_000`.
* `Long` хранит целые примерно до ±9,2 · 10¹⁸. Если число должно быть `Long`, а значение мало, пишут `5L` или явный тип: `val big: Long = 5`.
* `Double` хранит числа с дробной частью приближённо. Запись с точкой всегда `Double`: `3.0` - это `Double`, а `3` - `Int`. Запятая вместо точки - синтаксическая ошибка.
* `Boolean` принимает только `true` и `false`. Слова `True` и `"true"` - не то же самое.
* `Char` - ровно один символ в одинарных кавычках. `'ab'` - ошибка. `'A'` (символ) и `"A"` (текст из одного символа) - разные типы.
* `String` - текст в двойных кавычках; может быть пустым `""`.
* Явный тип пишется после имени: `val имя: Тип = значение`. Тип с заглавной буквы.
* Kotlin **не превращает** одно число в другое сам: `val price: Double = 5` - ошибка, нужно `5.0`. Для превращения служат функции, о них - в уроке о преобразовании типов.
* Типы `Int`, `Long`, `Double`, `Boolean`, `Char`, `String` называются *встроенными*; их имена пишутся именно так, регистр важен.

## Типичные ошибки

**1. Целое число там, где ждут `Double`.**

```kotlin
fun main() {
    val price: Double = 5
    println(price)
}
```

```text
Main.kt:2:23: error: initializer type mismatch: expected 'Double', actual 'Int'.
    val price: Double = 5
                      ^
```

Объявлен `Double`, а справа `Int`. Напишите `5.0`.

**2. Слишком много символов в `Char`.**

```kotlin
fun main() {
    val letter = 'ab'
    println(letter)
}
```

```text
Main.kt:2:18: error: too many characters in a character literal.
    val letter = 'ab'
                 ^^^^
```

В одинарных кавычках может быть только один символ. Для нескольких букв нужны двойные кавычки и тип `String`.

**3. Текст вместо символа.**

```kotlin
fun main() {
    val c: Char = "a"
    println(c)
}
```

```text
Main.kt:2:17: error: initializer type mismatch: expected 'Char', actual 'String'.
    val c: Char = "a"
                ^
```

`"a"` - текст, `'a'` - символ. Выберите кавычки в соответствии с типом.

**4. Слишком большое число для `Int`.**

```kotlin
fun main() {
    val big: Int = 3000000000
    println(big)
}
```

```text
Main.kt:2:18: error: initializer type mismatch: expected 'Int', actual 'Long'.
    val big: Int = 3000000000
                 ^
```

Значение не помещается в `Int`. Либо уберите явный тип (`val big = 3000000000` станет `Long`), либо объявите `val big: Long`.

**5. Запятая вместо точки.**

```kotlin
fun main() {
    val price = 49,9
    println(price)
}
```

```text
Main.kt:2:19: error: syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
    val price = 49,9
                  ^^
```

Дробную часть в Kotlin отделяет точка: `49.9`. Запятая вне кавычек нужна для другого, и компилятор не понимает, что за `9` стоит после неё.

## Итоги

* `Int` и `Long` - целые числа (разной вместимости), `Double` - числа с дробной частью, `Boolean` - `true`/`false`, `Char` - один символ в `'...'`, `String` - текст в `"..."`.
* Kotlin выводит тип по записи значения, но его можно задать явно: `val x: Double = 1.5`.
* Целое и дробное не смешиваются само: `Double` нельзя инициализировать значением `5`, только `5.0`.
* Дробную часть отделяют точкой, символы пишут в одинарных кавычках.

В следующем уроке ([Арифметика](lesson:kotlin.from-zero.arithmetic)) вы научитесь складывать, умножать и делить числа.

## Для тех, кто уже программирует

* Нет примитивов и обёрток в синтаксисе: `Int`, `Double` и т. д. выглядят как обычные классы, а компилятор сам использует примитивы JVM, где это возможно. Подробности - в `kotlin-first-steps`.
* Нет неявного расширения числовых типов: `val d: Double = 5` и `val l: Long = intValue` не компилируются, нужны `5.0` и `intValue.toLong()`. В Java и C# такое присваивание допустимо.
* Целый литерал, не помещающийся в `Int`, автоматически становится `Long`; суффикс `L` нужен для явного `Long` меньших значений.
* `Char` - не число: `'a' + 1` даёт `Char`, а получить код можно через `'a'.code`. Одинарные кавычки означают только `Char`, а не строку, как в Python и JavaScript.
* Разделитель `_` внутри числовых литералов (`1_000_000`) допустим, как в Java 7+ и Python 3.6+.
* `Double` - это 64-битное число по IEEE 754, поэтому `0.1 + 0.2` не равно `0.3` и здесь (подробнее в уроке об арифметике).
