## Данные и действия над ними вместе

В программе часто есть сущность, у которой несколько свойств: у товара есть название и цена, у счётчика - название и текущее значение. Пока мы хранили такое в отдельных переменных или в двух списках, и связь «этот `price` относится к этому `name`» держалась только в голове программиста. Чем больше свойств, тем легче перепутать.

Решение - **класс**: описание нового типа, который собирает вместе **свойства** (данные) и **методы** (функции, работающие с этими данными). По описанию можно создать сколько угодно **объектов** (экземпляров класса). Это основа большинства реальных программ на Kotlin, а здесь вы познакомитесь с самым маленьким её кусочком.

## Одна новая идея: класс описывает тип, объект хранит конкретные значения

```kotlin
class Item(val name: String, val price: Int)
```

В скобках после имени класса перечислены свойства, которые нужно задать при создании объекта. Объект создают, вызывая класс как функцию: `Item("Хлеб", 45)`. К свойствам обращаются через точку: `bread.name`. Внутри фигурных скобок класса записывают методы: `fun describe(): String { ... }`. Метод вызывают у объекта: `bread.describe()`.

Если перед параметром есть `val`, он становится свойством, которое нельзя менять. Если `var` - свойством, значение которого можно менять после создания объекта. Без `val` и `var` параметр доступен только при создании.

<!-- section: examples -->
## Пример 1. Класс с методом

```kotlin run
class Item(val name: String, val price: Int) {
    fun describe(): String {
        return "$name стоит $price"
    }
}

fun main() {
    val bread = Item("Хлеб", 45)
    val milk = Item("Молоко", 80)
    println(bread.name)
    println(milk.price)
    println(bread.describe())
    println(milk.describe())
}
```
```output
Хлеб
80
Хлеб стоит 45
Молоко стоит 80
```

Разбор:

* `class Item(val name: String, val price: Int)` описывает тип `Item`. Создание объекта `Item("Хлеб", 45)` задаёт оба свойства по порядку.
* `bread` и `milk` - два независимых объекта одного класса, у каждого свои значения.
* Внутри метода `describe` свойства `name` и `price` доступны по имени: метод работает с тем объектом, у которого был вызван.

## Пример 2. Изменяемое свойство и `this`

```kotlin run
class Counter(val label: String) {
    var count = 0

    fun increment() {
        count += 1
    }

    fun show() {
        println("${this.label}: $count")
    }
}

fun main() {
    val steps = Counter("шаги")
    val cups = Counter("чашки")
    steps.increment()
    steps.increment()
    cups.increment()
    steps.show()
    cups.show()
    steps.count = 10
    steps.show()
}
```
```output
шаги: 2
чашки: 1
шаги: 10
```

Разбор:

* Свойство `count` объявлено в теле класса через `var` с начальным значением 0. Параметр конструктора `label` - постоянное свойство.
* `increment()` меняет `count` именно у того объекта, у которого вызван: счётчики `steps` и `cups` не влияют друг на друга.
* Слово `this` означает «текущий объект». `this.label` и просто `label` - одно и то же. `this` нужен, когда имя спрятано другим, например параметром с тем же именем.
* Переменная `steps` объявлена через `val`, но `steps.count = 10` допустимо: `val` запрещает присвоить переменной другой объект, а не менять свойства внутри, если они `var`.

## Пример 3. `data class`

```kotlin run
class Plain(val x: Int)

data class Point(val x: Int, val y: Int)

fun main() {
    println(Plain(1) == Plain(1))
    val a = Point(1, 2)
    val b = Point(1, 2)
    println(a)
    println(a == b)
    println(a.x + b.y)
    val points = mutableListOf<Point>()
    points.add(a)
    points.add(Point(5, 6))
    println(points)
    for (p in points) {
        println("x=${p.x}, y=${p.y}")
    }
}
```
```output
false
Point(x=1, y=2)
true
3
[Point(x=1, y=2), Point(x=5, y=6)]
x=1, y=2
x=5, y=6
```

Разбор:

* Обычный класс сравнивается по тождеству: два объекта `Plain(1)` разные, поэтому `==` даёт `false`.
* Слово `data` перед `class` просит компилятор добавить удобное поведение: читаемую печать вида `Point(x=1, y=2)` и сравнение `==` по значениям свойств.
* Объекты можно хранить в списках, как числа или строки: тип списка - `MutableList<Point>`.
* Для классов, которые в основном хранят данные (точка, товар, запись), используют `data class`.

**Чтение записей.** Программа, создающая объекты из ввода, показана без запуска:

```kotlin
data class Item(val name: String, val price: Int)

fun main() {
    val n = readln().toInt()
    val items = mutableListOf<Item>()
    for (i in 1..n) {
        val parts = readln().split(" ")
        items.add(Item(parts[0], parts[1].toInt()))
    }
    println(items)
}
```

Для ввода `2`, `чай 50`, `кофе 120` она напечатает `[Item(name=чай, price=50), Item(name=кофе, price=120)]`.

**Попробуйте.** В примере 1 добавьте метод `discounted(percent: Int): Int`, который возвращает цену со скидкой (`price * (100 - percent) / 100`), и вызовите его у `milk`.

## Точные правила

* Класс - описание типа: `class Имя(параметры) { методы и свойства }`. Фигурные скобки не нужны, если тела нет.
* Параметр с `val` или `var` в круглых скобках после имени класса - одновременно параметр создания и свойство. Параметр без `val`/`var` свойством не становится.
* Объект создают вызовом `Имя(значения)`. Слова `new`, как в Java, в Kotlin нет.
* Все параметры без значений по умолчанию нужно передать при создании, в том же порядке и с теми же типами.
* Свойство `val` нельзя присвоить повторно, свойство `var` можно. Свойство в теле класса объявляют так же, как переменную, и задают начальное значение.
* Метод - функция внутри класса. Внутри метода свойства объекта доступны по имени, а `this` - сам объект.
* Метод вызывают у объекта через точку: `объект.метод(аргументы)`.
* `val` у переменной с объектом означает, что нельзя присвоить переменной другой объект; свойства `var` внутри объекта менять можно.
* У `data class` должен быть хотя бы один параметр с `val` или `var`. Он получает печать вида `Класс(поле=значение)` и сравнение `==` по значениям.
* Объекты - значения как любые другие: их можно передавать в функции, возвращать из функций и хранить в списках и словарях.

## Типичные ошибки

**1. Присваивание `val`-свойству.**

```kotlin
class Item(val name: String, val price: Int)

fun main() {
    val bread = Item("Хлеб", 45)
    bread.price = 50
}
```

```text
Main.kt:5:11: error: 'val' cannot be reassigned.
    bread.price = 50
          ^^^^^
```

Свойство объявлено через `val`. Если цена должна меняться, объявите `var price: Int`.

**2. Параметр без `val`/`var` не является свойством.**

```kotlin
class Item(name: String, val price: Int)

fun main() {
    val bread = Item("Хлеб", 45)
    println(bread.name)
}
```

```text
Main.kt:5:19: error: unresolved reference 'name' on receiver of type 'Item'.
    println(bread.name)
                  ^^^^
```

Параметр `name` доступен только при создании объекта. Чтобы он стал свойством, напишите `val name: String`.

**3. Не переданы все параметры.**

```kotlin
class Item(val name: String, val price: Int)

fun main() {
    val bread = Item("Хлеб")
}
```

```text
Main.kt:4:17: error: no value passed for parameter 'price'.
    val bread = Item("Хлеб")
                ^^^^
```

При создании нужно передать и название, и цену.

**4. Слово `new`.**

```kotlin
class Item(val name: String, val price: Int)

fun main() {
    val bread = new Item("Хлеб", 45)
}
```

```text
Main.kt:4:17: error: unresolved reference 'new'.
    val bread = new Item("Хлеб", 45)
                ^^^
Main.kt:4:32: error: syntax error: Expecting ')'.
...
```

Показаны не все сообщения компилятора: их три, остальные - следствие первого. В Kotlin объект создают без `new`: `Item("Хлеб", 45)`.

**5. Метод вызван без объекта.**

```kotlin
class Item(val name: String, val price: Int) {
    fun describe(): String = "$name: $price"
}

fun main() {
    println(describe())
}
```

```text
Main.kt:6:13: error: unresolved reference 'describe'.
    println(describe())
            ^^^^^^^^
```

Метод принадлежит объекту, поэтому вызов записывают через него: `bread.describe()`.

**6. `data class` без параметров.**

```kotlin
data class Empty()

fun main() {
    println(Empty())
}
```

```text
Main.kt:1:17: error: data class must have at least one primary constructor parameter.
data class Empty()
                ^^
```

`data class` хранит данные, поэтому ему нужно хотя бы одно свойство в скобках.

## Итоги

* Класс объединяет свойства и методы в один тип; объект создают вызовом `Имя(значения)`.
* Параметр с `val` или `var` становится свойством; `val` нельзя переприсвоить, `var` можно.
* Методы вызывают у объекта через точку, внутри метода свойства доступны по имени, а `this` - текущий объект.
* `data class` добавляет читаемую печать и сравнение по значениям; такие объекты удобно хранить в списках.
* Нового слова `new` в Kotlin нет.

Теперь у вас есть все средства для небольшой программы: ввод, условия, циклы, функции, списки, словари, обработка плохих строк и классы. Соберём их в проекте: [Мини-проект](lesson:kotlin.from-zero.mini-project).

## Для тех, кто уже программирует

* Основной конструктор записан в заголовке класса; отдельного блока конструктора и `new` нет. Параметры с `val`/`var` сразу создают свойства, нет шаблона «поле + геттер + сеттер», как в Java.
* Свойства Kotlin доступны как поля (`bread.price`), но на самом деле это пара геттер/сеттер. Можно переопределять их позже, не меняя вызовов.
* Классы по умолчанию закрыты для наследования (`final`). Чтобы унаследоваться, класс помечают `open`. Интерфейсы, наследование, `object`, `companion object` и `sealed` разбираются в `kotlin-fundamentals`.
* `data class` автоматически получает `equals`, `hashCode`, `toString`, `copy` и деструктуризацию. Это короткий аналог `record` из Java и `dataclass` из Python.
* Модификаторов `public` нет: по умолчанию всё открыто. Закрывают через `private`.
* `==` вызывает `equals`, как в Java, но в обратную сторону от привычки `.equals`; сравнение ссылок записывают `===`.
* Структур, как в Go, нет, но `data class` с `val`-полями заменяет их в большинстве случаев.
