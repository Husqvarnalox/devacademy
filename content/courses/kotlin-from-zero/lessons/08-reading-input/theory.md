## Зачем нужен ввод

До сих пор все данные были записаны в программе. Программа, которая всегда обрабатывает одни и те же значения, мало полезна: настоящая программа получает данные снаружи - от пользователя, из файла, от другой программы. Всё, что программа получает из внешнего мира, называется **вводом**. Ввод приходит текстом: даже число сначала записано цифрами, и программе нужно его прочитать.

Текст попадает на **стандартный ввод** (stdin) вашей программы - канал, по которому данные поступают в программу. В приложении вы вписываете его в специальное поле перед запуском (подробно - в подразделе «Как подать ввод своей программе» ниже), а при проверке решения его подаёт тест. Прочитать одну его строку помогает готовая команда `readln()`.

## Одна новая идея: readln() читает одну строку и возвращает её как текст

```kotlin
val name = readln()
```

Команда `readln()` (от *read line*, «прочитать строку») берёт из ввода очередную строку - всё до перевода строки - и возвращает её как значение типа `String`. Это значение можно сохранить в переменную и использовать как любой текст.

Что важно:

* один вызов читает **одну** строку; три строки на входе - три вызова;
* порядок вызовов задаёт порядок чтения: первый вызов получает первую строку, второй - вторую;
* строка читается целиком, вместе с пробелами внутри;
* результат всегда текст, даже если на входе цифры; как превратить текст в число, расскажет следующий урок.

## Как подать ввод своей программе

1. Под редактором откройте вкладку **«Вывод»**.
2. Нажмите на строку **«Ввод программы (stdin)»**: под ней раскроется поле.
3. Впишите в поле весь ввод заранее: каждое значение на своей строке, потому что один вызов `readln()` читает одну строку. Например, для примера 1 впишите `Анна` на первой строке и `Минск` на второй.
4. Нажмите **«Запустить»**.

Программа не останавливается и не ждёт, пока вы что-то напечатаете: всё, что записано в поле, она получает сразу при запуске. Если поле пустое, ввод пустой. Пока урок открыт, текст в поле остаётся, так что для следующего запуска достаточно поменять данные.

Кнопка **«Проверить решение»** это поле не использует: она запускает программу на вводе каждого теста по очереди.

## Пример 1. Две строки

Эту программу нельзя запустить в окне примеров, потому что там нет ввода, поэтому приведены ввод и вывод.

```kotlin
fun main() {
    val name = readln()
    val city = readln()
    println("Привет, $name из города $city!")
}
```

Ввод:

```text
Анна
Минск
```

Вывод:

```text
Привет, Анна из города Минск!
```

Разбор: первый `readln()` вернул `Анна`, второй - `Минск`. Значения сохранены в двух переменных и вставлены в шаблон.

## Пример 2. Строка с пробелами читается целиком

```kotlin
fun main() {
    val fullName = readln()
    println("Длина имени: ${fullName.length}")
    println(fullName.uppercase())
}
```

Ввод:

```text
Анна Смирнова
```

Вывод:

```text
Длина имени: 13
АННА СМИРНОВА
```

Разбор: `readln()` не делит строку на слова. Пробел - обычный символ, он вошёл в длину: 4 буквы, пробел и 8 букв дают 13.

## Пример 3. Ввод - это текст, а не число

```kotlin
fun main() {
    val line = readln()
    println("Символов: ${line.length}")
    println("Первый: ${line[0]}")
}
```

Ввод:

```text
12345
```

Вывод:

```text
Символов: 5
Первый: 1
```

Разбор: цифры на входе читаются как текст из пяти символов. Складывать или умножать такое значение нельзя, пока оно не превращено в число (следующий урок).

**Попробуйте.** Допишите пример 1 так, чтобы он читал ещё и третью строку - год рождения - и печатал её через запятую после города. Подайте на вход три строки и проверьте вывод.

## Точные правила

* `readln()` читает строку до символа перевода строки; сам перевод в результат не входит. Пробелы в начале и в конце строки сохраняются.
* Пустая строка во вводе читается как `""`.
* Каждый вызов `readln()` двигает чтение вперёд: прочитанная строка больше не будет прочитана.
* Если вводных строк меньше, чем вызовов `readln()`, программа останавливается с `ReadAfterEOFException` (EOF - *end of file*, «конец ввода»). Чтение «пока есть данные» разбирается позже.
* `readln()` возвращает `String`. Присвоить результат переменной типа `Int` нельзя: нужно преобразование.
* Вызывать нужно со скобками: `readln()`, а не `readln`.
* Программа в упражнении проверяется по тому, что она напечатала. Любой лишний вывод, в том числе «Введите имя:», считается ошибкой, поэтому приглашений к вводу в уроках нет.
* Если ввод поступает из файла или другой программы, `readln()` работает так же, как при вводе с клавиатуры.

## Типичные ошибки

**1. Читать больше строк, чем подано.**

```kotlin
fun main() {
    val n = readln()
    println(n)
}
```

При пустом вводе программа собирается, но при запуске печатает:

```text
Exception in thread "main" kotlin.io.ReadAfterEOFException: EOF has already been reached
	at kotlin.io.ConsoleKt.readln(Console.kt:152)
	at MainKt.main(Main.kt:2)
```

(В полном сообщении есть ещё одна строка стека.) Исключение называет причину: ввод уже закончился, а `readln()` ждёт новую строку. Сверьте число вызовов `readln()` с числом строк во вводе. Номер `Main.kt:2` показывает, какая именно строка программы читала.

**2. Присвоить текст числовой переменной.**

```kotlin
fun main() {
    val n: Int = readln()
    println(n)
}
```

```text
Main.kt:2:16: error: initializer type mismatch: expected 'Int', actual 'String'.
    val n: Int = readln()
               ^
```

`readln()` всегда возвращает текст. Преобразование текста в число - тема следующего урока.

**3. Забыть скобки.**

```kotlin
fun main() {
    val name = readln
    println(name)
}
```

```text
Main.kt:2:16: error: function invocation 'readln()' expected.
    val name = readln
               ^^^^^^
```

`readln` без скобок - имя команды, а не её вызов. Добавьте `()`.

**4. Приглашение к вводу в выводе.** Программа

```kotlin
fun main() {
    println("Введите имя:")
    val name = readln()
    println("Привет, $name!")
}
```

не вызывает ошибок, но для ввода `Анна` напечатает две строки: `Введите имя:` и `Привет, Анна!`. Проверка ожидает только `Привет, Анна!`, и тест не будет пройден. В заданиях печатайте только то, что требует условие.

**5. Ждать, что `readln()` разделит слова.** Для ввода `Анна Смирнова` одна команда `readln()` вернёт всю строку целиком. Разбивать строку на части научит урок о методах строк.

## Итоги

* Ввод - данные, которые программа получает снаружи; в упражнениях они приходят на стандартный ввод (stdin).
* `readln()` читает одну строку целиком и возвращает её как `String`; количество вызовов должно совпадать с количеством строк, которые нужно прочитать.
* Результат - всегда текст: числа из ввода придётся преобразовывать.
* Не печатайте приглашений: проверяется только вывод, который требует условие.

В следующем уроке ([Преобразование типов](lesson:kotlin.from-zero.type-conversion)) вы научитесь превращать прочитанный текст в числа и считать с ними.

## Для тех, кто уже программирует

* `readln()` - аналог `input()` в Python и `Console.ReadLine()` в C#, но без приглашения и со строгим типом результата: `String`, не `String?`. На конце ввода бросает `ReadAfterEOFException`.
* Нуллируемая версия `readlnOrNull()` возвращает `null` в конце ввода; старая `readLine()` тоже возвращает `String?`. Они пригодятся для чтения «до конца ввода» (урок 18).
* Нет объекта-читателя вроде `Scanner` в Java: чтение стандартного ввода - обычная функция из стандартной библиотеки, импорт не нужен.
* Для большого объёма данных читают сразу весь ввод: ``System.`in`.bufferedReader().readText()`` (именно так в упражнении `kotlin-first-steps`); для небольших задач хватает `readln()` в цикле.
* Разбиение строки на слова и числа выполняют `split(" ")` и `toInt()`, они разобраны в следующих уроках.
