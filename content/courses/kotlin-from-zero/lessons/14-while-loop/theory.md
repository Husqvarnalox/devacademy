## Зачем повторять действия

Многие задачи состоят из повторений: пересчитать товары в чеке, прочитать список оценок, ждать, пока пользователь введёт правильное число. Писать одну и ту же команду десять раз неудобно, а когда повторений заранее неизвестно сколько - невозможно. Для этого существуют **циклы**: конструкции, которые выполняют блок команд снова и снова.

## Одна новая идея: пока условие истинно, блок выполняется заново

Цикл `while` («пока») выглядит так:

```kotlin
while (условие) {
    // тело цикла
}
```

Программа делает по шагам:

1. Проверяет условие.
2. Если оно истинно, выполняет тело цикла целиком и **возвращается к шагу 1**.
3. Если оно ложно, пропускает тело и продолжает работу после цикла.

Каждое выполнение тела называется **итерацией** («повторением»). Условие проверяется **перед** каждой итерацией, поэтому цикл может не выполниться ни разу. Чтобы цикл когда-нибудь закончился, тело должно менять что-то, от чего зависит условие: чаще всего это переменная-**счётчик**, например `count += 1`. Переменная в таком цикле объявляется через `var`, потому что её значение меняется.

## Пример 1. Счётчик и накопление

```kotlin run
fun main() {
    var count = 1
    while (count <= 5) {
        println("Шаг $count")
        count += 1
    }
    println("Готово, count = $count")
    var money = 100
    var years = 0
    while (money < 200) {
        money = money * 11 / 10
        years += 1
    }
    println("Через $years лет будет $money")
    var k = 10
    while (k < 5) {
        println("Это не напечатается")
        k += 1
    }
    println("k = $k")
}
```
```output
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5
Готово, count = 6
Через 8 лет будет 212
k = 10
```

Разбор:

* Первый цикл печатает шаги, пока `count <= 5`. После пятой итерации `count` становится 6, условие ложно, и цикл заканчивается. Заметьте, что после цикла `count` равно 6, а не 5.
* Во втором цикле число повторений заранее неизвестно: деньги растут на 10% в год (целочисленно, с отбрасыванием дробной части), пока не достигнут 200. Подсчитывает итерации переменная `years`. Такие задачи удобно решать именно через `while`.
* Третий цикл не выполняется ни разу: условие `k < 5` ложно с самого начала, тело пропускается.

## Пример 2. Разбор числа по цифрам

```kotlin run
fun main() {
    var n = 4072
    var digits = 0
    var sum = 0
    while (n > 0) {
        sum += n % 10
        n /= 10
        digits += 1
    }
    println("Цифр: $digits, сумма: $sum")
}
```
```output
Цифр: 4, сумма: 13
```

Разбор:

* `n % 10` - последняя цифра числа, `n /= 10` отбрасывает её (деление нацело). На первых итерациях `n` равно 4072, 407, 40, 4, а затем 0 - и цикл останавливается.
* Переменные `digits` и `sum` накапливают результат от итерации к итерации. Это обычный приём: задать начальное значение до цикла (`0`) и менять его в теле.

## Пример 3. Ввод до значения-ограничителя

Заранее неизвестно, сколько чисел введёт пользователь. Договариваются о **ограничителе** (англ. *sentinel*) - особом значении, которое означает «конец». Здесь это `0`. Такая программа читает ввод, поэтому показана обычным блоком, без запуска.

```kotlin
fun main() {
    var sum = 0
    var count = 0
    var x = readln().toInt()
    while (x != 0) {
        sum += x
        count += 1
        x = readln().toInt()
    }
    println("Чисел: $count, сумма: $sum")
}
```

Для ввода

```text
5
12
-3
0
```

программа напечатает `Чисел: 3, сумма: 14`.

Разбор:

* Первое число читается **до** цикла, чтобы условию `x != 0` было что проверять.
* В теле цикла число учитывается, а затем читается следующее. Именно эта строка в конце тела двигает цикл вперёд: без неё условие навсегда осталось бы прежним.
* Число `0` в сумму не попадает: прочитав его, программа проверяет условие, видит `0` и выходит из цикла.

**Попробуйте.** В примере 1 замените условие `count <= 5` на `count < 5` и предскажите вывод. В примере 2 запустите программу с `n = 100`: сколько цифр она насчитает и почему?

## Точные правила

* Условие цикла обязано иметь тип `Boolean` и записывается в скобках. Тело заключают в фигурные скобки.
* Условие проверяется перед каждой итерацией. Если оно ложно с самого начала, тело не выполняется ни разу.
* Значение, от которого зависит условие, обычно хранится в `var`. Если переменная объявлена как `val`, менять её нельзя, и цикл на её основе либо не начнётся, либо не закончится.
* Цикл, у которого условие никогда не становится ложным, называется **бесконечным**. Программа с таким циклом не завершается сама, и её приходится останавливать принудительно. Обычная причина - забытое изменение переменной в теле.
* Типичная схема цикла с ограничителем: прочитать значение, `while (значение != ограничитель)`, обработать, прочитать следующее. Если ввод закончился, а ограничитель так и не встретился, `readln()` бросает исключение `ReadAfterEOFException`.
* Счётчик, который считает с 1 до `n`, при условии `i <= n` повторит тело `n` раз; при условии `i < n` - на одну итерацию меньше. Ошибка на единицу в границе - самая частая в циклах.
* Присваивание в условии (`while (x = 0)`) не допускается: присваивание не является выражением.

## Типичные ошибки

**1. Забыли изменить счётчик.**

```kotlin
fun main() {
    var count = 1
    while (count <= 3) {
        println("Шаг $count")
    }
}
```

Ошибки компиляции нет, но программа не завершается и печатает без остановки:

```text
Шаг 1
Шаг 1
Шаг 1
Шаг 1
...
```

(Показаны первые строки; вывод бесконечен.) Значение `count` в теле не меняется, условие всегда истинно. Добавьте в тело `count += 1`.

**2. Число вместо условия.**

```kotlin
fun main() {
    var count = 3
    while (count) {
        count -= 1
    }
}
```

```text
Main.kt:3:12: error: condition type mismatch: inferred type is 'Int' but 'Boolean' was expected.
    while (count) {
           ^^^^^
```

Как и в `if`, условие обязано быть `Boolean`. Для «пока не ноль» напишите `count != 0` или `count > 0`.

**3. Счётчик объявлен через `val`.**

```kotlin
fun main() {
    val count = 0
    while (count < 3) {
        count += 1
    }
}
```

```text
Main.kt:4:9: error: 'val' cannot be reassigned.
    count += 1
    ^^^^^
```

Значение переменной `val` назначается один раз. Переменной, которая меняется в цикле, нужен `var`.

**4. Ограничитель не встретился.**

```kotlin
fun main() {
    var sum = 0
    var x = readln().toInt()
    while (x != 0) {
        sum += x
        x = readln().toInt()
    }
    println(sum)
}
```

Для ввода из двух строк `5` и `3` без завершающего `0`:

```text
Exception in thread "main" kotlin.io.ReadAfterEOFException: EOF has already been reached
	at kotlin.io.ConsoleKt.readln(Console.kt:152)
	at MainKt.main(Main.kt:6)
	at MainKt.main(Main.kt)
```

Ввод закончился, а `readln()` ждёт ещё одну строку. Если в условии задачи ограничитель гарантирован, это не проблема; если нет, нужен способ проверить конец ввода (его покажет урок о значениях, которых может не быть).

**5. Присваивание вместо сравнения.**

```kotlin
fun main() {
    var x = 3
    while (x = 0) {
        x -= 1
    }
}
```

```text
Main.kt:3:12: error: only expressions are allowed in this context.
    while (x = 0) {
           ^^^^^
```

Для сравнения нужен `==` (или `!=`, `>`, `<`). Одиночный `=` присваивает значение и условием быть не может.

## Итоги

* `while (условие) { тело }` повторяет тело, пока условие истинно. Условие проверяется перед каждой итерацией.
* Цикл нужен, когда число повторений заранее неизвестно. Тело должно менять то, от чего зависит условие, иначе цикл бесконечен.
* Переменные-счётчики и накопители объявляются через `var` и получают начальное значение до цикла.
* Ввод до ограничителя: прочитать значение до цикла, проверить его в условии, а в конце тела читать следующее.

Когда число повторений известно заранее (от 1 до `n`), цикл удобнее записывать короче и безопаснее: [Цикл for и диапазоны](lesson:kotlin.from-zero.for-loop).

## Для тех, кто уже программирует

* `while (cond) { ... }` работает как в Java, C# и JavaScript; скобки вокруг условия обязательны, точек с запятой нет. Цикла `do { } while (cond)` с проверкой после тела в Kotlin тоже есть, но в курсе он не используется.
* Условие обязано быть `Boolean`: `while (n)` невозможно, в отличие от Python, JavaScript и C.
* Присваивание в Kotlin не выражение, поэтому классическая идиома C `while ((line = readLine()) != null)` не записывается. Вместо неё читают в теле: `while (true) { val line = readlnOrNull() ?: break; ... }` (урок 18).
* Цикла `while ... else` из Python нет. Цикл `loop {}` из Rust заменяется на `while (true)`.
* `readln()` при конце ввода бросает `ReadAfterEOFException` (в Java `BufferedReader.readLine()` вернул бы `null`, в Python `input()` бросает `EOFError`).
* Для счётчика от 1 до `n` идиоматичнее `for (i in 1..n)`; `while` оставляют для случаев, когда число итераций неизвестно.
