## Зачем нужны функции

Чем длиннее программа, тем чаще в ней повторяются одни и те же вычисления: цена со скидкой, проверка возраста, красивая печать строки. Копировать такой код в несколько мест опасно: найдя ошибку в одной копии, легко забыть исправить остальные. Кроме того, длинный `main`, где перемешано всё сразу, трудно читать.

Решение - оформить повторяющуюся часть как **функцию**: блок команд, которому дали имя. Один раз описываете, сколько угодно раз вызываете по имени. Вы уже пользуетесь функциями: `println`, `readln` и `toInt` - это функции, написанные до вас, а `main` из первого урока - тоже функция, которую вызывает система при запуске.

## Одна новая идея: функция принимает значения и возвращает результат

```kotlin
fun имя(параметр: Тип, ...): ТипРезультата {
    // команды
    return значение
}
```

* `fun` - слово, объявляющее функцию.
* **Параметры** - имена, через которые функция получает данные при вызове. Для каждого обязательно указывается тип.
* **Тип результата** записывается после двоеточия: каким будет значение, которое функция отдаёт.
* `return` («вернуть») завершает функцию и отдаёт значение вызвавшему.

Вызов выглядит как `square(5)`. Значения в скобках называют **аргументами**: они подставляются в параметры. Функция, которая ничего не возвращает, а только что-то делает (например, печатает), не имеет типа результата в записи.

## Пример 1. Первая функция

```kotlin run
fun square(x: Int): Int {
    return x * x
}

fun greet(name: String) {
    println("Привет, $name!")
}

fun main() {
    println(square(5))
    val area = square(12) + square(3)
    println("Сумма площадей: $area")
    greet("Анна")
    greet("Борис")
}
```
```output
25
Сумма площадей: 153
Привет, Анна!
Привет, Борис!
```

Разбор:

* `square` принимает один параметр `x` типа `Int` и возвращает `Int`. При вызове `square(5)` параметр `x` получает значение 5, тело считает `5 * 5`, а `return` отдаёт 25.
* Вызов функции - выражение, поэтому его результат можно напечатать или использовать в вычислении: `square(12) + square(3)`.
* `greet` ничего не возвращает: она печатает приветствие. Поэтому после списка параметров нет двоеточия и типа.
* Функции объявлены на верхнем уровне файла, рядом с `main`. Порядок их записи не важен: `main` может стоять и выше.

## Пример 2. Несколько параметров, выражение-тело, ранний возврат

```kotlin run
fun total(price: Int, count: Int): Int = price * count

fun discount(price: Int, percent: Int): Int {
    val cut = price * percent / 100
    return price - cut
}

fun describe(n: Int): String {
    if (n < 0) {
        return "отрицательное"
    }
    if (n == 0) {
        return "ноль"
    }
    return "положительное"
}

fun shout(text: String) {
    println(text.uppercase() + "!")
}

fun main() {
    println(total(120, 3))
    println(discount(2000, 15))
    println(describe(-4))
    println(describe(0))
    println(describe(9))
    val r = shout("привет")
    println(r)
}
```
```output
360
1700
отрицательное
ноль
положительное
ПРИВЕТ!
kotlin.Unit
```

Разбор:

* Если тело функции - одно выражение, фигурные скобки и `return` можно заменить знаком `=`: `fun total(price: Int, count: Int): Int = price * count`. Это сокращённая запись той же функции.
* Аргументы подставляются в параметры **по порядку**: в `total(120, 3)` цена - 120, количество - 3.
* В `discount` есть своя переменная `cut`. Она существует только внутри функции.
* В `describe` команда `return` срабатывает сразу и завершает функцию: остальной код не выполняется. Для любого числа выполнится ровно один из трёх `return`.
* Функция без явного типа результата на самом деле возвращает специальное значение `Unit` («ничего примечательного»). Обычно его не используют, но последние две строки `main` показывают: `println(r)` печатает `kotlin.Unit`.

## Пример 3. Область видимости

```kotlin run
fun counter(): Int {
    var inside = 10
    inside += 1
    return inside
}

fun main() {
    val x = 1
    println(counter())
    println(counter())
    println(x)
}
```
```output
11
11
1
```

Разбор:

* Переменная `inside` создаётся при каждом вызове заново и исчезает, когда функция закончилась. Поэтому оба вызова дают 11, а не 11 и 12.
* Переменная `x` из `main` внутри `counter` не видна, а `inside` не видна в `main`. Область, где имя действует, называется его **областью видимости**.

**Функция с вводом.** Начиная с этого урока задания устроены так: функцию пишете вы, а `main` с чтением ввода уже написан в заготовке и вызывает вашу функцию на разных данных. Такая программа читает ввод, поэтому показана без запуска:

```kotlin
fun fee(age: Int): Int {
    if (age < 7) {
        return 0
    }
    if (age < 18) {
        return 200
    }
    return 400
}

fun main() {
    val n = readln().toInt()
    for (i in 1..n) {
        val age = readln().toInt()
        println("Возраст $age: ${fee(age)}")
    }
}
```

Для ввода `3`, `5`, `12`, `40` (по числу в строке) программа напечатает строки `Возраст 5: 0`, `Возраст 12: 200`, `Возраст 40: 400`.

**Попробуйте.** В примере 2 вызовите `discount(500, 10)` и `total(discount(100, 20), 3)` (результат одной функции можно передать в другую) и предскажите ответы. Затем напишите функцию `isAdult(age: Int): Boolean`, которая возвращает `age >= 18`.

## Точные правила

* Объявление: `fun имя(параметры): ТипРезультата { тело }`. Имена функций и параметров пишут с маленькой буквы в стиле `camelCase`.
* У каждого параметра обязателен тип: `fun square(x: Int)`. Несколько параметров разделяются запятой.
* Если функция возвращает значение, тип результата указывается после `:`, а на каждом пути выполнения должен быть `return` значения этого типа. Компилятор проверяет, что функция не может «дойти до конца» без результата.
* Короткая запись `fun имя(параметры): Тип = выражение` эквивалентна телу с одним `return`. Тип результата здесь можно опустить, если компилятор его выведет сам, но для читаемости его лучше указывать.
* Функция без типа результата возвращает `Unit`. Писать `return Unit` не нужно, `return` без значения тоже допустим.
* Параметры неизменяемы (как `val`): присвоить им новое значение нельзя. Если нужна копия для изменения, заведите локальную `var`.
* Аргументы передаются **по значению**: функция получает копию числа или ссылку на строку, и изменить переменную `main` из функции нельзя. Результат возвращают через `return`.
* Область видимости: локальные переменные и параметры доступны только внутри функции. Переменная, объявленная в блоке `{ }`, видна от места объявления до конца блока.
* Порядок функций в файле значения не имеет: можно вызывать функцию, которая записана ниже.
* Одна функция - одно действие. Если для названия приходится использовать «и», обычно это две функции.

## Типичные ошибки

**1. Нет `return`.**

```kotlin
fun double(x: Int): Int {
    val result = x * 2
}

fun main() {
    println(double(4))
}
```

```text
Main.kt:3:1: error: missing return statement.
}
^
```

Функция обещает вернуть `Int`, но значение не отдаёт. Добавьте `return result` или превратите её в `fun double(x: Int): Int = x * 2`.

**2. Аргумент не того типа.**

```kotlin
fun square(x: Int): Int = x * x

fun main() {
    println(square("5"))
}
```

```text
Main.kt:4:20: error: argument type mismatch: actual type is 'String', but 'Int' was expected.
    println(square("5"))
                   ^^^
```

Функция ждёт `Int`, а получила текст. Если число пришло из ввода как строка, преобразуйте его: `square("5".toInt())`.

**3. Неверное число аргументов.**

```kotlin
fun square(x: Int): Int = x * x

fun main() {
    println(square(1, 2))
}
```

```text
Main.kt:4:23: error: too many arguments for 'fun square(x: Int): Int'.
    println(square(1, 2))
                      ^
```

Сообщение содержит заголовок функции - сверьтесь с ним. Если аргументов не хватает, ошибка будет вида `no value passed for parameter`.

**4. Результат другого типа.**

```kotlin
fun label(x: Int): Int {
    return "число $x"
}

fun main() {
    println(label(4))
}
```

```text
Main.kt:2:12: error: return type mismatch: expected 'Int', actual 'String'.
    return "число $x"
           ^^^^^^^^^^
```

В заголовке указано `Int`, а возвращается строка. Исправьте тип результата на `String` или само значение.

**5. Локальная переменная за пределами функции.**

```kotlin
fun counter(): Int {
    var inside = 10
    return inside
}

fun main() {
    counter()
    println(inside)
}
```

```text
Main.kt:8:13: error: unresolved reference 'inside'.
    println(inside)
            ^^^^^^
```

Имя `inside` известно только внутри `counter`. Хотите использовать значение - сохраните результат вызова: `val value = counter()`.

**6. Попытка изменить параметр.**

```kotlin
fun addOne(n: Int): Int {
    n += 1
    return n
}

fun main() {
    println(addOne(4))
}
```

```text
Main.kt:2:5: error: 'val' cannot be reassigned.
    n += 1
    ^
```

Параметр неизменяем. Вычислите новое значение в локальной переменной или сразу верните `n + 1`.

**7. Пропущен тип параметра.**

```kotlin
fun square(x): Int = x * x

fun main() {
    println(square(4))
}
```

```text
Main.kt:1:12: error: an explicit type is required on a value parameter.
fun square(x): Int = x * x
           ^
```

Для переменных тип можно не писать, но у параметров функции он обязателен: `fun square(x: Int)`.

## Итоги

* Функция - блок команд с именем: `fun имя(параметры): Тип { ... return значение }`.
* Параметры принимают данные, `return` отдаёт результат. Функция без результата возвращает `Unit` и записывается без типа.
* Локальные переменные и параметры видны только внутри функции; параметры неизменяемы.
* Короткая запись `fun f(x: Int): Int = x * x` подходит для тела из одного выражения.
* С этого урока задания содержат готовый `main`, который читает ввод и вызывает вашу функцию.

В следующем уроке выяснится, что делать, когда значения может не быть вовсе: [Значения, которых может не быть](lesson:kotlin.from-zero.nullable-values).

## Для тех, кто уже программирует

* Функции объявляются на верхнем уровне файла без класса и `static`; `Main.kt` превращается в класс `MainKt`, а функции - в его статические методы.
* Тип результата пишется после двоеточия, `Unit` соответствует `void`, но это настоящий тип со значением `kotlin.Unit`.
* Параметры неизменяемы, как `final` в Java. Аргументы передаются по значению (для объектов - значение ссылки), как в Java, а не по ссылке, как `ref` в C#.
* Вызывать функцию можно до её объявления в файле; предварительных объявлений, как в C, нет.
* Есть возможности, которые курс откладывает: значения параметров по умолчанию, именованные аргументы (`discount(price = 100, percent = 10)`), функции-расширения и лямбды, функции внутри функций. В подходящих местах fundamentals они будут показаны.
* Нет перегрузки по возвращаемому типу; перегрузка по параметрам есть. Тело-выражение выводит тип сам (`fun f() = 5`), но для публичных функций лучше указывать его явно.
