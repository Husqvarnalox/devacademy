## Зачем нужен ещё один цикл

В прошлом уроке цикл `while` повторял действия, пока истинно условие. Но очень часто число повторений известно заранее: напечатать таблицу умножения (10 строк), прочитать `n` чисел, пройти по всем буквам слова. Для такого цикла со `while` приходится писать три вещи отдельно: начальное значение счётчика, условие и его увеличение. Если забыть любую из них, цикл ломается.

Цикл `for` («для») собирает всё в одной строке: **для каждого** значения из заданного набора выполнить тело.

## Одна новая идея: цикл перебирает значения диапазона

```kotlin
for (i in 1..5) {
    // тело выполняется для i = 1, 2, 3, 4, 5
}
```

Запись `1..5` называется **диапазоном**: это числа от 1 до 5 включительно. Слово `in` читается «из». Переменная `i` - **переменная цикла**: на каждой итерации она получает очередное значение диапазона, и объявлять её отдельно не нужно. Менять её внутри тела нельзя: она создаётся заново на каждом шаге.

Кроме `..` диапазоны задаются так:

| Запись | Числа |
|---|---|
| `1..5` | 1, 2, 3, 4, 5 |
| `0 until 5` | 0, 1, 2, 3, 4 (правый конец **не** входит) |
| `5 downTo 1` | 5, 4, 3, 2, 1 (по убыванию) |
| `0..20 step 5` | 0, 5, 10, 15, 20 (с шагом 5) |

Если нужно просто повторить действие `n` раз и номер повторения не нужен, есть короткая запись `repeat(n) { ... }`.

<!-- section: examples -->
## Пример 1. Первые циклы

```kotlin run
fun main() {
    for (i in 1..5) {
        println("i = $i")
    }
    var sum = 0
    for (n in 1..100) {
        sum += n
    }
    println("Сумма 1..100: $sum")
    repeat(3) {
        println("Привет")
    }
}
```
```output
i = 1
i = 2
i = 3
i = 4
i = 5
Сумма 1..100: 5050
Привет
Привет
Привет
```

Разбор:

* Первый цикл выполняется пять раз; `i` пробегает значения от 1 до 5.
* Во втором цикле накапливается сумма всех чисел от 1 до 100. Переменная `sum` объявлена **до** цикла через `var` и меняется в теле.
* `repeat(3) { ... }` трижды выполняет команды в фигурных скобках. Переменная цикла здесь не нужна.

## Пример 2. Разные диапазоны и перебор символов

```kotlin run
fun main() {
    for (i in 0 until 3) print("$i ")
    println()
    for (i in 5 downTo 1) print("$i ")
    println()
    for (i in 0..20 step 5) print("$i ")
    println()
    for (i in 10 downTo 0 step 4) print("$i ")
    println()
    for (c in 'a'..'e') print(c)
    println()
    for (ch in "кот") print("[$ch]")
    println()
    for (i in 3..1) print("никогда")
    println("пусто")
}
```
```output
0 1 2 
5 4 3 2 1 
0 5 10 15 20 
10 6 2 
abcde
[к][о][т]
пусто
```

Разбор:

* `0 until 3` даёт 0, 1, 2: правый конец не входит. Когда границу задаёт длина (число элементов), удобнее `until`.
* `5 downTo 1` идёт назад. Запись `5..1` для этого не годится (см. ниже).
* `step` задаёт шаг. В `10 downTo 0 step 4` значения 10, 6, 2, а следующее было бы -2, что уже меньше нуля, поэтому цикл останавливается.
* Перебирать можно не только числа: `'a'..'e'` - символы от `a` до `e`, а `for (ch in "кот")` по очереди берёт каждый символ строки.
* `for (i in 3..1)` ничего не печатает: диапазон от 3 до 1 пуст, и тело не выполняется ни разу.

## Пример 3. Таблица умножения и подсчёт символов

```kotlin run
fun main() {
    val n = 7
    for (i in 1..10) {
        println("$n x $i = ${n * i}")
    }
    val word = "ананас"
    var count = 0
    for (ch in word) {
        if (ch == 'а') {
            count += 1
        }
    }
    println("Букв «а»: $count")
}
```
```output
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
Букв «а»: 3
```

Разбор:

* В шаблоне строки можно использовать и `i`, и вычисление `${n * i}`.
* Во втором цикле тело содержит `if`: циклы и условия комбинируются свободно. Каждый символ слова сравнивается с `'а'`, при совпадении счётчик увеличивается.

**Чтение `n` значений.** Если количество значений дано в первой строке ввода, цикл `for` подходит лучше всего. Эта программа читает ввод, поэтому показана без запуска:

```kotlin
fun main() {
    val n = readln().toInt()
    var sum = 0
    for (i in 1..n) {
        sum += readln().toInt()
    }
    println("Сумма: $sum")
}
```

Для ввода `3`, `10`, `20`, `5` (каждое число в своей строке) она напечатает `Сумма: 35`. Если `n` равно 0, диапазон `1..0` пуст, чтение не происходит, а сумма остаётся 0.

**Попробуйте.** В примере 2 замените `0 until 3` на `0..3` и проверьте, сколько чисел напечатается. Затем в примере 3 измените `n` и добавьте условие, чтобы печатались только чётные результаты.

## Точные правила

* `for (переменная in набор) { тело }` выполняет тело по одному разу для каждого значения набора, по порядку.
* `a..b` включает оба конца. `a until b` исключает `b`. `a downTo b` идёт по убыванию и включает оба конца. `step k` задаёт положительный шаг `k`; направление определяет сам диапазон.
* Если диапазон пуст (например `3..1` или `1..0`), тело не выполняется ни разу и ошибки нет.
* Переменная цикла существует только внутри цикла и равна `val`: присвоить ей новое значение нельзя. После цикла имя уже неизвестно.
* Перебирать можно целые числа, символы (`'a'..'z'`) и символы строки (`for (ch in text)`). Диапазон дробных чисел `1.0..3.0` существует, но перебрать его нельзя: между 1.0 и 3.0 бесконечно много значений.
* `repeat(n) { ... }` выполняет тело `n` раз и подходит, когда номер повторения не нужен.
* Классического цикла с тремя частями `for (int i = 0; i < n; i++)` в Kotlin нет.
* Для длины `n` (строки или списка) индексы идут от `0` до `n - 1`, то есть `0 until n`. Запись `0..n` даёт лишнюю итерацию и приводит к ошибке выхода за границы.

## Типичные ошибки

**1. Попытка изменить переменную цикла.**

```kotlin
fun main() {
    for (i in 1..3) {
        i = i * 2
        println(i)
    }
}
```

```text
Main.kt:3:9: error: 'val' cannot be reassigned.
        i = i * 2
        ^
```

Переменная цикла получает значение из диапазона на каждом шаге. Если нужно производное значение, заведите отдельную переменную: `val doubled = i * 2`.

**2. Круглые скобки забыты.**

```kotlin
fun main() {
    for i in 1..3 {
        println(i)
    }
}
```

```text
Main.kt:2:8: error: syntax error: Expecting '(' to open a loop range.
    for i in 1..3 {
       ^
```

Заголовок `for` всегда записывается в круглых скобках: `for (i in 1..3)`. (Сообщение показано не целиком: компилятор добавляет ещё одно, о неоднозначном `iterator()`, вызванное тем же недоразумением.)

**3. Цикл в стиле Java или C.**

```kotlin
fun main() {
    for (int i = 0; i < 3; i++) {
        println(i)
    }
}
```

Компилятор отвечает целым каскадом сообщений (больше десятка строк), потому что слово `int` и точки с запятой он читает как попытку записать что-то другое. Причина всех ошибок одна: такой конструкции в Kotlin нет, а после `for (` должно идти «переменная `in` набор значений». Правильно: `for (i in 0 until 3)`.

**4. Диапазон дробных чисел.**

```kotlin
fun main() {
    for (x in 1.0..3.0) {
        println(x)
    }
}
```

```text
Main.kt:2:15: error: for-loop range must have an 'iterator()' method.
    for (x in 1.0..3.0) {
              ^^^^^^^^
```

Дробные числа нельзя перебрать по одному. Перебирайте целый счётчик и вычисляйте дробное значение из него.

**5. Переменная цикла за пределами цикла.**

```kotlin
fun main() {
    for (i in 1..3) {
        println(i)
    }
    println(i)
}
```

```text
Main.kt:5:13: error: unresolved reference 'i'.
    println(i)
            ^
```

Имя `i` существует только внутри цикла. Если значение нужно после цикла, сохраните его в переменной, объявленной до цикла.

**6. Диапазон наоборот.** Запись `for (i in 5..1)` не вызывает ошибки и просто не выполняется ни разу (как `3..1` в примере 2). Для обратного счёта пишут `5 downTo 1`.

## Итоги

* `for (i in a..b)` повторяет тело для каждого числа диапазона. Переменная цикла объявляется в заголовке и не изменяется внутри.
* `until` исключает правый конец, `downTo` идёт назад, `step` задаёт шаг. Пустой диапазон - не ошибка: тело просто не выполняется.
* `for (ch in text)` перебирает символы строки, `repeat(n) { ... }` повторяет действие `n` раз.
* Если число повторений известно, предпочитайте `for`; если зависит от условия - `while`.

Что делать, если цикл нужно прервать досрочно или пропустить итерацию? Об этом - следующий урок: [Управление циклом: break и continue](lesson:kotlin.from-zero.loop-control).

## Для тех, кто уже программирует

* `for (x in collection)` - аналог `for ... in` в Python и `for-of` в JavaScript. Трёхчастного `for (init; cond; step)` нет: вместо него `for (i in 0 until n)`, `downTo` и `step`.
* Диапазоны - значения типа `IntRange`/`CharRange`, их можно хранить и передавать. `..` включает правую границу (в отличие от `range(a, b)` в Python), а `until` её исключает.
* Переменная цикла неизменяема (`val`); корректировать её, как `i += 2` в C, нельзя. Для шага есть `step`.
* `repeat(n) { }` - обычная функция стандартной библиотеки с лямбдой; в цикле с `break`/`continue` её лучше не использовать (в этом курсе для них берут `for` и `while`).
* Обход строки даёт `Char` (16-битная единица UTF-16), а не «символ Unicode» целиком. Для текстов с эмодзи и редкими иероглифами этого недостаточно, но для кириллицы и латиницы подходит.
* Индексный цикл по списку обычно записывают как `for (i in list.indices)` или обходят элементы напрямую: `for (x in list)` (урок 19).
