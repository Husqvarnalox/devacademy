## Много значений под одним именем

Пока мы хранили каждое значение в своей переменной: `price1`, `price2`, `price3`. Это работает для трёх чисел, но не для тридцати и тем более не тогда, когда их количество неизвестно заранее: например, список покупок или результаты контрольной. Нужна переменная, которая хранит **много значений сразу**, а программа может добавлять новые, просматривать все по очереди, считать сумму.

Такая переменная называется **коллекцией**. Самая распространённая коллекция - **список** (в Kotlin `List`): упорядоченный набор значений одного типа. У каждого элемента есть **индекс** - порядковый номер, который начинается с **нуля**: первый элемент имеет индекс 0, второй - 1.

## Одна новая идея: список хранит значения по порядку, у каждого есть индекс

Список создают, перечислив значения:

* `listOf("a", "b", "c")` - **неизменяемый** список: его состав задан один раз, добавлять и удалять элементы нельзя;
* `mutableListOf(1, 2, 3)` - **изменяемый** список: в него можно добавлять, удалять и заменять элементы.

Основные действия:

| Запись | Смысл |
|---|---|
| `list[0]` | элемент с индексом 0 |
| `list.size` | количество элементов |
| `list.add(x)` | добавить элемент в конец (только изменяемый список) |
| `x in list`, `list.contains(x)` | есть ли значение в списке |
| `list.sum()` | сумма чисел в списке |
| `list.sorted()` | новый список, отсортированный по возрастанию |

Перебирают элементы циклом `for (x in list)`: переменная `x` по очереди принимает каждое значение списка.

## Пример 1. Неизменяемый список

```kotlin run
fun main() {
    val colors = listOf("красный", "зелёный", "синий")
    println(colors)
    println(colors.size)
    println(colors[0])
    println(colors[colors.size - 1])
    println(colors.contains("синий"))
    println("жёлтый" in colors)
    for (c in colors) {
        println("Цвет: $c")
    }
}
```
```output
[красный, зелёный, синий]
3
красный
синий
true
false
Цвет: красный
Цвет: зелёный
Цвет: синий
```

Разбор:

* `println(colors)` печатает список целиком в квадратных скобках.
* Индексы идут с нуля, поэтому у списка из трёх элементов они равны 0, 1 и 2. Последний элемент имеет индекс `size - 1`.
* Проверка `"жёлтый" in colors` возвращает `Boolean`; слово `in` вам знакомо по диапазонам, здесь оно значит «содержится в».
* Цикл `for (c in colors)` проходит по всем элементам по порядку, индексы не нужны.

## Пример 2. Изменяемый список

```kotlin run
fun main() {
    val prices = mutableListOf(120, 80)
    prices.add(200)
    prices.add(50)
    prices[1] = 90
    println(prices)
    println("Товаров: ${prices.size}, сумма: ${prices.sum()}")
    println(prices.sorted())
    println(prices)
    prices.remove(200)
    println(prices)
    val empty = mutableListOf<String>()
    println(empty.isEmpty())
    for (i in 0 until prices.size) {
        println("${i + 1}) ${prices[i]}")
    }
}
```
```output
[120, 90, 200, 50]
Товаров: 4, сумма: 460
[50, 90, 120, 200]
[120, 90, 200, 50]
[120, 90, 50]
true
1) 120
2) 90
3) 50
```

Разбор:

* `add` дописывает элемент в конец. Запись `prices[1] = 90` заменяет элемент с индексом 1 (было 80).
* `sorted()` **не меняет** исходный список, а возвращает новый, отсортированный. Исходный `prices` после этого прежний.
* `remove(200)` удаляет первое найденное значение 200.
* Пустой список создают как `mutableListOf<String>()`: в угловых скобках указывают тип элементов, потому что по пустому списку компилятор не может его угадать. `isEmpty()` проверяет, что элементов нет.
* Когда нужен номер элемента, перебирают индексы: `0 until prices.size`.

## Пример 3. `val` не делает список неизменяемым

```kotlin run
fun main() {
    val items = mutableListOf("a")
    items.add("b")
    println(items)
    var changeable = listOf(3, 1, 2)
    changeable = changeable + 4
    println(changeable)
}
```
```output
[a, b]
[3, 1, 2, 4]
```

Разбор:

* Слово `val` запрещает присвоить переменной **другой** список, но не мешает менять **содержимое** изменяемого списка. `items.add("b")` допустим, потому что `items` - `mutableListOf`.
* Неизменяемый `listOf` можно только пересоздать: `changeable + 4` создаёт новый список с добавленным элементом, и результат присваивается переменной. Поэтому `changeable` объявлена через `var`.
* Итог: «изменяемость переменной» (`val`/`var`) и «изменяемость списка» (`listOf`/`mutableListOf`) - два независимых свойства.

**Чтение `n` чисел.** Если количество значений известно, их собирают в изменяемый список. Эта программа читает ввод, поэтому показана без запуска:

```kotlin
fun main() {
    val n = readln().toInt()
    val marks = mutableListOf<Int>()
    for (i in 1..n) {
        marks.add(readln().toInt())
    }
    println("Оценки: $marks")
    println("Сумма: ${marks.sum()}")
}
```

Для ввода `3`, `5`, `3`, `4` (по числу в строке) она напечатает `Оценки: [5, 3, 4]` и `Сумма: 12`.

**Попробуйте.** В примере 2 добавьте в `prices` ещё два числа и напечатайте сумму. Затем попробуйте обратиться к `prices[10]` и прочитайте сообщение об ошибке.

## Точные правила

* Все элементы списка имеют один тип: `List<Int>` хранит числа, `List<String>` - строки. Тип выводится из значений (`listOf(1, 2)`), а для пустого списка его указывают явно: `mutableListOf<Int>()`.
* Индексы начинаются с 0 и заканчиваются на `size - 1`. Индекс вне этого диапазона приводит к исключению во время работы программы.
* `listOf` создаёт список только для чтения: методов `add` и `remove` у него нет, и такая попытка не скомпилируется. `mutableListOf` создаёт изменяемый список.
* Присваивание `list[i] = x` и методы `add`, `remove` допустимы только для изменяемого списка.
* `size` - свойство без круглых скобок, `isEmpty()` и `contains(x)` - вызовы с круглыми скобками. Запись `list.size()` неверна.
* `sum()` определён для списков чисел; сумма пустого списка равна 0. `sorted()` возвращает новый список по возрастанию и не меняет исходный.
* Печать списка выводит элементы через запятую в квадратных скобках.
* `for (x in list)` перебирает элементы. Не изменяйте список (не добавляйте и не удаляйте элементы) во время такого цикла: это приводит к ошибке.
* `val list = mutableListOf(...)` запрещает присвоить `list` другой список, но не запрещает `add`.

## Типичные ошибки

**1. Индекс за границами.**

```kotlin
fun main() {
    val list = listOf(10, 20, 30)
    println(list[3])
}
```

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3
	at java.base/java.util.Arrays$ArrayList.get(Arrays.java:4227)
	at MainKt.main(Main.kt:3)
	at MainKt.main(Main.kt)
```

Допустимые индексы здесь 0, 1 и 2. Сообщение называет индекс и длину списка. (Показан стек вызовов целиком; точный текст зависит от версии JDK.) Последний элемент: `list[list.size - 1]`.

**2. Добавление в неизменяемый список.**

```kotlin
fun main() {
    val list = listOf(10, 20, 30)
    list.add(40)
}
```

```text
Main.kt:3:10: error: unresolved reference 'add' on receiver of type 'List<Int>'.
    list.add(40)
         ^^^
```

У `List` нет метода `add`. Создайте `mutableListOf(10, 20, 30)`.

**3. Элемент другого типа.**

```kotlin
fun main() {
    val list = mutableListOf(1, 2)
    list.add("три")
}
```

```text
Main.kt:3:14: error: argument type mismatch: actual type is 'String', but 'Int' was expected.
    list.add("три")
             ^^^^^
```

Список из чисел не принимает строки. Тип элементов выводится из первых значений и дальше не меняется.

**4. Скобки после `size`.**

```kotlin
fun main() {
    val list = listOf(1, 2, 3)
    println(list.size())
}
```

```text
Main.kt:3:18: error: expression 'size' of type 'Int' cannot be invoked as a function. Function 'invoke()' is not found.
    println(list.size())
                 ^^^^
```

`size` - это число, а не функция. Пишите `list.size`.

**5. Переприсваивание `val`.**

```kotlin
fun main() {
    val list = mutableListOf(1, 2)
    list = mutableListOf(3)
}
```

```text
Main.kt:3:5: error: 'val' cannot be reassigned.
    list = mutableListOf(3)
    ^^^^
```

Новый список переменной присвоить нельзя, но очистить и заполнить прежний можно. Если нужно заменить список целиком, объявите переменную через `var`.

**6. Лишняя итерация.**

```kotlin
fun main() {
    val list = listOf(10, 20, 30)
    for (i in 0..list.size) {
        println(list[i])
    }
}
```

```text
10
20
30
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3
	at java.base/java.util.Arrays$ArrayList.get(Arrays.java:4227)
	at MainKt.main(Main.kt:4)
	at MainKt.main(Main.kt)
```

Диапазон `0..list.size` включает `size`, а такого индекса нет. Нужно `0 until list.size`. Сам перебор элементов `for (x in list)` от таких ошибок защищает.

## Итоги

* Список - упорядоченная коллекция значений одного типа. Индексы начинаются с 0, последний равен `size - 1`.
* `listOf` создаёт список только для чтения, `mutableListOf` - изменяемый (`add`, `remove`, `list[i] = x`).
* `for (x in list)` перебирает элементы, `sum()` складывает числа, `sorted()` возвращает новый отсортированный список, `contains` и `in` проверяют наличие.
* `val` фиксирует переменную, но не содержимое изменяемого списка.

Список хранит значения по номерам. А если нужно находить значение по имени (цену по названию товара), понадобится другая коллекция: [Словари](lesson:kotlin.from-zero.maps).

## Для тех, кто уже программирует

* `List<T>` - интерфейс «только для чтения», `MutableList<T>` - изменяемый. Это разные типы в системе типов, а не `final`: у `List` просто нет методов `add`/`remove`. Но `val list: List<Int>` может ссылаться на объект, который кто-то другой изменит через `MutableList`: «только для чтения» не значит «неизменяемый навсегда».
* `listOf` соответствует неизменяемым спискам Java (на JVM это `Arrays$ArrayList` или `ImmutableCollections`), `mutableListOf` - `ArrayList`. Индексирование через `[]` - перегрузка оператора `get`/`set`.
* Индексы с нуля, выход за границы - исключение (`IndexOutOfBoundsException`), без обёртывания отрицательных индексов, как в Python (`list[-1]` в Kotlin - ошибка).
* `+` на списке создаёт новый список (`listOf(1) + 2`), как `concat` в JavaScript, а не изменяет исходный. Для изменения используют `+=` с `mutableListOf` или `add`.
* Распространённые операции высшего порядка (`map`, `filter`, `sortedBy`) требуют лямбд и разбираются в `kotlin-fundamentals`.
* Массивы (`arrayOf`, `IntArray`) тоже есть, но в повседневном Kotlin списки используют чаще.
