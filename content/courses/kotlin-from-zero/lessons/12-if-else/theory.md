## Зачем программе выбор

До сих пор программа выполняла строки сверху вниз, одну за другой, и всегда делала одно и то же. Но жизненные задачи почти всегда содержат слово «если»: если денег хватает - оплатить покупку, если на улице мороз - надеть шапку, если пароль неверный - показать сообщение об ошибке. Чтобы программа могла **выбирать**, что делать, в языке есть **условный оператор** `if`.

## Одна новая идея: условие решает, какой блок выполнится

Оператор `if` («если») принимает **условие** - выражение типа `Boolean`, такое как `balance >= price` из прошлого урока. Если условие истинно, выполняется один блок команд, если ложно - другой (необязательный), который начинается словом `else` («иначе»).

```kotlin
if (условие) {
    // выполняется, когда условие истинно
} else {
    // выполняется, когда условие ложно
}
```

**Блок** - это группа команд в фигурных скобках `{ }`; он выполняется целиком или не выполняется совсем. Условие всегда пишут в круглых скобках. Частей `else` может не быть: тогда при ложном условии программа просто идёт дальше.

Когда вариантов больше двух, проверки выстраивают цепочкой: `if ... else if ... else if ... else`. Программа проверяет условия сверху вниз и выполняет **первый** подходящий блок, остальные пропускает.

## Пример 1. Цепочка условий

```kotlin run
fun main() {
    val temperature = 8
    if (temperature < 0) {
        println("Мороз")
    } else if (temperature < 15) {
        println("Прохладно")
    } else if (temperature < 25) {
        println("Тепло")
    } else {
        println("Жарко")
    }
    val balance = 300
    val price = 450
    if (balance >= price) {
        println("Покупка оплачена")
    } else {
        println("Не хватает ${price - balance}")
    }
    println("Конец")
}
```
```output
Прохладно
Не хватает 150
Конец
```

Разбор:

* Условие `temperature < 0` ложно (8 не меньше нуля), поэтому программа переходит к `else if (temperature < 15)`. Оно истинно, выводится «Прохладно», а остальные ветки пропускаются. Условие `temperature < 25` тоже истинно, но до него дело не доходит.
* Во втором `if` условие ложно (300 меньше 450), выполняется блок после `else`.
* Строка `println("Конец")` стоит после `if` и выполняется в любом случае: оператор выбирает только между своими блоками.

## Пример 2. `if` как выражение

```kotlin run
fun main() {
    val a = 12
    val b = 7
    val bigger = if (a > b) a else b
    println("Больше: $bigger")
    val label = if (bigger % 2 == 0) "чётное" else "нечётное"
    println("Число $bigger - $label")
    println("Скидка: ${if (a >= 10) 5 else 0}%")
    var stock = 3
    if (stock > 0) {
        stock -= 1
        println("Выдан товар, осталось $stock")
    }
    if (stock > 5) {
        println("Много")
    }
    println("Конец")
}
```
```output
Больше: 12
Число 12 - чётное
Скидка: 5%
Выдан товар, осталось 2
Конец
```

Разбор:

* В Kotlin `if` умеет не только выполнять команды, но и **давать значение**. В `val bigger = if (a > b) a else b` переменной достаётся `a`, если условие истинно, и `b` - если ложно. Отдельной команды «присвоить в каждой ветке» писать не нужно.
* Такое `if` можно вставить прямо в шаблон строки: `${if (a >= 10) 5 else 0}`.
* Блок без `else` (`if (stock > 0) { ... }`) просто выполняется или пропускается. Второй такой блок не выполнился, потому что 2 не больше 5.

## Пример 3. Порядок условий и вложенность

```kotlin run
fun main() {
    val score = 95
    if (score >= 60) {
        println("Зачёт")
    } else if (score >= 90) {
        println("Отлично")
    }
    if (score >= 90) {
        println("Отлично")
    } else if (score >= 60) {
        println("Зачёт")
    }
    val isMember = true
    val total = 1200
    if (isMember) {
        if (total >= 1000) {
            println("Скидка 10%")
        } else {
            println("Скидка 5%")
        }
    } else {
        println("Без скидки")
    }
}
```
```output
Зачёт
Отлично
Скидка 10%
```

Разбор:

* Первая цепочка даёт неточный ответ для 95 баллов. Условие `score >= 60` истинно уже для 95, программа выбирает его блок и до проверки `score >= 90` не доходит. Условия цепочки идут от **самого узкого** к самому широкому (вторая цепочка).
* Внутри блока можно записать другой `if`. Так сделано в третьей части: сначала проверяется членство, потом сумма покупки.

**Попробуйте.** В примере 1 поменяйте `temperature` на `-4`, `15` и `30` и до запуска предскажите ответ. Затем в примере 3 поставьте `score = 75` и проследите, какие блоки выполняются.

## Точные правила

* Условие в `if` обязано иметь тип `Boolean` и записывается в круглых скобках. Числа и строки в роли условия не подходят: `if (n)` - ошибка.
* Блок `{ ... }` группирует команды. Если в ветке ровно одна команда, фигурные скобки можно опустить, но тогда к ветке относится **только** следующая команда. Новичкам надёжнее всегда писать фигурные скобки.
* Цепочка `if / else if / else` вычисляет условия сверху вниз до первого истинного и выполняет только его блок. Ветка `else` стоит в конце и срабатывает, когда подошли не условия выше.
* `else if` - это `else`, внутри которого стоит новый `if`. Отдельного слова `elif`, как в Python, нет.
* `if` является **выражением**: у него есть значение, которое можно сохранить в переменную или передать в `println`. Значением становится последнее выражение выбранного блока. Если `if` используется как выражение, ветка `else` обязательна, потому что значение должно существовать при любом условии.
* Типы значений в ветках должны сочетаться: `if (x > 0) "да" else 0` даёт значение смешанного типа, которое нельзя сохранить в `val name: String`.
* Если `if` стоит как обычная команда, значение ветки отбрасывается, и `else` можно не писать.
* Вложенные `if` допустимы, но глубокую вложенность читать трудно. Чаще её можно заменить цепочкой `else if` или условием с `&&`.

## Типичные ошибки

**1. Условие без скобок.**

```kotlin
fun main() {
    val x = 7
    if x > 5 {
        println("больше пяти")
    }
}
```

```text
Main.kt:3:7: error: syntax error: Expecting a condition in parentheses '(...)'.
    if x > 5 {
      ^
```

Компилятор называет суть в первой же строке: после `if` нужны скобки. Дальше он выдаёт ещё три сообщения о типах (они возникают из-за непонятого кода, их можно не читать). Правильно: `if (x > 5) { ... }`.

**2. Одно условие вместо сравнения.**

```kotlin
fun main() {
    val n = 1
    if (n) {
        println("есть")
    }
}
```

```text
Main.kt:3:9: error: condition type mismatch: inferred type is 'Int' but 'Boolean' was expected.
    if (n) {
        ^
```

В Python или JavaScript число может служить условием, в Kotlin - нет. Запишите сравнение: `if (n != 0)`.

**3. `if` как выражение без `else`.**

```kotlin
fun main() {
    val a = 3
    val b = 8
    val bigger = if (a > b) a
    println(bigger)
}
```

```text
Main.kt:4:18: error: 'if' must have both main and 'else' branches when used as an expression.
    val bigger = if (a > b) a
                 ^^
```

Если у `if` нет ветки `else`, значение при ложном условии не определено. Добавьте `else b`.

**4. Слово `elif` из Python.**

```kotlin
fun main() {
    val n = 3
    if (n > 5) {
        println("много")
    } elif (n > 1) {
        println("немного")
    }
}
```

```text
Main.kt:5:7: error: unresolved reference 'elif' on receiver of type 'Unit'.
    } elif (n > 1) {
      ^^^^
```

Kotlin не знает слова `elif`. Пишите `else if`. (Сообщение показано не целиком: компилятор находит ещё две связанные ошибки.)

**5. Забытые фигурные скобки.**

```kotlin
fun main() {
    val x = 3
    if (x > 5)
        println("большое")
        println("число больше пяти")
}
```

```text
число больше пяти
```

Ошибки компиляции нет, но программа лжёт. К `if` относится только первая команда, а вторая выполняется всегда, хотя отступ создаёт впечатление, что она тоже зависит от условия. Отступы Kotlin не учитывает. Заключите ветку в `{ }`.

## Итоги

* `if (условие) { ... } else { ... }` выбирает, какой блок выполнить. Условие обязано быть `Boolean`.
* Цепочка `else if` проверяет условия сверху вниз и выполняет первый подходящий блок. Порядок условий важен: от узкого к широкому.
* `if` в Kotlin - выражение: `val m = if (a > b) a else b`. Тогда `else` обязателен.
* Блок в фигурных скобках - единственный надёжный способ сгруппировать команды ветки.

Если вариантов много и все они проверяют одно и то же значение (номер дня, команду, код), цепочку `else if` удобнее заменить другим оператором. О нём - следующий урок: [Выбор из многих вариантов: when](lesson:kotlin.from-zero.when).

## Для тех, кто уже программирует

* Синтаксис `if (...) { } else if (...) { } else { }` совпадает с Java и C#, но `if` в Kotlin - выражение, поэтому тернарного оператора `a ? b : c` нет: пишут `if (a) b else c`. Символ `?:` в Kotlin - оператор для `null` (урок 18).
* Условие обязано быть `Boolean`. «Истинных» значений вроде `0`, `""` или пустого списка, как в Python и JavaScript, нет.
* Скобки в `if (...)` обязательны, точка с запятой не нужна. Отдельного `elif`/`elsif` нет: используется `else if`.
* Блок как выражение возвращает последнее выражение; `return` для этого не нужен. Если ветки разных типов, тип результата - общий родительский тип (например `Any`), и чаще всего это признак ошибки.
* Присваивание в Kotlin не выражение, поэтому `if (x = 5)` невозможно и опечатка вида «`=` вместо `==`» превращается в ошибку компиляции, а не в скрытый баг.
* Отступы значения не имеют, как в Java и C: «висячая» команда без скобок вводит в заблуждение так же, как в этих языках.
