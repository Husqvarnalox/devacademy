## Зачем управлять выводом

Вывод - единственный способ программы «сказать» результат. Чек, сообщение об ошибке, ответ на задачу - всё это текст, который программа печатает. От точности вывода зависит, поймёт ли человек или другая программа результат: лишний пробел или пропавший перенос строки превращает правильный ответ в непонятный.

В этом уроке вы научитесь печатать текст так, как нужно: в одной строке или нескольких, с кавычками внутри и из нескольких частей.

## Одна новая идея: печатают команды print и println, а особые символы записывают с обратной косой чертой

Вы уже знаете `println`: она печатает текст и **переводит строку**, то есть следующий вывод начнётся с новой строки. Её близнец `print` печатает текст и **не переводит строку**: следующий вывод продолжит ту же строку.

Некоторые символы нельзя просто вписать в текст: например, перевод строки или двойную кавычку (она закрыла бы строку). Для них есть **управляющие последовательности** - короткие записи, начинающиеся с обратной косой черты `\`:

| Запись | Что вставляет в текст |
|---|---|
| `\n` | перевод строки |
| `\"` | двойную кавычку |
| `\\` | один символ обратной косой черты |
| `\t` | табуляцию (широкий отступ) |
| `\$` | знак доллара (в Kotlin он имеет особый смысл, урок 4) |

Кроме того, части текста можно **склеить** знаком `+`: `"Привет, " + "мир"` даёт `Привет, мир`. А чтобы оставить в программе пояснение для читателя, используют **комментарий** - текст, который компилятор пропускает: `// до конца строки` или `/* несколько строк */`.

<!-- section: examples -->
## Пример 1. print и println

```kotlin run
fun main() {
    print("Итого: ")
    print(450)
    println(" руб.")
    println("Спасибо!")
}
```
```output
Итого: 450 руб.
Спасибо!
```

Разбор по строкам:

* `print("Итого: ")` печатает текст вместе с пробелом в конце и остаётся в той же строке.
* `print(450)` печатает число. Числа пишут без кавычек, подробно о них - со следующих уроков.
* `println(" руб.")` дописывает хвост и переводит строку.
* `println("Спасибо!")` печатает следующую строку целиком.

## Пример 2. Управляющие последовательности

```kotlin run
fun main() {
    println("Первая строка\nВторая строка")
    println("Он сказал: \"Привет\"")
    println("Путь: C:\\temp")
}
```
```output
Первая строка
Вторая строка
Он сказал: "Привет"
Путь: C:\temp
```

Разбор: `\n` внутри одной команды дал две строки вывода; `\"` напечатал кавычку и не закрыл текст; `\\` дал один обратный слэш. Сами служебные символы `\` в выводе не видны: это запись для программиста, а не часть вывода.

## Пример 3. Склейка и комментарии

```kotlin run
fun main() {
    // Склеиваем чек из нескольких частей
    println("Товар: " + "Хлеб" + ", цена " + "45" + " руб.")
    /* Числа после текста
       тоже приклеиваются слева направо */
    println("Итого: " + 45 + 45)
}
```
```output
Товар: Хлеб, цена 45 руб.
Итого: 4545
```

Разбор: комментарии не выводятся и не влияют на работу. Склейка выполняется слева направо: к тексту `"Итого: "` приклеилось `45`, получился новый текст, к нему приклеилось второе `45`. Складывать числа этим знаком в такой записи не получается, пока слева текст: арифметику разберём отдельным уроком.

**Попробуйте.** Замените в первом примере `print(450)` на `println(450)` и предскажите, как изменится вывод. Затем добавьте в пример 2 команду, которая печатает слово в кавычках и в конце ещё одну пустую строку (подсказка: `println()` без текста).

## Точные правила

* `println(x)` печатает значение и перевод строки; `println()` без аргументов печатает только перевод строки (пустую строку). `print(x)` печатает значение без перевода строки.
* Внутри строки в двойных кавычках обратная косая черта `\` начинает управляющую последовательность. Допустимы `\n`, `\t`, `\"`, `\'`, `\\`, `\$`. Неизвестная последовательность, например `\q`, - ошибка компиляции.
* Переносом строки управляет именно `\n`, а не нажатие Enter внутри кавычек: строковый литерал в кавычках должен закончиться на той же строке программы.
* Знак `$` внутри строки в Kotlin начинает **шаблон** (о нём - урок 4). Пока шаблонов нет, символ `$` перед буквой лучше записывать как `\$`.
* Операция `+` между двумя строками склеивает их. Если слева строка, а справа число, число превращается в текст и приклеивается. Если слева число, а справа строка, склеить так нельзя: будет ошибка компиляции.
* Склеивание выполняется слева направо. Скобки меняют порядок, но арифметику с числами в этом уроке мы не используем.
* `// ...` - комментарий до конца строки; `/* ... */` - комментарий, который может занимать несколько строк. Комментарии нужны читателю, и их отсутствие или наличие не меняет программу.
* Комментарии удобно использовать, чтобы временно «выключить» команду: добавьте `//` перед ней.

## Типичные ошибки

**1. Путаница print и println.** Вместо двух строк в одной получается склейка:

```kotlin
fun main() {
    print("Первая")
    print("Вторая")
}
```

Эта программа напечатает `ПерваяВторая` в одной строке, и ошибки не будет. Если нужен перенос, пользуйтесь `println` или добавьте `\n`.

**2. Косая черта не в ту сторону.**

```kotlin
println("Строка/nвторая")
```

Ошибки нет, но будет напечатано `Строка/nвторая`: перенос задаёт именно обратная косая черта `\n`.

**3. Кавычка внутри текста без `\`.**

```kotlin
fun main() {
    println("Он сказал: "Привет"")
}
```

```text
Main.kt:2:26: error: unresolved reference 'Привет' on receiver of type 'String'.
    println("Он сказал: "Привет"")
                         ^^^^^^
Main.kt:2:26: error: literals must be surrounded by whitespace.
    println("Он сказал: "Привет"")
                         ^^^^^^
```

Строка закончилась на второй кавычке, и `Привет` оказалось «словом без кавычек» - именем, которого нет. Напишите `\"Привет\"`.

**4. Число слева, текст справа.**

```kotlin
fun main() {
    println(5 + "штук")
}
```

```text
Main.kt:2:15: error: none of the following candidates is applicable:

fun plus(other: Int): Int:
  Argument type mismatch: actual type is 'String', but 'Int' was expected.
...
```

(Сообщение длиннее: ниже перечислены такие же варианты для остальных числовых типов, здесь оно сокращено.) Компилятор пытается сложить число `5` со строкой как с числом и не может. Начните выражение со строки: `"" + 5 + " штук"` или `"5 штук"`. Позже, с переменными, это решается удобнее (шаблоны строк, урок 4).

**5. Забытая закрывающая звёздочка у `/*`.** Комментарий, начатый `/*`, должен закончиться `*/`: иначе компилятор считает комментарием весь остаток файла и сообщает `Unclosed comment`.

<!-- section: summary -->
## Итоги

* `println` печатает и переводит строку, `print` - не переводит.
* Особые символы пишутся с обратной косой чертой: `\n` (перенос), `\"` (кавычка), `\\` (обратный слэш).
* Знак `+` склеивает текст слева направо; число справа от текста приклеивается, число слева от текста - ошибка.
* `//` и `/* */` - комментарии: они нужны читателю и не влияют на работу.

## Для тех, кто уже программирует

* `print`/`println` - как в Java (`System.out.print`/`println`), без отдельного `printf`: форматирование делается через `String.format` или `"...".format(...)` (урок 10).
* Строки в двойных кавычках поддерживают те же escape-последовательности, что и в Java, плюс `\$`. Одинарные кавычки означают `Char`, а не строку, как в Python или JavaScript.
* Сырая строка в тройных кавычках `"""..."""` не обрабатывает `\`, может занимать несколько строк и поддерживает шаблоны `$x`; в этом курсе она не используется.
* `+` для строк работает, но идиоматичнее шаблон `"Итого: $total"` (урок 4). `5 + "a"` не компилируется: слева `Int`, у которого нет `plus(String)`.
* Комментарии - `//` и `/* */`; вложенные блочные комментарии допустимы (в отличие от Java). Документационные комментарии - `/** ... */` (KDoc).
