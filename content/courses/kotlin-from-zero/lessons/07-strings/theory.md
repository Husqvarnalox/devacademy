## Зачем работать со строкой по частям

Текст в программе - это не только то, что печатают. Нужно узнать, сколько символов в имени, взять первую букву для инициалов, привести слово к одному регистру, чтобы сравнивать без учёта заглавных. Для этого у строки есть свойства и действия.

**Строка** (`String`) - последовательность символов. У каждого символа есть номер, который называется **индексом**.

## Одна новая идея: символы строки пронумерованы с нуля

Для строки `"Привет"` индексы такие:

| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| Символ | П | р | и | в | е | т |

Первый символ имеет индекс **0**, а последний - индекс на единицу меньше длины. Это самая частая причина ошибок «на единицу» у новичков, поэтому запомните: **длина шесть - индексы от 0 до 5**.

Основные средства:

* `text.length` - длина строки (число символов). Скобок нет: это свойство, а не действие.
* `text[i]` - символ с индексом `i`. Результат имеет тип `Char`.
* `text.uppercase()` - новая строка, в которой все буквы заглавные. `text.lowercase()` - все строчные. Здесь скобки есть: это действие.

Важно: строка **не меняется на месте**. `uppercase()` не изменяет `text`, а возвращает новую строку; если результат нужен потом, его сохраняют в переменную или сразу печатают.

<!-- section: examples -->
## Пример 1. Длина, символ, регистр

```kotlin run
fun main() {
    val word = "Kotlin"
    println(word.length)
    println(word[0])
    println(word[word.length - 1])
    println(word.uppercase())
    println(word.lowercase())
}
```
```output
6
K
n
KOTLIN
kotlin
```

Разбор по строкам:

* `word.length` - точка соединяет значение и то, что у него спрашивают. Результат `6` - число (`Int`).
* `word[0]` - первый символ, `K`. Номер пишут в квадратных скобках.
* `word[word.length - 1]` - последний символ. Длина 6, значит последний индекс 5, а выражение `6 - 1` как раз его и даёт.
* `word.uppercase()` и `word.lowercase()` возвращают новые строки. Исходная `word` остаётся прежней.

## Пример 2. Пробелы, знаки и пустая строка

```kotlin run
fun main() {
    val greeting = "Привет, мир!"
    println(greeting.length)
    println(greeting[0])
    println(greeting[6])
    println(greeting[greeting.length - 1])
    println("".length)
}
```
```output
12
П
,
!
0
```

Разбор: пробелы, запятая и восклицательный знак - такие же символы, как буквы, и тоже считаются в длине. В слове «Привет» шесть букв (индексы 0-5), поэтому `greeting[6]` - запятая. Пустая строка `""` не содержит символов, её длина 0.

## Пример 3. Строка остаётся прежней

```kotlin run
fun main() {
    val name = "Анна"
    val loud = name.uppercase()
    println(name)
    println(loud)
    println(name.lowercase())
}
```
```output
Анна
АННА
анна
```

Разбор: `name.uppercase()` создало новую строку и сохранило её в `loud`; `name` не изменилась. Третья команда создаёт ещё одну строку, но она не сохраняется, а сразу печатается.

## Точные правила

* `s.length` - число символов в строке `s` типа `Int`. Это свойство: скобки не нужны.
* `s[i]` возвращает `Char` с индексом `i`. Допустимые индексы: от `0` до `s.length - 1`. Индекс вне диапазона вызывает во время работы `StringIndexOutOfBoundsException`.
* Отрицательный индекс не означает «с конца» (как в Python): `s[-1]` вызовет ту же ошибку.
* Последний символ непустой строки - `s[s.length - 1]`. У пустой строки символов нет, и `""[0]` - ошибка.
* `s.uppercase()` и `s.lowercase()` возвращают новую строку с изменённым регистром. Они учитывают русские и другие буквы, а не только латиницу.
* Строки в Kotlin **неизменяемы**: символ нельзя заменить присваиванием `s[0] = 'К'`. Чтобы получить другой текст, создают новую строку.
* Свойство (`length`) пишется без скобок, действие (`uppercase()`) - со скобками. Если перепутать, компилятор сообщит об ошибке.
* Результат `text[i]` можно вставить в шаблон: `"${text[0]}"` - скобки нужны, потому что внутри индекс.

## Типичные ошибки

**1. Скобки у `length`.**

```kotlin
fun main() {
    val text = "abc"
    println(text.length())
}
```

```text
Main.kt:3:18: error: expression 'length' of type 'Int' cannot be invoked as a function. Function 'invoke()' is not found.
    println(text.length())
                 ^^^^^^
```

`length` - не действие, а число, готовое для чтения. Уберите скобки: `text.length`.

**2. Индекс за границей строки.**

```kotlin
fun main() {
    val word = "кот"
    println(word[5])
}
```

Программа собирается, но при запуске печатает:

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Index 5 out of bounds for length 3
	at ...
	at MainKt.main(Main.kt:3)
```

(Строки со стеком вызовов внутри библиотеки заменены многоточием.) Сообщение говорит: запрошен индекс 5, а в строке длиной 3 допустимы только 0, 1, 2. Номер строки программы, где это случилось, - `Main.kt:3`. Чаще всего причина - счёт «с единицы» вместо «с нуля».

**3. Попытка изменить символ.**

```kotlin
fun main() {
    val word = "кот"
    word[0] = 'К'
    println(word)
}
```

```text
Main.kt:3:9: error: no 'set' operator method providing array access.
    word[0] = 'К'
        ^^^
```

Строка не допускает замены символа. Новый текст собирают из частей, например `"К" + "от"`; другие способы - в уроке о методах строки.

**4. Потерять результат `uppercase()`.**

```kotlin
fun main() {
    val name = "Анна"
    name.uppercase()
    println(name)
}
```

Эта программа напечатает `Анна`: результат `uppercase()` вычислен, но никуда не записан. Ошибки нет, поэтому её сложно заметить. Пишите `val big = name.uppercase()` или `println(name.uppercase())`.

**5. Последний символ как `s[s.length]`.** Длина `3` - это число символов, а последний индекс `2`. Пишите `s[s.length - 1]`.

## Итоги

* Строка - последовательность символов с индексами от `0` до `length - 1`.
* `length` - свойство без скобок; `s[i]` - символ типа `Char`; `uppercase()` и `lowercase()` возвращают новые строки.
* Индекс вне диапазона даёт `StringIndexOutOfBoundsException` при запуске.
* Строки неизменяемы: изменить символ нельзя, нужно собрать новую строку.

## Для тех, кто уже программирует

* `s.length` - свойство (как в JavaScript), а не метод `s.length()` (Java) или `len(s)` (Python/Go).
* `s[i]` возвращает `Char` и проверяет границы; отрицательные индексы не считают с конца. Для последнего символа есть `s.last()`, для первого - `s.first()`.
* `String` неизменяема, как в Java, Python и JavaScript. `uppercase()`/`lowercase()` пришли на смену устаревшим `toUpperCase()`/`toLowerCase()` и по умолчанию не зависят от локали.
* Внутри строка - последовательность 16-битных UTF-16 единиц, как в Java: символы вне базовой плоскости (например, многие эмодзи) занимают две позиции индекса. Для кириллицы и латиницы это не важно.
* `s == t` сравнивает содержимое, а не ссылки (в отличие от Java); подробности - в уроке о сравнении.
* `substring`, `split` и другие методы появятся в уроке о методах строки.
