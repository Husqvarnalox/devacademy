## Разбор текста на части

Ввод программы почти всегда приходит строкой. Пользователь вводит «Анна;25;Минск» или «3, 5, 10», а программе нужны имя, возраст и город по отдельности или три числа. Чтобы такие строки разбирать, у `String` есть **методы** - действия, вызываемые через точку: `text.trim()`, `text.split(",")`. С `length`, `uppercase()` и индексом вы уже знакомы, теперь добавим те, что нужны для работы с вводом.

## Одна новая идея: строки не меняются, а методы возвращают новую строку или список

Строка в Kotlin **неизменяема**: ни один метод не правит исходный текст на месте. Каждый возвращает **новое значение**, которое нужно сохранить или напечатать. Основные методы:

| Метод | Результат |
|---|---|
| `s.trim()` | строка без пробелов в начале и в конце |
| `s.split(",")` | список частей, разрезанных по разделителю |
| `list.joinToString(", ")` | склейка элементов списка в одну строку через разделитель |
| `s.substring(a, b)` | часть строки от индекса `a` до `b` (без `b`) |
| `s.substring(a)` | часть строки от индекса `a` до конца |
| `s.indexOf("x")` | индекс первого вхождения или `-1`, если такого нет |
| `s.contains("x")` | есть ли подстрока |
| `s.startsWith("x")`, `s.endsWith("x")` | начинается или заканчивается ли строка на `x` |
| `s.replace("a", "b")` | новая строка с заменой всех вхождений |

## Пример 1. `trim` и `split`

```kotlin run
fun main() {
    val line = "  яблоко, груша ,слива  "
    println("[" + line.trim() + "]")
    val parts = line.split(",")
    println(parts)
    println(parts.size)
    for (p in parts) {
        println("[" + p.trim() + "]")
    }
}
```
```output
[яблоко, груша ,слива]
[  яблоко,  груша , слива  ]
3
[яблоко]
[груша]
[слива]
```

Разбор:

* Квадратные скобки в `println` нужны, чтобы увидеть границы строки: пробелы по краям иначе незаметны.
* `trim()` убрал пробелы только по краям. Пробелы внутри строки остались.
* `split(",")` разрезал строку по запятым и вернул список из трёх частей. Пробелы возле запятых остались в частях, поэтому каждую часть дополнительно очищают через `trim()`.

## Пример 2. Поиск и замена

```kotlin run
fun main() {
    val s = "Kotlin - язык программирования"
    println(s.substring(0, 6))
    println(s.substring(9))
    println(s.indexOf("язык"))
    println(s.indexOf("Python"))
    println(s.contains("язык"))
    println(s.startsWith("Kot"))
    println(s.endsWith("ия"))
    println(s.replace("язык", "инструмент"))
    println(s)
    println(s.length)
}
```
```output
Kotlin
язык программирования
9
-1
true
true
true
Kotlin - инструмент программирования
Kotlin - язык программирования
30
```

Разбор:

* `substring(0, 6)` берёт символы с индексами 0-5; символ с индексом 6 уже не входит. Правая граница не включается, как в `until`.
* `substring(9)` берёт всё от индекса 9 до конца.
* `indexOf` возвращает индекс начала найденной подстроки, а если её нет, число `-1`. Это не ошибка, а условный знак «не найдено».
* `replace` вернул новую строку, а `s` после этого осталась прежней (строки неизменяемы).

## Пример 3. Поля записи и склейка

```kotlin run
fun main() {
    val record = "Анна;25;Минск"
    val fields = record.split(";")
    val name = fields[0]
    val age = fields[1].toInt()
    val city = fields[2]
    println("$name ($age), $city")
    val words = "один два три".split(" ")
    println(words.joinToString(", "))
    println(words.joinToString(" | "))
    println("a,b,,c".split(","))
    println("a  b".split(" "))
    val numbers = listOf(3, 1, 2)
    println(numbers.joinToString(" + ") + " = " + numbers.sum())
}
```
```output
Анна (25), Минск
один, два, три
один | два | три
[a, b, , c]
[a, , b]
3 + 1 + 2 = 6
```

Разбор:

* Запись из трёх полей через `;` режется в список из трёх строк; к элементам обращаются по индексу, а число из строки получают через `toInt()`.
* `joinToString` делает обратное: склеивает элементы списка в одну строку с нужным разделителем. Он работает и со списком чисел.
* `"a,b,,c".split(",")` даёт четыре части, одна из них пустая. Два пробела подряд тоже дают пустую часть между ними. Это важно при разборе ввода: пустые части нужно учитывать.

**Чтение чисел из одной строки.** Типичная задача: прочитать строку `3, 5, 10` и сложить числа. Программа читает ввод, поэтому показана без запуска:

```kotlin
fun main() {
    val parts = readln().split(",")
    var sum = 0
    for (p in parts) {
        sum += p.trim().toInt()
    }
    println(sum)
}
```

Для ввода `3, 5, 10` она напечатает `18`.

**Попробуйте.** В примере 2 найдите индекс слова `программирования` и выведите всё, что идёт после него и до конца, а затем весь текст до символа `-` без пробелов по краям.

## Точные правила

* Методы `String` не изменяют исходную строку, а возвращают новое значение: `s.trim()` само по себе ничего не меняет, результат нужно использовать.
* `trim()` убирает пробельные символы (пробел, табуляция, перенос строки) только в начале и в конце.
* `split(разделитель)` возвращает `List<String>`. Подряд идущие разделители дают пустые части, пробелы вокруг частей остаются.
* `substring(a, b)` берёт символы от индекса `a` включительно до `b` исключительно. Выход за границы строки (`b` больше длины, `a` больше `b` или отрицательное число) приводит к исключению.
* `indexOf` возвращает индекс первого вхождения или `-1`. Передавать результат `-1` в `substring` нельзя без проверки.
* `contains`, `startsWith`, `endsWith` возвращают `Boolean` и различают регистр: `"Kotlin".contains("kot")` равно `false`.
* `replace(a, b)` заменяет все вхождения. Регистр тоже различается.
* `joinToString(разделитель)` склеивает элементы списка; без аргумента разделитель - запятая с пробелом.
* Методы вызываются через точку и всегда с круглыми скобками, даже без аргументов: `s.trim()`, а не `s.trim`. Свойство без скобок - только `length`.
* Строку можно обходить циклом `for (ch in s)`, но изменять символы через `s[i] = ...` нельзя.

## Типичные ошибки

**1. Выход за границы при `substring`.**

```kotlin
fun main() {
    println("abc".substring(2, 10))
}
```

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Range [2, 10) out of bounds for length 3
	at java.base/jdk.internal.util.Preconditions$1.apply(Preconditions.java:55)
	...
```

В строке три символа, а граница 10 слишком велика. Стек сокращён: показаны первые две строки, остальные строки внутреннего кода JDK опущены. В сообщении указан диапазон и длина строки. Допустимые границы: от 0 до `s.length`.

**2. Пропущены скобки.**

```kotlin
fun main() {
    val s = " кот "
    println(s.trim)
}
```

```text
Main.kt:3:15: error: function invocation 'trim()' expected.
    println(s.trim)
              ^^^^
```

`trim` - это метод, его нужно вызывать: `s.trim()`.

**3. Попытка заменить символ в строке.**

```kotlin
fun main() {
    val s = "кот"
    s[0] = 'К'
}
```

```text
Main.kt:3:6: error: no 'set' operator method providing array access.
    s[0] = 'К'
     ^^^
```

Строка неизменяема. Чтобы получить «Кот», соберите новую строку: `"К" + s.substring(1)`.

**4. Результат `indexOf` без проверки.**

```kotlin
fun main() {
    val s = "abc"
    println(s.substring(s.indexOf("x")))
}
```

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Range [-1, 3) out of bounds for length 3
	at java.base/jdk.internal.util.Preconditions$1.apply(Preconditions.java:55)
	...
```

Подстроки «x» нет, `indexOf` вернул `-1`, и `substring` получил недопустимую границу. Стек сокращён так же. Сначала проверяйте `if (index != -1)` или `s.contains("x")`.

**5. Меньше полей, чем ожидалось.**

```kotlin
fun main() {
    val fields = "Анна;25".split(";")
    println(fields[2])
}
```

```text
Exception in thread "main" java.lang.IndexOutOfBoundsException: Index 2 out of bounds for length 2
	at java.base/jdk.internal.util.Preconditions.outOfBounds(Preconditions.java:100)
	...
```

В строке только два поля, а код обращается к третьему. Стек сокращён. Перед разбором ввода сравнивайте `fields.size` с ожидаемым числом полей: так же, как вы проверяли число в прошлых уроках.

## Итоги

* Строки неизменяемы: методы возвращают новые значения, которые нужно сохранить или напечатать.
* `trim()` убирает пробелы по краям, `split(разделитель)` режет строку на список, `joinToString` склеивает список в строку.
* `substring(a, b)` берёт часть строки (правая граница не включается), `indexOf` возвращает индекс или `-1`.
* `contains`, `startsWith`, `endsWith`, `replace` ищут и заменяют с учётом регистра.
* После `split` проверяйте число частей, а перед `toInt()` очищайте части через `trim()`.

Мы научились разбирать данные, а ввод бывает неправильным. Следующий урок о том, как программа должна вести себя, когда что-то идёт не так: [Исключения](lesson:kotlin.from-zero.exceptions).

## Для тех, кто уже программирует

* `String` неизменяема, как в Java, JavaScript, Python и Go. Методы возвращают новые строки.
* `split` возвращает `List<String>`, а не массив. Как и в Java/JS, пустые части между подряд идущими разделителями сохраняются. В Python `split()` без аргумента склеивает пробелы подряд, а в Kotlin такого режима нет: используют `split(" ")` с последующей фильтрацией либо регулярные выражения (`Regex`).
* `substring(a, b)` - полуоткрытый диапазон, как в Java, в отличие от срезов Python с отрицательными индексами. Kotlin не допускает `s[-1]`.
* `indexOf` возвращает `-1`, а не бросает исключение, как в Java и JavaScript. Для строк рядом есть `indexOfFirst`, `lastIndexOf`, `removePrefix`, `removeSuffix`, `padStart`, `padEnd` и др.
* `joinToString` - аналог `String.join` из Java и `join` из Python; он принимает не только строки, но и любые элементы.
* Регистр различается в `contains` по умолчанию. Для игнорирования регистра есть параметр `ignoreCase = true`.
* Регулярные выражения и построитель строк (`StringBuilder`) в этом курсе не разбираются; они есть в `kotlin-fundamentals`.
