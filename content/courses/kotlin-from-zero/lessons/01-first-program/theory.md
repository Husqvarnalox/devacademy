## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Этот текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется Kotlin. На нём пишут серверы, приложения для Android и инструменты разработчиков. Он компактный: для первой программы хватает нескольких строк.

Компьютер не умеет выполнять текст на Kotlin напрямую. Поэтому нужен ещё один инструмент - **компилятор**: он читает исходный код, проверяет его и переводит в форму, которую можно выполнить. Если в тексте есть ошибка, компилятор останавливается и сообщает, что и где не так. Тогда программа даже не запускается.

В приложении вам не нужно вызывать эти инструменты вручную. Вы пишете текст в редакторе и нажимаете «Запустить»: приложение само переводит текст компилятором и выполняет результат. Первый запуск занимает несколько секунд: перевод занимает больше времени, чем сама работа маленькой программы.

## Одна новая идея: программа - это функция main с командами внутри

Самая маленькая программа на Kotlin выглядит так:

```kotlin
fun main() {
    // здесь пишут команды
}
```

Разберём её по частям:

* `fun` - сокращение от английского *function*, «функция». Функция - это именованный набор команд. Подробно о функциях рассказывает урок 17 этого курса, а пока достаточно знать: слово `fun` объявляет такой набор.
* `main` - имя функции, по-английски «главная». Выполнение программы всегда начинается с неё.
* `()` - пустые круглые скобки: этой функции пока не нужно ничего передавать.
* `{ ... }` - фигурные скобки ограничивают команды функции. Они выполняются сверху вниз, по одной в строке.

Первая команда, которую нужно знать, - `println("...")`: она печатает текст и переводит курсор на новую строку.

<!-- section: examples -->
## Пример 1. Печать одной строки

```kotlin run
fun main() {
    println("Касса открыта")
}
```
```output
Касса открыта
```

Разбор по строкам:

* `fun main() {` - начало программы: «здесь описана функция `main`». Открывающая фигурная скобка начинает блок команд.
* `println("Касса открыта")` - сама команда. `println` (от print line, «напечатать строку») - действие. В круглых скобках - то, что печатать: текст в двойных кавычках. Кавычки только показывают границы текста, на экран они не попадают.
* `}` - конец блока. Когда команды в `main` закончились, программа завершается.

## Пример 2. Несколько команд подряд

```kotlin run
fun main() {
    println("Первая строка")
    println("Вторая строка")
    println("Третья строка")
}
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет. Каждая команда занимает свою строку. Точка с запятой в конце не нужна: в Kotlin конец строки заканчивает команду.

**Попробуйте.** Поменяйте местами две строки с `println` и предскажите вывод до запуска. Затем удалите закрывающую кавычку в одной из строк и прочитайте, что ответит компилятор (разбор таких сообщений - в разделе об ошибках и в следующем уроке).

## Точные правила

* Файл с программой называется `Main.kt`. Расширение `.kt` - от слова Kotlin.
* Выполнение начинается с функции `main`. Если её нет или имя записано иначе, программе нечего запускать.
* Команды внутри `main` выполняются по порядку, сверху вниз. Каждая команда записывается с новой строки.
* Фигурные скобки идут парами: у каждой открывающей `{` должна быть закрывающая `}`. То же относится к круглым скобкам `( )`.
* **Строковый литерал** - текст, записанный прямо в программе, в двойных кавычках: `"Касса открыта"`. Он печатается как есть, без кавычек. Внутри допустимы русские буквы, пробелы, цифры и знаки.
* Регистр важен: `println` пишется строчными буквами, `Println` и `PRINTLN` для Kotlin - другие, неизвестные имена.
* Отступы (четыре пробела внутри блока) компилятору не нужны, но читателю очень помогают. Редактор расставляет их автоматически.
* Пустые строки между командами допустимы и улучшают чтение.

## Типичные ошибки

Сообщение компилятора начинается с имени файла, номера строки и номера столбца: `Main.kt:2:5: error: ...`. Под сообщением компилятор печатает строку кода и значки `^`, которые показывают место, где он увидел проблему. Во всех примерах ниже программа записана целиком (первая строка - `fun main() {`), поэтому ошибка во второй строке.

**1. Не закрыта круглая скобка.**

```kotlin
fun main() {
    println("Привет"
}
```

```text
Main.kt:2:21: error: syntax error: Expecting ')'.
    println("Привет"
                    ^
```

Скобка, открытая после `println`, не закрыта. Компилятор показывает конец строки: именно там он ждал `)`. Добавьте скобку.

**2. Имя с неправильным регистром.**

```kotlin
fun main() {
    Println("Привет")
}
```

```text
Main.kt:2:5: error: unresolved reference 'Println'.
    Println("Привет")
    ^^^^^^^
```

`unresolved reference` означает «не нахожу такое имя». Kotlin различает заглавные и строчные буквы, поэтому `Println` ему неизвестно. Узнать это самому можно по значкам `^^^^^^^`: они подчёркивают именно это слово.

**3. Опечатка в имени команды.**

```kotlin
fun main() {
    printn("Привет")
}
```

```text
Main.kt:2:5: error: unresolved reference 'printn'.
    printn("Привет")
    ^^^^^^
```

То же сообщение: имя `printn` не существует. Сравните его с правильным `println`.

**4. Не закрыты кавычки.**

```kotlin
fun main() {
    println("Привет)
}
```

```text
Main.kt:2:21: error: syntax error: Expecting '"'.
    println("Привет)
                    ^
Main.kt:2:21: error: syntax error: Expecting ')'.
    println("Привет)
                    ^
```

Строка началась кавычкой, но не закончилась до конца строки программы. Из-за этого скобка `)` попала внутрь текста, и компилятор сообщил о двух проблемах сразу. Вторая сообщена как следствие первой: исправьте кавычку, и обе пропадут.

**5. Не закрыта фигурная скобка.**

```kotlin
fun main() {
    println("Привет")
```

```text
Main.kt:2:22: error: syntax error: Expecting '}'.
    println("Привет")
                     ^
```

Компилятор дошёл до конца файла и не нашёл парной `}`. Посчитайте скобки: сколько открыто, столько должно быть закрыто.

**6. Функция названа не `main`.**

```kotlin
fun start() {
    println("Привет")
}
```

Эта программа собирается без ошибок, но при запуске появляется сообщение:

```text
no main manifest attribute, in prog.jar
```

Компилятор не проверяет, что в программе есть `main`: для него `start` - обычная функция. А запускающей части не хватает точки входа, и она сообщает об этом. Верните имя `main`.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; компилятор проверяет его и переводит в форму, которую можно выполнить.
* Минимальная программа на Kotlin - функция `fun main()`; команды пишут между её фигурными скобками, они выполняются сверху вниз.
* `println("текст")` печатает строку и переходит на следующую; кавычки на экран не попадают.
* Регистр букв в именах важен, а скобки и кавычки закрываются парами.

В следующем уроке ([Как читать сообщения об ошибках](lesson:kotlin.from-zero.compiler-errors)) вы научитесь читать сообщения компилятора и исправлять ошибки по одной.

## Для тех, кто уже программирует

* Точка входа - функция `fun main()` на верхнем уровне файла: ни класса, ни `static`, ни обязательного `args`. Вариант `fun main(args: Array<String>)` тоже допустим.
* Точки с запятой не нужны: команду заканчивает конец строки. Блоки выделяются фигурными скобками, отступы не значимы (в отличие от Python).
* `println` - аналог `print` в Python, `console.log` в JavaScript и `System.out.println` в Java; он добавляет перевод строки, `print` - нет.
* Kotlin статически типизирован и компилируется в байткод JVM. Файл `Main.kt` превращается в класс `MainKt`, а `main` - в его статический метод.
* Имена регистрозависимы. Функции и переменные принято писать с маленькой буквы (`camelCase`), типы - с большой.
* Нативного исполняемого файла, как в Go или Rust, здесь нет: результат - архив `prog.jar`, запускаемый командой `java -jar`.

## Что происходит при нажатии «Запустить»

Это необязательный раздел: для заданий он не нужен.

Приложение выполняет две команды. Сначала `kotlinc Main.kt -include-runtime -d prog.jar`: компилятор разбирает текст по правилам языка, проверяет, что все имена известны и все типы сочетаются, и записывает результат в архив `prog.jar`. В нём не машинный код процессора, а **байткод** - команды для воображаемого процессора, который называется **виртуальной машиной Java (JVM)**. Параметр `-include-runtime` кладёт в тот же архив и стандартную библиотеку Kotlin, чтобы одного файла хватало для запуска. Затем `java -jar prog.jar` запускает JVM: она загружает класс `MainKt` и выполняет его, начиная с `main`.

Именно поэтому первый запуск занимает несколько секунд: сам `kotlinc` - тоже программа на JVM, и ей нужно запуститься, прочитать ваш код и записать архив.

Ошибки вроде `Expecting ')'` вы видите **до** запуска: сборка останавливается, программа не стартует, и частично выполненного результата нет. Подробнее про байткод, JVM и компиляцию - в курсе [Kotlin: первые шаги](lesson:kotlin.first-steps.how-kotlin-runs).
