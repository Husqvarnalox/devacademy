## Зачем нужна арифметика

Подсчитать сумму покупки, сдачу, число полных коробок, среднюю оценку - большинство программ что-то считают. Для этого у языка есть арифметические операции, которые похожи на школьные, но имеют несколько особенностей. Главная из них: деление целых чисел работает иначе, чем на калькуляторе.

## Одна новая идея: тип операндов решает, каким будет деление

Основные операции:

| Операция | Значение | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `5 + 2` | `7` |
| `-` | вычитание | `5 - 2` | `3` |
| `*` | умножение | `5 * 2` | `10` |
| `/` | деление | `7 / 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |

Обратите внимание на деление: `7 / 2` равно `3`, а не `3.5`. Если **оба** числа целые (`Int`), деление **целочисленное**: дробная часть отбрасывается. А если хотя бы одно число дробное (`Double`), результат тоже дробный: `7 / 2.0` равно `3.5`.

Остаток от деления дополняет целочисленное деление: `7 / 2` - это «сколько раз 2 помещается в 7» (3 раза), а `7 % 2` - «сколько остаётся» (1).

Порядок действий такой же, как в математике: сначала `*`, `/`, `%`, потом `+`, `-`; скобки меняют порядок.

<!-- section: examples -->
## Пример 1. Покупка и сдача

```kotlin run
fun main() {
    val price = 80
    val count = 3
    val total = price * count
    println("К оплате: $total руб.")
    println("Сдача с 500: ${500 - total} руб.")
}
```
```output
К оплате: 240 руб.
Сдача с 500: 260 руб.
```

Разбор по строкам:

* `price * count` перемножает значения двух переменных. Результат `240` сохраняется в новой переменной `total`.
* В шаблоне `"$total"` вставляется значение переменной.
* `${500 - total}` - вычисляемая вставка. В фигурные скобки после `$` можно записать любое выражение, и в текст попадёт его результат. Для простого имени скобки не обязательны, для выражения нужны.

## Пример 2. Деление, остаток и приоритет

```kotlin run
fun main() {
    val apples = 17
    val box = 6
    println("Полных коробок: ${apples / box}")
    println("Остаётся: ${apples % box}")
    println(7 / 2)
    println(7 / 2.0)
    println(2 + 3 * 4)
    println((2 + 3) * 4)
}
```
```output
Полных коробок: 2
Остаётся: 5
3
3.5
14
20
```

Разбор: `17 / 6` - целочисленное деление, `17 % 6` - остаток, и вместе они дают «2 коробки и ещё 5 яблок» (2 * 6 + 5 = 17). Строки `7 / 2` и `7 / 2.0` показывают разницу типов операндов. В последних двух строках скобки меняют порядок действий.

## Пример 3. Обновление переменной

```kotlin run
fun main() {
    var balance = 1000
    balance -= 250
    balance += 100
    balance *= 2
    balance++
    println(balance)
}
```
```output
1701
```

Разбор: `balance -= 250` - сокращение для `balance = balance - 250`. Так же работают `+=`, `*=`, `/=`, `%=`. Запись `balance++` увеличивает значение на единицу (`balance--` уменьшает). Цепочка: 1000 - 250 = 750, 750 + 100 = 850, 850 * 2 = 1700, ещё +1 = 1701. Такие операции возможны только для `var`.

**Попробуйте.** Предскажите результат `-7 / 2` и `-7 % 3` до запуска, затем проверьте в редакторе. Деление округляет в сторону нуля, а знак остатка совпадает со знаком делимого.

## Точные правила

* Операции `+ - * / %` определены для `Int`, `Long` и `Double`. Для `String` из них работает только `+` (склейка).
* Деление `Int / Int` даёт `Int`: дробная часть отбрасывается в сторону нуля (`7 / 2` = 3, `-7 / 2` = -3). Остаток `a % b` удовлетворяет равенству `a == (a / b) * b + a % b` (`-7 % 3` = -1).
* Если один из операндов `Double`, результат тоже `Double`: `7 / 2.0` = 3.5, `1 + 2.5` = 3.5.
* Присвоить результат целочисленного деления переменной `Double` нельзя: `val share: Double = total / people` - ошибка типа, потому что слева `Double`, а справа `Int`. Правильное преобразование - в уроке о преобразовании типов.
* Деление целого числа на ноль (`5 / 0`, `5 % 0`) во время работы бросает `ArithmeticException: / by zero`. Деление дробного на ноль не бросает исключение, результатом будет `Infinity` или `NaN`.
* Приоритет: `* / %` выше, чем `+ -`; операции одного приоритета выполняются слева направо. Скобки всегда выполняются первыми.
* Составное присваивание `x op= y` равно `x = x op y`. Оно требует `var`.
* `x++` и `x--` увеличивают и уменьшают целую переменную на 1; тоже требуют `var`.
* Целые числа `Int` при выходе за предел переполняются без сообщения: `Int.MAX_VALUE + 1` даёт `-2147483648`. Как этого избежать - в курсе `kotlin-first-steps`.
* Дробные числа хранятся приближённо: `0.1 + 0.2` равно `0.30000000000000004`. Это свойство двоичного представления, а не ошибка Kotlin. Для денег, где важны копейки, обычно считают в целых копейках.

## Типичные ошибки

**1. Ожидать дробь от деления целых.**

```kotlin
fun main() {
    val total = 7
    val people = 2
    println(total / people)
}
```

Программа печатает `3`, а не `3.5`: оба числа `Int`. Чтобы получить дробный результат, нужен `Double` хотя бы с одной стороны (как это сделать с переменными - в уроке о преобразовании типов).

**2. Положить целочисленный результат в `Double`.**

```kotlin
fun main() {
    val total = 10
    val people = 3
    val share: Double = total / people
    println(share)
}
```

```text
Main.kt:4:23: error: initializer type mismatch: expected 'Double', actual 'Int'.
    val share: Double = total / people
                      ^
```

Результат деления двух `Int` - это `Int`, а Kotlin не превращает его в `Double` сам. Само деление в таком виде тоже не даст дроби.

**3. Деление на ноль.**

```kotlin
fun main() {
    val a = 10
    val b = 0
    println(a / b)
}
```

Программа собирается, но при запуске останавливается:

```text
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at MainKt.main(Main.kt:4)
```

Это ошибка времени выполнения: её нельзя найти до запуска. Ниже показана главная часть сообщения (в полном тексте есть ещё строка со стеком вызовов). Сообщение называет тип исключения (`ArithmeticException`), причину (`/ by zero`) и строку программы (`Main.kt:4`). Проверку делителя на ноль вы научитесь делать в уроках об условиях.

**4. Изменение `val`.**

```kotlin
fun main() {
    val x = 5
    x++
    println(x)
}
```

```text
Main.kt:3:5: error: 'val' cannot be reassigned.
    x++
    ^
```

`x++` меняет значение, а `val` менять нельзя. Объявите `var x = 5`.

**5. Забытые скобки.** `2 + 3 * 4` равно `14`, а не `20`. Если нужен другой порядок, расставьте скобки: `(2 + 3) * 4`.

## Итоги

* `+ - * / %` работают как в математике; сначала `* / %`, потом `+ -`, скобки меняют порядок.
* Деление двух `Int` целочисленное (`7 / 2` равно `3`); с `Double` оно дробное (`7 / 2.0` равно `3.5`).
* `%` даёт остаток; вместе с `/` оно решает задачи «сколько полных и сколько осталось».
* `+=`, `-=`, `*=`, `++`, `--` обновляют `var`. Деление целого на ноль останавливает программу с `ArithmeticException`.

В следующем уроке ([Строки](lesson:kotlin.from-zero.strings)) вы узнаете, как измерять текст и брать из него отдельные символы.

## Для тех, кто уже программирует

* `Int / Int` - целочисленное деление с усечением к нулю, как в Java, C#, Go; в Python 3 `/` всегда дробное, а `//` - деление с округлением вниз. В JavaScript `/` всегда дробное.
* Остаток `%` имеет знак делимого, как в Java: `-7 % 3 == -1`. Для неотрицательного остатка есть `mod` (`(-7).mod(3) == 2`).
* Операторы - методы типов (`plus`, `div`, `rem`), что позволяет перегружать их для своих классов. Для стандартных типов компилятор делает их примитивными операциями.
* Нет неявного расширения: `val x: Double = intValue` не компилируется; `Int + Double` допустимо и даёт `Double`.
* Переполнение `Int` тихое, как в Java и C#. Для проверенной арифметики есть `Math.addExact` и аналогичные методы, а `Long` расширяет диапазон.
* Степени нет как оператора: используют `Math.pow` или `kotlin.math.pow` (`2.0.pow(3)`). `++` и `--` есть, но в этом курсе их используют отдельной командой, а не внутри выражения.
