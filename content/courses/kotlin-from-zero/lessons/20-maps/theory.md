## Поиск значения по названию

Список хранит значения по номеру: «третий товар», «первая оценка». Но часто нужно находить значение по смыслу: цену по названию товара, город по названию страны, количество повторов по слову. Искать такое в списке пришлось бы перебором. Для этого есть **словарь** (в Kotlin `Map`): коллекция пар «ключ - значение».

**Ключ** - то, по чему ищут (название товара). **Значение** - то, что находят (цена). У каждого ключа в словаре ровно одно значение, и ключи не повторяются.

## Одна новая идея: словарь находит значение по ключу

Создание и основные действия:

| Запись | Смысл |
|---|---|
| `mapOf("a" to 1, "b" to 2)` | неизменяемый словарь: пары записываются как `ключ to значение` |
| `mutableMapOf("a" to 1)` | изменяемый словарь |
| `mutableMapOf<String, Int>()` | пустой изменяемый словарь (типы ключа и значения указаны явно) |
| `map[key]` | значение по ключу или `null`, если такого ключа нет |
| `map[key] = value` | добавить пару или заменить значение (изменяемый словарь) |
| `map.getOrDefault(key, d)` | значение по ключу или `d`, если ключа нет |
| `map.containsKey(key)` | есть ли такой ключ |
| `map.remove(key)` | удалить пару |
| `map.size`, `map.keys`, `map.values` | количество пар, все ключи, все значения |

Результат `map[key]` может быть `null`, потому что ключа может не оказаться. Поэтому его тип - nullable (`Int?`), и работать с ним нужно так, как в прошлом уроке: через `?:` или проверку.

## Пример 1. Чтение словаря

```kotlin run
fun main() {
    val capitals = mapOf("Франция" to "Париж", "Италия" to "Рим", "Испания" to "Мадрид")
    println(capitals)
    println(capitals["Италия"])
    println(capitals["Польша"])
    println(capitals.size)
    println(capitals.containsKey("Испания"))
    println(capitals.getOrDefault("Польша", "неизвестно"))
    for ((country, city) in capitals) {
        println("$country - $city")
    }
}
```
```output
{Франция=Париж, Италия=Рим, Испания=Мадрид}
Рим
null
3
true
неизвестно
Франция - Париж
Италия - Рим
Испания - Мадрид
```

Разбор:

* Запись `"Франция" to "Париж"` создаёт пару. Словарь печатается в фигурных скобках в виде `ключ=значение`.
* `capitals["Польша"]` возвращает `null`: такого ключа нет. Ошибки при этом не возникает.
* `getOrDefault` позволяет сразу получить запасное значение вместо `null`.
* В цикле `for ((country, city) in capitals)` каждая пара раскладывается на две переменные: ключ и значение. Две переменные записываются **в круглых скобках**. Порядок пар такой же, как при создании.

## Пример 2. Изменение и подсчёт

```kotlin run
fun main() {
    val stock = mutableMapOf("яблоки" to 5, "груши" to 2)
    stock["бананы"] = 7
    stock["груши"] = 10
    stock["яблоки"] = stock.getOrDefault("яблоки", 0) + 1
    println(stock)
    stock.remove("бананы")
    println(stock)
    val counts = mutableMapOf<Char, Int>()
    for (ch in "ананас") {
        counts[ch] = (counts[ch] ?: 0) + 1
    }
    println(counts)
    var total = 0
    for (value in counts.values) {
        total += value
    }
    println(total)
    println(counts.keys)
}
```
```output
{яблоки=6, груши=10, бананы=7}
{яблоки=6, груши=10}
{а=3, н=2, с=1}
6
[а, н, с]
```

Разбор:

* `stock["бананы"] = 7` добавляет новую пару, а `stock["груши"] = 10` заменяет значение у существующего ключа: ключи не дублируются.
* `stock.getOrDefault("яблоки", 0) + 1` берёт текущее количество и увеличивает на 1.
* Шаблон **подсчёта** встречается очень часто: `counts[ch] = (counts[ch] ?: 0) + 1`. Если символа в словаре ещё не было, `counts[ch]` равно `null`, оператор `?:` подставляет 0, и результат равен 1. Если был - число увеличивается.
* `counts.values` - все значения (здесь для суммы), `counts.keys` - все ключи. По строке можно проходить циклом `for (ch in "ананас")`: переменная получает символы по одному.

## Пример 3. Повторяющийся ключ

```kotlin run
fun main() {
    val prices = mapOf("a" to 1, "a" to 2)
    println(prices)
}
```
```output
{a=2}
```

Разбор:

* Ключ «a» указан дважды, поэтому остаётся одна пара с последним значением. Ключи уникальны.

**Чтение и подсчёт слов.** Программа, считающая повторы по вводу, показана без запуска:

```kotlin
fun main() {
    val n = readln().toInt()
    val counts = mutableMapOf<String, Int>()
    for (i in 1..n) {
        val word = readln()
        counts[word] = (counts[word] ?: 0) + 1
    }
    for ((word, count) in counts) {
        println("$word: $count")
    }
}
```

Для ввода `5`, `кот`, `пёс`, `кот`, `кот`, `пёс` (по слову в строке) она напечатает `кот: 3` и `пёс: 2`.

**Попробуйте.** В примере 2 посчитайте буквы своего имени и выведите букву, которая встречается чаще всего (подсказка: цикл по `counts` и переменная для лучшего значения).

## Точные правила

* Словарь - набор пар «ключ - значение». Ключи уникальны: запись в уже существующий ключ заменяет значение.
* Типы ключа и значения фиксированы: `Map<String, Int>` хранит строки как ключи и числа как значения. Для пустого словаря их указывают явно: `mutableMapOf<String, Int>()`.
* `map[key]` возвращает значение или `null`, поэтому тип результата - nullable (`Int?`). Для запасного значения используют `?:` или `getOrDefault`.
* `mapOf` создаёт словарь только для чтения; запись `map[key] = value` и `remove` у него недоступны. `mutableMapOf` создаёт изменяемый словарь.
* Пара создаётся записью `ключ to значение`. Выражение с `to` - обычный вызов, а не специальный синтаксис.
* Порядок пар сохраняется таким, в каком их добавили (для `mapOf` и `mutableMapOf`). Не опирайтесь на порядок в других видах словарей.
* `for ((key, value) in map)` раскладывает каждую пару на две переменные; скобки вокруг имён обязательны.
* `size` - свойство без скобок, `keys` и `values` - свойства; `containsKey(key)` - вызов.
* Тип ключа проверяется: искать число в словаре со строковыми ключами нельзя.

## Типичные ошибки

**1. Значение по ключу - не `Int`, а `Int?`.**

```kotlin
fun main() {
    val ages = mapOf("Анна" to 25)
    val age: Int = ages["Анна"]
    println(age)
}
```

```text
Main.kt:3:18: error: initializer type mismatch: expected 'Int', actual 'Int?'.
    val age: Int = ages["Анна"]
                 ^
```

Ключа могло не быть, поэтому результат может быть `null`. Исправление: `ages["Анна"] ?: 0` или `getOrDefault`.

**2. Запись в неизменяемый словарь.**

```kotlin
fun main() {
    val ages = mapOf("Анна" to 25)
    ages["Борис"] = 30
}
```

```text
Main.kt:3:9: error: no 'set' operator method providing array access.
    ages["Борис"] = 30
        ^^^^^^^^^
```

Словарь из `mapOf` нельзя изменить. Создайте его через `mutableMapOf`.

**3. Арифметика над значением, которое может быть `null`.**

```kotlin
fun main() {
    val ages = mapOf("Анна" to 25)
    println(ages["Анна"] + 1)
}
```

```text
Main.kt:3:26: error: operator call is prohibited on a nullable receiver of type 'Int?'. Use '?.'-qualified call instead.
    println(ages["Анна"] + 1)
                         ^
```

Даже если вы знаете, что ключ есть, компилятор этого не знает. Напишите `(ages["Анна"] ?: 0) + 1`.

**4. Ключ неверного типа.**

```kotlin
fun main() {
    val ages = mapOf("Анна" to 25)
    println(ages[5])
}
```

```text
Main.kt:3:13: error: type inference failed. The value of the type parameter 'K' must be mentioned in input types (argument types, receiver type, or expected type). Try to specify it explicitly.
    println(ages[5])
            ^^^^^^^
```

Ключи этого словаря - строки, число 5 не подходит. Сообщение формулируется через параметр типа `K` (тип ключа); смысл в том, что ключ имеет неверный тип.

**5. Две переменные без скобок.**

```kotlin
fun main() {
    val ages = mapOf("Анна" to 25)
    for (name, age in ages) {
        println("$name $age")
    }
}
```

```text
Main.kt:3:5: error: method 'iterator()' is ambiguous for this expression. Applicable candidates:
...
Main.kt:3:14: error: syntax error: Expecting 'in'.
    for (name, age in ages) {
             ^
Main.kt:3:15: error: syntax error: Expecting ')'.
    for (name, age in ages) {
              ^
...
```

Здесь показаны не все строки: компилятор выдал семь ошибок, многие - следствия первой синтаксической. Важна строка `Expecting 'in'`. Нужно `for ((name, age) in ages)`.

## Итоги

* Словарь хранит пары «ключ - значение», ключи уникальны, значение находят по ключу: `map[key]`.
* Результат `map[key]` может быть `null`, поэтому его тип `Int?`, `String?` и т. п.; запасное значение даёт `?:` или `getOrDefault`.
* `mapOf` - только чтение, `mutableMapOf` - изменяемый (`map[key] = value`, `remove`).
* `for ((key, value) in map)` перебирает пары; `keys` и `values` дают все ключи или значения.
* Шаблон подсчёта: `counts[x] = (counts[x] ?: 0) + 1`.

Слова и тексты - частая начинка словарей и списков. Дальше разберём, что умеют делать со строками: [Методы строк](lesson:kotlin.from-zero.string-methods).

## Для тех, кто уже программирует

* `Map<K, V>` - интерфейс только для чтения, `MutableMap<K, V>` - изменяемый. Реализация по умолчанию - `LinkedHashMap`: порядок вставки сохраняется (в отличие от `HashMap` в Java и порядка в Go-мапах, который случайный).
* `map[key]` не бросает исключение при отсутствии ключа, а возвращает `null`: тип результата `V?`. Это как `Map.get` в Java, но компилятор проверяет, что `null` обработан. Для обязательного значения есть `getValue(key)`, который бросает исключение.
* Нет аналога `defaultdict` или `Counter` из Python в самом языке, но `getOrDefault`, `getOrPut` и `?:` закрывают типичные случаи. В JavaScript аналог - `Map`; обычный объект как словарь в Kotlin не используется.
* `to` создаёт `Pair<A, B>`; запись `(key, value)` в цикле - деструктуризация пары.
* Ключи сравниваются через `equals` и `hashCode`. Для строк и чисел это работает как ожидается; для своих типов нужно особое устройство (классы - в `kotlin-fundamentals`).
* Трансформации (`filter`, `mapValues`, `groupBy`) работают через лямбды и разбираются позже.
