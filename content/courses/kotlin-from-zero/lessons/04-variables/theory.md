## Зачем нужны переменные

До сих пор программа печатала текст, записанный прямо в команде. Настоящие программы работают со значениями: цена товара, имя пользователя, число попыток. Значение нужно где-то хранить, а потом использовать по имени, не переписывая его каждый раз. Для этого служат **переменные**.

**Переменная** - это именованное место в памяти программы, где лежит значение. Имя позволяет обратиться к значению позже; по имени же значение можно заменить, если разрешено.

## Одна новая идея: val фиксирует значение, var позволяет его менять

В Kotlin переменную объявляют одним из двух слов:

```kotlin
val product = "Яблоки"
var price = 80
```

* `val` (от *value*, «значение») - переменная, которой значение дают **один раз**. Потом заменить его нельзя.
* `var` (от *variable*, «изменяемая») - переменная, значение которой можно заменять.

Правило выбора простое: объявляйте `val`, а `var` берите там, где значение действительно должно меняться. Тогда по программе сразу видно, что может измениться, а что нет.

Тип значения Kotlin определяет сам: `"Яблоки"` - это текст (тип `String`), `80` - целое число (тип `Int`). Это называется **выводом типа**. Тип запоминается и больше не меняется: в переменную с текстом нельзя положить число.

Чтобы вставить значение переменной в текст, пишут знак `$` и имя: `"Цена: $price"`. Это **шаблон строки**: вместо `$price` в текст попадёт значение переменной.

<!-- section: examples -->
## Пример 1. val и шаблон строки

```kotlin run
fun main() {
    val product = "Яблоки"
    val price = 80
    println(product)
    println(price)
    println("Цена за кг: $price руб.")
    println("Товар: $product")
}
```
```output
Яблоки
80
Цена за кг: 80 руб.
Товар: Яблоки
```

Разбор по строкам:

* `val product = "Яблоки"` - создаёт переменную `product` и кладёт в неё текст. Слева от `=` стоит имя, справа - значение.
* `val price = 80` - то же для числа. Число пишут без кавычек.
* `println(product)` и `println(price)` печатают значения. Имя переменной в команду пишется без кавычек: тогда выводится значение, а не само слово.
* В `"Цена за кг: $price руб."` вместо `$price` подставилось `80`. Остальной текст напечатался как есть.

## Пример 2. var и присваивание

```kotlin run
fun main() {
    var balance = 500
    println("Баланс: $balance")
    balance = 350
    println("Баланс: $balance")
    balance = 0
    println("Баланс: $balance")
}
```
```output
Баланс: 500
Баланс: 350
Баланс: 0
```

Разбор: слово `var` пишут один раз, при объявлении. Строка `balance = 350` - **присваивание**: значение справа записывается в переменную слева, старое значение пропадает. Каждый `println` показывает значение на тот момент, когда он выполняется: программа идёт сверху вниз.

## Пример 3. Фигурные скобки в шаблоне

```kotlin run
fun main() {
    val price = 80
    println("Цена: ${price}руб.")
    println("Цена: $price руб.")
}
```
```output
Цена: 80руб.
Цена: 80 руб.
```

Имя после `$` продолжается, пока идут буквы и цифры. Если сразу за переменной нужно дописать текст без пробела, имя обрамляют фигурными скобками: `${price}`. В скобках можно записать и более сложное выражение, но об этом - в уроке об арифметике.

**Попробуйте.** В примере 2 замените `var` на `val` и посмотрите на сообщение компилятора. Затем верните `var`, добавьте переменную `val owner = "Анна"` и выведите строку `Владелец: Анна, баланс: 0`.

## Точные правила

* Объявление: `val имя = значение` или `var имя = значение`. Тип выводится из значения: `Int` для целых чисел, `String` для текста в двойных кавычках.
* Присваивание: `имя = новое значение`. Оно допустимо только для `var`. Для `val` компилятор сообщит `'val' cannot be reassigned`.
* Тип переменной фиксирован. В `var city = "Минск"` нельзя потом записать `city = 100`: ошибка компиляции.
* Имя переменной состоит из букв, цифр и знака `_` и не начинается с цифры. Регистр важен: `Price` и `price` - разные имена. По традиции имена пишут со строчной буквы, а слова склеивают заглавной: `totalPrice`.
* Имя должно говорить о смысле значения: `price`, а не `x`. Это не требование компилятора, а забота о читателе.
* Одно имя в одном блоке объявляют один раз: два `val price` подряд - ошибка `conflicting declarations`.
* Переменную нельзя использовать раньше объявления: программа читается сверху вниз.
* Шаблон: `$имя` или `${имя}`. Чтобы напечатать сам знак `$`, пишут `\$`.
* `Int` - целое число в диапазоне примерно от -2 млрд до +2 млрд (точные границы и другие типы - в следующих уроках). `String` - текст любой длины, в том числе пустой `""`.

## Типичные ошибки

**1. Присваивание значению `val`.**

```kotlin
fun main() {
    val price = 100
    price = 120
    println(price)
}
```

```text
Main.kt:3:5: error: 'val' cannot be reassigned.
    price = 120
    ^^^^^
```

`val` не допускает замены. Если значение должно меняться, объявите `var`. Если не должно - не пытайтесь его менять.

**2. Запись значения другого типа.**

```kotlin
fun main() {
    var name = "Анна"
    name = 5
    println(name)
}
```

```text
Main.kt:3:10: error: assignment type mismatch: actual type is 'Int', but 'String' was expected.
    name = 5
         ^
```

`type mismatch` значит «типы не совпадают». Переменная `name` создана для текста, число в неё не помещается. Если число нужно хранить, заведите другую переменную.

**3. Неизвестное имя: опечатка или забытое объявление.**

```kotlin
fun main() {
    println(total)
}
```

```text
Main.kt:2:13: error: unresolved reference 'total'.
    println(total)
            ^^^^^
```

Такое сообщение знакомо по предыдущим урокам: имя `total` нигде не объявлено. Проверьте написание и регистр или объявите переменную выше.

**4. Имя в шаблоне «съело» буквы.**

```kotlin
fun main() {
    val price = 80
    println("Цена: $priceруб.")
}
```

```text
Main.kt:3:21: error: unresolved reference 'priceруб'.
    println("Цена: $priceруб.")
                    ^^^^^^^^
```

Для Kotlin `priceруб` - одно имя, потому что русские буквы допустимы в именах. Отделите переменную фигурными скобками: `${price}руб.`.

**5. Две переменные с одним именем.**

```kotlin
fun main() {
    val a = 1
    val a = 2
    println(a)
}
```

```text
Main.kt:2:9: error: conflicting declarations:
local val a: Int
local val a: Int
    val a = 1
        ^
Main.kt:3:9: error: conflicting declarations:
local val a: Int
local val a: Int
    val a = 2
        ^
```

Сообщение показывается для обеих строк: компилятору важно, что два объявления конфликтуют. Если нужно новое значение, используйте `var` и присваивание, а не второе объявление.

## Итоги

* Переменная - именованное хранилище значения; объявляется словами `val` (значение не меняется) и `var` (значение можно заменять).
* Присваивание `имя = значение` заменяет значение у `var`; для `val` это ошибка компиляции.
* Тип Kotlin определяет по значению: `80` - `Int`, `"Яблоки"` - `String`; тип потом не меняется.
* Шаблон `$имя` и `${имя}` вставляет значение переменной в текст.

В следующем уроке ([Основные типы](lesson:kotlin.from-zero.basic-types)) вы познакомитесь с дробными числами, логическими значениями и символами.

## Для тех, кто уже программирует

* `val` - неизменяемая ссылка (аналог `final` в Java), `var` - изменяемая. В Kotlin принято начинать с `val` и переходить на `var` только при необходимости.
* `val` не делает объект неизменяемым: если в `val` лежит изменяемый список, его содержимое менять можно. Запрещено только переприсваивание самой переменной (подробнее - в уроке о списках).
* Тип выводится (`val x = 5` - `Int`), но он статический: присвоить `String` переменной `Int` нельзя, в отличие от Python и JavaScript. Явный тип записывается после имени: `val x: Int = 5` (урок 5).
* Шаблоны `"$x"` и `"${x + 1}"` заменяют `printf`, f-строки Python и шаблонные литералы JavaScript. Интерполяция работает в любой строке в двойных кавычках.
* Точка с запятой не нужна. Объявление без начального значения возможно только с явным типом, и использовать переменную до присваивания нельзя (`variable 'x' must be initialized`).
* Повторное объявление переменной в той же области видимости - ошибка. Затенение (shadowing) допустимо только во вложенном блоке (с предупреждением).
