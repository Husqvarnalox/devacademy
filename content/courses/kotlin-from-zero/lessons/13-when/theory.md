## Когда цепочка `else if` становится неудобной

Представьте программу, которая по номеру дня недели печатает его название. Через `else if` придётся записать семь почти одинаковых проверок `day == 1`, `day == 2` и так далее. Читать такую цепочку утомительно, а ошибиться в одной из строк легко.

Когда нужно сравнить **одно и то же значение** с набором вариантов, в Kotlin есть оператор `when` («когда»). Он читается как таблица: слева - варианты, справа - что делать.

## Одна новая идея: `when` сверяет значение с вариантами по порядку

```kotlin
when (значение) {
    вариант1 -> действие1
    вариант2 -> действие2
    else -> действие, если ничего не подошло
}
```

Каждая строка внутри `when` называется **веткой**: слева условие-вариант, затем стрелка `->`, справа действие. Программа проходит ветки сверху вниз, находит **первую** подходящую, выполняет её и выходит из `when`. Ветка `else` («иначе») срабатывает, когда ни один из перечисленных вариантов не подошёл.

В варианте можно перечислить несколько значений через запятую (`6, 7 ->`) и проверять попадание в диапазон: `in 1..9` значит «число от 1 до 9 включительно». Как и `if`, оператор `when` может давать значение.

<!-- section: examples -->
## Пример 1. Значение и несколько вариантов

```kotlin run
fun main() {
    val day = 6
    val name = when (day) {
        1 -> "понедельник"
        2 -> "вторник"
        3 -> "среда"
        4 -> "четверг"
        5 -> "пятница"
        6, 7 -> "выходной"
        else -> "нет такого дня"
    }
    println("День $day: $name")
    val command = "stop"
    when (command) {
        "start" -> println("Запуск")
        "stop" -> println("Остановка")
        else -> println("Неизвестная команда: $command")
    }
}
```
```output
День 6: выходной
Остановка
```

Разбор:

* В первом `when` значение `day` сравнивается с вариантами. Подошла ветка `6, 7 ->`: запятая означает «или». Результат ветки становится значением всего `when` и сохраняется в `name`.
* Во втором `when` ветки выполняют действие (`println`), а значение не используется. Так же `when` работает со строками.
* Ветка `else` есть в обоих случаях. Для `when`, значение которого сохраняется, она обязательна.

## Пример 2. Диапазоны и `when` без аргумента

```kotlin run
fun main() {
    val age = 34
    val group = when (age) {
        in 0..6 -> "дошкольник"
        in 7..17 -> "школьник"
        in 18..64 -> "взрослый"
        else -> "пенсионер"
    }
    println(group)
    val temperature = -3
    val advice = when {
        temperature < 0 -> "мороз, нужна шапка"
        temperature < 20 -> "прохладно"
        else -> "тепло"
    }
    println(advice)
    val ch = 'k'
    when (ch) {
        'a', 'e', 'i', 'o', 'u' -> println("гласная")
        in 'a'..'z' -> println("согласная")
        else -> println("не латинская буква")
    }
}
```
```output
взрослый
мороз, нужна шапка
согласная
```

Разбор:

* `in 18..64` проверяет, попадает ли `age` в диапазон от 18 до 64; обе границы входят в него. 34 попадает, поэтому результат «взрослый».
* Если после `when` нет скобок со значением, каждая ветка слева содержит полноценное условие `Boolean`. Это замена длинной цепочки `else if` и бывает удобнее, когда условия разные по виду.
* Диапазон можно построить и из символов: `'a'..'z'` - все строчные латинские буквы. Буква `k` не гласная, поэтому первая ветка не подошла, а вторая подошла.

## Пример 3. Первая подходящая ветка, провала нет

```kotlin run
fun main() {
    val n = 5
    when {
        n > 0 -> println("положительное")
        n > 3 -> println("больше трёх")
        else -> println("не больше нуля")
    }
    when (n) {
        !in 1..3 -> println("вне 1..3")
        else -> println("внутри 1..3")
    }
    val parity = when (n % 2) {
        0 -> "чётное"
        else -> "нечётное"
    }
    println(parity)
}
```
```output
положительное
вне 1..3
нечётное
```

Разбор:

* Условия `n > 0` и `n > 3` оба истинны для 5, но выполнена только первая ветка: после неё `when` заканчивается. В отличие от `switch` в Java и C, команды `break` не нужны и «проваливания» в следующую ветку нет.
* `!in 1..3` читается «не входит в диапазон от 1 до 3».
* Значением `when` может быть вычисленное выражение: в третьем случае проверяется остаток `n % 2`.

**Попробуйте.** В примере 2 поменяйте `age` на `18`, `6` и `70` и предскажите группу. Затем в примере 3 поменяйте местами первые две ветки `when` без аргумента и посмотрите, как изменится вывод.

## Точные правила

* Вариант слева от `->` может быть значением (`1`, `"stop"`, `'a'`), несколькими значениями через запятую, проверкой `in диапазон` или `!in диапазон`. В `when` без аргумента слева стоит любое условие типа `Boolean`.
* Типы варианта и проверяемого значения должны сочетаться: сравнивать `Int` со строкой `"три"` нельзя.
* Ветки проверяются сверху вниз, выполняется первая подошедшая. После её выполнения `when` заканчивается; команды `break` для этого не нужны.
* Если `when` используется как **выражение** (его значение сохраняется или печатается), он обязан покрывать все случаи. Для числа и строки это значит, что последней должна идти ветка `else`.
* Если `when` стоит как обычная команда, `else` можно не писать: тогда при отсутствии совпадений ничего не произойдёт.
* Ветка с одним действием пишется в строку. Если нужно несколько команд, их заключают в фигурные скобки: `1 -> { println("a"); println("b") }`. Значением такой ветки становится последнее выражение блока.
* Диапазон `a..b` включает оба конца. Если начало больше конца (`10..1`), диапазон пуст и ни одно число в него не входит.
* Порядок веток значим для пересекающихся условий: узкое условие ставят выше широкого, как в цепочке `else if`.

## Типичные ошибки

**1. `when` как выражение без `else`.**

```kotlin
fun main() {
    val n = 3
    val word = when (n) {
        1 -> "один"
        2 -> "два"
    }
    println(word)
}
```

```text
Main.kt:3:16: error: 'when' expression must be exhaustive. Add an 'else' branch.
    val word = when (n) {
               ^^^^
```

Если значение `when` нужно, компилятор требует предусмотреть все случаи. Число 3 не покрыто ни одной веткой, поэтому добавьте `else -> "другое"`.

**2. Двоеточие вместо стрелки.**

```kotlin
fun main() {
    val n = 1
    when (n) {
        1: println("один")
        else -> println("другое")
    }
}
```

```text
Main.kt:4:10: error: syntax error: Expecting '->'.
    1: println("один")
     ^
```

В Kotlin нет слов `case` и `default`, как в Java и C. Вариант отделяется от действия стрелкой `->`, а запасная ветка называется `else`.

**3. Вариант другого типа.**

```kotlin
fun main() {
    val n = 3
    when (n) {
        "три" -> println("три")
        else -> println("другое")
    }
}
```

```text
Main.kt:4:9: error: incompatible types 'Int' and 'String'.
    "три" -> println("три")
    ^^^^^
```

Значение `n` - число, а вариант - строка, сравнивать их бессмысленно. Напишите `3 ->`.

**4. Привычный `break`.**

```kotlin
fun main() {
    val n = 1
    when (n) {
        1 -> {
            println("один")
            break
        }
        else -> println("другое")
    }
}
```

```text
Main.kt:6:13: error: 'break' and 'continue' are only allowed inside loops.
            break
            ^^^^^
```

После ветки `when` заканчивается сам, `break` ей не нужен. Это слово понадобится в циклах: об этом - в уроках про цикл `while` и команды `break` и `continue`.

**5. Диапазон, записанный наоборот.**

```kotlin
fun main() {
    val n = 5
    when (n) {
        in 10..1 -> println("в диапазоне")
        else -> println("другое")
    }
}
```

```text
другое
```

Ошибки нет, но ветка `in 10..1` не сработает никогда: диапазон `10..1` пуст, ведь начало больше конца. Запишите `1..10`.

<!-- section: summary -->
## Итоги

* `when` сверяет значение с вариантами сверху вниз и выполняет первую подходящую ветку. Команда `break` не нужна, проваливания нет.
* В варианте можно перечислить значения через запятую и проверить попадание в диапазон: `6, 7 ->`, `in 1..9 ->`.
* `when` без аргумента принимает в ветках любые условия `Boolean` и заменяет длинную цепочку `else if`.
* Как выражение `when` должен покрывать все случаи: нужна ветка `else`.

Теперь программа умеет выбирать. Следующий шаг - уметь **повторять** действия, не переписывая их много раз: [Цикл while](lesson:kotlin.from-zero.while-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `when` заменяет `switch`: без `case`, без `break`, без проваливания. Сопоставление идёт по равенству `==` (структурному), поэтому работает и со строками.
* Варианты не обязаны быть константами: допускаются произвольные выражения, диапазоны (`in 1..9`), проверки типа (`is String`, урок о типах и `sealed` в fundamentals) и условия в форме без аргумента.
* `when` - выражение. В позиции выражения обязан быть исчерпывающим; для `Boolean`, `enum` и `sealed`-типов `else` можно опустить, если перечислены все варианты. Для `Int` и `String` компилятор требует `else`.
* Если подходит несколько веток, выполняется первая, как в цепочке `if`. Из-за этого порядок веток - часть логики, а не стиль.
* Блок в ветке возвращает последнее выражение, `return` не нужен. Привычного для Go `fallthrough` нет вовсе.
* В отличие от паттерн-матчинга в Python 3.10+ или Rust, `when` не разбирает структуру значения: он проверяет равенство, диапазон, тип или произвольное условие. Деструктурирующее сопоставление не поддерживается.
