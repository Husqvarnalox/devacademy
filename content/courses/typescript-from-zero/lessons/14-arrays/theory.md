## Зачем нужны массивы

До сих пор у каждого значения было своё имя: `price1`, `price2`, `price3`. Для трёх цен это терпимо, для тридцати нет, а число покупок в чеке заранее вообще неизвестно. Нужен способ хранить **много однотипных значений под одним именем** и работать с ними циклом. Для этого есть **массив**: упорядоченный список значений.

## Одна новая идея: массив - пронумерованный список значений одного типа

Массив записывают в квадратных скобках, значения разделяют запятыми:

```text
const prices: number[] = [10, 20, 30];
```

Запись `number[]` читается «массив чисел»: квадратные скобки после названия типа означают «много значений такого типа». В `string[]` лежат строки, в `boolean[]` логические значения. Смешивать типы в одном массиве проверка не позволяет: массив чисел может содержать только числа.

Каждое значение в массиве называется **элементом** и имеет номер - **индекс**. Нумерация начинается с **нуля**: первый элемент имеет индекс 0, второй - 1, третий - 2. Прочитать элемент можно, записав индекс в квадратных скобках: `prices[0]` даёт 10. Число элементов хранится в свойстве **`length`** («длина»): `prices.length` равно 3.

<!-- section: examples -->
## Пример 1. Создать, прочитать, измерить

```typescript run
const prices: number[] = [10, 20, 30];
const names: string[] = ["хлеб", "молоко"];

console.log(prices);
console.log(prices[0], prices[2]);
console.log(prices.length);
console.log(names[1], names.length);
```
```output
[ 10, 20, 30 ]
10 30
3
молоко 2
```

`console.log` выводит весь массив в квадратных скобках. `prices[0]` - первый элемент, `prices[2]` - последний, а `prices.length` равно 3: число элементов на единицу больше индекса последнего. Из-за этого индекс последнего элемента всегда `length - 1`.

## Пример 2. Добавить и изменить

```typescript run
const prices: number[] = [10, 20, 30];

prices.push(40);
console.log(prices, prices.length);

prices[1] = 25;
console.log(prices);

console.log(prices[prices.length - 1]);
```
```output
[ 10, 20, 30, 40 ] 4
[ 10, 25, 30, 40 ]
40
```

Команда **`push`** («втолкнуть») добавляет значение в конец массива и увеличивает `length`. Присваивание `prices[1] = 25` заменяет элемент с индексом 1. Обратите внимание: массив объявлен через `const`, и всё равно меняется. `const` запрещает присвоить переменной **другой** массив (`prices = [1, 2]`), но не запрещает менять содержимое того, на что она указывает.

## Пример 3. Выход за границы

```typescript run
const prices: number[] = [10, 20, 30];
console.log(prices[3]);
console.log(prices[3] + 1);
console.log(prices[-1]);

const empty: number[] = [];
console.log(empty.length, empty[0]);
```
```output
undefined
NaN
undefined
0 undefined
```

Элемента с индексом 3 нет: массив содержит индексы 0, 1 и 2. Ошибки при этом нет: чтение несуществующего элемента даёт особое значение **`undefined`** («не определено»). Проверка типов этого не замечает: она считает, что `prices[3]` - число. Дальше `undefined + 1` даёт `NaN` («не число»), и ошибка проявляется далеко от места, где она возникла. Пустой массив `[]` объявляется с типом и имеет `length` равное 0; `empty[0]` тоже `undefined`. Поэтому обращаться к элементу нужно, зная, что индекс допустим: `index >= 0 && index < values.length`.

## Пример 4. Функции с массивами

```typescript run
function squares(n: number): number[] {
  const result: number[] = [];
  for (let i: number = 1; i <= n; i++) {
    result.push(i * i);
  }
  return result;
}

function sumOf(values: number[]): number {
  let total: number = 0;
  for (let i: number = 0; i < values.length; i++) {
    total = total + values[i];
  }
  return total;
}

const sq: number[] = squares(5);
console.log(sq);
console.log(sumOf(sq), sumOf([]));
```
```output
[ 1, 4, 9, 16, 25 ]
55 0
```

Тип `number[]` годится и для параметра, и для результата функции. В `squares` пустой массив заполняется через `push` внутри цикла. В `sumOf` цикл идёт по индексам от 0 до `length - 1`: условие `i < values.length` не допускает выхода за границу. Для пустого массива цикл не выполняется, и результат остаётся начальным значением 0.

**Попробуйте.** Напишите функцию `lastValue(values: number[]): number`, которая возвращает последний элемент, а для пустого массива 0. Сначала предскажите, что даст `values[values.length - 1]` для пустого массива (индекс получится -1), а затем проверьте, вызвав функцию без проверки на пустоту.

## Точные правила

* Тип массива: `T[]`, где `T` - тип элементов. Литерал: `[a, b, c]`. Пустой массив: `[]`; тип ему нужно указать (`const xs: number[] = []`).
* Индексы начинаются с 0 и идут до `length - 1`. Индекс последнего элемента - `values.length - 1`.
* `values.length` - число элементов, всегда целое, не меньше нуля.
* `values.push(x)` добавляет `x` в конец и возвращает новую длину. Тип `x` должен совпадать с типом элементов (иначе `TS2345`).
* `values[i] = x` заменяет существующий элемент; присвоение индексу за пределами длины расширяет массив и оставляет «дыры»: так не пишут.
* Чтение за границами (`values[10]`, `values[-1]`) не ошибка: результат `undefined`. Тип выражения при этом остаётся `number`, и ошибку нужно предупреждать проверкой индекса. Безопасное чтение с возможным отсутствием - урок про необязательные значения.
* Массив - **ссылочное** значение: `const copy = prices;` не создаёт новый массив, а даёт второе имя тому же. Изменение через `copy.push(40)` видно и через `prices`.
* `const` защищает переменную от переприсваивания, но не содержимое массива. Если нужно менять массив, `const` всё равно подходит; `let` нужен, только если переменной будут присваивать другой массив.
* Тип элементов нельзя смешивать: `[10, "20"]` в `number[]` - ошибка `TS2322`.
* `pop()` убирает и возвращает последний элемент (для пустого массива даёт `undefined`).
* Индекс - целое число. `values[1.5]` не даёт элемента (результат `undefined`).

## Типичные ошибки

**1. Элемент не того типа.**

```typescript
const prices: number[] = [10, "20", 30];
console.log(prices);
```

```text
main.ts(1,31): error TS2322: Type 'string' is not assignable to type 'number'.
```

«Нельзя присвоить строку там, где ожидается число»: во втором элементе лежит строка `"20"`. Число 31 в сообщении - позиция в строке, где стоит ошибочный элемент.

**2. `push` со значением другого типа.**

```typescript
const prices: number[] = [10, 20, 30];
prices.push("40");
console.log(prices);
```

```text
main.ts(2,13): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Метод `push` ожидает число (параметр), а получил строку (аргумент). Массив чисел принимает только числа.

**3. Опечатка в `length`.**

```typescript
const prices: number[] = [10, 20, 30];
console.log(prices.lenght);
```

```text
main.ts(2,20): error TS2551: Property 'lenght' does not exist on type 'number[]'. Did you mean 'length'?
```

У массива нет свойства `lenght`. Проверка предлагает вариант с похожим именем: так легко находить опечатки.

**4. Переприсвоение `const`.**

```typescript
const prices: number[] = [10, 20, 30];
prices = [1, 2];
```

```text
main.ts(2,1): error TS2588: Cannot assign to 'prices' because it is a constant.
```

Изменять содержимое массива можно (`push`, `prices[0] = 5`), а присвоить переменной новый массив - нет.

**5. Массив вместо числа.**

```typescript
const prices: number[] = [10, 20, 30];
const total: number = prices;
```

```text
main.ts(2,7): error TS2322: Type 'number[]' is not assignable to type 'number'.
```

Массив чисел и число - разные типы. Чтобы получить число из массива, нужно взять элемент (`prices[0]`) или посчитать итог циклом.

**6. Выход за границу.** Цикл `for (let i = 0; i <= values.length; i++)` обращается к `values[values.length]`, которого нет. Тип подсказки не даст: ошибка проявится как `undefined` или `NaN` в результате. Для индексов правильная пара - `i = 0; i < values.length`.

**7. Номер вместо индекса.** «Третий элемент» имеет индекс 2, а не 3. Если нужен элемент «номер n по счёту, считая с единицы», берите `values[n - 1]`.

<!-- section: summary -->
## Итоги

* Массив хранит упорядоченные значения одного типа; тип записывается `T[]`, например `number[]`.
* Индексы идут с нуля: первый элемент `values[0]`, последний `values[values.length - 1]`.
* `length` - число элементов, `push` добавляет в конец, `values[i] = x` заменяет элемент.
* `const` не мешает менять содержимое массива, но запрещает присвоить другой массив.
* Чтение за границами даёт `undefined` без ошибки типов: индекс нужно проверять самому.
* Присваивание `copy = prices` даёт второе имя тому же массиву, а не копию.

Индексный цикл удобен, но есть более короткий способ пройти по всем элементам: [Обход массива](lesson:typescript.from-zero.iterating-arrays).

## Для тех, кто уже программирует

* Массивы TypeScript - это массивы JavaScript: динамические, размер меняется, `push` добавляет за константное амортизированное время. Тип `number[]` - то же, что `Array<number>`.
* Индексация за границами не бросает исключение (в отличие от Java, C#, Python, Go) и даёт `undefined`. Тип `arr[i]` при этом `number`, а не `number | undefined`: опция `noUncheckedIndexedAccess` не входит в `strict`. Безопасное чтение - `arr.at(i)`, о нём в уроке про необязательные значения.
* Массив - ссылочное значение: `b = a` не копирует, `a === b` сравнивает ссылки, а не содержимое.
* Отрицательный индекс не отсчитывает с конца (в отличие от Python): `arr[-1]` - это `undefined`; для конца есть `arr.at(-1)`.
* Типы стираются: во время работы `number[]` ничего не проверяет. Данные извне (JSON, ввод) попадают в такой массив без проверки.
* Кортежи и многомерные массивы (`number[][]`) в этом курсе не используются.
