## Зачем нужен обход «по значениям»

Чаще всего с массивом делают одно: берут элементы по очереди и что-то с ними считают - складывают, ищут наибольший, проверяют каждый. Индексный цикл `for (let i = 0; i < values.length; i++)` для этого годится, но в нём много служебных деталей: счётчик, граница, запись `values[i]`. Каждая деталь - место для ошибки, например `<=` вместо `<`. Если индекс не нужен, ту же работу делает короткий цикл `for...of`.

## Одна новая идея: `for...of` отдаёт элементы по одному

```text
for (const элемент of массив) {
  тело
}
```

Читается «для каждого элемента из массива». Переменная `элемент` на каждой итерации получает очередное значение, начиная с первого. Ни счётчика, ни границы писать не нужно: цикл сам заканчивается после последнего элемента. Переменную объявляют через `const`: внутри одной итерации значение не меняется, а на следующей создаётся новая. Тип переменной проверка выводит из типа массива: для `number[]` это `number`.

Когда нужен ещё и номер элемента (напечатать «1. хлеб», найти позицию), используют индексный цикл `for (let i = 0; i < values.length; i++)`. Правило выбора: **не нужен индекс - `for...of`; нужен - индексный `for`**.

<!-- section: examples -->
## Пример 1. По очереди

```typescript run
const names: string[] = ["хлеб", "молоко", "сыр"];

for (const name of names) {
  console.log("Купить:", name);
}
```
```output
Купить: хлеб
Купить: молоко
Купить: сыр
```

На первой итерации `name` равно `"хлеб"`, на второй `"молоко"`, на третьей `"сыр"`. После последнего элемента цикл заканчивается сам.

## Пример 2. Сумма и среднее

```typescript run
function sumOf(values: number[]): number {
  let total: number = 0;
  for (const v of values) {
    total = total + v;
  }
  return total;
}

function average(values: number[]): number {
  if (values.length === 0) {
    return 0;
  }
  return sumOf(values) / values.length;
}

const grades: number[] = [5, 4, 5, 3];
console.log(sumOf(grades), average(grades), average([]));
```
```output
17 4.25 0
```

Накопитель `total` объявлен до цикла, а элементы прибавляются по одному. Среднее равно сумме, делённой на число элементов. Для пустого массива делить на `length` равный нулю нельзя: результат был бы `NaN`, поэтому случай обработан отдельно. Одна функция (`average`) вызывает другую (`sumOf`): так сложные задачи собирают из простых.

## Пример 3. Наибольшее значение

```typescript run
function maxOf(values: number[]): number {
  if (values.length === 0) {
    return 0;
  }
  let best: number = values[0];
  for (const v of values) {
    if (v > best) {
      best = v;
    }
  }
  return best;
}

console.log(maxOf([3, 9, 4]), maxOf([-5, -2, -9]), maxOf([]));
```
```output
9 -2 0
```

Идея поиска наибольшего: запомнить первый элемент как «лучший на сейчас», а затем для каждого элемента проверить, не больше ли он, и если да - запомнить его. Начинать с `0` нельзя: для массива `[-5, -2, -9]` ни один элемент не больше нуля, и функция неверно вернула бы 0. Начальное значение берут из самих данных. Для пустого массива `values[0]` не существует, поэтому он разобран до цикла.

## Пример 4. Когда нужен индекс

```typescript run
const items: string[] = ["хлеб", "молоко", "сыр"];
for (let i: number = 0; i < items.length; i++) {
  console.log(`${i + 1}. ${items[i]}`);
}

function indexOfValue(values: number[], target: number): number {
  for (let i: number = 0; i < values.length; i++) {
    if (values[i] === target) {
      return i;
    }
  }
  return -1;
}

console.log(indexOfValue([7, 3, 9, 3], 3), indexOfValue([7, 3, 9], 4));
```
```output
1. хлеб
2. молоко
3. сыр
1 -1
```

Нумерованный список требует номера, поэтому тут индексный цикл: `i + 1` превращает индекс в номер, начинающийся с единицы. В `indexOfValue` `return` внутри цикла сразу завершает функцию: найден первый подходящий элемент, дальше искать незачем. Если цикл закончился без находки, возвращается `-1`: так принято обозначать «не найдено», потому что такого индекса не бывает.

**Попробуйте.** Напишите функцию `countAbove(values: number[], limit: number): number`, которая считает элементы строго больше `limit`. Затем перепишите `sumOf` с индексным циклом и убедитесь, что результат не изменился.

## Точные правила

* Форма: `for (const x of массив) { тело }`. В `x` попадает каждый элемент по порядку, от первого до последнего.
* Тип `x` выводится из типа массива: `string` для `string[]`, `number` для `number[]`. Аннотацию писать не нужно.
* Цикл не выполняется, если массив пуст; ошибки при этом нет.
* `const x` неизменяема внутри итерации. Присвоение `x = ...` - ошибка `TS2588`. Даже с `let x` присвоение меняет только копию значения, а не элемент массива.
* `for...of` работает не только с массивами, но и со строками (по символам) и другими перебираемыми значениями; для числа или объекта проверка сообщает `TS2488`.
* `break`, `continue` и `return` внутри `for...of` работают так же, как в других циклах.
* Индексный цикл нужен, когда нужен номер элемента или требуется заменить элемент: `values[i] = ...`.
* Не добавляйте и не удаляйте элементы массива, по которому идёте циклом: результат трудно предсказать.
* Поиск максимума и минимума начинают с первого элемента, а не с 0 или другого числа «наугад», и обрабатывают пустой массив отдельно.
* Результат «не найдено» для позиции обозначают числом `-1`: допустимые индексы неотрицательны.

## Типичные ошибки

**1. Перебор не массива.**

```typescript
for (const n of 5) {
  console.log(n);
}
```

```text
main.ts(1,17): error TS2488: Type '5' must have a '[Symbol.iterator]()' method that returns an iterator.
```

Цикл `for...of` перебирает коллекцию, а `5` - одно число. Сообщение говорит на языке внутреннего устройства («метод итератора»), но смысл простой: справа от `of` должно стоять что-то, из чего можно брать значения по очереди.

**2. Попытка изменить элемент через `const`.**

```typescript
const nums: number[] = [1, 2, 3];
for (const n of nums) {
  n = n * 2;
}
```

```text
main.ts(3,3): error TS2588: Cannot assign to 'n' because it is a constant.
```

Чтобы удвоить элементы массива, нужен индексный цикл `nums[i] = nums[i] * 2`. Если написать `for (let n of nums) { n = n * 2; }`, ошибки не будет, но массив не изменится: `n` - копия значения.

**3. Тип накопителя не подходит к элементам.**

```typescript
const words: string[] = ["a", "b"];
let total: number = 0;
for (const w of words) {
  total = total + w;
}
```

```text
main.ts(4,3): error TS2322: Type 'string' is not assignable to type 'number'.
```

Число плюс строка даёт строку, а `total` объявлена числом. Сумму можно накапливать только по числовому массиву; для строк накопитель тоже должен быть строкой.

**4. Переменная цикла использована снаружи.**

```typescript
const nums: number[] = [-5, -2, -9];
for (const n of nums) {
  console.log(n);
}
console.log(n);
```

```text
main.ts(5,13): error TS2304: Cannot find name 'n'.
```

Переменная `n` существует только внутри цикла. Результат, нужный потом, накапливайте в переменной, объявленной до цикла.

**5. Максимум с нулевым началом.**

```typescript
const nums: number[] = [-5, -2, -9];
let max: number = 0;
for (const n of nums) {
  if (n > max) {
    max = n;
  }
}
console.log(max);
```

Программа напечатает `0`, хотя нуля в данных нет: ни один элемент не больше начального значения. Ошибки типов нет, и запуск проходит без сообщений. Начинайте с первого элемента массива.

**6. Деление на нулевую длину.** `sum / values.length` для пустого массива даёт `NaN` (при нулевой сумме `0 / 0`), а при ненулевой - бесконечность. Проверяйте `values.length === 0` до деления.

## Итоги

* `for (const x of массив)` перебирает элементы по очереди; индекс и граница не нужны.
* Если нужен номер элемента или надо заменить элемент, используйте индексный цикл `for (let i = 0; i < values.length; i++)`.
* Сумму, количество, максимум получают накопителем, объявленным до цикла.
* Максимум и минимум начинают с первого элемента, а не с нуля; пустой массив обрабатывают отдельно.
* `return` внутри цикла завершает функцию; «не найдено» обозначают `-1`.
* Переменная цикла существует только внутри него и не меняет массив.

Часто действие над каждым элементом хочется передать как параметр: например, «удвоить» или «оставить чётные». Для этого нужны функции, которые можно передавать как значения: [Стрелочные функции](lesson:typescript.from-zero.arrow-functions).

## Для тех, кто уже программирует

* `for...of` соответствует `for (x : xs)` в Java, `foreach` в C#, `for x in xs` в Python и `for _, x := range xs` в Go (в Go первым идёт индекс).
* Не путайте с `for...in`: он перебирает **ключи** (для массива - индексы как строки) и в курсе не используется.
* Для индекса вместе со значением есть `for (const [i, x] of xs.entries())`; пока достаточно индексного цикла.
* `for...of` работает через протокол итератора (`Symbol.iterator`): по строкам, множествам, словарям `Map`. Отсюда сообщение `TS2488`.
* Изменение массива во время обхода допустимо технически, но порядок обхода и результат рискованно зависят от операций; обычно собирают новый массив.
* Среднее по пустому массиву в JavaScript даёт `NaN`, а не исключение (в отличие от Python или Java при целочисленном делении).
