## Зачем нужны циклы

Многие задачи требуют повторения: пересчитать все товары в чеке, сложить расходы за месяц, напечатать числа от 1 до 100. Писать сто одинаковых команд вручную нелепо, и к тому же заранее неизвестно, сколько повторений понадобится. Для этого есть **циклы**: команда, которая выполняет один и тот же блок много раз.

## Одна новая идея: `while` повторяет блок, пока условие истинно

Цикл `while` («пока») выглядит как `if`, но блок выполняется не один раз:

```text
while (условие) {
  команды
}
```

Работает он так:

1. Проверяется условие.
2. Если оно истинно, выполняется блок целиком, и программа возвращается к шагу 1.
3. Если оно ложно, цикл заканчивается, и выполняется следующая команда после блока.

Один проход блока называется **итерацией**. Условие проверяется **перед** каждой итерацией, поэтому цикл может не выполниться ни разу.

Чтобы цикл когда-нибудь закончился, что-то внутри блока должно менять данные так, чтобы условие в конце концов стало ложным. Обычно для этого заводят переменную-**счётчик**: она считает итерации и меняется на каждой. Вторая типичная переменная - **накопитель**: в ней собирается результат (сумма, количество). Обе объявляют **до** цикла через `let` (их значения меняются) и меняют внутри.

<!-- section: examples -->
## Пример 1. Счётчик

```typescript run
let i: number = 1;
while (i <= 5) {
  console.log(i);
  i = i + 1;
}
console.log("Готово");
```
```output
1
2
3
4
5
Готово
```

Разбор по шагам:

* `let i: number = 1;` - счётчик, начальное значение 1.
* `i <= 5` - условие: пока `i` не больше пяти, цикл продолжается.
* `console.log(i);` - действие итерации.
* `i = i + 1;` - **обновление счётчика**: без этой строки `i` всегда равнялось бы 1, и цикл не завершился бы никогда.
* После пятой итерации `i` становится 6, условие ложно, цикл заканчивается, печатается «Готово».

## Пример 2. Накопитель

```typescript run
let total: number = 0;
let n: number = 1;
while (n <= 4) {
  total = total + n;
  n = n + 1;
}
console.log(total, n);
```
```output
10 5
```

В `total` собирается сумма: итерации добавляют 1, 2, 3 и 4. Начальное значение накопителя для суммы - 0: нейтральное число, которое не меняет результат. Обратите внимание на `n`: после последней итерации оно равно 5, а не 4 - оно увеличилось, и только после этого условие стало ложным.

## Пример 3. Сколько дней копить

```typescript run
function daysToSave(goal: number, perDay: number): number {
  let saved: number = 0;
  let days: number = 0;
  while (saved < goal) {
    saved = saved + perDay;
    days = days + 1;
  }
  return days;
}

console.log(daysToSave(1000, 300), daysToSave(900, 300), daysToSave(0, 300));
```
```output
4 3 0
```

Заранее число итераций неизвестно: оно зависит от цели и от суммы в день, и именно для таких задач `while` удобнее всего. Для цели 1000 при 300 в день накопления идут так: 300, 600, 900, 1200, и только после четвёртого дня `saved < goal` становится ложным. Для цели 900 накопление после третьего дня равно ровно 900, а `900 < 900` ложно, поэтому хватает трёх дней. Для цели 0 условие ложно сразу, тело не выполняется ни разу, и функция возвращает 0, без особой ветки.

Переменные `saved` и `days` объявлены **внутри** функции до цикла. Если объявить их внутри блока цикла, на каждой итерации они создавались бы заново с нулевыми значениями.

## Пример 4. Отсчёт вниз и разбор числа по цифрам

```typescript run
function countDigits(n: number): number {
  if (n === 0) {
    return 1;
  }
  let digits: number = 0;
  let rest: number = n;
  while (rest > 0) {
    rest = Math.floor(rest / 10);
    digits = digits + 1;
  }
  return digits;
}

console.log(countDigits(7), countDigits(2025), countDigits(100), countDigits(0));

let left: number = 3;
while (left > 0) {
  console.log(left);
  left = left - 1;
}
console.log("Старт!");
```
```output
1 4 3 1
3
2
1
Старт!
```

Счётчик не обязан расти: во втором цикле он уменьшается до нуля. В `countDigits` на каждой итерации последняя цифра отбрасывается: `Math.floor(2025 / 10)` равно 202, затем 20, затем 2, затем 0. Число итераций и есть количество цифр. Число 0 разобрано отдельным `if`: для него условие `rest > 0` ложно сразу, и цикл насчитал бы 0 цифр, а в записи нуля одна цифра.

**Попробуйте.** Измените в примере 1 условие на `i < 5` и предскажите вывод до запуска. Затем напишите функцию `factorial(n: number): number`, которая перемножает числа от 1 до `n` (для 4 это 24). Начальное значение накопителя здесь должно быть 1, а не 0: подумайте, почему.

## Точные правила

* Форма: `while (условие) { тело }`. Условие в круглых скобках, тело в фигурных; условие даёт значение `boolean`.
* Условие проверяется перед каждой итерацией, включая первую. Если оно ложно с самого начала, тело не выполняется ни разу.
* Условие проверяется только между итерациями: если счётчик стал «неправильным» посередине блока, остаток блока всё равно выполнится.
* Если тело не делает условие в конце концов ложным, цикл **бесконечный**. Проверка типов этого не обнаруживает; такая программа зависает, и её приходится останавливать кнопкой «Стоп» или по таймауту.
* Счётчик и накопитель объявляют через `let` **до** цикла. Переменную `const` в цикле изменить нельзя (`TS2588`).
* Переменные, объявленные внутри блока, существуют только внутри него и создаются заново на каждой итерации.
* Типовой шаблон: начальное значение, условие, действие, обновление. Если забыть любое из четырёх, цикл либо не заработает, либо не закончится.
* Граница `<` или `<=` определяет, участвует ли последнее значение. Для «от 1 до n включительно» нужно `i <= n`.
* Начальное значение накопителя - нейтральный элемент операции: 0 для суммы, 1 для произведения.
* Внутри цикла можно использовать `if` и `return`. `return` внутри цикла в функции завершает всю функцию сразу, не доводя цикл до конца.

## Типичные ошибки

**1. Забыли обновить счётчик.**

```typescript
let count: number = 5;
while (count > 0) {
  console.log(count);
}
```

Проверка типов ничего не сообщает: код допустим. Но `count` не меняется, условие `5 > 0` истинно всегда, и программа печатает пятёрку, пока её не остановят. Это **бесконечный цикл**. Если программа «зависла» и печатает одно и то же, первым делом проверьте, меняется ли внутри цикла то, от чего зависит условие. Исправление: добавить `count = count - 1;` в тело.

**2. Обновление идёт не в ту сторону.** Счётчик уменьшается, а условие ждёт, что он вырастет (или наоборот): `let i = 1; while (i < 10) { i = i - 1; }`. Условие остаётся истинным и цикл бесконечен. Определите, к какому значению должен идти счётчик.

**3. Ошибка на единицу.**

```typescript
let i: number = 1;
let total: number = 0;
while (i < 5) {
  total = total + i;
  i = i + 1;
}
console.log(total);
```

Нужно сложить числа от 1 до 5, но программа печатает 10, а не 15: из-за `i < 5` пятёрка в сумму не попала. Ошибки не видит ни проверка типов, ни выполнение. Помогает проверка на маленьком примере: выпишите, какие значения принимает счётчик, и убедитесь, что в них входит последнее нужное.

**4. Попытка изменить `const`.**

```typescript
const i: number = 1;
while (i <= 3) {
  console.log(i);
  i = i + 1;
}
```

```text
main.ts(4,3): error TS2588: Cannot assign to 'i' because it is a constant.
```

«Нельзя присвоить `i`, потому что это константа». Счётчик меняется, поэтому объявляйте его через `let`.

**5. Забыли скобки вокруг условия.**

```typescript
let i: number = 1;
while i <= 3 {
  i = i + 1;
}
```

```text
main.ts(2,7): error TS1005: '(' expected.
main.ts(2,14): error TS1005: ')' expected.
```

Так же, как у `if`, условие `while` обязательно стоит в круглых скобках.

**6. Переменная объявлена внутри блока, а используется снаружи.**

```typescript
let total: number = 0;
let i: number = 1;
while (i <= 3) {
  let step: number = i * 2;
  total = total + step;
  i = i + 1;
}
console.log(total, step);
```

```text
main.ts(8,20): error TS2304: Cannot find name 'step'.
```

Переменная `step` существует только в блоке цикла. Нужное снаружи значение накапливайте в переменной, объявленной до цикла.

## Итоги

* `while (условие) { ... }` повторяет блок, пока условие истинно; условие проверяется перед каждой итерацией, поэтому тело может не выполниться ни разу.
* Типичная заготовка: счётчик и накопитель объявляются через `let` до цикла, внутри блока выполняется действие и обновляется счётчик.
* Если в теле ничего не приближает условие к ложности, цикл бесконечен; типы этого не ловят.
* `<` против `<=` решает, войдёт ли последнее значение в результат: проверяйте границы на маленьких примерах.
* Начальное значение накопителя - 0 для суммы, 1 для произведения.
* Цикл вместе с `if` и функциями позволяет решать задачи, где число действий заранее неизвестно.

Этот урок завершает первую часть курса: вы умеете хранить значения, сравнивать их, выбирать и повторять действия внутри функций. Когда число повторений известно заранее, счётчик, условие и обновление удобнее записать в одну строку: [Цикл for](lesson:typescript.from-zero.for-loop).

## Для тех, кто уже программирует

* `while` работает так же, как в Java, C#, JavaScript и Go (в Go его роль играет `for` с одним условием). В Python тот же цикл без скобок и с двоеточием.
* Есть `do { ... } while (условие);` с проверкой после тела, но в курсе он не используется.
* Скобки вокруг условия обязательны (в отличие от Go и Python).
* Инкремент `i++` и составные присваивания (`+=`) в TypeScript есть; в этом курсе пока пишется явное `i = i + 1`, чтобы видна была суть.
* Тип `number` - это число с плавающей точкой: счётчик типа `0.1`, увеличиваемый на `0.1`, накапливает погрешность, поэтому условие вида `x === 1` для дробных счётчиков ненадёжно. Для счётчиков используйте целые числа.
* `tsc` не пытается доказать завершение цикла: бесконечный `while (true)` допустим.
* Переменные в блоке (`let`) ограничены блоком, как в Java и C#, а не функцией, как у устаревшего `var`.
