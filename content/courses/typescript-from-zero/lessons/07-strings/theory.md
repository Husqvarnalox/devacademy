## Зачем это нужно

Приветствие с именем, строка чека, сообщение «Осталось 3 шт.» - почти любой вывод программы собирается из постоянного текста и значений переменных. Нужно уметь соединять части в одну строку и узнавать, сколько в ней символов.

## Одна новая идея: строку можно собрать из частей

Есть два способа собрать строку:

* **Склейка** (конкатенация) оператором `+`: `"Привет, " + name` берёт текст слева и справа и соединяет их в один. Пробелы вставляйте сами: компьютер ничего не добавляет.
* **Шаблонная строка** записывается в **обратных кавычках** `` ` ` ``, а значения вставляются в неё через `${...}`: `` `Привет, ${name}!` ``. Внутри фигурных скобок может стоять любое выражение, результат превратится в текст и встанет на место. Шаблон читается как готовая фраза, и пропущенный пробел сразу виден.

Длина строки в символах хранится в её свойстве **`length`**: `"Привет".length` равно `6`. Свойство пишется через точку после значения и без скобок.

Оператор `+` работает по-разному в зависимости от значений: два числа он складывает, а если хотя бы одно значение текст - склеивает. Поэтому `2 + 3` равно `5`, а `"2" + "3"` равно `"23"`.

<!-- section: examples -->
## Пример 1. Склейка

```typescript run
const first = "Анна";
const last = "Петрова";
console.log(first + " " + last);
```
```output
Анна Петрова
```

Разбор: три части - имя, пробел в кавычках, фамилия. Без пробела получилось бы «АннаПетрова».

## Пример 2. Шаблонная строка

```typescript run
const first = "Анна";
console.log(`Привет, ${first}!`);
console.log(`Сумма: ${2 + 3}`);
```
```output
Привет, Анна!
Сумма: 5
```

Разбор: строка в обратных кавычках. В первой подставлена переменная, во второй вычислено выражение. Текст вокруг `${...}` остаётся как есть.

## Пример 3. Длина строки

```typescript run
const word = "Привет";
console.log(word.length, "".length, "a b".length);
```
```output
6 0 3
```

Разбор: в слове шесть символов, в пустой строке `""` - ноль, в `"a b"` три, потому что пробел тоже символ.

## Пример 4. Число и текст в `+`

```typescript run
const qty = 3;
console.log("Куплено: " + qty + " шт.");
console.log("2" + 3, 2 + 3, "2" + "3");
console.log(2 + 3 + "4", "4" + 2 + 3);
```
```output
Куплено: 3 шт.
23 5 23
54 423
```

Разбор: при склейке число превращается в текст. Выражение вычисляется слева направо: в `2 + 3 + "4"` сначала сложились числа (5), потом пришла склейка (`"54"`); в `"4" + 2 + 3` склейка идёт с самого начала, и получается `"423"`. Эту путаницу даёт смешивание чисел и текста в одном `+`; шаблонные строки её не создают.

## Пример 5. Кавычки внутри строки

```typescript run
console.log("Он сказал: \"привет\"");
console.log('Книга "Война и мир"');
console.log("Первая строка\nВторая строка");
```
```output
Он сказал: "привет"
Книга "Война и мир"
Первая строка
Вторая строка
```

Разбор: чтобы поставить внутрь двойных кавычек такую же, перед ней пишут обратную косую черту `\"`; либо берут другие внешние кавычки. Сочетание `\n` означает переход на новую строку.

**Попробуйте.** Соберите в шаблонной строке фразу «Вам 25 лет» из переменной `age`. Затем сделайте то же самое склейкой и сравните, где проще не забыть пробелы.

<!-- section: precise -->
## Точные правила

* Строки записывают в `"..."`, `'...'` или `` `...` ``. Подстановки `${выражение}` работают только в обратных кавычках; в остальных `${` - обычные символы.
* Оператор `+`: если обе стороны числа - сложение, если хотя бы одна строка - склейка (число становится текстом). Результат склейки - `string`.
* Склейка вычисляется слева направо вместе с остальными `+`.
* `s.length` - число символов (точнее, кодовых единиц). Для обычных слов, включая кириллицу, это число букв. Скобок у `length` нет - это свойство, а не вызов.
* `"".length` равно `0`: пустая строка допустима.
* Внутри строки: `\"` - двойная кавычка, `\'` - одинарная, `\\` - обратная косая черта, `\n` - перенос строки.
* Шаблонная строка может занимать несколько строк: переносы внутри обратных кавычек становятся частью текста.
* Арифметика над текстом отвергается (`TS2362`), кроме `+`.

## Типичные ошибки

**1. Опечатка в `length`.**

```typescript
let name = "Анна";
console.log(name.lenght);
```

```text
main.ts(2,18): error TS2551: Property 'lenght' does not exist on type 'string'. Did you mean 'length'?
```

«У строки нет свойства `lenght`. Вы имели в виду `length`?» Такие опечатки в языке без проверки типов дали бы молчаливое `undefined`, а TypeScript находит их до запуска.

**2. Скобки у `length`.**

```typescript
let name = "Анна";
console.log(name.length());
```

```text
main.ts(2,18): error TS2349: This expression is not callable.
  Type 'Number' has no call signatures.
```

`length` - число, а скобки означают «вызвать». Число вызывать нельзя. Уберите скобки.

**3. Забыли `+` между частями.**

```typescript
const name = "Анна";
console.log("Привет, " name);
```

```text
main.ts(2,24): error TS1005: ',' expected.
```

Между двумя значениями нет ни `+`, ни запятой. Проверка ждала запятую, потому что внутри скобок `console.log` значения разделяют запятыми.

**4. Забыли про пробелы.** `"Итого:" + total` даёт `Итого:450`. Пробел нужно вставить в текст: `"Итого: " + total`.

**5. Подстановка в обычных кавычках.**

```typescript
const total = 50;
console.log('Итого: ${total}');
```

Проверка молчит, а программа печатает `Итого: ${total}`. Подстановка работает только в обратных кавычках: `` `Итого: ${total}` ``. Эту ошибку проверка не видит, потому что сама строка допустима: смотрите на вывод.

**6. Незакрытая скобка в подстановке.**

```typescript
const total = 5;
console.log(`Итого: ${total);
```

```text
main.ts(2,28): error TS1005: '}' expected.
```

Каждой `${` нужна пара `}`.

## Итоги

* Строку собирают склейкой `+` или шаблоном `` `текст ${значение}` ``; шаблон читается проще.
* `+` складывает числа и склеивает, если среди значений есть текст; вычисление идёт слева направо.
* `s.length` - число символов (без скобок); пустая строка имеет длину 0.
* Подстановка работает только в обратных кавычках; опечатки в именах свойств проверка находит до запуска.

## Для тех, кто уже программирует

* Шаблонные строки - аналог f-строк Python, интерполяции C# (`$"..."`) и `fmt.Sprintf`; выражение внутри `${}` произвольное.
* `+` перегружен как в Java: числа складываются, со строкой склеивается. Неявное превращение числа в текст при склейке допускает и `tsc`, а `"5" * 2` отвергает.
* Строки неизменяемы, как в Java, C# и Python.
* `length` измеряет кодовые единицы UTF-16, не символы Юникода: эмодзи даёт 2. Для кириллицы совпадает с числом букв.
* Свойства без скобок (`s.length`), методы со скобками (`s.trim()`), как в Java для массивов; в отличие от Python, нет `len(s)`.
* `tsc` знает все свойства `string` и ловит опечатки (`TS2551`).
