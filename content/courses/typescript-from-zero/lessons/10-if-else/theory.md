## Зачем нужны условия

До сих пор программа выполняла все команды подряд, сверху вниз. Реальные задачи устроены иначе: «если товар есть на складе - продать, иначе - предложить замену», «если возраст меньше 7 лет - билет бесплатный». Решение зависит от данных, а значит, программа должна уметь выбирать, какие команды выполнить.

## Одна новая идея: `if` выполняет блок, только если условие истинно

Команда `if` (по-русски «если») состоит из **условия** в круглых скобках и **блока** в фигурных скобках:

```text
if (условие) {
  команды, которые выполняются, когда условие истинно
}
```

**Условие** - это выражение типа `boolean`, то есть такое, которое даёт `true` или `false`. Такие выражения вы уже строили в уроке про сравнение: `age >= 18`, `stock > 0 && price < 100`. **Блок** - это группа команд между `{` и `}`. Если условие даёт `true`, команды блока выполняются, если `false` - блок пропускается целиком, и программа идёт дальше.

К `if` можно добавить запасной вариант `else` («иначе»): его блок выполняется, когда условие ложно. А если вариантов больше двух, между ними ставят `else if` («иначе если»): проверки идут сверху вниз, и выполняется блок первой, которая оказалась истинной.

<!-- section: examples -->
## Пример 1. Только `if`

```typescript run
const temperature: number = -5;
if (temperature < 0) {
  console.log("Мороз");
}
console.log("Конец");
```
```output
Мороз
Конец
```

Условие `-5 < 0` истинно, поэтому печатается «Мороз». Команда `console.log("Конец")` стоит **после** блока, а не внутри него, и выполняется всегда. Замените `-5` на `10`: «Мороз» пропадёт, «Конец» останется.

## Пример 2. `if` и `else`

```typescript run
const stock: number = 0;
if (stock > 0) {
  console.log("Есть в наличии");
} else {
  console.log("Нет в наличии");
}
```
```output
Нет в наличии
```

Выполняется ровно один из двух блоков: либо первый, либо второй. Здесь `0 > 0` ложно, поэтому сработал `else`.

## Пример 3. Цепочка `else if`

```typescript run
const score: number = 78;
if (score >= 90) {
  console.log("Отлично");
} else if (score >= 75) {
  console.log("Хорошо");
} else if (score >= 50) {
  console.log("Удовлетворительно");
} else {
  console.log("Неудовлетворительно");
}
```
```output
Хорошо
```

Разбор: `78 >= 90` ложно, переходим дальше; `78 >= 75` истинно - печатаем «Хорошо» и **пропускаем всё остальное**, даже условие `score >= 50`, которое тоже было бы истинным. Поэтому порядок проверок важен: сначала самое строгое условие, затем более мягкие. Блок `else` в конце не обязателен; он ловит всё, что не подошло ни под одно условие.

## Пример 4. `return` внутри условий

```typescript run
function ticketPrice(age: number): number {
  if (age < 7) {
    return 0;
  }
  if (age < 18) {
    return 150;
  }
  if (age >= 65) {
    return 100;
  }
  return 300;
}

console.log(ticketPrice(5), ticketPrice(12), ticketPrice(30), ticketPrice(70));
```
```output
0 150 300 100
```

Функция из урока 9 теперь выбирает результат. Команда `return` завершает функцию немедленно, поэтому после `return 0;` остальные проверки для пятилетнего ребёнка не выполняются. Благодаря этому `else` здесь не нужен: когда мы дошли до `if (age < 18)`, возраст уже точно не меньше 7. Строка `return 300;` в конце срабатывает для всех, кто не попал в предыдущие условия. Запись с `else if` дала бы тот же результат; выбирайте ту, что читается проще.

## Пример 5. Условие - это просто булево значение

```typescript run
function isAdult(age: number): boolean {
  return age >= 18;
}

console.log(isAdult(17), isAdult(18));

function isLeapYear(year: number): boolean {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

console.log(isLeapYear(2024), isLeapYear(1900), isLeapYear(2000));
```
```output
false true
true false true
```

Когда функция должна вернуть `true` или `false`, `if` часто не нужен: достаточно вернуть само условие. Запись `if (age >= 18) { return true; } else { return false; }` работает, но длиннее. Високосный год делится на 4, но не на 100, либо делится на 400; скобки показывают порядок: сначала `&&`, затем `||`.

## Пример 6. Два независимых `if` и цепочка - разные вещи

```typescript run
let x: number = 10;
if (x > 5) {
  x = x - 5;
}
if (x > 3) {
  x = x - 3;
}
console.log(x);
```
```output
2
```

Здесь два отдельных `if`: после первого `x` равен 5, и второе условие `5 > 3` тоже истинно. Если бы вторая проверка была `else if`, она не выполнилась бы, и ответ был бы 5. Цепочка нужна, когда варианты **взаимоисключающие**, а отдельные `if` - когда проверки независимы.

**Попробуйте.** Напишите функцию `sign(n: number): string`, возвращающую `"плюс"`, `"минус"` или `"ноль"`, и вызовите её для 5, -3 и 0. Затем уберите ветку `else` и посмотрите, что скажет проверка (раздел об ошибках).

## Точные правила

* Форма: `if (условие) { ... }`, затем по желанию любое число `else if (условие) { ... }` и в конце не более одного `else { ... }`.
* Условие стоит в круглых скобках и должно давать значение типа `boolean`. Скобки обязательны.
* Тело записывают в фигурных скобках, даже если в нём одна команда. Без фигурных скобок язык допускает одну команду, но так легко добавить вторую и получить не то, что задумано; в курсе скобки ставятся всегда.
* Проверки выполняются сверху вниз до первой истинной. Остальные ветки не выполняются и их условия не вычисляются.
* Выполняется не больше одного блока цепочки. Если ни одно условие не истинно и нет `else`, не выполняется ни один.
* Переменная, объявленная через `let` или `const` внутри блока, существует только внутри этого блока. Снаружи её имя неизвестно.
* Функция с типом результата `number`, `string` или `boolean` обязана вернуть значение **на любом пути**. Если `if` без `else` не покрывает все случаи, проверка сообщает `TS2366`.
* Условие `7 <= age <= 17` писать нельзя: сравнения вычисляются по очереди, и второе сравнивает уже `boolean` с числом (`TS2365`). Пишите `age >= 7 && age <= 17`.
* Крайние значения диапазонов - главное место ошибок: `<` против `<=` меняет результат ровно на одной границе. Проверяйте значения на самой границе и рядом с ней.

## Типичные ошибки

**1. Не на всех путях есть `return`.**

```typescript
function sign(n: number): string {
  if (n > 0) {
    return "плюс";
  } else if (n < 0) {
    return "минус";
  }
}
```

```text
main.ts(1,27): error TS2366: Function lacks ending return statement and return type does not include 'undefined'.
```

«У функции нет завершающего `return`, а тип результата не допускает `undefined`». Для `n`, равного 0, ни одна ветка не сработала бы, и функция дошла бы до конца, ничего не вернув. Замените последнюю ветку на `else { return "ноль"; }` или добавьте `return` после цепочки.

**2. Забыли скобки вокруг условия.**

```typescript
const age: number = 20;
if age >= 18 {
  console.log("взрослый");
}
```

```text
main.ts(2,4): error TS1005: '(' expected.
main.ts(2,14): error TS1005: ')' expected.
```

Обе ошибки про одну строку: после `if` ожидалась открывающая скобка, а перед `{` - закрывающая. Строка и столбец указывают место, где проверка «споткнулась». Это синтаксическая ошибка, поэтому программа не запускается вовсе.

**3. Лишний `else` или забытая скобка.**

```typescript
const age: number = 20;
if (age >= 18) {
  console.log("взрослый");
}
else {
  console.log("ребёнок");
}
else {
  console.log("?");
}
```

```text
main.ts(8,1): error TS1128: Declaration or statement expected.
```

Второй `else` не к чему присоединить: у цепочки может быть только один. Если забыть закрывающую `}`, сообщение будет другим:

```text
main.ts(4,1): error TS1005: '}' expected.
```

Строка в нём указывает на конец файла, а ошибка находится выше: ищите блок, который не закрыт.

**4. Присваивание вместо сравнения.**

```typescript
let stock: number = 0;
if (stock = 5) {
  console.log("есть");
}
console.log(stock);
```

Проверка здесь ничего не сообщает, а программа печатает:

```text
есть
5
```

Одиночный `=` - это присваивание: оно кладёт 5 в `stock`, а результат выражения (5) вместо `true` или `false` считается «истинным». Условие стало всегда истинным, и товар «появился» сам. В условиях пишите `===`. Эта ошибка опасна тем, что нет ни сообщения, ни сбоя.

**5. Составное сравнение.**

```typescript
const age: number = 10;
if (7 <= age <= 17) {
  console.log("школьник");
}
```

```text
main.ts(2,5): error TS2365: Operator '<=' cannot be applied to types 'boolean' and 'number'.
```

Сначала вычисляется `7 <= age` и даёт `true` или `false`, а затем это значение сравнивается с 17. Правильно: `age >= 7 && age <= 17`.

**6. Порядок проверок в цепочке.**

```typescript
const score: number = 80;
if (score >= 50) {
  console.log("нормально");
} else if (score >= 70) {
  console.log("хорошо");
}
```

Программа печатает «нормально», хотя 80 заслуживает «хорошо»: первое условие уже истинно, и вторая ветка недостижима. Проверка ошибки не видит, потому что код допустим. Располагайте условия от самого строгого к самому мягкому.

## Итоги

* `if (условие) { ... }` выполняет блок, только если условие истинно; `else` - запасной блок; `else if` добавляет ещё варианты.
* Условие - значение типа `boolean`; сложные условия строят из сравнений и `&&`, `||`, `!`.
* Проверки идут сверху вниз до первой истинной, поэтому порядок условий важен; из цепочки выполняется не больше одного блока.
* Функция должна вернуть значение на любом пути, иначе проверка сообщает `TS2366`.
* Сравнивайте через `===`; одиночный `=` в условии - тихая ошибка. Диапазон записывают как `a >= x && a <= y`.
* Границы диапазонов проверяйте отдельно: на них чаще всего ошибаются.

Когда действие нужно повторить много раз, условий недостаточно: следующий урок посвящён циклу, который повторяет блок, пока условие истинно: [Цикл while](lesson:typescript.from-zero.while-loop).

## Для тех, кто уже программирует

* Синтаксис как в Java, C# и JavaScript: скобки вокруг условия, фигурные скобки у блока, `else if` двумя словами (в Python - `elif`).
* Формально `if` в TypeScript принимает любое значение и приводит его к «истинному» или «ложному» (число 0, пустая строка, `null`, `undefined`, `NaN` - ложные). В курсе в условиях стоят только булевы выражения.
* В отличие от Go, скобки вокруг условия обязательны.
* Тернарный оператор `условие ? a : b` существует, но в курсе не используется.
* Присваивание в условии (`if (x = 5)`) в TypeScript не считается ошибкой, в отличие от C# и Java (где тип `int` не подходит под условие); предупреждают об этом линтеры.
* `tsc` проверяет, что каждый путь возвращает значение (`TS2366`), и учитывает условия при сужении типов (урок про необязательные значения).
* `switch` в курсе пока не вводится: цепочки `else if` покрывают все задачи уровня 0.
