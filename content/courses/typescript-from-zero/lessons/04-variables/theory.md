## Зачем нужны переменные

Программе постоянно нужно запоминать: цену товара, сумму в корзине, имя покупателя. Записывать значение каждый раз заново неудобно, а менять его в десяти местах - опасно. Поэтому значению дают имя и работают с ним по имени. Такое именованное место для значения называется **переменной**.

## Одна новая идея: имя, значение и тип

Переменную **объявляют**, то есть создают, командой `const` или `let`:

```typescript
const price: number = 450;
```

Запись читается слева направо:

* `const` - слово «объявляю неизменяемую переменную»;
* `price` - **имя**: по нему мы обращаемся к значению. Имя придумываете вы: латинскими буквами, без пробелов, лучше по смыслу;
* `: number` - **аннотация типа**: пометка «в этой переменной лежат числа»;
* `= 450` - **начальное значение**;
* `;` - конец команды.

Есть две формы объявления:

* **`const`** (от constant, «постоянная») - значение нельзя заменить. Подходит для всего, что после задания не меняется: цена, ставка налога, имя.
* **`let`** («пусть») - значение можно заменить новым. Подходит для счётчиков, сумм, которые накапливаются.

Заменить значение у `let`-переменной можно **присваиванием**: `total = 500;` (без слова `let`). Правило простое: сначала `const`; если выяснилось, что значение должно меняться, - `let`. Тогда читателю сразу видно, что меняется, а что нет.

<!-- section: examples -->
## Пример 1. Объявить и использовать

```typescript run
const shop: string = "Пекарня";
const price: number = 45;
const isOpen: boolean = true;
console.log(shop, price, isOpen);
```
```output
Пекарня 45 true
```

Разбор: три переменные трёх типов. У каждой своё имя и свой тип после двоеточия. `console.log` получил не значения, а имена; вместо имён подставились значения. Обратите внимание: имена переменных пишутся без кавычек, иначе это был бы текст.

## Пример 2. Заменить значение

```typescript run
let balance: number = 1000;
console.log(balance);
balance = 750;
console.log(balance);
```
```output
1000
750
```

Разбор: `let` разрешает присваивание. Слово `let` пишется один раз, при объявлении; при замене остаётся только `balance = 750;`. Команды выполняются сверху вниз, поэтому первая печать видит 1000, а вторая - 750.

## Пример 3. Новое значение считается из старого

```typescript run
let total: number = 100;
total = total + 20;
console.log(total);
```
```output
120
```

Разбор: знак `=` в программе - это не «равно» из математики, а команда «положить справа в то, что слева». Правую часть `total + 20` компьютер вычисляет первой (100 + 20 = 120), потом результат записывается в `total`. Знак `+` пока воспринимайте как обычное сложение, подробно - в уроке 6.

## Пример 4. Копирование значения

```typescript run
let a: number = 1;
let b: number = a;
a = 5;
console.log(a, b);
```
```output
5 1
```

Разбор: в `b` попала копия значения `a` на момент объявления. Дальнейшие изменения `a` на `b` не влияют.

**Попробуйте.** В примере 2 замените `let` на `const` и посмотрите на сообщение проверки. Затем верните `let` и добавьте третье присваивание.

## Точные правила

* Объявление: `const имя: тип = значение;` или `let имя: тип = значение;`.
* `const` нельзя присваивать повторно. У `const` обязательно начальное значение.
* `let` можно присваивать сколько угодно раз. Присваивание пишется без слов `let`/`const`: `имя = значение;`.
* Имена: буквы, цифры, `_` и `$`; не начинаются с цифры; регистр важен (`total` и `Total` - разные имена). Принято начинать со строчной буквы, а составные имена писать так: `totalPrice` (каждое следующее слово с заглавной).
* Одно имя в одной области нельзя объявить дважды.
* Переменной нельзя пользоваться раньше, чем её объявили (выше по тексту).
* Аннотация `: тип` ограничивает, какие значения можно туда класть. Присвоить `number`-переменной текст нельзя (урок 5).
* Присваивание вычисляет правую часть, затем записывает результат. Старое значение теряется.
* Для значений типов `number`, `string`, `boolean` присваивание копирует значение: `let b = a` не связывает `b` с `a`.

## Типичные ошибки

**1. Присваивание константе.**

```typescript
const price: number = 450;
price = 500;
```

```text
main.ts(2,1): error TS2588: Cannot assign to 'price' because it is a constant.
```

«Нельзя присвоить `price`, потому что это константа». Если значение должно меняться, объявите его через `let`; если нет - значит, ошибка в логике, а не в объявлении.

**2. Использование до объявления.**

```typescript
console.log(total);
let total: number = 5;
```

```text
main.ts(1,13): error TS2448: Block-scoped variable 'total' used before its declaration.
main.ts(1,13): error TS2454: Variable 'total' is used before being assigned.
```

Команды выполняются сверху вниз, поэтому на первой строке `total` ещё нет. Перенесите объявление выше. Вторая строка сообщения - следствие первой.

**3. Повторное объявление.**

```typescript
let total: number = 5;
let total: number = 6;
```

```text
main.ts(1,5): error TS2451: Cannot redeclare block-scoped variable 'total'.
main.ts(2,5): error TS2451: Cannot redeclare block-scoped variable 'total'.
```

Объявлять нужно один раз. Для замены значения слово `let` не нужно: `total = 6;`.

**4. Переменная объявлена, но не получила значения.**

```typescript
let total: number;
console.log(total);
```

```text
main.ts(2,13): error TS2454: Variable 'total' is used before being assigned.
```

Проверка замечает, что ни одно значение не было присвоено до чтения. Чтобы не получить пустоту, задавайте начальное значение при объявлении.

**5. Опечатка в регистре.**

```typescript
let Total: number = 5;
console.log(total);
```

```text
main.ts(2,13): error TS2552: Cannot find name 'total'. Did you mean 'Total'?
```

`total` и `Total` - разные имена. Подсказка в сообщении помогает найти опечатку.

**6. Имя в кавычках.** `console.log("price")` напечатает слово `price`, а не значение переменной. Имена пишут без кавычек.

## Итоги

* Переменная - имя для значения; её объявляют через `const` (не меняется) или `let` (меняется).
* После имени через двоеточие записывается тип: `const price: number = 450;`.
* Присваивание `имя = значение;` вычисляет правую часть и записывает результат в переменную.
* Проверка находит присваивание константе, использование до объявления, повторное объявление и опечатки в имени.

Но аннотация нужна не для красоты: она позволяет проверке остановить программу, если вы положили в переменную значение не того вида. Как это работает, расскажет следующий урок: [Проверка типов](lesson:typescript.from-zero.type-checking).

## Для тех, кто уже программирует

* `const` в TypeScript/JavaScript запрещает **повторное присваивание**, но не делает неизменяемым сам объект (для массивов и объектов это важно, см. уроки о массивах).
* `let` и `const` блочные (область видимости - фигурные скобки); `var` в курсе не используется: он функциональный и поднимается наверх.
* Аннотация типа - после имени через двоеточие, как в Kotlin/Swift/Rust: `const price: number = 450;`. В отличие от Go, `:=` нет.
* Большинство аннотаций на локальных переменных можно опустить: тип выводится из начального значения (урок 5). В первых уроках мы записываем их, чтобы тип был виден.
* Использование `let x: number;` без значения: `strict` проверяет определённое присваивание и отвергает чтение (`TS2454`), как Java и C#.
* Повторное объявление в той же области - ошибка (`TS2451`), как в Go и Rust (но не как у `var`).
