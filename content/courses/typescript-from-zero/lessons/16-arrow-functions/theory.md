## Зачем передавать действие как значение

Функция `sumOf` всегда складывает. А что, если в одном месте нужно удвоить каждое число массива, в другом прибавить десять, в третьем посчитать только чётные? Писать по отдельной функции с одним и тем же циклом внутри - значит повторять одно и то же. Удобнее написать цикл один раз, а **что делать с каждым элементом** передать параметром.

Для этого функцию нужно уметь передавать как обычное значение: число, строку или массив. В TypeScript это возможно: функция - такое же значение, её можно положить в переменную и передать в другую функцию. Передаваемую функцию называют **обратным вызовом** (по-английски *callback*): вы отдаёте её другой функции, и та вызывает её, когда нужно.

## Одна новая идея: стрелочная функция - короткая запись функции-значения

**Стрелочная функция** записывается так:

```text
const double = (x: number): number => x * 2;
```

Читается слева направо: в скобках параметры с типами, после двоеточия тип результата, затем стрелка `=>`, после неё выражение, которое и есть результат. Слово `return` для короткой формы не нужно. Если тело длиннее одной команды, его пишут в фигурных скобках, и тогда `return` нужен, как в обычной функции.

У функции как значения есть **тип**. Тип функции из примера выше записывается `(x: number) => number`: «принимает число, возвращает число». С помощью таких типов описывают параметры, которые сами являются функциями.

<!-- section: examples -->
## Пример 1. Две записи одной функции

```typescript run
function doubleOld(x: number): number {
  return x * 2;
}

const double = (x: number): number => x * 2;

const describe = (price: number, count: number): string => {
  const total: number = price * count;
  return `Итого: ${total}`;
};

console.log(doubleOld(4), double(4));
console.log(describe(30, 3));
```
```output
8 8
Итого: 90
```

`doubleOld` и `double` делают одно и то же. Стрелочная запись короче, когда тело - единственное выражение. Для `describe` тело длиннее, поэтому оно в фигурных скобках и заканчивается `return`. Вызывают стрелочную функцию так же, как обычную: имя, скобки, аргументы.

## Пример 2. Функция в переменной

```typescript run
const add = (a: number, b: number): number => a + b;
const multiply = (a: number, b: number): number => a * b;

let operation: (a: number, b: number) => number = add;
console.log(operation(3, 4));

operation = multiply;
console.log(operation(3, 4));
```
```output
7
12
```

Тип `(a: number, b: number) => number` описывает «функцию двух чисел, возвращающую число». Переменной этого типа можно присвоить и `add`, и `multiply`: оба подходят. Имя параметра в типе (`a`, `b`) служит только пояснением, на проверку оно не влияет; важны число параметров и их типы.

## Пример 3. Функция как параметр

```typescript run
function applyTwice(f: (n: number) => number, x: number): number {
  return f(f(x));
}

function applyAll(values: number[], f: (n: number) => number): number[] {
  const result: number[] = [];
  for (const v of values) {
    result.push(f(v));
  }
  return result;
}

const double = (x: number): number => x * 2;

console.log(applyTwice(double, 5));
console.log(applyAll([1, 2, 3], double));
console.log(applyAll([1, 2, 3], (n) => n + 10));
```
```output
20
[ 2, 4, 6 ]
[ 11, 12, 13 ]
```

Параметр `f` имеет тип функции, и внутри мы вызываем его как обычную: `f(x)`. `applyTwice(double, 5)` вызывает `double` дважды: `double(double(5))` равно 20. В `applyAll` цикл один, а действие над элементом приходит снаружи. В последней строке стрелочная функция записана прямо в аргументе, без имени: `(n) => n + 10`. Типы `n` и результата писать не нужно: проверка знает, что `f` принимает число и возвращает число, и выводит остальное сама.

## Пример 4. Проверка как функция

```typescript run
function countWhere(values: number[], test: (n: number) => boolean): number {
  let count: number = 0;
  for (const v of values) {
    if (test(v)) {
      count = count + 1;
    }
  }
  return count;
}

const nums: number[] = [1, 2, 3, 4, 5, 6];
console.log(countWhere(nums, (n) => n % 2 === 0));
console.log(countWhere(nums, (n) => n > 4));
```
```output
3
2
```

Функция, которая отвечает `true` или `false`, называется **предикатом**. `countWhere` не знает, что считает: чётные, большие четырёх или что-то ещё - условие задаёт тот, кто вызывает. Одна функция с одним циклом заменяет десяток специальных.

**Попробуйте.** Вызовите `countWhere(nums, (n) => n < 0)` и объясните результат. Напишите стрелочную функцию `isBig = (n: number): boolean => n >= 100` и передайте её в `countWhere` по имени, без скобок.

## Точные правила

* Стрелочная функция: `(параметры): тип => выражение` или `(параметры): тип => { команды; return значение; }`.
* Параметры в скобках обязательны, если их не один; при одном параметре без типа скобки можно опустить, но в курсе их всегда пишут.
* Типы параметров обязательны, если стрелочная функция записана сама по себе (`const f = (x) => ...`): иначе `TS7006`. Исключение - функция, переданная прямо в аргумент, чей тип известен: параметры берутся из него.
* Тип результата можно опустить, но так проверка не сообщит о случайном изменении результата: в курсе его указывают.
* Тип функции: `(параметры) => результат`, например `(n: number) => boolean`. Он применяется для переменных, параметров и результатов.
* Функция передаётся **по имени без скобок**: `applyAll(values, double)`. Запись `double(5)` - это уже вызов, и вместо функции было бы передано число.
* Число аргументов при вызове должно совпадать с числом параметров (`TS2554`), а их типы - с типами параметров (`TS2345`).
* Функция, передаваемая другой функции для вызова, называется обратным вызовом (*callback*); функция, возвращающая `true` или `false`, - предикатом.
* Для короткого тела `x => x * 2` результат вычисляется и возвращается автоматически. В фигурных скобках без `return` функция вернёт `undefined`: проверка сообщит `TS2355`, если объявлен другой тип результата.
* Обычные функции (`function`) и стрелочные взаимозаменяемы для задач курса. У стрелочных есть отличия в поведении `this`, которые здесь не нужны.
* Стрелочная функция объявляется через `const` до использования: к `const` нельзя обратиться раньше строки с объявлением.

## Типичные ошибки

**1. Параметр без типа.**

```typescript
const double = (x) => x * 2;
console.log(double(4));
```

```text
main.ts(1,17): error TS7006: Parameter 'x' implicitly has an 'any' type.
```

«Параметр `x` неявно получает тип `any`»: проверка не знает, что вы собираетесь в него передавать. `any` отключает проверку типов, режим `strict` его не допускает. Допишите тип: `(x: number)`.

**2. Фигурные скобки без `return`.**

```typescript
const double = (x: number): number => {
  x * 2;
};
console.log(double(4));
```

```text
main.ts(1,29): error TS2355: A function whose declared type is neither 'undefined', 'void', nor 'any' must return a value.
```

В теле с фигурными скобками результат нужно вернуть явно. Строка `x * 2;` вычисляет значение и выбрасывает его. Либо уберите скобки (`=> x * 2`), либо допишите `return`.

**3. Не то число аргументов.**

```typescript
const double = (x: number): number => x * 2;
console.log(double(1, 2));
```

```text
main.ts(2,23): error TS2554: Expected 1 arguments, but got 2.
```

«Ожидался 1 аргумент, получено 2»: у `double` один параметр.

**4. Передана функция неподходящего типа.**

```typescript
function applyTwice(f: (n: number) => number, x: number): number {
  return f(f(x));
}
console.log(applyTwice((s: string) => s + "!", 5));
```

```text
main.ts(4,24): error TS2345: Argument of type '(s: string) => string' is not assignable to parameter of type '(n: number) => number'.
  Types of parameters 's' and 'n' are incompatible.
    Type 'number' is not assignable to type 'string'.
```

Ожидалась функция «число в число», а передана «строка в строку». Сообщение с отступами читается снизу вверх: числа в строки не превращаются, поэтому параметры несовместимы.

**5. Результат функции не того типа.**

```typescript
const isEven = (n: number): boolean => n % 2 === 0;
const f: (n: number) => number = isEven;
```

```text
main.ts(2,7): error TS2322: Type '(n: number) => boolean' is not assignable to type '(n: number) => number'.
  Type 'boolean' is not assignable to type 'number'.
```

Переменная `f` ждёт функцию, возвращающую число, а `isEven` возвращает логическое значение.

**6. Вызов вместо передачи.** `applyAll(values, double(2))` передаёт число 4 вместо функции: проверка сообщит `TS2345`. Если действие нужно передать, пишите имя без скобок: `applyAll(values, double)`.

## Итоги

* Функцию можно хранить в переменной и передавать в другую функцию как значение.
* Стрелочная функция: `(x: number): number => x * 2`; для длинного тела - в фигурных скобках с `return`.
* Тип функции записывается `(параметры) => результат`: `(n: number) => boolean`.
* Параметры самостоятельной функции нужно типизировать; у функции, переданной прямо в аргумент, типы выводятся из параметра.
* Функцию передают по имени без скобок; со скобками это вызов.
* Обратный вызов позволяет написать цикл один раз, а действие над элементом передавать снаружи.

Теперь можно переходить к готовым методам массивов, которые устроены именно так: [Методы массивов](lesson:typescript.from-zero.array-methods).

## Для тех, кто уже программирует

* Стрелочные функции соответствуют лямбдам в Java (`x -> x * 2`), C# (`x => x * 2`) и Python (`lambda x: x * 2`), но допускают блок команд.
* Тип `(n: number) => boolean` - то же, что `Func<int, bool>` в C# или `Predicate<Integer>` в Java; в Go - `func(int) bool`.
* Функции в TypeScript - полноценные значения (функции первого класса); замыкания работают как в JavaScript: функция запоминает переменные из окружения, где создана.
* Без аннотации параметра в `strict` возникает `TS7006`. Параметры функции-аргумента выводятся из ожидаемого типа (контекстная типизация).
* `this` у стрелочных функций берётся из окружающего кода, в отличие от обычных `function`. Курс его не использует.
* Из-за стирания типов во время работы тип функции не проверяется: JavaScript-вызов с лишними аргументами не упадёт.
