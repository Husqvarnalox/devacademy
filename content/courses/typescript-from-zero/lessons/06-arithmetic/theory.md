## Зачем это нужно

Касса складывает цены, магазин считает скидки, приложение делит счёт между друзьями. Компьютер умеет считать быстро и точно, но записывать формулы нужно по его правилам: какие знаки действий использовать, в каком порядке они выполняются и что делать, если результат получается дробным.

## Одна новая идея: выражение вычисляется в число

Запись из чисел и знаков действий называется **выражением**. Компьютер вычисляет его и подставляет результат: `2 + 3` превращается в `5`. Основные знаки (**операторы**) такие:

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3.5` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `7 ** 2` | `49` |

Деление в TypeScript обычное, не целочисленное: `7 / 2` даёт `3.5`. Чтобы получить целую часть, результат округляют функциями **`Math`**: `Math.floor` (вниз), `Math.ceil` (вверх), `Math.round` (до ближайшего целого). Слово `Math` («математика») - готовый набор функций, который не нужно подключать.

Из-за приоритета действий `2 + 3 * 4` равно `14`: умножение выполняется раньше сложения, как в школьной математике. Скобки меняют порядок.

<!-- section: examples -->
## Пример 1. Все операторы

```typescript run
console.log(7 + 2, 7 - 2, 7 * 2, 7 / 2, 7 % 2, 7 ** 2);
```
```output
9 5 14 3.5 1 49
```

Разбор: шесть выражений, шесть результатов через пробел. Остаток `7 % 2` равен `1`: 7 - это три двойки и один «лишний».

## Пример 2. Приоритет и скобки

```typescript run
console.log(2 + 3 * 4, (2 + 3) * 4);
```
```output
14 20
```

Разбор: без скобок сначала `3 * 4`, потом `2 + 12`. Со скобками сначала `2 + 3`, потом `5 * 4`. Если сомневаетесь в порядке, ставьте скобки: они ничего не стоят и делают формулу понятной.

## Пример 3. Округление

```typescript run
console.log(Math.floor(7 / 2), Math.ceil(7 / 2), Math.round(7 / 2), Math.round(2.4));
```
```output
3 4 4 2
```

Разбор: `7 / 2` равно 3.5. `floor` отбросил дробную часть вниз - 3, `ceil` поднял вверх - 4, `round` округлил 3.5 до ближайшего целого, причём ровно половину округляет вверх - 4. Для 2.4 ближайшее целое 2.

## Пример 4. Формула из переменных

```typescript run
const price = 40;
const count = 3;
const total = price * count;
const cash = 200;
const change = cash - total;
console.log("Сдача:", change);
```
```output
Сдача: 80
```

Разбор: цена и количество лежат в переменных; формула `price * count` работает при любых значениях. Типы здесь не записаны: проверка вывела их сама (все `number`).

## Пример 5. Погрешность дробей

```typescript run
console.log(0.1 + 0.2);
console.log((0.1 + 0.2).toFixed(2));
```
```output
0.30000000000000004
0.30
```

Разбор: компьютер хранит дробные числа в двоичной системе, и 0.1 с 0.2 записываются приближённо, как 1/3 в десятичной дроби. Крошечная погрешность видна при печати. Для показа пользователю дробь округляют методом `toFixed(2)`: «оставить два знака после точки». Метод применяют к числу через точку; результат - **текст** (`"0.30"`), а не число. Он нужен для вывода; в дальнейших вычислениях используйте исходное число.

**Попробуйте.** Предскажите, а затем проверьте: `console.log(10 % 3, 10 / 4, Math.floor(10 / 4));`. Измените цену и количество в примере 4 и убедитесь, что сдача считается заново.

## Точные правила

* Операторы: `+ - * / % **`. Приоритет: `**`, затем `* / %`, затем `+ -`; равные по приоритету идут слева направо; скобки - первыми.
* Вид результата арифметики над числами - `number`. Целых и дробных типов нет, есть один.
* `/` всегда обычное деление: `7 / 2` равно `3.5`. Деление на ноль не ошибка: `1 / 0` равно `Infinity` («бесконечность»), `0 / 0` равно `NaN` («не число»).
* `%` - остаток; знак остатка совпадает со знаком делимого: `-7 % 3` равно `-1`.
* `Math.floor(x)` - вниз до целого, `Math.ceil(x)` - вверх, `Math.round(x)` - к ближайшему целому (половина округляется в сторону плюс бесконечности: `Math.round(2.5)` равно `3`, `Math.round(-2.5)` равно `-2`).
* `Math.floor` для отрицательных идёт вниз: `Math.floor(-2.5)` равно `-3`.
* Дроби хранятся приближённо. Сравнивать вычисленные дроби на точное равенство ненадёжно; для денег часто считают в копейках целыми числами.
* `x.toFixed(2)` возвращает **строку** с двумя знаками после точки.
* Арифметические операторы `- * / % **` допустимы только над числами. Над текстом проверка сообщает `TS2362`. Оператор `+` особый: если одна из сторон текст, он склеивает (урок 7).

<!-- section: mistakes -->
## Типичные ошибки

**1. Арифметика с текстом.**

```typescript
const price = "100";
console.log(price * 2);
```

```text
main.ts(2,13): error TS2362: The left-hand side of an arithmetic operation must be of type 'any', 'number', 'bigint' or an enum type.
```

«Левая часть арифметического действия должна быть числом». Здесь `price` - текст, потому что значение в кавычках. Уберите кавычки. Эта ошибка пойманная проверкой: в обычном JavaScript такая программа молча дала бы 200 за счёт неявного превращения, а в другом случае - `NaN`.

**2. Приоритет без скобок.**

```typescript
console.log(10 + 20 / 2);
```

Печатает `20`, а не `15`: деление выполняется раньше сложения. Нужны скобки: `(10 + 20) / 2`.

**3. Ожидание целочисленного деления.** `7 / 2` даёт `3.5`, а не `3`. Целую часть получают так: `Math.floor(7 / 2)`.

**4. Дробь в расчёте на точность.** `0.1 + 0.2` не равно ровно `0.3`. Для денег считайте в копейках целыми числами, а на экран выводите с `toFixed(2)`.

**5. Использовать результат `toFixed` как число.** `(2.5).toFixed(1)` - это текст `"2.5"`; арифметика над ним отвергается (`TS2362`) и в других случаях склеивает.

<!-- section: summary -->
## Итоги

* Операторы `+ - * / % **` строят выражения; приоритет как в математике, скобки меняют порядок.
* `/` даёт дробь; целую часть получают через `Math.floor`, `Math.ceil` или `Math.round`; остаток - через `%`.
* Дроби хранятся приближённо; для показа округляйте `toFixed(2)` (результат - текст).
* Арифметика над текстом отвергается проверкой (`TS2362`).

## Для тех, кто уже программирует

* Единственный числовой тип `number` - это double (IEEE 754). Нет отдельного целочисленного деления: аналог `//` в Python - `Math.floor(a / b)`, а `a / b` для целых даёт дробь, в отличие от Java, C# и Go.
* `%` - остаток со знаком делимого, как в Java и C#, не как в Python.
* `**` - возведение в степень, как в Python.
* Безопасные целые - до 2^53 - 1 (`Number.MAX_SAFE_INTEGER`); для больших есть `bigint` (в курсе не используется).
* Деление на ноль не бросает исключение: даёт `Infinity` или `NaN`.
* В отличие от JavaScript, `"100" * 2` здесь не превращается молча в `200`: `tsc` отвергает его (`TS2362`). Но `"5" + 2` проверка допускает: результат `"52"`.
