## Зачем нужен ещё один цикл

В прошлом уроке счётчик жил в трёх разных местах: объявление до цикла, условие в скобках, обновление в конце блока. Когда число повторений известно заранее («для каждого числа от 1 до 10», «пять раз»), эти три части удобно собрать в одном месте. Если обновление счётчика лежит прямо под рукой, его трудно забыть, а значит, трудно получить бесконечный цикл.

Для этого есть цикл **`for`** («для»). Он не умеет ничего нового по сравнению с `while`: любой `for` можно переписать через `while`. Он просто записывает те же три части компактно.

## Одна новая идея: счётчик, условие и обновление в одной строке

```text
for (начало; условие; обновление) {
  тело
}
```

В скобках три части, разделённые точками с запятой:

1. **Начало** выполняется один раз до цикла: обычно объявление счётчика, например `let i: number = 1`.
2. **Условие** проверяется перед каждой итерацией, как в `while`: пока оно истинно, тело выполняется.
3. **Обновление** выполняется после каждой итерации: обычно счётчик увеличивается, например `i = i + 1`.

Счётчик, объявленный в начале, существует только внутри цикла: снаружи он недоступен.

<!-- section: examples -->
## Пример 1. От 1 до 5

```typescript run
for (let i: number = 1; i <= 5; i = i + 1) {
  console.log(i);
}
console.log("Готово");
```
```output
1
2
3
4
5
Готово
```

Это тот же цикл, что в уроке про `while`, только `let i = 1`, условие `i <= 5` и обновление `i = i + 1` стоят в одной строке. Порядок выполнения такой: начало (`i` равно 1), условие, тело, обновление, условие, тело, обновление и так далее. Когда после обновления `i` становится 6, условие ложно, и цикл заканчивается.

## Пример 2. Сумма и произведение

```typescript run
let sum: number = 0;
for (let i: number = 1; i <= 4; i = i + 1) {
  sum = sum + i;
}
console.log("Сумма:", sum);

let product: number = 1;
for (let i: number = 1; i <= 5; i = i + 1) {
  product = product * i;
}
console.log("Произведение:", product);
```
```output
Сумма: 10
Произведение: 120
```

Накопитель объявляется до цикла, а счётчик `i` живёт только внутри `for`. Поэтому во втором цикле можно снова назвать счётчик `i`: первый уже закончился, и его `i` не существует. Начальное значение накопителя для произведения равно 1, как и в `while`.

## Пример 3. Другой шаг и другое направление

```typescript run
for (let i: number = 0; i <= 10; i += 5) {
  console.log(i);
}

for (let n: number = 3; n > 0; n--) {
  console.log("Осталось", n);
}
```
```output
0
5
10
Осталось 3
Осталось 2
Осталось 1
```

Обновление не обязано быть «плюс один». Здесь появились две сокращённые записи, которые встречаются в чужом коде постоянно:

* `i += 5` означает то же, что `i = i + 5`: «прибавить 5 к `i`». Так же работают `-=`, `*=` и `/=`.
* `n--` означает `n = n - 1`; симметричная запись `n++` значит `n = n + 1`.

Если сокращения непривычны, можно по-прежнему писать `i = i + 1`: результат одинаков.

## Пример 4. Функции с циклом for

```typescript run
function factorial(n: number): number {
  let result: number = 1;
  for (let i: number = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}

function repeatText(text: string, times: number): string {
  let out: string = "";
  for (let i: number = 0; i < times; i++) {
    out = out + text;
  }
  return out;
}

console.log(factorial(5), factorial(1), factorial(0));
console.log(repeatText("ab", 3));
console.log(repeatText("-", 0) === "");
```
```output
120 1 1
ababab
true
```

`factorial(n)` перемножает числа от 2 до `n` (умножать на 1 бессмысленно). При `n` равном 1 или 0 цикл не выполняется ни разу, и возвращается начальное значение 1: так и принято считать. В `repeatText` счётчик начинается с 0 и условие строгое (`i < times`): тогда тело выполняется ровно `times` раз. Это основная пара для «повторить N раз»: от 0 до `N` не включая. Для цикла по числам «от 1 до `n` включительно» используют пару от 1 до `n` включая.

**Попробуйте.** Перепишите циклы `while` из прошлого урока (`sumTo`, `daysToSave`) через `for`, где это возможно. Какой из них неудобно переписывать и почему? Подсказка: в одной из задач число повторений заранее неизвестно.

## Точные правила

* Форма: `for (начало; условие; обновление) { тело }`. Три части разделены двумя точками с запятой, все три в круглых скобках.
* Порядок: начало один раз; затем повторяется «условие, тело, обновление». Как только условие ложно, цикл завершается и выполняется следующая команда после блока.
* Условие проверяется до первой итерации, поэтому тело может не выполниться ни разу (при `for (let i = 5; i < 3; i++)`).
* Счётчик, объявленный в начале через `let`, виден только внутри цикла: ни после него, ни в другом цикле. Обращение к нему снаружи - ошибка `TS2304`.
* Счётчик объявляют через `let`, не через `const`: обновление должно его менять. С `const` проверка выдаёт `TS2588`.
* Любую из трёх частей можно опустить (`for (;;)` - бесконечный цикл), но в этом курсе так не пишут.
* `i++` увеличивает `i` на 1, `i--` уменьшает; `i += k` прибавляет `k`. Это сокращения; смысл остался прежним.
* Пара «`i = 0; i < n`» повторяет тело ровно `n` раз. Пара «`i = 1; i <= n`» перебирает числа 1, 2, …, `n`.
* Если обновление идёт в сторону, противоположную условию (счётчик растёт, а условие ждёт, что он уменьшится), цикл бесконечен. Проверка типов этого не замечает.
* Накопитель (сумма, произведение, строка) объявляют до цикла и меняют внутри. Если объявить его внутри тела, он будет создаваться заново на каждой итерации.

## Типичные ошибки

**1. Запятые вместо точек с запятой.**

```typescript
let total: number = 0;
for (let i: number = 1, i <= 3, i = i + 1) {
  total = total + i;
}
console.log(total);
```

```text
main.ts(2,27): error TS1005: ',' expected.
main.ts(2,42): error TS1005: ';' expected.
```

Части в скобках `for` разделяются **точкой с запятой**. Запятая здесь означает «ещё одна переменная в этом же объявлении», поэтому компилятор после `i: number = 1,` ждёт ещё одно имя и сообщает «ожидалась запятая». Числа 27 и 42 - позиции в строке 2, где он остановился.

**2. Счётчик использован после цикла.**

```typescript
for (let i: number = 1; i <= 3; i = i + 1) {
  console.log(i);
}
console.log("Последний i:", i);
```

```text
main.ts(4,29): error TS2304: Cannot find name 'i'.
```

«Не найдено имя `i`»: переменная существует только внутри `for`. Если значение нужно после цикла, заведите переменную до цикла и записывайте в неё внутри.

**3. Счётчик объявлен через `const`.**

```typescript
for (const i = 0; i < 3; i = i + 1) {
  console.log(i);
}
```

```text
main.ts(1,26): error TS2588: Cannot assign to 'i' because it is a constant.
```

Обновление пытается изменить `i`, а константу изменить нельзя. Объявите счётчик через `let`.

**4. Ошибка на единицу.** Нужно повторить действие пять раз, а написано `for (let i = 0; i <= 5; i++)`: шесть значений (0, 1, 2, 3, 4, 5), значит шесть итераций. Ошибок не будет ни при проверке, ни при запуске. Выписывайте значения счётчика на маленьком примере.

**5. Не в ту сторону.** `for (let i = 10; i > 0; i++)`: счётчик растёт, условие `i > 0` истинно всегда, цикл бесконечен. Убедитесь, что обновление приближает условие к ложности.

**6. Накопитель объявлен внутри цикла.**

```typescript
function sumTo(n: number): number {
  for (let i: number = 1; i <= n; i++) {
    let total: number = 0;
    total = total + i;
  }
  return total;
}
```

```text
main.ts(6,10): error TS2304: Cannot find name 'total'.
```

Переменная `total` создана внутри блока цикла, а `return` стоит снаружи, поэтому имя там не найдено. Если «исправить» ошибку, перенеся `return` внутрь блока, получится ещё хуже: на каждой итерации `total` обнулялась бы заново. Накопитель объявляют до цикла.

## Итоги

* `for (начало; условие; обновление) { тело }` - тот же цикл, что `while`, с тремя частями в одной строке.
* Начало выполняется один раз; условие проверяется перед каждой итерацией; обновление - после каждой.
* Счётчик объявляется через `let` и виден только внутри цикла.
* `i++`, `i--` и `i += k` - сокращения для `i = i + 1`, `i = i - 1` и `i = i + k`.
* «Повторить `n` раз» - `i = 0; i < n`; «числа от 1 до `n`» - `i = 1; i <= n`.
* Накопитель объявляют до цикла; граница `<` или `<=` решает, войдёт ли последнее значение.

Бывает, что цикл нужно остановить раньше или пропустить одну итерацию, а иногда один цикл должен сидеть внутри другого: [Остановка, пропуск и вложенные циклы](lesson:typescript.from-zero.loop-control).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Форма `for (init; cond; step)` такая же, как в Java, C#, JavaScript и C++. В Python аналог - `for i in range(...)`; в Go - `for i := 0; i < n; i++`, без скобок.
* `let` в `for` создаёт новую привязку счётчика на каждой итерации (отличие от устаревшего `var`); это важно для замыканий, о которых речь пойдёт позже.
* `i++` и `i += k` есть в TypeScript, но `i++` как выражение в составе другого выражения лучше не использовать: `a[i++]` читается плохо.
* Счётчик типа `number`, идущий дробными шагами, накапливает погрешность: `for (let x = 0; x !== 1; x += 0.1)` не завершится. Счётчики делают целыми.
* Цикл `for...of` по массиву появится в уроке про обход массивов; `for...in` в курсе не используется.
