## Зачем нужны методы строк

Текст почти всегда приходит «грязным»: пробелы по краям, заглавные и строчные буквы вперемешку, несколько значений в одной строке через запятую. Прежде чем что-то делать с таким текстом, его нужно привести в порядок и разобрать на части. Для этого у каждой строки есть готовые **методы**: так же, как у массивов, они вызываются через точку, например `text.trim()`.

## Одна новая идея: метод строки возвращает новую строку, а исходная не меняется

Строки в TypeScript **неизменяемы**: ни один метод не меняет строку, у которой вызван. Он создаёт и возвращает новую. Поэтому результат нужно сохранить или сразу использовать: `text.toUpperCase();` в одиночку ничего не даёт.

Основные методы:

* **`trim()`** - убрать пробелы и переводы строк по краям.
* **`toUpperCase()`, `toLowerCase()`** - все буквы заглавные или строчные.
* **`split(разделитель)`** - разрезать строку на массив частей по разделителю.
* **`slice(от, до)`** - вырезать часть строки: с позиции «от» до позиции «до», не включая её. Без второго аргумента - до конца строки.
* **`includes(часть)`** - `true`, если строка содержит такую часть.
* **`replaceAll(что, чем)`** - заменить все вхождения одной части на другую.

Позиции в строке считаются так же, как индексы в массиве: с нуля.

<!-- section: examples -->
## Пример 1. Порядок в регистре и пробелах

```typescript run
const raw: string = "  Привет, мир  ";

console.log(`[${raw.trim()}]`);
console.log(raw.toUpperCase());
console.log(raw.trim().toLowerCase());

raw.trim();
console.log(`[${raw}]`);
```
```output
[Привет, мир]
  ПРИВЕТ, МИР  
привет, мир
[  Привет, мир  ]
```

`trim()` убрал пробелы по краям, но не внутри. `toUpperCase()` не стал убирать пробелы: он отвечает только за регистр. Методы можно соединять цепочкой: сначала `trim`, потом `toLowerCase`. А вот строка `raw.trim();` без присваивания ничего не изменила: последний вывод показывает исходный текст вместе с пробелами. Результат метода нужно сохранить: `const clean = raw.trim();`.

## Пример 2. Разрезать и склеить

```typescript run
const csv: string = "хлеб,молоко,сыр";
const parts: string[] = csv.split(",");

console.log(parts);
console.log(parts.length, parts[1]);
console.log(parts.join(" / "));

console.log("a  b".split(" "));
console.log("".split(","));
```
```output
[ 'хлеб', 'молоко', 'сыр' ]
3 молоко
хлеб / молоко / сыр
[ 'a', '', 'b' ]
[ '' ]
```

`split(",")` режет строку по запятым и возвращает массив строк: с ним работают уже знакомые методы массивов. `join` делает обратное. Обратите внимание на два краевых случая. Два пробела подряд дают **пустую часть** между ними: `["a", "", "b"]`. А пустая строка, разрезанная по запятой, даёт массив из одного элемента (самой пустой строки), а не пустой массив. Поэтому текст перед разбором чистят, а пустые части отбрасывают через `filter`.

## Пример 3. Вырезать часть

```typescript run
const word: string = "Привет";

console.log(word.slice(0, 3));
console.log(word.slice(3));
console.log(word.slice(-2));
console.log(word.length, word[0], word.at(-1));
```
```output
При
вет
ет
6 П т
```

`slice(0, 3)` берёт символы с позиций 0, 1 и 2 (позицию 3 не включает): «При». С одним аргументом `slice(3)` вырезает всё от позиции 3 до конца. Отрицательное число отсчитывает с конца: `slice(-2)` - последние два символа. Один символ читается как элемент массива: `word[0]`. Менять строку по индексу нельзя: `word[0] = "К"` - ошибка.

## Пример 4. Поиск и замена

```typescript run
const date: string = "2025-01-31";
console.log(date.replaceAll("-", "."));

const title: string = "Привет, мир";
console.log(title.includes("мир"), title.includes("мир!"), title.includes("привет"));
```
```output
2025.01.31
true false false
```

`replaceAll("-", ".")` заменяет **каждый** дефис на точку. Поиск `includes` различает регистр: `"привет"` не найден в «Привет», потому что `п` и `П` - разные символы. Чтобы искать без учёта регистра, сначала приводят обе строки к одному регистру.

## Пример 5. Готовые функции

```typescript run
function capitalize(word: string): string {
  if (word === "") {
    return "";
  }
  return word.slice(0, 1).toUpperCase() + word.slice(1).toLowerCase();
}

function initials(fullName: string): string {
  const words: string[] = fullName.trim().split(" ").filter((w) => w !== "");
  let result: string = "";
  for (const w of words) {
    result = result + w.slice(0, 1).toUpperCase();
  }
  return result;
}

console.log(capitalize("пРИВЕТ"));
console.log(capitalize("") === "");
console.log(initials("  иван  петрович  сидоров "));
```
```output
Привет
true
ИПС
```

`capitalize` берёт первую букву в верхнем регистре и добавляет остаток в нижнем. Пустую строку нужно обработать отдельно: `"".slice(0, 1)` даёт пустую строку, и ошибки бы не было, но проверка делает намерение явным. В `initials` текст сначала чистится, режется на слова и очищается от пустых частей (из-за двойных пробелов), а потом первые буквы слов склеиваются.

**Попробуйте.** Напишите функцию `isEmail(text: string): boolean`, которая проверяет, что в тексте есть символ `@` и точка (через `includes`). Проверьте её на `"a@b.ru"`, `"abc"` и `"a@b"`. Как сделать так, чтобы пробелы по краям не мешали?

## Точные правила

* Строки неизменяемы: каждый метод возвращает **новую** строку (или массив, или логическое значение). Исходная строка остаётся прежней. Присваивание по индексу `word[0] = "К"` запрещено (`TS2542`).
* Методы вызывают со скобками, даже если аргументов нет: `raw.trim()`. Без скобок это не вызов, а сама функция (`TS2322` при присваивании строке).
* `trim()` убирает пробелы, табуляции и переводы строк только по краям.
* `toUpperCase()` и `toLowerCase()` работают с кириллицей и другими алфавитами; они не удаляют пробелы.
* `split(sep)` возвращает `string[]`. Подряд идущие разделители дают пустые части; пустая строка даёт `[""]`, а не `[]`. `split("")` режет по символам.
* `slice(a, b)` берёт символы с позиции `a` до позиции `b`, не включая её. `slice(a)` - до конца. Отрицательные позиции отсчитываются с конца. Выход за границы ошибки не даёт.
* `includes(part)` различает регистр; `part` должна быть строкой (`TS2345` для числа).
* `replaceAll(a, b)` заменяет все вхождения; `replace(a, b)` - только первое.
* `text.length` - число символов (точнее, элементов UTF-16; для обычных букв это число букв). `text[i]` и `text.at(i)` дают один символ, `at(-1)` - последний.
* Результат метода можно сразу использовать: `text.trim().toLowerCase().split(" ")`.
* Пустой символ-разделитель, регистр и пробелы - главный источник ошибок обработки текста: данные чистят до разбора.

## Типичные ошибки

**1. Опечатка в названии метода.**

```typescript
const name: string = "anna";
console.log(name.toUppercase());
```

```text
main.ts(2,18): error TS2551: Property 'toUppercase' does not exist on type 'string'. Did you mean 'toUpperCase'?
```

Регистр букв в имени метода важен: `toUpperCase` пишется с заглавной `C`. Проверка предлагает ближайшее существующее имя.

**2. Метод без скобок.**

```typescript
const raw: string = "  hi  ";
const clean: string = raw.trim;
```

```text
main.ts(2,23): error TS2322: Type '() => string' is not assignable to type 'string'.
```

Без скобок `raw.trim` - сама функция (тип `() => string`), а не результат её вызова. Нужно `raw.trim()`.

**3. `split` присвоен переменной-строке.**

```typescript
const words: string = "a b c".split(" ");
```

```text
main.ts(1,7): error TS2322: Type 'string[]' is not assignable to type 'string'.
```

`split` возвращает массив частей. Переменная должна иметь тип `string[]`.

**4. Попытка изменить символ по индексу.**

```typescript
const word: string = "кот";
word[0] = "К";
```

```text
main.ts(2,1): error TS2542: Index signature in type 'String' only permits reading.
```

«Индексация строки допускает только чтение». Чтобы получить строку с заглавной первой буквой, соберите новую: `word.slice(0, 1).toUpperCase() + word.slice(1)`.

**5. Неверный тип аргумента.**

```typescript
const word: string = "hello";
console.log(word.includes(5));
```

```text
main.ts(2,27): error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.
```

Искать в строке можно только строку. Если нужно найти цифру, запишите её в кавычках: `"5"`.

**6. Результат метода потерян.** `raw.trim();` на отдельной строке не меняет `raw`. Ошибки типов нет, но программа продолжает работать с неочищенным текстом. Сохраняйте результат: `const clean = raw.trim();`.

**7. Пустые части после `split`.** `"a  b".split(" ")` даёт `["a", "", "b"]`: лишний пробел приводит к пустому элементу. Если важно число слов, отфильтруйте пустые: `.filter((w) => w !== "")`.

**8. Регистр при поиске.** `"Привет".includes("привет")` равно `false`. Приведите обе строки к одному регистру (`toLowerCase`) перед сравнением.

## Итоги

* Строки неизменяемы: методы возвращают новые значения, исходная строка остаётся как была.
* `trim`, `toUpperCase`, `toLowerCase` приводят текст в порядок; `split` режет на массив, `join` склеивает обратно.
* `slice(a, b)` вырезает часть от `a` до `b` (без `b`); отрицательные позиции считаются с конца.
* `includes` ищет часть и различает регистр; `replaceAll` заменяет все вхождения.
* `split` даёт пустые части при подряд идущих разделителях и `[""]` для пустой строки: перед разбором текст чистят, пустые части отбрасывают `filter`.
* Методы вызывают со скобками, а результат сохраняют или сразу используют.

Строки и массивы уже умеют много. Следующий шаг - собрать данные об одной вещи (название, цена, количество) в одно значение: [Объекты](lesson:typescript.from-zero.objects).

## Для тех, кто уже программирует

* Строки неизменяемы, как в Java, C#, Python и Go. Методы возвращают новые строки.
* `split(" ")` в JavaScript не отбрасывает пустые части и для `""` возвращает `[""]`. Аналога питоновского `split()` без аргумента (он делит по любым пробелам и пустых частей не оставляет) нет: нужен `filter`.
* `slice(a, b)` допускает отрицательные границы и не бросает исключений при выходе за границы (в отличие от `substring` в Java и `Substring` в C#). Есть устаревшие `substr` и `substring` с другими правилами; в курсе их нет.
* Строка - последовательность единиц UTF-16: символы вне базовой плоскости (например, эмодзи) занимают две единицы, `length` у них 2. Для букв кириллицы это не важно.
* Метод `replace` со строковым первым аргументом заменяет только первое вхождение; `replaceAll` - все (ES2021).
* Сравнение строк `===` побуквенное и зависит от регистра. Для сортировки с учётом языка есть `localeCompare`, в курсе не используется.
