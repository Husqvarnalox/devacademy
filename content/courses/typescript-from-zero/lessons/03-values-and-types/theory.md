## Зачем различать виды значений

Касса печатает «Итого: 450» и умеет вычитать скидку из 450. Название товара «Хлеб» она вычитать не умеет, зато умеет искать в нём буквы. Число и текст устроены по-разному, поэтому программе важно знать, с чем она имеет дело. Вид значения называется **типом**. В TypeScript тип - главное понятие, ради которого язык и создан: проверка, о которой шла речь в первых двух уроках, как раз сверяет типы.

## Одна новая идея: у каждого значения есть тип

В этом уроке три базовых типа:

* **`number`** (число) - целые и дробные: `42`, `3.5`, `-7`. Числа записывают без кавычек, дробную часть отделяют точкой.
* **`string`** (строка, то есть текст) - любые символы в кавычках: `"Хлеб"`, `"42"`, `""` (пустая строка). Всё, что в кавычках, - текст, даже цифры.
* **`boolean`** (логическое значение) - ровно два варианта: `true` («истина», да) и `false` («ложь», нет). Без кавычек и строчными буквами.

Увидеть тип значения во время работы можно операцией **`typeof`**: она записывается перед значением и возвращает название типа в виде текста. `typeof 42` даёт `"number"`.

<!-- section: examples -->
## Пример 1. Числа

```typescript run
console.log(42);
console.log(3.5);
console.log(-7);
```
```output
42
3.5
-7
```

Разбор: каждое значение записано без кавычек, поэтому это числа. Минус - часть записи отрицательного числа. Дробная часть отделяется точкой: `3,5` с запятой был бы двумя значениями.

## Пример 2. Текст

```typescript run
console.log("Хлеб", "по цене", 45);
```
```output
Хлеб по цене 45
```

Разбор: два текста и одно число; `console.log` печатает их через пробел. Кавычки в вывод не попадают.

## Пример 3. Логические значения

```typescript run
console.log(true);
console.log(false);
```
```output
true
false
```

Такие значения отвечают на вопросы «да или нет»: есть ли товар в наличии, оплачен ли заказ. Дальше они понадобятся в условиях.

## Пример 4. typeof

```typescript run
console.log(typeof 42);
console.log(typeof 3.5);
console.log(typeof "42");
console.log(typeof true);
```
```output
number
number
string
boolean
```

Разбор: `42` и `3.5` - оба числа, у целых и дробных один тип `number`. `"42"` в кавычках - текст, поэтому `string`. `typeof` вернул названия типов как текст, и `console.log` их напечатал.

## Пример 5. Число и текст ведут себя по-разному

```typescript run
console.log(5 + 5, "5" + "5");
```
```output
10 55
```

Знак `+` складывает числа и склеивает тексты (подробно - в уроках 6 и 7). Поэтому на экране выглядящие одинаково `5` и `"5"` дают разные результаты: `10` и `55`.

**Попробуйте.** Предскажите вывод `console.log(typeof "true", typeof true);`, затем запустите. Замените `"42"` в примере 4 на `42` и убедитесь, что `typeof` изменил ответ.

<!-- section: precise -->
## Точные правила

* Три базовых типа: `number`, `string`, `boolean`. Названия типов пишутся строчными буквами.
* У `number` один тип и для целых, и для дробных чисел. Дробную часть отделяет точка: `3.5`. Разделить разряды можно подчёркиванием: `1_000_000` - то же, что `1000000`.
* Число записывают без кавычек. Любое значение в кавычках - строка, даже `"42"` или `"true"`.
* Логических значений два: `true` и `false`, только строчными буквами, без кавычек. `True` и `"true"` - не они.
* `typeof значение` возвращает название типа **строкой**: `"number"`, `"string"`, `"boolean"`.
* Тип значения определяется его записью. Кавычки превращают что угодно в текст, а число превратить в текст и обратно можно только специальными средствами (урок 23).
* Не пишите числа с ведущим нулём (`007`): в языке это устаревшая запись, и проверка сообщает об ошибке `TS1121`.

## Типичные ошибки

**1. Логическое значение с заглавной буквы.**

```typescript
console.log(True);
```

```text
main.ts(1,13): error TS2304: Cannot find name 'True'.
```

`True` - неизвестное имя, а значение называется `true`. Регистр входит в запись.

**2. Число в кавычках.**

```typescript
console.log(typeof "45");
```

Программа работает и печатает `string`, а вы ожидали `number`. Ошибки нет: «45» в кавычках - корректный текст. Если значение должно быть числом, уберите кавычки.

**3. Запятая вместо точки в дробном числе.**

```typescript
console.log(3,5);
```

Программа печатает `3 5`: запятая разделила два значения. Для десятичной дроби нужна точка: `3.5`.

**4. Пропущена запятая между значениями.**

```typescript
console.log("Цена:" 45);
```

```text
main.ts(1,21): error TS1005: ',' expected.
```

Проверка ожидала запятую между двумя значениями. Столбец 21 указывает на число `45`: здесь она заметила, что запятой нет.

**5. Ожидание, что `typeof` вернёт не текст, а что-то особое.** `typeof 42` - это строка `"number"` из шести букв, и с ней можно обращаться как с любым другим текстом.

## Итоги

* Типы значений: `number` (число), `string` (текст в кавычках), `boolean` (`true` или `false`).
* По выводу `5` и `"5"` не отличить, но ведут они себя по-разному; `typeof` показывает тип.
* Дробная часть отделяется точкой, булевы значения пишутся строчными буквами без кавычек.

Следующий шаг - давать значениям имена, чтобы не повторять их и хранить результаты: [Переменные](lesson:typescript.from-zero.variables).

## Для тех, кто уже программирует

* Базовые типы: `number` (один числовой тип, IEEE 754 double: нет отдельных `int` и `float`), `string`, `boolean`. Есть ещё `bigint`, `symbol`, `null`, `undefined`: в курсе они появляются по мере необходимости.
* `typeof` - это операция JavaScript, она работает во время выполнения и возвращает строку. В позиции типа тот же `typeof` означает совсем другое: «тип такого-то значения» (`typeof x` в аннотации). В этом уроке только первое значение.
* В отличие от Python, нет целочисленного типа произвольной длины; в отличие от Java и C#, нет разных `int` и `double`: `1 / 2` равно `0.5`.
* Кавычки: `"..."`, `'...'` и обратные `` `...` `` дают тип `string`; в курсе - двойные.
* `typeof null` равен `"object"` - историческая особенность JavaScript, к которой мы вернёмся.
