## Зачем управлять циклом изнутри

Обычный цикл идёт до конца условия. Но задачи бывают другими: найти первого подходящего покупателя в списке и не просматривать остальных; пропустить пустые строки, а остальные обработать; вывести таблицу, где в каждой строке свой набор столбцов. Для этого нужны две команды, меняющие ход цикла изнутри, и возможность вложить один цикл в другой.

## Одна новая идея: `break` и `continue` меняют ход текущего цикла

* **`break`** («прервать») немедленно завершает цикл. Выполнение продолжается с первой команды после цикла.
* **`continue`** («продолжить») прекращает текущую итерацию и переходит к следующей: в `for` выполняется обновление и проверяется условие, в `while` сразу проверяется условие.

Обе команды действуют на **ближайший** охватывающий цикл. Если один цикл вложен в другой, `break` во внутреннем завершает только внутренний; внешний продолжает работать.

**Вложенный цикл** - это цикл в теле другого цикла. На каждую итерацию внешнего внутренний проходит свой путь целиком. Так обходят таблицы: внешний счётчик - строки, внутренний - столбцы.

<!-- section: examples -->
## Пример 1. `break`: остановиться, когда нашли

```typescript run
for (let n: number = 1; n <= 100; n++) {
  if (n * n > 50) {
    console.log("Первое число, чей квадрат больше 50:", n);
    break;
  }
}
console.log("Поиск окончен");
```
```output
Первое число, чей квадрат больше 50: 8
Поиск окончен
```

Цикл допускает значения до 100, но на числе 8 (`8 * 8` равно 64) условие `if` срабатывает, цикл прерывается, и остальные 92 значения не рассматриваются. Без `break` программа напечатала бы сообщение для каждого `n` от 8 до 100.

## Пример 2. `continue`: пропустить ненужное

```typescript run
let sum: number = 0;
for (let i: number = 1; i <= 10; i++) {
  if (i % 3 === 0) {
    continue;
  }
  sum = sum + i;
}
console.log(sum);
```
```output
37
```

Для чисел, кратных трём (3, 6, 9), срабатывает `continue`: итерация заканчивается, не дойдя до `sum = sum + i`, и цикл переходит к следующему `i`. В сумму попадают 1, 2, 4, 5, 7, 8 и 10, итого 37.

## Пример 3. Вложенные циклы: таблица

```typescript run
for (let row: number = 1; row <= 3; row++) {
  let line: string = "";
  for (let col: number = 1; col <= 4; col++) {
    if (col > 1) {
      line = line + " ";
    }
    line = line + row * col;
  }
  console.log(line);
}
```
```output
1 2 3 4
2 4 6 8
3 6 9 12
```

Внешний цикл выбирает строку (`row` равен 1, 2, 3). Для каждой строки внутренний цикл проходит четыре столбца и собирает числа в строку `line`. Обратите внимание: `line` объявляется **внутри** внешнего цикла, потому что для каждой строки таблицы нужна новая пустая строка. Всего тело внутреннего цикла выполняется 3 * 4 = 12 раз. К строке `line` прибавляется число: результат склейки остаётся строкой.

## Пример 4. Символ `\n` и функции

```typescript run
function firstDivisor(n: number): number {
  let found: number = n;
  for (let d: number = 2; d < n; d++) {
    if (n % d === 0) {
      found = d;
      break;
    }
  }
  return found;
}

function triangle(rows: number): string {
  let text: string = "";
  for (let r: number = 1; r <= rows; r++) {
    if (r > 1) {
      text = text + "\n";
    }
    for (let c: number = 1; c <= r; c++) {
      text = text + "*";
    }
  }
  return text;
}

console.log(firstDivisor(15), firstDivisor(49), firstDivisor(13));
console.log(triangle(4));
```
```output
3 7 13
*
**
***
****
```

`firstDivisor(n)` ищет наименьший делитель числа `n`, больший 1. Если делитель нашёлся, переменной `found` присваивается он и цикл прерывается: дальше искать незачем. Если не нашёлся (число простое, как 13), остаётся начальное значение, само число.

В `triangle` встретился символ **`"\n"`** - в строке он обозначает переход на новую строку (в тексте его пишут как два знака, но это один символ). Когда такая строка выводится через `console.log`, текст после `\n` печатается ниже. Здесь переход добавляется перед каждой строкой, кроме первой, поэтому в конце лишнего перехода нет. Внутренний цикл добавляет столько звёздочек, каков номер строки.

**Попробуйте.** В примере 1 замените `break` на `continue` и объясните вывод. Затем напишите функцию `countPairs(n: number): number`, которая считает пары (a, b), где `a` и `b` от 1 до `n` и `a < b`. Для `n` равного 4 пар шесть.

## Точные правила

* `break;` завершает ближайший охватывающий цикл (`for`, `while` и другие). После него выполняется команда за этим циклом.
* `continue;` завершает текущую итерацию ближайшего цикла. В `for` после этого выполняется обновление счётчика и проверяется условие; в `while` обновления нет, сразу проверяется условие.
* Вне цикла (и вне `switch`) `break` и `continue` недопустимы: проверка сообщает `TS1105` для `break`.
* В `while` перед `continue` счётчик должен быть уже обновлён, иначе цикл станет бесконечным: в `for` обновление при `continue` выполняется само.
* Во вложенных циклах `break` и `continue` относятся только к внутреннему. Чтобы выйти из обоих, в функции используют `return`.
* `return` внутри цикла завершает всю функцию сразу, поэтому в функциях поиск часто пишут через `return`, а не через `break`.
* Число итераций внутреннего цикла за всё время работы равно (число итераций внешнего) * (число итераций внутреннего).
* У вложенных циклов счётчики называют по-разному (`row` и `col`, `i` и `j`): иначе внутренний «заслоняет» внешний.
* Переменная, объявленная в теле внешнего цикла, создаётся заново на каждой его итерации; именно это нужно для «пустой строки на каждую строку таблицы».
* `"\n"` - один символ перевода строки; `"\t"` - табуляция; `"\\"` - обратная косая черта.

## Типичные ошибки

**1. `break` вне цикла.**

```typescript
const limit: number = 5;
if (limit > 3) {
  break;
}
console.log(limit);
```

```text
main.ts(3,3): error TS1105: A 'break' statement can only be used within an enclosing iteration or switch statement.
```

«`break` можно использовать только внутри охватывающего цикла или `switch`». Здесь цикла нет, `break` стоит внутри обычного `if`. Чтобы выйти из функции, пишут `return`.

**2. Счётчик внутреннего цикла использован снаружи.**

```typescript
for (let row: number = 1; row <= 2; row++) {
  for (let col: number = 1; col <= 3; col++) {
    console.log(row, col);
  }
  console.log("Последний столбец:", col);
}
```

```text
main.ts(5,37): error TS2304: Cannot find name 'col'.
```

Переменная `col` существует только внутри внутреннего цикла. Нужное после него значение сохраняйте в переменной, объявленной до этого цикла.

**3. Значение найдено в цикле, а возвращается снаружи.**

```typescript
function find(): number {
  for (let i: number = 1; i <= 10; i++) {
    if (i * i > 20) {
      break;
    }
  }
  return i;
}
```

```text
main.ts(7,10): error TS2304: Cannot find name 'i'.
```

Счётчик `for` не виден после цикла. Заведите переменную до цикла (`let found: number = 0;`), присвойте ей значение перед `break` и возвращайте её.

**4. `continue` до обновления счётчика в `while`.**

```typescript
let i: number = 0;
let sum: number = 0;
while (i < 5) {
  if (i === 2) {
    continue;
  }
  sum = sum + i;
  i++;
}
```

Проверка типов ошибки не видит, но на `i` равном 2 срабатывает `continue`, до `i++` дело не доходит, и условие бесконечно истинно: цикл зависает. В `for` такой беды нет, потому что обновление счётчика стоит в шапке цикла. В `while` увеличивайте счётчик до `continue`.

**5. Сбросили накопитель не там.** Строку таблицы нужно собирать заново для каждой строки: `let line = ""` стоит внутри внешнего цикла. Если вынести её наружу, в каждой следующей строке будут и старые значения. Если же ожидается общий итог, переменную, наоборот, объявляют снаружи обоих циклов. Спросите себя: «Сколько раз нужно начинать с нуля?»

## Итоги

* `break` завершает ближайший цикл целиком; `continue` пропускает остаток текущей итерации.
* Вложенный цикл выполняется целиком на каждую итерацию внешнего; всего итераций столько, сколько их у внешнего, умноженное на число у внутреннего.
* `break` и `continue` относятся к ближайшему циклу; в функции выйти сразу из обоих помогает `return`.
* В `while` обновляйте счётчик до `continue`; в `for` обновление выполняется само.
* `"\n"` в строке означает перевод строки.
* Накопитель объявляют там, где нужно начинать с нуля: внутри внешнего цикла для строки таблицы, снаружи для общего итога.

Теперь у вас есть всё, чтобы обрабатывать не одно значение, а целый набор: [Массивы](lesson:typescript.from-zero.arrays).

## Для тех, кто уже программирует

* `break` и `continue` работают как в Java, C#, JavaScript и Go, только в Go и JavaScript есть ещё метки (`outer:`) для выхода из внешнего цикла; в курсе они не используются.
* В Python к циклам добавляется ветка `else`; в TypeScript её нет.
* В TypeScript `break` допустим ещё и в `switch`; конструкция в курсе не вводится.
* Недостижимый код после `break` или `return` не считается ошибкой компиляции в `strict`, но редактор подсвечивает его (`allowUnreachableCode`).
* Для вложенных циклов с выходом из обоих часто удобнее вынести их в функцию и использовать `return`.
