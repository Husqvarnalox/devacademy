## Зачем это нужно

Чтобы программа принимала решения, она должна уметь задавать вопросы: хватает ли денег, совершеннолетний ли покупатель, нет ли товара на складе. Ответ на такой вопрос - всегда «да» или «нет», то есть значение типа `boolean`. Сравнения и логические операторы строят такие ответы из ваших данных.

## Одна новая идея: сравнение даёт true или false

**Оператор сравнения** сопоставляет два значения и возвращает `true` или `false`:

| Запись | Значение |
|---|---|
| `a === b` | равно |
| `a !== b` | не равно |
| `a < b`, `a > b` | меньше, больше |
| `a <= b`, `a >= b` | меньше или равно, больше или равно |

Обратите внимание: равенство записывается **тремя** знаками `===`. Один знак `=` - это присваивание из урока 4, а сравнение - совсем другая операция. Тройной знак сравнивает без «поправок»: значения должны быть одного типа и одинаковые.

Несколько условий соединяют **логическими операторами**:

* `&&` - «и»: истина, если истинны обе части;
* `||` - «или»: истина, если истинна хотя бы одна часть;
* `!` - «не»: меняет `true` на `false` и обратно.

Приоритет: сначала `!`, затем сравнения, затем `&&`, затем `||`. Скобки меняют порядок.

<!-- section: examples -->
## Пример 1. Сравнения чисел

```typescript run
const x: number = 5;
console.log(x === 5, x !== 5, x < 3, x > 3, x <= 5, x >= 6);
```
```output
true false false true true false
```

Разбор: шесть вопросов о числе 5, шесть ответов. `x <= 5` истинно, потому что `5` равно `5`, а `x >= 6` ложно.

## Пример 2. Сравнение строк

```typescript run
const a: string = "Кот";
const b: string = "кот";
console.log(a === b, a.toLowerCase() === b, a !== b);
console.log("а" < "б", "10" < "9");
```
```output
false true true
true true
```

Разбор: заглавная и строчная буквы - разные символы, поэтому `a === b` ложно. `a.toLowerCase()` («в нижний регистр», подробно - в уроке 19) делает из `"Кот"` строку `"кот"`, и тогда равенство истинно. Операторы `<` и `>` сравнивают строки посимвольно, как в словаре: `"а" < "б"` истинно. Но `"10" < "9"` тоже истинно, потому что первые символы сравниваются как символы: `"1"` меньше `"9"`. Числа так сравнивать нельзя: для сравнения значений как чисел они должны быть числами.

## Пример 3. Логические операторы

```typescript run
const age: number = 20;
const hasTicket: boolean = true;
console.log(age >= 18 && hasTicket, age < 18 || hasTicket, !hasTicket);
```
```output
true true false
```

Разбор: первое - «совершеннолетний И есть билет»: оба истинны, значит `true`. Второе - «несовершеннолетний ИЛИ есть билет»: первая часть ложна, вторая истинна, значит `true`. Третье - «нет билета»: `!true` равно `false`.

## Пример 4. Диапазон и приоритет

```typescript run
const t: number = 7;
console.log(t > 0 && t < 10, t === 7 && t % 2 === 1);
console.log(false || true && false, (false || true) && false);
```
```output
true true
false false
```

Разбор: «число между 0 и 10» записывается двумя сравнениями, соединёнными `&&`: цепочка `0 < t < 10` не работает (см. ниже). Во второй строке `&&` выполняется раньше `||`, но здесь результат совпал со скобочной записью. Скобки ставьте всегда, когда смешиваете `&&` и `||`.

## Пример 5. Погрешность дробей и сравнение

```typescript run
const sum: number = 0.1 + 0.2;
console.log(sum === 0.3, Math.abs(sum - 0.3) < 0.0001);
```
```output
false true
```

Разбор: из-за неточности дробей `0.1 + 0.2` не равно в точности `0.3`. Дроби сравнивают через допустимую разницу: `Math.abs(...)` (модуль, расстояние без знака) должно быть меньше малого числа.

**Попробуйте.** Придумайте условие «возраст от 6 до 12 включительно» и проверьте его на значениях 5, 6, 12, 13.

## Точные правила

* Операторы сравнения возвращают `boolean`: `=== !== < > <= >=`.
* `===` и `!==` проверяют равенство **без** приведения типов. В курсе используется только тройная запись: двойное `==` и `!=` с неявными преобразованиями не применяются.
* Сравнение значений разных типов (`number` и `string`) бессмысленно; проверка отвергает его: `TS2367`.
* Сравнение строк `<`, `>` посимвольное и зависит от регистра; цифры в строках сравниваются как символы, не как числа.
* Дробные результаты вычислений (например, `0.1 + 0.2`) лучше не сравнивать через `===`: из-за неточности хранения они могут отличаться от ожидаемых на малую величину.
* `&&`, `||`, `!` работают с `boolean`. `a && b` истинно, если истинны оба; `a || b` истинно, если истинно хотя бы одно.
* Приоритет: `!`, затем арифметика, затем сравнения (`< > <= >=`), затем `=== !==`, затем `&&`, затем `||`. Скобки - первыми.
* Цепочку `0 < x < 10` писать нельзя: `0 < x` даёт `boolean`, и сравнивать его с `10` проверка отвергает. Правильно: `0 < x && x < 10`.
* `=` - присваивание, `===` - сравнение; перепутать их проверка поможет не всегда.

## Типичные ошибки

**1. Сравнение числа и строки.**

```typescript
const x: number = 5;
console.log(x === "5");
```

```text
main.ts(2,13): error TS2367: This comparison appears to be unintentional because the types 'number' and 'string' have no overlap.
```

«Сравнение выглядит случайным: типы `number` и `string` не пересекаются». Они никогда не равны через `===`, значит, где-то перепутаны значения. Приведите оба к одному типу. Именно такие ошибки в языках без проверки типов превращаются в молчаливое `false`.

**2. Цепочка сравнений.**

```typescript
const x: number = 5;
console.log(0 < x < 10);
```

```text
main.ts(2,13): error TS2365: Operator '<' cannot be applied to types 'boolean' and 'number'.
```

Сначала вычисляется `0 < x` и даёт `true`; сравнивать `true` с `10` бессмысленно. Запишите: `0 < x && x < 10`.

**3. Присваивание вместо сравнения.**

```typescript
console.log(3 = 3);
```

```text
main.ts(1,13): error TS2364: The left-hand side of an assignment expression must be a variable or a property access.
```

Один знак `=` - присваивание, а слева стоит число, которому ничего присвоить нельзя. Для сравнения нужно `===`.

**4. Сравнение с литералом другого значения у `const` без аннотации.**

```typescript
const city = "Омск";
console.log(city === "Томск");
```

```text
main.ts(2,13): error TS2367: This comparison appears to be unintentional because the types '"Омск"' and '"Томск"' have no overlap.
```

У `const city = "Омск"` проверка запоминает не просто `string`, а точное значение `"Омск"`, и сравнение с другим точным значением заведомо ложно. В программах значение обычно приходит откуда-то извне, и такой случай возникает только в учебных примерах. Если вам нужна переменная-«текст вообще», запишите аннотацию: `const city: string = "Омск";`.

**5. Сравнение на равенство дробей.** `0.1 + 0.2 === 0.3` ложно из-за погрешности. Сравнивайте через допустимую разницу.

**6. Забыть о приоритете `&&` и `||`.** `a || b && c` читается как `a || (b && c)`. Пишите скобки.

<!-- section: summary -->
## Итоги

* Сравнения `=== !== < > <= >=` возвращают `true` или `false`; равенство - всегда тройное `===`.
* `&&`, `||`, `!` соединяют и обращают условия; смешивая `&&` и `||`, ставьте скобки.
* Числа и строки между собой не сравниваются: проверка сообщает `TS2367`.
* «Между» записывается двумя сравнениями: `0 < x && x < 10`.

Теперь у вас есть всё, чтобы упаковать действия в повторяемый блок: [Функции](lesson:typescript.from-zero.functions).

## Для тех, кто уже программирует

* `===` и `!==` - строгое сравнение без приведения типов. Нестрогие `==` и `!=` в курсе не применяются: правила приведения неочевидны (`"" == 0`, `null == undefined`).
* Сравнение строк по значению (`"a" === "a"`), а не по ссылке, как в Java; сравнение объектов и массивов, наоборот, по ссылке.
* В отличие от JavaScript, `tsc` отвергает сравнение типов без пересечения (`5 === "5"`, `TS2367`), а цепочки `0 < x < 10` (`TS2365`) - они в JavaScript выполняются и дают неожиданный результат.
* `NaN !== NaN`: единственное значение, не равное самому себе. `tsc` отвергает прямое сравнение `x === NaN` (`TS2845`); используйте `Number.isNaN` (урок 23).
* `&&` и `||` вычисляются лениво, как в Java и C#, и возвращают один из операндов, а не обязательно `boolean`, о чём подробнее в `typescript-first-steps`.
* Приоритет `&&` выше `||`, как в большинстве языков; отдельного оператора `and`/`or` нет, как в Python.
