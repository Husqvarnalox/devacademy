## Зачем нужны функции

Правило «скидка 10 процентов» применяется на кассе сотни раз в день. Если записывать формулу заново при каждой покупке, легко ошибиться в одном из мест и трудно исправить во всех. Поэтому повторяющееся действие выносят в **функцию**: именованный блок команд, который можно запускать (вызывать) когда угодно и с разными данными. Функция работает как калькулятор с кнопкой: вы даёте числа, получаете результат.

## Одна новая идея: функция принимает значения и возвращает результат

```typescript
function double(n: number): number {
  return n * 2;
}
```

Разбор записи:

* `function` - слово «объявляю функцию»;
* `double` - имя функции;
* `(n: number)` - **параметры**: имена, под которыми функция получает данные, каждое со своим типом. Здесь один параметр `n`, число;
* `: number` после скобок - **тип результата**: что функция возвращает. Здесь число;
* `{ ... }` - **тело**: команды, которые выполнятся при вызове;
* `return n * 2;` - **возврат**: команда `return` завершает функцию и отдаёт значение туда, откуда её вызвали.

**Вызов** записывается как `double(4)`: в скобках стоят **аргументы**, реальные значения для параметров. Параметр `n` внутри функции становится равен `4`. Результат вызова - значение, которое вернул `return`; его можно напечатать, сохранить в переменную или использовать в вычислении.

Типы параметров и результата проверка сверяет в каждом вызове. В отличие от переменных, где тип можно вывести из значения, у функций параметры **всегда** аннотируют: из вызова проверка не поймёт, что вы имели в виду. Тип результата тоже записывают: он служит договором, который функция обязана выполнить.

Объявление только описывает действие. Пока функцию не вызвали, её тело не выполняется.

<!-- section: examples -->
## Пример 1. Объявить и вызвать

```typescript run
function double(n: number): number {
  return n * 2;
}
console.log(double(4));
console.log(double(2.5));
```
```output
8
5
```

Разбор: функция объявлена один раз и вызвана дважды с разными аргументами. Каждый вызов вычисляет `n * 2` для своего значения.

## Пример 2. Несколько параметров и текст

```typescript run
function greet(name: string, shop: string): string {
  return "Привет, " + name + "! Добро пожаловать в " + shop + ".";
}
console.log(greet("Анна", "пекарню"));
```
```output
Привет, Анна! Добро пожаловать в пекарню.
```

Разбор: параметры перечисляются через запятую, и у каждого свой тип. Аргументы при вызове передаются в том же порядке: первый - в `name`, второй - в `shop`.

## Пример 3. Результат можно использовать дальше

```typescript run
function add(a: number, b: number): number {
  return a + b;
}
const sum = add(2, 3) * 2;
console.log(sum, add(add(1, 2), 3));
```
```output
10 6
```

Разбор: вызов `add(2, 3)` подставляется как число 5, и дальше идёт обычное умножение. Вызов можно вложить в вызов: `add(1, 2)` даёт 3, затем `add(3, 3)` даёт 6.

## Пример 4. return и console.log - не одно и то же

```typescript run
function hello(): void {
  console.log("Привет");
}
hello();
const result = hello();
console.log(result);
```
```output
Привет
Привет
undefined
```

Разбор: `hello` ничего не возвращает. Тип такого результата называется `void` («пусто»). Она печатает внутри себя; вызванная второй раз, она напечатала снова, а в `result` оказалось `undefined`: значение «ничего нет». Вывод и возврат - разные вещи: напечатанное видит человек, возвращённое получает код, который вызвал функцию. Функцию с вычислением лучше делать возвращающей, а печатать там, где вызываешь.

## Пример 5. Проверка вызова

```typescript
function double(n: number): number {
  return n * 2;
}
console.log(double("4"));
```

```text
main.ts(4,20): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Разбор: аргумент `"4"` - текст, параметр ждёт число. Проверка сообщает об этом **в месте вызова**. Программа не запустится, пока вы не исправите аргумент.

**Попробуйте.** Напишите функцию `square(n: number): number`, возвращающую квадрат числа, и вызовите её для 3, -4 и 0.5.

## Слово export в упражнениях

В упражнениях этого курса перед `function` стоит слово `export`: `export function double(...)`. Оно делает функцию доступной другим файлам, и проверка (отдельный файл) может вызвать вашу функцию с разными значениями. Вам достаточно оставлять это слово, как есть; подробно модули объясняются в `typescript-first-steps`.

## Точные правила

* Объявление: `function имя(параметр: тип, ...): тип_результата { тело }`.
* Параметры всегда аннотируются: без типа `strict`-проверка сообщает `TS7006`.
* Тип результата записывают после скобок. Если функция ничего не возвращает, её тип результата - `void`.
* `return значение;` завершает функцию и возвращает значение. Команды после `return` не выполняются.
* Функция, у которой тип результата не `void`, обязана вернуть значение на любой ветке (`TS2355`).
* Значение, которое возвращает `return`, должно подходить типу результата (`TS2322`).
* Вызов: `имя(аргументы)`; число аргументов должно совпадать с числом параметров (`TS2554`), а их типы - с типами параметров (`TS2345`).
* Параметры существуют только внутри функции. Присваивание параметру не меняет переменную, которую передали при вызове: функция получает копию значения.
* Результат вызова - выражение; его можно печатать, сохранять, передавать другой функции.
* Объявление функции не выполняет её тело. Тело выполняется при каждом вызове.
* `export` перед `function` нужно для проверки упражнений; без него проверка не найдёт функцию.

## Типичные ошибки

**1. Аргумент не того типа.**

```typescript
function double(n: number): number {
  return n * 2;
}
console.log(double("4"));
```

```text
main.ts(4,20): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Исправьте аргумент: `double(4)`.

**2. Неверное число аргументов.**

```typescript
function add(a: number, b: number): number {
  return a + b;
}
console.log(add(1));
```

```text
main.ts(4,13): error TS2554: Expected 2 arguments, but got 1.
```

«Ожидалось 2 аргумента, получен 1». Лишние аргументы тоже ошибка: `Expected 2 arguments, but got 3.`

**3. Забыли `return`.**

```typescript
function add(a: number, b: number): number {
  a + b;
}
```

```text
main.ts(1,37): error TS2355: A function whose declared type is neither 'undefined', 'void', nor 'any' must return a value.
```

Выражение `a + b;` вычислено и тут же забыто. Напишите `return a + b;`.

**4. Вернули не тот тип.**

```typescript
function label(name: string): number {
  return "Имя: " + name;
}
```

```text
main.ts(2,3): error TS2322: Type 'string' is not assignable to type 'number'.
```

Функция обещала число, а возвращает строку. Исправьте либо тип результата, либо возвращаемое значение, в зависимости от намерения.

**5. Параметр без типа.**

```typescript
function double(n) {
  return n * 2;
}
```

```text
main.ts(1,17): error TS7006: Parameter 'n' implicitly has an 'any' type.
```

«У параметра `n` неявный тип `any`». Допишите тип: `n: number`.

**6. Опечатка в имени функции.**

```text
main.ts(4,13): error TS2552: Cannot find name 'dobule'. Did you mean 'double'?
```

Имя при вызове должно совпадать с объявлением, включая регистр.

**7. Печатать вместо возврата.** Если функция делает `console.log(n * 2)` вместо `return n * 2`, вызывающий код получит `undefined`. Вычисляющие функции возвращают значение.

<!-- section: summary -->
## Итоги

* Функция: `function имя(параметры: типы): тип_результата { ... return значение; }`.
* Вызов `имя(аргументы)` выполняет тело и даёт возвращённое значение; без вызова тело не выполняется.
* Типы параметров и результата сверяются при каждом вызове: ошибки `TS2345`, `TS2554`, `TS2355`, `TS2322` находятся до запуска.
* `return` отдаёт значение вызвавшему коду и завершает функцию; `console.log` только показывает его.
* Параметры всегда аннотируются; `void` - тип функции, которая ничего не возвращает.

Функция может принимать решения. Следующий урок - условия: [if и else](lesson:typescript.from-zero.if-else).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Синтаксис типов - после имени через двоеточие (`n: number`), результат - после скобок (`): number`), как в Kotlin и Rust, а не как в Java и C#.
* Объявления `function` всплывают (hoisting): вызвать функцию можно выше её объявления. В курсе объявляйте до использования.
* Аргументы передаются по значению для `number`, `string`, `boolean`; для массивов и объектов передаётся ссылка (уроки о коллекциях).
* Перегрузки по числу или типу параметров в смысле Java нет; значения параметров по умолчанию и необязательные параметры - в `typescript-first-steps`.
* Без `return` значение `undefined`; тип результата такой функции - `void`.
* `strict` включает `noImplicitAny`: параметр без типа - ошибка, а не молчаливый `any`. Тип результата можно вывести, но в курсе его записывают: он фиксирует договор функции.
* `export` - ключевое слово ES-модулей, `tsc` определяет по нему, что файл - модуль; здесь нужно, чтобы проверка могла импортировать функции.
