## Зачем это нужно

Покупка состоит из названия, цены и количества. Пока вы хранили такие данные в трёх переменных или в ассоциативном массиве `["name" => ..., "price" => ...]`. Это работает, но массив ничего не гарантирует: в ключе легко ошибиться, а цену можно записать строкой. Кроме того, действия над покупкой (посчитать сумму, подписать) лежат в отдельных функциях, и связь «эта функция работает с этими данными» держится только в вашей голове.

**Класс** (class) решает обе проблемы: он описывает вид данных вместе с типами полей и действиями над ними. Из класса создают сколько угодно **объектов** (objects): отдельных покупок со своими значениями.

## Одна новая идея: класс - чертёж, объект - вещь по чертежу

Класс объявляется один раз:

* **свойства** (properties) - переменные внутри объекта с типом (`public string $name`);
* **конструктор** `__construct` - особая функция, которая вызывается при создании объекта и задаёт начальные значения;
* **методы** (methods) - функции внутри класса, которые работают с данными своего объекта.

Объект создаётся выражением **`new Item("Молоко", 90, 2)`**: PHP вызывает конструктор с этими аргументами. Дальше `$milk->name` читает свойство, а `$milk->total()` вызывает метод. Стрелка `->` читается как «у объекта ... возьми ...». Внутри метода сам объект называется **`$this`** (от «этот»).

Короткая форма конструктора, **продвижение параметров** (constructor promotion): если перед параметром конструктора написать `public`, PHP сам создаст одноимённое свойство и запишет в него значение. Вместо шести строк получается одна.

## Пример 1. Класс, создание объекта, свойства

```php run
<?php
declare(strict_types=1);

class Item
{
    public function __construct(
        public string $name,
        public int $price,
        public int $quantity,
    ) {
    }
}

$milk = new Item("Молоко", 90, 2);
echo $milk->name, "\n";
echo $milk->price, "\n";
$milk->quantity = 3;
echo $milk->quantity, "\n";
```
```output
Молоко
90
3
```

Разбор: `class Item { ... }` описывает вид объекта; имена классов принято писать с заглавной буквы. Три параметра конструктора с `public` стали тремя свойствами. Тело конструктора пустое: всю работу сделало продвижение. Строка `new Item(...)` создала объект, а `->` прочитало и изменило свойство. Тип `int` защищает: записать в `quantity` текст не получится.

## Пример 2. Методы

```php run
<?php
declare(strict_types=1);

class Item
{
    public function __construct(
        public string $name,
        public int $price,
        public int $quantity,
    ) {
    }

    public function total(): int
    {
        return $this->price * $this->quantity;
    }

    public function label(): string
    {
        return "{$this->name} x {$this->quantity}";
    }
}

$milk = new Item("Молоко", 90, 2);
echo $milk->label(), " = ", $milk->total(), "\n";
$bread = new Item("Хлеб", 50, 1);
echo $bread->label(), " = ", $bread->total(), "\n";
```
```output
Молоко x 2 = 180
Хлеб x 1 = 50
```

Разбор: метод объявляется как обычная функция, но внутри класса. Внутри метода `$this->price` - цена **того объекта, у которого вызвали метод**: для `$milk` это 90, для `$bread` - 50. Поэтому метод `total()` не принимает аргументов: все данные уже есть в объекте. В строке с кавычками свойство подставляется записью `{$this->name}` в фигурных скобках. Метод, как функция, может быть с типом результата: `total(): int`.

## Пример 3. Массив объектов

```php run
<?php
declare(strict_types=1);

class Item
{
    public function __construct(
        public string $name,
        public int $price,
        public int $quantity,
    ) {
    }

    public function total(): int
    {
        return $this->price * $this->quantity;
    }
}

$items = [
    new Item("Хлеб", 50, 1),
    new Item("Сыр", 400, 1),
    new Item("Молоко", 90, 3),
];

$sum = 0;
foreach ($items as $item) {
    echo $item->name, ": ", $item->total(), "\n";
    $sum += $item->total();
}
echo "Итого: ", $sum, "\n";
```
```output
Хлеб: 50
Сыр: 400
Молоко: 270
Итого: 720
```

Разбор: объекты - обычные значения, их можно хранить в массиве и обходить через `foreach`. Переменная `$item` на каждом шаге указывает на очередной объект.

## Пример 4. Копия объекта - тот же объект

```php run
<?php
declare(strict_types=1);

class Counter
{
    public function __construct(public int $value)
    {
    }
}

$a = new Counter(1);
$b = $a;
$b->value = 10;
echo $a->value, "\n";

$c = new Counter(1);
$c->value = 2;
echo $a->value, " ", $c->value, "\n";
```
```output
10
10 2
```

Разбор: присваивание `$b = $a` не создаёт новый объект, а даёт второе имя тому же самому. Поэтому изменение через `$b` видно через `$a`. Другой объект получается только через новое `new`. Числа и строки так не работают: они копируются.

## Как разбирают строку ввода

В упражнении строка вроде `Молоко;90;2` превращается в объект:

```php
$parts = explode(";", $line);
$item = new Item($parts[0], (int) $parts[1], (int) $parts[2]);
```

`explode` режет строку по `;`, а `(int)` превращает цену и количество из строк в числа: при включённом `strict_types` конструктор не примет строку там, где объявлен `int`.

**Попробуйте.** Добавьте в `Item` метод `isExpensive(): bool`, который возвращает `true`, если `price` больше 100.

## Точные правила

* `class Имя { ... }` описывает класс; в теле - свойства и методы. Имена классов пишут в `PascalCase`, методов и свойств - в `camelCase`.
* Свойство с типом: `public int $price;`. Типизированное свойство нельзя прочитать, пока оно не получило значение (`must not be accessed before initialization`).
* `public` значит «доступно снаружи класса». Есть и `private` (только внутри класса), его подробно разбирают в следующих курсах.
* Конструктор `__construct(...)` вызывается при `new`. Параметры с модификатором (`public`, `private`, `protected`, `readonly`) автоматически становятся свойствами и инициализируются аргументами.
* `new Имя(аргументы)` создаёт объект; без `new` имя класса - не функция. Аргументы проверяются как у обычной функции, включая `strict_types`.
* `->` читает свойство или вызывает метод. Для метода нужны круглые скобки: `$x->total()`, а `$x->total` - это (несуществующее) свойство.
* Внутри метода к свойствам обращаются через `$this->имя`; просто `$имя` - обычная локальная переменная.
* Переменная хранит не сам объект, а ссылку на него (в терминологии PHP - handle): присваивание копирует ссылку, а не объект. Чтобы получить независимую копию, используют `clone`.
* Модификатор `readonly` перед свойством запрещает менять его после создания.
* Объект нельзя напечатать через `echo`: он не превращается в строку без специального метода.

## Типичные ошибки

**1. Забыли `$this->` внутри метода.**

```php
<?php
declare(strict_types=1);

class Item
{
    public function __construct(public string $name, public int $price) {}

    public function bad(): string
    {
        return $name;
    }
}
$a = new Item("Чай", 100);
echo $a->bad(), "\n";
```

```text
Warning: Undefined variable $name in main.php on line 9
```

Внутри метода `$name` - локальная переменная, которой никто не задал значение. Пишите `$this->name`.

**2. Не хватает аргументов в `new`.**

```php
<?php
declare(strict_types=1);

class Item
{
    public function __construct(public string $name, public int $price) {}
}
$a = new Item("Чай");
```

```text
Fatal error: Uncaught ArgumentCountError: Too few arguments to function Item::__construct(), 1 passed in main.php on line 7 and exactly 2 expected in main.php:5
```

**3. Неверный тип в свойстве.**

```php
<?php
declare(strict_types=1);

class Item
{
    public function __construct(public string $name, public int $price) {}
}
$a = new Item("Чай", 100);
$a->price = "дорого";
```

```text
Fatal error: Uncaught TypeError: Cannot assign string to property Item::$price of type int in main.php:8
```

**4. Забыли `new`.** Вызов `Item("Чай", 100)` без `new` ищет функцию: `Fatal error: Uncaught Error: Call to undefined function Item() in main.php:7`.

**5. Точка вместо стрелки.** В PHP `.` склеивает строки, а метод вызывают через `->`. Запись `$a.total()` ищет функцию `total` и завершается: `Fatal error: Uncaught Error: Call to undefined function total() in main.php:9`.

**6. Опечатка в имени свойства или скобки у метода.** Чтение несуществующего свойства (`$a->nme` или `$a->total` без скобок) не останавливает программу, а выдаёт `Warning: Undefined property: Item::$nme in main.php on line 10` и значение `null`. Такие предупреждения легко пропустить.

**7. Ожидали копию.** После `$b = $a` изменения через `$b` видны в `$a`, потому что объект один.

## Итоги

* Класс описывает свойства и методы, `new` создаёт объект по этому описанию.
* Конструктор с модификатором `public` перед параметрами сразу создаёт свойства (продвижение параметров).
* `->` читает свойство или вызывает метод, внутри метода собственный объект - `$this`.
* Присваивание объекта копирует ссылку: два имени указывают на один объект.

## Для тех, кто уже программирует

* Продвижение параметров конструктора (PHP 8.0) - то же, что `record` в Java или `data class` в Kotlin, но класс остаётся обычным: можно добавлять методы и менять свойства, если они не `readonly`.
* Объекты в PHP передаются по «идентификатору», как в Java: присваивание копирует дескриптор, не данные. Копия - `clone`, и она неглубокая.
* Модификаторы доступа: `public`, `protected`, `private`. Свойство без модификатора допустимо только вместе с `var` или `static`, поэтому его пишут всегда. Типизированное свойство нельзя читать до инициализации.
* Нет перегрузки методов: у класса один конструктор; альтернативы делают статическими фабриками (`static function fromLine(string $line): self`).
* Чтение несуществующего свойства даёт `Warning` и `null`, а запись в несуществующее свойство в PHP 8.2+ помечена как устаревшая (`Deprecated`).
* `readonly`-свойства (8.1) и `readonly class` (8.2) удобны для неизменяемых данных; перечисления `enum` (8.1) - отдельный механизм.
* Магические методы (`__toString`, `__get`), интерфейсы и наследование изучаются в следующих курсах.
