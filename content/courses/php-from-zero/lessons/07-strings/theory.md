## Зачем это нужно

Большая часть данных, с которыми работают программы, - это текст: имена, адреса, сообщения, названия товаров. Из кусочков нужно собирать фразы, измерять длину и приводить регистр к единому виду, чтобы, например, «АННА» и «анна» считались одним именем. Этот урок учит делать это правильно, в том числе для русского текста.

## Одна новая идея: строка - это последовательность байтов, и русская буква занимает два

Текстовое значение называют **строкой** (`string`). Две строки склеивают **оператором `.`** (точка): `"Привет, " . "мир"` даёт `"Привет, мир"`. Плюс для строк не подходит: он складывает числа.

Есть тонкость. Компьютер хранит строку как последовательность **байтов**. PHP хранит текст в кодировке **UTF-8**: латинская буква занимает 1 байт, а русская - 2. Классическая функция `strlen` считает байты, поэтому `strlen("Привет")` вернёт 12, хотя букв шесть. Для букв есть семейство функций с префиксом `mb_` (от multibyte, «многобайтовый»), они понимают UTF-8: `mb_strlen` считает буквы, `mb_strtoupper` и `mb_strtolower` меняют регистр.

Эти функции входят в расширение PHP `mbstring`. В официальных сборках и на macOS оно есть; если на вашей машине появляется ошибка `Call to undefined function mb_strlen()`, установите пакет `php-mbstring` (например, `apt install php-mbstring` в Debian и Ubuntu).

<!-- section: examples -->
## Пример 1. Склейка

```php run
<?php
$first = "Анна";
$last = "Смирнова";
$full = $first . " " . $last;
echo $full . "\n";

$price = 120;
$count = 3;
echo "Итого: " . ($price * $count) . " руб.\n";
```
```output
Анна Смирнова
Итого: 360 руб.
```

Разбор: в первой части три куска (имя, пробел, фамилия) склеены точками в одну строку. Во второй части умножение взято в скобки, чтобы PHP сначала вычислил число, а потом склеил его с текстом. Число при склейке превращается в текст автоматически.

## Пример 2. Достроить строку с помощью `.=`

```php run
<?php
$line = "Хлеб";
$line .= ": ";
$line .= 45;
$line .= " руб.";
echo $line, "\n";
```
```output
Хлеб: 45 руб.
```

`$line .= ": ";` означает `$line = $line . ": ";`: к строке дописывается кусок. Так собирают длинный текст по шагам.

## Пример 3. Длина в байтах и в буквах

```php run
<?php
echo strlen("Hello"), "\n";
echo strlen("Привет"), "\n";
echo mb_strlen("Привет"), "\n";
echo mb_strlen("Привет, мир!"), "\n";
```
```output
5
12
6
12
```

Разбор: в слове `Hello` пять латинских букв, пять байт. У слова `Привет` 6 букв по 2 байта, `strlen` вернёт 12, а `mb_strlen` - 6. Последняя строка: шесть букв, запятая, пробел, три буквы и восклицательный знак - всего 12 символов (пробел и знаки тоже считаются).

## Пример 4. Регистр

```php run
<?php
echo strtoupper("hello"), "\n";
echo strtoupper("привет"), "\n";
echo mb_strtoupper("привет"), "\n";
echo mb_strtolower("ПРИВЕТ Мир"), "\n";
echo str_repeat("-", 10), "\n";
```
```output
HELLO
привет
ПРИВЕТ
привет мир
----------
```

Разбор: `strtoupper` работает только с латинскими буквами, поэтому русский текст остаётся прежним (в том числе поэтому её нельзя использовать для сравнения без учёта регистра). `mb_strtoupper` и `mb_strtolower` обрабатывают русские буквы. `str_repeat("-", 10)` повторяет строку нужное число раз и удобна для линий-разделителей.

**Попробуйте.** Посчитайте, сколько байт займёт ваше имя, и проверьте через `strlen`. Затем сравните с `mb_strlen`. Попробуйте также `mb_strtolower` для слова с заглавной буквой.

## Точные правила

* Оператор `.` склеивает две строки; значения других типов он превращает в текст: `"Цена: " . 120` даёт `"Цена: 120"`.
* Скобки вокруг арифметики внутри склейки ставят всегда: `"Итого: " . ($a * $b)`. В PHP 8 арифметика выполняется раньше склейки, но с скобками намерение видно сразу.
* `.=` дописывает кусок: `$s .= "x"` - то же, что `$s = $s . "x"`.
* Оператор `+` для текста не определён: `"a" + "b"` - `TypeError`. (Строки, похожие на числа, `+` складывает как числа; об этом - в уроке о преобразовании.)
* `strlen($s)` возвращает число **байтов**. `mb_strlen($s)` - число символов (букв, знаков, пробелов) в UTF-8.
* `strtoupper`, `strtolower`, `ucfirst` и многие другие классические функции работают побайтово и не меняют кириллицу. Для русского текста используют `mb_strtoupper`, `mb_strtolower`.
* `str_repeat($s, $n)` повторяет строку `$n` раз.
* Расширение mbstring: если в вашем PHP его нет, функции `mb_*` не определены; в приложении предполагается PHP с mbstring.
* Подстановка `"{$x}"` и склейка дают одинаковый результат. Подстановка короче для текста с несколькими переменными; склейка нужна, когда между кусками есть вычисления или вызовы функций.

## Типичные ошибки

**1. `+` вместо `.`.**

```php
<?php
echo "Привет, " + "Анна";
```

PHP: `Fatal error: Uncaught TypeError: Unsupported operand types: string + string in main.php:2`. Для склейки нужна точка: `"Привет, " . "Анна"`.

**2. `strlen` для кириллицы.** `strlen("Привет")` - 12, а не 6. Если для проверки «пароль не короче 8 букв» взять `strlen`, русское слово из 4 букв пройдёт как 8. Используйте `mb_strlen`.

**3. `strtoupper` для русских слов.** Строка не меняется, и это не ошибка. Нужна `mb_strtoupper`.

**4. Забыли пробелы при склейке.** `"Имя:" . $name` даст `Имя:Анна`. Пробел пишут внутри текста: `"Имя: " . $name`.

**5. Неверный порядок в склейке с числами.** `"Итого: " . $a + $b . " руб."` в PHP 8 вычислит сумму раньше склейки, но читается плохо и часто путает; ставьте скобки.

**6. Нет расширения mbstring.** Сообщение `Call to undefined function mb_strlen()` означает, что в вашей сборке PHP нет mbstring: установите его.

## Итоги

* Строки склеивают оператором `.`, достраивают через `.=`; `+` для текста не подходит.
* Строка в PHP - последовательность байтов в UTF-8: латинская буква занимает 1 байт, русская - 2.
* `strlen` считает байты, `mb_strlen` - символы. Регистр русского текста меняют `mb_strtoupper` и `mb_strtolower`.
* `str_repeat` повторяет строку; число превращается в текст при склейке автоматически.

Пока все данные записаны в самой программе. Настоящие программы получают их снаружи, например от пользователя: об этом [следующий урок](lesson:php.from-zero.reading-input).

## Для тех, кто уже программирует

* Склейка - `.`, а не `+`; `+` для двух нечисловых строк даёт `TypeError` (PHP 8), для числовых строк - арифметику. В PHP 8 приоритет `+`/`-` выше, чем у `.` (в PHP 7 был равный и слева направо).
* Строки - массивы байтов без кодировки; `strlen`, `substr`, `strtoupper`, `str_pad` и т.д. работают с байтами. Для UTF-8 - `mb_*` (mbstring), для сложных случаев (графемы, нормализация) - `intl`.
* `strtoupper`/`strtolower` с PHP 8.2 не зависят от локали и работают только с ASCII. До 8.2 их результат определялся локальными настройками.
* `mb_strlen` считает кодовые точки Юникода, а не графемные кластеры: эмодзи из нескольких кодовых точек даст больше 1. `mb_strlen("😀")` равно 1, `strlen("😀")` - 4.
* Строки изменяемы по индексу (`$s[0] = 'x'`), но в курсе это не используется.
* Интерполяция `"{$x}"` и heredoc присутствуют; конкатенация с `.=` - обычный способ накопления строки в цикле.
