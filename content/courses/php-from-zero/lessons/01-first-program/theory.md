## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Такой текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется **PHP**. На нём написана значительная часть сайтов в интернете, но в курсе мы используем его проще: как язык для программ, которые запускаются в командной строке, получают текст и печатают результат. Веб-страницы, формы и серверы в курсе не нужны.

Текст на PHP сам по себе ничего не делает - его должна кто-то прочитать и выполнить. В этом курсе выполняет его программа **`php`**. Она открывает файл с исходным кодом, читает команды по порядку и исполняет их на вашем компьютере. Файл с программой называется `main.php`, а запускают его командой `php main.php`.

В приложении вам не нужно вводить эту команду вручную: вы пишете текст в редакторе, нажимаете «Запустить», и приложение само вызывает `php main.php`. Запоминать команду пока не нужно.

## Одна новая идея: команда `echo` печатает текст

Чтобы увидеть результат работы программы, её нужно заставить что-то показать. Для этого есть команда `echo` (по-английски «эхо», «повторить вслух»). Она печатает то, что написано после неё. Текст в программе записывают в кавычках: `"Касса открыта"`.

Одна строка в начале каждого файла нужна всегда: `<?php`. Честное объяснение такое: PHP придумывали для веб-страниц, поэтому файл он по умолчанию считает **обычным текстом** и просто выводит его. Строка `<?php` сообщает: «дальше идёт код, выполняй». Сейчас просто пишите её первой строкой и не меняйте. Подробно о том, что происходит с текстом вне этой строки, рассказывает курс «PHP: первые шаги».

<!-- section: examples -->
## Пример 1. Печать одной строки

```php run
<?php
echo "Касса открыта\n";
```
```output
Касса открыта
```

Разбор по строкам:

* `<?php` - сообщает, что дальше идёт код. Эта строка ничего не печатает.
* `echo` - название команды: «напечатать».
* `"Касса открыта\n"` - **строковый литерал**: текст, записанный прямо в программе, в двойных кавычках. Кавычки на экран не попадают.
* `\n` внутри текста - два знака, которые PHP читает как «перейти на новую строку». Они ничего не печатают сами, а только заканчивают строку вывода. Подробно - в [уроке про вывод](lesson:php.from-zero.output).
* `;` - точка с запятой в конце команды. Она отмечает, что команда закончилась.

## Пример 2. Несколько команд подряд

```php run
<?php
echo "Первая строка\n";
echo "Вторая строка\n";
echo "Третья строка\n";
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет.

## Пример 3. Что будет без `\n`

```php run
<?php
echo "Итого: ";
echo "450 рублей";
echo "\n";
```
```output
Итого: 450 рублей
```

Без `\n` текст следующей команды продолжает ту же строку. Новую строку начинает только знак `\n`.

**Попробуйте.** Поменяйте местами две строки в примере 2 и предскажите вывод до запуска. Затем уберите одну кавычку вокруг текста и посмотрите, что сообщит PHP (подробнее - в разделе об ошибках и в следующем уроке).

## Точные правила

* Программа - это команды в файле. PHP выполняет их сверху вниз, по одной.
* Первая строка файла - `<?php`. Закрывающий тег `?>` в этом курсе не пишется никогда.
* Каждая команда заканчивается точкой с запятой `;`.
* **Строковый литерал** записывают в двойных `"..."` или одинарных `'...'` кавычках. Внутри допустимы русские буквы, пробелы, цифры и знаки. В этом уроке используются двойные кавычки (чем они отличаются - в уроке про вывод).
* Текст в кавычках печатается как есть. Если убрать кавычки, PHP решит, что это не текст, а имя, и будет искать его.
* Названия команд (`echo`) PHP не различает по регистру: `ECHO` тоже сработает. Но в курсе принято писать их строчными буквами.
* `echo` не переводит строку сам. Чтобы вывод закончился переводом строки, в конец текста добавляют `\n`.
* Пустые строки между командами допустимы и улучшают чтение.

## Типичные ошибки

**1. Забыли точку с запятой.**

```php
<?php
echo "Привет\n"
echo "Мир\n";
```

PHP: `Parse error: syntax error, unexpected token "echo", expecting "," or ";" in main.php on line 3`. Переводится: «синтаксическая ошибка: на строке 3 встретилось слово `echo`, а ожидалась запятая или точка с запятой». Обратите внимание: PHP указал на строку 3, хотя пропуск находится в строке 2. Он понял, что команда не закончилась, только когда увидел следующее слово. Если ошибка непонятна, посмотрите на конец предыдущей строки.

**2. Не закрыли кавычки.**

```php
<?php
echo "Привет\n;
```

PHP: `Parse error: syntax error, unexpected end of file, expecting variable or "${" or "{$"`. Текст начался с кавычки и не закончился, поэтому PHP дочитал файл до конца. У каждой открывающей кавычки должна быть закрывающая.

**3. Опечатка в названии команды.**

```php
<?php
ech "Привет\n";
```

PHP: `Parse error: syntax error, unexpected double-quoted string "Привет"`. Слова `ech` PHP не знает, поэтому считает его именем, а за именем текст стоять не может. Исправьте опечатку.

**4. Забыли кавычки у текста.**

```php
<?php
echo Привет;
```

PHP: `Fatal error: Uncaught Error: Undefined constant "Привет"`. Без кавычек `Привет` - не текст, а имя, а такого имени нет. Если вы хотите напечатать слово, оно должно стоять в кавычках.

**5. Забыли `<?php`.** Если убрать первую строку, PHP не выполнит `echo`, а напечатает его как обычный текст: на экране появится `echo "Привет\n";` целиком.

Общее правило чтения: найдите номер строки (`on line N`), затем первую часть сообщения - там вид ошибки и причина. Откройте указанную строку и посмотрите на неё и на предыдущую. Подробно - в [следующем уроке](lesson:php.from-zero.reading-errors).

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; PHP - язык, а программа `php` выполняет этот текст.
* Файл начинается со строки `<?php`, а каждая команда заканчивается точкой с запятой.
* `echo "текст\n";` печатает текст и переходит на новую строку; кавычки на экран не попадают.
* Команды выполняются сверху вниз; регистр в тексте и кавычки важны.

Любая следующая программа курса устроена так же: набор команд в `main.php`. Дальше - как читать сообщения об ошибках и исправлять их.

## Для тех, кто уже программирует

* Точки входа нет: `php` выполняет файл сверху вниз. Ни `main`, ни класса-обёртки не нужно.
* `echo` - языковая конструкция, а не функция (скобки не нужны); аналог `print` в Python, `console.log` в JavaScript, `fmt.Println` в Go. Перевода строки в конце нет: `\n` пишут сами.
* `<?php` - наследие того, что PHP встраивался в HTML: всё вне тегов выводится как есть. Закрывающий `?>` в чисто программных файлах не пишут.
* В этом курсе PHP работает как язык командной строки (`php main.php`), без веб-сервера. Ошибки и предупреждения приложение направляет в stderr.
* Имена функций и ключевые слова нечувствительны к регистру, имена переменных - чувствительны.
* Точка с запятой обязательна, кроме последнего оператора перед `?>`.

<!-- section: deep-dive -->
## Что происходит при `php main.php`

Это необязательный раздел: для заданий он не нужен.

Программа `php` читает файл целиком. Всё до `<?php` она отправляет на вывод как текст, а дальше разбирает по правилам языка. Если текст не соответствует правилам (например, не закрыта кавычка), ни одна команда файла не выполняется: вы сразу видите `Parse error`.

После разбора команды превращаются во внутренний байткод и выполняются по порядку. `echo` не рисует текст сам: он передаёт его в **стандартный вывод** - поток, который операционная система присоединяет к терминалу или, как в приложении, к окну результата. Поэтому одна и та же программа может печатать на экран и в файл.

Устройство движка (Zend Engine, опкоды, кэш OPcache) разобрано в уроке [«Как выполняется PHP»](lesson:php.first-steps.how-php-runs) курса «PHP: первые шаги».
