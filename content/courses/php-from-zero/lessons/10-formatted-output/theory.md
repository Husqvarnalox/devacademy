## Зачем это нужно

Результат вычислений редко годится для показа «как есть». Сумма в чеке должна иметь два знака после точки, числа в таблице должны стоять ровно в столбик, а в тексте иногда нужен знак процента. Для этого есть функция `printf`: вы описываете **шаблон строки** и отдельно передаёте значения, которые в него вставляются.

## Одна новая идея: шаблон с местами для значений

`printf` (print formatted - «печатать по формату») принимает первым аргументом строку-**формат**, а затем значения. В формате каждое место для значения начинается со знака `%`:

* `%d` - целое число;
* `%s` - строка;
* `%F` - дробное число; между `%` и `F` можно указать точность: `%.2F` - ровно два знака после точки.

Например, `printf("Цена: %d руб.\n", 120);` напечатает `Цена: 120 руб.`: вместо `%d` подставилось 120. Всё, что не начинается с `%`, печатается как есть, в том числе `\n`: перенос строки `printf` сам не добавляет.

Между `%` и буквой можно указать **ширину** поля: `%5d` отводит под число пять символов и прижимает его к правому краю. Так числа выстраиваются в столбик.

Отдельная функция `number_format` форматирует число для показа людям: задаёт знаки после точки и разделитель тысяч.

## Пример 1. Подстановка значений

```php run
<?php
printf("Цена: %d руб.\n", 120);
printf("Привет, %s!\n", "Анна");
printf("Пи: %.2F\n", 3.14159);
printf("Скидка: %d%%\n", 15);
printf("%s купил %d шт. на %.2F руб.\n", "Иван", 3, 359.5);
```
```output
Цена: 120 руб.
Привет, Анна!
Пи: 3.14
Скидка: 15%
Иван купил 3 шт. на 359.50 руб.
```

Разбор:

* значения подставляются **по порядку**: первое значение - в первое `%`, второе - во второе;
* `%.2F` округляет до двух знаков и дописывает нули: `359.5` стало `359.50`;
* знак процента, который нужно напечатать, записывается удвоенным: `%%`;
* число значений должно совпадать с числом спецификаторов (`%`-мест).

## Пример 2. Ширина и выравнивание

```php run
<?php
printf("[%5d]\n", 42);
printf("[%-5d]\n", 42);
printf("[%05d]\n", 42);
printf("[%8.2F]\n", 3.14159);
printf("[%6s]\n", "abc");
printf("[%-6s]\n", "abc");
```
```output
[   42]
[42   ]
[00042]
[    3.14]
[   abc]
[abc   ]
```

Разбор: число перед буквой - минимальная ширина поля. Без флагов значение прижимается вправо, `-` прижимает влево, `0` дополняет нулями слева. В `%8.2F` восемь - это **вся ширина поля** вместе с точкой и дробной частью, а `.2` - число знаков после точки. Не путайте: ширина стоит перед точкой, точность - после.

## Пример 3. Чек в столбик

```php run
<?php
printf("%-8s %3d x %7.2F\n", "Chai", 3, 45.5);
printf("%-8s %3d x %7.2F\n", "Kofe", 12, 120);
printf("%-8s %3d x %7.2F\n", "Sakhar", 1, 78.25);
```
```output
Chai       3 x   45.50
Kofe      12 x  120.00
Sakhar     1 x   78.25
```

Разбор: три строки используют один и тот же формат. Название выровнено влево в поле из 8 символов, количество - вправо в поле из 3, цена - вправо в поле из 7 с двумя знаками. Названия латиницей не случайны: см. раздел с кириллицей ниже.

## Пример 4. number_format

```php run
<?php
echo number_format(1234567.891, 2, '.', ' '), "\n";
echo number_format(1234567.891, 2, '.', ''), "\n";
echo number_format(1234.5, 1, ',', ' '), "\n";
echo number_format(2.5), "\n";
```
```output
1 234 567.89
1234567.89
1 234,5
3
```

Разбор: аргументы - число, количество знаков, десятичный разделитель, разделитель тысяч. Без последних двух аргументов `number_format` ставит запятую между тысячами и точку для дробной части, а при нуле знаков округляет до целого (`2.5` даёт `3`). Чтобы получить число без разделителя тысяч, передайте пустую строку, как во второй строке.

## Пример 5. Что показывает echo без форматирования

```php run
<?php
echo 7.10, " ", 100.0, " ", 1 / 3, " ", 0.1 + 0.2, "\n";
printf("%.2F %.2F %.20F\n", 7.10, 100.0, 0.1 + 0.2);
```
```output
7.1 100 0.33333333333333 0.3
7.10 100.00 0.30000000000000004441
```

Разбор: `echo` отбрасывает незначащие нули и показывает около 14 значащих цифр, поэтому `0.1 + 0.2` выглядит как `0.3`. На самом деле хранится чуть большее значение, что и показывает `%.20F`. Для денег и таблиц точность задают явно: `%.2F`.

**Попробуйте.** Замените `%8.2F` на `%-8.2F` и на `%08.2F` в примере 2 и предскажите вывод. Затем уберите значение у одного из `printf` и посмотрите на сообщение об ошибке.

## Точные правила

* Формат: `%[флаги][ширина][.точность]буква`. Буквы: `d` - целое, `s` - строка, `F` - дробное с точкой, `x` - шестнадцатеричное, `b` - двоичное, `%` - знак процента (пишется `%%`).
* Флаги: `-` - выровнять влево, `0` - дополнить нулями слева, `+` - всегда показывать знак числа, `'*` - дополнить символом `*` (любой символ после апострофа).
* Ширина - минимальное число символов. Если значение длиннее, оно не обрезается.
* Точность для `F` - число знаков после точки, значение округляется. Для `s` точность обрезает строку.
* Значения подставляются по порядку. Недостаточно значений - `ArgumentCountError`. Лишние значения игнорируются.
* `%d` отбрасывает дробную часть (`printf("%d", 3.99)` печатает `3`), нечисловая строка превращается в `0`.
* `printf` возвращает длину напечатанной строки и сам не печатает `\n`.
* `sprintf` принимает те же аргументы, но не печатает, а возвращает строку: `$s = sprintf("%.2F", $x);`.
* Используйте `%F`, а не `%f`: `%f` зависит от локали и при некоторых настройках ставит запятую. `%F` всегда использует точку. `number_format` тоже не зависит от локали.
* **Кириллица и ширина.** `printf` и `str_pad` считают ширину в **байтах**, а буква кириллицы занимает 2 байта. Поэтому `%-10s` с русским словом даст колонку короче, чем с латинским. Выравнивайте числа через `printf`, а подписи кириллицей дополняйте пробелами вручную в тексте формата, как в упражнении.
* `number_format($x, $знаков, $десятичный, $тысячи)` возвращает строку. Округляет «от нуля» при половинке (`2.5` даёт `3`).

## Типичные ошибки

**1. Не хватает значений.**

```php
<?php
printf("%s: %d руб.\n", "хлеб");
```

```text
Fatal error: Uncaught ArgumentCountError: 3 arguments are required, 2 given
```

Формат содержит два спецификатора, а передано одно значение. Число аргументов считается вместе с самим форматом: 3 нужно, 2 передано.

**2. Забыли `\n`.** `printf("Итого: %d", 5)` не переводит строку, и следующий вывод приклеится. `echo` и `printf` не добавляют перенос сами.

**3. Знак процента без удвоения.**

```php
<?php
printf("Скидка: 15%\n");
```

```text
Fatal error: Uncaught ArgumentCountError: 2 arguments are required, 1 given
```

Для PHP `%` начинает спецификатор, и он ждёт значения. Знак процента пишут как `%%`.

**4. Перепутали ширину и точность.** `%2.8F` - это ширина 2 и 8 знаков после точки, а не наоборот. Сначала ширина, потом `.` и точность.

**5. Ждали, что `%.2F` изменит переменную.** `printf` ничего не меняет, он только печатает значение в нужном виде. Само число в переменной остаётся прежним.

**6. Выровняли кириллицу `%-10s`.** Столбцы окажутся неровными, потому что ширина считается в байтах. Для латиницы всё работает как задумано.

**7. Использовали `%d` для дробных чисел.** `printf("%d", 3.99)` печатает `3`: дробная часть отбрасывается, а не округляется. Если нужна дробь, берите `%.2F`.

## Итоги

* `printf(формат, значения...)` подставляет значения в шаблон. `%d` - целое, `%s` - строка, `%.2F` - число с двумя знаками, `%%` - знак процента.
* Число перед буквой - ширина поля: `%5d` справа, `%-5d` слева, `%05d` с нулями.
* `number_format` добавляет разделитель тысяч и задаёт знаки после точки.
* `echo` показывает числа в сокращённом виде; для точного вида применяют `printf`.
* Кириллицу `printf` выравнивает по байтам, поэтому подписи выравнивают пробелами вручную.

Теперь программа умеет читать, считать и показывать данные. Чтобы она ещё и принимала решения, нужно научиться сравнивать значения. Об этом - [следующий урок](lesson:php.from-zero.comparison-and-logic).

## Для тех, кто уже программирует

* `printf`/`sprintf` близки к C: `%d`, `%s`, `%x`, флаги `-`, `0`, `+`. Есть позиционные аргументы `%2$s %1$s` и пользовательский символ заполнения `%'*8.2F`.
* `%F` против `%f`: `%f` зависит от локали (`setlocale`), `%F` - нет. Для вывода данных и протоколов используйте `%F`.
* `number_format` возвращает строку и не зависит от локали; для денег в production используют целые копейки или BCMath, а не float.
* Ширина в `printf` и `str_pad` считается в байтах, как и `strlen`. Многобайтовый аналог `mb_str_pad` появился в PHP 8.3, `sprintf` его не имеет.
* `echo` округляет дробные числа до `precision=14` значащих цифр, поэтому `echo 0.1 + 0.2` печатает `0.3`, а `var_dump(0.1 + 0.2)` показывает кратчайшую точную запись: `float(0.30000000000000004)`.
* Строки в двойных кавычках с `{$x}` часто заменяют `printf`; формат нужен, когда важны ширина и точность.
