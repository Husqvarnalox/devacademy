## Зачем это нужно

До сих пор программа выполняла все команды подряд, сверху вниз, независимо от данных. Но реальные задачи требуют выбора: если денег хватает - оформить покупку, иначе - сообщить об этом; если возраст меньше семи лет - билет бесплатный, иначе - платный. Выбор строится на ответе «да» или «нет», а такие ответы вы получать уже умеете: это сравнения из прошлого урока.

## Одна новая идея: блок кода выполняется только при ответе «да»

Конструкция **`if`** («если») принимает **условие** - выражение, дающее `bool`, - и блок кода в фигурных скобках. Блок выполняется, только если условие истинно:

```php
if ($age >= 18) {
    echo "Взрослый\n";
}
```

Если у вопроса есть второй ответ, добавляют **`else`** («иначе»). Если вариантов больше двух, между ними ставят **`elseif`** («иначе если»). PHP проверяет условия сверху вниз и выполняет блок **первого** истинного. Остальные пропускаются, даже если их условия тоже истинны:

```php
if ($age < 7) {
    echo "Бесплатно\n";
} elseif ($age < 18) {
    echo "Детский билет\n";
} else {
    echo "Полный билет\n";
}
```

Условие записывают в круглых скобках, блок - в фигурных. Внутри блока команды сдвигают вправо на четыре пробела: так сразу видно, что относится к ветке.

<!-- section: examples -->
## Пример 1. Если - иначе

```php run
<?php
$balance = 80;
$price = 120;

if ($balance >= $price) {
    echo "Покупка оформлена\n";
} else {
    $missing = $price - $balance;
    echo "Не хватает {$missing} руб.\n";
}
echo "Конец программы\n";
```
```output
Не хватает 40 руб.
Конец программы
```

Разбор: `80 >= 120` ложно, поэтому выполнился блок после `else`. Последняя строка стоит вне блоков и выполняется всегда. Переменная `$missing` создана внутри ветки и нужна только там.

## Пример 2. Несколько вариантов

```php run
<?php
$temperature = 12;

if ($temperature < 0) {
    echo "Мороз\n";
} elseif ($temperature < 15) {
    echo "Прохладно\n";
} elseif ($temperature < 25) {
    echo "Тепло\n";
} else {
    echo "Жарко\n";
}
```
```output
Прохладно
```

Разбор: `12 < 0` ложно, `12 < 15` истинно - выполняется второй блок, остальные условия даже не проверяются. Поэтому во втором условии не нужно писать `$temperature >= 0 && $temperature < 15`: левая часть уже известна из того, что первое условие не сработало.

## Пример 3. Порядок условий важен

```php run
<?php
$score = 95;

if ($score >= 60) {
    echo "Удовлетворительно\n";
} elseif ($score >= 90) {
    echo "Отлично\n";
}
```
```output
Удовлетворительно
```

Разбор: оценка 95 подходит под оба условия, но выполняется только первый подходящий блок, и ветка «Отлично» недостижима. Условия с более жёсткой границей ставят первыми: сначала `>= 90`, потом `>= 60`.

## Пример 4. Условие с логической операцией

```php run
<?php
$hour = 23;
$isWeekend = false;

if (($hour >= 9 && $hour < 18) && !$isWeekend) {
    echo "Магазин открыт\n";
} else {
    echo "Магазин закрыт\n";
}
```
```output
Магазин закрыт
```

Разбор: условие может быть любым выражением с `bool`. Здесь рабочее время не наступило (`23 < 18` ложно), поэтому выполнена ветка `else`.

**Попробуйте.** Измените `$hour` на 10 и `$isWeekend` на `true`, предскажите результат и проверьте.

## Точные правила

* Форма: `if (условие) { ... } elseif (условие) { ... } else { ... }`. Ветки `elseif` и `else` необязательны; `else` всегда последняя и не имеет условия.
* Условие вычисляется и приводится к `bool`. Ложными считаются `false`, `0`, `0.0`, пустая строка `""`, строка `"0"`, пустой массив и `null`; всё остальное истинно. Курс записывает условия как явные сравнения, чтобы не помнить этот список.
* Выполняется не больше одного блока из цепочки: первый, чей `if`/`elseif` истинен, либо `else`, если истинных нет.
* Фигурные скобки можно опустить, если в ветке одна команда, но это источник ошибок (см. ниже). Курс всегда пишет скобки.
* `else if` (два слова) тоже работает, но внутри образует вложенный `if`; `elseif` короче и ровнее.
* Переменные, созданные внутри блока `if`, видны и после него: у блоков в PHP нет собственной области видимости.
* Блоки можно вкладывать друг в друга: `if` внутри `if`. Если вложенность больше двух уровней, условие обычно можно упростить через `&&`.
* Для проверки одного значения на много вариантов в PHP есть `switch` и `match`; они появятся позже, когда понадобятся.

## Типичные ошибки

**1. Забытые круглые скобки.**

```php
<?php
$x = 5;
if $x > 3 {
    echo "big\n";
}
```

```text
Parse error: syntax error, unexpected variable "$x", expecting "(" in main.php on line 3
```

После `if` PHP ждёт открывающую скобку. Условие всегда заключают в `(...)`.

**2. Присваивание вместо сравнения.** Запись `if ($x = 5)` не проверяет `$x`, а кладёт в него 5; результатом выражения станет 5, то есть истина. Ветка выполнится всегда. Для вопроса «равно ли» пишите `===`.

**3. Условия в неправильном порядке.** В примере 3 ветка «Отлично» никогда не выполнится. Если в цепочке `elseif` есть пересекающиеся диапазоны, строгие границы пишут первыми.

**4. Граница не там.** «Не младше 18» - это `>= 18`. Запись `> 18` исключает ровно восемнадцатилетних. Проверяйте программу на самих граничных значениях: 17, 18 и 19.

**5. Забытая закрывающая скобка.**

```php
<?php
if (5 > 3) {
    echo "big\n";
}
else {
    echo "small\n"
}
```

```text
Parse error: syntax error, unexpected token "}", expecting "," or ";" in main.php on line 7
```

На самом деле пропущена `;` в конце строки 6, а PHP замечает это на следующем токене. Ищите ошибку на строке выше указанной.

**6. Две команды под `if` без скобок.** Если написать `if ($t > 10)` и под ним две сдвинутые вправо строки `echo "A\n";` и `echo "B\n";`, то условию подчиняется только первая из них, а вторая выполнится всегда: сдвиг для PHP ничего не значит. Пишите скобки всегда.

## Итоги

* `if (условие) { ... }` выполняет блок, только если условие истинно; `else` - запасной вариант, `elseif` - дополнительные.
* PHP проверяет ветки сверху вниз и выполняет только первую подходящую; порядок условий важен.
* Условие - выражение с `bool`; граничные значения (`>=` против `>`) проверяйте отдельно.
* `=` присваивает, `===` сравнивает.

Теперь программа умеет выбирать. Чтобы повторять действие много раз, нужны циклы: начнём с [цикла while](lesson:php.from-zero.while-loop).

## Для тех, кто уже программирует

* Синтаксис как в C и Java: условие в скобках, блок в `{}`. Ветка «иначе если» пишется `elseif` (допустим и `else if`); слова `elif`, как в Python, нет.
* Условие приводится к `bool` по правилам PHP: `"0"` и `[]` ложны, а `"0.0"` и `" "` истинны. Это отличается от JS (там `[]` истинно) и от Python (там `"0"` истинно).
* Область видимости функциональная, а не блочная: переменная из `if` живёт до конца функции.
* Есть альтернативный синтаксис `if (...): ... endif;`, популярный в шаблонах. Тернарный оператор `?:` и `??` встречаются часто, но в курсе пока не используются.
* `switch` сравнивает нестрого (`==`), поэтому в новом коде его чаще заменяют на `match`, где сравнение строгое.
