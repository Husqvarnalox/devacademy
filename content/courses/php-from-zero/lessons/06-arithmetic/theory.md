## Зачем это нужно

Компьютер был придуман для вычислений, и почти любая программа что-то считает: сумму заказа, скидку, время, средний балл. В этом уроке вы научитесь записывать вычисления и понимать, какой результат получится: целый или дробный, с остатком или без.

## Одна новая идея: выражение - это вычисление, результат которого можно сохранить

**Выражение** - запись, которую PHP вычисляет и получает значение. Основные операции:

| Запись | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `10 + 5` | `15` |
| `-` | вычитание | `10 - 5` | `5` |
| `*` | умножение | `10 * 5` | `50` |
| `/` | деление | `10 / 4` | `2.5` |
| `%` | остаток от деления | `10 % 4` | `2` |
| `**` | возведение в степень | `2 ** 10` | `1024` |

Для деления с отбрасыванием дробной части есть функция **`intdiv`** (от integer division, «целочисленное деление»): `intdiv(10, 4)` даёт `2`. Для округления есть `round` (до ближайшего целого или до заданного числа знаков), `floor` (вниз) и `ceil` (вверх).

Результат выражения записывают в переменную: `$total = $price * $count;`. Порядок такой же, как в математике: сначала `**`, затем `*`, `/`, `%`, затем `+`, `-`. Скобки меняют порядок.

<!-- section: examples -->
## Пример 1. Стоимость покупки

```php run
<?php
$price = 120;
$count = 3;
$total = $price * $count;
echo "Итого: {$total}\n";
```
```output
Итого: 360
```

Разбор: PHP вычисляет правую часть `$price * $count` (120 умножить на 3), получает 360 и кладёт результат в `$total`. Только после этого выполняется следующая команда.

## Пример 2. Деление, целая часть и остаток

```php run
<?php
echo 7 / 2, "\n";
echo 6 / 2, "\n";
echo intdiv(7, 2), "\n";
echo 7 % 2, "\n";
$minutes = 135;
echo intdiv($minutes, 60), " ч ", $minutes % 60, " мин\n";
```
```output
3.5
3
3
1
2 ч 15 мин
```

Разбор:

* `7 / 2` - точное деление, `3.5`. `6 / 2` делится нацело, и результат `3`: когда деление без остатка, PHP возвращает целое число.
* `intdiv(7, 2)` - целая часть деления, `3`. `7 % 2` - остаток, `1`: 7 = 2 * 3 + 1.
* Пара `intdiv` и `%` разбирает 135 минут на целые часы и оставшиеся минуты: 135 = 60 * 2 + 15.

## Пример 3. Порядок действий и скобки

```php run
<?php
echo 2 + 3 * 4, "\n";
echo (2 + 3) * 4, "\n";
echo 2 ** 10, "\n";
echo 100 - 30 - 20, "\n";
echo 20 / 4 / 5, "\n";
```
```output
14
20
1024
50
1
```

Разбор: умножение выполняется раньше сложения; скобки меняют порядок. Операции одного уровня (`-`, `/`) выполняются слева направо: `100 - 30 - 20` это `(100 - 30) - 20`.

## Пример 4. Округление

```php run
<?php
echo round(3.14159, 2), "\n";
echo round(2.5), "\n";
echo floor(3.7), "\n";
echo ceil(3.2), "\n";
var_dump(floor(3.7));
```
```output
3.14
3
3
4
float(3)
```

Разбор: `round(x, 2)` округляет до двух знаков, `round(2.5)` - до целого (половина округляется «от нуля», то есть вверх по модулю). `floor` отбрасывает дробную часть вниз, `ceil` поднимает вверх. Все три функции возвращают **float** (последняя строка показывает `float(3)`), хотя `echo` печатает его без `.0`.

## Пример 5. Сокращённое присваивание

```php run
<?php
$x = 10;
$x += 5;
echo $x, "\n";
$x -= 3;
$x *= 2;
echo $x, "\n";
$x++;
echo $x, "\n";
```
```output
15
24
25
```

Запись `$x += 5;` означает `$x = $x + 5;`. Аналогично `-=`, `*=`, `/=`, `%=`. Команда `$x++` прибавляет 1 (а `$x--` вычитает).

## Пример 6. Дробные числа неточны

```php run
<?php
echo 0.1 + 0.2, "\n";
var_dump(0.1 + 0.2);
```
```output
0.3
float(0.30000000000000004)
```

Компьютер хранит дроби в двоичной записи, и число 0.1 в ней представимо только приблизительно. `echo` показывает 14 значащих цифр и скрывает погрешность, а `var_dump` показывает точное значение. Поэтому результаты вычислений с дробями не сравнивают на равенство (урок о сравнении), а при выводе округляют.

**Попробуйте.** Вычислите на бумаге, а затем проверьте программой: `echo 17 % 5;`, `echo intdiv(17, 5);`, `echo 2 ** 3 ** 2;`. Что даст последнее выражение, если сначала возвести 3 в степень 2?

## Точные правила

* Приоритет: `**`, затем `*`, `/`, `%`, затем `+`, `-`. Скобки выполняются первыми. Операции одного уровня идут слева направо, кроме `**`: он выполняется справа налево (`2 ** 3 ** 2` - это `2 ** 9` = 512).
* `/` даёт `int`, если деление нацело, иначе `float`. `intdiv` всегда возвращает `int`.
* Знак остатка `%` совпадает со знаком делимого: `-7 % 3` даёт `-1`. Операнды `%` приводятся к целым: дробная часть отбрасывается и PHP предупреждает.
* `intdiv(-7, 2)` даёт `-3`: дробная часть отбрасывается в сторону нуля.
* `round`, `floor`, `ceil` возвращают `float`. Для денег и точных величин используйте целые числа (копейки) или округление при выводе.
* Деление на ноль: `/` и `intdiv` бросают `DivisionByZeroError: Division by zero`, `%` - `Modulo by zero`. Программа останавливается.
* `$x += 5` эквивалентно `$x = $x + 5`. Так же `-=`, `*=`, `/=`, `%=`, `**=`. `++` и `--` меняют значение на 1.
* Дробные числа хранятся приблизительно; `echo` показывает 14 значащих цифр.

## Типичные ошибки

**1. Ожидать целое число от `/`.** `echo 7 / 2;` печатает `3.5`, а не `3`. Для целой части - `intdiv(7, 2)`.

**2. Деление на ноль.**

```php
<?php
echo 5 / 0;
```

PHP: `Fatal error: Uncaught DivisionByZeroError: Division by zero in main.php:2`. Программа останавливается. Для `%` сообщение будет `Modulo by zero`. Перед делением проверяют делитель (после урока об условиях).

**3. `^` вместо `**`.** В PHP `2 ^ 3` - не степень, а побитовая операция «исключающее или»: результат `1`, а не `8`. Для степени - `**`.

**4. Знак `x` вместо `*` и запятая в числах.** Умножение - `*`. `3,5` вместо `3.5` - Parse error.

**5. Порядок действий.** `echo 10 - 2 * 3;` печатает `4`, а не `24`. Нужен другой порядок - ставьте скобки.

**6. Сравнивать результаты вычислений с дробями на равенство.** `0.1 + 0.2` не равно `0.3`. Подробнее - в уроке о сравнении.

**7. Остаток от дробного числа.** `10 % 4.5` даёт `Deprecated: Implicit conversion from float 4.5 to int loses precision`: оператор `%` работает с целыми.

<!-- section: summary -->
## Итоги

* Операции `+ - * / % **` работают как в математике, скобки меняют порядок.
* `/` может дать дробь; `intdiv` даёт целую часть, `%` - остаток. Вместе они делят число на «целые» и «остаток».
* `round`, `floor`, `ceil` округляют до ближайшего, вниз и вверх.
* `+=`, `-=`, `*=` и `++` сокращают записи вида `$x = $x + 5`.
* Дробные числа неточны, деление на ноль - ошибка.

Числа мы научились считать, теперь займёмся текстом: склейка, длина, регистр. Об этом - [следующий урок](lesson:php.from-zero.strings).

## Для тех, кто уже программирует

* `/` возвращает `int`, если операнды целые и деление нацело, иначе `float`: `6 / 2` - `int(3)`, `7 / 2` - `float(3.5)`. Целочисленное деление - `intdiv()` (оператора `//` нет: `//` начинает комментарий).
* `**` правоассоциативен: `2 ** 3 ** 2 = 512`; `-2 ** 2` равно `-4`, как в Python.
* `%` усекает операнды до `int`; знак результата - знак делимого (как в C, Java, JS, в отличие от Python). Для остатка по модулю у `float` есть `fmod()`.
* Деление на ноль - `DivisionByZeroError` для `/`, `intdiv()` и `%`; `fdiv()` возвращает `INF`/`NAN` без исключения.
* Переполнение `int` приводит к `float`, а не к оборачиванию (подробнее в `php-first-steps`, урок 01).
* `round()` округляет половину от нуля (`round(2.5)` - `3`, `round(-2.5)` - `-3`), а не банковским способом; возвращает `float`.
* `^` - побитовое XOR, степень - `**`.
* `$i++` возвращает старое значение, `++$i` - новое; `+=`, `.=`, `??=` присутствуют.
