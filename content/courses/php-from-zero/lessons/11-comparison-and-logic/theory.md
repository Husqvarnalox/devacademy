## Зачем это нужно

Программа становится полезной, когда умеет отвечать на вопросы о данных: хватает ли денег, прошёл ли студент, подходит ли возраст, пуста ли строка. Ответ на такой вопрос - одно из двух значений: «да» или «нет». В PHP это значения `true` и `false` типа `bool`, которые вы уже встречали. Сравнения и логические операции учат получать их из данных. В следующем уроке по такому ответу программа будет выбирать, что делать.

## Одна новая идея: выражение-вопрос, ответ которого bool

**Оператор сравнения** сопоставляет два значения и даёт `bool`:

| Запись | Вопрос |
|---|---|
| `$a === $b` | равны ли значение и тип |
| `$a !== $b` | различаются ли значение или тип |
| `$a < $b`, `$a > $b` | меньше, больше |
| `$a <= $b`, `$a >= $b` | меньше или равно, больше или равно |

Знак `=` - присваивание, он кладёт значение в переменную. Для вопроса «равны ли» нужны три знака: `===`.

**Логические операторы** соединяют несколько ответов:

* `A && B` - «и»: истинно, когда истинны обе части;
* `A || B` - «или»: истинно, когда истинна хотя бы одна;
* `!A` - «не»: меняет `true` на `false` и наоборот.

Пример: «возраст не меньше 18 и есть билет» - это `$age >= 18 && $hasTicket`.

В PHP есть ещё `==`, который сравнивает «мягко», приводя типы. Его результаты неожиданны, поэтому в курсе используется только `===`.

## Пример 1. Сравнения

```php run
<?php
var_dump(5 > 3);
var_dump(5 < 3);
var_dump(5 >= 5);
var_dump(5 <= 4);
var_dump(5 === 5);
var_dump(5 !== 5);
var_dump("apple" < "banana");
var_dump("a" === "a");
```
```output
bool(true)
bool(false)
bool(true)
bool(false)
bool(true)
bool(false)
bool(true)
bool(true)
```

Разбор: каждое выражение - вопрос, `var_dump` показывает ответ. Строки сравниваются по алфавиту (точнее, по кодам байтов), поэтому `"apple" < "banana"` истинно. Граница входит в ответ только у `>=` и `<=`: `5 >= 5` истинно, `5 > 5` было бы ложно.

## Пример 2. === и == для значений разных типов

```php run
<?php
var_dump(5 === "5");
var_dump(5 == "5");
var_dump(1 === 1.0);
var_dump(1 == 1.0);
var_dump(null === false);
var_dump(null == false);
var_dump("1" == "01");
var_dump("10" == "1e1");
```
```output
bool(false)
bool(true)
bool(false)
bool(true)
bool(false)
bool(true)
bool(true)
bool(true)
```

Разбор: `===` требует, чтобы совпадали и значение, и тип: число `5` и строка `"5"`, целое `1` и дробное `1.0`, `null` и `false` для него разные. Оператор `==` сначала приводит значения друг к другу, и получаются утверждения вроде «`"1"` равно `"01"`» и «`"10"` равно `"1e1"`»: обе строки похожи на числа, и PHP сравнивает их как числа. Результат такого сравнения нужно помнить наизусть, а `===` ведёт себя одинаково всегда.

## Пример 3. Логические операции

```php run
<?php
$age = 20;
$hasTicket = true;
var_dump($age >= 18 && $hasTicket);
var_dump($age < 18 || !$hasTicket);
var_dump(!true);
var_dump(true || false && false);
var_dump((true || false) && false);
```
```output
bool(true)
bool(false)
bool(false)
bool(true)
bool(false)
```

Разбор:

* первая строка: обе части истинны, значит, `true`;
* вторая: `20 < 18` ложно, `!$hasTicket` тоже ложно, значит, `false`;
* четвёртая и пятая показывают приоритет. `&&` вычисляется раньше `||`, поэтому `true || false && false` - это `true || (false && false)`, то есть `true`. Скобки в пятой строке меняют порядок, и результат становится `false`. Если выражение смешивает `&&` и `||`, ставьте скобки: так видно задуманный порядок.

## Пример 4. Дробные числа

```php run
<?php
var_dump(0.1 + 0.2 === 0.3);
var_dump(abs(0.1 + 0.2 - 0.3) < 0.0001);
```
```output
bool(false)
bool(true)
```

Разбор: `0.1 + 0.2` хранится как `0.30000000000000004`, поэтому точное равенство ложно. Вместо него проверяют, что разность по модулю (`abs`) меньше допустимой погрешности. Для денег часто хранят целые копейки: `1999` вместо `19.99`.

**Попробуйте.** Предскажите `var_dump(10 > 5 && 5 > 1);`, `var_dump("a" === "A");` и `var_dump(!(3 === 3));`, затем проверьте.

## Точные правила

* Любое сравнение даёт значение типа `bool`. Его можно положить в переменную: `$adult = $age >= 18;`.
* `===` истинно, если типы совпадают и значения равны. `!==` - его отрицание.
* `==` и `!=` перед сравнением приводят типы. В PHP 8 `0 == "abc"` ложно, а `"1" == "01"` и `"10" == "1e1"` истинны: если обе строки числовые, сравниваются числа. `null == false` и `0 == ""`: первое истинно, второе ложно. Курс применяет `===` и `!==`.
* `<`, `>`, `<=`, `>=` сравнивают числа как числа, а две нечисловые строки - побайтово. Сравнивать число со строкой без явного приведения не стоит.
* Сравнения нельзя записывать цепочкой: `1 < 2 < 3` - синтаксическая ошибка. Пишут `1 < 2 && 2 < 3`.
* `&&` и `||` вычисляются слева направо и **коротко**: если результат уже известен по левой части, правая не выполняется. `false && f()` не вызывает `f()`, `true || f()` тоже.
* Приоритет: сначала `!`, затем арифметика, затем сравнения, затем `&&`, затем `||`. Присваивание вычисляется последним.
* Те же операции есть в словесной форме `and`, `or`, но у них приоритет ниже присваивания: `$r = true and false;` кладёт в `$r` значение `true`. Используйте `&&` и `||`.
* Сравнение со `<=>` («космический корабль») возвращает `-1`, `0` или `1`; оно пригодится при сортировке.
* Дробные числа на равенство не сравнивают. Проверяют близость: `abs($a - $b) < $epsilon`.
* `echo true` печатает `1`, `echo false` - пустую строку. Для просмотра `bool` служит `var_dump`.

## Типичные ошибки

**1. Присваивание вместо сравнения.** Запись `$a = 5` кладёт 5 в переменную, а не проверяет её. Вопрос «равно ли» пишется `$a === 5`.

**2. Цепочка сравнений.**

```php
<?php
var_dump(1 < 2 < 3);
```

```text
Parse error: syntax error, unexpected token "<"
```

Нужно два сравнения: `1 < 2 && 2 < 3`.

**3. `=>` вместо `>=`.** Оператор «больше или равно» пишется `>=`: знак больше стоит первым. Запись `=>` в PHP относится к массивам и в сравнении вызовет `Parse error`.

**4. `>` там, где граница входит в условие.** «Не меньше 60» - это `>= 60`. С `> 60` оценка 60 не пройдёт. Всегда проверяйте граничные значения.

**5. Точное сравнение дробных чисел.** `0.1 + 0.2 === 0.3` ложно. Сравнивайте с погрешностью или работайте с целыми.

**6. Смешанный `&&` и `||` без скобок.** `$a || $b && $c` читается как `$a || ($b && $c)`. Если вы задумывали `($a || $b) && $c`, нужны скобки.

**7. Сравнение строки и числа через `===`.** Введённое число приходит строкой: `"5" === 5` ложно. Сначала приведите: `(int) trim(fgets(STDIN))`, как в упражнении.

## Итоги

* Сравнения `===`, `!==`, `<`, `>`, `<=`, `>=` дают `bool`; `=` - присваивание, а не сравнение.
* Курс использует `===`: он сравнивает значение и тип и не делает скрытых преобразований.
* `&&` - «и», `||` - «или», `!` - «не»; смешивая `&&` и `||`, ставьте скобки.
* Дробные числа сравнивают с допустимой погрешностью, а не через `===`.

Теперь программа может получить ответ «да» или «нет». В [следующем уроке](lesson:php.from-zero.if-else) такой ответ станет основанием для выбора: выполнять один блок кода или другой.

## Для тех, кто уже программирует

* `==` в PHP - слабое сравнение. В PHP 8 строка с числом сравнивается как число только если строка числовая: `0 == "abc"` теперь `false` (в PHP 7 было `true`), но `"1" == "01"`, `"10" == "1e1"` и `100 == "1e2"` по-прежнему `true`. Используйте `===`, как в JS и TS, и `!==`.
* `&&`, `||`, `!` возвращают настоящий `bool` (не последнее вычисленное значение, как в JS или Python). Короткое вычисление есть.
* `and`, `or`, `xor` - те же операции с очень низким приоритетом (ниже `=`), поэтому `$x = a() or b()` - не то же самое, что `$x = (a() or b())`. Это источник тихих ошибок.
* Цепочки `a < b < c` запрещены (в Python разрешены). `<=>` возвращает `-1`/`0`/`1`.
* Для `null` есть оператор `??` и проверки `isset`/`is_null`; они появятся позже.
* При сравнении массивов `==` сравнивает пары ключ-значение, `===` - ещё и порядок и типы.
