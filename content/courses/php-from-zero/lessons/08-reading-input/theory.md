## Зачем это нужно

До сих пор все данные были записаны прямо в программе. Но полезная программа работает с чужими данными: пользователь вводит имя, другая программа передаёт список, файл содержит таблицу. Всё, что программа получает снаружи, называется **вводом**. В этом уроке вы научитесь читать строки ввода и очищать их от лишних знаков.

## Одна новая идея: ввод приходит как строка, и её нужно очистить

Ввод поступает в программу через **стандартный ввод** (stdin): это канал, по которому данные попадают в программу. Если вы запускаете `php` в терминале, это клавиатура; в приложении текст берётся из специального поля, которое вы заполняете перед запуском (подробно - в подразделе «Как подать ввод своей программе» ниже), а при проверке решения его подаёт тест. В PHP, запущенном из командной строки, стандартный ввод доступен как константа **`STDIN`**.

Прочитать одну строку помогает функция **`fgets`** (от file get string, «получить строку из файла»):

```php
$line = fgets(STDIN);
```

У `fgets` две особенности:

* Она возвращает строку **вместе с переводом строки** в конце. Ввод `Анна` и Enter превращается в `"Анна\n"`.
* Когда ввод закончился, `fgets` возвращает `false` - значение «читать больше нечего».

Чтобы убрать перевод строки и лишние пробелы по краям, применяют **`trim`**:

```php
$name = trim(fgets(STDIN));
```

Читается изнутри наружу: сначала `fgets` читает строку, затем `trim` отрезает пробельные символы (пробелы, табуляции, `\n`, `\r`) с обоих концов. Каждый новый вызов `fgets(STDIN)` читает **следующую** строку.

Ещё одно правило: программа **не печатает приглашений** («Введите имя:»). Проверка сравнивает весь вывод, поэтому программа выводит только результат.

## Как подать ввод своей программе

1. Под редактором откройте вкладку **«Вывод»**.
2. Нажмите на строку **«Ввод программы (stdin)»**: под ней раскроется поле.
3. Впишите в поле весь ввод заранее: каждое значение на своей строке, потому что один вызов `fgets(STDIN)` читает одну строку. Например, для примера 2 впишите `Иван` на первой строке и `Самара` на второй.
4. Нажмите **«Запустить»**.

Программа не останавливается и не ждёт, пока вы что-то напечатаете: всё, что записано в поле, она получает сразу при запуске. Если поле пустое, ввод пустой (что тогда происходит, показано в примере 4). Пока урок открыт, текст в поле остаётся, так что для следующего запуска достаточно поменять данные.

Кнопка **«Проверить решение»** это поле не использует: она запускает программу на вводе каждого теста по очереди.

<!-- section: examples -->
## Пример 1. Прочитать имя и поприветствовать

Эту программу нельзя запустить в окне примеров, потому что у неё нет ввода, поэтому ниже приведены ввод и вывод.

```php
<?php
$name = trim(fgets(STDIN));
echo "Привет, {$name}!\n";
```

Ввод:

```text
Анна
```

Вывод:

```text
Привет, Анна!
```

Разбор: `fgets(STDIN)` вернула `"Анна\n"`, `trim` убрала `\n`, и `$name` содержит `"Анна"`. Без `trim` восклицательный знак оказался бы на следующей строке.

## Пример 2. Две строки

```php
<?php
$name = trim(fgets(STDIN));
$city = trim(fgets(STDIN));
echo "{$name} живёт в городе {$city}\n";
```

Ввод:

```text
Иван
Самара
```

Вывод:

```text
Иван живёт в городе Самара
```

Вторая команда `fgets` читает вторую строку: ввод обрабатывается по порядку, строка за строкой.

## Пример 3. Как работает trim

```php run
<?php
var_dump(trim("  Анна \n"));
var_dump(trim("\r\nСамара\r\n"));
var_dump(trim("Анна Иванова"));
```
```output
string(8) "Анна"
string(12) "Самара"
string(23) "Анна Иванова"
```

Разбор: `trim` убирает пробельные символы только по краям (`\r` встречается в текстах, созданных в Windows). Пробел внутри «Анна Иванова» остался. Числа в скобках - длина в байтах: «Анна» занимает 8 байт.

## Пример 4. Когда ввода нет

```php run
<?php
var_dump(fgets(STDIN));
```
```output
bool(false)
```

В окне примеров стандартный ввод пуст, поэтому `fgets` вернула `false`. Если программа читает больше строк, чем ей дали, `fgets` вернёт `false`, а `trim(false)` даст пустую строку. В уроке про чтение всего ввода вы научитесь отличать конец ввода от пустой строки.

**Попробуйте.** Уберите `trim` из примера 1 и подайте ввод `Анна`: восклицательный знак окажется на второй строке вывода. Это и есть причина, по которой `trim` нужен почти всегда.

## Точные правила

* `STDIN` - готовая константа, она существует только при запуске PHP из командной строки. Регистр важен: `stdin` - ошибка `Undefined constant "stdin"`.
* `fgets(STDIN)` читает одну строку до `\n` включительно. Если в последней строке перевода строки нет, она возвращается без него.
* При конце ввода `fgets` возвращает `false`.
* `trim($s)` возвращает копию строки без пробельных символов (пробел, `\t`, `\n`, `\r` и некоторые другие) в начале и конце. Исходная переменная не меняется, поэтому результат нужно присвоить: `$name = trim($name);`.
* Есть `ltrim` (только слева) и `rtrim` (только справа).
* Вся вводимая информация приходит строками: число `42` из ввода - строка `"42"`. Как превратить её в число - в следующем уроке.
* Не печатайте приглашений и пояснений: тесты сравнивают весь вывод.
* Пустая строка во вводе - это строка `"\n"`, а после `trim` - `""`. Это не то же самое, что конец ввода (`false`).

## Типичные ошибки

**1. Не вызвали `trim`.** Строка `"Анна\n"` содержит перевод строки. При печати `"Привет, " . fgets(STDIN) . "!"` восклицательный знак окажется на следующей строке, а при сравнении строк `"Анна\n"` не равна `"Анна"`.

**2. Прочитали меньше строк, чем нужно.** Если ввод содержит имя и город, а программа вызвала `fgets` один раз, город останется непрочитанным.

**3. Приглашения.** `echo "Введите имя: ";` добавит в вывод лишний текст, и проверка не пройдёт.

**4. `stdin` вместо `STDIN`.**

```php
<?php
$x = fgets(stdin);
```

PHP: `Fatal error: Uncaught Error: Undefined constant "stdin" in main.php:2`. Константа пишется заглавными буквами.

**5. Ожидать, что `trim` изменит переменную.** Запись `trim($name);` без присваивания ничего не меняет. Нужно `$name = trim($name);`.

**6. Пустой ввод.** Если программа запущена без ввода, `fgets` вернёт `false`. В этом случае `trim(false)` даёт пустую строку, а значит программа напечатает приветствие без имени. Ввод в упражнениях всегда есть, но в настоящих программах это нужно проверять.

## Итоги

* Стандартный ввод в PHP из командной строки - `STDIN`; одну строку читает `fgets(STDIN)`.
* `fgets` возвращает строку с переводом строки в конце, а при конце ввода - `false`.
* `trim` убирает пробельные символы по краям; привычная форма - `$x = trim(fgets(STDIN));`.
* Ввод всегда приходит строками; приглашения печатать не нужно.

Вводимое число - всё ещё строка. Как превратить её в число и проверить, что это число, - в [следующем уроке](lesson:php.from-zero.type-conversion).

## Для тех, кто уже программирует

* `STDIN`, `STDOUT`, `STDERR` - константы-потоки, определённые только в CLI. В веб-режиме их нет; там данные приходят из `$_GET`/`$_POST`/`php://input`.
* `fgets(STDIN)` аналог `input()` в Python, но строка приходит с `\n`; возвращает `false` на EOF (в Python - `EOFError`, в Go - ошибка). Проверять следует строго: `fgets(...) !== false`.
* Есть и другие способы: `readline()` (расширение может отсутствовать), `file('php://stdin')`, `stream_get_contents(STDIN)`, `fscanf(STDIN, "%d", $n)`. В курсе - `fgets` + `trim`, чтобы поведение было одинаковым везде.
* `trim` убирает по умолчанию ` \n\r\t\v\0`; второй аргумент задаёт набор символов. `mb_trim` появился в PHP 8.4 и учитывает Юникод-пробелы.
* В режиме `declare(strict_types=1)` вызов `trim(false)` - TypeError; поэтому при возможном конце ввода проверяют `false` до `trim`.
* Вывод в stdout и ввод из stdin буферизуются независимо; приглашения не нужны ни для корректности, ни для проверки.
