## Зачем это нужно

Компьютер хранит и обрабатывает значения по-разному: числа можно складывать, текст - склеивать, а ответ «да/нет» - использовать в условии. Чтобы понимать, что получится, нужно знать, к какому **типу** относится значение. Тип - это вид значения, он определяет, что с ним можно делать.

## Одна новая идея: у каждого значения есть тип

В этом уроке пять основных типов PHP:

| Тип | Что хранит | Как записывают |
|---|---|---|
| `int` | целое число | `42`, `-7`, `0` |
| `float` | дробное число | `3.14`, `0.5`, `2.0` |
| `string` | текст | `"Привет"`, `'Чай'` |
| `bool` | логическое значение «истина/ложь» | `true`, `false` |
| `null` | «значения нет» | `null` |

Число и текст, похожий на число, - разные вещи: `42` без кавычек - это `int`, а `"42"` в кавычках - `string`. В PHP тип принадлежит **значению**, а не переменной: сначала в `$a` можно положить число, потом текст.

Чтобы увидеть тип, есть две функции. **`var_dump($x)`** печатает тип и значение, это главный инструмент отладки. **`get_debug_type($x)`** печатает только имя типа одним словом: `int`, `float`, `string`, `bool`, `null`.

<!-- section: examples -->
## Пример 1. Пять типов в var_dump

```php run
<?php
var_dump(42);
var_dump(3.14);
var_dump("Привет");
var_dump(true);
var_dump(null);
```
```output
int(42)
float(3.14)
string(12) "Привет"
bool(true)
NULL
```

Разбор: `var_dump` печатает тип, а затем в скобках значение. Для текста в скобках стоит длина в **байтах**: `Привет` занимает 12 байт, потому что каждая русская буква в кодировке UTF-8 занимает два байта (подробно - в [уроке о строках](lesson:php.from-zero.strings)). Значение `null` var_dump печатает как `NULL`.

## Пример 2. Число и похожий на число текст

```php run
<?php
var_dump(42);
var_dump("42");
var_dump(4.0);
var_dump("");
```
```output
int(42)
string(2) "42"
float(4)
string(0) ""
```

Одно и то же «42» может быть числом и текстом - по кавычкам. Запись `4.0` даёт `float`, даже если дробная часть нулевая. Пустой текст `""` - это строка нулевой длины, а не `null`.

## Пример 3. Тип принадлежит значению

```php run
<?php
$x = 7;
echo get_debug_type($x), "\n";
$x = "семь";
echo get_debug_type($x), "\n";
$x = 2.5;
echo get_debug_type($x), "\n";
$x = false;
echo get_debug_type($x), "\n";
$x = null;
echo get_debug_type($x), "\n";
```
```output
int
string
float
bool
null
```

Одна и та же переменная `$x` на разных строках хранит значения разных типов. PHP это позволяет, но в программе стоит избегать лишней путаницы.

## Пример 4. Как echo печатает bool и null

```php run
<?php
echo "[", true, "|", false, "|", null, "]\n";
var_dump(true, false);
```
```output
[1||]
bool(true)
bool(false)
```

`echo` превращает значение в текст: `true` становится `1`, а `false` и `null` - пустой строкой. Поэтому `echo false` ничего не показывает. Увидеть настоящее значение помогает `var_dump`.

**Попробуйте.** Предскажите, а затем проверьте `var_dump` для значений `0`, `"0"`, `0.0`, `""` и `false`: все они разных типов.

## Точные правила

* `int` - целое число 64 бита: до 9223372036854775807. Подробнее о границах - в курсе «PHP: первые шаги».
* `float` - дробное число. Десятичный разделитель в коде - точка. Допустимо `.5` и научная запись `1e3` (она даёт `float`). Для удобства чтения можно писать `1_000_000`.
* `string` - текст в одинарных или двойных кавычках; длина считается в байтах (урок 7).
* `bool` - только `true` или `false`. Написание `TRUE` тоже допустимо, но в курсе строчными.
* `null` - особое значение «ничего нет». Не равно ни нулю, ни пустой строке, хотя `echo null` печатает пустое место.
* `var_dump($x)` печатает тип и значение, а `get_debug_type($x)` - имя типа: `int`, `float`, `string`, `bool`, `null`. Есть и старая функция `gettype`, но она возвращает `integer`, `double`, `boolean` - из-за истории PHP.
* Число в кавычках - текст. Запись `$price = "120";` создаёт `string`, не `int`.
* `echo` печатает `true` как `1`, а `false` и `null` как пустую строку.

<!-- section: mistakes -->
## Типичные ошибки

**1. Число в кавычках.** `$count = "12";` - это текст. Арифметика с ним иногда сработает, но в сравнениях и функциях возникают сюрпризы (урок о преобразовании).

**2. Запятая вместо точки в дробном числе.**

```php
<?php
$x = 3,14;
```

PHP: `Parse error: syntax error, unexpected token "," in main.php on line 2`. Запятая в PHP - разделитель, а десятичный разделитель - точка: `3.14`.

**3. `"true"` вместо `true`.** `$ok = "true";` - это непустой текст, а не логическое значение. Слово `true` без кавычек.

**4. `echo false` «ничего не печатает».** Это не ошибка: `false` превращается в пустую строку. Для отладки применяйте `var_dump`.

**5. Путать `null` и `""`.** Пустой текст имеет тип `string` и длину 0, а `null` - значение «нет значения».

**6. Оставить `var_dump` в готовой программе.** Это инструмент отладки: он печатает служебный формат, а не результат для пользователя.

<!-- section: summary -->
## Итоги

* Значение имеет тип: `int`, `float`, `string`, `bool` или `null`; тип принадлежит значению, а не переменной.
* `42` и `"42"`, `4` и `4.0` - значения разных типов, различимые по записи.
* `var_dump` показывает тип и значение, `get_debug_type` - только тип.
* `echo` печатает `true` как `1`, а `false` и `null` как пустое место.

Типы определяют, какие действия возможны. С числами можно считать, и этим займёмся в [следующем уроке](lesson:php.from-zero.arithmetic).

## Для тех, кто уже программирует

* PHP - динамически типизированный язык со скалярными типами `int`, `float`, `string`, `bool` и особым `null`; составные типы - `array`, `object`, а также `callable`, `iterable`.
* `int` - 64-битный знаковый; при переполнении результат становится `float`, а не оборачивается (подробно - в `php-first-steps`). `float` - IEEE 754 double.
* Различайте `gettype` (исторические имена `integer`, `double`) и `get_debug_type` (PHP 8: `int`, `float`, `bool`, класс объекта).
* `var_dump` печатает тип и длину в байтах (`string(12)`); `var_export` и `print_r` дают другие представления.
* Строки изменяемы побайтово, но не Unicode-aware: `strlen` считает байты (урок о строках).
* Нет отдельного типа `char`, `decimal` и `undefined`: неинициализированная переменная даёт Warning и `null`.
* Динамическая типизация сочетается со слабым приведением: нестрогие сравнения и арифметика с числовыми строками (урок о преобразовании типов, урок о сравнении).
