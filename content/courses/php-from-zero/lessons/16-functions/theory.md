## Зачем это нужно

Когда одна и та же последовательность команд нужна в нескольких местах, её копируют, и вместе с копиями появляются ошибки: исправили в одном месте, забыли в другом. Программа с сотней строк в одном потоке трудна и для чтения: непонятно, где что считается. Выход - дать группе команд **имя** и вызывать её по имени. Такая именованная группа называется **функцией**. Вы уже пользуетесь готовыми: `trim`, `round`, `printf`. Теперь вы научитесь писать свои.

## Одна новая идея: функция принимает значения и возвращает результат

```php
function totalPrice(int $price, int $quantity): int
{
    return $price * $quantity;
}

echo totalPrice(45, 3);
```

Разберём запись:

* `function` - слово, объявляющее функцию; `totalPrice` - её имя;
* в скобках **параметры**: `int $price` и `int $quantity`. Это переменные, которые получают значения при вызове. Слово `int` перед именем - **объявление типа**: функция принимает только целые;
* `: int` после скобок - тип **возвращаемого значения**: функция вернёт целое;
* `return` отдаёт результат и сразу завершает функцию;
* `totalPrice(45, 3)` - **вызов**. Значения в скобках называют **аргументами**: 45 попадает в `$price`, 3 - в `$quantity`.

Если функция только печатает и ничего не возвращает, тип результата - `void` («пусто»). Если параметру задано значение по умолчанию (`int $discount = 0`), его можно не передавать - такие параметры ставят последними.

Переменные внутри функции - **локальные**: они существуют только пока функция работает и не видны снаружи. Внешние переменные внутри функции тоже не видны. Всё нужное функция получает через параметры, а результат отдаёт через `return`.

**`declare(strict_types=1);`** - строка в самом начале файла, сразу после `<?php`. Она включает строгую проверку типов: если параметру `int` передали строку `"5"`, PHP останавливается с ошибкой, вместо того чтобы молча превратить её в число. Так ошибка находится сразу, на границе функции. С этого урока каждая программа курса начинается с `<?php` и `declare(strict_types=1);`.

## Пример 1. Функция, которая возвращает значение

```php run
<?php
declare(strict_types=1);

function totalPrice(int $price, int $quantity): int
{
    return $price * $quantity;
}

echo totalPrice(45, 3), "\n";
echo totalPrice(120, 2) + totalPrice(80, 1), "\n";
$bill = totalPrice(10, 10);
echo "Счёт: {$bill}\n";
```
```output
135
320
Счёт: 100
```

Разбор: вызов функции - выражение со значением, его можно печатать, складывать и класть в переменную. Функция написана один раз и вызвана с разными числами.

## Пример 2. Функция без результата и значение по умолчанию

```php run
<?php
declare(strict_types=1);

function greet(string $name, string $greeting = "Здравствуйте"): void
{
    echo "{$greeting}, {$name}!\n";
}

greet("Анна");
greet("Иван", "Привет");
```
```output
Здравствуйте, Анна!
Привет, Иван!
```

Разбор: `greet` ничего не возвращает (`void`), только печатает. Во втором вызове значение по умолчанию заменено на переданное.

## Пример 3. Локальные переменные и копия аргумента

```php run
<?php
declare(strict_types=1);

function withTax(int $price): int
{
    $tax = intdiv($price * 20, 100);
    $price = $price + $tax;
    return $price;
}

$price = 500;
echo withTax($price), "\n";
echo $price, "\n";
```
```output
600
500
```

Разбор: параметр `$price` внутри функции - **копия** значения. Изменение копии не затрагивает внешнюю `$price`: она осталась 500. Переменная `$tax` существует только внутри функции; снаружи её нет.

## Пример 4. Функция вызывает функцию

```php run
<?php
declare(strict_types=1);

function lineTotal(int $price, int $quantity): int
{
    return $price * $quantity;
}

function receiptLine(string $name, int $price, int $quantity): string
{
    return $name . ": " . lineTotal($price, $quantity) . " руб.";
}

echo receiptLine("Хлеб", 45, 2), "\n";
echo receiptLine("Сыр", 320, 1), "\n";
```
```output
Хлеб: 90 руб.
Сыр: 320 руб.
```

Разбор: `receiptLine` возвращает строку и использует `lineTotal`. Каждая функция делает одно дело, поэтому её легко проверить отдельно.

## Пример 5. Что меняет strict_types

```php run
<?php
// Режим по умолчанию (без declare): PHP сам приводит типы.
function double(int $n): int
{
    return $n * 2;
}

var_dump(double("5"));
var_dump(double(true));
```
```output
int(10)
int(2)
```

Разбор: без `declare(strict_types=1)` строка `"5"` молча превращается в `5`, а `true` - в `1`. Это удобно ровно до тех пор, пока не скрывает ошибку: функция не заметила, что ей передали не число. В строгом режиме оба вызова остановятся с `TypeError`.

**Попробуйте.** Напишите функцию `average(int $a, int $b): float`, которая возвращает среднее двух чисел, и выведите `average(3, 4)`. Затем добавьте в начало файла `declare(strict_types=1);` и вызовите `average("3", 4)`.

## Точные правила

* Форма: `function имя(тип $параметр, ...): тип { тело }`. Имя функции не начинается с `$`, регистр в именах функций не различается, но писать нужно единообразно (`camelCase`).
* `return выражение;` завершает функцию и возвращает значение. Код после `return` не выполняется. В функции с типом `void` пишут `return;` без значения или не пишут `return` вовсе.
* Тип результата должен совпадать с типом возвращаемого значения. `float` можно вернуть из функции, объявленной `: float`, и целое число (`return 5;`): `int` разрешено расширять до `float`, и это допускается даже в строгом режиме.
* Параметры со значениями по умолчанию ставят после обязательных.
* Число аргументов должно быть не меньше числа обязательных параметров. Лишние аргументы в пользовательскую функцию PHP игнорирует.
* Типы параметров, которые вы будете использовать: `int`, `float`, `string`, `bool`, `array` (появится в уроке о массивах). Функция с типом результата, но без `return`, - ошибка времени выполнения.
* Локальные переменные создаются при каждом вызове заново и исчезают после него. Переменные вне функции внутри неё недоступны: обращение к ним даёт `Warning: Undefined variable`. Есть слово `global`, но его избегают.
* `declare(strict_types=1);` должен быть первой командой в файле (после `<?php`). Он действует на вызовы функций и `return`, написанные **в этом файле**. Арифметику и сравнения он не затрагивает: `"5" + 3` по-прежнему равно `8`.
* Функции верхнего уровня можно вызывать и до их объявления в файле: PHP регистрирует их до начала выполнения. Курс всё равно пишет определение выше вызова.

## Типичные ошибки

**1. Строка вместо числа в строгом режиме.**

```php
<?php
declare(strict_types=1);
function total(int $price, int $qty): int
{
    return $price * $qty;
}
echo total("5", 2), "\n";
```

```text
Fatal error: Uncaught TypeError: total(): Argument #1 ($price) must be of type int, string given, called in main.php on line 6 and defined in main.php:3
```

Сообщение называет функцию, номер аргумента и его имя, ожидаемый и полученный типы. Данные из ввода приходят строками: перед вызовом превратите их в числа через `(int)` или `(float)`.

**2. Не хватает аргументов.**

```php
<?php
function total(int $price, int $qty): int
{
    return $price * $qty;
}
echo total(5), "\n";
```

```text
Fatal error: Uncaught ArgumentCountError: Too few arguments to function total(), 1 passed in main.php on line 5 and exactly 2 expected in main.php:2
```

У функции два обязательных параметра, а передан один.

**3. Использовать внешнюю переменную внутри функции.**

```php
<?php
$rate = 10;
function tax(int $price): int
{
    return $price * $rate / 100;
}
echo tax(200), "\n";
```

```text
Warning: Undefined variable $rate in main.php on line 4
```

Внутри функции `$rate` не существует: функция видит только свои параметры и локальные переменные. Результат вычисления - 0, потому что отсутствующая переменная считается `null`. Передайте значение третьим параметром.

**4. Забыли `return`.**

```php
<?php
declare(strict_types=1);
function twice(int $n): int
{
    $n * 2;
}
echo twice(4), "\n";
```

```text
Fatal error: Uncaught TypeError: twice(): Return value must be of type int, none returned in main.php:5
```

Выражение `$n * 2;` посчитано и выброшено. Результат нужно вернуть: `return $n * 2;`.

**5. Результат не того типа.**

```php
<?php
declare(strict_types=1);
function half(int $n): int
{
    return $n / 2;
}
echo half(5), "\n";
```

```text
Fatal error: Uncaught TypeError: half(): Return value must be of type int, float returned in main.php:4
```

Оператор `/` вернул `2.5` (`float`). Для целой части используйте `intdiv($n, 2)`, для дроби объявите `: float`.

**6. Опечатка в имени.** Вызов `totl(5)` даёт `Fatal error: Uncaught Error: Call to undefined function totl()`. Проверяйте имена.

**7. Печать вместо возврата.** Функция, которая печатает результат вместо `return`, не годится для вычислений: `echo total(5, 2) + 1` не сработает, если `total` ничего не возвращает. Вычисляющие функции возвращают значение, а печатью занимается вызывающий код.

## Итоги

* Функция - именованная группа команд: `function имя(тип $параметр): тип { ... return ...; }`.
* Параметры - переменные функции, аргументы - значения при вызове; снаружи внутрь данные идут через параметры, изнутри наружу - через `return`.
* Локальные переменные существуют только внутри функции; параметр - копия значения.
* `declare(strict_types=1);` заставляет PHP отвергать значения не того типа вместо скрытого преобразования; он действует на вызовы функций, но не на арифметику.
* Данные из ввода приводят к нужному типу до вызова.

Теперь можно хранить много значений в одной переменной: [массивы](lesson:php.from-zero.arrays).

## Для тех, кто уже программирует

* В PHP типы параметров и результата необязательны, но с `declare(strict_types=1)` они проверяются жёстко. Без него действует «слабый» режим: `"5"` -> `5`, `true` -> `1`, `5.0` -> `5`. Строка `"5 штук"` и дробное с потерей точности (`5.7`) приводят к `TypeError` либо `Deprecated`.
* Строгий режим касается только вызовов **из файла**, где он объявлен, и возвращаемых значений функций этого файла. Встроенные функции вызываются строго, если вызов сделан в таком файле. `int` -> `float` разрешено всегда.
* Область видимости функциональная: внешние переменные не видны без `global` или `use` (в замыкании). В отличие от JS, замыкания не захватывают окружение автоматически (стрелочные функции `fn` захватывают по значению - это тема `php-fundamentals`).
* Аргументы передаются по значению (массивы копируются лениво), по ссылке - только с `&`.
* Именованные аргументы (`totalPrice(price: 45, quantity: 3)`), необязательные типы (`?int`), объединения типов (`int|string`) и `never`/`static` доступны, но выходят за рамки этого урока.
* Функции регистрируются на этапе компиляции файла, поэтому вызов до объявления работает (но не для условно объявленных функций).
