## Зачем это нужно

Результат программы - это текст, и читать его будет человек. Поэтому важно управлять тем, как он выглядит: где начинается новая строка, как выровнены столбцы, как напечатать кавычки или путь к файлу. В этом уроке вы научитесь печатать несколько значений одной командой и записывать «невидимые» и служебные знаки.

## Одна новая идея: в строке в двойных кавычках некоторые знаки имеют особый смысл

Обратная косая черта `\` внутри текста в **двойных** кавычках сообщает PHP: «следующий знак особенный». Такое сочетание называют **управляющей последовательностью**. Вот те, что понадобятся:

| Запись | Что печатается |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция (широкий отступ) |
| `\"` | кавычка `"` |
| `\\` | одна обратная косая черта |
| `\$` | знак доллара `$` |

В **одинарных** кавычках (`'...'`) почти всё печатается буквально: знаки `\n` и `\t` там остаются двумя символами. Исключения - `\'` (апостроф) и `\\`. Выбор кавычек - это выбор: «разбирать особые знаки» или «печатать как есть».

Ещё две вещи: `echo` умеет печатать несколько значений за раз, если разделить их запятыми, а текст, который PHP должен пропустить, записывают в **комментарии**.

<!-- section: examples -->
## Пример 1. Несколько значений в одной команде

```php run
<?php
echo "Итого: ", 450, " руб.", "\n";
```
```output
Итого: 450 руб.
```

Разбор по строкам:

* Значения разделены запятыми, и `echo` печатает их подряд: сначала текст `Итого: `, потом число `450`, затем текст ` руб.` и перевод строки.
* Пробелов между значениями `echo` не добавляет. Пробел после двоеточия и перед словом «руб.» записан внутри текста.
* Число `450` стоит без кавычек, потому что это число, а не текст. О числах - в [уроке про значения](lesson:php.from-zero.values-and-types).

## Пример 2. Табуляция, кавычки и косая черта

```php run
<?php
echo "Хлеб\t45\n";
echo "Молоко\t89\n";
echo "Он сказал: \"Готово\"\n";
echo "Путь: C:\\kassa\n";
```
```output
Хлеб	45
Молоко	89
Он сказал: "Готово"
Путь: C:\kassa
```

Разбор: `\t` вставил один широкий отступ, поэтому «45» и «89» оказались в одном столбце. `\"` напечатало кавычку внутри текста, а `\\` - одну обратную косую черту.

## Пример 3. Двойные и одинарные кавычки

```php run
<?php
echo 'Цена\tитого', "\n";
echo "Цена\tитого", "\n";
echo 'Он сказал: "Готово"', "\n";
echo 'It\'s open', "\n";
```
```output
Цена\tитого
Цена	итого
Он сказал: "Готово"
It's open
```

Разбор:

* В первой строке текст в одинарных кавычках: `\t` напечатано как два символа. Перевод строки в конце добавила вторая часть команды, в двойных кавычках.
* Во второй строке двойные кавычки: `\t` стало табуляцией.
* В третьей строке одинарные кавычки позволяют писать двойные внутри без всяких знаков.
* В четвёртой строке апостроф внутри одинарных кавычек защищён косой чертой: `\'`.

## Пример 4. Комментарии

```php run
<?php
// Это комментарий: PHP его пропускает
echo "Видно\n"; // комментарий можно писать и после команды
/* А так можно закомментировать
   сразу несколько строк */
echo "Тоже видно\n";
```
```output
Видно
Тоже видно
```

Комментарии пишут для людей: чтобы объяснить, зачем нужна команда, или временно «выключить» её. Начинаются они с `//`; для нескольких строк используют `/* ... */`.

**Попробуйте.** В примере 3 поменяйте во второй строке `\t` на `\n` и предскажите вывод. Затем напишите `echo "C:\temp\n";` и посмотрите, что получилось: ответ в разделе об ошибках.

## Точные правила

* `echo` принимает одно или несколько значений через запятую: `echo "a", "b";`. Между значениями ничего не добавляется. Переводы строки пишут сами.
* В **двойных** кавычках работают `\n`, `\t`, `\"`, `\\`, `\$`. Многие другие сочетания (например, `\k`) PHP оставляет как есть: `"C:\kassa"` напечатает `C:\kassa`, потому что `\k` ничего не значит. Но `"C:\temp"` напечатает `C:`, табуляцию и `emp`.
* В **одинарных** кавычках разбираются только `\'` (апостроф) и `\\` (одна черта). Всё остальное, включая `\n`, печатается буквально.
* Знак `$` в двойных кавычках начинает имя переменной (урок 4). Чтобы напечатать его как обычный знак перед словом, пишут `\$` или используют одинарные кавычки.
* Многие примеры используют `"\n"` в двойных кавычках, потому что именно он даёт перевод строки.
* Комментарий `//` продолжается до конца строки; `/* ... */` может занимать несколько строк. PHP знает и `#`, но в курсе он не используется.
* Пустая строка в выводе - это просто `\n` без текста: `echo "\n";`.

<!-- section: mistakes -->
## Типичные ошибки

**1. Апостроф внутри одинарных кавычек.**

```php
<?php
echo 'It's open';
```

PHP: `Parse error: syntax error, unexpected identifier "s", expecting "," or ";"`. Строка закончилась на апострофе после `It`, а `s open` PHP прочитал как имя. Защитите апостроф (`'It\'s open'`) или возьмите двойные кавычки.

**2. Пропущена запятая между значениями.**

```php
<?php
echo "Итого: " 450;
```

PHP: `Parse error: syntax error, unexpected integer "450", expecting "," or ";"`. После текста PHP ждёт запятую или точку с запятой, а встретил число.

**3. `\n` в одинарных кавычках.** `echo 'Привет\n';` печатает `Привет\n` буквально и не переводит строку. Для перевода строки нужны двойные кавычки.

**4. Путь Windows с одной косой чертой.** `"C:\temp\new"` содержит `\t` и `\n`: получатся табуляция и перевод строки. Верно - `"C:\\temp\\new"`.

**5. Знак `$` перед словом.** `"Цена: $price"` PHP воспринимает как переменную. Если вам нужен буквальный текст `$price`, напишите `\$price`.

**6. Ожидать пробел между значениями.** `echo "a", "b";` печатает `ab`.

<!-- section: summary -->
## Итоги

* `echo` печатает несколько значений через запятую, подряд и без пробелов между ними.
* В двойных кавычках `\n` - перевод строки, `\t` - табуляция, `\"` - кавычка, `\\` - косая черта, `\$` - знак доллара.
* В одинарных кавычках почти всё печатается буквально, поэтому в них удобно писать кавычки другого вида.
* Комментарии `//` и `/* */` PHP пропускает.

Сейчас значения записаны прямо в `echo`. Чтобы использовать одно значение несколько раз и менять его, нужны переменные: [следующий урок](lesson:php.from-zero.variables).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `echo` - языковая конструкция: скобки не нужны, значения через запятую выводятся подряд. `print` тоже есть, но принимает одно значение и возвращает `1`; на практике используют `echo`.
* Двойные кавычки интерполируют переменные и обрабатывают escape-последовательности, одинарные - почти нет (как в shell). Heredoc `<<<EOT` и nowdoc `<<<'EOT'` работают так же по смыслу и подробно разбираются в следующих курсах.
* Перевода строки `echo` не добавляет (в отличие от `print` Python и `println` Go). Платформенная константа `PHP_EOL` существует, но в курсе пишется `"\n"`: тесты сравнивают `\n`.
* Неизвестные escape-последовательности (`"\k"`) не вызывают ошибку - обратная косая черта остаётся.
* Комментарии: `//`, `#`, `/* */`; `/** ... */` - doc-комментарий; `#[...]` с PHP 8 - атрибут, а не комментарий.
