## Зачем это нужно

Пока каждое значение жило в отдельной переменной. Но данные чаще приходят группами: температуры за неделю, цены в чеке, оценки группы. Заводить переменную на каждое значение невозможно, если их заранее неизвестное количество. Для таких данных служит **массив**: одна переменная, внутри которой лежит упорядоченный набор значений.

## Одна новая идея: массив - нумерованный список значений

Массив записывают в квадратных скобках, значения разделяют запятыми:

```php
$prices = [120, 80, 45];
```

Каждое значение (**элемент**) имеет номер - **индекс**. Нумерация идёт **с нуля**: у первого элемента индекс 0, у последнего - на единицу меньше, чем длина. Получить элемент можно по индексу: `$prices[0]` - это 120, `$prices[2]` - 45. Присваивание по индексу заменяет значение: `$prices[1] = 90;`.

Три главные операции:

* **добавить** в конец: `$prices[] = 300;` (пустые скобки значат «в конец»);
* **узнать длину**: `count($prices)` возвращает число элементов;
* **обойти** все элементы: цикл `foreach`.

```php
foreach ($prices as $price) {
    echo $price, "\n";
}
```

Цикл `foreach` на каждой итерации кладёт очередной элемент в переменную (`$price`), пока элементы не закончатся. Счётчик и условие писать не нужно. Если нужны и индекс, и значение: `foreach ($prices as $index => $price)`.

Пустой массив записывается `[]`. С него начинают, когда значения появятся позже, например из ввода.

## Пример 1. Создание, чтение, изменение

```php run
<?php
declare(strict_types=1);

$prices = [120, 80, 45];
echo "Первый: ", $prices[0], "\n";
echo "Последний: ", $prices[2], "\n";

$prices[1] = 90;
$prices[] = 300;
echo "Элементов: ", count($prices), "\n";
echo "Последний теперь: ", $prices[count($prices) - 1], "\n";
print_r($prices);
```
```output
Первый: 120
Последний: 45
Элементов: 4
Последний теперь: 300
Array
(
    [0] => 120
    [1] => 90
    [2] => 45
    [3] => 300
)
```

Разбор: после добавления в массиве четыре элемента, поэтому индекс последнего равен `count($prices) - 1`. Функция `print_r` печатает содержимое массива для отладки: слева индексы, справа значения.

## Пример 2. Обход через foreach

```php run
<?php
declare(strict_types=1);

$temperatures = [18, 21, 19, 25];
$sum = 0;
foreach ($temperatures as $t) {
    $sum += $t;
}
echo "Сумма: {$sum}\n";
echo "Среднее: ", $sum / count($temperatures), "\n";

foreach ($temperatures as $day => $t) {
    echo "День ", $day + 1, ": {$t}\n";
}
```
```output
Сумма: 83
Среднее: 20.75
День 1: 18
День 2: 21
День 3: 19
День 4: 25
```

Разбор: первый `foreach` накапливает сумму, как это делал цикл `while`, но без счётчика. Во втором переменная `$day` получает индекс (с нуля), и для человека к нему прибавляют 1.

## Пример 3. Массив из цикла и из ввода

```php run
<?php
declare(strict_types=1);

$squares = [];
for ($i = 1; $i <= 5; $i++) {
    $squares[] = $i * $i;
}
echo count($squares), ": ", $squares[0], " ", $squares[4], "\n";
```
```output
5: 1 25
```

Разбор: пустой массив заполняется в цикле добавлением `[]`. Так же собираются значения из ввода: читаем строку, превращаем в число, добавляем в массив.

## Пример 4. Массив в функции

```php run
<?php
declare(strict_types=1);

/** Сумма всех цен. */
function totalOf(array $prices): int
{
    $total = 0;
    foreach ($prices as $price) {
        $total += $price;
    }
    return $total;
}

function addTax(array $prices): array
{
    $result = [];
    foreach ($prices as $price) {
        $result[] = $price + intdiv($price * 20, 100);
    }
    return $result;
}

$cart = [100, 250, 50];
echo totalOf($cart), "\n";
echo totalOf(addTax($cart)), "\n";
echo totalOf($cart), "\n";
```
```output
400
480
400
```

Разбор: тип `array` в объявлении параметра значит «ожидается массив». Функция может и принимать, и возвращать массив. Исходный `$cart` не изменился: в функцию передаётся копия.

**Попробуйте.** Создайте массив из пяти оценок, найдите наибольшую через `foreach` и сравнения, не используя готовых функций.

## Точные правила

* Литерал: `[1, 2, 3]`. Значения могут быть любых типов, в том числе разных в одном массиве, но в курсе их однотипность - правило.
* Индексы целые и идут с 0. При добавлении `$a[] = x` новый индекс - наибольший прежний плюс 1.
* `$a[i]` читает элемент. Если индекса нет, PHP выдаёт `Warning: Undefined array key 5` и подставляет `null`; программа продолжает работу с пустым значением.
* `count($a)` возвращает число элементов. Для пустого массива это 0. Передать `count` что-либо кроме массива (или объекта, реализующего `Countable`) нельзя: будет `TypeError`.
* Индекс последнего элемента - `count($a) - 1`. Запись `$a[-1]` в PHP не означает «последний»: такого ключа нет.
* `foreach ($a as $v)` перебирает значения в порядке добавления; `foreach ($a as $k => $v)` - ключи и значения. Переменные цикла остаются после него.
* Массив **копируется при передаче**: изменение внутри функции не затрагивает исходный (в отличие от Java и JS, где передаётся ссылка). Присваивание `$b = $a;` тоже создаёт независимую копию.
* Массив нельзя напечатать через `echo`: выйдет слово `Array` и предупреждение `Array to string conversion`. Для отладки - `print_r($a)` или `var_dump($a)`.
* Массивы сравнивают через `===` только если нужны одинаковые пары ключ-значение и тот же порядок; в простых упражнениях сравнивают элементы по одному.

## Типичные ошибки

**1. Выход за границу.**

```php
<?php
$a = [10, 20, 30];
echo $a[3], "\n";
```

```text
Warning: Undefined array key 3 in main.php on line 3
```

В массиве из трёх элементов индексы 0, 1, 2; индекса 3 нет. Программа печатает пустое значение и продолжает работать, поэтому предупреждение легко не заметить. Последний элемент - `$a[count($a) - 1]`.

**2. Счёт с единицы.** Первый элемент - `$a[0]`, а не `$a[1]`. В цикле `for` по индексам условие - `$i < count($a)`, а не `<=`.

**3. `count` от не-массива.**

```php
<?php
echo count("abc"), "\n";
```

```text
Fatal error: Uncaught TypeError: count(): Argument #1 ($value) must be of type Countable|array, string given in main.php:2
```

Для длины строки есть `strlen` и `mb_strlen`; `count` работает только с массивами.

**4. Печать массива через `echo`.**

```php
<?php
$a = [10, 20, 30];
echo $a, "\n";
```

```text
Warning: Array to string conversion in main.php on line 3
```

Вывод будет `Array`. Чтобы увидеть содержимое - `print_r($a)`; для вывода значений - `foreach`.

**5. Ожидать, что функция изменит массив.** Функция `addTax` из примера 4 возвращает **новый** массив; исходный `$cart` остался прежним. Результат нужно присвоить или напечатать.

**6. Забыли инициализировать массив.** `$list[] = 5;` для несуществующей переменной сработает, но читать значения из пустого `$list` без предварительного `$list = [];` небезопасно. Заводите пустой массив явно.

## Итоги

* Массив `[a, b, c]` хранит упорядоченный набор значений; индексы идут с 0.
* `$a[i]` читает и записывает элемент, `$a[] = x` добавляет в конец, `count($a)` даёт длину.
* `foreach ($a as $v)` обходит значения, `foreach ($a as $k => $v)` - индексы и значения.
* Несуществующий индекс даёт `Warning: Undefined array key`, а не остановку программы.
* Массивы передаются в функции по значению; параметр с типом `array` принимает массив.

В PHP есть много готовых функций для массивов - сумма, поиск, сортировка. Об этом - [следующий урок](lesson:php.from-zero.array-functions).

## Для тех, кто уже программирует

* Массив PHP - это упорядоченная хеш-таблица: один тип служит и списком, и словарём (см. урок про ассоциативные массивы). Литерал `[1, 2, 3]` - просто карта с ключами 0, 1, 2. Деталь реализации: удаление элемента оставляет «дыру» в нумерации.
* Значения массивов копируются при присваивании и передаче (copy-on-write: реально копия создаётся при изменении). Объекты ведут себя иначе.
* Чтение несуществующего индекса не бросает исключение, а выдаёт `Warning` и `null`. Это источник тихих ошибок; в JS аналог - `undefined`, в Python - `IndexError`.
* Отрицательные индексы не считаются от конца, как в Python. Последний элемент: `$a[array_key_last($a)]` или `end($a)`.
* `foreach` по умолчанию обходит копию массива: изменения массива внутри цикла не влияют на итерацию. Обход по ссылке (`foreach ($a as &$v)`) требует осторожности и разобран в `php-first-steps`.
* Длина - обычная функция `count($a)`, а не свойство `length`, как в JS и Java. Для строк используется отдельная `strlen`; `count` работает только с массивами и `Countable`, а для остальных типов с PHP 8 выбрасывает `TypeError`.
