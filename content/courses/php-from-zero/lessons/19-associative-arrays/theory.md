## Зачем это нужно

В обычном массиве значение находят по номеру. Но номер ничего не говорит о смысле: что хранится под индексом 2 - цена, остаток на складе или чей-то возраст? Часто данные удобнее искать по названию: цена «Хлеба», оценка «Анны», число повторений слова «чай». Для этого в PHP тот же массив умеет хранить пары **ключ => значение**. Такой массив называют **ассоциативным**.

## Одна новая идея: ключ - это имя, по которому находят значение

```php
$prices = ["Хлеб" => 45, "Молоко" => 80];
echo $prices["Молоко"];
```

Каждый элемент записывается как `ключ => значение`. Ключ чаще всего строка. Читать, добавлять и менять значения можно по ключу: `$prices["Сыр"] = 320;` добавляет пару (если ключа нет) или заменяет значение (если ключ уже есть). Ключи в массиве **уникальны**: два элемента с одним ключом существовать не могут.

Обход через `foreach ($prices as $name => $price)` даёт ключ и значение; элементы идут в том порядке, в котором были добавлены.

Обращение к несуществующему ключу даёт `Warning: Undefined array key "..."`. Чтобы спросить «есть ли такой ключ», используют:

* **`isset($a["k"])`** - есть ли ключ и не равно ли значение `null`;
* **`array_key_exists("k", $a)`** - есть ли ключ, даже если значение `null`;
* **`$a["k"] ?? 0`** - оператор **`??`** («если нет - то»): берёт значение по ключу, а если его нет или оно `null`, подставляет запасное (здесь 0), и предупреждения не будет.

Значением может быть и другой массив: список записей, где каждая запись - массив с ключами. Это называют **вложенными массивами**.

## Пример 1. Создание, чтение, изменение

```php run
<?php
declare(strict_types=1);

$prices = ["Хлеб" => 45, "Молоко" => 80, "Сыр" => 320];
echo "Молоко стоит ", $prices["Молоко"], " руб.\n";

$prices["Чай"] = 150;
$prices["Хлеб"] = 50;
echo "Позиций: ", count($prices), "\n";
foreach ($prices as $name => $price) {
    echo "{$name}: {$price}\n";
}
```
```output
Молоко стоит 80 руб.
Позиций: 4
Хлеб: 50
Молоко: 80
Сыр: 320
Чай: 150
```

Разбор: «Чай» - новый ключ, поэтому позиций стало четыре. «Хлеб» - существующий ключ, поэтому его значение заменилось, а число позиций не изменилось. Порядок обхода - порядок добавления.

## Пример 2. Есть ли ключ

```php run
<?php
declare(strict_types=1);

$stock = ["Хлеб" => 12, "Молоко" => 0, "Сыр" => null];
var_dump(isset($stock["Хлеб"]));
var_dump(isset($stock["Молоко"]));
var_dump(isset($stock["Сыр"]));
var_dump(array_key_exists("Сыр", $stock));
var_dump(isset($stock["Чай"]));
echo $stock["Чай"] ?? "нет в наличии", "\n";
echo $stock["Хлеб"] ?? "нет в наличии", "\n";
```
```output
bool(true)
bool(true)
bool(false)
bool(true)
bool(false)
нет в наличии
12
```

Разбор: для «Молока» значение 0 - это не `null`, поэтому `isset` истинно. Для «Сыра» значение `null`: `isset` ложно, а `array_key_exists` истинно, потому что ключ существует. Запись `?? "нет в наличии"` безопасно читает отсутствующий ключ.

## Пример 3. Подсчёт повторений

```php run
<?php
declare(strict_types=1);

$words = ["чай", "кофе", "чай", "чай", "кофе", "сок"];
$counts = [];
foreach ($words as $word) {
    $counts[$word] = ($counts[$word] ?? 0) + 1;
}
foreach ($counts as $word => $count) {
    echo "{$word}: {$count}\n";
}
```
```output
чай: 3
кофе: 2
сок: 1
```

Разбор: это основной приём работы с ассоциативными массивами. Для каждого слова берём текущий счётчик (или 0, если слова ещё не было), прибавляем 1 и записываем обратно. Без `?? 0` на первом появлении слова было бы предупреждение `Undefined array key`.

## Пример 4. Сортировка с сохранением пар

```php run
<?php
declare(strict_types=1);

function show(array $pairs): void
{
    $parts = [];
    foreach ($pairs as $key => $value) {
        $parts[] = "{$key}={$value}";
    }
    echo implode(", ", $parts), "\n";
}

$scores = ["Яна" => 7, "Борис" => 9, "Анна" => 9];

$byName = $scores;
ksort($byName);
show($byName);

$byScore = $scores;
asort($byScore);
show($byScore);

$best = $scores;
arsort($best);
show($best);
```
```output
Анна=9, Борис=9, Яна=7
Яна=7, Борис=9, Анна=9
Борис=9, Анна=9, Яна=7
```

Разбор: `ksort` упорядочивает по ключам, `asort` - по значениям по возрастанию, `arsort` - по значениям по убыванию. В отличие от `sort`, они **сохраняют пары**: ключ не теряется. При равных значениях сохраняется прежний порядок (Борис и Анна идут так же, как в исходном массиве).

## Пример 5. Массив массивов

```php run
<?php
declare(strict_types=1);

$students = [
    ["name" => "Анна", "grades" => [5, 4, 5]],
    ["name" => "Иван", "grades" => [3, 4]],
];
foreach ($students as $student) {
    $avg = array_sum($student["grades"]) / count($student["grades"]);
    printf("%s: %.1F\n", $student["name"], $avg);
}
echo $students[1]["grades"][0], "\n";
```
```output
Анна: 4.7
Иван: 3.5
3
```

Разбор: каждый элемент `$students` - массив с ключами `name` и `grades`, а `grades` - ещё один массив. Доступ записывают цепочкой скобок: `$students[1]["grades"][0]` - первая оценка второго студента.

**Попробуйте.** Подсчитайте, сколько раз каждое число встречается в массиве `[3, 1, 3, 2, 3, 1]`, приёмом из примера 3, и выведите пары в порядке убывания частоты.

## Точные правила

* Ключи - целые числа или строки. Строка из десятичных цифр без ведущих нулей (`"5"`) автоматически становится целым ключом `5`; `"05"` остаётся строкой. Дробные ключи усекаются с предупреждением, `true` превращается в `1`. Подробнее об этом - в курсе `php-first-steps`; пока используйте строки-слова и целые числа.
* Запись по существующему ключу заменяет значение; по новому - добавляет пару в конец.
* `isset($a["k"])` - `true`, если ключ есть и значение не `null`. `array_key_exists("k", $a)` - `true`, если ключ есть. `$a["k"] ?? $default` не выдаёт предупреждений и возвращает запасное значение при отсутствии или `null`.
* `unset($a["k"])` удаляет пару.
* `ksort($a)` упорядочивает по ключам, `asort` - по значениям по возрастанию, `arsort` - по убыванию; `krsort` - по ключам по убыванию. Все эти функции меняют массив и сохраняют пары; сортировка устойчива.
* `sort` и `rsort`, наоборот, **выбрасывают** ключи и нумеруют значения заново: для ассоциативных массивов они почти никогда не подходят.
* `array_keys($a)` возвращает список ключей, `array_values($a)` - список значений.
* Вложенный массив читается цепочкой: `$a["x"]["y"]`. Если промежуточного ключа нет, будет `Warning`; безопасно - `$a["x"]["y"] ?? 0`.
* Оператор `??` работает и справа налево по цепочке: `$a ?? $b ?? 0` берёт первое существующее значение.

<!-- section: mistakes -->
## Типичные ошибки

**1. Читать отсутствующий ключ.**

```php
<?php
$p = ["a" => 1];
echo $p["b"], "\n";
```

```text
Warning: Undefined array key "b" in main.php on line 3
```

Результат - `null`, который `echo` печатает как пустую строку; программа продолжает работу с «пустотой». Проверьте ключ через `isset` или прочитайте с запасным значением: `$p["b"] ?? 0`.

**2. Счётчик без начального значения.** Запись `$counts[$word]++` для нового слова выдаёт предупреждение. Безопасный вариант: `$counts[$word] = ($counts[$word] ?? 0) + 1;`.

**3. Использовать массив как ключ.**

```php
<?php
$p = ["a" => 1];
$p[[1]] = 2;
```

```text
Fatal error: Uncaught TypeError: Cannot access offset of type array on array in main.php:3
```

Ключ может быть только числом или строкой.

**4. `isset` и `null`.** Если значение допускает `null`, `isset` скажет «нет» даже при существующем ключе. Для проверки именно ключа - `array_key_exists`.

**5. `sort` вместо `asort`.** После `sort($scores)` имена пропадают: остаются только числа. Для ассоциативных массивов выбирайте `ksort`, `asort`, `arsort`.

**6. Путать `=>` и `->` или `=` и `=>`.** В литерале массива пара пишется `"ключ" => значение`; `=` в этом месте даст синтаксическую ошибку. Стрелка `->` относится к объектам.

**7. Ключи с разным регистром.** `"Чай"` и `"чай"` - разные ключи, и это два счётчика. Перед подсчётом приводите слова к одному виду.

## Итоги

* Ассоциативный массив хранит пары `ключ => значение`; чтение, запись и обход идут по ключам.
* Ключи уникальны; запись по существующему ключу заменяет значение.
* `isset`, `array_key_exists` и `??` позволяют безопасно обращаться к возможно отсутствующему ключу.
* Подсчёт: `$counts[$k] = ($counts[$k] ?? 0) + 1;`.
* `ksort`, `asort`, `arsort` сортируют, сохраняя пары; `sort` ключи теряет.
* Значением может быть другой массив: так описывают таблицы и списки записей.

## Для тех, кто уже программирует

* Тип `array` в PHP - упорядоченная хеш-таблица, и список, и словарь одновременно. Порядок вставки сохраняется (как в `dict` Python 3.7+ и `Map` JS), в отличие от неупорядоченных хеш-таблиц Java `HashMap`.
* Ключ `"5"` превращается в целое `5`, `true` - в `1`, `null` - в `""`; `1.7` усекается до `1` (с `Deprecated`). Это отличие от JS-объектов и Python-словарей, где ключи типизированы по-другому.
* `??` - как одноимённый оператор в JS и C#: возвращает правый операнд, если левый не существует или равен `null`. `isset` не вызывает `Warning` ни для несуществующего ключа, ни для промежуточных уровней цепочки.
* `array_key_exists` отличает «ключа нет» от «значение `null`»; `isset` и `??` - нет.
* `ksort`/`asort`/`arsort` меняют массив на месте (передача по ссылке), как `sort`. Для неизменяемого результата делают копию (массивы копируются по значению).
* Вложенные массивы копируются целиком при присваивании; вложенные записи - не ссылки, как в JS.
