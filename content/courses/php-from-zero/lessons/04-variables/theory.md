## Зачем это нужно

Программа редко работает с одним значением один раз. Цену товара нужно показать, посчитать скидку и напечатать новую цену. Если каждый раз писать число заново, то при изменении цены придётся править много мест. Поэтому значение сохраняют в **переменной** и дальше обращаются к нему по имени.

## Одна новая идея: переменная - это имя, за которым хранится значение

Переменная - именованное место в памяти, где хранится значение. В PHP имя переменной начинается со знака доллара `$`. Значение записывают командой **присваивания**: имя, знак `=`, значение и `;`.

```php
$price = 120;
```

Читается так: «в переменную `price` записать 120». Знак `=` в программировании означает не «равно», а «положить значение справа в переменную слева». Позже в переменную можно записать другое значение: старое будет забыто.

Значение переменной можно **подставить** в текст. В строке с двойными кавычками запись `{$price}` заменяется на текущее значение:

```php
echo "Цена: {$price} руб.\n";
```

Эта подстановка называется **интерполяцией**. Фигурные скобки показывают, где кончается имя. Они нужны не всегда, но в курсе пишутся всегда: так нет неожиданностей.

<!-- section: examples -->
## Пример 1. Создать и напечатать

```php run
<?php
$product = "Чай";
$price = 120;
echo "Товар: {$product}\n";
echo "Цена: {$price} руб.\n";
```
```output
Товар: Чай
Цена: 120 руб.
```

Разбор по строкам:

* `$product = "Чай";` - переменная `$product` получает текст `Чай`.
* `$price = 120;` - переменная `$price` получает число 120. Число пишут без кавычек.
* В обоих `echo` стоят двойные кавычки, поэтому `{$product}` и `{$price}` заменяются значениями.

## Пример 2. Изменить значение

```php run
<?php
$price = 120;
echo "Было: {$price}\n";
$price = 100;
echo "Стало: {$price}\n";
```
```output
Было: 120
Стало: 100
```

Вторая строка присваивания заменила значение. Команды выполняются сверху вниз, поэтому первый `echo` увидел 120, а второй - 100.

## Пример 3. Копирование значения

```php run
<?php
$price = 100;
$copy = $price;
$price = 50;
echo "price={$price}, copy={$copy}\n";
```
```output
price=50, copy=100
```

`$copy = $price;` берёт значение, которое `$price` хранит **сейчас** (100), и кладёт его в `$copy`. Потом `$price` меняется, а `$copy` остаётся прежним: после копирования это два независимых значения.

## Пример 4. Одинарные кавычки и скобки

```php run
<?php
$name = "Анна";
$word = "кот";
echo "Привет, {$name}!\n";
echo 'Привет, {$name}!', "\n";
echo "Во дворе два {$word}а\n";
```
```output
Привет, Анна!
Привет, {$name}!
Во дворе два кота
```

Разбор: в двойных кавычках имя заменяется значением, в одинарных - нет. Третья строка показывает, зачем нужны скобки: они отделяют имя `word` от буквы `а` сразу за ним. Без скобок PHP прочитал бы `$wordа` как одно имя (в именах допустимы и русские буквы), и результат был бы неверным.

**Попробуйте.** Добавьте в пример 2 после `$price = 100;` строку `$price = 80;` и предскажите, что напечатает `echo`. Затем сделайте опечатку в имени (`{$prise}`) и посмотрите на сообщение.

## Точные правила

* Имя переменной: `$`, затем буква или подчёркивание, затем любое число букв, цифр и подчёркиваний. Пробелов в имени нет. Цифра первой стоять не может: `$1x` - ошибка.
* Регистр важен: `$price`, `$Price` и `$PRICE` - три разные переменные.
* Принятый стиль: имена строчными буквами по-английски, из нескольких слов - `$totalPrice` (первое слово с маленькой буквы, остальные с большой, без пробелов).
* Присваивание `$a = $b;` копирует значение. После этого изменение одной переменной не затрагивает другую.
* Переменную нужно создать до использования. Чтение несуществующей даёт `Warning: Undefined variable $имя`, а результат - пустое значение.
* Интерполяция работает только в двойных кавычках. В одинарных `{$x}` печатается как есть.
* В `"{$x}"` скобки обязательны, когда за именем сразу идут буквы или цифры: `"{$x}px"`.
* Один `echo` может печатать несколько значений и переменных через запятую: `echo $a, " ", $b, "\n";`. Но в курсе мы пишем интерполяцию, пока не изучим склейку строк.

## Типичные ошибки

**1. Опечатка в имени переменной.**

```php
<?php
$price = 120;
echo "Цена: {$prise}\n";
```

PHP: `Warning: Undefined variable $prise in main.php on line 3`. Программа печатает `Цена: ` с пустым местом. Сравните имя в сообщении с тем, которое вы задали: чаще всего отличается буква или регистр.

**2. Забыли `$`.**

```php
<?php
price = 5;
```

PHP: `Parse error: syntax error, unexpected token "=" in main.php on line 2`. Без `$` слово `price` не переменная, и присваивание невозможно.

**3. Цифра в начале имени.**

```php
<?php
$1x = 5;
```

PHP: `Parse error: syntax error, unexpected integer "1", expecting variable or "{" or "$"`. Начните с буквы: `$x1`.

**4. Пробел в имени.** `$my price = 5;` - Parse error: PHP читает `$my` как переменную, а `price` как лишнее слово. Пишите `$myPrice` или `$my_price`.

**5. Одинарные кавычки вместо двойных.** `echo 'Цена: {$price}';` печатает `Цена: {$price}` буквально.

**6. Русские буквы сразу за именем без скобок.** `"$wordы"` читается как переменная `$wordы`, и PHP сообщает `Warning: Undefined variable $wordы`. Используйте `"{$word}ы"`.

**7. Регистр.** `$Name` и `$name` - разные переменные. Предупреждение подскажет, какого именно имени не хватает.

<!-- section: summary -->
## Итоги

* Переменная хранит значение под именем, начинающимся с `$`; присваивание `$имя = значение;` кладёт или заменяет его.
* Регистр в имени важен; используется только созданная переменная, иначе Warning.
* `{$имя}` в строке с двойными кавычками подставляет значение; в одинарных кавычках подстановки нет.
* Копирование `$b = $a;` передаёт значение, и дальнейшие изменения переменные не связывают.

Мы уже печатали текст и число `120`. Какие бывают значения и чем они отличаются, расскажет [следующий урок](lesson:php.from-zero.values-and-types).

## Для тех, кто уже программирует

* Переменные не объявляются: первое присваивание создаёт переменную. Нет `let`/`var`/`const` и нет аннотации типа; тип привязан к значению и может измениться при следующем присваивании.
* Знак `$` обязателен при каждом использовании; имена чувствительны к регистру (имена функций и ключевые слова - нет).
* Чтение неопределённой переменной даёт `Warning: Undefined variable` (в PHP 7 - Notice) и значение `null`. Это одна из частых причин тихих ошибок: Warning не прерывает программу.
* Интерполяция `"{$x}"` и `"$x"` работает только в двойных кавычках и heredoc; сложные выражения (`{$a['k']}`, `{$obj->p}`) требуют фигурных скобок.
* Область видимости - функция: в глобальных переменных функция их не видит без `global` (урок о функциях).
* В именах допустимы байты 0x80-0xFF, то есть кириллица; в продакшен-коде имена пишут латиницей.
