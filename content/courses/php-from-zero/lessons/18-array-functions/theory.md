## Зачем это нужно

Со списком значений постоянно делают одни и те же вещи: считают сумму, ищут наибольшее, проверяют, есть ли значение, сортируют, собирают в одну строку для вывода. Каждый раз писать для этого цикл `foreach` можно, но в PHP на такие случаи есть готовые функции. Они короче и надёжнее: их уже проверили тысячи программистов.

## Одна новая идея: типовые операции со списком - готовые функции

Основные функции для списков:

| Функция | Что делает |
|---|---|
| `array_sum($a)` | сумма значений |
| `min($a)`, `max($a)` | наименьшее и наибольшее значение |
| `in_array($x, $a, true)` | есть ли значение `$x` в массиве |
| `sort($a)` | сортирует по возрастанию, **изменяя** сам массив |
| `rsort($a)` | сортирует по убыванию, изменяя массив |
| `implode(", ", $a)` | собирает массив в строку с разделителем |
| `array_slice($a, $start, $length)` | возвращает **новый** массив из части исходного |

Функции делятся на два рода. Одни **возвращают результат** и не трогают исходный массив (`array_sum`, `max`, `implode`, `array_slice`). Другие **меняют массив на месте** (`sort`, `rsort`): они ничего полезного не возвращают, и результат нужно искать в самом массиве. Путаница между ними - самая частая ошибка новичков.

Третий аргумент `true` у `in_array` включает строгое сравнение (как `===`). Курс всегда его указывает: без него `in_array` сравнивает через нестрогое `==`.

## Пример 1. Сумма, минимум, максимум, поиск

```php run
<?php
declare(strict_types=1);

$prices = [120, 45, 300, 80];
echo "Сумма: ", array_sum($prices), "\n";
echo "Дешевле всего: ", min($prices), "\n";
echo "Дороже всего: ", max($prices), "\n";
var_dump(in_array(300, $prices, true));
var_dump(in_array(100, $prices, true));
```
```output
Сумма: 545
Дешевле всего: 45
Дороже всего: 300
bool(true)
bool(false)
```

Разбор: все четыре функции возвращают значение, `$prices` остаётся прежним. `in_array` отвечает `bool`.

## Пример 2. sort и rsort меняют массив

```php run
<?php
declare(strict_types=1);

$scores = [30, 10, 20];
sort($scores);
echo implode(", ", $scores), "\n";
rsort($scores);
echo implode(", ", $scores), "\n";

$names = ["Яна", "Борис", "Анна"];
sort($names);
echo implode(", ", $names), "\n";
```
```output
10, 20, 30
30, 20, 10
Анна, Борис, Яна
```

Разбор: после `sort($scores)` сам `$scores` стал упорядоченным, и старый порядок потерян. Строки сортируются по алфавиту (точнее, по кодам символов). `implode` склеивает элементы через разделитель: так список выводят без лишней запятой в конце.

## Пример 3. Часть массива

```php run
<?php
declare(strict_types=1);

$results = [95, 88, 71, 64, 50];
$top = array_slice($results, 0, 3);
echo "Лучшие: ", implode(", ", $top), "\n";
$rest = array_slice($results, 3, 2);
echo "Остальные: ", implode(", ", $rest), "\n";
echo "Всего осталось в исходном: ", count($results), "\n";
```
```output
Лучшие: 95, 88, 71
Остальные: 64, 50
Всего осталось в исходном: 5
```

Разбор: `array_slice($a, 0, 3)` берёт три элемента, начиная с индекса 0. Если элементов меньше, чем запрошено, вернётся всё, что есть. Исходный массив не меняется.

## Пример 4. Строгий поиск

```php run
<?php
declare(strict_types=1);

$codes = [1, 2, 3];
var_dump(in_array("2", $codes));
var_dump(in_array("2", $codes, true));
var_dump(in_array(2, $codes, true));
```
```output
bool(true)
bool(false)
bool(true)
```

Разбор: без третьего аргумента строка `"2"` считается равной числу 2 (нестрого), с `true` типы должны совпасть. Данные из ввода приходят строками, поэтому сначала приведите их к числам, а затем ищите со строгим сравнением. Режим `strict_types` на `in_array` не влияет: сравнение задаёт именно третий аргумент.

**Попробуйте.** Соберите из массива `[3, 1, 2]` строку `"3 > 1 > 2"` через `implode`, затем отсортируйте массив по убыванию и выведите так же.

## Точные правила

* `array_sum` складывает числа; для пустого массива возвращает 0. Сумма целых - `int`, если есть дробные - `float`.
* `min($a)`, `max($a)` с массивом возвращают наименьший и наибольший элемент. Для **пустого** массива выбрасывают `ValueError`. С несколькими аргументами (`max(3, 7)`) работают так же.
* `in_array($needle, $haystack, true)` возвращает `bool`; значение и тип должны совпасть.
* `sort($a)` упорядочивает значения по возрастанию, `rsort($a)` - по убыванию; функции **меняют** массив, возвращают `true` и перенумеровывают индексы с 0. Устойчивость сортировки (равные элементы сохраняют порядок) гарантирована с PHP 8.0.
* Числа сортируются по значению, строки - по кодам байтов UTF-8. Для русских слов порядок верный, кроме буквы «ё», которая при такой сортировке окажется после «я». Сортировка с учётом языка (`Collator`) - тема `php-fundamentals`.
* `implode($separator, $a)` склеивает элементы в строку; числа превращаются в текст. Порядок аргументов: разделитель первый. Для пустого массива вернёт `""`.
* `array_slice($a, $offset, $length)` возвращает новый массив из `$length` элементов начиная с `$offset`; индексы нового массива начинаются с 0. Без третьего аргумента берётся всё до конца.
* `array_reverse($a)` возвращает перевёрнутую копию (исходный массив не меняется).
* Поиск позиции элемента: `array_search($x, $a, true)` возвращает индекс или `false`. Сравнивать результат с `false` нужно через `===`, потому что индекс 0 тоже «ложен».

## Типичные ошибки

**1. Присвоить результат `sort`.**

```php
<?php
$a = [3, 1, 2];
$sorted = sort($a);
var_dump($sorted);
```

```text
bool(true)
```

`sort` возвращает `true`, а упорядоченным становится сам `$a`. Нужен просто вызов `sort($a);`, а затем работа с `$a`. Если нужен отсортированный экземпляр и неизменённый оригинал, сначала сделайте копию: `$sorted = $a; sort($sorted);`.

**2. Перепутать порядок аргументов `implode`.**

```php
<?php
echo implode([1, 2], ", ");
```

```text
Fatal error: Uncaught TypeError: implode(): Argument #1 ($separator) must be of type string, array given in main.php:2
```

Сначала разделитель, потом массив: `implode(", ", [1, 2])`.

**3. `max` и `min` от пустого массива.**

```php
<?php
echo max([]), "\n";
```

```text
Fatal error: Uncaught ValueError: max(): Argument #1 ($value) must contain at least one element in main.php:2
```

Перед вызовом убедитесь, что массив не пуст: `count($a) > 0`.

**4. `in_array` без третьего аргумента.** Нестрогое сравнение находит «лишнее»: `in_array("abc", [0])` в PHP 8 даёт `false`, но `in_array("1", [1])` даёт `true`, а `in_array(null, [0])` - тоже `true`. Всегда пишите `true`.

**5. Считать, что `array_slice` изменяет массив.** Он возвращает новый массив; исходный остаётся целым. Результат присваивают переменной.

**6. Деление на `count` пустого массива.** Среднее значение `array_sum($a) / count($a)` для пустого массива даёт `DivisionByZeroError`. Проверяйте длину перед делением.

## Итоги

* `array_sum`, `min`, `max`, `in_array`, `implode`, `array_slice` возвращают результат и не меняют массив.
* `sort` и `rsort` меняют сам массив и возвращают `true`; результат присваивать не нужно.
* `in_array` всегда вызывают с третьим аргументом `true`.
* `min`/`max` от пустого массива - ошибка; проверяйте `count`.
* `implode(разделитель, массив)` собирает список в строку для вывода.

До сих пор ключами служили номера. Но данные часто удобнее искать по имени: цена по названию товара, оценка по фамилии. Для этого - [ассоциативные массивы](lesson:php.from-zero.associative-arrays).

## Для тех, кто уже программирует

* `sort`, `rsort`, `shuffle` и подобные работают по ссылке: параметр объявлен как `array &$array`. Они возвращают `true` и меняют переданный массив, в отличие от `array_slice`, `array_reverse` и `array_map`, которые возвращают новый.
* Сортировка по умолчанию использует `SORT_REGULAR`, то есть нестрогое сравнение: числовые строки сравниваются как числа. Для предсказуемого порядка строк можно передать флаг `SORT_STRING`.
* `usort` с пользовательским компаратором и `array_multisort` появятся позже вместе с анонимными функциями.
* `implode` - аналог `join` из Python/JS; порядок аргументов в PHP: разделитель, затем массив (старый вариант с обратным порядком удалён в PHP 8).
* `min`/`max` принимают и массив, и список аргументов; в отличие от JS `Math.max(...a)` не требуют распаковки.
* `array_sum` с нечисловыми значениями в PHP 8.3+ выдаёт `Warning: Addition is not supported on type string`; раньше молча считал их нулём.
