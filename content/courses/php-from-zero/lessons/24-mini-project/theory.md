## Зачем это нужно

Вы изучили по отдельности: чтение ввода, цикл, условие, массив, функцию, исключение, класс. Настоящая программа складывает эти умения вместе. В этом уроке нет нового языка, есть новый навык: **разбить задачу на этапы** и сделать каждый по отдельности. Такой подход работает для любой программы, даже если она в десять раз больше.

## Одна идея: конвейер из этапов

Программа-отчёт почти всегда устроена как конвейер:

1. **Прочитать**: получить строки ввода одну за другой до конца.
2. **Разобрать**: для каждой строки решить, что это (пустая, верная, неверная) и достать данные.
3. **Накопить**: прибавить данные к итогам (по категориям, общий итог, счётчики).
4. **Вывести**: оформить итоги в точном формате.

Пишите и проверяйте этапы по очереди. После этапа 1 напечатайте число строк. После этапа 2 - разобранные записи. Только когда этап верен, переходите к следующему: тогда ошибка всегда находится в последнем добавленном куске.

## Пример 1. Этап «разобрать» отдельно

Разбор строки удобно вынести в функцию, которая либо возвращает объект покупки, либо бросает исключение. Класс и функция - тот же приём, что в двух предыдущих уроках.

```php run
<?php
declare(strict_types=1);

class Purchase
{
    public function __construct(
        public string $category,
        public string $name,
        public int $price,
        public int $quantity,
    ) {
    }

    public function total(): int
    {
        return $this->price * $this->quantity;
    }
}

function parsePurchase(string $line): Purchase
{
    $parts = explode(";", $line);
    if (count($parts) !== 4) {
        throw new InvalidArgumentException("нужно 4 поля, найдено " . count($parts));
    }
    $category = trim($parts[0]);
    $name = trim($parts[1]);
    if ($category === "" || $name === "") {
        throw new InvalidArgumentException("пустая категория или название");
    }
    $price = filter_var(trim($parts[2]), FILTER_VALIDATE_INT);
    $quantity = filter_var(trim($parts[3]), FILTER_VALIDATE_INT);
    if ($price === false || $quantity === false || $price <= 0 || $quantity <= 0) {
        throw new InvalidArgumentException("цена и количество должны быть положительными целыми");
    }
    return new Purchase($category, $name, $price, $quantity);
}

$lines = ["Еда;Хлеб;50;2", "Еда;Чай;250", " Дом ; Лампа ; 1200 ; 1 ", "Еда;Сыр;;1", "Дом;Стул;-5;1"];
foreach ($lines as $line) {
    try {
        $p = parsePurchase($line);
        echo "OK: {$p->category} / {$p->name} = {$p->total()}\n";
    } catch (InvalidArgumentException $e) {
        echo "Пропуск: ", $e->getMessage(), "\n";
    }
}
```
```output
OK: Еда / Хлеб = 100
Пропуск: нужно 4 поля, найдено 3
OK: Дом / Лампа = 1200
Пропуск: цена и количество должны быть положительными целыми
Пропуск: цена и количество должны быть положительными целыми
```

Разбор: `explode` режет строку по `;`, `count` проверяет число полей, `trim` убирает пробелы вокруг каждого поля. Пустая цена в строке `Еда;Сыр;;1` не прошла `filter_var`, а отрицательная цена `-5` не прошла проверку `<= 0`. Главный цикл не думает, как устроена строка: он только спрашивает, получилась ли покупка.

## Пример 2. Этап «накопить» отдельно

```php run
<?php
declare(strict_types=1);

$records = [["Еда", 100], ["Дом", 1200], ["Еда", 270]];

$counts = [];
$sums = [];
$overall = 0;
foreach ($records as $record) {
    $category = $record[0];
    $amount = $record[1];
    $counts[$category] = ($counts[$category] ?? 0) + 1;
    $sums[$category] = ($sums[$category] ?? 0) + $amount;
    $overall += $amount;
}

foreach ($sums as $category => $sum) {
    echo $category, ": ", $counts[$category], " поз., ", $sum, " руб.\n";
}
echo "Всего: ", $overall, " руб.\n";
```
```output
Еда: 2 поз., 370 руб.
Дом: 1 поз., 1200 руб.
Всего: 1570 руб.
```

Разбор: массивы `$counts`, `$sums` и число `$overall` создаются **до** цикла, а внутри цикла только меняются. Запись `($counts[$category] ?? 0) + 1` создаёт счётчик при первой встрече категории. Порядок вывода здесь - порядок появления, а в задаче нужен алфавитный.

## Пример 3. Этап «вывести» отдельно

```php run
<?php
declare(strict_types=1);

$counts = ["Еда" => 2, "Транспорт" => 1, "Дом" => 1];
$sums = ["Еда" => 370, "Транспорт" => 120, "Дом" => 1200];

ksort($sums);
foreach ($sums as $category => $sum) {
    echo $category, ": ", $counts[$category], " поз., ", $sum, " руб.\n";
}

$bestName = "";
$bestTotal = 0;
foreach (["Хлеб" => 100, "Лампа" => 1200, "Стул" => 1200] as $name => $total) {
    if ($bestName === "" || $total > $bestTotal) {
        $bestName = $name;
        $bestTotal = $total;
    }
}
echo "Самая дорогая позиция: ", $bestName, " (", $bestTotal, " руб.)\n";
```
```output
Дом: 1 поз., 1200 руб.
Еда: 2 поз., 370 руб.
Транспорт: 1 поз., 120 руб.
Самая дорогая позиция: Лампа (1200 руб.)
```

Разбор: `ksort` сортирует массив по ключам, то есть по названиям категорий. Максимум ищется по ходу обхода. Начальное состояние - «ещё ничего не найдено» (`$bestName === ""`), а не число 0. При равенстве (`Лампа` и `Стул` по 1200) сравнение строгое `>`, поэтому остаётся первая найденная.

## Пример 4. Сборка целиком

Программа читает стандартный ввод, поэтому в окне примеров её не запустить. Вот каркас, в котором нужные части расставлены по этапам:

## Точные правила задачи

* Запись - строка `категория;название;цена;количество`: ровно четыре поля, разделённые `;`. Пробелы вокруг полей допустимы и убираются через `trim`.
* Категория и название - непустые строки. Цена и количество - **целые положительные** числа (проверяются `filter_var(..., FILTER_VALIDATE_INT)`, `0` и отрицательные - ошибка).
* Любая строка, не отвечающая этим правилам (не четыре поля, пустое поле, не целое число, неположительное значение), считается неверной: она учитывается в счётчике «Пропущено строк» и больше нигде.
* Пустая строка (после `trim`) не считается ни верной, ни неверной.
* Сумма позиции - цена, умноженная на количество. Категории различаются точно (регистр важен).
* Вывод: сначала по строке на каждую категорию в порядке `ksort` (по алфавиту, побайтово): `Категория: N поз., S руб.`, затем `Всего: S руб.`, затем `Самая дорогая позиция: Название (S руб.)`, затем `Пропущено строк: N`.
* Самая дорогая позиция - с наибольшей суммой (цена на количество); при равенстве остаётся первая из встреченных. Если верных записей нет, строка о ней не печатается.
* Программа не должна падать ни на каком вводе: пустом, состоящем из неверных строк, с окончаниями строк `\r\n`, с последней строкой без перевода строки.

## Типичные ошибки

**1. Накопление без начального значения.**

```php
<?php
$sums["Еда"] += 100;
echo $sums["Еда"], "\n";
```

```text
Warning: Undefined array key "Еда" in main.php on line 2
100
```

Ключа ещё нет, PHP предупреждает и считает его `null`. Пишите `$sums[$k] = ($sums[$k] ?? 0) + $amount;`.

**2. Максимум с начальным значением 0.** Если все суммы положительны, это работает, но признак «ничего не найдено» надёжнее: он не зависит от диапазона данных.

**3. Нестрогое сравнение с результатом `filter_var`.** Условие `if (!$price)` отвергает не только `false`, но и допустимый ноль. В этой задаче ноль всё равно ошибка, но привычка сравнивать с `false` строго избавляет от скрытых ошибок.

**4. Пропущенная строка попала в итоги.** После `$skipped++` забыли `continue`, и код ниже обработал несуществующую покупку. Из функции с исключением выход происходит автоматически, но после `catch` нужно явно перейти к следующей строке.

**5. `try` вокруг всего цикла.** Первая же неверная строка прерывает цикл. `try` ставят внутрь тела цикла.

**6. Пустая строка посчитана неверной.** По условию пустая строка не учитывается нигде.

**7. Забыли про пустой ввод.** В этом случае не должно быть ни ошибки, ни строки «Самая дорогая позиция».

## Итоги

* Большая задача решается конвейером: прочитать, разобрать, накопить, вывести. Каждый этап проверяют отдельно.
* Разбор строки удобно вынести в функцию, которая возвращает объект или бросает исключение; главный цикл ловит исключение и считает пропуск.
* Итоги копятся в переменных, созданных до цикла; ключи массива создаются через `?? 0`.
* Крайние случаи (пустой ввод, равные суммы, последняя строка без перевода) нужно проверять самому.

## Для тех, кто уже программирует

* Устройство задачи - обычный конвейер «читать, парсить, агрегировать, печатать»: в других языках на него ушли бы `Scanner`, `csv` или `readline`. В PHP строки разбирают `explode`, а для реальных CSV лучше `fgetcsv`/`str_getcsv`, которые умеют кавычки.
* Валидация вынесена в функцию с исключением, вызов обёрнут в `try/catch` внутри цикла. Альтернатива - возвращать `?Purchase` и проверять `null`; исключение удобнее, когда нужна причина.
* Агрегация идёт в ассоциативных массивах (`?? 0` - идиома PHP вместо `defaultdict`). `ksort` сортирует по ключам побайтово, поэтому латиница заглавная идёт раньше строчной; для словарной сортировки с учётом локали нужны `intl` или `uasort` с `strcoll`.
* Все деньги в целых числах (рубли) исключают проблемы с плавающей точкой; с копейками берут минимальную единицу (копейки) и форматируют при выводе.
* Числовые строки как ключи (`"123"`) PHP превращает в целые, и порядок `ksort` может отличаться от ожидаемого; для категорий это не проблема, для идентификаторов стоит помнить.
* Следующий курс переходит к устройству движка: как PHP компилирует код, как работают массивы-хэши и режимы типов.
