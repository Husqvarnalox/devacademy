## Зачем это нужно

Текст - самый частый вид данных: имена, адреса, названия товаров, строки ввода. Чаще всего с ним надо сделать несколько типовых вещей: разрезать строку на слова, проверить, есть ли в ней фрагмент, заменить часть, взять первые буквы, выровнять по ширине. Для каждой есть готовая функция. Главное - выбирать правильную версию для русского текста.

## Одна новая идея: функции работают либо с байтами, либо с символами

Русская буква в UTF-8 занимает два байта (вы видели это в уроке о строках: `strlen("Привет")` равно 12). Поэтому у части функций есть две версии:

* **обычная** (`substr`, `strtoupper`) считает **байты** и подходит для латиницы и цифр;
* **многобайтовая** с приставкой `mb_` (`mb_substr`, `mb_strtoupper`) считает **символы** и безопасна для кириллицы.

Для русских текстов всегда выбирайте `mb_`-версию. Функции без пары (`explode`, `implode`, `str_replace`, `str_contains`, `trim`) работают с любым текстом правильно, потому что ищут целые последовательности байтов.

Основные функции:

| Функция | Что делает |
|---|---|
| `explode($sep, $s)` | режет строку по разделителю на массив |
| `implode($sep, $a)` | собирает массив в строку |
| `str_contains($s, $part)` | есть ли в строке фрагмент (`bool`, с учётом регистра) |
| `str_replace($from, $to, $s)` | заменяет все вхождения `$from` на `$to` |
| `mb_substr($s, $start, $len)` | часть строки по символам |
| `mb_strtoupper`, `mb_strtolower` | верхний и нижний регистр |
| `mb_ucfirst($s)` | первая буква заглавная (PHP 8.4+); `ucfirst` не работает с кириллицей |
| `str_pad`, `mb_str_pad` | дополняет строку до заданной длины |

## Пример 1. explode и implode

```php run
<?php
declare(strict_types=1);

$line = "хлеб,молоко,сыр";
$items = explode(",", $line);
echo count($items), " товара, второй: ", $items[1], "\n";
echo implode(" | ", $items), "\n";

$gaps = explode(" ", "один  два");
echo count($gaps), "\n";
```
```output
3 товара, второй: молоко
хлеб | молоко | сыр
3
```

Разбор: `explode` режет по каждому вхождению разделителя. В последнем примере два пробела подряд дали **три** части: «один», пустая строка между пробелами и «два». Пустые части приходится пропускать самим: `if ($part === "") { continue; }`.

## Пример 2. Поиск и замена

```php run
<?php
declare(strict_types=1);

$text = "Кот спит. Кот ест.";
var_dump(str_contains($text, "спит"));
var_dump(str_contains($text, "кот"));
echo str_replace("Кот", "Пёс", $text), "\n";
echo str_replace(["Кот", "спит"], ["Пёс", "лает"], $text), "\n";
```
```output
bool(true)
bool(false)
Пёс спит. Пёс ест.
Пёс лает. Пёс ест.
```

Разбор: поиск различает регистр: «кот» со строчной в тексте нет. `str_replace` заменяет все вхождения. Если передать два массива, пары применяются по очереди.

## Пример 3. Части строки

```php run
<?php
declare(strict_types=1);

$word = "Привет";
echo mb_substr($word, 0, 3), "\n";
echo mb_substr($word, 3), "\n";
echo mb_substr($word, -2), "\n";
echo substr("Hello", 1, 3), "\n";
var_dump(mb_check_encoding(substr($word, 0, 3), "UTF-8"));
var_dump(mb_check_encoding(mb_substr($word, 0, 3), "UTF-8"));
```
```output
При
вет
ет
ell
bool(false)
bool(true)
```

Разбор: `mb_substr($s, $start, $length)` берёт `$length` символов, начиная с индекса `$start` (с нуля). Без длины берётся всё до конца, отрицательный старт считает с конца. Обычный `substr("Привет", 0, 3)` отрезал три **байта**: это одна буква и половинка второй, то есть строка с повреждённой кодировкой (`mb_check_encoding` вернула `false`). Для латиницы `substr` безопасен.

## Пример 4. Регистр

```php run
<?php
declare(strict_types=1);

echo ucfirst("ivan"), " ", ucfirst("иван"), "\n";
echo mb_ucfirst("иван"), "\n";
echo mb_strtoupper("привет"), " ", mb_strtolower("МИР"), "\n";
echo mb_strtoupper(mb_substr("анна", 0, 1)), ".\n";
```
```output
Ivan иван
Иван
ПРИВЕТ мир
А.
```

Разбор: `ucfirst` умеет только латиницу и оставил «иван» как есть. `mb_ucfirst` исправляет первую букву любого алфавита. Для инициала берут первую букву через `mb_substr`, поднимают регистр через `mb_strtoupper` и добавляют точку.

## Пример 5. Выравнивание

```php run
<?php
declare(strict_types=1);

echo str_pad("7", 3, "0", STR_PAD_LEFT), "\n";
echo str_pad("Tea", 8, "."), "45\n";
echo mb_str_pad("Чай", 8, "."), "45\n";
echo str_repeat("-", 10), "\n";
```
```output
007
Tea.....45
Чай.....45
----------
```

Разбор: `str_pad($s, $length, $fill, $type)` дополняет строку заполнителем до длины `$length`; по умолчанию справа, `STR_PAD_LEFT` - слева. Для «Чай» использована `mb_str_pad` (PHP 8.3+): она считает символы, и точек получилось пять, как для латиницы.

**Попробуйте.** Разделите строку `"иванов иван иванович"` по пробелам и выведите каждое слово с заглавной буквы.

## Точные правила

* `explode($separator, $string)` возвращает массив частей. Разделитель не должен быть пустой строкой. Подряд идущие разделители дают пустые элементы; необязательный третий аргумент ограничивает число частей.
* `str_contains($haystack, $needle)` различает регистр; для пустого `$needle` вернёт `true`. Парные `str_starts_with` и `str_ends_with` проверяют начало и конец строки.
* `str_replace($search, $replace, $subject)` - порядок аргументов именно такой. Работает с массивами, регистр различает (для игнорирования регистра есть `str_ireplace`).
* `mb_substr($s, $start, $length = null)`: старт считается в символах с нуля, отрицательный - с конца. Для пустого результата вернёт `""`.
* `mb_strtoupper`, `mb_strtolower`, `mb_strlen` работают с UTF-8 (задан настройкой `default_charset`). `mb_ucfirst` и `mb_lcfirst` появились в PHP 8.4; в более старых версиях первую букву поднимают так: `mb_strtoupper(mb_substr($s, 0, 1)) . mb_substr($s, 1)`.
* `str_pad($s, $length, $pad = " ", $type = STR_PAD_RIGHT)` считает **байты**; для кириллицы - `mb_str_pad` (PHP 8.3+). Если строка длиннее `$length`, она возвращается без изменений.
* `str_repeat($s, $times)` повторяет строку; `strrev` переворачивает по байтам и ломает кириллицу.
* Строковые функции не меняют исходную строку, а возвращают новую: результат нужно присвоить.
* Функции расширения `mbstring` в некоторых сборках ставятся отдельно (пакет `php-mbstring`); в официальных сборках и macOS они есть.

## Типичные ошибки

**1. Пустой разделитель в `explode`.**

```php
<?php
echo explode("", "abc");
```

```text
Fatal error: Uncaught ValueError: explode(): Argument #1 ($separator) must not be empty in main.php:2
```

Чтобы разрезать строку на буквы, используйте `mb_str_split($s)`.

**2. `substr` для кириллицы.** `substr("Привет", 0, 3)` возвращает повреждённую строку: два байта первой буквы и один байт второй. На экране это «П» и символ-заменитель. Берите `mb_substr`.

**3. `ucfirst` и `strtoupper` для русского.** Они не меняют кириллицу: `ucfirst("иван")` вернёт `иван`. Используйте `mb_ucfirst` или `mb_strtoupper(mb_substr(...))`.

**4. Пропущенные пустые части после `explode`.** `explode(" ", "один  два")` вернёт три элемента, средний пустой. Если пустые части нежелательны, пропускайте их.

**5. Перепутанный порядок аргументов `str_replace`.** Сначала что искать, затем на что менять, затем где: `str_replace("кот", "пёс", $text)`. Строка `$text` идёт последней.

**6. Ждать, что функция изменит строку.** `str_replace("а", "о", $s);` без присваивания ничего не меняет: `$s` останется прежней. Пишите `$s = str_replace(...)`.

**7. Регистр.** `str_contains("Привет", "привет")` ложно. Для поиска без учёта регистра приведите обе строки к одному регистру через `mb_strtolower`.

## Итоги

* Для кириллицы выбирайте `mb_`-версии: `mb_substr`, `mb_strtoupper`, `mb_strtolower`, `mb_str_pad`, `mb_ucfirst`.
* `explode` режет строку на массив, `implode` собирает обратно; пустые части после `explode` нужно пропускать самому.
* `str_contains` ищет фрагмент с учётом регистра, `str_replace` заменяет все вхождения.
* Строковые функции возвращают новую строку и не меняют исходную.

Теперь можно разобрать ввод любого размера: [чтение всего ввода до конца](lesson:php.from-zero.reading-all-input).

## Для тех, кто уже программирует

* Строки PHP - последовательности байтов без знания кодировки; поэтому `strlen`, `substr`, `strtoupper`, `str_pad` оперируют байтами, а `mb_*` - символами UTF-8 (аналог кодовых точек, не графем). Для графем и сравнения с учётом языка есть расширение `intl`.
* `explode`/`implode` - аналоги `split`/`join`. `explode` не принимает регулярное выражение (для этого `preg_split`) и не схлопывает подряд идущие разделители.
* `str_contains`, `str_starts_with` и `str_ends_with` появились в PHP 8.0: раньше писали `strpos($s, $x) !== false` и забывали про `0`. `mb_ucfirst`, `mb_lcfirst` и `mb_trim` добавлены в PHP 8.4, `mb_str_pad` - в 8.3.
* Все функции возвращают новую строку; строки в PHP изменяемы по индексу (`$s[0] = "X"`), но это редко нужно и опасно для UTF-8.
* Отрицательные индексы допускаются в `mb_substr`, `substr` и `$s[-1]` (последний байт).
