## Зачем это нужно

Многие задачи состоят из повторения: пересчитать позиции в чеке, дождаться, пока накопится нужная сумма, обработать каждую строку входных данных. Писать одну и ту же команду десять раз неудобно, а если число повторов заранее неизвестно, невозможно. Для повторения служат **циклы**. Первый из них - `while`.

## Одна новая идея: пока условие истинно, блок выполняется снова и снова

**`while`** («пока») проверяет условие перед каждым проходом. Если оно истинно, выполняется блок, затем условие проверяется заново; когда оно становится ложным, цикл заканчивается, и программа идёт дальше:

```php
$i = 1;
while ($i <= 3) {
    echo "Шаг {$i}\n";
    $i++;
}
```

Один проход цикла называется **итерацией**. Переменная `$i` здесь - **счётчик**: он начинается с 1 и растёт на каждой итерации. Запись `$i++` означает «увеличить `$i` на единицу», это сокращение для `$i += 1`.

У цикла три части, и забыть любую опасно:

1. **Начальное значение** (`$i = 1`) задают до цикла.
2. **Условие** (`$i <= 3`) решает, нужен ли ещё один проход.
3. **Изменение** (`$i++`) внутри блока приближает момент, когда условие станет ложным. Без изменения цикл не закончится никогда.

Вторая типичная роль цикла - накопление: переменная-**накопитель** собирает результат (сумму, количество) по мере прохода.

<!-- section: examples -->
## Пример 1. Счёт от 1 до 3

```php run
<?php
$i = 1;
while ($i <= 3) {
    echo "Шаг {$i}\n";
    $i++;
}
echo "Готово, i = {$i}\n";
```
```output
Шаг 1
Шаг 2
Шаг 3
Готово, i = 4
```

Разбор: после третьей итерации `$i` стало 4, условие `4 <= 3` ложно, и цикл закончился. Значение счётчика после цикла - 4, а не 3: это стоит помнить.

## Пример 2. Накопление суммы

```php run
<?php
$sum = 0;
$n = 1;
while ($n <= 5) {
    $sum += $n;
    $n++;
}
echo "Сумма чисел от 1 до 5: {$sum}\n";
```
```output
Сумма чисел от 1 до 5: 15
```

Разбор: `$sum` начинается с нуля и на каждой итерации растёт на текущее `$n`: 0 + 1 + 2 + 3 + 4 + 5. Накопитель всегда задают до цикла, иначе нечему будет прибавлять.

## Пример 3. Число повторов заранее неизвестно

```php run
<?php
$balance = 1000;
$years = 0;
while ($balance < 1500) {
    $balance = $balance * 110 / 100;
    $years++;
}
echo "Лет: {$years}, на счёте: " . round($balance, 2) . "\n";
```
```output
Лет: 5, на счёте: 1610.51
```

Разбор: вклад растёт на 10% в год, пока не достигнет 1500. Сколько лет понадобится, вычислить в голове непросто, но цикл `while` в этом и силён: он повторяет, пока цель не достигнута. Здесь `round` скрывает хвост дробной части.

## Пример 4. Цикл может не выполниться ни разу

```php run
<?php
$i = 10;
while ($i < 5) {
    echo "Не напечатается\n";
    $i++;
}
echo "Конец\n";
```
```output
Конец
```

Разбор: условие проверяется до первого прохода. Раз оно изначально ложно, блок пропускается целиком. Так же ведёт себя и цикл, у которого цель уже достигнута к началу.

**Попробуйте.** Измените условие примера 1 на `$i < 3` и предскажите, сколько строк появится и чему равно `$i` в конце.

## Точные правила

* Форма: `while (условие) { тело }`. Условие вычисляется перед каждой итерацией, включая первую.
* Если условие ложно с самого начала, тело не выполняется ни разу.
* `$i++` увеличивает переменную на 1, `$i--` уменьшает; `$sum += $x` - то же, что `$sum = $sum + $x`.
* Цикл, у которого условие никогда не становится ложным, называется **бесконечным**. Программа продолжает работать, пока её не остановят вручную (в терминале - `Ctrl+C`); приложение прерывает запуск по таймауту.
* Переменные, созданные в теле, остаются доступными после цикла.
* Для счётчика с известными границами удобнее цикл `for`; он описан в следующем уроке. `while` предпочтителен, когда число итераций заранее неизвестно.
* Есть и `do { ... } while (условие);`: тело выполняется минимум один раз, условие проверяется после. Он встречается редко и в курсе не используется.

## Типичные ошибки

**1. Забыли изменить счётчик.**

```php
<?php
$i = 1;
while ($i <= 3) {
    echo "Шаг {$i}\n";
}
```

Программа напечатает `Шаг 1` бесконечно много раз: `$i` не меняется, и условие всегда истинно. Остановите её `Ctrl+C` и добавьте `$i++`.

**2. Не задали начальное значение.**

```php
<?php
while ($i < 3) {
    echo "x\n";
    break;
}
```

```text
Warning: Undefined variable $i in main.php on line 2
```

Переменная `$i` не существует. PHP предупреждает и считает её значение `null`. Цикл работает, но результат случайный. Все переменные цикла задавайте перед ним. (В примере стоит `break`, чтобы цикл не стал бесконечным: об этой команде - в уроке про управление циклами.)

**3. Ошибка на единицу.** `while ($i < 3)` и `while ($i <= 3)` дают три и четыре прохода при счёте от 1 до 3 и от 0 до 3. Проверьте крайние значения: сколько проходов вы ожидаете и сколько получаете.

**4. Накопитель внутри цикла.**

```php
while ($n <= 5) {
    $sum = 0;
    $sum += $n;
    $n++;
}
```

Обнуление на каждой итерации стирает накопленное: в конце `$sum` равно последнему слагаемому. Накопитель создают до цикла.

**5. Условие, которое меняется не в ту сторону.** `$balance` растёт, а условие `$balance > 0` всегда истинно: цикл бесконечен. Перед запуском проверьте, что изменение переменной приближает условие к ложному.

<!-- section: summary -->
## Итоги

* `while (условие) { ... }` повторяет блок, пока условие истинно; условие проверяется перед каждой итерацией.
* Цикл нуждается в начальном значении, условии и изменении, которое когда-нибудь сделает условие ложным.
* Накопитель (сумма, количество) задаётся до цикла и меняется внутри.
* `$i++` увеличивает на единицу, `+=` прибавляет произвольное значение.

Когда число повторов известно заранее, удобнее [цикл for](lesson:php.from-zero.for-loop).

## Для тех, кто уже программирует

* `while` работает как в C, Java и JS; есть `do ... while`. Альтернативная запись `while (...): ... endwhile;` встречается в шаблонах.
* Присваивание внутри условия, `while ($line = fgets(STDIN))`, законно, но опасно: строка `"0"` ложна. Для чтения ввода курс использует строгое сравнение (урок 21).
* `break` и `continue` принимают число уровней вложенности: `break 2;` выходит сразу из двух циклов.
* Переменные цикла остаются видимыми после него, как и в Python; в JS с `let` это не так.
* PHP-скрипт в CLI по умолчанию не ограничен по времени (`max_execution_time=0`), так что бесконечный цикл придётся остановить вручную.
