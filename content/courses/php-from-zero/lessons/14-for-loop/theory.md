## Зачем это нужно

Часто известно, сколько раз нужно повторить действие: напечатать строки чека с первой по десятую, перебрать числа от 1 до 100, пройти по месяцам года. Цикл `while` справится, но начальное значение, условие и изменение счётчика разбросаны по трём местам, и среди них легко что-то пропустить. Цикл `for` собирает все три части в одной строке.

## Одна новая идея: заголовок цикла описывает счётчик целиком

В круглых скобках `for` стоят три части, разделённые точками с запятой:

```php
for ($i = 1; $i <= 3; $i++) {
    echo "Шаг {$i}\n";
}
```

1. **Начало** (`$i = 1`) выполняется один раз перед циклом.
2. **Условие** (`$i <= 3`) проверяется перед каждой итерацией; пока оно истинно, цикл продолжается.
3. **Шаг** (`$i++`) выполняется после каждой итерации.

Это точно тот же цикл, что и

```php
$i = 1;
while ($i <= 3) {
    echo "Шаг {$i}\n";
    $i++;
}
```

только записанный компактно. Выбирайте `for`, когда есть счётчик и известны его границы; `while` - когда нужно повторять «пока не случится событие».

<!-- section: examples -->
## Пример 1. Счёт от 1 до 5

```php run
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "{$i} ";
}
echo "\n";
```
```output
1 2 3 4 5 
```

Разбор: после каждой цифры печатается пробел, поэтому в конце строки остаётся лишний пробел. Лишний пробел в конце строки незаметен глазу, но тест, сравнивающий вывод побуквенно, его заметит; позже вы увидите, как соединять значения без хвоста (функция `implode`).

## Пример 2. Другой шаг и обратный счёт

```php run
<?php
for ($i = 0; $i <= 20; $i += 5) {
    echo "{$i} ";
}
echo "\n";
for ($i = 3; $i >= 1; $i--) {
    echo "{$i}...";
}
echo "Старт!\n";
```
```output
0 5 10 15 20 
3...2...1...Старт!
```

Разбор: шаг - любое выражение. `$i += 5` прибавляет пятёрку; `$i--` уменьшает счётчик, а условие меняется на `>=`. Если счётчик уменьшается, условие должно быть «больше», иначе цикл не выполнится.

## Пример 3. Таблица цен

```php run
<?php
$price = 45;
for ($count = 1; $count <= 4; $count++) {
    $total = $price * $count;
    echo "{$count} шт. - {$total} руб.\n";
}
```
```output
1 шт. - 45 руб.
2 шт. - 90 руб.
3 шт. - 135 руб.
4 шт. - 180 руб.
```

Разбор: счётчик участвует в вычислениях внутри тела: на каждой итерации он увеличивает количество. Цикл `for` не нужно подстраивать под число итераций: достаточно поменять границу.

## Пример 4. Накопление и итог после цикла

```php run
<?php
$sum = 0;
for ($i = 1; $i <= 10; $i++) {
    $sum += $i * $i;
}
echo "Сумма квадратов 1..10: {$sum}\n";
echo "Счётчик после цикла: {$i}\n";
```
```output
Сумма квадратов 1..10: 385
Счётчик после цикла: 11
```

Разбор: накопитель `$sum` задан до цикла. Счётчик `$i` после цикла равен 11: условие `11 <= 10` стало ложным именно на этом значении.

**Попробуйте.** Напечатайте чётные числа от 2 до 20 одним `for`. Затем напечатайте числа от 10 до 1.

## Точные правила

* Форма: `for (начало; условие; шаг) { тело }`. Каждая из трёх частей может быть пустой, но точки с запятой остаются: `for (;;)` - бесконечный цикл.
* Порядок: начало, затем повторяется «проверка условия - тело - шаг». Если условие ложно с первой проверки, тело не выполняется.
* Число итераций `for ($i = a; $i < b; $i++)` равно `b - a` (при `b > a`); с `<=` оно на единицу больше. Эту разницу полезно проверять вручную на маленьких числах.
* В начале и шаге допускаются несколько выражений через запятую: `for ($i = 0, $j = 10; $i < $j; $i++, $j--)`. Условия через запятую соединять нельзя: используйте `&&`.
* Счётчик можно изменять и внутри тела, но это сбивает читателя: цикл ломается, когда шаг и тело меняют счётчик по-разному.
* Счётчик остаётся доступным после цикла (см. пример 4).
* Для обхода массивов в PHP есть более удобный цикл `foreach`; он появится вместе с массивами.

## Типичные ошибки

**1. Запятые вместо точек с запятой.**

```php
<?php
for ($i = 0, $i < 3, $i++) {
    echo $i;
}
```

```text
Parse error: syntax error, unexpected token ")", expecting ";" in main.php on line 2
```

Части заголовка разделяются `;`. Запятая внутри одной части допустима, а между частями - нет, поэтому PHP дочитал до конца первой части и ждал `;`.

**2. Ошибка на единицу.** Чтобы пройти по пяти элементам, нужен `$i < 5` при счёте с нуля или `$i <= 5` при счёте с единицы. Если границу перепутать, цикл сделает на один проход больше или меньше.

**3. Шаг не в ту сторону.** `for ($i = 10; $i > 0; $i++)` бесконечен: счётчик растёт, а условие требует, чтобы он был больше нуля. Для обратного счёта шаг - `$i--`.

**4. Лишняя точка с запятой после заголовка.** Запись `for (...);` заканчивает цикл пустой командой, а блок `{ ... }` ниже выполняется один раз после цикла. Никакой ошибки PHP не выдаёт, но результат неверен.

**5. Дробный счётчик.** Цикл `for ($x = 0; $x != 1; $x += 0.1)` может не остановиться: сумма десяти «одной десятых» не равна 1 точно. Для счётчика используйте целые числа.

**6. Использовать `$i` из предыдущего цикла.** После цикла счётчик сохраняет последнее значение. Перед новым циклом его всегда задают заново, в начале `for`.

<!-- section: summary -->
## Итоги

* `for (начало; условие; шаг)` собирает управление счётчиком в одной строке.
* Начало выполняется один раз, условие проверяется перед каждым проходом, шаг выполняется после каждого прохода.
* Для обратного счёта шаг - `$i--`, а условие - `>` или `>=`.
* Различие `<` и `<=` определяет, сколько раз выполнится тело; границы проверяют вручную.

В следующем уроке цикл можно будет досрочно прервать или пропустить его итерацию, а также вложить один цикл в другой: [break, continue и вложенные циклы](lesson:php.from-zero.loop-control).

## Для тех, кто уже программирует

* Синтаксис `for` в PHP совпадает с C и Java; запятая в частях начала и шага разрешена, как в C.
* Переменная счётчика не локальна для цикла и остаётся видимой после него (в JS с `let` и в Java это не так).
* Для обхода коллекций обычно используют `foreach`, а не `for` с индексом.
* Счётчик, в отличие от Python `range`, не создаёт объект: это обычная переменная, и менять её можно как угодно.
* `for (;;)` работает как `while (true)`.
