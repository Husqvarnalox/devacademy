## Зачем это нужно

Цикл по умолчанию проходит все значения от начала до конца. Но на практике часто нужно иное: прекратить поиск, как только нужное найдено; пропустить неподходящую запись и перейти к следующей; перебрать пары значений, например ряды и места в зале. Для этого есть две команды управления циклом и вложенные циклы.

## Одна новая идея: цикл можно прервать или пропустить его итерацию

* **`break`** («прервать») немедленно завершает цикл. Выполнение продолжается с команды после цикла.
* **`continue`** («продолжить») пропускает остаток тела на текущей итерации и переходит к следующей.

Обычно эти команды стоят внутри `if`: «если встретили плохое значение - пропустить его», «если деньги кончились - остановиться».

**Вложенный цикл** - это цикл внутри тела другого цикла. Внешний цикл на каждой своей итерации запускает внутренний с самого начала. Если внешний цикл выполняется 3 раза, а внутренний 4, тело внутреннего выполнится 12 раз.

<!-- section: examples -->
## Пример 1. break останавливает цикл

```php run
<?php
$budget = 300;
echo "Купили товары:";
for ($i = 1; $i <= 10; $i++) {
    $cost = $i * 40;
    if ($cost > $budget) {
        break;
    }
    $budget -= $cost;
    echo " {$i}";
}
echo "\nОсталось: {$budget} руб.\n";
```
```output
Купили товары: 1 2 3
Осталось: 60 руб.
```

Разбор: товар номер `$i` стоит `$i * 40`. Первые три помещаются в бюджет. Четвёртый стоит 160, а осталось 60, поэтому `break` прерывает цикл. Остальные шесть итераций не выполняются, хотя цикл заявлен до 10.

## Пример 2. continue пропускает итерацию

```php run
<?php
for ($i = 1; $i <= 9; $i++) {
    if ($i % 2 === 0) {
        continue;
    }
    echo $i, " ";
}
echo "\n";
```
```output
1 3 5 7 9 
```

Разбор: для чётных `$i` условие истинно, `continue` пропускает `echo` и переходит к шагу `$i++`. Цикл при этом продолжается до 9.

## Пример 3. Вложенные циклы: таблица умножения

```php run
<?php
for ($row = 1; $row <= 3; $row++) {
    for ($col = 1; $col <= 4; $col++) {
        printf("%4d", $row * $col);
    }
    echo "\n";
}
```
```output
   1   2   3   4
   2   4   6   8
   3   6   9  12
```

Разбор: для каждого ряда внутренний цикл печатает четыре числа (`%4d` отводит под число четыре символа). Перевод строки стоит после внутреннего цикла, но внутри внешнего: он завершает ряд. Всего тело внутреннего цикла выполнилось 3 * 4 = 12 раз.

## Пример 4. break во вложенном цикле

```php run
<?php
for ($i = 1; $i <= 3; $i++) {
    echo "Ряд {$i}:";
    for ($j = 1; $j <= 5; $j++) {
        if ($j > $i) {
            break;
        }
        echo " {$j}";
    }
    echo "\n";
}
```
```output
Ряд 1: 1
Ряд 2: 1 2
Ряд 3: 1 2 3
```

Разбор: `break` завершает только внутренний цикл, в котором стоит. Внешний при этом продолжается: после каждого `break` печатается перевод строки и начинается следующий ряд.

**Попробуйте.** Замените `break` в примере 1 на `continue` и предскажите, что напечатается: будут ли куплены товары с большими номерами, если деньги кончились?

## Точные правила

* `break;` завершает ближайший объемлющий цикл (`while`, `for`, а также `foreach` и `switch`). `continue;` переходит к следующей итерации ближайшего цикла.
* В цикле `for` после `continue` всё равно выполняется шаг (`$i++`); в `while` шаг пишется в теле, поэтому `continue` перед ним его **пропустит** (см. ошибку 2).
* Обе команды допускают число уровней: `break 2;` выходит сразу из двух вложенных циклов, `continue 2;` переходит к следующей итерации внешнего. Курс применяет эту возможность только по необходимости.
* Вне цикла `break` и `continue` недопустимы: PHP сообщает об этом до запуска программы.
* Число выполнений тела вложенного цикла равно произведению числа итераций внешнего и внутреннего (если внутренний не прерывается).
* Счётчики вложенных циклов называют разными именами (`$row`, `$col`; допустимы `$i`, `$j`). Одно имя в обоих циклах приведёт к тому, что внутренний сломает внешний.

## Типичные ошибки

**1. `break` вне цикла.**

```php
<?php
break;
echo 1;
```

```text
Fatal error: 'break' not in the 'loop' or 'switch' context in main.php on line 2
```

Команды `break` и `continue` имеют смысл только внутри цикла.

**2. `continue` в `while` до увеличения счётчика.**

```php
<?php
$i = 0;
while ($i < 5) {
    if ($i === 2) {
        continue;
    }
    echo $i;
    $i++;
}
```

Программа напечатает `01` и зависнет: на `$i === 2` выполняется `continue`, `$i++` пропускается, значение не меняется, и условие снова приводит к тому же `continue`. В `while` увеличивайте счётчик до `continue` или переходите на `for`.

**3. Ожидать, что `break` выходит из всех циклов.** Во вложенных циклах он завершает только внутренний. Нужен выход из обоих - `break 2;` либо флажок-переменная.

**4. Одинаковое имя счётчика в обоих циклах.** При `for ($i...) { for ($i...) }` внутренний цикл меняет счётчик внешнего, и внешний завершается раньше времени или не завершается вовсе.

**5. Перевод строки не на том уровне.** Если `echo "\n"` оказывается внутри внутреннего цикла, каждое число уйдёт на новую строку; если после обоих, весь ряд склеится в одну. Перевод строки ставят там, где закончилась логическая строка вывода.

**6. Слишком много вложенности.** Три и более вложенных цикла почти всегда можно упростить, вынеся часть логики отдельно (как это делается через функции в следующем уроке).

## Итоги

* `break` завершает ближайший цикл, `continue` переходит к следующей итерации.
* В `for` после `continue` выполняется шаг, в `while` - нет, поэтому счётчик в `while` меняют до `continue`.
* Во вложенных циклах внутренний цикл запускается заново на каждой итерации внешнего; `break` действует только на внутренний.
* Эти команды используют, чтобы пропускать некорректные данные и останавливаться, когда ответ уже найден.

Теперь у вас есть переменные, ввод, условия и циклы. Чтобы не повторять один и тот же код, его оформляют как [функцию](lesson:php.from-zero.functions).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `break` и `continue` ведут себя как в C. Отличие PHP: числовой аргумент (`break 2;`) вместо меток, как в Java и JS.
* `continue` внутри `switch` ведёт себя как `break` (а в PHP 7.3+ ещё и выдаёт предупреждение): в `switch` внутри цикла пишите `continue 2;`.
* В `for` команда `continue` выполняет шаг, в `while` и `do ... while` - нет.
* `goto` в PHP существует, но в курсе не используется.
