## Типы в PHP: динамические по природе, строгие по желанию

PHP хранит тип вместе со значением, а не с переменной: `$x = 5; $x = "пять";` допустимо. Но современный PHP позволяет **объявлять** типы параметров, возвращаемых значений и свойств, и движок проверяет их при выполнении:

```php
function area(float $w, float $h): float { return $w * $h; }
```

Есть два режима проверки:

* **слабый** (по умолчанию): скаляры приводятся «без потерь», `area("3", 4)` работает;
* **строгий** (`declare(strict_types=1);` первой инструкцией файла): значение должно подходить по типу, а `"3"` для `float` - `TypeError`. Единственное разрешённое расширение - `int` в `float`.

Вторая половина урока - **приведение типов** (type juggling): что PHP делает со значениями разных типов в операторах `==`, `+`, `if`, `switch`. В PHP 8 правила сравнения строк с числами стали разумнее, но ловушки остались, и поэтому по умолчанию пишут `===`.

## Точные правила

**Какие типы можно объявлять.** Скалярные `int`, `float`, `string`, `bool`; `array`, `callable`, `iterable`, `object`, `mixed`; имена классов и интерфейсов; `self`, `static`; для возврата ещё `void` и `never`.

* **Nullable** `?int` - то же, что `int|null`.
* **Объединение** `int|string` (union types, PHP 8.0). Порядок не важен; `?T` - сокращение для `T|null`.
* **Пересечение** `Countable&Iterator` (intersection types, PHP 8.1).
* **Автономные** `null` и `false` как самостоятельные типы, а также `true` (PHP 8.2); комбинации объединений и пересечений со скобками - DNF-типы `(A&B)|null` (PHP 8.2).
* **`mixed`** (PHP 8.0) - любое значение, включая `null`; `static` как возвращаемый тип (8.0).
* **`never`** (PHP 8.1) - функция не возвращает управление: она всегда бросает исключение или вызывает `exit`. `void` означает «вернулась, но без значения».
* **Типизированные свойства** появились в PHP 7.4, **типизированные константы классов** - в PHP 8.3 (`const string NAME = 'x';`).
* **Скалярные объявления** и `strict_types` существуют с PHP 7.0.

**`strict_types`.** Директива действует на вызовы, *совершаемые из этого файла*, и должна стоять первой инструкцией. Возвращаемые значения проверяются по режиму файла, в котором объявлена функция. В строгом режиме `int` принимает только `int`, `float` принимает `float` и `int`, `string` - только `string`, `bool` - только `bool`; `null` разрешён лишь для nullable-типов. Исключение: вызовы встроенных функций *из других встроенных функций* (например, через `array_map`) идут в слабом режиме.

**Слабый режим.** Скаляр приводится, если значение подходит без потерь: `"10"` и `true` для `int`, `10` для `string`. Нечисловая строка для `int` даёт `TypeError`. Дробное число или строка вроде `"1.5"` для `int`: PHP 8.1 объявил такое «неявное преобразование с потерей точности» устаревшим (выдаёт Deprecated), поэтому на него полагаться нельзя. `null` в параметр пользовательской функции без `?` - `TypeError`.

**Объединённые типы в слабом режиме.** Если значение точно подходит одному из типов объединения, оно остаётся как есть. Иначе PHP пробует по порядку `int`, `float`, `string`, `bool` и берёт первый подходящий; числовая строка становится `int`, если она целочисленная, и `float` в остальных случаях. Тонкие случаи (например, дробный `float` для `int|string`) зависят от версии и дают Deprecated, поэтому на них не полагайтесь.

**Сравнение `==` и `===`.** `===` сравнивает тип и значение. `==` сначала приводит операнды к общему виду. PHP 8 изменил главное правило: если число сравнивается со строкой, которая **не является числовой**, число превращается в *строку*, и сравниваются две строки. Поэтому `0 == "a"` теперь ложно (в PHP 7 было истинно), `"abc" == 0` ложно, а `"1" == "01"`, `"10" == "1e1"` и `100 == "1e2"` по-прежнему истинны: обе стороны числовые, сравниваются как числа. Числовыми считаются строки вида `" 12"`, `"12 "` (пробелы допустимы с обеих сторон начиная с PHP 8), `"1.5"`, `"1e3"`, `".5"`, `"+5"`; но не `"12abc"`, `"0x1A"` и не пустая строка.

Прочие нестрогие равенства: `null == false`, `null == ""`, `null == 0`, `"0" == false` и `[] == false` истинны, а `0 == ""` в PHP 8 ложно. Полную таблицу смотрите в руководстве, а в коде пользуйтесь `===`.

**Приведение к `bool`.** Ложны: `false`, `0`, `0.0`, `""`, `"0"`, пустой массив, `null`. Строки `"0.0"` и `"false"` истинны.

**Арифметика.** Числовая строка в операции превращается в `int` или `float`. Строка с числом в начале (`"5 apples"`) даёт предупреждение «A non-numeric value» и берёт начальную часть. Полностью нечисловая строка в арифметике в PHP 8 бросает `TypeError`. Переполнение `int` превращает результат в `float`. Деление `/` возвращает `int`, только если результат целый.

**Дробные числа.** `0.1 + 0.2 == 0.3` ложно, как и в любом языке с двоичной арифметикой; сравнивайте с допуском.

**Нестрогие функции.** `in_array`, `array_search`, `array_keys` с искомым значением и `switch` сравнивают через `==`. У `in_array` и `array_search` третий аргумент `true` включает `===`. Выражение `match` всегда сравнивает строго.

## Примеры

**Пример 1. Строгий режим: что принимает `int`-параметр.**

```php run
<?php
declare(strict_types=1);

function half(int $n): float
{
    return $n / 2;
}

function scale(float $x): float
{
    return $x * 2;
}

foreach ([10, 10.0, '10', true, null] as $arg) {
    try {
        $result = (string) half($arg);
    } catch (TypeError $e) {
        $result = $e::class;
    }
    echo get_debug_type($arg), ' -> ', $result, "\n";
}
echo 'int to float: ', scale(3), "\n";
```
```output
int -> 5
float -> TypeError
string -> TypeError
bool -> TypeError
null -> TypeError
int to float: 6
```

Единственное допустимое расширение в строгом режиме - `int` в `float`.

**Пример 2. Тот же `half` в слабом режиме (без `declare`).**

```php run
<?php
function half(int $n): float
{
    return $n / 2;
}

foreach (['10', true, 'abc', null, '5 apples'] as $arg) {
    try {
        $result = (string) half($arg);
    } catch (TypeError $e) {
        $result = $e::class;
    }
    echo var_export($arg, true), ' -> ', $result, "\n";
}

function id(int|float|string|bool $v): string
{
    return get_debug_type($v);
}

echo id('10'), ' ', id('1.5'), ' ', id(true), ' ', id(1.5), "\n";

function number(int|float $v): string
{
    return get_debug_type($v);
}

echo number('10'), ' ', number('1.5'), ' ', number('1e2'), ' ', number(true), "\n";
```
```output
'10' -> 5
true -> 0.5
'abc' -> TypeError
NULL -> TypeError
'5 apples' -> TypeError
string string bool float
int float float int
```

Если значение точно подходит одному из типов объединения, оно не меняется (`'10'` остаётся строкой для `int|float|string|bool`). Иначе числовая строка становится `int`, когда она целочисленная, и `float` в остальных случаях; `true` для `int|float` даёт `int`.

**Пример 4. Ловушки приведения и их лечение.**

```php run

declare(strict_types=1);

var_dump(in_array('abc', [0]));              // PHP 8: false

    echo 'abc' * 1;
```

## Типичные ошибки

* **Использовать `==` по привычке.** В `if ($code == "0")` или `if ($id == $input)` сравнение зависит от содержимого строк. Пишите `===` и приводите типы явно на границе ввода.
* **Считать, что `declare(strict_types=1)` защищает все вызовы.** Он влияет на вызовы из файла, где объявлен. Вызов вашей функции из файла без директивы идёт в слабом режиме. Ставьте директиву в каждый файл.
* **Ставить `declare` не первой инструкцией.** Перед ним допустимы только комментарии; иначе фатальная ошибка.
* **`in_array($x, $list)` без третьего аргумента.** Найдёт `"1e1"` в списке `["10"]`.
* **Проверять `if ($s)` для строки.** `"0"` ложно; для пустоты используйте `$s === ''`, для наличия ключа - `isset` или `array_key_exists`.
* **Сравнивать дроби через `==`.** Используйте допуск или целые числа (копейки вместо рублей).
* **Приводить пользовательский ввод через `(int)`.** `(int) "12abc"` молча даёт 12, а `(int) "abc"` даёт 0. Проверяйте `is_numeric` или `filter_var($s, FILTER_VALIDATE_INT)`.
* **Возвращать из `never`-функции значение и ждать, что оно что-то вернёт.** `never` означает «не возвращает управление»: тело должно завершаться `throw` или `exit`.
* **Полагаться на устаревшее неявное усечение дробных чисел.** Начиная с PHP 8.1 `half(1.5)` для `int`-параметра помечено Deprecated; используйте `intdiv`, `(int) round(...)` или `floor` явно.

## Итоги

* Типы объявляются у параметров, результатов и свойств; `?T`, `A|B` (8.0), `A&B` (8.1), `never` (8.1), `null`/`false`/`true` и DNF (8.2), типы констант (8.3).
* `declare(strict_types=1)` в начале файла отключает приведение скаляров при вызовах из этого файла; допустимо только расширение `int` до `float`.
* В PHP 8 число и нечисловая строка сравниваются как строки: `0 == "a"` ложно; числовые строки по-прежнему сравниваются как числа.
* Используйте `===`, третий аргумент `in_array`/`array_search` и `match` там, где важна точность.
