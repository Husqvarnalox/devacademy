# Разбор: Лабиринт с одним тараном

## Наивное решение
Для каждой стены `#` заменить её на пустую клетку и запустить BFS. Стен может быть порядка `n·m`, а каждый BFS стоит `O(n·m)`, итого `O((n·m)^2)`. При `n = m = 500` это порядка `6·10^10` операций - за 5 секунд не успеть.

## Ключевая идея
Положение определяется не только клеткой, но и тем, использован ли таран. Вершины графа - пары `(клетка, k)`, `k ∈ {0, 1}`. Рёбра:

* из `(v, k)` в соседнюю пустую клетку `u` - в `(u, k)`;
* из `(v, 0)` в соседнюю стену `u` - в `(u, 1)`;
* из `(v, 1)` в стену ходить нельзя.

Каждое ребро имеет длину 1, поэтому подходит обычный BFS в графе на `2·n·m` вершинах.

## Алгоритм
```
dist[(S, 0)] = 0; очередь = [(S, 0)]
пока очередь не пуста:
    (v, k) = извлечь
    для соседа u клетки v внутри поля:
        k2 = k + (1 если u - стена иначе 0)
        если k2 <= 1 и dist[(u, k2)] не задано:
            dist[(u, k2)] = dist[(v, k)] + 1
            добавить (u, k2)
ответ = min(dist[(E, 0)], dist[(E, 1)]) среди заданных, иначе -1
```

## Почему верно
Любой допустимый путь в исходной задаче - это путь в графе состояний, и наоборот: счётчик `k` лишь отслеживает число пройденных стен. Длины совпадают, поэтому кратчайший путь в графе состояний - ответ. BFS находит его по тому же инварианту, что и на обычной сетке: очередь хранит состояния в порядке неубывания расстояния, каждое состояние попадает в неё раз, и при первом достижении `dist` уже минимально (индукция по слоям).

Отдельные отметки для `k = 0` и `k = 1` необходимы: состояние `(v, 0)` строго сильнее `(v, 1)` (из него доступно всё, что из `(v, 1)`, и ещё стены), поэтому ранний приход в `(v, 1)` не может «закрыть» клетку для `(v, 0)`. Именно это ломает версию с одной отметкой на клетку.

## Сложность
Время и память `O(n·m)` (константа 2 из-за двух слоёв). Для `500·500·2 = 5·10^5` состояний все языки укладываются существенно быстрее секунды.

## Подводные камни
* Нужна отдельная отметка на каждое из двух состояний, а не на клетку.
* Старт и финиш не стены; ответ 0 допустим только если они совпадают, но по условию это разные клетки.
* Пробитая стена - это шаг в клетку `#`; повторно пробивать нельзя.
* В Python `list.pop(0)` слишком медленен: используйте индекс головы или `deque`.
* Ввод до `250000` символов: читайте целиком (`sys.stdin.buffer.read`, `BufferedReader`), не по символам.
