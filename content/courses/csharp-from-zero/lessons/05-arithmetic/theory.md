## Зачем нужна арифметика

Программа почти всегда что-то считает: стоимость покупки, сдачу, сколько целых упаковок получится и сколько останется, сколько минут в двух с половиной часах. Для этого в C# есть привычные операции над числами. В этом уроке работаем с целыми числами - типом `int`. Дробные числа - в следующем уроке.

Операторы:

* `+` сложение, `-` вычитание, `*` умножение;
* `/` деление;
* `%` остаток от деления.

Результат выражения можно напечатать сразу или сохранить в переменную: `int total = price * quantity;`.

## Одна новая идея: деление целых отбрасывает дробную часть

Если делить `int` на `int`, результат тоже `int`. Поэтому `7 / 2` равно `3`, а не `3.5`: дробная часть просто отбрасывается. Это не ошибка, а правило: у целых нет дробной части. Оператор `%` даёт то, что «не поместилось»: `7 % 2` равно `1`.

Вместе они отвечают на два бытовых вопроса. Из 30 тетрадей, сложенных в пачки по 12: `30 / 12` - сколько полных пачек (2), `30 % 12` - сколько тетрадей осталось (6).

<!-- section: examples -->
## Пример 1. Операции над переменными

```csharp run
int price = 85;
int quantity = 4;
int total = price * quantity;
int paid = 500;
int change = paid - total;
Console.Write("Сумма: ");
Console.WriteLine(total);
Console.Write("Сдача: ");
Console.WriteLine(change);
```
```output
Сумма: 340
Сдача: 160
```

Разбор по строкам:

* `int total = price * quantity;` - сначала вычисляется выражение справа (85 умножить на 4), затем результат 340 кладётся в новую переменную `total`;
* `int change = paid - total;` - значения переменных подставляются в выражение, получается 160;
* выражение можно написать и прямо внутри `Console.WriteLine`: `Console.WriteLine(price * quantity);`.

## Пример 2. Деление и остаток

```csharp run
int minutes = 135;
int hours = minutes / 60;
int rest = minutes % 60;
Console.Write("Часов: ");
Console.WriteLine(hours);
Console.Write("Минут: ");
Console.WriteLine(rest);
Console.WriteLine(7 / 2);
Console.WriteLine(7 % 2);
```
```output
Часов: 2
Минут: 15
3
1
```

135 минут - это 2 часа и 15 минут: `135 / 60` даёт 2 полных часа, `135 % 60` даёт 15 оставшихся минут. Последние две строки показывают правило: `7 / 2` равно `3`, а `7 % 2` равно `1`, потому что 7 = 3 * 2 + 1.

## Пример 3. Приоритет и скобки

```csharp run
Console.WriteLine(2 + 3 * 4);
Console.WriteLine((2 + 3) * 4);
Console.WriteLine(10 - 4 - 3);
Console.WriteLine(-(3 + 4));
```
```output
14
20
3
-7
```

Как в школьной математике, `*`, `/` и `%` выполняются раньше `+` и `-`: в `2 + 3 * 4` сначала `3 * 4`. Скобки меняют порядок. Операции одного уровня идут слева направо: `10 - 4 - 3` это `(10 - 4) - 3`. Знак минус перед числом или скобкой меняет знак.

## Пример 4. Сокращённые записи

```csharp run
int score = 10;
score += 5;
score -= 3;
score *= 2;
score /= 4;
score++;
Console.WriteLine(score);
```
```output
7
```

* `score += 5;` - то же, что `score = score + 5;` («увеличить на 5»); так же работают `-=`, `*=`, `/=`;
* `score++;` - увеличить на 1 (`score--;` - уменьшить на 1);
* ход значений: 10, 15, 12, 24, 6, 7.

**Попробуйте.** Замените в примере 2 `135` на `60`, `59` и `0` и предскажите результат до запуска. Затем вычислите на бумаге `score` из примера 4 для начального значения 20.

## Точные правила

* Арифметика над `int` даёт `int`.
* **Целочисленное деление** `a / b` отбрасывает дробную часть **в сторону нуля**: `7 / 2` это `3`, `-7 / 2` это `-3` (не `-4`).
* **Остаток** `a % b` связан с делением: `a == (a / b) * b + a % b`. Знак остатка совпадает со знаком делимого: `-7 % 2` равно `-1`, `7 % -2` равно `1`.
* **Приоритет:** сначала унарный минус и скобки, затем `*`, `/`, `%`, затем `+`, `-`. Одинаковые по приоритету операции выполняются слева направо.
* **Сокращённые операторы:** `x op= y` означает `x = x op y`; `x++` и `x--` меняют значение на единицу. Используйте их как отдельную инструкцию.
* **Деление на ноль:** при делении `int` на значение 0 во время работы программы возникает `DivideByZeroException`. Деление на литерал `0` компилятор замечает сам (ошибка `CS0020`).
* **Переполнение:** у `int` ограниченный диапазон (около ±2,1 миллиарда). Что случается за его пределами и как с этим работать - в курсе [Как выполняется C#](lesson:csharp.first-steps.how-csharp-runs).
* Выражение само по себе не команда: `x + 1;` без присваивания не компилируется (`CS0201`).

<!-- section: mistakes -->
## Типичные ошибки

**1. Ожидают дробный результат от деления целых.**

```csharp
int a = 7;
int b = 2;
Console.WriteLine(a / b);
```

Ошибки нет, но напечатается `3`, а не `3.5`. Это не сбой программы, а правило для `int`. Если нужна дробная часть, числа делают дробными (следующий урок). Если нужен остаток - `%`.

**2. Забыли про приоритет.** Нужно прибавить 2 и 3 и умножить на 4. `2 + 3 * 4` даёт 14, а не 20. Ставьте скобки: `(2 + 3) * 4`. Скобки не мешают, когда есть сомнения.

**3. Выражение без присваивания.**

```csharp
int x = 5;
x + 1;
```

Компилятор: `error CS0201: Only assignment, call, increment, decrement, await, and new object expressions can be used as a statement` («в качестве инструкции можно использовать только присваивание, вызов, увеличение, уменьшение ...»). Вычисленное значение некуда деть. Напишите `x = x + 1;` или `x++;`.

**4. Деление на ноль.**

```csharp
int a = 10;
int b = 0;
Console.WriteLine(a / b);
```

Программа собирается, но при запуске: `Unhandled exception. System.DivideByZeroException: Attempted to divide by zero.` и строка `at Program...: line 3` - место ошибки. Проверяйте делитель до деления (условия - в одном из следующих уроков). А `Console.WriteLine(10 / 0);` не соберётся: `error CS0020: Division by constant zero`.

**5. Путают `=` и `==`.** Знак `=` - присваивание, не сравнение. Сравнение (`==`) - позже, в уроке о сравнениях.

## Итоги

* `+ - * / %` над `int` дают `int`; результат можно напечатать или положить в переменную.
* `/` для целых - целочисленное деление: `7 / 2` равно `3`; `%` - остаток: `7 % 2` равно `1`. Вместе они дают «сколько целых» и «сколько осталось».
* Умножение, деление и остаток выполняются раньше сложения и вычитания; скобки меняют порядок.
* `x += 5;` и `x++;` - сокращённые присваивания.
* Деление на ноль останавливает программу ошибкой выполнения.

Дальше - числа с дробной частью и деньги: [Дробные числа: double и decimal](lesson:csharp.from-zero.double-and-decimal).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `/` между двумя `int` - целочисленное деление, как в Java и C, а не как `/` в Python 3 или JavaScript; нужного результата добиваются приведением (`(double)a / b`).
* Целое деление усекается к нулю (`-7 / 2 == -3`), `%` сохраняет знак делимого (`-7 % 2 == -1`), как в Java и C, а не как `%` и `//` в Python.
* Степени оператором нет (`**` не существует): `Math.Pow` возвращает `double`.
* Переполнение `int` по умолчанию не проверяется, значение «заворачивается»; включить проверку можно ключевым словом `checked`. Подробности - в `csharp-first-steps`.
* `x++` и `x--` в виде инструкции работают как обычно; в выражениях различаются префиксная и постфиксная формы (в курсе используется только инструкция).
* Деление `int` на 0 бросает `DivideByZeroException`; для `double` результат - бесконечность или `NaN`, исключения нет.

<!-- section: deep-dive -->
## Как процессор делит

Это необязательный раздел: для заданий он не нужен.

Для `int` компилятор создаёт инструкцию целочисленного деления процессора, которая возвращает сразу и частное, и остаток; поэтому `a / b` и `a % b` согласованы между собой: `(a / b) * b + a % b == a`. Правило усечения к нулю закреплено спецификацией языка, на разных процессорах результат один и тот же.

Приоритет операций определяет форму дерева разбора: `2 + 3 * 4` превращается в дерево, где сложение стоит выше, а умножение - его правым потомком; сначала вычисляются листья. Скобки просто меняют форму дерева и в машинном коде не остаются.

Когда оба операнда - константы, компилятор вычисляет выражение сам во время сборки (`2 + 3 * 4` становится `14` ещё в IL). Поэтому деление на константу `0` он отвергает сразу, а деление на переменную со значением 0 обнаруживается только при выполнении.
