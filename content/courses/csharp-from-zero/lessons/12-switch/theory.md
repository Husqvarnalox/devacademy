## Зачем нужен switch

Представьте программу, которая по номеру дня недели печатает его название или по команде выбирает действие. На `if` это превращается в длинную цепочку `if (day == 1) ... else if (day == 2) ...`, где каждый раз повторяется `day ==`. Когда нужно выбрать действие по **точному значению** одной переменной, удобнее инструкция **`switch`** («переключатель»).

У `switch` две формы:

* **инструкция** - выполняет блок команд для подошедшего значения;
* **выражение** - вычисляет и возвращает значение, подходящее случаю. Это короткая запись для частого сценария «значение по таблице».

## Одна новая идея: сопоставление значения с вариантами

`switch` берёт значение и сверху вниз сравнивает его с вариантами. Первый совпавший вариант выбирает ветку. Вариант на случай, если не подошло ничего, называется **`default`** (в инструкции) или **`_`** (в выражении).

<!-- section: examples -->
## Пример 1. Инструкция switch

```csharp run
int day = 3;
switch (day)
{
    case 1:
        Console.WriteLine("Понедельник");
        break;
    case 2:
        Console.WriteLine("Вторник");
        break;
    case 3:
        Console.WriteLine("Среда");
        break;
    default:
        Console.WriteLine("Другой день");
        break;
}
```
```output
Среда
```

Разбор:

* `switch (day)` - в скобках значение, по которому выбираем;
* `case 3:` - метка: если значение равно 3, выполняются команды ниже, до `break`;
* `break;` завершает ветку и переходит к концу `switch`. Без `break` (или другого выхода) компилятор выдаст ошибку;
* `default:` - ветка для всех остальных значений, ставится последней.

## Пример 2. Несколько значений в одной ветке

```csharp run
int month = 7;
switch (month)
{
    case 12:
    case 1:
    case 2:
        Console.WriteLine("Зима");
        break;
    case 6:
    case 7:
    case 8:
        Console.WriteLine("Лето");
        break;
    default:
        Console.WriteLine("Не зима и не лето");
        break;
}
```
```output
Лето
```

Если подряд идут несколько меток без команд между ними, они делят одну ветку: для 6, 7 и 8 выполняется один и тот же блок.

## Пример 3. switch по строке

```csharp run
string command = "stop";
switch (command)
{
    case "start":
        Console.WriteLine("Запуск");
        break;
    case "stop":
        Console.WriteLine("Остановка");
        break;
    default:
        Console.WriteLine("Неизвестная команда");
        break;
}
```
```output
Остановка
```

`switch` работает и со строками; регистр различается, как при сравнении `==`.

## Пример 4. Выражение switch

```csharp run
string command = "stop";
string name = command switch
{
    "start" => "Запуск",
    "stop" => "Остановка",
    _ => "Неизвестная команда"
};
Console.WriteLine(name);

int number = 15;
string size = number switch
{
    < 10 => "малое",
    < 100 => "среднее",
    _ => "большое"
};
Console.WriteLine(size);

int month = 7;
int days = month switch
{
    2 => 28,
    4 or 6 or 9 or 11 => 30,
    _ => 31
};
Console.WriteLine(days);
```
```output
Остановка
среднее
31
```

Разбор:

* `значение switch { вариант => результат, ... }` - выражение; его значение кладётся в переменную (`string name = ...`);
* в конце после `}` стоит `;`, потому что это часть команды объявления;
* варианты разделены запятыми; `=>` означает «тогда результат»;
* `_` - «всё остальное», обязательный страховочный вариант;
* в варианте можно написать сравнение (`< 10`) или объединить значения словом `or` (`4 or 6 or 9 or 11`). Варианты проверяются сверху вниз, поэтому `< 10` стоит перед `< 100`.

**Попробуйте.** Напишите `switch` по номеру месяца, который печатает число дней в нём (февраль считаем 28). Затем сделайте то же по названию месяца строкой.

## Точные правила

* **Инструкция:** `switch (значение) { case значение1: команды break; ... default: команды break; }`. Значение может быть целым числом, символом, строкой, `bool` и т. п.
* Каждая ветка с командами обязана заканчиваться `break;` (или `return`, `continue`, `throw`). Иначе `error CS0163: Control cannot fall through from one case label ('case 1:') to another`.
* Метки без команд между ними объединяются в одну ветку (пример 2).
* Повтор значения в разных метках - `error CS0152: The switch statement contains multiple cases with the label value '1'`.
* В метке `case` допустимы только **константы**: `case 5:`, `case "stop":`. Условие вроде `case d > 1:` не работает (`error CS0029`).
* `default` необязателен. Если он есть и ничему не подошло, выполняется он; если нет, `switch` ничего не делает.
* **Выражение:** `значение switch { образец => результат, ... }`. Результаты должны подходить по типу. Образцы: константы, сравнения (`< 10`, `>= 18`), объединение `or`, `and`, и `_` для всех остальных.
* Если выражение `switch` не покрывает все значения, компилятор выдаёт `warning CS8509: The switch expression does not handle all possible values of its input type`, а во время работы на непокрытом значении будет `SwitchExpressionException`. Добавляйте `_`.
* Образцы проверяются сверху вниз; выполняется первый подошедший.
* `switch` удобен для сравнения одного значения с набором вариантов. Для произвольных условий и диапазонов с несколькими переменными применяйте цепочку `if`.

## Типичные ошибки

**1. Нет break.**

```csharp
int d = 1;
switch (d)
{
    case 1:
        Console.WriteLine("a");
    case 2:
        Console.WriteLine("b");
        break;
}
```

Компилятор: `error CS0163: Control cannot fall through from one case label ('case 1:') to another`. В C# в отличие от C ветки не «проваливаются» друг в друга: завершайте каждую `break;`.

**2. Повторяющиеся значения.**

```csharp
switch (d)
{
    case 1: Console.WriteLine("a"); break;
    case 1: Console.WriteLine("b"); break;
}
```

Компилятор: `error CS0152: The switch statement contains multiple cases with the label value '1'`.

**3. Условие в метке.**

```csharp
switch (d)
{
    case d > 1:
        break;
}
```

Компилятор: `error CS0029: Cannot implicitly convert type 'bool' to 'int'`. После `case` нужна константа. Для условий используйте `if` или выражение `switch` с образцом `> 1`.

**4. Нет варианта `_` в выражении.**

```csharp
int d = 3;
string s = d switch
{
    1 => "a",
    2 => "b"
};
```

Компилятор: `warning CS8509: The switch expression does not handle all possible values of its input type (it is not exhaustive)`. Для `d == 3` программа остановится с `SwitchExpressionException`. Всегда завершайте выражение вариантом `_`.

**5. Забытые запятые и `;`.** В выражении варианты разделяются запятыми, а после закрывающей `}` нужна `;`. Забытая запятая даёт синтаксическую ошибку.

**6. Путают `case` и `=>`.** В инструкции используются `case значение:` и `break`, в выражении - `значение => результат` без `case` и без `break`.

**7. Регистр строк.** `case "Stop":` не сработает для `"stop"`. Приведите значение к нужному виду или перечислите варианты.

**8. Результаты разных типов.** Все результаты выражения должны подходить типу переменной: `string s = x switch { 1 => "a", _ => 5 };` даёт `error CS0029: Cannot implicitly convert type 'int' to 'string'`. Делайте результаты одного типа.

<!-- section: summary -->
## Итоги

* `switch` выбирает действие по точному значению переменной; ветки пишут как `case значение:` и заканчивают `break;`.
* Несколько значений можно собрать в одну ветку; `default` - ветка «все остальные».
* Выражение `switch` вычисляет значение: `значение switch { образец => результат, ..., _ => результат }`; образцы могут быть сравнениями и `or`.
* Всегда добавляйте `default` или `_`.
* Для сложных условий и диапазонов по нескольким переменным применяйте `if`.

С условиями программа выбирает путь один раз. Чтобы повторять действия многократно, нужны циклы - о них следующий урок: [Цикл while](lesson:csharp.from-zero.while-loop).

## Для тех, кто уже программирует

* Инструкция `switch` в C# не допускает неявного «проваливания» (fall-through) между непустыми ветками, в отличие от C, Java и JavaScript. Явный переход - `goto case 2;`, в курсе не используется.
* `switch` поддерживает строки, перечисления, `bool`, а с C# 7+ - образцы (patterns): типы, сравнения, свойства, `and`/`or`/`not`. Выражение `switch` (C# 8) - аналог `match` в Rust и Scala или `switch` expression в Java 14+.
* Выражение `switch` проверяет исчерпываемость: компилятор предупреждает, если вариантов не хватает, а на непокрытом значении во время работы бросается `SwitchExpressionException`.
* Результат выражения должен иметь общий тип; у `string s = x switch { 1 => "a", _ => 5 }` его нет.
* Для `int` и `string` компилятор может превратить `switch` в таблицу переходов или в вычисление хеша строки; для вас это эквивалентно цепочке сравнений, но быстрее на большом числе вариантов.
* Идиоматичный C# предпочитает выражение `switch` для «таблиц значений» и инструкцию для ветвей с несколькими командами.

<!-- section: deep-dive -->
## Во что превращается switch

Это необязательный раздел: для заданий он не нужен.

Для небольшого числа вариантов компилятор генерирует цепочку сравнений, как если бы вы написали `if` / `else if`. Если варианты - плотный набор целых чисел (1, 2, 3, ...), он может построить **таблицу переходов**: по значению сразу вычисляется адрес нужной ветки, без последовательных проверок. Для строк компилятор вычисляет хеш и сравнивает с хешами меток, а при совпадении проверяет строку целиком.

Правило «каждая ветка заканчивается `break`» не просто стиль. В C и Java забытый `break` приводил к тому, что выполнялась следующая ветка, и это была одна из самых частых ошибок. Дизайнеры C# запретили неявное «проваливание» на уровне компилятора, оставив объединение пустых меток для случая «несколько значений - одно действие».
