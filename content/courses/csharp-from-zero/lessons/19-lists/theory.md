## Зачем нужен список

Длину массива нужно знать заранее, а при чтении данных до конца ввода или при сборе подходящих значений их количество неизвестно. Для таких задач есть **список** `List<T>`: коллекция, которая сама растёт при добавлении элементов и сжимается при удалении. Он похож на массив (элементы пронумерованы с нуля, к ним обращаются по индексу), но умеет добавлять, удалять и искать.

## Одна новая идея: тип элементов в угловых скобках

Запись `List<int>` читается «список целых». В угловых скобках указывается **тип элементов**; так же устроены `List<string>` (список строк) и `List<bool>`. Такие типы, зависящие от другого типа, называют *обобщёнными* (generic); собственные обобщения вы будете писать позже, пока достаточно уметь указывать тип элементов.

Список создают командой `new`:

```csharp
List<int> numbers = new List<int>();
```

Пустые скобки `()` означают «создать пустой список». Сразу задать значения можно так: `new List<int> { 5, 1, 4 }`.

Основные операции:

| Запись | Что делает |
|---|---|
| `list.Add(x)` | добавляет `x` в конец |
| `list.Count` | сколько элементов (свойство, без скобок) |
| `list[i]` | читает или меняет элемент с индексом `i` |
| `list.Remove(x)` | удаляет первое значение, равное `x`; возвращает `true`, если нашло |
| `list.RemoveAt(i)` | удаляет элемент с индексом `i` |
| `list.Contains(x)` | есть ли в списке значение `x` (`true` / `false`) |
| `list.Sort()` | упорядочивает элементы по возрастанию (на месте) |
| `foreach (T x in list)` | обходит все элементы |

## Пример 1. Добавление, удаление, проверка

```csharp run
List<string> shopping = new List<string>();
shopping.Add("хлеб");
shopping.Add("молоко");
shopping.Add("сыр");
Console.WriteLine(shopping.Count);
Console.WriteLine(shopping[1]);
shopping.Remove("молоко");
Console.WriteLine(string.Join(", ", shopping));
Console.WriteLine(shopping.Contains("сыр"));
```
```output
3
молоко
хлеб, сыр
True
```

Разбор:

* после трёх `Add` в списке три элемента: `хлеб`, `молоко`, `сыр` с индексами 0, 1, 2;
* `shopping.Remove("молоко")` ищет значение и удаляет его; следующие элементы сдвигаются, `сыр` теперь имеет индекс 1;
* `Contains` отвечает на вопрос «есть ли такое значение» и возвращает `bool`.

## Пример 2. Начальные значения и сортировка

```csharp run
List<int> numbers = new List<int> { 5, 1, 4, 9, 2 };
numbers.Sort();
Console.WriteLine(string.Join(" ", numbers));
numbers.RemoveAt(0);
Console.WriteLine(string.Join(" ", numbers));
numbers[0] = 100;
Console.WriteLine(string.Join(" ", numbers));
```
```output
1 2 4 5 9
2 4 5 9
100 4 5 9
```

`Sort()` меняет сам список, а не создаёт новый. `RemoveAt(0)` удаляет первый элемент (это наименьшее число после сортировки). Индексатор `numbers[0]` заменяет значение, как у массива.

## Пример 3. Список растёт в цикле

```csharp run
List<int> evens = new List<int>();
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        evens.Add(i);
    }
}
Console.WriteLine($"Чётных: {evens.Count}");
Console.WriteLine(string.Join(" ", evens));
```
```output
Чётных: 5
2 4 6 8 10
```

Мы не знали заранее, сколько будет подходящих чисел, поэтому массив здесь неудобен. Список принимает ровно столько элементов, сколько подошло.

## Пример 4. Список в методах

```csharp run
List<int> prices = new List<int> { 120, 40, 300, 75, 500 };
List<int> cheap = Below(prices, 100);
Console.WriteLine($"Дешёвые: {string.Join(" ", cheap)}");
Console.WriteLine($"Сумма дешёвых: {Total(cheap)}");

static List<int> Below(List<int> values, int limit)
{
    List<int> result = new List<int>();
    foreach (int v in values)
    {
        if (v < limit)
        {
            result.Add(v);
        }
    }
    return result;
}

static int Total(List<int> values)
{
    int sum = 0;
    foreach (int v in values)
    {
        sum += v;
    }
    return sum;
}
```
```output
Дешёвые: 40 75
Сумма дешёвых: 115
```

Список можно принимать параметром и возвращать как результат: тип записывается так же, как у переменной. Метод `Below` не меняет исходный список, а собирает новый. `List` передаётся в метод без копирования: изменения внутри метода видны снаружи (подробнее в уроке о классах).

## Пример 5. Чтение до конца ввода

Ввод:

```
7
3
7
```

```csharp
List<int> numbers = new List<int>();
string? line = Console.ReadLine();
while (line != null)
{
    numbers.Add(int.Parse(line));
    line = Console.ReadLine();
}
Console.WriteLine($"Всего: {numbers.Count}");
Console.WriteLine($"Есть тройка: {numbers.Contains(3)}");
```

Вывод:

```
Всего: 3
Есть тройка: True
```

Цикл чтения из урока о `while` теперь складывает значения в список. Ввод может содержать любое количество строк.

**Попробуйте.** Соберите в список названия трёх фильмов, отсортируйте их (`Sort()` упорядочит строки по алфавиту) и напечатайте через `string.Join`. Удалите средний элемент по индексу. Добавьте в пример 4 метод `Above` для цен выше порога.

## Точные правила

* Тип: `List<T>`, где `T` - тип элементов. Все элементы одного типа.
* `Count` - количество элементов (у массива это `Length`). Индексы идут от 0 до `Count - 1`.
* Нельзя обратиться к элементу по индексу, которого нет: `ArgumentOutOfRangeException`. Добавлять через индекс нельзя (`list[5] = 1` в пустом списке - ошибка), только через `Add`.
* `Remove(x)` удаляет первое найденное значение `x` и возвращает `bool`; `RemoveAt(i)` удаляет по индексу.
* `Contains(x)` просматривает список по порядку: чем длиннее список, тем дольше проверка.
* `Sort()` сортирует на месте по возрастанию: числа по значению, строки по алфавиту (с учётом региональных правил).
* Во время `foreach` нельзя добавлять и удалять элементы списка: получите `InvalidOperationException`. Собирайте изменения в другой список или используйте `for`.
* Список - ссылочный тип: `List<int> b = a;` не копирует элементы. Копия: `new List<int>(a)`.

## Типичные ошибки

**1. Индекс за границами.**

```csharp
List<int> xs = new List<int> { 1, 2 };
Console.WriteLine(xs[5]);
```

Программа останавливается: `System.ArgumentOutOfRangeException: Index was out of range. Must be non-negative and less than the size of the collection. (Parameter 'index')`. Перед обращением проверяйте `i < xs.Count`.

**2. Изменение списка внутри `foreach`.**

```csharp
List<int> xs = new List<int> { 1, 2, 3 };
foreach (int x in xs)
{
    if (x == 2) xs.Remove(x);
}
```

Ошибка во время работы: `System.InvalidOperationException: Collection was modified; enumeration operation may not execute.` Соберите элементы на удаление отдельно или постройте новый список.

**3. `Length` вместо `Count`.**

```csharp
List<int> xs = new List<int> { 1, 2, 3 };
Console.WriteLine(xs.Length);
```

Компилятор: `error CS1061: 'List<int>' does not contain a definition for 'Length' ...`. У списка свойство называется `Count`.

**4. Не тот тип элемента.**

```csharp
List<int> xs = new List<int>();
xs.Add("пять");
```

Компилятор: `error CS1503: Argument 1: cannot convert from 'string' to 'int'`. Список целых принимает только целые.

**5. Список объявлен, но не создан.**

```csharp
List<int> xs;
xs.Add(1);
```

Компилятор: `error CS0165: Use of unassigned local variable 'xs'`. Нужно `List<int> xs = new List<int>();`.

**6. `Remove` вместо `RemoveAt`.**

```csharp
List<int> xs = new List<int> { 10, 20, 30 };
xs.Remove(1);
```

Ошибки нет, но и удаления нет: `Remove(1)` ищет значение 1, а не индекс 1, не находит и возвращает `false`. Для удаления по индексу есть `RemoveAt(1)`.

**7. Забыли, что `Sort` меняет сам список.** Порядок исходных данных после `Sort()` потерян. Если он нужен, отсортируйте копию: `List<int> sorted = new List<int>(numbers); sorted.Sort();`.

## Итоги

* `List<T>` - растущая коллекция: `new List<int>()`, `Add`, `Count`, индексатор, `foreach`.
* `Remove(значение)`, `RemoveAt(индекс)`, `Contains`, `Sort` покрывают большинство повседневных задач.
* Список удобен, когда число элементов заранее неизвестно, например при чтении до конца ввода.
* Не меняйте список внутри `foreach`.
* Список можно передавать в метод и возвращать из метода.

Когда нужно искать значение не по номеру, а по имени (например, цену по названию товара), используют словарь: [Словари](lesson:csharp.from-zero.dictionaries).

## Для тех, кто уже программирует

* `List<T>` - аналог `ArrayList<T>` из Java, `list` из Python и массива JavaScript, но типизирован. Внутри - массив, который удваивается при нехватке места; `Add` в среднем занимает константное время, `Insert`, `Remove` и `Contains` линейное.
* Размер - `Count` (у массива `Length`, у строки `Length`, у `Dictionary` `Count`): путаница между ними - частая ошибка.
* Современный C# позволяет создавать список «выражением коллекции»: `List<int> a = [1, 2, 3];` (C# 12). В курсе используется классическая запись.
* Изменение коллекции во время `foreach` приводит к исключению (версия коллекции проверяется), в отличие от Python, где поведение «тихо» некорректно. Исключение: `RemoveAll(x => ...)` с лямбдой, о ней позже.
* `Sort()` изменяет список на месте и использует сравнение по умолчанию; для строк оно учитывает региональные настройки. Стабильность сортировки не гарантируется. LINQ `OrderBy` возвращает новую последовательность и стабилен.
* Для безопасного обмена данными с чужим кодом возвращают `IReadOnlyList<T>` или копию; в курсе возвращаем `List<T>` напрямую.
* Двумерный список - `List<List<int>>`; вложенные угловые скобки допустимы.

## Как список растёт

Это необязательный раздел: для заданий он не нужен.

Внутри `List<T>` хранит обычный массив и счётчик занятых элементов. У массива есть запас места - **ёмкость**. Пока она не исчерпана, `Add` просто записывает значение в следующую ячейку. Когда места не хватает, список выделяет новый массив вдвое большего размера, копирует туда старые элементы и дальше работает с ним. Копирование дорогое, но случается редко, поэтому в среднем добавление в конец остаётся быстрым.

`RemoveAt(i)` и `Remove(x)` сдвигают все последующие элементы на одну позицию влево, поэтому удаление из начала длинного списка медленнее, чем из конца. `Contains` проверяет элементы по очереди. Для частых поисков по значению придуманы другие структуры; одну из них, словарь, вы увидите в следующем уроке.
