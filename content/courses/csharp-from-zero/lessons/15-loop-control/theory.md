## Зачем управлять циклом

Не всегда нужно выполнять цикл до конца. Если мы ищем первое подходящее число, после находки продолжать незачем. Если в строке ввода попалась пустая строка, её нужно пропустить и перейти к следующей. Для этого есть две команды: **`break`** («прервать») и **`continue`** («продолжить со следующего прохода»). Третья тема урока - **вложенные циклы**: цикл внутри цикла, нужный для таблиц и «строк со столбцами».

## Одна новая идея: две команды, два разных эффекта

* **`break`** сразу завершает ближайший цикл. Выполнение продолжается с первой команды после его закрывающей `}`.
* **`continue`** пропускает остаток текущего прохода и переходит к проверке условия (в `for` - сначала к шагу, затем к проверке) для следующего прохода.

Обе команды почти всегда стоят внутри `if`: «если нашли - прервать», «если строка не подходит - пропустить».

Вложенный цикл выполняется полностью на каждом проходе внешнего. Если внешний цикл делает 3 прохода, а внутренний 4, то тело внутреннего выполнится 3 x 4 = 12 раз.

<!-- section: examples -->
## Пример 1. break: первая находка

```csharp run
for (int i = 50; i < 100; i++)
{
    if (i % 7 == 0)
    {
        Console.WriteLine($"Первое число, кратное 7: {i}");
        break;
    }
}
Console.WriteLine("Поиск закончен");
```
```output
Первое число, кратное 7: 56
Поиск закончен
```

Цикл перебирает числа с 50. Как только `i % 7 == 0` (остаток от деления на 7 равен нулю), печатается результат, и `break` выходит из цикла. Числа от 57 до 99 уже не проверяются.

## Пример 2. continue: пропуск ненужного

```csharp run
for (int i = 1; i <= 7; i++)
{
    if (i % 2 == 0)
    {
        continue;
    }
    Console.WriteLine($"Нечётное: {i}");
}
```
```output
Нечётное: 1
Нечётное: 3
Нечётное: 5
Нечётное: 7
```

Для чётных чисел выполняется `continue`: команда `Console.WriteLine` ниже пропускается, и цикл переходит к `i++` и следующей проверке. Для нечётных `if` ложно, и строка печатается.

## Пример 3. Бесконечный цикл с выходом по break

```csharp run
int balance = 100;
int years = 0;
while (true)
{
    balance += balance / 2;
    years++;
    if (balance >= 300)
    {
        break;
    }
}
Console.WriteLine($"Лет: {years}, на счёте: {balance}");
```
```output
Лет: 3, на счёте: 337
```

`while (true)` - условие всегда истинно, цикл завершается только по `break`. Каждый год к сумме прибавляется половина (целочисленное деление): 100, 150, 225, 337. Проверка делается в середине тела, после очередного года, - так бывает удобнее, чем вынести её в заголовок.

## Пример 4. Вложенные циклы

```csharp run
for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 4; col++)
    {
        Console.Write("#");
    }
    Console.WriteLine();
}
Console.WriteLine();
for (int row = 1; row <= 4; row++)
{
    for (int col = 1; col <= row; col++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
```
```output
####
####
####

*
**
***
****
```

Внешний цикл считает строки, внутренний печатает символы одной строки. После внутреннего цикла `Console.WriteLine()` переводит строку. Во втором фрагменте верхняя граница внутреннего цикла - `row`, поэтому в строке номер 3 три звёздочки.

## Пример 5. break во вложенном цикле

```csharp run
for (int a = 1; a <= 3; a++)
{
    for (int b = 1; b <= 3; b++)
    {
        if (b > a)
        {
            break;
        }
        Console.WriteLine($"{a}-{b}");
    }
}
```
```output
1-1
2-1
2-2
3-1
3-2
3-3
```

`break` прерывает только **ближайший** цикл, внутренний. Внешний продолжает работу: при `a` равном 1 внутренний цикл прерывается на `b` равном 2, но `a` становится 2 и всё повторяется заново.

## Пример 6. Ввод до слова «конец»

Ввод:

```
Анна

Борис
конец
Вера
```

```csharp
int count = 0;
while (true)
{
    string? line = Console.ReadLine();
    if (line == null || line == "конец")
    {
        break;
    }
    if (line == "")
    {
        continue;
    }
    count++;
}
Console.WriteLine($"Имён: {count}");
```

Вывод:

```
Имён: 2
```

Разбор:

* чтение стоит в начале тела, поэтому `continue` безопасен: следующий проход прочитает новую строку;
* `line == null` - ввод закончился без слова «конец», его тоже считаем концом;
* после слова «конец» цикл прерван, поэтому «Вера» не читается;
* пустая строка пропускается, `Борис` и `Анна` засчитаны.

**Попробуйте.** В примере 1 замените 7 на 13 и 50 на 100: найдите первое число, кратное 13, и подумайте, что будет, если подходящего числа в диапазоне нет. В примере 4 сделайте второй фрагмент убывающим: 4 звёздочки, затем 3, 2, 1.

## Точные правила

* `break;` завершает ближайший объемлющий цикл (`while`, `for`, а также `foreach` из следующих уроков) или `case` в `switch`. Вне цикла и `switch` команда не допускается (`CS0139`).
* `continue;` переходит к следующему проходу ближайшего цикла. В `for` перед проверкой условия выполняется шаг, в `while` сразу проверяется условие.
* В `while` с `continue` все изменения переменных условия должны выполняться до `continue`, иначе цикл не продвинется. В `for` шаг выполняется самим циклом и защищает от этой ошибки.
* Команды после `break` или `continue` в том же блоке недостижимы (предупреждение `CS0162`).
* Во вложенных циклах счётчики должны называться по-разному: внутренний цикл не может объявить `i`, если он уже объявлен снаружи (`CS0136`). Обычно берут `row` и `col`, `i` и `j`.
* Число проходов вложенных циклов перемножается; если вложенность глубокая, программа может работать заметно дольше.
* `break` во внутреннем цикле не прерывает внешний. Чтобы прервать оба, пользуются признаком (переменной типа `bool`), условием внешнего цикла или выносят цикл в метод (после урока о методах).

## Типичные ошибки

**1. `break` вне цикла.**

```csharp
int x = 3;
if (x > 2)
{
    break;
}
```

Компилятор: `error CS0139: No enclosing loop out of which to break or continue`. `break` работает только внутри цикла или `switch`.

**2. `continue` в `while` до изменения счётчика.**

```csharp
int i = 0;
while (i < 5)
{
    if (i == 2)
    {
        continue;
    }
    i++;
}
```

Когда `i` становится равным 2, `continue` возвращает к проверке, а `i++` не выполняется: `i` навсегда остаётся равным 2, цикл бесконечный. Увеличивайте счётчик до `continue` либо используйте `for`, где шаг выполняется автоматически.

**3. Одинаковое имя счётчика во вложенных циклах.**

```csharp
for (int i = 0; i < 2; i++)
{
    for (int i = 0; i < 2; i++)
    {
        Console.WriteLine(i);
    }
}
```

Компилятор: `error CS0136: A local variable or function named 'i' cannot be declared in this scope because that name is used in an enclosing local scope to define a local variable`. Назовите счётчики по-разному.

**4. Ожидание, что `break` выйдет из обоих циклов.** После `break` во внутреннем цикле внешний продолжает работу. Если нужно выйти из обоих, установите признак `found = true;`, прервите внутренний цикл и проверьте признак во внешнем.

**5. Код после `break` или `continue`.**

```csharp
for (int i = 0; i < 3; i++)
{
    continue;
    Console.WriteLine(i);
}
```

Компилятор: `warning CS0162: Unreachable code detected`. Строка с `Console.WriteLine` никогда не выполняется.

**6. Бесконечный `while (true)` без `break`.** У такого цикла должна быть хотя бы одна достижимая команда `break` (или `return`, о нём позже). Перед запуском найдите её в тексте.

**7. Путают `break` и `continue`.** Если нужно пропустить одну строку и продолжить, пишите `continue`. `break` прекратит весь цикл, и оставшиеся данные не будут обработаны.

<!-- section: summary -->
## Итоги

* `break` завершает ближайший цикл; `continue` пропускает остаток прохода.
* Обычно обе команды стоят внутри `if`.
* `while (true)` с `break` - способ вынести выход из цикла в удобное место тела.
* Вложенные циклы выполняются в виде «полный внутренний на каждый проход внешнего»; счётчики называют по-разному.
* В `while` изменяйте счётчик или читайте новую строку до `continue`.

## Для тех, кто уже программирует

* `break` и `continue` работают как в C, Java и JavaScript. Меток для выхода из нескольких циклов, как `break outer;` в Java или JavaScript, в C# нет: используют флаг, `return` из метода или (редко) `goto`.
* В `switch` `break` завершает ветку, в цикле - цикл. Поэтому в цикле с `switch` внутри `break` относится к `switch`, а не к циклу. Для выхода из цикла из ветки `switch` применяют флаг или `return`.
* В C# нет конструкции `for ... else` из Python. Для «ничего не найдено» заводят переменную-признак.
* `while (true)` допустим и повсеместно используется для циклов «читать, пока не конец». Компилятор понимает, что после такого цикла код достижим только через `break`.
* Идиома `foreach` + `continue` (пропуск ненужных элементов) в C# встречается очень часто. LINQ-фильтрация (`Where`) позволяет записать то же без `continue`, но это за рамками курса.

## break и continue как переходы

Это необязательный раздел: для заданий он не нужен.

На уровне машинных команд цикл - это условные и безусловные переходы. `break` превращается в переход на метку после цикла, а `continue` - в переход на метку проверки условия (в `for` - на шаг). Команды не имеют собственной «логики остановки», это просто структурированные переходы.

Именно поэтому в C# они разрешены только внутри цикла: компилятору нужно знать, на какую метку переходить. В языках с метками (Java, JavaScript) `break outer` указывает на метку внешнего цикла явно. В C# для того же случая принято выделить внутренние циклы в отдельный метод и выйти из него через `return`.
