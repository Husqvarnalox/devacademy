## Зачем нужны массивы

До сих пор каждое значение жило в своей переменной. Когда значений много (температуры за неделю, цены в чеке, оценки класса), заводить сорок переменных невозможно, да и обработать их циклом нельзя. Для этого есть **массив**: пронумерованный ряд однотипных значений под одним именем.

## Одна новая идея: нумерация с нуля и фиксированная длина

* Значения массива называют **элементами**, а номер элемента - его **индексом**. Нумерация начинается с **нуля**: первый элемент имеет индекс 0, второй - 1, последний в массиве из 5 элементов - 4.
* Длина массива задаётся при создании и **не меняется**. Количество элементов хранит свойство `Length`.
* Все элементы имеют один тип. Тип массива записывают с квадратными скобками: `int[]` - «массив целых».

Создать массив можно двумя способами:

```csharp
int[] temps = { 12, 15, 9, 20, 17 };   // сразу с готовыми значениями
int[] zeros = new int[5];              // пять элементов, все равны 0
```

Читать и менять элемент можно по индексу в квадратных скобках: `temps[0]`, `temps[i]`, `temps[2] = 11;`. Обойти все элементы можно циклом `for` с индексом от 0 до `Length - 1` либо более коротким циклом **`foreach`**: «для каждого элемента из массива»:

```csharp
foreach (int t in temps)
{
    Console.WriteLine(t);
}
```

В `foreach` нет индекса, он просто даёт значения по очереди. Если индекс не нужен, `foreach` надёжнее: выйти за границы массива в нём невозможно.

## Пример 1. Создание, чтение, изменение

```csharp run
int[] temps = { 12, 15, 9, 20, 17 };
Console.WriteLine(temps[0]);
Console.WriteLine(temps[4]);
Console.WriteLine(temps.Length);
temps[2] = 11;
Console.WriteLine(string.Join(", ", temps));
```
```output
12
17
5
12, 15, 11, 20, 17
```

Разбор:

* `temps[0]` - первый элемент, `temps[4]` - последний (индекс на единицу меньше длины);
* `temps.Length` - 5. Круглых скобок нет: `Length` - свойство, а не метод;
* присваивание `temps[2] = 11;` заменяет третий элемент;
* `string.Join(", ", temps)` склеивает элементы в одну строку через разделитель. Печатать массив целиком командой `Console.WriteLine(temps)` нельзя: выведется только название типа.

## Пример 2. Заполнение циклом

```csharp run
int[] squares = new int[5];
for (int i = 0; i < squares.Length; i++)
{
    squares[i] = i * i;
}
Console.WriteLine(string.Join(" ", squares));
```
```output
0 1 4 9 16
```

`new int[5]` создаёт пять нулей. Цикл идёт от 0 до `Length - 1`; условие `i < squares.Length` перестаёт выполняться ровно тогда, когда индекс выходит за массив.

## Пример 3. foreach: сумма и наибольшее

```csharp run
int[] prices = { 120, 80, 300, 45 };
int sum = 0;
int max = prices[0];
foreach (int p in prices)
{
    sum += p;
    if (p > max)
    {
        max = p;
    }
}
Console.WriteLine($"Сумма: {sum}");
Console.WriteLine($"Максимум: {max}");
```
```output
Сумма: 545
Максимум: 300
```

`max` начинается с первого элемента, как в задаче о температурах: так подходят и отрицательные значения. Переменная `p` на каждом проходе получает следующий элемент.

## Пример 4. Обратный порядок

```csharp run
string[] days = { "пн", "вт", "ср" };
for (int i = days.Length - 1; i >= 0; i--)
{
    Console.WriteLine(days[i]);
}
```
```output
ср
вт
пн
```

Массивы бывают не только числовыми: `string[]` хранит строки. Для обратного порядка нужен `for` с индексом: стартуем с `Length - 1` и идём вниз до 0.

## Пример 5. Массив как параметр метода

```csharp run
int[] marks = { 5, 4, 3, 5, 5 };
Console.WriteLine(CountFives(marks));
Console.WriteLine(Total(marks));

static int CountFives(int[] values)
{
    int count = 0;
    foreach (int v in values)
    {
        if (v == 5)
        {
            count++;
        }
    }
    return count;
}

static int Total(int[] values)
{
    int sum = 0;
    for (int i = 0; i < values.Length; i++)
    {
        sum += values[i];
    }
    return sum;
}
```
```output
3
22
```

Тип параметра записывается так же, как тип переменной: `int[] values`. Метод получает **тот же массив**, а не его копию (подробнее в уроке о классах): если бы метод изменил `values[0]`, изменение увидели бы и в основной части. Здесь методы только читают.

## Пример 6. Ввод в массив

Ввод:

```
3
10
20
30
```

```csharp
int n = int.Parse(Console.ReadLine() ?? "");
int[] numbers = new int[n];
for (int i = 0; i < n; i++)
{
    numbers[i] = int.Parse(Console.ReadLine() ?? "");
}
Console.WriteLine(string.Join(" + ", numbers));
```

Вывод:

```
10 + 20 + 30
```

Размер массива берётся из ввода: `new int[n]`. Затем цикл `for` заполняет элементы, как в примере 2, только значения читаются из строк.

**Попробуйте.** Создайте массив из названий трёх товаров и напечатайте его в обратном порядке. Найдите в массиве `{ 4, 8, 2, 9, 5 }` наименьший элемент. Подумайте, что произойдёт при обращении к `temps[5]` в примере 1, и проверьте предположение.

## Точные правила

* Тип: `int[]`, `string[]`, `double[]`, `bool[]` и так далее. Создание: `new int[n]` (n элементов) или литерал `{ 1, 2, 3 }`.
* Элементы нового массива получают значения по умолчанию: `0` для чисел, `false` для `bool`. Для `string[]` элементами будут `null` (пустого значения нет), поэтому строковые массивы создают литералом.
* Индексы идут от 0 до `Length - 1`. Обращение за границы приводит к ошибке выполнения `IndexOutOfRangeException`.
* Длина не меняется. Чтобы «добавить» элемент, нужно создать новый массив или использовать список (следующий урок).
* `Length` - свойство без круглых скобок.
* В `foreach (тип имя in массив)` переменная цикла доступна только для чтения: присвоить ей значение нельзя (`CS1656`).
* Массив - ссылочный тип: переменная хранит ссылку на массив. Присваивание `int[] b = a;` не копирует элементы, обе переменные указывают на один массив. Сравнение `a == b` сравнивает ссылки, а не содержимое.
* Для печати содержимого используют `string.Join(разделитель, массив)` или цикл.

## Типичные ошибки

**1. Обращение за границу массива.**

```csharp
int[] a = { 1, 2, 3 };
Console.WriteLine(a[3]);
```

Программа компилируется, но при запуске останавливается: `Unhandled exception. System.IndexOutOfRangeException: Index was outside the bounds of the array.` В массиве из трёх элементов допустимы индексы 0, 1, 2. Последний элемент всегда `a[a.Length - 1]`.

**2. Условие `<=` в цикле по массиву.**

```csharp
int[] a = { 1, 2, 3 };
int s = 0;
for (int i = 0; i <= a.Length; i++)
{
    s += a[i];
}
```

Последний проход при `i` равном 3 выбрасывает то же `IndexOutOfRangeException`. Для индексов нужно строгое сравнение: `i < a.Length`.

**3. `Length` со скобками.**

```csharp
int[] a = { 1, 2, 3 };
Console.WriteLine(a.Length());
```

Компилятор: `error CS1955: Non-invocable member 'Array.Length' cannot be used like a method`. Скобки нужны методам, а `Length` - свойство.

**4. Размер не совпадает с числом значений.**

```csharp
int[] a = new int[3] { 1, 2 };
```

Компилятор: `error CS0847: An array initializer of length '3' is expected`. Либо уберите размер (`int[] a = { 1, 2 };`), либо перечислите три значения.

**5. Присваивание переменной `foreach`.**

```csharp
int[] a = { 1, 2, 3 };
foreach (int x in a)
{
    x = x * 2;
}
```

Компилятор: `error CS1656: Cannot assign to 'x' because it is a 'foreach iteration variable'`. Чтобы изменить элементы, используйте `for` и `a[i] = a[i] * 2;`.

**6. Метод `Add` у массива.**

```csharp
int[] a = { 1, 2, 3 };
a.Add(4);
```

Компилятор: `error CS1061: 'int[]' does not contain a definition for 'Add' ...`. Массив фиксированной длины, дописать в него нельзя. Для растущей коллекции нужен список из следующего урока.

**7. Массив объявлен, но не создан.**

```csharp
int[] a;
a[0] = 1;
```

Компилятор: `error CS0165: Use of unassigned local variable 'a'`. Сначала создайте массив: `int[] a = new int[3];`.

**8. Печать массива и сравнение.** `Console.WriteLine(a)` печатает `System.Int32[]`, а `a == b` для двух одинаковых по содержимому массивов даёт `False`, потому что сравниваются ссылки. Используйте `string.Join` и цикл.

**9. Отрицательный размер.** `new int[n]` при отрицательном `n` останавливает программу: `System.OverflowException: Arithmetic operation resulted in an overflow.` Размер приходит из ввода, проверяйте его, если ввод может быть некорректным.

## Итоги

* Массив - фиксированный ряд однотипных элементов: `int[] a = { 1, 2, 3 };` или `new int[n]`.
* Индексы начинаются с 0, последний - `a.Length - 1`; выход за границы - `IndexOutOfRangeException`.
* `for` с индексом нужен, чтобы менять элементы или идти в обратном порядке; `foreach` - чтобы просто пройти по значениям.
* Массив можно передавать в метод как параметр; метод видит тот же массив.
* Печатать содержимое удобно через `string.Join`.

Массив нельзя увеличить. Когда количество элементов заранее неизвестно, нужен список: [Списки List](lesson:csharp.from-zero.lists).

## Для тех, кто уже программирует

* Массивы C# - объекты ссылочного типа с проверкой границ (как в Java, в отличие от C). Длина `Length` - свойство; многомерные (`int[,]`) и «рваные» (`int[][]`) массивы есть, в курсе не используются.
* Литерал `int[] a = { 1, 2, 3 };` разрешён только при объявлении; в другом месте нужно `new int[] { 1, 2, 3 }` (C# 12 добавил `[1, 2, 3]`).
* `foreach` работает с любой коллекцией, не только с массивом; его переменная доступна только для чтения.
* Равенство массивов - по ссылке, как в Java (`==`); сравнить содержимое можно через `SequenceEqual` из LINQ.
* Для срезов есть `Span<T>` и диапазоны (`a[1..3]`), не разбираются здесь.
* Строковый массив из `new string[3]` содержит `null`, а не пустые строки (как `String[]` в Java); при включённых nullable-аннотациях литерал безопаснее.
* Индексатор `a[^1]` («с конца») существует с C# 8; в курсе используем `a[a.Length - 1]`.

## Как устроен массив в памяти

Это необязательный раздел: для заданий он не нужен.

Массив - один непрерывный участок памяти в управляемой куче. В начале участка хранятся служебные данные (в том числе длина), затем элементы подряд. Адрес элемента вычисляется как «начало + индекс x размер элемента», поэтому доступ по индексу выполняется за одинаковое время для любого индекса.

Проверка границ - это сравнение индекса с длиной перед каждым обращением. JIT-компилятор убирает такие проверки, если доказывает, что индекс безопасен (типичный пример: `for (int i = 0; i < a.Length; i++)`). Поэтому записывайте цикл именно в такой форме. Поскольку переменная массива хранит ссылку, присваивание `b = a` копирует ссылку, а не данные: это основа поведения ссылочных типов, которое разберём подробнее в уроке о классах.
