## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер ничего не додумывает: он выполняет то, что написано, шаг за шагом, сверху вниз.

Команды записывают текстом на специальном языке. Такой текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется **C#** (читается «си шарп»). На нём пишут игры, настольные и мобильные приложения, серверы и инструменты для разработчиков.

Текст на C# сам по себе ничего не делает: процессор не понимает его напрямую. Нужен переводчик. Его роль выполняет **компилятор**: программа, которая читает исходный код, проверяет его по правилам языка и создаёт из него то, что компьютер может выполнить. Если в тексте есть ошибка, компилятор сообщает о ней, и программа не запустится. Готовую программу запускает платформа **.NET**: набор готовых средств, который выполняет программы на C# и умеет, например, выводить текст на экран.

Файл с исходным кодом в этом курсе называется `Program.cs`. Окончание `.cs` означает «C Sharp». В приложении вам не нужно вызывать компилятор вручную: вы пишете текст в редакторе и нажимаете «Запустить», а приложение само собирает программу и запускает её. Запоминать команды сборки пока не нужно.

## Одна новая идея: команда `Console.WriteLine` печатает текст

Чтобы увидеть результат работы программы, её нужно заставить что-то показать. Для этого есть команда `Console.WriteLine(...)`. Она печатает то, что указано в скобках, и переходит на следующую строку. Текст в программе записывают в двойных кавычках: `"Касса открыта"`.

В других учебниках перед первой командой стоят строки вроде `class Program` и `static void Main`. В современном C# для простой программы они не нужны: файл может состоять просто из команд, и они выполняются сверху вниз. Зачем нужны эти строки и что делает C#, когда запускает программу, - в курсе [Как выполняется C#](lesson:csharp.first-steps.how-csharp-runs); для этого курса знать это не требуется.

<!-- section: examples -->
## Пример 1. Печать одной строки

```csharp run
Console.WriteLine("Касса открыта");
```
```output
Касса открыта
```

Разбор по строкам:

* `Console` - название готового средства .NET, которое работает с окном вывода (консолью). Слово означает «консоль».
* `.` - точка соединяет название средства и действие, которое мы просим выполнить.
* `WriteLine` - название действия: «записать строку» (write line). Такое действие называется **методом**; подробно о методах - в одном из следующих уроков (пока это просто команда с именем).
* `(` и `)` - скобки, внутри которых стоит то, что нужно напечатать. Это значение, которое мы передаём команде.
* `"Касса открыта"` - **строковый литерал**: текст, записанный прямо в программе, в двойных кавычках. Кавычки на экран не попадают.
* `;` - точка с запятой в конце команды. Она отмечает, что команда закончилась. Команда, заканчивающаяся точкой с запятой, называется **инструкцией**.

## Пример 2. Несколько команд подряд

```csharp run
Console.WriteLine("Первая строка");
Console.WriteLine("Вторая строка");
Console.WriteLine("Третья строка");
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет.

## Пример 3. Число и пустая строка

```csharp run
Console.WriteLine("Итого:");
Console.WriteLine(450);
Console.WriteLine();
Console.WriteLine("рублей");
```
```output
Итого:
450

рублей
```

Число `450` написано без кавычек: это не текст, а число (о них - в уроке про переменные и типы). Команду можно вызвать и без значения: `Console.WriteLine();` печатает пустую строку.

**Попробуйте.** Поменяйте местами две строки в примере 2 и предскажите вывод до запуска. Затем уберите одну кавычку вокруг текста и посмотрите, что сообщит компилятор (подробнее - в разделе об ошибках и в следующем уроке).

## Точные правила

* Программа - это команды в файле. Они выполняются сверху вниз, по одной.
* **Строковый литерал** записывают в двойных кавычках `"..."`. Одинарные кавычки `'...'` в C# означают другое (один символ) и для текста не подходят. Внутри строки допустимы русские буквы, пробелы, цифры и знаки.
* Текст в кавычках печатается как есть. Если убрать кавычки, компилятор решит, что это не текст, а имя, и будет искать его среди известных.
* Регистр важен: `Console.WriteLine` работает, `console.writeline` и `Console.Writeline` - нет.
* Между `Console` и `WriteLine` стоит точка. Пробелов внутри имён нет.
* Каждая инструкция заканчивается точкой с запятой. Без неё программа не соберётся.
* Пустые строки между командами допустимы и улучшают чтение. `Console.WriteLine();` без значения печатает пустую строку.
* Любое количество пробелов и переводов строки между элементами команды не влияет на результат, но принято писать одну команду на строке.
* В приложении стандартные средства .NET, в том числе `Console`, уже подключены, поэтому дополнительных строк в начале файла не требуется.

## Типичные ошибки

Компилятор сообщает об ошибке одной строкой в таком виде: `Program.cs(1,19): error CS1010: ...`. В скобках стоят номер строки и номер символа в строке, затем код ошибки и описание. Если на вашей системе включён русский язык, описание может быть на русском; код ошибки остаётся тем же. Подробно о чтении сообщений - в следующем уроке.

**1. Не закрыли кавычки.**

```csharp
Console.WriteLine("Привет);
```

Компилятор: `error CS1010: Newline in constant` («перевод строки внутри константы»). Строка началась с кавычки и не закончилась до конца строки. Следом идут ещё сообщения (`CS1026: ) expected`, `CS1002: ; expected`): это следствия первой ошибки, чинить их по отдельности не нужно. Проверьте, что у каждой открывающей кавычки есть закрывающая. Редактор обычно подсвечивает текст в кавычках одним цветом: если цвет «убегает» до конца строки, кавычка пропущена.

**2. Забыли точку с запятой.**

```csharp
Console.WriteLine("Привет")
```

Компилятор: `error CS1002: ; expected` («ожидалась точка с запятой»). Позиция в скобках указывает на конец строки, где компилятор ждал `;`. Допишите её.

**3. Опечатка в названии команды.**

```csharp
Console.Writeline("Привет");
```

Компилятор: `error CS0117: 'Console' does not contain a definition for 'Writeline'` («в Console нет определения для Writeline»). Регистр входит в имя: правильно `WriteLine` с заглавной L.

**4. Маленькая буква в `Console`.**

```csharp
console.WriteLine("Привет");
```

Компилятор: `error CS0103: The name 'console' does not exist in the current context` («имя console в этом месте не существует»). Слово `console` с маленькой буквы - другое имя, которого нет.

**5. Забыли кавычки у текста.**

```csharp
Console.WriteLine(Привет);
```

Компилятор: `error CS0103: The name 'Привет' does not exist in the current context`. Без кавычек `Привет` - не текст, а имя, а такого имени нет. Если вы хотите напечатать слово, оно должно стоять в кавычках.

Общее правило чтения: сначала найдите номер строки в скобках, затем код и описание ошибки. Откройте указанную строку и посмотрите на неё и на предыдущую: иногда проблема в строке выше.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; C# - язык, компилятор переводит текст в исполняемую программу, а .NET её выполняет.
* `Console.WriteLine("текст");` печатает значение и переходит на следующую строку; кавычки на экран не попадают.
* Команды выполняются сверху вниз; каждая заканчивается точкой с запятой.
* Регистр букв и кавычки важны: от них зависит, поймёт ли компилятор вашу команду.

Любая следующая программа курса устроена так же: набор команд в `Program.cs`. В следующем уроке вы научитесь читать сообщения компилятора и исправлять ошибки: [Как читать сообщения компилятора](lesson:csharp.from-zero.compiler-errors).

## Для тех, кто уже программирует

* Точки входа в тексте нет: файл состоит из инструкций верхнего уровня (top-level statements), компилятор сам создаёт для них метод `Main`. Ни класса-обёртки, ни `static void Main` писать не нужно.
* `Console.WriteLine` - аналог `print` в Python, `System.out.println` в Java, `console.log` в JavaScript и `fmt.Println` в Go. В отличие от `print`/`console.log`, он принимает одно значение (или строку формата), а не список через запятую.
* Точка с запятой обязательна.
* Строки пишутся только в двойных кавычках; `'x'` - литерал типа `char`.
* C# компилируется: ошибки синтаксиса и типов обнаруживаются до запуска, программа с ошибкой компиляции не стартует.
* Пространства имён `System`, `System.Linq`, `System.Collections.Generic` и ещё несколько подключены автоматически (неявные `using`), поэтому `Console` работает без `using System;`.

## Что происходит при сборке и запуске

Это необязательный раздел: для заданий он не нужен.

Компилятор C# (он называется Roslyn) не превращает текст сразу в команды процессора. Он создаёт файл `.dll` с **промежуточным кодом IL**: это компактный набор инструкций, не привязанный к конкретному процессору. Среда выполнения .NET (CLR) загружает этот файл и переводит IL в машинный код во время работы программы. Поэтому одна и та же сборка работает на разных процессорах, где установлен .NET.

Файл `Program.cs` из одних команд компилятор оборачивает в служебный класс с методом `Main`: именно с него начинается выполнение. Подробнее этот путь разобран в курсе [Как выполняется C#](lesson:csharp.first-steps.how-csharp-runs).

Команда `Console.WriteLine` не рисует текст сама. Она передаёт его в так называемый стандартный вывод - поток текста, который операционная система присоединяет к терминалу или, как в этом приложении, к окну результата. Когда команды закончились, программа завершается и возвращает операционной системе код 0 («всё прошло хорошо»); по этому коду автоматические проверки отличают успех от сбоя.
