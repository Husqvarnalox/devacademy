## Зачем сравнивать

Чтобы программа могла выбирать («совершеннолетний ли посетитель?», «хватает ли денег?», «последняя ли это строка?»), она должна уметь отвечать на вопросы «да или нет». Вопрос о значениях записывается **сравнением**, а ответ - значение типа `bool`: `true` («да») или `false` («нет»). Тип `bool` вы уже видели в уроке о переменных, а теперь научитесь получать его значения из вычислений.

Операторы сравнения:

* `==` равно, `!=` не равно;
* `<` меньше, `>` больше;
* `<=` меньше или равно, `>=` больше или равно.

## Одна новая идея: условия можно соединять

Часто нужно проверить несколько вещей сразу: возраст не меньше 18 **и** есть билет; скидка положена, если пенсионер **или** студент. Для этого есть логические операторы:

* `&&` - «и»: результат `true`, только если истинны обе части;
* `||` - «или»: результат `true`, если истинна хотя бы одна часть;
* `!` - «не»: меняет `true` на `false` и наоборот.

<!-- section: examples -->
## Пример 1. Сравнения

```csharp run
int a = 7;
int b = 3;
Console.WriteLine(a > b);
Console.WriteLine(a == b);
Console.WriteLine(a != b);
Console.WriteLine(a <= 7);

bool big = a > 5;
Console.WriteLine(big);
Console.WriteLine($"a больше b: {a > b}");
```
```output
True
False
True
True
True
a больше b: True
```

Разбор:

* `a > b` - вопрос «7 больше 3?», ответ `True`. Результат можно печатать;
* `a == b` - вопрос «равны ли они?». Здесь два знака равенства, потому что один `=` означает присваивание;
* `a <= 7` - «меньше или равно»: так как 7 равно 7, ответ `True`;
* результат сравнения можно сохранить в переменную типа `bool` или вставить в интерполированную строку.

## Пример 2. И, или, не

```csharp run
int age = 20;
bool hasTicket = true;
Console.WriteLine(age >= 18 && hasTicket);
Console.WriteLine(age < 18 || hasTicket);
Console.WriteLine(!hasTicket);
Console.WriteLine(!(age > 30));
```
```output
True
True
False
True
```

Разбор:

* `age >= 18 && hasTicket` - обе части истинны, значит `True`;
* `age < 18 || hasTicket` - первая часть ложна, вторая истинна, достаточно одной: `True`;
* `!hasTicket` - «не `true`», то есть `False`;
* `!(age > 30)` - скобки нужны, чтобы `!` относился ко всему сравнению: `age > 30` ложно, поэтому `!` даёт `True`.

## Пример 3. Строки

```csharp run
string s = "Да";
string t = "да";
Console.WriteLine(s == "Да");
Console.WriteLine(s == t);
Console.WriteLine(s != t);
Console.WriteLine("яблоко" == "яблоко");
```
```output
True
False
True
True
```

Строки сравниваются `==` и `!=` по содержимому, а регистр букв различается: `"Да"` и `"да"` - разные строки. Операторы `<` и `>` для строк не определены.

## Пример 4. Диапазон и приоритет

```csharp run
int x = 5;
Console.WriteLine(x >= 1 && x <= 10);
Console.WriteLine(x < 1 || x > 10);
Console.WriteLine(1 + 2 == 3 && 2 * 2 > 3);
Console.WriteLine(true || false && false);
```
```output
True
False
True
True
```

* «x от 1 до 10» записывается двумя сравнениями, соединёнными `&&`; запись `1 <= x <= 10` как в математике в C# не работает;
* «x вне диапазона» - `||`: достаточно одного нарушения;
* сначала выполняются арифметика, затем сравнения, затем `&&`, затем `||`: `1 + 2 == 3` истинно, `2 * 2 > 3` тоже, итог `True`;
* в последней строке `&&` выполняется раньше `||`: `false && false` даёт `false`, затем `true || false` даёт `True`. Если приоритет неочевиден, ставьте скобки.

**Попробуйте.** Придумайте значения `a` и `b`, при которых `a > b || a == b` истинно, а `a > b && a == b` ложно. Затем запишите условие «число не лежит между 20 и 30 включительно» двумя способами: через `||` и через `!` со скобками.

## Точные правила

* Сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают `bool`. Числа разных типов можно сравнивать (`int` с `double`), строку с числом - нельзя (`CS0019`).
* **Приоритет:** сначала арифметика, затем `<`, `>`, `<=`, `>=`, затем `==`, `!=`, затем `&&`, затем `||`. Унарное `!` выполняется раньше сравнений, поэтому `!x == y` - не то же, что `!(x == y)`.
* **`&&`** и **`||`** вычисляются слева направо и **коротко**: если результат уже известен по левой части, правая не вычисляется (`false && ...` всегда `false`, `true || ...` всегда `true`).
* **`!`** применяется к `bool`: `!true` равно `false`.
* Строки сравнивают `==` и `!=` по содержимому; регистр различается: `"Да" != "да"`.
* Присваивание `=` и сравнение `==` - разные операторы. Присваивание `x = 5` само имеет тип `int`, поэтому в условии вместо `x == 5` оно даёт ошибку `CS0029`.
* Дробные `double` сравнивать на точное равенство ненадёжно: `0.1 + 0.2 == 0.3` ложно. Для `decimal` проблемы нет.
* Выражение сравнения можно писать прямо в `{}` интерполированной строки; результат печатается как `True` или `False`.
* Логические операторы работают только с `bool`: `1 && 0` - ошибка, в C# нет «истинных» и «ложных» чисел.

## Типичные ошибки

**1. Один знак равенства вместо двух.**

```csharp
int x = 5;
Console.WriteLine(x = 7);
Console.WriteLine(x);
```

Ошибки нет, но `x = 7` - это присваивание: переменной `x` присвоили 7, и напечатается `7`, а затем снова `7`. Для вопроса «x равно 7?» нужно `x == 7`. Там, где ожидается `bool` (например, в условии), запись `x = 7` даёт `error CS0029: Cannot implicitly convert type 'int' to 'bool'`.

**2. Цепочка сравнений как в математике.**

```csharp
int x = 5;
bool a = 1 < x < 10;
```

Компилятор: `error CS0019: Operator '<' cannot be applied to operands of type 'bool' and 'int'`. Первое сравнение даёт `bool`, который нельзя сравнить с 10. Пишите `1 < x && x < 10`.

**3. Сравнение строки с числом.**

```csharp
int x = 5;
Console.WriteLine(x == "5");
```

Компилятор: `error CS0019: Operator '==' cannot be applied to operands of type 'int' and 'string'`. Превратите текст в число (`int.Parse`) или сравнивайте строку со строкой.

**4. `<` и `>` для строк.**

```csharp
Console.WriteLine("abc" > "abd");
```

Компилятор: `error CS0019: Operator '>' cannot be applied to operands of type 'string' and 'string'`. Для строк доступны `==` и `!=`.

**5. `||` вместо `&&` в диапазоне.** Условие `x >= 1 || x <= 10` истинно для любого числа, потому что любое число либо не меньше 1, либо не больше 10. «Между» - это `&&`, «вне» - `||`.

**6. Забыты скобки у `!`.** `!x > 3` не скомпилируется: `!` применяется к `x`, а не к сравнению. Пишите `!(x > 3)` или проще `x <= 3`.

**7. Ошибка на границе.** `n > 10` и `n >= 10` - разные условия. Для «от 10 до 99 включительно» нужны `>=` и `<=`. Проверяйте границы на крайних значениях: 9, 10, 99, 100.

**8. Регистр в строках.** `"Да" == "да"` ложно. Если регистр не важен, приведите обе строки к одному виду (методы строк - в одном из следующих уроков).

## Итоги

* Сравнения `==  !=  <  >  <=  >=` дают значение `bool`: `True` или `False`.
* `=` присваивает, `==` сравнивает.
* `&&` - «и», `||` - «или», `!` - «не»; приоритет: сравнения, затем `&&`, затем `||`; сомневаетесь - ставьте скобки.
* Диапазон: «между» - `x >= a && x <= b`, «вне» - `x < a || x > b`.
* Строки сравниваются `==` и `!=` с учётом регистра.

Теперь программа может отвечать на вопросы «да или нет». Следующий шаг - выполнять разные действия в зависимости от ответа: [Условия: if / else](lesson:csharp.from-zero.if-else).

## Для тех, кто уже программирует

* Операторы те же, что в Java и JavaScript, но `bool` строгий: условие обязано быть `bool`, как в Java, и нет «истинных» значений как в JavaScript, Python или C. `if (x)` для `int` не скомпилируется.
* `==` для `string` сравнивает **содержимое** (оператор перегружен), в отличие от Java, где `==` сравнивает ссылки. Сравнение с учётом регистра по умолчанию; для других правил - `string.Equals(a, b, StringComparison.OrdinalIgnoreCase)`.
* Нет цепочек сравнений Python (`1 < x < 10`) и оператора `===` JavaScript.
* `&&` и `||` короткие; `&` и `|` на `bool` тоже работают, но вычисляют обе части. В курсе их нет.
* Для ссылочных типов `==` по умолчанию сравнивает ссылки, но многие типы (в том числе `string`) переопределяют его; сравнение объектов - тема уроков о классах.
* Равенство `double` через `==` точное и поэтому ненадёжно; для приближённого сравнения используют допуск: `Math.Abs(a - b) < 1e-9`.
* Операторы `and`, `or`, `not` существуют только в шаблонах (`is not null`), а не в обычных выражениях.

## Как вычисляется короткое замыкание

Это необязательный раздел: для заданий он не нужен.

В выражении `a && b` компилятор генерирует условный переход: если `a` ложно, переход пропускает вычисление `b`, и результат сразу `false`. Так же `a || b` пропускает `b`, если `a` истинно. Благодаря этому можно писать безопасные проверки вроде `n != 0 && 100 / n > 5`: при `n == 0` деление не выполнится, и исключения не будет.

Результат сравнения - обычное значение типа `bool` (один байт); логических «условий» как отдельного понятия в языке нет. `if` и циклы просто принимают выражение типа `bool`. Именно поэтому условие можно предварительно сохранить в переменную и дать ей понятное имя: `bool isAdult = age >= 18;`.
