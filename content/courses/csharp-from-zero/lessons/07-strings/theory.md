## Зачем собирать строки

Сообщение «Привет, Анна! Тебе 17 лет.» состоит из постоянного текста и значений переменных. Печатать каждую часть отдельной командой `Write` неудобно. В C# есть два способа собрать строку из частей: **склейка** оператором `+` и **интерполяция** `$"..."`. Второй способ читается лучше и в этом курсе основной.

## Одна новая идея: интерполяция

Если перед открывающей кавычкой поставить `$`, внутри строки можно писать выражения в фигурных скобках: на их место подставится значение.

```csharp
string name = "Анна";
Console.WriteLine($"Привет, {name}!");
```

Результат: `Привет, Анна!`. Строка, начинающаяся с `$"`, называется **интерполированной**. Без `$` фигурные скобки были бы обычными символами.

Две полезные мелочи рядом: у строки есть **длина** (`name.Length` - количество символов) и **формат** после двоеточия внутри скобок (`{price:F2}` - число с двумя знаками после точки).

<!-- section: examples -->
## Пример 1. Склейка и интерполяция

```csharp run
string name = "Анна";
int age = 17;
Console.WriteLine("Привет, " + name + "!");
Console.WriteLine("Возраст: " + age);
Console.WriteLine($"Привет, {name}! Тебе {age} лет.");
Console.WriteLine($"Через год будет {age + 1}.");
```
```output
Привет, Анна!
Возраст: 17
Привет, Анна! Тебе 17 лет.
Через год будет 18.
```

Разбор:

* `"Привет, " + name + "!"` - оператор `+` между строками склеивает их. Строки не изменяются, получается новая;
* `"Возраст: " + age` - если одна часть строка, а другая число, число превращается в текст и склеивается;
* `$"Привет, {name}! Тебе {age} лет."` - то же самое, но короче и без кавычек и плюсов вокруг каждого значения;
* в скобках можно писать выражение: `{age + 1}` вычислит 18 до подстановки.

## Пример 2. Плюс у строк и у чисел

```csharp run
Console.WriteLine("5" + "3");
Console.WriteLine(5 + 3);
```
```output
53
8
```

`"5"` и `"3"` - строки (в кавычках), для них `+` означает склеивание. `5` и `3` - числа, для них `+` - сложение. Кавычки меняют смысл: `"5"` это текст из одного символа, а не число пять.

## Пример 3. Длина и формат

```csharp run
using System.Globalization;

CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;

string product = "Тетрадь";
decimal price = 45.5m;
double ratio = 3.14159;
Console.WriteLine($"В слове {product} символов: {product.Length}");
Console.WriteLine($"Цена: {price:F2}");
Console.WriteLine($"Число: {ratio:F2}");
Console.WriteLine($"Пять: {5:F2}");
Console.WriteLine(ratio.ToString("F2", CultureInfo.InvariantCulture));
```
```output
В слове Тетрадь символов: 7
Цена: 45.50
Число: 3.14
Пять: 5.00
3.14
```

Разбор:

* `product.Length` - свойство строки: сколько в ней символов. Скобок после `Length` нет;
* `{price:F2}` - после двоеточия идёт **формат**; `F2` (fixed-point, 2) печатает ровно два знака после точки, лишнее округляется, недостающее дополняется нулями: `45.5` превращается в `45.50`;
* последняя строка - тот же формат для одного значения: `ratio.ToString("F2", CultureInfo.InvariantCulture)`. Второй аргумент закрепляет точку именно для этого вызова, независимо от настроек. В программах курса строка `CurrentCulture = InvariantCulture` в начале делает то же самое для всех вызовов сразу.

## Пример 4. Фигурные скобки как текст

```csharp run
string name = "Анна";
Console.WriteLine($"Шаблон: {{name}}, значение: {name}");
```
```output
Шаблон: {name}, значение: Анна
```

Чтобы напечатать саму фигурную скобку в интерполированной строке, её удваивают: `{{` и `}}`.

**Попробуйте.** Напечатайте одной командой строку «Анна, Анна: 8 символов» (имя дважды и длина имени вместе с пробелом после запятой). Затем сделайте `price` равным `3` и проверьте, что `{price:F2}` печатает `3.00`.

## Точные правила

* `+` для строки и любого значения создаёт новую строку; значение предварительно превращается в текст. Для двух чисел `+` - сложение. Строки склеиваются слева направо: `1 + 2 + "a"` это `"3a"`, а `"a" + 1 + 2` это `"a12"`.
* **Интерполяция:** `$"текст {выражение} текст"`. В скобках допустим любой вычисляемый код: имя, арифметика, свойство. Перед кавычкой должен стоять `$`.
* Чтобы напечатать `{` или `}`, пишут `{{` или `}}`. Кавычку внутри строки по-прежнему записывают как `\"`.
* **`Length`** - свойство строки, возвращающее число символов (`int`). Для `""` равно 0. Пишется без скобок.
* **Формат** задаётся после двоеточия: `{значение:формат}`. `F2` - два знака после точки, `F0` - без дробной части, `F3` - три знака. Число округляется по обычным правилам, нули добавляются. Буква формата может быть и маленькой: `f2`.
* **Культура:** формат применяется по текущей культуре. Если в начале программы стоит `CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;`, разделитель - точка. Тот же результат даёт `x.ToString("F2", CultureInfo.InvariantCulture)` для одного значения.
* Для `double` формат `F2` округляет двоичное приближение числа: `2.675` может стать `2.67`, потому что в `double` оно хранится как `2.67499999...`. Для денег используйте `decimal`.
* Строка с `$` может содержать и обычные escape-последовательности (`\n`, `\"`).

## Типичные ошибки

**1. Забыли `$`.**

```csharp
string name = "Анна";
Console.WriteLine("Привет, {name}!");
```

Ошибки компиляции нет, напечатается `Привет, {name}!`: без `$` скобки - обычный текст. Если в выводе вы видите фигурные скобки, проверьте `$` перед кавычкой. (Компилятор здесь ещё и предупредит, что переменная `name` не используется: `warning CS0219`.)

**2. Пропущена закрывающая скобка.**

```csharp
string s = "x";
Console.WriteLine($"{s");
```

Компилятор: `error CS8076: Missing close delimiter '}' for interpolated expression started with '{'`. Проверьте парность `{` и `}`.

**3. Длина со скобками.**

```csharp
string s = "ab";
Console.WriteLine(s.Length());
```

Компилятор: `error CS1955: Non-invocable member 'string.Length' cannot be used like a method`. `Length` - не метод, скобки не нужны.

**4. Неправильный регистр.**

```csharp
Console.WriteLine(s.length);
```

Компилятор: `error CS1061: 'string' does not contain a definition for 'length' ...`. У `string` есть `Length` с заглавной буквы.

**5. Вычитание строк.**

```csharp
Console.WriteLine("a" - "b");
```

Компилятор: `error CS0019: Operator '-' cannot be applied to operands of type 'string' and 'string'`. Для строк определён только `+`.

**6. Склейка вместо сложения.** `"Итого: " + 2 + 3` даст `Итого: 23`, а не `Итого: 5`. Сначала вычислите сумму в скобках: `"Итого: " + (2 + 3)` или `$"Итого: {2 + 3}"`.

**7. Кавычки внутри строки.** `$"Она сказала "Да""` даёт `CS1003`: внутри текста кавычки пишут как `\"`.

**8. Строка не стала числом.** `int c = "3" + 4;` не скомпилируется: результат склейки - строка (`CS0029`). Превращение текста в число - тема урока о разборе чисел.

## Итоги

* Строки склеивают `+`; число рядом со строкой превращается в текст. `"5" + "3"` это `53`, а `5 + 3` это `8`.
* `$"... {выражение} ..."` подставляет значения в текст; без `$` скобки печатаются как есть; `{{` и `}}` дают сами скобки.
* `s.Length` - число символов строки (без скобок).
* `{x:F2}` печатает число с двумя знаками после точки; вместе со строкой `CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;` в начале программы разделитель всегда точка.

## Для тех, кто уже программирует

* Интерполяция `$"{x}"` похожа на f-строки Python и шаблонные строки JavaScript; формат пишется после двоеточия (`{x:F2}`, как `f"{x:.2f}"`), выравнивание - после запятой (`{x,10}`).
* `string` неизменяема, `+` создаёт новый объект; для многих склеек в цикле используют `StringBuilder`.
* `+` со строкой слева приводит правый операнд к строке неявно (как в Java и JavaScript), в Python это ошибка типов.
* `Length` - свойство, а не метод (в отличие от `len(s)` в Python и `length()` в Java). `Length` считает единицы UTF-16, а не «символы» для человека: эмодзи и некоторые знаки занимают две единицы.
* Результат форматирования дробных чисел зависит от `CurrentCulture`; в `String.Format` Java то же с `Locale`. Для данных, которые читают другие программы, указывайте `CultureInfo.InvariantCulture`.
* Есть буквальные строки `@"C:\temp"` и необработанные `"""..."""`, в курсе они не используются.

<!-- section: deep-dive -->
## Что делает компилятор с интерполяцией

Это необязательный раздел: для заданий он не нужен.

Для `$"Привет, {name}! Тебе {age} лет."` компилятор не склеивает текст каждый раз заново. Он превращает строку в вызов форматирования с отдельными частями: постоянный текст добавляется как есть, а значения вставляются с использованием текущей культуры и, при необходимости, формата. Начиная с C# 10 для этого используется специальный тип «обработчик интерполированных строк», который позволяет избежать лишних промежуточных строк. На результат это не влияет.

Строка `string` внутри - массив 16-битных единиц UTF-16, поэтому `Length` возвращает число единиц, а не число «видимых букв». Для русских букв, цифр и обычных знаков одна единица равна одному символу, и разница заметна лишь для эмодзи и редких иероглифов.
