## Зачем нужен словарь

В списке и массиве значения ищут по номеру. Но в жизни чаще спрашивают иначе: «сколько стоит молоко?», «сколько раз встретилось слово?», «какая оценка у Анны?». Нужно найти значение не по позиции, а по имени. Для этого служит **словарь** `Dictionary<TKey, TValue>`: набор пар «ключ - значение». По ключу словарь находит значение сразу, не просматривая все пары по порядку.

## Одна новая идея: ключ уникален, а запись по ключу и добавляет, и заменяет

Тип словаря указывает два типа в угловых скобках: тип ключа и тип значения. `Dictionary<string, int>` - «ключи-строки, значения-числа».

```csharp
Dictionary<string, int> prices = new Dictionary<string, int>();
prices["хлеб"] = 45;
```

Запись `prices["хлеб"] = 45;` делает одно из двух: если ключа `"хлеб"` ещё нет, добавляет пару, а если есть - заменяет значение. Ключи в словаре не повторяются.

Чтение `prices["хлеб"]` возвращает значение, но если ключа нет, программа остановится с исключением `KeyNotFoundException`. Поэтому перед чтением ключ проверяют. Есть два способа:

* **`ContainsKey(k)`** - возвращает `true`, если ключ есть;
* **`TryGetValue(k, out int v)`** - ищет ключ и одновременно достаёт значение. Если ключ найден, метод возвращает `true` и кладёт значение в переменную `v`; если нет, возвращает `false`, а `v` получает значение по умолчанию (0). Слово `out` означает: «результат метод положит в эту переменную»; новую переменную можно объявить прямо в вызове (`out int v`).

Остальное: `prices.Count` - число пар, `prices.Remove(k)` - удаление пары, обход через `foreach`, внутри которого элемент - пара `KeyValuePair<string, int>` со свойствами `Key` и `Value`.

<!-- section: examples -->
## Пример 1. Запись, чтение, замена

```csharp run
Dictionary<string, int> prices = new Dictionary<string, int>();
prices["хлеб"] = 45;
prices["молоко"] = 89;
prices["сыр"] = 320;
Console.WriteLine(prices["молоко"]);
prices["хлеб"] = 50;
Console.WriteLine(prices["хлеб"]);
Console.WriteLine(prices.Count);
Console.WriteLine(prices.ContainsKey("яблоко"));
```
```output
89
50
3
False
```

Разбор:

* три присваивания добавляют три пары; в словаре три записи;
* повторное присваивание по ключу `"хлеб"` заменило значение 45 на 50, а не добавило вторую запись, поэтому `Count` остался равным 3;
* `ContainsKey("яблоко")` возвращает `False`: такого ключа нет.

## Пример 2. TryGetValue

```csharp run
Dictionary<string, int> stock = new Dictionary<string, int>
{
    ["яблоки"] = 12,
    ["груши"] = 0
};

if (stock.TryGetValue("яблоки", out int apples))
{
    Console.WriteLine($"Яблок: {apples}");
}
if (stock.TryGetValue("манго", out int mango))
{
    Console.WriteLine($"Манго: {mango}");
}
else
{
    Console.WriteLine("Манго нет в списке");
}
```
```output
Яблок: 12
Манго нет в списке
```

Так можно задать начальные пары: `["ключ"] = значение` в фигурных скобках после `new`. `TryGetValue` возвращает `true` или `false` и подходит прямо в условие `if`; переменная `apples`, объявленная через `out int apples`, доступна ниже в том же блоке. Различие «ключа нет» и «значение равно 0» важно: для груш было бы `true` и 0.

## Пример 3. Подсчёт слов

```csharp run
string[] words = { "кот", "сом", "кот", "лев", "кот", "сом" };
Dictionary<string, int> counts = new Dictionary<string, int>();
foreach (string w in words)
{
    if (counts.ContainsKey(w))
    {
        counts[w] = counts[w] + 1;
    }
    else
    {
        counts[w] = 1;
    }
}

List<string> keys = new List<string>(counts.Keys);
keys.Sort();
foreach (string k in keys)
{
    Console.WriteLine($"{k}: {counts[k]}");
}
```
```output
кот: 3
лев: 1
сом: 2
```

Это шаблон «посчитать, сколько раз встретилось»: если слово уже есть, увеличиваем значение, иначе создаём запись со значением 1. Порядок пар в словаре не гарантирован, поэтому для стабильной печати ключи копируются в список (`new List<string>(counts.Keys)`), сортируются, и по ним читаются значения.

## Пример 4. Метод со словарём

```csharp run
string[] cats = { "еда", "транспорт", "еда", "кино", "транспорт" };
int[] amounts = { 300, 50, 120, 400, 70 };

Dictionary<string, int> totals = Totals(cats, amounts);
List<string> names = new List<string>(totals.Keys);
names.Sort();
foreach (string name in names)
{
    Console.WriteLine($"{name}: {totals[name]}");
}

static Dictionary<string, int> Totals(string[] cats, int[] amounts)
{
    Dictionary<string, int> result = new Dictionary<string, int>();
    for (int i = 0; i < cats.Length; i++)
    {
        if (!result.ContainsKey(cats[i]))
        {
            result[cats[i]] = 0;
        }
        result[cats[i]] += amounts[i];
    }
    return result;
}
```
```output
еда: 420
кино: 400
транспорт: 120
```

Сначала для каждой новой категории создаётся запись с нулём, затем к ней прибавляется сумма. Словарь передаётся из метода как результат так же, как список.

## Пример 5. Обход пар

```csharp run
Dictionary<string, int> grades = new Dictionary<string, int>();
grades["Анна"] = 5;
foreach (KeyValuePair<string, int> pair in grades)
{
    Console.WriteLine($"{pair.Key} = {pair.Value}");
}
```
```output
Анна = 5
```

Каждый элемент при обходе - пара с ключом `pair.Key` и значением `pair.Value`. Если в словаре несколько пар, порядок обхода не гарантируется, поэтому выводы, зависящие от порядка, строят через отсортированные ключи, как в примере 3.

**Попробуйте.** Подсчитайте буквы слова `"молоко"`: ключ - символ строки (`char`, о нём позже; можно взять `string` из одной буквы). Измените пример 3 так, чтобы вместо числа вхождений хранился список. Подумайте, что напечатает `Console.WriteLine(prices["яблоко"])` в примере 1, и проверьте.

## Точные правила

* Тип: `Dictionary<TKey, TValue>`. Ключи уникальны; значения могут повторяться.
* `d[k] = v` добавляет или заменяет. `d.Add(k, v)` только добавляет и при повторе ключа бросает `ArgumentException`.
* `d[k]` для отсутствующего ключа бросает `KeyNotFoundException`.
* `TryGetValue(k, out V v)` возвращает `true` и значение либо `false` и значение по умолчанию (0, `false`, `null`).
* `ContainsKey(k)` проверяет только ключ; `Count` - число пар; `Remove(k)` - удаляет пару по ключу.
* Порядок перебора не гарантирован и зависит от реализации; на него нельзя опираться. Для упорядоченного вывода сортируют ключи.
* Ключи-строки сравниваются с учётом регистра: `"Кот"` и `"кот"` - разные ключи.
* Во время `foreach` нельзя добавлять и удалять пары (`InvalidOperationException`), как и в списке.
* В `out`-параметр метод кладёт результат: переменную объявляют при вызове (`out int v`) либо заводят заранее.

## Типичные ошибки

**1. Чтение отсутствующего ключа.**

```csharp
Dictionary<string, int> d = new Dictionary<string, int>();
d["яблоко"] = 3;
Console.WriteLine(d["груша"]);
```

Программа останавливается: `Unhandled exception. System.Collections.Generic.KeyNotFoundException: The given key 'груша' was not present in the dictionary.` Проверьте ключ через `ContainsKey` или используйте `TryGetValue`.

**2. Повторный `Add` с тем же ключом.**

```csharp
Dictionary<string, int> d = new Dictionary<string, int>();
d.Add("a", 1);
d.Add("a", 2);
```

Ошибка во время работы: `System.ArgumentException: An item with the same key has already been added. Key: a`. Присваивание `d["a"] = 2;` заменило бы значение без ошибки.

**3. Значение не того типа.**

```csharp
Dictionary<string, int> d = new Dictionary<string, int>();
d["a"] = "один";
```

Компилятор: `error CS0029: Cannot implicitly convert type 'string' to 'int'`. Тип значения указан в угловых скобках.

**4. Ключ не того типа.**

```csharp
Dictionary<string, int> d = new Dictionary<string, int>();
d[1] = 5;
```

Компилятор: `error CS1503: Argument 1: cannot convert from 'int' to 'string'`. Ключи этого словаря - строки.

**5. `TryGetValue` без `out`.**

```csharp
Dictionary<string, int> d = new Dictionary<string, int>();
int n = 0;
if (d.TryGetValue("a", n))
{
    Console.WriteLine(n);
}
```

Компилятор: `error CS1620: Argument 2 must be passed with the 'out' keyword`. Пишите `out n` (или `out int n`).

**6. Расчёт на порядок пар.** Код, который «обычно» печатает пары в порядке добавления, может вести себя иначе после удалений или в другой версии .NET. Для стабильного вывода сортируйте ключи.

**7. Путают словарь и список.** Если ключи - числа от 0 до n - 1 подряд, словарь не нужен: подойдёт список или массив. Словарь выбирают, когда ищут по произвольному ключу: названию, имени, номеру заказа.

**8. Регистр букв.** Слова `"Кот"` и `"кот"` в словаре - разные ключи. Если регистр не важен, приведите слово к одному виду перед использованием (`ToLower`, следующие уроки).

<!-- section: summary -->
## Итоги

* `Dictionary<TKey, TValue>` хранит уникальные ключи и значения; поиск идёт по ключу.
* `d[k] = v` добавляет или заменяет, `d[k]` читает (ключ обязан существовать).
* `ContainsKey` и `TryGetValue(k, out v)` проверяют наличие ключа без исключения.
* `Count`, `Remove(k)`, `foreach` с `KeyValuePair` (`Key`, `Value`).
* Порядок пар не гарантирован: для вывода сортируйте ключи.
* Шаблон подсчёта: если ключ есть, увеличить значение, иначе создать со значением 1.

Данные во вводе часто приходят строками вроде «хлеб 45». Чтобы разобрать такую строку, нужны методы работы с текстом: [Методы строк](lesson:csharp.from-zero.string-methods).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `Dictionary<TKey, TValue>` - хеш-таблица, аналог `HashMap` из Java и `dict` из Python. Поиск, вставка и удаление в среднем за константное время. В отличие от Python и JavaScript, порядок обхода формально не гарантирован (хотя без удалений на практике совпадает с порядком вставки). Для отсортированного словаря есть `SortedDictionary`.
* Чтение отсутствующего ключа бросает `KeyNotFoundException`, а не возвращает `null` как `Map.get` в Java или `undefined` в JavaScript. Идиома C#: `TryGetValue`. Есть также `GetValueOrDefault(key, 0)`, который в курсе не используется.
* `out`-параметр - аналог возврата второго значения (как `(value, ok)` в Go). Ключевое слово `out` обязательно и на вызове.
* Ключ сравнивается через `Equals` и `GetHashCode`; для `string` это сравнение по значению с учётом регистра. Для своих типов ключей эти методы нужно переопределять (`record` делает это автоматически, об этом позже).
* Изменение словаря во время `foreach` бросает исключение (в Python - `RuntimeError`).
* Ключи не могут быть `null`: `d[null]` бросает `ArgumentNullException`.
* Индексатор-инициализатор `new Dictionary<string,int> { ["a"] = 1 }` и коллекционный `{ { "a", 1 } }` равнозначны.

## Как словарь находит значение быстро

Это необязательный раздел: для заданий он не нужен.

Внутри `Dictionary` лежит массив «корзин». Для ключа вычисляется **хеш-код** - число, получаемое из значения ключа (для строки оно зависит от всех её символов). Хеш-код превращается в номер корзины, и словарь сразу заглядывает именно туда. Если в корзине несколько ключей (коллизия), их сравнивают по очереди через `Equals`.

Поэтому поиск не зависит от размера словаря, а ключи должны вести себя предсказуемо: два равных ключа обязаны давать один и тот же хеш-код, и хеш ключа не должен меняться, пока он лежит в словаре. По этой же причине нельзя положить в словарь ключ `null`: у него нет хеш-кода. Нет и гарантированного порядка: он определяется внутренним устройством корзин, а не порядком добавления.
