## Зачем нужен for

Очень часто число повторений известно заранее: напечатать таблицу умножения, обработать `n` строк ввода, пройти по числам от 1 до 100. В цикле `while` для этого приходится держать в разных местах три вещи: начальное значение счётчика, условие и изменение счётчика. Цикл **`for`** собирает их в одну строку заголовка, поэтому их трудно потерять.

## Одна новая идея: заголовок из трёх частей

```csharp
for (начало; условие; шаг)
{
    // тело цикла
}
```

* **начало** выполняется один раз перед циклом, обычно объявляет счётчик: `int i = 0`;
* **условие** проверяется перед каждым проходом, как в `while`;
* **шаг** выполняется после каждого прохода тела, обычно `i++` («увеличить `i` на 1»).

Запись `for (int i = 0; i < 3; i++)` полностью равна такому `while`:

```csharp
int i = 0;
while (i < 3)
{
    // тело
    i++;
}
```

Отличие одно: счётчик `i`, объявленный в заголовке `for`, существует только внутри цикла и исчезает после его закрывающей `}`. Для счётчика принято короткое имя `i` (от слова index).

<!-- section: examples -->
## Пример 1. Считаем от 1 до 5

```csharp run
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine($"Строка {i}");
}
```
```output
Строка 1
Строка 2
Строка 3
Строка 4
Строка 5
```

Разбор:

* `int i = 1` - счётчик начинает с 1;
* `i <= 5` - пока не больше пяти;
* `i++` - после каждого прохода увеличиваем на 1.

Пять проходов, и счётчик в теле принимает значения от 1 до 5 включительно.

## Пример 2. Накопитель в for

```csharp run
int total = 0;
for (int i = 1; i <= 10; i++)
{
    total += i;
}
Console.WriteLine($"Сумма от 1 до 10: {total}");
```
```output
Сумма от 1 до 10: 55
```

Накопитель `total` объявлен до цикла и поэтому виден после него. Счётчик `i` после цикла уже не существует.

## Пример 3. Другой шаг и обратный отсчёт

```csharp run
for (int i = 10; i >= 0; i -= 5)
{
    Console.Write(i + " ");
}
Console.WriteLine();

for (int i = 0; i < 20; i += 7)
{
    Console.Write(i + " ");
}
Console.WriteLine();
```
```output
10 5 0 
0 7 14 
```

Шаг не обязан быть `i++`. Любая команда подойдёт: `i -= 5` вычитает пять, `i += 7` прибавляет семь. Если считаем вниз, условие должно проверять нижнюю границу (`i >= 0`), иначе цикл не выполнится. После каждого числа печатается пробел (`Console.Write`), а пустой `Console.WriteLine()` в конце переводит строку.

## Пример 4. Строка по частям

```csharp run
string bar = "";
for (int i = 0; i < 5; i++)
{
    bar += "#";
}
Console.WriteLine(bar);
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"3 x {i} = {3 * i}");
}
```
```output
#####
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

Здесь `i` объявлено в двух циклах подряд, и ошибки нет: каждый счётчик живёт только в своём цикле. Оператор `+=` для строк дописывает текст в конец.

## Пример 5. Число повторений приходит из ввода

Ввод:

```
3
5
4
5
```

```csharp
int n = int.Parse(Console.ReadLine() ?? "");
int sum = 0;
for (int i = 0; i < n; i++)
{
    int mark = int.Parse(Console.ReadLine() ?? "");
    sum += mark;
}
Console.WriteLine($"Оценок: {n}, сумма: {sum}");
```

Вывод:

```
Оценок: 3, сумма: 14
```

Первая строка ввода - количество `n`. Цикл `for (int i = 0; i < n; i++)` выполняется ровно `n` раз, и каждый проход читает ещё одну строку. Это стандартная форма для задач вида «сначала количество, потом столько-то значений». Счётчик, который идёт от 0 до `n - 1`, привычнее всего: `i < n` даёт `n` проходов.

**Попробуйте.** В примере 1 замените `i <= 5` на `i < 5` и скажите, сколько строк будет. В примере 3 измените начальное значение и шаг так, чтобы напечатались 100 90 80. В примере 5 подумайте, что произойдёт при `n`, равном 0.

## Точные правила

* `for (начало; условие; шаг) { тело }`. Порядок выполнения: начало (один раз) -> условие -> тело -> шаг -> условие -> тело -> шаг -> ... -> условие ложно, выход.
* Все три части разделяются точками с запятой (не запятыми). Любая часть может быть пустой, но в курсе так не пишут.
* Переменная из заголовка видна только в заголовке и теле цикла. Имя можно использовать снова в следующем цикле, но не во вложенном или объемлющем блоке, где оно уже занято (`CS0136`).
* `for (int i = 0; i < n; i++)` выполняет тело `n` раз со значениями `i` от 0 до `n - 1`. `for (int i = 1; i <= n; i++)` тоже `n` раз со значениями от 1 до `n`.
* Если условие ложно с самого начала (например, `n` равно 0), тело не выполняется.
* Изменять счётчик внутри тела допустимо, но делать этого не стоит: цикл становится трудно читать.
* Если изменение счётчика идёт не в ту сторону, цикл бесконечный: `for (int i = 0; i < 10; i--)` не закончится.

## Типичные ошибки

**1. Точка с запятой после заголовка.**

```csharp
for (int i = 0; i < 3; i++);
{
    Console.WriteLine("x");
}
```

Компилятор: `warning CS0642: Possible mistaken empty statement`. Цикл `for` с пустым телом пройдёт три раза, а блок `{ ... }` выполнится один раз после него, поэтому будет напечатан один `x`, а не три. Уберите `;`.

**2. Запятые вместо точек с запятой.**

```csharp
for (int i = 0, i < 3, i++)
{
    Console.WriteLine(i);
}
```

Компилятор: `error CS1002: ; expected`, дважды. Части заголовка разделяются `;`.

**3. Счётчик использован после цикла.**

```csharp
for (int i = 0; i < 3; i++)
{
    Console.WriteLine(i);
}
Console.WriteLine(i);
```

Компилятор: `error CS0103: The name 'i' does not exist in the current context`. Если значение нужно после цикла, объявите переменную до него.

**4. Имя уже занято.**

```csharp
int i = 10;
for (int i = 0; i < 3; i++)
{
    Console.WriteLine(i);
}
```

Компилятор: `error CS0136: A local variable or function named 'i' cannot be declared in this scope because that name is used in an enclosing local scope to define a local variable`. Выберите другое имя для счётчика или для внешней переменной.

**5. Ошибка на единицу.** Для `n` повторений пара «начало и условие» должна быть `i = 0` и `i < n`, либо `i = 1` и `i <= n`. Смесь `i = 1` и `i < n` даёт на один проход меньше, а `i = 0` и `i <= n` - на один больше. Проверьте цикл на `n`, равном 1.

**6. Цикл идёт не в ту сторону.**

```csharp
for (int i = 10; i > 0; i++)
{
    Console.WriteLine(i);
}
```

Счётчик растёт, а условие `i > 0` истинно всегда: вывод не прекращается. Для обратного отсчёта нужен `i--`.

**7. Читаем меньше или больше строк, чем есть.** Если цикл ждёт `n` значений, а во вводе их меньше, `ReadLine` вернёт `null`, а `?? ""` даст пустую строку. Тогда `int.Parse("")` завершится ошибкой `FormatException`. Количество повторений должно соответствовать данным.

## Итоги

* `for (начало; условие; шаг)` - цикл со счётчиком; все три части записаны в заголовке и разделены `;`.
* `for (int i = 0; i < n; i++)` выполняет тело ровно `n` раз.
* Счётчик из заголовка недоступен после цикла; накопитель объявляют до цикла.
* Шаг может быть любым: `i += 2`, `i--`, `i -= 5`; условие должно соответствовать направлению.
* Следите за границей: `<` и `<=` отличаются на один проход.

Иногда цикл нужно прервать досрочно или пропустить часть прохода: [Управление циклом: break и continue](lesson:csharp.from-zero.loop-control).

## Для тех, кто уже программирует

* `for` такой же, как в C, Java и JavaScript. Условие обязано быть `bool`. Счётчик, объявленный в заголовке, ограничен циклом (в JavaScript с `var` это не так).
* Частей может быть несколько: `for (int i = 0, j = 10; i < j; i++, j--)`. Любая часть может быть опущена, `for (;;)` - бесконечный цикл.
* Для перебора диапазона нет конструкции вроде `range` из Python или `for i := range n` из Go; пишется явный счётчик. Для обхода элементов массива и списка есть `foreach` (урок о массивах), и он предпочтительнее, когда индекс не нужен.
* Изменение счётчика в теле разрешено (в Java тоже), но ломает читаемость.
* Замыкания в C# захватывают переменную, а не значение. Для `for` счётчик один на весь цикл, для `foreach` на каждую итерацию создаётся новая переменная; об этом позже, в теме лямбд.
* Строки в цикле лучше собирать через `StringBuilder`: `+=` на каждой итерации создаёт новую строку. Для учебных объёмов это не важно.

## Что делает компилятор с for

Это необязательный раздел: для заданий он не нужен.

`for` - это синтаксический сахар над циклом с проверкой в начале: компилятор выписывает начало, затем метку, проверку условия, тело, шаг и переход назад. Именно поэтому `for` и `while` работают одинаково быстро: после разбора программы различия между ними нет.

Когда граница известна и тело простое, JIT-компилятор может развернуть несколько итераций в одну (loop unrolling) или убрать проверку выхода за границы массива, если докажет, что индекс всегда внутри массива. Для вас это означает: пишите цикл так, как проще читать.
