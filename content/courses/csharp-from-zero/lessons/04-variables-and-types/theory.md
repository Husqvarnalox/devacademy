## Зачем нужны переменные

До сих пор программа печатала текст, который вы сами вписали в кавычки. Настоящие программы работают со значениями, которые меняются: цена товара, количество, имя покупателя, «открыт ли магазин». Чтобы значение можно было запомнить, изменить и использовать в нескольких местах, ему дают имя и хранят в **переменной**.

**Переменная** - это именованное место в памяти, где лежит одно значение. Представьте подписанную коробку: на ней написано имя, внутри лежит значение, и содержимое можно заменить.

У каждой переменной в C# есть **тип**: он определяет, какие значения в неё можно положить. Три первых типа:

* `int` - целое число: `0`, `42`, `-7`. Для количеств, возрастов, номеров;
* `string` - текст: `"Тетрадь"`, `"Анна"`, `""` (пустой). Для имён, названий, сообщений;
* `bool` - логическое значение: `true` («истина») или `false` («ложь»). Для признаков «да/нет»: открыт ли магазин, оплачен ли заказ.

## Одна новая идея: объявление с типом

Переменную сначала **объявляют**: указывают тип, имя и начальное значение.

```csharp
int quantity = 10;
```

Читается: «создать переменную типа `int` с именем `quantity` и положить в неё `10`». Знак `=` здесь означает не «равно», а **присваивание**: «положить значение справа в переменную слева».

<!-- section: examples -->
## Пример 1. Три переменные

```csharp run
string shop = "Книжный";
int books = 120;
bool isOpen = true;
Console.WriteLine(shop);
Console.WriteLine(books);
Console.WriteLine(isOpen);
```
```output
Книжный
120
True
```

Разбор по строкам:

* `string shop = "Книжный";` - переменная `shop` типа `string`, в ней текст. Слово в кавычках - строковый литерал, как в прошлых уроках;
* `int books = 120;` - переменная `books` типа `int`, в ней число 120; кавычек у числа нет;
* `bool isOpen = true;` - переменная типа `bool`, в ней `true`. В тексте программы пишут маленькими буквами;
* `Console.WriteLine(shop);` печатает не слово `shop`, а **значение** переменной: `Книжный`. Кавычки вокруг имени означали бы текст, без кавычек - переменную;
* `True` с большой буквы - так C# печатает значение `bool`. Это только вид вывода, значение то же.

## Пример 2. Изменение значения

```csharp run
int books = 120;
Console.Write("Было книг: ");
Console.WriteLine(books);
books = 95;
Console.Write("Стало книг: ");
Console.WriteLine(books);
```
```output
Было книг: 120
Стало книг: 95
```

`books = 95;` - присваивание **без типа**: переменная уже существует, мы только кладём в неё новое значение. Старое значение исчезает. Если написать тип ещё раз (`int books = 95;`), компилятор сообщит, что переменная с таким именем уже есть.

## Пример 3. Присваивание копирует значение

```csharp run
int a = 5;
int b = a;
a = 9;
Console.WriteLine(a);
Console.WriteLine(b);
```
```output
9
5
```

В строке `int b = a;` берётся текущее значение `a` (5) и копируется в `b`. После этого переменные независимы: изменение `a` на `9` не затрагивает `b`.

## Пример 4. var: тип выводит компилятор

```csharp run
var city = "Казань";
var year = 2025;
var ready = false;
Console.WriteLine(city);
Console.WriteLine(year);
Console.WriteLine(ready);
```
```output
Казань
2025
False
```

Слово `var` значит «определи тип по значению справа»: здесь это `string`, `int` и `bool`. Тип у переменной остаётся строгим и неизменным; `var` лишь избавляет от повторения. Пользоваться `var` удобно, когда тип виден из значения справа, как здесь. В этом курсе в первых уроках типы пишутся явно, чтобы вы привыкли их видеть.

**Попробуйте.** Объявите в примере 2 переменную `string unit = "шт.";` и добавьте команды, которые напечатают её после числа. Затем попробуйте написать `books = "много";` и прочитайте сообщение компилятора.

## Точные правила

* **Объявление:** `тип имя = значение;`. Значение должно подходить типу. Объявить переменную без значения (`int x;`) можно, но использовать её до присваивания нельзя (ошибка `CS0165`).
* **Присваивание:** `имя = значение;`. Сначала вычисляется правая часть, затем результат кладётся в переменную. Тип переменной не меняется.
* **Имена:** буквы, цифры и `_`; не начинаются с цифры; регистр различается (`books` и `Books` - разные имена); нельзя использовать зарезервированные слова (`int`, `class`, `if` и т. д.). Принятый стиль для локальных переменных - `camelCase`: первое слово строчными, следующие с заглавной (`totalPrice`). Имя должно говорить, что хранится: `quantity`, а не `q1`.
* **`int`** - 32-битное целое со знаком, от -2 147 483 648 до 2 147 483 647. Если значение за пределами, нужен другой тип (о них - в `csharp-first-steps`).
* **`string`** - текст в двойных кавычках; пустая строка `""`. Значения `string` в C# нельзя изменить «на месте»: присваивание создаёт новую строку (подробнее - в уроке о методах строк).
* **`bool`** - только `true` или `false` (маленькими буквами).
* **`var`** требует начального значения, из которого можно вывести тип. После объявления `var x = 5;` в `x` можно класть только `int`.
* Переменная, которой присвоили значение и больше никогда не использовали, вызывает предупреждение `CS0219` (см. ниже): она, скорее всего, лишняя.

## Типичные ошибки

**1. Значение не подходит типу.**

```csharp
int count = "три";
```

Компилятор: `error CS0029: Cannot implicitly convert type 'string' to 'int'` («нельзя неявно преобразовать string в int»). Тип `int` принимает только целые числа. Исправьте значение (`int count = 3;`) или тип, если вам действительно нужен текст.

**2. Присваивание другого типа позже.**

```csharp
int count = 3;
count = "пять";
```

Тот же `CS0029` на второй строке: тип переменной не меняется.

**3. Использование без значения.**

```csharp
int x;
Console.WriteLine(x);
```

Компилятор: `error CS0165: Use of unassigned local variable 'x'` («использование переменной, которой не присвоено значение»). Присвойте значение до первого использования.

**4. Повторное объявление.**

```csharp
int count = 1;
int count = 2;
```

Компилятор: `error CS0128: A local variable or function named 'count' is already defined in this scope`. Второе объявление - ошибка. Чтобы изменить значение, пишите без типа: `count = 2;`.

**5. Другой регистр в имени.**

```csharp
int count = 1;
Console.WriteLine(Count);
```

Компилятор: `error CS0103: The name 'Count' does not exist in the current context`. `count` и `Count` - разные имена.

**6. var без значения.**

```csharp
var x;
```

Компилятор: `error CS0818: Implicitly-typed variables must be initialized`. Компилятору не из чего выводить тип.

**7. Неиспользуемая переменная - первое предупреждение.**

```csharp
int unused = 5;
Console.WriteLine("Привет");
```

Программа запустится, но компилятор сообщит: `warning CS0219: The variable 'unused' is assigned but its value is never used`. Предупреждение показывает возможную ошибку: возможно, вы собирались использовать переменную. Удалите её или начните использовать.

## Итоги

* Переменная - именованное место для значения; у неё есть тип, имя и значение.
* `int` - целые числа, `string` - текст, `bool` - `true` или `false`. Объявление: `int quantity = 10;`.
* `имя = значение;` кладёт новое значение (тип не пишут); присваивание копирует значение.
* Тип переменной не меняется: положить строку в `int` нельзя, компилятор сообщит `CS0029`.
* `var` не отменяет типов: компилятор сам выводит тип из значения справа.

## Для тех, кто уже программирует

* C# статически типизирован: тип переменной задаётся при объявлении и не меняется. `var` - это не динамический тип и не `var` из JavaScript, а вывод типа на этапе компиляции (как `auto` в C++ или `var` в Java 10+).
* Локальные переменные не получают значения по умолчанию: чтение до присваивания - ошибка компиляции `CS0165`, в отличие от Java для полей или Go с нулевыми значениями.
* `int` - 32 бита со знаком (`System.Int32`), `string` - ссылочный тип `System.String`, неизменяемый; `bool` печатается как `True`/`False`.
* `string` и `int` - псевдонимы типов `System.String` и `System.Int32`: `String` и `string` взаимозаменяемы, принят второй вариант.
* Повторное объявление переменной с тем же именем в той же области видимости запрещено (`CS0128`), в том числе во вложенных блоках.
* Включённый по умолчанию анализ nullable запрещает класть `null` в `string` без явного `string?`; подробнее - в уроке о вводе.
* Локальная переменная, которой присвоена константа и которая нигде не читается, даёт предупреждение `CS0219`; объявленная, но не использованная вообще - `CS0168`.

## Что такое «место в памяти»

Это необязательный раздел: для заданий он не нужен.

Для локальных переменных простых типов среда выполнения отводит место в стеке вызовов. Тип определяет, сколько байт занимает значение и как их читать: `int` занимает 4 байта, `bool` - 1 байт. Именно поэтому в `int` нельзя положить текст: у текста другое устройство и размер, а компилятор заранее проверяет, что операции допустимы для типа.

`string` устроен иначе: переменная хранит **ссылку** на объект в управляемой куче, а не сами символы. Поэтому `string` называют ссылочным типом, а `int` - значимым. Разница между «копией значения» и «копией ссылки» - тема урока [Значимые и ссылочные типы](lesson:csharp.first-steps.value-types-and-nullable). Для начинающих достаточно правила: присваивание строки тоже безопасно, потому что строки нельзя изменить после создания.

Компилятор помечает имя переменной в метаданных отладочной сборки, чтобы отладчик показывал её значение под тем же именем; в самом машинном коде имён уже нет.
