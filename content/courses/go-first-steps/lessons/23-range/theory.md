## Зачем это нужно

Обходить срез по индексам (`for i := 0; i < len(s); i++`) можно, но записи много, а ошибка в границе (`<=` вместо `<`) случается часто. В Go есть форма цикла, которая сама проходит все элементы: `for ... range`.

## Одна новая идея: range выдаёт на каждом шаге индекс и значение

```go
for i, v := range s {
    // i - номер элемента, v - его значение
}
```

На каждой итерации `i` получает индекс (с нуля), а `v` - **копию** значения элемента. Границы цикла Go вычисляет сам. Если индекс не нужен, на его место ставят `_`: `for _, v := range s`.

<!-- section: examples -->
## Пример 1. Индекс и значение

```go run
package main

import "fmt"

func main() {
    colors := []string{"красный", "зелёный", "синий"}
    for i, c := range colors {
        fmt.Println(i, c)
    }
}
```
```output
0 красный
1 зелёный
2 синий
```

Тело выполняется трижды, по разу на элемент. Переменные `i` и `c` существуют только внутри цикла.

## Пример 2. Только значения: сумма

```go run
package main

import "fmt"

func main() {
    prices := []int{120, 80, 45}
    total := 0
    for _, p := range prices {
        total += p
    }
    fmt.Println("итого:", total)
}
```
```output
итого: 245
```

Индекс не нужен, поэтому вместо него `_`. Запись `total += p` - сокращение для `total = total + p`.

## Пример 3. Подсчёт с условием

```go run
package main

import "fmt"

func main() {
    ages := []int{15, 22, 17, 40, 18}
    adults := 0
    for _, a := range ages {
        if a >= 18 {
            adults++
        }
    }
    fmt.Println("взрослых:", adults, "из", len(ages))
}
```
```output
взрослых: 3 из 5
```

`adults++` увеличивает счётчик на единицу. Типичный шаблон: обход, условие, счётчик.

**Попробуйте.** В примере 2 поменяйте `_, p` на `i, p` и прочитайте сообщение компилятора. Затем в примере 3 замените `>=` на `>` и предскажите ответ.

## Точные правила

* **Форма**: `for i, v := range s`. Для массива и среза `i` - индекс `0..len-1`, `v` - значение элемента.
* **Пустой срез**: тело не выполняется ни разу.
* **Ненужная переменная** заменяется на `_`. Только индекс: `for i := range s`.
* **Копия**: `v` - копия элемента. Присваивание `v = ...` не меняет срез; для изменения пишут `s[i] = ...`.
* **Неиспользованные** `i` или `v` - ошибка компиляции, как и любая локальная переменная.
* **Область видимости**: `i` и `v` существуют только в теле цикла и создаются заново на каждой итерации.
* **Число повторений** вычисляется один раз перед циклом: добавление элементов внутри цикла не продлевает его.
* **Целое число**: `for i := range 3` повторяет тело три раза (`i` = 0, 1, 2); так можно заменить цикл со счётчиком. Когда число повторений зависит от условия, а не от длины, нужен обычный `for`.
* **Строки** и **карты** тоже обходят через `range`; об этом в следующих уроках.
* **Сокращения**: `x += y`, `x -= y`, `x *= y` и `x++`, `x--` - это команды, а не выражения.

## Типичные ошибки

**1. Индекс объявлен, но не использован.**

```go
for i, v := range xs {
    fmt.Println(v)
}
```

Компилятор: `declared and not used: i`. Замените `i` на `_`.

**2. Единственная переменная - это индекс.**

```go
total := 0
for v := range xs {
    total += v
}
```

Программа компилируется, но `v` здесь - индекс, а не значение: вы сложите 0 + 1 + 2 ... вместо элементов. Для значений нужна пара: `for _, v := range xs`.

**3. Изменение копии.**

```go
for _, v := range xs {
    v = v * 2
}
```

Срез `xs` не изменится: `v` - копия. Правильно: `for i := range xs { xs[i] = xs[i] * 2 }`.

**4. Целочисленное среднее.** `avg := sum / len(xs)` отбросит дробную часть, и сравнения «выше среднего» дадут не тот результат. Приводите: `float64(sum) / float64(len(xs))`.

Как заметить самому: напечатайте `i` и `v` внутри цикла на маленьком срезе и сверьте с ожиданием.

<!-- section: summary -->
## Итоги

* `for i, v := range s` обходит срез или массив, выдавая индекс и копию значения.
* Ненужную переменную заменяют на `_`; неиспользованная переменная - ошибка.
* Изменить элемент можно только по индексу: `s[i] = ...`.
* Шаблон «обход, условие, счётчик» решает множество задач.

## Для тех, кто уже программирует

* `range` возвращает пару (индекс, значение), как `enumerate` в Python; значение - копия элемента.
* `for _, v := range` - привычная замена `for each`; единственная переменная даёт индекс, а не значение (отличие от Python и JS `for...of`).
* С Go 1.22 переменные цикла создаются заново на каждой итерации (замыкания безопасны), и появился `for i := range n`.
* Длина вычисляется один раз перед началом; добавление в срез внутри цикла его не удлиняет.
* Тот же `range` работает для строк (руны), карт, каналов и функций-итераторов.
