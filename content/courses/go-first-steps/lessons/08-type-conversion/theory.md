## Зачем это нужно

В программах часто встречаются и целые, и дробные числа: количество товаров (`int`) и цена (`float64`), число оценок и средний балл. Чтобы их вместе использовать, нужно сказать Go, как превратить одно в другое. Иначе компилятор остановит программу: он не хочет угадывать, что вы имели в виду, и тихо терять точность.

## Одна новая идея: преобразование записывают явно

**Преобразование типа** - создание значения другого типа из имеющегося. Запись: `тип(значение)`.

* `float64(n)` - целое `n` становится дробным: `7` превращается в `7.0`.
* `int(f)` - дробное `f` становится целым: **дробная часть отбрасывается**, округления нет. `int(3.99)` для переменной со значением `3.99` даёт `3`.

Преобразование создаёт **новое значение**; сама переменная остаётся прежней.

<!-- section: examples -->
## Пример 1. Целые в дробное деление

```go run
package main

import "fmt"

func main() {
    sum := 7
    n := 2
    fmt.Println(sum / n)
    fmt.Println(float64(sum) / float64(n))
}
```
```output
3
3.5
```

Первая строка - целочисленное деление. Во второй строке оба числа сначала превращены в `float64`, поэтому деление дробное. Преобразовывать нужно оба операнда: `float64(sum) / n` не соберётся, потому что типы разные.

## Пример 2. Дробное в целое

```go run
package main

import "fmt"

func main() {
    f := 3.99
    fmt.Println(int(f))
    fmt.Println(int(-f))
}
```
```output
3
-3
```

Для положительных и отрицательных значений дробная часть просто отбрасывается: `3.99` даёт `3`, `-3.99` даёт `-3`. Это не округление: чтобы получить ближайшее целое, нужны другие средства.

## Пример 3. Порядок действий имеет значение

```go run
package main

import "fmt"

func main() {
    sum := 7
    n := 2
    fmt.Println(float64(sum / n))
    fmt.Println(float64(sum) / float64(n))
}
```
```output
3
3.5
```

В первой строке сначала выполняется `sum / n` (целое `3`), и только потом результат становится `3` в виде `float64` - дробная часть уже потеряна. Преобразовывать нужно **до** операции, а не после.

**Попробуйте.** Для `sum := 7` и `n := 2` напечатайте `float64(sum) / 2`. Что получится? Подумайте, почему число `2` здесь не нужно преобразовывать.

## Точные правила

* Запись: `T(x)`, где `T` - имя типа. `float64(5)`, `int(f)`.
* **Целое в дробное** (`int` в `float64`) выполняется всегда. Для очень больших целых возможна потеря точности, но для обычных чисел преобразование точное.
* **Дробное в целое** отбрасывает дробную часть («усечение к нулю»): `int(2.9) == 2`, `int(-2.9) == -2`. Если значение не умещается в `int`, результат зависит от платформы и использовать его нельзя.
* **Константы**: `int(3.99)` для записанного прямо в программе числа - ошибка компиляции, потому что в целое нельзя положить дробную часть. Усечение работает для значений в переменных.
* **Числовой литерал без типа** подстраивается под соседа: в выражении `float64(sum) / 2` число `2` само становится `float64`. Поэтому преобразовывать нужно только переменные.
* **Из текста в число и обратно** нельзя `float64("5")`: компилятор отвергнет такое преобразование. Для текста есть отдельные функции (будут позже).
* Преобразование не меняет исходную переменную.
* Результат делится на дробный и целый только по типам: `float64` с нулевой дробной частью всё равно `float64`. Println печатает `4`, а не `4.0`.

## Типичные ошибки

**1. Присвоили результат целочисленного деления в `float64`.**

```go
total := 10
var avg float64 = total / 4
```

Компилятор: `cannot use total / 4 (value of type int) as float64 value in variable declaration`. `total / 4` - это `int`. Решение: `float64(total) / 4`.

**2. Преобразование не там.**

```go
fmt.Println(float64(7 / 2))
```

Вывод: `3`, а не `3.5`. Преобразуется уже готовое целое. Если оба числа записаны прямо в программе, пишите `7.0 / 2`; для переменных - `float64(a) / float64(b)`. Как заметить: ответ дробный по смыслу, а на экране целое число.

**3. Ожидали округление от `int()`.**

```go
f := 2.9
fmt.Println(int(f))
```

Вывод: `2`, а не `3`. `int` отбрасывает дробную часть. Как заметить: результат всегда не больше по модулю, чем исходное число.

**4. Преобразовали текст в число.**

```go
fmt.Println(float64("5"))
```

Компилятор: `cannot convert "5" (untyped string constant) to type float64`. Для текста преобразование типов не подходит. Если «5» пришло из ввода, читайте его сразу в числовую переменную (`Scan`).

<!-- section: summary -->
## Итоги

* `float64(x)` и `int(f)` - явные преобразования; Go не делает их сам.
* `int(f)` отбрасывает дробную часть, а не округляет.
* Для дробного деления преобразуйте операнды до деления.
* Преобразование не меняет исходную переменную.

Теперь вы можете сочетать целые и дробные в одном расчёте. Выводить результаты красиво - с нужным числом знаков после запятой - поможет следующий урок: [Форматированный вывод](lesson:go.first-steps.formatted-output).

## Для тех, кто уже программирует

* Преобразования всегда явные, в том числе `int` в `float64` и `int32` в `int64`. Нет неявного расширения, как в C/Java/C#/JS.
* `T(x)` выглядит как приведение типов в C-подобных языках, но это конструктор значения: для числа в строку так не работает (`string(65)` даёт символ, а не «65»; для чисел нужен `strconv`).
* `int(f)` усекает к нулю, как приведение `(int)` в C/Java; в Python `int(f)` делает то же, а `round` округляет.
* Числовые литералы без типа подстраиваются: `x * 2`, где `x` - `float64`, не требует `2.0`.
* Нет перегрузки операторов: смешанные операнды - ошибка компиляции.
