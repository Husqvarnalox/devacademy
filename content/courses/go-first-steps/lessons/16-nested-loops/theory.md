## Зачем это нужно

Данные часто имеют два измерения: строки и столбцы таблицы, ряды и места в зале, дни и часы в расписании. Чтобы пройти по всем сочетаниям, один цикл внутри другого: для каждой строки обойти все столбцы. Такая конструкция называется **вложенными циклами**.

## Одна новая идея: внутренний цикл полностью выполняется на каждой итерации внешнего

```go
for i := 1; i <= 3; i++ {        // внешний цикл
    for j := 1; j <= 2; j++ {    // внутренний цикл
        // тело
    }
}
```

Когда `i` равно 1, внутренний цикл проходит все значения `j`. Затем `i` становится 2, и внутренний цикл запускается заново с начала. Общее число повторений тела - **произведение** повторений: 3 · 2 = 6.

Внешний счётчик меняется медленно, внутренний - быстро.

<!-- section: examples -->
## Пример 1. Все пары

```go run
package main

import "fmt"

func main() {
    for i := 1; i <= 2; i++ {
        for j := 1; j <= 3; j++ {
            fmt.Println("i =", i, "j =", j)
        }
    }
}
```
```output
i = 1 j = 1
i = 1 j = 2
i = 1 j = 3
i = 2 j = 1
i = 2 j = 2
i = 2 j = 3
```

Видно порядок: пока `i = 1`, счётчик `j` проходит 1, 2, 3; потом `i = 2` и `j` снова начинает с 1. Всего шесть строк.

## Пример 2. Прямоугольник из символов

```go run
package main

import "fmt"

func main() {
    for row := 0; row < 3; row++ {
        for col := 0; col < 5; col++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}
```
```output
*****
*****
*****
```

Внутренний цикл печатает одну строку из пяти звёздочек через `Print` (без перевода строки). `Println()` без значений после него завершает строку, и внешний цикл начинает следующую. Эта пара - общий шаблон для вывода таблиц.

## Пример 3. Треугольник: граница зависит от внешнего счётчика

```go run
package main

import "fmt"

func main() {
    for i := 1; i <= 4; i++ {
        for j := 1; j <= i; j++ {
            fmt.Print("#")
        }
        fmt.Println()
    }
}
```
```output
#
##
###
####
```

Предел внутреннего цикла `j <= i` зависит от внешнего: в строке 1 один символ, в строке 4 четыре. Всего повторений: 1 + 2 + 3 + 4 = 10, а не 4 · 4.

**Попробуйте.** В примере 2 поменяйте местами числа 3 и 5 и предскажите картинку. Затем в примере 3 замените `j <= i` на `j <= 4 - i + 1` и проверьте, какая фигура получится.

## Точные правила

* **Порядок выполнения**: для каждого значения внешнего счётчика внутренний цикл выполняется целиком, с начала до конца.
* **Число повторений** тела: произведение, если границы постоянны; сумма по строкам, если граница внутреннего цикла зависит от внешнего счётчика (как в треугольнике).
* **Разные счётчики**: внутри вложенных циклов используйте разные имена (`i` и `j`, `row` и `col`). Одинаковое имя во внутреннем цикле создаёт новую переменную, которая скрывает внешнюю; об этом мы поговорим в уроке про области видимости.
* **Таблицы**: типичная схема - внутренний цикл печатает ячейки (`Print`), после него `Println()` завершает строку.
* **Разделители без пробела в конце**: печатайте разделитель *перед* каждым элементом, кроме первого (`if j > 1 { fmt.Print(" ") }`).
* **`break` и `continue`** действуют на ближайший цикл. Чтобы завершить внешний цикл из внутреннего, используют флаг (переменную `bool`) или метки.
* **Стоимость**: вложенные циклы быстро растут: при `n = 1000` тело выполнится миллион раз. Это важно при больших данных.
* Глубина вложенности не ограничена, но три уровня и больше читаются тяжело.

## Типичные ошибки

**1. Нет перевода строки после внутреннего цикла.**

```go
for i := 1; i <= 3; i++ {
    for j := 1; j <= 3; j++ {
        fmt.Print(i*j, " ")
    }
}
```

Вывод - одна длинная строка `1 2 3 2 4 6 3 6 9 `. Добавьте `fmt.Println()` после внутреннего цикла, но внутри внешнего. Как заметить: таблица оказалась в одну строку.

**2. Предел внутреннего цикла не тот.**

```go
for i := 1; i <= 4; i++ {
    for j := 1; j <= 4; j++ {
        fmt.Print("#")
    }
    fmt.Println()
}
```

Ожидали треугольник, получили квадрат 4 на 4: внутренняя граница `4` не зависит от `i`. Нужно `j <= i`. Как заметить: сравните число символов в первой и последней строках с задачей.

**3. Ожидание, что `break` выйдет из обоих циклов.**

```go
for i := 1; i <= 3; i++ {
    for j := 1; j <= 3; j++ {
        if j == 2 {
            break
        }
        fmt.Println(i, j)
    }
}
```

Вывод: `1 1`, `2 1`, `3 1`. `break` завершил только внутренний цикл; внешний продолжился. Чтобы остановить всё, заведите переменную `done := false`, поставьте её в `true` перед `break` и проверяйте во внешнем цикле.

<!-- section: summary -->
## Итоги

* Вложенные циклы обходят сочетания значений: внутренний цикл выполняется полностью на каждой итерации внешнего.
* Число повторений - произведение (или сумма, если граница зависит от внешнего счётчика).
* Таблица: внутренний цикл печатает ячейки, `Println()` после него завершает строку.
* `break` и `continue` действуют только на ближайший цикл.

Вы закончили блок управления выполнением: условия, `switch`, циклы. Теперь программы можно структурировать - выделять повторяющиеся части в **функции**. Это тема следующего урока: [Функции](lesson:go.first-steps.functions).

## Для тех, кто уже программирует

* Вложенные циклы устроены как везде; особенностей две: нет скобок в заголовках и `break`/`continue` действуют на ближайший цикл.
* Вынести выход из внешнего цикла можно метками: `outer: for ... { for ... { break outer } }`.
* Вывод таблицы без пробела в конце строки делают условием `if j > 1` перед `Print(" ")`; в Go нет `join` для чисел в стандартной библиотеке без `strings` и `strconv`.
* Печать в цикле через `fmt.Print` буферизуется ОС, но каждая команда - системный вызов; для больших объёмов используют `bufio.Writer` (будет позже).
* С версии Go 1.22 переменная цикла создаётся заново на каждой итерации.
