## Зачем это нужно

Программы постоянно работают с текстом: имена, сообщения, слова из ввода. Если текст на английском, про его устройство можно не думать. Но как только в нём русские буквы или эмодзи, привычные операции дают неожиданные результаты: `len("привет")` равно не 6, а 12. Чтобы работать с любым текстом правильно, нужно понимать, из чего состоит строка.

## Одна новая идея: строка хранит байты, а символ называется руной

Компьютер хранит только числа, поэтому каждому символу присвоен числовой код, а в памяти он записан одним или несколькими **байтами**. Go использует кодировку UTF-8: латинская буква занимает 1 байт, кириллическая - 2, эмодзи - 4.

* строка (`string`) - последовательность **байтов**; `len(s)` возвращает число байтов;
* символ в смысле «одна буква» называется **руной** (`rune`) - это число, код символа;
* `for i, r := range s` обходит строку по символам: `r` - руна, `i` - номер байта, с которого она начинается;
* `[]rune(s)` превращает строку в срез рун, `string(r)` собирает из руны строку из одного символа.

Строка в Go **неизменяема**: нельзя заменить символ на месте, можно лишь собрать новую строку.

<!-- section: examples -->
## Пример 1. Байты и символы

```go run
package main

import "fmt"

func main() {
    for _, s := range []string{"hello", "привет", "Я", "😀"} {
        fmt.Println(s, len(s), len([]rune(s)))
    }
}
```
```output
hello 5 5
привет 12 6
Я 2 1
😀 4 1
```

Для каждой строки напечатаны сама строка, число байтов (`len(s)`) и число символов (`len([]rune(s))`). Для латиницы они совпадают, для кириллицы число байтов вдвое больше, у эмодзи 4 байта на один символ.

## Пример 2. Обход по символам

```go run
package main

import "fmt"

func main() {
    for i, r := range "яб😀" {
        fmt.Println(i, r, string(r))
    }
}
```
```output
0 1103 я
2 1073 б
4 128512 😀
```

`range` выдаёт позицию байта (0, 2, 4: символы занимают разное число байтов) и руну. Руна - число (код Unicode), поэтому `Println` печатает её как `1103`, а `string(r)` превращает руну обратно в строку из одного символа.

## Пример 3. Пакет strings

```go run
package main

import (
    "fmt"
    "strings"
)

func main() {
    s := "Привет, Мир"
    fmt.Println(strings.ToUpper(s))
    fmt.Println(strings.ToLower(s))
    fmt.Println(strings.Contains(s, "Мир"))
    fmt.Println(strings.Repeat("ab", 3))
    fmt.Println(strings.TrimSpace("  отступы  ") + "|")
}
```
```output
ПРИВЕТ, МИР
привет, мир
true
ababab
отступы|
```

Пакет `strings` собирает готовые операции над строками: `ToUpper`, `ToLower`, `Contains` (есть ли подстрока), `Repeat` (повтор), `TrimSpace` (убрать пробелы по краям). Они не меняют исходную строку, а возвращают новую.

## Пример 4. Разворот по символам

```go run
package main

import "fmt"

func reverse(s string) string {
    result := ""
    for _, r := range s {
        result = string(r) + result
    }
    return result
}

func main() {
    fmt.Println(reverse("Go и Я"))
}
```
```output
Я и oG
```

Каждый следующий символ ставится перед накопленным результатом. Работа идёт с рунами, поэтому кириллица не ломается.

**Попробуйте.** В примере 1 добавьте строку `"ёж"`. Затем в примере 2 замените `string(r)` на `r` и посмотрите, что напечатает `Println`.

## Точные правила

* **Строка** - неизменяемая последовательность байтов, обычно в UTF-8. Литерал в двойных кавычках: `"привет"`.
* **`len(s)`** - число байтов. Для числа символов: `len([]rune(s))`.
* **`s[i]`** - i-й байт (число типа `byte`), а не символ. Для кириллицы это половина символа: `"привет"[0]` равно 208.
* **Руна**: тип `rune` (число, код символа). Литерал руны в одинарных кавычках: `'я'`; `'a'` и `"a"` - разные вещи (число и строка).
* **`range` по строке** даёт пары (номер байта начала символа, руна).
* **Преобразования**: `[]rune(s)` - строка в срез рун; `string(runes)` - срез рун в строку; `string(r)` - одна руна в строку из одного символа.
* **Неизменяемость**: `s[0] = 'x'` - ошибка компиляции. Новую строку собирают через сцепление `+`.
* **Срез байтов** `s[:n]` может разрезать символ пополам и дать нечитаемый текст; для символов используйте `[]rune`.
* **Пакет `strings`**: `ToUpper`, `ToLower`, `Contains`, `Repeat`, `TrimSpace`, `HasPrefix`, `HasSuffix`, `Fields` (разбить по пробелам) и другие. Функции возвращают новую строку.
* **Печать руны**: `fmt.Println(r)` покажет число; `fmt.Printf("%c", r)` или `string(r)` покажут символ.
* **«Один символ глазами человека»** иногда состоит из нескольких рун (например, буква с отдельным значком ударения); в этом уроке такие случаи не рассматриваются.

## Типичные ошибки

**1. Длина строки в байтах принимается за число символов.**

```go
fmt.Println(len("привет"))
```

Вывод `12`, а не `6`. Для числа символов - `len([]rune(s))`. Как заметить: на русском тексте `len` вдвое больше ожидаемого.

**2. Индексирование кириллической строки.**

```go
s := "привет"
fmt.Println(s[0])
```

Вывод `208` - это первый байт буквы «п», а не буква. Для символа используйте `[]rune(s)[0]` или `range`. Срез `s[:1]` даст «�», потому что символ разрезан пополам.

**3. Попытка изменить символ.**

```go
s := "привет"
s[0] = 'П'
```

Компилятор: `cannot assign to s[0] (neither addressable nor a map index expression)`. Строки неизменяемы. Соберите новую строку: обойдите исходную циклом `range` и добавляйте нужные символы к результату.

**4. Печать руны как числа.**

```go
for _, r := range "яб" {
    fmt.Println(r)
}
```

Вывод `1103` и `1073`. Руна - это число; чтобы увидеть символ, используйте `string(r)` или `Printf("%c", r)`.

**5. Разворот по байтам.** Цикл `for i := len(s) - 1; i >= 0; i--` с `s[i]` выдаст нечитаемый набор байтов для кириллицы. Разворачивайте руны.

Как заметить самому: проверяйте функции на строках с кириллицей и пустой строке, а не только на латинице.

## Итоги

* Строка - байты в UTF-8; `len` считает байты, символы считают через `len([]rune(s))`.
* `range` по строке выдаёт руны; `string(r)` превращает руну в строку.
* Строки неизменяемы; новые собирают сцеплением.
* Пакет `strings` даёт `ToUpper`, `ToLower`, `Contains`, `Repeat`, `TrimSpace` и другие функции.
* Всегда проверяйте текстовые функции на кириллице и пустой строке.

## Для тех, кто уже программирует

* `string` - неизменяемая последовательность байтов (обычно UTF-8), а не символов; `len(s)` и `s[i]` работают с байтами. В отличие от Python 3, индексация не по кодовым точкам.
* `rune` - псевдоним `int32` (кодовая точка Unicode); `byte` - псевдоним `uint8`. Литерал `'я'` имеет тип rune (нетипизированная константа).
* `range` по строке декодирует UTF-8 и выдаёт (байтовый индекс, rune); недопустимые байты становятся `U+FFFD`.
* `[]rune(s)` копирует и декодирует, `string(runes)` кодирует обратно; сцепление в цикле создаёт много временных строк (для больших объёмов используют `strings.Builder`).
* `string(65)` для числа даёт символ, а не «65»: для чисел в текст используют `strconv.Itoa`; `go vet` ругается на такие преобразования.
* `strings.ToUpper/ToLower` учитывают Unicode; сравнение без учёта регистра: `strings.EqualFold`.
* Конкатенация `+` создаёт новую строку; сравнение `==` и порядок `<` идут по байтам.
