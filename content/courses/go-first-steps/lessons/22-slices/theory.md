## Зачем это нужно

Массив требует знать длину заранее. Но данных бывает столько, сколько пришло: оценок в классе может быть 12 или 30, покупок в чеке - от одной до сотни. Нужна последовательность, которая растёт по мере необходимости. В Go это **срез** (slice).

## Одна новая идея: срез - это массив, длина которого может меняться

Срез объявляют почти как массив, но без длины в скобках:

```go
var nums []int           // пустой срез, длина 0
nums = append(nums, 10)  // добавили элемент: [10]
nums = append(nums, 20)  // теперь [10 20]
fmt.Println(len(nums))   // 2
fmt.Println(nums[1])     // 20
```

* `[]int` - срез целых чисел (в скобках пусто);
* `append(срез, значение)` **возвращает** новый срез с добавленным элементом в конце, поэтому результат всегда присваивают: `nums = append(nums, 10)`;
* `len` и индексы `nums[i]` работают как у массива, нумерация с нуля.

Срез можно создать сразу со значениями, литералом: `[]int{3, 1, 4}`.

<!-- section: examples -->
## Пример 1. Литерал, append и len

```go run
package main

import "fmt"

func main() {
    s := []int{3, 1, 4}
    fmt.Println(s, len(s))
    s = append(s, 1)
    s = append(s, 5, 9)
    fmt.Println(s, len(s))
    fmt.Println(s[0], s[len(s)-1])
}
```
```output
[3 1 4] 3
[3 1 4 1 5 9] 6
3 9
```

`append` умеет добавлять сразу несколько значений: `append(s, 5, 9)`. Последний элемент среза имеет индекс `len(s)-1`.

## Пример 2. Построение среза в цикле

```go run
package main

import "fmt"

func main() {
    var squares []int
    for i := 1; i <= 5; i++ {
        squares = append(squares, i*i)
    }
    fmt.Println(squares)
    sum := 0
    for i := 0; i < len(squares); i++ {
        sum = sum + squares[i]
    }
    fmt.Println("сумма:", sum)
}
```
```output
[1 4 9 16 25]
сумма: 55
```

`var squares []int` создаёт пустой срез, и к нему сразу можно применять `append`. Заранее знать, сколько будет элементов, не нужно: цикл сам наращивает срез. Затем второй цикл обходит его по индексам.

## Пример 3. Чтение слов из ввода в срез

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Scan(&n)
    var names []string
    for i := 0; i < n; i++ {
        var name string
        fmt.Scan(&name)
        names = append(names, name)
    }
    for i := 0; i < len(names); i++ {
        fmt.Println(i+1, names[i])
    }
}
```

Если ввод `3` и слова `Анна Борис Вера`, программа напечатает

```text
1 Анна
2 Борис
3 Вера
```

Число слов `n` известно только при запуске, поэтому массив не подошёл бы, а срез наращивается в цикле. Переменная `name` объявлена внутри цикла: на каждой итерации создаётся новая, её значение добавляется в срез.

**Попробуйте.** В примере 2 вместо `i*i` добавляйте `i*10`. Затем в примере 1 уберите присваивание `s = ` перед первым `append` и прочитайте сообщение компилятора.

## Точные правила

* **Тип**: `[]T` - срез элементов типа `T`. Длина не входит в тип, поэтому срезы разной длины - один тип.
* **Нулевое значение** - пустой срез (`nil`): длина 0, печатается как `[]`. С ним безопасно работают `len` и `append`.
* **Литерал**: `[]string{"a", "b"}`.
* **`append`** принимает срез и одно или несколько значений того же типа и возвращает новый срез. Исходную переменную он не меняет, поэтому нужно писать `s = append(s, x)`.
* **Индексация** и `len` - как у массива. Индекс должен быть от `0` до `len(s)-1`; иначе паника `index out of range`. Элемент с индексом `len(s)` ещё не существует: сначала его нужно добавить через `append`.
* **Запись** `s[i] = v` меняет существующий элемент. Для пустого среза она недопустима: сначала нужен `append`.
* **Печать**: `fmt.Println(s)` показывает значения в квадратных скобках.
* **Под капотом** срез ссылается на массив и умеет перераспределять его при росте. Подробности (ёмкость, общая память) вы найдёте в курсе `go-fundamentals`; для работы с этим уроком они не нужны.
* **Вывод через пробел без хвоста**: ставьте разделитель перед элементом, кроме первого напечатанного.

## Типичные ошибки

**1. Результат append не сохранён.**

```go
var s []int
append(s, 2)
```

Компилятор: `append(s, 2) (value of type []int) is not used`. Исправление: `s = append(s, 2)`.

**2. Индекс за пределами среза.**

```go
s := []int{1, 2}
fmt.Println(s[2])
```

Панику при запуске:

```text
panic: runtime error: index out of range [2] with length 2
```

Для пустого среза сообщение будет `index out of range [0] with length 0`. Проверьте границы и длину; чаще всего виноват цикл `i <= len(s)`.

**3. Запись в несуществующий элемент.**

```go
var s []int
s[0] = 1
```

Тоже паника `index out of range [0] with length 0`. Срез `s` пуст: элементу `s[0]` ещё нечего менять. Добавьте элемент: `s = append(s, 1)`.

**4. Путаница с пробелом в конце.** Цикл `for ... { fmt.Print(x, " ") }` оставит пробел после последнего числа, и строгая проверка вывода не пройдёт. Печатайте пробел перед элементом, кроме первого.

**5. Срез вместо массива в сравнении.** Срезы нельзя сравнивать через `==` (только с `nil`). Для проверки равенства обходите элементы циклом.

Как заметить самому: напечатайте `len(s)` и `s` до и после `append`; проверьте граничные случаи: пустой срез и один элемент.

<!-- section: summary -->
## Итоги

* Срез `[]T` - последовательность переменной длины; нулевое значение - пустой срез.
* `s = append(s, x)` добавляет элемент; результат `append` обязательно присваивают.
* `len(s)` - число элементов; индексы от `0` до `len(s)-1`.
* Срез удобен, когда число значений известно только при запуске, например при чтении `n` чисел.

В следующем уроке появится удобный способ обходить срез без индексов: [range](lesson:go.first-steps.range).

## Для тех, кто уже программирует

* Срез - небольшая структура (указатель на массив, длина, ёмкость); `append` возвращает новый заголовок среза и при нехватке места выделяет новый массив, поэтому результат нужно присваивать.
* Ссылочная семантика: два среза могут делить одну память, и изменение элемента через один видно через другой. Подробно - в `go-fundamentals` и `go-professional`.
* `var s []int` - `nil`-срез; он ведёт себя как пустой для `len`, `append` и `range`, поэтому инициализация не нужна. `s == nil` проверяет только отсутствие массива.
* Срезы нельзя сравнивать через `==` и использовать как ключи карт.
* Есть `make([]int, n)` и выражение `s[a:b]` - они пока не нужны.
* Нет аналога `list.append()` с побочным эффектом: именно потому присваивание обязательно.
