## Зачем это нужно

Цикл со счётчиком подходит, когда известно число повторений. Но часто оно не известно заранее: читать числа, пока не придёт ноль; делить число, пока оно не станет единицей; повторять, пока пользователь не введёт правильный ответ. Для таких задач цикл строят вокруг **условия**, а не счётчика.

## Одна новая идея: цикл продолжается, пока условие истинно

Если в заголовке `for` оставить только условие, получится цикл «пока»:

```go
for условие {
    // тело
}
```

Если убрать и условие, цикл будет бесконечным: `for { ... }`. Остановить его изнутри можно командой:

* **`break`** - выйти из цикла немедленно;
* **`continue`** - пропустить остаток текущей итерации и перейти к следующей проверке.

<!-- section: examples -->
## Пример 1. Цикл с условием

```go run
package main

import "fmt"

func main() {
    n := 1000
    steps := 0
    for n > 1 {
        n = n / 2
        steps++
    }
    fmt.Println(steps)
}
```
```output
9
```

Число делится пополам, пока больше единицы: 1000, 500, 250, 125, 62, 31, 15, 7, 3, 1. Сколько раз придётся делить, заранее видно только из самих данных. В заголовке есть только условие, никакого счётчика.

## Пример 2. Бесконечный цикл и break

```go run
package main

import "fmt"

func main() {
    i := 50
    for {
        if i%7 == 0 {
            fmt.Println(i)
            break
        }
        i++
    }
}
```
```output
56
```

`for { ... }` повторяет тело без проверки; `break` внутри `if` завершает цикл, когда найдено первое число, кратное 7.

## Пример 3. continue

```go run
package main

import "fmt"

func main() {
    sum := 0
    for i := 1; i <= 9; i++ {
        if i%2 == 0 {
            continue
        }
        sum += i
    }
    fmt.Println(sum)
}
```
```output
25
```

Для чётных `i` команда `continue` пропускает `sum += i` и переходит к следующему `i`. Складываются только нечётные: 1 + 3 + 5 + 7 + 9 = 25.

**Попробуйте.** В примере 2 поменяйте начальное значение на `i := 57` и подумайте, какое число найдёт цикл. Затем замените `i%7` на `i%13`.

## Точные правила

* **Формы `for`**: `for i := 0; i < n; i++ {}` (со счётчиком), `for условие {}` (цикл «пока»), `for {}` (бесконечный).
* **`for условие`** проверяет условие до каждой итерации. Если оно ложно сразу, тело не выполнится ни разу.
* **`break`** выходит из ближайшего (внутреннего) цикла. Вне цикла (и вне `switch`) он недопустим: `break is not in a loop, switch, or select`.
* **`continue`** переходит к следующей итерации. В цикле со счётчиком выполняется шаг (`i++`), а в цикле только с условием шаг вы пишете сами: если `continue` находится перед ним, шаг будет пропущен.
* **Условие должно меняться**: что-то в теле должно приводить к ложному условию или к `break`. Иначе цикл бесконечен.
* **Чтение до конца ввода**: если `Scan` ничего не прочитал (ввод закончился), прежнее значение переменной не меняется. Если переменную объявить **внутри** цикла, на каждой итерации она будет нулевой, и признак «0» сработает.
* Команды `break` и `continue` обычно стоят внутри `if`.

<!-- section: mistakes -->
## Типичные ошибки

**1. Условие никогда не станет ложным.**

```go
n := 10
for n > 0 {
    fmt.Println(n)
}
```

Тело не меняет `n`, цикл не заканчивается, и вывод бесконечен. Добавьте изменение (`n--`). Как заметить: перед запуском спросите, что в теле приближает конец цикла.

**2. `continue` перед шагом в цикле «пока».**

```go
i := 0
for i < 5 {
    if i == 2 {
        continue
    }
    i++
}
```

Когда `i` равно 2, `continue` возвращает к проверке, а `i++` не выполняется. Цикл зависает. Решение: переместите `i++` в начало тела, либо используйте цикл со счётчиком, где шаг выполняется сам.

**3. `break` вне цикла.**

```go
if true {
    break
}
```

Компилятор: `break is not in a loop, switch, or select`. `break` имеет смысл только внутри `for` или `switch`.

**4. Ввод закончился раньше нуля.**

```go
var x int
for {
    fmt.Scan(&x)
    if x == 0 {
        break
    }
}
```

Если ввод кончился без нуля, `Scan` ничего не записывает, в `x` остаётся последнее значение, и цикл бесконечен. Когда переменная объявлена внутри цикла (`var x int` в теле), на каждой итерации она нулевая, и цикл завершается. Условие окончания лучше продумать заранее.

<!-- section: summary -->
## Итоги

* `for условие { }` - цикл «пока»; `for { }` - бесконечный цикл.
* `break` завершает цикл, `continue` переходит к следующей итерации.
* Цикл должен приближаться к завершению: меняйте переменную из условия или используйте `break`.
* `continue` в цикле «пока» не выполняет шаг, который стоит после него.

Циклы можно вкладывать друг в друга - так строят таблицы: [Вложенные циклы](lesson:go.first-steps.nested-loops).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `for cond {}` - это `while`; `for {}` - `while (true)`. Нет `do ... while`: его заменяют `for { ...; if !cond { break } }`.
* `break` и `continue` действуют на ближайший цикл. Для выхода из внешнего есть метки (`outer:`), они будут позже.
* В `switch` внутри цикла `break` относится к `switch`, а не к циклу - ловушка для программистов на C/Java.
* Условие обязано быть `bool`.
* Закрытый поток ввода не возвращает исключение: `Scan` просто вернёт ошибку, которую пока не проверяем.
