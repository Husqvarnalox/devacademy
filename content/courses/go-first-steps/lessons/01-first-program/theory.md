## Что такое программа

Каждое приложение на телефоне и каждый сайт работают потому, что кто-то заранее описал компьютеру, что делать. Такое описание называется **программой**: это последовательность точных команд. Компьютер не догадывается и не додумывает, он выполняет то, что написано, шаг за шагом.

Команды записывают текстом на специальном языке. Этот текст называется **исходным кодом**, а язык - **языком программирования**. В этом курсе язык называется Go. Его придумали, чтобы программы были простыми для чтения и быстрыми при работе.

Компьютер не понимает текст на Go напрямую. Поэтому есть ещё один инструмент - **компилятор**: он переводит текст программы в файл, который может выполнить компьютер. Язык, в котором так делают, называется **компилируемым**. Сначала переводчик, потом запуск - так работает и Go.

В приложении вам не нужно запускать компилятор вручную. Вы пишете текст в редакторе, нажимаете «Запустить», и приложение само переводит программу и запускает её. Команда, которую оно выполняет, выглядит как `go run main.go`; запоминать её сейчас не нужно.

## Одна новая идея: программа на Go - это набор строк с фиксированной формой

Самая маленькая полезная программа состоит из трёх частей:

1. `package main` - сообщает: «это программа, которую можно запустить».
2. `import "fmt"` - подключает набор готовых возможностей. Пакет `fmt` умеет выводить текст.
3. `func main() { ... }` - место, с которого программа начинает работу. Всё, что внутри фигурных скобок, выполняется сверху вниз.

Внутри `main` стоит команда `fmt.Println("...")`. Она печатает текст и переводит курсор на новую строку.

<!-- section: examples -->
## Пример 1. Печать одной строки

```go run
package main

import "fmt"

func main() {
    fmt.Println("Касса открыта")
}
```
```output
Касса открыта
```

Разбор по строкам:

* `package main` - первая строка любой запускаемой программы. Слово `package` (пакет) обозначает группу файлов, а имя `main` говорит, что эта группа - программа, а не набор готовых функций для чужих программ.
* `import "fmt"` - подключение пакета `fmt` (от слова format, «форматирование»). Без этой строки имя `fmt` неизвестно.
* `func main() {` - объявление **функции** с именем `main`. Функция - именованный блок команд. Слово `func` обязательно, круглые скобки пока пустые, фигурная скобка открывает блок.
* `fmt.Println("Касса открыта")` - вызов функции `Println` из пакета `fmt`. Текст в двойных кавычках передан ей в скобках.
* `}` - закрывает блок `main`. Когда команды в нём закончились, программа завершается.

## Пример 2. Несколько команд подряд

```go run
package main

import "fmt"

func main() {
    fmt.Println("Первая строка")
    fmt.Println("Вторая строка")
    fmt.Println("Третья строка")
}
```
```output
Первая строка
Вторая строка
Третья строка
```

Порядок вывода совпадает с порядком команд: компьютер идёт сверху вниз и ничего не пропускает и не переставляет.

**Попробуйте.** Поменяйте местами две строки с `Println` и предскажите вывод до запуска. Затем удалите одну пару кавычек вокруг текста и посмотрите, как компилятор отреагирует (подробнее - в разделе об ошибках).

<!-- section: precise -->
## Точные правила

* Программа начинается с `package main`, затем идут `import`, затем объявления функций. Порядок менять нельзя.
* Выполнение начинается с функции `main`. Если её нет, программа не соберётся.
* **Строковый литерал** - текст, записанный прямо в программе, в двойных кавычках: `"Касса открыта"`. Литерал в кавычках печатается как есть, без кавычек. Внутри допустимы русские буквы, пробелы, цифры и знаки.
* Регистр важен: `Println` и `println` - разные имена. Из пакета можно использовать только имена с заглавной буквы: `fmt.Println` работает, `fmt.println` - нет.
* Между именем пакета и функцией стоит точка: `fmt.Println`. Аргументы функции (то, что ей передают) записывают в круглых скобках.
* Открывающая фигурная скобка блока стоит на той же строке, что и `func main()`.
* Отступы внутри блока делают табуляцией или пробелами. Для компилятора они не важны, для читателя - важны. В Go принят единый стиль, который расставляет инструмент `gofmt`.
* Пустые строки между частями программы допустимы и улучшают чтение.

## Типичные ошибки

**1. Забыли `import "fmt"`.**

```go
package main

func main() {
    fmt.Println("привет")
}
```

Компилятор: `undefined: fmt`. Он не знает имени `fmt`, пока пакет не подключён. Добавьте `import "fmt"` под `package main`. Узнать это самому можно по сообщению: когда `undefined` относится к имени пакета, не хватает `import`.

**2. Имя функции с маленькой буквы.**

```go
fmt.println("привет")
```

Компилятор: `undefined: fmt.println (but have Println)`. В скобках он подсказывает правильное имя. Из чужого пакета доступны только имена, начинающиеся с заглавной буквы. Замените `println` на `Println`.

**3. Не закрыли кавычки.**

```go
fmt.Println("привет)
```

Компилятор: `newline in string` и `syntax error: unexpected newline in argument list; possibly missing comma or )`. Строка началась и не закончилась до конца строки программы. Проверьте, что у каждой открывающей кавычки есть закрывающая на той же строке. Редактор обычно подсвечивает текст в кавычках одним цветом: если цвет «убегает» на следующие строки, где-то пропущена кавычка.

**4. Два текста подряд без запятой.**

```go
fmt.Println("a" "b")
```

Компилятор: `syntax error: unexpected literal "b" in argument list; possibly missing comma or )`. Несколько значений в скобках отделяют запятой; как это работает, разберём в уроке про вывод.

Общее правило чтения: сообщение начинается с номера строки и столбца (`6:18`), затем идёт описание. Откройте указанную строку и посмотрите на неё и на предыдущую.

## Итоги

* Программа - точная последовательность команд; исходный код - её текст; компилятор переводит его в файл, который выполняет компьютер.
* Минимальная программа на Go: `package main`, `import "fmt"`, `func main() { ... }`.
* `fmt.Println("текст")` печатает строку и переходит на следующую; кавычки не попадают на экран.
* Команды в `main` выполняются сверху вниз.

Это основа: любая следующая программа в курсе устроена так же, меняется только содержимое `main`. В следующем уроке вы научитесь читать сообщения компилятора и исправлять ошибки: [Как читать сообщения об ошибках](lesson:go.first-steps.compiler-errors).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Программа - пакет `main` с функцией `main`; точка входа не принимает аргументов и ничего не возвращает. Класса-обёртки нет.
* Точка с запятой в конце строки не нужна: компилятор вставляет её сам по правилам. Из-за этого `{` нельзя переносить на новую строку.
* Неиспользуемый импорт - ошибка компиляции, а не предупреждение.
* Видимость определяется регистром первой буквы: `Println` экспортируется, `println` нет. Ключевых слов `public`/`private` нет.
* Компиляция даёт один нативный исполняемый файл без виртуальной машины и интерпретатора на целевой машине.
* `go run` собирает и запускает во временной папке, `go build` оставляет файл.

<!-- section: deep-dive -->
## Что происходит при `go run`

Это необязательный раздел: для заданий он не нужен.

Команда `go run main.go` сначала запускает компилятор. Он разбирает текст по правилам языка, проверяет, что все имена известны и все типы сочетаются, и создаёт исполняемый файл во временной папке. Потом этот файл запускается как обычная программа, а после завершения временные файлы удаляются.

Внутрь исполняемого файла Go добавляет небольшой служебный код - **рантайм**. Он отвечает за память, за запуск `main` и за остановку программы. Поэтому даже самая короткая программа занимает мегабайты, но её можно скопировать на другой компьютер с той же операционной системой и архитектурой процессора и запустить без установленного Go.

Именно поэтому ошибки вроде `undefined: fmt` вы видите **до** запуска: сборка прерывается, программа не стартует, и никакого частично выполненного результата нет.
