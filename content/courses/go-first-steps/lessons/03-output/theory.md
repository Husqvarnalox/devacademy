## Зачем это нужно

Почти любая программа в итоге что-то показывает: чек, сообщение, таблицу. Часто в одной строке надо соединить текст и числа, а иногда - напечатать часть строки и продолжить её позже. Для этого нужно знать, как именно ведут себя команды вывода.

## Одна новая идея: вывод состоит из значений и переводов строки

**Значение** - то, что можно напечатать: текст в кавычках, число. Числа пишут без кавычек: `450`. В скобки команды вывода можно поставить несколько значений через запятую.

* `fmt.Println(a, b, c)` печатает значения, **ставит пробел между ними** и **в конце переводит строку** (Println - «print line»).
* `fmt.Print(a, b, c)` печатает значения и **не переводит строку**. Следующий вывод продолжится в той же строке.
* Внутри текста в кавычках последовательность `\n` означает **перевод строки**: на этом месте текст продолжится с новой строки.

<!-- section: examples -->
## Пример 1. Несколько значений в Println

```go run
package main

import "fmt"

func main() {
    fmt.Println("Товар:", "чай", "цена:", 120)
    fmt.Println("Всего позиций:", 3)
}
```
```output
Товар: чай цена: 120
Всего позиций: 3
```

* В первой команде четыре значения: два текста, ещё текст и число. Println вставил по одному пробелу между ними, поэтому самим пробелы в кавычках ставить не нужно.
* Число `120` стоит без кавычек и печатается как число.
* Каждая команда Println заканчивается переводом строки, поэтому результаты на разных строках.

## Пример 2. Print не переводит строку

```go run
package main

import "fmt"

func main() {
    fmt.Print("Загрузка")
    fmt.Print("...")
    fmt.Println(" готово")
    fmt.Println("Шаги:", 3, 4)
}
```
```output
Загрузка... готово
Шаги: 3 4
```

Первые две команды `Print` продолжают одну строку. Только `Println` в третьей команде заканчивает её. Пробел перед словом «готово» мы поставили сами - внутри кавычек.

## Пример 3. Перевод строки внутри текста

```go run
package main

import "fmt"

func main() {
    fmt.Print("Он сказал: \"Привет\"\nи ушёл\n")
}
```
```output
Он сказал: "Привет"
и ушёл
```

* `\n` дважды: между фразами и в конце. Благодаря второму `\n` следующий вывод начался бы с новой строки.
* `\"` - способ поместить кавычку внутрь текста, не закончив его. Обратная косая черта делает следующий символ «особенным» или «обычным». Такие записи называются **экранированием**.

**Попробуйте.** В примере 2 замените `Print("...")` на `Println("...")` и предскажите, где теперь окажутся слова «готово».

<!-- section: precise -->
## Точные правила

* Println ставит пробел между **любыми** соседними значениями и перевод строки в конце. Если вызвать `fmt.Println()` без значений, будет напечатана пустая строка.
* Print ставит пробел между соседними значениями только тогда, когда **ни одно из них не является текстом**: `fmt.Print(1, 2)` даёт `1 2`, а `fmt.Print("a", 1)` - `a1`. Из-за этого правила Print удобен лишь тогда, когда вы сами контролируете все пробелы.
* Перевод строки Print в конце не добавляет, его надо записать самому: `"...\n"`.
* Часто используемые escape-последовательности: `\n` - перевод строки, `\t` - табуляция (широкий пробел), `\"` - кавычка внутри текста, `\\` - сама обратная косая черта.
* Текст в кавычках не может занимать несколько строк программы: перенос внутри кавычек - ошибка. Для переноса используйте `\n` или несколько команд.
* Число без кавычек - число, число в кавычках - текст: `5` и `"5"` выглядят одинаково на экране, но являются разными значениями. Различие станет важным в уроке про типы.

## Типичные ошибки

**1. Пропущена запятая между значениями.**

```go
fmt.Println("Всего" 5)
```

Компилятор: `syntax error: unexpected literal 5 in argument list; possibly missing comma or )`. Значения в скобках перечисляются через запятую. Добавьте её. Заметить самому можно по словам `possibly missing comma`.

**2. Склейка текста и числа через `+`.**

```go
fmt.Println("Итого: " + 5)
```

Компилятор: `invalid operation: "Итого: " + 5 (mismatched types untyped string and untyped int)`. Знак `+` складывает числа с числами или склеивает текст с текстом, но не смешивает их. Замените `+` на запятую: `fmt.Println("Итого:", 5)`; о настоящих операциях мы поговорим в уроке про арифметику.

**3. Строки слиплись.** Вместо двух строк на экране одна:

```go
fmt.Print("Итого: 175")
fmt.Print("Спасибо")
```

Вывод: `Итого: 175Спасибо`. Print не переводит строку. Либо замените на Println, либо допишите `\n` в конце первого текста. Заметить можно по результату: на экране нет перехода на новую строку там, где он нужен.

**4. Двойные пробелы.**

```go
fmt.Println("Привет, ", "Анна")
```

Вывод: `Привет,  Анна` (два пробела). Один пробел вы поставили в кавычках, второй добавил Println. Уберите пробел из кавычек. Правило: при Println пробелы между значениями не пишите сами.

<!-- section: summary -->
## Итоги

* `fmt.Println(a, b, c)` - значения через пробел и перевод строки в конце.
* `fmt.Print(...)` - без перевода строки; продолжение в той же строке.
* `\n` внутри текста - перевод строки, `\"` - кавычка внутри текста.
* Числа пишутся без кавычек, значения разделяются запятыми.

Теперь вы можете печатать строки из нескольких частей, но значения пока записаны прямо в команде. Чтобы хранить значение и использовать его несколько раз, нужны переменные: [Переменные](lesson:go.first-steps.variables).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `fmt.Println(a, b)` ведёт себя как `print(a, b)` в Python: пробел между аргументами и перевод строки; разделитель менять нельзя (нет `sep=`/`end=`), для этого есть `Printf`.
* `fmt.Print` не равен `System.out.print` один к одному: он добавляет пробел между соседними операндами, если оба не строки.
* Конкатенации строки и числа через `+` нет, неявного преобразования нет.
* `Printf` с форматами - в уроке про форматированный вывод.
* Строки в двойных кавычках; одинарные кавычки в Go означают символ (руну), а не текст.
* Вывод идёт в стандартный поток вывода (stdout); в приложении он сравнивается с ожидаемым.
