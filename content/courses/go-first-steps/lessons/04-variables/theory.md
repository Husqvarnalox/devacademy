## Зачем это нужно

Программе часто нужно запомнить значение: имя покупателя, сумму в корзине, число попыток. Если писать значение прямо в каждой команде, его трудно менять и легко перепутать. Хранилище с именем - **переменная** - позволяет записать значение один раз, использовать по имени и изменить в одном месте.

## Одна новая идея: переменная - это имя для значения

**Переменная** - именованная ячейка в памяти компьютера, в которой лежит значение. По имени значение можно прочитать, а можно заменить новым.

Два действия, которые нужно различать:

* **Объявление** - создание переменной с именем и первым значением: `age := 25`.
* **Присваивание** - замена значения уже существующей переменной: `age = 26`.

Знак `=` здесь не означает «равно» как в математике. Он выполняет действие: «положить значение справа в переменную слева».

<!-- section: examples -->
## Пример 1. Два способа объявить переменную

```go run
package main

import "fmt"

func main() {
    var city = "Казань"
    temperature := 18
    fmt.Println(city, temperature)
}
```
```output
Казань 18
```

* `var city = "Казань"` - полная форма: слово `var` (variable, «переменная»), имя, знак `=` и значение.
* `temperature := 18` - короткая форма. Знаки `:=` одновременно объявляют переменную и кладут в неё значение. Её используют чаще всего, но только внутри функций.
* В `Println` вместо значений стоят имена; программа подставила то, что в них лежит.

## Пример 2. Присваивание меняет значение

```go run
package main

import "fmt"

func main() {
    balance := 100
    fmt.Println("Было:", balance)
    balance = 70
    fmt.Println("Стало:", balance)
}
```
```output
Было: 100
Стало: 70
```

Во второй строке переменная создана через `:=`. В пятой стоит `=` без двоеточия: переменная уже есть, меняется только её значение. Строка с `Println` не меняет ничего: она только читает значение.

## Пример 3. Переменная хранит копию

```go run
package main

import "fmt"

func main() {
    a := 5
    b := a
    a = 9
    fmt.Println(a, b)
}
```
```output
9 5
```

`b := a` берёт значение, которое сейчас лежит в `a` (число 5), и кладёт его в новую переменную. Дальше они независимы: изменение `a` не переписывает `b`.

**Попробуйте.** Поменяйте строку `a = 9` на `b = 9` и предскажите вывод. Затем добавьте после `b := a` строку `a = b` и подумайте, что изменится.

<!-- section: precise -->
## Точные правила

* **Имя переменной**: буквы, цифры и `_`, не может начинаться с цифры; регистр важен (`total` и `Total` - разные имена). Допустимы русские буквы, но принято писать имена латиницей на английском: `name`, `price`, `itemCount`. Имена в стиле «верблюд» (`itemCount`) - стандарт Go.
* **Ключевые слова** (`func`, `var`, `for`, `if` и другие) использовать как имена нельзя.
* **`var имя = значение`** работает везде. **`имя := значение`** - только внутри функции. Вне функции (на уровне пакета) разрешён только `var`.
* **`:=` требует новую переменную** слева. Если все имена слева уже объявлены в этой области, будет ошибка `no new variables on left side of :=`.
* **Несколько переменных**: `x, y := 1, 2` создаёт две переменные; значения справа вычисляются раньше, чем присваиваются.
* **Использовать нужно все**: объявленная и ни разу не прочитанная локальная переменная - ошибка `declared and not used`.
* **Тип** переменной определяется первым значением и потом не меняется: в переменную с числом нельзя положить текст. Подробно - в следующем уроке.
* **Копирование**: `b := a` копирует значение; переменные остаются независимыми.

## Типичные ошибки

**1. Переменная объявлена и не использована.**

```go
x := 5
fmt.Println("привет")
```

Компилятор: `declared and not used: x`. Go не допускает лишних локальных переменных. Либо используйте её (напечатайте), либо удалите объявление. Как заметить: сообщение называет имя переменной и строку объявления.

**2. Повторное объявление через `:=`.**

```go
x := 5
x := 6
```

Компилятор: `no new variables on left side of :=`. Вторая строка пытается создать то, что уже есть. Чтобы изменить значение, пишите `x = 6`. Как заметить: в сообщении стоит слово `new`, а вы не собирались создавать новое.

**3. Присваивание до объявления.**

```go
x = 5
```

Компилятор: `undefined: x`. Знак `=` только меняет, а менять пока нечего. Напишите `x := 5` для первого раза.

**4. `:=` вне функции.**

```go
x := 5

func main() {
}
```

Компилятор: `syntax error: non-declaration statement outside function body`. На верхнем уровне допускаются только объявления с ключевыми словами, и `x := 5` к ним не относится. Используйте `var x = 5` или перенесите строку внутрь `main`.

<!-- section: summary -->
## Итоги

* Переменная - имя для значения; `var имя = значение` и `имя := значение` создают её, `имя = значение` меняет.
* Каждая локальная переменная должна быть использована.
* `b := a` копирует значение; дальнейшие изменения не связывают переменные.
* Тип переменной не меняется: подробно в следующем уроке.

Теперь можно запоминать значения и менять их по ходу программы. Следующий вопрос: что именно может лежать в переменной и какие бывают виды значений. Об этом - [Базовые типы](lesson:go.first-steps.basic-types).

<!-- section: programmer -->
## Для тех, кто уже программирует

* `:=` объявляет и инициализирует; тип выводится из значения. Аналог `let`/`var` в JS или `auto` в C++, но тип остаётся статическим навсегда.
* `=` без объявления - ошибка, а не создание глобальной переменной, как могло бы быть в Python или JS без `let`.
* Неиспользуемая локальная переменная - ошибка компиляции.
* `var x int` без значения даёт нулевое значение, не `null`/`undefined`: подробно в следующем уроке.
* Переменные нельзя объявлять повторно в одной области; затенение во вложенных блоках возможно (об этом позже).
* Нет `const`-подобного `let`: для неизменяемого значения есть `const`.
