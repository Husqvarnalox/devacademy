## Зачем это нужно

Одно и то же действие часто нужно в нескольких местах: напечатать приветствие, нарисовать рамку, показать сумму в одном формате. Если копировать код, при каждой правке придётся искать все копии. Лучше записать действие один раз, дать ему имя и вызывать по имени. Такая именованная часть программы называется **функцией**.

Вы уже пользуетесь функциями: `fmt.Println` и `fmt.Scan` - это функции, написанные другими людьми. Теперь вы будете писать свои.

## Одна новая идея: функция - это именованный блок команд, которому можно передать значения

```go
func greet(name string) {
    fmt.Println("Здравствуйте,", name)
}
```

* `func` - ключевое слово, объявляющее функцию;
* `greet` - имя функции (его выбираете вы);
* `(name string)` - **параметры**: имена, под которыми функция получает значения, и их типы;
* `{ ... }` - **тело** функции: команды, которые выполняются при вызове.

Само объявление ничего не печатает. Команды из тела выполняются, когда функцию **вызывают**: `greet("Анна")`. Значение в скобках при вызове называется **аргументом**. Параметр - это имя в объявлении, аргумент - значение при вызове: при `greet("Анна")` внутри функции переменная `name` равна `"Анна"`.

<!-- section: examples -->
## Пример 1. Одно объявление, несколько вызовов

```go run
package main

import "fmt"

func greet(name string) {
    fmt.Println("Здравствуйте,", name)
}

func main() {
    greet("Анна")
    greet("Борис")
    greet("Вера")
}
```
```output
Здравствуйте, Анна
Здравствуйте, Борис
Здравствуйте, Вера
```

Разбор по строкам:

* `func greet(name string)` объявляет функцию с одним параметром типа `string`. Пока `main` не вызвала её, она не выполняется.
* `fmt.Println("Здравствуйте,", name)` - тело: печатает текст и значение параметра.
* В `main` три вызова. Каждый выполняет тело заново, подставляя свой аргумент в `name`.

Программа по-прежнему начинается с `main`. Порядок объявлений в файле не важен: `greet` можно было написать и после `main`.

## Пример 2. Несколько параметров

```go run
package main

import "fmt"

func printLine(symbol string, count int) {
    for i := 0; i < count; i++ {
        fmt.Print(symbol)
    }
    fmt.Println()
}

func main() {
    printLine("-", 10)
    fmt.Println("Меню")
    printLine("=", 4)
}
```
```output
----------
Меню
====
```

Параметры перечисляют через запятую, у каждого свой тип. Аргументы при вызове идут в том же порядке: `"-"` попадает в `symbol`, `10` - в `count`. Если поменять их местами, `printLine(10, "-")`, компилятор откажется собирать программу: типы не совпадают.

Тело функции может содержать цикл, `if` и всё остальное, что вы уже знаете.

## Пример 3. Параметры одного типа и вычисления внутри функции

```go run
package main

import "fmt"

func showArea(w, h int) {
    fmt.Println("Площадь:", w*h)
}

func main() {
    showArea(3, 4)
    showArea(10, 2)
}
```
```output
Площадь: 12
Площадь: 20
```

`w, h int` - краткая запись для `w int, h int`. Внутри функции параметры используются как обычные переменные.

**Попробуйте.** В примере 2 вызовите `printLine("*", 0)` и предскажите вывод. Затем добавьте в пример 3 третий вызов `showArea(7, 7)`.

## Точные правила

* **Объявление**: `func имя(параметр тип, параметр тип) { тело }`. Функция без параметров пишется с пустыми скобками: `func hello() { ... }`, а вызывается `hello()`.
* **Параметр** - переменная, которая существует внутри функции. При каждом вызове она получает копию переданного значения. Изменение параметра внутри функции не меняет переменную вызывающей стороны.
* **Аргументы** должны совпадать с параметрами по количеству, порядку и типу. Go не подставляет значения по умолчанию и не приводит типы сам.
* **Имена параметров** видны только внутри тела своей функции. В другой функции можно использовать то же имя - это будет другая переменная.
* **Порядок объявлений** на уровне пакета не важен: функцию можно вызвать выше её объявления.
* **Имя функции**: начинается с буквы, обычно в `camelCase` (`printLine`, `showArea`). С заглавной буквы пишут имена, которые должны быть видны из других пакетов; об этом позже, в уроке про пакеты.
* **Что функция делает**: сейчас наши функции печатают результат сами. В следующем уроке функция научится возвращать значение вызывающему коду.
* **Хороший признак** выделения функции: вы поймали себя на копировании одного и того же блока кода с разными значениями.

## Типичные ошибки

**1. Неверное число аргументов.**

```go
func greet(name string) {
    fmt.Println("Здравствуйте,", name)
}

func main() {
    greet()
}
```

Компилятор:

```text
not enough arguments in call to greet
	have ()
	want (string)
```

Строка `have` показывает, что вы передали, а `want` - что ожидала функция. Лишний аргумент даёт `too many arguments in call to greet`. Исправление: передайте ровно столько значений, сколько параметров.

**2. Аргумент не того типа.**

```go
greet(5)
```

Компилятор: `cannot use 5 (untyped int constant) as string value in argument to greet`. Параметр `name` имеет тип `string`, а `5` - число. Чтобы передать текст, возьмите его в кавычки: `greet("5")`.

**3. У параметра не указан тип.**

```go
func greet(name) {
    fmt.Println("Здравствуйте,", name)
}
```

Компилятор: `undefined: name`. Одно слово в скобках Go читает как тип параметра, а такого типа нет. Пишите и имя, и тип: `name string`.

**4. Использование параметра вне своей функции.**

```go
func main() {
    greet("Анна")
    fmt.Println(name)
}
```

Компилятор: `undefined: name`. Параметр `name` существует только внутри `greet`. Если значение нужно в `main`, объявите там свою переменную.

Как заметить самому: читайте первую строку сообщения компилятора - в ней указаны файл, строка, столбец и причина. Затем сравните объявление функции с вызовом: число, порядок и типы.

## Итоги

* Функция - именованный блок команд: `func имя(параметры) { ... }`. Объявление ничего не выполняет, команды запускает вызов.
* Параметр - имя внутри функции, аргумент - значение при вызове; число, порядок и типы должны совпадать.
* Одну функцию можно вызывать сколько угодно раз с разными значениями.
* Теперь вы можете не копировать код, а выносить повторяющееся действие в функцию.

Пока функции только печатают. В следующем уроке они научатся отдавать результат: [Возврат значений](lesson:go.first-steps.return-values).

## Для тех, кто уже программирует

* Объявление `func name(a, b int)` - тип пишется после имени; подряд идущие параметры одного типа группируются.
* Нет значений по умолчанию, именованных аргументов при вызове и перегрузки: имя функции в пакете уникально.
* Аргументы передаются по значению: функция получает копию. Срезы, карты и указатели копируют только заголовок или адрес, но об этом позже.
* Порядок объявлений на уровне пакета не важен; вложенные именованные функции запрещены (внутри функции можно объявлять только функциональные литералы).
* Видимость из других пакетов определяется регистром первой буквы имени, а не ключевым словом.
* Функции - значения первого класса, но этого урока они не касаются.
