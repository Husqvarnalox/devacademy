## Зачем это нужно

Число, текст и ответ «да/нет» хранятся по-разному и допускают разные действия: числа можно складывать, текст нельзя. Если бы компьютер не знал, что лежит в переменной, он бы не мог проверить, что вы не складываете имя с суммой. В Go у каждого значения есть **тип**, и компилятор проверяет типы до запуска.

## Одна новая идея: у значения есть тип, и он не меняется

**Тип** - вид значения: что в нём хранится и какие действия с ним допустимы. Четыре базовых типа:

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число | `42`, `-7`, `0` |
| `float64` | число с дробной частью | `12.5`, `-0.25` |
| `string` | текст | `"Чай"`, `""` |
| `bool` | логическое значение: «истина» или «ложь» | `true`, `false` |

Тип переменной задаётся при объявлении и потом не меняется. В переменную типа `int` нельзя положить текст, а в `string` - число.

Если переменную объявили **без** значения, она не остаётся пустой: в неё кладётся **нулевое значение** своего типа. Это `0` для чисел, `""` (пустая строка) для текста, `false` для `bool`.

<!-- section: examples -->
## Пример 1. Типы и значения

```go run
package main

import "fmt"

func main() {
    var title string = "Тетрадь"
    var count int = 3
    var price float64 = 49.9
    var paid bool = true
    fmt.Println(title, count, price, paid)
}
```
```output
Тетрадь 3 49.9 true
```

Полная запись: `var имя тип = значение`. Тип стоит **после** имени. Короткая форма даёт те же типы без явной записи: `count := 3` (int), `price := 49.9` (float64), `title := "Тетрадь"` (string), `paid := true` (bool). Go определяет тип по виду записанного значения.

## Пример 2. Нулевые значения

```go run
package main

import "fmt"

func main() {
    var n int
    var f float64
    var b bool
    var s string
    fmt.Println(n, f, b)
    fmt.Println("строка:", s, "конец")
}
```
```output
0 0 false
строка:  конец
```

Ни одна из четырёх переменных не получила значения, но все определены. В последней строке между словами «строка:» и «конец» два пробела: пустая строка `s` тоже значение, и Println поставил пробелы по обе стороны от него.

## Пример 3. Число 5 и число 5.0

```go run
package main

import "fmt"

func main() {
    whole := 5
    fractional := 5.0
    var price float64 = 12
    fmt.Println(whole, fractional, price)
}
```
```output
5 5 12
```

Println печатает `5.0` как `5`, но для Go это разные значения: `whole` - `int`, а `fractional` - `float64`, потому что в записи есть точка. Целое число без точки можно записать в `float64` напрямую (`var price float64 = 12`), потому что число 12 точно представимо и как дробное.

**Попробуйте.** В примере 1 замените `49.9` на `49` и посмотрите, что изменилось в выводе. Затем замените `var count int = 3` на `var count int = 3.5` и прочитайте сообщение компилятора.

## Точные правила

* Типы пишутся строчными буквами: `int`, `float64`, `string`, `bool`.
* **`int`** - целое со знаком. Его размер зависит от платформы: на современных 64-битных компьютерах это 64 бита, диапазон около ±9,2·10¹⁸. В учебных задачах этого с запасом хватает. У Go есть и другие целые типы (`int32`, `int64`, `uint8`), к ним вернёмся позже.
* **`float64`** - число с плавающей точкой двойной точности. Это приближённое представление: не все дроби хранятся точно. Используйте его для измерений и денег с оговорками, но не для подсчёта штук.
* **`string`** - текст в UTF-8; русские буквы в нём допустимы. Пустая строка `""` - допустимое значение, и она отличается от `" "` (строки из пробела).
* **`bool`** - только `true` или `false`, без чисел и текста.
* **Нулевые значения**: `0`, `0`, `""`, `false`. Они определены для любой переменной, объявленной без значения.
* **Вывод типа**: `x := 5` - `int`, `x := 5.0` - `float64`, `x := "5"` - `string`, `x := true` - `bool`. Точка в записи числа делает его дробным.
* **Строгость**: значение одного типа нельзя положить в переменную другого, даже если «по смыслу» оно подходит: `int` не превращается в `float64` автоматически. Правила преобразования - в одном из следующих уроков.
* Запись `var имя тип` объявляет с нулевым значением, `var имя тип = значение` - с заданным, `var имя = значение` и `имя := значение` определяют тип по значению.

## Типичные ошибки

**1. Дробное число в переменной `int`.**

```go
var n int = 3.5
```

Компилятор: `cannot use 3.5 (untyped float constant) as int value in variable declaration (truncated)`. В целое число дробную часть положить некуда. Решение: тип `float64` или целое значение. Как заметить: в сообщении слово `truncated` («отброшено»).

**2. Текст там, где нужно число.**

```go
var n int = "5"
```

Компилятор: `cannot use "5" (untyped string constant) as int value in variable declaration`. Кавычки превращают пятёрку в текст. Уберите кавычки. Как заметить: сообщение называет оба типа - `string` (у значения) и `int` (у переменной).

**3. Одна переменная в другую другого типа.**

```go
var f float64 = 1
var c int = 2
f = c
```

Компилятор: `cannot use c (variable of type int) as float64 value in assignment`. Хотя 2 как дробное число существует, Go не преобразует сам. Так в программе не появляется скрытых потерь точности. Нужно явное преобразование: оно в уроке 8.

**4. Число вместо bool.**

```go
var ok bool = 1
```

Компилятор: `cannot use 1 (untyped int constant) as bool value in variable declaration`. В Go ни 0, ни 1 не заменяют `false` и `true`. Пишите `true` или `false`.

<!-- section: summary -->
## Итоги

* Типы: `int` (целые), `float64` (дробные), `string` (текст), `bool` (`true`/`false`).
* Тип переменной не меняется, и компилятор следит за этим до запуска.
* Без значения переменная получает нулевое значение: `0`, `0`, `""`, `false`.
* `:=` определяет тип по значению: `5` - int, `5.0` - float64.

## Для тех, кто уже программирует

* Статическая строгая типизация: нет неявных преобразований между числовыми типами, даже `int` в `float64`. Ближе к Rust, чем к Python/JS/C.
* Нет `null` для базовых типов: у каждого типа есть нулевое значение. Переменная без инициализации безопасна.
* `string` - неизменяемая последовательность байт в UTF-8, не `char[]`.
* `bool` не приводится из чисел и строк; нет «истинности» значений.
* `int` зависит от платформы (32 или 64 бита), `float64` - IEEE 754 double.
* `x := 5.0` даёт `float64`, а `x := 5` - `int`: тип по умолчанию определяется видом литерала.
* Тип пишется после имени: `var n int`, не `int n`.

## Откуда берутся типы и нулевые значения

Необязательный раздел.

Компьютер хранит всё в виде нулей и единиц. Одна и та же последовательность битов может быть числом, буквой или признаком «да». Тип говорит компилятору, как их интерпретировать и сколько места занимает значение: `int` на 64-битной машине занимает 8 байт, `bool` - один.

Поэтому «нулевое значение» - это просто память, заполненная нулями: для `int` это число 0, для `bool` - `false`, для `string` - пустая строка. Go всегда обнуляет память при создании переменной, так что чтение «мусора» из неинициализированной переменной, как в языке C, невозможно.

Число `float64` хранится в формате IEEE 754: знак, порядок и дробная часть. Не все десятичные дроби, например 0,1, представимы в нём точно, поэтому результаты вычислений с дробными могут отличаться от ожидаемых в последних знаках.
