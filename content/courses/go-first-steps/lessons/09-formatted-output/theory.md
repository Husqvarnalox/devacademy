## Зачем это нужно

`Println` печатает значения «как есть». Для чека, таблицы или денег этого мало: нужно ровно две цифры после точки, выравнивание, знак процента. Для таких задач есть **форматированный вывод**: вы пишете шаблон строки, а программа подставляет в него значения.

## Одна новая идея: шаблон с глаголами

`fmt.Printf` принимает **шаблон** - текст, в котором стоят **глаголы** (метки вида `%d`), и после него значения. Каждый глагол заменяется очередным значением:

```go
fmt.Printf("%s купил %d шт.\n", "Анна", 3)
```

Основные глаголы:

| Глагол | Для чего |
|---|---|
| `%d` | целое число (`int`) |
| `%s` | текст (`string`) |
| `%f` | дробное число (`float64`); `%.2f` - с двумя знаками после точки |
| `%v` | любое значение в виде по умолчанию |
| `%%` | сам знак процента |

Printf **не переводит строку сам**: `\n` в конце шаблона нужно написать. `fmt.Sprintf` принимает те же аргументы, но не печатает, а **возвращает готовую строку**.

<!-- section: examples -->
## Пример 1. Деньги с двумя знаками

```go run
package main

import "fmt"

func main() {
    name := "Анна"
    count := 3
    price := 149.5
    fmt.Printf("%s купила %d шт. по %.2f руб.\n", name, count, price)
}
```
```output
Анна купила 3 шт. по 149.50 руб.
```

* Три глагола - три значения, по порядку: `%s` получает `name`, `%d` - `count`, `%.2f` - `price`.
* `149.5` превратилось в `149.50`: `%.2f` дополняет нулями и округляет, если знаков больше.
* `\n` в конце нужен, иначе следующий вывод продолжится на этой строке.

## Пример 2. Sprintf, проценты и `%v`

```go run
package main

import "fmt"

func main() {
    line := fmt.Sprintf("Скидка %d%%", 15)
    fmt.Println(line)
    fmt.Printf("%v %v %v\n", 42, "текст", true)
    fmt.Printf("%T %T %T %T\n", 5, 5.0, "a", true)
}
```
```output
Скидка 15%
42 текст true
int float64 string bool
```

* `Sprintf` собрал строку и сохранил её в переменной `line`; на экран она попала только через `Println`.
* `%%` дал один знак процента.
* `%v` подходит для любого значения.
* `%T` печатает тип значения: так можно проверить, какой тип Go выбрал для `5` и `5.0`.

## Пример 3. Ширина полей

```go run
package main

import "fmt"

func main() {
    fmt.Printf("%-8s|%5d|%8.2f|\n", "Чай", 12, 3.14159)
    fmt.Printf("%-8s|%5d|%8.2f|\n", "Кофе", 7, 250.0)
}
```
```output
Чай     |   12|    3.14|
Кофе    |    7|  250.00|
```

Число после `%` - минимальная ширина поля. `%5d` выравнивает число вправо, `%-8s` (с минусом) прижимает текст влево, `%8.2f` задаёт ширину 8 и два знака после точки. Так получаются ровные столбцы.

**Попробуйте.** Измените `%8.2f` на `%.1f` и предскажите вывод. Затем в примере 1 уберите `\n` и добавьте после Printf ещё один `Println("!")`.

<!-- section: precise -->
## Точные правила

* Глагол должен соответствовать типу: `%d` - целые, `%s` - текст, `%f` - дробные, `%t` - `bool`, `%v` - любые, `%q` - текст в кавычках, `%T` - название типа.
* **Число знаков**: `%.2f` - два знака после точки. Без числа `%f` печатает шесть знаков. Округляется до ближайшего.
* **Ширина и выравнивание**: `%5d` - минимум пять позиций, по правому краю; `%-5d` - по левому; `%05d` - дополнить нулями слева (`00042`); `%8.2f` - ширина 8, два знака.
* **Количество значений** должно совпадать с количеством глаголов.
* Знак процента в шаблоне пишут как `%%`.
* **Десятичный разделитель** всегда точка, независимо от региона компьютера.
* **Printf** не добавляет перевод строки и не расставляет пробелы между значениями: всё, что нужно, вы пишете в шаблоне. **Println** шаблонов не понимает.
* **Sprintf** возвращает строку. Результат можно сохранить в переменную, напечатать позже или использовать как часть другого сообщения.
* Ошибки в шаблоне не останавливают сборку: компилятор о них молчит, и вместо значения в тексте появляется пометка (`%!d(float64=2.5)`). Инструмент `go vet` умеет такие места находить.

<!-- section: mistakes -->
## Типичные ошибки

**1. Забыли `\n` в Printf.**

```go
fmt.Printf("Итого: %d", 5)
fmt.Printf("Спасибо")
```

Вывод: `Итого: 5Спасибо`. Printf не переводит строку. Допишите `\n` в конец шаблона. Как заметить: две строки слиплись.

**2. Глагол не соответствует типу.**

```go
fmt.Printf("%d шт.\n", 2.5)
```

Вывод: `%!d(float64=2.5) шт.`. Программа собралась, но вместо числа в тексте появилась пометка: `%d` ждёт `int`, а пришло `float64`. Используйте `%f`/`%.1f` для дробных или `%v`, если тип не важен. Как заметить: в выводе есть `%!` - всегда признак ошибки в шаблоне. Похожая пометка для текста вместо числа: `%!s(int=5)`.

**3. Число значений не совпадает с числом глаголов.**

```go
fmt.Printf("%d %d\n", 1)
fmt.Printf("%d\n", 1, 2)
```

Первая команда: `1 %!d(MISSING)` - значения не хватило. Вторая: `1` и затем `%!(EXTRA int=2)` - значение лишнее. Сравните количество глаголов и аргументов.

**4. Шаблон в Println.**

```go
fmt.Println("%d шт.", 5)
```

Вывод: `%d шт. 5`. Println не разбирает глаголы, а печатает оба значения через пробел. Если нужен шаблон, используйте Printf.

<!-- section: summary -->
## Итоги

* `fmt.Printf(шаблон, значения...)` подставляет значения вместо глаголов; перевод строки пишем сами.
* `%d` - int, `%s` - string, `%.2f` - float64 с двумя знаками, `%v` - любое значение, `%%` - процент.
* Ширина (`%5d`, `%-8s`, `%8.2f`) выравнивает столбцы.
* `fmt.Sprintf` возвращает строку вместо печати.
* Пометки `%!` в выводе означают ошибку в шаблоне.

## Для тех, кто уже программирует

* `Printf` аналогичен `printf` из C, но безопаснее: ошибки типов не приводят к неопределённому поведению, а печатают `%!d(...)`. Компилятор их не ловит, зато `go vet` ловит.
* `%v` - универсальный формат (аналог `{}` в Rust/Python). `%+v` и `%#v` дают расширенный вывод структур, их увидим позже.
* `Sprintf` - аналог `String.format`/`f"..."`; интерполяции строк `"${x}"` в языке нет.
* Округление `%.2f` не банковское, а по двоичному представлению числа: `2.675` может напечататься как `2.67`.
* `Println` не форматирует; нет аргументов `sep`/`end` из Python.
* `%T` показывает динамический тип - удобно при отладке.
