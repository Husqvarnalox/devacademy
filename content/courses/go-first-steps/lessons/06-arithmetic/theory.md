## Зачем это нужно

Программа почти всегда что-то вычисляет: итог чека, время в пути, остаток после деления. Вычисления записываются почти так же, как на бумаге, но у них есть важные особенности, которые приводят к неожиданным результатам, если их не знать.

## Одна новая идея: оператор действует так, как предписывает тип

**Арифметика** - вычисления с числами. Знаки действий (**операторы**):

| Оператор | Действие |
|---|---|
| `+` | сложение |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `%` | остаток от деления |

Главная особенность: `/` зависит от типа. Если делятся два целых (`int`), результат тоже целый, а дробная часть **отбрасывается**. Это **целочисленное деление**. Остаток от него даёт оператор `%`.

Например, 7 делится на 2 как «3 целых и остаток 1»: `7 / 2` равно `3`, а `7 % 2` равно `1`. Если же делится `float64`, то дробная часть сохраняется: `7.0 / 2.0` равно `3.5`.

<!-- section: examples -->
## Пример 1. Пять действий

```go run
package main

import "fmt"

func main() {
    a := 17
    b := 5
    fmt.Println(a+b, a-b, a*b)
    fmt.Println(a/b, a%b)
}
```
```output
22 12 85
3 2
```

* Первая строка вывода - сумма, разность и произведение.
* `17 / 5` дало `3`: в 17 помещается три полные пятёрки. Остаток `17 % 5` равен `2`, потому что 17 = 3·5 + 2.

## Пример 2. Деление целых и дробных

```go run
package main

import "fmt"

func main() {
    x := 7.0
    y := 2.0
    fmt.Println(x / y)
    m := 7
    n := 2
    fmt.Println(m / n)
}
```
```output
3.5
3
```

`7.0` с точкой - число типа `float64`, `7` без точки - `int`. Знак `/` один и тот же, а результат разный. Поэтому при делении проверяйте, какого типа ваши числа.

## Пример 3. Приоритет и сокращения

```go run
package main

import "fmt"

func main() {
    fmt.Println(2 + 3*4)
    fmt.Println((2 + 3) * 4)
    fmt.Println(10 - 4 - 3)
    fmt.Println(-7/2, -7%2)
    count := 5
    count += 2
    count++
    fmt.Println(count)
}
```
```output
14
20
3
-3 -1
8
```

* `*` и `/` выполняются раньше `+` и `-`; скобки меняют порядок.
* Одинаковые по приоритету действия выполняются слева направо: `10 - 4 - 3` - это `(10 - 4) - 3`.
* `-7 / 2` равно `-3`: дробная часть отбрасывается в сторону нуля. Остаток при этом `-1` (знак остатка совпадает со знаком делимого).
* `count += 2` - сокращение для `count = count + 2`; `count++` - прибавить единицу. Это только удобная запись, новых возможностей она не добавляет.

**Попробуйте.** Предскажите `Println(20/6, 20%6)` и `Println(20.0/6)` и запустите. Затем сравните: `1/2` и `1.0/2`.

## Точные правила

* **Приоритет**: сначала `*`, `/`, `%`, затем `+`, `-`. Равные по приоритету выполняются слева направо. Скобки всегда первыми.
* **Типы**: оба операнда (числа, с которыми работает оператор) должны быть одного типа. `int + int` - `int`, `float64 + float64` - `float64`; смешивать нельзя, пока явно не преобразовать значения.
* **Целочисленное деление** отбрасывает дробную часть **в сторону нуля**: `7 / 2 = 3`, `-7 / 2 = -3`.
* **Остаток** `%` определён только для целых чисел. Связь с делением: `a == (a/b)*b + a%b`. Для положительных чисел остаток лежит от `0` до `b-1`. Типичные применения: чётность (`n % 2`), последние цифры (`n % 10`), перевод единиц (минуты в часы).
* **Деление на нуль**: целых на литерал `0` - ошибка компиляции; на переменную, равную нулю - ошибка при запуске (паника `integer divide by zero`). Деление дробных на ноль даёт специальное значение «бесконечность» без ошибки.
* **Результат выражения** можно присвоить переменной или напечатать сразу.
* **Сокращения**: `x += n`, `x -= n`, `x *= n`, `x /= n`, `x %= n`, `x++`, `x--`. `x++` - отдельная команда, а не выражение: `y := x++` запрещено.
* **Точность**: для `float64` результат вычислений приближённый (`0.1 + 0.2` может не быть ровно `0.3`).

## Типичные ошибки

**1. Ожидали дробный результат от деления целых.**

```go
a := 7
b := 2
fmt.Println(a / b)
```

Вывод: `3`, а ожидалось `3.5`. Оба числа `int`, поэтому и результат `int`. Чтобы получить `3.5`, нужны дробные числа (`7.0 / 2.0`) или преобразование типа, о нём - следующие уроки. Как заметить: перед делением спросите себя, какого типа оба числа.

**2. Смешали `int` и `float64`.**

```go
a := 3
b := 2.5
fmt.Println(a * b)
```

Компилятор: `invalid operation: a * b (mismatched types int and float64)`. Оператор требует один тип с обеих сторон. Сделайте обе переменные одного типа (`a := 3.0`) либо преобразуйте значения (урок про преобразования).

**3. `%` с дробными.**

```go
x := 7.5
fmt.Println(x % 2)
```

Компилятор: `invalid operation: operator % not defined on x (variable of type float64)`. Остаток определён только для целых.

**4. Деление на ноль.**

```go
fmt.Println(5 / 0)
```

Компилятор: `invalid operation: division by zero`. Если делитель записан в переменной (`b := 0; fmt.Println(a / b)`), программа соберётся, но при запуске остановится с сообщением `panic: runtime error: integer divide by zero`. Паника - аварийная остановка. Перед делением на значение, которое может быть нулём, его нужно проверять (условия - в одном из следующих уроков).

<!-- section: summary -->
## Итоги

* `+ - * / %` работают с числами одного типа; `*`, `/`, `%` выполняются раньше `+`, `-`.
* Деление `int` на `int` целое: `7 / 2` равно `3`, остаток даёт `%`.
* Деление `float64` сохраняет дробную часть.
* Деление на ноль - ошибка компиляции (для литерала) или паника при запуске.

Теперь у вас есть всё, чтобы вычислять. Чтобы работать с чужими данными, а не с числами, записанными в программе, нужен ввод: [Чтение ввода](lesson:go.first-steps.reading-input).

## Для тех, кто уже программирует

* `/` для целых - целочисленное деление, как в Java, C, C#; в Python 3 это `//`. Для дробного результата нужно привести к `float64`.
* Деление округляет к нулю (`-7/2 == -3`), как в Java/C, а не к минус бесконечности, как в Python (`-7//2 == -4`). Знак `%` совпадает со знаком делимого.
* `int + float64` не компилируется: нет неявного расширения, как в C/Java/JS.
* Оператора возведения в степень нет (`math.Pow` из пакета `math`).
* `x++` и `x--` - инструкции, не выражения: нет `y = x++` и префиксных `++x`.
* Переполнения целых при арифметике происходят молча (оборачиваются), деление целых на нуль - паника.
