## Зачем это нужно

Представьте формулу `price * 1.2` в десяти местах программы. Когда ставка изменится, придётся найти и исправить десять мест, и где-то вы ошибётесь. А читатель кода не поймёт, что такое `1.2`. Число, смысл которого не ясен из записи, называют **магическим числом**, и его лучше заменить именем.

Второй вопрос - как оставить в коде пояснение для людей, которое компьютер не будет выполнять.

## Одна новая идея: имя для неизменного значения

**Константа** - имя для значения, которое известно заранее и не меняется. Объявляется словом `const`:

```go
const vatRate = 0.2
```

После этого везде вместо `0.2` пишут `vatRate`. Изменить значение можно только в одном месте, в объявлении; присвоить новое значение константе в ходе программы нельзя.

**Комментарий** - текст в программе для человека; компилятор его игнорирует. Однострочный комментарий начинается с `//` и продолжается до конца строки.

<!-- section: examples -->
## Пример 1. Константа в расчёте

```go run
package main

import "fmt"

func main() {
    // Ставка налога: 20 процентов
    const taxRate = 0.2
    price := 250.0
    fmt.Printf("С НДС: %.2f\n", price*(1+taxRate))
    fmt.Printf("Налог: %.2f\n", price*taxRate)
}
```
```output
С НДС: 300.00
Налог: 50.00
```

* Строка с `//` объясняет, откуда ставка. Комментарий не меняет поведение программы.
* `const taxRate = 0.2` объявлено один раз и используется дважды. Чтобы изменить ставку, достаточно поправить одну строку.
* Имя `taxRate` говорит больше, чем `0.2`: читатель видит смысл числа.

## Пример 2. Несколько констант и многострочный комментарий

```go run
package main

import "fmt"

func main() {
    /* Размер коробки в сантиметрах.
       Площадь считаем для одной стороны. */
    const (
        width  = 20
        height = 30
    )
    area := width * height // 600 квадратных сантиметров
    fmt.Println(area)
}
```
```output
600
```

* Круглые скобки после `const` собирают несколько констант в группу.
* Комментарий `/* ... */` может занимать несколько строк.
* Комментарий в конце строки после `//` тоже допустим.

**Попробуйте.** В примере 1 замените `0.2` на `0.25` и сравните результат. Затем попробуйте добавить строку `taxRate = 0.3` и прочитайте сообщение компилятора.

## Точные правила

**Константы**

* Запись: `const имя = значение` или с типом `const имя тип = значение`. Знак `:=` для констант не используется.
* Значение должно быть вычислено при компиляции: число, текст, `true`/`false` или выражение из таких значений и других констант. Значение, прочитанное из ввода или полученное от переменной, константой стать не может.
* Константу, как и переменную, можно объявить внутри функции и вне функций (на уровне пакета).
* Неиспользованная константа не вызывает ошибки, в отличие от переменной.
* Константа без явного типа подстраивается под контекст: `taxRate` из примера 1 свободно умножается на `float64`.

**Комментарии**

* `// ...` до конца строки. `/* ... */` - многострочный; вложенные комментарии не поддерживаются.
* Хороший комментарий объясняет **зачем**, а не пересказывает код: `// ставка НДС с 2019 года` полезнее, чем `// константа`.
* Закомментированный код легко временно отключить, но не оставляйте его надолго.

**Имена**

* Имя описывает смысл: `totalPrice`, `itemCount`, а не `x1` и `tmp`. Для очень коротких действий допустимы короткие имена вроде `i` (позже, в циклах).
* Имена из нескольких слов пишут «верблюдом»: `vatRate`, `maxItems`. Подчёркивания в именах Go не принято использовать.
* Имя не может начинаться с цифры и совпадать с ключевым словом.
* Имя с заглавной буквы (`VatRate`) означает «доступно из других пакетов»; пока пишите имена со строчной.

## Типичные ошибки

**1. Присваивание константе.**

```go
const rate = 0.2
rate = 0.3
```

Компилятор: `cannot assign to rate (neither addressable nor a map index expression)`. Константа не меняется. Если значение должно меняться - это переменная. Как заметить: ошибка указывает на строку с `=` и имя константы.

**2. `:=` в объявлении константы.**

```go
const rate := 0.2
```

Компилятор: `syntax error: unexpected :=, expected =`. Для констант пишется простой знак `=`.

**3. Константа из значения переменной.**

```go
n := 5
const m = n * 2
```

Компилятор: `n * 2 (value of type int) is not constant`. Значение должно быть известно ещё до запуска, а `n` - переменная. Замените `const` на `m := n * 2`.

**4. Комментарий не закрыт.**

```go
/* пояснение
fmt.Println("a")
```

Компилятор: `comment not terminated`. Многострочный комментарий дошёл до конца файла, и весь последующий код оказался внутри него. Как заметить: часть кода в редакторе подсвечена как комментарий, и появляются дополнительные ошибки (например, о неиспользуемом `fmt`).

## Итоги

* `const имя = значение` задаёт неизменное значение с понятным именем; присвоить новое нельзя.
* Магические числа лучше заменять константами.
* `//` и `/* */` - комментарии для людей; пишите в них причину, а не пересказ кода.
* Имена должны отражать смысл и записываться «верблюдом».

На этом закончен блок базового синтаксиса: вы умеете хранить, вычислять, читать и печатать. Следующий блок учит программу принимать решения, и начинается он со сравнений: [Сравнения и логика](lesson:go.first-steps.comparison-and-logic).

## Для тех, кто уже программирует

* `const` вычисляется при компиляции; нельзя положить в const результат вызова функции или значение из переменной (в отличие от `final` в Java или `const` в JS).
* Константы без типа («untyped») ведут себя гибко: `const big = 1 << 40` умещается в `float64` и в `int64`, но не в `int32`.
* Нет `enum`: вместо него группа констант с `iota` (будет позже).
* Неиспользуемая константа - не ошибка, в отличие от неиспользуемой переменной.
* Комментарии `//` и `/* */`, как в C. Комментарии перед объявлением (doc comments) используются инструментом `go doc`.
* Стиль: `camelCase`, а не `snake_case`; заглавная буква - экспорт.
