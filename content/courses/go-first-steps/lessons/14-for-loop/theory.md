## Зачем это нужно

Напечатать числа от 1 до 5 можно пятью командами, а от 1 до 1000 - нельзя. Любая обработка множества данных (все товары в чеке, все оценки группы, все секунды таймера) требует повторять одно и то же действие. Для повторения есть **цикл**.

## Одна новая идея: цикл for со счётчиком

```go
for начало; условие; шаг {
    // тело цикла
}
```

Три части в заголовке:

* **начало** выполняется один раз перед циклом: обычно объявляет счётчик (`i := 1`);
* **условие** проверяется перед каждым повторением: пока оно истинно, тело выполняется;
* **шаг** выполняется после каждого повторения: обычно меняет счётчик (`i++`, то есть «прибавить 1»).

Одно выполнение тела цикла называют **итерацией**. Когда условие становится ложным, цикл заканчивается, и программа идёт дальше.

<!-- section: examples -->
## Пример 1. Счёт от 1 до 5

```go run
package main

import "fmt"

func main() {
    for i := 1; i <= 5; i++ {
        fmt.Println(i)
    }
}
```
```output
1
2
3
4
5
```

Что происходит по шагам:

1. `i := 1` - создаётся счётчик.
2. Проверка `i <= 5`: истинно, тело печатает 1.
3. `i++` - счётчик становится 2. Проверка снова, печать, шаг.
4. После пятого повторения `i` становится 6, условие `6 <= 5` ложно, цикл закончился.

## Пример 2. Накопление суммы

```go run
package main

import "fmt"

func main() {
    sum := 0
    for i := 1; i <= 4; i++ {
        sum += i
        fmt.Println("i =", i, "сумма =", sum)
    }
    fmt.Println("Итого:", sum)
}
```
```output
i = 1 сумма = 1
i = 2 сумма = 3
i = 3 сумма = 6
i = 4 сумма = 10
Итого: 10
```

`sum` объявлена **до** цикла и живёт после него. Если объявить её внутри тела, она обнулялась бы на каждом повторении и не была бы видна после цикла.

## Пример 3. Другой шаг и обратный счёт

```go run
package main

import "fmt"

func main() {
    for i := 10; i > 0; i -= 3 {
        fmt.Print(i, " ")
    }
    fmt.Println()
}
```
```output
10 7 4 1 
```

Шаг может быть любым: здесь счётчик уменьшается на 3. В конце строки остался пробел, потому что `Print(i, " ")` печатает его после каждого числа; позже вы научитесь его избегать.

**Попробуйте.** Измените в примере 1 условие на `i < 5` и предскажите вывод. Затем пусть цикл печатает только чётные числа от 2 до 10: подумайте, что нужно поменять в начале и в шаге.

## Точные правила

* Запись: `for i := 0; i < n; i++ { ... }`. Круглых скобок нет, фигурные обязательны.
* Порядок выполнения: начало один раз, затем повторяется «проверка условия - тело - шаг». Если условие ложно с самого начала, тело не выполнится ни разу.
* **Счётчик** `i` существует только внутри цикла. После `}` обращаться к нему нельзя: `undefined: i`.
* **Число повторений** для `for i := a; i < b; i++` равно `b - a` (при `b > a`); для `i <= b` оно на единицу больше.
* **`i++`** - сокращение для `i = i + 1`, `i--` - для `i = i - 1`, `i += 2` - для `i = i + 2`.
* **Накопление**: переменная, в которую собирается итог (сумма, количество), объявляется до цикла и меняется в теле.
* **Бесконечный цикл**: если условие всегда истинно (забыли шаг, шаг идёт не в ту сторону), программа не завершится. В приложении выполнение остановится по ограничению времени.
* Начало и шаг можно пропускать, оставив условие (`for i < 10 {`): это тема следующего урока.
* **Имена счётчиков**: `i`, `j`, `k` - общепринятые для коротких циклов.

## Типичные ошибки

**1. Ошибка на единицу (off-by-one).**

```go
for i := 1; i < n; i++ {
    sum += i
}
```

Ошибки компиляции нет, но для `n = 5` суммируются числа 1-4, и итог 10 вместо 15. Условие `i < n` не включает `n`. Нужно `i <= n`. Как заметить: на небольших числах (n = 1, 2, 3) подсчитайте вручную число повторений и сравните с ожидаемым.

**2. Забыли шаг.**

```go
for i := 1; i <= 5; {
    fmt.Println(i)
}
```

Счётчик не меняется, условие всегда истинно, и программа печатает единицы без конца. В приложении выполнение завершится по таймауту. Добавьте `i++`. Как заметить: вывод не прекращается или программа «зависла».

**3. Использование счётчика после цикла.**

```go
for i := 1; i <= 3; i++ {
}
fmt.Println(i)
```

Компилятор: `undefined: i`. Счётчик живёт только внутри `for`. Если значение нужно после цикла, объявите переменную раньше и меняйте её в цикле.

**4. Накопитель внутри цикла.**

```go
for i := 1; i <= 3; i++ {
    sum := 0
    sum += i
}
fmt.Println(sum)
```

Компилятор: `undefined: sum`. Переменная объявлена внутри тела и недоступна снаружи; кроме того, она создаётся заново на каждом повторении. Объявите `sum := 0` перед `for`.

<!-- section: summary -->
## Итоги

* `for начало; условие; шаг { ... }` повторяет тело, пока условие истинно.
* Счётчик живёт только внутри цикла; итоги накапливают в переменной, объявленной до цикла.
* `i < n` и `i <= n` отличаются на одно повторение - проверяйте границы на малых значениях.
* Забытый шаг или неверное условие дают бесконечный цикл.

Теперь вы можете повторять действие известное число раз. Часто число повторений заранее неизвестно: это тема следующего урока - [Циклы с условием и управление ими](lesson:go.first-steps.loop-control).

## Для тех, кто уже программирует

* В Go единственное ключевое слово цикла - `for`. Нет `while` и `do ... while`; их роль играют разные формы `for`.
* Скобок вокруг заголовка нет, фигурные скобки обязательны.
* `i++` и `i--` - операторы-инструкции, не выражения: `a[i++]` недопустимо.
* Счётчик, объявленный в заголовке, виден только в цикле. С Go 1.22 для каждой итерации создаётся своя копия счётчика (важно при замыканиях и горутинах).
* Цикл по диапазону (`for ... range`) будет в уроках про коллекции.
* Нет оператора запятая, поэтому два счётчика ведут через `i, j := 0, n`.
