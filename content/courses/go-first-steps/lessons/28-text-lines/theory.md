## Зачем это нужно

Реальные данные чаще устроены строками: одна запись - одна строка. Это ведомость (имя и оценки), журнал покупок (товар и цена), файл настроек. Чтение по словам через `Scan` теряет границы строк, а нам нужно знать, где кончается одна запись. Для этого строки читают целиком и потом разбирают.

## Одна новая идея: Scanner отдаёт ввод по строкам, а Fields разбивает строку на слова

```go
sc := bufio.NewScanner(os.Stdin)
for sc.Scan() {
    line := sc.Text()   // очередная строка без перевода строки
    // ...
}
```

* `bufio.NewScanner(os.Stdin)` создаёт сканер строк;
* `sc.Scan()` пытается прочитать следующую строку и возвращает `true`, если она есть, и `false`, когда ввод закончился - поэтому им удобно управлять циклом;
* `sc.Text()` возвращает прочитанную строку.

Чтобы разобрать строку, используют `strings.Fields(line)`: она делит по любым пробелам и возвращает срез слов; лишние пробелы и пустые части отбрасываются. Числа получают из слов через `strconv.Atoi`.

<!-- section: examples -->
## Пример 1. Разбиение строки на слова

```go run
package main

import (
    "fmt"
    "strings"
)

func main() {
    parts := strings.Fields("  Анна   5  4 \t 5 ")
    fmt.Println(len(parts))
    fmt.Println(parts[0], parts[1])
    fmt.Println(len(strings.Fields("   ")))
}
```
```output
4
Анна 5
0
```

Лишние пробелы и табуляция не создают пустых слов. Строка из одних пробелов даёт пустой срез, поэтому прежде чем обращаться к `parts[0]`, проверяют `len(parts)`.

## Пример 2. Эхо строк с номерами

```go
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    sc := bufio.NewScanner(os.Stdin)
    n := 0
    for sc.Scan() {
        n++
        fmt.Println(n, sc.Text())
    }
}
```

Для ввода из строк `привет` и `мир` программа напечатает:

```text
1 привет
2 мир
```

Цикл `for sc.Scan()` завершается сам, когда строки кончаются; `break` и проверка ошибки не нужны. Пробелы внутри строки сохраняются: `Text` возвращает её целиком.

## Пример 3. Разбор записей «товар цена»

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    sc := bufio.NewScanner(os.Stdin)
    total := 0
    for sc.Scan() {
        fields := strings.Fields(sc.Text())
        if len(fields) == 0 {
            continue
        }
        price, err := strconv.Atoi(fields[1])
        if err != nil {
            continue
        }
        total += price
    }
    fmt.Println(total)
}
```

Для строк `чай 120`, `кофе 200` и пустой строки между ними программа напечатает `320`. Пустая строка пропускается через `continue`, а запись, в которой цена не число, тоже: `Atoi` вернула ошибку. (Строка из одного слова вызвала бы панику на `fields[1]`; как защищаться от неё, вы увидите в мини-проекте.)

**Попробуйте.** В примере 1 замените строку на `"a,b c"` и предскажите число слов. Затем в примере 2 напечатайте длину каждой строки через `len(sc.Text())`.

## Точные правила

* **Цикл чтения**: `for sc.Scan() { ... }`. `Scan` возвращает `false` в конце ввода (или при ошибке чтения).
* **`sc.Text()`** возвращает текущую строку без символа перевода строки (и без `\r` в конце, если ввод в формате Windows). Последняя строка читается, даже если после неё нет перевода строки.
* **Пустые строки** тоже приходят в цикл: `Text()` возвращает `""`.
* **`strings.Fields(s)`** делит по пробелам, табуляциям и переводам строк; пустые части не создаёт. Для пустой строки или строки из пробелов результат - пустой срез.
* **Проверяйте длину** `fields` перед обращением по индексу: `fields[0]` на пустом срезе - паника.
* **`strconv.Atoi(слово)`** возвращает `(int, error)`; при ошибке слово не число.
* **`continue`** пропускает остаток тела цикла и переходит к следующей строке: удобный способ отбросить пустую или плохую запись.
* **Размер строки**: Scanner по умолчанию принимает строки до 64 КБ; для очень длинных строк буфер увеличивают отдельной настройкой.
* **Не смешивайте** чтение через `Scanner` и через `Scan`/`Fscan` из одного ввода: каждый из них забирает данные себе, часть текста потеряется.
* **Сканер читает строки, а не слова**: имя и оценки на одной строке приходят вместе, и их разделяет `Fields`.

## Типичные ошибки

**1. Путаница `Scan()` и `Text()`.**

```go
line := sc.Scan()
fmt.Println(strings.Fields(line))
```

Компилятор: `cannot use line (variable of type bool) as string value in argument to strings.Fields`. `Scan()` возвращает `bool` (есть ли строка), а сам текст возвращает `Text()`.

**2. Обращение к слову пустой строки.**

```go
for sc.Scan() {
    f := strings.Fields(sc.Text())
    fmt.Println(f[0])
}
```

Если во вводе есть пустая строка, при запуске:

```text
panic: runtime error: index out of range [0] with length 0
```

Добавьте `if len(f) == 0 { continue }`.

**3. Нет пропуска плохой записи.** Если слово оценки не число, `strconv.Atoi` вернёт `0` и ошибку; без проверки `err` в сумму молча попадёт ноль. Проверяйте ошибку или явно отбрасывайте запись.

**4. Деление на ноль или на неверное число записей.** Среднее `sum / count` при `count == 0` для `int` вызывает панику, а для `float64` даёт `NaN`. Считайте число слов (`len(fields)-1`) и проверяйте, что оно больше нуля, если ввод не гарантирован.

**5. Смешение способов чтения.** Если сначала прочитать число через `fmt.Scan`, а затем строки через `Scanner`, первая строка может оказаться потерянной. Выберите один способ на всю программу.

Как заметить самому: прогоните программу на вводе с пустой строкой в середине, с лишними пробелами и без перевода строки в конце.

<!-- section: summary -->
## Итоги

* `bufio.NewScanner(os.Stdin)` и `for sc.Scan() { sc.Text() }` читают ввод построчно до конца.
* `strings.Fields` делит строку на слова, игнорируя лишние пробелы; для пустой строки возвращает пустой срез.
* Слова превращают в числа через `strconv.Atoi`; ошибку проверяют.
* `continue` пропускает пустые или неподходящие записи.

## Для тех, кто уже программирует

* `bufio.Scanner` читает токены; по умолчанию - строки (`ScanLines`), есть `ScanWords` и `ScanRunes`. Размер токена ограничен 64 КБ, больше задают через `sc.Buffer`.
* `sc.Scan()` возвращает `false` и при EOF, и при ошибке; ошибку читают через `sc.Err()` после цикла (в этих задачах опускаем).
* `strings.Fields` - аналог `str.split()` без аргументов (делит по пробелам, игнорирует пустые части), `strings.Split` делит по явному разделителю и пустые части сохраняет.
* `Text()` создаёт строку-копию, `Bytes()` возвращает срез на внутренний буфер, годный только до следующего `Scan`.
* Не смешивайте разные читатели одного `os.Stdin`: буферизованный читатель забирает данные вперёд.
* `\r\n` из Windows сканер отрезает сам.
