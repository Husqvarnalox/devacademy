## Зачем это нужно

До сих пор программа выполняла все команды подряд. Реальные задачи требуют выбора: если на счёте хватает денег, списать; иначе - показать ошибку; если сумма большая - применить скидку. Для выбора используется **условный оператор**.

## Одна новая идея: команды выполняются, только если условие истинно

```go
if условие {
    // эти команды выполняются, если условие истинно
} else {
    // эти команды выполняются, если условие ложно
}
```

**Условие** - выражение типа `bool` (сравнение, логическое выражение, переменная `bool`). Если оно `true`, выполняется блок после `if`. Если `false` - блок после `else`, если он есть. Ветка `else` необязательна.

Когда вариантов больше двух, между `if` и `else` добавляют `else if` - следующее условие, которое проверяется, только если предыдущие были ложными.

<!-- section: examples -->
## Пример 1. if без else

```go run
package main

import "fmt"

func main() {
    temperature := -5
    if temperature < 0 {
        fmt.Println("Мороз")
    }
    fmt.Println("Конец")
}
```
```output
Мороз
Конец
```

Условие `-5 < 0` истинно, блок выполнился. Команда после закрывающей скобки выполняется в любом случае. При `temperature := 5` вывод был бы только «Конец».

## Пример 2. if и else

```go run
package main

import "fmt"

func main() {
    n := 7
    if n%2 == 0 {
        fmt.Println(n, "чётное")
    } else {
        fmt.Println(n, "нечётное")
    }
}
```
```output
7 нечётное
```

Выполняется ровно одна из двух веток. Слово `else` стоит на той же строке, что и закрывающая скобка предыдущего блока.

## Пример 3. Цепочка else if

```go run
package main

import "fmt"

func main() {
    total := 1500
    discount := 0
    if total >= 5000 {
        discount = 10
    } else if total >= 1000 {
        discount = 5
    }
    fmt.Printf("Скидка: %d%%\n", discount)
}
```
```output
Скидка: 5%
```

Проверки идут сверху вниз. Для `total = 1500` первое условие ложно, второе истинно: `discount` становится 5. Третьей ветки нет, поэтому при `total < 1000` скидка останется нулём, заданным заранее.

**Попробуйте.** Поставьте `total := 6000` и затем `total := 999` и предскажите результат. Потом поменяйте две проверки местами и посмотрите, что произойдёт при `6000`.

## Точные правила

* **Синтаксис**: `if условие { ... }`. Круглые скобки вокруг условия не нужны, фигурные обязательны даже для одной команды.
* **Условие** обязано быть типа `bool`. `if x {` при числовом `x` - ошибка `non-boolean condition in if statement`.
* **`else`** пишется на той же строке, что и `}`: `} else {`. Перенос на новую строку - синтаксическая ошибка.
* **Цепочка** `if ... else if ... else ...`: проверяется сверху вниз, выполняется первая подходящая ветка, остальные пропускаются. Последняя ветка `else` ловит всё, что не подошло.
* **Порядок проверок важен**. Для порогов проверяйте сначала самый строгий: `>= 90`, потом `>= 75`.
* **Вложенность**: `if` можно помещать внутрь другого `if`. Это допустимо, но много уровней затрудняют чтение; часто их заменяют `&&` и `else if`.
* **Область видимости**: переменная, объявленная внутри блока `{ ... }`, существует только в нём.
* Присваивание в условии (`if x = 5`) недопустимо: Go отвергает такую запись, защищая от замены `==` на `=`.

## Типичные ошибки

**1. Фигурная скобка на новой строке.**

```go
if x > 3
{
    fmt.Println("a")
}
```

Компилятор: `syntax error: unexpected newline, expected { after if clause`. Открывающая `{` должна быть на строке с `if`.

**2. `else` на новой строке.**

```go
if x > 3 {
    fmt.Println("a")
}
else {
    fmt.Println("b")
}
```

Компилятор: `syntax error: unexpected keyword else, expected }`. Перевод строки после `}` завершает команду, поэтому `else` оказывается «ничьим». Пишите `} else {`.

**3. Условие не `bool`.**

```go
x := 5
if x {
}
```

Компилятор: `non-boolean condition in if statement`. Сравните значение явно: `if x != 0 {`. А запись `if x = 5 {` даст `syntax error: cannot use assignment x = 5 as value` - нужно `==`.

**4. Неправильный порядок проверок.**

```go
if score >= 60 {
    fmt.Println("Оценка: 3")
} else if score >= 90 {
    fmt.Println("Оценка: 5")
}
```

Ошибки компиляции нет, но для `95` напечатается `Оценка: 3`: первое условие истинно, вторая проверка недостижима. Как заметить: проверьте граничные и крайние значения (`95`, `60`, `59`) и сверьте с ожидаемым ответом. Исправление: сначала более строгие пороги.

<!-- section: summary -->
## Итоги

* `if условие { ... }` выполняет блок при истинном условии; `else` - при ложном.
* `else if` добавляет проверки; срабатывает первая подходящая ветка.
* Условие - только `bool`; скобки вокруг него не нужны, фигурные скобки обязательны, `else` стоит рядом с `}`.
* В цепочках сначала проверяйте самые строгие условия.

Когда нужно сравнить одно значение с набором вариантов, цепочка `else if` становится громоздкой. В этом случае удобнее другая конструкция: [switch](lesson:go.first-steps.switch).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Скобок вокруг условия нет, а фигурные обязательны (однострочный `if cond stmt;` невозможен).
* Условие строго `bool`: нет «истинных» чисел, строк и указателей, как в Python/JS/C.
* Тернарного оператора нет: вместо `x ? a : b` пишут `if`.
* `else` должен стоять на одной строке с `}`: это следствие автоматической вставки точки с запятой.
* В Go есть `if` с коротким оператором перед условием (`if v := f(); v > 0 {`), его разберём позже.
* Присваивание не выражение, поэтому `if (x = 5)` из C невозможно.
