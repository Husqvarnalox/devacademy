## Go: компиляция в один исполняемый файл

Go - **компилируемый** язык. Команда `go build` переводит исходный код в машинный код вашего процессора и компонует результат в один исполняемый файл. Для запуска такого файла не нужен ни интерпретатор, ни виртуальная машина: рантайм Go (планировщик горутин, сборщик мусора) встроен в сам файл.

Приложение делает именно это: `go build -o prog main.go`, а затем запускает `./prog` и подаёт ему ввод в stdin.

Минимальная программа:

```go
package main

import "fmt"

func main() {
    fmt.Println("привет")
}
```

* `package main` - пакет, из которого собирается исполняемая программа;
* `func main()` - точка входа;
* `import "fmt"` - подключение пакета стандартной библиотеки. Неиспользуемый импорт - **ошибка компиляции**, как и неиспользуемая локальная переменная.

Ввод: `fmt.Scan(&n)` читает значения, разделённые пробелами и переводами строк. Вывод: `fmt.Println`, `fmt.Printf`.

## Подробнее

**Сборка.** `go build` разбирает пакеты, проверяет типы, компилирует каждый пакет в объектный код и компонует. Ошибки типов обнаруживаются на этом этапе, до запуска. `go run main.go` собирает во временную папку и запускает; `go vet` ищет подозрительные конструкции.

**Рантайм внутри файла.** Программа на Go содержит планировщик горутин, сборщик мусора и аллокатор. Поэтому даже короткая программа - это файл в несколько мегабайт, зато его можно просто скопировать на другую машину той же ОС и архитектуры. Для другой платформы собирают с переменными `GOOS` и `GOARCH`.

**Типы.** `int` зависит от платформы (на 64-битных - 64 бита). Явные размеры: `int32`, `int64`, `uint8`. Смешивать разные целые типы без явного приведения нельзя: `int64(x) + y` требует, чтобы `y` тоже был `int64`. Деление целых усекает: `7 / 2` равно `3`. Переполнение целых заворачивается без ошибки.

**Объявления.** `var x int = 5`, короткая форма `x := 5` (только внутри функций), константы - `const`. У неинициализированной переменной **нулевое значение**: `0`, `""`, `false`, `nil`.

**Форматирование.** `fmt.Printf("%.2f", x)` всегда использует точку: пакет `fmt` не зависит от региональных настроек. Часто используемые глаголы: `%d` целое, `%s` строка, `%v` значение по умолчанию, `%q` строка в кавычках.

**Ввод.** `fmt.Scan(&a, &b)` удобен, но работает медленно на больших вводах. Для скорости оборачивают stdin: `reader := bufio.NewReader(os.Stdin)` и `fmt.Fscan(reader, &x)`. Ошибки ввода возвращаются вторым значением: `n, err := fmt.Fscan(reader, &x)`; конец ввода даёт `io.EOF`.

**Ошибки как значения.** В Go нет исключений для обычных ошибок: функции возвращают `error` последним значением, и вызывающий код проверяет `if err != nil`.

**Цикл.** В Go единственное ключевое слово цикла - `for`: `for i := 0; i < n; i++`, `for cond {}`, `for {}` и `for i, v := range xs`.

## Примеры

**Пример 1. Переменные и деление.**

```go run
package main

import "fmt"

func main() {
    a := 7
    b := 2
    fmt.Println(a / b)
    fmt.Println(float64(a) / float64(b))
    var z int
    var s string
    fmt.Printf("%d %q\n", z, s)
}
```
```output
3
3.5
0 ""
```

**Пример 2. Переполнение int32 и int64.**

```go run
package main

import "fmt"

func main() {
    var x int32 = 2147483647
    x++
    fmt.Println(x)
    var y int64 = 2000000000
    fmt.Println(y + y)
}
```
```output
-2147483648
4000000000
```

**Пример 3. Ошибка как значение.**

```go run
package main

import (
    "fmt"
    "strconv"
)

func main() {
    n, err := strconv.Atoi("42")
    fmt.Println(n, err)
    _, err = strconv.Atoi("abc")
    fmt.Println(err != nil)
}
```
```output
42 <nil>
true
```

**Пример 4. Цикл `for` и `range`.**

```go run
package main

import "fmt"

func main() {
    words := []string{"go", "rust", "zig"}
    for i, w := range words {
        fmt.Println(i, w)
    }
}
```
```output
0 go
1 rust
2 zig
```

**Пример 5. Форматирование и локаль.**

```go run
package main

import "fmt"

func main() {
    fmt.Printf("%.2f\n", 5.0/3)
    fmt.Printf("%6.1f|\n", 3.14159)
}
```
```output
1.67
   3.1|
```

## Типичные ошибки

* **Неиспользуемые импорты и переменные.** Компилятор отвергает программу. Удалите лишнее или присвойте `_`.
* **`:=` вне функции.** На уровне пакета разрешено только `var`.
* **Сумма в `int32`.** Пишите `int64` для сумм до миллиардов (хотя на 64-битных платформах `int` тоже 64 бита, тип по умолчанию платформо-зависим).
* **Смешение типов.** `int` и `int64` складывать напрямую нельзя.
* **Игнорировать `err`.** Ошибка ввода или преобразования проходит незамеченной, программа продолжает работу с нулевым значением.
* **`fmt.Scan` на больших данных.** Он медленный; используйте `bufio.NewReader(os.Stdin)` и `fmt.Fscan`.
* **Деление `int / int` вместо дробного.** Приведите к `float64` до деления.
* **Скобки у `if`/`for`.** В Go они не нужны, а открывающая `{` должна стоять на той же строке.

## Итоги

* `go build` создаёт самостоятельный исполняемый файл с рантаймом внутри; интерпретатор не нужен.
* Неиспользуемые импорты и переменные - ошибки компиляции.
* Целые не смешиваются без приведения, переполнение молчаливое; для больших сумм - `int64`.
* Ошибки - обычные значения, `fmt.Printf("%.2f")` не зависит от локали.
