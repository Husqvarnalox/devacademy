## Зачем это нужно

Пока значения записаны прямо в программе, она всегда считает одно и то же. Полезная программа получает данные снаружи: число от пользователя, слово, сумму покупки. В этом курсе данные приходят через **ввод** (stdin, стандартный ввод): приложение передаёт программе текст, а программа его читает. Для проверки упражнений приложение подаёт ввод из теста.

## Одна новая идея: Scan кладёт прочитанное в переменную

`fmt.Scan(&a)` читает из ввода одно значение и записывает его в переменную `a`. Тип переменной подсказывает, как читать: в `int` - целое число, в `float64` - дробное, в `string` - одно слово (до пробела).

Значок `&` перед именем означает «адрес переменной»: функции Scan нужно сказать не «какое сейчас значение у a», а «где лежит a, чтобы заменить значение». Пока достаточно запомнить правило: **в Scan перед именем переменной всегда ставят `&`**.

Значения в вводе отделяются **пробельными символами**: пробелом, табуляцией или переводом строки. Поэтому `3 4` и две строки `3` и `4` читаются одинаково.

<!-- section: examples -->
## Пример 1. Имя и возраст

```go
package main

import "fmt"

func main() {
    var name string
    var age int
    fmt.Scan(&name, &age)
    fmt.Println("Имя:", name)
    fmt.Println("Возраст:", age)
}
```

Если ввод `Анна 30`, программа напечатает:

```text
Имя: Анна
Возраст: 30
```

* `var name string` и `var age int` создают переменные нужных типов. Без типа нельзя: у переменной ещё нет значения, по которому его можно определить.
* `fmt.Scan(&name, &age)` читает два значения подряд: первое слово - в `name`, следующее число - в `age`.
* Дальше значения используются так же, как любые другие.

## Пример 2. Вычисление по введённым данным

```go
package main

import "fmt"

func main() {
    var price, rate float64
    fmt.Scan(&price, &rate)
    fmt.Println(price * rate)
}
```

Для ввода `200 0.25` программа напечатает `50`. Целое `200` читается в `float64` без проблем. Дробные числа записываются **через точку**: `0.25`, а не `0,25`.

Блок без слова `run` - это показ программы с вводом; приложение запускает ваши программы, подставляя ввод из тестов.

## Пример 3. Что остаётся, если ввода нет

```go run
package main

import "fmt"

func main() {
    var n int
    fmt.Scan(&n)
    fmt.Println(n)
}
```
```output
0
```

Здесь программа запущена с пустым вводом. Читать нечего, `Scan` ничего не записывает, и в `n` остаётся нулевое значение. Ошибки на экране нет, программа просто печатает `0`. Именно поэтому важно понимать, что именно подано на вход.

**Попробуйте.** В примере 1 поменяйте порядок переменных в `Scan` на `&age, &name` и подумайте, что произойдёт при вводе `Анна 30`: первое слово не получится прочитать как число.

<!-- section: precise -->
## Точные правила

* `fmt.Scan(&a, &b, &c)` читает по порядку столько значений, сколько указано переменных. Тип каждой переменной определяет разбор значения.
* **Разделители**: пробел, табуляция, перевод строки (любое их количество). Поэтому количество строк ввода не важно.
* **`string`** получает одно слово - до первого пробельного символа. Фразу с пробелами таким способом не прочитать.
* **`int`** принимает запись вида `42`, `-7`. Запись `3.5` или `abc` прочитать как `int` нельзя.
* **`float64`** принимает `12.5`, `3`, `-0.1`; десятичный разделитель - точка.
* **Результат функции**: `Scan` возвращает число успешно прочитанных значений и ошибку. Сейчас мы их не используем; как работать с ошибками, расскажем позже. Если чтение не удалось, значение переменной не меняется.
* **Конец ввода**: когда ввод закончился, Scan ничего не записывает. В программе, которая читает в цикле, это нужно учитывать.
* `var a, b int` объявляет сразу две переменные одного типа. Для разных типов делают отдельные объявления.
* Переменная должна быть объявлена **до** Scan: читать можно только в уже существующее имя.

## Типичные ошибки

**1. Забыли `&`.**

```go
var n int
fmt.Scan(n)
fmt.Println(n)
```

Вывод: `0`, независимо от ввода. Программа собирается, потому что Go не знает, что вы хотели записать значение в `n`: функции передана копия числа. Исправление: `fmt.Scan(&n)`. Как заметить: после ввода чего угодно переменная остаётся равной нулевому значению.

**2. Прочитали фразу в одну строковую переменную.**

```go
var name string
fmt.Scan(&name)
```

При вводе `Анна Иванова` в `name` окажется только `Анна`. Чтобы получить обе части, нужно две переменные: `fmt.Scan(&firstName, &lastName)`. Как заметить: напечатайте прочитанное значение и сравните со вводом.

**3. Ввод не того типа.**

```go
var n int
fmt.Scan(&n)
```

Для ввода `abc` значение `n` остаётся `0`, а программа продолжает работу как ни в чём не бывало. Другая версия той же ошибки - дробное число с запятой. При `var f float64; var n int` и вводе `12,5 3` в `f` прочитается `12`, затем чтение остановится на запятой и `n` останется `0`. Проверяйте, что формат ввода совпадает с типом переменной (точка в дробных).

**4. Объявили переменную, но не прочитали в неё.**

```go
var a, b int
fmt.Scan(&a)
fmt.Println(a + b)
```

Вывод: только `a`, потому что `b` осталась `0`. Число переменных в Scan должно совпадать с числом значений, которые вам нужны.

<!-- section: summary -->
## Итоги

* `fmt.Scan(&a, &b)` читает значения из ввода в переменные; `&` обязателен.
* Значения разделяются пробелами и переводами строк; `string` получает одно слово.
* Тип переменной решает, как разбирать ввод; при несовпадении переменная остаётся с нулевым значением.
* Дробные числа вводят через точку.

Теперь программы могут работать с чужими данными. Но при вычислении `float64` и `int` в одном выражении возникнут ошибки типов. Как их решать, расскажет следующий урок: [Преобразование типов](lesson:go.first-steps.type-conversion).

## Для тех, кто уже программирует

* `fmt.Scan` - ближайший аналог `scanf`/`cin >> x`, а не `input()`: читает токены, а не строки, и разбирает их по типу переменной.
* `&n` - указатель на переменную. Scan записывает значение через него. Забытое `&` - не ошибка компиляции: аргумент `any`, а не проверка типа.
* Возвращает `(n int, err error)`, но обычные учебные программы пока игнорируют результат. Для быстрого ввода больших объёмов есть `bufio` (позже).
* Нет приведения вида `int(input())`: тип определяется переменной.
* Для чтения строки целиком используют `bufio.Scanner` (будет позже), а не Scan.
