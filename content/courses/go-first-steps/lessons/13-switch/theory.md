## Зачем это нужно

Если нужно сравнить одно значение с несколькими вариантами (номер дня, команда меню, код ответа), цепочка из десяти `else if` занимает много места, и в ней легко ошибиться. Для такого выбора есть конструкция, где варианты перечислены списком.

## Одна новая идея: switch выбирает ветку по значению

```go
switch значение {
case вариант1:
    // команды
case вариант2:
    // команды
default:
    // если ничего не подошло
}
```

Go вычисляет `значение` и сравнивает его с вариантами по порядку. Первый подошедший `case` выполняется, после чего весь `switch` **завершается**. Ветка `default` необязательна и выполняется, если ни один вариант не подошёл.

<!-- section: examples -->
## Пример 1. Выбор по значению

```go run
package main

import "fmt"

func main() {
    day := 3
    switch day {
    case 1:
        fmt.Println("понедельник")
    case 2:
        fmt.Println("вторник")
    case 3:
        fmt.Println("среда")
    default:
        fmt.Println("другой день")
    }
}
```
```output
среда
```

`day` равно 3, подошла третья ветка. Остальные пропущены: прерывать `switch` специальной командой не нужно.

## Пример 2. Несколько значений в одном case

```go run
package main

import "fmt"

func main() {
    day := 6
    switch day {
    case 6, 7:
        fmt.Println("выходной")
    default:
        fmt.Println("будний день")
    }
}
```
```output
выходной
```

Значения через запятую означают «любое из них». Это удобно, когда разным вариантам соответствует одно действие.

## Пример 3. switch без выражения

```go run
package main

import "fmt"

func main() {
    temperature := 22
    switch {
    case temperature < 0:
        fmt.Println("мороз")
    case temperature < 15:
        fmt.Println("прохладно")
    case temperature < 25:
        fmt.Println("тепло")
    default:
        fmt.Println("жарко")
    }
}
```
```output
тепло
```

Здесь после `switch` ничего нет, а в каждом `case` стоит условие. Выполняется первая ветка, у которой условие истинно: `22 < 0` и `22 < 15` ложны, `22 < 25` истинно. Это более компактная запись цепочки `if / else if`.

**Попробуйте.** В примере 3 поставьте `temperature := 30` и `temperature := -10`. Затем в примере 1 уберите `default` и поставьте `day := 9`. Что напечатается?

## Точные правила

* **Форма с выражением**: `switch x { case a: ... }` сравнивает `x` с каждым `case` через `==`. Тип значений в `case` должен совпадать с типом `x`.
* **Форма без выражения**: `switch { case условие: ... }`. Каждое `case` содержит выражение `bool`.
* **Одна ветка выполняется**: после неё switch завершается. В отличие от C и Java, команда `break` в конце ветки не нужна.
* **Несколько значений**: `case 6, 7:`.
* **default** выполняется, если не подошёл ни один `case`. Он может стоять где угодно, но обычно его ставят последним.
* **Повторяющиеся значения** в `case` недопустимы: компилятор сообщает `duplicate case`.
* **fallthrough** - редкое слово, которое принудительно передаёт управление следующей ветке; в этом курсе оно не нужно.
* **Выбор между switch и if**: если сравнивается одно значение с набором вариантов - switch; если проверяются разные условия - `if/else if` или `switch` без выражения.
* В ветке может быть сколько угодно команд; фигурные скобки вокруг неё не нужны.

## Типичные ошибки

**1. Повторяющийся `case`.**

```go
switch day {
case 1:
    fmt.Println("a")
case 1:
    fmt.Println("b")
}
```

Компилятор: `duplicate case 1 (constant of type int) in expression switch`, а ниже `previous case` с номером строки первого. Одно значение не может вести в две ветки. Удалите или объедините.

**2. Значение другого типа в `case`.**

```go
day := 1
switch day {
case "1":
    fmt.Println("a")
}
```

Компилятор: `cannot convert "1" (untyped string constant) to type int`. `day` - число, а `"1"` - текст. Уберите кавычки. Как заметить: сообщение называет тип `int` у переменной и `string` у значения.

**3. Условие в `case` у `switch` с выражением.**

```go
x := 7
switch x {
case x > 5:
    fmt.Println("большой")
}
```

Компилятор: `cannot convert x > 5 (untyped bool value) to type int`. Если после `switch` стоит значение, то в `case` нужно значения для сравнения, а не условия. Для условий уберите `x` после `switch`: `switch { case x > 5: ... }`.

**4. Ждали выполнения нескольких веток.** Программист на C может ожидать, что после `case 2` выполнится и `case 3`. В Go этого нет: выполняется только одна ветка. Чтобы одно действие связать с несколькими значениями, перечисляйте их в одном `case 2, 3:`.

<!-- section: summary -->
## Итоги

* `switch x { case a: ... default: ... }` выбирает ветку по значению.
* Выполняется одна ветка, `break` не нужен; через запятую можно перечислить несколько значений.
* `switch { case условие: ... }` заменяет цепочку `if / else if`.
* `default` ловит все остальные значения.

С выбором разобрались. Следующая важная возможность - повторение действий: [Цикл for](lesson:go.first-steps.for-loop).

<!-- section: programmer -->
## Для тех, кто уже программирует

* Без проваливания: каждая ветка заканчивается сама, `break` не нужен. Для обратного поведения есть ключевое слово `fallthrough`.
* `switch` не ограничен целыми числами: работает со строками, булевыми, почти любыми сравниваемыми типами.
* В `case` можно перечислять несколько значений через запятую (как `case 1: case 2:` в C).
* `switch` без выражения - замена цепочки `if/else if`, аналог `match` с условиями или `switch(true)` в JS.
* Дубликаты констант в `case` - ошибка компиляции.
* Паттерн-матчинга как в Rust/Python 3.10 нет.
