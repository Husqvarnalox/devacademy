## Зачем это нужно

Чтобы программа могла выбирать («если баланс достаточен - списать деньги»), ей нужно уметь отвечать на вопросы «да/нет»: больше ли одно число другого, равны ли два слова, верно ли сразу несколько условий. Ответ «да/нет» - значение типа `bool`, и вопросы строятся из сравнений и логических операторов.

## Одна новая идея: сравнение даёт bool

**Сравнение** - выражение, которое проверяет соотношение двух значений и даёт `true` или `false`:

| Оператор | Смысл |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<`, `<=` | меньше, меньше или равно |
| `>`, `>=` | больше, больше или равно |

Обратите внимание: проверка равенства - **два** знака `==`. Одинарный `=` - присваивание.

**Логические операторы** соединяют `bool`-значения:

* `a && b` - «и»: истинно, когда истинны оба;
* `a || b` - «или»: истинно, когда истинно хотя бы одно;
* `!a` - «не»: меняет значение на противоположное.

<!-- section: examples -->
## Пример 1. Сравнения

```go run
package main

import "fmt"

func main() {
    a := 7
    b := 3
    fmt.Println(a > b, a == b, a != b, a <= 7)
}
```
```output
true false true true
```

Каждое сравнение стало отдельным значением `bool`, и Println напечатал их через пробел: `7 > 3` - истина, `7 == 3` - ложь, `7 != 3` - истина, `7 <= 7` - истина (знак `<=` допускает равенство).

## Пример 2. Логические операторы

```go run
package main

import "fmt"

func main() {
    age := 25
    hasTicket := true
    fmt.Println(age >= 18 && hasTicket)
    fmt.Println(age < 18 || !hasTicket)
    fmt.Println(!(age >= 18))
}
```
```output
true
false
false
```

* Первая строка: оба условия верны, значит «и» истинно.
* Вторая: `age < 18` ложно, `!hasTicket` ложно (билет есть), «или» из двух ложных - ложь.
* Третья: скобки нужны, чтобы `!` относился ко всему сравнению.

## Пример 3. Строки, остаток и приоритет

```go run
package main

import "fmt"

func main() {
    name := "Анна"
    fmt.Println(name == "Анна", name == "анна")
    n := 10
    fmt.Println(n%2 == 0)
    x := 5
    fmt.Println(x >= 1 && x <= 10)
    fmt.Println(false && false || true)
}
```
```output
true false
true
true
true
```

* Тексты тоже сравниваются через `==`; регистр букв важен.
* `n%2 == 0` - типичная проверка чётности: сначала считается остаток, потом сравнение.
* `x >= 1 && x <= 10` - способ записать «x от 1 до 10».
* В последней строке `&&` выполняется раньше `||`: `(false && false) || true` даёт `true`.

**Попробуйте.** Предскажите `fmt.Println(!true || true && false)` и проверьте. Затем поменяйте `false && false || true` на `false && (false || true)` и сравните ответы.

## Точные правила

* **Результат сравнения** - значение типа `bool`. Его можно сохранить в переменную (`ok := x > 5`) и напечатать.
* **Сравниваемые значения** должны иметь один тип: `int` с `float64` сравнить нельзя без преобразования. Числа литералом подстраиваются под тип.
* **Строки** сравниваются по символам (по порядку кодов): `"a" < "b"`. Для проверки равенства используйте `==`.
* **`bool`** допускает `==` и `!=`, но для проверки истинности достаточно использовать само значение: `ok`, а не `ok == true`.
* **Приоритет** (от высшего к низшему): `!`, арифметика (`*` `/` `%`, затем `+` `-`), сравнения, `&&`, `||`. Сомневаетесь - ставьте скобки.
* **Сокращённое вычисление**: в `a && b`, если `a` ложно, значение `b` не вычисляется; в `a || b` - если `a` истинно. Это позволяет писать проверки, где второе условие имеет смысл только при истинном первом.
* **Цепочки не работают**: `1 < x < 10` не компилируется. Пишите `1 < x && x < 10`.
* **Числа с плавающей точкой** сравнивать на точное равенство опасно: `0.1 + 0.2 == 0.3` в Go даёт `false`, потому что дробные хранятся приближённо.
* `&&` и `||` принимают только `bool`: числа и текст в них не работают.

## Типичные ошибки

**1. `=` вместо `==`.**

```go
a := 5
fmt.Println(a = 5)
```

Компилятор: `syntax error: unexpected = in argument list; possibly missing comma or )`. Присваивание не даёт значения для сравнения. Для проверки используйте `==`. В условиях `if` такая же ошибка выглядит как `cannot use assignment a = 5 as value` - с этим вы встретитесь в следующем уроке.

**2. Цепочка сравнений.**

```go
fmt.Println(1 < x < 10)
```

Компилятор: `invalid operation: 1 < x < 10 (mismatched types untyped bool and untyped int)`. Сравнение `1 < x` даёт `bool`, а дальше его пытаются сравнить с числом. Запишите `1 < x && x < 10`.

**3. Сравнение значений разных типов.**

```go
a, b := 1, 2.5
fmt.Println(a == b)
```

Компилятор: `invalid operation: a == b (mismatched types int and float64)`. Чтобы сравнивать, приведите значения к одному типу (урок 8): `float64(a) == b`.

**4. Точное равенство дробных чисел.**

```go
a, b := 0.1, 0.2
fmt.Println(a+b == 0.3, a+b)
```

Вывод: `false 0.30000000000000004`. Дробные числа хранятся приближённо, поэтому сумма немного отличается от `0.3`. Не сравнивайте дробные на точное равенство; проверяйте, что разница меньше допустимой погрешности. Как заметить: ожидание «математически верно» не совпадает с выводом.

<!-- section: summary -->
## Итоги

* Сравнения `== != < <= > >=` дают `bool`.
* `&&` - «и», `||` - «или», `!` - «не»; приоритет: `!`, затем `&&`, затем `||`.
* Диапазон записывают как `x >= a && x <= b`; цепочек `a < x < b` в Go нет.
* Сравнивать можно значения одного типа; дробные на точное равенство лучше не проверять.

Теперь программа может вычислить ответ «да/нет». Следующий шаг - действовать по этому ответу: [Условие if / else](lesson:go.first-steps.if-else).

## Для тех, кто уже программирует

* Тип `bool` строгий: `if x` для числа или строки не скомпилируется, нет «истинных» и «ложных» значений, как в Python и JS.
* Нет `===`: `==` не приводит типы, а разные типы вообще не сравниваются.
* Цепочки `1 < x < 10`, допустимые в Python, не работают.
* Логические операторы: `&&`, `||`, `!` (не `and`/`or`/`not`). Вычисление сокращённое.
* Операторов `^^` (xor) для `bool` нет; для этого используют `a != b`.
* Тернарного оператора `? :` нет - для выбора значения пишут `if`.
