## Зачем это нужно

Пока мы хранили каждое значение в своей переменной: `a`, `b`, `c`. Для семи температур за неделю или тридцати оценок класса это неудобно: нельзя пройти по ним циклом, нельзя написать общий код. Нужна структура, в которой много значений одного типа лежат подряд, а доступ к ним идёт по номеру. Самая простая такая структура - **массив**.

## Одна новая идея: массив - это нумерованный ряд ячеек фиксированной длины

```go
var temps [7]int
```

Это ряд из семи ячеек типа `int`. Длина (7) входит в тип: `[7]int` и `[8]int` - разные типы. Все ячейки сразу заполнены нулями.

Ячейки нумеруют **индексами**, и счёт идёт **с нуля**: у массива из семи элементов индексы 0, 1, 2, 3, 4, 5, 6.

```go
temps[0] = 18           // записать в первую ячейку
fmt.Println(temps[0])   // прочитать из первой ячейки
fmt.Println(len(temps)) // 7: число ячеек
```

Встроенная функция `len` возвращает длину массива. Последний элемент имеет индекс `len(temps) - 1`.

<!-- section: examples -->
## Пример 1. Создание, запись и чтение

```go run
package main

import "fmt"

func main() {
    var a [3]int
    fmt.Println(a)
    a[0] = 5
    a[2] = 9
    fmt.Println(a)
    fmt.Println(a[2], len(a))
}
```
```output
[0 0 0]
[5 0 9]
9 3
```

* `var a [3]int` создаёт три нулевые ячейки; `Println` печатает массив в квадратных скобках.
* `a[0] = 5` и `a[2] = 9` записывают значения по индексам. Ячейка с индексом 1 осталась нулём.
* `a[2]` - последний элемент, потому что `len(a)` равно 3.

## Пример 2. Литерал и обход циклом

```go run
package main

import "fmt"

func main() {
    prices := [4]int{120, 80, 45, 200}
    sum := 0
    for i := 0; i < len(prices); i++ {
        sum = sum + prices[i]
    }
    fmt.Println("сумма:", sum)
    fmt.Println("средняя цена:", float64(sum)/float64(len(prices)))
}
```
```output
сумма: 445
средняя цена: 111.25
```

Литерал `[4]int{120, 80, 45, 200}` создаёт массив сразу с значениями. Типичный обход: счётчик от `0` до `i < len(prices)`. Условие `<`, а не `<=`: индекс `len(prices)` уже за пределами.

## Пример 3. Массив строк

```go run
package main

import "fmt"

func main() {
    days := [3]string{"пн", "вт", "ср"}
    for i := 0; i < len(days); i++ {
        fmt.Println(i+1, days[i])
    }
}
```
```output
1 пн
2 вт
3 ср
```

Массив может хранить значения любого типа. Номер для человека (с 1) отличается от индекса (с 0) на единицу: в программе пишем `i+1`.

**Попробуйте.** В примере 1 запишите значение в `a[3]` и посмотрите на сообщение компилятора. Затем в примере 2 замените `<` на `<=` и посмотрите, что произойдёт при запуске.

## Точные правила

* **Объявление**: `var имя [длина]тип`. Длина - константа (число или `const`), известная при компиляции; переменная длиной быть не может.
* **Литерал**: `[3]int{1, 2, 3}`; можно написать `[...]int{1, 2, 3}`, длина вычислится по числу значений. Если значений меньше длины, остальные - нулевые.
* **Нулевое значение**: каждая ячейка получает нулевое значение своего типа (`0`, `""`, `false`).
* **Индекс** - целое число от `0` до `len(a)-1`. Запись `a[i]` работает и для чтения, и для записи.
* **Выход за границы**: константный индекс вне диапазона - ошибка компиляции; вычисленный во время работы приводит к панике `index out of range`, и программа завершается.
* **`len(a)`** для массива - число ячеек, известное заранее, и никогда не меняется.
* **Массив - значение**: присваивание `b := a` копирует все ячейки; изменение `b` не меняет `a`. Передача массива в функцию тоже копирует его.
* **Печать**: `fmt.Println(a)` показывает значения в квадратных скобках через пробел.
* **Ограничение**: длина фиксирована, массив не растёт. Поэтому для списков переменной длины в следующем уроке мы возьмём срезы.

## Типичные ошибки

**1. Индекс за границей, известный при компиляции.**

```go
var a [3]int
fmt.Println(a[3])
```

Компилятор: `invalid argument: index 3 out of bounds [0:3]`. Допустимы индексы 0, 1, 2.

**2. Индекс за границей, вычисленный при запуске.**

```go
var a [3]int
i := 3
fmt.Println(a[i])
```

Программа собирается, но при запуске падает:

```text
panic: runtime error: index out of range [3] with length 3
```

Сообщение называет плохой индекс и длину. Обычная причина - цикл `i <= len(a)` вместо `i < len(a)`, либо путаница между номером (с 1) и индексом (с 0).

**3. Длина берётся из переменной.**

```go
n := 4
var b [n]int
```

Компилятор: `invalid array length n`. Длина массива должна быть известна при компиляции. Если число элементов определяется вводом, нужен срез (следующий урок).

**4. Массивы разной длины - разные типы.**

```go
var a [3]int
var c [4]int = a
```

Компилятор: `cannot use a (variable of type [3]int) as [4]int value in variable declaration`.

**5. Начало поиска максимума с нуля.** Если `max := 0`, то для массива из отрицательных чисел вы получите `0`, которого в данных нет. Начинайте с первого элемента.

Как заметить самому: при панике смотрите на число в квадратных скобках и на длину; перебирайте граничные случаи (первый и последний элемент).

<!-- section: summary -->
## Итоги

* Массив `[n]T` хранит `n` значений одного типа; длина - часть типа и фиксирована.
* Индексы идут с нуля: от `0` до `len(a)-1`; обход - `for i := 0; i < len(a); i++`.
* Выход за границы - ошибка компиляции для константного индекса и паника при запуске для вычисленного.
* Массив при присваивании копируется целиком.

Если число значений заранее неизвестно, массив не подходит. Тогда используют срезы - гибкие последовательности: [Срезы](lesson:go.first-steps.slices).

## Для тех, кто уже программирует

* Массив в Go - значение, а не ссылка: `b := a` копирует все элементы, а в функцию передаётся копия. Сравнивать массивы одного типа можно через `==`.
* Длина входит в тип: `[3]int` и `[4]int` несовместимы. Длина обязана быть константой.
* Индексы проверяются: выход за границы - паника `index out of range`, а не неопределённое поведение, как в C.
* На практике массивы используют редко; основная структура - срез (следующий урок), который ссылается на массив.
* Нулевое значение массива - массив нулевых значений, `new`/инициализация не нужны.
* `len` - встроенная функция, а не метод; для массива вычисляется при компиляции.
