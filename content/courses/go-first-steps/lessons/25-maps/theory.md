## Зачем это нужно

Часто нужно найти значение не по номеру, а по названию: цену по имени товара, количество повторов по слову, оценку по фамилии. Поиск в срезе пришлось бы делать перебором всех элементов. Для таких задач есть **карта** (`map`): набор пар «ключ - значение» с быстрым доступом по ключу.

## Одна новая идея: карта связывает ключ со значением

```go
prices := map[string]int{"чай": 120, "кофе": 200}
fmt.Println(prices["чай"])   // 120
prices["сок"] = 150          // добавить
prices["чай"] = 130          // изменить
delete(prices, "кофе")       // удалить
```

Запись `map[string]int` читается «карта из строк в целые»: ключи типа `string`, значения типа `int`. Читать и записывать пишут `m[ключ]`. Если ключа нет, чтение даёт **нулевое значение** типа (`0`, `""`), а ошибки не будет. Чтобы отличить «нет ключа» от «значение 0», используют форму с двумя результатами:

```go
v, ok := prices["чай"]   // ok равно true, если ключ есть
```

Порядок обхода карты через `range` **случайный**. Если нужен порядок, ключи собирают в срез и сортируют.

<!-- section: examples -->
## Пример 1. Основные операции

```go run
package main

import "fmt"

func main() {
    stock := map[string]int{"яблоки": 5}
    stock["груши"] = 3
    stock["яблоки"] = stock["яблоки"] + 2
    fmt.Println(stock["яблоки"], stock["груши"], stock["сливы"])
    fmt.Println(len(stock))
    delete(stock, "груши")
    fmt.Println(len(stock))
}
```
```output
7 3 0
2
1
```

Чтение отсутствующего ключа `"сливы"` даёт 0 и ничего не добавляет в карту. `len` возвращает число пар.

## Пример 2. Проверка наличия ключа

```go run
package main

import "fmt"

func main() {
    ages := map[string]int{"Анна": 30, "Тим": 0}
    for _, name := range []string{"Анна", "Тим", "Лев"} {
        age, ok := ages[name]
        if ok {
            fmt.Println(name, "возраст", age)
        } else {
            fmt.Println(name, "не найден")
        }
    }
}
```
```output
Анна возраст 30
Тим возраст 0
Лев не найден
```

У «Тима» значение равно 0, но ключ есть (`ok` истинно). Без `ok` его нельзя отличить от «Льва».

## Пример 3. Подсчёт частоты и стабильный порядок

```go run
package main

import (
    "fmt"
    "slices"
)

func main() {
    words := []string{"да", "нет", "да", "может", "да", "нет"}
    counts := map[string]int{}
    for _, w := range words {
        counts[w]++
    }

    var keys []string
    for w := range counts {
        keys = append(keys, w)
    }
    slices.Sort(keys)

    for _, w := range keys {
        fmt.Println(w, counts[w])
    }
}
```
```output
да 3
может 1
нет 2
```

* `map[string]int{}` создаёт пустую карту, готовую к записи.
* `counts[w]++` работает и для нового слова: из отсутствующего ключа читается 0, после увеличения запишется 1.
* `for w := range counts` с одной переменной даёт ключи. Их складывают в срез `keys`, сортируют и обходят срез. Так вывод одинаков при каждом запуске.

## Пример 4. Чтение до конца ввода

```go
package main

import "fmt"

func main() {
    total := 0
    for {
        var x int
        _, err := fmt.Scan(&x)
        if err != nil {
            break
        }
        total += x
    }
    fmt.Println(total)
}
```

`fmt.Scan` возвращает два значения: сколько значений прочитано и ошибку. Когда данные кончились, ошибка не `nil`, и `break` прерывает бесконечный цикл. Для ввода `1 2 3` программа напечатает `6`. Это приём для ввода неизвестной длины; он понадобится в упражнении.

**Попробуйте.** В примере 3 добавьте слово `"Да"` в `words` и проверьте, где оно окажется в выводе и почему. Затем в примере 2 добавьте в карту ключ `"Лев": 5`.

## Точные правила

* **Тип**: `map[K]V`. Ключ - тип, значения которого можно сравнивать через `==` (числа, строки, `bool`); срез ключом быть не может.
* **Создание**: литерал `map[string]int{"a": 1}`, пустая карта `map[string]int{}` или `make(map[string]int)`. Это равнозначные способы.
* **Нулевая карта** (`var m map[string]int`) равна `nil`: читать и вызывать `len`, `range`, `delete` можно, а записывать - паника `assignment to entry in nil map`.
* **Чтение отсутствующего ключа** даёт нулевое значение типа и не меняет карту. Для проверки наличия служит `v, ok := m[k]`.
* **Запись** `m[k] = v` добавляет пару или заменяет значение. `m[k]++` и `m[k] += x` работают так же.
* **`delete(m, k)`** удаляет пару; для отсутствующего ключа ничего не происходит.
* **`len(m)`** - число пар.
* **Порядок обхода** `range` не определён и меняется от запуска к запуску. Нельзя на него полагаться при выводе.
* **Стабильный вывод**: `var keys []K`, добавить ключи через `range`, `slices.Sort(keys)`, обойти `keys`.
* **Чтение до конца ввода**: `_, err := fmt.Scan(&x)` и `if err != nil { break }`.
* **Ключи с разным регистром** (`"Go"` и `"go"`) - разные ключи.

## Типичные ошибки

**1. Запись в nil-карту.**

```go
var counts map[string]int
counts["a"]++
```

Паника при запуске:

```text
panic: assignment to entry in nil map
```

Создайте карту: `counts := map[string]int{}`.

**2. Вывод в порядке обхода.**

```go
for w, n := range counts {
    fmt.Println(w, n)
}
```

Программа компилируется, но порядок строк может отличаться при каждом запуске, и проверка вывода будет то проходить, то нет. Соберите ключи в срез и отсортируйте их.

**3. Принять 0 за «нет ключа».** `if counts[w] == 0` не отличает отсутствующее слово от слова с нулевым значением. Если это важно, используйте `v, ok := counts[w]`.

**4. Неподходящий тип ключа.**

```go
var m map[[]int]string
```

Компилятор: `invalid map key type []int`. Ключом могут быть только сравнимые типы: числа, строки, `bool`.

**5. Бесконечный цикл чтения.** Если в `for { fmt.Scan(&x) ... }` не проверять ошибку, цикл не закончится, когда ввод закончится. Проверяйте `err != nil` и вызывайте `break`.

Как заметить самому: запустите программу несколько раз подряд на одном вводе; если вывод меняется, где-то используется порядок обхода карты.

## Итоги

* `map[K]V` хранит пары «ключ - значение»; чтение, запись и удаление идут по ключу.
* Отсутствующий ключ даёт нулевое значение; наличие проверяют формой `v, ok := m[k]`.
* `m[k]++` удобно считает частоты.
* Порядок обхода карты случайный: для стабильного вывода сортируйте ключи.
* Записывать можно только в созданную карту, не в `nil`.

Теперь займёмся самим текстом и разберёмся, что на самом деле лежит в строке: [Строки, байты и руны](lesson:go.first-steps.strings-and-runes).

## Для тех, кто уже программирует

* `map` - хеш-таблица, как `dict` в Python или `HashMap` в Java; нулевая карта `nil` допускает чтение, но не запись.
* Отсутствующий ключ даёт нулевое значение типа, без исключения или `KeyError`; наличие проверяет идиома `v, ok := m[k]`.
* Порядок обхода намеренно рандомизирован: в отличие от Python 3.7+, порядок вставки не сохраняется. Для упорядоченного вывода сортируйте ключи (`slices.Sorted(maps.Keys(m))` в Go 1.23+).
* Ключи должны быть сравнимыми: срезы, карты и функции не подходят.
* Карты не потокобезопасны: одновременная запись из разных горутин вызывает аварийное завершение.
* `delete` безопасно для отсутствующего ключа; `len(m)` - число пар.
