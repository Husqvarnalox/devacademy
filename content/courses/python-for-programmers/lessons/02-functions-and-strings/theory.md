## Функции и строки: где опыт другого языка подводит

Функции в Python - обычные объекты: их можно присвоить, передать и вернуть. Из этого вытекают особенности, которых нет в Java или C#: значения по умолчанию вычисляются **один раз при определении функции**, область видимости определяется функцией (а не блоком `{}`), а параметры бывают позиционные, именованные, «остальные» (`*args`, `**kwargs`) и только именованные.

Строки (`str`) - неизменяемые последовательности символов Unicode. Индексация даёт строку из одного символа (типа `char` нет), срезы создают новые строки, а склейка в цикле через `+` каждый раз создаёт новый объект; для сборки используют `"".join(...)`. Форматирование выполняют f-строки.

Зачем это знать: ошибка с изменяемым значением по умолчанию и путаница с областью видимости - два самых частых источника «необъяснимых» багов у тех, кто пришёл с других языков.

## Примеры

**Пример 1. Значение по умолчанию вычисляется один раз.**

```python run
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add_item("a"))
print(add_item("b"))

def add_item_ok(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

print(add_item_ok("a"), add_item_ok("b"))
print(add_item.__defaults__)
```
```output
['a']
['a', 'b']
['a'] ['b']
(['a', 'b'],)
```

Пустой список создаётся при выполнении `def` и становится атрибутом функции (`__defaults__`). Все вызовы без второго аргумента делят этот список. Безопасный шаблон - значение-маркер `None` и создание объекта внутри функции. Для неизменяемых значений (числа, строки, кортежи, `None`) проблемы нет.

**Пример 2. Виды параметров и возврат нескольких значений.**

```python run
def stats(*numbers, scale=1):
    return min(numbers) * scale, max(numbers) * scale

lo, hi = stats(3, 9, 4, scale=10)
print(lo, hi)

def connect(host, port=80, *, timeout=5):
    return f"{host}:{port} timeout={timeout}"

print(connect("example.org", timeout=1))
print(connect(port=8080, host="local"))
```
```output
30 90
example.org:80 timeout=1
local:8080 timeout=5
```

`*numbers` собирает лишние позиционные аргументы в кортеж, параметры после `*` можно передать только по имени. Функция «возвращает несколько значений», на самом деле возвращая кортеж, который тут же распаковывается. Любой аргумент можно передать по имени в любом порядке.

**Пример 3. Область видимости и `nonlocal`.**

```python run
def make_counter():
    total = 0
    def inc():
        nonlocal total
        total += 1
        return total
    return inc

c = make_counter()
c()
print(c(), c())

for i in range(3):
    pass
print(i)
```
```output
2 3
2
```

Имя ищется по правилу LEGB: локальная область, объемлющие функции, модуль, встроенные. Блоки `for` и `if` область не создают, поэтому `i` виден после цикла. Присваивание внутри функции создаёт **локальное** имя; чтобы изменить имя объемлющей функции, нужно `nonlocal`, для модульного - `global`.

**Пример 4. Строки: индексы, срезы, методы.**

```python run
s = "Привет, мир"
print(s[0], s[-1], s[:6], s[::-1], len(s))
parts = "  a, b ,c ".split(",")
print(parts, [p.strip() for p in parts])
print("-".join(["a", "b", "c"]), "ab" * 3, "мир" in s)
upper = s.upper()
print(s, upper)
print(len("Ёж"), len("Ёж".encode("utf-8")))
```
```output
П р Привет рим ,тевирП 11
['  a', ' b ', 'c '] ['a', 'b', 'c']
a-b-c ababab True
Привет, мир ПРИВЕТ, МИР
2 4
```

Срез `s[a:b:step]` выходит за границы без ошибки; отрицательный шаг идёт справа налево. Методы не изменяют строку, а возвращают новую. `len` считает символы Unicode, а не байты: в UTF-8 буква «Ё» занимает два байта.

**Пример 5. f-строки и спецификации формата.**

```python run
price = 1234.5
n = 7
name = "Анна"
print(f"{price:,.2f} {n:03d} [{n:>5}] [{name:<6}] {n=}")
print(f"{name!r} {2 + 3} {'-' * 3}")
```
```output
1,234.50 007 [    7] [Анна  ] n=7
'Анна' 5 ---
```

После двоеточия идёт мини-язык формата: `,` - разделитель тысяч, `.2f` - два знака после запятой, `03d` - целое с нулями до ширины 3, `>5` и `<6` - выравнивание. `{n=}` печатает имя и значение (удобно при отладке), `!r` подставляет `repr`.

## Точные правила

* **Порядок параметров:** обычные, со значением по умолчанию, `*args`, только именованные, `**kwargs`. Параметр со значением по умолчанию нельзя ставить перед обязательным (кроме именованных после `*`).
* **Значения по умолчанию** вычисляются при выполнении `def`. Изменяемое значение (`[]`, `{}`, `set()`) в качестве умолчания - частая ошибка.
* **Передача аргументов:** объект передаётся по ссылке на объект (иногда это называют «call by sharing»): функция может изменить переданный список, но присваивание параметру не меняет имя вызывающего кода.
* **Функция без `return`** возвращает `None`.
* **Область видимости:** присваивание делает имя локальным во всей функции. Чтение имени до присваивания в той же функции даёт `UnboundLocalError`.
* **Строки** неизменяемы; `s[0] = "x"` - `TypeError`. Сравнение строк - по кодам символов Unicode.
* **Срезы** `s[a:b]` включают `a` и исключают `b`; индекс вне диапазона в срезе не ошибка, а в обычной индексации - `IndexError`.
* **Сборка строки:** `"".join(parts)` линейна по размеру результата; многократное `+=` в цикле в общем случае квадратично (CPython иногда это оптимизирует, но полагаться на это не стоит).
* **Формат:** `f"{значение!преобразование:спецификация}"`; спецификацию понимает метод `__format__` значения.

## Типичные ошибки

**1. Изменяемое значение по умолчанию.**

```python
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags
# add_tag("a") -> ['a'], затем add_tag("b") -> ['a', 'b']
```

Список общий для всех вызовов. Исправление: `tags=None` и `if tags is None: tags = []`.

**2. Чтение имени, которое ниже присваивается.**

```python
count = 0
def bump():
    count = count + 1
    return count
# UnboundLocalError: cannot access local variable 'count' where it is not associated with a value
```

Присваивание делает `count` локальным во всей функции, поэтому правая часть читает ещё не заданное локальное имя. Передайте значение параметром и верните результат; `global` оставляйте на крайний случай.

**3. Попытка изменить строку.**

```python
s = "abc"
s[0] = "X"
# TypeError: 'str' object does not support item assignment
```

Соберите новую строку: `"X" + s[1:]` или `s.replace("a", "X", 1)`.

**4. Забытое `return` у функции с вычислением.** Результат становится `None`, и ошибка проявляется позже, например как `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`. Ищите в traceback строку, где `None` встретился впервые.

**5. Сравнение результата метода с исходной строкой.** `s.strip()` не меняет `s`; если результат не присвоен, изменения потеряны.

## Итог

* Значение по умолчанию создаётся один раз при `def`; для изменяемых используйте `None`.
* Параметры бывают позиционные, именованные, `*args`, только именованные и `**kwargs`; «несколько значений» - это кортеж.
* Область видимости задаётся функцией и правилом LEGB; блоки её не создают.
* Строки неизменяемы; срезы, `join` и f-строки с форматом - основные инструменты.

## Главное для тех, кто уже программирует

* **Перегрузки нет.** Одно имя - одна функция; различие по числу и виду аргументов делают значениями по умолчанию, `*args` и проверкой типов (как в JavaScript).
* **Аргументы по имени** есть у любой функции (`f(a=1, b=2)`), а параметры «только по имени» заменяют объект с настройками из Java.
* **Нет `final`/`const`** для параметров и нет `char`: символ - строка длины 1.
* **Замыкания** захватывают переменные, а не значения: `nonlocal` нужен для присваивания (в JavaScript достаточно `let`).
* **Строки** неизменяемы, как в Java, C# и Go; `+=` в цикле медленно. Аналог `StringBuilder` - список и `"".join`. Кавычки `'...'` и `"..."` равноправны; `"""..."""` - многострочная строка.
* **Форматирование:** f-строки вместо `String.format`/шаблонных литералов; `{x:>8.2f}` соответствует `%8.2f`.
* **Unicode:** `str` - Unicode (кодовые точки, не UTF-16 единицы, как в Java и JS); байты - отдельный тип `bytes`.
