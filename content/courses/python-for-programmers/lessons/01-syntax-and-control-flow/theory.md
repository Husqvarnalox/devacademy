## Что нового для человека, который уже программирует

Если вы пишете на Java, JavaScript, C# или Go, то циклы, условия и функции вам знакомы. В Python другое не слова, а модель: **имя - это ярлык на объект**, а не коробка с типом. Это объясняет почти все сюрпризы первых недель.

* У переменной нет типа, есть у значения. `x = 10`, затем `x = "десять"` допустимо: имя `x` просто переставили на другой объект.
* Блоки задаются отступом, а не скобками. Двоеточие в конце заголовка и одинаковый отступ тела обязательны.
* В условие можно поставить любое значение: у каждого объекта есть «истинность» (truthiness).
* `==` сравнивает значения, `is` проверяет, один ли это объект.
* `int` не переполняется: длина числа ограничена только памятью.
* В цикле `for` вы получаете сами элементы, а не индексы; для пар «индекс - элемент» и «элемент - элемент» есть `enumerate` и `zip`.

Зачем это знать: большая часть ошибок «программиста с другого языка» - это попытка перенести привычную модель (типизированные переменные, `i++`, индексные циклы) туда, где она не работает.

## Примеры

**Пример 1. Имена и объекты.**

```python run
a = [1, 2]
b = a
b.append(3)
print(a, a is b)

x = 10
x = "десять"
print(type(x).__name__)
```
```output
[1, 2, 3] True
str
```

Строка `b = a` не копирует список: оба имени указывают на один объект, поэтому изменение через `b` видно через `a`. Тип есть у объекта (`str`), а имя `x` его не хранит.

**Пример 2. Истинность.**

```python run
for v in [0, 0.0, "", [], {}, None, "0", [0], " "]:
    print(repr(v), bool(v))
print("" or "по умолчанию", 0 and 5, 3 and 5)
```
```output
0 False
0.0 False
'' False
[] False
{} False
None False
'0' True
[0] True
' ' True
по умолчанию 0 5
```

Ложны: `None`, `0`, `0.0`, пустые строка, список, словарь, множество, кортеж. Всё остальное истинно, включая строку `"0"` и список `[0]`. Операторы `and` и `or` возвращают один из операндов, а не обязательно `True`/`False`: `x or "по умолчанию"` - привычная замена значения по умолчанию.

**Пример 3. `==` и `is`.**

```python run
a = [1, 2]
b = [1, 2]
print(a == b, a is b)
value = None
print(value is None, value == None)
```
```output
True False
True True
```

Списки равны по содержимому, но это два объекта. Сравнение с `None` пишут через `is`: `None` существует в единственном экземпляре, а `==` можно переопределить в классе.

**Пример 4. Целые числа, `//` и `%`.**

```python run
print(2 ** 100)
print(-7 // 2, -7 % 2, 7 // -2, 7 % -2)
print(divmod(-7, 2))
print(int(-3.5), round(2.5), round(3.5), 7 / 2)
print(0.1 + 0.2)
```
```output
1267650600228229401496703205376
-4 1 -4 -1
(-4, 1)
-3 2 4 3.5
0.30000000000000004
```

`//` округляет **вниз** (к минус бесконечности), а `%` берёт знак делителя, поэтому всегда выполняется `a == (a // b) * b + a % b`. В C, Java и Go `-7 / 2` даёт `-3`, а `-7 % 2` даёт `-1`; в Python `-4` и `1`. Для индексов по кругу это удобно: `(-1) % 5` равно `4`. `int()` отбрасывает дробную часть, `round()` округляет «к чётному» (2.5 даёт 2). `/` всегда возвращает `float`. Двоичная дробь в `0.1 + 0.2` та же, что в любом другом языке.

**Пример 5. Итерация без индексов.**

```python run
names = ["Анна", "Борис", "Вера"]
scores = [90, 75]
for i, name in enumerate(names, start=1):
    print(i, name)
print(list(zip(names, scores)))
values = [3, 8, 6]
print([b - a for a, b in zip(values, values[1:])])
```
```output
1 Анна
2 Борис
3 Вера
[('Анна', 90), ('Борис', 75)]
[5, -2]
```

`enumerate` отдаёт пары (номер, элемент), `zip` склеивает последовательности и **останавливается по самой короткой** - Вера пропала без ошибки. Пары соседних элементов получаются из `zip(values, values[1:])`.

**Пример 6. Ветка `else` у цикла.**

```python run
for n in range(2, 20):
    for d in range(2, n):
        if n % d == 0:
            break
    else:
        print(n, end=" ")
print()
```
```output
2 3 5 7 11 13 17 19 
```

`else` у цикла выполняется, если цикл завершился без `break`. Здесь так находятся простые числа. Это редкая, но законная конструкция; в других языках её нет.

## Точные правила

* **Присваивание** связывает имя с объектом. Составное `b += [3]` для списка изменяет объект на месте (`list.__iadd__`), для числа и строки создаёт новый объект.
* **Отступы.** Один уровень - обычно 4 пробела. Смешивать табуляцию и пробелы нельзя. Пустое тело пишут как `pass`.
* **Условие** в `if` и `while` приводится к `bool` по правилам истинности. Пользовательский класс управляет этим через `__bool__` или `__len__`.
* **Цепочки сравнений**: `0 <= x < 10` означает `0 <= x and x < 10`, `x` вычисляется один раз.
* **Целые**: `int` без ограничения разрядов; `//` и `%` согласованы через `divmod`. `bool` - подкласс `int` (`True + True == 2`).
* **`is`** сравнивает идентичность (`id`). Для `None`, `True`, `False` используйте `is`; для чисел и строк - никогда: небольшие числа и некоторые строки реализация может переиспользовать, но это деталь CPython, на которую нельзя полагаться.
* **`for`** работает с любым итерируемым объектом. `range(n)` лениво выдаёт числа и не создаёт список. Переменная цикла после цикла остаётся в области видимости.
* **`while ... else`, `for ... else`**: `else` выполняется, если не было `break`.
* **Тернарное выражение**: `a if условие else b`. Операторов `++`, `--`, `?:` и `&&`/`||` нет: пишут `+= 1`, `x if c else y`, `and`/`or`.

## Типичные ошибки

**1. Попытка сложить строку и число (как в JavaScript).**

```python
print("Итого: " + 5)
# TypeError: can only concatenate str (not "int") to str
```

Python не приводит типы молча. Исправление: `f"Итого: {5}"` или `"Итого: " + str(5)`. Узнать причину можно по последней строке traceback.

**2. Присваивание вместо сравнения.**

```python
if x = 5:
    pass
# SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

Присваивание - инструкция, а не выражение; в условии нужен `==`. Операция `:=` существует, но для другого случая.

**3. Неверный отступ.**

```python
for i in range(3):
print(i)
# IndentationError: expected an indented block after 'for' statement on line 1
```

Тело цикла обязано быть сдвинуто. Так же выглядит случайный лишний отступ: `unexpected indent`.

**4. Деление и округление «как в C».** Ожидая `-3` от `-7 // 2`, вы получите `-4`. Если нужно отбросить дробную часть, используйте `int(-7 / 2)` или `math.trunc`.

**5. `is` для значений.** `if name is "admin"` может работать на одних строках и не работать на других; верно `==`. Интерпретатор предупреждает об этом в виде `SyntaxWarning`.

**6. Ложное значение как «нет значения».** `if not count:` считает отсутствие и ноль одним и тем же. Когда `0` допустим, пишите `if count is None:`.

## Итог

* Имя - ярлык на объект; тип у значения. Присваивание не копирует.
* Отступ - часть синтаксиса; условие принимает любое значение по правилам истинности, `and`/`or` возвращают операнды.
* `==` - равенство значений, `is` - тот же объект; `None` проверяют через `is`.
* Целые произвольной длины; `//` округляет вниз, `%` берёт знак делителя.
* Вместо индексных циклов - `for x in items`, `enumerate`, `zip`.

## Главное для тех, кто уже программирует

* **Java / C# / Go:** статической типизации нет; типы проверяются во время выполнения, ошибка видна только при выполнении строки. Объявлять переменные не нужно, присваивание создаёт имя. Скобок `{}` и `;` нет, блок задаёт отступ.
* **JavaScript:** нет `==`/`===` различия: `==` не приводит типы (`1 == "1"` ложно). Нет `undefined`, есть `None`. `[]` и `{}` **ложны** (в JS истинны); `"0"` истинна и в Python, и в JS.
* **Деление:** `/` всегда `float`, `//` - целочисленное с округлением вниз. Знак `%` как у делителя (как в Ruby, в отличие от C, Java, JavaScript и Go).
* **Числа:** `int` не переполняется (нет `long`/`BigInteger`); `float` - обычный IEEE 754 double.
* **Циклы:** `for` - всегда по итерируемому; классического `for (i = 0; i < n; i++)` нет, используйте `range`. `enumerate` и `zip` вместо индексов.
* **Логика:** `and`, `or`, `not` вместо `&&`, `||`, `!`; `a if c else b` вместо `c ? a : b`; цепочки сравнений `a < b < c`.
* **Идентичность:** `is` - это `==` в Java на ссылках; `==` в Python - это `.equals()`.
