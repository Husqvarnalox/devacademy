## Что проверяет эта проверка

Значимые (`int`, `struct`) и ссылочные (`class`, `string`, массивы) типы, копирование при присваивании и передаче в метод, `Nullable<T>` (`int?`), операторы `?.` и `??`, упаковку значения в `object`, аннотации nullable для ссылочных типов.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Значимые и ссылочные типы, struct и class, nullable](lesson:csharp.first-steps.value-types-and-nullable), [Система типов и память: упаковка, ref, Span, nullable](lesson:csharp.fundamentals.type-system-and-memory).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```csharp run
Coord a = new Coord { X = 1 };
Coord b = a;
b.X = 9;
Cell c = new Cell { X = 1 };
Cell d = c;
d.X = 9;
Console.WriteLine($"{a.X} {c.X}");

int? n = null;
Console.WriteLine(n.HasValue);
Console.WriteLine(n ?? 7);
int? m = n + 1;
Console.WriteLine(m is null);

object o1 = 5;
object o2 = 5;
Console.WriteLine($"{o1 == o2} {o1.Equals(o2)}");

string? s = null;
Console.WriteLine(s?.Length ?? -1);

struct Coord
{
    public int X;
}

class Cell
{
    public int X;
}
```
```output
1 9
False
7
True
False True
-1
```

Структура `Coord` копируется целиком, поэтому изменение копии не видно в оригинале; для класса `Cell` копируется ссылка, и объект общий. Для `int?` поле `HasValue` показывает, есть ли значение, а `??` подставляет запасное; арифметика с `null` даёт `null`. Две упаковки одного числа - разные объекты: `==` сравнивает ссылки, а `Equals` - содержимое.

<!-- section: precise -->
## Что нужно уметь

* объяснять разницу между копированием значения и копированием ссылки;
* знать, что параметр метода получает копию: для структуры - копию значения, для класса - копию ссылки;
* использовать `int?`, `HasValue`, `Value`, `??` и `?.`;
* знать, что аннотации `string?` относятся к компилятору, а не к типу во время выполнения;
* понимать упаковку (boxing) и сравнение `object` по ссылке;
* не изменять структуру, хранящуюся в списке, через индексатор.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Ожидание, что структура ведёт себя как класс: изменение копии не меняет оригинал.
* Чтение `value.Value` у `int?`, равного `null`: `InvalidOperationException`.
* Сравнение упакованных чисел через `==`: сравниваются ссылки.
* Подавление предупреждения nullable оператором `!` без проверки.
* Изменяемая структура в коллекции: изменение поля копии не затрагивает элемент.
* Путаница между `int.Parse` (исключение) и `int.TryParse` (значение по умолчанию).
