## Типы, нулевые значения и строки

Go - язык со **статической типизацией**: у каждой переменной тип известен при компиляции, и компилятор не смешивает типы молча. Нельзя сложить `int` и `float64` без явного преобразования, нельзя присвоить `int32` переменной типа `int64`.

Три идеи этого урока сделают чтение чужого Go-кода намного проще.

**1. У каждой переменной всегда есть значение.** Если вы объявили переменную и ничего ей не присвоили, она получает **нулевое значение** своего типа: `0` для чисел, `false` для `bool`, `""` для строки, `nil` для указателей, срезов, карт, каналов, функций и интерфейсов. Неинициализированных переменных, как в C, в Go нет. Хорошие Go-типы проектируют так, чтобы их нулевое значение было полезным (`sync.Mutex`, `bytes.Buffer`, пустой срез).

**2. Константы бывают «нетипизированными».** Запись `const limit = 1000` не привязана к `int`: это просто число, которое подстроится под контекст. Поэтому `limit` можно использовать и как `float64`, и как `time.Duration`, без преобразований.

**3. Строка - это неизменяемая последовательность байтов, а не символов.** `len("Привет")` равно `12`, а не `6`: каждая кириллическая буква в UTF-8 занимает два байта. Символ Unicode в Go называется **руной** (`rune`), и цикл `for range` по строке выдаёт именно руны.

```go
s := "Привет"
fmt.Println(len(s), len([]rune(s)))
```

Первое число - байты, второе - символы. Разница между ними - источник половины ошибок новичков при работе с текстом.

## Точные правила

**Базовые типы.**

* Целые со знаком: `int8`, `int16`, `int32`, `int64`; без знака: `uint8`, `uint16`, `uint32`, `uint64`; `int` и `uint` имеют размер платформы (32 или 64 бита), `uintptr` нужен для низкоуровневого кода.
* `byte` - синоним `uint8`, `rune` - синоним `int32`. Это не отдельные типы, а другие имена: `[]byte` и `[]uint8` - один и тот же тип.
* Вещественные: `float32`, `float64`; комплексные: `complex64`, `complex128`.
* `bool` (`true`/`false`) и `string`.
* Переполнение целых **не вызывает ошибки**: значение «заворачивается» по модулю `2^N`. `var x uint8 = 255; x++` даёт `0`.

**Нулевые значения** (спецификация, раздел «The zero value»): `0` для чисел, `false` для `bool`, `""` для `string`, `nil` для указателей, функций, интерфейсов, срезов, каналов и карт. Для структур и массивов нулевое значение собирается поэлементно. Важное следствие: **чтение из `nil`-среза и `nil`-карты безопасно** (длина `0`, значения по ключам нулевые), а **запись в `nil`-карту вызывает панику**, тогда как `append` к `nil`-срезу работает.

**Объявления.**

* `var x int` - нулевое значение; `var x = 5` - тип выводится; `x := 5` - короткое объявление, только внутри функций, и хотя бы одна переменная слева должна быть новой.
* Неиспользуемая локальная переменная и неиспользуемый импорт - ошибка компиляции.
* Имя `_` (пустой идентификатор) отбрасывает значение.

**Константы.**

* Константа может быть **типизированной** (`const a int = 5`) и **нетипизированной** (`const a = 5`). Нетипизированная константа имеет «вид» (целая, вещественная, рунная, строковая, логическая) и вычисляется с произвольной точностью (компиляторы обязаны поддерживать целые минимум в 256 бит); тип она получает только при использовании.
* `const huge = 1 << 100` допустимо, пока вы не пытаетесь положить это в `int`: ошибка возникнет именно тогда («overflows int»).
* `iota` - счётчик внутри блока `const (...)`, начинается с `0` и растёт на строку. Им задают перечисления.
* Деление констант тоже зависит от вида: `7 / 2` - целое `3`, а `7 / 2.0` - `3.5`.

**Преобразования** всегда явные: `float64(i)`, `int64(x)`. Преобразование вещественного в целое отбрасывает дробную часть (к нулю); для констант, не помещающихся в тип, это ошибка компиляции, для переменных - просто усечение или заворачивание.

**Строки.**

* `string` неизменяема: `s[0] = 'x'` не компилируется. «Изменение» создаёт новую строку.
* `len(s)` - число **байтов**. `s[i]` - **байт** (тип `byte`).
* `for i, r := range s` разбирает строку как UTF-8 и выдаёт **индекс начала** руны в байтах и саму руну (`rune`). Недопустимые байты UTF-8 дают руну `U+FFFD` шириной в один байт.
* `[]rune(s)` создаёт срез рун (копия), `[]byte(s)` - срез байтов (копия), `string(runes)` собирает строку обратно.
* Число символов считают через `utf8.RuneCountInString(s)` или `len([]rune(s))`.
* `string(65)` - это **не** `"65"`, а символ с кодом 65 (`"A"`); для чисел используйте `strconv.Itoa`. Утилита `go vet` предупреждает об этом преобразовании для целых типов, кроме `rune` и `byte`.

## Примеры

**Пример 1. Нулевые значения.**

```go run
package main

import "fmt"

type Point struct {
	X, Y int
	Tag  string
}

func main() {
	var i int
	var f float64
	var b bool
	var s string
	var p *int
	var sl []int
	var m map[string]int
	var e error
	var pt Point

	fmt.Printf("%v %v %v %q\n", i, f, b, s)
	fmt.Println(p == nil, sl == nil, m == nil, e == nil)
	fmt.Printf("%+v\n", pt)

	// Чтение из nil-карты и append к nil-срезу безопасны.
	fmt.Println(m["нет"], len(sl))
	sl = append(sl, 1)
	fmt.Println(sl)
}
```

```output
0 0 false ""
true true true true
{X:0 Y:0 Tag:}
0 0
[1]
```

Нулевое значение структуры собирается из нулевых значений полей. А вот запись `m["a"] = 1` в `nil`-карту вызвала бы панику `assignment to entry in nil map`: карту нужно создать через `make` или литерал.

**Пример 2. Нетипизированные константы и преобразования.**

```go run
package main

import (
	"fmt"
	"time"
)

const limit = 1000 // нетипизированная целая константа

const (
	Sunday = iota // 0
	Monday        // 1
	Tuesday       // 2
)

func main() {
	var f float64 = limit // подходит как float64
	var n int8 = 100      // и как int8
	timeout := limit * time.Millisecond
	fmt.Println(f, n, timeout)

	fmt.Println(7/2, 7/2.0, Tuesday)

	// Нетипизированные константы считаются точно.
	const huge = 1 << 100
	fmt.Println(huge >> 98)

	// Преобразования - только явные, а переполнение молчаливо.
	var u uint8 = 255
	u++
	var x float64 = 3.99
	fmt.Println(u, int(x), int(-x))

	var a int32 = 7
	var b int64 = int64(a) * 3
	fmt.Println(b)
}
```

```output
1000 100 1s
3 3.5 2
4
0 3 -3
21
```

Константа `limit` стала `float64`, `int8` и `time.Duration` без единого преобразования, потому что сама она никакого типа не имела. А переменная `a` типа `int32` в `int64` без `int64(a)` не превращается.

**Пример 3. Байты и руны.**

```go run
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	s := "Привет, 世界"
	fmt.Println(len(s), utf8.RuneCountInString(s), len([]rune(s)))

	// s[i] - байт, а не символ.
	fmt.Println(s[0], s[1])

	// range даёт индекс в байтах и руну.
	for i, r := range "Гo世" {
		fmt.Printf("%d:%c(%d байт) ", i, r, utf8.RuneLen(r))
	}
	fmt.Println()

	// Срез по байтам может разрезать символ пополам.
	fmt.Printf("%q %q\n", s[:2], s[:1])

	// Недопустимый UTF-8 превращается в U+FFFD при range.
	bad := "a\xffb"
	for _, r := range bad {
		fmt.Printf("%U ", r)
	}
	fmt.Println()

	// string(число) даёт символ с этим кодом.
	fmt.Println(string(rune(65)), string(rune(0x1F44B)))
}
```

```output
20 10 10
208 159
0:Г(2 байт) 2:o(1 байт) 3:世(3 байт) 
"П" "\xd0"
U+0061 U+FFFD U+0062 
A 👋
```

Первые два байта строки - это одна буква `П` в кодировке UTF-8 (`208 159`). Поэтому `s[:2]` - целая буква, а `s[:1]` - обрывок, который `%q` показывает как `"\xd0"`.

## Типичные ошибки

* **`len(s)` как число символов.** Для текста не на латинице это даёт байты. Для символов используйте `utf8.RuneCountInString`.
* **Разворот или обрезка строки по байтам.** `s[:n]` и разворот `[]byte(s)` могут разрезать многобайтный символ. Работайте через `[]rune` или `range`.
* **Ожидание, что `s[i]` - символ.** Это `byte`; для печати символа нужен `string(rune(...))` или `%c` с руной.
* **Запись в `nil`-карту.** Читать можно, писать нельзя: `var m map[string]int; m["a"] = 1` - паника. Создавайте `make(map[string]int)`.
* **`string(65)` вместо `strconv.Itoa(65)`.** Первое даёт `"A"`.
* **Неявное смешение чисел.** `int + int64`, `float64 * int` не компилируются: приведите типы явно. Это не придирка компилятора: так видно, где возможна потеря точности.
* **Целочисленное деление.** `a / b` для `int` отбрасывает остаток; для дроби приведите хотя бы один операнд: `float64(a) / float64(b)`.
* **Расчёт на ошибку при переполнении.** Целые «заворачиваются» без предупреждения; границы проверяйте сами (`math.MaxInt32` и т. д.).

<!-- section: summary -->
## Итоги

* У каждой переменной есть нулевое значение; полезные типы делают его рабочим. Читать `nil`-карту можно, писать в неё нельзя.
* Нетипизированная константа подстраивается под контекст и считается с большой точностью; типизированная - нет.
* Преобразования между числовыми типами всегда явные, переполнение молчаливо заворачивает значение.
* Строка - неизменяемые байты в UTF-8: `len` считает байты, `range` выдаёт руны, `[]rune(s)` даёт символы.
* `byte` - это `uint8`, `rune` - это `int32`; число не превращается в текст через `string(n)`.

<!-- section: facts -->
## Факты

* Спецификация фиксирует нулевые значения для всех типов, поэтому «мусора» в переменных в Go не бывает.
* В `range` по строке индексы идут по байтам, поэтому они не последовательны для многобайтных символов.
