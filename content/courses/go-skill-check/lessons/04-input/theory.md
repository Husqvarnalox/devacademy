## Что проверяет эта проверка

Чтение данных через `io.Reader`, `bufio.Scanner` и `bufio.Reader` с `fmt.Fscan`, разбор строк (`strings.Fields`, `strings.Split`), `strconv.ParseInt`, признак конца `io.EOF`, ширину целых типов и переполнение.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Поток чисел: bufio и int64](lesson:go.first-steps.number-stream), [Построчное чтение и разбор текста](lesson:go.first-steps.text-lines).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```go run
package main

import (
	"bufio"
	"fmt"
	"strings"
)

func main() {
	sc := bufio.NewScanner(strings.NewReader("a 1\nb 2\n"))
	n := 0
	for sc.Scan() {
		n += len(strings.Fields(sc.Text()))
	}
	fmt.Println(n, sc.Err())
}
```
```output
4 <nil>
```

`Scan` читает строки до конца данных, `Fields` считает слова, а `sc.Err()` после цикла возвращает `nil` при нормальном завершении.

<!-- section: precise -->
Проверка предполагает умение:

* читать строки и числа до конца ввода;
* отличать `io.EOF` от некорректных данных;
* знать предел `Scanner` и ширину числовых типов;
* писать разбор строк с понятной ошибкой;
* принимать `io.Reader`, чтобы код проверялся без стандартного ввода.

<!-- section: mistakes -->
Как подготовиться и на чём чаще всего ошибаются.

* Цикл `for sc.Scan()` без проверки `sc.Err()` скрывает ошибки чтения.
* Токен длиннее 64 КБ останавливает `Scanner`.
* Переполнение целых типов фиксированной ширины молчаливо.
* Повторение: список уроков ниже.
