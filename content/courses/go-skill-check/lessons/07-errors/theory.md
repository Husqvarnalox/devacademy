## Что проверяет эта проверка

Ошибки как значения: сторожевые ошибки, обёртывание через `%w`, `errors.Is`, `errors.As`, пользовательские типы ошибок, `errors.Join`, подводный камень с типизированным nil и выбор между ошибкой и `panic`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Функции, ошибки как значения и defer](lesson:go.fundamentals.functions-and-errors), [Пакеты, ошибки-значения и go test](lesson:go.fundamentals.errors-and-table-tests).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```go run
package main

import (
	"errors"
	"fmt"
	"os"
)

func main() {
	_, err := os.Open("no-such-file.txt")
	wrapped := fmt.Errorf("load config: %w", err)
	fmt.Println(errors.Is(wrapped, os.ErrNotExist))
}
```
```output
true
```

Ошибка файловой системы обёрнута с контекстом, но `errors.Is` по-прежнему находит причину: `os.ErrNotExist`.

<!-- section: precise -->
Проверка предполагает умение:

* оборачивать ошибки через `%w` и искать причину через `errors.Is` и `errors.As`;
* описывать собственный тип ошибки с методом `Error`;
* возвращать литерал `nil`, а не типизированный nil-указатель;
* объединять несколько ошибок через `errors.Join`;
* различать ожидаемую ошибку и панику.

<!-- section: mistakes -->
Как подготовиться и на чём чаще всего ошибаются.

* `%v` не оборачивает ошибку: `errors.Is` перестаёт работать.
* Сравнение `err == ErrX` не видит обёрнутые ошибки.
* `errors.As` требует указатель на переменную нужного типа.
* Повторение: список уроков ниже.
