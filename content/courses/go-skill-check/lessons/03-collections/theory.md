## Что проверяет эта проверка

Срезы (`len`, `cap`, общий массив, `append`), карты (нулевое значение, `ok`-форма, nil-карта), строки как байты и руны, `range` по строкам и коллекциям.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Массивы](lesson:go.first-steps.arrays), [Срезы](lesson:go.first-steps.slices), [Обход через range](lesson:go.first-steps.range), [Поиск, фильтрация и сортировка](lesson:go.first-steps.slice-algorithms), [Карты](lesson:go.first-steps.maps), [Строки, байты и руны](lesson:go.first-steps.strings-and-runes).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```go run
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4}
	t := s[1:3]
	t = append(t, 99)
	fmt.Println(s, t, len(t), cap(t))
	fmt.Println(len("Go"), len("Привет"))
}
```
```output
[1 2 3 99] [2 3 99] 3 3
2 12
```

Срез `t` делит массив с `s`, поэтому `append` записал `99` на место `s[3]`. `len` считает байты: каждая кириллическая буква занимает 2 байта.

<!-- section: precise -->
Проверка предполагает умение:

* объяснять, когда срезы делят память;
* безопасно использовать nil-срезы и не писать в nil-карту;
* различать `len` в байтах и число символов;
* использовать `append` и присваивать его результат;
* писать функции над срезами и картами без зависимости от порядка обхода.

<!-- section: mistakes -->
Как подготовиться и на чём чаще всего ошибаются.

* Неприсвоенный `append` не меняет срез.
* Запись в nil-карту - паника, чтение безопасно.
* `range` по строке даёт байтовые индексы и руны.
* Порядок обхода карты случаен.
* Повторение: список уроков ниже.
