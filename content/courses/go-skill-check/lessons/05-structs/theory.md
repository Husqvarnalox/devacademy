## Что проверяет эта проверка

Структуры и композитные литералы, нулевые значения полей, методы с получателем-значением и получателем-указателем, указатели и `nil`, встраивание, копирование структур, структуры в картах.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Типы, нулевые значения и строки](lesson:go.fundamentals.types-values-zero-values), [Структуры, методы и встраивание](lesson:go.fundamentals.structs-methods-embedding).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```go run
package main

import "fmt"

type Counter struct{ n int }

func (c *Counter) Inc() { c.n++ }

func main() {
	var c Counter
	c.Inc()
	c.Inc()
	d := c
	d.Inc()
	fmt.Println(c.n, d.n)
}
```
```output
2 3
```

Метод с указателем изменяет `c`. Присваивание `d := c` копирует структуру, поэтому дальнейшие изменения `d` не влияют на `c`.

<!-- section: precise -->
Проверка предполагает умение:

* выбирать между получателем-значением и получателем-указателем;
* понимать, что присваивание структуры копирует её;
* не обращаться к полям через nil-указатель;
* использовать встраивание как композицию;
* помнить, что значения в карте не адресуемы.

<!-- section: mistakes -->
Как подготовиться и на чём чаще всего ошибаются.

* Метод со значимым получателем меняет копию.
* Структуры в карте нельзя менять «на месте».
* Указатель по умолчанию `nil`: его нужно создать.
* Повторение: список уроков ниже.
