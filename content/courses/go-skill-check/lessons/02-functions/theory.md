## Что проверяет эта проверка

Функции с несколькими результатами, ошибки как значения (`error`, `errors.New`, `fmt.Errorf` с `%w`, `errors.Is`), передачу параметров по значению, `defer` и правила `:=`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Функции](lesson:go.first-steps.functions), [Возврат значений](lesson:go.first-steps.return-values), [Область видимости](lesson:go.first-steps.scope), [Ошибка как значение](lesson:go.first-steps.errors-first-look).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```go run
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func parse(s string) (int, error) {
	n, err := strconv.Atoi(s)
	if err != nil {
		return 0, errors.New("не число: " + s)
	}
	return n, nil
}

func main() {
	fmt.Println(parse("12"))
	fmt.Println(parse("x"))
}
```
```output
12 <nil>
0 не число: x
```

Функция возвращает пару «значение, ошибка»; печать пары через `Println` показывает оба значения.

<!-- section: precise -->
Проверка предполагает умение:

* вызывать функции с несколькими результатами и проверять `err` сразу;
* создавать и оборачивать ошибки, сравнивать их через `errors.Is`;
* понимать, что параметры копируются;
* знать порядок вызовов `defer`;
* замечать затенение переменных через `:=`.

<!-- section: mistakes -->
Как подготовиться и на чём чаще всего ошибаются.

* Игнорирование ошибки через `_` приводит к ложным нулевым результатам.
* `err == ErrX` не находит обёрнутую ошибку; нужен `errors.Is`.
* Значение рядом с ошибкой считается недействительным: возвращайте нули.
* Повторение: список уроков ниже.
