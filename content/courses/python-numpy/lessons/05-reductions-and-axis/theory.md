## Свернуть массив — но по какой оси?

**Редукция** — операция, которая сворачивает массив в меньший: `sum`, `mean`, `max`, `argmax`, `std`. Без параметров она сворачивает весь массив в одно число. С параметром `axis` — вдоль выбранной оси: из матрицы `n × m` можно получить `m` сумм по столбцам или `n` сумм по строкам.

Запомнить удобнее так: **`axis=k` означает «убрать ось k из формы»**. Для `a.shape == (3, 4)`: `axis=0` убирает первую ось, результат имеет форму `(4,)` — по одному значению на столбец (мы «идём вниз по строкам»); `axis=1` убирает вторую ось, результат `(3,)` — по значению на строку. Параметр `keepdims=True` не убирает ось, а оставляет её длины 1, чтобы результат можно было сразу использовать в broadcasting.

Вторая тема урока — **численная устойчивость**. Формулы, одинаковые на бумаге, ведут себя по-разному в арифметике конечной точности. Среднее и дисперсию нужно считать так, чтобы большие по модулю, но почти одинаковые числа не вычитались друг из друга.

## Семантика axis

Для массива формы `(d0, d1, ..., dk)` вызов `a.sum(axis=i)` возвращает массив формы без `i`-й оси. Допустим и кортеж: `a.sum(axis=(0, 2))`. `axis=None` (по умолчанию) сворачивает все оси. Отрицательные значения считаются с конца: `axis=-1` — последняя ось.

* `sum`, `prod`, `mean`, `std`, `var`, `min`, `max` возвращают значения; `argmin` и `argmax` — **индексы** вдоль оси (при равенстве — первый). Без `axis` `argmax` работает по уплощённому массиву.
* `keepdims=True` сохраняет свёрнутые оси длины 1.
* `mean` целочисленного массива возвращает `float64`. `sum` целых малой ширины по умолчанию накапливается в платформенном целом (на 64-битных платформах — `int64`), поэтому `np.sum(int8_array)` не переполняется, а вот `a * 2` для `int8` переполняется. Параметр `dtype` задаёт накопитель: `a.sum(dtype=np.float64)` для `float32` повышает точность.
* `np.sum` для вещественных чисел использует **попарное суммирование**, которое даёт погрешность заметно ниже, чем наивный последовательный цикл. Но результат всё равно зависит от порядка операций и не обязан совпадать с `sum` из Python бит в бит.

## Устойчивое среднее и дисперсия

Дисперсия выборки: `Var = Σ (x_i - mean)^2 / (n - ddof)`. Параметр **`ddof`** («delta degrees of freedom») задаёт делитель: `ddof=0` — смещённая оценка для всей совокупности (по умолчанию в `np.var` и `np.std`), `ddof=1` — несмещённая оценка по выборке (поправка Бесселя). Заметьте, что в `pandas` значение по умолчанию другое (`ddof=1`).

Формула `Var = E[x^2] - (E[x])^2` математически верна, но численно опасна: когда среднее велико по сравнению с разбросом, оба слагаемых огромны и почти равны, а разность съедает все значащие цифры (**катастрофическое сокращение**). Для `x = 1e9 + [0, 1, 2, 3, 4]` в `float64` слагаемые порядка `1e18`, где шаг между соседними числами равен 128, а истинная дисперсия равна 2. **Двухпроходный** алгоритм сначала считает среднее, потом сумму квадратов отклонений `Σ (x_i - mean)^2`: отклонения малы, и точность сохраняется. Для потоков данных применяют алгоритм Велфорда, который обновляет среднее и сумму квадратов отклонений за один проход.

## Устойчивый softmax

`softmax(z)_i = exp(z_i) / Σ_j exp(z_j)`. Для `z_i = 1000` `exp` переполняется в `inf`, и результат — `nan`. Softmax инвариантен к сдвигу: `softmax(z) = softmax(z - c)`, поэтому вычитают максимум строки (`c = max(z)`). Тогда все показатели не больше 0, `exp` не превышает 1, и в сумме есть слагаемое 1, так что деление безопасно. Максимум берут по нужной оси с `keepdims=True`.

## Примеры

**Пример 1. Оси и формы.**

```python run
import numpy as np

a = np.arange(12).reshape(3, 4)
print(a)
print("axis=0:", a.sum(axis=0), a.sum(axis=0).shape)
print("axis=1:", a.sum(axis=1), a.sum(axis=1).shape)
print("keepdims:", a.sum(axis=1, keepdims=True).shape, "всё:", a.sum())
b = np.arange(24).reshape(2, 3, 4)
print("(2,3,4) axis=(0, 2):", b.sum(axis=(0, 2)).shape, "axis=-1:", b.sum(axis=-1).shape)
```

import numpy as np

scores = np.array([[0.1, 0.7, 0.2],

print("класс по строкам:", scores.argmax(axis=1))

**Пример 3. Дисперсия: наивная формула и двухпроходная.**

```python run
import numpy as np

x = 1e9 + np.arange(5, dtype=np.float64)
naive = np.mean(x ** 2) - np.mean(x) ** 2
two_pass = np.mean((x - x.mean()) ** 2)
print("истинная дисперсия: 2.0")
print("наивная формула сильно промахнулась:", abs(naive - 2.0) > 0.5)
print("двухпроходная:", two_pass, "np.var:", x.var())
print("ddof=0:", np.var([1.0, 2.0, 3.0, 4.0]), "ddof=1:", np.var([1.0, 2.0, 3.0, 4.0], ddof=1))
```
```output
истинная дисперсия: 2.0
наивная формула сильно промахнулась: True
двухпроходная: 2.0 np.var: 2.0
ddof=0: 1.25 ddof=1: 1.6666666666666667
```

**Пример 4. softmax.**

```python run
import numpy as np

z = np.array([[1000.0, 1001.0, 999.0]])
with np.errstate(over="ignore", invalid="ignore"):
    naive = np.exp(z) / np.exp(z).sum(axis=1, keepdims=True)
print("наивный:", naive)

shifted = z - z.max(axis=1, keepdims=True)
stable = np.exp(shifted) / np.exp(shifted).sum(axis=1, keepdims=True)
print("устойчивый:", np.round(stable, 6), "сумма равна 1:", np.isclose(stable.sum(), 1.0, rtol=0, atol=1e-12))
```
```output
наивный: [[nan nan nan]]
устойчивый: [[0.244728 0.665241 0.090031]] сумма равна 1: True
```

## Типичные ошибки

* **Путать `axis=0` и `axis=1`.** Проверяйте форму результата: `axis=0` убирает первую ось. На квадратной матрице путаницу не заметит интерпретатор — заметит только тест с несимметричными данными.
* **Забыть `keepdims=True` при нормировке.** Результат `(n,)` не делит строки, как вы ожидали (см. [broadcasting](lesson:python.numpy.broadcasting)).
* **Использовать `E[x^2] - E[x]^2`.** При большом среднем получится ноль или даже отрицательная дисперсия. Сначала вычитайте среднее.
* **Не знать про `ddof`.** `np.var` по умолчанию делит на `n`, а не на `n - 1`; для оценки по выборке нужен `ddof=1`.
* **Softmax без вычитания максимума.** Результат — `nan` при больших значениях логитов.
* **Считать `argmax` значением.** `argmax` — это индекс; значение даёт `max`.
* **Накапливать `float32` в `float32` на больших массивах.** Укажите `dtype=np.float64` у `sum` / `mean`, если важна точность.

<!-- section: summary -->
## Итоги

* `axis=k` убирает ось `k`; `keepdims=True` оставляет её с длиной 1.
* `argmax` возвращает индекс вдоль оси (первый при равенстве).
* `ddof` задаёт делитель `n - ddof`: 0 для совокупности, 1 для несмещённой оценки по выборке.
* Дисперсию считайте двухпроходно (сначала среднее), а softmax — после вычитания максимума строки.
* Проверяйте реализации на несимметричных данных и данных с большим смещением.
