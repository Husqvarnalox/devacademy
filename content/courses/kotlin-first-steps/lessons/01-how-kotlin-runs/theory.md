## Kotlin: компилятор kotlinc и JVM

Kotlin - язык, который компилируется в **байткод JVM** (тот же формат `.class`, что и у Java), а затем выполняется на JVM. Поэтому Kotlin-программа запускается там же, где Java, и может вызывать Java-библиотеки.

Приложение делает два шага:

1. `kotlinc` компилирует все `.kt`-файлы в архив `prog.jar` и добавляет в него стандартную библиотеку Kotlin (`-include-runtime`).
2. `java -jar prog.jar` запускает этот архив на JVM.

Точка входа - функция верхнего уровня `fun main()`. Классы для неё писать не нужно: компилятор сам создаёт класс `MainKt` для файла `Main.kt`.

```kotlin
fun main() {
    val n = readln().toInt()
    println(n * 2)
}
```

`readln()` читает строку из stdin (бросает исключение, если ввод закончился), `readlnOrNull()` возвращает `null` в конце ввода. `println` пишет строку в stdout.

## Подробнее

**Что делает kotlinc.** Он проверяет типы, затем генерирует байткод. Файл верхнего уровня `Main.kt` превращается в класс `MainKt`, а функция `main` - в статический метод. Для запуска требуется стандартная библиотека Kotlin, поэтому она вкладывается в jar. Дальше JVM работает так же, как для Java: загрузка классов, интерпретация, JIT-компиляция горячего кода.

**Скорость запуска.** Компиляция `kotlinc` заметно дольше запуска: сам компилятор - это JVM-программа, поэтому каждый запуск включает старт JVM. Это нормально для обучающей проверки и обычно не мешает в больших проектах, где сборка выполняется инкрементально.

**`val` и `var`.** `val` объявляет переменную, которую нельзя переприсвоить (аналог `final` в Java), `var` - изменяемую. `val` не делает объект неизменяемым: `val list = mutableListOf(1)` позволяет `list.add(2)`, но нельзя написать `list = ...`. Типы выводятся: `val x = 5` - это `Int`.

**Числа.** `Int` - 32 бита, `Long` - 64 бита (литерал `5L`), `Double` - 64 бита. Преобразования между числовыми типами явные: `x.toLong()`, `n.toDouble()`. Переполнение `Int` тихое, как в Java: `Int.MAX_VALUE + 1` равно `Int.MIN_VALUE`. Деление целых усекает: `7 / 2` равно `3`.

**Строки.** Шаблоны: `"sum=$sum"` и `"${a + b}"`. Многострочные строки пишутся в тройных кавычках.

**Ввод целиком.** Для чисел, разбросанных по строкам, удобнее прочитать весь stdin: `System.in.bufferedReader().readText()`, разбить на слова через `split(Regex("\\s+"))` и отфильтровать пустые элементы (после ведущих пробелов первый элемент пустой). Преобразование - `toLong()`.

**Форматирование.** `"%.2f".format(Locale.ROOT, x)` использует точку как разделитель независимо от региональных настроек. Без `Locale` берётся локаль по умолчанию, и в некоторых системах получится запятая.

**Выражения.** `if` и `when` в Kotlin - выражения, у них есть значение: `val m = if (a > b) a else b`. Для цикла: `for (i in 0 until n)`, а `repeat(n) { ... }` выполняет блок `n` раз.

## Примеры

В Kotlin-блоках ниже вывод показан в комментариях: сборка и запуск происходят в упражнении.

**Пример 1. `val`, `var` и вывод типов.**

```kotlin
fun main() {
    val a = 7
    var b = 2
    b += 1
    println(a / b)          // 2
    println(a / b.toDouble()) // 2.3333333333333335
}
```

**Пример 2. Переполнение и Long.**

```kotlin
fun main() {
    println(Int.MAX_VALUE + 1)          // -2147483648
    println(2_000_000_000L + 2_000_000_000L) // 4000000000
}
```

**Пример 3. Чтение всего stdin.**

```kotlin
import java.util.Locale

fun main() {
    val words = System.`in`.bufferedReader().readText()
        .split(Regex("\\s+")).filter { it.isNotEmpty() }
    val nums = words.drop(1).map { it.toLong() }
    println("sum=${nums.sum()}")
    println("avg=" + "%.2f".format(Locale.ROOT, nums.average()))
}
```

Слово `in` в Kotlin зарезервировано, поэтому `System.in` пишут в обратных кавычках.

**Пример 4. `if` как выражение.**

```kotlin
fun sign(x: Long): String = if (x < 0) "minus" else if (x == 0L) "zero" else "plus"

fun main() {
    println(sign(-5))  // minus
    println(sign(0))   // zero
}
```

## Типичные ошибки

* **Сумма в `Int`.** Два числа по 2 000 000 000 переполняют `Int`. Используйте `Long` и `toLong()`.
* **Деление `Long` на `Int` с ожиданием дроби.** Результат целый. Нужно `sum.toDouble() / n`.
* **Забыть `Locale`.** `"%.2f".format(x)` в русской локали даст запятую.
* **Пустые слова после `split`.** Если ввод начинается с пробела, первый элемент пуст; `toLong()` на нём бросит `NumberFormatException`. Фильтруйте пустые строки.
* **Присваивание `val`.** `val x = 1; x = 2` - ошибка компиляции. Если значение должно меняться, нужен `var`.
* **Путать `readln` и `readlnOrNull`.** Первая бросает исключение в конце ввода, вторая возвращает `null`.
* **Писать `System.in` без кавычек.** `in` - ключевое слово, нужны обратные кавычки.

## Итоги

* `kotlinc` компилирует `.kt` в байткод JVM; `java -jar` запускает его вместе со стандартной библиотекой Kotlin.
* Точка входа - `fun main()` на верхнем уровне файла.
* `val` нельзя переприсвоить, `var` можно; числовые преобразования явные; переполнение `Int` тихое.
* Для вывода с точкой используйте `Locale.ROOT`.
