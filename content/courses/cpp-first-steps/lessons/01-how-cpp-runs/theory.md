## C++: из исходников в машинный код заранее

C++ - **компилируемый заранее** (AOT, ahead-of-time) язык. До запуска программы специальная программа - компилятор - переводит ваш код в машинные инструкции процессора и записывает исполняемый файл. Во время работы нет ни интерпретатора, ни виртуальной машины, ни сборщика мусора: процессор выполняет готовый машинный код.

Приложение запускает примерно такую команду:

```
clang++ -std=c++23 -pthread -O2 -Wall -Wextra main.cpp -o prog
./prog
```

* `-std=c++23` - версия стандарта языка;
* `-pthread` - подключить поддержку потоков (нужна `std::thread` на Linux, на macOS безвредна);
* `-O2` - включить оптимизации;
* `-Wall -Wextra` - показать предупреждения о подозрительном коде.

Минимальная программа:

```cpp
#include <iostream>

int main() {
    std::cout << "привет\n";
}
```

`#include` подставляет текст заголовочного файла, `main` - точка входа. Вывод - `std::cout <<`, ввод - `std::cin >>`.

## Подробнее

**Этапы сборки.** Препроцессор обрабатывает `#include` и макросы; компилятор переводит каждый `.cpp` (единицу трансляции) в объектный файл; **компоновщик** (linker) объединяет объектные файлы и библиотеки в исполняемый файл. Ошибка типов - ошибка компиляции, «не найден символ» - ошибка компоновки.

**Поведение ошибок во время работы.** Компилятор не проверяет выход за границы массива в `v[i]`: это **неопределённое поведение** (undefined behavior). Программа может упасть, выдать мусор или работать «правильно». Метод `v.at(i)` проверяет границы и бросает `std::out_of_range`. Переполнение знаковых целых (`int`) тоже неопределённое поведение, в отличие от беззнаковых, где оно определено как «заворачивание».

**Типы.** `int` обычно 32 бита, `long long` - не меньше 64 бит. Для сумм используйте `long long` (или `std::int64_t` из `<cstdint>`). Деление целых усекает к нулю: `7 / 2` равно `3`, `-7 / 2` равно `-3`.

**Ввод-вывод.** `std::cin >> a >> b` читает значения, разделённые пробельными символами, включая переводы строк. Вывод дробных чисел: `std::cout << std::fixed << std::setprecision(2) << x` (нужен `<iomanip>`). Поток `cout` по умолчанию использует классическую локаль `C`, то есть точку. Для ускорения на больших вводах пишут `std::ios::sync_with_stdio(false); std::cin.tie(nullptr);`.

**Стандартная библиотека.** `std::vector<T>` - динамический массив, `std::string` - строка, `std::min`/`std::max` - в `<algorithm>`. Пространство имён `std::` обязательно, если не написано `using namespace std;` (в учебных программах допустимо, в больших проектах нежелательно).

**Память.** Локальные переменные живут на стеке и уничтожаются при выходе из блока. Динамическая память под `std::vector` и `std::string` управляется самими объектами. Явные `new` и `delete` в современном коде почти не нужны (подробнее - в следующем уроке).

**Предупреждения.** `-Wall -Wextra` ловят, например, неиспользуемые переменные и сравнение знаковых с беззнаковыми. Относитесь к ним как к ошибкам.

## Примеры

**Пример 1. Целочисленное деление и приведение.**

```cpp run
#include <iostream>

int main() {
    int a = 7, b = 2;
    std::cout << a / b << "\n";
    std::cout << static_cast<double>(a) / b << "\n";
    std::cout << -7 / 2 << "\n";
    std::cout << -7 % 2 << "\n";
}
```
```output
3
3.5
-3
-1
```

**Пример 2. Размеры типов и `long long`.**

```cpp run
#include <iostream>

int main() {
    long long big = 2000000000LL + 2000000000LL;
    std::cout << big << "\n";
    std::cout << sizeof(char) << "\n";
    std::cout << (sizeof(long long) >= 8) << "\n";
}
```
```output
4000000000
1
1
```

**Пример 3. Формат вещественных.**

```cpp run
#include <iomanip>
#include <iostream>

int main() {
    double x = 5.0 / 3;
    std::cout << std::fixed << std::setprecision(2) << x << "\n";
    std::cout << std::setprecision(0) << 2.5 << "\n";
}
```
```output
1.67
2
```

**Пример 4. `vector` и проверка границ.**

```cpp run
#include <iostream>
#include <stdexcept>
#include <vector>

int main() {
    std::vector<int> v{10, 20, 30};
    try {
        std::cout << v.at(1) << "\n";
        std::cout << v.at(5) << "\n";
    } catch (const std::out_of_range&) {
        std::cout << "out_of_range\n";
    }
}
```
```output
20
out_of_range
```

**Пример 5. Типовая форма чтения.**

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        long long x;
        std::cin >> x;
        sum += x;
    }
    std::cout << sum << "\n";
}
```

## Типичные ошибки

* **Сумма в `int`.** Переполнение знакового `int` - неопределённое поведение. Используйте `long long`.
* **`7 / 2` вместо дробного.** Приведите один операнд: `static_cast<double>(sum) / n`.
* **Неинициализированные переменные.** `int x;` содержит мусор; читать его - неопределённое поведение. Пишите `int x = 0;`.
* **`v[i]` за границами.** Нет ошибки, есть неопределённое поведение. Для отладки используйте `at`.
* **Забыть `#include`.** Без `<vector>` или `<iomanip>` программа не компилируется.
* **Игнорировать предупреждения.** Они часто указывают на реальные ошибки.
* **Использовать значение после неудачного чтения.** После сбоя `cin >> x` поток в состоянии ошибки; проверяйте `if (!(std::cin >> x))`.
* **Сравнение `int` с `v.size()`.** `size()` беззнаковый; отрицательное число превращается в огромное.

## Итоги

* C++ компилируется в машинный код до запуска: препроцессор, компилятор, компоновщик; рантайма-интерпретатора нет.
* Проверки времени выполнения не навязываются: выход за границы и переполнение `int` - неопределённое поведение.
* `long long` для сумм, `static_cast<double>` до деления, `std::fixed` и `setprecision` для вывода.
* Включайте `-Wall -Wextra` и читайте предупреждения.
