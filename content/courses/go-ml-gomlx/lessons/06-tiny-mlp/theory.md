## Маленькая нейронная сеть и переобучение

Логистическая регрессия проводит между классами **прямую**. Если классы разделяются не прямой, а, например, кругом (точка «снаружи» круга - класс 1, «внутри» - класс 0), линейная модель не справится. Решение - добавить **скрытый слой**: сначала несколько линейных комбинаций признаков, затем нелинейная функция, затем ещё одна линейная комбинация.

```text
вход x (16) → h = tanh(x W1 + b1) (64) → z = h W2 + b2 (1) → вероятность σ(z)
```

Это **многослойный перцептрон (MLP)**. Нелинейность `tanh` существенна: без неё два линейных слоя схлопываются в один (второй пример проверяет это числами). Параметров в такой сети `16*64 + 64 + 64*1 + 1 = 1153`. Учится она тем же способом, что и предыдущие модели: потеря, `graph.Gradient` по всем четырём параметрам, шаг против градиента. Новыми будут только размерности и функции `MatMul` и `Tanh`; именно для этого вы потратили три урока на графы, градиенты и спуск.

Вторая большая тема урока - **переобучение**. Сеть из 1153 параметров легко запоминает 100 обучающих точек, включая **шум**. В упражнении 10% меток перевёрнуты специально, и 14 из 16 признаков не несут информации. Что происходит при долгом обучении:

* на обучающих данных точность растёт вплоть до 100%, потеря стремится к нулю;
* на отдельной проверочной выборке потеря после некоторого момента **растёт**, а точность остаётся заметно ниже обучающей.

Разрыв между обучением и проверкой и называется переобучением. Подробнее о переобучении и разбиении выборки на train/validation/test вы читали в курсе [«Основы машинного обучения»](lesson:ml.foundations.what-is-ml). В этом уроке вы увидите его в числах и попробуете одно из лекарств - **L2-регуляризацию** (в задаче со звёздочкой).

## Точные правила

**Форма сети.** `x` - `[n, 16]`, `W1` - `[16, 64]`, `b1` - `[1, 64]`, `W2` - `[64, 1]`, `b2` - `[1, 1]`. `graph.MatMul(a, b)` умножает матрицы `[n, k]` на `[k, m]`. Смещения хранятся как `[1, m]`, потому что расширение (см. урок 2) требует равного ранга. Метки `y` имеют форму `[n, 1]`, как и выход.

**Инициализация.** Нулевые веса недопустимы: все скрытые нейроны получили бы одинаковые градиенты и остались бы одинаковыми навсегда. Веса берут случайными с масштабом порядка `1/sqrt(fan_in)`, где `fan_in` - число входов слоя (так сделана функция `initWeights` в упражнении). Смещения можно начинать с нуля. Генератор задан фиксированным зерном, поэтому запуск воспроизводим.

**Потеря и обновление.** Потеря та же, что в предыдущем уроке: `mean(softplus(z) - y z)` по логитам. `Gradient(loss, W1, b1, W2, b2)` возвращает четыре градиента в порядке аргументов, и каждый параметр обновляется как `p - lr * grad`. Здесь `lr = 0.3`, пакет - все 100 точек, один шаг на эпоху.

**Переобучение измеряют на отложенных данных.** Тестовая выборка (400 точек) не участвует в градиентах; по ней считают потерю и точность. Если потеря на тесте растёт, а на обучении падает, модель запоминает.

**L2-регуляризация.** К потере добавляют штраф `λ/2 * (Σ W1² + Σ W2²)`. Градиент штрафа по весу `W` равен `λ W`: каждый шаг дополнительно «сжимает» веса к нулю. Смещения обычно не штрафуют. Чем больше `λ`, тем меньше норма весов; при слишком большом `λ` модель недообучается, то есть плохо работает уже на обучающих данных. Штраф входит в *обучаемую* потерю, но не обязан входить в печатаемую `train/test loss`: сравнивать модели надо по одинаковой метрике.

**Что не доказывают числа из курса.** Одна выборка, одно зерно, один набор гиперпараметров. Вывод «L2 с `λ = 0.004` лучше» относится к этому эксперименту. На другом зерне оптимум сместится. Настоящая оценка требует нескольких зёрен или кросс-валидации.

**Масштаб.** Это учебная сеть для CPU: 1000 эпох на чистом Go-бэкенде занимают доли секунды, потому что данных мало. Для больших моделей такой бэкенд не подходит; здесь на сцену выходит XLA и GPU (см. урок 1).

## Примеры

**Пример 1. Без нелинейности слои схлопываются.**

```go run
package main

import (
	"fmt"

	"github.com/gomlx/compute"
	_ "github.com/gomlx/compute/gobackend"
	"github.com/gomlx/gomlx/core/graph"
	"github.com/gomlx/gomlx/core/tensors"
)

func main() {
	backend, err := compute.NewWithConfig("go")
	if err != nil {
		panic(err)
	}
	// Two linear layers without an activation are ONE linear layer: (x W1) W2 = x (W1 W2).
	// With tanh in between the equality breaks, which is exactly what makes the network more expressive.
	exec := graph.MustNewExec(backend, func(x, w1, w2 *graph.Node) []*graph.Node {
		stacked := graph.MatMul(graph.MatMul(x, w1), w2)
		merged := graph.MatMul(x, graph.MatMul(w1, w2))
		withTanh := graph.MatMul(graph.Tanh(graph.MatMul(x, w1)), w2)
		return []*graph.Node{stacked, merged, withTanh, graph.MatMul(x, w1)}
	})
	x := tensors.FromValue([][]float32{{1, 2}, {-1, 0.5}})
	w1 := tensors.FromValue([][]float32{{1, -1, 0.5}, {0.5, 2, -1}})
	w2 := tensors.FromValue([][]float32{{1}, {0.5}, {2}})
	out := exec.MustExec(x, w1, w2)
	fmt.Println("hidden shape:", out[3].Shape(), "output shape:", out[0].Shape())
	show := func(name string, t *tensors.Tensor) {
		v := t.Value().([][]float32)
		fmt.Printf("%-16s %.3f %.3f\n", name, v[0][0], v[1][0])
	}
	show("stacked linear:", out[0])
	show("one merged layer:", out[1])
	show("with tanh:", out[2])
}
```

```output
hidden shape: (Float32)[2, 3] output shape: (Float32)[2, 1]
stacked linear:  0.500 -1.750
one merged layer: 0.500 -1.750
with tanh:       -0.349 -1.676
```

Строки «stacked linear» и «one merged layer» совпадают: `(x W1) W2 = x (W1 W2)`. Значит, сеть без `tanh` умеет только то, что умеет одна линейная модель. С `tanh` результат другой, и именно эта разница даёт сети дополнительную выразительность.

**Пример 2. XOR: то, что не решает прямая.**

```go run
package main

import (
	"fmt"
	"math/rand"

	"github.com/gomlx/compute"
	_ "github.com/gomlx/compute/gobackend"
	"github.com/gomlx/gomlx/core/graph"
	"github.com/gomlx/gomlx/core/tensors"
)

func forward(x, w1, b1, w2, b2 *graph.Node) *graph.Node {
	h := graph.Tanh(graph.Add(graph.MatMul(x, w1), b1))
	return graph.Add(graph.MatMul(h, w2), b2)
}

func step(x, y, w1, b1, w2, b2 *graph.Node) []*graph.Node {
	z := forward(x, w1, b1, w2, b2)
	loss := graph.ReduceAllMean(graph.Sub(graph.Softplus(z), graph.Mul(y, z)))
	g := graph.Gradient(loss, w1, b1, w2, b2)
	upd := func(p, grad *graph.Node) *graph.Node { return graph.Sub(p, graph.MulScalar(grad, 0.5)) }
	return []*graph.Node{upd(w1, g[0]), upd(b1, g[1]), upd(w2, g[2]), upd(b2, g[3]), loss}
}

func random(rng *rand.Rand, rows, cols int) *tensors.Tensor {
	m := make([][]float32, rows)
	for i := range m {
		m[i] = make([]float32, cols)
		for j := range m[i] {
			m[i][j] = float32(rng.NormFloat64())
		}
	}
	return tensors.FromValue(m)
}

func main() {
	backend, err := compute.NewWithConfig("go")
	if err != nil {
		panic(err)
	}
	// XOR: no straight line separates {(0,0),(1,1)} from {(0,1),(1,0)}, a hidden layer does.
	x := tensors.FromValue([][]float32{{0, 0}, {0, 1}, {1, 0}, {1, 1}})
	y := tensors.FromValue([][]float32{{0}, {1}, {1}, {0}})
	rng := rand.New(rand.NewSource(1))
	w1, b1 := random(rng, 2, 8), tensors.FromValue([][]float32{make([]float32, 8)})
	w2, b2 := random(rng, 8, 1), tensors.FromValue([][]float32{{0}})

	train := graph.MustNewExec(backend, step)
	predict := graph.MustNewExec(backend, func(x, w1, b1, w2, b2 *graph.Node) *graph.Node {
		return graph.Sigmoid(forward(x, w1, b1, w2, b2))
	})
	for epoch := 1; epoch <= 3000; epoch++ {
		out := train.MustExec(x, y, w1, b1, w2, b2)
		w1, b1, w2, b2 = out[0], out[1], out[2], out[3]
		if epoch == 1 || epoch == 3000 {
			p := predict.MustExec(x, w1, b1, w2, b2)[0].Value().([][]float32)
			fmt.Printf("epoch %4d: loss = %.3f predictions = %.2f %.2f %.2f %.2f\n", epoch, out[4].Value(), p[0][0], p[1][0], p[2][0], p[3][0])
		}
	}
}
```

```output
epoch    1: loss = 1.121 predictions = 0.45 0.80 0.13 0.66
epoch 3000: loss = 0.001 predictions = 0.00 1.00 1.00 0.00
```

Задача XOR: классы `{(0,0), (1,1)}` и `{(0,1), (1,0)}` не разделимы прямой. Сеть с восемью скрытыми нейронами сводит потерю с `1.1` практически к нулю за 3000 эпох и предсказывает вероятности около `0, 1, 1, 0`. Первая строка зависит от случайной инициализации; важен итог.

Для упражнения в цифрах (при тех же гиперпараметрах: 1000 эпох, `lr = 0.3`): точность на обучении достигает `1.000`, на тесте остаётся около `0.75`. Потеря на обучении между 300 и 1000 эпохами падает с `0.315` до `0.064`, а на тесте *растёт* с `0.658` до `0.694`. Лучшее значение тестовой потери в проверенных запусках - `0.602` при 500 эпохах, то есть остановить обучение раньше было бы полезнее (ранняя остановка). Это и есть переобучение.

## Типичные ошибки

* **Нет нелинейности.** Модель вырождается в линейную и не отделяет круг. Это ловушка заготовки упражнения.
* **Нулевая инициализация весов.** Все нейроны скрытого слоя одинаковы; обучение не «ломает симметрию».
* **Слишком большой масштаб инициализации.** `tanh` насыщается, градиенты почти нулевые.
* **Форма смещения `[64]` вместо `[1, 64]`.** Ранги не совпадают: сложение `[n, 64]` и `[64]` невозможно.
* **Оценка по обучающей выборке.** Точность 100% на train ничего не говорит об обобщении.
* **Подбор `λ` по тестовой выборке и вывод «стало лучше».** Тестовую выборку нельзя использовать для выбора гиперпараметров, иначе оценка завышена; для этого нужна отдельная проверочная выборка.
* **Слишком сильная регуляризация.** При `λ = 0.1` веса схлопываются к нулю, модель ничего не предсказывает (точность около `0.5`).
* **Включение штрафа в печатаемую потерю.** Тогда числа с разным `λ` несопоставимы.
* **Вывод по одному запуску.** Разница в сотых долях на одном зерне может быть случайной.

<!-- section: summary -->
## Итоги

* MLP: линейный слой, нелинейность `tanh`, линейный слой; параметры обновляются градиентным спуском с помощью `graph.Gradient`.
* Без нелинейности любое число линейных слоёв эквивалентно одному.
* Переобучение видно по разрыву train/test: потеря на тесте перестаёт убывать и растёт, пока на обучении падает к нулю.
* L2-регуляризация сжимает веса: умеренное `λ` улучшает тестовую потерю, слишком большое ведёт к недообучению.
* Выводы из одного эксперимента ограничены: настоящую оценку дают несколько зёрен и отдельная проверочная выборка.

## Факты

* По теореме универсальной аппроксимации сеть с одним скрытым слоем достаточной ширины может приблизить широкий класс непрерывных функций; теорема ничего не говорит о том, найдёт ли такое приближение градиентный спуск и как много данных нужно.
* L2-регуляризация в линейных моделях известна как гребневая регрессия (регуляризация Тихонова).
