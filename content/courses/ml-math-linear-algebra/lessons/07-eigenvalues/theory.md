## Направления, которые матрица только растягивает

Ковариационная матрица данных, матрица переходов в PageRank, матрица вторых производных функции потерь - всё это квадратные матрицы, и у каждой есть особые направления, которые определяют поведение системы. Собственные векторы и значения показывают, вдоль каких направлений дисперсия данных максимальна (основа метода главных компонент), к какому распределению сходится случайное блуждание по страницам и какой шаг обучения допустим при градиентном спуске.

Квадратная матрица `A` действует на вектор `v` как отображение: `v → Av`. Обычно результат отличается от `v` и длиной, и направлением. Но у многих матриц есть ненулевые векторы, которые не поворачиваются, а только растягиваются (или сжимаются, или меняют знак):

`A v = λ v`

Такой вектор `v` называется **собственным вектором** матрицы `A`, а число `λ` (лямбда) - соответствующим **собственным значением**. Вектор `v` определён с точностью до умножения на число: если `v` собственный, то и `3v`, и `-v` тоже. Поэтому обычно берут вектор длины 1, и знак всё равно остаётся произвольным.

Примеры. У диагональной матрицы `diag(3, 1)` собственные векторы - оси координат: `(1, 0)` растягивается в 3 раза, `(0, 1)` остаётся на месте. У симметричной матрицы `[[2, 1], [1, 2]]` собственные векторы повёрнуты на 45°: `(1, 1)/√2` для `λ = 3` и `(1, -1)/√2` для `λ = 1`. У поворота плоскости на 90° действительных собственных векторов нет - любое направление поворачивается; в таком случае собственные значения комплексные (`±i`).

**Как найти.** Условие `Av = λv` равносильно `(A - λI) v = 0`; ненулевое решение есть, только если `det(A - λI) = 0`. Для матрицы `2 × 2` это квадратное уравнение `λ² - след · λ + определитель = 0`; для `[[2, 1], [1, 2]]` получаем `λ² - 4λ + 3 = 0`, откуда `λ = 3` и `λ = 1`. Для больших матриц этот путь не используют. Вместо него применяют итерации; самая простая - **степенной метод**: взять любой вектор и много раз умножать его на `A`, нормируя длину. Компонента вдоль направления с наибольшим `|λ|` растёт быстрее всех остальных, и вектор выстраивается вдоль доминирующего собственного вектора.

## Примеры

**Пример 1. Степенной метод на чистом Python.** Матрица `[[2, 1], [1, 3]]`: её наибольшее собственное значение `(5 + √5)/2 ≈ 3.618`. Стартуем с вектора `(1, 0)` и смотрим, как оценка `λ` приближается к точному значению.

```python run
import math

A = [[2.0, 1.0], [1.0, 3.0]]

def matvec(A, v):
    return [sum(a * x for a, x in zip(row, v)) for row in A]

def norm(v):
    return math.sqrt(sum(x * x for x in v))

v = [1.0, 0.0]
for step in range(1, 7):
    w = matvec(A, v)                 # растягиваем и поворачиваем
    v = [x / norm(w) for x in w]     # возвращаем длину 1
    lam = sum(a * b for a, b in zip(v, matvec(A, v)))   # Rayleigh: v^T A v при |v| = 1
    print(step, [round(x, 4) for x in v], round(lam, 6))

print("точное значение:", round((5 + math.sqrt(5)) / 2, 6))
Av = matvec(A, v)
print("A v - lam v =", [round(a - lam * b, 6) for a, b in zip(Av, v)])
```
```output
1 [0.8944, 0.4472] 3.0
2 [0.7071, 0.7071] 3.5
3 [0.6, 0.8] 3.6
4 [0.5547, 0.8321] 3.615385
5 [0.5369, 0.8437] 3.617647
6 [0.53, 0.848] 3.617978
точное значение: 3.618034
A v - lam v = [-0.009528, 0.005955]
```

Разбор:

* `matvec` - произведение матрицы на вектор из прошлых уроков: скалярное произведение каждой строки с `v`.
* Деление на `norm(w)` возвращает длину 1. Без него вектор растёт (или стремится к нулю) в `|λ|` раз за шаг; направление при этом то же.
* `lam` - **отношение Рэлея** `vᵀAv / vᵀv`. При `|v| = 1` знаменатель равен 1. Для собственного вектора оно равно `λ`, а для почти собственного даёт очень точную оценку: уже на шаге 4 три знака верны.
* Ошибка убывает в `|λ₂|/|λ₁|` раз за шаг; здесь `λ₂ = (5 - √5)/2 ≈ 1.382`, отношение `≈ 0.38`. Остаток `Av - λv` после шести шагов порядка `0.01` и продолжает уменьшаться.

**Пример 2. Стационарное распределение и PageRank.** Три страницы; `P[i][j]` - вероятность перейти со страницы `i` на страницу `j` (в каждой строке сумма 1). С вероятностью `0.15` пользователь «прыгает» на случайную страницу - это матрица `G`. Распределение `p` по страницам обновляется как `p ← pG`; предельное `p` - это собственный вектор `G` слева с `λ = 1`, то есть `p = pG`.

```python run
P = [[0.0, 0.5, 0.5],
     [0.0, 0.0, 1.0],
     [0.5, 0.5, 0.0]]
d = 0.85
n = len(P)
G = [[d * P[i][j] + (1 - d) / n for j in range(n)] for i in range(n)]

p = [1 / n] * n                # начинаем с равномерного распределения
for step in range(1, 51):
    p = [sum(p[i] * G[i][j] for i in range(n)) for j in range(n)]   # p <- p G
    if step in (1, 2, 5, 50):
        print(step, [round(x, 4) for x in p], "сумма =", round(sum(p), 6))

pG = [sum(p[i] * G[i][j] for i in range(n)) for j in range(n)]
print("p = pG:", all(abs(a - b) < 1e-9 for a, b in zip(p, pG)))
```
```output
1 [0.1917, 0.3333, 0.475] сумма = 1.0
2 [0.2519, 0.3333, 0.4148] сумма = 1.0
5 [0.2325, 0.3333, 0.4341] сумма = 1.0
50 [0.2339, 0.3333, 0.4327] сумма = 1.0
p = pG: True
```

* Каждая строка `G` суммируется в 1, поэтому сумма компонент `p` остаётся равной 1 на каждом шаге - нормировать по длине (как в примере 1) здесь не нужно.
* Это тот же степенной метод, только вектор умножается на матрицу слева (`p ← pG`), то есть работает с `Gᵀ`. Наибольшее собственное значение матрицы переходов равно 1; остальные по модулю меньше 1, поэтому ошибка быстро затухает: уже на 5-м шаге компоненты `p` отличаются от предельных меньше чем на `0.002`.
* Итог: страница 3 (последняя строка `P`) важнее страницы 1 (`0.43` против `0.23`), потому что на неё ведёт больше ссылок. Так ранжирует страницы алгоритм PageRank; для интернета матрица огромна, и степенной метод - практически единственный способ.
* Прыжок с вероятностью `0.15` гарантирует сходимость для любой структуры ссылок; без него (`d = 1.0`) в этом примере получилось бы `[0.2222, 0.3333, 0.4444]`.

**Пример 3. То же в NumPy.** `np.linalg.eigh` предназначена для симметричных матриц (результат отсортирован по возрастанию), `np.linalg.eig` - для произвольных (значения могут быть комплексными).

```python run
import numpy as np

S = np.array([[2.0, 1.0], [1.0, 2.0]])
vals, vecs = np.linalg.eigh(S)           # симметричная матрица: значения по возрастанию
print("eigh значения:", vals.round(6))
print("S V = V diag(vals):", np.allclose(S @ vecs, vecs * vals))
print("V^T V = I:", np.allclose(vecs.T @ vecs, np.eye(2)))

R = np.array([[0.0, -1.0], [1.0, 0.0]])  # поворот на 90 градусов
print("eig поворота:", np.linalg.eig(R)[0])

# ковариация облака точек, вытянутого вдоль направления (3, 1)
rng = np.random.default_rng(0)
X = rng.normal(size=(500, 2)) @ np.array([[3.0, 1.0], [0.0, 0.5]])
cvals, cvecs = np.linalg.eigh(np.cov(X.T))
axis = cvecs[:, -1]                      # собственный вектор наибольшего значения
axis = axis * np.sign(axis[0])           # знак вектора произволен - фиксируем сами
print("дисперсии вдоль осей:", cvals.round(3))
print("главная ось:", axis.round(3))
```
```output
eigh значения: [1. 3.]
S V = V diag(vals): True
V^T V = I: True
eig поворота: [0.+1.j 0.-1.j]
дисперсии вдоль осей: [0.21 9.74]
главная ось: [0.946 0.324]
```

* `vecs * vals` умножает каждый столбец `vecs` на своё значение, то есть вычисляет `V·diag(vals)`; равенство `S V = V Λ` - матричная запись `Av = λv` для всех пар сразу.
* `V^T V = I`: собственные векторы симметричной матрицы ортогональны и имеют длину 1.
* Поворот не имеет действительных собственных векторов, поэтому `eig` возвращает комплексные значения `±i`.
* У ковариации облака точек наибольшее собственное значение `9.74` - дисперсия вдоль главной оси, направленной примерно вдоль `(3, 1)`; вдоль перпендикулярной оси дисперсия всего `0.21`. Это идея метода главных компонент, которому посвящён следующий урок. Знак `axis` у `eigh` зависит от реализации LAPACK, поэтому он фиксируется вручную.

**Попробуйте.** В примере 1 поменяйте старт на `v = [1.0, -1.0]`: значение `λ` то же, а вектор стремится к собственному вектору с противоположным знаком. Затем возьмите `A = [[1.0, 0.0], [0.0, -1.0]]` и старт `[1.0, 1.0]`: предскажите, что станет с `v`, и объясните, почему степенной метод здесь не сходится.

## Определения и свойства

Для квадратной матрицы `A` ненулевой вектор `v` и число `λ` образуют **собственную пару**, если `Av = λv`. Все собственные значения - корни **характеристического многочлена** `det(A - λI)` степени `n`, поэтому их `n` штук с учётом кратности (возможно, комплексных). Сумма собственных значений равна следу матрицы (сумме диагонали), произведение - определителю; матрица вырождена тогда и только тогда, когда среди значений есть `0`.

**Симметричные матрицы** (`A = Aᵀ`) - частый случай в ML: ковариационная матрица, `XᵀX` из прошлого урока, гессиан, матрица Грама. Для них:

* все собственные значения действительны;
* собственные векторы, отвечающие разным значениям, ортогональны, и можно выбрать ортонормированный базис из собственных векторов;
* **спектральное разложение** `A = V Λ Vᵀ`, где столбцы `V` - собственные векторы (`VᵀV = I`), а `Λ = diag(λ₁, ..., λₙ)`. Так `A` записывается как «повернуть - растянуть вдоль осей - повернуть обратно».

Если все `λᵢ ≥ 0`, матрица называется **неотрицательно определённой**; ковариационные матрицы и `XᵀX` всегда такие, поскольку `vᵀ(XᵀX)v = ‖Xv‖² ≥ 0`.

**Степенной метод.** Пусть `|λ₁| > |λ₂| ≥ ...`, а стартовый вектор имеет ненулевую составляющую вдоль `v₁`. Тогда последовательность `v ← Av / ‖Av‖` сходится к `±v₁`, а ошибка убывает как `|λ₂/λ₁|ᵏ` после `k` шагов. Один шаг стоит `O(n²)` для плотной матрицы (умножение матрицы на вектор) и `O(число ненулевых элементов)` для разреженной. Если `λ₁ < 0`, знак вектора меняется на каждом шаге, поэтому в упражнении знак фиксируется явно. При `|λ₁| = |λ₂|` (например, `+1` и `-1`) метод не сходится.

**Отношение Рэлея** `R(v) = vᵀAv / vᵀv`. Для симметричной `A` оно лежит между наименьшим и наибольшим собственными значениями и достигает максимума `λ₁` на `v₁`. Поэтому дисперсия данных вдоль единичного направления `u` равна `uᵀSu` (где `S` - ковариация), а направление максимальной дисперсии - собственный вектор `S` с наибольшим значением.

**NumPy.** `np.linalg.eig(A)` работает для любой квадратной матрицы и может вернуть комплексные числа; `np.linalg.eigh(S)` - только для симметричных (использует одну треугольную половину), быстрее, устойчивее, возвращает действительные значения по возрастанию и ортонормированные векторы-столбцы. Собственные векторы определены с точностью до знака: два корректных запуска могут вернуть `v` и `-v`, поэтому тесты и сравнения делают с учётом знака.

**Где используется.**

* **Метод главных компонент (PCA):** собственные векторы ковариационной матрицы - главные оси, собственные значения - дисперсии вдоль них.
* **PageRank и цепи Маркова:** стационарное распределение - собственный вектор матрицы переходов с `λ = 1`.
* **Оптимизация:** у квадратичной функции потерь `L(w) = ½ wᵀHw - bᵀw` градиентный спуск `w ← w - lr · ∇L` сходится, только если `lr < 2/λ_max(H)`. Отношение `λ_max/λ_min` (число обусловленности) определяет скорость: чем оно больше, тем длиннее «овраг» и медленнее спуск. Это объясняет, почему стандартизация признаков ускоряет обучение линейной регрессии из урока [«Линейная регрессия с нуля»](lesson:ml.foundations.linear-regression); для потерь `½·MSE` в ней `H = XᵀX/n`.
* **Спектральная кластеризация, графовые нейросети:** собственные векторы матриц графа.

## Типичные ошибки

* **Нет нормировки в степенном методе.** Симптом: числа растут до `inf` или падают до `0`, затем `nan`. Причина: вектор умножается на `A` без деления на длину. Исправление: делить на `‖Av‖` на каждом шаге.
* **Стартовый вектор ортогонален главному.** Симптом: метод «сошёлся» к другому вектору или остался на месте. Причина: составляющая вдоль `v₁` равна нулю и никогда не появится. Исправление: взять вектор из единиц или случайный вектор.
* **Скачущий знак при отрицательном `λ₁`.** Симптом: `v` не сходится, хотя `Av ≈ λv` выполняется. Причина: на каждом шаге вектор переворачивается. Исправление: сравнивать направления с точностью до знака или фиксировать знак после каждого шага.
* **Одинаковые по модулю значения `λ₁` и `λ₂`.** Симптом: вектор колеблется между двумя значениями. Причина: нет «победителя» по скорости роста. Исправление: сдвиг `A + cI` или другой алгоритм (`eigh`).
* **`eig` вместо `eigh` для симметричной матрицы.** Симптом: порядок значений произвольный, ортогональность столбцов при кратных значениях не гарантируется, иногда результат имеет комплексный тип. Исправление: для симметричных матриц применять `np.linalg.eigh`.
* **Строки вместо столбцов.** Симптом: проверка `A @ v == lam * v` не проходит. Причина: собственные векторы лежат в **столбцах** `vecs`, `vecs[i]` - строка. Исправление: `vecs[:, i]`.
* **Сравнение векторов без учёта знака.** Симптом: тест «падает» на другой машине. Исправление: сравнивать `|vᵀu|` с `1` или заранее фиксировать знак.
* **Лево- и правосторонние векторы.** Стационарное `p` удовлетворяет `p = pP` (строка слева), а не `Pp = p`; для `P` со строками-вероятностями это собственный вектор `Pᵀ`.

<!-- section: summary -->
## Итоги

* Собственная пара `Av = λv`: вектор, который матрица только растягивает; определён с точностью до масштаба и знака.
* Симметричные матрицы (ковариация, `XᵀX`, гессиан) имеют действительные значения и ортогональные векторы; `A = VΛVᵀ`.
* Степенной метод `v ← Av/‖Av‖` находит доминирующий собственный вектор; скорость определяется `|λ₂/λ₁|`; оценка значения - отношение Рэлея.
* PageRank и стационарное распределение цепи Маркова - собственный вектор с `λ = 1`; главные оси данных - собственные векторы ковариации; допустимый шаг обучения ограничен `2/λ_max`.
* В NumPy для симметричных матриц используйте `eigh`; знаки векторов произвольны.

## Почему степенной метод работает, и что за пределами

Пусть симметричная `A` имеет ортонормированные собственные векторы `v₁, ..., vₙ` и стартовый вектор `x = c₁v₁ + ... + cₙvₙ`. Тогда `Aᵏx = c₁λ₁ᵏv₁ + ... + cₙλₙᵏvₙ = λ₁ᵏ (c₁v₁ + c₂(λ₂/λ₁)ᵏv₂ + ...)`. Все слагаемые, кроме первого, содержат степени отношения `|λᵢ/λ₁| < 1` и затухают; нормировка нужна лишь для того, чтобы числа не вышли за диапазон `float64`. Эта же формула показывает, почему нужно `c₁ ≠ 0`.

Чтобы найти не только главный вектор, применяют **дефляцию**: вычитают найденную компоненту `A - λ₁v₁v₁ᵀ` и повторяют метод. Практичнее использовать готовые методы библиотеки LAPACK (их вызывает `eigh`) или итерации Ланцоша для больших разреженных матриц. Если нужны собственные значения несимметричной матрицы (например, матрицы переходов), `np.linalg.eig(A)` возвращает правые векторы `Av = λv`; левые векторы `uA = λu` получаются из `eig(A.T)`.
