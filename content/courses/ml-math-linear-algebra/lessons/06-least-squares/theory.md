## Лучшая прямая, когда точная невозможна

Линейная регрессия, из которой вырастают и простые прогнозы цен, и последний слой многих нейросетей, сводится к одной задаче: подобрать веса так, чтобы предсказания как можно меньше отличались от ответов. Из прошлого урока вы знаете, как решить систему уравнений, у которой столько же уравнений, сколько неизвестных. В данных так почти не бывает: объектов (строк) обычно намного больше, чем признаков.

Пусть `X` - матрица `n × d` (по строке на объект, по столбцу на признак), `y` - вектор ответов длины `n`, `w` - вектор весов длины `d`. Требование `Xw = y` - это `n` уравнений с `d` неизвестными. При `n > d` такая система **переопределена**: точного решения нет, потому что данные содержат шум и точки не лежат на одной прямой. Вместо равенства ищут вектор `w`, для которого `Xw` максимально близко к `y`. Разность `r = y - Xw` называется **остатком** (вектором ошибок), а мера близости - сумма квадратов остатков `‖Xw - y‖² = r₁² + ... + rₙ²`. Это ровно `n · MSE`, поэтому минимизировать её - то же самое, что минимизировать среднеквадратичную ошибку. Метод называется **методом наименьших квадратов**.

**Свободный член.** Прямая `y = w₀ + w₁x` содержит константу `w₀`. Чтобы она не требовала отдельной формулы, к `X` дописывают столбец из единиц: `Xb = [1 | X]`. Тогда `w₀` - вес при этом столбце, и вся модель снова имеет вид `Xb · w`.

**Геометрия.** Все возможные результаты `Xb · w` - это линейные комбинации столбцов `Xb`; они заполняют «плоскость» (подпространство) в пространстве длины `n`. Вектор `y` в эту плоскость обычно не попадает. Ближайшая к нему точка плоскости - его ортогональная проекция, а остаток `r` - перпендикуляр, опущенный на плоскость. Перпендикуляр ортогонален каждому столбцу, то есть скалярное произведение остатка с каждым столбцом равно нулю: `Xbᵀ (y - Xb w) = 0`. Раскрыв скобки, получаем **нормальные уравнения**:

`Xbᵀ Xb · w = Xbᵀ y`

Это квадратная система `(d + 1) × (d + 1)`, и её уже можно решать методом Гаусса.

## Примеры

**Пример 1. Прямая «площадь - цена» на чистом Python.** Четыре квартиры, цена в миллионах рублей. Соберём нормальные уравнения вручную и решим систему `2 × 2` по формулам Крамера.

```python run
# площадь (м^2) -> цена (млн руб.)
area = [30.0, 50.0, 70.0, 90.0]
price = [3.2, 4.8, 7.1, 8.9]

# матрица Xb: столбец единиц и столбец площадей
Xb = [[1.0, a] for a in area]

# собираем Xb^T Xb и Xb^T y вручную
XtX = [[sum(r[i] * r[j] for r in Xb) for j in range(2)] for i in range(2)]
Xty = [sum(r[i] * p for r, p in zip(Xb, price)) for i in range(2)]
print("XtX =", XtX)
print("Xty =", Xty)

# система 2x2 решается по формулам Крамера
det = XtX[0][0] * XtX[1][1] - XtX[0][1] * XtX[1][0]
w0 = (Xty[0] * XtX[1][1] - XtX[0][1] * Xty[1]) / det
w1 = (XtX[0][0] * Xty[1] - Xty[0] * XtX[1][0]) / det
print("w =", [round(w0, 4), round(w1, 4)])

pred = [w0 + w1 * a for a in area]
res = [p - q for p, q in zip(price, pred)]
print("остатки:", [round(e, 4) for e in res])
print("все |Xb^T r| < 1e-9:", all(abs(sum(r[i] * e for r, e in zip(Xb, res))) < 1e-9 for i in range(2)))
print("MSE =", round(sum(e * e for e in res) / len(res), 4))
```
```output
XtX = [[4.0, 240.0], [240.0, 16400.0]]
Xty = [24.0, 1634.0]
w = [0.18, 0.097]
остатки: [0.11, -0.23, 0.13, -0.01]
все |Xb^T r| < 1e-9: True
MSE = 0.0205
```

Разбор:

* `Xb` имеет строки `[1, площадь]`; `XtX[i][j]` - скалярное произведение столбцов `i` и `j`, а `Xty[i]` - скалярное произведение столбца `i` с ответами. Так выглядит произведение `XbᵀXb` без матричной библиотеки.
* `det` - определитель `XtX`; он отличен от нуля, поэтому у системы единственное решение. Формулы для `w0` и `w1` - правило Крамера для системы `2 × 2`.
* Модель: цена = `0.18 + 0.097 · площадь`, то есть около 97 тыс. рублей за квадратный метр.
* Остатки в сумме дают `0`, а скалярные произведения остатка со столбцом единиц и со столбцом площадей равны нулю - это и есть условие `Xbᵀ r = 0`. Прямая не проходит ни через одну точку, но ошибки уравновешены.

**Пример 2. Когда `XtX` вырождена.** Допустим, в таблицу по ошибке попал дубликат признака: площадь записана дважды. Столбцы `Xb` линейно зависимы, и нормальные уравнения перестают иметь единственное решение. Добавка `λ` к диагонали (кроме элемента свободного члена) это исправляет.

```python run
area = [30.0, 50.0, 70.0, 90.0]
Xb = [[1.0, a, a] for a in area]       # третий столбец повторяет второй
d = 3

def gram(l2):
    G = [[sum(r[i] * r[j] for r in Xb) for j in range(d)] for i in range(d)]
    for i in range(1, d):              # свободный член (i = 0) не штрафуем
        G[i][i] += l2
    return G

def det3(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
            - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))

print("det(XtX)             =", det3(gram(0.0)))
print("det(XtX + 1.0 * I')  =", round(det3(gram(1.0)), 1))
```
```output
det(XtX)             = 0.0
det(XtX + 1.0 * I')  = 16004.0
```

* Нулевой определитель означает, что решить систему методом Гаусса нельзя (в упражнении `solve` выбросит `ValueError`).
* `gram(l2)` строит `XbᵀXb + l2 · I'`, где `I'` - единичная матрица с нулём на позиции `(0, 0)`. После добавки определитель положителен, решение единственно. Это **гребневая (ridge) регрессия**.

**Пример 3. То же в NumPy.** Три способа получить веса и сравнение обусловленности.

```python run
import numpy as np

area = np.array([30.0, 50.0, 70.0, 90.0])
price = np.array([3.2, 4.8, 7.1, 8.9])
Xb = np.column_stack([np.ones(4), area])

w_normal = np.linalg.solve(Xb.T @ Xb, Xb.T @ price)
w_lstsq, *_ = np.linalg.lstsq(Xb, price, rcond=None)
print("нормальные уравнения:", w_normal.round(4))
print("np.linalg.lstsq:     ", w_lstsq.round(4))

# обусловленность: матрица XtX хуже, чем сама X
print("cond(X)   =", round(np.linalg.cond(Xb), 1))
print("cond(XtX) =", round(np.linalg.cond(Xb.T @ Xb), 1))

# ridge: свободный член не штрафуем
pen = 1000.0 * np.eye(2)
pen[0, 0] = 0.0
w_ridge = np.linalg.solve(Xb.T @ Xb + pen, Xb.T @ price)
print("ridge, alpha=1000:", w_ridge.round(4))

# дубликат признака: XtX вырождена, а lstsq возвращает решение минимальной нормы
Xd = np.column_stack([np.ones(4), area, area])
w_d, _, rank, _ = np.linalg.lstsq(Xd, price, rcond=None)
print("ранг =", rank, "веса:", w_d.round(4))
```
```output
нормальные уравнения: [0.18  0.097]
np.linalg.lstsq:      [0.18  0.097]
cond(X)   = 183.4
cond(XtX) = 33634.4
ridge, alpha=1000: [2.12   0.0647]
ранг = 2 веса: [0.18   0.0485 0.0485]
```

* `lstsq` возвращает четыре значения; нужны первое (веса) и, для диагностики, третье (ранг матрицы).
* `cond(XtX)` примерно равно `cond(X)` в квадрате (`183.4² ≈ 33 636`): формирование `XᵀX` возводит число обусловленности в квадрат, и теряется около половины верных знаков. Поэтому библиотеки решают задачу через QR или SVD, не строя `XᵀX`.
* Ridge с большим `alpha` сжимает наклон (`0.097` → `0.0647`), а свободный член растёт, чтобы сохранить среднюю цену.
* С дубликатом признака ранг равен `2`, а не `3`: `lstsq` выбрала решение с наименьшей нормой, поделив вес `0.097` поровну между двумя одинаковыми столбцами.

**Попробуйте.** В примере 1 замените цену `8.9` на `12.0` и предскажите, как изменится наклон `w1`, прежде чем запускать. В примере 3 поставьте `alpha = 0` и убедитесь, что получились веса обычных наименьших квадратов.

## Определения и формулы

Задача наименьших квадратов: найти `w`, минимизирующий `L(w) = ‖Xb w - y‖²`. Градиент `∇L = 2 Xbᵀ (Xb w - y)`; приравняв его к нулю, снова получаем нормальные уравнения `Xbᵀ Xb w = Xbᵀ y`. Функция `L` выпукла, поэтому найденная точка - глобальный минимум, и градиентный спуск из урока [«Линейная регрессия с нуля»](lesson:ml.foundations.linear-regression) сходится к тому же ответу (при подходящем шаге).

**Когда решение единственно.** Матрица `XbᵀXb` обратима тогда и только тогда, когда столбцы `Xb` линейно независимы. Она вырождена, если есть дублирующиеся или пропорциональные признаки, признак-константа (совпадает со столбцом единиц), признаки, связанные суммой (например, доли категорий, дающие в сумме 1), или `d + 1 > n` (признаков не меньше, чем объектов). Тогда минимум достигается на целом семействе весов.

**Ridge (L2-регуляризация).** Минимизируется `‖Xb w - y‖² + λ ‖w₁:‖²`, где штраф не включает свободный член `w₀`. Нормальные уравнения превращаются в `(XbᵀXb + λ I') w = Xbᵀ y`; `I'` - единичная матрица с нулём в позиции `(0, 0)`. Для `λ > 0` матрица `XbᵀXb + λI'` всегда обратима, решение единственно, а веса сжимаются к нулю тем сильнее, чем больше `λ`. Свободный член не штрафуют, чтобы сдвиг всех ответов на константу не менял наклоны.

**Метрика.** `R² = 1 - SS_res / SS_tot`, где `SS_res = Σ(yᵢ - ŷᵢ)²`, `SS_tot = Σ(yᵢ - ȳ)²`. Значение `1` - идеальное предсказание, `0` - не лучше, чем предсказывать среднее, отрицательное - хуже среднего.

**Сложность.** Построение `XbᵀXb` стоит `O(n · d²)`, решение системы - `O(d³)`. При большом `d` дорого именно второе, при большом `n` - первое. `np.linalg.lstsq` работает через SVD, примерно за `O(n · d²)`.

**Численная устойчивость.** `cond(XᵀX) = cond(X)²`: при `cond(X) ≈ 10⁸` матрица нормальных уравнений уже почти вырождена в формате `float64` (около 16 десятичных знаков). QR-разложение и SVD работают с `X` напрямую, поэтому `np.linalg.lstsq` и `sklearn` не обращаются к `XᵀX`. Для небольших хорошо обусловленных задач нормальные уравнения - быстрый и понятный способ.

**Где используется.** Линейная и полиномиальная регрессия; гребневая регрессия как базовый метод борьбы с переобучением и коллинеарностью; подгонка последнего слоя модели на готовых эмбеддингах; метод наименьших квадратов внутри алгоритмов, которые на каждом шаге решают линейную подзадачу.

## Типичные ошибки

* **Забыли столбец единиц.** Симптом: прямая обязана проходить через начало координат, остатки систематически смещены (их сумма не равна нулю). Причина: нет свободного члена. Исправление: `Xb = [[1.0] + row for row in X]`.
* **Обращение `XᵀX` и умножение на `Xᵀy`.** Симптом: неточные веса на почти зависимых признаках. Причина: обращение матрицы медленнее и менее устойчиво, чем решение системы. Исправление: `solve(XtX, Xty)` или `lstsq`.
* **`ValueError` или `LinAlgError: Singular matrix`.** Симптом: ошибка на данных с дубликатами признаков или с `d` больше `n`. Причина: `XᵀX` вырождена. Исправление: убрать зависимые признаки, добавить `λ > 0` или использовать `lstsq` (решение минимальной нормы).
* **Штраф на свободный член.** Симптом: при увеличении `λ` предсказания тянутся к нулю, а не к среднему ответу. Причина: в `I'` на позиции `(0, 0)` стоит `1`. Исправление: обнулить этот элемент.
* **Разные масштабы признаков при ridge.** Штраф одинаков для всех весов, поэтому признак в километрах штрафуется иначе, чем тот же признак в миллиметрах. Исправление: стандартизировать признаки перед регуляризацией.
* **Путаница порядка в `y - Xw`.** Остаток `y - Xw` и ошибка `Xw - y` отличаются знаком; в проверке `Xᵀr = 0` знак не важен, а в формуле градиента важен.

<!-- section: summary -->
## Итоги

* Переопределённая система `Xw = y` точного решения не имеет; метод наименьших квадратов минимизирует `‖Xw - y‖²` (то есть MSE).
* Свободный член вводится столбцом единиц; остаток оптимального решения ортогонален всем столбцам `Xb`, что даёт нормальные уравнения `XbᵀXb w = Xbᵀy`.
* Для вырожденной `XbᵀXb` помогает ridge: `(XbᵀXb + λI') w = Xbᵀy` с нештрафуемым свободным членом.
* Численно надёжнее `np.linalg.lstsq`: прямое формирование `XᵀX` возводит число обусловленности в квадрат.
* Градиентный спуск и нормальные уравнения находят один и тот же минимум.

## Проекция на столбцы

Если столбцы `Xb` линейно независимы, решение нормальных уравнений даёт `ŷ = Xb (XbᵀXb)⁻¹ Xbᵀ y = H y`. Матрица `H` называется **проекционной** (в статистике - «шляпной»): `H² = H`, `Hᵀ = H`, а её след равен числу столбцов `d + 1`. Это объясняет геометрию урока: `H` отправляет любой вектор в плоскость столбцов по перпендикуляру. Диагональные элементы `H` показывают, насколько сильно каждая точка тянет модель на себя; точки с большим `Hᵢᵢ` (выбросы по признакам) называют точками с высоким рычагом.

Ridge-решение тоже имеет форму `ŷ = H_λ y`, но след `H_λ` меньше `d + 1`: чем больше `λ`, тем меньше «эффективное число параметров» модели. Через SVD (для центрированных признаков) это записывается явно: каждая компонента решения умножается на `sᵢ² / (sᵢ² + λ)`, где `sᵢ` - сингулярные числа `X`, поэтому направления с малыми `sᵢ` (шумные, почти зависимые) подавляются сильнее всего. К этому выводу курс вернётся в последнем уроке.
