## Из результата обратно к причине

Прямая задача выглядит так: известны веса `x` и признаки `A`, нужно получить предсказания `A x`. В ML часто нужна обратная: известны признаки `A` и ответы `b`, а подобрать надо веса `x`, чтобы `A x = b`. Так выводят формулы линейной регрессии (следующий урок), решают задачи на гауссовых процессах, считают стационарное распределение марковской цепи. Все эти задачи сводятся к **системе линейных уравнений**.

Пример из жизни. Три чека из магазина: в первом 2 булки хлеба, 1 пакет молока и 1 упаковка яиц - 260 рублей; во втором 1 хлеб и 2 молока - 200; в третьем 3 хлеба и 1 яйца - 220. Нужно найти цены. Если `x = (x_1, x_2, x_3)` - цены хлеба, молока и яиц, то получается система `2·x_1 + x_2 + x_3 = 260`, `x_1 + 2·x_2 = 200`, `3·x_1 + x_3 = 220`. В матричном виде `A x = b`: `A` - **матрица коэффициентов** (строка на каждый чек), `x` - неизвестные, `b` - правые части.

Стандартный способ решения - **метод Гаусса** (исключение). Из уравнений вычитают другие уравнения, умноженные на числа, и так обнуляют коэффициенты под главной диагональю. Получается **треугольная** система, которая решается снизу вверх (**обратный ход**): последнее уравнение содержит одну неизвестную, её подставляют в предыдущее и так далее. Элемент, на который делят при обнулении, называют **ведущим** (pivot). Если он равен нулю или очень мал, делить на него нельзя, поэтому перед шагом выбирают строку с наибольшим по модулю элементом в столбце и ставят её наверх (**частичный выбор ведущего элемента**).

Бывает, что система не решается. Если третий чек - это «два первых минус второй», он ничего нового не сообщает (или противоречит остальным), и однозначных цен найти нельзя. Такая матрица называется **вырожденной** (сингулярной): её строки линейно зависимы. Признак вырожденности - **определитель** `det A` равен нулю. Определитель - число, которое показывает, во сколько раз отображение `x → A x` растягивает площадь (в трёх измерениях - объём). Ноль означает, что пространство схлопывается и часть информации теряется.

Если матрица невырождена, существует **обратная матрица** `A⁻¹`: `A⁻¹ A = A A⁻¹ = I`, и решение записывается как `x = A⁻¹ b`. Но на практике обратную матрицу почти никогда не строят: `x` находят прямо методом Гаусса.

## Примеры

**Пример 1. Метод Гаусса с выбором ведущего элемента.** Решаем систему о ценах и систему, в которой на месте первого ведущего стоит нуль.

```python run
def solve(A, b):
    n = len(A)
    M = [list(map(float, row)) + [float(bi)] for row, bi in zip(A, b)]   # расширенная матрица [A | b]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))        # частичный выбор ведущего
        M[col], M[pivot] = M[pivot], M[col]
        for r in range(col + 1, n):
            factor = M[r][col] / M[col][col]
            M[r] = [a - factor * c for a, c in zip(M[r], M[col])]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):                                      # обратный ход
        s = sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return x


# чеки: хлеб, молоко, яйца (штук в покупке) -> итоговая сумма
A = [[2, 1, 1],
     [1, 2, 0],
     [3, 0, 1]]
b = [260, 200, 220]
print([round(v, 6) for v in solve(A, b)])

# ведущий элемент A[0][0] = 0: без перестановки строк делить пришлось бы на ноль
print([round(v, 6) for v in solve([[0, 1], [2, 1]], [3, 7])])
```
```output
[40.0, 80.0, 100.0]
[2.0, 3.0]
```

Разбор:

* `M` - расширенная матрица `[A | b]`: правая часть переносится вместе со строками, поэтому одна операция над строкой меняет сразу и коэффициенты, и `b`.
* Для каждого столбца `col` выбираем строку с наибольшим по модулю элементом (`max(..., key=...)`), меняем её местами с текущей, затем вычитаем её, умноженную на `factor`, из строк ниже - под диагональю остаются нули.
* Обратный ход идёт с последней строки: `x[i] = (b_i - Σ_{j>i} m_ij·x_j) / m_ii`.
* Цены: хлеб 40, молоко 80, яйца 100 (первый чек: `2·40 + 80 + 100 = 260`).
* Во втором запуске `A[0][0] = 0`: без перестановки пришлось бы делить на ноль, а выбор ведущего ставит вторую строку наверх.

**Пример 2. Определитель, обратная матрица и вырожденность.** Определитель считается теми же шагами: произведение ведущих элементов, знак меняется при каждой перестановке строк. Обратную матрицу получаем методом Гаусса - Жордана: преобразуем `[A | I]` в `[I | A⁻¹]`.

```python run
def determinant(A):
    n = len(A)
    M = [list(map(float, row)) for row in A]
    det = 1.0
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))
        if abs(M[pivot][col]) < 1e-12:
            return 0.0
        if pivot != col:
            M[col], M[pivot] = M[pivot], M[col]
            det = -det                                   # перестановка строк меняет знак
        det *= M[col][col]
        for r in range(col + 1, n):
            factor = M[r][col] / M[col][col]
            M[r] = [a - factor * c for a, c in zip(M[r], M[col])]
    return det


def inverse(A):
    n = len(A)
    M = [list(map(float, row)) + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(A)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))
        if abs(M[pivot][col]) < 1e-12:
            raise ValueError("матрица вырождена")
        M[col], M[pivot] = M[pivot], M[col]
        M[col] = [v / M[col][col] for v in M[col]]
        for r in range(n):
            if r != col:
                M[r] = [a - M[r][col] * c for a, c in zip(M[r], M[col])]
    return [row[n:] for row in M]


print(determinant([[2, 1], [1, 1]]), determinant([[0, 1], [1, 0]]), determinant([[1, 2], [2, 4]]))
inv = inverse([[2, 1], [1, 1]])
print([[round(v, 6) + 0.0 for v in row] for row in inv])
```
```output
1.0 -1.0 0.0
[[1.0, -1.0], [-1.0, 2.0]]
```

* `det [[2, 1], [1, 1]] = 2·1 - 1·1 = 1`. Для `[[0, 1], [1, 0]]` (обмен координат) нужна одна перестановка строк, поэтому `-1`: отрицательный определитель означает отражение.
* У `[[1, 2], [2, 4]]` вторая строка вдвое больше первой: второй ведущий после исключения равен нулю, определитель `0`, а `inverse` на такой матрице выбросит `ValueError`.
* В `inverse` строка делится на ведущий элемент, после чего из **всех** остальных строк (и выше, и ниже) вычитается кратное ей. Справа остаётся `A⁻¹`: для `[[2, 1], [1, 1]]` это `[[1, -1], [-1, 2]]`; проверка: `2·1 + 1·(-1) = 1`, `2·(-1) + 1·2 = 0`.

**Пример 3. То же в NumPy и число обусловленности.** Функции `np.linalg.solve`, `det`, `inv`, `cond`; матрица, близкая к вырожденной, показывает, чем опасны малые ошибки данных.

```python run
import numpy as np

A = np.array([[2.0, 1.0, 1.0], [1.0, 2.0, 0.0], [3.0, 0.0, 1.0]])
b = np.array([260.0, 200.0, 220.0])
print(np.round(np.linalg.solve(A, b), 6))
print(round(np.linalg.det(A), 6), np.round(np.linalg.inv(A) @ b, 6))

try:
    np.linalg.solve(np.array([[1.0, 2.0], [2.0, 4.0]]), np.array([1.0, 2.0]))
except np.linalg.LinAlgError as e:
    print("LinAlgError:", e)

H = np.array([[1.0, 1.0], [1.0, 1.0001]])          # почти вырожденная матрица
b = np.array([2.0, 2.0001])
print("cond:", round(np.linalg.cond(H)))
print(np.round(np.linalg.solve(H, b), 6))
print(np.round(np.linalg.solve(H, b + np.array([0.0, 0.00005])), 6))
```
```output
[ 40.  80. 100.]
-3.0 [ 40.  80. 100.]
LinAlgError: Singular matrix
cond: 40002
[1. 1.]
[0.5 1.5]
```

* `np.linalg.solve(A, b)` решает систему (внутри - разложение Гаусса с выбором ведущего); `np.linalg.inv(A) @ b` даёт то же, но дороже и менее точно. Определитель `-3`: объём растягивается втрое, ориентация меняется. Для вырожденной матрицы `solve` выбрасывает `LinAlgError`.
* `H` невырождена, но её столбцы почти параллельны: `cond(H) ≈ 40 000`. Правую часть сдвинули на `0.00005` - около `0.002%` её длины, - а решение изменилось с `(1, 1)` на `(0.5, 1.5)`, на десятки процентов: малая ошибка в данных стала большой ошибкой в весах.

**Попробуйте.** В примере 1 замените третий чек на `[3, 0, 2]`, а `b` - на `[260, 200, 320]`: третий чек стал «два первых минус второй», система вырождена. Решение теперь не единственно, и `solve` вернёт набор цен, который определяют лишь ошибки округления: последний ведущий элемент почти нулевой. Поэтому в упражнении такой случай распознают как ошибку. В примере 3 вычислите `np.linalg.cond(np.eye(3))` и объясните ответ.

## Система уравнений и метод Гаусса

**Система** `A x = b`, где `A` - матрица `n × n`, `x, b ∈ ℝⁿ`. Решением называют вектор `x`, при подстановке которого все уравнения верны.

**Прямой ход:** для столбца `k = 1..n` выбрать строку `r ≥ k` с наибольшим `|a_rk|`, поменять её со строкой `k`, затем для каждой строки `i > k` вычесть из неё строку `k`, умноженную на `a_ik / a_kk`. Результат - верхнетреугольная матрица. **Обратный ход:** `x_i = (b_i - Σ_{j>i} u_ij·x_j) / u_ii` для `i = n..1`.

**Зачем выбирать ведущий элемент.** Нулевой ведущий делить нельзя. Малый ведущий (но не нулевой) делает множители `a_ik / a_kk` огромными и усиливает ошибки округления. Пример: `[[10⁻²⁰, 1], [1, 1]] x = [1, 2]` имеет решение `x ≈ (1, 1)`, но исключение без перестановки строк в арифметике `float` даёт `(0, 1)`; с перестановкой получается `(1, 1)`.

**Сложность:** прямой ход - порядка `(2/3)·n³` операций, обратный - `n²`.

## Вырожденные матрицы

Для квадратной `A` равносильны: `A` невырождена; `det A ≠ 0`; столбцы (и строки) линейно независимы; `A x = 0` только при `x = 0`; `A x = b` имеет единственное решение для любого `b`; `A⁻¹` существует. Если `A` вырождена, решений либо нет, либо бесконечно много. В данных это **линейная зависимость признаков** (мультиколлинеарность), например цена в рублях и в долларах по фиксированному курсу: веса при таких признаках определены неоднозначно.

## Определитель

Определитель равен произведению ведущих элементов, умноженному на `(-1)^s`, где `s` - число перестановок строк. Свойства: `det I = 1`; `det(A B) = det A · det B`; `det Aᵀ = det A`; перестановка двух строк меняет знак. Геометрически `|det A|` - коэффициент изменения площади (объёма), знак показывает, сохраняется ли ориентация. Для `2 × 2`: `det [[a, b], [c, d]] = a·d - b·c`.

## Обратная матрица

`A⁻¹` определяется условием `A A⁻¹ = A⁻¹ A = I`; `(A B)⁻¹ = B⁻¹ A⁻¹`. Метод Гаусса - Жордана преобразует `[A | I]` в `[I | A⁻¹]`, что стоит порядка `2n³` операций - примерно втрое больше, чем решение одной системы. К тому же ошибки накапливаются при построении всех `n²` элементов `A⁻¹`. Поэтому вместо `x = A⁻¹ b` используют `solve(A, b)`; обратная матрица нужна, лишь если требуются все её элементы (например, ковариационная матрица оценок параметров).

## Обусловленность

**Число обусловленности** `cond(A) ≥ 1` - наибольший коэффициент растяжения отображения `A`, делённый на наименьший (в `L2`-норме). Оно ограничивает рост относительной ошибки: если `A x = b` и `A (x + dx) = b + db`, то

`|dx| / |x| ≤ cond(A) · |db| / |b|`.

Грубое правило: при `cond(A) ≈ 10^k` теряется порядка `k` верных десятичных цифр. У единичной матрицы `cond = 1`, у вырожденной - бесконечность; чем ближе столбцы к параллельным, тем больше `cond`.

## Где это встречается

* **Линейная регрессия:** нормальные уравнения `(Xᵀ X) w = Xᵀ y` - система относительно весов `w`; зависимые признаки делают `Xᵀ X` вырожденной, а регуляризация `(Xᵀ X + λ I) w = Xᵀ y` уменьшает `cond`.
* **Гауссовы процессы, метод Ньютона, марковские цепи:** `K α = y` с матрицей ядра, шаг Ньютона, стационарное распределение - линейные системы.

## Типичные ошибки

* **`inv(A) @ b` вместо `solve(A, b)`.** Результат выглядит верно, но вычисления дороже и менее точны. Признак: заметная невязка `A x - b` на плохо обусловленных матрицах. Исправление: `np.linalg.solve(A, b)`.
* **Деление на нулевой ведущий.** Без перестановки строк система вроде `[[0, 1], [2, 1]]` приводит к `ZeroDivisionError`. Исправление: выбирать строку с наибольшим `|a_ik|` перед каждым шагом.
* **Сравнение определителя с нулём напрямую.** Из-за округления определитель вырожденной матрицы может оказаться `1e-17`, а не `0`. Исправление: сравнивать ведущие элементы с малым порогом (`1e-12`) относительно масштаба матрицы; для оценки близости к вырожденности смотреть на `cond`.
* **Вера в результат без проверки.** Для почти вырожденной матрицы `solve` исключения не выбросит (оно возникает при точно нулевом ведущем), но вернёт неточное решение. Признак: огромные веса, сильная зависимость от шума. Исправление: проверять `np.linalg.cond(A)` и невязку `|A x - b| / |b|`.
* **Изменение входных данных.** Исключение «на месте» портит `A` и `b`, которые вызывающему коду ещё нужны. Исправление: работать с копией (расширенная матрица `[A | b]` из новых строк).
* **Неквадратная матрица.** `solve` определена для квадратных `A`; при лишних уравнениях задачу решает метод наименьших квадратов (следующий урок).

<!-- section: summary -->
## Итоги

* Система `A x = b` описывает обратную задачу: найти веса `x`, дающие ответы `b`. Решается методом Гаусса: прямой ход с выбором ведущего элемента и обратный ход.
* Матрица вырождена, если её строки линейно зависимы; тогда `det A = 0`, и решение либо не существует, либо не единственно.
* Определитель - произведение ведущих элементов со знаком от перестановок; `|det|` показывает изменение площади (объёма).
* Обратная матрица `A⁻¹` строится методом Гаусса - Жордана, но для решения систем лучше `solve`: дешевле и точнее.
* Число обусловленности `cond(A)` показывает, во сколько раз малая ошибка в `b` может вырасти в ошибке `x`.

Дальше: [метод наименьших квадратов](lesson:ml.math.least-squares) - что делать, если уравнений больше, чем неизвестных, и точного решения нет.

## LU-разложение

Исключение Гаусса раскладывает матрицу в произведение `P A = L U`: `P` - перестановки строк, `L` - нижнетреугольная матрица множителей `a_ik / a_kk`, `U` - верхнетреугольная (результат прямого хода). Тогда `A x = b` распадается на две дешёвые подстановки: `L y = P b` и `U x = y`, по `O(n²)` каждая. Разложение делают один раз, а затем быстро обрабатывают много правых частей - так устроен `np.linalg.solve(A, B)` для матрицы `B` с несколькими столбцами. Определитель читается оттуда же: `det A = ± Π u_ii`. Для больших матриц произведение сотен чисел переполняется или уходит в нуль, поэтому используют `np.linalg.slogdet`: он возвращает знак и `log|det|` отдельно.
