## Что проверяет эта проверка

Цикл событий: синхронный код, микрозадачи (промисы, `await`) и макрозадачи (таймеры), цепочки `then`/`catch`, `Promise.all`/`allSettled`/`race`, `return` и `return await` внутри `try`, ограничение параллелизма и времени ожидания, отмена через `AbortController`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитывается урок: [Цикл событий, промисы и async/await](lesson:javascript.fundamentals.promises-and-async).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

## Пример того, что понадобится

```javascript run
const wait = (ms, value) => new Promise((resolve) => setTimeout(resolve, ms, value));

async function withTimeout(promise, ms) {
  let id;
  const timer = new Promise((_, reject) => {
    id = setTimeout(() => reject(new Error("timeout")), ms);
  });
  try {
    return await Promise.race([promise, timer]);
  } finally {
    clearTimeout(id);
  }
}

console.log("старт");
withTimeout(wait(10, "быстро"), 500).then(console.log);
withTimeout(wait(200, "медленно"), 20).catch((e) => console.log(e.message));
console.log("конец синхронной части");
```
```output
старт
конец синхронной части
быстро
timeout
```

`Promise.race` возвращает результат первого завершившегося промиса, а `finally` останавливает таймер в любом исходе. Порядок вывода определяется очередями, а не порядком строк.

<!-- section: precise -->
## Что нужно уметь

* называть порядок: синхронный код, затем микрозадачи, затем следующая макрозадача (таймер);
* знать, что тело `async`-функции выполняется синхронно до первого `await`;
* различать `Promise.all` (отказ при первой ошибке), `allSettled` (никогда не отказывает) и `race` (первый завершившийся);
* объяснять, что `catch` в цепочке возвращает её в успешное состояние;
* понимать, что `return promise` в `try` не ловится `catch`, а `return await promise` ловится;
* ограничивать число одновременных задач общим счётчиком и «рабочими»;
* ставить тайм-аут через `Promise.race` и отменять работу через `AbortController`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* `forEach` и `async`-колбэк: цикл не ждёт завершения, надо `for...of` с `await` или `Promise.all(map(...))`.
* Запуск всех задач сразу (`Promise.all(tasks.map(run))`) вместо ограничения параллелизма.
* Тайм-аут без `clearTimeout` держит процесс и таймер активными.
* Пачки по `limit` вместо скользящего окна: одна медленная задача задерживает всю пачку.
* Ошибка, брошенная синхронно из функции, которая обещала вернуть промис, обходит `catch` вызывающего.
