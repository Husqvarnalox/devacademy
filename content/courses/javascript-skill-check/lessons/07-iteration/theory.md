## Что проверяет эта проверка

Протокол итерации (`Symbol.iterator`, `next`, `return`), отличие итерируемого объекта от одноразового итератора, генераторы и `yield`, ленивые конвейеры над бесконечными источниками, `for...of` против `for...in`, подводные камни методов массивов (`sort`, `map(parseInt)`).

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитывается урок: [Массивы, итерация и генераторы](lesson:javascript.fundamentals.arrays-and-iteration).

<!-- section: examples -->
## Пример того, что понадобится

```javascript run
function* naturals() {
  for (let i = 1; ; i++) yield i;
}
function* take(iterable, n) {
  if (n <= 0) return;
  let count = 0;
  for (const x of iterable) {
    yield x;
    if (++count >= n) return;
  }
}
const squares = (function* () {
  for (const x of naturals()) yield x * x;
})();
console.log([...take(squares, 4)]);
```
```output
[ 1, 4, 9, 16 ]
```

Источник бесконечный, но конвейер ленивый: значения вычисляются по одному по мере запросов, и `take` останавливает обход после четвёртого.

<!-- section: precise -->
## Что нужно уметь

* реализовать `[Symbol.iterator]()` у собственного класса так, чтобы объект можно было обойти многократно;
* объяснять, что генератор не выполняет код до первого `next()` и приостанавливается на каждом `yield`;
* строить цепочки `map`/`filter`/`take` на генераторах без промежуточных массивов;
* знать, что выход из `for...of` через `return` или `break` вызывает `return()` у итератора и закрывает ресурс;
* различать `for...of` (значения по итератору) и `for...in` (перечислимые ключи);
* помнить про сортировку по строкам по умолчанию и про лишний аргумент-индекс у колбэков.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Попытка превратить бесконечный источник в массив (`Array.from`, расширение) зависает или падает.
* Класс хранит один итератор вместо генераторного метода, и второй обход оказывается пустым.
* `take` запрашивает у источника лишний элемент или не закрывает его.
* `["1", "2", "3"].map(parseInt)` даёт `[1, NaN, NaN]`: индекс становится основанием системы счисления.
* `[10, 9, 1].sort()` ставит `10` раньше `9`: сравнение идёт по строкам.
