## Что проверяет эта проверка

Цепочка прототипов и поиск свойств, собственные и унаследованные свойства, `Object.create`, классы с `extends`, приватные поля `#`, статические методы, поверхностное и глубокое копирование.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитывается урок: [Объекты, прототипы и классы](lesson:javascript.fundamentals.objects-and-prototypes).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```javascript run
class Counter {
  #count = 0;
  inc() { return ++this.#count; }
}
const c = new Counter();
c.inc();
console.log(c.inc(), Object.keys(c), JSON.stringify(c));

const base = { kind: "base" };
const child = Object.create(base);
child.own = 1;
console.log(Object.hasOwn(child, "kind"), "kind" in child, Object.getPrototypeOf(child) === base);
```
```output
2 [] {}
false true true
```

Приватное поле `#count` не видно снаружи ни ключам, ни JSON. Свойство `kind` не принадлежит `child`, но поиск по цепочке прототипов его находит.

<!-- section: precise -->
## Что нужно уметь

* описать, как движок ищет свойство: сначала у самого объекта, затем по цепочке `[[Prototype]]` до `null`;
* знать, что присваивание создаёт собственное свойство, а `delete` убирает только его;
* различать `Object.hasOwn(obj, key)` и оператор `in`;
* создавать объекты с заданным прототипом через `Object.create` и читать цепочку через `Object.getPrototypeOf`;
* писать классы с `extends`, `super`, приватными полями и статическими методами (`new this()` в статическом фабричном методе);
* понимать, что `{ ...obj }` копирует один уровень, а `structuredClone` делает глубокую копию.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* Поле, названное с подчёркиванием (`_items`), не приватно: к нему можно обратиться снаружи.
* Метод `toArray`, возвращающий внутренний массив, раскрывает приватное состояние.
* `new Stack()` внутри статического метода всегда создаёт базовый класс, даже если вызвали подкласс.
* `obj.hasOwnProperty(key)` ломается на объектах без прототипа; надёжнее `Object.hasOwn`.
* Расширение `{ ...a }` оставляет вложенные объекты общими.
