## Что проверяет эта проверка

Приведение типов при `+`, `*`, `==` и в шаблонных строках, разница между `==`, `===`, `Object.is` и сравнением `includes`, особые значения `NaN` и `-0`, строгий разбор чисел из строк, `parseInt` против `Number`.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Значения, ссылки и равенство](lesson:javascript.first-steps.values-and-equality), [Типы и приведение типов](lesson:javascript.fundamentals.types-and-coercion).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

<!-- section: examples -->
## Пример того, что понадобится

```javascript run
const samples = ["42", " 7 ", "", "12px", "0x10"];
for (const s of samples) {
  const strict = /^[+-]?\d+$/.test(s.trim()) ? Number(s) : null;
  console.log(JSON.stringify(s), Number(s), strict);
}
console.log(NaN === NaN, Object.is(NaN, NaN), [NaN].includes(NaN));
```
```output
"42" 42 42
" 7 " 7 7
"" 0 null
"12px" NaN null
"0x10" 16 null
false true true
```

`Number` прощает пустую строку и шестнадцатеричную запись, поэтому для строгого разбора нужна проверка формата до приведения. `NaN` не равен себе при `===`, но `Object.is` и `includes` считают его равным.

<!-- section: precise -->
## Что нужно уметь

* предсказывать результат `+` для смеси чисел и строк и результат `*`, `-`, `/` (всегда числа);
* знать, что `==` приводит типы по фиксированным правилам, и писать код с `===`;
* различать `null == 0` (ложь) и `null >= 0` (истина);
* объяснять, когда вызываются `valueOf` и `toString` у объекта;
* проверять `NaN` через `Number.isNaN` и различать `0` и `-0` через `Object.is`;
* отличать `parseInt` (читает префикс) от `Number` (требует всю строку).

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* `Number("")` и `Number("  ")` дают `0`, поэтому пустой ввод незаметно становится числом.
* `Boolean("false")` истинно: любая непустая строка истинна.
* Глобальный `isNaN` приводит аргумент к числу, и `isNaN("abc")` истинно; нужен `Number.isNaN`.
* `[] == ![]` истинно, потому что оба операнда сначала приводятся к числам.
* `parseInt("08px")` возвращает `8`, и ошибка разбора остаётся незамеченной.
