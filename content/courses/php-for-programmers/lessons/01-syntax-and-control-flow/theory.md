## Зачем этот урок

Если вы пишете на Python, Java, C#, Go или JavaScript, то условия, циклы и арифметику в PHP узнаете сразу. Сложности начинаются там, где PHP «помогает»: сравнивает `"10"` и `"1e1"` как числа, считает строку `"0"` ложной, возвращает `false` вместо ошибки и меряет строки байтами. Урок собирает такие места вместе. Успешное прохождение (упражнение и квиз) засчитывает уроки 01-15 курса «PHP с нуля».

## Главная мысль

PHP динамически типизирован и по умолчанию **слабо** типизирован: операторы и функции сами приводят значения к нужному типу. Три привычки снимают большинство проблем: сравнивать только через `===`, проверять ввод явно (`filter_var`, `is_numeric`) и помнить, что строка - это последовательность **байтов**, а не символов. Здесь и далее все примеры начинаются с `<?php` и `declare(strict_types=1);` - строгий режим вызовов, о границах которого говорит следующий урок.

<!-- section: examples -->
## Пример 1. Равенство и сравнение

```php run
<?php
declare(strict_types=1);

echo json_encode(["10" == "1e1", 100 == "1e2", "1" == "01", null == false, [] == false, "0" == false, 0 == "a", 0 == "", "abc" == 0, null == 0]), "\n";
echo json_encode(["10" === "1e1", "1" === "01", 1 === 1.0, "abc" === "abc", [1, 2] === [1, 2], [1, 2] === [2 => 1]]), "\n";
echo json_encode([1 <=> 2, "a" <=> "b", [1, 2] <=> [1, 3], "10" <=> "9", "10" <=> "9a"]), "\n";
```
```output
[true,true,true,true,true,true,false,false,false,true]
[false,false,false,true,true,false]
[-1,-1,-1,1,-1]
```

Две **числовые** строки `==` сравнивает как числа: `"10"` и `"1e1"` - одно и то же число, поэтому результат `true`. Если одна из строк не числовая, сравнение идёт как со строками. `null`, `false`, `[]`, `"0"` и `0` в разных парах «равны» друг другу, поэтому `==` не транзитивен. В PHP 8 число и **нечисловая** строка сравниваются как строки: `0 == "a"` ложно (в PHP 7 было истинно), но на это правило лучше не опираться. `===` требует совпадения типа и значения (`1 === 1.0` ложно). Оператор `<=>` возвращает `-1`, `0` или `1`; для двух числовых строк он тоже сравнивает числа.

## Пример 2. Числа

```php run
<?php
declare(strict_types=1);

var_dump(7 / 2, 6 / 3, intdiv(7, 2), -7 % 3, intdiv(-7, 2), 2 ** 3, 2 ** -1);
var_dump(PHP_INT_MAX + 1, 0.1 + 0.2 == 0.3, round(2.5), round(-2.5), (int) -3.99);
```
```output
float(3.5)
int(2)
int(3)
int(-1)
int(-3)
int(8)
float(0.5)
float(9.223372036854776E+18)
bool(false)
float(3)
float(-3)
int(-3)
```

Оператор `/` возвращает `int`, только если деление нацело (`6 / 3`), иначе `float`. Целочисленное деление - `intdiv` (округляет к нулю), остаток `%` берёт знак делимого: `-7 % 3` равно `-1`. Целые числа 64-битные; при переполнении `int` молча превращается в `float`. `round` округляет половину от нуля и всегда возвращает `float`; приведение `(int)` отбрасывает дробную часть.

## Пример 3. Строки в арифметике

```php run
<?php
declare(strict_types=1);

var_dump("10" + "5", "10" . "5", "1.5" + 1, "5" * "4");
var_dump((int) "12abc", (int) "abc", is_numeric("1e3"), is_numeric(" 5"), is_numeric("5 "), is_numeric("5 apples"));
try {
    echo "abc" * 1;
} catch (TypeError $e) {
    echo get_class($e), ": ", $e->getMessage(), "\n";
}
```
```output
int(15)
string(3) "105"
float(2.5)
int(20)
int(12)
int(0)
bool(true)
bool(true)
bool(true)
bool(false)
TypeError: Unsupported operand types: string * int
```

Для сложения и склейки у PHP разные операторы: `+` всегда арифметика, `.` всегда склейка, поэтому `"10" + "5"` равно `15`, а `"10" . "5"` - `"105"`. Числовая строка в арифметике превращается в число. Строка с мусором после числа (`"5 apples"`) даёт число и предупреждение `Warning: A non-numeric value`, а полностью нечисловая (`"abc"`) в PHP 8 бросает `TypeError`. Приведение `(int)` ничего не бросает: `"abc"` молча становится `0`. Строгий режим этого не меняет: он проверяет только вызовы функций, но не арифметику.

## Пример 4. Строки - это байты

```php run
<?php
declare(strict_types=1);

$word = "Привет";
echo strlen($word), " ", mb_strlen($word), "\n";
echo strtoupper($word), " ", mb_strtoupper($word), "\n";
echo strrev("abc"), " ", mb_substr($word, 0, 3), " ", substr($word, 0, 3) === "При" ? "да" : "нет", "\n";
echo str_pad("Привет", 10, "."), "|", mb_str_pad("Привет", 10, "."), "|\n";
```
```output
12 6
Привет ПРИВЕТ
cba При нет
Привет|Привет....|
```

Файл хранится в UTF-8: латинская буква занимает один байт, кириллическая - два. Функции без префикса `mb_` (`strlen`, `substr`, `strtoupper`, `str_pad`) работают с байтами и режут кириллицу посередине символа. Для текста пользователя берите `mb_strlen`, `mb_substr`, `mb_strtoupper` и `mb_str_pad` (последняя есть с PHP 8.3). Это расширение mbstring; в официальных сборках оно подключено.

## Пример 5. Ложные значения, ?? и switch

```php run
<?php
declare(strict_types=1);

var_dump((bool) "0", (bool) "0.0", (bool) "", (bool) [], (bool) [0], (bool) 0.0, (bool) "false");
$ok = true and false;
$ok2 = (true and false);
var_dump($ok, $ok2);
$config = ["port" => 0, "host" => null];
echo $config["port"] ?? 8080, " ", $config["port"] ?: 8080, " ", $config["host"] ?? "localhost", " ", $config["name"] ?? "-", "\n";

function label(mixed $x): string
{
    switch ($x) {
        case 0:
            return "ноль";
        case "a":
            return "a";
        default:
            return "другое";
    }
}

echo label("a"), " ", label("0"), " ", label(null), " ", label(""), "\n";
```
```output
bool(false)
bool(true)
bool(false)
bool(false)
bool(true)
bool(false)
bool(true)
bool(true)
bool(false)
0 8080 localhost -
a ноль ноль другое
```

Ложны `false`, `0`, `0.0`, `""`, `"0"`, `[]` и `null`; всё остальное истинно, включая `"0.0"`, `"false"` и `[0]`. Оператор `and` имеет приоритет ниже `=`, поэтому `$ok = true and false` присваивает `true`, а `and false` отбрасывается; для условий пишите `&&`. Оператор `??` подставляет запасное значение только для `null` и отсутствующего ключа, поэтому порт `0` сохраняется; `?:` реагирует на любое ложное значение и заменяет `0` на `8080`. `switch` сравнивает через `==`: `"0"` и `null` попадают в `case 0`.

## Пример 6. Проверка ввода: 0 - это не ошибка

```php run
<?php
declare(strict_types=1);

foreach (["42", "0", "-7", "007", "4.5", "1e3", "abc", " 12 ", ""] as $text) {
    $n = filter_var($text, FILTER_VALIDATE_INT);
    echo json_encode($text), " -> ", var_export($n, true), "\n";
}
```
```output
"42" -> 42
"0" -> 0
"-7" -> -7
"007" -> false
"4.5" -> false
"1e3" -> false
"abc" -> false
" 12 " -> 12
"" -> false
```

`filter_var($text, FILTER_VALIDATE_INT)` возвращает целое число или `false`. Результат `0` корректен, поэтому проверять нужно `$n === false`, а не `!$n`. Фильтр отвергает ведущие нули, дробную часть и экспоненту, но срезает пробелы по краям. При построчном чтении `fgets(STDIN)` возвращает строку **вместе с `\n`** (отсюда `trim`) и `false` в конце ввода; цикл всегда пишут как `while (($line = fgets(STDIN)) !== false)`.

<!-- section: precise -->
* Типы значений: `int`, `float`, `string`, `bool`, `array`, `null` (плюс объекты, ресурсы, функции). Целочисленный тип 64-битный, переполнение даёт `float`.
* Ложные значения: `false`, `0`, `-0`, `0.0`, `""`, `"0"`, `[]`, `null`. Строки `"0.0"`, `" "`, `"false"` и массив `[0]` истинны.
* `==` приводит типы: числовые строки сравниваются как числа, `null`/`false`/`0`/`""`/`[]` частично равны друг другу, число и нечисловая строка сравниваются как строки (PHP 8). `===` не приводит ничего. Для `switch` и `in_array` действует `==`.
* `/` даёт `int` только при делении нацело, иначе `float`; деление на ноль (`/`, `%`, `intdiv`) бросает `DivisionByZeroError`. `fdiv` возвращает `INF` и `NAN` без исключения.
* `%` работает с целыми и сохраняет знак делимого; `intdiv` округляет к нулю; `floor` и `round` возвращают `float`.
* `+` всегда арифметика, `.` всегда склейка. Число в начале строки (`"5 apples"`) допускается с предупреждением, строка без числа в арифметике - `TypeError`. `is_numeric` допускает пробелы в начале и конце и экспоненту.
* Приведения `(int)`, `(float)`, `intval` не проверяют ввод; проверка - `is_numeric` или `filter_var`.
* `and`, `or`, `xor` имеют приоритет ниже `=`; для условий используйте `&&`, `||`.
* `strlen`, `substr`, `strtoupper`, `str_pad` считают байты; для текста - `mb_`-версии. `declare(strict_types=1);` пишут первой инструкцией файла.

<!-- section: mistakes -->
**1. Число со словом в арифметике.**

```php
<?php
declare(strict_types=1);
$total = "5 apples" + 1;
echo $total, "\n";
```

```text
Warning: A non-numeric value encountered in main.php on line 3
```

Программа напечатает `6`, а предупреждение уйдёт в поток ошибок: данные «почти число» молча принимаются. Для проверки используйте `is_numeric` или `filter_var`.

**2. Строка без числа в арифметике.**

```php
<?php
declare(strict_types=1);
echo "abc" * 2;
```

```text
Fatal error: Uncaught TypeError: Unsupported operand types: string * int in main.php:3
```

Это `TypeError`. Приведение `(int) "abc"` такого исключения не бросает и тихо даёт `0`, поэтому ошибка ввода становится нулём.

**3. Деление на ноль.**

```php
<?php
declare(strict_types=1);
echo intdiv(10, 0);
```

```text
Fatal error: Uncaught DivisionByZeroError: Division by zero in main.php:3
```

Оператор `/` и `%` ведут себя так же (`Division by zero`, `Modulo by zero`). Проверьте делитель до вызова.

**4. Проверка ввода через `!$n`.**

```php
$n = filter_var("0", FILTER_VALIDATE_INT);
if (!$n) {
    echo "ошибка";   // сработает для корректного значения 0
}
```

Правильно: `if ($n === false)`. По той же причине цикл `while ($line = fgets(STDIN))` останавливается на последней строке `0` без перевода строки: `"0"` ложно.

**5. `strlen` для текста пользователя.** `strlen("Привет")` равно `12`, а `substr("Привет", 0, 3)` обрезает букву пополам. Нужны `mb_strlen` и `mb_substr`.

**6. `declare(strict_types=1)` не первой строкой.**

```php
<?php
echo "start\n";
declare(strict_types=1);
```

```text
Fatal error: strict_types declaration must be the very first statement in the script in main.php on line 3
```

Директива должна идти первой инструкцией файла (после `<?php`), иначе фатальная ошибка.

## Главное для тех, кто уже программирует

* Сравнивайте через `===` и `!==`. `==` приводит типы: `"10" == "1e1"`, `null == false`, `[] == false`, `"0" == false` истинны. В PHP 8 `0 == "a"` ложно.
* `int` 64-битный и при переполнении становится `float`; `/` не делит нацело (нужен `intdiv`); `%` как в C: знак делимого.
* `+` не склеивает строки (склейка - `.`), нечисловая строка в арифметике бросает `TypeError`, а `(int) "abc"` даёт `0`.
* Ложные значения: `0`, `0.0`, `""`, `"0"`, `[]`, `null`, `false`. `??` реагирует только на `null` и отсутствие ключа, `?:` - на любое ложное значение.
* `and`/`or` ниже `=` по приоритету; `switch` использует `==`; `match` - `===`.
* Строки - байты в UTF-8 (`strlen("Привет") === 12`); для текста есть `mb_*`.
* `fgets` возвращает `false` в конце ввода и строку с `\n`; `filter_var` вернёт `false` для ошибки и `0` для нуля.
* Предупреждения (`Warning`, `Deprecated`) не прерывают программу: ошибка может остаться незамеченной, если не смотреть stderr.
