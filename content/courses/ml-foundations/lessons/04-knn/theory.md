## Скажи мне, кто твои соседи

Метод `k` ближайших соседей (k-NN, k nearest neighbours) - самый «человеческий» алгоритм классификации. Чтобы определить класс нового объекта, найдите в обучающей выборке `k` самых похожих на него объектов и посмотрите, какой класс среди них встречается чаще. Так поступает врач, сравнивая пациента с похожими случаями, или вы, когда выбираете фильм по тем, что нравились людям с похожим вкусом.

Здесь нет «обучения» в привычном смысле: модель - это сама выборка. Вся работа происходит в момент предсказания: измерить расстояния до всех известных точек, отобрать ближайшие, посчитать голоса.

Два вопроса определяют поведение метода:

1. **Как измерять расстояние?** Для чисел на плоскости естественно евклидово расстояние (длина отрезка). Если признаки в разных масштабах, самый «крупный» признак заглушит остальные - снова нужна стандартизация.
2. **Сколько соседей брать?** При `k = 1` метод повторяет ближайшую точку, включая её ошибки (выбросы и неверные метки). При слишком большом `k` решает почти вся выборка, и редкие классы теряются. Хорошее значение выбирают по validation.

## Определение

Обучающая выборка `(x_1, y_1), ..., (x_m, y_m)`, точки `x_i ∈ ℝ^d`. Для запроса `q`:

1. Вычислить расстояния `d(q, x_i) = sqrt(Σ_j (q_j - x_{ij})^2)`.
2. Упорядочить индексы по возрастанию расстояния и взять первые `k`.
3. Метка ответа - самая частая среди `y_i` выбранных `k` соседей.

Корень можно не извлекать: функция `sqrt` монотонна, поэтому порядок по `d` и по `d^2` одинаков. В коде сравнивают **квадраты расстояний**, это быстрее и при целых координатах точно.

## Детерминированное разрешение ничьих

На практике ничьи неизбежны, а результат должен быть воспроизводимым. В этом курсе правила таковы:

1. **Ничья по расстоянию.** Порядок соседей определяется парой `(квадрат расстояния, индекс в обучающей выборке)`: при равных расстояниях раньше идёт точка с меньшим индексом.
2. **Ничья по голосам.** Среди меток с одинаковым максимальным числом голосов побеждает та, чей ближайший сосед стоит раньше в порядке из п. 1.
3. **Слишком большое `k`.** Если `k` больше размера выборки, берутся все точки.

Эти правила однозначны, и ответ не зависит от внутренних деталей реализации (в отличие от «взять первый из `max` по словарю»).

## Сложность

Для одного запроса: расстояния до `m` точек в `d` измерениях - `O(m·d)`, сортировка - `O(m log m)`. Время запроса `O(m·d + m log m)`, память `O(m)`. Вместо полной сортировки можно держать кучу размера `k` (`O(m log k)`) или использовать пространственные индексы (k-d деревья), но для высоких размерностей их выигрыш пропадает. Обучение не требует вычислений: `O(1)`, хотя хранить выборку нужно целиком (`O(m·d)`).

## Выбор `k`: leave-one-out

Чтобы выбрать `k` без отдельной валидационной части, на небольших данных используют **leave-one-out** (оставить один): для каждой точки `i` предсказывают её метку по всем остальным точкам и считают долю верных. Точка не должна участвовать в собственном предсказании, иначе при `k = 1` каждая точка нашла бы сама себя и точность была бы идеальной (это утечка). Сложность `O(m^2 d + m^2 log m)`.

**Компромисс смещения и дисперсии.** Малое `k` - гибкая, но шумная граница решений (риск переобучения); большое `k` - сглаженная граница, возможное недообучение. Для двух классов удобно брать нечётное `k`, чтобы ничьих по голосам не было.

## Примеры

**Пример 1. Классификация точки.**

```python run
train_x = [(0, 0), (0, 1), (1, 0), (5, 5), (5, 6), (6, 5)]
train_y = ["a", "a", "a", "b", "b", "b"]

def sqdist(p, q):
    return sum((u - v) ** 2 for u, v in zip(p, q))

def predict(query, k):
    order = sorted(range(len(train_x)), key=lambda i: (sqdist(train_x[i], query), i))
    labels = [train_y[i] for i in order[:k]]
    return max(set(labels), key=labels.count), labels

for q in [(1, 1), (4, 4), (6, 6)]:
    label, neighbours = predict(q, 3)
    print(q, "->", label, neighbours)
```
```output
(1, 1) -> a ['a', 'a', 'a']
(4, 4) -> b ['b', 'b', 'b']
(6, 6) -> b ['b', 'b', 'b']
```

**Пример 2. Влияние `k` и leave-one-out.** Одна точка помечена «неправильно» (выброс среди класса `a`). При `k = 1` она портит предсказания соседей, при `k = 3` или `5` - нет.

```python run
xs = [0, 1, 2, 3, 4, 5, 10, 11, 12, 13]
ys = ["a", "a", "a", "a", "b", "a", "b", "b", "b", "b"]

def predict(rest_x, rest_y, q, k):
    order = sorted(range(len(rest_x)), key=lambda i: ((rest_x[i] - q) ** 2, i))
    labels = [rest_y[i] for i in order[:k]]
    first = {}
    for pos, lab in enumerate(labels):
        first.setdefault(lab, pos)
    return min(set(labels), key=lambda lab: (-labels.count(lab), first[lab]))

for k in (1, 3, 5):
    ok = 0
    for i in range(len(xs)):
        rest_x, rest_y = xs[:i] + xs[i + 1:], ys[:i] + ys[i + 1:]
        ok += predict(rest_x, rest_y, xs[i], k) == ys[i]
    print("k =", k, "leave-one-out accuracy =", ok / len(xs))
```
```output
k = 1 leave-one-out accuracy = 0.8
k = 3 leave-one-out accuracy = 0.9
k = 5 leave-one-out accuracy = 0.9
```

**Пример 3. Ничья.** Две метки получили по два голоса; побеждает та, у которой ближайший сосед ближе.

```python run
train_x = [1, 2, 3, 4]
train_y = ["a", "a", "b", "b"]
query = 3.4

order = sorted(range(4), key=lambda i: ((train_x[i] - query) ** 2, i))
print("порядок соседей (индексы):", order)
print("метки по порядку:", [train_y[i] for i in order])
# голоса 2:2, первым идёт сосед с меткой b -> ответ b
```
```output
порядок соседей (индексы): [2, 3, 1, 0]
метки по порядку: ['b', 'b', 'a', 'a']
```

**Пример 4. Масштаб признаков.** Два признака: доход в рублях и возраст в годах. Клиенты `a` и `b` одного возраста, но доход отличается на 2000 рублей; клиент `c` с доходом как у `a` старше на 40 лет. Метрика считает `a` ближе к `c`, чем к `b`, потому что крупные числа дохода заглушают возраст. Поэтому признаки стандартизуют по train.

```python run
a = (50000, 30)
b = (52000, 30)   # доход отличается на 2000
c = (50000, 70)   # возраст отличается на 40 лет
d2 = lambda p, q: sum((u - v) ** 2 for u, v in zip(p, q))
print("расстояние^2 a-b:", d2(a, b), " a-c:", d2(a, c))
```
```output
расстояние^2 a-b: 4000000  a-c: 1600
```

## Типичные ошибки

* **Не учесть саму точку при leave-one-out.** Точка находит сама себя как ближайшего соседа, и точность завышена.
* **Забыть про масштаб признаков.** Признак с большими числами определяет расстояние полностью.
* **Недетерминированное разрешение ничьих.** Используйте полный порядок `(расстояние, индекс)` и явное правило для голосов; не полагайтесь на порядок обхода словаря или множества.
* **Сортировать обучающие данные на месте.** Меняется порядок индексов, и тай-брейк ломается; создавайте новый список индексов.
* **Взять `k` больше размера выборки без обработки.** Срез `order[:k]` безопасен, а вот собственный цикл может упасть.
* **Выбирать `k` по тесту.** Это гиперпараметр, подбирайте его по validation или leave-one-out.
* **Брать чётное `k` в бинарной задаче без правила для ничьих.** Получается неопределённое поведение.

## Итоги

* k-NN предсказывает метку большинством голосов среди `k` ближайших обучающих точек; обучения нет, работа в момент запроса.
* Сравнивать можно квадраты расстояний; порядок соседей - `(d², индекс)`.
* Ничьи по голосам разрешаются меткой, чей ближайший сосед ближе.
* Маленькое `k` - шумная граница, большое - сглаженная; `k` подбирают по validation или leave-one-out.
* Запрос стоит `O(m·d + m log m)`; признаки нужно масштабировать.

Этим уроком завершается курс «Основы машинного обучения». Дальше пригодятся деревья решений, ансамбли и регуляризация.
