# Разбор: k-NN с детерминированными ничьими

## Алгоритм
```
порядок = индексы 0..m-1, отсортированные по (d²(train_x[i], q), i)
соседи = порядок[:k]
для rank, i в соседях:
    голоса[y_i] += 1; первая_позиция.setdefault(y_i, rank)
ответ = метка с максимумом голосов, при равенстве - с наименьшей первой позицией
```

## Почему результат однозначен
Пара `(d², i)` задаёт **полный порядок** на индексах: два разных индекса никогда не сравниваются как равные, поэтому множество первых `k` соседей и их последовательность определены однозначно. Ключ `(-голоса, первая_позиция)` тоже полный порядок на метках: у разных меток первые позиции различны. Следовательно, победитель единственный и не зависит от порядка обхода словаря.

## Квадрат расстояния
`sqrt` возрастает, поэтому сортировка по `d²` даёт тот же порядок, что по `d`. Для целых координат `d²` вычисляется точно, и равенства расстояний обнаруживаются надёжно (с `float` после `sqrt` можно получить расхождения в последнем бите).

## Leave-one-out
Для точки `i` обучающей выборкой служит срез без `i`; порядок оставшихся сохраняется, поэтому тай-брейк по индексу одинаков у всех реализаций. Если оставить точку `i` в обучении, расстояние до неё равно 0, и при `k = 1` метод всегда угадывает.

## Сложность
Один запрос: `O(m·d)` на расстояния плюс `O(m log m)` на сортировку; leave-one-out по всем точкам: `O(m²·d + m² log m)`. Для больших `m` заменяют сортировку на кучу размера `k` (`O(m log k)`) или используют пространственный индекс.

## Подводные камни
* Сортировать нужно список индексов, а не сами обучающие данные: иначе тай-брейк по индексу теряет смысл.
* `max(set(labels), key=labels.count)` при ничьей возвращает произвольный элемент: порядок обхода множества не определён. Нужен явный ключ.
* Масштабируйте признаки по train перед использованием расстояния; здесь тесты работают с уже сопоставимыми координатами.
