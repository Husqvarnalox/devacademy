# Разбор: градиентный спуск для линейной регрессии

## Что нужно получить
Параметры `w, b`, минимизирующие `MSE = (1/n)·Σ(w·x + b - y)^2`. Проверка - аналитическое решение метода наименьших квадратов.

## Из потерь в шаг
Ошибка точки `e_i = w·x_i + b - y_i`. По правилу цепочки `∂L/∂w = (2/n)·Σ e_i·x_i`, `∂L/∂b = (2/n)·Σ e_i`. Один шаг: `w ← w - lr·∂L/∂w`, `b ← b - lr·∂L/∂b`. Градиенты вычисляются по одним и тем же старым `(w, b)`: если пересчитать `b` по уже обновлённому `w`, это уже другой алгоритм.

## Почему спуск приходит к МНК
`L` - выпуклая квадратичная функция двух переменных, её единственный минимум - решение уравнения `∇L = 0`, то есть нормальное уравнение МНК. На квадратичной функции шаг `lr < 2/λ_max` сжимает расстояние до минимума в каждом собственном направлении в `|1 - lr·λ_i|` раз, поэтому ошибка убывает геометрически. Если хотя бы одно `|1 - lr·λ_i| > 1`, ошибка растёт - так тест «большой lr расходится» отличает честный спуск от готовой формулы.

## Масштаб признаков
Для данных `x ∈ [100, 1000]` наибольшее собственное число гессиана порядка `10^6`, поэтому допустимый `lr` порядка `10^-6`; `lr = 0.1` сразу расходится. После стандартизации гессиан равен `2·I`, спуск сходится при любом `lr < 1`, а `lr = 0.1` даёт множитель `0.8` на эпоху. Параметры возвращаются в исходный масштаб подстановкой `z = (x - μ)/σ`.

## Сложность
Время `O(n · epochs)`, память `O(1)` сверх входа. Аналитическое решение - `O(n)`, поэтому на реальных линейных задачах малого размера спуск не нужен; его ценность - в моделях без формулы.

## Подводные камни
* Делить градиент на `n` и не терять множитель 2.
* Не масштабировать данные внутри `fit` - иначе тест «без масштабирования расходится» будет противоречить условию.
* Считать `σ` с делением на `n`, как в условии. На итоговые `w, b` в исходном масштабе выбор `n` или `n - 1` не влияет (масштаб сокращается), но скорость сходимости в стандартизованных координатах немного меняется.
* Постоянный признак: `σ = 0`, деления быть не должно.
