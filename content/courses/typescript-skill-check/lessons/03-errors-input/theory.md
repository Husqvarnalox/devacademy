## Что проверяет эта проверка

Выбрасывание ошибки через `throw new Error`, перехват блоком `try / catch / finally`, значение `unknown` в `catch` и проверка `instanceof Error`, разбор текста построчно, строгая проверка чисел (`Number`, `NaN`) и подсчёт пропущенных строк.

## Что даёт прохождение

Проверка состоит из короткого упражнения с запуском тестов и квиза на чтение кода (порог квиза - 75%). Если пройдены обе части, засчитываются уроки: [Ошибки и исключения](lesson:typescript.from-zero.errors-and-exceptions), [Чтение ввода](lesson:typescript.from-zero.reading-input).

Если не пройдены, ничего не отнимается: прогресс сохраняется, а система покажет первый незавершённый урок из этого списка как место для повторения. Проверку можно пройти снова в любой момент, и открыть её можно без каких-либо условий.

## Пример того, что понадобится

```typescript run
function parsePercent(text: string): number {
  const value: number = Number(text.trim());
  if (text.trim() === "" || Number.isNaN(value) || value < 0 || value > 100) {
    throw new Error("процент вне диапазона: " + JSON.stringify(text));
  }
  return value;
}

const lines: string[] = ["40", "x", "", "100", "101"];
let sum = 0;
let skipped = 0;
for (const line of lines) {
  try {
    sum += parsePercent(line);
  } catch (error) {
    skipped++;
    if (error instanceof Error) {
      console.log(error.message);
    }
  }
}
console.log(sum, skipped);
```
```output
процент вне диапазона: "x"
процент вне диапазона: ""
процент вне диапазона: "101"
140 3
```

Функция проверяет входные данные и выбрасывает `Error`; цикл ловит ошибку внутри `try`, считает пропуск и продолжает работу со следующей строкой. Пустая строка отдельно проверяется до `Number`, потому что `Number("")` равно `0`. В `catch` значение имеет тип `unknown`, поэтому до чтения `message` нужна проверка `instanceof Error`.

<!-- section: precise -->
## Что нужно уметь

* выбрасывать `new Error("текст")` в начале функции, когда данные неверны;
* перехватывать ошибку в `try / catch` и читать сообщение только после `instanceof Error`;
* продолжать цикл после ошибки на одной строке;
* делить текст на строки (`split`, `trim`) и пропускать пустые;
* превращать строку в число и распознавать неудачу (`Number`, `Number.isNaN`, пустая строка);
* предсказывать порядок `try`, `catch` и `finally`.

<!-- section: mistakes -->
## На чём чаще всего ошибаются

* `Number("")` и `Number("  ")` равны `0`, поэтому пустая строка незаметно становится оценкой.
* Чтение `error.message` без проверки: в строгом режиме значение в `catch` имеет тип `unknown` (`TS18046`).
* `split("\n")` оставляет пустой последний элемент, если текст заканчивается переводом строки.
* Пустой `catch {}` скрывает не только неверные данные, но и ошибки в самом коде.
* `finally` выполняется всегда, даже если в `try` уже стоит `return`.
