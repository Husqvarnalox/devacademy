## Срез - это окно на массив

Массив в Go имеет фиксированную длину, поэтому в программах почти всегда используют **срезы** (`[]int`). Срез - маленькая структура из трёх полей:

1. **указатель** на элемент базового массива, с которого начинается срез;
2. **len** - сколько элементов видно;
3. **cap** - сколько элементов можно использовать от начала среза до конца базового массива.

Из этого следует главное: **несколько срезов могут смотреть на один и тот же массив**. Присваивание `b := a` копирует только эти три числа, а не элементы. Изменение через `b` видно через `a`.

```go
a := []int{1, 2, 3}
b := a
b[0] = 99
fmt.Println(a[0]) // 99
```

`append(s, x)` добавляет элемент. Если `len < cap`, он записывается **в тот же массив**; если места нет, Go выделяет новый массив большего размера, копирует туда элементы, и результат уже не связан со старым массивом. Поэтому результат `append` всегда присваивают: `s = append(s, x)`.

## len, cap, срезы срезов и append

**Устройство.** Срез - заголовок `{ptr, len, cap}`. Передача среза в функцию копирует заголовок (три слова), а не данные: функция может изменить элементы, видимые вызывающему коду, но `append` внутри функции не изменит длину среза у вызывающего.

**Создание.** `[]int{1,2,3}` - литерал; `make([]int, n)` - `n` нулевых элементов (`len = cap = n`); `make([]int, 0, 10)` - пустой срез с запасом `cap = 10`.

**Срез среза.** `s[i:j]` даёт срез от `i` до `j-1`: `len = j - i`, `cap = cap(s) - i`. Данные не копируются. Запасная ёмкость сохраняется: `s[:2]` у среза из пяти элементов имеет `len = 2`, а `cap = 5`, то есть `append` к нему перезапишет `s[2]`.

**Тройной срез.** `s[i:j:k]` ограничивает ёмкость: `cap = k - i`. Тогда `append` к результату вынужден выделить новый массив и не затронет оригинал.

**Рост.** Когда `len == cap`, `append` создаёт новый массив большего размера. Точная формула роста - деталь реализации и меняется между версиями Go, поэтому рассчитывать на конкретное значение `cap` после `append` нельзя. Можно полагаться только на то, что `cap >= len`.

**copy.** `copy(dst, src)` копирует `min(len(dst), len(src))` элементов и возвращает их число. Чтобы получить независимую копию: `c := make([]int, len(s)); copy(c, s)` или `slices.Clone(s)`.

**nil-срез.** `var s []int` равен `nil` (`len = cap = 0`), и `append` к нему работает. Пустой срез `[]int{}` не `nil`, но для `len`, `range`, `append` они ведут себя одинаково.

**Удаление элемента.** Идиома `s = append(s[:i], s[i+1:]...)` сдвигает хвост влево **в том же массиве**. Если на тот же массив смотрит другой срез, он увидит изменённые данные. Для независимого результата сначала создайте копию.

**Утечка памяти.** Маленький срез от большого массива удерживает весь массив в памяти, пока на него есть ссылка.

**Сравнение.** Срезы нельзя сравнивать через `==` (кроме сравнения с `nil`). Для содержимого - `slices.Equal`.

## Примеры

**Пример 1. Общий массив.**

```go run
package main

import "fmt"

func main() {
    a := []int{1, 2, 3}
    b := a
    b[0] = 99
    fmt.Println(a, b)
    c := make([]int, len(a))
    copy(c, a)
    c[1] = -1
    fmt.Println(a, c)
}
```
```output
[99 2 3] [99 2 3]
[99 2 3] [99 -1 3]
```

**Пример 2. len и cap у среза среза.**

```go run
package main

import "fmt"

func main() {
    s := make([]int, 5, 8)
    t := s[2:4]
    fmt.Println(len(s), cap(s))
    fmt.Println(len(t), cap(t))
    u := s[2:4:4]
    fmt.Println(len(u), cap(u))
}
```
```output
5 8
2 6
2 2
```

**Пример 3. append в запас перезаписывает соседей.**

```go run
package main

import "fmt"

func main() {
    s := []int{1, 2, 3, 4, 5}
    t := s[:2]
    t = append(t, 100)
    fmt.Println(s)
    fmt.Println(t)
}
```
```output
[1 2 100 4 5]
[1 2 100]
```

`t` имеет `cap = 5`, поэтому `append` записал 100 в тот же массив на место `s[2]`.

**Пример 4. Тройной срез защищает оригинал.**

```go run
package main

import "fmt"

func main() {
    s := []int{1, 2, 3, 4, 5}
    t := s[:2:2]
    t = append(t, 100)
    fmt.Println(s)
    fmt.Println(t)
}
```
```output
[1 2 3 4 5]
[1 2 100]
```

**Пример 5. Функция и append.**

```go run
package main

import "fmt"

func grow(s []int) {
    s = append(s, 1)
    s[0] = -1
}

func main() {
    s := make([]int, 1, 1)
    grow(s)
    fmt.Println(s, len(s))
    p := make([]int, 1, 5)
    grow(p)
    fmt.Println(p, len(p))
}
```
```output
[0] 1
[-1] 1
```

В первом вызове `append` выделил новый массив, и `s[0] = -1` изменило уже его. Во втором место было, и запись попала в общий массив, но длина `p` у вызывающего осталась `1`.

## Типичные ошибки

* **Не присвоить результат `append`.** `append(s, x)` без `s =` бесполезен.
* **Считать, что `b := a` копирует данные.** Копируется заголовок; элементы общие.
* **Удаление через `append(s[:i], s[i+1:]...)`, когда оригинал нужен.** Сдвиг портит исходные данные. Скопируйте перед удалением.
* **Опираться на `cap` после `append`.** Формула роста не гарантирована.
* **Хранить срез на огромный массив.** Маленький срез удерживает весь массив; скопируйте нужную часть.
* **Сравнивать срезы через `==`.** Не компилируется; используйте `slices.Equal`.
* **Модификация среза в цикле `range` по нему.** `range` вычисляет срез один раз; добавленные элементы не будут пройдены.
* **Выход за пределы.** `s[5]` при `len = 3` - паника `index out of range` во время работы.

## Итоги

* Срез - это `{ptr, len, cap}` поверх массива; присваивание и передача в функцию копируют заголовок, а не данные.
* `append` пишет в общий массив, пока есть `cap`, и выделяет новый, когда места нет; всегда присваивайте результат.
* `s[i:j:k]` ограничивает `cap`; независимую копию делают через `copy` или `slices.Clone`.
* Идиома удаления сдвигает элементы в том же массиве.
